## บทนำ
วิดีโอสาธิตวิธีสมัครใช้งาน RapidAPI ฟรี เพื่อรับ API key ของเครื่องมือ YouTube Video Summarizer GPT AI สำหรับใช้สรุปวิดีโอ YouTube

## คำแปลเต็ม

บน rapidapi.com มีเครื่องมือชื่อ YouTube Video Summarizer GPT AI และเราสามารถใช้มันได้ คุณต้องสมัครบัญชี Rapid API ก่อน ฟรี จากนั้นไปที่บัญชีนี้ แล้วคลิกที่ปุ่ม subscribe จากนั้นคุณสามารถสมัครแพ็กเกจฟรี (free plan) ได้ แล้วคลิกที่ create summary ตรงนี้ และตรงนี้คุณจะเห็น API key ของคุณ แต่คุณไม่สามารถคัดลอกมันได้จริง ๆ ผมเองก็ไม่รู้เหมือนกันว่าทำไม แต่ผมก็คัดลอกอันเดียวกันกับที่แสดงอยู่ตรงนี้ แล้วกลับไป แล้วก็วางมันลงตรงนี้
