GitHub มันก็เหมือน Google Drive แต่สำหรับไฟล์บนคอมพิวเตอร์ของคุณจริง ๆ ถ้าคุณกำลังคิดว่า ทำไมฉันไม่อัปโหลดไฟล์ทั้งหมดของฉันขึ้น Google Drive ล่ะ จริง ๆ แล้วคุณทำได้นะ แต่ Google Drive ไม่ได้ถูกสร้างมาเพื่อสิ่งนี้ GitHub คือที่ที่คุณเก็บไฟล์ทั้งหมดของคุณ เพื่อให้เอเจนต์ AI อ่านได้ง่าย ๆ Claude Code อ่านมันได้ง่ายมาก ดึงข้อมูลและแยกมันออกมาได้เลย ส่วน Google นั้นทำได้ยากมาก ต้องตั้งค่าอะไรเยอะแยะ แต่อันนี้ง่ายสุด ๆ ซึ่งก็ตลกดี เพราะคนส่วนใหญ่คิดว่ามีแต่โปรแกรมเมอร์เท่านั้นที่ใช้ GitHub แต่ตอนนี้คุณและผมเริ่มใช้มันกันแล้ว

แต่มันง่ายมากนะครับ เราใช้ GitHub เพื่อเก็บไฟล์ทั้งหมดของเรา แค่นั้นเอง เราไม่ได้เก็บอะไรอื่น เราใช้มันเพื่อเก็บไฟล์ล้วน ๆ และสิ่งที่เราทำคือ ทุกครั้งที่คุณทำงานบนคอนเทนต์ของคุณ ใช่ไหม นี่คือคุณ กำลังทำงานอยู่บนอะไรสักอย่าง วาดได้แย่มาก แต่ว่าโดยพื้นฐานแล้ว ทุกครั้งที่คุณทำงานเสร็จ คุณจะส่งมันขึ้นไปบน GitHub ซึ่งก็คือคลาวด์นั่นแหละ มันรันอยู่ตลอด 24 ชั่วโมง

ปัญหาของการไม่ push ไฟล์ขึ้น GitHub คือ คุณมีไฟล์อยู่แค่ในเครื่องของคุณ ใช่ไหมครับ สมมติว่านี่คือคอมพิวเตอร์ของคุณ โอเค สมมติว่านี่คอมพิวเตอร์ของคุณ และคุณกำลังคุยกับใครสักคน แล้วสมมติว่าคุณทำน้ำหกใส่ หรือสมมติว่ามีคนขโมยมันไป ไฟล์ทั้งหมดที่อยู่บนคอมพิวเตอร์ของคุณก็จะหายไปตลอดกาล อยู่ในความว่างเปล่า และคุณไม่มีทางได้มันกลับคืนมา

ทำไมคุณถึงต้องใช้ GitHub เพราะทุกครั้งที่คุณทำงานเสร็จ คุณสามารถทำสิ่งที่เรียกว่า push ซึ่งก็คือการส่งไฟล์ของคุณขึ้นไป และมันจะบันทึก snapshot ของไฟล์ทั้งหมดเอาไว้ ดังนั้นมันไม่เพียงช่วยบันทึกไฟล์ของคุณไว้ในที่ที่มันอยู่ แต่มันยังบันทึกประวัติของไฟล์ทั้งหมดของคุณด้วย คุณจะมีสิ่งที่เรียกว่า change log ที่คุณสามารถดูการเปลี่ยนแปลงทั้งหมดที่คุณทำได้ตลอดเวลา ซึ่ง Google Drive และซอฟต์แวร์อื่น ๆ ไม่สามารถทำได้ นั่นคือเหตุผลที่มันสำคัญมาก

และเหตุผลที่สำคัญจริง ๆ คือ สมมติว่าคอมพิวเตอร์เครื่องนั้นระเบิดขึ้นมาจริง ๆ คุณก็แค่ซื้อคอมพิวเตอร์เครื่องใหม่ ใช่ไหมครับ นี่เครื่องใหม่ ดูดีมาก ดีใจด้วยนะ แล้วคุณก็แค่ดึงไฟล์ทั้งหมดลงมาบนเครื่องนี้ ทุกอย่างที่อยู่บนแล็ปท็อปเครื่องเก่า ก็จะย้ายมาอยู่บนเครื่องใหม่เรียบร้อย

อีกคำถามที่ผมเจอบ่อยคือ ถ้าผมมีคอมพิวเตอร์สองเครื่อง หรือผมมีแล็ปท็อปหนึ่งเครื่องกับเดสก์ท็อปหนึ่งเครื่อง แล้วผมจะแชร์ไฟล์ระหว่างมันยังไง นี่คือวิธีแชร์ไฟล์: ผ่าน GitHub ทุกอย่างที่คุณทำงาน คุณสามารถบันทึกมันขึ้นไปได้ แล้วคุณก็ใช้เดสก์ท็อปอีกเครื่องเพื่อดึงไฟล์ทั้งหมดนั้นลงมาบนคอมพิวเตอร์ของคุณ คุณสามารถทำงานบนแล็ปท็อปหลายเครื่องพร้อมกันได้เลยถ้าต้องการ

มันยังใช้ได้กับทีมอีกด้วย สมมติว่านี่คือคุณ นี่คือเพื่อนร่วมทีมของคุณ แล้วคุณทั้งคู่กำลังทำงานในไฟล์ธุรกิจของคุณ คุณทั้งคู่สามารถทำงานบนไฟล์เดียวกัน บันทึกทุกอย่าง และเห็นว่าใครกำลังทำอะไรอยู่ นั่นคือเหตุผลที่ GitHub สำคัญมาก

การตั้งค่ามันง่ายมาก สิ่งที่คุณต้องทำคือไปที่ GitHub แล้วคลิก sign up ผมต้องคลิก sign in เพราะผมต้องล็อกอินกลับเข้ามา แล้วผมจะล็อกอินเร็ว ๆ คุณก็แค่สมัครด้วยบัญชี Google หรืออะไรก็ได้ แล้วทำตามขั้นตอนให้ครบ แล้วคุณก็จะเข้ามาที่หน้านี้ สิ่งนี้คือ feed มันเกือบจะเหมือนโซเชียลมีเดีย แต่สำหรับ commits และ pushes ทั้งหมด นั่นคือการเปลี่ยนแปลงทั้งหมดที่คุณทำกับไฟล์ของคุณ

ดูสิ นี่คือทีม dev ของผม เราสร้างไฟล์บางอย่างสำหรับโปรเจกต์ของลูกค้า มันโผล่ขึ้นมาใน feed ผมสามารถเห็นได้ว่าใครกำลังทำงานอะไรอยู่ตลอดเวลา และมีการเปลี่ยนแปลงอะไรเกิดขึ้นบ้าง แล้วคุณจะเห็นทางซ้ายมีสิ่งที่เรียกว่า repositories ดังนั้นเวลาผมพูดถึงคำว่า repo หรือ GitHub นั่นคือสิ่งที่ผมหมายถึง มันก็คือ repository นั่นแหละ repository คืออะไร ก็แค่โฟลเดอร์ที่คุณใช้เก็บของทั้งหมดของคุณ

ผมอาจจะพาคุณดูอย่างอื่นอีก แต่ผมไม่ค่อยได้เข้าไปยุ่งกับมัน สิ่งเดียวที่คุณต้องรู้จริง ๆ คือ settings ซึ่งคุณสามารถเปลี่ยน repository เพื่อเชิญคนเข้ามาในโปรเจกต์ของคุณ ให้มาร่วมงานกันได้ มี tokens และอีกหลายอย่าง แต่สำหรับการสร้าง repo แรกของคุณ สิ่งที่คุณต้องทำคือคลิก new ตั้งชื่อมัน ผมจะตั้งชื่อว่า Noah Test123 แล้วคุณไม่ต้องใส่คำอธิบายด้วยซ้ำ แล้วเลือก visibility สำคัญมาก ให้ตั้งเป็น private คุณไม่ต้องการให้คนอื่นเข้าถึงมัน แล้วก็ add a read me แค่นั้นแหละ แล้วเลือก owner คุณต้องเลือกตัวคุณเอง ซึ่งก็แปลกดี แล้วก็ create the repository บูม ตอนนี้คุณมี repo แล้ว เยี่ยม คุณไปได้เลย
