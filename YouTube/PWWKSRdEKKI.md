## ประเด็นหลัก

- ปัญหาที่ระบบนี้แก้: คนส่วนใหญ่ใช้ AI แบบแยกส่วน — หลายแท็บ หลายแอป หลาย login แต่ไม่มีความทรงจำร่วมกัน ต้องคอยอธิบายตัวเองซ้ำทุกครั้งที่เปิดแชทใหม่
- แนวคิดหลักคือ One Screen AI Team — จอเดียว ความทรงจำชุดเดียว agent ทุกตัว (Claude, Hermes, OpenClaw ฯลฯ) ทำงานบน dashboard เดียวกันและอ่านข้อมูลจากสมองเดียวกัน
- ระบบประกอบด้วย Hermes Apollo (แชทเสียง), Hermes Oracle (เฝ้าดูคู่แข่ง), Hermes Astros (มอนิเตอร์คีย์เวิร์ด) และแชทหลักกับ Hermes บนหน้า Mission Control
- หัวใจของระบบคือความทรงจำ — ทุกบทสนทนาถูกบันทึกลง Obsidian vault อัตโนมัติ และ agent ทุกตัวอ่านจาก vault เดียวกัน ทำให้สลับโมเดลเมื่อไหร่ก็ไม่ต้องอธิบายตัวเองใหม่
- Kanban board เปลี่ยนวิธีทำงานจาก "เขียน prompt" เป็น "ยื่น ticket" โดย dispatcher จะสร้าง worker agent ขึ้นมาทำงานให้เสร็จโดยไม่ต้องคอยดูแล
- Goal Mode (โหมดเป้าหมาย) คือจุดที่ทรงพลังที่สุด — พิมพ์เป้าหมายใหญ่หนึ่งอย่าง แล้ว Hermes วนลูปทำงานอัตโนมัติหลายชั่วโมง กลับมาอีกทีงานเสร็จรออยู่แล้ว
- ระบบใช้ cron jobs (งานตามตารางเวลา) เป็นอัตโนมัติชั้นที่สอง เช่น Oracle เช็คคู่แข่งทุกสองสามชั่วโมง หรือตั้งรายงานประจำสัปดาห์ครั้งเดียวรันไปตลอด
- Hermes มี guardrails ในตัว — ถ้า agent เจอการกระทำเสี่ยง เช่น ลบไฟล์ มันจะหยุดถามเจ้าของก่อน แล้วค่อยกลับมาทำต่อ
- สลับโมเดลใหม่ได้ในสองคลิกจากแท็บ Manage (เช่น LFM 2.5, MuseSpark 1.2, Qwen 3.8) โดยความทรงจำ workflow และ dashboard ไม่เปลี่ยนแปลง
- รันได้โดยไม่แพง — ใช้โมเดลท้องถิ่นฟรี (LFM 2.5 2B, Omni Router) หรือ Claude Code เวอร์ชันฟรี งานเดียวกันอาจเสียเงินเป็นดอลลาร์บนโมเดลพรีเมียมแต่เป็นศูนย์บน local
- เข้าถึงได้จากทุกที่ด้วย Tailscale (ฟรี ตั้งค่า ~10 นาที) — เปิด dashboard จากแล็ปท็อปต่างประเทศหรือมือถือได้ งานและประวัติแชทเหมือนเดิม
- เปรียบเทียบปิดท้าย: แบบเก่า (ห้าแท็บ ห้า login ความทรงจำศูนย์) กับแบบใหม่ (จอเดียว ยื่น ticket ทีม AI ไม่เคยเลิกงาน) — โมเดลเหมือนกัน ต่างกันที่ "สำนักงาน" และระบบรอบตัวคือตัวตัดสินว่าจะประหยัดเวลา 2 หรือ 20 ชั่วโมงต่อสัปดาห์

## ความเห็นสรุป
