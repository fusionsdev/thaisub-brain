## บทนำ

คลิปนี้เป็นบทเรียนจากชุด CPA Evolution 3.0 ของ William Souza ว่าด้วยการสมัครเข้าร่วม CPA Network (เครือข่าย Affiliate) ซึ่งมือใหม่หลายคนมองว่าเป็นเรื่องยาก เพราะต้องส่งใบสมัครและรอการอนุมัติ วิทยากรอธิบายว่ากุญแจสำคัญคือการแสดงให้เครือข่ายเห็นว่าเราเป็นนักการตลาดที่จริงจัง มีทิศทางและงบประมาณ พร้อมสร้างความสัมพันธ์ระยะยาว และสาธิตการกรอกฟอร์มสมัครจริงบน MaxBounty พร้อมเทคนิคการติดตามผลหลังส่งใบสมัคร

สวัสดีครับ ยินดีต้อนรับสู่วิดีโอใหม่ของเรา

ในวิดีโอนี้ เราจะพูดถึงการเข้าร่วม CPA Network ครับ

การเข้าร่วม CPA นั้น มือใหม่หลายคนมองว่าเป็นปัญหาใหญ่ เพราะคุณไม่สามารถเข้าไปใช้บัญชีของ CPA Network ได้ทันที

คุณต้องส่งใบสมัครก่อน แล้วต้องผ่านการอนุมัติจากเครือข่าย เพื่อให้พวกเขาเปิดใช้งานบัญชีให้

หลังจากนั้น คุณถึงจะเริ่มโปรโมท Offer ของพวกเขาได้

สำหรับบางคน มันอาจดูเป็นเรื่องยาก แต่จริงๆ แล้ว การได้รับการอนุมัติจาก CPA Network ดีๆ นั้นง่ายมากครับ

คุณแค่ยังไม่ได้ทำตามกระบวนการที่ถูกต้องเท่านั้นเอง

สิ่งแรกที่คุณต้องทำ คือการคิดว่า CPA Network ต้องการอะไร

ลองสวมบทบาทเป็นพวกเขา และเข้าใจว่าพวกเขาคาดหวังอะไรจาก Affiliate หน้าใหม่

CPA Network ต้องการ Affiliate ที่จะสร้างรายได้ให้พวกเขาและ Merchant ของพวกเขา

พวกเขาไม่ต้องการคนที่ไม่มีแนวคิดอะไรเลย ว่าจะทำอะไร กำลังจะลองวิธีแล้ววิธีเล่า แบบสุ่มๆ

และสุดท้ายจะพยายามเปลี่ยน Affiliate Manager ให้มาเป็นโค้ชส่วนตัวของตัวเอง

ถ้าคุณเข้าใจตรงนี้ การเข้าร่วม CPA Network ก็ง่ายมากครับ

เพราะเมื่อคุณส่งใบสมัคร สิ่งที่คุณต้องทำคือแสดงให้พวกเขาเห็นว่า คุณจริงจังกับเรื่องนี้จริงๆ

และคุณพยายามสร้างความสัมพันธ์ระยะยาว ที่ทำกำไรได้กับบริษัทของพวกเขา

แสดงให้เห็นว่าคุณมีงบประมาณพอสมควรสำหรับการเริ่มต้น

และคุณพร้อมที่จะเป็น Affiliate มืออาชีพ ที่จะไม่ไปกวน Affiliate Manager ด้วยการถามโน่นถามนี่ตลอดเวลา

อย่าขอให้พวกเขามาโค้ชหรือสอน CPA marketing ให้คุณ

สุดท้ายคุณจะได้คุยกับพวกเขา เพื่อขอเคล็ดลับบ้าง แต่ก็แค่นั้น

และคุณต้องแสดงให้ CPA Network เห็นว่า คุณเป็นคนที่เอาจริงกับเรื่องนี้

คุณตั้งใจจริงๆ ที่จะสร้างธุรกิจ CPA ที่ประสบความสำเร็จ และมีแนวทางที่ชัดเจนสำหรับเรื่องนี้

สิ่งที่ผมแนะนำคือ ให้ไปที่ CPA Network ที่ดีๆ สักสองสามแห่ง

มี CPA Network อยู่ไม่กี่แห่งที่ผมมีลิงก์แนะนำ (referral link) ให้

ถ้าคุณใช้ลิงก์ของผม โอกาสที่คุณจะผ่านอนุมัติกับบริษัทเหล่านั้นก็จะง่ายขึ้นอีกครับ

ดังนั้น ไปที่ CPA Network เหล่านั้น ส่งใบสมัคร และกรอกข้อมูลที่จำเป็นทั้งหมดให้ครบ

อย่าโกหกอะไรทั้งสิ้น ถ้าคุณเพิ่งเริ่มต้นในวงการนี้

บอกไปตรงๆ ว่าคุณเป็นมือใหม่ แต่ชี้แจงว่าคุณจริงจังกับเรื่องนี้ และมีเงินทุนอยู่บ้าง

คุณตั้งใจจะโฟกัสกับวิธีที่มีประสิทธิภาพจริงๆ ไม่ใช่ลองสุ่มๆ ไปเรื่อย

และคุณมีคนช่วยเหลืออยู่แล้ว เพื่อที่คุณจะได้ไม่ต้องไปกวน Affiliate Manager ขอให้สอน CPA marketing

แสดงสิ่งเหล่านี้ให้พวกเขาเห็น ทั้งตอนกรอกใบสมัคร และตอนที่พวกเขาติดต่อกลับมาหาคุณ

เมื่อคุณได้คุยกับพวกเขาแล้ว มีโอกาสสูงมากที่พวกเขาจะอนุมัติให้คุณ

เพียงแค่ทำให้แน่ใจว่า อย่าโกหกตอนส่งใบสมัคร

เพราะ Affiliate Manager ฉลาดมากครับ

พวกเขาคุ้นเคยกับการรับมือคนจำนวนมาก และง่ายมากที่พวกเขาจะจับคนโกหกได้

ดังนั้น จงพูดความจริง และอธิบายให้พวกเขาฟังชัดเจนว่า เจตนาของคุณในวงการนี้คืออะไร

และทำให้ชัดเจนว่า คุณจะใช้วิธีแบบ White Hat (วิธีสุจริต) เท่านั้น

คุณจะไม่สร้างปัญหาให้พวกเขาหรือ Merchant ของพวกเขา

และคุณกำลังมองหาการสร้างความสัมพันธ์ที่ดี แบบระยะยาว ที่ทำกำไรได้ทั้งสองฝ่าย

ทีนี้ มาดูที่คอมพิวเตอร์ของผมกัน ผมจะสาธิตวิธีกรอกฟอร์มใบสมัครให้ดีที่สุด

ที่อยู่ แล้วก็คำถามที่มือใหม่หลายคนกลัว

ก็คือคำถามเกี่ยวกับวิธีโปรโมทที่คุณจะใช้ ว่าจะโปรโมท Offer ประเภทไหน

ผมบอกได้เลยว่า การตอบคำถามเหล่านี้ไม่ยากครับ

คุณแค่ต้องจริงใจ 100% เท่านั้น

อย่าพยายามหลอกบัญชี อย่าแกล้งทำเป็นว่า คุณเป็น Super Affiliate หรือรู้ทุกอย่างเกี่ยวกับ Affiliate Marketing และ CPA Marketing

แค่เป็นตัวของตัวเอง

ถ้าคุณไม่แน่ใจว่าจะตอบคำถามบางข้ออย่างไร ลองไปเรียนเทรนนิ่งก่อน

เริ่มต้นกับเทรนนิ่ง ดูว่าเราจะใช้วิธีแบบไหน กลยุทธ์แบบไหน ในการตั้งแคมเปญของคุณ

เมื่อรู้แล้ว คุณค่อยกลับมาส่งใบสมัคร พร้อมรู้แน่ชัดว่าจะต้องให้ข้อมูลอะไรกับ CPA Network

สิ่งที่ผมมักแนะนำเสมอ คือการทำให้ CPA Network เห็นชัดเจนว่า คุณมีทิศทางและรู้ว่ากำลังทำอะไรอยู่

คุณรู้เรื่องของตัวเอง ในแง่ของการมีทิศทางที่ชัดเจน

ไม่ใช่ว่าคุณต้องเป็นมือโปร แต่คุณต้องรู้ว่ากำลังทำอะไร

CPA Network ไม่ชอบ Affiliate ที่เพิ่งเริ่มต้น แล้วก็ยิงมั่วแบบสุ่มๆ

ถ้าคุณไม่มีแนวคิดเลยว่าจะทำอะไร จะลองวิธีแล้ววิธีเล่า นั่นไม่น่าสนใจสำหรับพวกเขาแน่นอน

ดังนั้น คุณต้องแสดงให้เห็นว่า คุณมีแนวทาง มีทิศทางที่จะไป

คุณต้องแสดงให้เห็นว่าคุณเป็นมืออาชีพ และจริงจังกับเรื่องนี้

การบอกพวกเขาว่าคุณมีงบประมาณที่ดี ก็เป็นเรื่องเชิงบวกได้

แม้ว่าคุณอาจจะยังไม่มีเงินมากมายสำหรับลงทุนในแคมเปญ

ก็ยังบอกได้ว่าคุณมีเงินอย่างน้อยสองสามพันดอลลาร์สำหรับการลงทุน

เพราะมันแสดงให้เห็นว่าคุณพร้อมที่จะลงทุน

และถ้าคุณพร้อมที่จะลงทุน แสดงว่าคุณคงจะจริงจังกับเรื่องนี้

นี่คือสิ่งที่คุณต้องทำครับ

ในแง่ของ Offer ที่คุณจะโปรโมท ไปดูเทรนนิ่งก่อน ดูให้เข้าใจว่าเราจะใช้กลยุทธ์แบบไหน

แล้วค่อยนำข้อมูลนั้นมากรอกที่นี่

นักเรียนแต่ละคนอาจเลือกเส้นทางที่ต่างกันในเทรนนิ่งนี้

สุดท้ายก็อาจลงเอยด้วยการโปรโมท Offer คนละแบบ ใช้ Traffic Source คนละแบบ

นั่นคือเหตุผลที่ผมไม่สามารถให้คำตอบตายตัวได้ว่า ทุกคนควรตอบอะไรในช่องนี้

ลองดูเทรนนิ่ง ดูสิ่งที่คุณจะทำเป็นอย่างแรก

เมื่อคุณมีแนวคิดแล้วว่าจะไปทางไหน คุณค่อยกลับมากรอกใบสมัคร

แต่ไม่ต้อง แค่ไม่ต้องแกล้งเป็นคนอื่น

แค่บอกพวกเขาตรงๆ ว่าคุณกำลังเริ่มต้น แต่คุณตั้งใจที่จะสร้างความสัมพันธ์ระยะยาว ที่ทำกำไรได้กับบริษัทของพวกเขา

ผมมั่นใจว่า CPA Network หลายแห่งจะยอมรับใบสมัครของคุณ

ฟอร์มนี้ไม่ได้ซับซ้อนครับ

อย่างที่เห็น มีแค่คำถามไม่กี่ข้อเกี่ยวกับวิธีโปรโมท

ส่วนอย่างอื่นเป็นข้อมูลส่วนตัว เช่น ข้อมูลติดต่อ

ไม่มีอะไรยากเกินไป อย่างที่เพิ่งเห็นไป

การส่งใบสมัครไม่ใช่เรื่องยาก

สิ่งที่คุณต้องทำหลังส่งใบสมัครแล้ว คือการติดต่อพวกเขา และแสดงว่าคุณเป็นคนกระตือรือร้น และอยากร่วมงานกับพวกเขาจริงๆ

สิ่งที่คุณต้องทำคือ โทรหาพวกเขา และขอคุยกับ Affiliate Manager

อธิบายว่าทำไมคุณถึงคิดว่าพวกเขาควรอนุมัติใบสมัครของคุณ

อีกทางเลือกหนึ่ง คือการแอด Affiliate Manager ของพวกเขาบน Skype หรือแอปแชทอื่นๆ

แล้วคุยกับพวกเขา อธิบายว่าทำไมพวกเขาควรยอมรับใบสมัครของคุณ

มันไม่ซับซ้อนครับ

การได้คุยโทรศัพท์กับ Affiliate Manager หรือคุยบน Skype ไม่ใช่เรื่องยากเลย

พวกเขาจะถามคำถามง่ายๆ คล้ายๆ กับที่อยู่ในใบสมัคร

คุณแค่ต้องจำไว้ว่า มันไม่ควรยากอะไร

และคุณควรอธิบายให้พวกเขารู้ชัดเจนว่า เจตนาของคุณคืออะไร

แสดงให้เห็นว่าคุณมีความตั้งใจที่ดีในการทำงานกับบริษัทของพวกเขา

Affiliate Manager โดยทั่วไปใจดีมาก และไม่ยากที่คุณจะอธิบายทุกอย่างให้พวกเขาฟัง

และสุดท้ายก็จะผ่านอนุมัติจากบริษัทดีๆ ได้

แต่ที่สำคัญมาก คือคุณต้องโทรหาพวกเขา หรืออย่างน้อยก็แชทบน Skype

เพราะถ้าคุณไม่ทำ พวกเขาอาจจะไม่ใช้เวลาตรวจสอบใบสมัครของคุณอย่างจริงจัง

พวกเขาได้รับใบสมัครจำนวนมากทุกวัน และยากที่พวกเขาจะตรวจสอบทั้งหมดได้อย่างทั่วถึง

แต่ถ้าคุณติดต่อพวกเขาและได้คุยกัน โอกาสที่พวกเขาจะพิจารณาใบสมัครของคุณอย่างละเอียดก็สูงขึ้นมาก
