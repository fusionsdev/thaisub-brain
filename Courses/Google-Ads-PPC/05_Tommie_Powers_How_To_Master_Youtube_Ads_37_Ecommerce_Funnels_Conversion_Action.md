## คำแปลเต็ม
ในวิดีโอนี้ผมอยากพูดถึง E-commerce Funnel ครับ
นี่เป็นสิ่งที่ผมชอบมาก และผมอยากให้คุณได้แนวคิดว่ามันทำงานยังไง
ถ้าคุณมีร้านแบบ Shopify หรืออะไรทำนองนั้น คุณก็ติดตั้ง Conversion Pixel ต่างๆ บน Shopify ได้
โดยใช้แอปและเครื่องมือต่างๆ ซึ่งจะจัดการสิ่งที่คุณต้องการส่วนใหญ่ได้
ถ้าคุณส่ง traffic ไปที่หน้า product ของคุณ
แต่โดยส่วนตัวผมแนะนำให้คุณส่ง traffic ไปที่ Funnel
และแม้ในกรณีแย่สุด คุณก็ใช้แอปบน Shopify ที่ให้คุณเสนอทางเลือกในการซื้อเพิ่มเติม
หลังจากที่ลูกค้าซื้อแล้วบนหน้าแรกได้
และนี่คือหัวใจสำคัญของวิธีทำโฆษณาของเรา
มันคือเรื่องของ Funnel ทั้งหมด ว่าเราจะสร้างยอดซื้อเพิ่มขึ้นในกระบวนการได้ยังไง
หรือทำให้ยอดเฉลี่ยต่อออเดอร์ หรือ Average Order Value สูงขึ้น ซึ่งเป็นคำที่คุณอาจเคยได้ยิน
ผมแนะนำให้คุณใช้ Funnel ครับ
และมันสร้างง่ายมากด้วยเครื่องมืออย่าง ClickFunnels
ที่คุณสามารถประกอบ Funnel หนึ่งอันเพื่อทดสอบได้ง่ายๆ
คุณทดสอบได้ แต่สิ่งสำคัญคือเราทำให้โฆษณาของเราคุ้มทุนได้ด้วย Funnel แบบนี้
และสิ่งที่คุณเห็นบนหน้าจอคือภาพแสดงองค์ประกอบของ E-commerce Funnel ทั่วไปครับ
ไม่ได้ใช้ทุกองค์ประกอบเสมอไป ผมจะยกตัวอย่างให้สองสามแบบ
แต่จะโชว์ให้ดูว่าที่เราชอบรันเป็นหลักคือแบบไหน ที่ทำให้เราได้ผล
ผมใช้เงินกับ YouTube ถึง 15,000–20,000 ต่อวันกับ Funnel แบบนี้เลยครับ
และคุณจะทำแบบ Minimum Viable (ขั้นต่ำที่ใช้งานได้) ก็ได้ถ้าต้องการ
แต่เราจะส่ง traffic ไปที่หน้า Product Sales Page ก่อนครับ
โดยทั่วไปแล้วนั่นคือ Landing Page ไม่ใช่หน้า Product บนเว็บไซต์ของคุณโดยตรง
ถ้าคุณส่งไปที่หน้า Product บนเว็บของคุณ
คุณใช้แอปแบบ One-Click Upsell ได้ครับ
เพื่อนผมชื่อ Ezra ใช้แล้วได้ผลดีมาก
ตอนนี้เรากำลังใช้อยู่กับแบรนด์อีคอมเมิร์ซหนึ่งที่ผมทำงานด้วย และมันทำงานได้ดีมาก
คุณใช้แบบนั้นได้ถ้าอยากส่งไปที่หน้า Product ของคุณ
แต่ผมแนะนำให้ทำ Landing Page เฉพาะ (Dedicated Landing Page)
เพื่อให้มันเรียบง่ายอย่างที่ผมโชว์ให้ดู
ให้วิดีโอทำหน้าที่หนัก แล้วให้ Landing Page เรียบง่ายกว่านั้น
เพื่อพาลูกค้าไปสู่การตัดสินใจซื้อต่อ

สิ่งที่เราใช้เป็นประจำคือ Landing Page หน้า Product Sales
ที่พาลูกค้าไปที่หน้าสั่งซื้อและชำระเงิน (Checkout)
และทันทีที่พวกเขาชำระเงินเสร็จ เราก็เสนอ One-Click Upsell ตัวที่หนึ่ง
จากนั้นก็เสนอ One-Click Upsell ตัวที่สอง
และสิ่งสุดท้ายคือหน้า Purchase Confirmation (ยืนยันการซื้อ) ครับ
สิ่งที่เกิดขึ้นในสถานการณ์นี้คือ เราจะมี Conversion Pixel อยู่ตรงนี้
เพราะแต่ละขั้นตอนเหล่านี้แทนมูลค่าหนึ่งๆ
สมมติว่านี่คือ 50 ดอลลาร์ แล้วเรามี Upsell มูลค่า 97 ดอลลาร์
และอาจมี Upsell มูลค่า 197 ดอลลาร์ตรงนี้ ขอผมทำใหม่นะครับ มันไม่ค่อยทำงาน
มันติดขัดนิดหน่อย 197 ครับ
สิ่งที่เกิดขึ้นคือ Pixel ตรงนี้จะแทนมูลค่า 50 ดอลลาร์
Pixel นี้จะแทนมูลค่า 97 ดอลลาร์
แล้ว Pixel Conversion มูลค่า 197 จะเกิดตรงนี้ครับ
คุณยังต้องมีอีกหน้าหนึ่ง สำหรับกรณีที่ลูกค้าไม่รับข้อเสนอนี้
คุณจะไม่มี Pixel นั้นตรงนั้น
คุณต้องเสนอ Upsell ให้พวกเขา แล้วก็ต้องมีวิธีให้พวกเขาปฏิเสธได้ด้วย
สิ่งที่เกิดขึ้นคือคุณจะมีหน้าให้ลูกค้าปฏิเสธทุกข้อเสนอ
ทุกข้อเสนอผมจะทำหน้า Decline แยก
ตรงนี้ผมจะสร้างมัน แล้วให้พวกเขาสามารถปฏิเสธได้
ซึ่งจะพาไปยังหน้า Purchase Confirmation อีกหน้าหนึ่ง
ที่ไม่มีมูลค่า Conversion เพราะผมวาง Tag มูลค่า 50 ดอลลาร์ไว้ตรงนี้แล้ว ถูกต้องไหมครับ?
และแบบเดียวกันตรงนี้ ถ้าพวกเขารับข้อเสนอ
ผมก็จะมี Conversion Value ตรงนี้
และถ้าพวกเขาปฏิเสธ ผมจะพาไปที่หน้า Thank You แยกต่างหากที่ไม่มีการยิง Event
แต่ผมจะได้ติดตาม 50 และ 97 ไว้แล้ว
และถ้าพวกเขารับทั้งหมด แน่นอนว่าผมมีหน้า Thank You สุดท้าย
ที่มี Conversion Pixel สำหรับข้อเสนอ 197 ครับ
นั่นคือภาพรวมที่ผมอยากให้คุณเข้าใจกระบวนการนี้ครับ
ในกรณีนี้เราต้องการ Tag สามตัวใช่ไหมครับ? สาม Conversion Tags
และพวกมันจะเป็น Purchase Conversion Pixel ทั้งหมด
สมมติว่าคุณอยากได้แค่ตัวเดียว จะเกิดอะไรขึ้น?
คุณก็จะไปตรงนี้ แล้วก็จะมีแค่สองตัว
สมมติว่าเราไม่ทำ 197 กัน ขอเอาของที่ไม่จำเป็นออกไปก่อน
ตอนนี้เรามี Pixel สองตัว
และถ้าพวกเขาปฏิเสธอันนี้ เราจะมีหน้าแยกที่ไม่มี Pixel
สิ่งที่เกิดขึ้นคือ เมื่อพวกเขาซื้อสินค้า 50 ดอลลาร์ Pixel ถูกยิง
เราจะโชว์ Upsell ให้พวกเขาทันที
Event Snippet จะอยู่ตรงนี้ ขอทำให้ถูกต้องนะครับ
Event Snippet ผมต้องแน่ใจว่าใช้ภาษาที่ถูกต้องกับ Google
Event จะอยู่บนหน้านี้สำหรับ Purchase Conversion Pixel มูลค่า 50 ดอลลาร์
และถ้าพวกเขารับ Upsell มูลค่า 97 ดอลลาร์
เราจะมี Event Snippet มูลค่า 97 อยู่บนหน้านี้
และถ้าพวกเขาปฏิเสธ เราจะมีหน้า Purchase Confirmation แยกต่างหาก
ที่ไม่มี Event Snippet นั้นอยู่
ในกรณีนี้เราจะต้องใช้แค่สอง Conversion Tags เท่านั้น
และถ้าเราไม่เสนอ Upsell เลย ซึ่งผมไม่แนะนำ
แต่ถ้าคุณไม่อยากเสนอ Upsell สิ่งที่คุณมีคือหน้า Sales Page ไปยังหน้า Order
แล้วก็ตรงไปที่ Purchase Conversion มูลค่า 50 ดอลลาร์
Event Snippet จะอยู่ตรงนี้เพื่อบอก Google ว่ามีคนซื้อสินค้าจริง
แล้วก็จบที่หน้านี้

ยิ่งคุณมี Upsell มากเท่าไหร่ มันก็ยิ่งซับซ้อนขึ้นอีกนิดครับ
ทุกครั้งที่มี Upsell หนึ่งตัว คุณต้องมีหน้า Purchase Confirmation สองหน้า
หน้าหนึ่งสำหรับกรณีรับข้อเสนอ อีกหน้าหนึ่งสำหรับกรณีปฏิเสธ
นี่คือสิ่งที่ผมพยายามอธิบายครับ
และสิ่งที่เราชอบคือ Upsell สองตัว
คุณทำมากกว่านั้นได้ แต่ผมพบว่าเราทำรายได้จำนวนมากจาก Back End
ผ่านอีเมลและอะไรทำนองนั้น
เราไม่พยายามยัดเยียด Upsell ให้ลูกค้ามากเกินไป
คุณทำได้ถ้าต้องการ แต่ผมพบว่า Funnel แบบนี้
ที่มีสินค้าหน้าบ้าน แล้วตามด้วย Upsell สองตัว ได้ผลดีมากสำหรับเรา
มันก็ประมาณนี้ครับ
ขายที่ Front End แล้วมี Upsell สองตัว คุณต้องใช้ Purchase Conversion Pixel สามตัว
ขายที่ Front End แล้วมี Upsell หนึ่งตัว คุณต้องใช้ Pixel สองตัว
และถ้าคุณไม่มี Upsell เลย ซึ่งผมไม่แนะนำ คุณจะต้องใช้แค่ตัวเดียว
และพวกมันจะถูกวางบนหน้าถัดไป
นี่คือวิธีที่เรารัน E-commerce Funnel ของเราโดยประมาณครับ

และเมื่อคุณจะไปสร้าง Funnel ของคุณเอง
คุณก็แค่ย้อนกลับมาดูวิดีโอนี้ แล้ววางผัง Funnel ที่คุณจะรันลงบนกระดาษ
จากนั้นเขียนว่าควรวาง Pixel ตรงไหนบ้าง
แล้วค่อยไปสร้างมันจริงๆ และวางไว้ในตำแหน่งที่ถูกต้อง
ประมาณนี้สำหรับ E-commerce Funnel และวิธีที่เรารันมันครับ
แล้วเจอกันในวิดีโอหน้า
