sub-agents โดยพื้นฐานแล้วคือ agents ที่ช่วยปกป้อง context window ของคุณ โอเค ถ้าคุณเห็นบทเรียนที่แล้ว ในวิดีโอก่อนหน้านี้ ผม spawn agent สี่ตัว ผม spawn สามหรือสี่ตัวเพื่อค้นหา GitHub Twitter ผม spawn GitHub มันก็ไปทำ แล้วมันก็รวมทุกอย่างเข้าด้วยกัน และสร้างรายงานเต็มรูปแบบให้ผม และให้ทุกอย่างมาโดยตรง ใช่ไหมครับ เมื่อ agent ออกไปทำงานแบบนั้น มันกิน tokens เยอะมาก ซึ่งจะเติมเต็ม context window ของคุณ
