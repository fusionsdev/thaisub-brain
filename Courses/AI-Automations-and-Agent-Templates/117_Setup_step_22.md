## บทนำ
คลิปนี้สอนวิธีเพิ่มการเผยแพร่โพสต์ไปยัง Twitter ในระบบอัตโนมัติ เนื่องจาก Twitter ไม่มีการเชื่อมต่อโดยตรงอีกต่อไป การโพสต์ผ่าน API ทางการจึงทำได้ยาก ผู้สอนจึงใช้บริการภายนอกอย่าง upload.post.com ซึ่งใช้ฟรีได้ถึง 10 โพสต์ต่อเดือน จากนั้นพาเชื่อมบัญชี Twitter ใส่ username และ API key รวมถึงอธิบายบั๊กเล็กๆ ที่เกิดขึ้นช่วงถ่ายทำและวิธีตรวจสอบว่าเชื่อมต่อถูกต้อง

## คำแปลเต็ม
ตอนนี้ผมจะโชว์วิธีเผยแพร่โพสต์ไปยัง Twitter ด้วย Twitter ไม่มีการเชื่อมต่อโดยตรงกับระบบอีกต่อไป และการโพสต์ผ่าน API ทางการก็อาจทำได้ยาก นั่นคือเหตุผลที่เราจะใช้บริการภายนอกชื่อ upload.post.com

คุณคลิกเข้าไปแล้วสมัครใช้งานแบบฟรี ซึ่งอนุญาตให้เผยแพร่ได้สูงสุด 10 โพสต์ต่อเดือน แล้วถ้าต้องการมากกว่านั้น คุณอาจต้องอัปเกรดเป็นแพ็กเกจรายเดือน $14 ซึ่งตอนนี้ผมสมัครอยู่

สิ่งแรกที่ต้องทำคือไปที่ manage คลิกตรงนี้ แล้วพิมพ์ชื่อผู้ใช้ (username) อะไรก็ได้ ไม่สำคัญว่าชื่อนั้นคืออะไร แล้วคุณคลิกที่แพลตฟอร์มต่างๆ เหล่านี้เพื่อเชื่อมบัญชีที่แตกต่างกัน ถ้าผมอยากโพสต์ไปที่ Twitter ผมคลิกที่มัน แล้วระบบจะให้ผมอนุมัติแอป ผมคลิกอนุมัติ แล้วบัญชีนี้ก็จะถูกเพิ่มเข้าไปในบัญชีของผม และนั่นคือทั้งหมดที่ผมต้องการ

คุณสามารถเผยแพร่ไปยังบัญชีอื่นๆ เหล่านี้ได้ด้วยถ้าต้องการ แต่ผมอยากโพสต์เฉพาะ Twitter ด้วยเครื่องมือนี้ ก็แค่นี้พอสำหรับผม ตอนนี้ผมต้องไปตรงนี้ ก่อนอื่นเราจะปลดลิงก์อันนี้ไว้ก่อน เพื่อทดสอบเฉพาะ Twitter เพราะเราได้ทดสอบการเผยแพร่กับ Instagram และ Facebook ไปแล้วในขั้นตอนก่อนหน้า

ตอนนี้เราต้องเข้าไปตรงนี้ เพราะสิ่งที่ต้องได้ต่อไปคือ API key จากเครื่องมือนี้ งั้นเรามาเอา username ก่อน เพราะเราอยู่บนหน้า username อยู่แล้ว username ต้องใส่ลงไปตรงนี้ แล้วเราก็เอา API key จากส่วน API keys คุณคลิก copy key นี้ แต่ก่อนอื่นต้องสร้าง key ก่อน ถ้ายังไม่มีก็คลิก create แล้วคัดลอกมา จากนั้นวางมันลงตรงนี้ ปล่อยส่วนนี้ไว้ อย่าลบมัน ลบเฉพาะข้อความตัวอย่าง (placeholder) นี้เท่านั้น พอคัดลอกเสร็จก็ไปต่อ

เราต้องเช็คให้แน่ใจว่าเป็น Twitter ใช่ แล้วตอนนี้ platform นี้ ก็ลงตัวสมบูรณ์ แล้ว image URL คืออันนี้ ดี

ทีนี้มันอาจเกิดขึ้นได้ว่า ตอนนี้ช่วงที่อัดวิดีโอนี้ มันมีบั๊กเล็กๆ อยู่ มันเคยทำงานได้ แต่่วันนี้มันมีปัญหา แต่ผมติดต่อฝ่ายสนับสนุนแล้ว ผมเลยไม่แน่ใจว่ามันจะทำงานได้หรือไม่ แต่มันน่าจะทำงานได้ในภายหลัง และผมจะอัปเดตให้คุณทราบเมื่อเขาซ่อมเสร็จ

แต่ตอนนี้ นี่เป็นวิธีที่สะดวกที่สุดในการเผยแพร่กับระบบอัตโนมัตินี้บน Twitter ผมจะกลับไปตรงนี้ และต้องไปที่ webhook ของผม อันนี้ แล้วมันควรจะส่งส่วนนี้ไป และผมเห็นว่ามันน่าจะเกิดข้อผิดพลาด มันขึ้นว่า fail to upload image not found ซึ่งมันไม่เคยเกิดขึ้นมาก่อน แต่คุณอาจต้องรอจนกว่ามันจะทำงานได้ และผมจะอัปเดตให้คุณทราบ

แต่การตั้งค่าตรงนี้ การตั้งค่านี้เป็นวิธีที่ถูกต้องเป๊ะ และมันเคยทำงานได้มาก่อน นี่คือวิธีที่คุณโพสต์ และเมื่อผมได้รับอัปเดตกลับมาว่าเขาซ่อมเสร็จแล้ว ผมจะรายงานกลับมา และจะแปะโน้ตไว้ใต้คลิปวิดีโอนี้ว่าตอนนี้ซ่อมเสร็จแล้ว
