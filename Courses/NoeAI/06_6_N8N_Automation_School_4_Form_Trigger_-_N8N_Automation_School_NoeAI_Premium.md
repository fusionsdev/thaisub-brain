## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับสู่อีกหนึ่งวิดีโอครับ ในวิดีโอนี้ผมจะอธิบายเรื่อง on-form submission trigger ครับ อันนี้เจ๋งมาก ดูนะครับ

เอาล่ะ โดยพื้นฐานแล้ว on-form submission trigger ก็คือฟอร์มหนึ่งนั่นแหละครับ เจ๋งป่ะล่ะ ผมจะเพิ่มโหนด Edit Fields เข้าไป เพื่อจะได้จัดระเบียบข้อมูลที่ส่งเข้ามา แต่ข้างในฟอร์ม เราสร้างแบบฟอร์มได้ เมื่อเราใส่ข้อมูลเข้าไป มันจะทริกเกอร์และเริ่มทำงานครับ แบบนี้เหมาะมากสำหรับส่งให้ลูกค้ากรอก เพื่อใช้ตอนเริ่มงานกับลูกค้า (onboarding) อะไรแบบนั้นครับ

เราตั้งชื่อได้ เช่น NoeAI test แล้วก็ทดสอบการส่งฟอร์ม จากนั้นก็เพิ่มส่วนประกอบของฟอร์มได้ หลัก ๆ ก็คือ label แล้วก็ทำได้แบบ text, password, radio, hidden, drop-down ได้หมดเลยครับ เลือกได้ตามต้องการ แล้วก็ทำ phone ได้ด้วย ไปที่ช่อง phone number ตรงนี้ เท่านี้เองครับ

จากนั้นตั้งค่าตอบกลับเมื่อส่งฟอร์ม หรือเมื่อเวิร์กโฟลว์เสร็จสิ้น ก็คือถ้าเวิร์กโฟลว์รันครบ มันจะทำงานตามที่ตั้ง แต่คุณไม่ต้องกังวลเรื่องนั้นตอนนี้ครับ

แล้วก็มีตัวเลือกด้านล่าง เช่น append n8n attribution นั่นคือตอนที่ส่งฟอร์ม n8n จะส่งข้อความบอกว่า นี่คือการส่งมาจาก n8n คุณไม่จำเป็นต้องใช้ก็ได้ เช่นตอนส่งอีเมล คุณปิดมันได้ มีตัวเลือกอีกหลายอย่าง จริง ๆ ผมไม่ค่อยได้ใช้ตัวนี้เลยนะ บอกตรง ๆ ผมใช้ Airtable, Jotform อะไรแบบนั้น ซึ่งคุณใช้เป็นทริกเกอร์ตรงนี้ได้เหมือนกันครับ

เราสามารถเอามันไปใช้จริงได้ เราจะก็อปปี้แล้ววาง แล้วก็ publish เพื่อใช้งาน แล้วก็ใส่ URL ลงไป จากนั้นคุณก็จะได้ฟอร์มของคุณครับ พอกรอกข้อมูล เช่น NoeAI เบลอเบลอเบลอ@gmail.com แล้วก็ 9199999999 แล้วกด submit มันก็จะถูกส่งไป เราสามารถดู execution logs ของเราได้ แล้วก็เห็นว่ามันเข้ามา ถูกส่งเรียบร้อยในโหมด production ครับ

และเพื่อโชว์การส่งข้อมูลต่อ ถ้าผมอยากได้ข้อมูล ผมคลิก copy to editor แล้วข้อมูลทั้งหมดที่ส่งเข้ามาจะถูกปักหมุด (pin) ไว้ครับ มันจะอยู่ตรงนั้นจนกว่าผมจะ unpin ซึ่งการ unpin ทำได้โดยคลิกขวาแล้วเลือก มันจะค้างไว้แบบนั้นเรื่อย ๆ แล้วผมก็เชื่อมมันเข้ากับโหนด Edit Fields ได้ แล้วเดี๋ยวผมจะลงรายละเอียดเรื่องการแปลงข้อมูล (data transformation) มากกว่านี้ แต่ตอนนี้ผมลากเฉพาะข้อมูลที่ต้องการได้ ข้อมูลมันถูกส่งเข้ามาตอนเวลาเท่านี้ พอทริกเกอร์ มันก็เข้ามาแบบสวยงาม ลากได้หมด และมันแสดงเป็นตารางด้วยครับ

นี่คือทั้งหมดของ form trigger ครับ เจอกันในวิดีโอหน้าครับ
