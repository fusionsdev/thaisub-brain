# สรุป: Block stupid Ads and manage DNS // AdguardHome Tutorial

## ประเด็นหลัก

- AdGuard Home เป็นทางเลือกที่ทรงพลังกว่า Pi-hole สำหรับ DNS blocking ในเครือข่าย
- มีฟีเจอร์ DNS over HTTPS และ DNS over TLS support มาตรฐานในตัว
- สามารถ deploy บน Docker ได้ง่ายด้วย Docker Compose
- มีคุณสมบัติพิเศษเช่น การบล็อก service ตาม IP/Mac address
- สามารถตั้งค่าเพื่อเข้ารหัส DNS queries ทั้งในเครือข่ายภายในและกับ upstream servers

## ความเห็นสรุป

AdGuard Home เป็นโซลูชัน DNS blocking ที่สมบูรณ์แบบและมีฟีเจอร์ที่ทันสมัยกว่า Pi-hole อย่างเห็นได้ชัด โดยเฉพาะในด้านความปลอดภัยของ DNS queries ที่เข้ารหัสไว้ การติดตั้งผ่าน Docker ทำให้ง่ายต่อการจัดการและบำรุงรักษา และคุณสมบัติการบล็อกตาม service และการกำหนดค่าเฉพาะเจาะจงตามอุปกรณ์เป็นฟีเจอร์ที่น่าประทับใจ
