## ประเด็นหลัก

- ช่อง Ink Explainer ใช้แอนิเมชัน stickman ง่าย ๆ เล่าเรื่องประวัติศาสตร์ / การอยู่รอด และมีวิวรวมสูงมาก (ประมาณการรายได้ราว $40K/เดือน)
- ไม่ต้องรู้แอนิเมชันมืออาชีพ — ใช้ workflow AI ชุดเดียวแทนซอฟต์แวร์ตัดต่อซับซ้อน
- เชื่อม Higgsfield กับ ChatGPT ผ่าน MCP / CLI แล้วติดตั้ง plugin
- ใช้ master cloning prompt เพื่อวิเคราะห์ช่องอ้างอิงจาก screenshot แล้วลอกสไตล์ภาพ / thumbnail / ตัวละคร
- เลือกสไตล์ stick figure หรือ 2D cartoon จากนั้นเลือก niche เช่น survival and adventure
- AI สร้างไอเดียคลิป 10 แบบ เลือกความยาว (เช่น 30 วินาที) และ aspect ratio 16:9 หรือ 9:16
- อนุมัติ voice-over script แล้วให้ Higgsfield สร้าง character reference image
- สร้างวิดีโอจริงด้วย Seedance 2.5 ผ่าน workflow ที่เชื่อมไว้โดยไม่ต้อง prompt ทีละฉาก
- ตัวอย่างในคลิปคือแอนิเมชัน 30 วินาทีเรื่องติดยุคหิน — ตัวละครคงที่และฉากลื่น
- ลิงก์ Higgsfield อยู่ใน description / pinned comment และขอ master prompt ได้ฟรีด้วยคอมเมนต์ "Mark AI guy"

## ความเห็นสรุป

คลิปนี้เป็นบทสอนทำคลิป YouTube แนว stickman ด้วย AI แบบไม่เขียนโค้ด โดยยึดช่อง Ink Explainer เป็นตัวอย่างรายได้และสไตล์ครับ. จุดขายคือ master prompt + Higgsfield MCP + Seedance 2.5 ที่ลดงานมือลงเหลือการเลือกตัวเลือกในแชทครับ. เหมาะกับคนที่อยากทดสอบ niche เล่าเรื่องภาพประกอบโดยไม่ต้องเรียนแอนิเมชันเต็มรูปแบบครับ.
