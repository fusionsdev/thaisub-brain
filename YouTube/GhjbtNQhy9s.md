## ประเด็นหลัก

- Claude Skills คือไฟล์คำสั่งที่บันทึก workflow ซ้ำๆ ไว้ครั้งเดียว แล้วเรียกใช้ใน Claude ได้ทันทีโดยไม่ต้องพิมพ์บริบทใหม่ทุกครั้ง
- ไม่ต้องเชื่อม API เข้าบัญชี Google Ads — ส่งออก CSV แล้วแนบเข้า Claude ก็พอ ข้อมูลยังอยู่กับผู้ใช้
- Skill 1: Negative Keyword Analyzer ช่วยไล่คำค้นหาขยะจากรายงาน 90 วัน พร้อม match type เหตุผล และประมาณการประหยัดงบ
- ตัวอย่างบัญชี SHK ใน München: เห็น wasted spend จากคำเชิงข้อมูล/อบรม/เงินเดือน และรายการ negative ที่ตัดได้ทันที
- Skill 2: RSA Headline Generator สร้างหัวข้อ 15 ชุด + คำอธิบาย 4 ชุด ภายใต้ลิมิต 30 ตัวอักษร พร้อม USP และ keyword
- มีคำแนะนำ pinning ตำแหน่งหัวข้อ ส่วนขยายโฆษณา (Assets) และจุดที่ควรยืนยันกับลูกค้าก่อนขึ้นจริง
- Skill 3: Quick Audit Skill อ่านรายงานแคมเปญ + กลุ่มโฆษณา + คำค้นหา แล้วให้คะแนนบัญชีพร้อม quick wins
- ตัวอย่าง audit ได้คะแนน 5/10 ชี้ช่องว่างทราฟฟิก ~25% negative บางเกินไป และ target CPA ที่ยังไม่เหมาะ
- ดาวน์โหลด Skills ทั้งสามได้ฟรีจากคำอธิบายวิดีโอ แล้วอัปโหลดผ่านเมนู Skills ใน Claude.ai
- ต่อยอดได้เอง เช่น Skill วิเคราะห์คู่แข่ง หรือใส่กฎเฉพาะธุรกิจเข้า Skill เดิมด้วยคำสั่งเพิ่ม

## ความเห็นสรุป

คลิปนี้เหมาะกับเจ้าของธุรกิจและเอเจนซี่ที่ทำ Google Ads แล้วอยากลดงานซ้ำโดยไม่ต้องเป็นสายเทค.
สาม Skills ครอบคลุมงานที่กินเวลามากที่สุดคือ negative keywords ข้อความ RSA และ quick audit จาก CSV.
ถ้าเริ่มจากไฟล์ดาวน์โหลดฟรีแล้วปรับกฎให้เข้ากับธุรกิจตัวเอง จะประหยัดทั้งเวลาและงบโฆษณาได้ชัดเจนครับ.
