## บทนำ

บทเรียนนี้ว่าด้วยคำสั่ง /model ใน Claude Code ซึ่งใช้สำหรับสลับโมเดล AI ที่ใช้ทำงาน เช่น Opus 4.6, Sonnet และ Haiku พร้อมวิธีปรับระดับความพยายาม (effort) เพื่อควบคุมต้นทุนการใช้โทเคนให้เหมาะสมกับงานแต่ละประเภท

## คำแปลเต็ม

ทุกคนครับ ยินดีต้อนรับสู่บทเรียนคำสั่ง model ครับ สิ่งที่ผมจะโชว์ให้ดูวันนี้มันง่ายมาก ๆ เลย คำสั่ง model ช่วยให้คุณสลับโมเดลได้ ถ้าคุณอยากใช้โมเดลอื่นใน Claude Code คุณก็แค่พิมพ์คำสั่งสแลช แล้วมันก็จะให้คุณเลือกโมเดลต่าง ๆ ได้

คุณเลือกโมเดลเริ่มต้นได้ ซึ่งก็คือ Opus 4.6 ครับ ณ เดือนมีนาคมนี้ โมเดลเริ่มต้นคือ Opus 4.6 ที่มี context window 1 ล้านโทเคน มันมีความสามารถมากที่สุดสำหรับงานที่ซับซ้อน ถ้าคุณกำลังทำอะไรที่มันซ้ำ ๆ กัน คุณก็คงไม่ใช้ 4.6 ถ้าคุณทำงานที่ไม่ต้องวางแผนเยอะ ไม่ต้องคิดเยอะ คุณก็จะใช้โมเดลอย่าง Sonnet ซึ่งเก่งมากสำหรับงานทั่วไปในชีวิตประจำวัน และถ้าคุณอยากได้คำตอบที่ไวมาก จากโมเดลที่ใช้ความคิดน้อยลงไปอีก คุณก็จะใช้โมเดลที่ชื่อ Haiku

พูดตามตรงเลยนะครับ ผมไม่ค่อยได้สลับโมเดลเท่าไหร่ มันเป็นวิธีการปรับต้นทุนมากกว่า เพื่อ optimize การใช้โทเคนและค่าใช้จ่ายของคุณ ถ้าคุณมีแพลน Claude Max คุณก็ไม่จำเป็นต้องทำแบบนั้น แต่ถ้าคุณใช้ API หรืออะไรประมาณนั้น คุณก็อยากจะประหยัดโทเคน คำสั่งนี้ก็จะช่วยให้คุณทำแบบนั้นได้

และคุณยังทำอย่างอื่นได้อีก คุณสามารถกดปุ่มลูกศรสองปุ่มบนคีย์บอร์ด เพื่อดูว่ามันแสดงคำว่า high effort ยังไง แล้วคุณก็ใช้ปุ่มเหล่านี้ปรับได้ ผมก็เลือก max effort ได้ นั่นหมายความว่ามันจะใช้ความคิดมากที่สุด ส่วน low effort คือใช้ความคิดน้อยที่สุด แต่ผลลัพธ์ก็จะไม่ได้ดีเท่า medium effort เป็นค่าเริ่มต้น ส่วน high effort และ max effort อยู่ถัดขึ้นไป ผมใช้ high effort เพราะมันเป็นจุดกึ่งกลางที่ดีระหว่าง max กับตัวอื่น ซึ่งก็โอเคสำหรับผม แล้วที่เหลือผมก็แค่กด enter ก็เรียบร้อยครับ นี่คือทั้งหมดของบทเรียน model ครับ
