## บทนำ

คลิปนี้เป็นบทเรียนของ Bob Miles ว่าด้วยการใช้ data layer events ใน Google Tag Manager เพื่อติดตามอีเวนต์เฉพาะ เช่น การส่งฟอร์ม ที่ใช้หน้า thank you หรือการคลิกลิงก์ไม่ได้ วิทยากรสาธิตการสร้าง trigger จากอีเวนต์ form submit ทดสอบด้วย debugger และตั้งค่าให้ยิง Google Ads conversion tracking tag

## คำแปลเต็ม

ในบางกรณี thank you page URL หรือการคลิกลิงก์ หรือการคลิกปุ่ม หรืออะไรทำนองนั้น ไม่สามารถทำงานได้ และคุณต้องพึ่ง data layer event

สำหรับบางสถานการณ์ ผมมักใช้ data layer events เพื่อติดตามอีเวนต์บางอย่าง หรือ macro และ micro conversion ภายใน funnel ที่คุ้มค่าต่อการติดตาม และด้วยการใช้ data layer คุณติดตามอะไรก็ได้ที่ต้องการ ขอแค่มี developer ที่ช่วยคุณตั้งค่า data layer pushes เหล่านี้

ตัวอย่างเช่น ผมมี funnel ที่ซับซ้อนมาก โดยไม่มีเส้นทาง URL ที่ชัดเจนตลอดขั้นตอนการสมัคร เรามักใช้ data layer events เพื่อติดตามการลงทะเบียน ตั้งแต่เริ่มสมัคร ไปจนถึงสมัครสำเร็จ และทดลองใช้สำเร็จ โดยใช้ data layer events

เพื่อเป็นการสาธิตการตั้งค่า ผมจะพาคุณดูตัวอย่าง ตรงนี้ เมื่อผมมีหน้า contact ส่วนตัว ที่ผมสร้าง data layer push event ขึ้นมาเอง ทุกครั้งที่มีการส่งฟอร์ม data layer event จะถูก push ออกมา

ภายใน data layer event นี้ คุณจะเห็นชื่อของ data layer ซึ่งคุณใช้เป็น trigger เพื่อยิง Google Ads conversion tracking tag ได้ และผมยังส่งค่าอื่นๆ ไปด้วย เช่น อีเมล เบอร์โทรศัพท์ของ lead ซึ่งผมใช้สำหรับ Enhanced Conversions ในภายหลังได้ ขอโชว์วิธีการทำงานให้ดู

มาเปิด debugger กัน ผมจะโชว์อีเวนต์ใน data layer ให้ดู เราต้องคัดลอก URL และเชื่อมต่อ debugger ก่อน เพื่อดูว่าทุกอย่างทำงานถูกต้อง อันนี้เชื่อมต่อแล้ว อันนี้ก็เชื่อมต่อแล้ว

สิ่งที่ผมจะทำคือ กรอกฟอร์ม แล้วส่งมันออกไป เอาละครับ ตอนนี้คุณจะเห็นว่า มี page view ใหม่ใน debugger ซึ่งก็คือ thank you page ของผม คุณใช้ thank you page เป็น trigger ได้ แต่ลืมส่วนนั้นไปเถอะ สิ่งสำคัญคือ data layer event ที่คุณใช้เป็น trigger ได้

ดูตรงนี้ ในหน้า contact ของเรา มีอีเวนต์ใหม่ชื่อว่า form submit และอีเวนต์นี้ถูก push ตอนที่ฟอร์มถูกส่ง ถ้าเราเปิดดูข้อมูล เราจะเห็นว่าฟอร์มถูกส่งโดยชื่อ Bob Meyer อีเมลของ lead นี้คือ info@bomaripersnel นี่คือเบอร์โทรศัพท์ นี่คือข้อความ และตรงนี้ คุณเห็นชื่ออีเวนต์

นี่คือชื่อของ data layer event และมันแสดงที่นี่ด้วย และชื่อนี้สามารถนำไปใช้เพื่อ trigger แท็กของคุณได้ นั่นคือสิ่งที่เราจะตั้งค่าตอนนี้

โอเค หยุด debug แล้วไปที่การตั้งค่า Google Tag Manager กัน ตรงนี้เราไปที่ Triggers และเราจะสร้าง trigger ใหม่ trigger นี้จะชื่อว่า event form submit หรือ contact form

ต่อไปคือ trigger configuration ตรงนี้เราจะเลือก custom event และมันง่ายมาก สิ่งที่คุณต้องทำคือ คัดลอกชื่อของอีเวนต์ที่ถูก trigger และที่คุณอยากใช้เป็น trigger ผมคัดลอกมาแล้ว ซึ่งก็คืออีเวนต์นี้ และผมจะให้มันยิงบน custom events ทั้งหมด ไม่ต้องใช้ filter

ตอนนี้ผมบันทึกอีเวนต์แล้ว ต่อไป ไปที่ conversion form ที่ผมสร้างไว้แล้ว สำหรับวิดีโอเรื่อง thank you page trigger ผมจะเปลี่ยนมันเป็น event trigger แทน

ถ้าคุณจะตั้งค่า Google Ads conversion tracking pixel ใหม่ สิ่งที่คุณต้องทำคือ ตั้งค่าอย่างที่ผมโชว์ก่อนหน้านี้ แล้วตอนสุดท้าย คุณเลือกอีเวนต์ที่เพิ่งสร้าง เป็น trigger ของคุณ

เราจะบันทึกมัน แล้วส่งแท็ก จากนั้นเริ่ม debug กันใหม่ ไปที่ preview กลับไปที่หน้า contact ของเรา เอาละ Tag Assistant เชื่อมต่อแล้วที่นี่ และลองกรอกฟอร์มอีกครั้ง ส่งคำขอติดต่อทดสอบ เอาละครับ

กลับมาที่ debug ของเรา คุณจะเห็นว่า page ใหม่ contact thank you ถูก trigger แล้ว และตรงนี้คุณเห็นด้วยว่า อีเวนต์ form submit ถูก trigger บนหน้าก่อนหน้า ซึ่งเป็นหน้าที่ฟอร์มถูกส่งจริงๆ

และตรงนี้ คุณเห็นว่า Google Ads conversion tracking tag ของเราถูกยิง เนื่องจาก event trigger ที่เราใช้ นั่นแหละครับ

คุณใช้ event triggers แบบนี้ สำหรับทุก conversion ที่คุณอยากติดตามได้ ผมมักใช้มันสำหรับสถานการณ์การติดตามที่ซับซ้อน เมื่อใช้ thank you page ไม่ได้ หรือเมื่อ link-click trigger ไม่สมเหตุสมผล ดังนั้นมันมีประโยชน์มาก

อย่าลืมดู briefing ซึ่งเป็นเอกสารมาตรฐาน ที่คุณส่งให้ developer ได้ ถ้าคุณอยากให้เขาส่ง data layer push event มาให้ และถ้ามีคำถาม หรือต้องการความช่วยเหลือในการตั้งค่า Google Ads conversion tracking ของคุณ ส่งข้อความหาผมได้เลยครับ
