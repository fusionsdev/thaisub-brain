# สรุป: DeepSeek Harness VS Claude Code

- **ช่อง:** Julian Goldie SEO · **ความยาว:** ~8 นาที · **ลิงก์:** https://www.youtube.com/watch?v=Gn5x9qHuCkQ

## ประเด็นหลัก

- เปรียบเทียบ DeepSeek Harness (แฮนเนสโอเพนซอร์สฟรีตัวใหม่ของ DeepSeek) กับ Claude Code โดยใช้พรอมป์เดียวกันเป๊ะ: สร้างเว็บไซต์บัญชีสไตล์อนิเมะ 3 มิติพร้อมเกม Tetris
- DeepSeek Harness ทำเว็บไซต์เสร็จใน 11 นาที เสียเงินแค่ $0.05 และใช้ 483,000 tokens ส่วน Claude Code ใช้เวลา 30+ นาที ยังไม่เสร็จ ใช้ไปแค่ 48,000 tokens ตอนอัด
- ผลลัพธ์ของ Claude Code ดูโปรกว่า เก็บรายละเอียดได้ดีกว่า (เช่น รู้คอนเทกซ์เรื่อง Manchester, Northwest, England) และเกมที่สร้างดูลื่นไหลกว่า
- DeepSeek C++ เพิ่งปล่อยบน GitHub ได้ 2 วัน มียอด stars 105,000 ดาว เป็นโปรเจกต์ที่เติบโตเร็วที่สุดตัวหนึ่งตลอดกาล แต่เพิ่งเป็นเวอร์ชัน V0.1
- จุดเด่นของ DeepSeek Harness คือเปิดให้เสียบ "สมอง" (โมเดล) ได้อิสระ เช่น ใช้ Open Code เป็นสมอง และใช้งานได้ฟรี
- คะแนน: Claude Code desktop ได้ 9/10 (ตัวหลักที่ใช้ทุกวัน) ส่วน DeepSeek Harness ได้ 7/10 เพราะชอบการแข่งขัน แต่ยังไม่ตื่นเต้นเท่า
- ราคา: DeepSeek ถูกกว่า Claude ประมาณ 57 เท่า แต่ใช้ tokens เยอะกว่ามาก เพราะเป็นโมเดลที่ "พูดเยอะ" (verbose)
- ทีมงานใช้ DeepSeek 3.4 Pro เทียบกับ Claude Opus 5 โหมด High แบบสูสี
- ความเห็นสรุปของทีม: Claude ยังนำหน้าด้านคุณภาพผลลัพธ์ แต่ DeepSeek Harness น่าจับตามอง มีที่ว่างสำหรับทั้งคู่ในตลาด

## ความเห็นสรุป

คลิปนี้ให้ภาพชัดเจนว่าแฮนเนสโอเพนซอร์สอย่าง DeepSeek Harness กำลังมาแรงด้วยเรื่องความคุ้มค่า (ถูกกว่าเกือบ 60 เท่า) ขณะที่ Claude Code ยังครองด้านคุณภาพและความละเอียดของงาน โดยสรุปคือ Claude เหมาะกับงานที่ต้องการคุณภาพสูง ส่วน DeepSeek Harness เหมาะกับงานที่ต้องการประหยัดต้นทุน แม้จะเพิ่งเป็นเวอร์ชันแรก ๆ แต่มีอนาคตที่น่าจับตา
