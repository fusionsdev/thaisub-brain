## บทนำ
วิดีโอนี้เป็นส่วนที่ 3 ของการตั้งค่า workflow การเผยแพร่ (publishing workflow) ใน n8n โดยต่อเชื่อมโมดูลต่าง ๆ เข้ากับ Google Sheets เพื่อระบุวิดีโอที่ต้องการเผยแพร่ จากนั้นส่งข้อมูลไปยัง make.com เพื่อกระจายวิดีโอไปยังแพลตฟอร์มโซเชียลมีเดียหลายแห่ง เช่น Facebook, LinkedIn, Instagram และ YouTube พร้อมระบบยืนยันผลการเผยแพร่กลับมายัง Telegram

## คำแปลเต็ม

ตอนนี้เราต้องเริ่มต้นกับกระบวนการทำงานของการเผยแพร่ (publishing workflow) และเรามาเชื่อมต่อโมดูลที่เหลือตรงนี้เข้ากับ Google ที่ถูกต้องก่อน เพราะนี่คือส่วนสำคัญ เราสามารถส่ง video ID ที่เราต้องการใน workflow นี้เพื่อระบุวิดีโอที่อยากเผยแพร่ แล้วตรงนี้เรามาดูตรงนี้ก่อน ยังข้ามส่วนนี้ไปก่อนนะ และตรงนี้เราก็อยากใช้ชีตเดียวกัน เราต้องเลือก generate post โดยให้คอลัมน์ที่ใช้แมตช์คือ video ID และเรามาลบส่วนนี้ก่อน ลบ ลบ ลบ

และสิ่งที่เราใส่ใน TikTok เดี๋ยวจะอธิบายให้ฟังว่าหมายความว่าอะไรในอีกไม่กี่นาทีข้างหน้า และตรงนี้เราจะต้องแมตช์ video ID ก่อนที่เราจะทำได้ เรามากด save ก่อน เราจำเป็นต้องเปิดใช้งาน (activate) workflow นี้จริง ๆ ก่อน วิธีที่เราเผยแพร่วิดีโอ คล้ายกับแบบนี้ เราก็แค่พิมพ์คำว่า publish แล้ววาง video ID ของวิดีโอที่เราต้องการเผยแพร่ จากนั้นคลิก test แล้วมันก็จะเดินไปยังส่วนถัดไป เราเห็นคำว่า Post ตรงนี้เราต้องแก้ไขบางอย่าง ต้องลบส่วนนั้นออก และผมได้ปรับส่วนนี้ให้ในเวอร์ชันของคุณแล้ว คุณไม่ต้องทำเอง นี่คือตัวกรอง (filter) และตอนนี้ผมคลิก test อีกครั้ง ลองเทสต์การเผยแพร่พีดอีกครั้ง และตอนนี้มันควรจะไปที่ด้านล่างอย่างที่เห็น และตอนนี้เราต้องเข้าไปดูว่าเกิดอะไรขึ้น มันอ่าน Google Sheet ไม่ได้ โอเค นั่นเป็นเพราะเราต้องแมป video ID ที่เรามีตรงนี้ ผมต้องเข้าไปตรงนี้ก่อน เพราะสิ่งที่ต้องเปลี่ยนจริง ๆ คือ แล้วมันก็เปลี่ยนเป็นสีเขียว ผมได้ปรับส่วนนี้ให้ในเวอร์ชันของคุณแล้ว คุณไม่ต้องลบส่วนนี้ ตอนนี้คุณมี video ID แล้ว และโมดูลนี้ก็จะทำงานได้ด้วย เห็นไหม นี่คือ และตอนนี้มันจะให้ข้อมูลที่ผมต้องการ เพื่อเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ เหล่านี้ ตอนนี้ผมสามารถเชื่อมต่อมันอีกครั้งได้

และถ้าผมคลิก ผมเห็นว่าผมต้องใส่ make webhook เข้าไป make.com เป็นอีกแพลตฟอร์มสำหรับระบบอัตโนมัติและการเผยแพร่ ไม่ใช่การเผยแพร่อย่างเดียว make.com เป็นระบบอัตโนมัติอีกตัว และตรงนี้ผมได้เชื่อมโยงไว้ให้คุณแล้ว เราอยู่ในส่วนที่ 2 ของวิดีโอแล้ว และนี่คือลิงก์ไปยัง make.com คุณสามารถสมัครใช้งานฟรีได้ และเมื่อเข้าไปแล้วก็คลิก create a new scenario จากนั้นเราก็จะนำเข้า blueprint นี้ตรงนี้ เราไปที่ import แล้วเลือกไฟล์ที่เราเพิ่งดาวน์โหลดไป น่าจะเป็นไฟล์นี้ คลิก save แล้วคุณจะเห็นว่าเรามีแพลตฟอร์มโซเชียลมีเดียทั้งหมดที่คุณต้องใช้ เราจะไล่ดูกัน และเรามี webhook ที่เราต้องการ เราสามารถคลิก add webhook คลิกคัดลอก แล้วไปที่ workflow ของผม โพสต์ตรงนี้

และตอนนี้ส่วนใหญ่ควรเชื่อมต่อไว้แล้ว ตรงนี้ เมื่อผมเทสต์ ผมเห็นว่า successfully determined ตอนนี้ผมจะยกเลิกการเชื่อมต่อมันก่อน แล้วเรียกใช้ด้วยการคลิก run once เพื่อให้เห็นข้อมูลที่ถูกส่งจริง ๆ แล้วคลิก test step อีกครั้ง แล้วคุณจะเห็นว่ามันส่ง caption วิดีโอ และทุกอย่างที่เราต้องการเพื่อให้เผยแพร่ได้ เราสามารถเชื่อมต่อมันกลับมาใหม่ได้ ตอนนี้เราต้องไปที่แพลตฟอร์มโซเชียลมีเดียต่าง ๆ ถ้าคุณยังไม่ได้เชื่อมต่อกับ make.com คุณต้องเพิ่มมันก่อน คุณคลิกที่มัน แล้วมันจะให้คุณล็อกอินเข้าสู่ Facebook ในกรณีนี้ แล้วคุณก็โหลดเพจ Facebook ทั้งหมดที่คุณเป็นแอดมินได้ และถ้าคุณยังไม่มี Facebook ก็ต้องสร้างก่อน อันนี้ถูกเลือกไว้แล้ว ควรจะแมตช์กันแล้ว แล้วคุณก็แค่คลิกที่มัน และตรงนี้เราก็ต้องล็อกอินด้วยบัญชี Google เดียวกับที่มีชีต เพราะมันอาจจะส่งข้อมูลความปลอดภัยว่ามีการเผยแพร่แล้ว

อย่างที่เห็น ผมต้องเลือก Google Sheet ที่ถูกต้องตอนนี้ ตรงนี้ ชีตของผม ผมต้องขึ้นไปด้านบน พิมพ์ค้นหาอีกครั้ง พิมพ์ว่า น่าจะเป็น 28 อันนี้แหละ ชีตของผม และตอนนี้มันควรจะโหลดรูปแบบวันที่นี้มา นี่คือวันที่เผยแพร่และสถานะการเผยแพร่ ถ้าเกิดว่ามันไม่โหลด คุณก็แค่คัดลอกและวางลงไปตรงนั้น แล้วนี่คือตัวแปรที่เก็บเวลาและวันที่ และตรงนี้ใน make.com เราต้องแทรก n8n webhook นี่คือสิ่งที่เรามีตรงนี้ เห็นไหม ลองใส่ test webhook นี้ก่อน แล้วเราจะสลับมันกลับทีหลัง อันนี้ควรจะทำงานได้แล้ว

โดยพื้นฐานนี่คือการส่งข้อมูลกลับไปยัง n8n และจากนั้นไปยัง Telegram ของผม ผมจะเห็นใน Telegram ว่าวิดีโอนี้ถูกเผยแพร่ไปยังแพลตฟอร์มไหนหรืออะไรประมาณนั้น ผมจึงได้รับการยืนยันว่ามันถูกเผยแพร่แล้ว ซึ่งสำคัญสำหรับผม และนั่นคือเหตุผลที่ผมมีโมดูลสุดท้ายนี้ คุณแค่ต้องเชื่อมต่อแพลตฟอร์มโซเชียลมีเดียที่คุณอยากเผยแพร่จริง ๆ เท่านั้น ข้ามแพลตฟอร์มที่ไม่ต้องการได้ คุณแค่ลบโมดูลทิ้งก็ได้ ถ้าคุณไม่อยากได้ทั้งหมด และไม่มี TikTok เพราะ TikTok ไม่ได้อยู่ในนี้ ซึ่งเราจะทำนอก make.com เพราะ make.com ไม่มี TikTok โดยตรง แต่เดี๋ยวผมจะแสดงให้ดูในอีกไม่กี่นาที เรามาเชื่อมต่อโมดูลอื่น ๆ ก่อนเพื่อให้คุณเห็นวิธีทำ

กับ LinkedIn ก็เหมือนกัน แค่คลิก sign in with และน่าจะเสร็จแล้ว และตรงนี้จริง ๆ คุณสามารถลบทั้งหมดที่มีอยู่ได้เพราะมันจะง่ายกว่า เล็กน้อย คุณแค่ต้องคลิกแล้ววาง แล้วมันก็เชื่อมต่อแล้ว สิ่งเดียวที่ต้องเปลี่ยนตรงนี้คือแพลตฟอร์ม นี่คือ LinkedIn ใช่ไหม ขอทำแบบเดียวกัน คลิกวางอีกครั้ง และนี่คือ Instagram และตรงนี้เรามี YouTube YouTube และตอนนี้เราต้องเชื่อมต่อ Instagram ตรงนี้ก็แค่ล็อกอินด้วยบัญชี Instagram แต่ก่อนที่คุณจะเห็นบัญชี Instagram ตรงนี้ในรายการ คุณต้องมี Facebook ต้องมีเพจ Facebook ที่คุณเป็นแอดมินก่อน จากนั้นในเพจ Facebook คุณต้องคลิก switch สลับไปใช้ Facebook ในโหมดโปรไฟล์ แล้วไปที่ Settings เพราะตรงนี้คุณต้องเชื่อมต่อบัญชี Instagram ของคุณ ไปที่ linked accounts แล้วคุณจะเห็นว่าต้องเชื่อมต่อบัญชี Instagram ตรงนี้ และเมื่อเชื่อมต่อแล้ว คุณจะเห็นเพจ Instagram หรือบัญชี Instagram ของคุณในรายการดรอปดาวน์ แล้วก็แค่นั้น

กับ YouTube คุณแค่ต้องล็อกอินด้วยบัญชี YouTube คลิก sign in แล้วมันจะเลือกช่องที่คุณต้องการเผยแพร่ให้อัตโนมัติ และเมื่อเสร็จแล้วก็ไปต่อได้ ลองรีเฟรชตรงนี้ดู เจอ error ขอเก็บไว้ก่อน และเมื่อตั้งค่าอย่างนี้แล้ว ตอนนี้เราต้องเทสต์มัน ในการเทสต์ ผมจะเข้าไปตรงนี้ แล้วตรงนี้ผมต้อง trigger มัน ผมต้องใส่ค่านี้แล้วคลิก listen for test จากนั้นคลิกตรงนี้ แล้วคลิก run this module เพราะผมแค่อยากเทสต์อย่างรวดเร็ว เราต้องมี Valid URL parameter ก่อนที่จะเทสต์ได้ งั้นเรามาทำวิธีอื่นดีกว่า ก่อนอื่นเราต้องไปตรงนี้ก่อน แล้วเข้าไปตรงนี้ก่อน แล้วผมจะยกเลิกการเชื่อมต่อบัญชีอื่น ๆ เพราะผมอยากเทสต์แค่บัญชีเดียวตอนนี้ เพราะผมอยากเห็นว่า webhook ส่งข้อมูลกลับมายัง Telegram ของผมไหม เพื่อจะได้รู้ว่าเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ แล้ว ผมคลิก Run Once แล้วคลิก test step อีกครั้ง แล้วคุณจะเห็นว่ามันควรจะบันทึก มันควรส่งข้อมูลตรงนี้พร้อมกับพีดไปยังเพจ Facebook ของผม แล้วมันควรจะถูกเผยแพร่ โอเค ตรงนี้ผมเห็นแล้ว ถูกต้อง เพราะตรงนี้ผมต้องกลับไปตอนนี้ เพราะตอนนี้ผมต้องไปที่ webhook ของผม ผมต้องคลิก listen for test event แล้วคลิก run this module only และตรงนี้ผมพิมพ์ข้อความอะไรก็ได้เพราะมันไม่สำคัญ ยกเว้น chat ID ที่สำคัญ ส่วน binary ก็ไม่สำคัญ แต่ตรงนี้ต้องเป็นตัวเลข ตอนนี้ส่งแล้ว และตรงนี้คุณเห็นว่ามันได้รับแล้ว มันสำคัญตรงที่: มีข้อมูลถูกส่งไหม? มี แล้วผมไปที่ Telegram เพื่อดูว่าทุกอย่างเป็นสีเขียวไหม มันเป็นสีเขียวทั้งหมด และด้วยสิ่งนี้ การตั้งค่าก็เกือบเสร็จแล้ว

ตอนนี้ผมต้องเปลี่ยนอีกอย่างหนึ่ง ผมต้องไปที่ production URL ตรงนี้ แล้วแทนที่ test webhook ด้วยตัวจริงที่ active ตรงนี้ แล้วผมจะดูว่าวิดีโอถูกเผยแพร่ไปยังบัญชีต่าง ๆ เหล่านั้นไหม เชื่อมต่อมันอีกครั้ง แล้วคลิก run once อีกครั้ง และตอนนี้ผมต้องสลับอันนี้เป็น active แล้วส่งอีกครั้ง ตรงนี้ ข้อความ และผมเห็นว่ามี error เพราะ YouTube มีปัญหา ผมต้องกลับไปที่ YouTube อีกครั้ง ต้องเพิ่มการเชื่อมต่อ YouTube ใหม่ บางครั้งการเชื่อมต่อพวกนี้ก็หลุด คุณต้องทำใหม่ คลิกอีกครั้งแล้ว run once แล้วทำใหม่อีกครั้ง ตอนนี้มันน่าจะทำงานได้ ใช่ มันทำงานแล้ว ผมโหลดบัญชีของผมได้แล้ว และผมได้รับข้อความแล้ว วิดีโอถูกเผยแพร่ไปยัง Facebook แล้วผมไปที่ Facebook ของผม ซึ่งจริง ๆ คืออันนี้ ผมเห็นว่าวิดีโอถูกเผยแพร่แล้ว แล้วผมได้รับการยืนยันถัดไป วิดีโอถูกเผยแพร่ไปยัง LinkedIn ผมไปที่บัญชี LinkedIn ได้ มันถูกเผยแพร่ไปยัง LinkedIn ของผม และยังได้รับการยืนยันว่ามันถูกเผยแพร่ไปยัง Instagram ด้วย นี่คือ Instagram demo ของผม และตรงนี้คือ reels ของผม คุณควรจะเห็นว่ามันถูกเผยแพร่แล้ว
