ตัวอย่างเช่น HTTP request ที่ให้ข้อมูลคุณมาเป็นพันบรรทัด และคุณไม่อยากคอยคลิกหาสิ่งที่ต้องการอยู่ตลอดเวลา สิ่งที่ data transformation nodes ช่วยให้คุณทำได้คือ ช่วยให้คุณจัดระเบียบข้อมูล ใช่ไหมครับ คุณต้องการความเรียบง่าย คุณต้องการความเป็นระเบียบ เพราะถ้าคุณส่งข้อมูลจำนวนมาก มีสองอย่างเกิดขึ้น หนึ่ง มันปวดหัวมากและยากที่จะเข้าใจ แต่ยิ่งคุณส่งข้อมูลข้ามหลายโหนดมากเท่าไร คุณก็ยิ่งใช้พื้นที่มากขึ้น ตัวเลขและโค้ด JSON พวกนี้กินพื้นที่บนคอมพิวเตอร์ของคุณ มันเป็นข้อมูลปริมาณเล็กน้อยต่อชิ้น แต่ถ้าคุณมีข้อมูลไหลเข้ามาเป็นจำนวนมาก ผมเคยเห็น HTTP requests ที่ให้ข้อมูลมา 10 เมกะไบต์ และมันทำให้คอมพิวเตอร์ของคุณแครชได้ ดังนั้นการจัดระเบียบข้อมูลระหว่างทางจึงสำคัญมาก

กับตัวนี้ คุณสามารถหา data transformation nodes เหล่านี้ได้ในส่วน data แต่เราจะคลิกเข้ามาตรงนี้ มีหลายตัวที่เราจะมาอธิบายกัน ตัวแรกที่เราจะเริ่ม และสำคัญที่สุดที่คุณต้องรู้คือ edit fields node

ด้วย edit fields คุณสามารถเลือกได้ว่าต้องการส่งข้อมูลไหนผ่านไป ผมจะยกตัวอย่างให้ดู เรามีข้อมูลนำเข้าอยู่แล้ว เรามีข้อมูลทั้งหมดของคอนเทนต์ที่เราขโมยมาจากคนอื่น สมมติว่าผมมีข้อมูลเจ็ดชิ้น ผมมี sub name และ channel name สมมติว่าผมอยากส่งแค่ sub name และ channel name สิ่งที่ผมทำได้ใน edit fields คือ เข้ามาแล้วก็เพิ่ม field ด้วยตนเอง ผมพิมพ์อะไรก็ได้ เช่น สมมติว่าเราทำแบบนี้ แล้วผมก็ลากอันนี้มาตรงนี้ แล้วคุณจะเห็นว่ามันอยู่ในเครื่องหมายปีกกา นั่นคือโค้ด JSON

สิ่งที่ผมทำได้คือ ถ้าผมอยากพิมพ์ค่าทั้งหมดแบบ dynamic values ด้วยตนเอง inside ตรงนี้ dynamic value คือสิ่งที่เปลี่ยนแปลงไปตาม flow นี่คือการ hard coding บางอย่าง เช่น Hello โอเค ทุกครั้งที่ผม fire อันนี้เพื่อให้ subs ทำงาน แล้วทำไมมันถึงไม่เวิร์กล่ะ ก็เพราะว่ามันเป็นตัวเลข เห็นไหมครับ โอเค นั่นสำคัญที่คุณต้องเห็นเช่นกัน

กับ edit fields คุณสามารถตั้งค่าได้หลายอย่าง คุณมี string ซึ่งก็คือคำพูดนั่นแหละ อย่างเช่นข้อความแบบนี้ มันจะเวิร์ก มันจะถูกส่งผ่านเป็นข้อความ ตรงข้ามกับ number ตัวเลขมันไม่เวิร์ก เพราะมันเป็นตัวเลข แต่ถ้าผมใส่ 19 มันจะเวิร์ก โอเค แล้วคุณก็มี Boolean ซึ่งก็คือ true หรือ false นั่นเอง เหมือนกับเช็คหรือไม่เช็ค มันเหมือนกับการกลั่นแกล้งตรงนี้ เราไปลองดูกัน แล้วบูม ดูนี่สิ ถ้าผมใส่ true ผมว่าไม่เวิร์กนะ แต่มันเวิร์ก หรือ false ก็ได้ บูม ผมก็ไม่รู้เหมือนกันว่ามันจะเวิร์กไหม เห็นไหมครับ true

แล้วก็ array array ค่อนข้างอธิบายยาก แต่ array ก็คือลิสต์ มันคือชุดของข้อมูล ตัวอย่างเช่น ดูสิว่าอันเหล่านี้เป็น items พวกมันจะถูกส่งผ่านมาเป็น item ของตัวเอง แต่ถ้าผมอยากรวมมันเป็นชุดเดียว ผมก็เข้ามาแล้วทำแบบนี้ ลองดูว่ามันเวิร์กไหม ผมว่าไม่เวิร์กนะ แต่ถ้าผมอยากได้ item หนึ่งอัน ดูสิ ปล่อยการแปลง type ไปก่อน เข้าใจแล้ว คุณก็จะใส่ไว้ในลิสต์ นั่นคือเหตุผลที่ผมบอกว่า array ค่อนข้างปวดหัว เพราะมันถูกสร้างมาให้แสดงว่าทั้งหมดนี้เป็น items แต่ละตัว ถ้าผมอยากลิสต์มัน ผมก็จะได้ item หนึ่งอัน แล้วทั้งหมดนี้ก็จะถูกจัดกลุ่มไว้ใต้ item นั้น นั่นคือ array โดยรวม โอเค แล้วคุณจะเจอแบบนี้บ่อยมาก ให้ Claude อธิบายให้คุณฟังได้

Objects ผมไม่รู้ด้วยซ้ำว่ามันคืออะไร ผมค่อนข้างแน่ใจว่ามันไม่ใช่รูปภาพ ผมไม่ค่อยได้ใช้ objects เลย แล้วก็ binary data binary data ก็คือรูปภาพ มันคือไฟล์ ถ้าผมต้องการดาวน์โหลดรูปภาพจาก Google Drive ของผม แล้วอัปโหลดมันไปยังโซเชียลมีเดียทั้งหกแพลตฟอร์ม มันก็จะดาวน์โหลดรูปภาพมาในรูปแบบ binary data binary ก็คือชุดของเลขศูนย์และเลขหนึ่ง รูปภาพและวิดีโอทั้งหมดบนโลกก็คือชุดของเลขศูนย์และเลขหนึ่งนั่นแหละ แต่มันมีเป็นล้านล้านตัวภายในไฟล์เดียว ดังนั้นดาวน์โหลด binary data แล้วส่งผ่านมันต่อไป เลขศูนย์และเลขหนึ่งคือ binary นั่นเอง

แล้วถ้าผมอยากจัดระเบียบข้อมูลนี้ ก่อนถึง edit fields node สมมติว่าผมอยากส่งแค่ record ID ผมสามารถลบอันนี้ออกได้ ผมแค่ลากและวาง ให้ส่ง channel และส่ง subs โอเค แล้วทุก ๆ item มันจะส่งข้อมูลพวกนี้ไป ตอนนี้สังเกตว่ามีห้า items โอเค ห้า items ด้วย dynamic values พวกนี้ไม่ได้ถูก hard code มันจะเปลี่ยนไปตาม item ที่ไหลผ่านมา คุณสามารถคลิกที่ table เพื่อดูทั้งหมด นี่คือห้ารายการที่เรามี ดูสิ AI Nick blah เราจะส่งสาม field นี้สำหรับแต่ละรายการ มันไหลผ่านมาและส่ง channel กับ record ID สำหรับแต่ละรายการ และมันเป็นแบบ dynamic

ดูนี่สิ สมมติว่าผมอยาก hard code ตัวเลขสำหรับทุกอัน ไปเลย โอ้ ไม่นะ เพราะผมเพิ่มเครื่องหมายผิด นี่คือสิ่งที่ผมพูดถึงตลอด โอเค บูม แล้วมันก็ hard code ให้ทุกอัน คุณเห็นไหมว่าอันก่อนหน้านี้เป็นแบบ dynamic ดังนั้นคุณสามารถ hard code สิ่งต่าง ๆ ได้

แล้วก็ นั่นคือทั้งหมดสำหรับ edit fields โดยสรุปมันช่วยให้คุณจัดการข้อมูลและจัดระเบียบทุกอย่างได้ และคุณยังได้เรียนรู้เกี่ยวกับประเภทข้อมูลต่าง ๆ และวิธีการส่งผ่านข้อมูลอีกด้วย แต่นั่นคือทั้งหมดสำหรับวิดีโอนี้ เจอกันบทเรียนหน้านะครับ
