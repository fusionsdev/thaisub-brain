## บทนำ

บทเรียนนี้เจาะลึกวิธีตั้งค่า conversion ด้วย cart data (ข้อมูลตะกร้าสินค้า) ใน Google Ads ผ่าน Google Tag Manager โดยแบ่งเป็นสองขั้นตอนหลัก ขั้นแรกคือการให้ developer ขยาย purchase data layer ด้วยข้อมูลสินค้า ภาษา และประเทศของฟีด เพื่อให้แท็กทราบว่าจะดึงข้อมูล cost of goods sold จากที่ไหน ขั้นที่สองคือการเปิดใช้งานฟีเจอร์ product-level sales data ในแท็ก conversion ของ Google Ads ให้เรียบง่าย

## คำแปลเต็ม

มาซูมเข้าไปดูวิธีที่คุณสามารถตั้งค่า conversions ด้วย cart data กัน จริง ๆ แล้วมีสองวิธีหลัก วิธีแรกคือตั้งค่าผ่าน Google Tag หรืออีกวิธีคือใช้วิธีแบบ hard-coded ด้วย Google Tag แบบ gtag ในวิดีโอนี้ ผมอยากเจาะลึกวิธีตั้งค่าผ่าน GTM และถ้าคุณต้องการตั้งค่าผ่าน GTM โดยพื้นฐานแล้วคุณต้องทำสองอย่างใหญ่ ๆ มีสองขั้นตอนหลัก ขั้นตอนที่หนึ่งใหญ่กว่าขั้นตอนที่สอง

ในขั้นแรก โดยพื้นฐานแล้วคุณต้องให้ developer ของคุณมาช่วยอีกครั้ง developer ของคุณต้องสร้างส่วนขยายของ purchase data layer ของคุณ purchase data layer ของคุณจะถูกขยายด้วย cart data เช่น รายการสินค้าที่มาจาก Merchant Center เพื่อให้แท็กทราบว่าจะดึงข้อมูล cost of goods sold (ต้นทุนขาย) จากที่ไหน คุณยังต้องส่ง feed language (ภาษาของฟีด) และประเทศของผู้ใช้ด้วย ดังนั้นจึงมีแอตทริบิวต์บางอย่างที่คุณต้องวางไว้ใน purchase data layer เพื่อส่งต่อให้ Google Tag Manager อย่างถูกต้อง

ผมได้สร้างเทมเพลตอีเมลที่คุณสามารถใช้ส่งให้ developer หรือคนที่รับผิดชอบ data layer ของร้านค้าอีคอมเมิร์ซของคุณ และตรงนั้นคุณจะชี้ไปยัง event หรือ URL ที่ต้องการแก้ไข data layer ก่อน เก้าในสิบครั้ง คุณกำลังทำสิ่งนี้เพื่อการติดตั้งอีคอมเมิร์ซ และเก้าในสิบครั้ง อีคอมเมิร์ซของคุณตั้งอยู่บน framework ของ Google Analytics 4 ดังนั้นคุณจะมี event อย่าง view_item, add_to_cart, begin_checkout และบนหน้า checkout สำเร็จก็จะเป็น purchase

และภายใน purchase event นั้นเอง คุณจะขยาย data layer ด้วยข้อมูลหลายอย่าง สำหรับ cart data มีตัวแปรหลายตัวที่คุณต้องวางไว้ ทั้งหมดนี้จำเป็นต้องวางให้ครบ ยกเว้นตัวเดียว นั่นคือ aw_merchant_id เพราะคุณไม่จำเป็นต้องใส่ ID นี้ทุกครั้ง เนื่องจาก ID นี้จะถูกใช้ก็ต่อเมื่อคุณต้องการส่งข้อมูล cost of goods sold จากบัญชี Google Analytics หรือ Google Merchant Center ของคุณไปยัง Google Ads ในความเห็นของผม ถ้าคุณอยากใช้ฟีเจอร์นี้ให้เต็มที่ คุณควรใส่ Google Merchant Center ID ด้วย และคุณต้องเพิ่มแอตทริบิวต์ฟีดที่เป็น cost of goods sold เพื่อให้ cart data คำนวณกำไร (gross) ของคุณ แล้วส่งไปให้ Google Ads ได้

ผมยังรวมตัวอย่างการติดตั้งภายใน data layer ไว้ด้วย ตรงนี้คุณจะเห็น data layer push นี่คือ data layer push สำหรับ purchase event ของคุณ และ data layer ส่วนใหญ่ประกอบด้วยตัวแปรเหล่านี้: event ซึ่งก็คือ purchase, transaction ID เพื่อใช้ตัด Conversion ที่ซ้ำกัน, value ซึ่งก็คือมูลค่า, และ currency ส่วนใหญ่แล้วคุณจะส่งแค่ตัวแปรเหล่านี้ใน purchase event อาจมีตัวแปรเพิ่มอีกสองสามตัว แต่โดยรวมแล้วมันเป็น data layer push ที่เรียบง่ายและตรงประเด็น

คุณต้องเสริม data layer นี้ด้วยโค้ดที่ไฮไลต์ไว้ต่อไปนี้ คุณต้องส่ง merchant ID ของคุณ ซึ่งเป็นตัวเลขสุ่มหนึ่งชุด คุณต้องส่ง feed language และรายการสินค้าที่ซื้อรวมกันในรูปแบบ array ด้วย ถ้าคุณมีสินค้าหลายรายการในออเดอร์ คุณต้องใส่ใน array และสำคัญมากที่ developer จะต้องเข้าใจสิ่งนี้ เพราะถ้าคุณไม่ใส่สินค้าใน array cart data ของคุณจะไม่ทำงาน ต้องระวังเรื่องการติดตั้งจุดนี้ให้มาก และทำตามคู่มือ

สิ่งที่คุณต้องทำ ถ้าคุณโฆษณาในประเทศเดียว ภาษาเดียว จากบัญชี Google Merchant Center เดียว คุณก็สามารถใส่ค่าคงที่ (static values) สำหรับ merchant ID, feed ID และ feed language ได้ สมมติว่าผมเป็นนักโฆษณาอีคอมเมิร์ซในประเทศหนึ่ง และส่งสินค้าไปที่เนเธอร์แลนด์เท่านั้น ไม่ส่งไปประเทศอื่น จากบัญชีเดียว ผมก็แค่สั่งให้ developer ใช้ค่าคงที่มาใส่ตรงนี้ได้

แต่ถ้าคุณใช้ Google Merchant Center หลายบัญชี และใช้ฟีดหลายประเทศ เช่น ถ้าคุณอยู่ในสหรัฐฯ แล้วยังส่งไปประเทศอื่นด้วย คุณต้องทำให้ค่าเหล่านี้เป็น dynamic คุณต้องทำให้ feed country เป็น dynamic ตามประเทศที่จัดส่งออเดอร์ไปถึง สมมติว่าคุณส่งไปประเทศหนึ่ง ทั้งที่ปกติเว็บของคุณอยู่ในสหรัฐฯ คุณต้องแก้ feed country ให้เป็นรหัสประเทศที่คุณส่งไป เช่นเดียวกันกับ feed language

ขออีกตัวอย่างหนึ่ง สมมติว่าผมเป็นร้านค้าออนไลน์ในเนเธอร์แลนด์ และเพิ่งขายออเดอร์ให้ลูกค้าคนหนึ่งในเบลเยียม feed country ควรเป็น BE ซึ่งดึงจากภายในบัญชี GMC ของผม และ feed language อาจเป็นภาษาดัตช์หรือฝรั่งเศสก็ได้ ขึ้นอยู่กับภาษาของร้านค้า คุณสามารถสร้างตัวแปรตรงนี้ที่ส่ง feed language ที่ถูกต้องได้ โดยอิงจาก feed language ที่ถูกกำหนดเป้าหมายไว้ในฟีดของคุณสำหรับผู้ใช้คนนั้น

สมมติว่ามันเป็นชุดค่านี้ ผู้ใช้มาจากภูมิภาคที่พูดภาษาฝรั่งเศสในเบลเยียม ฟีดภาษาฝรั่งเศสของคุณที่กำหนดเป้าหมายในเบลเยียมถูกใช้ และ ID ของบัญชี Google Merchant Center ของคุณคือ 98765 นี่คือค่าที่คุณอยากจะใส่แบบ dynamic และ developer ของคุณต้องสร้างสิ่งนี้ให้คุณ โดยอิงจากเงื่อนไขบางอย่างที่คุณตกลงกัน

แต่ถ้าคุณโฆษณาในหลายประเทศที่เกินกว่าค่าคงที่เดียว คุณต้องแน่ใจว่าทำให้ค่าเหล่านี้เป็น dynamic และต้องแน่ใจว่าถ้าคุณส่งสินค้าในรูปแบบ array คุณใช้ ID เดียวกับที่ใช้ในบัญชี Google Merchant Center ของคุณ ตรวจสอบสามรอบ ไม่งั้น cart data ของคุณจะไม่ถูกจับคู่กับสินค้าที่คุณอัปโหลดในบัญชี GMC ของคุณ ดังนั้นควรปรึกษาหรือวิเคราะห์ว่าคุณต้องใช้ฟิลด์ ID ภายในตัวไหน อาจเป็น post ID หรือแม้แต่รหัสสินค้าแบบอื่น ต้องตรวจสอบให้ดีว่าใช้ ID ตัวไหน ตาม ID ที่คุณใช้ในบัญชี GMC ของคุณ แล้วทุกอย่างจะเรียบร้อย

ถ้าส่วนนี้เข้าที่แล้ว และ developer ของคุณแก้ไข data layer เสร็จแล้ว คุณก็ขยับไปที่ Google Tag Manager ได้ ซึ่งก็คือขั้นตอนที่สอง ในขั้นตอนนี้ คุณต้องแก้ไขเล็กน้อยที่แท็ก Google Ads conversion tracking ของคุณ ซึ่งง่ายมาก ผมจะโชว์ให้ดู นี่คือจุดที่คุณเปิดใช้งานฟีเจอร์ cart data ขอหยิบบัญชีเดโม่ของผมก่อน แล้วข้ามไปที่แท็ก Google Ads conversion tracking แบบสุ่มหนึ่งตัว สมมติว่านี่ไม่ใช่แท็กฟอร์มติดต่อ แต่เป็นแท็ก purchase โดยส่ง conversion value, transaction ID และ currency

สิ่งเดียวที่คุณต้องทำตรงนี้ ก็คือติ๊กช่องเล็ก ๆ นี้ "provide product-level sales data" แล้วใช้ data layer ถ้าคุณทำตามคำแนะนำในเทมเพลตอีเมลหรือคู่มืออย่างเป็นทางการ คุณสามารถอ้างอิง data layer ได้ ตราบใดที่คุณใช้รูปแบบเดียวกันกับที่ Google แนะนำ ถ้าคุณไม่ได้ใช้รูปแบบเดียวกันกับที่ Google สอนไว้ คุณก็ใช้ custom fields ได้ และตรงนั้นคุณสามารถแมปตัวแปรหลายตัวตามตัวแปรใน data layer ของคุณ เพื่อชี้ให้ Google Tag Manager ไปที่ตัวแปร cart data ที่ถูกต้อง

แต่ในความเห็นของผม คุณควรใช้ data layer เพราะมันเป็นวิธีที่มีประสิทธิภาพที่สุด และไม่ค่อยเสี่ยงต่อความผิดพลาด พอตั้งค่าเสร็จ คุณก็บันทึก และ publish container ของคุณ จากนั้น cart data ของคุณจะถูกส่งไปยัง Google Ads และทุกอย่างก็เสร็จสมบูรณ์ ขอให้โชคดีกับการตั้งค่านะครับ ในวิดีโอหน้า ผมจะพูดถึงวิธีติดตั้งแบบ hard-coded ถ้าคุณไม่ได้ใช้ GTM สำหรับแท็ก Google Ads conversion tracking ของคุณ ไปต่อกันเลย
