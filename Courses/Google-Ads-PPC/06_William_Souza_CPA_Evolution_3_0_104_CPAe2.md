## บทนำ

คลิปนี้เป็นวิดีโอสั้นๆ เกี่ยวกับการจดโดเมน (domain) วิลเลียมอธิบายว่าโดยปกติแล้วไม่จำเป็นต้องจดโดเมนเพื่อใช้กับวิธีใน CPA Evolution 2.0 เพราะใช้ซอฟต์แวร์ของเขาได้ แต่ถ้าอยากใช้ landing page ของตัวเองหรือต้องการ host ตัวติดตาม (tracking) ก็ต้องมี hosting และโดเมนเป็นของตัวเอง พร้อมสาธิตการจดโดเมนกับผู้ให้บริการที่เขาแนะนำ

## คำแปลเต็ม

ยินดีต้อนรับสู่วิดีโอใหม่นี้ครับ และในคลิปนี้ผมแค่อยากพูดกับคุณสั้นๆ เกี่ยวกับการจดโดเมน

สิ่งแรกที่ผมอยากบอกคือ มันไม่จำเป็นจริงๆ ที่คุณต้องทำตามบทเรียนและวิธีต่างๆ ใน CPA Evolution 2.0 เพราะวิธีทั้งหมดที่เรามี แม้ว่ามันต้องใช้ landing page หรือส่วนใหญ่ต้องใช้ landing page หน้า landing เหล่านั้นก็สามารถสร้างได้ด้วยซอฟต์แวร์ของเรา คุณจึงใช้เซิร์ฟเวอร์และโดเมนของเราเพื่อรันแคมเปญของคุณได้

ดังนั้นมันไม่จำเป็นต้องจดโดเมน แต่ในกรณีที่คุณอยากใช้ landing page ของคุณเองจากแหล่งอื่น หรือถ้าคุณต้องการสร้าง landing page เอง หรือถ้าคุณต้องการ host ระบบติดตาม (tracking) ของคุณเอง คุณอาจต้องมีบัญชี hosting และชื่อโดเมน

การจดโดเมนนั้นง่ายมาก คุณแค่ต้องไปที่ผู้รับจดทะเบียน (registrar) Namecheap.com เป็นผู้ที่ผมแนะนำ พวกเขามีการสนับสนุนที่ยอดเยี่ยมมากๆ เป็น registrar ที่คุณจะชอบทำงานด้วยแน่นอน

และมันง่ายมาก แค่เข้ามาที่นี่ คุณค้นหาโดเมนที่ต้องการ สมมติว่าค้นหาอะไรสักอย่างเช่น CPA แล้วกดปุ่มค้นหา แล้วดูว่านามสกุล (extension) ไหนว่างบ้าง

อย่างที่เห็น cpatraining.com ถูกจดไปแล้ว CPATraining.net ก็ถูกใครสักคนจดทะเบียนไปแล้ว แต่ก็ยังมีนามสกุลอื่นว่างอยู่ สมมติว่าผมอยากเลือก cpatraining.co ผมก็แค่คลิกปุ่มนี้เพื่อเพิ่มโดเมนลงในตะกร้าของผม แล้วก็ดำเนินการชำระเงิน แล้วก็จบ โดเมนถูกจดทะเบียนเรียบร้อยในบัญชีของผมกับ Namecheap

จากนั้นผมก็แค่ต้องชี้ name server หรือ DNS ของโดเมนไปยังบริษัท hosting และมีบทช่วยสอนอธิบายวิธีทำสิ่งนี้ใน CPA Evolution 2.0 อยู่แล้ว คุณแค่ทำตามบทช่วยสอนนั้น คุณก็สามารถชี้โดเมนไปยัง hosting ของคุณ แล้วหลังจากนั้นคุณก็สามารถใช้มันได้แล้ว

และจริงๆ แล้วสำหรับวิธีต่างๆ ที่เราจะใช้ใน CPA Evolution สมมติว่าคุณจะใช้โดเมนสำหรับ hosting เว็บไซต์และ landing page คุณไม่ต้องกังวลเรื่องนามสกุลโดเมนมากนัก เพราะสิ่งที่เราจะทำไม่เกี่ยวข้องกับ SEO ดังนั้นนามสกุลอาจมีความหมายในบางกรณี แต่สำหรับวิธีส่วนใหญ่ที่เราครอบคลุม มันเกี่ยวข้องกับระบบอื่นๆ เช่น paid social, video และสิ่งเหล่านั้น ซึ่งนามสกุลของโดเมนไม่ค่อยสำคัญเท่าไหร่

เอาล่ะ จบสำหรับวิดีโอนี้ครับ มันเป็นแค่วิดีโอสั้นๆ เพื่อแสดงวิธีจดโดเมน ซึ่งง่ายมาก และขอบคุณมาก แล้วเจอกันในวิดีโอหน้าๆ ครับ
