## บทนำ
ต่อจากตอนที่แล้ว คลิปนี้เป็นการตั้งค่าระบบเผยแพร่ (publishing) ให้วิดีโอที่ระบบสร้างขึ้นถูกโพสต์อัตโนมัติไปยังแพลตฟอร์มโซเชียลมีเดียต่าง ๆ ผ่าน make.com เริ่มจากนำเข้า blueprint ตั้งค่า webhook เชื่อมต่อ Google Sheet ที่ปรับแต่งด้วย Apps Script ตั้งตารางการเผยแพร่ เชื่อมต่อ Facebook, Instagram, LinkedIn, YouTube และ TikTok ผ่าน uploadpost.com พร้อมรับอีเมลยืนยันกลับมาที่ inbox ของคุณ

## คำแปลเต็ม

ในตอนนี้เราจะมาตั้งค่าระบบเผยแพร่ เราต้องการให้วิดีโอที่เข้ามาในระบบถูกจัดตารางเผยแพร่อัตโนมัติตามกำหนดที่เราตั้งได้ตรงนี้ ซึ่งผมจะพูดถึงรายละเอียดอีกครั้งในอีกไม่กี่นาที และเราจะเปลี่ยนไปใช้อีกแพลตฟอร์มหนึ่ง เพราะผมพบว่าการเชื่อมต่อแพลตฟอร์มโซเชียลมีเดียใน make.com (แพลตฟอร์มระบบอัตโนมัติ) ทำได้ง่ายกว่าในทางเทคนิค คุณสามารถคลิก sign up เพื่อสมัครบัญชีฟรี ซึ่งเพียงพอสำหรับการทดสอบ และยังใช้เป็นแพลตฟอร์มเผยแพร่จริงได้ด้วย สร้าง scenario ใหม่ แล้วไปที่ขั้นตอนหมายเลข... คลิกตรงนั้น มันจะดาวน์โหลด blueprint อีกตัวสำหรับ make.com สำหรับระบบเผยแพร่ของเรา แล้วคลิก import นำเข้าไฟล์ publisher เข้ามา

พอระบบอัตโนมัติพร้อมแล้ว มีไม่กี่อย่างที่ต้องทำ ไปที่ webhooks แล้วคลิก add a webhook webhook คือวิธีดักจับข้อมูล ในกรณีนี้เราต้องการรับข้อมูลจาก Google Sheet ของเรา คัดลอกแอดเดรสไว้ เพราะสิ่งที่ต้องทำคือกลับไปที่ Google Sheet เพราะตรงนี้มีบางอย่างที่คุณอาจไม่ทันสังเกต นี่คือ Google Sheet ที่ปรับแต่งพิเศษ ผมเขียนสคริปต์เพิ่มเติมให้มันมีฟังก์ชันพิเศษ เพื่อให้เผยแพร่วิดีโอจาก Google Sheet ได้อัตโนมัติ เราต้องคลิก authorize เพื่ออนุญาต คลิก OK เลือกบัญชี Google ของคุณ คลิกลิงก์ด้านล่าง แล้วเลือกทั้งหมดแล้วคลิก continue พอทำเสร็จแล้ว คลิก install trigger หรือ install automation จากนั้นยังมีอีกสองสามอย่างที่ต้องทำ ไปที่ Apps Script (เครื่องมือเขียนสคริปต์ของ Google) สิ่งที่ต้องทำคือเปลี่ยนค่าสองสามค่า แต่มันง่ายมาก ไม่ต้องเขียนโค้ดอะไร ค่าแรกที่ต้องกรอกคือ sheet ID ก่อนอื่นคัดลอกมันมา แล้วใช้ Ctrl+F เพื่อค้นหา แล้ววางลงตรงนี้ แล้วขยายส่วนนี้ เพื่อหา sheet ID ของเรา sheet ID ของเราอยู่ตรงนี้ นี่คือ sheet ID แล้วแทนที่มัน คลิก replace all

อย่างถัดไปก็ทำแบบเดียวกันกับ webhook คัดลอกมัน ไปที่ Ctrl+F วางลงไป ลบของเดิม กลับมา คัดลอกอันนี้ วางลงไป คลิก replace เท่านี้ จากนั้นเลือก test and send row เราต้องคลิก save แล้วกลับมาตรงนี้เพื่อให้แน่ใจว่ามันกำลังฟังอยู่ ถ้ามันหยุดไปด้วยเหตุผลใดก็ตาม ให้คลิก redetermined data structure แล้วเข้าไปคลิก make sure... test send row ใน make.com นี่คือฟังก์ชันทดสอบ และคุณจะเห็นว่าถ้ามันทำงาน มันจะหน้าตาแบบนี้ สิ่งที่เราจะทำคือ เริ่มจาก unlink อันนี้ออกก่อน แล้ว trigger เวิร์กโฟลว์นี้โดยคลิก run once จากนั้นส่งข้อมูลทดสอบไปที่ webhook ของระบบอัตโนมัติ แล้วคุณจะเห็นว่ามันส่งข้อมูลถูกต้องไหม เรามีข้อความโพสต์ (post text) เรามีวิดีโอ URL และอีเมล เราต้องการรับการตอบกลับเมื่อเผยแพร่เสร็จ

จากนั้นเราจะเชื่อมต่อโมดูลเผยแพร่ต่าง ๆ เพื่อกระจายข้อมูลที่ส่งไปที่ webhook ไปยังแพลตฟอร์มต่าง ๆ และก่อนหน้านั้นผมอยากโชว์ฟีเจอร์เจ๋ง ๆ อีกหนึ่งอย่าง คือมีบางอย่างเกิดขึ้นแล้ว พอเราเปิดใช้งานระบบ มันได้จัดตารางวิดีโอของผมให้เผยแพร่แล้ว ตรงนี้คือตารางเวลาที่ตั้งได้ตรงนี้ เราพิมพ์ได้ว่าต้องการเผยแพร่กี่วิดีโอต่อวัน และช่วงเวลาใดที่วิดีโอควรถูกเผยแพร่ เช่น 9 โมงถึง 7 โมงเย็น พอตั้งค่าเสร็จ ควรตั้งก่อนคลิก setup เพราะทุกครั้งที่มีวิดีโอใหม่เกิดขึ้น ระบบจะใช้ตารางเวลานี้ แต่คุณเปลี่ยนทีหลังได้ในสเปรดชีต จากนั้นวิดีโอของผมจะถูกจัดตารางในสามวันถัดไประหว่าง 9 โมงเช้าถึง 7 โมงเย็น แล้วเผยแพร่และส่งไปยังแพลตฟอร์มต่าง ๆ ในช่วงเวลานั้น แค่จำไว้ตรงนี้

ต่อไปมาด้านบนสุด เชื่อมต่อ Facebook คลิก Add แล้วคลิก Save ไปที่ Facebook พิมพ์ชื่อ คลิก save แล้วทำต่อด้วยบัญชี Facebook ของคุณ ตรวจสอบว่าคุณเป็นแอดมินของ Facebook Page เพราะวิดีโอจะถูกเผยแพร่ไปที่ Page ไม่ใช่โปรไฟล์ส่วนตัว จากนั้น Facebook ที่เชื่อมต่อกับบัญชีคุณจะโหลดขึ้นมาตรงนี้ ผมจะเลือกอันนี้ ทุกอย่างตั้งไว้แล้ว ตัวแปรวิดีโอพวกนี้มาจาก webhook อยู่แล้ว ดี

ต่อไป Google Sheet ก็สำคัญเหมือนกัน สิ่งที่มันทำคือเขียนวันที่เผยแพร่และเปลี่ยนสถานะจาก scheduled เป็น published เพื่อให้รู้ว่าวิดีโอนี้เผยแพร่แล้ว ตรงนี้ต้องเชื่อมต่อบัญชี Google อีกครั้ง คลิก sign in with Google เข้าสู่ระบบด้วยบัญชีเดียวกับที่เป็นเจ้าของ Google Sheet นี้ พอทำเสร็จ... เหมือนที่ผมแสดงก่อนหน้านี้ คลิก sign in with Google เลือกบัญชีเดียวกัน แล้วมันจะขึ้นใน drop-down คลิก search แล้วคลิกที่ sheet ID มันควรโหลด Google Sheet ใหม่ขึ้นมา ชีตของผมชื่อ demo13 พิมพ์ demo 135 ก็ได้ เท่านี้มันควรโหลดขึ้นมาแล้ว แค่นั้น

ต่อไปคือการตอบกลับ (response back) นี่คือจุดที่เราต้องการรับอีเมลแจ้งว่า "วิดีโอของคุณถูกเผยแพร่แล้ว" นี่คือตัวอย่าง: วิดีโอของคุณถูกเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ ในเวลานี้ นั่นคือสิ่งที่ผมต้องการให้มีกลับมา เพื่อยืนยันว่าวิดีโอถูกเผยแพร่จริง และในการทำแบบนี้ ก่อนอื่นต้องเข้าไปที่ webhook สิ่งที่ต้องทำคือ เลือก production URL... จริง ๆ คือ test URL ของ webhook ซึ่งใช้ระหว่างการทดสอบ และนี่คือสิ่งเดียวที่ต้องตั้งตรงนี้ จากนั้นต้อง trigger ก่อนอื่น unlink โมดูลอื่น ๆ ออก ผมต้องส่งข้อมูลจาก webhook นี้กลับไปยังเวิร์กโฟลว์ N8N ของผม ในการทำแบบนี้ ต้องเปิดใช้งาน (activate) ก่อน แล้วเปลี่ยนเป็น listen for test แล้ว trigger อันนี้ มันจะส่งข้อมูลโพสต์ไปเผยแพร่ แล้วผมจะได้รับการตอบกลับกลับมาที่ webhook ใน N8N แล้วคุณจะเห็นว่ามันทำงานได้ กลับมาดู มันทำงานแล้ว

จากนั้นตั้งค่า Gmail response node เป็นบัญชี Gmail เดียวกับที่ใช้เป็น trigger ตอนต้น นี่คือจุดที่เราส่งต่อจดหมายข่าวไป แล้วมันถูกเปลี่ยนเป็นวิดีโอ และระบบอัตโนมัติส่งการตอบกลับกลับมาที่ inbox ที่เก็บจดหมายข่าวทั้งหมด และตรงนี้ที่เราต้องการรับการยืนยัน ตรงนี้ไม่จำเป็นต้องเป็น Gmail inbox เราต้องการ Gmail แค่บัญชีเดียวสำหรับเชื่อมต่อกับระบบอัตโนมัติ เพราะอีเมลที่คุณส่งต่อมาจากถูกดึงออกจาก trigger และนี่คือผลลัพธ์ที่มาจากสเปรดชีต นั่นคือเหตุผลที่เราระบุอีเมลของคุณตรงนี้ เราเก็บที่อยู่อีเมลไว้ในชีตภายใต้ email response แล้วส่งต่อผ่านระบบอัตโนมัติกลับไปที่เวิร์กโฟลว์ N8N มันรับกลับมาที่นี่ เพื่อส่งการยืนยันกลับไปยังอีเมลของคุณ และทุกอย่างเป็นสีเขียว คุณเห็น subject line ตรงนี้ นี่คือ title ที่บอกว่าถูกเผยแพร่ไปยังแพลตฟอร์มไหน แล้วก็เนื้อหาอีเมล บอกว่าเผยแพร่ผ่านแพลตฟอร์มนี้ในเวลานี้ ถ้าคลิก send test ผมควรได้รับอีเมลตรงนี้ คุณเห็นไหม "วิดีโอ AI digital watches ของคุณถูกเผยแพร่ไปที่ Facebook" เยี่ยม และเห็นว่าทุกอย่างเป็นสีเขียว สิ่งเดียวที่เหลือคือกลับไป สลับเป็น production แล้วเปลี่ยน test webhook เป็น production webhook เพราะผมทดสอบแล้วและรู้ว่ามันทำงาน ข้อมูลถูกส่งถูกต้อง แค่นั้น

สิ่งที่เหลือคือเชื่อมต่อโมดูลอื่น ๆ ทั้งหมด อันถัดไปคือ Instagram ก่อนเชื่อมต่อต้องไปที่ Facebook แล้วไปที่ Facebook Page ที่คุณเป็นแอดมิน แล้วไปที่ switch profile เพื่อสลับเป็น Acting as Facebook Page แล้วไปที่ linked accounts ตรงนี้ต้อง link บัญชี Instagram ที่ต้องการเผยแพร่ไป คุณจะเห็นอะไรประมาณ connect an Instagram แล้วคลิก connect พอทำเสร็จกลับมาที่ make.com คลิกแล้วระบบจะให้ sign in ด้วยบัญชี Facebook พอทำเสร็จ บัญชี Instagram ที่เพิ่ง link จะโผล่ใน N8N ให้เลือกได้ และตรงนี้ควรตั้งค่าไว้แล้ว ไม่ต้องทำอะไรเพิ่ม สิ่งเดียวที่ผมจะเปลี่ยนคือ ผมจะ clone โมดูลนี้กับ Google Sheet แล้วเชื่อมต่อตรงนี้ และตรงนี้ผมใช้ webhook เดียวกัน คุณสามารถแทนที่ webhook ในโมดูลต่าง ๆ เหล่านี้ได้เลย และอย่างที่เห็น แต่ละโมดูลเราระบุแพลตฟอร์มเฉพาะ เช่น TikTok เป็นต้น เราจะได้รู้เสมอว่าเผยแพร่ไปที่ไหน

ต่อไปอันถัดไป อันนี้แค่ดึงรูปภาพและวิดีโอของผมมาเป็น... ซึ่งจำเป็นสำหรับ LinkedIn คลิก add connection แล้วระบบจะให้ sign up ด้วยบัญชี LinkedIn พอทำเสร็จคลิก save และตรงนี้ผมจะลบโมดูล Google Sheet ทิ้ง เพราะมันเหมือนกันทุกแพลตฟอร์ม และคุณตั้งค่าเฉพาะแพลตฟอร์มที่ต้องการเผยแพร่จริงเท่านั้น ไม่ต้องตั้งทั้งหมดถ้าไม่ใช้ทั้งหมด แต่ผมแค่อยากโชว์ให้ดู แล้วเชื่อมต่ออันถัดไป อันนี้ไม่ต้องตั้งค่าอะไร และต่อไปคือ YouTube ไปที่ YouTube คุณอาจเจอขั้นตอน verify แล้วต้องคลิกเชื่อมต่อใหม่ ผมจะไปที่ YouTube พิมพ์ข้อมูล แล้วคลิก sign in with Google เลือกบัญชีที่เชื่อมกับช่อง YouTube ของผม เลือกช่อง YouTube แล้วคลิก open อีกครั้ง มันโหลดขึ้นมา แล้วต้อง map ค่าอีกครั้ง ตรงนี้คือ post title คุณเลือกวิดีโอว่าต้องการเผยแพร่ไปที่ไหน ตรงนี้ต้องเลือก public คำอธิบายคือตัวโพสต์นั่นแหละ เท่านี้ คลิก save คลิกอีกครั้ง แล้วเสร็จ

ส่วนสุดท้าย ก่อนอื่นคลิก save ต่อไปคือ TikTok TikTok ไม่มีการเชื่อมต่อโดยตรงกับ make.com แต่เราใช้วิธีแก้ (workaround) ซึ่งก็ง่ายพอสมควร โมดูลแรกยังเหมือนเดิม โมดูลที่สองต่างออกไปเล็กน้อย ตรงนี้เราใช้บริการอีกตัวหนึ่งซึ่งจะพบได้ใต้วิดีโอนี้: uploadpost.com ไปที่เว็บ คุณสมัครบัญชีฟรีได้ บัญชีฟรีเผยแพร่ได้สูงสุด 10 วิดีโอต่อเดือน และต้องอัปเกรด $14 ต่อเดือนเพื่อได้ 120 วิดีโอต่อเดือน นี่เฉพาะถ้าคุณต้องการเผยแพร่ไปที่ TikTok และนี่คือการเชื่อมต่อที่ง่ายที่สุดในตอนนี้ ลองใช้ฟรีก่อนได้ คลิก try for free สมัครบัญชี พอเสร็จไปที่ manage users แล้วคลิก add a new user การเพิ่มผู้ใช้ใหม่ แค่เพิ่มชื่อ ซึ่งไม่จำเป็นต้องตรงกับชื่อบัญชี TikTok ก็ได้ ไม่สำคัญ จากนั้นคลิก TikTok มันจะเชื่อมต่อกับบัญชี TikTok ที่คุณกำลังล็อกอินอยู่โดยอัตโนมัติ แล้วก็เชื่อมต่อเสร็จ แค่นี้สำหรับตอนนี้ สิ่งเดียวที่ต้องทำอีกคือขอ API key ไปที่ส่วนนั้น ผมมีบทเรียนสั้น ๆ ให้ด้วย เรื่อง Get API key from uploadpost.com คลิกดูได้ถ้าต้องการความช่วยเหลือเพิ่ม แต่ก็ง่ายมาก: ไปที่ API keys สร้างใหม่ แล้วใส่ลงใน make.com สิ่งเดียวที่ต้องเปลี่ยนตรงนี้คือใส่ username ของคุณ ซึ่งหาได้จาก registered users คัดลอกค่านั้นมาวางตรงนี้ เท่านี้ก็เสร็จ

เมื่อตั้งค่านี้เสร็จ เราสามารถทดสอบรอบสุดท้ายได้ สิ่งที่ผมจะทำคือคลิก test และตรงนี้ก็สลับเป็น active แล้วกลับไปที่ชีต คลิก run the test function อีกครั้ง แล้วสังเกตใน make.com ว่ามี error ไหม แล้วตรวจว่าวิดีโอถูกเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ หรือยัง ตอนนี้มันรันสำเร็จ และถูกเผยแพร่ไปยังบัญชี TikTok ของผมด้วย จากนั้นผมจะเชื่อมต่อโมดูลทั้งหมด คลิก align แล้วตรวจสอบว่าวิดีโอถูกเผยแพร่หรือยัง คุณเห็นบนบัญชี TikTok, LinkedIn, YouTube, Facebook และ Instagram ของผม

มีสิ่งหนึ่งที่ควรพูดถึง: ตอนแรกที่คุณลองเชื่อมต่อโมดูล TikTok ผ่าน uploadpost.com อาจมี error เกิดขึ้นได้ สำหรับผม error หน้าตาแบบนี้ คุณอาจเจอ error แบบนี้ ซึ่งถึงแม้ดูเหมือนไม่มีอะไร แต่ถ้าคลิกที่สัญลักษณ์นี้แล้วเลื่อนลงไปที่ header นี่คือจุดที่ error จะแสดง "โพสต์ไม่ถูกเผยแพร่" เพราะบางครั้งมันเกิดขึ้นตอนเริ่มต้น แต่ทีมสนับสนุนตอบกลับมาว่าเป็นข้อจำกัดที่ตั้งไว้ การตั้งค่าตรงนี้ถูกต้องแล้ว ไม่ต้องกังวล สำหรับผม error นี้หายไปหลังจากประมาณ 20-30 นาที แล้วการเผยแพร่ TikTok ก็ทำงาน และบางครั้งอาจใช้เวลาถึง 24 ชั่วโมงกว่าจะหาย ตามที่ทีมสนับสนุนแจ้ง แค่จำไว้ ถ้ายังทำไม่ได้ ผมจะแปะลิงก์ใต้วิดีโอนี้สำหรับวิธีเผยแพร่ไปยัง TikTok ด้วยวิธีอื่นผ่าน Buffer และ Zapier

ขั้นตอนสุดท้าย: ต้องสลับเป็น active คลิก แล้วตรวจให้แน่ใจว่า... จากนั้นไปที่ N8N ตอนนี้ปิดหน้านี้ได้ ปิด N8N ได้ แล้วคุณลองรันทดสอบสองสามครั้งได้ และคุณเห็นว่าวิดีโอของผมถูกเผยแพร่ ผมได้รับการยืนยันจากทุกแพลตฟอร์ม และตอนนี้ผมจะทดสอบรอบสุดท้าย ถ้าผมเป็นคุณ: หยิบจดหมายข่าวมาฉบับหนึ่ง เพราะทุกอย่างตั้งค่าเสร็จแล้ว แค่ส่งต่อ (forward) ไปที่ inbox ที่เชื่อมต่อกับระบบ แล้วปล่อยให้ระบบสร้างโพสต์ แล้วใน Google Sheet คุณควรเห็นรายการใหม่และถูกจัดตาราง และคุณรันฟังก์ชันทดสอบก็ได้ ไปที่ชีต คลิก test หรือปล่อยไว้ แล้วในสองสามวันถัดมา ค่อยตรวจว่าโพสต์ถูกเผยแพร่ไปยังโซเชียลมีเดียของคุณจริงไหม
