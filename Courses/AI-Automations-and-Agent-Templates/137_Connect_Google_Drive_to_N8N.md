## บทนำ
วิดีโอนี้สอนวิธีเชื่อมต่อ Google Drive เข้ากับ n8n ซึ่งต่างจากการเชื่อมต่อ Google Sheets ตรงที่ต้องใช้ client ID และ client secret จาก Google Cloud Console ขั้นตอนครอบคลุมตั้งแต่การสร้างโปรเจกต์ เปิดใช้งาน API สร้าง OAuth client ID กำหนดขอบเขตการเข้าถึง (scopes) เพิ่มผู้ใช้ทดสอบ และนำ client ID กับ client secret ไปวางใน n8n เพื่อเชื่อมต่อบัญชี

## คำแปลเต็ม

การเชื่อมต่อกับบัญชี Google Drive ของคุณนั้นไม่ตรงไปตรงมาเหมือนกับการเชื่อมต่อ Google Sheets คุณไม่สามารถแค่ล็อกอิน Google แล้วมันจะเชื่อมต่อให้ทันที มันต่างออกไปเล็กน้อยตรงนี้ คุณต้องมี client ID และ client secret

เพื่อให้ได้มา คุณต้องไปที่ Google Cloud Console แล้วใช้บัญชีของคุณเชื่อมต่อ หรือสมัครบัญชีใหม่ถ้าคุณไม่เคยใช้มาก่อน จากนั้นคุณต้องไปที่ enable APIs and services ถ้าคุณไม่เคยใช้ มันอาจจะหน้าตาแบบนี้ คลิก agree and continue จากนั้นผมสามารถสร้างโปรเจกต์ใหม่ได้ ผมตั้งชื่อมันว่า my drive connection AI agent social media demo organization ลองคลิก create ดู เหมือนมันยาวเกินไป ขอเรียกมันแค่นั้น แล้วคลิก create

จากนั้นผมต้อง enable APIs and services ซึ่งบางครั้งอาจใช้เวลาสักครู่ มันไม่ใช่แพลตฟอร์มที่เร็วที่สุด ดังนั้นไม่ต้องแปลกใจถ้ามันโหลดอยู่สองสามวินาทีก่อนที่อะไรจะแสดงขึ้นมาตรงนี้ ตอนนี้มันให้ Google Drive มาให้แล้ว บางทีมันอาจเจอให้แล้ว ถ้าคุณต้องการตัวเลือกอื่น ถ้ามันไม่แสดงขึ้นมา คุณสามารถไปที่ library ได้ ถ้าผมคลิก library แล้วคุณสามารถค้นหามันได้ แล้วมันจะขึ้นมา แล้วคุณก็เปิดใช้งานมันได้

จากนั้นผมคลิกตรงนี้ ตอนนี้มันเปิดใช้งานแล้ว ดังนั้นผมสามารถคลิกที่เมนูนำทางตรงนี้ ผมไปที่เมนู แล้วไปที่ APIs and services จากนั้นผมต้องไปที่ credentials ตรงนี้ผมต้องคลิก create credentials ผมต้องเลือก OAuth client ID ตรงนี้ผมต้องกำหนดค่าหน้าจอ consent ก่อน ดังนั้นผมคลิกตรงนี้ เลือก user แล้วคลิก create

ตอนนี้ผมสามารถตั้งชื่อมันได้ มันก็คือ my AI agent social media demo support email แค่เลือกอีเมลของผม ผมไม่ต้องการโลโก้ ไม่ต้องการแอป ไม่ต้องการอะไรทั้งนั้น ส่วน developer contact ผมใส่อีเมลเดียวกัน แล้วคลิก save and continue

ตอนนี้ผมต้องกำหนดว่าต้องการขอบเขต (scopes) แบบไหน ฟังก์ชันอะไรที่ผมต้องการเข้าถึงจาก Google และผมไปที่ add and remove scopes ตรงนี้มีรายการการเข้าถึงทั้งหมดที่ผมสามารถใช้ได้ หรือฟีเจอร์ทั้งหมดที่ผมต้องการ สำหรับผม ผมต้องการบางอย่างที่เกี่ยวกับ Google Drive สลับไปที่ 50 เพื่อให้เห็นสิ่งที่ต้องการ Google Drive, drive auth, file, บางทีก็ see and download, drive file, drive read only โอเค ผมคิดว่ามันยังให้ drive metadata read-only ด้วย นั่นคือทั้งหมดที่ผมต้องการ และสิ่งสำคัญคือต้องคลิกที่มัน แล้วมันจะถูกเพิ่มเข้าไปในรายการ ดี ทีนี้คลิก save and continue

ตอนนี้ผมต้องเพิ่มตัวเองเป็นผู้ใช้ทดสอบ (test user) ตรงนี้ ใส่อีเมล แล้วคลิก save and continue กลับไปที่แดชบอร์ด ตอนนี้ผมสามารถกลับไปที่ credentials แล้วคลิก create credentials ตอนนี้ผมต้องเลือกแอปพลิเคชันของผม ซึ่งเราสามารถข้ามมันไปได้ จากนั้นเราต้องระบุ authorized redirect URL ซึ่งผมได้มาจาก n8n นั่นคืออันนี้ นั่นคือสิ่งที่ผมต้องการ ดังนั้นผมเพิ่มมันตรงนี้ แล้วคลิก create

ตอนนี้ผมสามารถรับ client ID ได้ตรงนี้ ผมเห็น client ID และ client secret คุณไม่ควรแชร์สิ่งนี้กับใคร ดังนั้นผมจะลบมันก่อนอัปโหลดวิดีโอนี้ ขอคัดลอกแล้วกลับไป นั่นคือ client ID และ client secret ขอคัดลอกอันนั้นด้วย แล้ววางลงตรงนี้

ตอนนี้เราจะถูกขอให้ล็อกอินด้วยบัญชีเดียวกับที่เพิ่งตั้งค่าใน Cloud Console นี้ คลิก continue ตรงนี้ สิ่งเหล่านี้คือ scopes ทั้งหมด ผมต้องเลือกทั้งหมดเหมือนกับสิทธิ์ที่ผมต้องการ ตอนนี้มันสำเร็จแล้ว และตอนนี้ Google Drive ของผมเชื่อมต่อแล้ว และผมสามารถใช้งานมันได้
