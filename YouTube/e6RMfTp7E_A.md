## ประเด็นหลัก
- ไลฟ์สตรีมทดสอบครั้งแรกของช่อง เน้นตอบคำถามจากแชทแบบเรียลไทม์ พร้อมสาธิตการทำงานจริงใน Hermes Agent ไปด้วย
- เจ้าของช่องเล่าพื้นหลังว่าเคยเป็นนักแปลภาษาญี่ปุ่น–อังกฤษมากว่า 10 ปี เพิ่งเริ่มสนใจ AI เมื่อปีที่แล้ว และมองว่ามุมมองแบบคนไม่ใช่เดฟช่วยให้สอนคนทั่วไปได้ดีขึ้น
- สาธิตการใช้งาน Hermes Agent ทั้งบนเดสก์ท็อปและบน DGX Spark รวมถึงการสลับระหว่างโลคัลกับรีโมต, Kanban, สกิลต่าง ๆ และระบบเมมโมรีในตัว
- ใช้ MiniMax H3 รันแบบโลคัลบน Spark ทำการ์ตูนเรื่องรูปทรงให้ลูกชายวัย 3 ขวบ ชี้เทคนิค last frame to first frame เพื่อความคอนซิสเทนต์ระหว่างคลิป
- แนะนำวิธีจัดระเบียบสกิล: ปิดสกิลที่ไม่ใช้ผ่าน Hermes dashboard, ใช้ skills curator และใช้โปรไฟล์แยกสำหรับโปรเจกต์ระยะยาว
- มุมมองต่อ Buzz: ชอบวิสัยทัศน์และคอนเซปต์ แต่ยังบั๊กเยอะ ไม่เหมาะใช้งานเดี่ยวรายวัน เหมาะกับทีมหรือคอมมูนิตี้มากกว่า
- ใช้ Herder เป็นเทอร์มินัลมัลติเพล็กซ์เซอร์หลักแทน Warp ชื่นชมเรื่องการออเคสเตรตเอเจนต์หลายตัวและการคงเซสชันไว้
- สนับสนุนโลคัล AI และโอเพนซอร์ส เพื่อไม่ให้ถูกล็อกกับผู้ให้บริการรายเดียว และสามารถใช้โมเดลหลากหลายผ่าน Hermes
- กำลังทำเกมปริศนาสไตล์พิกเซลชื่อ token burn ใน Grok Build โดยใช้แนวคิดระบบโทเคนของเอเจนต์ในการแก้ปริศนา
- กำลังค้นคว้า Cloudflare OS, MPP (การชำระเงินสำหรับ endpoint) และระบบเมมโมรีทางเลือก เช่น Hindsight, Open Viking, Graphify
- ความเห็นเรื่อง AGI: ยังไปไม่ถึงตอนนี้ คาดว่าปีหน้าหรือหลังปี 2027 แต่มองว่าโมเดลจะถึงจุดที่ปล่อยเวอร์ชันใหม่ต่อไม่ได้
