ถ้าคุณดูวิดีโอที่แล้ว เราทำงานกันในนี้ ตอนนี้ผมจะแยกย่อยสิ่งที่เราทำ เราสร้างไฟล์ CLAUDE.md ขึ้นมา และในไฟล์นั้นมีข้อมูลทั้งหมดของคุณแล้ว มันมีแบรนด์ของคุณ เครื่องมือของคุณ ว่าใครเป็นทีม สถานะธุรกิจปัจจุบันของคุณ และไฟล์สำคัญต่างๆ

ผมแค่อยากแยกย่อยว่า Claude คิดยังไงเวลามันอ่านไฟล์พวกนี้ เพราะถ้าคุณสังเกต ผมไม่ได้ให้ CLAUDE.md ที่ยาวเป็นย่อหน้าๆ เหมือนเดิม มันแทบไม่มีอะไรเลย เทียบไม่ได้เลย ถ้าผมลองเปิดมันในเทอร์มินัล นี่คือมุมมองเทอร์มินัลของผม มันมีบรรทัดบอกว่ามีกี่บรรทัด อันนี้แค่ 92 บรรทัด ซึ่งดี เราอยากให้ CLAUDE.md สั้นๆ CLAUDE.md ก็เหมือนจุดอ้างอิง เหมือนเข็มทิศ เมื่อ Claude ทำงาน มันจะอ่านไฟล์ MD นี้ แล้วมันจะไปในทิศทางหนึ่งตามที่ไฟล์ MD นี้บอก

ถ้าผมเปิดไฟล์ MD นี้ มันคือแบรนด์เสียงทั้งหมด ดูตรงนี้ ตรงด้านล่าง ตอนนี้เรากำลังเพิ่มสิ่งที่เรียกว่า reference guides เข้ามา reference guides ก็คือคู่มือให้ Claude ได้บริบทและข้อมูลเพิ่มเติมเกี่ยวกับส่วนนั้นของธุรกิจที่คุณทำอยู่ ตัวอย่างเช่น business guide หรือ context guide

Claude เข้ามา อ่านไฟล์นี้ แล้วมันรู้ว่า: เรากำลังทำอะไรบางอย่างเกี่ยวกับธุรกิจของเขา ผมต้องการรายละเอียดเพิ่มเติมเกี่ยวกับธุรกิจของเขา แล้วมันก็จะเข้าไปใน reference context guide มันจะเข้าไปในโฟลเดอร์นี้ แล้วเปิด business context guide ขึ้นมา แล้วคุณจะเห็นว่ามันยาวแค่ไหน ขอเปิดในเทอร์มินัล ดูนะ อันนี้ยาวเป็นบ้า อันนี้ 200 บรรทัด มันมีข้อมูลทั้งหมดของเรา จัดระเบียบไว้ในที่เดียว มันมีลูกค้าในอุดมคติของเรา โครงสร้างทีม สินค้าที่เราเสนอ ฟันเนลคืออะไร เส้นทางการเดินทางของลูกค้าเป็นยังไง การตลาดและเทคของเรา ทุกอย่างอยู่ในนี้

มันรู้ว่าเวลามันทำงานกับธุรกิจของเรา มันจะไปอ่าน CLAUDE.md และมันจะมองหาข้อมูลธุรกิจ ข้อมูลลูกค้าเต็มรูปแบบและกระบวนการต่างๆ อยู่ใน reference guide นี้ แล้วตอนนี้มันจะอ่านอันนี้ และตอนนี้มันมีข้อมูลทั้งหมดเกี่ยวกับคอนเทนต์

แล้วก็ context window ซึ่งก็คืออันนี้ นี่คือ context สิ่งที่จะเกิดขึ้นคือ ดูนะ ถ้าผมไปที่โปรเจกต์ใหม่ เลือกโฟลเดอร์อื่น แล้วเข้าไปในโฟลเดอร์ที่เราสร้างไว้ ถามว่า "ช่วยบอกหน่อยได้ไหม avatar ในฝันของผมสำหรับแบรนด์ส่วนตัวคือใคร?" แล้วดูสิว่ามันจะทำอะไร มันจะอ่านไฟล์ CLAUDE.md อะไรวะ? นั่นคือบั๊ก ขอเดี๋ยว กลับไปก่อน โอ๊ะ ไม่เป็นไร มันเหมือนสลับไป คิดว่าผมเผลอไปโดนอะไรเข้าที่บ้าน

แต่ดูสิ มันอ่าน "school community finder reference video" มันเข้าไปในโฟลเดอร์นั้น แล้วมันต้องการข้อมูลเกี่ยวกับธุรกิจของเขา มันก็ไปอ่าน business context MD "avatar ในฝันของคุณสำหรับแบรนด์ส่วนตัว คุณสมบัติหลัก พวกเขารู้จัก AI แต่ตามไม่ทัน ไม่ได้เก่งสุดๆ อะไรแบบนั้น" เห็นไหมว่ามันทำงานยังไง

ถ้าเราอยากได้รายละเอียดละเอียดขึ้น และอยากจัดระเบียบให้ดีขึ้นอีกหน่อย เพราะตอนนี้ reference ของผมคือ business context และ voice guide แต่มันค่อนข้างจะงงๆ ตรงนั้น สิ่งที่ผมอยากทำคือ "มาสร้าง avatar กัน" และอันนี้ไม่ได้อยู่ในคำแนะนำของคอร์ส ผมแค่อยากโชว์ว่ามันทำงานยังไง แทนที่จะใส่ข้อมูล avatar ทั้งหมดลงใน business context guide เพื่อจัดระเบียบ เราสร้าง reference อีกอันที่เฉพาะกับ avatar ของเราได้ไหม? แล้วอัปเดตไฟล์ CLAUDE.md ให้ชี้ไปที่อันนั้น เวลามีคนถามเกี่ยวกับ avatar ของเรา

ดูนะ อันนี้จะเจ๋งมาก มันอาจจะถามคำถามเราก่อน แต่เราจะให้มันสร้าง avatar guide สำหรับเรา แล้วมันควรจะอัปเดตไฟล์ CLAUDE.md ให้อ้างอิง guide นั้นทุกครั้งที่มีคนถาม ดูนี่สิ ตอนนี้มันเข้าไปในไฟล์ CLAUDE.md แล้ว "ได้เลย ผมจะสร้าง avatar guide ตัดส่วน avatar ออกจาก business context และอัปเดตไฟล์ CLAUDE.md ทั้งหมดในครั้งเดียว" มันทำมันในโหมดหนึ่ง ซึ่งผมจะพูดถึงในบทหลัง แต่คุณเห็นไหมว่ามันเป็นสีเขียวตรงนี้? นั่นหมายความว่ามันกำลังเขียน ทุกครั้งที่คุณเห็นสีเขียวพร้อมไฟล์ นั่นหมายความว่ามันกำลังเขียนไฟล์ และทุกครั้งที่เห็นอันนั้น หมายความว่ามันกำลังลบ

เอาล่ะ ผมจะกดยิงมันเลย ตอนนี้มันกำลังเขียน reference guide ของเรา เห็นไหม? ปัง! เห็น avatar guide ไหม? ตรงนั้น เอาล่ะ ตอนนี้ให้มันเอาข้อมูล avatar ออกจาก business context มันกำลังทำการลบ เห็นไหม? มันกำลังเอาอันนี้ออก มันสร้างอัปเดต avatar guide และตัด context ทิ้ง

ลองดูว่ามันทำตามที่มันบอกจริงไหม เราเข้าไปใน business context มันทำแล้ว ตอนนี้มันเหลือ 188 บรรทัด ดูตรงนี้ แล้วนี่คือ reference guide ใช่ และมันอัปเดต reference แล้ว ตอนนี้มันเขียนว่า "Dream Avatar" ใช่ไหม? ถ้าผมไปที่โปรเจกต์ใหม่ แล้วเปิดไฟล์ที่เรากำลังทำงานอยู่ ถามว่า "ช่วยเล่าเพิ่มเติมเกี่ยวกับ avatar ในฝันของผมสำหรับแบรนด์ส่วนตัวหน่อยได้ไหม?" สิ่งที่มันจะทำคือ มันจะอ่านไฟล์ CLAUDE.md แล้วมันจะไปที่ reference guide ที่สร้างขึ้นมาเพื่อ avatar นั้นโดยเฉพาะ ซึ่งเจ๋งมาก

ลองดูกัน ผมหวังว่าจะขยายในเทอร์มินัลได้ แต่คุณเห็นว่ามันตรงดิ่งไปที่ avatar guide ผมบอกแล้วว่ามันตรงไปที่นั่น แล้วมันให้บทเรียนเชิงลึกเต็มรูปแบบเกี่ยวกับ avatar นั้น

นั่นคือวิธีที่คุณจัดระเบียบไฟล์ทั้งหมดของคุณ ถ้าคุณมีไฟล์สำหรับแต่ละเรื่อง มันจะทำแบบนี้ ตัวอย่างเช่น สมมติว่าผมอยากทำโฆษณาสำหรับเจ้าของธุรกิจที่อยากเข้าร่วมคอมมูนิตี้โรงเรียนของผม อะไรประมาณนั้น มันจะอ่านไฟล์ CLAUDE.md ก่อน แล้วบอกว่า "ผมต้องรวบรวมข้อมูล avatar ทั้งหมด มาเริ่มที่ avatar ก่อน แล้วผมต้องรู้ข้อมูลธุรกิจเพิ่มเติมเกี่ยวกับคอมมูนิตี้โรงเรียน" มันก็จะไปอ่านอันนั้น แล้วบางทีมันก็ไปอ่าน voice guide ว่าผมพูดยังไง เพื่อที่มันจะเขียน ad copy ได้ มันจะไปที่ทั้งสามไฟล์นั้น แล้วกลับมาพร้อมกับผลลัพธ์ที่เกือบสมบูรณ์แบบ ซึ่งถูกต้อง

นั่นคือวิธีการทำงานของ CLAUDE.md และ reference guides โดยสรุป ถ้าพวกคุณมีคำถามอะไร หรือบทนี้อาจจะงงหน่อย ผมพยายามอธิบายให้ง่ายที่สุดเท่าที่จะทำได้ แต่บอกผมได้ในคอมมูนิตี้โรงเรียน แล้วผมช่วยคุณได้ นั่นคือทั้งหมดสำหรับบทนี้ แล้วเจอกันบทหน้านะครับ
