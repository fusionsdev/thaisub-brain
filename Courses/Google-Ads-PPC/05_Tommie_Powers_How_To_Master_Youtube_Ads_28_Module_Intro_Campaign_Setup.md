## บทนำ

วิดีโอนี้เป็นบทนำของโมดูลการสร้างแคมเปญในคอร์ส C3 โดยอธิบายแนวคิดว่าแคมเปญคือการเลือกว่าต้องการแสดงข้อความต่อใคร และแนะนำ workflow ที่ต้องวางแผนด้วย media planning template ก่อนลงมือสร้างจริงใน Google Ads manager

## คำแปลเต็ม

ในบทนี้ เราจะเข้าสู่เฟสที่ใหญ่ที่สุด ถัดไปของ C3 ของเรา หลังจากที่เราคุยกัน เรื่องแคมเปญไปแล้ว

ตอนนี้ เราจะมาโฟกัส กับการสร้างแคมเปญของเรา อย่างที่ผมบอกไว้ แคมเปญก็คือ การเลือกว่า คุณอยากจะแสดงข้อความของคุณ ไปให้ใครเห็น

เราคุยกันไปแล้วเรื่อง Creative ว่าคุณอยากจะพูดอะไร ทีนี้ก็เป็นเรื่องว่า คุณอยากจะให้ใคร เป็นคนเห็นข้อความนั้น และนั่นคือแก่นแท้ ของกระบวนการสร้างแคมเปญ

ตลอดทั้งบทนี้ เราจะเข้าไปดูใน Google Ads manager จริงๆ และไปดูการตั้งค่า และการเปิดแคมเปญต่างๆ

เราจะใช้ media planning template ด้วย เพราะแนวคิดคือ ตอนที่คุณสร้างแคมเปญ คุณไม่ควรเดา คุณควรจะวางแผนไว้แล้ว นั่นคือวิธีที่เราทำงาน

Template นี้ถูกออกแบบมา ให้เราได้วางแผนแคมเปญไว้ก่อน แล้วค่อยเข้าไปสร้างมัน เราจะเดินผ่านขั้นตอนเหล่านี้ ด้วยกันในบทนี้ เริ่มกันเลยครับ
