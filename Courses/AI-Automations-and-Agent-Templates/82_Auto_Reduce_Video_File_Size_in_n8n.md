## บทนำ
วิดีโอนี้สอนวิธีบีบอัดไฟล์วิดีโอให้มีขนาดเล็กกว่า 5MB ก่อนส่งไปยังแพลตฟอร์มเผยแพร่ make.com เพราะบัญชีฟรีของ make.com จำกัดขนาดไฟล์สูงสุดที่ 5MB โดยใช้ Cloud Convert ในการบีบอัด และ Cloudinary ในการเก็บลิงก์ถาวรของวิดีโอ พร้อมทั้งสาธิตการตั้งค่าโฟลว์ทั้งหมดใน n8n

## คำแปลเต็ม

ในวิดีโอนี้ ผมจะโชว์วิธีบีบอัดขนาดไฟล์ก่อนที่คุณจะส่งมันไปยังแพลตฟอร์มเผยแพร่ make.com เพราะอย่างที่เห็นในขั้นตอนติดตั้งที่ 5.4 บัญชีฟรีมีขีดจำกัดขนาดไฟล์สูงสุดที่ 5MB ดังนั้นถ้าคุณไม่อยากจ่ายเงินเพื่อใช้ระบบเผยแพร่ของ make.com คุณต้องบีบอัดไฟล์วิดีโอของคุณก่อนส่งไปยัง make.com ให้เหลือน้อยกว่า 5MB นี่คือเหตุผลที่ผมเพิ่มส่วนนี้เข้ามา ซึ่งเป็นโพรเซสเล็ก ๆ ที่ลดขนาดไฟล์วิดีโอลงโดยไม่เปลี่ยนแปลงอะไรเกี่ยวกับวิดีโอเลย และคุณภาพก็ยังดูเหมือนเดิม

ในการเชื่อมต่อสิ่งนี้เข้ากับโฟลว์ของคุณ สิ่งที่ต้องทำคือ ขั้นแรกย้ายอันนี้เล็กน้อย จากนั้นเราต้องยกเลิกการเชื่อมโยง (unlink) ส่วนตรงนี้ มาซูมเข้าไปดูตรงก่อน Google Sheet นี้ คุณต้องยกเลิกการเชื่อมโยงอันนี้ แล้วจากนั้นเราต้องลากอันนี้ลงมาตรงนี้ เพราะนี่คือจุดที่เราจะตั้งค่าโฟลว์นี้

สิ่งแรกที่คุณต้องมี และผมจะสร้างมันให้ดู คุณต้องมีโหนด HTTP request และก่อนที่คุณจะไปต่อ คุณต้องสมัครบัญชีฟรีบน Cloud Convert ก่อน และเมื่อทำเสร็จแล้ว คุณก็ไปที่แดชบอร์ดของคุณ แล้วเราก็ไปต่อกัน ด้านล่างวิดีโอนี้ ผมใส่ลิงก์ไว้ให้แล้ว ตรงนี้ สิ่งแรกที่เราต้องใช้คือ URL นี้ เพราะมันจะใส่เข้าไปตรงนั้น เราต้องตั้งเป็น POST อันนี้ใส่เข้าไป แล้วจากนั้นเราก็มีพารามิเตอร์ที่ต้องใช้สำหรับ header ของเรา ตรงนี้แค่เปิดใช้งาน send headers แล้วเราใส่ค่านี้ คัดลอกแล้ววางลงไป

ตรงนี้จะเป็น API key ของคุณ ซึ่งผมได้โชว์วิธีขอไว้แล้ว แล้วจากนั้นเรามี content type เราก็เพิ่ม content type อีกอัน และนี่คือ application/json แล้วตอนนี้คุณไปที่แดชบอร์ดของคุณตรงนี้ ไปที่ authorization API แล้วคลิกที่ create a new key และเมื่อทำเสร็จ คุณก็คัดลอกคีย์นั้นแล้ววางลงไปตรงนี้ แล้วมาเปลี่ยนชื่ออันนี้เป็น compress video กัน แล้วกลับไป

สิ่งที่เราจริง ๆ ต้องการทำคือ เข้าไปในนั้นและ trigger เวิร์กโฟลว์หนึ่งครั้ง เพื่อให้เรามีไฟล์วิดีโอจริงไว้ทดสอบโฟลว์บีบอัดของเรา มาคลิกสองครั้ง คลิกที่ test แล้วจากนั้นเราต้องไปที่บอทของเราใน Telegram เราต้องส่งลิงก์วิดีโอ TikTok เพื่อให้โพรเซสเริ่มทำงานจริง ๆ แล้วเราก็แค่รอ

ในระหว่างนั้น เราสามารถเพิ่มโมดูลเพิ่มอีกสองสามตัวได้ เราต้องการโหนด wait เพราะการบีบอัดวิดีโออาจใช้เวลาถึง 20 วินาที มาลองใส่ 20 วินาทีตรงนี้ แล้วจากนั้นเราก็ตั้งค่าโมดูลอื่นที่ต้องใช้สำหรับ Cloud Convert เพื่อรับ URL ของไฟล์วิดีโอที่บีบอัดแล้ว มาดูอันนั้นกัน ตรงนี้เราต้องเปลี่ยนเป็น GET แล้วจากนั้นเราต้องไปตรงนี้ ตรงนี้ผมต้องการ URL นี้ วางแทนที่ตรงนี้ เปลี่ยนอันนี้เป็น expressions ตอนนี้เราต้องรอจนกว่าเราจะจับคู่อันนี้ได้อย่างถูกต้องจนมันเปลี่ยนเป็นสีเขียว แล้วจากนั้นทุกอย่างด้านล่างจะคงเดิม เหมือนที่คุณมี API key อยู่ในนั้นแล้ว ดี

มาเปลี่ยนชื่ออันนี้กัน แล้วจากนั้นเราก็ต้องการเพิ่ม Cloudinary อีกอัน เราต้องอัปโหลดไฟล์ เพราะ URL จาก Cloud Convert ของวิดีโออาจหมดอายุได้ภายในไม่กี่ชั่วโมง มันไม่ใช่ URL ถาวร นั่นคือเหตุผลที่เราต้องเพิ่มอันนี้ แต่อันนี้ทำง่ายมาก สิ่งเดียวที่ต้องเปลี่ยนตรงนี้คือเปลี่ยนจาก image เป็น video upload แล้วจากนั้นสิ่งที่ต้องเปลี่ยนคืออันนี้เป็น form แล้วตรงนี้เราต้องแมป URL ที่เราได้จาก Cloud Convert เราจะทำสิ่งนี้เมื่อการสร้างวิดีโอเสร็จสิ้น นี่คือ upload video มาคลิก save และรอจนกว่ามันจะเสร็จ

ระหว่างที่รอ ผมเพิ่งสังเกตว่าเราต้องเพิ่มอย่างอื่น นี่คือด้านล่างวิดีโอนี้ ซึ่งเป็นโค้ด JSON อันนี้ และเราต้องเพิ่มมันในโหนด compress เลื่อนไปที่ activate send headers แล้วเลือกใช้ แล้ววางโค้ดนี้ตรงนี้ แล้วรอจนกว่ามันจะเสร็จ คลิก save ไปที่โหนด compressed video ของเรา แล้วเลื่อนลงไปด้านล่าง ตรงนี้เราเจอ error ว่ามันไม่ใช่ JSON ที่ถูกต้อง ตอนนี้ผมเพิ่งคลิก test step อีกครั้ง และมันก็ทำงานได้แล้ว แสดงว่าโค้ดถูกต้อง งั้นมันต้องรอประมาณ 20 วินาที ไปตรงนี้ คลิก test step รอ 20 วินาที แล้วมาดูผลกัน

ตอนนี้เราต้องไปที่โหนดนั้นแล้วอัปโหลดวิดีโอ ตรงนี้เราต้องตั้งค่า URL จาก getURL อันนี้ แล้วคลิก test step ตอนนี้มันเสร็จแล้ว มาดูกัน นี่คือ URL ตอนนี้ผมอยากรู้ว่าขนาดไฟล์ใหญ่แค่ไหน มาบันทึกมัน แล้วผมเห็นว่ามันคือ 4MB ซึ่งต่ำกว่า 5 ดังนั้นโพรเซสทำงานได้สำเร็จ ตอนนี้เราจะเชื่อมต่อโหนดเหล่านี้กลับเข้าไปใหม่ ตรวจสอบให้แน่ใจว่าฟิลด์ต่าง ๆ ถูกแมปกับ URL ที่ถูกต้องของวิดีโอ ตรงนี้คุณจะเห็นว่ามันไม่มีอันนั้น และตอนนี้เราต้องเลือกจาก upload video เพราะนั่นไม่ใช่ลิงก์ Cloudinary คลิก test step แล้วมันก็ทำงานได้แล้ว Telegram ก็ถูกต้องอยู่แล้ว และผมเดาว่าอันนี้ก็เหมือนกัน มาคลิก test แล้วผมก็ได้วิดีโอที่ถูกต้อง และก็แค่นั้น

สิ่งสุดท้ายคือการตรวจสอบตรงนี้ แล้วเช็คว่ามันเป็นลิงก์วิดีโอที่ถูกต้อง ใช่ ดี จากตรงนี้ทุกอย่างเหมือนเดิม โพรเซสเผยแพร่ยังคงเหมือนเดิม เพราะสิ่งเดียวที่เปลี่ยนไปคือลิงก์ และคุณไม่ต้องเปลี่ยนอะไรเลย แค่คลิก แล้วตอนนี้คุณก็มีซีเควนซ์การบีบอัดของคุณแล้ว ซึ่งทำให้แน่ใจว่าวิดีโอต่ำกว่า 5MB

ถ้าคุณมีวิดีโอที่ยาวกว่า คุณอาจต้องปรับการตั้งค่าการบีบอัดตรงนี้ อัตราบิต (bit rate) ต้องต่ำลง แล้วขนาดไฟล์ก็จะลดลงตามไปด้วย ถ้าคุณต้องการลดขนาดไฟล์ลงอีก ผมแนะนำให้คัดลอกโค้ดนี้ ใส่ลงใน ChatGPT แล้วขอให้มันช่วยคุณ หรือส่งให้ Claude เพื่อปรับแต่งมัน
