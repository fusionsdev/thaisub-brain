## บทนำ

บทเรียนนี้สอนการติดตั้งและรันสกิลแรกของคุณใน Claude Code ซึ่งก็คือสกิล Skill Creator ที่ใช้สร้างสกิลตัวอื่น ๆ ต่อ ผู้สอนสาธิตการดาวน์โหลดไฟล์ zip ลากเข้าไปติดตั้ง และทดสอบการเรียกใช้สกิล ทั้งแบบเรียกตรงและแบบอัตโนมัติผ่านคำสำคัญในคำอธิบายสกิล

## คำแปลเต็ม

ว่าไงทุกคน ยินดีต้อนรับสู่อีกวิดีโอหนึ่งครับ ในบทเรียนนี้เราจะติดตั้งและรันสกิลแรกของคุณ ซึ่งน่าตื่นเต้นมาก และมันก็คือสกิลที่ใช้สร้างสกิลตัวอื่น ๆ ต่อ ดังนั้นมันสำคัญมาก เรามาเริ่มกันเลยครับ

สิ่งที่คุณต้องทำคือเปิด Claude Code ขึ้นมาใหม่ แล้วเลื่อนลงมาดาวน์โหลดไฟล์นี้ — คลิก Download แล้วมันจะได้ไฟล์ zip ออกมา แล้วเราก็กลับมาที่ Claude ตรงนี้ เลือกโฟลเดอร์ที่เราจะทำงาน หรือที่เราจะติดตั้งมัน แล้วผมก็แค่ลากไฟล์นี้เข้าไปตรงนี้ เราน่าจะเห็นกล่องเล็ก ๆ โผล่ขึ้นมาให้กด Install โอเค ปล่อยให้มันทำงาน เราจะปล่อยให้มันรันสักครู่ ผมสร้างสคริปต์ติดตั้งไว้ให้แล้ว คุณไม่ต้องทำอะไรเลย แค่ดูมันทำงาน แล้วก็กดยอมรับแน่นอน ปล่อยให้มันรันไป

โอเค ดูเหมือนมันกำลังดาวน์โหลดสกิลอยู่ มันรู้ว่าสกิลทั้งหมดของผมอยู่ที่ไหน แล้วตอนนี้มันบอกว่าผมมีสกิลนี้อยู่แล้ว แต่มันจะเขียนทับด้วยเวอร์ชันใหม่ล่าสุด ซึ่งเจ๋งมาก นั่นคือสิ่งที่เราต้องการ เสร็จแล้ว — Skill Creator อัปเดตแล้ว: Claude Skills พร้อมไฟล์ zip ใหม่ของคุณ รวมถึง reference agent ตัวใหม่ และสคริปต์ทั้งหมดสำหรับการ benchmark, description และ optimization แล้วก็เรียบร้อย

เราก็เลยติดตั้ง Claude Code เสร็จเรียบร้อย ซึ่งง่ายมากจริง ๆ ต่อไปเราจะรันมันและทดสอบ เพื่อให้แน่ใจว่ามันทำงานได้ เราจะพิมพ์เครื่องหมายทับ (/) แล้วค้นหา — มันชื่อว่า Skill Creator เราก็เลือก skill แล้วก็เจอมันตรงนั้น — คำอธิบายบอกว่า organize Claude skills with CLAUDE.md เราก็กดเลือก แล้วกด Enter ดูว่าจะเกิดอะไรขึ้น สิ่งที่มันควรทำคือถามคำถามเราเกี่ยวกับสิ่งที่เราอยากสร้าง มีข้อความขึ้นมาว่า skill creator โหลดพร้อมแล้ว — คุณอยากทำอะไร? สร้างสกิลใหม่ ปรับปรุงสกิลที่มีอยู่ รัน evals เพื่อทดสอบว่าสกิลทำงานยังไง หรือปรับปรุงคำอธิบายสกิลให้ทริกเกอร์ได้แม่นยำขึ้น

ขออธิบายให้ฟังหน่อยนะครับ ในคำอธิบายของแต่ละสกิล — เห็นมั้ยว่ามี description ตรงนี้ — ผมเคยอธิบายไปในบทเรียนก่อนแล้ว ว่าคำอธิบายแต่ละอันมีคำสำคัญที่ใช้ทริกเกอร์สกิลได้ เพราะฉะนั้นแทนที่ผมจะต้องเรียก skill creator เอง ผมแค่พูดว่า — ช่วยสร้างสกิลให้หน่อยได้ไหม — แล้วลองรันดู มันควรจะเรียกสกิลขึ้นมา แล้วมันจะถามว่า — คุณต้องการให้ผมทำอะไร? ขอไอเดียคร่าว ๆ หน่อย — เพื่อให้มันรู้ว่าผมกำลังจะทำสกิล

และเพื่อโชว์ให้เห็นว่ามันทำงานยังไง — ช่วยสร้างสกิลใหม่ให้หน่อยได้ไหม Claude — เห็นมั้ยว่าผมไม่ได้เรียกมันตรง ๆ แต่มันใช้คำสำคัญที่ผมพูด ไปเทียบกับคำอธิบายของสกิล ดูสิครับ มันกำลังเปิดสกิลขึ้นมา มันเปิด Skill Creator ขึ้นมาเอง แม้ผมจะไม่ได้เรียกชื่อมันตรง ๆ มันก็ใช้คำสำคัญนี้ ซึ่งเจ๋งมากจริง ๆ

นั่นคือทั้งหมด มันจะถามคุณ แล้วคุณก็สร้างสกิลได้เลย อะไรประมาณนั้น สิ่งที่เราจะทำในบทเรียนหน้าก็คือเราจะสร้างสกิลจริง ๆ โดยใช้สกิลนี้ ซึ่งเป็นบทเรียนต่อเนื่อง ตอนนี้คุณมี Skill Creator แล้ว คุณรู้วิธีเรียกใช้สกิลแล้ว รู้ว่าแค่พูดคำที่อยู่ในคำอธิบายก็ทริกเกอร์ได้ แล้วคุณมีสกิลตัวสร้าง — คุณสามารถสร้างสกิลอะไรก็ได้บนโลกใบนี้ ต่อไปเราจะไปสร้างสกิลแรกของคุณจริง ๆ เจอกันครับ
