## คำแปลเต็ม

เอาล่ะครับทุกคน วันนี้เราจะพูดถึง error workflows กันครับ อันนี้สำคัญสุด ๆ เลย เราจะลงรายละเอียดกัน ว่า error workflow คืออะไร และผมจะสร้างมันให้ดูสด ๆ ตรงนี้เลย

ใน n8n มีโหนดที่ชื่อ error trigger ซึ่งเป็นเวิร์กโฟลว์เดียวที่คุณต้องสร้างไว้ มันคืออะไร มันคือโหนดที่ทริกเกอร์เมื่อเกิดข้อผิดพลาดจากเวิร์กโฟลว์อื่น ๆ ทั้งหมดครับ

ลองดู ถ้าเข้าไปในโฟลว์อื่น ๆ ของผม ผมมี error workflow อีกอันที่จะโชว์ให้ดู ตรงนี้ไง error workflow มันจะทริกเกอร์เมื่อเวิร์กโฟลว์อื่นมีข้อผิดพลาด แล้วจะมาทริกเกอร์เวิร์กโฟลว์นี้ครับ

มันเป็นไปได้ยังไง ในทุกเวิร์กโฟลว์จะมีปุ่มสามจุดอยู่ด้านบน แล้วคุณจะเห็นตัวเลือก work หรือ error workflow หรือ notify when this errors อะไรแบบนั้น ผมเลือกตัวนี้ไว้ เพราะผมสร้าง error workflow ไว้แล้ว

ตอนที่คุณสร้าง error workflow โดยใช้ error trigger บางอย่างจะโผล่มาตรงนี้ เห็นไหม workflow 11 ของผมเป็นสีเทา นั่นคือ error 11 มันตรวจจับได้ว่ามีข้อผิดพลาดเกิดขึ้นที่อื่นในเวิร์กโฟลว์อื่น ดังนั้นมันจะโผล่ขึ้นมาสำหรับแต่ละเวิร์กโฟลว์ แล้วคุณก็เลือกอันนี้ได้ เวิร์กโฟลว์นี้จะไม่ error เพราะมันเป็นไปไม่ได้จริง ๆ แล้วมันก็จะ fire อันนี้

สิ่งที่ผมทำคือ ผมส่งอีเมลไปหาผมเอง เนื้อหาประมาณว่า error workflow ประเภท text แล้วเมื่อ error workflow ทำงาน มันส่งข้อมูลหลายส่วนมา สิ่งที่ผมอยากทำคือ ไปที่ error workflow แล้วส่งอีเมลง่าย ๆ แล้วก็ส่ง URL ของมัน คุณส่งชื่อเวิร์กโฟลว์ได้ ผมไม่รู้ด้วยซ้ำว่าดึงมาจากไหน ลองดูตรงนี้ ที่ด้านล่างมันเขียนว่า name ดังนั้นผมทำแบบ error workflow name มันจะส่งชื่อเฉพาะของเวิร์กโฟลว์มา แล้วก็จะส่ง URL มา ผมก็ทำแบบนี้ URL แล้วถ้าผมอยากได้อะไรเพิ่ม ผมก็เพิ่มโหนดส่งข้อความเพื่อความแน่ใจ ประมาณนั้น แล้วก็ publish

จากนั้นทุกครั้งที่มีอะไร error มันจะส่งอีเมลหาผม ดูนะ ผมจะรันเวิร์กโฟลว์เล็ก ๆ อันหนึ่ง แล้วมันก็ส่งออกไป ผมน่าจะได้รับอีเมลตอนนี้ ลองดูกัน เห็นไหม คุณอาจยังไม่เห็น เดี๋ยวก็เห็น มันส่ง error workflow มาให้ผม มันส่ง URL ที่แน่นอนว่าเวิร์กโฟลว์ไหนผิดพลาด แล้วผมก็รู้ว่า ตอนตื่นเช้ามาเช็คอีเมล ผมจะเห็นว่าอันนี้ error แล้วก็ต้องไปแก้ ใช่ไหมล่ะ

มันสำคัญสุด ๆ เพราะถ้าคุณมีสิ่งที่รันทุกวัน แล้วคุณพึ่งพามัน แต่คุณไม่รู้ว่ามันทำงานอยู่หรือเปล่า คุณก็กำลังทำร้ายตัวเองอยู่ ดังนั้นคุณต้องมี error workflow นี้ครับ และในหน้า executions คุณจะเห็น error ทั้งหมดที่เกิดขึ้น เช่น TikTok puller ของผม error ทุกวันเลย แต่ไม่เป็นไร

นี่คือเวิร์กโฟลว์ที่สำคัญมาก ถ้าผมเป็นคุณ ผมจะสร้างมันตอนนี้เลย และตรวจสอบให้แน่ใจว่า ทุกเวิร์กโฟลว์ที่คุณสร้างใน n8n คุณเปิดใช้งาน error workflow ในตัวตั้งค่าด้วยครับ
