## คำแปลเต็ม

ขอต้อนรับสู่คำสั่ง permissions นะครับ permissions จริง ๆ แล้ว สิ่งที่มันทำคือ — เดี๋ยวผมขอออกจาก point mode ก่อน — permissions ทั้งหมดมันเกี่ยวกับ allow และ deny ครับ คุณสามารถตั้งค่าได้ว่า tools ไหนที่คุณต้องการให้ allow ไว้ตลอดเลย

เวลาที่คุณใช้งานแล้วมันมี pop-up ขึ้นมาถาม allow หรือ deny ใช่ไหมครับ? permissions ก็คือสิ่งที่ให้คุณดูได้ว่าคุณกำลังได้รับ allow อันไหนอยู่บ้าง และคุณสามารถสร้าง rules ขึ้นมาเพื่อกำหนดว่าคุณต้องการ allow อะไรได้ด้วยนะครับ

เวลาที่คุณใช้งานในส่วนต่าง ๆ มันก็ทำแบบนั้นให้คุณอยู่แล้วโดยอัตโนมัติครับ พอคุณ accept ในหน้านั้น มันก็จะอัปเดตข้อมูลตรงนี้ให้คุณเรียบร้อย

ซึ่งจริง ๆ ผมไม่เคยใช้ส่วนนี้เลยนะครับ แต่ก็น่าสนุกดีที่ให้คุณได้เห็นและเข้าใจวิธีการทำงานของ permissions ครับ แต่คุณสามารถเข้าไปดูได้ว่าคุณได้ allow อะไรไว้บ้าง

สมมติว่าคุณเคย allow บางอย่างสำหรับบางอย่างไว้ แต่คุณไม่ต้องการแล้ว คุณสามารถกลับเข้าไปเปลี่ยนได้ครับ เปลี่ยนเป็น ask หรือ deny หรืออะไรก็ได้ตามที่คุณต้องการครับ นั่นคือการทำงานของ permissions ครับ
