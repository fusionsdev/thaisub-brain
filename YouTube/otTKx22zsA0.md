## ประเด็นหลัก

- ข่าวหลุดบน X ระบุว่า Claude Haiku 5 โมเดลเล็กตัวใหม่ของ Anthropic
  กำลังจะเปิดตัวภายในไม่กี่สัปดาห์
- ข้อกล่าวอ้างหลัก: context window 1 ล้าน token, ความสามารถใกล้เคียง Opus 5,
  เบากว่า Fable 5/Opus 5 ราว 20 เท่า, ตอบสนองเร็วขึ้น,
  มุ่งเป้า coding agents และงานปริมาณมาก
- ยังเป็นเพียงข่าวหลุดจากโพสต์เดียว ยังไม่มีการยืนยันอย่างเป็นทางการจาก Anthropic
- บันไดโมเดล Claude ปัจจุบัน: Fable 5/Mythos 5 (บนสุด) → Opus 5
  (เปิดตัว 24 กรกฎาคม) → Sonnet 5 → Haiku 4.5 (ล่างสุด)
- Haiku 4.5 ตัวปัจจุบันเก่งเกินขนาดอยู่แล้ว: คะแนน coding เทียบเท่า Sonnet 4
  ด้วยน้ำหนัก 1 ใน 3 และเร็วกว่า 2 เท่า
- ทีม Augment ทดสอบแล้วพบว่า Haiku 4.5 ทำประสิทธิภาพได้ 90% ของ Sonnet 4.5
  และชนะ Sonnet รุ่นเก่าในเรื่องการใช้คอมพิวเตอร์
- การเปิดตัวจริงน่าจะเริ่มจากแอป Claude และ Claude Code ก่อน
  แล้วขยายไปฝั่ง developer และแพลตฟอร์มคลาวด์
- วิธีใช้งานจริง: ร่างสคริปต์/hooks/คำบรรยายเป็นชุดใหญ่
  วางแผน welcome flow สมาชิกใหม่ และร่าง landing pages
- ทิป 4 ข้อ: ฝึกใช้ Haiku 4.5 ตอนนี้เลย, จับคู่โมเดลให้ตรงกับงาน,
  ฝังโมเดลเล็กในระบบอย่าง Agent OS, จับทิศทางมากกว่าตัวเลขสเปก
- เทรนด์ชัดเจน: โมเดลเล็กเก่งขึ้นเรื่อยๆ การหันมาใช้ตัวเล็กคือการตัดสินใจที่ฉลาด
