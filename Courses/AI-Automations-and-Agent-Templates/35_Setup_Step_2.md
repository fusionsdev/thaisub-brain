## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 2 ของการตั้งค่าระบบอัตโนมัติโดยใช้แพลตฟอร์ม make.com โดยนำเข้าเทมเพลต blueprint แล้วเชื่อมต่อโมดูลต่าง ๆ เริ่มจาก Google Drive (ต้องใช้บัญชี Google Workspace), Google Sheet สำหรับเก็บข้อมูล, Assembly AI สำหรับถอดเสียงวิดีโอ, OpenAI สำหรับสร้างคำบรรยายอัตโนมัติ และสุดท้ายทดสอบระบบทั้งหมดตั้งแต่การอัปโหลดวิดีโอจนถึงการสร้างตารางเวลาลงโพสต์

## คำแปลเต็ม

ส่วนถัดไปที่เราจะตั้งค่าคือกระบวนการอัตโนมัติโดยใช้แพลตฟอร์มระบบอัตโนมัติที่ชื่อว่า make.com ถ้าคุณยังไม่มีบัญชี คุณสามารถสมัครได้ฟรี และแพ็กเกจฟรีก็เพียงพอที่จะใช้ระบบอัตโนมัตินี้ และคุณจะได้ ผมยังได้ใส่ตารางราคาไว้ในขั้นตอนการตั้งค่าที่ 1 หลังจากผมทำเสร็จ คุณจะเห็นชัดเจนว่าระบบอัตโนมัติทั้งหมดนี้มีค่าใช้จ่ายเท่าไหร่

เมื่อคุณตั้งค่า make.com เสร็จแล้ว คลิกที่ create a new scenario ตรงนี้คุณเลือก build from แล้วคลิก แล้วนำเข้า blueprint ที่คุณเพิ่งดาวน์โหลด นี่คือไฟล์ คลิก save ตอนนี้มันถูกนำเข้าแล้ว ตอนนี้เราจะเชื่อมต่อโมดูลต่าง ๆ ตรงนี้ สิ่งแรกที่เราต้องเชื่อมต่อคือ Google Drive อันนี้ใช้ได้กับบัญชี Google แบบ workspace เท่านั้น อันนี้ใช้ไม่ได้กับ Google ส่วนตัวของคุณ ตามที่เขียนไว้ตรงนี้ คุณอาจทำได้แต่มันซับซ้อนทางเทคนิคมาก และมันง่ายกว่ามากที่จะใช้บัญชี Google Workspace นั่นก็คืออันนี้ ให้ผมโชว์ให้ดู นี่มีช่วงทดลองใช้ฟรี และมีค่าใช้จ่ายประมาณ 8 ยูโรต่อเดือน ผมมีบัญชีแบบนี้ และคุณยังได้พื้นที่ 30 กิกะไบต์ด้วย ซึ่งมีประโยชน์มากเพราะเราใช้ Google Drive ด้วย ถ้าคุณมีไฟล์เยอะก็มีประโยชน์มาก เข้าใจใช่ไหม และผมจะแนะนำให้ใช้บัญชีนี้ เริ่มทดลองใช้ฟรี คุณสามารถทดสอบได้ฟรีสองสัปดาห์ และเพียงพอสำหรับการตั้งค่าระบบอัตโนมัตินี้ จากนั้นคุณจะเห็นว่ามันมีประโยชน์หรือไม่

จากนั้นคุณก็คลิก sign in with Google แล้วเลือกบัญชี Google ที่คุณเพิ่งสร้าง หรือที่มีอยู่แล้ว แล้วมันจะโหลดซ้ำตรงนี้ ผมได้เพิ่มไว้แล้ว และตรงนี้เราต้องทำแค่อย่างเดียว เมื่อคุณอยู่ใน Google ของคุณแล้ว ให้ผมโชว์วิธีการทำงาน เมื่อคุณไปที่ drive.google.com ด้วยบัญชีที่คุณเพิ่งสมัคร นี่สำคัญมากที่จะต้องหาโฟลเดอร์นี้ เพราะตอนนี้เราต้องการโฟลเดอร์ นี่คือที่ที่เรามี TikTok uploads หรือ social media video uploads นี่คือที่ที่เราจะเชื่อมต่อกับระบบอัตโนมัติ make.com ของเราตรงนี้

ผมจะคลิกตรงนี้ แล้วค้นหา TikTok แล้วคุณจะเห็นว่ามันขึ้นมาแล้วว่า uploads ตอนนี้ผมเลือกอันนี้ได้ นี่คือจำนวนไฟล์ที่คุณต้องการอัปโหลดครั้งละเท่าไหร่ ผมตั้งไว้ที่ 30 เพราะถ้าคุณอัปโหลดวิดีโอ 60 ตัวพร้อมกัน คุณอาจตั้งค่านี้ได้ แต่อาจเกิด error ได้ เพราะระบบอัตโนมัติจะทำงานนานเกินไป ผมจะปล่อยไว้ที่ 30 และคุณสามารถหรือคุณต้องอัปเกรดบัญชี make ของคุณเป็นแบบเสียเงิน ซึ่งจะได้ timeout ที่สูงขึ้น แล้วคุณสามารถอัปโหลดเป็นชุดใหญ่ได้ หรือคุณจะทดสอบเองว่าอัปโหลดวิดีโอพร้อมกันได้กี่ตัวก่อนที่จะเจอปัญหานี้ แต่ด้วยค่านี้คุณปลอดภัย

ตรงนี้เราต้องเลือกบัญชีเดียวกับที่คุณเพิ่งเชื่อมต่อ คุณไม่ต้องทำอะไรตรงนี้ ตรงนี้คุณไม่ต้องทำอะไร มันเป็นเพียงลิงก์ของ Google Drive โมดูลนี้เราจะตั้งค่าตอนท้าย มันเฝ้าดู Google Drive นี้ และเมื่อใดก็ตามที่มีวิดีโอใหม่เข้ามา มันจะรู้ และมันจะรับลิงก์ของไฟล์นั้น มันจะแปลงเป็นลิงก์ที่เปิดเผยต่อสาธารณะได้ เพื่อให้เราสามารถประมวลผลมันได้ แล้วเรายังต้องมีรูปแบบเฉพาะของลิงก์เพื่อให้มันทำงานกับตัวเผยแพร่โซเชียลมีเดียของเรา เพื่อให้วิดีโอถูกอัปโหลดไปยังเครื่องมือจัดตารางเวลาของเรา

แล้วตรงนี้เรามี Google Sheet นี่คือ Google Sheet ที่เราสร้างไว้ในการตั้งค่าครั้งแรก เราจะเรียกมันว่า demos setup ตอนนี้ผมจะเข้าไปตรงนี้ ต้องแน่ใจว่าคุณเพิ่มการเชื่อมต่อไปยังบัญชี Google ที่คุณมี Google Sheet นี้อยู่ แค่เลื่อนเมาส์ไปที่ไอคอนของคุณทางด้านขวาบน แล้วมันจะแสดงว่าบัญชี Google ไหน คลิกที่ sign in with บัญชีนี้ แล้วคลิกที่ฟิลด์นี้ แล้วผมต้องค้นหา ผมไม่แน่ใจว่าอันนี้ถูกต้องหรือไม่ แต่ผมคิดว่ามันน่าจะใช่ ถ้าผมพิมพ์ Demo คุณจะเห็นว่ามันขึ้นมาแล้ว setup post to นั่นคืออันที่เราต้องการ ตอนนี้ชีตปกติแล้วมันถูกเติมไว้แล้วอย่างที่คุณเห็น นั่นคือชีตวิดีโอ อันนี้ถูกเชื่อมต่อไว้แล้ว เราสามารถคลิก save ได้

ต่อไปเรามี Assembly AI นี่คือเครื่องมือที่จะรับวิดีโอและถอดเสียงมัน นี่สำคัญมากเพราะเราต้องการสร้างข้อความคำบรรยายสำหรับวิดีโอโดยอัตโนมัติ เพื่อที่คุณจะได้ไม่ต้องเขียนด้วยมือ และสำหรับอันนี้ คุณจะพบลิงก์ด้านล่างวิดีโอนี้ สิ่งที่คุณต้องทำคือเข้าไปคลิก แล้วมันคือ Assembly API key คุณจะได้มันมายังไง? คุณก็แค่เข้าสู่ระบบและลองใช้ API ฟรี และเมื่อคุณทำเสร็จ ดูตรงนี้ นี่คือ API key ของคุณ คัดลอกคีย์นั้นแล้ววางลงไป คลิก แล้วมันจะถูกเชื่อมต่อ และพวกเขายังให้เครดิต 50 ดอลลาร์อีกด้วย ซึ่งถือว่าเยอะมากเมื่อเทียบกับราคาที่ถูกขนาดนี้ เพราะการถอดเสียงวิดีโอ 1 ชั่วโมงมีค่าใช้จ่ายแค่ประมาณ 10 ถึง 30 เซนต์เท่านั้น และเราแค่อัปโหลดวิดีโอสั้น ๆ ประมาณ 30 วินาทีหรือ 45 วินาที และรายละเอียดค่าใช้จ่ายทั้งหมดนี้อยู่ในขั้นตอนการตั้งค่าที่แล้ว คุณสามารถดูได้ว่าสนใจหรือไม่ นี่คือสิ่งที่คุณต้องทำ: เชื่อมต่อ Assembly แล้วก็เสร็จ คุณไม่ต้องทำอะไรเพิ่ม แค่ให้แน่ใจว่ามันเป็นการเชื่อมต่อเดียวกันตรงนี้ และอันนี้จะสร้างทรานสคริปต์

ตอนนี้เรามีการเชื่อมต่อ OpenAI คุณสามารถใช้โมเดล AI ใดก็ได้ที่คุณต้องการ ผมแค่เชื่อมต่อ OpenAI ไว้ ถ้าคุณยังไม่ได้เพิ่มการเชื่อมต่อ ให้ใส่ API key ถ้าคุณอยากรู้วิธีรับ API นี้ ให้ไปที่ technical tutorials แล้วไปที่ get API connection แล้วคุณจะพบบทช่วยสอนเกี่ยวกับเรื่องนี้ คุณแค่คลิก แล้วใส่ API key แล้วมันจะโหลดตรงนี้ ตรงนี้คุณมี prompt นี่คือ prompt ที่จะรับทรานสคริปต์จากวิดีโอของเราแล้วแปลงเป็นโพสต์หรือคำบรรยาย ตอนนี้คุณสามารถปรับแต่งมันได้ตามคำบรรยายที่คุณต้องการ แล้วคลิก save

และเรามี Google Sheet อีกครั้ง โดยพื้นฐานแล้วนี่คือชีตหรือโมดูลที่บันทึกคำบรรยาย กลับไป ผมคิดว่าเราได้ตั้งค่า demo setup post to TikTok ไว้แล้ว และเนื่องจากมันบันทึกเฉพาะคำบรรยายตรงนี้ คลิก save และตอนนี้เราจะทดสอบรันเพื่อดูว่ามันทำงานถูกต้องหรือไม่ ในการทำสิ่งนี้ เราต้องเข้าไปในโฟลเดอร์ Google Drive ของผมก่อน แล้วเพิ่มวิดีโอใหม่ แค่วิดีโอเดียวสำหรับการทดสอบ และอันนี้จะถูกอัปโหลด คุณสามารถไปตรงนี้ได้ ตรงนี้คุณสามารถตั้งค่า posts per day ว่าคุณต้องการให้ลงโพสต์กี่โพสต์ต่อวัน และในช่วงเวลาใดที่คุณต้องการให้โพสต์ถูกจัดตารางเวลา จากข้อมูลนี้มันจะเติมข้อมูลให้โดยอัตโนมัติ

ตอนนี้ผมได้อัปโหลดวิดีโอแล้ว สิ่งที่เราต้องการทำคือเราจะ trigger อันนี้ก่อน ถ้าผมคลิก run มันจะค้นหาวิดีโอ คุณเห็นไหมว่ามันเร็วมาก ตอนนี้มันถอดเสียงวิดีโอ แล้วรับทรานสคริปต์ มันสร้างคำบรรยาย แล้วบันทึกกลับไปยังชีตของผม ตอนนี้ผมเห็น error มันไม่ควรเกิดขึ้นเพราะด้วยเหตุผลบางอย่างมันลบ prompt ออก ผมจะวาง prompt กลับเข้าไปใน caption generator prompt ถ้าเกิดแบบนี้ คุณก็แค่วางมันกลับลงไปตรงนั้น แล้วก็แค่นั้น ตอนนี้ผมจะทดสอบอีกครั้ง ในการทดสอบอีกครั้งผมต้องอัปโหลดวิดีโออีกตัว แค่ลบอันนี้ ตอนนี้ผมมีวิดีโออีกตัวในนั้น แล้วรันมันอีกครั้ง ตอนนี้เห็นว่าข้อความคำบรรยายถูกเพิ่มแล้ว และลิงก์วิดีโอถูกเพิ่มแล้ว

ตอนนี้ลองจำลองดูว่าเรามีหลายรายการ แล้วเราต้องรอสักครู่ แล้วโพสต์ทั้งหมดนี้จะถูกจัดตารางเวลาตามการตั้งค่าวันที่ของเรา ตามการตั้งค่าตารางเวลาตรงนี้ และอย่างที่คุณเห็น มันสร้างตารางเวลาโดยอัตโนมัติ มันเหมือนกับ 4 โพสต์ต่อวัน ระหว่าง 10 โมงเช้าถึง 4 ทุ่ม และมันคือหมายเลขโพสต์ มันถูกจัดไปในวันถัดไปแล้ว ดังนั้นอันนี้ทำงานถูกต้อง ขั้นตอนถัดไปที่เราต้องทำคือส่งต่อไปยังกระบวนการเผยแพร่
