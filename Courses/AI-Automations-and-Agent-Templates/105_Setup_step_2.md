## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 2 ของการตั้งค่า AI agent สำหรับสร้างวิดีโอโซเชียลมีเดีย โดยเริ่มจากการอัปโหลดรูปภาพขึ้น Cloudinary, ดึงข้อมูลจาก Google Sheets, สร้างวิดีโอจากรูปภาพด้วยโมเดล Kling ผ่านแพลตฟอร์ม PIAPI, สร้างเพลงประกอบ และนำทุกอย่างมารวมกันเป็นวิดีโอสุดท้ายด้วย JSON2Video ก่อนจะไปตั้งค่าขั้นตอนเผยแพร่ในวิดีโอถัดไป

## คำแปลเต็ม

ผมจะโชว์ให้ดูว่ามันทำงานยังไง ระบบจะสร้างวิดีโอให้คุณยังไง? คุณก็แค่อัปโหลดรูปภาพ จากนั้นก็พิมพ์ video ID ลงไป ขอกลับไปก่อนนะครับ ผมจะดึง video ID มาตรงนี้ หรือจะถามมันตรง ๆ ก็ได้ว่าวิดีโอสำหรับอันนี้คืออะไร ผมมีมันอยู่ตรงนี้แล้ว เห็นวิดีโอและมันทำงานได้ ตอนนี้ผมก็คัดลอกมันได้ แล้วก็อัปโหลดรูปภาพหรือสร้างรูปภาพขึ้นมา คุณเพิ่มขั้นตอนแบบที่สร้างวิดีโอจาก prompt โดยไม่ต้องใช้รูปภาพก็ได้ แต่ผมว่าวิธีใช้รูปภาพมันง่ายกว่า เพราะคุณแค่ถ่ายรูปตัวเองหรือสร้างรูปด้วย AI แล้วอัปโหลด แล้วให้มันแปลงเป็นวิดีโอ ซึ่งเป็นกระบวนการที่สั้นและได้ผลดีมาก และตรงนี้ปกติระบบจะทำงานต่อแบบนี้ ขั้นแรกผมบอกว่าอยากให้วิดีโอไหนแปลง หรือ video ID คืออะไร จากนั้นก็บอกว่าควรเกิดอะไรขึ้นในวิดีโอ เช่น ผู้ชายคนหนึ่งกำลังวิ่ง [ฟังไม่ชัด] แล้วก็มี prompt สำหรับเพลง ผมตั้งเป็น lo-fi inspirational piano ได้ แล้วจากนั้นก็คลิก และมันจะถูกส่งผ่านไปยังขั้นตอนการเผยแพร่ แต่ก่อนที่ผมจะทำได้ หรือจริง ๆ ผมส่งได้เลย แต่ก่อนที่ผมจะคลิก test ผมต้องตั้งค่าสาขานี้ก่อน

เมื่อเราอัปโหลดรูปภาพ อย่างที่เห็น สาขานี้จะเป็นกระบวนการสร้างวิดีโอ ตรงนี้เรามี Telegram อีกครั้ง ผมต้องเลือกบัญชี Telegram จากนั้นเราใช้เครื่องมือที่ชื่อว่า Cloudinary ผมแปะลิงก์ไว้ข้างล่างนี้แล้ว คุณใช้มันเพื่ออัปโหลดรูปภาพก่อน ต้องอัปโหลดรูปภาพไปที่บัญชีนี้ก่อน พอเข้าสู่ระบบแล้ว คุณก็คัดลอก cloud name เพราะเราต้องเอามันไปใส่ในช่อง placeholder ตรงนี้ แล้วคุณต้องสร้าง credential แบบ generic ตั้งชื่อ credential ตามที่ต้องการ แล้วใส่ API credentials ของคุณ คุณมีวิดีโอสอนทางเทคนิคเรื่องนี้ด้วย ตรง "get API credential from" แค่ทำตามแล้วใส่ข้อมูลลงไป แล้วก็ไปต่อได้เลย

อีกอย่างที่ต้องทำคือสร้าง upload preset ทำได้โดยไปที่ settings ไปที่ upload settings คือ upload แล้วตรงนั้นสร้าง upload preset ขึ้นมา ชื่ออะไรก็ได้ไม่สำคัญ จากนั้นคลิก unsign [ฟังไม่ชัด] แล้วคลิก save แล้วคัดลอกมาวางตรงนี้ เท่านี้เอง ผมจะกด trigger โดยคลิก test workflow ขอให้แน่ใจว่าอัปโหลดรูปภาพแล้ว ด้วยสไตล์ prompt เฉพาะนี้ แล้วผมทดสอบว่ามันทำงานได้ไหม นี่คืองานเดียวของโมดูลนี้คืออัปโหลดวิดีโอของผมไปที่ Cloudinary หรืออัปโหลดรูปภาพก่อน พอทุกอย่างเป็นสีเขียวใน output และมันทำงาน คุณก็เห็นว่ามันอัปโหลดเรียบร้อย ตอนนี้ผมไปต่อได้แล้ว

ตอนนี้ผมมีฟังก์ชัน split ที่แยก prompt ของผมออก ผมจะแชร์รายละเอียดว่ามันคืออะไร แต่ก่อนอื่นเราต้องเลือก Google Sheet ที่ถูกต้องก่อนเพื่อดึงแถวข้อมูล อันนี้ก็แค่ดึงข้อมูลที่ผมต้องใช้ในขั้นถัดไป ไปต่อกัน ผมอยากยกเลิกการเชื่อมต่ออันนี้ก่อน ดูกัน มันควรดึงข้อมูลจาก video ID เฉพาะนี้ ดูตรงนี้ ลองสลับไปที่ schema คุณจะเห็น caption text ที่สร้างในขั้นแรกด้วย AI, text number one, text number two สำหรับวิดีโอ นั่นคือข้อมูลที่ผมต้องใช้เพื่อสร้างวิดีโอจริงในขั้นต่อไป ผมก็เชื่อมต่ออันนี้กลับได้

ตอนนี้เรามีโมดูล generate แล้ว เราใช้เครื่องมือที่ชื่อว่า Kling จริง ๆ คือ Kling ซึ่งเป็นตัวสร้างวิดีโอยอดนิยมที่เราใช้ในกระบวนการอัตโนมัติได้ และเราใช้แพลตฟอร์ม API ที่ชื่อว่า PIAPI เพราะเราสามารถเข้าถึงโมเดลต่าง ๆ เช่น ตัวสร้างวิดีโอและตัวสร้างเพลงได้จากที่เดียว ซึ่งเข้าถึงง่ายมาก กลับไปตรงนี้ สิ่งที่ต้องทำคือสร้าง header แล้วคลิก create new credential แล้วใส่ API key จาก PIAPI ผมมีวิดีโอสอนให้คุณด้วย ตรง "get API credential from PIAPI" และมีลิงก์ไป PIAPI ข้างล่างวิดีโอนี้ พอใส่ข้อมูลแล้วเราก็ไปต่อได้

เลื่อนลงมาตรงนี้ นี่คือ prompt เราต้องแน่ใจว่าทุกอย่างเป็นสีเขียว และก่อนทำเราควรกลับไปที่โหนดนี้ ยกเลิกการเชื่อมต่ออันนี้ก่อน เพราะตอนนี้ผมมีวิดีโอที่ต้องรอ การสร้างวิดีโอใช้เวลาประมาณหนึ่งถึงหนึ่งนาทีครึ่ง เพื่อความแน่ใจผมเพิ่ม wait node ไว้สองนาทีครึ่ง เพื่อให้มีเวลาเพียงพอก่อนที่วิดีโอจะเสร็จก่อนไปต่อในกระบวนการ แล้วเราก็จะได้ video URL

ตอนนี้ผมเข้าไปตรงนี้ คลิก test workflow เพื่อดูว่าทุกอย่างเป็นสีเขียวไหม โอเค ตอนนี้เห็นว่า image URL เป็น undefined ไม่ดีเลย ผมต้องดูว่าเรามี image URL ไหม แค่ลากมันมาตรงนี้ ไม่ใช่ตรงนั้น ขยายหน้าจอหน่อย ผมอยากลาก image URL มาตรงนี้ ตรงนี้ แล้วคุณจะเห็นว่ามันเป็นสีเขียวแล้ว ตอนนี้ผมอยากทดสอบอีกครั้ง เพราะคราวนี้วิดีโอที่ถูกต้องจะถูกสร้างขึ้น ผมไม่แน่ใจว่าวิดีโอก่อนหน้าสร้างออกมาเป็นอะไร มันยังประมวลผลอยู่ ดี

ระหว่างนี้เรามาทำส่วนสร้างเพลงกันต่อ ตรงนี้มีโมดูล generate music อันนี้ก็มาจาก PIAPI เหมือนกัน ดังนั้นเราใช้การยืนยันตัวตนเดียวกับที่ใช้ในโมดูล generate video ได้ สิ่งเดียวที่เราทำคือสร้างเพลงจาก music prompt ที่เราแยกออกมาจากคำสั่งที่ส่งไปพร้อมกับรูปภาพ เราต้องรอสักครู่ก่อนที่จะเสร็จ เพื่อให้แน่ใจว่าตัวแปรนี้จะเปลี่ยนเป็นสีเขียว ตอนนี้เสร็จแล้ว ขอคลิก save ก่อน เพราะตอนนี้ยังไม่มีการบันทึกอัตโนมัติ

ตอนนี้เรามี video URL แล้ว ผมดูได้แล้ว วิดีโออยู่ตรงนี้แล้ว อันนี้ควรจะเป็นรูปภาพของผมที่แปลงเป็นวิดีโอแล้ว เห็นไหมว่าคนกำลังวิ่ง อันนี้ดูแปลก ๆ หน่อยใช่ไหมครับ? มีคนที่สองโผล่มาด้วย ผมอาจจะสร้างวิดีโอใหม่หรือระบุ prompt ให้ชัดขึ้น แต่ตอนนี้ปล่อยมันไว้ก่อน วิดีโอค่อนข้างดีแต่บางครั้งคุณต้องลองหนึ่งหรือสองครั้งเพื่อให้ได้ prompt ที่ถูกต้องจนวิดีโอออกมาดี ตอนนี้ไปต่อได้เพราะวิดีโอเสร็จแล้ว

ต่อไปเป็นเพลง ตรงนี้มันเปลี่ยนเป็นสีเขียว นี่คือเพลง ผมคลิก test step สำหรับเพลง อันนี้อาจใช้เวลาประมาณหนึ่งนาที ผมเลยมี wait module หนึ่งนาที คลิกเลย

ผมมีโมดูลวิดีโออีกตัวที่รวมทุกอย่างเข้าด้วยกัน มันนำวิดีโอที่เราสร้างไว้ตรงนี้กับเพลงมารวมเป็นวิดีโอสุดท้าย เราใช้เครื่องมือที่ชื่อว่า JSON2Video มีลิงก์อยู่ข้างล่างด้วย สมัครบัญชี JSON2Video ได้ตรงนี้ แล้วก็ต้องเชื่อมต่อมันก่อน ขอเข้าไปโชว์วิธีทำ มันง่ายมาก คุณต้องเลือก custom auth และบัญชี custom auth ตรงนี้คลิก create new แล้วใส่ API key ของคุณ แต่ก่อนอื่นใส่ค่านี้ก่อน เปิดตรงนั้น ใส่ตรงนี้ แล้วใส่ API ตามด้วย ผมจะโชว์วิธีเอา API key จาก JSON2Video ดูวิดีโอสั้น ๆ นี้แล้วก็ทำได้เลย ผมทำไว้แล้ว

ตรงนี้มี settings ไม่กี่อย่างให้ปรับผลลัพธ์ของวิดีโอ นี่คือฟอร์แมต: Instagram story format ซึ่งเป็นฟอร์แมตแนวตั้ง เพราะผมอยากได้วิดีโอแบบโซเชียลมีเดีย ตรงนี้คือ video URL จากขั้นตอนก่อนหน้าที่แปลงรูปภาพเป็นวิดีโอ ตรงนี้คือ title ซึ่งเป็นชื่อที่อยู่บนวิดีโอที่ AI agent ของเราสร้างขึ้น นั่นคือ title one ที่จะถูกเพิ่มเข้าไป พร้อมกับฟอนต์และอื่น ๆ คุณเปลี่ยนได้ถ้าอยากเปลี่ยนหน้าตาหรือสไตล์ และตรงนี้คือ bottom text number two และตรงนี้คือเพลง อันนี้รวมทุกอย่างเข้าด้วยกัน พอคลิก test step มันจะทำงาน แต่ใช้เวลาประมาณ 30 วินาที เร็วกว่าอันก่อนหน้านิดหน่อย แล้วเราก็จะได้ URL

คลิก test แล้วรอ 30 วินาที ระหว่างนั้นเราตั้งค่า sheet ตรงนี้ได้ด้วย อันนี้ก็เป็น Google Sheet หรือโมดูลที่บันทึกข้อมูลทั้งหมดที่เราสร้าง เช่น video ID และ video URL และบันทึกลงที่ถูกต้องตรงนี้ คลิกโหลด อันนี้ไม่ต้องใช้ ตรงนี้มี Telegram ขอให้แน่ใจว่าเชื่อมต่อบัญชีที่ถูกต้อง แล้วผมก็ไปที่ขั้นตอนสุดท้ายได้ อันนี้เชื่อมต่อแล้ว คลิก test step แล้วดูว่าจะเกิดอะไรขึ้น ถ้าทุกอย่างเป็นสีเขียวมีเครื่องหมายถูก คุณจะเห็นวิดีโอตรงนี้ และเห็นข้อความบนวิดีโอ นี่คือ text number one และ number two ที่เราสร้างไว้ และเห็นสไตล์ของวิดีโอตามที่เรากำหนด ซึ่งคุณเปลี่ยนได้ แค่ย้อนกลับไปก่อนจะใช้ระบบอัตโนมัติทั้งหมดนี้เป็นกระบวนการอัตโนมัติ

บางทีผมอาจลองเพิ่มขนาดฟอนต์อีกหน่อย แล้วไป test step รอ 30 วินาที ดูผลลัพธ์ พอพอใจกับดีไซน์แล้ว และคุณเห็นเพลงด้วย ไม่รู้ว่าคุณได้ยินไหม แต่เรามีเพลงด้วย และส่วนสร้างวิดีโอของ AI agent ของเราก็ตั้งค่าเสร็จแล้ว ในวิดีโอถัดไปเราจะตั้งค่า workflow การเผยแพร่ เพื่อให้คุณเผยแพร่ไปยังบัญชีโซเชียลมีเดียต่าง ๆ ได้โดยตรงจาก AI agent

ตอนนี้คุณเห็นว่าขนาดฟอนต์ใหญ่ขึ้นนิดหน่อย คุณขยับข้อความลงหรือขึ้นก็ได้ หรือขยับอันนี้ลงหรือขึ้น ทำได้โดยเข้าไปตรงนี้ คุณจะเห็น margin top ซึ่งคือระยะจากด้านบนของ text number one คือระยะจากตรงนี้ถึงตรงนี้ และยังเห็น margin สำหรับด้านล่างด้วย นี่คือระยะจากตรงนี้ถึงตรงนี้ และคุณเห็นว่า ขยับข้อความนี้ไปมาได้ถ้าต้องการ หรือเปลี่ยนสีข้อความ สไตล์ฟอนต์ตามที่ต้องการ ไปดู Google Sheet กัน ทุกอย่างเรียบร้อย video URL อยู่ตรงนั้น นั่นคือทุกอย่างที่เราต้องการเพื่อเผยแพร่ และคลิก save ก่อนไปต่อ
