## บทนำ

## คำแปลเต็ม

ยินดีต้อนรับสู่โมดูล Start Here ของ Skills และ MCP Library ครับ ในโมดูลนี้ ผมจะให้สกิล Claude ทั้งหมดที่ผมใช้ในธุรกิจเป็นประจำทุกวัน รวมถึงสกิลใหม่ๆ ที่ผมปล่อยออกมาเรื่อยๆ และ MCP ทั้งหมดด้วย ซึ่งมันช่วยให้คุณเชื่อมต่อ Claude Code (เครื่องมือเขียนโค้ดด้วย AI) เข้ากับแอปพลิเคชันหลายๆ ตัวได้ มันก็คือคลังที่ผมพัฒนาขึ้นมานั่นแหละครับ

ถ้าคุณกำลังดูวิดีโอนี้อยู่ แต่ยังไม่เคยสร้าง Claude skill สักตัว หรือไม่เคยสร้างอะไรเลย และไม่รู้ด้วยซ้ำว่าผมพูดถึงอะไร แสดงว่าคุณมาไกลเกินไปแล้ว และควรออกไปจากตรงนี้ก่อน ผมรู้ว่ามันน่าดึงดูดมากที่จะเข้ามาโหลดของพวกนี้ไปใช้ แต่พูดตรงๆ เลยนะครับ ในระยะยาวคุณจะเสียหายมากกว่าถ้าข้ามสิ่งที่คุณต้องเรียนจริงๆ นั่นก็คือคอร์ส Claude Mastery แล้วตามด้วย Claude Code for Dummies

ถ้าคุณยังไม่ได้เรียนสองคอร์สนั้นอย่างจริงจัง และยังไม่เข้าใจทุกอย่างที่ผมถามถึง แสดงว่าคุณมาไกลเกินไปแล้ว คุณต้องกลับไปเรียนให้จบก่อน เข้าใจไหมครับ? เพราะผมไม่ยอมรับคนที่ข้ามคอร์สพวกนั้น แล้วมาถามผมว่า "โอ้ ผมไม่รู้จะโหลดสกิลยังไง" "ผมไม่รู้ว่า MCP คืออะไร" "ผมไม่รู้ว่ามันทำงานยังไง" ผมแยกย่อยทุกอย่างให้คุณแล้ว ผมทำให้ง่ายที่สุดเท่าที่จะทำได้แล้ว เข้าใจไหมครับ?

พอคุณเรียนสองคอร์สนั้นจบและเข้าใจแล้ว สร้างอะไรเองเป็นแล้ว ทุกอย่างในนี้จะเข้าใจง่ายขึ้นมาก เพราะฉะนั้นไปเรียนให้จบก่อนแน่นอนครับ

ถ้าคุณเรียนจบแล้วและเข้าใจ MCP รู้วิธีสร้างสกิลเองได้ ดีมาก สิ่งที่คุณต้องทำต่อไปคือ ผมเตรียมคู่มือติดตั้งสำหรับ Claude Desktop ไว้ให้ ถ้าคุณใช้ Claude Desktop ในการแชทโดยเฉพาะ ผมให้คู่มือติดตั้งไว้แล้ว ไปดูวิดีโอนั้นได้เลย

ถ้าคุณใช้ Claude Code บนเดสก์ท็อป หรือในเทอร์มินัล Cursor VS Code หรือที่ไหนก็ตาม ผมก็เตรียมคู่มือติดตั้งไว้ให้คุณเหมือนกัน ว่าจะติดตั้งสกิลพวกนี้ยังไง ผมสร้างคลังขนาดใหญ่ที่เราเพิ่มของเข้าไปเรื่อยๆ คุณดาวน์โหลดสกิลเหล่านี้ได้ และมีวิดีโอแนะนำทีละสกิลครบทุกตัว

ก็จบเท่านี้สำหรับวิดีโอนี้ครับ ถ้ามีคำถามอะไรบอกได้เลย ไปดูคู่มือติดตั้งก่อน แล้วค่อยลงลึกไปในคลังสกิลนะครับ
