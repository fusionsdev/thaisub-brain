## บทนำ
วิดีโอนี้สอนวิธีสมัครและเติมเงินในบัญชี Anthropic เพื่อใช้งาน API จากนั้นสร้าง API key ใหม่ในเมนู API keys และนำไปใส่ใน n8n พร้อมย้ำเตือนว่าไม่ควรเปิดเผย key ให้ใครเห็น

## คำแปลเต็ม
สำหรับ API คุณไปที่เว็บของ Anthropic แล้วสมัครบัญชี เมื่อสมัครเสร็จแล้ว คุณอาจต้องเติมเงินสักประมาณ 5 ดอลลาร์เพื่อให้ใช้งานได้ จากนั้นคุณไปที่เมนู API keys แล้วกดสร้าง key ใหม่ แล้วผมก็สร้าง key ขึ้นมาได้ ผมจะลบ key นี้ก่อนอัปโหลดวิดีโอ เพราะคุณไม่ควรนำ key นี้ไปแสดงให้ใครเห็น แล้วจากนั้นกด save
