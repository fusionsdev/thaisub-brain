## บทนำ

บทเรียนนี้พูดถึง Schedule Trigger หรือ cron trigger ใน n8n ซึ่งเป็นทริกเกอร์ที่สำคัญที่สุดตัวหนึ่ง เพราะมันให้คุณกำหนดเวลารันเวิร์กโฟลว์ได้ตามต้องการ เช่น ทุกวัน ทุกชั่วโมง หรือทุกสัปดาห์ ผู้สอนยังอธิบายด้วยว่าเบื้องหลังของ n8n คือโค้ด cron ที่ทำงานบนเซิร์ฟเวอร์ และยกตัวอย่างการใช้ cron job ใน Claude Code จริง

## คำแปลเต็ม

ว่าไงทุกคน ยินดีต้อนรับสู่อีกวิดีโอหนึ่งครับ วันนี้เราจะพูดถึงทริกเกอร์อีกตัวหนึ่ง ผมจะลบอันเดิมทิ้งไปก่อน เพราะคุณสร้างหลายทริกเกอร์พร้อมกันในเวิร์กโฟลว์เดียวไม่ได้ ซึ่งเป็นจุดที่ค่อนข้างน่าเสียดาย เราจะไปใช้ Schedule Trigger — นี่น่าจะเป็นทริกเกอร์ที่สำคัญที่สุด และน่าจะเป็นเหตุผลหลักเดียวที่ทำให้ n8n ยังมีคุณค่า นั่นก็เพราะมันเป็น scheduled trigger

ถ้าคุณไม่รู้ว่า schedule trigger คืออะไร มันก็คือตัวที่ทริกเกอร์เมื่อไหร่ก็ได้ที่คุณต้องการ คุณตั้งเวลาได้ เช่น ถ้าผมคลิกเข้ามา จะเห็นว่าตั้งเป็นวันได้ สมมติว่าผมอยากให้ทริกเกอร์ทุกวัน ผมก็เลือกวัน แล้วก็ตั้งช่วงเวลาได้ แน่นอนว่ามันจะเป็นแบบนั้นทุกวัน แล้วผมก็ตั้งให้ทริกเกอร์ตอนตี 4 ก็ได้ เลือกเวลาไหนก็ได้ตามใจ ถ้าอยากให้ทริกเกอร์ตอนเที่ยงทุกวัน มันก็จะทริกทุกวันตอนเที่ยง ผมก็จะเลือก 12:00 น.

ผมจะตั้งแบบนี้ก่อน เพราะตอนที่ผมจะเดินหน้าต่อ ผมไม่อยากให้มันทริกเกอร์ทุกวัน ถ้าสมมติว่าผมอยากได้แบบ... ซึ่งค่อนข้างเจ๋ง คุณตั้งให้ทริกเกอร์ทุกชั่วโมงได้ ผมไม่รู้ว่าคุณจะเอาไปทำอะไรแบบนั้น นอกจากว่าคุณกำลังอัปเดตข้อมูลค่อนข้างถี่ เพื่อแอปอะไรสักอย่าง คุณตั้งเป็นวินาทีได้ และตั้งเป็นสัปดาห์ก็เจ๋งดี — คุณทริกเกอร์อาทิตย์ละครั้งได้ แล้วก็เลือกวันได้ เช่น ถ้าคุณอยากได้การเตือนรายวัน หรืออยากให้งานบางอย่างทำงานวันจันทร์กับวันศุกร์ ก็เลือกได้เลย

ผมจะเลือกวันจันทร์กับวันศุกร์ แล้วตั้งให้ทริกเกอร์ตอน 7 โมงเช้า ทีนี้ทุกวันจันทร์กับศุกร์ตอน 7 โมง มันก็จะรันเวิร์กโฟลว์นี้ให้ ซึ่งเจ๋งดี มันเลือกตาม... ไม่ได้ ซึ่งแปลกนิดหน่อย แต่คุณก็ตั้งตามวันที่เลือกได้ และเลือกชั่วโมงกับ... ซึ่งผมไม่รู้ว่าทำไมคุณถึงต้องใช้แบบนั้น แต่โดยรวมคุณตั้งให้มันทำงานเมื่อไหร่ก็ได้ตามต้องการ

และด้วยความที่ n8n คือโค้ด ถ้าคุณเขียนโค้ดไม่เป็น มันก็คือโค้ดที่รันอยู่เบื้องหลัง ส่วนหน้าตา (front end) เขาทำให้ง่ายสุด ๆ สำหรับคนที่ไม่ใช่นักพัฒนา ถ้าคุณไม่รู้ว่า schedule trigger คืออะไร มันเรียกว่า cron job ครับ cron ก็คือตัวตั้งเวลาทริกเกอร์แบบหนึ่ง มันรันบนเซิร์ฟเวอร์ และรันตามเวลาที่กำหนด เช่น ใน Claude Code ที่ผมเพิ่งใช้เมื่อกี้ ผมรัน cron job เพื่อวนลูป — ผมโพสต์คอนเทนต์ทั้งหมดของผม แล้วก็แบบ... มาตรวจดูหน่อยว่าเราอยู่ตรงไหนแล้ว วนลูปทุก ๆ 2 นาทีเพื่อเช็คว่าโพสต์ไปแล้วหรือยัง

สิ่งที่มันทำคือมันตั้ง cron job ขึ้นมา เห็นมั้ยครับ เห็น cron พวกนั้นมั้ย มันมีเครื่องหมายดอกจันกับเลขสอง (แบบ */2) — นั่นคือวิธีสังเกตว่ามันคือ cron ซึ่งก็คือโค้ดนั่นแหละ ผมว่ามันเจ๋งดี สิ่งทั้งหมดที่คุณเรียนในคอร์สนี้คือโค้ด และมันย้อนกลับไปที่ Claude Code กับสิ่งที่คุณทำอยู่ตรงนั้น นั่นคือทั้งหมดสำหรับ scheduled trigger ครับ เจอกันบทเรียนหน้า
