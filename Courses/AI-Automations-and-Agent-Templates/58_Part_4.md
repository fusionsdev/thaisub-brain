## บทนำ
วิดีโอนี้เป็นส่วนที่ 4 ของการตั้งค่าระบบสร้างวิดีโอ เราจะตั้งค่ากระบวนการเผยแพร่ (publishing) ผ่านแพลตฟอร์มอัตโนมัติอีกตัวที่ชื่อ make.com โดยเชื่อมต่อโซเชียลมีเดียหลายแพลตฟอร์ม ทั้ง Instagram, Facebook, YouTube, LinkedIn และ TikTok รวมถึงวิธีแก้ไขข้อผิดพลาดที่เกิดขึ้นระหว่างการทดสอบ

## คำแปลเต็ม

ก่อนอื่น คุณอาจเห็นลายน้ำ (watermark) ในวิดีโอนี้ เพราะใน JSON2 Version แบบแผนฟรี จะมีลายน้ำปรากฏ หากต้องการเอาออกต้องอัปเกรดเป็นแบบเสียเงิน ตรงนี้ให้คลิก top up with credits แล้วซื้อแพ็กเกจใดแพ็กเกจหนึ่ง ผมซื้อมาแล้ว อันนี้ให้เครดิตประมาณหลายร้อยวิดีโอที่คุณสร้างได้ด้วยแพ็กเกจนี้ ซึ่งใช้ได้นานหลายเดือน และเมื่อทำเสร็จและลบลายน้ำได้แล้ว เราก็ไปต่อได้

เราจะตั้งค่ากระบวนการเผยแพร่ในแพลตฟอร์มอัตโนมัติอีกตัวที่ชื่อ make.com คุณสมัครบัญชีฟรีได้ตรงนี้ แล้วไปที่ scenarios ด้านล่างนี้คุณจะพบ make blueprint ดาวน์โหลดมัน จากนั้นคลิก create new scenario แล้วคลิก import แล้วนำเข้า blueprint ที่เพิ่งดาวน์โหลด เท่านั้นเอง

ตอนนี้จะมีโซเชียลมีเดียหลายแพลตฟอร์ม เช่น TikTok คุณไม่จำเป็นต้องเชื่อมต่อทั้งหมด มีเพียงแพลตฟอร์มที่คุณอยากเผยแพร่จริง ๆ เท่านั้น ส่วนที่เหลือปล่อยไว้ได้ แต่ผมจะตั้งค่าทั้งหมดให้คุณดู เพื่อให้เห็นวิธีการทำ

สิ่งแรกที่ต้องทำคือคัดลอก webhook คลิก save แล้วคัดลอก จากนั้นกลับไปที่ workflow ของผมในส่วน publishing เข้าไปตรงนี้ แล้ววาง webhook จาก make.com ลงตรงนี้ เท่านั้นที่ต้องทำ จากนั้นต้องไปที่โมดูลแรก เพราะต้องดึงโพสต์ที่ต้องการเผยแพร่ คลิก add แล้วเลือก video ID ตรงนี้ video ID คือวิดีโอที่ต้องการ ลากมันเข้ามา แล้วมันจะให้โพสต์จากชีตที่มี ID นี้ มันโหลดค่าเฉพาะนี้ให้ผม ซึ่งก็คือวิดีโอที่ต้องการเผยแพร่ใน workflow นี้

ตอนนี้เข้าไปตรงนี้จริง ๆ กลับมาที่โมดูลแรก ยังใช้ได้ดี และสิ่งเดียวที่ต้องทำคือให้ค่าเหล่านี้เป็นสีเขียวทั้งหมด เพราะนี่คือข้อมูลทั้งหมดที่ต้องส่งไปยังระบบเผยแพร่อัตโนมัติของเรา เพื่อให้เผยแพร่ได้อย่างถูกต้อง เมื่อคลิกมันควรแสดง successful และเมื่อตัดการเชื่อมต่อแล้วคลิก run once แล้วส่งค่า มันควรปรากฏ นี่คือข้อมูลทั้งหมดที่ต้องการ: caption, วิดีโอ และชื่อวิดีโอ

ตอนนี้เชื่อมต่อแพลตฟอร์มโซเชียลมีเดียต่าง ๆ ได้แล้ว เริ่มจาก Instagram ก่อนใช้งาน คุณต้องไปที่ Facebook และต้องมี Facebook page ที่เชื่อมกับบัญชี Instagram ไปที่ Facebook page นั้น สลับเป็นมุมมองแบบเพจ (view as your page) แล้วไปที่ linked accounts แล้วเชื่อมบัญชี Instagram เมื่อทำเสร็จแล้วกลับมาตรงนี้ คลิก แล้วระบบจะให้ลงชื่อเข้าใช้ด้วยบัญชี Facebook ยืนยัน แล้วบัญชี Instagram ที่เพิ่งเชื่อมต่อจะปรากฏตรงนี้

ตรงนี้คือวิดีโอและข้อความ caption ซึ่งจับคู่ถูกต้องแล้ว สิ่งเดียวที่ต้องเปลี่ยนคือเพิ่มบัญชี Google ของคุณ ซึ่งควรเป็นบัญชีเดียวกับที่ใช้ในชีต เพราะผมต้องการบันทึกลงชีตว่าโพสต์นี้ถูกเผยแพร่แล้ว ต้องค้นหาชีตใหม่ซึ่งก็คืออันนี้ และตรงนี้มันบันทึกวันที่เผยแพร่และสถานะการเผยแพร่ เยี่ยม คลิก save

ต่อไปเรามี Telegram bot อีกตัว คลิก add แล้วใส่ token เดียวกับที่ใช้ใน N8N เพื่อเชื่อมต่อบอทนี้ ไปที่ BotFather แล้วดึง token อีกครั้ง คลิก แล้วเท่านี้ มันคือข้อความตอบกลับที่ยืนยันว่าโพสต์พร้อมชื่อถูกเผยแพร่ไปยังแพลตฟอร์มนี้ในเวลานี้

ต่อไปคือ Facebook ซึ่งทำงานแบบเดียวกัน คลิก แล้วระบบจะให้ลงชื่อเข้าใช้ด้วยบัญชี Facebook ตรวจสอบว่าเลือก "download a video from URL" แล้ว เราต้องการเพียง URL และข้อความ caption เยี่ยม

สิ่งที่ผมจะทำคือลบโมดูลที่ซ้ำออก เพราะมันเหมือนกันในทุกโมดูล ถือค้างไว้แล้วเลือกหลายค่าได้ตรงนี้ เราต้องการค่านี้ คลิก paste แล้วสิ่งเดียวที่ต้องเปลี่ยนคือ platform ต้องเป็น Facebook

ต่อไป YouTube ใน YouTube คลิก Add แล้วเลือก Sign In with Google เลือกบัญชี Google ที่จัดการช่องของผม เลือกช่องที่ต้องการเผยแพร่ คลิก open แล้วลูกศรควรหายไป ตอนนี้ชื่อวิดีโอคืออันนี้ หมวดหมู่วิดีโอเป็นอะไรก็ได้ ตั้งค่าเป็น Public คำอธิบายคือข้อความ caption เท่านั้นที่ต้องใช้ คลิกเปิดอีกครั้ง คลิก save ดี

ต่อไป LinkedIn คลิก add แล้วเลือก LinkedIn คลิก แล้วระบบจะให้เข้าสู่ระบบ แล้วตรงนี้ตั้งค่าครบแล้ว คลิก แล้วเราจะเปลี่ยนอันนี้เป็น YouTube และอันนี้เป็น LinkedIn คลิก save

สำหรับ TikTok ไม่มีการเชื่อมต่อโดยตรงใน make.com ดังนั้นเราจึงใช้เครื่องมือบุคคลที่สาม ชื่อว่า upload.post.com ไปที่บัญชีนี้ ซึ่งง่ายมาก คุณสมัครแบบฟรี ได้วิดีโอประมาณ 10 วิดีโอที่เผยแพร่อัตโนมัติได้ แล้วค่อยอัปเกรด แพ็กเกจถัดไปราคา $14 ต่อเดือน ให้วิดีโอ 120 วิดีโอ จากนั้นไปที่ manage users เพราะมีบางอย่างที่ต้องใช้ เราต้องการ username ของคุณ สร้างได้เลย พิมพ์อะไรก็ได้ ไม่สำคัญ แล้วใต้ username นั้น คลิกที่ TikTok คลิก แล้วระบบจะให้ลงชื่อเข้าใช้ เมื่อทำเสร็จ บัญชีของคุณจะแสดงว่าเชื่อมกับ TikTok แบบนี้

จากนั้นดึง... ไม่ใช่ TikTok username แต่เป็น username ของแพลตฟอร์มนี้ที่เพิ่งสร้าง แล้ววางลงตรงนี้ จากนั้นใส่ API key ตรงนี้ ไปที่ API keys แล้วคุณจะพบ key ของคุณ ที่เหลือปล่อยไว้ตามเดิม เท่านั้นเอง สิ่งเดียวที่ต้องเปลี่ยนคือ platform เป็น TikTok คลิก save

ทีนี้เราจะทดสอบรัน คลิก Test แล้วกลับไปที่ webhook ของเรา คลิก test แล้วดูว่ามี error หรือไม่ และวิดีโอถูกเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ หรือยัง ตอนนี้มันรันแล้ว ผมเห็น error ถ้าคลิกดู มันบอกว่า invalid video description ถ้าไปดูที่ description จะเห็นว่ามีอักขระแบบนี้ ซึ่ง YouTube ไม่อนุญาต

ผมต้องไปที่โพสต์ของผมก่อน เรามี description ของโพสต์นี้ซึ่งก็คืออันนี้ แล้วต้องลบมันออก ต้องลบส่วนนี้ออกไป เท่านั้น จากนั้นกลับมาตรงนี้ นี่คือวิธีที่คุณต้องแก้ไขเมื่อเจอ error ต้องเข้าไปตรงนี้ ภายใต้ caption generator เขียน caption แล้วตั้งกฎ (rule) ได้ว่า "ห้ามใช้อักขระแบบนี้หรือแบบนี้ใน caption ที่สร้าง"

จากนั้นกลับมา คลิก save คลิก run แล้วเข้าไปตรงนี้ โหลดข้อมูลใหม่ของ description ที่ปรับแล้ว แล้วกลับมาคลิก test ตอนนี้มันควรส่งวิดีโอไปยังแพลตฟอร์มโซเชียลมีเดียอีกครั้ง และผมเห็นข้อความยืนยันส่งเข้ามาแล้ว ซึ่งจะเกิดขึ้นบนโทรศัพท์ด้วย มันถูกเผยแพร่แล้ว ถูกเผยแพร่แล้ว ถูกเผยแพร่บน LinkedIn แล้ว ลองรีเฟรชดู ผมเห็นวิดีโอบน Facebook แล้ว มันถูกเผยแพร่แล้ว ถูกเผยแพร่แล้ว และเผยแพร่บนบัญชี LinkedIn แล้ว และไม่เห็น error ดังนั้นระบบนี้ใช้งานได้

ตอนนี้คลิกสลับเป็น on แล้วกลับไป ตอนนี้เปิดใช้งานแล้ว กลับมาตรงนี้ คลิก save ได้ด้วย สลับเป็น on แล้วทุกอย่างพร้อม สิ่งเดียวที่ต้องทำคือเข้าไปในแอป ซึ่งทำบนโทรศัพท์ได้ แล้วคลิกปุ่มแชร์บน Instagram โพสต์ใดก็ได้ แล้วแชร์ จากนั้นระบบจะสร้างโคลนของโพสต์นี้ให้ผม และเผยแพร่ไปยังทุกแพลตฟอร์มเหล่านี้โดยอัตโนมัติ
