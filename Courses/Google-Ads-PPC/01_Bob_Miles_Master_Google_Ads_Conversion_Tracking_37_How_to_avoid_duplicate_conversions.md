## บทนำ

คลิปนี้ของ Bob Miles อธิบายถึงปัญหาของการนับ conversion ซ้ำซ้อน (duplicate conversions) ในบัญชี Google Ads ซึ่งเกิดขึ้นเมื่อ pixel ยิงซ้ำและทำให้ระบบเห็น conversion หลายตัวจากรายการซื้อจริงเพียงรายการเดียว พร้อมวิธีแก้ไขด้วยการส่ง transaction ID หรือ form submission ID ไปกับ conversion tracking และอธิบายความต่างระหว่างการตั้งค่า count แบบ unique กับ all รวมถึงตัวอย่างจริงจากบัญชีที่พบ conversion rate 600% จากการนับซ้ำ

## คำแปลเต็ม

การวัด duplicate conversions (คอนเวอร์ชันซ้ำซ้อน) ภายในบัญชีของคุณสามารถนำไปสู่ปัญหามหาศาลได้ การหลีกเลี่ยง conversion ซ้ำซ้อนจึงเป็นเรื่องสำคัญมาก และในคลิปนี้ เราจะมาพูดถึงวิธีป้องกันการส่ง conversion ซ้ำซ้อน และวิธีจัดการปัญหาพวกนี้ได้ง่ายๆ งั้นเราเริ่มกันเลย

ทำไมการหลีกเลี่ยง conversion ซ้ำซ้อนจึงสำคัญ และทำอย่างไร? เมื่อคุณส่ง transaction ID ไปกับ Google Ads conversion tracking คุณจะช่วยให้ Google ระบุและกรอง conversion ซ้ำที่อาจเกิดขึ้นได้จากหลายสาเหตุ หนึ่งในนั้นคือตอนที่ conversion pixel ของคุณถูกยิงมากกว่าหนึ่งครั้งบนหน้า checkout success ซึ่งเท่ากับการส่ง conversion หลายตัวที่แท้จริงแล้วเป็นแค่ conversion เดียวกัน

การส่ง transaction ID เข้าไป จะช่วยให้คุณมองเห็นภาพ conversion ที่แม่นยำมากขึ้น ซึ่งสำคัญมากต่อการประเมินประสิทธิภาพของแคมเปญ Google Ads และยังช่วยป้องกันการประมูลเกินจริง (overbidding) เพราะถ้าคุณใช้ smart bidding เช่น Maximize conversions หรือ Target CPA แล้วเผลอส่ง conversion หลายตัวที่จริงๆ แล้วเป็นแค่ตัวเดียว Smart bidding ก็จะเร่งการประมูลอย่างเต็มที่ และสุดท้ายคุณจะจ่ายแพงกว่าที่ควรจ่ายสำหรับ conversion จริงแต่ละตัว

จะหลีกเลี่ยง conversion ซ้ำซ้อนได้อย่างไร? เมื่อผู้ใช้ทำ conversion สำเร็จ คุณควรสร้าง ID ที่ไม่ซ้ำใคร ซึ่งอาจเป็น transaction ID หรือ form submission ID แล้วส่งไปพร้อมกับแท็ก Google Ads จะตรวจสอบ transaction ID ที่ซ้ำกันเพื่อกรอง conversion ที่อาจซ้ำออกไป หลังจากนั้น คุณจึงลงทะเบียน conversion ที่ไม่ซ้ำเพียงหนึ่งตัวในบัญชีของคุณ

มีข้อสังเกตสำคัญสองข้อตรงนี้ เนื่องจากใน Google Ads คุณมีตัวเลือกในการตั้งค่า count (การนับ) ได้ โดยเลือก unique หรือ all ซึ่งการตั้งค่านี้โดยพื้นฐานจะนับจากจำนวน conversion ที่เกิดขึ้นภายในเซสชันเดียวกัน และไม่ได้เชื่อมโยงกับ transaction ID ของออเดอร์คุณโดยตรง ดังนั้น ถ้าคุณต้องการนับเฉพาะรายการที่ไม่ซ้ำ คุณควรใช้ transaction ID สำหรับ Google Ads conversion tracking pixel เสมอ และจากนั้นก็ขึ้นอยู่กับคุณว่าจะตั้งค่า count ให้เหมาะสมกับ Google Ads อย่างไร เพราะมันหมายความว่าคุณต้องการติดตามแค่หนึ่ง transaction หรือหนึ่ง conversion ต่อครั้ง หรือต้องการติดตามทั้งหมด นั่นเป็นสิ่งที่แตกต่างกันเล็กน้อย

ข้อสังเกตที่สองที่ผมอยากพูดถึงคือ transaction ID ไม่ได้ใช้ได้เฉพาะกับบัญชีอีคอมเมิร์ซเท่านั้น แน่นอนว่าสำหรับอีคอมเมิร์ซนี่เป็นวิธีแก้ที่ง่าย เพราะส่วนใหญ่คุณมี order ID หรือ transaction ID ที่ไม่ซ้ำ ซึ่งส่งไปกับ conversion tracking pixel ไปยัง Google Ads ได้ง่ายมาก แต่เรื่องนี้ก็ทำได้สำหรับการทำ lead generation เช่นกัน และนี่คือจุดที่นักโฆษณาสาย lead gen จำนวนมากพลาดโอกาสไป เพราะหลายคนไม่ได้ส่ง form submission ID ที่ไม่ซ้ำซึ่งทำหน้าที่เดียวกัน Form submission ID คือ ID ที่ผูกกับฟอร์มใดฟอร์มหนึ่งโดยเฉพาะ และช่วยให้คุณตัดข้อมูล conversion ที่ซ้ำออกได้เช่นกัน

ดังนั้น อย่าลืมใช้ transaction ID เสมอ ไม่ว่าจะเป็นธุรกิจอีคอมเมิร์ซ lead gen หรือแทบจะทุกธุรกิจ นี่เป็นเรื่องสำคัญมากที่ต้องทำให้เข้าที่เข้าทาง

ตรงนี้เป็นภาพหน้าจออย่างย่อจากหนึ่งในการตรวจบัญชี (audit) ที่ผมเพิ่งทำไป และตรงนี้คุณจะเห็นปัญหาถ้าคุณไม่ใช้ transaction ID ตรงนี้คุณจะเห็นแค่ไม่กี่คลิก คลิกที่ไม่ซ้ำบนคีย์เวิร์ดค้นหาบางคำ หนึ่งคลิกต่อหนึ่งคลิก บนคีย์เวิร์ดที่ไม่ใช่แบรนด์ทั้งหมดนี้ และตรงนี้คุณจะเห็นว่าบัญชีนี้มี conversion มากกว่าหกครั้งสำหรับคลิกเดียวบนคีย์เวิร์ดค้นหาคำนี้ ซึ่งส่งผลให้ conversion rate สูงถึง 600% ดังนั้น ถ้าคุณใช้ smart bidding เช่น Target CPA หรือ Maximize conversions แล้ว Smart bidding จะคิดว่าทุกอย่างง่ายมากตรงนี้ มันสมเหตุสมผลที่ smart bidding จะรุก aggressively กับค่าเฉลี่ยสูงสุด เพราะคุณส่ง conversion มากกว่าที่เกิดขึ้นจริงถึงหกเท่า

พูดง่ายๆ คือ คุณได้รับ conversion ที่ไม่ซ้ำแค่หนึ่งตัวในฝั่งแบ็กเอนด์ แต่เนื่องจากปัญหาการติดตามและการไม่ส่ง transaction ID ที่ไม่ซ้ำ Google Ads จึงได้รับหกครั้งในกรณีนี้ และนี่คือสิ่งที่คุณไม่อยากให้เกิด เพราะมันนำไปสู่ข้อมูลที่ไม่แม่นยำในรายงานของคุณ คุณจะตัดสินใจผิดพลาดจากข้อมูล conversion ของแคมเปญที่คุณติดตามมา

ดังนั้น อย่าลืมติดตั้งเรื่องนี้ให้เรียบร้อย คุณทำได้ง่ายๆ ด้วยการแก้ไข Google Tag, Google Ads conversion tracking หรือ hard-coded conversion event snippet ถ้าคุณใช้ Google tag หรือ gtag แต่คุณก็สามารถส่ง transaction ID ผ่าน API ได้เช่นกันถ้าคุณใช้วิธีนั้น ในวิดีโอสองคลิปถัดไป ผมจะแสดงให้คุณเห็นวิธีส่ง transaction ID ง่ายๆ ผ่าน GTM หรือ Google tag งั้นเราไปดูกันเลยครับ
