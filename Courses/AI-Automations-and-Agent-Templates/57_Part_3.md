## บทนำ
วิดีโอนี้สาธิตการสร้างวิดีโอจริงจากเนื้อหาที่เตรียมไว้แล้ว โดยใช้เครื่องมือ Captions AI เพื่อสร้าง AI clone หรือ AI avatar อ่านสคริปต์ จากนั้นใช้ JSON2Video เพื่อรวมวิดีโอ ข้อความหัวข้อ และคำบรรยายเข้าด้วยกันเป็นวิดีโอสุดท้าย ก่อนส่งกลับผ่าน Telegram ให้ผู้ใช้ตรวจสอบ

## คำแปลเต็ม

เราจะสร้างวิดีโอจริงจากเนื้อหาที่เรามีอยู่แล้ว เช่นเนื้อหาข้อความ เราใช้เครื่องมือที่ชื่อ Captions AI คุณสามารถคลิก "sign up for a free account" (สมัครบัญชีฟรี) ได้ และมันทำให้เราสามารถอัปโหลด AI clone ของคุณเองได้

คุณแค่คลิก "create a new record a video" หรือคุณสามารถอัปโหลดวิดีโอความยาวไม่กี่นาที แล้วมันจะสร้าง AI twin ให้คุณ หรืออีกทางเลือกคือสร้าง AI avatar และฉันจะแสดงวิธีใช้ทั้งสองวิธี

อย่างแรกคุณต้องคลิกที่โมดูลนั้น เพราะเราต้องตั้งค่ามัน สิ่งที่คุณต้องใส่ตรงนี้คือ API key จากแอป Captions ฉันได้ทำบทเรียนเชิงเทคนิคไว้ให้แล้ว คุณสามารถดูวิธีขอ API key ได้จากวิดีโอนั้น

วิธีการทำงานคือ เราต้องดึงรายชื่อ speaker (ผู้พูด) ที่มีอยู่ก่อน คลิกที่มัน และเมื่อตั้งค่า API key แล้ว คลิก test โมดูลนี้จะโหลด speaker ที่มีอยู่ทั้งหมดให้ฉัน

ต่อไปโมดูล generate video ซึ่งจะสร้างวิดีโอ AI clone หรือ AI avatar ของเรา ตรงนี้คุณต้องใส่ API key ด้วย และตรงนี้คุณจะเห็นคำสั่งจริง นี่คือสคริปต์ที่วิดีโอจะใช้ และเสียงที่จะอ่านสคริปต์ให้เรา

ภายใต้ "creator name" คุณสามารถเลือก AI clone ที่คุณสร้างไว้ คุณเห็น clone ต่าง ๆ ตรงนี้ และคุณใช้ตัวที่คุณใช้ตอนบันทึก หรือคุณจะใช้อวตารใดก็ได้ที่ Captions AI ให้มา คุณยังสามารถพรีวิวได้ด้วยซ้ำว่าพวกมันจะหน้าตาเป็นอย่างไร

สำหรับอันนี้ ฉันสามารถสลับมันได้ ถ้าฉันอยากใช้ Kira ฉันต้องไปที่ด้านบนตรงนี้ หาว่ามันอยู่ที่ไหน แล้วลากมันมาตรงนี้ แล้วมันก็จะแสดงขึ้นมา ถ้าคุณอยากใช้ AI twin ของตัวเองก็ลากมันมาตรงนี้ ลบอันนี้ออกแล้วลากอันใหม่เข้ามา คุณก็จะได้ AI clone ของคุณเอง

ฉันจะใช้ AI avatar นี้ จากนั้นคลิก test step ตอนนี้มันรันแล้ว กระบวนการสร้างวิดีโอนี้ใช้เวลานานถึง 6 นาที นั่นเป็นเหตุผลที่เรามี wait node (โหนดรอ) ที่รอ 6 นาที และตรงนี้สิ่งเดียวที่คุณต้องทำคือใส่ API key จากแอป Captions แล้วโมดูลนี้จะดึงวิดีโอมาให้หลังจากครบ 6 นาที

ตอนนี้เราต้องรอ 6 นาที และฉันจะคลิก save ระหว่างนี้ฉันสามารถตั้งค่าโมดูลอื่น ๆ ที่ตามมาได้แล้ว นี่คือโมดูลที่จะรวมวิดีโอของฉัน และเพิ่มข้อความหัวข้อนี้ลงไปเป็นข้อความบนวิดีโอ โดยเราใช้เครื่องมือวิดีโออีกตัวหนึ่งที่ชื่อ JSON2Video คุณสามารถคลิก "sign up for a free account" ได้

กลับไปที่ขั้นตอน สิ่งแรกที่ต้องทำคือสร้าง credential ใหม่ ไปที่ "create new credential" ใต้วิดีโอนี้คุณจะพบโค้ดชิ้นนี้ วางมันลงไป แล้วคลิกที่ "API key" แล้วคัดลอกคีย์ของคุณใส่ลงไป แล้วคลิก save

จากนั้นสิ่งที่เกิดขึ้นคือ เครื่องมือนี้จะรวมองค์ประกอบของเราเข้าด้วยกัน อย่างแรกมันจะนำวิดีโอที่สร้างไว้แล้ว เพิ่มข้อความหัวข้อที่เราสร้างไว้ และเพิ่มคำบรรยาย แล้วรวมเป็นวิดีโอสุดท้าย จากนั้นเราต้องรออีก 3 นาทีครึ่ง แล้วเราก็จะได้ไฟล์วิดีโอสุดท้าย

ตรงนี้คุณต้องตั้งค่าบัญชีของคุณด้วย แค่นั้นก็พอ แล้วเราก็บันทึกวิดีโอลงใน Google Sheets ของเรา ไปที่ "generate video ready to match" ตรงนี้เราต้องคลิก reload ตอนนี้เราต้องรอจนกว่าเราจะทดสอบได้ว่าทุกอย่างเป็นสีเขียว แต่ขอพูดต่อก่อน

ขั้นตอนถัดไปคือบัญชี Telegram คุณต้องเลือกบัญชีที่ใช้เป็น trigger ตั้งแต่แรก คือ credential ชุดเดียวกัน และมันจะส่งข้อความกลับมาว่า "นี่คือวิดีโอสุดท้ายของคุณ" ใช่ไหม ฉันต้องการได้รับการยืนยัน "นี่คือ caption" "นี่คือ URL ของวิดีโอ" และตรงนี้ "get video" จะดาวน์โหลดวิดีโอด้วย ดังนั้นมันจะส่งวิดีโอมาให้ฉันและแสดงวิดีโอนั้น เพื่อให้ฉันเห็นมันในบัญชี Telegram ของฉันจริง ๆ และด้วยการตั้งค่าเครื่องมือเหล่านี้ ทุกอย่างก็จะเสร็จสมบูรณ์

ตอนนี้เราต้องรอจนกว่าวิดีโอจะเสร็จ และเราเห็นว่าวิดีโอเสร็จสมบูรณ์แล้ว ฉันสามารถเปิดมันดูได้ นี่คือ avatar ของฉัน กลับไปที่โมดูลที่เราตั้งค่าไว้ แล้วคลิกเพื่อตรวจว่าทุกอย่างเป็นสีเขียว คลิก test step อันนี้จะส่งงานไปที่ JSON2Video จากนั้นคลิกตรงนี้ เราต้องรอ 3 นาทีครึ่งจนกว่าวิดีโอนี้จะเสร็จ

ตอนนี้มันรันสำเร็จแล้ว ฉันคลิก open ดูวิดีโอ แล้วมันควรจะให้วิดีโอสุดท้ายแก่ฉัน "จำได้ไหมตอนที่เนื้อหาดูสมจริงในชีวิตเรา" นี่คือวิดีโอ มันใช้งานได้ กลับไปตอนนี้ เราต้องบันทึกมันลงชีตนี้ แต่ฉันตั้งค่าทั้งหมดไว้แล้ว มันเป็นสีเขียวแล้ว ตอนนี้มันควรจะถูกบันทึกไว้ตรงนี้ อยู่ไหนนะ? นี่คือ URL ที่ฉันต้องการ เยี่ยม

ตอนนี้ฉันต้องการรับการตอบกลับ ลองคลิกตรงนี้ มันจะส่งข้อความมา นี่คือ caption ของฉัน และนี่คือ URL ของวิดีโอ ฉันอยากได้รับวิดีโอด้วย ไปที่การตั้งค่านี้ คลิกเพื่อให้มันส่งวิดีโอมาให้ฉัน สมบูรณ์แบบ

ขั้นตอนสุดท้ายคือการนำวิดีโอนี้ไปใช้ และเราจะตั้งค่ากระบวนการเผยแพร่อัตโนมัติในวิดีโอถัดไป
