## บทนำ

## คำแปลเต็ม
ในคลิปนี้ ผมจะโชว์อัปเดตสั้นๆ ให้ดูสำหรับระบบอัตโนมัติทุกตัวที่ใช้ Creatomate ในการสร้างวิดีโอ อย่างที่เห็นในบทสอนติดตั้ง ระบบนี้ทำงานโดยใช้เทมเพลตและตัวยึดตำแหน่ง (placeholder) สำหรับข้อความและวิดีโอ

ทีนี้ ถ้าคุณล็อกอินเข้า Creatomate ตอนนี้เขาปรับอินเทอร์เฟซไปนิดหน่อย ให้คลิก Create a New Template แล้วคลิก Start from Scratch เลือกรูปแบบแนวตั้ง (vertical) แล้วคลิก Create

ตอนนี้คุณจะเห็นว่าไม่มีองค์ประกอบวิดีโอให้ลากลงมาแล้ว นี่คือสาเหตุที่ผมต้องให้คุณคลิกที่ upload คลิก browse แล้วอัปโหลดวิดีโออะไรก็ได้ที่เป็นรูปแบบแนวตั้ง ไม่สำคัญว่าวิดีโอเป็นอะไร ขอแค่เป็นรูปแบบเดียวกันก็พอ

สิ่งที่เราจะทำตรงนี้คือ เปลี่ยน provider เป็น none และตรงนี้ตั้งค่าเป็น dynamic แล้วเราจะได้องค์ประกอบวิดีโอชื่อ video nk6 ตรงนี้ เราสามารถเปลี่ยนชื่อได้ตามต้องการ ผมจะเรียกว่ามันว่า background ก็ได้ แล้วจากนั้นคุณก็แค่ลากและเลือกองค์ประกอบข้อความ คลิกเพื่อเพิ่มองค์ประกอบข้อความ อย่างที่เห็น แล้วเราก็เปลี่ยนชื่อมันได้เหมือนกัน อันนี้จะเป็น text one

องค์ประกอบข้อความยังทำงานเหมือนเดิมอย่างที่ผมโชว์ในบทสอนแล้ว การอัปเดตมีแค่ส่วนวิดีโอพื้นหลังเท่านั้น ดังนั้นคุณเพิ่ม text one แล้วก็ใส่ข้อความอื่นๆ ทั้งหมดตามที่ผมเคยโชว์ไว้ในบทสอน

จากนั้นผมจะตั้งชื่อเทมเพลตให้ไม่ซ้ำใคร เช่น template 275 เพื่อที่ผมจะได้หามันเจอในระบบอัตโนมัติของผม แล้วเมื่อผมเข้าไปตรงนี้ ผมสร้างคอนเนกชันไว้แล้ว คลิก refresh แล้วผมจะเห็นและเลือกเทมเพลตที่ผมสร้างไว้ เอาล่ะ ไปคลิก use this template กัน

อันนี้ดี เทมเพลตถูกบันทึกแล้ว มันน่าจะโผล่มาตรงนี้ตามปกติ ลองคลิก refresh ดู โอเค ยังไม่เซฟ อาจจะต้องใช้เวลาสักครู่ งั้นเข้าไปใหม่ คลิก exit จริงๆ แล้วอาจจะใช้เวลาไม่กี่วินาทีกว่ามันจะดึงเทมเพลตมา ตอนนี้มันมาละ นี่คือสิ่งที่ผมเพิ่งสร้าง และคุณเห็นวิดีโอพื้นหลังแล้ว

ทีนี้ข้อความไม่โผล่ขึ้นมาเพราะผมลืมไป ข้อความก็ต้องตั้งค่าเป็น dynamic ด้วย ดังนั้นต้องตั้งค่าข้อความเป็น dynamic แล้วพอเราคลิกมัน มันจะโหลดเทมเพลตใหม่ ตอนนี้คุณเห็นข้อความแล้ว และตรงนี้คุณมีตัวยึดตำแหน่งวิดีโอที่ใช้ได้เหมือนที่ผมบอกในบทสอนติดตั้ง

สรุปคือ นี่เป็นเพียงอัปเดตสั้นๆ เท่านั้น
