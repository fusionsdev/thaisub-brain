## บทนำ
บทเรียนนี้จากคอร์ส Master Google Ads Conversion Tracking ของ Bob Miles อธิบายเรื่อง Consent Mode ครับ
เมื่อผู้ใช้ไม่ยินยอมให้เก็บคุกกี้ เราจะยิง Tracking Script บางตัวไม่ได้ ทำให้ Conversion หายไป
ผู้สอนอธิบายว่าทำไมต้องใช้ Consent Mode กลไกเบื้องหลังการทำงาน การคาดการณ์ Conversion (Conversion Modelling)
พร้อมยกตัวอย่างตัวเลขจริงจากเว็บ pipcmastery.com ของเขา และวิธีเริ่มต้นติดตั้งผ่าน Google Tag Manager ครับ

## คำแปลเต็ม
ผู้ใช้บางคนจะไม่ยินยอมตามนโยบายความเป็นส่วนตัวและ/หรือนโยบายคุกกี้ของคุณครับ
นี่อาจเป็นปัญหาใหญ่สำหรับคุณในฐานะนักโฆษณา
เพราะมันหมายความว่าคุณไม่สามารถยิง Tracking Script บางตัวได้
ลองนึกถึง Google Analytics 4 หรือ Conversion Pixel ของ Google Ads บนหน้า Thank You ของคุณ
ผู้ใช้ที่ไม่ยินยอมก็กลายเป็นผู้ที่ติดตามไม่ได้โดยพื้นฐาน
และถ้าพวกเขาเกิด Conversion ขึ้นมา Conversion เหล่านั้นก็จะมองไม่เห็นด้วย
โชคดีที่มีวิธีแก้ไขบางส่วน ซึ่งไม่สมบูรณ์ 100% แต่สามารถกู้คืน
Conversion ที่หายไปเหล่านี้กลับมาได้ประมาณ 70%
มันเรียกว่า Consent Mode และ Conversion Modelling ครับ
นี่คือเครื่องมืออย่างเป็นทางการของ Google ที่คุณสามารถใช้
เพื่อปฏิบัติตามกฎระเบียบความเป็นส่วนตัวในท้องถิ่น
และยังใช้เพื่อคาดการณ์ Conversion บางส่วนที่วัดไม่ได้
เนื่องจากการคลิกที่ไม่ได้รับความยินยอม ครับ

ในบทเรียนนี้ผมอยากพูดถึงว่าทำไมคุณถึงต้องใช้ Consent Mode ตั้งแต่แรก
มันทำงานอย่างไรภายใต้ฝาครอบ (ซึ่งอาจจะต้องดูซ้ำสองสามครั้ง)
จะได้ Uplift แบบไหนบ้าง และคุณจะติดตั้ง Consent Mode ด้วยตัวเอง
โดยใช้ Google Tag Manager ได้ยังไง
ไปดำดิ่งกันที่ว่าทำไมคุณถึงต้องใช้ Consent Mode ตั้งแต่แรก

ประเด็นใหญ่ข้อแรก: Google Consent Mode ทำให้แน่ใจว่าคุณในฐานะนักโฆษณา
ใช้เฉพาะข้อมูลที่คุณได้รับอนุญาตเท่านั้น เพื่อให้สอดคล้องกับกฎระเบียบข้อมูลในท้องถิ่น ครับ
ผมมาจากเนเธอร์แลนด์ ถ้าผมอยากปฏิบัติตามกฎหมายความเป็นส่วนตัวของเนเธอร์แลนด์
ผมต้องปฏิบัติตามกฎหมายยุโรปที่เรียกว่า AVG และ/หรือกฎ GDPR
Google Consent Mode โดยพื้นฐานช่วยให้ผมยิงเฉพาะ Tag ที่ผู้ใช้ยินยอม
และไม่ยิง Tag ที่ผู้ใช้ไม่ได้ยินยอม ครับ

ประโยชน์ใหญ่ข้อที่สอง: Consent Mode ใช้ Conversion Modelling
ซึ่งใช้ Machine Learning เพื่อประมาณ Conversion ที่อาจเกิดขึ้นเมื่อไม่มีการยินยอม
นี่เป็นเรื่องค่อนข้างซับซ้อน และผมใช้ภาพนามธรรมบางภาพเพื่ออธิบายการทำงาน
แต่ถ้าคุณไม่เข้าใจก็ไม่เป็นไร
คุณอาจต้องดูซ้ำสองสามครั้งหรือมากกว่านั้น
ผมเองก็ต้องทำแบบนั้นตอนเริ่มแรก มันค่อนข้างซับซ้อน
แต่ผมจะพูดถึงมันว่า มันทำงานยังไง

มันทำงานยังไง?
มันเชื่อมต่อกับระบบจัดการคุกกี้ (Cookie Management) ของเว็บไซต์นักโฆษณา
หรือที่เรียกว่า CMP และปรับพฤติกรรมของ Tag ของคุณตามความยินยอมของผู้ใช้
และนี่อาจเป็น Google Tags แต่ก็เป็น Tag ของบุคคลที่สาม
ที่คุณติดตั้งใน Google Tag Manager ได้ด้วย
ลองนึกถึง LinkedIn, Microsoft UET หรือแม้แต่ Meta Ads Conversion Pixel
ทุกอย่างจัดการได้ผ่าน Consent Mode ถ้าคุณตัดสินใจใช้มัน ครับ
มันใช้อัลกอริทึม Machine Learning ขั้นสูงเพื่อวิเคราะห์ข้อมูลในอดีต
และคาดการณ์โอกาสที่จะเกิด Conversion
คุณยังสามารถระบุแหล่งที่มา (Attribute) ของ Conversion ให้กับการคลิกที่ไม่ยินยอมได้ด้วย

นี่คือภาพหน้าจอของปัญหาที่ผมเจอครับ
นี่คือภาพหน้าจอของการคลิกที่เลือกไม่รับ (Opt-out) และเลือกยอมรับ (Opt-in)
จากเว็บ pipcmastery.com ของเราเอง
และในไตรมาสแรกของปีนี้ ผมพบว่าผู้ใช้ประมาณหนึ่งในสามปฏิเสธคุกกี้ทั้งหมด
ผมจึงไม่สามารถยิง Tag สำหรับผู้ใช้กลุ่มนี้ได้
แต่ด้วยการใช้ Consent Mode และ Conversion Modelling
ผมสามารถกู้คืนผู้ใช้ที่หายไปเหล่านี้ได้ประมาณ 70% ครับ
จริงๆ แล้วมันทำงานแบบนี้ครับ

ตรงนี้คุณเห็นภาพที่เรียบง่ายมาก
สมมติว่าคุณเริ่มต้นด้วยการคลิกโฆษณา 1,000 ครั้ง และมีอัตราการยินยอม (Consent Rate) 50%
คุณจะมีการคลิกที่ยินยอม 500 ครั้ง และไม่ยินยอม 500 ครั้ง
ก็ไม่มีปัญหาเลยที่จะสังเกตและระบุแหล่งที่มาของ Conversion จากการคลิกที่ยินยอม
อย่างน้อยถ้าการคลิกเหล่านี้ไม่ได้ใช้ Ad Blocker หรือบล็อกคุกกี้ของเบราว์เซอร์เพิ่มเติม
แต่เรื่องนั้นเอาไว้วิดีโอหน้า
ก็ไม่มีปัญหาเลย Conversion 50 ครั้งถูกระบุแหล่งที่มาให้ Google Ads ตามปกติ
จากนั้นคุณมีการคลิกที่ไม่ยินยอม และ Google ก็สามารถคาดการณ์ Conversion เก้าครั้งเหล่านี้ได้
โดยอาศัยลักษณะร่วมระหว่างการคลิกเหล่านี้
แล้วสร้าง Conversion เพิ่มอีกเก้าครั้งราวกับเป็นมายากล
ซึ่งไม่อย่างนั้นมันจะหายไปเพราะการคลิกที่ไม่ยินยอม ครับ
ดังนั้น แทนที่จะได้ Conversion Rate 5% คุณก็จะได้ประมาณ 5.9%
เมื่อใช้ Consent Mode และ Conversion Modelling
ซึ่งเป็น Uplift 18% ในตัวอย่างนี้ ครับ
ตัวเลขเหล่านี้เป็นเพียงตัวอย่าง แต่ทำให้คุณเห็นภาพว่าคาดหวังอะไรได้บ้าง
เมื่อติดตั้ง Consent Mode

จริงๆ แล้วมันทำงานยังไง?
มันค่อนข้างซับซ้อน คุณอาจต้องดูซ้ำสองสามครั้งหรืออ่านเอกสารทางการเพิ่มเติม
แต่มีสี่ขั้นตอนหลัก ครับ
ขั้นตอนแรก: การคลิกโฆษณาถูกแบ่งออกเป็นสองกลุ่ม
กลุ่มหนึ่งมีลิงก์ที่ชัดเจนและสังเกตได้ไปยัง Conversion และอีกกลุ่มไม่มี
คุณมีการคลิกที่ยินยอมพร้อม Conversion ตรงนี้
และมีการคลิกที่ไม่ยินยอมตรงนี้ ซึ่งยังไม่รู้ Conversion
ในขั้นตอนที่สอง: กลุ่มที่สังเกตได้ ซึ่งก็คือกลุ่มที่ยินยอมจริงๆ
ถูกแบ่งออกเป็นหลายกลุ่มย่อย
กลุ่มย่อยเหล่านี้สร้างจากลักษณะร่วมกัน และคำนวณเมตริกสำคัญสำหรับแต่ละกลุ่ม
กลุ่มย่อยถูกสร้างจากเบราว์เซอร์ อุปกรณ์ วันที่ และอื่นๆ อีกมากมาย
จากนั้นกลุ่มที่ไม่ถูกสังเกต (Unobserved) จะถูกจัดเข้ากลุ่มย่อยเดียวกัน
โดยใช้ลักษณะร่วมเดียวกัน เช่น อุปกรณ์ที่ใช้ เบราว์เซอร์ที่ใช้
และในขั้นตอนถัดไป การคลิกที่ไม่ถูกสังเกตจะถูกเชื่อมโยงกับ Conversion
โดยใช้ Conversion Rate ที่รู้จักและลักษณะอื่นๆ จากกลุ่มที่สังเกตได้
Machine Learning จะเชื่อมโยงการคลิกโฆษณาและ Conversion ที่ไม่ถูกสังเกต
เข้ากับกลุ่มที่สังเกตได้อื่นๆ
และด้วยวิธีนี้คุณจึงสร้าง Conversion Uplift
จาก Conversion ที่ถูกคาดการณ์โดย AI ครับ

ถ้าคุณติดตั้งสิ่งนี้ผ่าน Google Tag Manager หรือ Google Tag ทั่วไป
คุณก็เข้าไปที่ Conversion Action ของ Google Ads ที่ต้องการ
เข้าไปที่ Diagnosis
จากตรงนั้นคุณจะเห็นว่า Consent Mode ของ Conversion ของคุณติดตั้งถูกต้อง
และทำงานอยู่หรือไม่ และ Google รู้จัก Uplift บางส่วนแล้วหรือยัง
ตรงนี้คุณจะเห็นว่าเราได้ Uplift เกือบ 5% ในการระบุแหล่งที่มาของ Conversion
จากการติดตั้ง Consent Mode และ Conversion Modelling ครับ

คุณติดตั้งมันได้ยังไง? มีสองวิธีหลัก ครับ
วิธีแรกคือผ่าน Google Tag
คุณปรับพฤติกรรมของ Tag ตามความยินยอม สำหรับการติดตั้ง Google Tag
โดยการเพิ่มและอัปเดตโค้ด Consent ในทุกหน้าของเว็บไซต์
หรือคุณใช้ Google Tag Manager ได้
Google Tag Manager ช่วยให้คุณจัดการว่า Tag จะทำงานอย่างไร
เมื่อตอบสนองต่อการตั้งค่าความยินยอม
Google Tag Manager มีฟีเจอร์ในตัวหลายอย่างที่ทำงานร่วมกับ
ระบบจัดการคุกกี้หรือ CMP บางตัว
ผมชอบทำงานกับ Google Tag Manager เพราะมันให้ความยืดหยุ่น
และตัวเลือกการกำหนดค่าได้มากกว่า Google Tag ที่เขียนโค้ดตายตัว
ผมจึงแนะนำให้ทำผ่านฝั่ง GTM ครับ
แต่ถ้าคุณผูกติดกับ Google Tag คุณก็ต้องใช้วิธีนั้น
ในบทเรียนหน้า ผมจะโชว์วิธีติดตั้งด้วยตัวเองผ่าน GTM ให้ดูครับ
