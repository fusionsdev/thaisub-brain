# สรุป: How to build $25k 3D games with GPT-6 Astra
- **ช่อง:** Ray Fu · **ความยาว:** ~0.9 นาที · **ลิงก์:** https://www.youtube.com/watch?v=UKGCSE9lUBc

## ประเด็นหลัก
- กรณีศึกษา: เกมที่ AI สร้างมีผู้เล่น 60 ล้านคน ทำรายได้ $25,000
- Astra ได้รับเลือกเป็นโมเดลดีที่สุดสำหรับสร้างเกม 3D มัลติเพลเยอร์
- ขั้น 1: ใช้พรอมต์บอก Astra ว่าอยากสร้างเกมอะไร — มันถามกลับ 10 คำถามก่อนสร้าง
- Astra ไม่ได้แค่เขียนโค้ด — เปิด Unity, Blender, Unreal Engine สร้างเกมเอง ทั้งวาง component สร้าง geometry ตั้ง material และ export บิลด์ที่เล่นได้
- ขั้น 2: ต่อ H2O MCP เข้า ChatGPT — ได้โมเดล generation 30+ ตัวสร้างทุก asset: ตัวละคร ฉาก เท็กซ์เจอร์ แอนิเมชัน คัตซีน
- Astra เลือกโมเดลให้แต่ละชนิดของ asset อัตโนมัติ (ตัวละคร/ฉาก/เอฟเฟกต์ คนละโมเดล)
- ขั้น 3: เพลย์เทสต์ให้ Astra ดูแล้วให้มันปรับ — ใช้พรอมต์ให้มันถาม 5 คำถามเพื่อ refine
- รับคู่มือฉบับเต็มโดยกดไลก์ + คอมเมนต์ "game"

## ความเห็นสรุป
ขั้นตอนครบวงจรที่ฟังดูทะเยอทะยาน — จากพรอมต์สู่ไฟล์เกมเล่นได้จริงบนเอนจินมาตรฐาน จุดขายคือการเชื่อมหลายเครื่องมือ (Astra + H2O MCP + ChatGPT) เป็นระบบเดียวครับ
