## บทนำ
วิดีโอนี้สอนวิธีสมัครบัญชี ElevenLabs แบบฟรีซึ่งเพียงพอสำหรับใช้งานระบบอัตโนมัตินี้ จากนั้นไปสร้าง API key ในเมนู API แล้วนำมาใส่ใน n8n เพื่อเชื่อมต่อ

## คำแปลเต็ม
คุณไปที่เว็บนี้ได้เลย คุณสามารถสมัครบัญชีฟรี ซึ่งเพียงพอที่จะใช้ระบบอัตโนมัตินี้ได้ แล้วจากนั้นคุณไปที่เมนู API กด create a key แล้วก็นำ key นั้นมาใส่ตรงนี้ แล้วกด save จากนั้นระบบก็จะทำการเชื่อมต่อให้
