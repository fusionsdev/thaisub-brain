## บทนำ

คลิปนี้อธิบายวิธีใช้ Google Display Network และ Discovery Ads เพื่อขยายธุรกิจ โดยเน้นว่าโฆษณา display มักถูกมองข้ามทั้งๆ ที่เข้าถึงผู้ใช้ออนไลน์กว่า 90% วิทยากรแนะนำให้เริ่มจากโฆษณากลุ่มล่างของฟันเนล (remarketing) ก่อน แล้วค่อยขยับขึ้นกลุ่มบน พร้อมเตือนเรื่องความเสี่ยงในการเผางบประมาณหากไม่จัดโครงสร้างแคมเปญและเลือกภาพ/landing page ให้ดี

## คำแปลเต็ม

มีคนน้อยมากที่เข้าใจวิธีใช้ YouTube เพื่อขยายธุรกิจ

แต่ที่น่าสนใจคือ คนที่เข้าใจวิธีใช้ Google Display Network หรือ Discovery Ads เพื่อขยายธุรกิจยิ่งน้อยลงไปอีก

มาวิเคราะห์กันสักเล็กน้อย

อย่างที่เราวางไว้ 3 ล้านเว็บไซต์เป็นส่วนหนึ่งของ Google Display Network

ดังนั้นเมื่อคุณรันโฆษณาแบบ display ผ่าน Google โฆษณาของคุณสามารถแสดงบนหนึ่งใน 3 ล้านเว็บไซต์นั้น

ผู้ใช้ออนไลน์กว่า 90% ขึ้นไปโต้ตอบกับ Display Network เป็นประจำ

ดังนั้น ไม่ว่าลูกค้าของคุณเป็นใคร อยู่ในหมวดหมู่ไหน กลุ่ม niche แบบไหน คุณก็เข้าถึงพวกเขาด้วย Display Network ได้

และผ่าน Discovery Ads ซึ่งผมชอบมาก

มันคือโฆษณาแบบ display ที่แสดงบน YouTube ในฟีดมือถือ

มันแสดงใน Gmail ได้ แสดงในแอป Discover ได้

นี่คือตำแหน่งพรีเมียมสำหรับโฆษณาแบบ display ผ่านสิ่งที่เรียกว่า Discovery

นี่คือภาพรวมคร่าวๆ ว่ามันแสดงได้ที่ไหนบ้าง

มันแสดงได้บนโฆษณาในฟีด ถ้าเกี่ยวข้องกับคุณ แต่สำหรับคนส่วนใหญ่ที่ดูคลิปนี้ อาจไม่เกี่ยวข้อง

Display เป็นเรื่องของกลุ่มบนและกลุ่มล่างของฟันเนลจริงๆ

นี่คือจุดที่เราสามารถแนะนำแบรนด์และสินค้าของเราให้คนใหม่ๆ รู้จัก

เพราะการเข้าถึงที่กว้าง และความสามารถในการสร้าง audience เจ๋งๆ

เราสามารถเข้าถึงคนที่อยู่บนสุดของฟันเนลได้

และเพราะ display และ discovery เก่งเรื่องนี้ มันจึงทรงพลังมากที่กลุ่มล่างของฟันเนล ในขั้นการซื้อ

และยังเก่งในการสร้างความภักดี

คุณใช้ display เพื่อทำให้คนซื้อครั้งที่สอง หรือครั้งที่สาม หรือเปลี่ยนจากคนที่ซื้อ 1-2 ครั้งให้กลายเป็นสมาชิก (subscriber)

เราแนะนำให้เริ่มจากกลุ่มล่างของฟันเนลก่อน

คนส่วนใหญ่ที่ดูคลิปนี้จะประสบความสำเร็จกับ display และ discovery แบบกลุ่มล่างของฟันเนล

การทำกลุ่มบนของฟันเนลยุ่งยากกว่าเล็กน้อย

ตรงนี้คุณต้องโฟกัสกับการสร้างกลุ่มเป้าหมายมากเป็นพิเศษ

คุณต้องมีโฆษณาที่ดีมาก ต้องมี landing page ที่ยอดเยี่ยม และอื่นๆ อีกมาก

แต่จำไว้ว่า การทำกลุ่มบนของฟันเนลคือการตลาดแบบขัดจังหวะ (interruption marketing)

คุณต้องมีภาพที่ว้าว มีหัวข้อข่าวที่สะดุดตา

ต้องมีคำกระตุ้นการตัดสินใจ (call to action) ที่ทำให้คนคลิก

แล้วคุณต้องเฝ้าดูแคมเปญพวกนี้อย่างใกล้ชิด เพราะมีพื้นที่โฆษณาและอิมเพรสชันให้คุณมากมาย

มันง่ายมากที่แคมเปญ display จะเข้าสู่โหมดสิ้นเปลืองและเผางบประมาณของคุณ

สิ่งที่เราเจอบ่อยในโฆษณาช้อปปิ้งหรือ search คือ บางครั้งคุณให้งบประมาณแคมเปญระดับหนึ่ง แต่มันใช้ไม่หมด

เพราะแคมเปญพวกนั้นถูกจำกัดด้วยปริมาณการค้นหา

ผมรับประกันได้ว่า ไม่ว่างบประมาณเท่าไหร่ที่คุณให้ display Google จะหาทางใช้จนหมดแน่นอน

ต้องเฝ้าดูแคมเปญกลุ่มบนบน display ให้ดี และมั่นใจว่ามันไม่สิ้นเปลืองเกินไป

ความสำเร็จกับ display และ discovery มาจากสี่สิ่ง

อย่างแรก คือการได้กลุ่มเป้าหมายที่ถูกต้อง

เราแนะนำ และขอเน้นย้ำ ให้เริ่มจาก remarketing

นี่คือจุดที่เราสร้าง audience อย่างกลุ่มคนทิ้งตะกร้า (cart abandoner) กลุ่มคนดูหน้าเพจสินค้า และแม้แต่คนที่เคยซื้อในอดีต

สิ่งที่ทำได้กับ display คือ เราสามารถทำให้คนที่ซื้อครั้งเดียวซื้ออีกครั้ง

หรือบางคนเป็นลูกค้าที่หายไป (lapsed customer) ซื้อเมื่อปีก่อนแล้วไม่ซื้ออีก ให้พวกเขากลับมาซื้ออีกครั้ง

หรือบางคนซื้อไปหลายครั้งแต่ยังไม่เป็นสมาชิก ถ้าเรามีบริการสมาชิก ก็ชวนพวกเขาเป็นสมาชิก

หรือบางคนซื้อสินค้าของเราไปหนึ่งอย่างแต่ยังไม่ซื้ออย่างอื่น เราก็ใช้ display ให้พวกเขากลับมาซื้อเพิ่ม

เริ่มต้นด้วย display ที่กลุ่มล่างของฟันเนล นั่นคือจุดที่เกือบจะการันตีผลได้อย่างน้อยบางส่วนสำหรับธุรกิจของคุณ

สิ่งถัดไปคือ คุณต้องมีภาพที่ถูกต้อง

เราต้องมีภาพที่เล่าเรื่องและดึงดูดให้คนคลิก

ไม่ว่าจะเป็นการเตือนให้พวกเขานึกถึงสินค้าของเรา หรือโน้มน้าวให้ลองดูสินค้าของเราตั้งแต่แรก

ภาพที่ถูกต้องและคำโฆษณาที่ถูกต้อง คือองค์ประกอบที่สำคัญที่สุดของโฆษณา

จากนั้นเราจะเลือก landing page ที่ถูกต้อง

เราจะส่งทราฟฟิกไปที่ไหน? สำคัญมาก

เพราะถ้าเรารันโฆษณากลุ่มบนของฟันเนล พวกเขาอาจไม่แปลงเป็นยอดขายในการซื้อครั้งแรก

เราอาจต้อง remarket กับพวกเขาเพื่อให้ซื้อ

ถ้าเราจะ remarket กับพวกเขา เราควรส่งพวกเขาไปหน้าไหน?

คิดให้ดีเรื่อง landing page นี่เป็นส่วนใหญ่ของความสำเร็จหรือความล้มเหลวของแคมเปญ display

แล้วก็โครงสร้างแคมเปญและการตั้งค่า bidding

เราต้องตั้งค่าให้ดีเพื่อจำกัดความสิ้นเปลือง เราไม่อยากจ่ายแพงเกินไปสำหรับ remarketing

เราอยากรันมันให้ดี และมันเป็นส่วนสำคัญของสื่อผสมโดยรวมของเรา เราไม่อยากจ่ายแพงเกินไป

และถ้าเราใช้ display และ discovery สำหรับกลุ่มบนของฟันเนล ก็มีโอกาสเติบโต

และตอนนี้คุณอาจยังไม่ได้ใช้มัน คู่แข่งของคุณก็ไม่ได้ใช้เหมือนกัน

แต่ก็มีโอกาสมหาศาลที่จะสิ้นเปลืองงบประมาณ

จัดโครงสร้างแคมเปญให้ดี นั่นจะทำให้คุณประสบความสำเร็จ

นี่ควรเป็นส่วนสำคัญจริงๆ ของสื่อผสมการตลาดของคุณ อย่างแน่นอน และเหมาะที่สุดสำหรับกลุ่มบนของฟันเนลด้วย
