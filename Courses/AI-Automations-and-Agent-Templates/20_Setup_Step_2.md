## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 2 ของการตั้งค่าระบบอัตโนมัติ เราจะตั้งค่า scenario แรกบนแพลตฟอร์ม make.com (เดิมคือ Integromat) โดยนำเข้าบลูเพรนต์ เชื่อมต่อ Google Sheets และ OpenAI เพื่อเปลี่ยนบทความบล็อกให้เป็นโพสต์โซเชียลมีเดียหลายสไตล์พร้อมสร้างรูปภาพ แล้วบันทึกทุกอย่างกลับลง Google Sheets

## คำแปลเต็ม

ตอนนี้เราจะตั้งค่า scenario แรกที่จำเป็นสำหรับระบบอัตโนมัติของเรา ด้านล่างนี้คุณจะพบลิงก์สำหรับดาวน์โหลด blueprint เมื่อดาวน์โหลดแล้ว คลิก import แล้วไปที่ scenario ที่เราต้องการ คลิก แล้วมันถูกนำเข้าแล้ว

ตอนนี้เรายังต้องปรับการตั้งค่าบางอย่าง เราต้องเชื่อมต่อกับ Google Sheet ของเรา โดยคลิก add a webhook แล้วคลิก save และ copy ไป จากนั้นไปที่ Google Sheets แล้วไปที่ Apps Script ตรงนั้นเราต้องใส่โค้ด เลื่อนลงมาหน่อยแล้วเห็น "insert make webhook generator" นี่คือจุดที่ผมแทนที่ด้วย webhook คลิก save

ก่อนอื่นเราต้องเปิดใช้งาน webhook เพื่อให้มันรับข้อมูลจาก Google Sheets และเราสามารถตรวจสอบว่าการเชื่อมต่อทำงานหรือไม่ ผมจะเลือกบล็อกอะไรก็ได้ พิมพ์ลงไป แล้วมันควรแทรกบล็อกให้อัตโนมัติ อย่างที่เห็น ต้องคลิก run จากนั้นคลิก generate แล้วมันควรจับ URL ของบล็อกและชื่อบล็อก เพราะนี่คือสิ่งที่จำเป็นสำหรับการสร้างรูปภาพ จากนั้นเชื่อมต่อใหม่ได้

เราไม่ต้องตั้งค่าโมดูลพวกนี้ สิ่งเดียวที่ต้องตั้งค่าคือโมดูล Google Sheets และโมดูล OpenAI เหล่านี้ ในโมดูล Google Sheets คุณจะเห็นฟิลด์ชื่อ Insert Sheet ID สิ่งแรกที่ต้องทำคือเพิ่มบัญชี Google ของคุณ ตรวจสอบว่าเป็นบัญชีเดียวกับที่โฮสต์ Google Sheet นี้ คุณดูได้โดยวางเมาส์เหนือไอคอนบัญชีที่มุมขวาบน แล้วจะเห็นว่าคุณเข้าสู่ระบบด้วยบัญชี Google ใด และตรวจสอบว่าลงชื่อเข้าใช้ด้วยบัญชี Google เดียวกันในโมดูลชีตนี้

เมื่อทำเสร็จ มันจะปรากฏตรงนี้ แล้วเลือกจาก dropdown ได้ จากนั้นใช้ตัวเลขนี้ ตั้งแต่เครื่องหมาย slash ถึง slash นี่คือ Google Sheet ID ที่ต้องใส่ สิ่งที่มันทำคือดึง post templates จาก Google Sheets ของเราซึ่งถูกระบุไว้ แล้วนำเข้าสู่ระบบอัตโนมัติของเรา ผมทำแบบนี้กับทั้งสามโมดูลได้เลย แค่ต้องใส่และตรวจสอบว่ามันโหลดค่าเหล่านั้นมา ดี ใช้ได้เหมือนกัน คลิกตรงนี้

ต่อไปคือโมดูล OpenAI คลิก save แล้วสำหรับ OpenAI สิ่งที่ต้องมีคือการเชื่อมต่อ OpenAI ถ้าคุณยังไม่มี คุณต้องคลิก add แล้วใส่ OpenAI API key ของคุณ ซึ่งคุณจะพบวิดีโอสอนวิธีได้ทางด้านซ้ายมือ ในหัวข้อ "Get API key from OpenAI" คุณจะพบวิธีขอ API key แบบสั้น ๆ เมื่อทำแล้ว คุณต้องทำแค่ครั้งเดียวถ้ายังไม่มี และเมื่อเพิ่มแล้ว คุณก็เลือกใช้มันได้กับระบบอัตโนมัติอื่น ๆ ที่เหลือและระบบอัตโนมัติอื่นที่คุณจะสร้างต่อไป ดังนั้นเมื่อเชื่อมต่อไว้แล้ว ไม่ต้องทำอะไรเพิ่ม แค่สร้างการเชื่อมต่อให้เรียบร้อยเท่านั้น

จากนั้นต้องตั้งค่า Google Sheets อีกตัวหนึ่ง ผมต้องดึง Sheet ID แล้วใส่ลงตรงนี้ นี่คือจุดที่มันควรบันทึกข้อมูล ตรงนี้ต้องตั้งค่าบางอย่าง ตรวจสอบว่ามันเจอชีตที่ถูกต้อง ใช่ ต่อไปตรงนี้คือส่วน blog article ต้องเลื่อนลงมา แล้วผมจะเลือก blog title เพราะอยากรู้ว่าโพสต์โซเชียลมีเดียใช้บทความบล็อกใด post style ตรงนี้คือ key points ผมแค่พิมพ์ลงไป

โพสต์นี้คือสิ่งที่โมดูล OpenAI ตัวแรกทำ มันวิเคราะห์บทความบล็อก มันไม่ได้สร้างข้อความ มันดูบทความบล็อก แล้วแตกบทความออกตามสไตล์โพสต์ ซึ่งก็คือ key points ดังนั้นมันจึงแยกประเด็นสำคัญของบทความบล็อกออกมา นั่นคือสิ่งที่มันทำ และมันบันทึกสิ่งนี้ลงชีต เพื่อให้เรารู้ทีหลังว่าโพสต์นี้มาจากบทความไหน หัวข้อคืออะไร และใช้สไตล์อะไรในการสร้างข้อความโพสต์ เราจะได้รู้ที่มา

ส่วนถัดไป เราไม่ต้องตั้งค่าอะไรมาก ไปที่โมดูลนี้ เพิ่มชีตตรงนี้ เพราะต้องทำแบบเดียวกัน ข้อแตกต่างคือตอนนี้มันเรียกว่า key facts ดังนั้น source blog article เหมือนเดิม post style คือ key facts และ post topic คือผลลัพธ์อีกครั้ง คลิก OK ในโมดูลนี้ด้วย รอจนกว่ามันจะโหลดชีต ดี source blog post style ตรงนี้มันเรียกว่าแบบนี้ และต้องใช้ผลลัพธ์จากตรงนั้น และตอนนี้ตั้งค่าเสร็จแล้ว ไม่ต้องทำอะไรเพิ่ม

ตรงนี้คือจุดที่สร้างโพสต์ ข้อความโพสต์ถูกสร้างขึ้น คุณเห็นวิธีที่มันทำงาน ไปที่โมดูลแรก: key points มันจะดึง key points ที่ถูกแยกโดยโมดูลที่แตกบทความบล็อกเป็นประเด็นสำคัญ แล้วใช้เทมเพลตตัวอย่างโพสต์โซเชียลมีเดียที่ได้จาก Google Sheets ตรงนี้สำหรับสไตล์ที่เกี่ยวข้อง จากนั้นแปลงรายการประเด็นสำคัญในกรณีนี้ให้เป็นโพสต์โซเชียลมีเดียตามโครงสร้างนี้ และอย่างที่บอก คุณเปลี่ยนสิ่งนี้ได้ตามต้องการ เปลี่ยนโพสต์ตัวอย่างที่เป็นแม่แบบได้ เปลี่ยนและแทนที่ด้วยอย่างอื่นได้

ต่อไปคือโมดูล Google Sheets สิ่งที่เราต้องการคือบันทึกข้อความโพสต์ที่สร้างขึ้นลงในชีตของเรา ขอตรวจสอบก่อนว่านี่คือ Google Sheet ที่ถูกต้องไหม ใช่ ถูกต้อง ตอนนี้เราต้องลิงก์ generated post ซึ่งมาจากตรงนี้ สำหรับทุกโมดูลเหล่านี้ generated post text คืออันนี้ และสุดท้ายคือ post text ที่บันทึกตรงนี้ บันทึกกัน

และสุดท้ายคือจุดที่สร้างรูปภาพ ตอนนี้คุณไม่ต้องทำอะไรเพราะเชื่อมต่อไว้แล้ว มันจะใช้หัวข้อบล็อกและสร้างรูปภาพ คุณสามารถเปลี่ยนคำสั่ง prompt สำหรับรูปภาพได้ ทำให้มันสร้างในสไตล์ที่คุณต้องการได้ทุกแบบ ผมใช้สไตล์แบบ stylized เพื่อให้มันดูไม่เหมือนรูป AI จริง ๆ แต่ดูเหมือนภาพประกอบกราฟิกมากกว่า เพื่อให้โดดเด่นขึ้น และไม่ดูเหมือนรูปที่สร้างด้วย AI ทั้งที่มันก็สร้างด้วย AI นั่นแหละ แต่คุณไม่ต้องทำอะไรกับส่วนเหล่านี้

และผมต้องการบันทึก URL ของรูปภาพที่สร้างจากโมดูลนี้ลงใน Google Sheets ของผม ตรงนี้ต้องใส่ Sheet ID อีกครั้ง แล้วมันจะโหลดชีตของผมอีกครั้ง จากนั้นไปที่ image link แล้วคลิก dropdown นี้แล้วเลือก URL แล้วคลิก OK ต้องทำแบบนี้กับโมดูลอื่น ๆ ด้วย เมื่อทำครบแล้ว ตรงนี้ต้องขยาย image แล้วเลือก URL และอันสุดท้าย จากนั้นเราก็ทดสอบรันเพื่อดูว่ามันทำงานหรือไม่ Image link โอเค คลิก save ตอนนี้ตั้งค่าเสร็จแล้ว

จากนั้นผมยกเลิกการเลือกมันอีกครั้ง คลิก และเราเลือกได้แค่ checkbox เพื่อให้มันเริ่มทำงานทันที เพราะผมสามารถควบคุมมันจากภายใน Google Sheets ได้ มันจะ trigger เมื่อผมคลิกที่ checkbox อย่างที่เห็น แล้วออกจากตรงนั้นได้ จากนั้นสลับเป็นโหมดเปิดใช้งาน ลบข้อมูลทั้งหมด แล้วตอนนี้มันควรทำงานเมื่อคลิก generate

ถ้าเราตั้งค่าทุกอย่างถูกต้อง จะเห็นว่ามันกำลังรันอยู่แล้ว มันโอนบทความบล็อกไปยัง post style แรกแล้ว และสร้างเสร็จแล้ว ตอนนี้มันแยก key points ของบทความบล็อกนี้ และใช้เป็นฐานสำหรับโพสต์โซเชียลมีเดียของเรา จากนั้นมันก็สร้างโพสต์โซเชียลมีเดียแล้ว เราจะเห็นได้เลย อย่างที่เห็น นี่คือบทความต้นฉบับ นี่คือ post style นี่คือโพสต์ซึ่งเป็นรายการประเด็น และนี่คือโพสต์ที่สร้างแล้ว ซึ่งเป็นประเด็นสำคัญของบทความนี้

ตอนนี้มันสร้างลิงก์รูปภาพแล้ว สิ่งที่ Google Sheets ของผมทำคือแปลง URL รูปภาพเป็น Google Drive URL เพราะสำคัญมาก เนื่องจากรูปภาพที่สร้างด้วย AI จากลิงก์ OpenAI จะใช้งานได้เพียงประมาณ 2 ชั่วโมงเท่านั้น หลังจากนั้นรูปจะหายไป ดังนั้นเราต้องดาวน์โหลดมันลงในโฟลเดอร์ Google Drive แล้วอัปโหลด แล้วแทรกลงตรงนี้ และ Google Sheets ทำทั้งหมดนี้ให้ คุณไม่ต้องทำอะไรเลย

และคุณเห็นว่ามันรันผ่านอันที่สองและอันที่สามแล้ว อันแรกถึงขั้นรูปภาพแล้ว มันสร้างรูปภาพของอันที่สอง และตอนนี้อันที่สาม ตรงนี้ปกติจะเป็นลิงก์ OpenAI และตอนนี้มันถูกแปลงเป็นลิงก์ Google Drive แล้ว และบันทึกลงในโฟลเดอร์ Google Drive ของคุณโดยอัตโนมัติ ในตำแหน่งเดียวกับที่ Google Sheets ตั้งอยู่ แต่คุณไม่ต้องทำอะไรเพราะมันอยู่บนชีตของคุณแล้วตลอด

และสิ่งถัดไปที่ต้องตั้งค่าคือกระบวนการเผยแพร่
