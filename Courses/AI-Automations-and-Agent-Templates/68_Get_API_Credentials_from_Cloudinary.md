## บทนำ
วิดีโอนี้แสดงขั้นตอนการขอ API credentials จาก Cloudinary ตั้งแต่การสร้าง key ใหม่ การยืนยันทางอีเมล ไปจนถึงการนำ API key และ API secret ไปกรอกในระบบอัตโนมัติของคุณ

## คำแปลเต็ม

ตรงนี้ผมต้องกรอก user และ password ตอนนี้ผมเจอสิ่งนี้ภายใต้... แล้วเข้าไปที่ API ตรงนั้นคุณสามารถสร้าง key ใหม่ได้ โดยคุณจะได้รับอีเมลยืนยันก่อน และเมื่อยืนยันแล้วก็สามารถสร้าง API key ใหม่ได้ ซึ่งผมทำไว้แล้ว ตรงนี้ API key จะใส่ในช่อง user จากนั้นผมต้องใช้ API secret ซึ่งต้องกรอกรหัสยืนยันที่ได้รับทางอีเมล แล้วก็คัดลอกมันมาวางตรงนี้ จากนั้นคลิกที่... แล้วมันก็จะแสดงขึ้นมาและถูกเลือก
