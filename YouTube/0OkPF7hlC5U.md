## ประเด็นหลัก

- Black Forest Labs ปล่อย FLUX3 video โมเดล multimodal (ภาพ วิดีโอ เสียง การคาดเดาการเคลื่อนไหว) พร้อมพรีวิว 48 ชั่วโมงภายใน Hermes Agent ซึ่งสามารถต่อช็อตหลายช็อตเป็นชอร์ตฟิล์มจากพรอมป์เดียว end-to-end
- วิธีตั้งค่า: อัปเดต Hermes Agent แล้วเปิดใช้งานเครื่องมือ BFL FLUX3 video (text to video, image to video, get result key frames to video) ในหน้า capabilities ของแอปเดสก์ท็อป
- เป้าหมายหลัก: สร้างตัวละครที่คงเส้นคงวา (มาสคอต Toby จาก PFP) ให้เดินทางข้ามโลกหลากสไตล์ศิลป์ โดยวางแผนซีนด้วย key frames 4-5 อันต่อฉาก
- โลกทั้ง 7 ใบ: โลกมาร์กเกอร์ → นิวยอร์กสมจริง → ญี่ปุ่นซามูไรอนิเมะ → ชายฝั่งทรายดำภูเขาไฟ → โลกไดโนเสาร์เคลย์เมชัน → สถานีรถไฟยุค 1910 สไตล์ภาพยนตร์เงียบ → วิหารกระจกสีแฟนตาซี → โรมโบราณ → กลับสู่โลกมาร์กเกอร์
- บทเรียนสำคัญ: คลิป 5 วินาทีต่อกันไม่เนียน ควรใช้คลิปต่อเนื่อง 20 วินาที; การใช้ reference image ช่วยให้ FLUX3 จับสไตล์ได้แม่นมาก; พอร์ทัลสีทองช่วยกลบรอยต่อระหว่างฉาก
- ปัญหาที่เจอ: หัวไดโนเสาร์กลายเป็นหาง (โมเดลสลับด้านหน้า-หลัง), ตัวละครหลุดจากดีไซน์ต้นฉบับ, connection errors บน Terra จึงสลับไปใช้ Soul — วิธีแก้คือลดความซับซ้อนของพรอมป์ ตัดต่อด้วยรีแอคชันช็อต และรีเจนเนอเรตคลิปทั้งคลิปแทนการต่อชิ้นส่วน
- ผลงานสุดท้าย: หนังสั้น 2 นาที 25 วินาที จบด้วยข้อความ "ถ้าคุณจินตนาการได้ คุณก็สำรวจมันได้" พร้อมเพลงประกอบ ตัดต่อครอสเฟดออกเป็นคัทสะอาด

## ความเห็นสรุป

วิดีโอนี้เป็นการสาธิตเวิร์กโฟลว์สร้างชอร์ตฟิล์มด้วย AI ได้อย่างโปร่งใสและสมจริง ไม่ได้โชว์แต่ผลลัพธ์สวยงาม แต่เล่าปัญหา การลองผิดลองถูก และการแก้ไขทีละขั้นตอน ซึ่งมีคุณค่าสำหรับคนที่อยากลองทำวิดีโอเจนด้วยตัวเอง จุดแข็งของ FLUX3 คือการรักษาตัวละครให้คงเส้นคงวาและการทำงานกับ reference image ส่วนจุดที่ยังต้องใช้ความพยายามของมนุษย์คือการวางซีน การจัดการรอยต่อ และการตัดต่อขั้นสุดท้าย
