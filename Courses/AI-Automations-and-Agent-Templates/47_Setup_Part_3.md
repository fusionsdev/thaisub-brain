## บทนำ
วิดีโอนี้เป็นขั้นตอนการสร้างวิดีโอจากสคริปต์ที่ระบบดึงมาจาก Google Sheets โดยใช้ Captions AI ในการสร้างวิดีโอคนพูด ไม่ว่าจะเป็น AI clone ของตัวเองหรือ avatar ที่ทางแพลตฟอร์มให้มา จากนั้นนำวิดีโอที่ได้ไปเพิ่มชื่อเรื่องและคำบรรยายด้วย JSON2Video ก่อนบันทึกลง Google Sheets และส่งการยืนยันกลับมาทาง Telegram

## คำแปลเต็ม

ตอนนี้เรามีโพรเซสที่สร้างวิดีโอจากคอนเทนต์ที่เราดึงออกมาและปรับแต่งให้เราแล้ว ขั้นแรกคือการเชื่อมต่อ Captions AI ซึ่งเป็นแอปที่เราใช้ สร้างวิดีโอด้วย Captions AI ไม่ว่าจะใช้ AI clone ของเราเองหรือ avatar ที่พวกเขาให้มา คุณคลิกที่ get started คุณสามารถสมัครบัญชีฟรีได้

สิ่งแรกที่คุณทำคือขอ API key ซึ่งผมได้โชว์วิธีทำไว้แล้วในวิดีโอเทคนิค get API key from Captions App และจากนั้นนั่นคือทั้งหมดที่คุณต้องใช้จากตรงนี้ แล้วคุณสามารถคลิก test step ได้ สิ่งที่มันทำอย่างแรกคือดึงรายการ speakers มาให้ผม ซึ่งก็คือ AI avatars ที่ผมสามารถใช้กับวิดีโอของผมได้

และคุณสามารถสร้าง AI ของคุณเองได้ คุณไปที่ new AI ตามที่พวกเขาเรียก แล้วคลิกที่ upload a video หรือ record a video จากนั้นคุณอัปโหลดวิดีโอตัวเองพูดสักสองสามนาที แล้วคลิกสร้าง จากนั้นมันจะใช้เวลาสักครู่ แล้วคุณก็จะมี AI twin ของคุณเองพร้อมใช้งาน และมันจะแสดงขึ้นมาตรงนี้ด้วย นี่คือ AI twins ที่ผมมี หรือคุณสามารถไปใช้ตัวอื่นที่เห็นตรงนี้ได้ และคุณจะเห็นตัวเลือกต่าง ๆ เหล่านี้ พร้อมตัวอย่าง คุณสามารถดูได้ทั้งหมดถ้าไม่อยากใช้ avatar ของตัวเอง และคุณสามารถเลือกตัวอื่นได้

เมื่อทำเสร็จแล้ว เราก็ไปต่อขั้นตอนถัดไป ในโมดูลตรงนี้ คุณต้องเพิ่ม API key ของคุณตรงนี้ด้วย และตรงนี้คือจุดที่วิดีโอถูกสร้างขึ้น นี่คือจุดที่มีสคริปต์ที่มาจาก Google Sheets คุณเห็นนั่นคือสคริปต์ที่เราสร้างไว้ ถ้าตัวแปรใดตัวแปรหนึ่งไม่เป็นสีเขียว คุณสามารถลากสคริปต์เข้ามาได้ คุณไปดูว่าเรามีอะไร แล้วลากมันมาวางตรงตำแหน่งนี้

ในการสร้างวิดีโอ ตรงนี้เราเลือก creator ที่ต้องการใช้ ซึ่งมาจาก get speakers และตรงนั้นผมสามารถเลือกใครก็ได้ ไม่ว่าจะเป็นของผมเอง ใช่ไหม? อันนี้เป็นของผมอันหนึ่ง มันชื่อ Video one ผมสามารถใช้ตัวนี้ หรือจะใช้ avatar อื่นที่พวกเขาให้ก็ได้ สำหรับตัวอย่างนี้ ผมจะใช้ของตัวเอง แล้วคลิก test แล้วโพรเซสสร้างวิดีโอก็จะเริ่มขึ้น ใช้เวลาประมาณสองนาทีครึ่ง นั่นคือเวลาที่มันอาจใช้จนกว่าวิดีโอจะเสร็จ จากนั้นเราถึงจะไปต่อส่วนถัดไปได้

ตรงนี้คือจุดที่เราได้รับวิดีโอ ตรงนี้คุณต้องใส่ API key ของคุณด้วย แล้วคลิก test step และตอนนี้เราต้องรอจนกว่าสองนาทีครึ่งจะผ่านไป แล้วเราจะไปต่อขั้นตอนถัดไป แต่ระหว่างนั้นเราสามารถไปที่โมดูลนี้โดยอัตโนมัติได้

วิดีโอที่เราได้จากแอป Captions นั้นเป็นเพียงวิดีโอคนพูดสคริปต์ที่เราสร้างขึ้น แต่เรายังต้องการมีชื่อเรื่องอยู่ด้านบนของวิดีโอ และมีคำบรรยายด้วย และเราใช้เครื่องมืออีกตัวที่ชื่อว่า JSON2Video ซึ่งเป็นเครื่องมือนี้ และคุณสามารถสมัครบัญชีฟรีได้ตรงนี้ เมื่อทำเสร็จแล้ว คุณไปที่ create new ตรงนี้ แล้วคุณต้องวางโค้ดนี้ นี่คือตัวแปร API key ต้องใส่ API key ลงไป ผมได้โชว์วิธีทำไว้แล้วในบทเรียนเทคนิค get API key from JSON2Video แล้วคุณใส่ค่าลงไป คลิก แล้วก็เสร็จ แล้วคุณก็ไปต่อกับอันนี้ได้

ตรงนี้เราต้องเช็คว่าทุกอย่างเป็นสีเขียวไหม นี่คือ text overlay ของเรา นี่คือข้อความที่อยู่บนวิดีโอ ตรงนี้คุณเห็นว่าเรามีสององค์ประกอบ: อันบน และตรงนี้เรามีคำบรรยายอยู่ด้านล่าง และนี่คือการจัดสไตล์ที่แตกต่างกัน: ฟอนต์ พื้นหลัง และอื่น ๆ คุณสามารถปรับแต่งได้ตามต้องการ แม้แต่ตำแหน่งตรงนี้ และตรงนี้เรามีคำบรรยาย นี่คือชื่อเรื่องที่แสดงด้านล่าง นี่คือคำพูดที่พูดในวิดีโอ และตรงนี้คุณสามารถจัดรูปแบบในรูปแบบต่าง ๆ ได้ถ้าต้องการ

ตอนนี้ผมเห็นว่าวิดีโอเสร็จแล้ว ผมสามารถเช็คได้ หรือผมต้องไปขั้นตอนถัดไป ตอนนี้วิดีโอเสร็จแล้ว ให้ผมได้ลิงก์ไปยังวิดีโอ ผมคลิกที่มัน แล้วผมจะได้ลิงก์เต็มของวิดีโอ ตอนนี้เราต้องส่งมันไปยัง JSON2Video เราคลิกที่มัน คลิก test แล้วมันจะส่งวิดีโอไป ซึ่งจะใช้เวลาประมาณ 2 นาทีกว่าจะเสร็จ

และตรงนั้นเรามี JSON2Video อีกตัว ซึ่งจะดึงวิดีโอของเรามา และตรงนี้คุณเลือกบัญชีที่คุณเชื่อมต่อไว้ในขั้นตอนก่อนหน้า และตอนนี้เราสามารถ trigger มันได้ นี่คือ URL วิดีโอที่จะถูกส่งให้เราเมื่อโมดูลนี้ทำงานเสร็จ ซึ่งจะใช้เวลาอีกประมาณ 2 นาที ในระหว่างนั้นเราสามารถตั้งค่า Google Sheet ตรงนี้ได้ สิ่งเดียวที่ต้องทำคือเลือก Google Sheet ที่เราเชื่อมต่อไว้ ตอนนี้เราอยากบันทึก URL วิดีโอด้วย

ตอนนี้เราต้องรอจนกว่ามันจะเสร็จ ในระหว่างนั้นมาคลิก save ด้วย เพราะมันไม่มีการบันทึกอัตโนมัติ ตอนนี้มาดูวิดีโอกัน นี่คือ URL เราอยู่ตรงนี้ และคุณเห็นว่าตอนนี้มันมีชื่อเรื่องอยู่ด้านบนและมีคำบรรยายด้วย ดังนั้นตอนนี้เราสามารถเก็บมันลงใน Google Sheet ได้ เพราะนี่คือวิดีโอที่เสร็จสมบูรณ์ และมันพร้อมแล้ว เราก็แค่คลิก test แล้วมันจะถูกบันทึกไปยังตำแหน่งนี้ เยี่ยม

ตอนนี้กลับไป ข้อควรทราบอย่างหนึ่ง ถ้าคุณใช้ JSON2Video ในแบบฟรี คุณจะเห็นลายน้ำ (watermark) สองสามจุดในวิดีโอนี้ และเพื่อกำจัดมัน คุณต้องไปที่ credits แล้วตรงนั้นคุณต้องคลิก top up with credits แล้วซื้อแผนเติมเงินหรือแผนสมาชิกแบบใดแบบหนึ่ง แต่ผมใช้แบบเติมเงิน ซึ่งให้เครดิตจำนวนมาก และมันใช้ได้กับวิดีโอมากกว่า 700 เรื่อง ดังนั้นนั่นเยอะมาก นั่นเป็นสิ่งที่ควรจำไว้เมื่อคุณต้องการวิดีโอที่ไม่มีลายน้ำ

ตอนนี้เรามาต่อกับ Telegram response ตรงนี้ นี่เป็นเพียงข้อความตอบกลับที่ผมได้รับการยืนยัน ดังนั้นแค่ตรวจสอบให้แน่ใจว่าบัญชี Telegram เชื่อมต่อกับบอทที่ถูกต้อง เมื่อผมเปิดอันนี้ คุณจะเห็นว่าผมได้รับคำบรรยาย และได้รับ URL วิดีโอ และเพื่อให้เห็นวิดีโอด้วย ผมต้องเชื่อมต่ออันนี้ด้วย อันนี้จะส่งวิดีโอตรง ๆ มาให้ผมที่นี่ อย่างที่คุณเห็น ดังนั้นผมจึงควบคุมได้เต็มที่ว่าอะไรจะถูกสร้างและเผยแพร่ แล้วจากนั้นเราก็ไปที่ขั้นตอนถัดไปซึ่งเกี่ยวกับการเผยแพร่วิดีโอ
