## คำแปลเต็ม

ในวิดีโอนี้ ผมจะอธิบายและโชว์ให้คุณเห็นว่าโมเดล Claude ตัวไหนจะทำงานดีที่สุดสำหรับคุณ ผมจะแจกแจงโมเดลสามตัวของ Anthropic ซึ่งตอนนี้คือ Opus 4.7 ที่เป็นตัวท็อป, Sonnet 4.7 และ Haiku 4.5 ผมจะอธิบายแต่ละโมเดลว่าโดยหลักแล้วคุณควรใช้ตัวไหน

มีสามตัวใช่ไหมครับ อย่างที่ผมเพิ่งบอก Opus, Sonnet และ Haiku แต่ละตัวทำหน้าที่ต่างกัน เหมือนที่ผมเคยอธิบายในบทเรียนก่อนหน้า คุณสามารถเข้ามาที่แชทแล้วเปลี่ยนโมเดลระหว่างตัวที่คุณอยากใช้ได้ แต่จะรู้ได้ยังไงว่าควรใช้ตัวไหน นี่คือคำถามสำคัญครับ

ถ้าคุณเป็นคนที่... ก่อนที่ผมจะพูดถึงสิ่งที่คุณทำได้ คุณยังสามารถเข้าไปที่ models overview เพื่อดูการเปรียบเทียบประสิทธิภาพได้ด้วย Anthropic ทำไว้ให้เสมอ คุณสามารถไปที่ platform.claude.com แล้วมันจะแจกแจงให้คุณเห็นว่าสองโมเดลนี้ต่างกันยังไง ผมไม่อยากใช้เวลากับเรื่องนี้มาก มันไม่ได้สำคัญขนาดนั้นจริง ๆ

ผมใช้ Opus 4.7 เป็นหลักอยู่แล้ว แต่ถ้าคุณพยายามประหยัดเงิน มันอาจช่วยคุณได้ โอเค มาดู Opus กันก่อน มันเป็นโมเดลที่แพงที่สุด มีค่าใช้จ่าย input $5 และ output $25 ต่อหนึ่งล้าน tokens ซึ่งเราได้อธิบาย tokens ไปแล้วในวิดีโอก่อน ไปดูได้เลยครับ ทุกหนึ่งล้าน tokens เสียค่าใช้จ่าย $5 และสำหรับหนึ่งล้าน tokens ของ output เสีย $25 มันแพงมาก และมันคือโมเดลที่ดีที่สุดในโลก ไม่มีอะไรใกล้เคียงเลย ไม่มีอะไรที่ ChatGPT สร้างได้ หรือ Gemini สร้างได้ มันคือที่สุดจริง ๆ ดูจาก benchmark ทั้งหมดสิครับ มันดีที่สุด และเหตุผลที่มันดีที่สุด เพราะมันทำงานใช้เหตุผลที่ยากที่สุดและงานเขียนโค้ดที่ซับซ้อนที่สุด

ถ้าคุณเป็นมือใหม่ และไม่ได้นั่งคิดว่าฉันต้องเขียนโค้ด แต่แค่พยายามคิดว่าจะเริ่มส่งอีเมล จัดการชีวิต และทำระบบอัตโนมัติยังไง คุณก็ไม่จำเป็นต้องใช้โมเดลระดับสูงขนาดนั้น ถ้าคุณไม่ได้ทำโปรเจกต์เยอะและใช้แพ็กเกจ Max คุณก็ใช้ Opus 4.7 ได้เลย ไม่มีอะไรห้ามคุณ และนั่นคือสิ่งที่ผมทำจริง ๆ ผมไม่เคยเปลี่ยนโมเดลเลย

แต่สิ่งที่ Opus จะทำคือ มันดีที่สุด ทำงานยากที่สุด และแม่นยำสำหรับงานที่ต้องการความละเอียด แต่มันแพงที่สุด สิ่งที่ผมชอบทำเป็นการส่วนตัวตอนสร้างโปรเจกต์ใหญ่ คือผมใช้ Opus เหมือนเป็นสมอง ผมให้มันคิดแทนสมอง เวลาผมกำลังคิดและวางแผน ผมจะมาที่ Opus 4.7 ตรงนี้ แล้วให้มันคิดทั้งเรื่อง ให้มันวางแผนทุกอย่างทุกจุด เพราะจากนั้นผมจะสลับไปใช้ Sonnet ได้ พอได้แผนทั้งหมดแล้ว นั่นคือตอนที่ผมจะไปใช้ Sonnet

เพราะ Sonnet คือความสมดุลที่ดีระหว่างความสามารถสูง มันไม่สุดทางด้านไหน แต่แข็งแรงมากสำหรับงานระบบอัตโนมัติ มันมีความสมดุลดีที่สุดระหว่างความเร็วและคุณภาพ และมันดีที่สุดสำหรับงานธรรมดาแบบ default ที่ทำซ้ำ ๆ ได้ เช่น สมมติคุณมี Claude skill ที่ตั้งไว้ ซึ่งผมจะอธิบายทีหลังในคอร์สนี้ มันอ่านข้อมูลของคุณแล้วสรุปย่อให้คุณทุกวัน งานแบบนั้นเป็นขั้นตอนที่ไม่ต้องคิดมากใช่ไหมครับ? เหมือนผมเข้าไปในแอป แล้วให้สรุปย่อเดิมทุกวัน คุณไม่ต้องคิดมันเลย

โมเดลก็เหมือนกัน ผมสามารถให้งานที่ทำซ้ำ ๆ กับ Sonnet ได้ แล้วมันจะถูกกว่ามาก มันเสียแค่ $3 ต่อ input และ $15 ต่อ output เทียบกับ $5 และ $25 ของ Opus ดังนั้นผมจะประหยัดเงินค่าการใช้งานได้เยอะมาก สิ่งที่ผมชอบทำคือ คิดผ่านปัญหาทั้งหมด โปรเจกต์ทั้งหมด และทุกอย่างที่ใหญ่ ๆ ที่ผมจะทำด้วย Opus ก่อน แล้วให้ Sonnet สร้างทุกอย่างออกมาให้ เพราะผมให้แผนเต็ม ๆ ไปแล้ว มันแค่ต้องลงมือทำ

แล้วก็มี Haiku ผมเองไม่เคยใช้มันเลยจริง ๆ แต่มันเป็นตัวที่เน้นความเร็วมาก และทำงานที่ถูกมาก ผมพูดถึงงานที่ตรงไปตรงมาสุด ๆ แบบที่ลิงยังทำได้ มันต้องง่ายมาก ๆ เป็นระบบอัตโนมัติที่ตรงไปตรงมามากที่ลิงทำได้ถ้าคุณสั่งมัน มันโง่หน่อยแต่ถูก ดังนั้นมันจะประหยัดเงินให้คุณเยอะ ผมไม่เคยใช้มันเลย

สรุปทั้งหมดนี้ก็คือ ถ้าคุณมีแผนที่ใหญ่พอ ถ้าคุณใช้ Max หรือ Max Pro และคุณไม่ใช่คนที่สร้างซอฟต์แวร์ทั้งระบบ คุณก็ใช้ Opus 4.7 ไปเลย ทุกอย่างที่ Opus 4.7 ทำได้ ทุกอย่างที่ Sonnet และ Haiku ทำได้ Opus ทำได้ดีกว่า แค่นั้นเอง เหตุผลเดียวที่คุณจะสลับโมเดลก็เพื่อประหยัดเงินค่าการใช้งานและ API tokens จริง ๆ นี่คือทั้งหมดของการอธิบาย Opus 4.7, Sonnet 4.7 และ Haiku 4.5 ครับ ถ้ามีคำถามอะไร บอกผมได้ในคอมมูนิตี้
