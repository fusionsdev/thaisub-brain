## คำแปลเต็ม

ว่าไงครับทุกคน? ในวิดีโอนี้ ผมจะโชว์วิธีตั้งค่า Claude และแพ็กเกจราคาที่คุณต้องใช้ต่อไป เพื่อให้คุณเข้าใจชัดเจนว่าควรเลือกแบบฟรี Pro หรือ Max ถ้าอยากดูทั้งหมด ก็แค่ไปที่ claude.com/pricing แล้วคุณจะเห็นแพ็กเกจ Pro และ Max รวมถึงทีม (Teams) และ API

API เอาไว้สำหรับกรณีที่คุณใช้งานนอกแอป Claude แล้วยังอยากใช้โมเดล — แต่คุณไม่จำเป็นต้องใช้มัน ถ้าคุณเป็นทีม หรือสมมติว่าคุณเป็นเจ้าของธุรกิจที่มีพนักงานหลายคน แล้วอยากให้ทุกคนใช้บัญชี Claude ของคุณ คุณก็เลือกแพ็กเกจทีมได้ ซึ่งเหมาะกับทีมประมาณ 5 ถึง 150 คน โดยคิดราคาต่อคน และแพ็กเกจ premium ก็ $100 เพื่อความจุที่มากขึ้น 5 เท่า แล้วคุณก็จะได้ฟีเจอร์ระดับ enterprise อีกด้วย คุณคลิกดูได้เลย

แต่สำหรับพวกคุณส่วนใหญ่ จะมีบัญชีฟรี บัญชี Pro และบัญชี Max ครับ และที่คุณอาจไม่เห็นคือ Max 20 เท่า ราคา $200 ผมเดาว่าเขาซ่อนไว้ด้วยเหตุผลบางอย่าง แต่คุณคงไม่อยากใช้แบบฟรี เพราะมันจะทำงานอะไรไม่สำเร็จ

ที่จริงแล้ว ปัญหาอยู่ที่การเลือกระหว่าง Pro กับ Max ครับ ถ้าคุณใช้ Pro คุณจะได้ปริมาณการใช้งาน (usage) ที่จำกัด ถ้าพวกคุณเคยเห็นผม หรือเห็นคนอื่นบ่นเรื่องปริมาณการใช้ Claude นั่นเป็นเพราะว่าแพ็กเกจที่ถูกกว่า คุณจะได้ไม่มากพอ โมเดลนี้เป็นเครื่องมือที่ทรงพลังที่สุดบนโลก เขาไม่ยอมให้คุณใช้เต็มที่ด้วยแพ็กเกจต่ำๆ ผมจะลงรายละเอียดว่าการใช้งานมันทำงานยังไงในอีกวิดีโอหนึ่ง แต่ที่คุณต้องรู้คือ ถ้าคุณเป็นมือใหม่ คนที่เขียนอีเมล เขียนเอกสาร และไม่ได้สร้างโปรเจกต์หรือแอปทั้งตัว ผมแนะนำให้เริ่มด้วย Pro ก่อน ถ้าคุณมั่นใจว่าจะไม่ได้ใช้เยอะมาก ก็เริ่มด้วย Pro ได้เลย คุณอัปเกรดเป็น Max ทีหลังได้เสมอ

แต่ถ้าคุณเป็นคนที่สร้างผลิตภัณฑ์เยอะ ทำ automation เยอะแบบในคอร์สนี้ทั้งหมด ผมแนะนำให้ใช้บัญชี Max ครับ ส่วนตัวผมใช้แพ็กเกจ Max ราคา $200 ต่อเดือน ผมไม่เคยใช้จนหมดปริมาณเลย มันคุ้มค่ากับการลงทุนแน่นอน มันคือการลงทุนที่ดีที่สุดในชีวิตผม เพราะผมเปลี่ยน Claude ให้ทำงานหลายอย่าง มันคุ้มกับปริมาณที่จ่ายไป แต่ถ้าคุณเป็นมือใหม่ เพิ่งเริ่มใช้ Claude ผมแนะนำ Pro ถ้าคุณใช้ Claude มาระยะหนึ่งแล้ว และเริ่มเก่งขึ้นเรื่อยๆ ผมแนะนำให้ใช้ Max Plan

ต่อไปคือการดาวน์โหลดและสมัครใช้งาน ง่ายมากครับ แค่เข้าไปที่ claude.ai แล้วเข้ามา แล้วคุณก็เลือก continue with Google หรือกรอก Gmail แล้วมันจะพาไปที่ claude.ai ซึ่งดูเหมือนผมต้องสมัครก่อน ผมจะล็อกอินให้ดูเร็วๆ ตรงนี้ มันจะพาผมผ่านขั้นตอนต่างๆ แล้วพอสมัครเสร็จ คุณจะเจอหน้าจอแบบนี้ ซึ่งคือ Claude ถ้าคุณเห็นหน้านี้ แปลว่าคุณล็อกอินเข้า Claude แล้ว

นี่คือเวอร์ชันเดสก์ท็อปจริงๆ หรือจะเป็นเว็บก็ได้ ถ้าจะดาวน์โหลดเวอร์ชันเดสก์ท็อป ให้ไปที่มุมล่างซ้าย คลิก Get Apps แล้วระบบจะถามตามคอมพิวเตอร์ของคุณให้ติดตั้งเดสก์ท็อป ผมใช้ Mac OS ก็แค่คลิก Download for Mac แล้วคุณจะเห็นไฟล์ดาวน์โหลด จากนั้นมันจะแนะนำขั้นตอน แต่คุณแค่คลิกมันเมื่อดาวน์โหลดเสร็จ แล้วลากแอปเข้าไปในโฟลเดอร์ตรงนี้

สิ่งที่ผมชอบทำคือ ผมจะเอาแอปไปวางไว้ตรงนี้ เพราะผมใช้มันทุกวัน อยากให้เข้าถึงง่าย คลิกได้สะดวก แล้วก็วางลงบนเดสก์ท็อปของคุณ สิ่งที่ต้องทำเพื่อเปิดมัน ก็แค่คลิกที่แอป แล้วมันจะเด้งขึ้นมา เนื่องจากผมล็อกอินไว้แล้ว มันน่าจะถามให้คุณล็อกอิน แล้วคุณก็จะเข้ามาอยู่ในพื้นที่แบบนี้

นี่คือวิธีตั้งค่า Claude Code และนี่คือรายละเอียดแพ็กเกจทั้งหมด ถ้าพวกคุณยังลังเลว่าจะเลือกแพ็กเกจไหน โปรดคอมเมนต์บอกพวกเรา แล้วผมจะตอบให้ความช่วยเหลือ แล้วเจอกันในวิดีโอหน้านะครับ
