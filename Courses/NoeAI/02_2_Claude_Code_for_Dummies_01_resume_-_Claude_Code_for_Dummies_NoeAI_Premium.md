## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่บทเรียนคลังคำสั่งนะครับ คำสั่งพวกนี้จริง ๆ แล้วง่ายมากเลยครับ ผมจะมาโชว์คำสั่งง่าย ๆ ใน Claude Code ให้ทุกคนดูนะครับ เพื่อให้ทุกคนได้เห็นเครื่องมือต่าง ๆ และเข้าใจการทำงานของมันกันครับ

เดี๋ยวผมจะเปิดโฟลเดอร์ตรงนี้นะครับ อ้อ ผมเปิดอีกหน้าต่างนึงไว้แล้ว งั้นเปิดโฟลเดอร์ school community ละกันนะครับ จากนั้นพอเราจะเริ่ม เราก็แค่พิมพ์ blog เพื่อเริ่ม session ครับ

อันนี้ตลกดีนะครับ อันนี้เป็นคำสั่งแรกที่ผมเคยโชว์ทุกคนเลยครับ มันเรียกว่า resume function หรือ command resume ครับ สิ่งที่คำสั่งนี้ทำคือ มันให้คุณเข้าถึงประวัติการสนทนาที่ผ่านมาของคุณได้ครับ ถ้าผมคลิกดู ผมก็จะเห็นแชททั้งหมดที่ผมเคยทำไว้ก่อนหน้านี้ครับ

ใน Claude Desktop คุณจะเห็นว่ามันมีแถบข้างที่คุณสามารถดูทุกอย่างที่คุณเคยทำ และคุณสามารถเข้าถึงมันได้โดยตรงครับ แต่ฟีเจอร์นั้นไม่มีใน terminal นะครับ แต่สิ่งที่คุณทำได้คือ คุณพิมพ์ slash แล้วคุณก็จะมีรายการขึ้นมาใช่ไหมครับ? ผมก็สามารถดึงขึ้นมาได้ครับ ลองดูนะครับ ผมดึงอันนี้ตรงนี้ขึ้นมาได้ครับ กด Enter นี่เป็นหนึ่งในบทเรียนที่เราทำกันก่อนหน้านี้ในหมวด agent ครับ

ผมสามารถดึงมันขึ้นมาได้เรื่อย ๆ เลยครับ พิมพ์ resume แล้วก็เลือกอันอื่นต่อได้อีก มีให้เลือกเยอะแยะเลยครับ

นั่นแหละครับ resume command มันก็แค่ให้คุณกลับไปทำงานต่อจากเซสชันที่ค้างไว้ได้ครับ
