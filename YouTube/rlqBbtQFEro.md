## ประเด็นหลัก

- MiniMax ปล่อย Code 2.0 ซึ่งเป็นการ rebuild สถาปัตยกรรมทั้งหมดใหม่บนเฟรมเวิร์กโอเพนซอร์ส Pi Agent ไม่ใช่แพตช์เล็ก ๆ
- จุดขายหลักคือ AI ที่ทำงานเวิร์กโฟลว์ยาว ๆ หลายขั้นตอนได้จนเสร็จ โดยไม่สะดุดหรือพังกลางคันเหมือนรุ่นก่อน
- Pi Agent ถูกออกแบบมาสำหรับเวิร์กโฟลว์ที่ขับเคลื่อนด้วยเครื่องมือ (tool-driven) ไม่ใช่แค่การสนทนา ทำให้ AI เก่งขึ้นในการทำงานให้เสร็จ ไม่ใช่แค่ตอบคำถาม
- ฟีเจอร์ใหม่ที่เปิดใช้งานแล้ว: Agent teams (ทีมเอเจนต์), remote control, เบราว์เซอร์ในตัว, goal mode, งานตามกำหนดเวลา, หน่วยความจำถาวร และสกิลที่ใช้ซ้ำได้
- Agent teams แยกบทบาทคนสร้างกับคนรีวิวออกจากกัน (อ้างแนวคิด "กรรมการกับผู้เข้าแข่งขัน" จากบล็อก MiniMax) ทำให้ได้ระบบควบคุมคุณภาพจริง
- Assistant memory ช่วยให้ไม่ต้องอธิบายบริบทใหม่ทุกครั้ง ส่วน Skills เปลี่ยนกระบวนการที่ทำซ้ำได้ให้เป็นสกิลที่รันซ้ำได้คุณภาพเท่าเดิม
- Remote control ตั้งแต่เวอร์ชัน 3.0.52 ควบคุมและอนุมัติขั้นตอนงานจากโทรศัพท์ได้
- เวิร์กโฟลว์ตัวอย่างที่ 1: เครื่องผลิตคอนเทนต์รายสัปดาห์ เปลี่ยนข่าว AI automation หนึ่งสัปดาห์ให้เป็นคอนเทนต์เต็มสัปดาห์ (YouTube, LinkedIn, วิดีโอสั้น, อีเมล)
- เวิร์กโฟลว์ตัวอย่างที่ 2: ซีเควนซ์ออนบอร์ด 7 วันสำหรับสมาชิกใหม่ของ AI Profit Boardroom
- เปลี่ยนวิธีคิดจาก "ให้ AI ทำงานทีละงาน" เป็น "ตั้งผลลัพธ์ (outcome) ให้ AI" แทน
- โปรโมต AI Profit Boardroom (สมาชิก 3,800 คน, คอลปรึกษารายสัปดาห์, คลังพรอมป์, แผนที่สมาชิก) และ AI Success Lab (ฟรี, สมาชิก 87,000 คน, มีโน้ตและพรอมป์จากวิดีโอนี้)

## ความเห็นสรุป

วิดีโอนี้เป็นการรีวิวแบบโปรโมตเชิงพาณิชย์ที่อธิบาย MiniMax Code 2.0 ได้กระชับและเข้าใจง่าย โดยเฉพาะแนวคิด Agent teams กับหน่วยความจำถาวร และให้พรอมป์ตัวอย่างที่ใช้จริงได้ทันที อย่างไรก็ตาม เนื้อหาครึ่งหลังเป็นโฆษณาชวนเข้าร่วมคอมมูนิตี้ AI Profit Boardroom และ AI Success Lab ควรชมแบบจับประเด็นทางเทคนิค แล้วประเมินด้วยตัวเองก่อนตัดสินใจสมัครสมาชิก
