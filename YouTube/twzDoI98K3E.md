## ประเด็นหลัก

- Hermes Bot Mode ฟีเจอร์ใหม่จาก Nous Research ปล่อยมา 5 วันที่แล้ว ติดตั้งภายใน 60 วินาที แต่แทบยังไม่มีใครพูดถึง
- Hermes agent คือ autonomous agent ที่มีวงจรการเรียนรู้ สร้างและปรับปรุง skills เอง สะสมความจำข้าม session ยิ่งใช้นานยิ่งรู้จักวิธีทำงานของคุณ
- รองรับการใช้งานหลากหลาย ทั้ง command line, แอปเดสก์ท็อป, Telegram, Discord, Slack, WhatsApp และอื่นๆ รวมกว่า 20 แพลตฟอร์มจาก gateway เดียว มี tools ในตัว 60 กว่าอย่าง รองรับ MCP และเปิด source ภายใต้ MIT license
- จุดเด่นคือระบบ profiles แต่ละ profile คือ home directory แยก มี config, soul file, memory, sessions, skills และ database ของตัวเอง ทำให้ agent แต่ละตัวแยก state กันอย่างแท้จริง
- Bot Mode เป็น desktop plugin ที่เปลี่ยน profiles ให้เป็นรายชื่อ agent ที่มีชื่อ มีแชต, avatar, บุคลิก และตารางเวลาของตัวเอง ไม่ต้องแก้ core ไม่มี daemon แฝง ไม่กินพื้นที่เพิ่ม
- soul file คือตัวตนของ agent ถูกวางในตำแหน่งแรกของ system prompt และแทนที่ตัวตน default ทั้งหมด
- มีแผง routines สำหรับงานซ้ำของแต่ละ agent ขับเคลื่อนโดย Hermes scheduler เบื้องหลังคือ cron jobs ธรรมดาที่ตั้งชื่อตาม agent
- ไฮไลต์คือการส่งข้อความระหว่าง agent ผ่าน agent inbox ทุก agent มีกล่องข้อความถาวร ส่งงานหากันได้ด้วยการ mention @ชื่อ agent
- การติดตั้ง: ดาวน์โหลด Hermes desktop installer, รัน Hermes setup พร้อม flag portal แล้ววาง plugin ลงในโฟลเดอร์ plugins กด Ctrl K เพื่อ reload
- เคล็ดลับ 5 ข้อ: รัน Hermes update ก่อน, ห้าม process สองตัวชี้ profile เดียวกัน, ลบ agent ต้องใช้คำสั่ง Hermes profile delete, การส่งข้อความเป็นแบบต่อการเรียกใช้ และเริ่มด้วย agent สองตัวก่อน
- เจ้าของช่องทดลองจริง: สร้างเครื่องคิดเลข HTML หน้าเดียวสำหรับ AI Profit Boardroom และ landing page สำหรับข้อเสนอตรวจ SEO ฟรี ด้วย prompt เดียวได้ไฟล์เดียว
- ระบบนิเวศ AI Profit Boardroom มี Agent OS ในตัว พร้อม walkthrough, คอล coaching สด, roadmap 30 วัน และคลัง prompts ให้เริ่มต้นได้ทันที
