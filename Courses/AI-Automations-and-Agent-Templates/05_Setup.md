## บทนำ
วิดีโอนี้สอนตั้งค่าระบบอัตโนมัติบน Make.com ที่รับหัวข้อหลัก (niche) ของคุณเพียงหัวข้อเดียว แล้วสร้างหัวข้อย่อยใหม่ ๆ ไม่ซ้ำกันในทุกครั้ง ระบบจะค้นหาวิดีโอ YouTube ที่กำลังมาแรง สร้างบทถอดเสียงและคำบรรยาย ใช้ ElevenLabs พากย์เสียง สร้างวิดีโอด้วย Creatomate แล้วเผยแพร่ไปยังแพลตฟอร์มโซเชียลมีเดียที่คุณเลือก พร้อมบันทึกข้อมูลทั้งหมดลง Google Sheets

## คำแปลเต็ม

ในการตั้งค่าระบบอัตโนมัติ ให้ไปที่ปุ่มด้านล่างวิดีโอนี้ คลิกที่ Download blueprint จากนั้นไปที่บัญชี Make ของคุณแล้วคลิก Create a New Scenario จากนั้นคลิกที่ More แล้วเลือก Import และเลือกไฟล์ blueprint ที่เพิ่งดาวน์โหลดมา

ตอนนี้เราต้องตั้งค่าโมดูลบางส่วน เราจะเริ่มจาก webhook โดยคลิกที่ Add แล้วพิมพ์ชื่ออะไรก็ได้ ไม่สำคัญเท่าไร ขอแค่ตั้งค่าให้เรียบร้อย จากนั้นเราต้องคัดลอกที่อยู่ (address) ไปไว้ในคลิปบอร์ด

จากนั้นกลับไปที่เทมเพลต Google Sheet ที่อยู่ด้านล่างวิดีโอนี้ คลิกแล้วเลือก Make a copy จะตั้งชื่อใหม่ก็ได้ แล้วบุ๊กมาร์กไว้เพื่อให้เปิดใช้ได้สะดวก

ต่อไปกลับมาที่ webhook เราคัดลอกลิงก์นี้ แล้วไปที่ Apps Script ตรงนี้เราต้องวางลิงก์ลงในบริเวณนี้ อย่างที่เห็น วางลงตรงนี้ จากนั้นยังต้องแก้ไขอีกจุดหนึ่งคือใส่ที่อยู่อีเมลของคุณ หากคุณต้องการใช้ TikTok เพราะ TikTok ไม่มีการเชื่อมต่อโดยตรง ถ้าต้องการใช้งาน ระบบอัตโนมัตินี้จะส่งอีเมลพร้อมลิงก์ไฟล์วิดีโอมาให้คุณ แล้วคุณค่อยอัปโหลดขึ้น TikTok เอง ถ้าต้องการให้ส่งอีเมลก็ระบุอีเมลไว้ตรงนี้ แล้วอีเมลนี้จะใช้สำหรับส่วนนี้ของคุณ ถ้าคุณไม่ได้ใช้ TikTok หรือไม่ต้องการใช้ ก็ข้ามส่วนนี้ไปได้เลย

ตอนนี้กลับมาที่ระบบอัตโนมัติของเรา เราตั้งค่าขั้นตอนแรกเรียบร้อยแล้ว ต่อไปต้องตั้งค่า Google Sheets โดยคลิกสร้างการเชื่อมต่อ Google Sheet แล้วคลิก Sign in with Google จากนั้นระบบจะให้เลือกบัญชี Google หากคุณมีหลายบัญชี ให้ลงชื่อเข้าใช้ด้วยบัญชีเดียว ต้องแน่ใจว่าเป็นบัญชีเดียวกับ Google Sheet อันนี้ ถ้าคลิกที่ไอคอนของคุณด้านบน จะเห็นว่าบัญชี Google ที่กำลังล็อกอินอยู่คือบัญชีไหน ต้องแน่ใจว่าใช้บัญชีเดียวกันตอนลงชื่อเข้าใช้ตรงนี้ ผมจะทำขั้นตอนนี้ให้เสร็จแล้วไปต่อ และเมื่อมันขึ้นว่า Google ก็แสดงว่าทุกอย่างเรียบร้อย

สิ่งต่อไปที่ต้องใช้คือ Google Sheet ID ที่ถูกต้อง ผมจะลบค่านี้ออกแล้ววาง Google Sheet ID ของตัวเองที่เตรียมไว้ จากนั้นมันจะโหลดหัวข้อและหัวข้อย่อยขึ้นมา ตรงนี้เราไม่ต้องตั้งค่าอะไรเพิ่ม ไปที่ส่วนถัดไปกัน

Google Sheet อีกอันหนึ่ง เลือกบัญชี Google ของคุณ จากนั้นวาง Google Sheet ID ที่ได้จากส่วนนี้ของ URL สเปรดชีต แล้วคลิก OK

ต่อไปถึงโมดูล AI ตัวแรก คลิก Create connection คุณต้องมี API key และ organization ID จาก OpenAI ผมสอนวิธีได้มาในบทเรียนเทคนิค (technical tutorials) ที่อธิบายวิธีขอ OpenAI API key ให้ทำตามนั้นถ้ายังไม่มีการเชื่อมต่อ OpenAI แล้วใส่คีย์ตรงนี้ ถ้ามีอยู่แล้วก็เลือกจากเมนูแบบเลื่อนลงได้เลย

ตรงนี้จะเห็นว่าเราต้องรันระบบอัตโนมัติก่อน เราจะยกเลิกการเชื่อมต่อออกไปก่อน คลิก Save จากนั้นกลับไปที่โค้ด Apps Script ตรงนี้ต้องแน่ใจว่าเลือกฟังก์ชัน rotate and send data แล้วคลิก Run นี่เป็นสิ่งที่ต้องทำ เพราะต้องรันโค้ดนี้แล้วทำขั้นตอนอนุญาต (authorization) ให้เสร็จ แค่คลิก OK ไปสองสามครั้งก็เสร็จ

ตอนนี้เราต้องกระตุ้นการทำงานจริง เราคลิก Wait for new แล้วรัน จากนั้นข้อมูลจะถูกส่งจากจุดนี้ไปยัง webhook ตรงนี้อย่างที่เห็น และตอนนี้เราสามารถเข้าไปดูได้ว่าตัวแปรต่าง ๆ จับคู่กันถูกต้องหรือไม่ ตรงนี้เต็มแล้ว เรียบร้อยดี

ต่อไปเชื่อมต่อโมดูล Google Sheet อีกครั้ง เลือกบัญชี Google connection ของคุณ ตรงนี้ต้องใส่ Sheet ID ของตัวเองอีกครั้ง OK จากนั้นเลือกการเชื่อมต่อ AI ที่ตั้งไว้ก่อนหน้านี้ได้เลย เพราะตั้งไว้ครั้งเดียวแล้วใช้ได้ตลอด ตรงนี้เหมือนเดิม เลือก OpenAI ของผม OK ตรงนี้ไม่ต้องตั้งค่าอะไร

คุณต้องมี Pexels API key เพื่อให้ได้มา ผมมีบทเรียนในส่วน technical tutorials ที่สอนวิธีขอ Pexels API key ให้ไปขอมาแล้ววางตรงนี้ แล้วคลิก OK ไปต่อยังโมดูลถัดไป ตรงนี้ไม่ต้องตั้งค่าอะไร ตรงนี้ก็ไม่ต้องตั้งค่า เพราะอ้างอิงกับค่าที่ตั้งไว้แล้ว ทำงานได้เลย

ต่อไปเป็น ElevenLabs ตรงนี้ต้องขอ API key เช่นกัน หาได้จากบทเรียนในส่วน technical tutorials ที่สอนวิธีขอ 11 Labs API key ให้กรอกให้ครบแล้วคลิก Save ส่วนการเชื่อมต่อเสียง (voice) คุณเลือกเสียงได้จากบัญชี 11 Labs ของคุณ เข้าไปลองฟังเสียงต่าง ๆ เพื่อหาเสียงที่ชอบได้ โดยในบัญชี 11 Labs จะเห็นส่วน Voices ไล่ฟังเสียงต่าง ๆ ได้ ผมจำได้ว่าเลือกเสียง George ไว้ เห็นไหม นี่คือเสียง George ที่เลือกไว้ ฟังตัวอย่างได้ แล้วเลือกเสียงที่ชอบใน Make automation จากนั้นคลิก OK

ต่อไปเป็น Google Drive ต้องลงชื่อเข้าใช้ด้วยบัญชี Google เดิมที่ใช้ก่อนหน้านี้ ทำขั้นตอนลงชื่อเข้าใช้ให้เสร็จด้วยบัญชีเดียวกัน จากนั้นเข้าไปใน Google Drive ตั้งโฟลเดอร์เฉพาะ แล้วเลือกตำแหน่งโฟลเดอร์ตรงนี้ มันจะค้นหาในบัญชี Drive ของคุณและแสดงโฟลเดอร์ต่าง ๆ ให้เลือก ผมเลือกโฟลเดอร์ที่เตรียมไว้แล้ว คลิก OK จากนั้นแค่เลือกบัญชี คลิก OK เลือกบัญชี คลิก OK

ต่อไปเป็น Creatomate ต้องตั้งค่าบัญชี Creatomate เช่นกัน เพื่อขอ API key ให้ไปที่ technical tutorials ที่สอนวิธีขอ Creatomate API แล้วกลับมาใส่ตรงนี้แล้วคลิก Save จากนั้นต้องเลือกเทมเพลต ถ้ายังไม่มีต้องสร้างใน Creatomate ก่อน ไปที่ Create new template เลือกขนาดที่กำหนดไว้ล่วงหน้าได้ แล้วปรับแต่งเทมเพลต ผมจะไม่สาธิตส่วนนี้เพราะมีบทเรียนวิธีสร้าง Creatomate video template อยู่แล้ว ไปดูได้ถ้าต้องการความช่วยเหลือ พอตั้งค่าและปรับแต่งเทมเพลตเสร็จแล้ว กลับมาเลือกเทมเพลตที่สร้างจากตรงนี้ได้ แล้วที่เหลือก็ตั้งค่าเรียบร้อย ไม่ต้องทำอะไรเพิ่ม คลิก OK

ต่อไป Google เลือกบัญชี Google Sheet แล้วไม่ต้องทำอะไรเพิ่ม คลิก OK

ต่อไปเป็นโมดูลแพลตฟอร์มโซเชียลมีเดียที่วิดีโอจะถูกเผยแพร่ กับ HTTP module ของ Make ไม่ต้องทำอะไร ต้องเข้าไปที่บัญชีโซเชียลมีเดียเท่านั้น คลิก Create connection จากนั้นระบบจะให้ล็อกอินบัญชี LinkedIn ของคุณ ทำตามขั้นตอนให้เสร็จ พอเชื่อมต่อสำเร็จมันจะแสดงว่าทำงานได้ แล้วเลือกจากเมนูแบบเลื่อนลงได้เลย ตรงนี้ทำเหมือนเดิมกับบัญชีอื่น คลิก Create connection พอเสร็จแล้วจะเห็นแบบนี้ และหน้าตาจะเหมือนกันสำหรับทุกแพลตฟอร์มโซเชียลมีเดีย พอตั้งค่าเสร็จไม่ต้องแก้ไขอะไรอีก แค่คลิก OK

ต่อไปเป็น Instagram for Business ใน Instagram ต้องสร้างบัญชีธุรกิจก่อน แต่ก่อนอื่นต้องไปที่เพจ Facebook และต้องมีเพจ Facebook ที่เชื่อมต่อกับบัญชี Instagram ที่ต้องการโพสต์ วิธีหา: ไปที่ Facebook แล้วสลับโปรไฟล์เป็นเพจ Facebook ของคุณ คลิกตรงนี้ เลือกเพจที่ต้องการเผยแพร่ แล้วคลิกที่เพจ Facebook ของคุณ จากนั้นเลื่อนลงไปที่ Settings และเลื่อนไปด้านล่าง ตรงนี้เขียนว่า Connected accounts เห็นว่าผมเชื่อมต่อกับบัญชี Instagram ไว้แล้ว ถ้ายังไม่ได้เชื่อมต่อจะเห็นปุ่ม Connect คลิก Connect แล้วเลือกบัญชี Instagram ของคุณ พอเสร็จแล้วหน้าตาจะเป็นแบบนี้ จากนั้นกลับไปที่ Make แล้ว Create connection ทำตามขั้นตอนและลงชื่อเข้าใช้ พอเสร็จจะมีหน้าตาคล้ายแบบนี้ มีเมนูแบบเลื่อนลงและตัวเลือกเล็กน้อย แต่ไม่ต้องทำอะไร แค่คลิก OK

กับ Twitter จะต่างออกไปเล็กน้อย ถ้ายังไม่เคยใช้ Twitter ต้องตั้งค่าบัญชี developer ก่อน ผมจะไม่ลงรายละเอียดวิธีทำ หาได้ใน technical tutorials อย่างที่เห็นเรามีโมดูล Twitter สองโมดูล ตรงนี้ต้อง Create connection แล้วไปที่ Show advanced settings แล้วกรอก API key และ API secret ซึ่งหาได้หลังตั้งค่าบัญชี developer บน Twitter เสร็จแล้ว ใต้หัวข้อ Keys and tokens ถ้าคลิก Regenerate จะได้ข้อมูลนี้มา ส่วนโมดูล Twitter อีกอัน คลิกตรงนี้ ใส่ Client ID และ Client secret ซึ่งก็หาได้จากส่วนนี้เหมือนกัน ใส่ได้เลยหลังตั้งค่าบัญชี developer เสร็จ คลิกแล้วจะได้ Client secret ด้วย แล้วคลิกเพื่อเชื่อมต่อ และมีบทเรียนเทคนิคที่ครอบคลุมขั้นตอนเหล่านี้อยู่แล้ว

จากนั้นก็แค่คลิก Create connection เพื่อล็อกอินบัญชี Facebook และทำตามขั้นตอนให้เสร็จ

ตอนนี้คุณแค่ต้องเลือกแพลตฟอร์มโซเชียลมีเดียที่อยากโพสต์จริง ๆ เท่านั้น ถ้าอยากโพสต์ทุกแพลตฟอร์มก็ตั้งค่าตามที่บอก ถ้าอยากโพสต์แค่ Instagram กับ YouTube ก็ลบโมดูลอื่นทิ้งได้ แล้วระบบอัตโนมัติจะเผยแพร่เฉพาะแพลตฟอร์มที่เลือกไว้เท่านั้น

พอตั้งค่านี้เสร็จ ส่วนสุดท้ายคือกลับไปที่โค้ด Apps Script หาได้ในเมนู Extensions แล้วเข้า Apps Script code ตรงนั้นเราจะตั้ง trigger ใหม่ ใช้ฟังก์ชัน rotate and send ที่ต้องการ คลิกที่ Open จากนั้นเลือก Time driven แล้วเลือก Day timer ถ้าเลือกอันนี้จะรันทุกวันในช่วง 7 โมงเช้าถึง 8 โมงเช้า เวลาใดเวลาหนึ่งระหว่างสองช่วงนั้น ก็เลือกได้แม้กระทั่งรายสัปดาห์ เช่นสัปดาห์ละครั้ง จันทร์เวลานี้ ถ้าอยากรันหลายครั้งต่อสัปดาห์ ตั้ง trigger แรกเป็นแบบ week timer เลือกวันจันทร์ แล้วตั้ง trigger อีกอัน เลือกเวลา แล้วเลือก week timer เลือกวันพฤหัสบดี มันก็จะโพสต์ในวันนั้นด้วย ทำแบบนี้ได้หลายครั้งต่อสัปดาห์ตามต้องการ พอตั้งค่าเสร็จ มันจะกระตุ้นระบบอัตโนมัตินี้โดยอัตโนมัติ รันและเผยแพร่วิดีโอโซเชียลมีเดีย

แต่ก่อนหน้านั้นผมแนะนำให้ทดสอบสองสามครั้งก่อน เพื่อให้เห็นผลลัพธ์และปรับแต่งเอาต์พุตของวิดีโอจนกว่าจะพอใจ วิธีทดสอบคือคลิก Run once ผมกดตรงนี้ตอนนี้ไม่ได้ แต่ตอนเริ่มต้นเราเคยทำไปแล้ว คลิก Run once แล้วกลับไปที่ Apps Script เลือกฟังก์ชัน rotate and send แล้วคลิก Run นี่คือวิธีทดสอบว่าระบบรันผ่านหรือไม่ และข้อมูลทั้งหมดจะถูกบันทึกลงในสเปรดชีตนี้

สิ่งแรกที่ต้องระบุก่อนเริ่มคือหัวข้อหลักของคุณ เช่น อาจเป็น selling digital products ถ้านี่คือหัวข้อของผม ลองลบแล้วทดสอบใหม่อีกครั้งเพื่อความถูกต้อง ใส่ niche ของคุณตรงนี้ ใส่ได้หลายหัวข้อ แล้วระบบจะข้ามไปหัวข้อถัดไปโดยอัตโนมัติเสมอ เลือก niche หลัก แล้วระบบจะใช้เป็นแกนหลักเสมอ แล้วสร้างหัวข้อย่อยขึ้นมา อย่างที่เห็น ถ้าคลิก Run ภายในไม่กี่วินาทีจะเห็นหัวข้อย่อยถูกสร้างขึ้น เช่น "creating an effective sales function for digital products" และในแต่ละครั้งระบบจะสร้างหัวข้อย่อยใหม่ที่ไม่ซ้ำกับที่เคยสร้างแล้ว เป็นไอเดียใหม่ที่ไม่ซ้ำเดิมเสมอโดยอิงจากหัวข้อหลักของคุณ

ถ้าอยากเปลี่ยนหัวข้อ สลับตรงนี้ได้ เช่น เปลี่ยนเป็น email marketing with ChatGPT แล้วถ้ารัน ระบบจะเลือกหัวข้อถัดไปประมาณ email marketing with ChatGPT แต่ถ้าปล่อยหัวข้อเดิมไว้ มันก็จะสร้างหัวข้อย่อยใหม่จากหัวข้อเดิม เช่น ถ้ารันโดยปล่อยหัวข้อ email with ChatGPT ไว้ ระบบจะสร้างหัวข้อย่อยอีกอันที่เกี่ยวกับ email marketing with ChatGPT ซึ่งไม่ซ้ำกับที่เคยครอบคลุมมาแล้ว ระบบนี้ทำแบบนี้ได้ไม่มีที่สิ้นสุดจนกว่าคุณจะเปลี่ยนหัวข้อ นี่คือสิ่งที่ทำให้ระบบนี้ทรงพลัง

ตรงนี้ยังมีเทมเพลตให้เล่นปรับแต่งได้ นี่คือเทมเพลตสำหรับบทถอดเสียง (transcript) และคำบรรยาย (captions) ปรับแต่งได้ ปล่อยให้ระบบอัตโนมัติสร้างได้เลย เห็นไหมว่ายังรันอยู่ และรายละเอียดทั่วไป คำบรรยายจะถูกบันทึกตรงนี้ URL จะถูกบันทึกตรงนี้ และคุณสามารถปรับแต่งเอาต์พุตได้ ในแต่ละครั้งระบบจะเลือกสไตล์เทมเพลตที่ต่างกัน คุณจึงมีเทมเพลตหลากหลายประเภทอยู่เสมอ เพิ่มเทมเพลตใหม่ได้ ถ้าเจอตัวอย่าง transcript และ captions ที่พิสูจน์แล้วว่าดีจาก Instagram หรือ YouTube ก็วางลงตรงนี้ได้ แล้วระบบจะใช้เป็นเทมเพลตในรอบถัดไป

ถ้าเข้าไปดู จะเห็นว่า transcript ถูกส่งเข้ามาโดยอัตโนมัติแล้ว เช่น รอบนี้ระบบใช้ transcript อันนี้ ส่วนอันนี้เป็นอันที่สอง และเมื่อรันครั้งถัดไปมันจะเลือกอันนี้เป็นเทมเพลต ระบบจะสลับไปมาระหว่างเทมเพลตและสไตล์ต่าง ๆ เสมอ แน่นอนว่าเปลี่ยนได้ แค่ต้องแน่ใจว่า transcript มีห้าประโยคเสมอ เพราะนี่คือสิ่งสำคัญมาก เพราะนี่คือเอาต์พุตที่เห็นใน Creatomate ซึ่งมีข้อความห้าส่วน แต่ละส่วนหนึ่งประโยค และแต่ละส่วนจับคู่กับประโยคใน transcript ดังนั้นสำคัญมากที่ถ้าจะแก้ไข ต้องแน่ใจว่ามีห้าประโยคหรือห้าบรรทัดพอดี นี่คือสิ่งเดียวที่ต้องจำไว้ตอนแก้เทมเพลต transcript ส่วนตรงนี้ไม่สำคัญ จะสร้างเทมเพลตคำบรรยายแบบไหนก็ได้ตามต้องการ
