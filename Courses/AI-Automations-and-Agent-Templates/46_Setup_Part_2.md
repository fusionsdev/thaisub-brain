## บทนำ
วิดีโอนี้เป็นส่วนหนึ่งของการตั้งค่าระบบอัตโนมัติสำหรับสร้างวิดีโอ TikTok โดยใช้ Perplexity AI เป็นเครื่องมือค้นคว้าออนไลน์ แล้วใช้ OpenAI เขียนสคริปต์ คำบรรยาย และไทเทิลใหม่จากข้อมูลที่ค้นคว้ามา จากนั้นแยกตัวแปรต่าง ๆ และบันทึกผลลัพธ์ลง Google Sheets เพื่อใช้ในขั้นตอนถัดไป

## คำแปลเต็ม

ต่อไปนี้เราจะใช้เครื่องมือที่ชื่อ Perplexity AI ซึ่งเป็นเสิร์ชเอนจินที่ขับเคลื่อนด้วย AI แบบออนไลน์ ที่เราจะนำมาใช้ สิ่งที่คุณต้องมีคือ API key จาก Perplexity และผมก็ได้สอนวิธีขอ API key นี้ไว้แล้วในบทเรียนเทคนิคชื่อ Get API key from Perplexity ดังนั้นคุณแค่วาง API key ลงไป แล้วเลื่อนลงมาตรงนี้ ทุกอย่างดูเรียบร้อยดี มันขึ้นเป็นสีเขียว เราจึงไม่ต้องทำอะไรเพิ่ม

สิ่งที่โมดูลนี้ทำคือ มันจะดูสคริปต์ของวิดีโอ แล้วพยายามหาข้อมูลใหม่ ๆ ที่ไม่ซ้ำใคร และเป็นข้อมูลที่กำลังเป็นกระแสอยู่ในตอนนี้ เกี่ยวข้องกับหัวข้อของวิดีโอที่เรามี เช่น วิดีโอ TikTok ที่กำลังไวรัล ดังนั้นถ้าผมคลิก test ตอนนี้ ระบบก็จะทำการค้นคว้า ซึ่งอาจใช้เวลาสองสามวินาที เพราะมันเข้าถึงฟีเจอร์หลายอย่าง

ส่วนโมดูล cleanup นั้น มันจะทำความสะอาดข้อมูลที่เราได้กลับมาจาก Perplexity คุณจะเห็นว่ามันมักจะรวมเนื้อหาบางอย่าง ซึ่งนั่นเป็นแค่กระบวนการคิด (thought process) ที่มันใช้ในการค้นคว้า เราไม่จำเป็นต้องใช้ส่วนนั้น ผมต้องการแค่ผลลัพธ์สุดท้ายเท่านั้น นั่นคือเหตุผลที่ผมใส่ฟังก์ชันทำความสะอาดนี้ไว้ เพื่อให้ได้เฉพาะคำตอบที่สะอาดแล้ว

ต่อไปเรามีโมดูล AI ของ OpenAI คุณสามารถใช้บัญชีเดิมได้ ถ้าผมเชื่อมต่อไว้แล้วในขั้นตอนก่อนหน้า ตรงนี้จะเป็นการเขียนข้อความที่เราต้องการสำหรับวิดีโอ TikTok ของเรา มันจะใช้ข้อมูลนำเข้าจาก Perplexity แล้วใช้โครงสร้างของสคริปต์วิดีโอต้นฉบับเป็นต้นแบบ เพื่อเขียนใหม่สำหรับหัวข้อที่มันค้นคว้ามา จากนั้นมันก็จะให้ข้อความคำบรรยาย (caption) ซึ่งเป็นข้อความที่เผยแพร่ไปพร้อมกับวิดีโอ และไทเทิลที่แสดงซ้อนบนวิดีโอ แต่ปรับให้เข้ากับหัวข้อใหม่ของเรา และนี่คือสิ่งที่มันควรจะส่งออกมาเป็นผลลัพธ์สุดท้าย ที่ผมจะนำไปใช้สร้างวิดีโอของตัวเองได้

ตอนนี้ผมมีอีกหนึ่งฟังก์ชันที่ใช้แยกตัวแปรต่าง ๆ ออกจากกัน ตรงนี้เรามีทุกอย่างรวมอยู่ในข้อความเดียว แต่ผมต้องการให้มันเป็นสามตัวแปรที่แตกต่างกัน นั่นคือข้อความของผม (my text) สคริปต์วิดีโอ (video transcript) และข้อความคำบรรยาย (caption text) ที่แยกจากกัน เยี่ยมมาก

ผมยังกำหนด video ID ที่ไม่ซ้ำกัน เพื่อเก็บไว้ในฐานข้อมูล Google Sheets ของผม ซึ่งผมเชื่อมต่อไว้แล้ว แต่ผมต้องแก้เฉพาะของผมเท่านั้น เพราะผมมั่นใจแล้วว่าตรงนี้ถูกต้อง จากนั้นเราต้องไปที่ generated posts และตอนนี้เราต้องบันทึกตัวแปรต่าง ๆ เหล่านั้นอีกครั้ง

ตรงนี้เราอยู่ที่ส่วน generated ผมต้องการ template ID เพราะผมรู้ชัดเจนว่าวิดีโอของผมอิงจากเทมเพลตไหน ซึ่งมาจากตอนต้น ๆ ตรงนี้จากส่วน template จากนั้นก็มี topic ซึ่งก็คือผลการค้นคว้าจาก Perplexity นั่นคือคำตอบที่ทำความสะอาดแล้วจาก Perplexity จากนั้นก็ text overlay ซึ่งเรามีผลลัพธ์อยู่ตรงนี้ นั่นคือข้อความของผม สคริปต์วิดีโอของผม และข้อความคำบรรยายของผม ส่วนพวกนี้เรายังไม่จำเป็นต้องใช้ เดี๋ยวจะใช้ในขั้นตอนถัดไป

และถ้าผมคลิก test มันควรจะบันทึกข้อมูลลงในแถวแรกตรงนี้ และนี่คือข้อความทั้งหมดที่ผมต้องใช้เพื่อสร้างวิดีโอของตัวเอง ซึ่งเราจะทำกันในขั้นตอนถัดไป
