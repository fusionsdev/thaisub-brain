สิ่งที่เราจะทำคือ นำ Gmail assistant ที่เราสร้างไว้ ถ้าคุณยังไม่ได้ทำ ขอให้ไปดูวิดีโอก่อน แล้วเราจะนำ skill ที่เราสร้างไว้ มาปรับแก้มัน เราสร้าง skill ขึ้นมา ถ้าคุณดึงมันลงมา จะเห็นว่าเราสร้างอันหนึ่งไว้ มันเข้าไปอ่านอีเมลของเรา ดึงอีเมลออกมา แล้วก็ทำเครื่องหมายว่าอ่านแล้ว ร่างอีเมล หรือติดดาวสิ่งสำคัญให้เรา เป็นเวิร์กโฟลว์สามขั้นตอน ตอนนี้มันอยู่ใน skill เดียว

เมื่อคุณเริ่มเก่งในการสร้าง skill คุณจะสร้าง skill ที่เรียกใช้ skill อื่นๆ ฟังผมทนหน่อยนะครับ ตัวอย่างเช่น ถ้าคุณดูคลิปที่แล้ว ผมโชว์ daily content researcher ซึ่งเข้าไปทำเวิร์กโฟลว์ทั้งหมดนี่ นี่คือเวิร์กโฟลว์หนึ่ง ส่วนอันนี้สำหรับ email assistant ก็เป็นอีกเวิร์กโฟลว์หนึ่ง สิ่งที่ผมทำได้คือ สร้าง skill ระดับบนสุด ที่จะเรียก daily researcher และ email assistant พร้อมกัน มันจะทำงาน เมื่อผมเรียกใช้ มันจะเรียก skill ทั้งสองนี้ และรันทั้งคู่จากพรอมป์ต์เดียว หรือคำสั่ง slash เดียว ซึ่งโคตรเจ๋ง นี่คือวิธีที่คุณสร้างระบบทั้งหมด

ตัวอย่างที่ดีมากคือ content team ของผม ผมมี content ideator skill ที่สร้างไอเดีย มี content analysis skill ที่วิเคราะห์คอนเทนต์ที่ชนะทั้งหมด ผมมี ideator skill ที่อ่านผลวิเคราะห์นั้นแล้วสร้างไอเดียจากมัน ผมมี scripter ที่นำไอเดียและผลวิเคราะห์ไปเขียนสคริปต์ แล้วผมก็มี skill ระดับบนสุดที่รันทั้งหมดพร้อมกัน ซึ่งเจ๋งมาก และผมไม่อยากทำให้สมองคุณระเบิด แต่คุณคงเห็นแล้วว่า skill เรียก skill เรียก skill ได้อีก ถ้าคุณอยากทำขนาดนั้นจริงๆ แต่ผมไม่อยากลงลึกเกินไปจนซับซ้อนเกินจำเป็น เพื่อตอบคำถามที่คุณอาจคิดอยู่ คือ มันทำได้แน่นอน และนั่นคือสิ่งที่เราจะทำ

เราจะเปิด Claude ขึ้นมา ก่อนหน้านี้เรารัน skill ที่ดู Gmail ของเราแล้วร่างอีเมล เราก็มี skill อื่นๆ ด้วย ถ้าเข้าไปที่ customize แล้วดู skill ทั้งหมดที่เรามี จะเห็นว่าเรามี daily content researcher ที่ทำงานวิจัยคอนเทนต์ทั้งหมดและ scrape ข้อมูล และมี email assistant สิ่งที่ผมอยากทำคือ สร้าง skill เดียว ที่เป็นทั้งอ่านอีเมล ทำวิจัยคอนเทนต์รายวัน แล้วรวบรวมทั้งหมด เขียน brief ให้ผม มันดึงสามสิ่งมารวมกัน ซึ่งบ้ามาก

เราจะเริ่มแชทใหม่ แล้วพิมพ์ว่าอยากสร้าง skill ที่เรียกใช้ Email, daily content และเข้าไปใน Google Calendar เพื่อดึงอีเวนต์ทั้งหมด ดึงทั้งสามสิ่งนี้มารวมกัน แล้วเขียน brief เต็มรูปแบบเกี่ยวกับทุกอย่าง ตั้งชื่อมันว่า Morning Brief เพราะคุณเช็คอีเมลตอนเช้า เช็คปฏิทินว่ามีอะไร และเช็คข่าวสาร แน่นอน เราจะเรียกมันว่า Morning Brief และมันจะ orchestrate ข้อมูลทั้งสามแหล่งนี้

มันจะเริ่มทำงาน มันจะดู skill สองอันที่มีอยู่ ว่าผลลัพธ์ของมันคืออะไร แล้วจะทำอะไรต่อ ตอนนี้มันมีความชัดเจนแล้ว มันจะถามคำถามสองสามข้อ เราจะตอบคำถามของมัน "Morning Brief ควร orchestrate สามแหล่งข้อมูลยังไง? รันทั้งสามแบบ parallel แล้วสังเคราะห์เป็น brief เดียว" parallel หมายถึงรันพร้อมกัน นี่คือสิ่งที่ผมจะลงรายละเอียดเพิ่มในคอร์ส Claude Code เรื่อง agents และอื่นๆ แต่ขอให้ภาพรวมแบบเร็วๆ ก่อน

เมื่อคุณทำทีละขั้น แล้วก็ขั้น แล้วก็ขั้น มันเรียงต่อกันเป็นเส้นตรง นั่นเรียกว่า sequence คุณทำงานเป็นลำดับขั้น ซึ่งปกติคุณทำแบบนั้นเมื่อต้องใช้ผลลัพธ์จากขั้นหนึ่งไปอีกขั้นหนึ่ง ตัวอย่างเช่น ในการสร้างไอเดียคอนเทนต์ ผมต้องมีข้อมูลก่อน ต้องมีข้อมูลก่อน ถึงจะ ideate ได้ แล้วค่อยเขียนสคริปต์ แล้วค่อยถ่ายทำ ผมทำไม่ได้ถ้ายังไม่มีข้อมูล เขียนสคริปต์ไม่ได้ถ้ายังไม่มีไอเดีย สร้างไอเดียไม่ได้ถ้ายังไม่มีข้อมูล สิ่งเหล่านี้ต้องเกิดขึ้นตามลำดับ เพราะมันพึ่งพากัน

ต่างจาก parallel ที่สมมติผมเรียกใช้เวิร์กโฟลว์ นี่คือ trigger เรามีหนึ่ง สอง สาม สี่อย่างพร้อมกัน skill ของผมทำสามสิ่งหรือสี่สิ่งพร้อมกัน แล้วส่ง brief เต็มรูปแบบกลับมาให้ผมตรงนี้ นี่คือ skill หนึ่ง นี่คือ brief ที่ปลายทาง นี่คือเวิร์กโฟลว์หกขั้นตอน ส่วนอันนี้เป็นเวิร์กโฟลว์สามขั้นตอน เพราะมันรันแบบ parallel ทั้งหมดรันพร้อมกัน ผลลัพธ์ของอันหนึ่งไม่ขึ้นกับอีกอัน ไม่พึ่งพากัน ก็เลยรันพร้อมกันได้

เมื่อมันถามว่า "รันทั้งสามแบบ parallel ไหม?" ก็คือ เราประหยัดเวลาได้ไหม โดยรันทั้งสามพร้อมกัน ผมเลือกเอาเลย แล้ว "ส่วนอีเมลใน brief สุดท้ายควรละเอียดแค่ไหน? ย่อเป็น headline อย่างเดียว" เราเลือกเอาผลลัพธ์เต็มจาก assistant แล้ว "ควรดึงอีเวนต์ออกมาไกลแค่ไหน?" ผมอยากได้แค่วันนี้ เพราะผมจะรัน skill นี้ทุกวัน ก็ขอผลลัพธ์ของวันนี้เท่านั้น

มีคำถามอีกชุด "brief แบบรวมควรมีโครงสร้างยังไง? แบบมีโครงสร้าง เช่น executive summary สามส่วน exec summary บวกสามสิ่งที่สำคัญที่สุดสำหรับวันนี้" เราจะทำแบบ exec summary แล้ว "brief ควรเชื่อมโยงความสัมพันธ์ระหว่างสามแหล่งข้อมูลไหม?" ใช่ ผมอยากเห็น มันจะ cross-reference อีเมล คอนเทนต์ และข้อมูลทั้งหมด เพื่อดูว่ามีอะไรเกี่ยวข้องกัน แล้ว "หลังจากส่ง brief ควรถามคำถามต่อเหมือน content researcher ไหม?" แค่ส่ง brief แล้วหยุด โอเค

ตอนนี้มันจะสร้าง skill ให้เรา ปล่อยให้มันทำงานสักครู่ แล้วเสร็จ! มันสร้าง Morning Brief เต็มรูปแบบ และไฟล์ markdown ทั้งหมด มันอ่านอีเมล อ่านคอนเทนต์รายวัน แล้วก็ไปอ่านปฏิทินของเราพร้อมกัน นี่คือสิ่งที่เราคุยกัน: skill หลักหนึ่งอันที่เรียกใช้ skill สามอันด้านล่าง ซึ่งเจ๋งมาก ตอนนี้เสร็จแล้ว เราจะเซฟ skill และมันเซฟเรียบร้อย ผมจะคลิก manage เพื่อยืนยันว่ามันอยู่ในลิสต์ แล้วตอนนี้เรามี Morning Brief แล้ว

กลับไปที่แชท แล้วทดสอบกัน ผมจะพิมพ์ Morning Brief แล้วรัน ปล่อยให้มันทำงาน แล้วมันดูปฏิทินของผม มี onboarding call มีสมาชิกใหม่เจ็ดคนเข้าร่วมเมื่อคืน Anthropic ปล่อย Claude Design ก่อนสิ้นสัปดาห์ มีคนจองคิวทำคอนเทนต์ อีเมล inbox ก็จัดการร่างเรียบร้อย นั่นคือทั้งหมด เรามี skill ที่ใช้งานได้แล้ว

นี่คือวิธีที่คุณอัปเกรดและแก้ไข skill ของคุณ คุณเพิ่งได้มาสเตอร์คลาสเต็มเรื่องทักษะการสร้าง skill วิธีสร้าง วิธีใช้ สิ่งที่อยากให้ทุกคนทำคือ เข้าไปในคอมมูนิตี้ แล้วโพสต์ชัยชนะของคุณ บอกว่าคุณเรียนจบโหมดทักษะนี้แล้ว และไปสร้างอะไรที่เจ๋งจริงๆ ผมอยากเห็นมาก เท่านี้สำหรับบทเรียนนี้ เจอกันบทเรียนหน้านะครับ
