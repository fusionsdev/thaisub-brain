## บทนำ

บทเรียนนี้เป็นวิดีโอเปิดคอร์ส N8N Automation School — ผู้สอนพาชมอินเทอร์เฟซของ n8n แบบเต็มรูปแบบ ตั้งแต่ภาพรวมว่า n8n คืออะไร (แพลตฟอร์มออโตเมชันแบบคลาวด์ รันได้ 24/7 ต่างจาก Claude Code ที่ต้องเปิดเครื่องตลอด) ราคา, หน้า Workflows, Credentials, Executions, Templates, การสร้าง workflow แรก, โหนด, logs, การ debug และคำแนะนำให้ตั้ง error workflow

## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับสู่วิดีโอแนะนำ N8N Automation School ในคอร์สทั้งหมดนี้ ผมจะพาคุณดูเครื่องมือที่ทรงพลังที่สุดในโลก และเป็นเครื่องมือโปรดของผม เพราะตอนที่ผมเริ่มใช้ n8n มันคือสิ่งที่สอนผม และทำให้ผมเก่งในการสร้างเวิร์กโฟลว์ และถึงแม้ Claude Code จะเก่งแค่ไหน โดยเฉพาะการสร้างเวิร์กโฟลว์ ซึ่งผมพูดบ่อยว่า n8n เป็นสิ่งที่เก่งที่สุด ผมก็ยังคิดว่าการเข้าใจพื้นฐานของ n8n มีค่ายิ่งมาก เพราะเมื่อคุณเรียนรู้มัน คุณจะเข้าใจว่า AI ทำงานยังไง และนั่นคือส่วนที่สำคัญที่สุด

หลายคนเพิ่งเริ่มกับ Claude Code ถ้าคุณยังไม่รู้ว่ากำลังทำอะไรอยู่กับการสร้างเวิร์กโฟลว์ คุณจะยิงเท้าตัวเอง คอร์สนี้จะอธิบายทุกอย่างให้คุณ และผมจะบอกด้วยว่า n8n ยังไม่ตายนะ โอเค สิ่งที่ n8n ทำคือ มันเอาเวิร์กโฟลว์ขึ้นไปไว้บนคลาวด์ เพื่อให้รันได้ตลอด 24 ชั่วโมง 7 วัน ปัญหาของ Claude Code ตอนนี้คือ มันไม่รันเอง เว้นแต่คอมพิวเตอร์ของคุณจะเปิดตลอด 24/7 แต่ผมรันทุกอย่างบนแล็ปท็อป ดังนั้นทันทีที่ปิดฝา มันก็หยุดทำงาน แต่ n8n รันบนคลาวด์ คุณจึงควรใช้มันสำหรับการรันแบบ trigger ซึ่งผมจะอธิบายตลอดคอร์สนี้ แต่ตอนนี้ผมจะพาเดินชมแบบเต็มรูปแบบก่อน

ถ้าคุณไม่รู้ว่า n8n คืออะไร มันก็คือแพลตฟอร์มออโตเมชัน เหมือน Zapier, Make หรืออะไรทำนองนั้น และมันเป็นแบบ synchronous ช่วยให้คุณเชื่อมต่อแอปนับพันๆ เข้าด้วยกัน คุณไปเอา CRM อย่าง GoHighLevel แล้วดึงข้อมูลจากตรงนั้น เชื่อมต่อกับ Google แล้วก็เชื่อมต่อกับ Telegram แล้วคุณก็เชื่อมต่อได้อีกเยอะ มันน่าทึ่งมาก

ราคาครับ ตอนนี้ผมจ่ายเดือนละ 24 ดอลลาร์ คุ้มมาก และมันถูกเพราะผมอยู่ในไทย แต่ปกติแพ็กเกจ starter ก็ 24 ดอลลาร์ต่อเดือน ผมแนะนำให้ลงทุนกับมัน นั่นคือทั้งหมดที่คุณต้องใช้ คุณจะไม่ได้รัน execution เยอะขนาดนั้น เว้นแต่คุณทำงานหนักจริงๆ คุณไม่ต้องใช้แพ็กเกจใหญ่เท่าที่มันโฆษณาไว้

เมื่อคุณสมัครและล็อกอินแล้ว มันจะพาคุณมาที่หน้านี้ ซึ่งมีหลายอย่าง คุณมีหน้า Workflows ที่งานทั้งหมดของคุณอาศัยอยู่ มี Credentials ที่เก็บข้อมูลการเชื่อมต่อสำหรับแต่ละแอป คุณต้องสร้าง credentials ขึ้นมา ซึ่งผมจะเพิ่มเป็นบทเรียนระหว่างทาง แล้วก็มี Executions ซึ่งก็คือ log การทำงานว่าอะไรทำงานบ้าง เช่น social puller ของผมเช้านี้ล้มเหลว ล้มทุกเช้าเลย น่ารำคาญสุดๆ นั่นคือปัญหาของ n8n มันค่อนข้างเปราะ ซึ่งคุณจะได้เรียนรู้เอง

แล้วก็มี Personal, Shared with you แล้วก็มีฟีเจอร์แชท ที่คุณคุยกับ agent แล้วให้มันสร้างเวิร์กโฟลว์ให้ ซึ่งเจ๋งดี ผมไม่เคยใช้ เพราะผมเชื่อมมันกับ Claude Code ซึ่ง Claude Code สร้างเวิร์กโฟลว์ทั้งหมดให้ผม ซึ่งจะโชว์วิธีเชื่อมต่อในบทเรียนหน้า แล้วก็มี admin packages และ Templates

Templates เจ๋งมาก Template library คือที่ที่คนที่สร้างของมาขาย หรือแจกเทมเพลตฟรี อันนี้เป็น "generate AI viral videos" โพสต์ลงโซเชียลทั้งสองแพลตฟอร์ม คนนี้สร้างวิดีโอ AI แบบไวรัล แล้ว auto-post ลงโซเชียล ซึ่งเจ๋งมาก คุณเข้าไปดูได้ มีของให้ดาวน์โหลดเยอะ แต่เพราะเรามีเทมเพลตหลายร้อยอันในคอร์สนี้ มันเลยรู้จักมันดี ผมก็เลยไม่ค่อยใช้ แล้วก็มี Settings และ API tokens ต่างๆ แต่ผมจะไม่ลงรายละเอียดตรงนั้น

เมื่อคุณอยากสร้าง workflow มันง่ายมาก เข้าไปที่ create แล้วจะเห็นหลายอย่าง คุณจะเห็น "add 1st step" คุณคลิกเพื่อใส่ trigger ได้ และย้ายไปตรงไหนก็ได้ แล้วเพิ่ม node เช่น split-out ได้ และแต่ละ node ก็มี fields ต่างกัน ซึ่งตัวอย่างนี้ไม่ค่อยดี เพราะ node แต่ละแบบมี fields ไม่เหมือนกัน แต่คุณจะเห็นระหว่างคอร์ส ผมจะโชว์วิธีตั้งค่าทุกอย่าง

ภายใน workflow มีปุ่ม execute ซึ่งจะ trigger ให้ workflow เริ่มทำงาน ผมใส่แค่คำว่า execute workflow มันก็เปลี่ยนเป็นสีเขียว หมายความว่ามันทำงานแล้ว แล้วก็มี logs ด้านล่าง บอกคุณว่ามีอะไรเกิดขึ้น ซึ่งคุณจะเห็น input และ output สิ่งที่คุณจะได้เรียนรู้เกี่ยวกับ n8n คือเรื่อง data transformation input ของคุณกำหนด output ของคุณ ถ้าคุณใส่ขยะเข้าไป คุณก็ได้ขยะออกมา เช่นเดียวกัน ถ้าคุณจัดการข้อมูลไม่ถูกต้องและใส่ข้อมูลห่วยๆ คุณก็ได้ผลลัพธ์ห่วยๆ และในนี้คุณจะติดตามได้ว่าเกิดอะไรขึ้น ซึ่งเจ๋งมาก

แล้วก็มี sidebar ตรงนี้ ปุ่ม plus ช่วยให้เพิ่มแอปได้ คุณเชื่อมต่อแอปอะไรก็ได้ในโลกตรงนี้ เสิร์ชหาได้ แล้วก็มี Sticky notes เพื่อจัดระเบียบ สมมติผมอยากจัดระเบียบ trigger ก็เพิ่ม sticky note แล้วมันเป็น markdown เห็นไหม มันจะทำเป็นหัวข้อ ผมพิมพ์ trigger แล้วเปลี่ยนสีได้ นั่นช่วยให้จัดระเบียบทุกอย่าง แล้วคุณจะเห็นระหว่างทาง

แล้วก็มี focus panel ซึ่งผมไม่เคยใช้ ไม่รู้ว่ามันไว้ทำอะไร และ n8n AI ตัวนี้จะอ่านสิ่งที่คุณกำลังสร้าง และคุยกับมันได้ แต่คุณมีแค่ 150 ครั้ง ซึ่งค่อนข้างจำกัด เพราะ Claude Code ทำทุกอย่างให้ผมอยู่แล้ว แล้วก็มี Executions ที่เป็น log การทำงาน คุณเห็นทุกครั้งที่รัน ว่ามี error ตรงไหน คุณคลิกแล้วมันจะบอกคุณว่าผิดพลาดที่ตรงไหน

ถ้าอยาก debug ใน editor คุณคลิก debug in editor แล้วมันจะแสดงผล บางทีมันก็เพี้ยนๆ หน่อย แต่คุณสามารถ pin การ execution ได้ มันจะตรึงข้อมูลไว้ เพื่อไม่ให้ต้องรันซ้ำแล้ว debug ซ้ำ คุณแค่ pin ไว้ แล้วทำงานกับ node อื่นๆ ต่อไป แล้วก็มี Evaluation ซึ่งบอกตรงๆ ว่าผมก็ไม่รู้ว่ามันใช้ทำอะไร

แล้วก็มีเมนูตรงนี้ คุณแก้ description ได้ เพิ่มคำอธิบาย workflow ได้ ทำสำเนา workflow ได้ ดาวน์โหลด workflow ซึ่งจะดาวน์โหลดเป็นไฟล์ JSON เห็นไหม มันเป็น JSON แล้วก็ share, rename, import from URL, import from file ผมสามารถนำไฟล์ที่เพิ่งดาวน์โหลดมา import ได้ เราลอง import from file ไปที่ Downloads แล้วมันจะอัปโหลดไฟล์ JSON เข้ามา นี่คือวิธีที่ n8n flow ทั้งหมดถูกสร้างจาก JSON ซึ่งก็คือเครื่องหมายวงเล็บแบบหรูหรา

แล้วก็มี Settings สิ่งที่ผมแนะนำคือ ตั้งค่า error workflow เสมอ ซึ่งผมจะลงรายละเอียดในโมดูลหลังๆ แล้วก็มี credential setup guide ซึ่งจะครอบคลุมทีหลังเช่นกัน มันสำคัญมาก เพราะเมื่อ workflow ของคุณล้มเหลว คุณตั้งออโตเมชันให้ส่งอีเมลหาคุณทุกเช้าได้ ว่าอันไหนล้มเหลวตอนกลางคืน หรือถ้าเป็นเรื่องสำคัญมาก มันก็ส่งอีเมลหรือแจ้งเตือนทันที และคุณจัดการได้ทันที ประหยัดเวลาคุณได้เยอะ

นี่คือทั้งหมดสำหรับการเดินชมเต็มรูปแบบ บทเรียนหน้า ผมจะโชว์วิธีติดตั้ง Claude Code skill เพื่อให้คุณสร้าง workflow ใน n8n ได้ เจอกันบทเรียนหน้านะครับ
