## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 4 ของการตั้งค่า โดยสอนวิธีเผยแพร่วิดีโอที่สร้างเสร็จแล้วไปยังแพลตฟอร์มโซเชียลมีเดียต่าง ๆ ผ่าน Make.com ซึ่งมีการเชื่อมต่อโดยตรงกับแพลตฟอร์มเหล่านี้ ครอบคลุมการตั้งค่า webhook จาก n8n การเชื่อมต่อ Facebook, LinkedIn, Instagram, YouTube และ Telegram สำหรับรับข้อความยืนยัน รวมถึงคำแนะนำเรื่องขีดจำกัดขนาดไฟล์วิดีโอ 5 MB และวิธีแก้ไข

## คำแปลเต็ม

ขั้นตอนต่อไปของเราคือการเผยแพร่วิดีโอของเราไปยังโซเชียลมีเดียต่าง ๆ ซึ่งเราจะตั้งค่าในแพลตฟอร์มนี้ด้วย และสิ่งแรกคือเราจะทำสิ่งนี้บนแพลตฟอร์ม automation อีกตัวหนึ่งที่ชื่อว่า make.com เพราะในทางเทคนิคมันง่ายกว่ามาก พวกเขามีการเชื่อมต่อโดยตรงกับโซเชียลมีเดียทั้งหมดนี้ ยกเว้นอันหนึ่งซึ่งเราจะทำบน automation อีกตัวที่ตั้งค่าง่ายยิ่งกว่า ไม่ต้องกังวล เราจะทำในอีกไม่กี่นาทีหลังจากที่เราเชื่อมต่อสี่แพลตฟอร์มนี้แล้ว

ไปที่ make.com คุณสามารถสมัครบัญชีฟรีได้ ด้านล่างวิดีโอนี้ควรมีลิงก์ให้ และจากนั้นไปที่ create a new scenario และคุณจะพบ make blueprint ตรงนี้ด้วย คลิกแล้วไปที่ import เลือกไฟล์ แล้ว import คลิก save

แล้วสิ่งที่เหลือคือการเชื่อมต่อโมดูลต่าง ๆ อันดับแรกเราจะยกเลิกการเชื่อมโยงอันนี้ เพราะสิ่งที่ต้องทำคือเพิ่ม webhook คลิกที่มัน แล้วคัดลอก webhook ไปที่ automation ใน n8n ของเรา เราไม่ต้องทำอะไร แต่ก่อนอื่นเราต้องเชื่อมต่อชีตนี้ ซึ่งต้องเลือกบัญชี Google ที่ถูกต้อง อันนี้ควรจะให้ข้อมูลทั้งหมดที่เราสร้างไว้ในขั้นตอนที่แล้ว

สิ่งที่ผมอยากทำคือเพิ่ม filter และ filter ก็คือ video ID ตรงนี้ผมแค่ต้องลาก video ID ที่เราสร้างไว้ตรงไหนสักแห่งมาเป็น video ID เพราะผมต้องการดึงข้อมูลจากวิดีโอเฉพาะที่ผมกำลังสร้างเท่านั้น เพราะนั่นคือสิ่งเดียวที่จะถูกเผยแพร่ เอาล่ะ

ตอนนี้เรามาต่อกับ webhook ตรงนี้ เปิดมัน แล้วคุณจะเห็นว่าฟิลด์ทั้งหมดควรเป็นสีเขียว และเมื่อเราคลิก test มันควรจะได้รับข้อมูล สำเร็จ ดี ตอนนี้เราจะเรียกมันอีกครั้ง คลิก run once แล้วเรียก webhook อีกครั้ง เพื่อให้เราเห็นข้อมูลที่ได้รับจริง ๆ

ตรงนี้เราเห็นว่านี่คือข้อมูลที่ถูกส่ง และนี่คือสิ่งที่เราต้องใช้เพื่อเผยแพร่วิดีโอของเราไปยังแพลตฟอร์มต่าง ๆ ดังนั้นตอนนี้เราสามารถเชื่อมต่อมันได้อีกครั้ง และตอนนี้เราแค่ต้องเชื่อมต่อแพลตฟอร์มโซเชียลมีเดียต่าง ๆ เหล่านี้ และมันค่อนข้างตรงไปตรงมา

เราแค่คลิกที่โมดูลตรงนี้ แล้วคลิก จากนั้นระบบจะให้เข้าสู่ระบบบัญชี Facebook ของคุณ คุณต้องมีเพจ Facebook ที่เชื่อมกับ Facebook ส่วนตัวของคุณ แล้วมันจะโหลดขึ้นมาตรงนี้ ผมเพิ่งเลือกการเชื่อมต่อล่าสุด อันนี้เชื่อมกับอินพุตจาก n8n อย่างถูกต้องแล้ว คุณแค่คลิก save

ตรงนี้เราแค่ต้องเชื่อม Google Sheet ที่ถูกต้อง ต้องเข้าสู่ระบบด้วยบัญชี Google ที่เชื่อมกับ Google Sheet นี้ และตรงนี้เราต้องไปที่ Spreadsheet ID และตรงนี้มันโหลดชีตของผมมาแล้ว มันไม่ใช่อันนี้จริง ๆ มันคืออันนี้ อันที่ถูกต้อง จากนั้นมันจะโหลดชื่อชีต

ตอนนี้สิ่งเดียวที่ผมอยากพูดคือ VDURL มันไม่ใช่... จริง ๆ แล้วมันผิดตำแหน่ง อันนี้คือวันที่เผยแพร่ ดังนั้นสถานะควรสลับเป็น publish เพราะเรายังไม่ได้เผยแพร่อะไร เราต้องการให้เขียนวันที่เผยแพร่ แค่ดึงอันนี้มาตัดออก แล้ววางกลับไปตรงนี้ และนั่นคือทั้งหมดที่เราต้องการสำหรับโมดูลนี้

และตอนนี้ตรงนี้เรามี response กลับมา นี่คือการตอบกลับจาก n8n ดังนั้นเราสามารถรับข้อความใน Telegram ได้ว่าโพสต์นี้ถูกเผยแพร่แล้ว การทำแบบนี้เราต้องเชื่อมต่อก่อน และเรามี webhook สองอัน: test URL และ production อันดับแรก test URL ใช้ได้เฉพาะเหตุการณ์ทดสอบ ผมจะแสดงให้ดูว่าหมายความว่าอะไร สิ่งที่ผมต้องการคือมี test webhook ตรงนี้ มันโอเค คลิก save แล้วกลับมา คลิก save

อีกขั้นตอนแรกที่ผมจะทำคือ ผมต้องเรียกมันก่อน ผมต้องสลับอันนี้เป็น active ก่อน ผมจะยกเลิกการเชื่อมโยงอันนี้ก่อน เพราะผมต้องตั้งค่า webhook แค่ครั้งเดียว ผมจะยกเลิกการเชื่อมโยงเพราะผมต้องแน่ใจว่าข้อมูลที่ถูกต้องถูกส่งผ่านก่อนที่ผมจะลองเผยแพร่ไปยังแพลตฟอร์มอื่น ๆ ซึ่งผมจะเชื่อมต่อในขั้นตอนถัดไป

คลิกที่มัน จากนั้นเราต้องการคลิก test และทันทีที่เราต้องเปิดใช้งานอันนี้ แล้วตอนนี้เราก็สามารถ... วิดีโอจะถูกเผยแพร่ แล้วมันควรจะถูกส่งกลับมา คุณเห็นว่ามันทำงานแล้ว

ตอนนี้เราไปที่ Telegram เปิดดู นี่คือข้อความที่เราได้รับ และตรวจสอบ: มันเป็นสีเขียวทั้งหมดไหม? นี่คือตัวแปรทั้งหมดที่เราได้รับจาก webhook response หลังจากกระบวนการเผยแพร่ และเมื่อผมเรียกมัน ผมได้รับข้อความว่า วิดีโอที่มี ID นี้ถูกเผยแพร่ไปที่ Facebook ในเวลานี้ นั่นคือสิ่งที่ผมต้องการเป๊ะ

ตอนนี้กระบวนการนี้ทำงานแล้ว และสิ่งที่ผมจะทำต่อไปคือสลับเป็น production กลับมาตรงนี้ แล้ววางอันนี้ลงไป และแค่นั้น ผมรู้ว่ามันทำงานได้ ผมยังสามารถตรวจสอบ Facebook ว่าวิดีโอถูกเผยแพร่จริงหรือไม่ และคุณเห็นว่ามันทำงานได้

กลับมาตรงนี้ ก่อนที่เราจะไปต่อ มีสิ่งหนึ่งที่ผมอยากชี้ให้เห็นคือ ขนาดไฟล์สูงสุดที่คุณสามารถใช้วิดีโอเพื่อประมวลผลในบัญชี make.com ของคุณคือประมาณ 5 MB ถ้าวิดีโอของคุณใหญ่กว่านั้น คุณต้องอัปเกรด

คุณมีสองทางเลือกในการอัปเกรดบัญชี Make ของคุณไปยังแพ็กเกจถัดไป ไปที่ Organizations ตรงนี้ แล้วคุณสามารถสมัครระดับถัดไปซึ่งประมาณ $10 ต่อเดือน อย่างที่เห็น นั่นคือแพ็กเกจที่ผมสมัครไว้

หรือมีวิธีเลี่ยง คือเข้าไปในบัญชี n8n ของคุณ แล้วตั้งค่า workflow ขนาดเล็กที่บีบอัดวิดีโอให้ต่ำกว่า 5 MB ผมจะเพิ่มสิ่งนี้เป็นโบนัส หลังจากขั้นตอน... ผมจะเพิ่มวิดีโอโบนัสที่แสดงวิธีทำ แต่สำหรับตอนนี้ผมจะทำตามขั้นตอนเดียวกันที่ผมทำอยู่ตรงนี้

นี่คือสิ่งที่สำคัญมากที่ต้องรู้ ถ้าคุณเจอ error เรื่องขนาดไฟล์สูงสุด มันไม่เกี่ยวกับวิดีโอของคุณ แต่เกี่ยวกับขีดจำกัดของบัญชี นั่นคือสิ่งที่ผมอยากบอก

หรืออีกวิธีหนึ่งคือการลดขนาดวิดีโอ ไปที่ generate แล้วลดความยาวสคริปต์ จาก 700 ซึ่งน่าจะประมาณ 40... คุณอาจต้องลอง 600 หรือ 500 แล้ววิดีโอจะสั้นลงและขนาดไฟล์จะเล็กลง แต่พูดตรง ๆ คุณต้องอัปเกรดหรือใช้วิธีเลี่ยง

ผมจะ continue ตรงนี้ เชื่อมต่อโมดูลเหล่านี้อีกครั้ง ตรงนี้กับ LinkedIn กระบวนการเดียวกัน ผมเข้าสู่ระบบ คลิก แล้วระบบจะให้เข้าสู่ระบบบัญชีของคุณ และเมื่อทำเสร็จแล้วอันนี้จะถูกโหลดและควรจับคู่ให้ถูกต้องแล้ว ไฟล์วิดีโอมา...

จริง ๆ แล้วผมพบอันนี้แล้ว ตอนนี้ผมจะลบ Google sheets เหล่านี้ทั้งหมด แล้ว clone อันนี้แทน เพราะมันเหมือนกันทั้งหมด อันนี้แค่บันทึกวันที่ของวิดีโอ จริง ๆ แล้วปกติคุณต้องการแค่อันเดียว เพราะทั้งหมดบันทึกลงในแถวเดียวกัน สมมติว่าวิดีโอนี้ถูกเผยแพร่ในเวลานี้ คุณจึงสามารถลบมันออกได้เช่นกัน

และแน่นอนคุณแค่ต้องตั้งค่าบัญชีโซเชียลมีเดียที่คุณต้องการเผยแพร่เท่านั้น แต่ผมเพิ่มไว้ทุกที่ ขั้นตอนถัดไปคือ เราต้องการ webhook ใช่มั้ย? นี่คือ production อันนี้เชื่อมต่อแล้ว

ต่อไปคือ Instagram สำหรับ Instagram คุณต้องทำอีกหนึ่งขั้นตอนก่อน ต้องมีเพจ Facebook แล้วไปที่ Facebook ของคุณ ไปที่ Settings เพราะคุณต้องเชื่อมต่อ Facebook กับ Instagram ซึ่งคุณทำได้ตรงนี้โดยการเพิ่มภายใต้ linked accounts และคุณเห็นว่ามันเชื่อมกับบัญชี Instagram ตรงนี้ และเมื่อคุณเชื่อมต่อแล้ว บัญชี Instagram นี้จะปรากฏใน make.com ตรงนี้ แล้วคุณก็เข้าสู่ระบบได้

แล้ว video URL และ caption ก็ถูกแมปแล้ว เราทำไว้แล้ว และตรงนี้แค่ต้องใส่ webhook

ตอนนี้มาถึง YouTube มันค่อนข้างคล้ายกัน คุณแค่ต้องเข้าสู่ระบบด้วยบัญชีของคุณ บางครั้งคุณต้องต่ออายุการเชื่อมต่อ แล้วคลิก sign in แล้วทำขั้นตอนให้เสร็จ แล้วเลือกช่องที่คุณต้องการ จากนั้นมันควรจะโหลดฟิลด์นี้

ตรงนี้ title คุณไม่ได้สร้างอัตโนมัติจริง ๆ ตอนนี้คุณสามารถใช้ ผมแค่ใส่บางอย่างเช่น "watch title" เพราะมันไม่สำคัญมากนัก คุณสามารถใช้ข้อมูลที่เราเก็บไว้ตรงนี้ได้ แต่เพื่อให้ได้ title นี้ คุณต้องปรับแต่งเล็กน้อย ไปที่ Make ของคุณ แล้วเราต้องเพิ่ม parameter ชื่อ video แล้วเราจะ... รันโมดูลก่อนหน้านี้ แล้วผมจะจับคู่เพื่อให้ได้ title วิดีโอ

จากนั้น category คุณต้องเลือกหมวดหมู่วิดีโอที่ควรเผยแพร่ภายใต้ และนั่นก็แค่ข้อความ caption และแค่นั้น คลิก save เราต้องใส่ webhook ที่ถูกต้อง คลิก save คลิก save เปิดอันนี้อีกครั้ง คลิก ยังมี error คลิก ตอนนี้หายแล้ว และแค่นั้น

ตอนนี้เราเชื่อมต่อทั้งหมดแล้ว และมันควรจะทำงานได้ จากนั้นสลับเป็น active คลิก แล้วคุณก็สามารถรันมันได้ สร้างวิดีโออีกอัน แล้วมันควรจะถูกเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ เหล่านี้โดยอัตโนมัติ และคุณจะได้รับข้อความยืนยันเมื่อใดก็ตามที่มันถูกเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ

และนั่นคือทั้งหมดสำหรับแพลตฟอร์มเหล่านี้ และถ้าคุณต้องการเผยแพร่ไปที่ TikTok ด้วย อย่าลืมดูวิดีโอถัดไป ผมจะแสดงวิธีตั้งค่ามัน
