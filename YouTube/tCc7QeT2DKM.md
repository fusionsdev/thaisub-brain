# สรุป: How to Make AI Micro Dramas for 100% Free (Full Course)

## ประเด็นหลัก
- ใช้ workflow สาม prompt ร่วมกับ ChatGPT (ฟรี) เพื่อสร้าง AI micro drama ทั้งเรื่อง
- Prompt ชุดที่ 1 เจนเรื่องตามสไตล์ ไอเดีย และความยาว (1/3/5/10 นาที หรือกำหนดเอง)
- Prompt ชุดที่ 2 เจน image prompt ตัวละคร + สตอรี่บอร์ดครบมุมกล้อง บท แอ็กชัน เสียง
- Prompt ชุดที่ 3 รวมเป็น master prompt สำหรับ Google Flow agent mode
- เจนรูปตัวละครด้วย Nano Banana / Nano Banana Pro ใน Google Flow (ปิด agent ชั่วคราว)
- อัตราส่วนภาพ 16:9 ตอนเจน reference แล้วเปลี่ยนเป็น 9:16 ตอนเจนวิดีโอ
- โมเดลวิดีโอ Omni Flash + โมเดลภาพ Nano Banana Pro ใน agent
- แบ่งสคริปต์เป็นช็อตละ 10 วินาที เพราะ Google Flow เจนได้ครั้งละ 10 วินาที
- เจนทีละกลุ่มช็อต (เช่น 2–4 แล้ว 5–9) regenerate ช็อตที่ล้ม แล้ว rename / ดาวน์โหลด 720p
- ตัดต่อใน CapCut Filmora หรือ Premiere Pro; ถ้า narration ไม่เข้า ขอสคริปต์จาก ChatGPT แล้วเจนด้วย 11 Labs
- เดโอดราม่า: Emily พบว่า Daniel มีชู้กับ Sophia และแอบโอนเงินครอบครัว

## ความเห็นสรุป
คอร์สสั้นที่เน้น workflow ฟรีจริงจัง ตั้งแต่เลือกสไตล์ใน ChatGPT จนถึง agent mode ใน Google Flow
และตัดต่อจบ. เหมาะกับผู้ที่อยากทำ micro drama แนวหักหลังโดยรักษาตัวละครสม่ำเสมอ
โดยไม่ต้องเจนช็อตทีละช็อตด้วยมือทั้งหมดครับ.
