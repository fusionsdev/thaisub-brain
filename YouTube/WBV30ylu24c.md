## ประเด็นหลัก
- ไม่ต้องจ่ายหลายพันต่อเดือนเพื่อใช้ AI API อีกแล้ว — มีแพลตฟอร์มแจกฟรี
- **Bites** — inference hub ขนาดใหญ่ เข้าถึงโมเดลโอเพนซอร์ส 100,000+ ตัว (ข้อความ/ภาพ/วิดีโอ/เสียง) ผ่าน API key อันเดียว
- **Nvidia Nim** — ให้เครดิตใช้โมเดล frontier 80+ ตัว เช่น DeepSeek, Kimi, ChatGPT พร้อม rate limit ที่เพียงพอ
- **OpenRouter** — กรองหาโมเดลฟรีได้ทันที เช่น Qwen, GLM, Kimi, Llama
- มีคู่มือละเอียดพร้อมลิงก์ทั้งสามแพลตฟอร์ม — กดไลก์ + คอมเมนต์ "API" เพื่อรับ
