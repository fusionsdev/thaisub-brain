## บทนำ
วิดีโอสอนวิธีสร้างบอทใหม่ใน Telegram เพื่อรับ API key (access token) ตั้งแต่การค้นหาบอทสร้างบอท ตั้งชื่อและ username ที่ต้องลงท้ายด้วย "bot" ไปจนถึงการจัดการความปลอดภัยของคีย์ เช่น การเพิกถอน (revoke) คีย์ที่ไม่ใช้แล้ว

## คำแปลเต็ม

ตรงนี้คือ access token วิธีได้มามีดังนี้ ก่อนอื่นเข้าไปใน Telegram พิมพ์ค้นหา BotFather แล้วคลิกที่มัน จากนั้นคลิก start นี่คือที่ที่คุณจัดการบัญชีของคุณใน Telegram ทุกอย่างที่คุณใช้สร้างบอทก็ทำตรงนี้ จากนั้นคุณต้องคลิก create a new bot แล้วตั้งชื่อบอทใหม่ ผมจะเรียกมันว่า "My 1st AI agent" จากนั้นต้องเลือก username ซึ่งต้องอยู่ในรูปแบบนี้ ผมจะตั้งเป็น my_1st_ai_agent_bot ตรงนี้ต้องไม่มีช่องว่างคั่น และต้องลงท้ายด้วย bot ต้องลงท้ายด้วย bot ดี ตอนนี้คุณได้ API key มาแล้ว คุณไม่ควรโชว์คีย์นี้ให้ใครเห็น ผมจะลบคีย์นี้ทีหลังและ revoke คีย์ทิ้ง วิธีทำก็แค่พิมพ์คำสั่งเพื่อปิดใช้งาน API key ผมจะไม่โชว์มันให้ใครเห็น ดังนั้นก่อนอัปโหลด [วิดีโอ] ผมจะลบมันออก แต่ตอนนี้ผมมีคีย์ที่ใช้กับระบบนี้ได้แล้ว และคลิก save ตรงนี้ แล้วเมื่อ [เสร็จสิ้น] ...
