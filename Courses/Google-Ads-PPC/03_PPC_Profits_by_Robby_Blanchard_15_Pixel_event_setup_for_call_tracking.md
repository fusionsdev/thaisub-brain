## บทนำ

วิดีโอนี้เป็นเทรนนิ่งในคอร์ส Pay-Per-Call Profits โมดูล 3 โดยร็อบบี้ แบลนชาร์ด (Robby Blanchard) สอนการสร้าง Meta Pixel (Facebook Pixel) เพื่อใช้ติดตามผลโฆษณาสายเรียกเข้า (pay-per-call) เนื้อหาครอบคลุมตั้งแต่แนวคิดว่า Pixel คืออะไร ทำไมถึงสำคัญ การสร้าง data set ใน Meta Business Suite การติดตั้งโค้ดบน landing page และการตั้งค่า post-back ในเครื่องมือ MarketCall เพื่อให้ Facebook รู้ว่าโฆษณาตัวไหนให้ผลดีที่สุด

## คำแปลเต็ม

ยินดีต้อนรับสู่เทรนนิ่งอีกหนึ่งตัวของ Pay-Per-Call Profits ครับ ผมตื่นเต้นมากที่ได้มาอยู่ในเทรนนิ่งนี้ เรายังอยู่ในโมดูล 3 ถ้าคุณยังไม่ได้ดูเทรนนิ่งก่อนหน้าในโมดูลนี้ ควรกลับไปดูนะครับ ในเทรนนิ่งแรกผมพูดถึงการตั้งค่า Business และ Ads Manager ครอบคลุมพื้นฐานว่าสิ่งเหล่านี้คืออะไรและตั้งค่าอย่างไร แบบเรียลไทม์ในวิดีโอเลย และในเทรนนิ่งล่าสุดผมพูดถึงการเตรียมบัญชีของคุณให้อยู่ได้ยาว ๆ (preparing your accounts for longevity) คือการวอร์มบัญชี ทำไมเราถึงต้องทำแบบนั้น สร้างความเชื่อมั่นและ billing threshold สำหรับ Facebook รวมถึงการเตรียม Likes campaign และ Boosted Posts

วันนี้ผมจะพูดถึงการตั้งค่า Event และทำให้ Event ทำงานสำหรับ call tracking และ MarketCall ของคุณ สำหรับคนที่ยังไม่รู้ว่า Pixel คืออะไร ผมจะอธิบายให้ฟังนะครับ Facebook Pixel คืออะไร และทำไมมันถึงสำคัญ มันสำคัญมากที่ต้องรู้ Pixel ให้คิดว่ามันเป็นโค้ดชิ้นเล็ก ๆ โดยพื้นฐานมันคือชุดของโค้ดที่ Facebook ใช้ ซึ่งคุณนำไปวางบนเว็บไซต์ มันจะติดตามการกระทำของผู้ใช้ หรือสิ่งที่ Facebook เรียกว่า Event ซึ่งอาจเป็น PageView, Lead, Contact อะไรประมาณนั้น และมันจะบันทึก Event เหล่านั้นบนแพลตฟอร์ม แล้วส่งข้อมูลกลับไปให้ Facebook เพื่อวัดผลโฆษณาของคุณ ซึ่งสำคัญมาก

จำไว้ว่าสิ่งหนึ่งเกี่ยวกับธุรกิจนี้คือ ทุกอย่างคือเรื่องของข้อมูล เราจะลงลึกไปกับการวิเคราะห์ข้อมูล และการตัดสินใจเรื่องโฆษณาของเราล้วนอิงจากข้อมูล ถ้าไม่มี Event ที่เราอยากติดตาม เราก็จะไม่มีข้อมูล และไม่รู้ว่าโฆษณาตัวไหนทำงานดี ในคอร์สนี้เราติดตาม Lead เราติดตาม Lead และ Contact เพราะนั่นคือสิ่งที่สำคัญจริง ๆ และเมื่อผมพูดถึงเมตริกต่าง ๆ ในเทรนนิ่งอนาคต คุณจะได้เรียนรู้ทั้งหมดว่าเราติดตามยังไง และทำไม Event เหล่านั้นถึงสำคัญ แต่สิ่งที่เราต้องทำก่อนคือต้องมี Pixel เพื่อให้สามารถติดตาม Event เหล่านั้นได้

แล้วทำไมมันถึงสำคัญ? เพราะมันติดตามผลของเรา เราจะเห็นได้ว่าเกิดอะไรขึ้นหลังจากมีคนคลิกโฆษณา Facebook ของเรา เราจะเห็นว่าโฆษณาของเราเป็นยังไง landing page ของเราเป็นยังไง และโฆษณาตัวไหนทำได้ถูกต้อง เพราะเราสามารถติดตามได้ว่าโฆษณาไหนให้ Lead ที่มีคุณภาพ (qualified leads) และโฆษณาไหนให้สายโทรที่ตรงตามเงื่อนไขและจ่ายเงิน (qualified and paid calls) มันยังช่วยให้เรา optimize แคมเปญ เพราะมันช่วยให้ Facebook แสดงโฆษณาของคุณกับคนที่น่าจะได้ผลลัพธ์ที่ต้องการมากที่สุด ซึ่งก็คือคนที่ตั้งใจจะโทรหาเรา และมันยังช่วยเพิ่ม Return on Ad Spend (ROAS) เพราะการตัดสินใจโดยอิงข้อมูลนำไปสู่การใช้จ่ายโฆษณาที่มีประสิทธิภาพกว่า จำไว้ให้ดี

สรุปคือ Pixel มีบทบาทหลักสองอย่าง อย่างแรกคือบทบาทในการติดตาม และอย่างที่สองคือช่วยเรื่องประสิทธิภาพ วันนี้ผมจะแสดงวิธีตั้งค่า Pixel ใน Facebook และวิธีนำ Pixel ไปวางบน landing page ของเรา เราอยากให้ Pixel อยู่บน landing page เพื่อที่เราจะคำนวณได้ว่า landing page หรือ bridge ของเราทำงานให้เราแค่ไหน แล้วเราก็จะตั้งค่า Pixel ใน MarketCall ด้วย เพื่อให้มันติดตาม Event ของเราและบอก Facebook ว่าโฆษณาตัวไหนทำงานดีที่สุดสำหรับเรา

เอาล่ะ ผมจะหยุดแชร์หน้าจอแป๊บหนึ่งแล้วแชร์หน้าจอ Facebook เราจะเข้าไปใน Meta Business Suite กัน ไปที่ Meta Business Portfolio ตอนนี้คุณเห็นแล้วว่าผมอยู่ใน Meta Business Portfolio จำไว้ว่า Business ของคุณคือ Business ของคุณ และเมื่อคุณเข้าไปแล้ว คุณจะอยู่ฝั่งหลังบ้าน (back end) ของ Facebook ผมบอกว่า Facebook นะครับ ตรงที่มีตัว F สีน้ำเงินนั่นคือแอป Facebook ส่วน Meta คือฝั่งหลังบ้านของ Facebook นั่นคือ Meta Business ของคุณ ซึ่งเป็นที่ที่คุณบริหารธุรกิจ และ Business Portfolio หรือ Business Manager คือที่ที่เราจัดการทุกอย่างที่เรามี มันเหมือนแดชบอร์ดธุรกิจของคุณ และภายใน Business Portfolio นี้คือที่ที่คุณจะพบ Data Sources หรือที่ Facebook หรือ Meta เรียกมันว่า Data Sets

เราจะเลื่อนลงมาตรงนี้ แล้วคลิกที่ Data Sources จากนั้นไปที่ Data Sets และ Pixels คลิกที่ Data Sets and Pixels แล้วคุณจะเห็นว่าผมยังไม่มี data set ในบัญชีนี้เลย สิ่งแรกที่ต้องทำคือคลิก Add จากนั้นตั้งชื่อ data set ของคุณ ผมจะตั้งชื่อโดยใช้วันที่และระบุ niche เพราะผมอยากรู้ว่า niche หรือ vertical ไหนที่ผมรันแคมเปญนี้อยู่ เพราะถ้าคุณคิดดู ถ้าผมโปรโมทประกันรถยนต์ กับประกันบ้าน หรือกำจัดปลวก คนที่โทรเข้ามาก็คนละกลุ่มกัน ผมเลยต้องตั้งชื่อ Pixel ตาม vertical ของผม ตัวอย่างที่ใช้ตลอดคอร์สนี้คือ auto ผมจะตั้งชื่อว่า Auto Insurance Pixel เพื่อให้รู้ว่าเป็นตัวไหน จากนั้นผมจะเอาเครื่องหมายถูกออกตรง Conversion API Gateway demo เพราะเราไม่ต้องการมัน แล้วกด Create

ใช้เวลาสักครู่ในการสร้าง มันบอกว่าข้อมูล set ถูกสร้างแล้ว และเพื่อเริ่มรับข้อมูลผมต้องไปที่ Events Manager เลือก Connect Data และเลือกประเภทข้อมูลที่อยากเริ่มส่งให้ Auto Insurance Pixel ผมจะโชว์อะไรบางอย่างก่อนที่จะไป Events Manager ขอออกจากหน้านี้แป๊บหนึ่ง แล้วโชว์สิ่งที่สำคัญมาก นั่นคือการ assign คนใน Connected Assets ของคุณ เพราะถ้าไม่ทำ คุณจะไม่สามารถดึง Pixel นี้ขึ้นมาใช้ตอนเปิดแคมเปญได้ ซึ่งเราจะทำในเทรนนิ่งหน้า คุณต้อง assign คนของเรา ใครก็ตามที่ทำงานใน Business Manager และคลิก Full Control จากนั้น assign ให้ทุกคนที่ทำงานใน Business ของผมเข้าถึง Pixel ของผมได้

สิ่งต่อไปที่ต้องทำคือ Connect My Assets ผมต้องแน่ใจว่า Ad Account ที่จะลงโฆษณาเชื่อมต่อกับ Pixel แล้ว ผมจะคลิก Other Business Assets และเลือก Ad Account ตัวแรกที่ผมสร้างไว้สำหรับลงโฆษณา ตอนนี้ผมเชื่อมต่อผู้คนแล้วและเชื่อมต่อ Ad Account แล้ว ตอนนี้ไปที่ Events Manager ต่อได้เลย ตรงนี้แสดง Data Set ID หรือ Pixel ID ของผม ซึ่งสำคัญมาก ไม่กี่ขั้นตอนจากนี้เราจะใช้มันใน MarketCall แต่ขอให้รู้ว่ามันอยู่ตรงนี้

ตอนนี้ผมจะไปที่ Events Manager ซึ่งเป็นที่ที่คุณดูข้อมูลทั้งหมดของ Pixel ของคุณ เป็นที่ที่คุณเข้ามาดู analytics ของ Pixel และเป็นที่ที่เราตั้งค่าต่าง ๆ ของ Pixel ด้วย ตอนนี้คุณเห็นว่าผมอยู่ใน Events Manager และต้องตั้งค่า Pixel นี้ ในการตั้งค่า Pixel ผมจะเลือก Meta Pixel — Gather events from Browser แล้วคลิก Set up Meta Pixel จากนั้นเลือก Install Code Manually เพราะผมจะเพิ่มโค้ด Pixel ลงบนเว็บไซต์ด้วยตัวเอง ผมต้องคัดลอก Base Code นี้ แล้วนำไปวางบน landing page เพื่อให้ Pixel ทำงานบน landing page

ผมจะคัดลอกโค้ดนี้ แล้วกลับไปที่ Funnel Builder ในเครื่องมือ Pay-Per-Call Profits ของเรา ขอหยุดแชร์แล้วแชร์ใหม่ ตอนนี้คุณเห็นว่าผมอยู่ในเครื่องมือ PPC Profits แล้ว ผมอยู่ในแดชบอร์ดหลัก จำไว้ว่าการเข้าถึงพื้นที่ landing page หรือ funnel ของคุณ ไปที่ Landing Pages แล้วก็ Editor ตรงนี้ ผมจะเข้าไปในเครื่องมือนี้ ถ้าคุณยังไม่ได้ดูโมดูล 4... ในโมดูล 4 คุณจะได้เรียนรู้ทั้งหมดเกี่ยวกับ landing pages และการตั้งค่าเว็บไซต์และ landing page ของคุณ ดังนั้นถ้ายังไม่ได้ทำ สิ่งแรกที่ควรทำคืออ่าน Tutorial ตรงนี้ ซึ่งสำคัญมากสำหรับเรื่อง landing page เพื่อให้เข้าใจว่ามันทำงานยังไง

คุณจะเข้าถึงเครื่องมือนี้ ถ้านี่เป็นครั้งแรกที่คุณล็อกอิน คุณจะยังไม่เห็นเว็บไซต์ใด ๆ ในการสร้างเว็บไซต์ใหม่ กด Create New Site — ผมจะพูดถึงเรื่องนี้ในโมดูล 5 ดังนั้นคนที่ดูแล้วอาจจะเห็นซ้ำ แล้วค่อยดูโมดูล 5 เรื่องการสร้างเว็บไซต์ด้วย ยังไงก็ดูโมดูล 5 ด้วยนะครับ มันสำคัญมาก แต่เมื่อคุณเข้ามาเพื่อใส่ Pixel คุณจะสร้างเว็บไซต์แรกของคุณ

Site Title จะตั้งตาม niche เช่น ถ้าผมอยากสร้างเว็บไซต์ตรงนี้ ผมก็ตั้งว่า Auto Insurance และ URL ไม่เกี่ยวกับโดเมนของคุณ มันเป็นแค่คำอะไรก็ได้ที่เกี่ยวกับ niche นั้น แล้วเลือก Template จากนั้นกด Create Your Site ผมสร้างเว็บไซต์ของผมแล้ว เลยจะไม่สร้างอีกอันตรงนี้ เมื่อคุณสร้างเว็บไซต์แล้ว คุณเข้าไปที่ Visit Site และเข้าไปที่พื้นที่นี้ในแดชบอร์ดได้ ในการวาง Pixel สำหรับ landing page เมื่อคุณสร้าง landing page เสร็จแล้ว คุณจะเอาโค้ดไปวางตรงนี้ และคุณต้องมีเว็บไซต์ที่สร้างไว้ก่อน แล้วคลิกเข้าไปในแดชบอร์ด แล้วเลื่อนลงมาตรงที่เขียนว่า Pixel Code คลิกที่ Pixel Code แล้ววางโค้ดที่ผมเพิ่งคัดลอกจาก Business Manager สำหรับ data set ของผม ผมตั้งค่าแบบ manual ใช่ไหมครับ ผมคัดลอก Base Code ใน Facebook แล้ววางโค้ดนั้นตรงนี้

ตอนนี้คุณจะเห็นว่ามันเขียนว่า PageView ดังนั้นนี่จะเป็นการนับจำนวนการเข้าชม landing page ของผม เพื่อใช้คำนวณว่า landing page ทำผลงานได้ดีแค่ไหน จากนั้นกด Save Changes แล้วกลับไปที่ Meta อีกครั้งเพื่อตั้งค่า Pixel ต่อ แต่สิ่งที่ต้องทำก่อนคือ Activate Pixel หลังจากวาง Pixel แล้ว ต้องเปิดใช้งานมัน ผมจะกลับไปที่ Landing Pages — คุณต้องสร้าง landing page ก่อนเมื่อคุณพร้อม ซึ่งจะอยู่ในโมดูล 5 แต่คุณสามารถเข้าไปที่หน้า funnel หน้าใดก็ได้ภายใน funnel เพื่อเปิดใช้งาน Pixel คุณต้องมีโดเมนอยู่ในนี้ก่อน ผมจะกด Get URL แล้วคัดลอกลิงก์นี้ จากนั้นสิ่งที่ต้องทำคือใส่ลิงก์นี้ในเบราว์เซอร์เพื่อเปิดใช้งาน Pixel ผมจะทำอย่างนั้น เปิดใช้งาน Pixel แล้วกลับไปที่ Facebook เพื่อตั้งค่า Pixel ต่อ

ตอนนี้กลับมาที่ Facebook แล้ว ผมจะตั้งค่าต่อ กด Continue และต้องแน่ใจว่าเปิด Advanced Matching — คุณควรเปิด Advanced Matching เสมอ แล้วกด Done ตอนนี้ Pixel ของผมถูกตั้งค่าใน Facebook แล้ว แต่ผมยังต้องตั้งค่า Pixel ใน MarketCall ด้วย

สิ่งที่เราทำมาแล้ว: สร้าง Pixel แล้ว และวางโค้ด PageView ในแดชบอร์ด landing page แล้ว เพื่อที่ว่าเมื่อเรามี landing page เราจะเห็นเมตริกของ landing page และดูว่า landing page ทำงานดีแค่ไหน สิ่งต่อไปที่ต้องทำคือ... (ผมจะกด Don't show again — ณ จุดนี้ Pixel ของคุณถูกเปิดใช้งานแล้ว) จากนั้นรีเฟรชหน้านี้ แล้วผมจะไปที่... ขอถือไว้แป๊บ เราจะไปเอาโค้ดของเรา ขอหยุดแชร์หน้าจอแป๊บหนึ่ง แล้วเข้าไปใน MarketCall

ก่อนจะเข้า MarketCall สิ่งที่ต้องทำคือคัดลอก Pixel ID และสร้าง Access Token เพราะเราจะต้องใช้ทั้งสองอย่างใน MarketCall สิ่งที่ผมแนะนำคือให้คัดลอกและวางลงในเอกสาร เพื่อให้คุณมีทั้งสองค่าที่ต้องใช้ สิ่งแรกคือคัดลอก Data Set ID — นี่คือ data set ของผม เห็นตรงนี้เขียนว่า Data Set ID คลิกที่มันก็จะคัดลอกไปยังคลิปบอร์ด แล้ววางลงในเอกสาร จากนั้นเลื่อนลงไปด้านล่างสุด

ตอนนี้ผมมาอยู่ที่ Settings — ตอนแรกผมอยู่ที่ Overview ตอนนี้ไปที่ Settings ซึ่งเป็นที่ที่คุณเห็น Data Set ID ของคุณ หรือจะดูจากด้านบนก็ได้ และถ้าเลื่อนลงมาเกือบสุดหน้า จะเห็นปุ่ม Generate Access Token ผมต้องสร้าง Access Token เพื่อใส่ใน MarketCall ผมจะกด Generate ตรงใต้ Setup Direct Integration เลือก data set ที่ถูกต้อง ถ้าคุณมีหลาย data set ก็ต้องเลือก data set ที่คุณกำลังตั้งค่า ผมเห็นของผมอยู่ อันนี้เป็นอันเดียวที่ผมมี แล้วกด Generate Access Token ผมต้องใช้มันเพื่อให้ Facebook คุยกับ MarketCall ได้จริง ๆ

จากนั้นคัดลอกโค้ดนี้ เพราะผมต้องใช้ Access Token ด้วย คัดลอก Pixel ID และคัดลอก Access Token แล้วสลับไปมาได้ เมื่อคัดลอกโค้ดเสร็จและวางในเอกสารแล้ว ตอนนี้กลับเข้าไปล็อกอิน MarketCall ของผม

เมื่อเข้ามาใน MarketCall แล้ว สิ่งที่ต้องจำไว้คือคุณต้องเลือก Offer ที่จะโปรโมทแล้ว และต้องสร้าง Campaign กับ... เมื่อคุณเลือก Offer และผ่านการอนุมัติ คุณต้องกรอกข้อมูลต่าง ๆ ไว้แล้วด้วย ดังนั้นนี่จะเป็นหนึ่งในขั้นตอนสุดท้ายก่อนที่คุณจะรันโฆษณา เพราะคุณต้องมี Campaign ที่สร้างใน MarketCall ก่อนถึงจะตั้งค่า Pixel ได้ จำไว้ให้ดี

สิ่งที่ต้องทำคือเลื่อนลงไปที่ด้านล่างสุดตรงที่เขียนว่า Automation แล้วคลิกเข้าไป คุณจะเห็นว่าในนี้มี post-back อยู่หนึ่งอันแล้ว เราจะเก็บมันไว้ แล้วคลิก Add a Postback ต้องแน่ใจว่า Template เขียนว่า Facebook และ Object, Method และ Status ตรงนี้ตั้งเป็น All แต่คุณต้องเลือก Campaign ของคุณ ผมจะเลือก campaign ของผม นี่คือจุดที่เราต้องใส่ข้อมูลบางอย่าง จำได้ไหมว่าผมคัดลอก Pixel ID ไว้? ผมจะวาง Pixel ID ตรงนี้ ผมจะลบข้อความที่เขียนว่า Pixel ID ออก แล้ววาง Pixel ID ของผมลงไป ตอนนี้คุณเห็นชุดตัวเลขนั้น นั่นคือ Pixel ID ของผม แล้ว Access Token ก็จะวางตรงนี้เหมือนกัน ลบคำว่า Token ออก แล้วเอา Access Token จากเอกสารของผม (อยู่ในแท็บอื่น คุณเลยไม่เห็น) วางลงตรงนี้ สำคัญมากว่าต้องทำแบบนี้

อีกอย่างคือผมจะปล่อยส่วนอื่นในนี้ไว้เหมือนเดิม — JSON ตรงนี้ ผมจะไม่แก้อะไร แล้วเลื่อนลงไปด้านล่างสุดกด Create นี่คือ post-back Pixel ตัวแรก อันที่จริงผมต้องทำสองครั้ง และต้องแก้ไขในครั้งที่สอง เพราะอันนี้จะติดตามสายเรียกเข้าของเรา ส่วนอันถัดไปจะติดตาม Lead คุณจะได้เรียนรู้ว่า Lead และ Contact คืออะไรในโมดูลหลัง ๆ ตอนที่เราดู analytics

ผมต้องใส่ post-back Pixel อีกครั้ง กด Add Postback อีกครั้ง แล้วเลือก Facebook เลื่อนมาตรง Status คราวนี้ผมจะคลิกเลือก Contact ซึ่งจะเป็น Contact ของผม ต้องเลือก Campaign ของผม และทำแบบเดียวกัน ใส่ Token ตรงนี้ แล้วเลื่อนไปทางขวาเพื่อใส่ Pixel ID กลับเข้าไป ลบ Pixel ID ออกแล้ววาง Data Set ID ลงไปอีกครั้ง (Pixel ID หรือ Data Set ID ก็คืออันเดียวกัน) ต้องแน่ใจว่าคุณใส่ให้ถูกต้อง ระหว่างวงเล็บหรือระหว่างเครื่องหมายเปอร์เซ็นต์ ตอนนี้คุณเห็น Pixel ID ของผมแล้ว สิ่งสุดท้ายที่ต้องทำสำหรับตัวที่บอกว่า Contact คือพิมพ์คำว่า contact ตรงนี้ เพื่อให้สคริปต์ดึงข้อมูล contact ของผมเข้ามา แค่นั้นเอง แล้วเลื่อนลงไปด้านล่างสุดกด Create

ตอนนี้คุณจะเห็นทั้งสองรายการ เห็น post-back แบบ Lead และ post-back แบบ Contact แค่นั้นเองที่ต้องทำ และคุณควรจะเห็นทั้งหมดสามรายการเสมอ: อันแรกเริ่มต้นที่เราไม่ลบ อัน Lead และอัน Contact

และนี่คือวิธีที่เราทำให้ Pixel ติดตาม Lead และ Contact ของเรา ซึ่งเราจะลงลึกในเทรนนิ่งหลัง ๆ เพื่อให้ได้ประสิทธิภาพโฆษณาที่ดีที่สุด และสามารถขยายสเกลและประสบความสำเร็จกับแคมเปญของเรา ในวิดีโอนี้คุณได้เรียนรู้เกี่ยวกับการสร้าง Pixel การวางบน landing page และการวางใน MarketCall ในวิดีโอหน้า เราจะอยู่ในโมดูล 3 ต่อ โดยจะได้เรียนรู้เกี่ยวกับ Browser Hero และ Facebook Secrets ในวิดีโอที่ห้า แล้วเจอกันในเทรนนิ่งหน้าเกี่ยวกับ Browser Hero ครับ ขอบคุณที่รับชม
