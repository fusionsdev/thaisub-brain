# Content System 5.1 — Trending Topics Scraping

> **ที่มา:** บทเรียนจากคอร์ส NoeAI Automator  
> **ภาษา:** คำแปลภาษาไทยจากต้นฉบับภาษาอังกฤษ (STT via faster-whisper)

---

## บทนำ

บทเรียนนี้สาธิตการใช้ Claude Code สร้าง skill สำหรับดึงหัวข้อที่กำลังมาแรง (trending topics) ในกลุ่มเฉพาะของคุณเพื่อนำไปทำคอนเทนต์ ผู้สอนอธิบายหลักการเลือกแหล่งข้อมูล การให้คะแนนเนื้อหาแบบอัตโนมัติ และการส่งไอเดียเข้าไปในระบบ content pipeline ผ่าน Airtable

## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับเข้าสู่บทเรียนเรื่องการดึงหัวข้อที่กำลังมาแรง (trending topic scraping) ในบทนี้ผมจะโชว์วิธีใช้ Claude Code ในการดึงหัวข้อที่กำลังมาแรงในกลุ่มเฉพาะของคุณ เพื่อเอาไปทำคอนเทนต์ สิ่งนี้จัดอยู่ในหมวดการค้นคว้า (research) เพราะจริง ๆ แล้วเรากำลังค้นคว้าว่าหัวข้อไหนกำลังมาแรงที่สุดในกลุ่มของเรา โดยพิจารณาจากความขัดแย้งและกระแสที่เกิดขึ้น

ทำไมเราถึงต้องทำแบบนี้? เพราะเราอยากอยู่แนวหน้าของข่าวสาร ถ้าเราได้ข่าวที่ไม่มีใครเคยได้ยินมาก่อน มันก็จะช่วยผลักดันเราไปข้างหน้าในทุกด้าน คุณเข้าใจใช่ไหมครับ เวลาคุณทำคอนเทนต์เกี่ยวกับข่าว ผมขอบอกไว้อย่างหนึ่งว่า ผมไม่ได้ทำคอนเทนต์แนวข่าวเยอะนัก แต่ผมจะให้ skill นี้กับคุณอยู่ดี เพราะผมคิดว่ามันมีคุณค่ามาก

สิ่งที่ผมจะบอกคือ มันคือการแข่งกันส่งคอนเทนต์ออกมาให้เร็วที่สุด ถ้าคุณรัน skill นี้ทุกเช้า คุณจะอยู่แนวหน้าและเป็นคนแรกที่ปล่อยวิดีโอในทุกหัวข้อ และมันยังช่วยให้คุณรู้ว่าควรไปทางไหน ซึ่งเจ๋งมาก แต่บอกตามตรง ผมไม่ค่อยชอบแนวนี้เท่าไหร่ ผมคิดว่าคุณควรทำคอนเทนต์ที่ดีจริง ๆ มากกว่า ไม่จำเป็นต้องพึ่งกระแสข่าว แต่ก็เข้าใจได้

สิ่งที่คุณต้องทำก็คือ ไปดาวน์โหลดไฟล์มา พอได้ไฟล์แล้วก็เปิดมันขึ้นมา แล้วคุณจะเห็น resource ต่าง ๆ และไฟล์ MD สำหรับ skill นี้ แค่ลากมันเข้าไป มันก็จะสร้าง skill ให้คุณ ซึ่งดีมาก ผมมีมันอยู่บนคอมพิวเตอร์แล้ว เลยไม่ต้องทำขั้นตอนนั้น แต่ลองรันมันดู แล้วผมจะโชว์ให้เห็นว่ามันทำอะไรบ้าง

ผมจะเปิด daily content researcher ขึ้นมา กด tab ได้ ขอโชว์ข้างในให้ดูหน่อยนะครับ โอเค สิ่งที่ผมทำคือ ผมอยู่ในสาย AI ผมเลยเลือกแหล่งข้อมูลสามแห่ง ผมใช้ Reddit เพราะ Reddit โดยทั่วไปเป็นฐานข้อมูลที่ดีที่สุดสำหรับคนที่ถามคำถาม คนที่ถามคำถาม ก่อให้เกิดกระแส หรือปล่อยข่าว ผมอยากอ่าน Reddit ตลอดเวลา เพราะผมไม่รู้แน่ชัด มันเป็นโซเชียลมีเดียที่ถูกมองข้ามอย่างไม่น่าเชื่อ

แล้วผมก็ใช้ Perplexity AI ซึ่งทำการค้นคว้าเชิงลึกบนอินเทอร์เน็ต มันน่าจะใช้คำอธิบาย/การสืบค้นจากเว็บ แล้วก็ GitHub ซึ่งผมจะอธิบายให้ฟังตรงนี้ หลักการทำงานคือ มันจะตรวจสอบ log ก่อนหน้านี้ ตอนจบแต่ละรอบมันจะบันทึกการค้นคว้า 10 หัวข้อที่ทำในวันนั้นไว้ ทุกเช้าที่คุณรัน มันจะดู log ครั้งล่าสุดที่คุณรัน และมั่นใจว่าจะไม่นำหัวข้อเดิมมารันซ้ำ

มันจะโหลด context ทั้งหมดเข้ามา อ่านโปรเจกต์ Claude ของคุณ อ่าน avatar ของคุณ แล้วดูคอนเทนต์ที่ไวรัลของคุณ hook, swipe และเสียงในสคริปต์ของคุณ มันจะโหลด context ทั้งหมดนี้เข้ามา แล้วดูว่าอะไรกำลังไวรัลสำหรับคุณ อะไรที่ใช้ได้ผล ตัวอย่างเช่น ถ้าผมทำคอนเทนต์เกี่ยวกับ ChatGPT แล้วมันไปได้สวย มันก็จะไปหาข่าวเกี่ยวกับ ChatGPT เพิ่ม เพราะมันรู้ว่ามันใช้ได้ผล หรือหาอะไรที่เกี่ยวข้อง ซึ่งเจ๋งมาก

แล้วมันจะทำ live scrape จากสี่แหล่งแบบขนาน โอเค สี่แหล่ง ไม่ใช่สามแหล่ง มันจะ scrape Twitter ด้วย Apify ใช้ Apify scraper ถ้าคุณยังไม่ได้ตั้งค่า ไปตั้งค่า Apify ก่อน ผมค่อนข้างแน่ใจว่าโชว์วิธีทำไว้ในบทเรียน Steal Competitor Data และ Source Competitors ผมจะโชว์วิธีเชื่อมต่อ Apify ตรงนั้น มันจะใช้ Apify scrape Twitter และมองหา viral archetype แปดแบบ

ผมสร้าง skill นี้มาเพื่อกลุ่มเฉพาะของผมโดยเฉพาะ แต่ถ้าคุณอยากปรับใช้ มันง่ายมากที่จะเอาไปใช้กับแพลตฟอร์มอื่น เหตุผลที่ผมเลือก X, เว็บ และ GitHub trending ก็เพราะนั่นคือที่ที่กลุ่มเป้าหมายของผมอยู่ พวกเทคและเจ้าของธุรกิจของผมแอบซ่อนตัวอยู่ตรงนั้น แหล่งข้อมูลของผมอยู่ตรงนั้น กลุ่มเป้าหมายของผมอยู่บน Instagram เป็นเจ้าของธุรกิจที่เลื่อนฟีดอยู่ กลุ่มเป้าหมายของผมซึ่งก็คือพวกเนิร์ด อยู่บน X และ Twitter ทั้งวัน โพสต์เกี่ยวกับ AI หรืออยู่ในฟอรัม Reddit โพสต์เกี่ยวกับข่าว และ GitHub trending ผมเข้าไปดู repos บน GitHub ตลอดเวลา เพื่อหา Claude skills ใหม่ ๆ และ repo ใหม่ ๆ มาใช้ ผมเลยรู้ว่าแหล่งข้อมูลอยู่ตรงไหน และผมก็เข้าไปค้นหาในแหล่งพวกนั้น

ถ้าคุณอยู่ในวงการอสังหาริมทรัพย์ คุณก็ควรคิดว่าหัวข้อที่กำลังมาแรงในอสังหาฯ ออกมาจากแหล่งไหน แหล่งข่าวไหนให้หัวข้อ trending มากที่สุด เป็นนิตยสาร? เป็น Instagram account เจาะจง? เป็น Twitter account เจาะจง? หรือเป็นคณะกรรมการที่อยู่อาศัยของรัฐบาลกลาง? อะไรก็ตามที่เราได้มา เราก็อยากเอาข้อมูลพวกนั้นมา scrape คุณใช้ Apify scrape อะไรก็ได้แทบทั้งนั้น

แต่โดยหลักแล้วผมใช้ web search ซึ่งก็คือการค้นหาข่าว แล้วก็ GitHub trending เพื่อหา repo ที่กำลังมาแรงรายวัน แล้วมันก็ทำการประเมินแบบคัดสรร (genetic evaluation) ทุกชิ้นที่ scrape มา จะถูกอ่านและให้คะแนน มันให้คะแนนตามความเหมาะกับ archetype — ไอเดียนี้เข้ากับต้นแบบเนื้อหาไวรัลเฉพาะของผมไหม อะไรที่ใช้ได้ผลกับผม ตัวอย่าง ChatGPT มันจะให้คะแนน TAM (Total Addressable Market) — ตลาดที่เข้าถึงได้ใหญ่แค่ไหน เรากำลังทำข่าวที่เข้าถึงตลาดได้กว้างที่สุดไหม เราอยากตีคนให้ได้มากที่สุด โดยเฉพาะกับคอนเทนต์แบบนี้ แล้วก็คะแนน demo-ability — มันมีศักยภาพให้ผมสาธิตวิธีใช้งานได้ไหม แล้วก็ hook ที่ยืนยาว ไม่ตกยุค

ชิ้นไหนที่ไม่เข้ากับ viral archetype ทั้งแปดแบบก็จะถูกข้ามไป แล้วมันก็จะนำเสนอ 10 อันดับคอนเทนต์ที่ดีที่สุดตามคุณภาพ พร้อมแหล่งที่มา เหตุผล และมุมที่แนะนำ แล้วก็บันทึก research log เป็นไฟล์ markdown

ดูตัวอย่างจากตอนที่รันจริงนะครับ มันปล่อยข่าวว่าแอปค้นหาใหม่ของทุกคนฟรี ทุกคนมี iPhone อยู่แล้ว ใช้เว็บเบราว์ซ์ ถามอะไรก็ได้ บลา ๆ บลา และมันมีฐานผู้ใช้มหาศาล ซึ่งเจ๋ง แล้ว Perplexity เพิ่งปล่อย AI demo ฟรีบน livestream อะไรประมาณนี้ แล้วมันก็ไล่เรียงไปทุกอย่าง "Claude Cowork" ที่มี remote access ก็เจ๋งดี ผมไม่เห็นมาก่อนเลย เจ๋ง "สร้าง Claude Code ของคุณเอง" เครื่องมือฟรี เขียนโค้ดง่าย ๆ หรือ agent ใช้แค่ bash เท่านั้น น่าสนใจ เห็นไหมครับว่าของแบบนี้มันดี แบบนี้คือของดีจริง ๆ

มันทำให้ผมเอาข้อมูลพวกนั้นไปอัปโหลดต่อได้ มันควรจะถามให้ผมค้นคว้า มันบันทึกงานวิจัยไว้ให้เราแล้ว และมันสังเกตว่าบทวิเคราะห์ทั้งหมดของผมเกี่ยวกับ Claude Code มันเลยหาข้อมูล Claude Code มาให้เยอะมาก แล้วมันก็ถามว่าอยากเพิ่มไอเดียหมายเลขไหนเข้าไปใน content pipeline "ให้หมายเลข 1 กับ 7 มา" แล้วที่ผมต้องทำก็แค่ กดอย่างนั้นอย่างนี้ ทีนี้มันจะเข้าไปใน Airtable pipeline ที่ผมโชว์ให้ดู และอัปโหลดไอเดียทั้งหมดเป็น record ให้

เราจะได้เรียนวิธีสร้าง content pipeline กันในบทเรียนถัดไป ตรงนี้ยังไม่ต้องกังวล มันแค่สร้าง record ให้เรา ถ้าผมดึงอันนี้กลับมาดู เห็นไหมครับ? "Claude Code remote access" มันเพิ่งเอาเข้าไปวางไว้ตรงนี้ พร้อม resource ทั้งหมด ดูสิ มันให้วัสดุและงานวิจัยครบทุกอย่าง มันให้เหตุผลว่าทำไม Reddit ถึงบอกว่าควรทำวิดีโอนี้ มุมที่แนะนำคืออะไร ให้ข้อมูลครบทุกอย่างที่เราต้องการ

จากตรงนี้เราจะไปต่อกันที่ขั้นตอนถัดไป ซึ่งผมจะโชว์ให้ดูเร็ว ๆ นี้ มันสามารถเอาข้อมูลทั้งหมดที่เราสะสมไว้ ไปสร้างวิดีโอไวรัลได้เลย นี่คือทุกอย่างสำหรับ skill ตัวดึงหัวข้อที่กำลังมาแรง ไปดาวน์โหลด ไปติดตั้ง แล้วบอกผมได้ใน community ถ้ามีปัญหาอะไร ฝากกดติดตามด้วยนะครับ นี่คือทั้งหมด เจอกันบทเรียนหน้าครับ
