## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับสู่วิดีโอเรื่องทริกเกอร์ครับ เราจะพูดถึงการที่เวิร์กโฟลว์ไปทริกเกอร์อีกเวิร์กโฟลว์หนึ่ง ซึ่งเจ๋งมากครับ นี่คือจุดเริ่มต้นของการสร้างโฟลว์แบบหลายเวิร์กโฟลว์ (multi-workflow) ซึ่งดีมาก แทนที่จะสร้างเวิร์กโฟลว์ที่ใหญ่โตมโหฬารในไฟล์เดียว คุณสร้างเวิร์กโฟลว์ง่าย ๆ อันหนึ่ง แล้วมันเรียกอีกอัน แล้วก็เรียกอีกอันได้เรื่อย ๆ ผ่านทริกเกอร์ล้วน ๆ เลยครับ

เราจะสร้างแบบมินิ ๆ ดูกัน หลักการคือ ทริกเกอร์นี้ทำงานเมื่อถูกเรียกจากเวิร์กโฟลว์อื่นครับ มีตัวเลือกให้ทำหลายอย่าง คุณกำหนดได้ว่าจะใช้ fields ที่กำหนดเอง หรือใช้ define using JSON example ถ้าคุณอยากให้ข้อมูลเข้ามาในรูปแบบที่ต้องการ คุณจัดรูปแบบ JSON ได้ เช่น ผมอยากได้แค่ชื่อ อีเมล และเบอร์โทร แล้วก็ส่งค่าพวกนั้นไป มันก็จะส่งแบบนั้น แต่แบบนั้นมันค่อนข้างยืดหยุ่นน้อยครับ ผมส่วนใหญ่จะเลือก accept all data แล้วค่อยมาจัดระเบียบข้อมูลทีหลัง เดี๋ยวผมจะโชว์ให้ดูว่ามันทำงานยังไง

โดยพื้นฐาน เราจะสร้างอีกเวิร์กโฟลว์หนึ่ง เพื่อไปทริกเกอร์เวิร์กโฟลว์นี้ครับ เราจะทำแบบง่าย ๆ ใช้ manual trigger ก่อน แล้วก็ใช้ Airtable และ search records จากนั้นดึงข้อมูลของผมขึ้นมา เช่น ลิสต์คู่แข่งทั้งหมดของผม ถ้ามันโหลดได้ เราจะดึงข้อมูลทั้งหมด แล้วส่งต่อไปยังขั้นถัดไป ซึ่งเจ๋งมากครับ

ลองดูนะครับ YouTube competitors ขอแค่ 10 รายการ พอให้ง่าย ๆ แล้วสิ่งที่ผมอยากทำ ผมจะรันมันเพื่อดูว่ามันทำงานไหม โอเค มันทำงานแล้ว ผมจะปักหมุดโหนดนี้ไว้ มันจะได้ไม่ต้องเรียก API ซ้ำ ๆ ผมจะใส่ค่าแบบตายตัว (hard-coded) ไว้ในนี้แล้ว

จากนั้นสิ่งที่เราจะทำคือ ผมจะรัน execute sub-workflow ซึ่งจะไปทริกเกอร์เจ้าเวิร์กโฟลว์ของเราตรงนั้นครับ ถ้าผม publish แล้วมันชื่อ workflow 10 ผมเข้ามาตรงนี้แล้วค้นหา workflow 10 ได้เลย แล้วก็รันแบบ for all items ดูนะครับ เรามีข้อมูลทั้งหมดส่งเข้ามา แล้วก็ fire ดู มันดูเหมือน fire แล้วนะ เราเห็นข้อความสีเขียว มันเข้ามาทางนี้แล้ว ดูสิครับ 1239 มัน fire แล้ว มันทริกเกอร์แล้ว มันส่งข้อมูลทั้งหมดนี้เข้ามาในนี้ ผมก็อปปี้ไปที่ editor ได้ และมันส่งข้อมูลทั้งหมดจากเวิร์กโฟลว์นั้นมา

จากนั้นผมเข้ามาตรงนี้ แล้วจัดระเบียบข้อมูลที่อยากเก็บไว้ได้ และทุกครั้งที่มันทริกเกอร์ มันจะส่งข้อมูลนั้นมา แล้วให้ข้อมูลที่ผมต้องการกับผม ดูสิ copy to editor แล้วเห็นไหม มีข้อมูลทั้งหมดที่ผมอยากให้ส่งต่อมาซ้ำ ๆ ทุกครั้ง เรียบร้อยครับ

นี่คือทั้งหมดของ sub-workflow trigger หรือที่เรียกว่า executed by another workflow trigger ครับ มันให้คุณทริกเกอร์เวิร์กโฟลว์จากเวิร์กโฟลว์อื่นได้ ถ้ายังไม่เคยดู webhook trigger ไปดูได้นะครับ นี่คือทั้งหมดของวิดีโอนี้ครับ
