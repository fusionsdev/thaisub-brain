## บทนำ

คลิปนี้จากคอร์ส Master Google Ads Conversion Tracking ของ Bob Miles สอนวิธีตั้งค่าข้อมูลลูกค้าใหม่ (new customer) เทียบกับลูกค้าเก่า (returning customer) ผ่านตัวแปร new_customer ใน conversion event snippets ด้วย gtag พร้อมตัวอย่างคำสั่งงานนักพัฒนา (developer) และตัวอย่าง script จำลองที่ต้องไม่ copy-paste ทั้งหมด

## คำแปลเต็ม

คุณสามารถตั้งค่าข้อมูลลูกค้าใหม่ได้ โดยการเพิ่มมันเข้าไปใน snippet ของ conversion event
ผมได้เขียนเทมเพลตอีเมล ที่คุณสามารถใช้เพื่อสั่งงานนักพัฒนา (developer) ได้อย่างถูกต้อง
เพื่อให้เห็นชัดว่าต้องทำอะไรบ้าง
คุณต้องสั่งนักพัฒนาว่าจริงๆ แล้วต้องทำอะไร
นักพัฒนาต้องสร้างพารามิเตอร์ new_customer (ลูกค้าใหม่) ที่ดูในฐานข้อมูล (database) ว่า ลูกค้ารายนี้มีอยู่ในฐานข้อมูลแล้วหรือยัง
ตามนั้น นักพัฒนาต้องใช้ค่า true หรือ false โดย true สำหรับลูกค้าใหม่ และ false สำหรับลูกค้าเก่า
นี่คือส่วนที่ยากที่สุด ที่นักพัฒนาต้องเขียน script หรือโค้ด เพื่อค้นหาข้อมูลลูกค้าใหม่ในฐานข้อมูลของคุณเอง
หลังจากที่คุณสั่งงานนักพัฒนาอย่างถูกต้องแล้ว คุณต้องชี้ไปที่ snippet ของ conversion event ที่นักพัฒนาต้องเพิ่มตัวแปร new_customer
สิ่งสำคัญ คือ ต้องระบุ event ทั้งหมด ที่นักพัฒนาต้องเพิ่มตัวแปร new_customer หรือ URL ที่ใช้ trigger conversion event snippets
เพื่อให้นักพัฒนาหา conversion snippets ทั้งหมดได้ง่าย และคุณแน่ใจได้ว่า ไม่มี conversion event snippet ไหนถูกปล่อยว่างโดยไม่มี new_customer ถ้าสมเหตุสมผล
สมมติว่าคุณเป็น advertiser แบบ lead gen (เก็บลีด) และคุณติดตามฟอร์ม 2 ตัว
เช่น ฟอร์มส่งข้อความติดต่อ (contact form) และฟอร์มขอใบเสนอราคา (quotation form)
คุณต้องสั่งนักพัฒนาให้เพิ่มตัวแปร new_customer ในทั้ง 2 conversion event snippets
ดังนั้น ให้ระบุ event และ/หรือหน้าเว็บตรงนี้ คุณสามารถติดตามได้ทั้งหมด
ผมได้ใส่ตัวอย่าง script ไว้ตรงนี้
คุณจะเห็น script ที่ trigger conversion event ของ gtag
นี่เป็นเพียง script ตัวอย่าง ผมไม่ได้ใส่ค่าจริงลงไป
สำคัญมาก ที่นักพัฒนาไม่ควร copy-paste script ทั้งหมดนี้
มันเกี่ยวกับตัวแปรที่ไฮไลต์เท่านั้น
คุณจะเห็นว่าตัวแปร new_customer ต้องถูกเพิ่มเข้าไปใน conversion event snippet หรือ event snippet อื่นที่คุณใช้ส่งข้อมูล
มันอาจเป็น purchase (การซื้อ) ก็ได้
ที่นักพัฒนาต้องทำ คือ แก้ไข script เหล่านี้ทั้งหมด ผลักค่า (push) นี้ แล้วใส่ค่า true หรือ false ตามว่าเป็นลูกค้าใหม่หรือลูกค้าเก่า
โดยพื้นฐาน นี่คือทั้งหมดที่ต้องทำ มันค่อนข้างง่าย
และมันขึ้นอยู่กับคำสั่งจากคุณ ในฐานะผู้ลงโฆษณา Google Ads
ถ้าคุณเก่งด้านเทคนิคจริงๆ คุณอาจทำเองได้
ถ้าคุณไม่เก่งด้านเทคนิค คุณต้องจ้างนักพัฒนามาทำให้ แต่อย่างน้อยก็ต้องมีคำสั่งที่ถูกต้อง เพื่อให้คนๆ นั้นรู้ว่าต้องทำอะไร
