## บทนำ

## คำแปลเต็ม

ในวิดีโอนี้ ผมอยากจะโชว์ปลั๊กอินที่สะดวกที่สุดเท่าที่ผมเคยใช้ สำหรับลูกค้า WooCommerce ทั้งหมดของผม ปลั๊กอินนี้ชื่อว่า SuiteCode และ SuiteCode ได้พัฒนา pixel manager สำหรับ WooCommerce ที่แก้ปัญหาความต้องการด้านการติดตามทั้งหมดของคุณ คุณสามารถใช้มันสำหรับการติดตาม Conversion ของ Google Ads ใช้สำหรับ enhanced e-commerce ได้ และยังใช้กับแพลตฟอร์มอื่น ๆ อย่าง Microsoft Ads เป็นต้น

ผมชอบปลั๊กอินนี้มากที่สุด เพราะมันรวมเทคนิคการติดตามขั้นสูงไว้ด้วย และนั่นคือจุดที่ปลั๊กอินอื่น ๆ มักจะหยุดอยู่ ปลั๊กอินอื่นมักจะแค่ใส่ conversion ID และ conversion label เพื่อให้คุณติดตาม Conversion ด้วย conversion pixel ของ Google Ads ได้ แต่พวกมันไม่ไปไกลกว่านั้น พวกมันไม่ให้การติดตาม cart data (ข้อมูลตะกร้าสินค้า) ไม่รวม enhanced conversions ไม่รวม conversion adjustments และโซลูชันการติดตามขั้นสูงทั้งหมดนี้ ถูกรวมอยู่ในปลั๊กอินตัวนี้เอง นั่นคือเหตุผลที่ผมชอบมันมาก

ก่อนที่จะเข้าเนื้อหา ผมอยากโชว์ราคาให้ดู เพื่อให้คุณรู้ว่าต้องจ่ายเท่าไหร่สำหรับปลั๊กอินแบบนี้ ผมคิดว่ามันคุ้มมากกับสิ่งที่คุณได้ หนึ่งเว็บไซต์ที่ใช้งาน $10 ต่อเดือน ด้วย $10 ต่อเดือน คุณก็แก้ปัญหาความต้องการและโซลูชันการติดตามทั้งหมดของคุณแล้ว ถ้าคุณมีหลายเว็บไซต์ ถ้าคุณเป็นเอเจนซีและลงโฆษณาให้ลูกค้า WordPress หลายราย คุณจะได้ดีลที่ดีกว่า โดยเว็บไซต์เดียวไม่แพงเกิน $5 ต่อเดือน ผมว่ามันเป็นราคาที่น่าสนใจสำหรับเว็บไซต์ WordPress เกือบทั้งหมด

การติดตั้งปลั๊กอินนี้ค่อนข้างง่าย พอคุณซื้อแล้ว คุณสร้างบัญชี แล้วเขาจะให้ license คุณ จากนั้นคุณก็ดาวน์โหลดปลั๊กอินจากเว็บไซต์ของเขา แล้วอัปโหลดเข้าไปที่ส่วนปลั๊กอินของคุณ คุณไม่ควรค้นหา Pixel Manager ของ SuiteCode จากคลังปลั๊กอิน คุณต้องอัปโหลดมันในฐานะ premium plugin แล้วใส่รายละเอียดบัญชีของคุณ เพื่อให้เขาจับ license ของคุณได้ พอทำทั้งหมดนี้เสร็จ คุณก็เริ่มตั้งค่าปลั๊กอินได้จริง ๆ แล้วผมจะแทรกลิงก์เอกสารประกอบไว้ใกล้กับวิดีโอนี้ด้วย

นี่คือหน้าตาภายในอินเทอร์เฟซ พอติดตั้งเสร็จแล้ว สิ่งแรกที่ต้องทำคือใส่รายละเอียดบัญชีของคุณ ผมจะไม่โชว์รายละเอียดบัญชี เพราะนี่คือลูกค้าที่ใช้งานอยู่จริงของผม มีข้อมูลส่วนตัว จากนั้นพอเปิดใช้งานแล้ว คุณก็เริ่มตั้งค่าปลั๊กอินได้ คุณหามันเจอได้ที่ไหน? ไปที่ WooCommerce แล้วก็ Pixel แล้วคุณจะเห็นหน้าจอแบบนี้ สิ่งที่เห็นตรงนี้คือการตั้งค่าพื้นฐานบางอย่าง

พอคุณสร้าง purchase conversion ใน Google Ads แล้ว คุณก็ไปที่การตั้งค่าแท็ก (tag configuration) สิ่งที่ผมมักจะทำ คือไปที่ Google Tag Manager implementation หรือ gtag setup แล้วมันจะแสดง conversion ID และ conversion label ให้คุณ คุณต้องใช้ทั้งสองอย่าง เพื่อตั้งค่า conversion tag ของ Google Ads อย่างถูกต้อง ตรงนี้คือจุดที่คุณใส่ conversion ID และ conversion label

จากนั้นคุณยังสามารถใส่ Google Analytics 4 ID เพื่อส่งข้อมูล enhanced e-commerce ไปยัง property GA4 ของคุณได้ และถ้าคุณมี container ของ Google Optimize คุณก็ใส่ตรงนี้ได้เช่นกัน ถ้าคุณใช้ Meta คุณสามารถใส่ Meta pixel ตรงนี้ได้ และยังมี pixel อื่น ๆ อีก สมมติว่าคุณลงโฆษณาใน Microsoft คุณสามารถใส่ UET tag ได้ คุณยังสามารถใส่ Twitter pixel, Pinterest Pixel, Snapchat Pixel ได้ และ Pixel Manager จะทำให้ data layer ภายในเว็บไซต์ของคุณถูกเติมข้อมูลอย่างถูกต้อง เพื่อส่งข้อมูล e-commerce ของคุณไปกับแท็กทั้งหมดแยกกัน ในวิธีที่สะดวกและขั้นสูงที่สุดเท่าที่เป็นไปได้

ตรงนี้คือที่ใส่ pixel สำหรับการติดตาม Conversion พื้นฐาน จากนั้นถ้าคุณไปต่อ นี่คือจุดที่ความสนุกเริ่มต้น ตรงนี้คุณกำหนดได้ว่า logic ของยอดคำสั่งซื้อ (order total) ควรเป็นแบบไหน คุณอยากดูยอดรวมออเดอร์รวมภาษีและค่าจัดส่งไหม? หรือไม่อยากรวมภาษีและค่าจัดส่ง? นี่คือค่าเริ่มต้น และผมคิดว่านี่คือค่าเริ่มต้นที่ดีที่สุดที่คุณควรเลือก เพราะสุดท้ายคุณก็ต้องจ่ายภาษีและค่าจัดส่งเองอยู่ดี คุณไม่อยากส่งข้อมูลส่วนนั้นไปยังเครื่องมือโฆษณาของคุณรวมถึง Google Ads

คุณยังสามารถเปิดใช้งานการป้องกันการนับซ้ำของออเดอร์ (order duplication prevention) พวกเขาจะส่ง transaction ID ไปด้วย และนี่จะช่วยตัด Conversion ที่ซ้ำกันใน Google Ads ออกไป สะดวกมาก จากนั้นก็มีส่วนเฉพาะของ Google ตรงนี้คุณสามารถใส่ Google Merchant Center ID ของบัญชีหลักของคุณ และนี่จะเปิดใช้งาน cart data (ข้อมูลตะกร้าสินค้า) ผมมีวิดีโอเฉพาะเกี่ยวกับ cart data ในอนาคต และมันทรงพลังมาก

สิ่งที่ฟีเจอร์นี้ทำได้ คือเปิดใช้งานการติดตามกำไรขั้นต้น (gross profit) และกำไรสุทธิ (net profit) และยังแสดงภายใน Google Ads ว่าผู้คนคลิกสินค้าไหนจากโฆษณารายการสินค้า (product listing ads) แล้วสุดท้ายซื้อสินค้าอะไร คุณสามารถทำการวิเคราะห์ไขว้ (cross-analysis) เพื่อดูว่าผู้คนซื้อสินค้าอะไรในที่สุด อันนี้ทรงพลังมาก

คุณยังสามารถเปิดใช้งาน Google Analytics เพื่อ enhanced e-commerce ได้ด้วยการติ๊กช่องนี้ เพื่อให้ property GA4 ของคุณถูกเติมด้วยพารามิเตอร์ Ecom เช่นกัน อันนี้ก็น่าสนใจ นี่คือ GA4 API secret code ถ้าเหตุการณ์ purchase และ refund จะถูกส่งไปยัง Google ผ่าน Measurement Protocol เพื่อความแม่นยำที่มากขึ้น ในความเห็นของผม คุณควรทำแบบนี้เช่นกัน เพื่อเพิ่มความแม่นยำในรายงาน GA4 ของคุณ

คุณสามารถเปิด enhanced link attribution เปิด Google User ID และยังเปิดใช้งาน Google Ads phone conversion numbers ได้ ถ้าคุณอยู่นอกสหภาพยุโรป และต้องการติดตามสายโทรเข้าด้วย conversion action แบบ phone call มีตัวเลือกการตั้งค่าที่น่าสนใจหลายตัวให้เลือกตรงนี้ และทั้งหมดนี้คุณสามารถดูย้อนกลับได้ในเอกสารประกอบของพวกเขา

คุณยังมีตัวเลือก Google Consent Mode ถ้าคุณต้องการเปิดใช้งาน Google Consent Mode แบบ standard คุณก็ทำได้ตรงนี้ ผมมักใช้ Cookiebot สำหรับการจัดการความยินยอม แต่คุณก็สามารถเชื่อมต่อได้จากภายในปลั๊กอินตรงนี้ ซึ่งในความเห็นผมมีประโยชน์จริง ๆ

จากนั้นเราก็มี dynamic remarketing อันนี้ก็ทรงพลังมาก เพราะเก้าในสิบครั้ง ผู้คนตั้งค่า dynamic remarketing ผิดทาง โดยพารามิเตอร์ e-comm ไม่ได้ถูกตั้งค่าอย่างถูกต้อง และ/หรือส่ง product identifier ID ผิดให้กับ Google Ads ทำให้ Google ไม่สามารถ remarket คนด้วยสินค้าที่พวกเขาดูจริง ๆ

คุณต้องเปิดใช้งานการเก็บข้อมูลกลุ่มเป้าหมาย dynamic remarketing และต้องแน่ใจว่าคุณส่ง product identifier ตัวไหนไปที่ Google Merchant Center และ product identifier ตัวไหนที่ควรส่งเข้าไปใน data layer ของ remarketing นี่คือสิ่งที่คุณสามารถตรวจสอบได้ในฟีด Google Merchant Center ของคุณ คุณไปที่ส่วน IDs แล้วเช็ค ID ว่า ID นี้เป็น post ID หรือ SKU ส่วนใหญ่แล้วมันจะเป็น post ID แต่บางครั้งคนก็ใช้ product identifier แบบอื่นเช่นกัน ดังนั้นต้องตรวจสอบสามรอบ เพราะตรงนี้คือจุดที่หลายคนทำพลาด พูดตรง ๆ เลย

ก็ประมาณนี้ นี่คือการตั้งค่าที่สำคัญที่สุด ผมคิดว่านี่คือปลั๊กอินที่น่าประทับใจและล้ำหน้าที่สุดตัวหนึ่งที่คุณใช้กับ WooCommerce ได้ ผมใช้มันกับลูกค้า WooCommerce ทั้งหมดของผม เพราะมันใช้ได้ผลเสมอ และมันรวมฟีเจอร์ขั้นสูงอย่างที่ผมบอกไปแล้ว เช่น cart data, enhanced conversions อะไรพวกนั้น และมันช่วยประหยัดเวลาคุณได้มาก ด้วยค่าธรรมเนียม license เพียงเล็กน้อย ดังนั้น ลองไปดูและทดสอบด้วยตัวเองดู
