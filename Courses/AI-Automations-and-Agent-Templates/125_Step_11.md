## บทนำ
วิดีโอนี้สอนวิธีตั้งค่า AI voice agent (เอเจนต์เสียง) ด้วย ElevenLabs เพื่อรับโทรศัพท์และจองคิวนวดให้ร้านนวดท้องถิ่น โดยใช้ Conversational AI ของ ElevenLabs กำหนดบทบาทและโครงสร้างการสนทนา เชื่อมต่อกับ Cal.com ซึ่งเป็นเครื่องมือจองคิว เพื่อให้เอเจนต์ดึงเวลาว่างและจองนัดหมายอัตโนมัติ พร้อมปรับแต่งเสียงและโมเดล AI

## คำแปลเต็ม

สิ่งแรกที่เราจะตั้งค่าคือ ElevenLabs ไปที่ step number ตรงนี้ แล้วคุณจะเห็น ElevenLabs IO นี่คือเครื่องมือที่เราจะใช้จัดการฟีเจอร์ voice agent ของเรา คุณแค่สมัครบัญชีฟรี แล้วคลิก go to app และตรงส่วนด้านซ้ายจะมีหัวข้อชื่อ Conversational AI ไปที่ agents (เอเจนต์) ตรงนี้คลิก new agent (เอเจนต์ใหม่) ตั้งชื่อให้มัน ฉันจะเรียกมันว่า demo voice agent แล้วเลือกเทมเพลต blank (ว่างเปล่า) แล้วคลิก create

มันจะเปิดการตั้งค่านี้ให้อัตโนมัติ ตรงนี้เราสามารถตั้งภาษาของเอเจนต์ได้ ฉันจะปล่อยเป็นภาษาอังกฤษ ตรงนี้คือ first message (ข้อความแรก) ซึ่งเป็นข้อความต้อนรับ หลังจากมีคนโทรเข้ามา มันควรตอบอย่างไร? ฉันเตรียมไว้ให้แล้ว กรณีการใช้งานตรงนี้คือร้านนวดท้องถิ่นที่ใช้ AI voice agent จัดการการจองคิวนวด เราจะพิมพ์สิ่งนี้เป็นข้อความแรก คุณสามารถปรับข้อความนี้ให้เข้ากับธุรกิจหรือสถานการณ์เฉพาะของคุณได้

จากนั้นเลื่อนลงมาด้านล่าง ตรงนี้เรามีส่วน system ซึ่งเป็นจุดที่เรากำหนดว่า AI agent ของเราควรทำอะไร? และควรใช้เครื่องมืออะไรในการทำงานที่ได้รับมอบหมาย? โดยพื้นฐานมันมีหน้าที่สองอย่าง มันต้องหาช่วงเวลาว่างจากผู้ใช้ เช่น หาเวลาว่างถัดไปเพื่อจองนัดหมาย แล้วก็ต้องทำการจองนัดหมาย ตรงนี้เราแค่คัดลอกข้อความนี้วางลงไป และอันนี้ก็สำหรับกรณีร้านนวด คุณต้องแก้ไขส่วนต่าง ๆ เหล่านั้น

ขั้นตอนสำคัญที่เรามีตรงนี้คือโครงสร้าง (structure) มีหลายส่วน ส่วนแรกคือสิ่งที่มันต้องทำ: your booking assistant (ผู้ช่วยจองคิวของคุณ) นี่คือรายละเอียดเกี่ยวกับธุรกิจ และตรงนี้คือ services (บริการ) ที่เรามีให้ นาทีนี้ฉันจะกลับมาที่นี่ เพราะตรงนี้เราต้องใส่ event ID (รหัสกิจกรรม) เราต้องกำหนดว่าเรามีบริการอะไรบ้าง เพื่อให้ AI agent รู้ เพราะมันสำคัญต่อการเปรียบเทียบการจอง เนื่องจากแต่ละบริการมีปฏิทินเฉพาะที่ผูกไว้ และเราจะตั้งค่านี้ในส่วนถัดไปของวิดีโอ

ตอนนี้ฉันอยากอธิบายให้คุณฟัง ตรงนี้คือคำอธิบายว่ามันควรทำอะไร จากนั้นเรามี conversation flow (ลำดับการสนทนา) นี่คือสิ่งที่เกิดขึ้นหลังจากมีคนโทรเข้า อย่างแรกมันจะทักทายด้วยข้อความ จากนั้นถามว่าสนใจบริการนวดแบบไหน สนใจบริการไหน มีหลายกรณีบริการที่แตกต่างกัน มีนักนวดที่ชอบเป็นพิเศษไหม? มาเป็นครั้งแรกหรือเปล่า? คุณปรับแต่งส่วนนี้ได้ คุณ甚至可以เพิ่มคำถามเพิ่มเติมใน conversation flow ได้ถ้าต้องการ

และเมื่อมันเก็บข้อมูลครบแล้ว มันจะบอกว่าต้องทำอะไรต่อ เพื่อหาช่วงเวลาว่าง เราจะตั้งค่า tool (เครื่องมือ) สำหรับสิ่งนั้น และมีอีกสองสามอย่างที่เราจะกลับมาทำต่อเมื่อเราตั้งค่า voice agent ทั้งหมด เพราะเราต้องแก้ไขมัน

สิ่งแรกที่ต้องทำคือแทนที่ event IDs เหล่านี้ตรงนี้ ในการทำ เราจะไปที่แพลตฟอร์มอื่นที่เรามีตรงนี้ ชื่อ Cal.com ซึ่งเป็นเครื่องมือจองคิวที่คุณสมัครบัญชีฟรีได้ เมื่อเข้าใช้งานครั้งแรก คุณไปที่ event types (ประเภทกิจกรรม) ตรงนั้นฉันมีบริการนวดสองสามรายการของธุรกิจนี้อยู่แล้ว ขอเดleteอันหนึ่งก่อน ฉันจะโชว์วิธีตั้งค่า ตรงนี้คุณแค่ใส่ประเภทการจองหรือบริการที่คุณมี และใช้เวลานานแค่ไหน? การนัดหมายเหล่านี้ยาวเท่าไหร่?

จากนั้นคลิก new สมมติว่าฉันอยากสร้างบริการนวดใหม่ ชื่อ Deep Massage (นวดลึก) ตั้งชื่อมัน จากนั้นกำหนดระยะเวลา (duration) แล้วคลิก continue จากนั้นคุณสามารถกำหนดช่วงเวลาให้บริการ (availability) ได้ ตรงนี้คุณใส่... ไปที่ availability แล้วสร้างตารางเวลา (schedule) ได้ นี่คือเวลาทำการของคุณหรือเวลาที่บริการพร้อมให้บริการ และเมื่อตั้งค่าเสร็จ คุณไปที่ event types แล้วกำหนดเวลาว่างเหล่านี้ให้กับบริการ

ตรงนี้คุณเห็นว่าฉันกำหนดเวลาเหล่านี้ให้แล้ว และนี่คือช่วงเวลาว่าง แต่ส่วนสำคัญคือสิ่งที่เราต้องการคือ ID ตรงนี้ด้านบน แต่ก่อนจะเก็บมัน กลับไปที่ Conversational AI agent ของฉันก่อน ตอนนี้ฉันอยากเพิ่มบริการนวดใหม่ที่เพิ่งพิมพ์ไป ชื่อ Deep Massage ระยะเวลา 90 นาที คุณไม่จำเป็นต้องระบุราคาถ้าไม่ต้องการ แต่ฉันแค่ใส่ไว้ และตรงนี้เรามีจุดต่าง ๆ หลายจุด ตรงนี้เรามีตัวเลือกการนัดหมาย deep massage ดังนั้นคุณอาจต้องแทนที่ทั้งหมดด้วยชื่อบริการเฉพาะของคุณ แล้วเรามีอีกหนึ่งอัน รวมเป็นสี่ตัวเลือก ตรงนี้คือ deep massage 90 นาที ราคา 120 บาท เหมาะสำหรับหลังวันที่เหนื่อยล้า เท่านี้สำหรับตอนนี้

ตอนนี้เราต้องเก็บ ID ทั้งหมดเหล่านี้ ขอบันทึกก่อน แล้วเราจะได้ ID เหล่านี้ตรงนี้ กลับไปที่ event types แล้วดูทีละขั้นตอน เริ่มจากอันที่สาม อันนี้คือ quick massage (นวดด่วน) ของฉัน และตรงนี้มี ID ฉันคัดลอกค่านี้ และนี่คือบริการแรกของฉัน กลับไปที่อันถัดไป Relaxation massage (นวดผ่อนคลาย) นั่นคืออันนั้น Express relief (บรรเทาเมื่อยล้า) ใส่สิ่งนี้ลงตรงนี้และตรงนี้ แล้วสุดท้ายเรามี deep massage ของเรา ได้แล้ว คลิก save ตอนนี้เราเชื่อมต่อมันแล้ว

สิ่งที่เราอยากปรับตรงนี้คือไปที่ settings แล้วปรับการตั้งค่า นี่คือ voice time (เวลารอตอบ) เราพิมพ์ลบหนึ่ง (-1) และตรงนี้เราก็พิมพ์ลบหนึ่งด้วย นี่คือเวลาที่เมื่อผู้ใช้เงียบ เอเจนต์เสียงควรรอนานแค่ไหนก่อนจะพูดอีกครั้ง? และเมื่อฉันพิมพ์ลบหนึ่ง มันควรจะรอจนกว่าผู้ใช้จะตอบเสมอ และนั่นสำคัญมาก ไม่เช่นนั้นมันอาจขัดจังหวะการสนทนากะทันหัน

ตรงนี้คือ maximal conversation duration (ระยะเวลาสนทนาสูงสุด) มันอยู่ได้นานแค่ไหน? การจองคิวควรใช้เวลาไม่เกิน 10 นาที ฉันจึงใส่ 600 วินาทีลงไป เท่านี้ คลิก save

มาถึงอีกส่วนที่สำคัญมากที่เราจะตั้งค่า นั่นคือเสียง (voice) ตรงนี้คุณเลือกเสียงที่ต้องการได้ ขอเลือกเสียงผู้หญิงสักเสียง คุณ甚至可以อัปโหลดเสียงของคุณเอง ไปที่ส่วนนั้น แล้วอัปโหลดเสียงของคุณ หรือจะบันทึกเสียงตัวเองแล้วเลือกใช้ก็ได้ แต่ฉันจะเลือกจากเสียงที่มีให้ และเท่านี้ คลิก save

อีกตัวเลือกที่ตั้งค่าได้คือ LLM model ซึ่งก็คือโมเดล AI ที่ขับเคลื่อนการสนทนา อาจเป็นอะไรก็ได้ที่คุณต้องการ ตรงนี้คุณเห็นโมเดลและราคาต่าง ๆ ฉันปล่อยไว้ที่ 2.0 Flash คุณทดลองกับโมเดลอื่นได้ อาจให้ผลลัพธ์ดีกว่า แต่ฉันปล่อยไว้แบบนี้ มันเป็นหนึ่งในโมเดลที่ถูกที่สุดและยังใช้งานได้ดี คุณตั้งค่า temperature (อุณหภูมิ) ของโมเดลได้ ฉันปล่อยไว้แบบนี้ ไม่สำคัญเท่าไหร่ ไม่จำเป็นต้องปรับถ้าไม่ต้องการ แต่ตอนนี้ขอแค่ตั้งค่าให้ถูกต้อง

อีกอย่างที่ฉันทำคือลบเครื่องมือ end call (จบการสนทนา) ออก เพราะบางครั้งมันอาจตัดสายโดยไม่ตั้งใจ ฉันอยากให้ผู้ใช้เป็นคนจบการสนทนาเอง ฉันจะลบมันออก
