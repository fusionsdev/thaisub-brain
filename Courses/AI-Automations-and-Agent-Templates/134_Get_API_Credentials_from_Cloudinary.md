## บทนำ
วิดีโอสาธิตวิธีรับ API credentials ของ Cloudinary โดยเริ่มจากการกรอก user และ password เข้าไปที่เมนู API เพื่อสร้างคีย์ใหม่ จากนั้นนำ API key และ API secret ไปใช้ในระบบ

## คำแปลเต็ม

ตรงนี้ผมต้องกรอก user และ password ตอนนี้ผมเจออันนี้อยู่ข้างใต้ แล้วก็เข้าไปที่เมนู API และตรงนั้นคุณสามารถสร้างคีย์ใหม่ได้ ตอนแรกคุณจะได้รับอีเมลยืนยัน และเมื่อคุณกรอกข้อมูลแล้ว คุณก็จะสามารถสร้าง API key ใหม่ได้ ซึ่งผมทำขั้นตอนนี้ไปแล้ว และตรงนี้ API key จะถูกใส่ในช่อง user จากนั้นผมต้องใช้ API secret เพื่อให้ได้มา ผมต้องกรอกรหัสยืนยันที่ได้รับทางอีเมลด้วย จากนั้นก็คัดลอกและวางลงไปตรงนี้ได้ แล้วก็คลิก แล้วมันก็จะแสดงขึ้นมาและถูกเลือกไว้
