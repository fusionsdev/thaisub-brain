## บทนำ
คลิปนี้สอนวิธีติดตั้ง Google Sheet สำหรับสรุปวิดีโอ YouTube อัตโนมัติโดยใช้ AI ของ Anthropic (Claude) มาเขียนบทสรุป เริ่มจากคัดลอกชีต ทำการ authorize และ install เมนูเสริม แล้วกรอก API key สามตัว ได้แก่ YouTube API key, transcript API จาก Rapid API และ Anthropic API key จากนั้นแค่วางลิงก์วิดีโอ YouTube ลงในชีต ระบบจะดึงคำบรรยายและสรุปเนื้อหาให้อัตโนมัติ

## คำแปลเต็ม
ในวิดีโอนี้ผมจะโชว์วิธีตั้งค่า Google Sheet สำหรับสรุปวิดีโอ YouTube ที่ใช้ Claude AI ในการสร้างบทสรุป ด้านล่างนี้คุณจะเจอลิงก์ไปยัง Google Sheet นี้ แล้วคุณคลิก make a copy

มีบางอย่างที่คุณต้องกรอกลงใน Google Sheet ข้อมูลสองสามอย่างเพื่อให้มันตั้งค่าได้ แต่จริงๆ แล้วง่ายมาก อย่างที่คุณจะได้เห็น เราได้เตรียมช่อง API keys ต่างๆ ที่ต้องกรอกไว้ตรงนี้แล้ว

แต่เราต้องรอจนกว่าตรงนี้จะมีเมนูแบบกำหนดเอง (custom menu) โผล่ขึ้นมา เราต้องทำขั้นตอน authorize และขั้นตอนติดตั้งให้เสร็จก่อน มันอาจใช้เวลาโหลดไม่กี่วินาที จากนั้นเราถึงค่อยเอา keys เหล่านั้นมากรอกตรงนี้

ตอนนี้มันโหลดเป็น custom menu แล้ว คุณต้องคลิก authorize จากนั้นต้องทำขั้นตอนการอนุมัติให้เสร็จ ผมจะไม่โชว์ขั้นตอนนี้ให้ดู เพราะมันอาจมีข้อมูลที่ละเอียดอ่อน แต่คุณแค่ทำตามขั้นตอนไป บางจุดมันมีข้อความบอกว่าตรงนี้คุณต้องคลิกที่ [ปุ่ม] ซึ่งมีวงเล็บกำกับไว้ แต่ไม่เป็นไร แล้วคุณคลิก แล้วก็ทำขั้นตอนการอนุมัติต่อได้ พอทำเสร็จมันจะขึ้นว่าสำเร็จ (successful) อย่างที่เห็น ตอนนี้มันทำงานได้แล้ว

ขั้นตอนต่อไปคือ ผมต้องคลิก install ใช่ เยี่ยม แล้วสิ่งที่เหลือก็แค่เอา API keys มาลง ตอนนี้ผมจะไม่โชว์ว่าหา keys เหล่านี้จากที่ไหน

สำหรับ YouTube API key ผมมีบทสอนอยู่แล้ว คุณไปดูวิธีขอ YouTube API key จาก Google Cloud Console ได้ นี่หาง่ายมาก จากนั้นคุณต้องเอา API key สำหรับ transcript API จาก Rapid API พอได้มาแล้วก็ใส่ไว้ตรงนี้

แล้วเราต้องมี Anthropic API key อันนี้ก็ง่ายมากเช่นกัน คุณไปที่ console.anthropic.com ลิงก์อยู่ด้านล่างวิดีโอนี้ด้วย ตรงนั้นคุณล็อกอิน แล้วถ้าคุณยังไม่มีเงินในบัญชี คุณต้องเติมเงินสักประมาณ $5 แล้วคุณก็ไปที่ API keys ตรงนั้นคลิก create a new key พอสร้างเสร็จก็วางมันลงตรงนี้เหมือนกัน

ผมจะกรอก API keys ของผมเอง ผมจะไม่โชว์ให้คุณดูเพราะเป็นข้อมูลที่ละเอียดอ่อน แล้วพอกรอกครบแล้ว เราจะไปที่รายการวิดีโอ ตอนนี้เราทดสอบได้แล้ว

ผมเอา URL ของวิดีโอ YouTube มาแล้ววางตรงนี้ แล้วมันควรจะกรอกข้อมูลตรงนี้ให้ทันที ผมต้องคลิก allow เพื่อให้มันดึงคำบรรยายมา บันทึกไว้ในไฟล์เอกสาร แล้วผมยังมีช่องทำเครื่องหมาย summarize ให้คลิกด้วย ผมคลิกมัน แล้วมันจะแสดงข้อความ summarizing video จากนั้นอาจใช้เวลาไม่กี่วินาที ขึ้นอยู่กับความยาวของวิดีโอ แล้วบทสรุปจะถูกแทรกมาตรงนี้ อย่างที่เห็น นี่คือบทสรุปของวิดีโอ ตอนนี้ชีตนี้ก็ทำงานได้แล้ว
