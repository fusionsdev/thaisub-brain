## ประเด็นหลัก

- Hermes Agent เปิดตัว Botmode ฟีเจอร์ใหม่ เป็นทางเลือกฟรีของ Grokbot จาก xAI ปล่อยเป็น public beta หนึ่งวัน ประกาศโดย Technium ผู้ร่วมก่อตั้งและวิศวกรหลักของ Hermes Agent และ Nous Research เมื่อมีคนทักว่าคล้าย Grokbot เขาตอบสามคำว่า "That's the point"
- เดิม Hermes Agent ทำงานแบบ session (เปิดแชท มอบงาน เปิด session ใหม่) ซึ่งเละเร็วเพราะทุกอย่างดูเป็นรายการแชทยาวๆ เหมือนกันหมด Botmode เปลี่ยนเป็น roster (รายชื่อบอท) แผงด้านซ้ายของจอ บอทแต่ละตัวมี avatar บุคลิก แชท ความจำ และตารางงานของตัวเอง สร้างบอทใหม่ได้ในไม่กี่วินาที และ agent profiles เดิมจะโผล่เป็นบอทอัตโนมัติหลังติดตั้ง plugin
- จุดเด่นสำคัญ: ในส่วน advanced ของแต่ละบอท ปักหมุดโมเดลเฉพาะได้ (research bot ใช้โมเดลหนึ่ง, writing bot อีกตัว, inbox bot ใช้ local model) — ทุกบอทคิดด้วยสมองคนละตัวได้ ซึ่ง Grokbot ไม่ให้
- Grokbot รันบนโมเดล xAI ในคลาวด์ xAI ส่วน Botmode เป็นโอเพนซอร์ส MIT license ฟรี รันบนเครื่องตัวเอง ใช้โมเดลอะไรก็ได้ และแต่ละบอทมีความจำแยกกัน ไม่ปนกัน
- ฟีเจอร์หลัก: bot-to-bot messaging ผ่าน agent inbox (แสดงที่มาของข้อความ), mentions (@ชื่อบอท ส่งงานข้ามบอทได้ เช่น "@researcher ดึงข้อมูลล่าสุดมาให้หน่อย"), routines (งานประจำตามตาราง เช่น สรุปกล่องข้อความทุกเช้า ตรวจ niche ตอนเที่ยง ดึงไอเดียคอนเทนต์ทุกวันจันทร์)
- ตัว routine รันบน Hermes cron jobs เดิม ไม่มีการต่อเติมอะไรใหม่ บอทใน Botmode ก็คือ Hermes profile ซึ่งมีอยู่แล้ว ทำให้ไม่มี core patches ไม่มี daemon ไม่มีระบบเก็บข้อมูลเพิ่ม และ plugin ที่พยายามหาทางเลี่ยงระบบจะพัง ส่วน Botmode ใช้พื้นผิวมาตรฐานที่ Hermes มีอยู่แล้ว (อุปมาบ้านบนฐานราก vs บ้านต้นไม้)
- ทุกบอทมีไฟล์ personality (ไฟล์บุคลิก) กำหนดวิธีพูด/พฤติกรรม การ cloning ก็อปปี้ทุกอย่างรวมถึงความจำ และ avatar มีรูปทรงเรขาคณิต 7 รูปทรง 10 สี ตากระพริบเป็นไฟสถานะเวลา Bot ทำงาน
- ข้อจำกัดของ beta: ต้องติดตั้งบนเครื่องที่รัน desktop app (ไม่ใช่เซิร์ฟเวอร์/Home server), ยังใส่บอทหลายตัวใน group chat ไม่ได้, การส่งข้อความระหว่างบอทไม่ใช่แบบขัดจังหวะทันที (live interrupts อยู่ในแผนอนาคต), และการลบบอทไม่ได้อยู่ในอินเทอร์เฟซ (ทำผ่าน command line เพื่อกันลบพลาด)
- ผู้พูดชี้ว่า "เครื่องมือเฉพาะไม่สำคัญเท่ารูปแบบ (pattern)": ทีมเอเจนต์ที่มีชื่อ มีงาน มีความจำ มีตารางงาน คุยกันเองได้ — ทักษะนี้ถ่ายทอดไปทุกเครื่องมือในอนาคต (Claude อาจปล่อยอะไรคล้ายๆ ด้วย) และย้ำว่าไม่ใช่ของนักพัฒนาเท่านั้น เพราะ routine อย่าง "สรุปกล่องข้อความทุกเช้า" คืองานเจ้าของธุรกิจ
- ข้อสรุป: Grokbot โชว์ให้โลกเห็นรูปแบบทีมเอเจนต์ AI ส่วน Hermes Botmode ทำให้มันฟรี โอเพนซอร์ส และเป็นของคุณ (โมเดลต่อบอท ความจำต่อบอท การส่งข้อความระหว่างบอท) คนที่ตั้งค่า roster ตอนนี้จะได้ความจำสะสมหลายเดือนก่อนคนอื่น
- โปรโมต AI Profit Boardroom (aiprofitboardroom.com): Hermes playbook ฉบับเต็ม, บทเรียนรายวัน, คอลโค้ชชิ่ง 4 ครั้ง/สัปดาห์, Agent Operating System + ไฟล์ zip, แผน 30 วัน, member map, สมาชิกกว่า 3,700 คน
