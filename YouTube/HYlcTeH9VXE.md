# สรุป: Trying Out Matt Pocock's /grill-me Skill in Hermes Agent
- **ช่อง:** Tonbi's AI Garage · **ความยาว:** ~18 นาที (1094 วินาที) · **ลิงก์:** https://www.youtube.com/watch?v=HYlcTeH9VXE

## ประเด็นหลัก
- ผู้พูดแนะนำสกิล /grill-me ของ Matt Pocock จาก repo ชื่อ mattskills บน GitHub ซึ่งเป็น agent skill ที่กำลังฮิต โดยมีเวอร์ชันขั้นสูงกว่าชื่อ grill with docs.
- จุดประสงค์ของสกิลคือการ align (ปรับให้ตรงกัน) ระหว่างผู้พัฒนาและเอเจนต์ AI ก่อนเริ่มโปรเจกต์ เพื่อให้มีวิสัยทัศน์และโฟกัสเดียวกัน และลดการเสียเวลาและ tokens ในช่วงแรกของงาน.
- ผู้พูดนำสกิลไปใช้กับโปรเจกต์จริงของตัวเองชื่อ Frontier Labs ซึ่งเป็นเกม simulation แนว SimCity ที่ผู้เล่นเป็น AI lab แข่งขันกับ lab อื่น ต้องบริหารสมดุลทรัพยากรและเรียนรู้เรื่อง AI ไปในตัว.
- การใช้งานใช้ Hermes Agent กับโมเดล GPT-5.6 soul โดยผู้พูดตอบคำถามทีละข้อ พร้อมเลือกใช้คำแนะนำ (recommendation) ที่เอเจนต์เสนอเป็นส่วนใหญ่.
- คำถามไล่ตั้งแต่ gameplay แบบ turn-based แคมเปญ 5 ปี กลุ่มผู้เล่น จนถึงรายละเอียดเทคนิค เช่น tech stack แพลตฟอร์มเว็บ MVP demo และ vertical slice.
- สกิลมีระบบจับเวลา 120 วินาทีต่อคำถาม หากไม่ตอบ เอเจนต์จะตัดสินใจตามคำแนะนำแทน และยังสามารถจับความขัดแย้งของคำตอบก่อนหน้าได้เอง.
- ผ่านไป 71 คำถามใน 42 นาที ทั้งสองฝ่ายได้ความเข้าใจร่วมกัน (shared understanding) โดยยังไม่มีการ implementation จนกว่าผู้ใช้จะยืนยันและขอแยกต่างหาก.
- หลังยืนยัน ผู้พูดขอให้บันทึกการตัดสินใจทั้งหมดเป็นแผน ซึ่งออกมาเป็นไฟล์ markdown ที่มีโครงสร้าง implementation plan พร้อม tasks และ timeline ครบถ้วน.
- ข้อแนะนำจากผู้พูด: ควรกันเวลาไว้ประมาณ 1 ชั่วโมง เพราะต้องอ่านและคิดเยอะ แต่คำถามที่ได้มีคุณภาพ เจาะจงประเด็นสำคัญ ไม่ใช่คำถามสุ่ม.
- สกิลนี้ช่วยให้ผู้พูดกลั่นกรองวิสัยทัศน์ของโปรเจกต์ที่ตอนแรกคลุมเครือให้ชัดเจนขึ้นก่อนลงมือสร้างจริง.

## ความเห็นสรุป
วิดีโอนี้สาธิตการใช้งานจริงของ /grill-me ได้ชัดเจนและน่าเชื่อถือ โดยแสดงให้เห็นทั้งกระบวนการ 71 คำถาม พฤติกรรมของเอเจนต์ และผลลัพธ์ที่ได้จริง. จุดแข็งคือการอธิบายประโยชน์ของการ align ก่อนเริ่มงาน พร้อมข้อควรระวังเรื่องเวลาที่ต้องใช้. เหมาะสำหรับคนที่รัน agents เองและอยากให้โปรเจกต์เริ่มต้นอย่างมีทิศทางเดียวกัน.
