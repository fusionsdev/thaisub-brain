## บทนำ

ในบทเรียนนี้ เราจะมาเรียนรู้วิธีวิเคราะห์คอนเทนต์ทั้งหมดของคุณด้วย Claude Code ผ่านสกิลวิเคราะห์คอนเทนต์ที่ผู้สอนเตรียมไว้ให้ ซึ่งจะวิเคราะห์ทั้งภาพและทรานสคริปต์ของวิดีโอ พร้อมดึงข้อมูลเชิงลึกอย่างโครงสร้างฮุก โครงสร้างบอดี้ และรูปแบบภาพ เพื่อให้คุณรู้ว่าคอนเทนต์แบบไหนที่กำลังเวิร์กจริง ๆ ก่อนตัดสินใจสร้างคอนเทนต์ต่อ

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่อีกหนึ่งบทเรียนครับ ในบทเรียนนี้ เราจะสอนคุณวิเคราะห์คอนเทนต์ทั้งหมดของคุณด้วย Claude Code ถ้าคุณยังไม่ได้ดูบทเรียนก่อนหน้านี้เกี่ยวกับคอนเทนต์ Instagram เราสร้างเวิร์กโฟลว์เวอร์ชันเรียบง่ายไว้แล้ว ที่ดาวน์โหลดคอนเทนต์ทั้งหมดของเรามาไว้ในที่เดียวที่ใช้งานง่าย เราจะมีเมตริกทั้งหมดของคอนเทนต์เราอยู่ครบ ทุกอย่างเลยครับ

และถ้าคุณตั้งค่ามันไว้แล้ว มันควรจะรันทุกวันและอัปเดตข้อมูลเรื่อย ๆ ตรงนี้คือจุดที่เราต้องการของสำคัญ เราอยากรู้ฮุกและโครงสร้างฮุก ซึ่งเดี๋ยวผมจะแจกแจงว่าทั้งหมดนี้หมายถึงอะไรในอีกไม่กี่วินาที แต่เราต้องการข้อมูลทั้งหมดนี้ เพื่อที่เวลาตัดสินใจเรื่องคอนเทนต์ต่อจากนี้ เราจะรู้จริง ๆ ว่าอะไรเวิร์กบ้าง ใช่ไหมครับ? เพราะเมตริกบอกว่าดีเป็นเรื่องหนึ่ง แต่การรู้ว่าพูดอะไรลงไปจริง ๆ เป็นอีกเรื่องหนึ่ง

สิ่งที่เราจะทำคือเราจะดาวน์โหลด Claude Skill ผมเตรียมสกิลให้คุณแล้ว มันจะวิเคราะห์คอนเทนต์ทั้งหมดของคุณทั้งแบบภาพ และวิเคราะห์ทรานสคริปต์ด้วย มันจะทำได้ทั้งการวิเคราะห์ภาพและการวิเคราะห์ข้อความ ซึ่งโคตรเจ๋งเลย เราจะตั้งค่ามันก่อน แล้วพอตั้งเสร็จ ผมจะเจาะลึกว่าข้อมูลแต่ละจุดคืออะไร ทำไมคุณถึงต้องใช้มัน และมันจะช่วยให้คุณคอนเทนต์ไวรัลและเติบโตบนโซเชียลมีเดียได้ยังไง เริ่มกันเลยครับ

ก่อนอื่น เราจะเข้าไปที่โฟลเดอร์นี้ ในโฟลเดอร์คุณจะมี Claude Skill อยู่ มีไฟล์ดาวน์โหลดอยู่ตรงนั้น สิ่งที่ผมจะทำคือเปิด Claude Code ขึ้นมา เริ่มเซสชันใหม่ แล้วเราก็แค่ลากไฟล์วางลงไป มันจะช่วยเราตั้งค่าให้เอง ง่ายมาก จากนั้นเราก็รันและเริ่มได้เลย

สำหรับบทเรียนนี้ เราจะต้องใช้ของสองสามอย่าง เราจะต้องใช้ OpenAI API key ซึ่งผมจะพาคุณไปดูวิธีได้มา และเราจะต้องใช้ Gemini API key ซึ่งผมก็จะพาไปดูเหมือนกัน แล้วผมยังจะให้สกิลที่คุณต้องติดตั้ง ซึ่งมันจะทำงานทั้งหมดให้คุณเอง สกิลวิเคราะห์ตัวนี้ ผมใช้มันมาหลายเดือนแล้ว เรียกว่าเก็บรายละเอียดมาให้คุณเต็มที่แล้วครับ ตัวนี้จะเจ๋งมาก เรามาลองรันมันกัน

โอเค มันดูเหมือนจะดึงไฟล์ .env ขึ้นมา ถ้าคุณดูบทเรียนก่อนหน้านี้ ผมเพิ่งรู้ว่าตอนที่ผ่านมามันใส่ค่าแค่ระดับโปรเจกต์เท่านั้น ดังนั้นอันนี้มันจะดึงไฟล์ .env ทั้งระบบของคุณขึ้นมา คุณไม่ต้องคอยเข้า ๆ ออก ๆ เปลี่ยนไฟล์ใหม่บ่อย ๆ แบบนั้นแล้ว

เราจะต้องกรอก token ต่าง ๆ ให้ครบ ผมจะย้อนกลับไปที่บทเรียนเก่า เพื่อใส่ค่า Meta access token, Instagram user, project และ anon key ถ้าคุณยังไม่ได้ดูบทเรียนก่อนหน้านี้ ผมสอนวิธีทำทั้งหมดนั้นไว้แล้วในบทเรียนพวกนั้น คุณจะมี token พวกนี้ทั้งหมด มันไม่โชว์เพราะผมรีสตาร์ทไป แต่เราจะต้องใช้ OpenAI key และ Gemini key ด้วย เดี๋ยวผมจะพาคุณดูในอีกแป๊บนะครับ

โอเค เรามี key ครบแล้ว ถ้าคุณยังไม่ได้ย้อนกลับไปดูบทเรียนเก่า ไปดูได้เลย เพื่อที่คุณจะได้ key พวกนี้ทั้งหมดสำหรับไฟล์ .env ของคุณ เราจะได้ OpenAI key หนึ่งอันและ Gemini key หนึ่งอัน ไฟล์ของคุณควรมีหน้าตาแบบนี้: ผมมี key อื่น ๆ ครบอยู่ข้างบน เพียงเพื่อเหตุผลด้านความปลอดภัย ผมล็อกมันไว้ เรามี OpenAI และ Gemini อยู่

วิธีได้มา คือเราจะไปที่หน้า OpenAI billing ครับ ผมจะพิมพ์ OpenAI billing แล้วเข้าไปที่หน้า overview จากนั้นเราก็แค่ล็อกอิน ผมเองยังไม่เคยใช้แอป OpenAI เลยด้วยซ้ำ แต่ใช้ API ซึ่งตลกดี ใช่ครับ ถ้าเข้าไปแล้ว มันจะบอกว่า pay as you go คุณมี credit balance อยู่ เพื่อเพิ่มเครดิต คุณก็แค่กด add credit แล้วเติมเงินตามที่ต้องการ ผมเติมประมาณสิบบักเกอร์ ใช้ได้ทั้งเดือนหรือนานกว่านั้นด้วยซ้ำ พูดตามตรง แค่เติมเครดิตเข้าไป

จากนั้นสิ่งที่ต้องทำคือเข้าไปที่หน้า API keys แล้วคุณจะเห็นรายการ key ของคุณ สิ่งที่ต้องทำคือคลิก create secret key เราจะตั้งชื่อว่า School Community เดี๋ยวผมจะหมุน key นี้ใหม่นอกกล้อง แต่ตั้งชื่อว่า School Community แบบ default แล้วคลิก create secret key จากนั้นก็คัดลอก key ออกมา มันยาวกว่าเดิมมาก แต่ผมโอเคกับมัน

จากนั้นเราก็คัดลอก แล้วเข้าไปที่ไฟล์ .env ของเรา ตรงนี้คือ OpenAI key ของเรา ผมจะลบอันเดิมแล้ววางอันใหม่ลงไป ผมวางทั้งอันเลย คุณจะเห็นครึ่งหนึ่งของมันอยู่ตรงนั้น จากนั้นเราจะทำแบบเดียวกันกับ Gemini API key เรามี OpenAI key แล้ว และคุณกด Command+S เพื่อบันทึก ตอนนี้มันบันทึกแล้ว

ต่อไป ผมอยากเข้าไปที่ AI Google Studio นี่คือที่ที่คุณจะได้ API key ของ Gemini วิธีได้มาง่ายมาก เราเข้าไปแล้วจะเห็นปุ่ม get API key เราคลิก get API key แล้วคลิก create API key ตั้งชื่อว่า Community Test แล้วคุณจะมีโปรเจกต์อยู่ คลิก create แค่นั้น จากนั้นเราจะเห็น School Community เป็นโปรเจกต์ของคุณ

ถ้าคุณเพิ่งเริ่ม คุณจะเห็น quota tier มันอาจจะถามให้คุณตั้งค่า billing พอตั้งค่าแล้ว มันจะพาคุณผ่านขั้นตอนต่าง ๆ เพื่อความรวดเร็วของวิดีโอ ผมไม่อยากใช้เวลากับตรงนี้มาก ขอแค่ถาม Claude วิธีตั้งค่าก็พอ ถ่าย screenshot หน้าจอให้มันดู แล้วมันจะจัดการตั้งค่า billing ให้ พอตั้งค่า billing เสร็จ คุณจะมีสิ่งที่เรียกว่า tier ต่าง ๆ จากนั้นผมจะคัดลอก API key นี้ แล้วเข้าไปที่ไฟล์ .env ของผม แล้วแทนที่ค่าตรงนี้ กดบันทึก เรียบร้อย

ตอนนี้ไฟล์ .env ของเรามี token ครบแล้ว เยี่ยมมาก ผมจะจัดระเบียบไฟล์นิดหน่อยเพื่อความเป็นระเบียบ กด Command+S เสร็จแล้ว ตอนนี้ผมจะกลับไปที่ Claude Code แล้วพิมพ์ขอให้ทดสอบ Gemini และ OpenAI ก่อน เราจะต้องทดสอบมันอีกครั้ง เราแค่อยากให้แน่ใจว่า key พวกนี้ใช้งานได้ มันสำคัญมาก

ปล่อยให้มันรันไป รอดูโมเดลทำงาน มันดูเหมือนจะโอเคแล้ว ดูที่ source แล้วพบปัญหากับ key พิเศษ เดี๋ยวขอเช็คก่อน ไฟล์ดูปกติดี ปัญหาอยู่ที่ source ผมจะลบ key พวกนี้ทั้งหมดทิ้งเลยดีกว่า ปล่อยให้มันคิดแป๊บนึง ให้มันทดสอบ key โดยตรง ตอนนี้มันจะทดสอบ key แล้ว ว้าว ทั้งสอง key ใช้งานได้ ตอนนี้มาใส่ quotes ใน .env และ source ของเราก็ใช้งานได้ เยี่ยม มันเวิร์กแล้ว พร้อมไปต่อ

ต่อไปมันจะติดตั้งอะไรบางอย่าง อย่างเช่น yt-dlp และ FFmpeg นั่นจะช่วยให้คุณทำ transcription ได้บนเครื่องของคุณเอง มันจะให้เราดาวน์โหลดวิดีโอ ถอดทรานสคริปต์ แล้วอัปโหลดไปให้ OpenAI หรือ Gemini ซึ่งสำคัญมาก ผมจะปล่อยให้มันทำงานต่ออีกสักพัก โอเค เยี่ยม

เราปล่อยให้มันทำงาน และสิ่งที่มันทำคือ: key ทั้งหมดของเราดี ใช้งานได้จริง เครื่องมือถูกติดตั้งแล้ว และตอนนี้สกิลถูกติดตั้งแบบ global แล้ว ขั้นตอนสุดท้ายคือรีสตาร์ท Claude แล้วผมจะรันคำสั่ง analyze content จากโปรเจกต์ไหนก็ได้ สิ่งที่เราจะทำคือปิด Claude Code ลง แล้วรีสตาร์ทมันขึ้นมาใหม่ จากนั้นรันสกิล analyze content ผมปิด Claude แล้วเปิดใหม่เรียบร้อย ตอนนี้เราจะมารันสกิลกัน

เรามี Supabase ตั้งค่าไว้แล้วพร้อมคอนเทนต์ Instagram ทั้งหมดอย่างที่คุณเห็น เป้าหมายตอนนี้คือกรอกข้อมูลจุดต่าง ๆ เหล่านี้ให้ครบ เราจะกด analyze และสกิลนี้จะวิเคราะห์คอนเทนต์จำนวนมาก ทั้ง Instagram และ YouTube มันจะดึงวิดีโอ วิเคราะห์ภาพ สร้างข้อมูล และเขียนลง Supabase และ Airtable นี่คือสกิลที่ผมสร้างเองสำหรับระบบของผม แต่คุณสามารถปรับมันได้ ถ้าคุณอยากแก้สกิล ใช่ไหมครับ?

ก่อนอื่น ขอดู breakdown หน่อย ขอดูข้างในสกิลทีละขั้นตอนได้ไหมครับ? สกิลก็คือเวิร์กโฟลว์ที่ถูกเขียนตายตัว สกิลที่ผมสร้างไว้ มันอ่านข้อมูลจาก Supabase และถูก hard-code ไว้แบบนั้น ผมมี TikTok และ YouTube อยู่ในนั้นด้วย รวมถึง Shorts ด้วย มันวิเคราะห์ได้เกือบทุกอย่าง สำหรับสกิลที่ผมให้คุณ ผมให้เวอร์ชันเต็มมา ในบทเรียนนี้เรามีแค่คอนเทนต์ Instagram เราก็แค่ต้องเช็คให้แน่ใจ นี่คือ breakdown เต็ม ๆ

OpenAI, Gemini, Meta access และค่าใช้จ่ายประมาณ 0.004 เซนต์ต่อวิดีโอ ขั้นแรกมันจะเช็ค API keys พอรัน มันจะเช็คว่า OpenAI และ Gemini key ที่ตั้งไว้ทำงานหรือไม่ จากนั้นมันจะ query ไปที่ Supabase เพื่อหาวิดีโอที่ยังไม่ได้วิเคราะห์ มันจะดึงวิดีโอ 20 รายการจากคอนเทนต์ของคุณ ที่ค่า analyzed ยังไม่เป็น true คุณกำหนดจำนวนได้ จากนั้นมันจะประมวลผลแต่ละวิดีโอโดยดาวน์โหลดมัน ถอดทรานสคริปต์ แล้วส่งให้ OpenAI เพื่อวิเคราะห์ มันส่งทรานสคริปต์ไปให้ GPT-4o แล้วก็ทำการวิเคราะห์ภาพด้วย ส่งไปให้ Gemini แล้วได้ข้อมูล text hook, visual, audio แบบนั้น อัปเดต Supabase แล้วจัดการข้อผิดพลาด มันจะวนซ้ำใหม่ถ้ามีอะไรล้มเหลว

นี่คือเหตุผลที่ผมไม่ใช้ N8N กับงานนี้แล้ว ผมเคยมีเวิร์กโฟลว์แบบนี้เป๊ะ แต่ Claude Code มันดีกว่ามาก เราเลยจะทำแบบนี้ แล้วมันจะรายงานผลลัพธ์ให้เรา พร้อมจัดการ cleanup ให้เสร็จ นี่คือไปป์ไลน์ทั้งหมด ถ้าคุณอยากแก้ไขอะไรตรงนี้ คุณทำได้เลย ขึ้นอยู่กับคุณ

สิ่งที่ผมจะถามมันคือ ขอดูว่าแทนที่จะ hard-code กับคอนเทนต์เก่าของผม มันจะทำยังไงกับของตัวอย่างนี้ ผมมีตารางตั้งไว้แล้ว ส่วนคุณก็มีตารางของคุณตั้งไว้แล้ว ผมมีคอนเทนต์อยู่สองสามชิ้นที่ยังไม่ได้วิเคราะห์ คุณจะได้เห็นผมทำแบบสด ๆ กับของจริงของผม แต่คุณมีตารางของคุณพร้อมแล้ว

สิ่งที่เราจะทำคือเข้าไปแล้วรันสกิล analyze content เราจะรันมัน และมันจะพาเราผ่านแต่ละขั้นตอน มันจะเช็ค OpenAI และ Gemini key แล้ว query Supabase เพื่อหาวิดีโอที่ยังไม่ได้วิเคราะห์ แล้วก็บูม ปล่อยให้มันทำงาน เดี๋ยวดูนะครับ

ตอนนี้มันกำลังถามผมว่า อยากวิเคราะห์แพลตฟอร์มไหนและกี่วิดีโอ มันสังเกตว่าในตารางคอนเทนต์ของผม มีวิดีโอ 116 รายการที่ยังไม่ได้วิเคราะห์ เป็น Instagram 48 รายการที่ยังไม่ได้วิเคราะห์ และมีชุดทดสอบอีกห้ารายการ สิ่งที่เราจะทำคือรัน Instagram ตรงนี้ ผมมีคอนเทนต์หลายชิ้นที่ยังไม่ได้วิเคราะห์ แต่ผมไม่จำเป็นต้องวิเคราะห์ทั้งหมด สิ่งที่มันจะทำคือ ดึงวิดีโอ Instagram ที่ยังไม่ได้วิเคราะห์จาก Supabase แล้วประมวลผลแต่ละรายการ ดึงข้อมูล อัปเดต Supabase อัปเดต Airtable แล้วรายงานผลสุดท้าย โอเค เราจะปล่อยให้มันรันไป

ระหว่างที่มันรัน ผมจะแจกแจงข้อมูลประเภทต่าง ๆ ที่เรากำลังเก็บในกระบวนการวิเคราะห์นี้ ขอแบ่งหน้าจอหน่อย ในการสร้างคอนเทนต์ไวรัล ผมอยากรู้ข้อมูลหลายจุด โอเค มันจะเริ่มจากตรงนี้ คุณจะสังเกตว่า มันเป็นแบบนี้กับ Claude Code คือคุณปล่อยให้มันทำงานและให้ permission ไปเรื่อย ๆ ขณะที่คุณไปทำอย่างอื่น ผมกำลังอธิบายให้คุณฟังในขณะที่มันทำงาน ใช่ไหมครับ? ซึ่งเป็นเรื่องใหญ่ สำคัญมาก

เข้ามาที่ข้อมูลกัน เรามีหลายจุด และผมจะพาคุณดูทีละจุด อันแรกคือ ID ของวิดีโอแต่ละรายการ เพื่อให้เราบอกได้ว่าต้องอัปเดตตัวไหน เรามี user ID ซึ่งก็คือผู้ใช้ที่เราทำการ scrape ให้ ถ้าคุณเป็น SaaS คุณจะมี user ID ที่ผูกกับผู้ใช้แต่ละคน จากนั้นมันจะรู้ว่าเวลาสร้างรายงาน ควรโชว์เฉพาะข้อมูลของคนนั้น ทางด้านนี้ คุณจะเห็นวิดีโอทั้ง 48 รายการ สคริปต์ครบ แล้วมันบอกว่า "let me spawn five parallel sub-agents to process the first batch" นั่นคือมีเอเจนต์ห้าตัวทำงานเวิร์กโฟลว์พร้อมกัน ถ้าเป็น N8N มันจะวนทีละตัว เว้นแต่คุณทำลูปห้าตัว ซึ่งอาจทำให้ AI โอเวอร์โหลด แต่อันนี้มัน spawn sub-agent มาทำงานเดียวกันจริง ๆ

ผมมี 48 วิดีโอ คุณจะ spawn ห้าตัว ถ้าใช้เวลาหนึ่งนาทีต่อวิดีโอ นั่นคือห้าวิดีโอต่อนาที งานทั้งหมดจะเสร็จในแปดถึงเก้านาทีเพราะมัน spawn ไปพร้อมกัน มันกำลังปล่อยวิดีโอสามถึงห้ารายการใน wave แรก บางเอเจนต์ไม่มี permission รัน batch หรือใช้ Airtable MCP มันเลยเปลี่ยนวิธี แล้วมันก็หาทางไปต่อได้ ซึ่งเจ๋งมาก ปล่อยให้มันทำงานต่อไป

ในส่วนของข้อมูล คุณมี handles, URL, วิดีโอหรือรีลส์ อันนี้อาจเก่าไปหน่อย ตารางของคุณใหม่กว่า แต่ของผมนี่เก่าไปนิดหน่อย จากนั้นคุณมี thumbnail ซึ่งก็คือภาพปกที่มาพร้อมวิดีโอ คุณมี spoken hook คือสิ่งที่คุณได้ยินออกมา เช่น ผมสร้างระบบติดตามข้อมูล TikTok นี้ขึ้นมา ผมขายมันไป แล้วผมจะให้คุณตอนนี้เลย นั่นคือฮุกที่ผมใช้ ซึ่งสำคัญมาก และมันคือส่วนที่สำคัญที่สุดของวิดีโอทุกตัว

จากนั้นคุณมี body structure คือโครงสร้างของสคริปต์จริง ๆ มันเป็นลิสต์? เป็น bullet? หรือเป็นเพียงการพูดระบาย? อะไรประมาณนั้น แล้วก็มี topic ซึ่งก็คือแท็กหัวข้อสามถึงห้าประโยค วิดีโอนี้เกี่ยวกับอะไร? ข้อมูล TikTok ใช่ไหมครับ? จากนั้นคุณมี caption ของวิดีโอจริง ซึ่งไม่ต้องอธิบายเพิ่ม แล้วก็มีทรานสคริปต์เต็มทั้งหมด แล้วก็ duration ของวิดีโอว่ายาวแค่ไหน

แล้วเราก็มีวันที่โพสต์ ซึ่งเป็นเมตริกที่ดี เพราะคุณจะรู้ว่าผ่านมานานแค่ไหนแล้วตั้งแต่โพสต์วิดีโอนี้ คุณจะคำนวณ views ต่อวันได้ ซึ่งเจ๋งมาก เรามี analyze timestamp เก็บไว้ว่าเราวิเคราะห์วิดีโอเหล่านี้ครั้งสุดท้ายเมื่อไหร่ เพื่อให้ข้อมูลสดใหม่เสมอ เรามี call to action เช่นตอนท้ายวิดีโอผู้คนพูดอะไร สำหรับตัวนี้ผมพูดว่า "คอมเมนต์คำว่า viral ด้านล่าง แล้วผมจะส่งให้คุณตอนนี้เลย" เรามี content type เป็นการสนทนา ทีละขั้นตอน มันเป็นปัญหาและวิธีแก้? เป็นการระบาย? เป็นการสาธิตที่เราทำอยู่? คือโครงสร้างจริงของการส่งมอบคอนเทนต์

จากนั้นเรามี analyzed ซึ่งเป็น true หรือ false ทุกครั้งที่รัน มันจะดึงรายการที่ค่าเป็น false ออกมา ถ้าเป็น false โมเดลจะรู้ว่ามันต้องวิเคราะห์ทั้งวิดีโอ ซึ่งคือสิ่งที่กำลังเกิดขึ้นตอนนี้พอดี แล้วเราก็มี topic summary ซึ่งเป็นคำอธิบายยาวขึ้นว่าวิดีโอเกี่ยวกับอะไร เช่น "วิดีโอนี้สาธิตระบบติดตามข้อมูล TikTok ที่ติดตามเมตริกและหัวข้อที่กำลังมาแรง เพื่อช่วยสร้างคอนเทนต์"

จากนั้น visual format อันนี้สำคัญมาก มันบอกว่าวิดีโอมีรูปแบบภาพแบบไหน เป็น vertical selfie? เป็นการสาธิตหน้าจอ? เป็น split screen? แบบนั้น ใช่ไหมครับ? มันสำคัญเพราะคุณจะรู้ว่ารูปแบบภาพแบบไหนเวิร์กที่สุดสำหรับคุณ แล้วค่อยตัดสินใจจากข้อมูล แล้วเราก็มี spoken hook framework อันนี้ใหญ่เลย spoken hook framework คือคุณมี spoken hook ซึ่งเป็นสิ่งที่พูดจริง แต่ framework คือโครงสร้างของมัน ตัวอย่างเช่น "ผมสร้างระบบติดตามข้อมูล X ขึ้นมา ผมขายมันไป แล้วผมจะให้คุณตอนนี้เลย" ในวิดีโอจริงผมพูดว่า "ผมสร้างระบบติดตามข้อมูล TikTok นี้ขึ้นมา ผมขายมันไป แล้วผมจะให้คุณตอนนี้เลย"

มันเป็นเทมเพลตแบบ Mad Lib มันจะเอาคำสำคัญออกไป พอผมจะเขียนฮุกอื่นในบทเรียนอื่น เช่นทำสำหรับ Instagram สิ่งที่ต้องทำคือเปลี่ยนคำว่า X ออก แล้วแทนด้วยของใหม่ แบบสลับส่วนได้นั่นเอง

แต่เดี๋ยวก่อน ดูนี่สิ ผมว่าเราทำเสร็จแล้ว มันทำงานให้เราเรียบร้อย Instagram ทั้ง 43 รายการตอนนี้วิเคราะห์แล้ว ฐานข้อมูลคอนเทนต์ของคุณอัปเดตเรียบร้อย เยี่ยมมาก "ขอตัวอย่างจากวิดีโอที่ดีที่สุดที่วิเคราะห์เสร็จแล้วหน่อย" เยี่ยม ผมจะแจกแจงให้ดูว่ามันให้อะไรเราบ้าง

ในนี้คุณจะเห็น spoken hook structure ด้วยว่าเป็นฮุกแบบไหน เป็น contrarian hook? เป็น announcement hook? เป็น question hook? เป็น tutorial hook? แบบนั้นทั้งหมด แล้วเดี๋ยวผมจะแจกแจงความรู้คอนเทนต์ของผมเพิ่มอีกมากในบทเรียนเรื่องการเขียนสคริปต์ แต่ตอนนี้แค่โชว์ว่าข้อมูลแบบไหนที่เราได้จากวิดีโอทั้งหมดนี้

ดูนี่สิ เรามีเมตริกครบ มี spoken hook, text hook, hook structure อย่างที่ผมเพิ่งพูด นี่คือ text hook แบบ raw ถ้าคุณไม่รู้ว่า text hook คืออะไร มันคือคำบนหน้าจอ ซึ่งสำคัญมากที่ต้องรู้ เพราะเวลาทำวิดีโอไวรัล จะมี spoken, text, visual และ audio สี่อย่างนี้รวมกัน เมื่อมันซิงค์กัน มันจะสร้างวิดีโอไวรัล ผู้คนเห็นผมพลิกกล้องขึ้น ทำให้สายตาพวกเขาขยับตาม นั่นคือ visual hook ส่วน text hook คือสิ่งที่พวกเขาอ่านบนหน้าจอ spoken hook คือสิ่งที่พวกเขาได้ยิน และ audio hook คือเสียงที่พวกเขาได้ยิน สี่อย่างนี้รวมกันสร้างไวรัล และเราได้ข้อมูลครบทั้งหมดนี้

ส่วน content type กับ call to action เราพูดไปแล้ว แล้วก็ visual และ audio เรายังทำ visual format ด้วย เราหาวิดีโอคุณใช้รูปแบบภาพแบบไหน ซึ่งต่างจาก visual format ตรงที่ visual format คือรูปแบบจริงของวิดีโอ ส่วนอีกอันเป็นภาพรวมที่กว้างกว่า ตัวอย่างเช่น นี่คือวิดีโอ talking head แบบ vertical selfie คุณสามารถมีวิดีโอ talking head แบบสาธิต หรือแบบ split screen ก็ได้ แล้วเราก็มี visual movement บอกว่าเกิดอะไรขึ้นในภาพ ซึ่ง Gemini ใช้หาสิ่งเหล่านี้ ส่วน audio hook ก็เช่นเสียงที่ตัดเข้ามา ง่ายมาก

และข้อมูลทั้งหมดนี้ ผมเก็บไว้ทั้งหมด เพราะในอีกหนึ่งหรือสองบทเรียนถัดไป เราจะสร้าง brief เต็มรูปแบบว่าอะไรเวิร์กสำหรับคอนเทนต์ Instagram ของผม และอะไรไม่เวิร์ก ซึ่งเริ่มจากการมีข้อมูลทั้งหมดนี้เตรียมไว้ให้แล้ว นั่นคือทั้งหมดสำหรับวิดีโอนี้ เจอกันในบทเรียนหน้านะครับ
