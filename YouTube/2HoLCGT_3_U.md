## ประเด็นหลัก

- Julian โชว์ Agent OS ของเขาที่รันอยู่บน Hermes AI โดยใช้ฟีเจอร์ใหม่ Hermes Bot Mode ซึ่งเพิ่งเปิดตัวเป็น public beta หนึ่งวัน ฟรีและ open source
- Agent OS เป็นระบบโฟลเดอร์ที่มี agents ชื่อต่างๆ แต่ละตัวมีหน้าที่ เช่น Oracle ติดตามคู่แข่ง Astros ดึงไอเดียคอนเทนต์ Apollo จัดการคำตอบเสียง และ Muse เปลี่ยนโน้ตเป็นสคริปต์บทเรียน
- แต่ละบอทมี avatar ความจำ และโมเดล AI เป็นของตัวเอง ทำให้ทำงานเป็นระบบ ไม่ใช่แค่แชตแยกกัน
- ฟีเจอร์สำคัญคือ bot-to-bot messaging ที่บอทส่งงานหากันได้เอง พร้อมระบุที่มาของข้อความ และสามารถ mention บอทด้วยเครื่องหมาย @ ในแชตได้
- ทุกบอทมีพาเนล routines สำหรับงานที่รันตามตารางเวลา ทำงานบน scheduler เดิมที่ Hermes มีอยู่แล้ว และทุกบอทมี soul file (ไฟล์บุคลิกภาพ) ที่กำหนดวิธีพูดและพฤติกรรมของบอท
- การ clone บอทจะติดไฟล์บุคลิกภาพ ทักษะ และความจำไปด้วย ทำให้บอทใหม่เริ่มต้นจากที่รู้งานแล้ว
- จุดที่ยังเป็นข้อจำกัดของ Bot Mode: เป็นปลั๊กอินเดสก์ท็อปต้องรันบนเครื่องที่รันแอป ยังรวมหลายบอทใน group chat เดียวไม่ได้ และการส่งข้อความระหว่างบอทยังไม่ทันที
- Julian แนะนำแนวคิดว่าเครื่องมือสำคัญน้อยกว่าระบบ ทักษะการออกแบบระบบเอเจนต์จะใช้กับเครื่องมือใดก็ได้ในอนาคต
- ช่องทางรับ Agent OS แบบสำเร็จรูปคือ AI Profit Boardroom และช่องทางฟรีคือ AI success lab
