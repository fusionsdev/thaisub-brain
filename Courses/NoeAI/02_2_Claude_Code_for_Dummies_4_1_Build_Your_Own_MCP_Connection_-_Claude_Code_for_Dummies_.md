## บทนำ

บทเรียนนี้สอนวิธีสร้าง MCP (Model Context Protocol) เชื่อมต่อ Claude Code กับแอปใดก็ได้บนโลกด้วยตัวเอง ผ่านสกิล MCP Builder ที่ผู้สอนแถมให้ โดยสาธิตการสร้าง MCP เชื่อมต่อ Airtable ตั้งแต่การอ่าน API docs ไปจนถึงการใส่ API key และทดสอบการใช้งานจริง พร้อมอธิบายความต่างระหว่าง native connection แบบจำกัดกับ MCP ที่ควบคุมได้ทุกอย่าง

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่บทเรียน Build Your Own MCP Connection ครับ ในบทเรียนนี้ ผมจะโชว์วิธีเชื่อมต่อกับแอปใดก็ได้บนโลกนี้ด้วย Claude Code และผมจะให้สกิล MCP Builder กับคุณด้วย เพื่อที่ Claude Code จะได้ทำงานทุกอย่างให้คุณเอง มันจะทำการวิจัย มันจะทำทุกอย่างให้คุณเลย โอเคไหม?

มีอะไรที่ผมอยากพูดถึงสั้น ๆ คือ ถ้าพวกคุณส่วนใหญ่เคยทำงานใน Claude Desktop ใช่ไหมครับ? คุณจะมีการเชื่อมต่อแบบ native อยู่เยอะ native connection คือการเชื่อมต่อง่าย ๆ ที่คุณแค่คลิกไม่กี่ปุ่มก็เชื่อมต่อได้แล้ว ปัญหาของ native connection พวกนี้คือมันไม่ค่อยมีความสามารถมากนัก ใช่ไหมครับ?

ตัวอย่างที่ดีคือ Gmail ตัวนี้ตรงนี้ มันให้คุณสร้าง ดึงรายการ อ่านข้อความ ค้นหาได้ แต่มันส่งเมลไม่ได้ ไม่ได้จัดระเบียบให้คุณ มีหลายงานและหลายเครื่องมือที่มันทำไม่ได้ เพราะ Claude หรือ Anthropic เขาจำกัดความสามารถที่ให้ AI ใช้ เพื่อที่เขาจะได้ไม่ถูกฟ้อง ใช่ไหมครับ? ซึ่งผมส่วนตัวไม่เห็นด้วยนัก เพราะผมควบคุมได้ว่า AI กำลังทำอะไร ผมนั่งดูมันอยู่ มันไม่ได้รันมั่ว ๆ แล้วยิงอีเมลหาทุกคน มันเลยจำกัดมากในฝั่ง connector

แต่ใน Claude Code โดยเฉพาะใน terminal มีอะไรให้ทำได้มากกว่ามาก คุณควบคุมได้ว่าจะให้โมเดลเข้าถึงอะไร คุณให้เครื่องมือได้อีกเยอะ ตัวอย่างเช่น Gmail อันเดิม มันให้ทำได้ไม่กี่อย่าง แต่ใน Gmail server ที่ผมสร้างเอง มันส่งเมลได้ มันติดป้ายกำกับและจัดลำดับความสำคัญได้ มันจัดระเบียบอีเมลให้ผมทั้งหมด เพราะผมสร้างอินทิเกรชันของตัวเอง ผมสร้าง MCP server ของตัวเอง โอเคไหม?

MCP ก็แค่การเชื่อมต่อระหว่าง Claude Code กับแอปที่คุณอยากใช้ เรามาเริ่มกันเลยดีกว่า วันนี้เราจะสร้างมันขึ้นมาใน Claude Code ด้วยกัน เราจะทำแบบ tutorial แบบเร็ว ๆ ผมจะโชว์วิธีเชื่อมต่อแอปอะไรก็ได้บนโลกใบนี้ ผมจะวางไฟล์ไว้ตรงนี้ แล้วเราจะเปิดหน้าต่างใหม่ โอเคไหม? เราได้หน้าต่างใหม่ เพื่อโชว์คุณตั้งแต่เริ่มต้น

สิ่งที่ผมจะทำคือเปิดโฟลเดอร์ เราจะทำงานในโฟลเดอร์ School Community Example เราจะกด open เอ๊ะ ทำไมไม่เปิดสักที? เพราะผมอยู่ในหน้าต่างอื่นนั่นเอง โอเค เดี๋ยวปิดอันนี้ก่อน เยี่ยม น่าจะใช้ได้แล้ว เราเปิดเข้าไปแล้ว ตอนนี้ผมอยู่ในโฟลเดอร์ School Community แต่สำหรับคุณ คุณแค่หาโฟลเดอร์ที่คุณทำงานอยู่ ลากไฟล์ลงไป แล้วก็เสร็จ จากนั้นพิมพ์คำสั่งแล้วเราก็เริ่มได้เลย

ในโฟลเดอร์นี้ ผมวางสกิล MCP Builder ไว้ข้างล่าง สิ่งที่คุณต้องทำคือเลื่อนลงมา ดาวน์โหลดไฟล์นี้ โอเค เราจะดาวน์โหลดมัน ผมไปที่โฟลเดอร์ Downloads แล้วลากไฟล์นี้มา ผมว่าไฟล์นี้เป็น zip ฉันไม่แน่ใจว่า Claude Code Terminal จะเปิดมันได้ไหม แต่ลองดูกัน แล้วผมจะพิมพ์ขอให้มันติดตั้งสกิล MCP Builder แบบ local หรือ project side ในโฟลเดอร์ School Community Example ผมรู้ว่าผมมีเวอร์ชัน global อยู่แล้ว แต่ผมกำลังสอนบทเรียน และอยากโชว์วิธีสร้างจากศูนย์

จากนั้นเราจะสร้าง MCP connection ไปยัง Airtable ซึ่งผมก็รู้ว่าผมมี connection แบบ global อยู่แล้ว แต่เราอยากทำในโปรเจกต์นี้แบบ sandbox แยกต่างหาก เราจะปล่อยให้มันทำงานตรงนี้ ส่วนคุณก็แค่ลากไฟล์ลงในโฟลเดอร์ แล้วขอให้มันตั้งค่าให้ ถ้าคุณไม่เคยสร้างมาก่อน

ผมมีสกิลหลายตัวอยู่แล้ว ผมมี MCP Builder skill อยู่จริง ๆ ใช่ แล้วก็อีกเยอะแยะมากมาย โอเค เราจะปล่อยให้มันทำงาน มันบอกว่า zip มีสกิล MCP Builder พร้อมไฟล์อ้างอิง เดี๋ยวแตกไฟล์แล้ววางในโฟลเดอร์สกิลของโปรเจกต์ มันจะวางไว้ฝั่งโปรเจกต์ให้ผม ผมน่าจะเห็นมันเข้ามาตรงนี้ นั่นไง อยู่ตรงนั้น เยี่ยม เห็นไหม? เจ๋งมาก มันลงทะเบียนแล้ว

ดูนี่สิ ขอดู global MCP หน่อย มันลงทะเบียนแล้ว มันจะเลียนแบบรูปแบบจาก global มาสู่ local เราจะปล่อยให้มันทำงานต่ออีกแป๊บ ถ้าคุณเพิ่งเริ่มใช้คุณจะเห็นว่ามันใช้ token เท่าไหร่และใช้ความพยายามแบบไหน มีอะไรให้ทำได้หลายอย่าง และถ้าคุณอยากเห็นว่ามันทำงานในโฟลเดอร์ไหนหรือไฟล์อะไร นั่นคือสิ่งที่ผมชอบ ผมคลิกดูได้เลย เสร็จแล้ว ผมเห็นสกิลขึ้นมาแบบ live ผมเปิดไฟล์ SKILL.md ได้ และอ่านได้ว่ามันกำลังทำอะไรอยู่ ข้างในมันเหมือนคู่มือพัฒนาสกิลคุณภาพสูง

ตอนนี้มันกำลังแก้ไขไฟล์ให้เรา และมันก็ยังทำงานอยู่ มีเครื่องมือต่าง ๆ เปลี่ยนไปเรื่อย ๆ ดูนี่สิ แล้วถ้าอยากปิดก็ปิดได้ตรงนั้น ตอนนี้ MCP Builder ถูกติดตั้งแล้ว มันบอกว่า "สกิลถูกติดตั้งฝั่งโปรเจกต์แล้ว ตอนนี้คุณสามารถเรียกใช้ MCP Builder skill แยกจากเวอร์ชัน global ได้ พร้อมจะให้ MCP Builder เริ่มกระบวนการหรือยัง?" เจ๋ง มันอยู่ในโฟลเดอร์แล้ว โอเค

สำหรับคุณ คุณก็แค่บอกว่าอยากติดตั้งบนเครื่องทั้งหมด เพื่อที่คุณจะเรียกใช้จากที่ไหนก็ได้ ในโฟลเดอร์ไหนก็ตามที่คุณอยู่ พิมพ์ MCP Builder แล้วก็ใช้ได้เลย ตอนนี้มันตั้งชื่อให้ว่า NoeAI MCP Builder Skills เป๊ะเลย ผมจะกด Tab เพื่อเปิดมันดู โดยไม่รันมันจริง ๆ

ตอนนี้เราอยากเชื่อมต่อแอปที่เรายังไม่มีการเชื่อมต่อ สิ่งแรกที่ผมทำเวลาจะเชื่อมต่อแอป คือไปหา API docs ก่อน ผมจะเข้าไปที่ Airtable API โอเค แล้วหาดูว่ามันทำอะไรได้บ้าง สิ่งแรกที่ผมจะทำคือเข้ามาดู หาส่วน developer แล้วมันควรจะมีลิสต์ว่ามันทำอะไรได้บ้าง นี่คือ record expanding และทั้งหมดนี้อยู่ใน Airtable API จากนั้นผมก็จะขึ้นมาตรงนี้ ขอเช็คให้แน่ใจ นี่คือ API documentation ตรงนี้ นั่นคือที่ที่เราอยากอยู่ บูม เป๊ะ

สิ่งที่ผมทำคือคัดลอกลิงก์นี้ แล้วกลับมาที่นี่ และก่อนที่คุณจะสร้าง Airtable MCP ขออ่านแล้วบอกผมหน่อยว่ามันทำอะไรได้บ้าง ภายใน MCP นี้ ที่เกี่ยวกับธุรกิจของผม โอเค มันจะจำสองสิ่งนี้ไว้ แต่สิ่งที่ผมอยากได้คืออยากรู้ให้ชัดว่ามันจะทำอะไรได้บ้าง มันจะเข้าไปอ่าน API docs ก่อน ซึ่งผมไม่จำเป็นต้องวางลิงก์ให้มันด้วยซ้ำ มันจะทำ deep research ให้เราเอง มันมีเครื่องมือค้นหาอินเทอร์เน็ตเพื่อหา API documentation ที่มันทำได้ แต่ผมชอบให้ตรงไปตรงมา เพื่อมันจะได้ไม่ต้องค้นหาเสียเวลา

แต่มันกำลังดึงข้อมูลทั้งหมด แล้วอ่าน แล้วดู API แล้วอ่านไฟล์ทั้งหมดของเราว่าธุรกิจเราคืออะไร จากนั้นมันจะ cross-reference และไอเดียเฉพาะว่าคุณทำอะไรได้บ้างเมื่อเชื่อมต่อ ซึ่งเจ๋งมาก และนั่นเป็นวิธีที่ดีในการค้นหาว่าการเชื่อมต่อนี้ทรงพลังและมีค่าแค่ไหน

มันบอกว่า "client-side rendered นี่คือ breakdown ของสิ่งที่สำคัญ" มันสามารถ query ข้อมูลของคุณ เพิ่มรายการใหม่ ลบ เห็นตารางทั้งหมดของคุณใน Airtable ซึ่งเจ๋งมาก มันทำ content pipeline ได้ มันจัดการไปป์ไลน์ทั้งหมดของผมจาก Claude Code มันติดตามไทม์ไลน์โปรเจกต์ทั้งหมด มันติดตาม leads มันทำ ad research ให้เราได้ มันสร้างโฆษณาได้ทุกอย่าง เยอะแยะมากมาย

มันบอกเราตรง ๆ ว่ามันทำอะไรให้ธุรกิจคุณได้บ้าง เพราะเราเทรนมันกับธุรกิจคุณแล้ว ใช่ไหมครับ? เราสอน Claude Code แล้ว มันรู้ไฟล์ทั้งหมดของคุณ เราพร้อมแล้ว

สิ่งที่ผมอยากทำคือรัน MCP Builder skill ผมจะเลือกตัว NoeAI เพราะไม่อยากให้มันปนกัน จากนั้นผมจะถามว่า "ช่วยสร้าง Airtable MCP ได้ไหม? สร้างในโปรเจกต์นี้โดยเฉพาะ ผมมี Airtable MCP ตัวอื่นตั้งไว้แบบ global อยู่ ผมไม่อยากให้คุณไปแตะมัน ผมต้องการแค่ในโฟลเดอร์โปรเจกต์นี้เท่านั้น" โอเค เราจะปล่อยให้มันทำงาน

โดยปกติขั้นแรกของ MCP Builder คือมันจะไปวิจัย API docs ของ Airtable ซึ่งเราให้ลิงก์ API ไปแล้ว มันเลยรู้ชัดว่าต้องสร้างยังไง โอเค มันกำลังอ่านเอกสารทั้งหมด ถ้าคุณเปิดดู คุณจะเห็นคำสั่งต่าง ๆ ที่ต้องกด approve เยอะแยะ ถ้าผมเปิดโฟลเดอร์ resource ขึ้นมา มันอยู่ตรงนี้ ผมไม่ต้องไปไกลขนาดนั้นด้วยซ้ำ ตรงนี้มี MCP best practices, MCP Python, MCP server

MCP ก็คือโค้ดนั่นแหละ มันคือโค้ดไม่กี่บรรทัด พร้อมกับ API key ที่เราจะต้องไปเอามาในอีกแป๊บ เพื่อเรียกใช้เครื่องมือและปลดล็อกทั้งหมด เพื่อให้เราสร้าง อัปเดต ทำอะไรก็ได้ในซอฟต์แวร์นั้น ซึ่งตอนนี้คือ Airtable ใช่ไหมครับ? และคุณอ่านผ่านมันได้เสมอ ผมว่ามันน่าสนใจนะ การอ่านพวกนี้ มันมี core question answering อะไรพวกนั้น ซึ่งเจ๋งมาก

เราจะปล่อยให้มันทำงานต่ออีกแป๊บ แล้วดูนี่สิ ตอนนี้เรามีไฟล์ชื่อ Airtable MCP อยู่ในนี้ ดูสิ มันมีเครื่องมือต่าง ๆ มันกำลังสร้างทุกอย่างให้เราเอง เห็นไหมว่ามันกำลังเขียนไฟล์อยู่ write แปลว่ามันกำลังสร้างไฟล์ มันเขียนไฟล์หลายไฟล์ให้เรา วิธีเชื่อมต่อตรง ๆ เข้าไปใน Airtable เจ๋ง มันยังสร้างอยู่ ขอโชว์ให้ดู มันใช้เวลาสองสามนาที ผมว่ามันรันมาเกือบสามนาทีแล้ว

แต่ขอดูของเจ๋ง ๆ หน่อย มันกำลังรวบรวมสิ่งที่มันรู้เกี่ยวกับ Airtable server แล้วทดสอบ และมันล้มเหลว มันมี exit codes มันเจอเวอร์ชันไม่ตรง แล้วมันก็หาทางไปรอบ ๆ ใช่ไหม? "เดี๋ยวแก้ให้" มันเพิ่มคำสั่ง แล้วทดสอบตลอดเวลา มันกำลังโหลดเครื่องมือทั้งเจ็ดตัว ตอนนี้มันกำลังลงทะเบียน มันบอกว่า "ไม่มี Airtable key ในไฟล์ .env ของคุณ ขอเช็คว่ามีการตั้งค่าใน global settings ไหม" ซึ่งผมไม่อยากให้เกิดแบบนั้น เพราะผมไม่เก็บ .env ไว้ใน global เราสร้าง .env ระดับโปรเจกต์สำหรับโฟลเดอร์นี้โดยเฉพาะเพื่อเก็บ API key ได้

ที่มันทำคือ มันพบว่าไม่มี Airtable key ในโปรเจกต์ มันเลยเริ่มหาแบบ global บนเครื่องผม หาทั่วทุกที่ เพราะผมเก็บ API key ทั้งหมดไว้แบบ global มันจะเจอตัวที่ผมใช้กับ MCP ตัวอื่น ซึ่งเราไม่ต้องการ ผมเลยหลีกเลี่ยงไว้ก่อน คุณกด Escape เพื่อหยุดมันทำงานได้เสมอ

MCP servers ต้องอยู่ในไฟล์ .mcp.json ที่ระดับโปรเจกต์ ไม่ใช่ใน settings "เดี๋ยวสร้างให้" โอเค ดูนะ เรามี MCP Builder แล้ว และตอนนี้มันสร้างไฟล์ .env แล้ว เห็นไหม เราจะใส่ Airtable API key ตรงนี้ แล้วดูว่ามันวาง MCP ไว้ตรงไหน เจ๋ง

ตอนนี้มาถึงส่วนของคุณแล้ว คุณต้อง: ไปสร้าง Airtable access token พร้อมกำหนด scopes, วาง key ลงในไฟล์ .env, เปลี่ยนค่า Airtable เป็น key จริง, อัปเดต MCP ใส่ API key แล้วรีสตาร์ท เจ๋ง ดูเหมือนเรามีไฟล์ .mcp แล้ว เยี่ยม

เดี๋ยวผมจะลงรายละเอียดไฟล์ .env เพิ่มในบทเรียนหน้า แต่อันนี้สำคัญที่คุณต้องเห็น ไฟล์ .env คือที่เก็บ key ทั้งหมดของคุณ แค่นั้นแหละ เหมือน Airtable, Meta, GoHighLevel ทุกอย่างที่ sensitive คุณจะเก็บไว้ใน .env แล้วสิ่งที่เกิดขึ้นคือ สมมติผมเปิดไฟล์นี้ขึ้นมา ทุกครั้งที่ Claude Code ทำงาน ไฟล์ .env คืออันนี้ และนี่คือไฟล์ .mcp ซึ่งข้างในมี MCP server อยู่ มีข้อมูล Airtable อยู่

แต่ที่ Claude Code ทำคือ สมมติว่านี่คือ Claude Code ตรงนี้ เวลาผมคุยกับมัน แล้วผมบอกว่า "Claude Code ฉันอยากเชื่อมต่อ Airtable" นี่คือ Airtable โอเคไหม? Claude Code เข้าไปหา Airtable ตรง ๆ ไม่ได้ เพราะ Claude ยังไม่รู้จัก MCP นั่นคือเหตุผลที่มันสร้างไฟล์ขึ้นมา สิ่งที่มันทำคือไปที่ MCP แล้วดึงข้อมูล ถ้าเราดูในไฟล์ .mcp เรามีอะไรตรงนี้? บูม เห็นไหม? นี่คือ MCP server ของคุณ มันเป็นเหมือนโค้ดหนึ่งบรรทัด คุณมีชื่อของมัน คุณมีคำสั่ง มันก็คือโค้ดนั่นเอง

ไม่ต้องถามผมว่าสิ่งเหล่านี้หมายความว่าอะไร แต่ที่คุณต้องรู้คือ นี่คือวิธีที่มันเชื่อมต่อเข้า Airtable แล้วคุณจะเห็นว่ามีช่อง Airtable API key อยู่ และเห็นไหมว่ามันว่างเปล่า? โอเค นั่นคือจุดที่ .env เข้ามา เราวาง key ไว้ใน .env จากนั้น Claude Code จะอ่าน .env แล้วเราใส่ key ไว้ในนั้น หรือจะใส่ key ตรง ๆ ใน .mcp ก็ได้ เราทำซ้ำได้นั่นเอง key ก็คือสตริงยาว ๆ นั่นแหละ เหมือนกันหมด

มันจะรู้ว่าผมเขียนมันไว้อีกที่หนึ่ง จากนั้นมันจะสังเกตเห็นค่าว่าง ค้นหา ไม่เจอ มันจะไปที่ .env ดึง key กลับมา ยิงเข้าไปที่ MCP แล้วปลดล็อกการเข้าถึง Airtable แล้วส่งผลลัพธ์กลับมาให้เรา นั่นคือวิธีอธิบาย .env และ MCP ที่ง่ายที่สุดเท่าที่ผมจะอธิบายได้

แต่ตอนนี้มาลงมือทำกัน เราทำตามคำแนะนำของมัน เรามี .env และ .mcp แล้ว โอเค ตอนนี้เราจะไปที่ Airtable เปิดมันขึ้นมา แล้วเราจะอยู่ในหน้า builder ซึ่งเจ๋งมากเพราะมันพาผมไปที่นั่นตรง ๆ มันทำ deep research ว่ารู้ว่าต้องไปที่ไหน ต้องทำอะไร ซึ่งเจ๋งมาก ผมไม่รู้ว่าทำไมผมเรียกมันว่า "เขา" ตลอด

ผมจะลบ Airtable ตัวอย่างชื่อ Claude Code Example อันนี้ออก แล้วคลิก create token ตั้งชื่อว่า School Example กด add scope แล้วเพิ่ม scopes ทั้งหมดที่มันแนะนำ มันบอกว่ามันต้องการอะไรบ้าง แต่ผมจะให้ access กับทุกอย่าง เพราะนั่นจะปลดล็อกพลังของมัน Claude Code จะทำได้ทั้งหมดที่เราถามไว้ จากนั้นตรงส่วน access token มันเป็นแบบ add-all resources ผมอยากให้มันเข้าถึง workspace ทั้งปัจจุบันและอนาคตทั้งหมดของผม ใช่ แล้วก็สร้าง token

ขอพูดถึงอีกอย่าง คือซอฟต์แวร์แต่ละตัวจะต่างกันหมด อันนี้เป็นซอฟต์แวร์ที่ตั้งค่ากับ Claude Code ง่ายที่สุดตัวหนึ่ง ซึ่งเป็นเหตุผลที่ผมเลือกมัน แต่ n8n จะต่างออกไป Apify จะต่างออกไป Supabase จะต่างออกไป GoHighLevel จะต่างออกไป Meta apps จะต่างออกไป ทั้งหมดเลย โอเค ผมแค่อยากพูดไว้ก่อน

จากนั้นผมจะคลิก create token แล้วคุณจะได้สตริงยาว ๆ ออกมา ผมจะลบมันทิ้งเพื่อไม่ต้องกังวล แต่จากนั้นเราจะเข้ามาที่ไฟล์ .env ของเรา เห็นแบบนี้ แล้วทำตามที่มันบอก: "วาง key ลงใน .env และแทนที่ Airtable key ตัวเก่าด้วย key จริง" ผมจะลบค่าเดิม แล้ววาง key ใหม่ กด Command+S เพื่อบันทึก น่าจะเซฟได้อัตโนมัติ บางทีคลิกขวาก็ได้ ไม่แน่ใจ แต่ Command+S เซฟอัตโนมัติ เราพร้อมแล้ว

เราใส่ key ลงไปแล้ว แล้วถ้าไปดูที่ไฟล์ .mcp จะเห็นว่ามันไม่ได้ใส่ให้อัตโนมัติ เราก็ต้องแทนที่ตรงนี้ด้วย บางครั้ง Claude จะอ่านไฟล์ .env แล้วใส่ key ที่เจอเข้าไปใน MCP server ให้อัตโนมัติ แต่บาง MCP server ก็งอแง ไม่ยอมให้ทำแบบนั้น แต่มันเสนอให้แล้ว ผมเลยกดยอมรับ ตอนนี้มันติดตั้งแล้ว เราพร้อมใช้

key อยู่ในไฟล์แล้ว ใช่ไหม? เราจะปล่อยให้มันทำงาน แล้วดูว่ามันทำอะไร มันบอกว่า "คุณต้องรีสตาร์ท Claude Code เพื่อให้ MCP server โหลด พิมพ์ /mcp เพื่อเช็คว่า Airtable server โผล่ขึ้นมาไหม แล้วรีสตาร์ทเซสชัน มันจะโหลดให้อัตโนมัติ พอโหลดแล้วคุณจะมีเครื่องมือเจ็ดตัวฝั่งโปรเจกต์" เยี่ยม มันบอกว่าเราตั้งค่าเสร็จแล้ว

กับ MCP คุณต้องรีสตาร์ทหน้าต่างเพื่อให้เข้าถึงได้ เพราะทุกครั้งที่เริ่มเซสชันใหม่ใน Claude Code คุณเหมือนกับการเปิดสวิตช์ MCP ทั้งหลาย เมื่อเริ่มเซสชัน MCP ทั้งหมดจะเปิดขึ้น แต่ตอนที่เพิ่งสร้าง มันยังไม่รู้จัก พอออกแล้วกลับเข้ามาใหม่ มันถึงจะเปิดและคุณเข้าถึงได้ สิ่งที่เราจะทำคือพิมพ์คำสั่ง /quit เห็นไหม? ตอนนี้ผมออกมาแล้ว

จากนั้นผมจะพิมพ์ claude อีกครั้ง มันถามว่า "MCP servers อาจ execute code หรือเข้าถึงระบบ" นั่นบอกเราว่า MCP ตัวนี้เป็นแบบนั้น ซึ่งดี ผมกด 1 โอเค ตอนนี้ผมเข้ามาแล้ว และสิ่งที่ผมอยากทำคือกด /resume เพื่อโชว์ให้ดูว่าผมกลับมาคุยต่อจากเดิมได้ โดยการทำแบบนี้ ผมกลับมาที่บทสนทนาก่อนหน้าได้ ซึ่งเราออกจากบทสนทนานี้ไปแล้ว แต่ถ้าอยากกลับมาก็แค่ /resume โอเค เรามี key อยู่ในไฟล์แล้ว

ตอนนี้เราอยู่ในบทสนทนาเดิมเป๊ะ ผมพิมพ์ /mcp แล้วเราจะเห็น Project MCPs บูม นั่นไง โอเค เราจะทดสอบมัน ผมกด Escape เพื่อออกจากเมนู แล้วถามว่า "ช่วย list Airtable bases ที่คุณเห็นใน Airtable หน่อย" เราจะทดสอบตรงนี้ ตอนนี้มันกำลังเรียกใช้งาน เห็นไหม? ผลลัพธ์คือ มันดึง Airtable ทั้งหมดของผมออกมา และตอนนี้มันเข้าถึงได้ทุกอย่างจริง ๆ

นั่นคือวิธีที่คุณเชื่อมต่อแอปของคุณผ่าน MCP เข้ากับ Claude Code ง่ายมาก ตรงไปตรงมา เราไปดูไฟล์ .env และ .mcp กันแล้ว ผมให้สกิล MCP Builder กับคุณ มันใช้ง่ายมากสำหรับเชื่อมต่อแอปของคุณ ผมว่าผมทำได้ดีทีเดียว ตรงไปตรงมา ถ้าคุณมีคำถามอะไร บอกได้ในคอมมูนิตี้

ตอนนี้คุณสามารถเชื่อมต่อแอปใดก็ได้บนโลกใบนี้เป็นส่วนใหญ่ เข้ากับ Claude Code เพื่อเริ่มทำงานในนั้นได้ ผมขอให้คุณเริ่มใช้ MCP Builder ตัวนี้ แล้วเริ่มถามมันว่า "ช่วยเชื่อมต่อแอปนี้ได้ไหม? ช่วยเชื่อมต่อแอปนี้ได้ไหม?" แล้วเริ่มเชื่อมต่อแอปให้มากที่สุดเท่าที่จะทำได้ ผมรู้ว่าเราเคยทำแบบนั้นใน Claude Desktop แต่ว่า MCP ตัวนี้จะดีกว่า Claude Desktop มาก ดังนั้นเริ่มเชื่อมต่อสิ่งต่าง ๆ ได้เลย แล้วบอกผมในคอมมูนิตี้ว่าคุณเชื่อมต่ออะไรไปบ้าง ผมอยากเห็นของเจ๋ง ๆ เผื่อผมจะได้ shout out ให้ แล้วน่าจะจบแค่นี้ เจอกันในบทเรียนหน้านะครับ
