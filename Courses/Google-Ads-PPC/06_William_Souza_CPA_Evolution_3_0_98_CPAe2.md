## คำแปลเต็ม

สวัสดีครับ เพื่อนๆ ชาว CPA Evolution 2.0 evolutioneers ทุกคน ผม Jay Garces ครับ ในวิดีโอต่อจากนี้ ผมจะขอแชร์แหล่งทรัพยากร สองสามที่ ที่คุณสามารถใช้แก้ไขภาพ ที่คุณสร้างขึ้นมาได้ฟรี

ในวิดีโอก่อนหน้านี้ ผมได้แชร์แหล่งทรัพยากร ที่คุณสามารถหารูปภาพ สำหรับโฆษณาของคุณได้ และในวิดีโอนี้ ผมจะขอแชร์แหล่งทรัพยากร ที่คุณสามารถใช้แก้ไขภาพ ที่คุณได้มาจากแหล่งฟรีอื่นๆ ที่ผมแนะนำในวิดีโอที่แล้ว อย่างรวดเร็วครับ

เรามาเริ่มกันที่ Photoshop CS2 กันก่อนเลยครับ ตอนนี้ผมใช้ Photoshop ในการแก้ไขภาพ และสร้างภาพที่ใช้สำหรับโฆษณาของผม Photoshop มีช่วงการเรียนรู้ (learning curve) อยู่บ้าง ดังนั้น จุดประสงค์ของวิดีโอนี้ ไม่ใช่เพื่อสอนให้คุณเรียนรู้ แต่เพื่อแสดงให้คุณเห็นว่า คุณสามารถดาวน์โหลดเวอร์ชันฟรี ได้จากที่ไหน

สิ่งที่คุณต้องทำก็คือ ไปที่ digitaltrends.com/computing/how-to-get-photoshop-for-free ผมจะลองไฮไลต์ URL ให้คุณดูนะครับ คุณเห็นไหมครับ ผมคิดว่าผมไม่สามารถทำให้มันใหญ่กว่านี้ได้ URL อีกครั้งคือ digitaltrends.com/computing/how-to-get-photoshop-for-free และคำเหล่านั้นทั้งหมด แยกจากกันด้วยเครื่องหมายขีดกลาง (dash)

อีกครั้งนะครับ Photoshop ตัวนี้ เป็นเวอร์ชันเก่าของ Photoshop แต่มันก็คือซอฟต์แวร์มาตรฐาน สำหรับการแก้ไขภาพ และการสร้างภาพ ดังนั้น ผมขอแนะนำอย่างยิ่งครับ

มันมีช่วงการเรียนรู้ เล็กน้อย แต่ข้อดีก็คือ มันเป็นที่นิยมมาก จนมีบทเรียนฟรี (free tutorials) อยู่ทั่วอินเทอร์เน็ต มีบทเรียนฟรี อยู่บนเว็บไซต์ต่างๆ มากมาย ดังนั้น มันไม่น่าจะยากสำหรับคุณ ที่จะหาความช่วยเหลือ หากคุณติดปัญหากับฟีเจอร์ใดฟีเจอร์หนึ่ง หรือกำลังพยายามเรียนรู้มัน

เดินหน้าต่อไปเลยครับ ตรงนั้นแหละ ที่คุณจะได้คำแนะนำ ว่าคุณสามารถดาวน์โหลดมันได้ฟรีได้อย่างไร อีกครั้งนะครับ ผมใช้เวอร์ชันที่ค่อนข้างเก่า เพราะมันตรงกับความต้องการของผม และผมคิดว่าเวอร์ชันนี้ CS2 นั้นเก่ากว่าเวอร์ชันที่ผมใช้อยู่ แต่มันอาจจะทำให้คุณมีปัญหาเล็กน้อย ผมไม่แน่ใจนัก แต่ผมอ่านจากบทความนี้ ว่าคุณยังสามารถใช้มันได้

ผมคิดว่า มันอาจจะทำงานไม่ค่อยเข้ากับระบบปฏิบัติการ (operating system) อย่าง Windows เท่าไหร่นัก แต่ผมใช้ Windows เวอร์ชันเก่า คอมพิวเตอร์ของผมเก่ามากจริงๆ แต่มันก็ทำงานได้ และผมขอแนะนำอย่างยิ่งครับ

ต่อไป เป็นแหล่งทรัพยากรถัดไป ที่ผมอยากจะแนะนำ นั่นคือ GIMP ครับ G-I-M-P GIMP ก็เหมือนกับเป็นทางเลือกของ Photoshop วิธีการทำงานของซอฟต์แวร์พวกนี้ คือการทำงานด้วยเลเยอร์ (layers) ลองนึกถึงเลเยอร์ ว่าเป็นแผ่นกระดาษ ที่คุณสามารถวาดภาพหนึ่งภาพ ลงบนแผ่นกระดาษนั้น จากนั้น บนอีกแผ่นหนึ่ง คุณก็วาดอีกภาพหนึ่ง และคุณสามารถวางภาพซ้อนทับกันได้

ประโยชน์ของมันก็คือ มันทำให้คุณสามารถแก้ไขส่วนหนึ่งส่วนใด ของภาพนั้น โดยไม่ทำลายภาพทั้งภาพ มันเจ๋งมากครับ

คุณเห็นไหมครับ GIMP เป็นทางเลือกของ Photoshop มันก็มีช่วงการเรียนรู้เหมือนกัน แต่ว่า จริงๆ แล้ว มันเป็นตัวเลือกที่ดีกว่า CS2 ครับ เพราะว่า หาก CS2 ทำงานไม่เข้ากับระบบปฏิบัติการของคุณ ผมค่อนข้างมั่นใจว่า GIMP จะเข้ากันได้ เพราะซอฟต์แวร์ตัวนี้ อยู่มานานพอสมควร และมีการอัปเดตอยู่ตลอดเวลา และมันฟรี 100% ครับ

ดังนั้น แค่ไปที่ gimp.org เพื่อดาวน์โหลดซอฟต์แวร์ตัวนี้

ต่อไป ก็เป็นอีกหนึ่งคำแนะนำที่ผมอยากจะให้ นั่นคือ Pixlr ครับ pixlr.com ถ้าคุณไปที่เว็บนั้น สิ่งที่คุณต้องทำคือ พวกเขามีเว็บแอป (web apps) อยู่สามตัว ที่คุณสามารถใช้ได้ ตัวที่ผมกำลังใช้อยู่ตรงนี้ คือ Pixlr Editor คุณจะพบมันได้ที่ pixlr.com และตรงนี้ คุณสามารถสร้างภาพใหม่ หรือเปิดภาพจากเครื่องของคุณ หรือเปิดภาพที่อยู่บน URL หรือเปิดภาพจากไลบรารี (library) ก็ได้

สมมติว่า ผมต้องการสร้างภาพใหม่ ผมจะคลิกตรงนี้ มันจะให้ตัวตั้งสำเร็จรูป (presets) มาให้ ลองดูสิว่าผมมีอะไรบ้าง แล้วผมจะเลือก 1024 by 768 ผมจะคลิก แล้วมันจะให้สิ่งที่เรียกว่า canvas (ผืนผ้าใบ) เพื่อสร้างภาพบนนั้น

และคุณก็จะมีเครื่องมือ (tools) อยู่ตรงนี้ ตรงด้านข้าง ซึ่งอันนี้ เป็นมาตรฐานของซอฟต์แวร์แก้ไขภาพหลายตัว ขึ้นอยู่กับว่าซอฟต์แวร์นั้น มีความสามารถมากแค่ไหน เครื่องมือพวกนี้ อาจจะค่อนข้างเทคนิค คุณสามารถสร้างภาพ เพิ่มรูปภาพ และปรับแต่งทั้งหมดนี้ ตามที่คุณต้องการ

ลองดูสิว่าผมกำลังทำอะไรอยู่ตรงนี้ จริงๆ แล้ว ผมเลือกเครื่องมือนี้มา ผมเองก็ไม่รู้เหมือนกันว่ามันคืออะไร มันเป็นเครื่องมือ sharpen (การลับคมภาพ) ดังนั้น มันคงไม่ทำอะไร ผมแค่เล่นไปเรื่อยๆ ผมไม่ได้ตั้งใจจะทำวิดีโอทั้งคลิป เพื่อพูดถึงทุกฟีเจอร์ แต่ควรจะมีฟีเจอร์ตรงนี้ ที่ให้คุณใส่ข้อความได้ นี่ไง ตัวเลือกข้อความ เราจะใส่ข้อความลงไป ผมจะพิมพ์ว่า my name is Jay (ชื่อของผมคือ Jay) จากนั้น คุณก็สามารถปรับฟอนต์ (font) ขนาดฟอนต์ สไตล์ และแม้แต่สีได้ แล้วก็คลิก OK

เมื่อคุณทำเสร็จแล้ว คุณจะเห็นแถบนำทาง (navigation bar) อยู่ด้านบน และคุณก็จะไปที่ File แล้วก็เซฟภาพลงในเครื่องของคุณ ประมาณนั้นแหละครับ

ผมไม่ได้ตั้งใจจะลงลึกไปในรายละเอียดปลีกย่อย ของแหล่งทรัพยากรตัวนี้ ผมไม่ได้ใช้ตัวนี้เป็นหลัก ผมใช้ Photoshop แต่ผมลองใช้แล้ว พบว่ามันค่อนข้างดี และมันทำให้ผมนึกถึง Photoshop และมันเป็นมิตรกับมือใหม่ (newbie-friendly) มาก คุณสามารถใช้มัน และเรียนรู้มันได้ และแน่นอน หากคุณต้องการ คุณก็สามารถสมัครสมาชิก (sign up) ได้ และหากคุณต้องการความช่วยเหลือ คุณก็แค่คลิกปุ่มตรงนี้ คุณสามารถสำรวจ ค้นหาคำตอบ สำหรับปัญหาที่คุณอาจจะเจอได้

และแหล่งสุดท้าย ที่ผมอยากจะแชร์กับคุณ คือ download.cnet.com ครับ อันนี้ไม่ใช่แหล่งทรัพยากร สำหรับโปรแกรมแก้ไขรูปภาพ หรือโปรแกรมตัดต่อภาพโดยเฉพาะ แต่อันนี้ จริงๆ แล้ว เป็นแหล่งที่คุณสามารถดาวน์โหลดซอฟต์แวร์ เกือบทุกชนิดได้ฟรี ก็ไม่เชิงว่าฟรีทั้งหมดนะครับ แต่หลายตัวก็ฟรี หลายตัวคุณต้องจ่ายเงิน หรือให้ทดลองใช้ประมาณ 10 วัน 15 วัน หรือ 30 วัน

แต่ถ้าคุณไปที่ download.cnet.com และผมใช้ Windows เพราะนั่นคือระบบปฏิบัติการ ที่ผมใช้อยู่ ผมก็จะไปที่แถบค้นหาตรงนี้ แล้วค้นหาคำว่า image editor (โปรแกรมแก้ไขภาพ) แล้วดูว่ามีอะไรโผล่มาบ้าง ขึ้นอยู่กับว่าอะไรขึ้นมา คุณก็สามารถไล่ดูรายการ และเข้าไปดูหน้าของมันได้ และคุณจะเห็นว่า มันบอกว่าตัวไหนฟรีหรือไม่ ตัวนี้ฟรี ตัวนี้เป็นแบบทดลองใช้ (trial) และตัวนี้ก็ให้ทดลองใช้ ตัวนี้ราคา 99 cents

สิ่งที่คุณต้องทำก็คือ ดาวน์โหลดตัวหนึ่งมา แล้วมันจะให้รายการโปรแกรมแก้ไขภาพทั้งหมด ที่พวกเขามีอยู่ในคลัง (repository) ของพวกเขา

ตอนนี้ เมื่อผมดาวน์โหลดซอฟต์แวร์จาก download.com นี่คือสิ่งที่ผมเคยใช้ ผมเคยใช้มันนานมาแล้ว ก่อนที่ผมจะเริ่มซื้อซอฟต์แวร์จริงๆ ในที่สุด ผมก็ซื้อ Photoshop และเรียนรู้วิธีใช้มัน และเพื่อเรียนรู้วิธีใช้ ผมก็แค่ไปที่ YouTube เมื่อไหร่ก็ตามที่ผมเจอปัญหา ผมก็ไปที่ YouTube และมีวิดีโอที่แสดงคำตอบ ให้กับปัญหาที่ผมเจอเป๊ะๆ

แต่เมื่อคุณใช้มัน ต้องแน่ใจว่า หนึ่ง คุณเลือกแพลตฟอร์ม (platform) ที่คุณใช้อยู่ ถ้าคุณใช้ Windows ก็ให้คลิกเลือก Windows แทนที่จะเป็น all (ทั้งหมด) จากนั้น หน้าก็จะรีเฟรช และแสดงทุกอย่างสำหรับ Windows หากคุณใช้ Mac ก็ให้เลือก Mac ตรงนี้

สำหรับเรตติ้ง (rating) ผมส่วนตัวชอบเลือกซอฟต์แวร์ ที่มีเรตติ้งประมาณสี่ดาวขึ้นไป แต่ว่า นี่คือหน้า editor's picks (ตัวเลือกของบรรณาธิการ) และ editor's picks อาจจะมีความลำเอียงได้ ผมไม่แน่ใจว่าพวกเขาได้รับค่าตอบแทนหรือไม่ ดังนั้น ลองยกเลิกการเลือกอันนั้น แล้วไปที่ user rating (เรตติ้งจากผู้ใช้) กัน

ผมชอบเลือกสี่ดาวขึ้นไป อีกครั้ง และผมก็ชอบ editor's picks เหมือนกัน งั้นกลับไปตรงนั้น แล้วเลือกมันด้วย มันให้เลือกได้แค่อย่างเดียว ผมไม่ได้เข้ามาในเว็บนี้สักพักแล้ว งั้นลองดู สามดาวขึ้นไป แล้วก็ user rating สี่ดาวขึ้นไป
