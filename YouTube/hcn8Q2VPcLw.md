# Hermes AI + Obsidian Just Got Simpler

## ประเด็นหลัก

- วิธีให้ AI มีความจำระยะยาว (memory) คือใช้ Obsidian เป็น vault (คลังข้อมูล) กลางเพียงที่เดียว เอเจนต์ทุกตัวทั้ง Hermes และ Claude เขียนและอ่านความจำจาก vault เดียวกัน ไม่ต้องมีเครื่องมือความจำหลายตัว
- ความจำแบบ "สมองร่วมหนึ่งอัน" ดีกว่าการต่อระบบความจำหลายระบบ เพราะช่วยให้เอเจนต์โฟกัส และลดการใช้ tokens (โทเค็น) ลง
- ระบบความจำทำงานเป็น positive feedback loop (วงจรป้อนกลับเชิงบวก): เอเจนต์บันทึกสิ่งที่ทำได้เอง และสามารถดึงความทรงจำกลับมาตอบคำถามเกี่ยวกับธุรกิจได้
- ลูกค้าจองนัดหมายทางโทรศัพท์ได้ 3 วิธี: เชื่อม Hermes กับ Google Workspace API ผ่าน Telegram/WhatsApp, ต่อ voice agent (เอเจนต์เสียง) กับ ElevenLabs ผ่าน Tailscale, หรือใช้ Hermes Apollo ใน Agent OS — วิธีที่ง่ายสุดคือ Telegram/WhatsApp + Google Workspace
- Obsidian vault เป็นแค่โฟลเดอร์ไฟล์ จึงย้ายไปอยู่บนเครื่องเก่าได้ ซิงค์ได้ 3 ทาง: ซิงค์โฟลเดอร์ผ่านคลาวด์ (Obsidian Sync, iCloud, Drive), Tailscale เชื่อมตรง, หรือใช้ MCP (Model Context Protocol) สำหรับ Obsidian
- แก้ปัญหาเข้า Agent OS ไม่ได้: ตรวจว่าได้รันคำสั่ง start แล้ว และให้เอเจนต์บอก localhost (ที่อยู่ในเครื่อง) ที่ถูกต้อง เช่น localhost:3000
- ซิงค์ความจำข้ามสองเวิร์กสเตชันด้วยการล็อกอิน Obsidian บัญชีเดียว แล้วตั้งค่า Sync → Remote Vault (vault ระยะไกล) เพื่อเลี่ยงไฟล์ที่ขัดแย้งกัน
- ไอเดียจัดออฟฟิศสำหรับทำงานกับ AI: ไมโครโฟนคุณภาพดี แสงสว่าง จอที่สอง และลู่วิ่งเดินสำหรับเก็บสเต็ประหว่างรอเอเจนต์ทำงาน
- คำแนะนำเรื่อง AI avatar: ถ้าทำแบบไม่แสดงหน้า (faceless) จะไม่ต้องซิงค์ audio API กับ video API ทำให้เลือกใช้เสียงสมจริงอย่าง Fish ได้ และควรวอร์มอัพบัญชีบนแพลตฟอร์มอย่าง Pinterest ให้เป็นธรรมชาติก่อน

## ความเห็นสรุป

วิดีโอนี้เป็น Q&A ที่เน้นการใช้งานจริงของระบบ AI แบบ agentic โดยหัวใจคือแนวคิด "ความจำกลางที่เดียว" ผ่าน Obsidian ซึ่งเป็นวิธีที่ปฏิบัติได้จริงและประหยัดค่าใช้จ่าย เนื้อหามีทั้งการจองนัดหมายอัตโนมัติ การซิงค์ข้ามเครื่อง และเคล็ดลับเล็กๆ น้อยๆ ที่ใช้งานได้ทันที แม้บางจุดจะเป็นชื่อเครื่องมือเฉพาะ แต่โดยรวมเหมาะกับผู้เริ่มต้นที่อยากสร้างระบบ AI สำหรับธุรกิจของตัวเองครับ
