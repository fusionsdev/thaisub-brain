## บทนำ
วิดีโอนี้สอนตั้งค่า AI agent ที่จัดการอีเมล ปฏิทิน และรายการงาน (to-do list) ของคุณผ่าน Telegram โดยใช้ n8n ร่วมกับ OpenAI, Anthropic, Google Calendar, Gmail และ Google Sheets รวมถึงระบบเตือนความจำที่ส่งข้อความก่อนถึงกำหนดส่งงาน

## คำแปลเต็ม

ในวิดีโอนี้ผมจะแสดงวิธีตั้งค่า AI agent ที่จัดการคำตอบ การสร้างรายการงาน และทุกอย่างผ่าน Telegram อย่างที่ผมตั้งค่าไว้ตรงนี้ และในวิดีโอเราต้องตั้งค่าระบบที่ทำให้คุณทำทั้งหมดนี้ได้ ก่อนอื่นคุณต้องสร้างบัญชีใหม่ถ้าคุณยังไม่มีบนแพลตฟอร์มอัตโนมัติอย่าง n8n คุณสามารถเริ่มต้นใช้งานได้ และจากนั้นคลิกดาวน์โหลด AI agent ด้านล่าง แล้วคลิก เมื่อคุณอยู่ที่หน้า personal คลิก create new แล้วคลิก import from file แล้วคุณจะเห็นไฟล์ที่เพิ่งดาวน์โหลด คลิกเปิด แล้วมันก็จะถูกนำเข้า สิ่งที่เหลือคือการเชื่อมต่อโมดูลต่าง ๆ เหล่านั้นกับบัญชีของคุณเอง

เราจะเริ่มด้วยบัญชี Telegram ถ้าคุณยังไม่มีคุณต้องสร้างการเชื่อมต่อ คุณต้องหา access token คุณจะพบคำแนะนำว่าหาได้จากที่ไหนในวิดีโอสอนสั้น ๆ ตรงนี้ แล้ววางลงไป แล้วคลิก save และเมื่อมันปรากฏขึ้น มันควรจะถูกเลือกโดยอัตโนมัติในโมดูล Telegram อื่น ๆ ทั้งหมด แต่ควรตรวจสอบทุกโมดูลว่าเลือกถูกต้องหรือไม่ ตอนนี้เรามี Telegram ที่ตั้งค่าแล้ว และยังมีอีกอันหนึ่งตรงนี้ คุณไม่ต้องเปลี่ยนอะไร แค่ตรวจสอบว่าบัญชีถูกเลือกตรงนี้

ต่อไปคือโมดูล OpenAI ตรงนี้คุณต้องเพิ่ม credential สำหรับ OpenAI ของคุณ คือ API key และตรงนั้นมีวิดีโอสอนด้วย คุณวางคีย์ลงตรงนี้แล้วคลิก save แค่นั้น จากนั้นเราต้องไปที่ Anthropic ตรงนี้คุณต้องสร้าง credential สำหรับ Anthropic ใส่ API key ตรงนี้ มีวิดีโอสอนสั้น ๆ ว่าหาได้จากที่ไหน เมื่อทำเสร็จแล้วคลิก save แค่นั้นสำหรับโมดูลเหล่านี้

และอีกอย่างที่ต้องทำคือการเชื่อมต่อโมดูลต่าง ๆ สำหรับ Google ซึ่งจัดการรายการงาน อีเมล และปฏิทิน เริ่มจากปฏิทินก่อน สิ่งเดียวที่ต้องทำตรงนี้ คุณต้องมีบัญชี Google และตรงนี้คลิก create a new credential แล้วคลิก sign in with Google แล้วลงชื่อเข้าด้วย Google ที่คุณจัดการปฏิทิน และเมื่อทำเสร็จแล้วคลิก แล้วตรวจสอบโมดูล Google Calendar อื่น ๆ ทั้งหมดว่าเลือกบัญชี Google ที่ถูกต้องหรือไม่ ตรงนี้ดี ดูดีแล้ว แล้วทำแบบเดียวกันกับ Gmail คลิก create new ลงชื่อเข้าด้วยบัญชี Gmail ที่คุณต้องการให้ AI agent จัดการให้ เพื่อให้มันอ่านอีเมลและตอบอีเมลได้ แล้วกลับไปเพื่อให้มันทำงาน และตรวจสอบ Gmail อื่น ตรงนี้ก็ทำงาน อันหนึ่งใช้ส่งข้อความ อีกอันใช้อ่าน และผมจะแสดงตอนท้ายว่ามันทำงานอย่างไรและคุณสื่อสารกับ AI agent เพื่อเข้าถึงอีเมลและนัดประชุมในปฏิทินได้อย่างไร

และขั้นตอนสำคัญคือ Google Sheets อันแรก คุณจะพบเทมเพลตด้านล่างวิดีโอนี้ คลิกแล้วคลิก make a copy ตรวจสอบให้แน่ใจว่าคุณลงชื่อเข้าด้วยบัญชี Google เดียวกัน กับบัญชีที่ถูกต้อง สิ่งเดียวที่ต้องระวังคือเมื่อคุณเชื่อมต่อบัญชี Google Sheets ตรงนี้ภายใต้ create new credential เมื่อคลิก sign in ตรวจสอบให้แน่ใจว่าคุณลงชื่อเข้าด้วยบัญชีเดียวกับที่มี Google Sheet นี้ เพราะมันสำคัญมากสำหรับ AI agent ในการเข้าถึงและใช้งาน ผมทำไปแล้ว คลิก close แล้ว สิ่งที่ต้องทำใน Google Sheet คือเลือก Google Sheet จากดรอปดาวน์ โดยพื้นฐานคุณสามารถเปลี่ยนชื่อมันได้ ตรงนี้ผมเปลี่ยนชื่อเป็นชื่อนี้ ถ้าคุณมี Google Sheets หลายอันในบัญชี การตั้งชื่อเฉพาะก็สมเหตุสมผล สำหรับอันนี้ และนี่คือสิ่งเดียวที่จำเป็น และเราต้องทำกับโมดูลอื่น ๆ เหล่านี้ด้วย ผมต้องเลือก Google Sheet ที่ถูกต้อง ถ้ามันไม่แสดง แสดงว่า Google Sheet อยู่ในบัญชีที่ผิด นั่นคือเหตุผลที่การเชื่อมต่อบัญชีที่ถูกต้องภายใต้ credentials สำคัญมาก ตรงนี้เลือกให้ถูกต้อง คลิก save ด้วย ตอนนี้ผมคิดว่าแค่นั้น ตอนนี้มี error ผมไม่รู้ว่าคืออะไร ต้องเลือกชีต นี่คือชีต แค่นั้น ลองตรวจสอบว่าชีตถูกเลือกตรงนี้ ตรงนี้มันทำงาน ดี คลิก save อีกครั้ง ปกติเราตั้งค่าทุกอย่างเสร็จแล้ว

ตอนนี้เราต้องทดสอบว่ามันทำงานไหม ตรงนี้คุณเห็น workflow สองอัน โดยพื้นฐาน อันนี้คือ AI agent ที่จัดการ to-do list การอ่านและตอบอีเมล และจัดการปฏิทินของคุณ และอันนี้คือลำดับการเตือนความจำ มันจะชัดเจนขึ้นเมื่อเราทดสอบ ดังนั้นผมจะกลับไปที่ workflow ที่ผมตั้งค่าไว้แล้วแบบเดียวกัน เพื่อแสดงฟังก์ชันทั้งหมดของคุณสมบัติ AI agent เหล่านี้ นี่คือของผม มัน active อยู่แล้ว ตรวจสอบให้แน่ใจว่ามันสลับเป็นโหมดเปิด และเมื่อเปิดแล้วคุณสามารถไปที่ Telegram ตรวจสอบให้แน่ใจว่าเป็น agent เดียวกับที่คุณใช้ตอนเริ่มต้น แล้วผมก็สื่อสารกับมันได้

สิ่งแรกที่ผมทำได้ เรามาลองปฏิทินกัน ผมสามารถอัดเสียงได้จะเร็วกว่า สมมติว่าผมจะพูดว่า โอเค ตอนนี้สร้างการประชุมใหม่ในปฏิทินของฉันพรุ่งนี้เวลา 20:00 น. เกี่ยวกับการอัปโหลดหรือตัดต่อวิดีโอ YouTube ของฉัน และตรงนี้คุณจะได้รับการยืนยัน มันตั้งการประชุมในปฏิทินของผม และตรงนี้ผมเห็นว่ามันปรากฏในปฏิทินแล้ว ดี ตอนนี้ผมถามได้ว่ามีกิจกรรมอะไรบ้างที่กำหนดไว้พรุ่งนี้ในปฏิทินของฉัน มันอ่านปฏิทินของผมและบอกได้ว่ามีกิจกรรมอะไร coming up ต้องทำอะไรบ้าง แล้วนี่คือสิ่งที่มันตอบ และผมสามารถให้มันลบกิจกรรมได้ ตรงนี้ผมบอกว่าลบการประชุมที่กำหนดไว้พรุ่งนี้เวลา 20:00 น. มาดูกันว่าผมทำได้ไหม มันควรจะรู้อยู่แล้วว่าต้องลบอะไร มันควรถูกลบ ดูสิ มันหายไปแล้ว นี่คือวิธีที่ผมจัดการปฏิทินของผม

ไปที่อันถัดไปคือการจัดการกล่องจดหมาย ผมเปิดอีเมล demo ของผม มันมีสองอีเมล และผมแค่อยากถามมันว่า: มีอีเมลอะไรในกล่องขาเข้าที่ยังไม่ได้อ่านบ้าง? มาดูว่ามันตอบถูกไหม คุณเห็นไหม มันตอบถูกต้องว่า 2 ฉบับ แล้วผมถามมันได้ว่า: สรุปเนื้อหาของอีเมลล่าสุด สรุปเนื้อหาของอีเมลล่าสุดที่ฉันได้รับ แล้วมันควรจะเปิดอีเมลและให้สรุปสั้น ๆ ว่ามันเกี่ยวกับอะไร มาดูว่ามันทำอะไร และใช่ มันบอกว่าอีเมลเกี่ยวกับอะไร เพอร์เฟกต์

ฟีเจอร์สุดท้ายที่เจ๋งคือ: สมมติว่าคุณมีฝ่ายบริการลูกค้า และนี่คือลูกค้าที่มีปัญหา และผมจะขอให้ AI agent เขียนคำตอบไปยังอีเมลนั้น เขียนคำตอบไปยังอีเมลที่มีหัวข้อ ซึ่งลูกค้ามีปัญหา และส่งไปยังลูกค้าคนนั้น ตอบกลับเขา มาดูว่ามันทำอะไร มันระบุอีเมลฉบับที่สองนี้ได้ และถ้ามันส่งคำตอบ คุณจะเห็น ตอนนี้ผมไปที่ sent emails เห็นไหม มันส่งไปแล้ว และนี่คืออีเมล ดังนั้นมันส่งกลับไปยังลูกค้าแล้ว และนี่เยี่ยมมากสำหรับการตอบกลับที่รวดเร็ว แม้กระทั่งอีเมลส่วนตัวหรืออะไรก็ตาม นี่คือฟีเจอร์ที่ตั้งค่าอย่างถูกต้องแล้ว

และตอนนี้ส่วนสุดท้ายคือรายการงาน เรามีรายการงาน ผมมีของผมตรงนี้ ผมถามมันได้ ก่อนอื่นผมมีสามรายการในรายการงานของผม ผมจะถามมันว่า: มีอะไรในรายการงานของฉันที่ยังทำไม่เสร็จบ้าง? เพราะมันยังเปลี่ยนสถานะจาก pending เป็นเสร็จได้ และคุณเห็นว่ามี error ดูเหมือนชีตถูกจัดโครงสร้างสำหรับโครงสร้างที่มีชื่อว่า to do design มันไม่เข้าใจ ผมแค่บอกว่า ระบุงานที่ยังค้างอยู่ในรายการงานของฉัน มาดูว่าครั้งนี้มันตอบถูกไหม ผมไม่รู้ว่าทำไมมีการเชื่อมต่อ error ผมมองไม่เห็นข้อผิดพลาด งั้นมีงานอะไรในรายการงานของฉัน? เริ่มจากเวอร์ชันง่ายกว่ากัน มาดู มันยังทำได้ เข้าถึง Google Sheet ของฉันและบอกฉันว่างานอะไรบ้างที่อยู่ในนั้น เพราะก่อนหน้านี้มันทำงานได้ ผมตั้งค่างานไว้สองสามอย่างและไม่ได้เปลี่ยนอะไร ผมไม่รู้ว่าปัญหาคืออะไร ก่อนหน้านี้ผมไม่ได้เปลี่ยนอะไร ลองตรวจสอบว่าผมเชื่อมต่อถูกต้องไหม มันคือ AI agent และ test1 นั่นคือ Google Sheet ดูเหมือนผมเลือกบัญชีผิด บัญชีที่เลือกผิด มันควรเป็นบัญชีที่สอง ใช่ ผมคิดว่าเราแก้ปัญหาได้แล้ว นั่นคือเหตุผลว่าทำไมการเลือกบัญชีที่มี Google Sheet จริง ๆ ถึงสำคัญ มาบันทึกอีกครั้ง ตอนนี้มันน่าจะทำงาน เข้าถึงรายการงานใน Google Sheet ของฉันที่ยังไม่เสร็จสมบูรณ์ มาดูว่าครั้งนี้มันตอบถูกไหม คุณเห็นไหม ตอนนี้มันตอบถูกแล้ว สามงานและวันครบกำหนดที่เห็นตรงนี้ เพอร์เฟกต์

และตอนนี้สมมติว่าผมทำงานหนึ่งเสร็จแล้ว กรุณาทำเครื่องหมายงานอัปโหลดบทช่วยสอนการตั้งค่า AI agent workflow ว่าเสร็จสมบูรณ์ ตอนนี้มันควรเปลี่ยนสถานะเป็น complete ดูสิ และผมได้รับคำตอบกลับมา เจ๋งมาก
