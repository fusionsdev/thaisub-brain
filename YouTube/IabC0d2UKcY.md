## ประเด็นหลัก
- Home labs เริ่มต้นด้วยโปรเจ็กต์เล็กๆ และขยายไปเรื่อยๆ ทำให้เกิดความต้องการตัดสินใจระหว่างใช้เซิร์ฟเวอร์เดียวขนาดใหญ่กับการสร้างคลัสเตอร์
- การเลือกแบบ cluster (horizontal scaling) ช่วยลดภาระให้แต่ละเครื่อง ให้ high availability และโอกาสเรียนรู้เทคโนโลยีใหม่ๆ แต่เพิ่มความซับซ้อน
- การเลือกแบบเซิร์ฟเวอร์เดียว (vertical scaling) ง่ายกว่าในการจัดการ ลดความซับซ้อนให้กับ workload ที่ต้องการ resource สูงในที่เดียว และสามารถทดลองได้มากผ่าน virtualization
- การใช้ enterprise server platform เช่น AMD Epic ให้คุณสิทธิประโยชน์เหมือน enterprise ได้เช่น ECC memory, redundant power supplies, security features
- การเริ่มต้นด้วย mini PCs ขนาดเล็กสำหรับ cluster เป็นกลยุทธ์ที่ดีสำหรับผู้เริ่มต้น เพราะให้ performance ดีในขณะที่ใช้ power น้อย

## ความเห็นสรุป
การตัดสินใจระหว่างเซิร์ฟเวอร์เดียวและ cluster ขึ้นอยู่กับความต้องการของแต่ละบ้านน่ะครับ ทั้งสองแบบมีข้อดีและข้อเสียที่แตกต่างกัน หากคุณเพิ่งเริ่มต้น home lab ควรเริ่มต้นกับเซิร์ฟเวอร์เดียวที่มีความสามารถพอสมควรแล้วค่อยๆ ขยายตามความต้องการจริงๆ ไม่ควรสร้างบางอย่างเพียงเพราะว่าดูน่าประทับใจใน server rack
