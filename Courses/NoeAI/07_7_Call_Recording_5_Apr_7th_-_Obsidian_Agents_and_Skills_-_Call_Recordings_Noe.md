## คำแปลเต็ม

การสร้างเพอร์ซันแนลแบรนด์และสร้างบริษัท มันเป็นช่วงเวลาที่ยากลำบากนะครับ ทุกคนชอบทำเป็นว่าตัวเองสมบูรณ์แบบ ว่าโอ้ ฉันตัดต่อวิดีโอทุกคลิปของฉันได้เพอร์เฟกต์มาก แต่ผมกลับไปนั่งอัดวิดีโอตัวเองตามร้านกาแฟ ใส่เสื้อกล้าม หลังไปปาร์ตี้ที่ผับมาแบบโทรม ๆ แล้วคนก็ชอบมันนะ ครับ เจ๋งมาก

เอาล่ะครับทุกคน วันนี้ผมจะมาตอบคำถาม แล้วก็อยากจะพูดถึงเรื่อง carousel ด้วย เพราะช่วงนี้ผมเห็นอะไรบ้า ๆ เกิดขึ้นกับ carousel บน Instagram เยอะมาก งั้นผมจะตอบคำถามทุกคนก่อน แล้วถ้าเหลือเวลา เดี๋ยวค่อยเข้าเรื่องนั้นทีหลัง ทุกคนพร้อมกันไหมครับ เอาล่ะ เริ่มกันเลย

ผมเห็นคุณยกมือขึ้น มีอะไรจะถามครับ

คือคุณคงเห็นข่าวเรื่องการเชื่อมต่อ Gemma 4 ไปแล้ว คุณคิดยังไงกับเรื่องนั้นครับ

Gemma 4 ที่ว่าใช่ไหมครับ G-E-M-M-A เป็นโมเดลที่คุณเอามาเชื่อมต่อแล้วมันรันบนคอมพิวเตอร์คุณได้เลย อ๋อ ผมเคยเห็นมาแล้ว มันหมายความว่าคุณสามารถรัน Claude Code ลงบนเครื่องได้แบบไม่ต้องใช้ API และไม่ต้องสมัครสมาชิกเลย แค่ติดตั้ง Gemma 4 แล้วเชื่อมต่อกับ Claude คุณก็จะมี AI agent วิ่งอยู่สามตัวในทันที เข้าใจแล้วใช่ไหมครับ

สำหรับตัวผมเองนะ ผมรันทุกอย่างบนเครื่องของผมเอง ผมไม่มีอะไรที่ต้องพึ่งคลาวด์ และผมก็ไม่ค่อยจะไปยุ่งกับเรื่องนั้นเท่าไหร่ ถ้าจะพูดตรง ๆ ทุกคนตอนนี้หมกมุ่นกับการตามหาของใหม่ที่เพิ่งออกมา ปัญหาคือทุกคนที่ทำคอนเทนต์ก็จะแบบว่า นี่คือของใหม่ที่เพิ่งออกมานะ แล้วทุกคนก็จะรู้สึกเหมือนตัวเองกำลังตกยุค ผมพูดเรื่องนี้กับคนในกลุ่มเสมอ พวกเขาบอกว่าผมแค่สแปมของแบบนี้เพราะมันไปไวรัล ไม่ได้ใช้จริงซะหน่อย เข้าใจใช่ไหมครับ

สำหรับผม ผมใช้แค่เครื่องมือเดียว แล้วทำมันให้เก่งแบบสุด ๆ ถ้ามีอัปเดตหรือความก้าวหน้าของเครื่องมือนั้น ผมค่อยเอามาปรับเข้ากับ workflow ของผมทีหลัง สิ่งหนึ่งที่ผมเพิ่งทำไปและมันไม่ใช่ของใหม่เลยคือ Obsidian มีมานานแล้ว แต่ช่วงนี้คนเริ่มให้ความสนใจกันเยอะ ผมเริ่มใช้ Obsidian เป็นสมองที่สอง (second brain) ของผม ถ้าพวกคุณยังไม่รู้ว่า Obsidian คืออะไร มันคือแอปที่เชื่อมต่อกับระบบไฟล์ของคุณ แล้วมันจะแมปไฟล์ของคุณออกมา จัดระเบียบทุกอย่างให้ ผมเก็บระบบคอนเทนต์ทั้งหมดของผมไว้ในนี้ ผมมีทุกอย่างเต็มไปหมด แล้วมันก็เชื่อมโยงไปยังไฟล์จริง ถ้าผมเข้าไปในโฟลเดอร์งานวิจัย มันก็เชื่อมกับคอนเทนต์รายวันของผม ผมสามารถเลื่อนดูได้ ผมรู้ทุกแหล่งข้อมูล และมันก็ไล่ตามทุกขั้นตอนเล็ก ๆ ของผม

ผมเพิ่งค้นพบสิ่งนี้ตอนนี้แหละ ซึ่งเป็นเหตุผลที่ผมอาจจะสลับหน้าจอได้ไม่คล่องเท่าไหร่ แต่มันเหมือนสร้างสมองให้คุณ แล้วมันก็มีฟีเจอร์แผนผังหรือ maps ซึ่งเดี๋ยวผมลองเปิดให้ดู ถ้าพวกคุณเคยเห็นมาแล้ว มีคนอีกหลายคนกำลังโปรโมตสิ่งนี้อยู่ มันจะแมปสิ่งต่าง ๆ ออกมาตามความหมายของมัน ยกตัวอย่างเช่นเรื่องสกิล ผมมีเอกสารสกิลทั้งหมดของคอนเทนต์ผมอยู่ในนี้ แล้วในกราฟจริง ๆ โนดทั้งหมดก็เชื่อมต่อถึงกันหมด ทุกอย่างมันพันกันไปหมด การมองกราฟนี้ให้คุณค่าไหม ไม่เชิงหรอก มันมีประโยชน์มากกว่าสำหรับคอมพิวเตอร์ที่จะเข้าใจว่าทุกอย่างเชื่อมโยงกันยังไง ส่วนสำหรับคน เราก็ใช้ canvas ง่าย ๆ ที่มนุษย์อ่านเข้าใจได้ ที่คุณสามารถจัดระเบียบได้ทุกอย่างจริง ๆ

มีใครถามไหมว่ามันเชื่อมต่อกับ Google Drive ได้ไหม คำถามดีมากเลยครับ มันเชื่อมต่อกับระบบไฟล์ของคุณ มันเป็นแค่กระจกสะท้อนระบบไฟล์ของคุณ ทุกโฟลเดอร์ที่คุณมีในคอมพิวเตอร์จะอยู่ในนี้ แล้วคุณก็สามารถเชื่อมต่อ Claude Code เข้ากับ Google Drive ได้ แล้วคุณก็ push ทุกอย่างลงไปใน Google Drive ได้ ให้มันจัดการจัดระเบียบไฟล์ทั้งหมดของคุณใน Google ได้เลย เจ๋งดี

แต่จุดประสงค์ของมันคืออะไรล่ะ Noah คุณใช้มันแค่เพื่อมองเห็นไฟล์ของคุณหรือเปล่า แล้วเราจะได้คุณค่าจากการมองเห็นมันยังไง

ผมได้คุณค่าเพราะเวลาผมมองไฟล์ของผมเอง ผมก็แบบว่า โอ้ นี่มันบ้ามาก มีอะไรอยู่ในนี้บ้าง แล้วมันก็เป็น Markdown ทั้งหมด ซึ่งเป็นวิธีที่คอมพิวเตอร์ใช้คุยกับเอกสารหรืออ่านเอกสาร มันเป็นเอกสารที่ดูไม่สวยเท่าไหร่สำหรับมนุษย์เรา แต่เราอ่านได้นะ มันถูกสร้างมาเพื่อให้ LLM อ่านโดยเฉพาะ สิ่งที่ Obsidian ทำคือ ถ้าผมเปิดไฟล์เดียวกัน เช่น ขอเข้าไปที่โฟลเดอร์ Amazon Ads ของ Brandon นะ Obsidian จะเอา Markdown นั้นมาทำให้ดูสวยและอ่านง่าย แล้วคุณยังสร้าง Kanban ได้ สร้าง pipeline ได้ และสิ่งที่เจ๋งคือทุกอย่างเชื่อมโยงถึงกัน คุณจะเห็นว่ามันมีลิงก์ไปยังไฟล์อื่น ๆ มันเหมือนสารานุกรมสำหรับไฟล์ทั้งหมดบนคอมพิวเตอร์ของคุณ ผมเองก็ยังเรียนรู้ไปพร้อม ๆ กันแหละ ผมเพิ่งค้นพบเรื่องนี้จริง ๆ

เออ ใช่ครับ เอาเงินจาก Amazon มาด้วยเลย ขออีก ครับเพื่อน ผมไม่รับงานรีวิวแบรนด์แล้วโว้ย ไม่เอาพวกนั้นแล้ว พวกโง่ทั้งนั้น แต่สำหรับเคสการใช้งานของผมตอนนี้และต่อไป คือการมองเห็น pipeline ทั้งหมดของผมพร้อมข้อมูลข้างในทั้งหมด แล้วงานต่อไปของผมคือผมจะเริ่มสร้างไฟล์สกิลทั้งหมดของผม ผมสร้างสกิลแรกแล้ว นี่คือสกิล content creator ของผม มันเป็น workflow ว่าสกิลทำงานยังไง มันรวบรวมข้อมูล ดึง hook ที่พิสูจน์แล้วจากหลายแหล่งข้อมูล สร้างคอนเทนต์ แล้วก็บันทึกลง Airtable สิ่งที่เจ๋งคือ นี่คือเหตุผลที่ผมชอบอันนี้มากกว่า Figma เพราะผมเคยเป็นคนสาย Figma ตัวยง แต่พอผมแก้ไขอะไรสักอย่าง เช่น แก้สคริปต์คอนเทนต์ ผมไม่ต้องไปเปิด Figma เพื่ออัปเดตมันอีก มันอัปเดตให้อัตโนมัติ มันบ้ามาก

เอาล่ะทุกคน มีอะไรอีกไหมครับ

เราสามารถทำให้การนอนเป็นระบบอัตโนมัติได้ไหม

คำถามสุดยอดมากครับ ผมก็พยายามอยู่เหมือนกันครับเพื่อน เอาเลย มีอะไรจะถามผม

เอาล่ะ ผมรอคอยวันนี้มาก เพราะผมมีโอกาสได้เข้าไปดูเนื้อหาในคอร์สเยอะขึ้นมาก และการดูมันทำให้เกิดคำถามเพียบ ผมไม่อยากไปถมบอร์ดของคอมมูนิตี้มากเกินไป นั่นแหละที่ผมมาถามในคอลนี้ แต่ผมมีคำถามสั้น ๆ สองสามข้อที่อยากถามให้จบ ๆ ไป คุณมองความสัมพันธ์ระหว่างสกิลที่อยู่บนคอมพิวเตอร์ กับสกิลที่อยู่ในฝั่งแชทของแอป Claude ยังไงครับ เพราะผมพบว่าตัวเองพยายามทำความเข้าใจว่า อันนี้มันอัปเดตหรือยัง อันนั้นอัปเดตไหม มันเหมือนผมมีสกิลอยู่สองที่ เพราะบางครั้งผมใช้แชทเมื่อแค่อยากคุยทั่วไป เพราะหลัก ๆ ผมมีโปรเจกต์และแชทอยู่ในโปรเจกต์ ขณะที่ Claude Code มันเป็นพื้นที่อิสระมากกว่า แล้วนี่คุณใช้เวอร์ชันเดสก์ท็อปของ Claude Code หรือเปล่า

คือผมสร้างรีพอร์ตอันนึงขึ้นมาในแชท แล้วจู่ ๆ ผมก็อยากไปใช้ Claude Code แล้วผมก็แบบว่า เฮ้ ผมสร้างอันนั้นในแชทไปแล้ว มันก็เลยไปอยู่ในแท็บ Customize แล้วก็ Skills และ Claude Code ของผมก็อิงจากระบบไฟล์บนคอมพิวเตอร์ของผม ผมเลยอยากเห็นว่าเซตอัปของคุณเป็นยังไง แล้วคุณจัดการยังไง คุณทำทุกอย่างใน Claude Code เลยหรือ ไม่ใช้แชทเลยเหรอ แล้วสกิลพวกนั้นมันอัปเดตกันยังไงระหว่างทั้งสองที่

สำหรับผม ผมจะใช้แชทก็ต่อเมื่ออยากได้อะไรที่เป็นภาพ หรืออยากโชว์เคสการใช้งานที่พวกคุณจะไม่เข้าใจถ้าไม่เห็นภาพ ผมเลยทำมันให้ดูง่าย ๆ เรื่องของสกิลคือ มันอยู่ในไฟล์คำสั่งที่ซ่อนอยู่บนเครื่องคุณ มันเป็นแบบ global เต็มรูปแบบ ผมไม่ได้ใช้เวอร์ชันเดสก์ท็อปของ Claude จริงจังเท่าไหร่สำหรับงานของผม สมมติว่าคุณอยู่ใน Claude Desktop แล้วสร้างสกิลขึ้นมา มันจะอยู่ในแท็บ Customize กับ Skills ของคุณ สิ่งที่คุณทำได้คือ ผมสร้างโฟลเดอร์ที่สองขึ้นมาในคอมพิวเตอร์ ซึ่งอยู่ใต้โฟลเดอร์หลักของผม เพราะไฟล์สกิลของคุณมันอยู่บนเครื่องแบบ global คุณไม่สามารถ commit และ push ขึ้น GitHub ได้ ดังนั้นถ้าคอมพิวเตอร์คุณจมลงก้นมหาสมุทร คุณจะสูญเสียสกิลทั้งหมด ซึ่งน่ากลัวมาก สิ่งที่ผมทำคือผมสร้างโฟลเดอร์สำรอง แล้วก็ใช้สกิลตัวสร้างสกิล (skill creator) ทุกครั้งที่ผมสร้างสกิลใหม่ มันจะทำสำเนาเข้าโฟลเดอร์ที่อยู่ในเครื่องผมโดยอัตโนมัติ ซึ่งผมสามารถ push ได้ มันก็แค่ก็อปปี้เฉย ๆ

เจ๋งดี แล้วคุณก็สร้างระบบอัตโนมัติที่ถูกทริกเกอร์ทุกครั้งที่มีการสร้างสกิลใหม่ใช่ไหม ประมาณนั้นแหละ วิธีนี้ก็เป็นทางเลือกของผมเหมือนกัน

ทุกสัปดาห์ผมจะรันสกิลวางแผนวันอาทิตย์ (Sunday planning skill) มันจัดการการเงินทั้งสัปดาห์ให้ผม มันวางแผนสัปดาห์และนัดหมายของผม ทุกอย่างที่ผมต้องทำ แล้วก็จัดระเบียบทั้งหมดให้ แต่ที่สำคัญกว่านั้นคือมันทำความสะอาดเครื่องทั้งเครื่องของผม มันจัดระเบียบไฟล์กระจัดกระจาย ตอนที่ผมเปิดโชว์ให้ดู คุณจะเห็นว่ามีไฟล์ลอย ๆ อยู่บ้าง เพราะผมทำงานหนักทั้งสัปดาห์ พอถึงวันนั้น ผมรันมัน มันทำความสะอาดเครื่องทั้งหมด แล้วก็ทำสำเนา มันจะตรวจว่า คุณมี 100 ไฟล์ แต่ในโฟลเดอร์สำเนามีแค่ 90 ก็ต้องเพิ่มอีก 10 ไฟล์ที่หายไปเข้าไปในสำเนา

แล้วอีกคำถามหนึ่งที่ต่อจากนี้คือ ผมใช้ Antigravity แทน Cursor มันก็คล้ายกัน แค่บังเอิญโหลดมันมาก่อนที่จะเข้ามาในคอลนี้ แล้วคุณจัดการยังไง

ข้อดีของแอป Claude ในฝั่งแชทคือผมมีประวัติแชททั้งหมดของผม ผมสามารถย้อนกลับไปคุยกับมันใหม่ได้ถ้าจำเป็น มันจัดระเบียบความคิดและสมองของผมได้จริง ๆ แล้วคุณทำแบบนั้นจากฝั่ง Cursor หรือฝั่ง Claude Code ได้ยังไง

ผมไม่ใช่คนสาย Antigravity ผมไม่เคยใช้ Antigravity เลย แต่ที่คุณพูดคือมันสร้างความจำแบบโลคัลใช่ไหม มันทำอะไรเหรอ

มันก็เหมือนสำเนาของ Cursor ก็คิดซะว่าผมใช้ Cursor อยู่ แต่ที่ผมถามคือ ในฝั่ง Claude อย่าง OpenAI หรือ Claude แชทเวอร์ชันมันมีประวัติทั้งหมดของผม แต่พอผมใช้ Cursor แล้วปิด แล้วเปิดใหม่ มันเริ่มต้นใหม่หมด ผมเลยสงสัยว่าคุณจัดการยังไง เพราะมีหลายอย่างที่ผมต้องย้อนกลับไปหาบทสนทนาหรือประวัติเก่า ๆ เพื่อคุยต่อ คุณเข้าถึงมันยังไงแทนที่จะเริ่มจากศูนย์ทุกครั้ง

เรื่องนี้ตลกดี เพราะผมเพิ่งรีสตาร์ทคอมพิวเตอร์ก่อนหน้านี้เอง ตอนนั้นผมทำงานอยู่สามโปรเจกต์พร้อมกัน สิ่งที่ผมทำคือ ผมทำงานหลัก ๆ แค่ไม่กี่โฟลเดอร์ ผมทำงานในโฟลเดอร์ธุรกิจของผม ถ้าทำคอนเทนต์ก็จะอยู่ในโฟลเดอร์คอนเทนต์ออร์แกนิก ถ้าทำโปรเจกต์ลูกค้าก็จะอยู่ในโฟลเดอร์ของลูกค้ารายนั้น ผมทำอะไรซ้ำ ๆ เดิม ๆ ผมเลยรู้ว่าโฟลเดอร์ไหนที่ผมทำงานอยู่ สมมติว่าผมรู้ว่าผมกำลังทำงานคอนเทนต์ลูกค้าอยู่ใน Obsidian สิ่งที่ผมชอบทำคือ ผมเข้าไปใน NoeAI แล้วผมมีทุกอย่างอยู่แล้ว มันโผล่ขึ้นมาให้ผมทั้งหมดเลย

เจ๋งมากเลย

อะไรนะ มันไม่เคยเป็นแบบนั้นสำหรับผม นี่คือสิ่งที่ผมถามพอดี เพราะมันไม่ทำแบบนั้น นั่นแหละคือสิ่งที่ผมกลัว

เดี๋ยวผมโชว์ให้ดู มันหยุดบทสนทนาไว้จริง ๆ นะ ดูอันนี้สิ ผมอยู่ใน NoeAI แล้วนี่คือหน้าต่างที่มันจะเปิดขึ้นมา คุณเห็นส่วนสีฟ้าตรงนี้ไหม นี่คือวิธีที่ผมรักษาความเป็นระเบียบ ผมเปลี่ยนชื่อเทอร์มินัลทั้งหมดของผมตลอดเวลา ถ้าผมรัน Claude Code แล้วกำลังทำงานในระบบคอนเทนต์ของผม ผมก็จะกด /resume แล้วก็เห็นเลยว่า นี่ไง ระบบคอนเทนต์ อยู่ตรงนั้น เห็นไหมครับ โอ้ เทอร์มินัลของผม เยอะมากเลย ผมกำลังทำงานใน Obsidian ผมก็แค่พิมพ์ clog /resume

แล้วคุณทำยังไงให้สิ่งเหล่านั้นโผล่ขึ้นมา คุณทำยังไงให้ได้ส่วนสีฟ้าเหล่านั้น

ดูนะครับ ผมจะเลือกมาซักอันนึงแบบสุ่ม ผมอาจจะตั้งชื่อมันว่าแบบนี้ อันนี้คืออันใหม่ วิธีคือคุณพิมพ์เครื่องหมาย / แล้วตามด้วย rename แล้วคุณก็ตั้งชื่อมัน พอผมออกจาก Claude Code แล้วกลับเข้ามาใหม่ ถ้าผมอยากหา ผมรู้ว่าผมกำลังทำงานเรื่อง Ramsey resume แล้วก็บูม มันอยู่ตรงนั้น มันจะแสดงเธรดต่าง ๆ ทั้งหมดที่แตกต่างกัน ที่เมื่อก่อนผมไม่เห็น พอคลิกอันที่ต้องการ เช่น อันนี้คือ content puller ที่ผมกำลังทำอยู่ มันจะดึงการคำนวณและคอนเท็กซ์ทั้งหมดที่เรามีกลับมา เข้าใจแล้ว

แต่จุดที่ต้องระวังคือ มันไม่ใช่แบบสากล มันไม่ได้จำทุกที่ สมมติว่าผมกำลังทำงานใน NoeAI แล้วผมเข้าไปดู คุณจะเห็นว่ามีแค่อันเดียว เพราะนั่นคือโปรเจกต์เดียวที่ผมทำในโฟลเดอร์นั้น แต่มันมีความจำสำหรับโฟลเดอร์เฉพาะนั้น สำหรับโปรเจกต์ที่คุณเคยทำงานอยู่ น่าสนใจ

ถ้าอย่างนั้นคุณไม่เห็นคุณค่าในการมีเธรดเดียวแล้วกลับมาที่มันทุกสัปดาห์สำหรับงานอัปเดตลูกค้ารายสัปดาห์เหรอ แบบไม่ต้องเริ่มใหม่ ดึงคอนเท็กซ์จากสัปดาห์ก่อนมา หรือคุณมองแต่ละสัปดาห์เป็นเรื่องแยกกัน

เพราะถ้าคุณกลับมาที่คอนเท็กซ์เดิมเรื่อย ๆ คอนเท็กซ์ของคุณจะใหญ่ขึ้นเรื่อย ๆ จนเกิดสิ่งที่เรียกว่า context rot คือคอนเท็กซ์ของคุณใหญ่เกินไปจนมันไม่สามารถนำทุกอย่างที่คุณพูดมาพิจารณาได้ เพราะมันมีตัวอักษรมากเกินไป ยิ่งคอนเท็กซ์น้อยเท่าไหร่ ผลลัพธ์ก็จะดีขึ้นเท่านั้น อย่างน้อยก็ในแง่ของความจำ วิธีแก้คือการสร้างไฟล์คอนเท็กซ์ สมมติว่าคุณทำงานในโปรเจกต์หนึ่ง สมมติว่าผมกำลังทำงานให้ลูกค้า แล้วผมอยู่ระหว่างการสร้างงาน ผมเคยบอกว่าผมกำลังรีสตาร์ทคอมพิวเตอร์ เราจำเป็นต้องเซฟและ commit ทุกอย่าง เพื่อให้แน่ใจว่าเรากลับมาทำต่อจากที่ค้างไว้ได้ แล้วมันก็เอาไปไว้ในที่ปลอดภัย มัน commit และ push เอกสารทั้งหมดว่าบทสนทนาเราอยู่ตรงไหน พอวันรุ่งขึ้นผมล็อกอินกลับมา แล้วผมเริ่มเซสชันใหม่ ผมก็บอกว่า เรากำลังทำงานโปรเจกต์ของ Alex Robinson อยู่ ช่วยดึงมันกลับมา แล้วเรามาทำต่อจากที่ค้างไว้ได้ไหม แล้วมันก็มีคอนเท็กซ์ทั้งหมด เพราะผม commit และ push ไปแล้ว มันก็ไปอ่านเอกสารทั้งหมดให้ผม มันจะได้คอนเท็กซ์ทั้งหมดนั้นมา

แต่คุณจะใช้คำสั่ง rename ก่อนใช่ไหม คุณจะกลับไปแล้วก็ rename ใช่ ผม rename ทุกอย่างแล้วตอนนี้ เพราะมันง่ายที่จะรักษาความเป็นระเบียบเวลาทำหลายโปรเจกต์ เข้าใจไหม เอาล่ะ ขอบคุณที่อธิบายทั้งหมดนะ ขอบคุณมาก

ยังมีคำสั่งเจ๋ง ๆ ที่ละเอียดอ่อนอีกเยอะ พวกคุณเคยเห็นอันนี้ไหม ไม่รู้ว่าทำไมผมแชร์หน้าจอไม่ขึ้น แต่เดี๋ยวดูวิธีที่ผมทำนะ ผมเข้า Claude Code แล้วก็ดูสิ คำสั่งบางอันเจ๋งมาก คุณสามารถดูการใช้งานของคุณได้ตรงนี้ เจ๋ง ผมพิมพ์คำสั่ง แล้วก็เห็นได้ว่าเกิดอะไรขึ้นกับเซสชันทั้งหมดของผมตอนนี้ อันนี้เจ๋งมาก แล้วก็มี /resume ผมใช้การออกและกลับเข้ามาบ่อยมาก ทุกครั้งที่ทำงานเสร็จผมก็ทำแบบนั้น พวกคุณเคยเห็นอันนี้ไหม อันนี้โคตรเจ๋ง สมมติว่าคอมพิวเตอร์ผมไม่ระเบิดและไม่ทำให้คอลนี้ช้าลงนะ เอาล่ะ มาทำงานต่อจากที่ค้างไว้ พอเครื่องมันกำลังทำงานอยู่ คุณไม่สามารถคุยกับมันต่อได้เพราะมันกำลังยุ่ง แต่สิ่งที่คุณทำได้คือถามมันว่า ขั้นตอนต่อไปจะใช้เวลานานแค่ไหน แล้วมันจะตอบคุณขึ้นมาด้านข้าง มันจะให้คำตอบขณะที่งานกำลังรันอยู่ จากประวัติที่ผ่านมา อันนี้ควรใช้เวลาประมาณห้าถึงเจ็ดนาที แล้วผมก็กด space เพื่อออกจากโหมดนั้น แล้วกลับมาที่เดิมได้เลย เจ๋งจริง ๆ

น่าสนใจ ผมแค่อยากได้มุมมองว่าคุณทำงานยังไง เพราะคุณอยู่ในเรื่องนี้ลึกกว่าผมมาก ผมแค่พยายามเรียนรู้วิธีที่ดีที่สุด ว่าเข้าใกล้มันยังไง

อีกอันที่ผมใช้คือ /compact /compact มีประโยชน์เพราะถ้าโปรเจกต์คุณใหญ่จริง ๆ สมมติว่าโปรเจกต์ของคุณเริ่มใหญ่ขึ้นเรื่อย ๆ ณ จุดนั้น สมมติว่าคุณเริ่มจะหมดคอนเท็กซ์ เหลือแค่ 80 ถึง 90 เปอร์เซ็นต์ คุณจะเจอปัญหา context rot สิ่งที่คุณทำได้คือรัน /compact แล้วมันจะบีบอัดบทสนทนาให้คุณ ย่อมันลง สรุปมันให้ แล้วคุณรู้ได้ยังไงว่าคุณใช้คอนเท็กซ์ไปเท่าไหร่

โอเค แล้วสิ่งนี้มันต้องรัน 24 ชั่วโมงต่อวันไหม หรือเป็นสิ่งที่ออกมาทำทุกเช้า

ผมคงไม่ถึงกับบอกว่าตลอด 24 ชั่วโมง แต่แน่นอนว่าเป็นช่วงเวลาทำงานของเจ้าของธุรกิจ มันคงไม่ใช่แค่ทุกเช้าใช่ไหม

โอเค สาเหตุที่ผมถามแบบนั้นก็เพราะ คุณสามารถสร้างเอเจนต์ได้ตราบเท่าที่คอมพิวเตอร์ของคุณเปิดอยู่ตลอด 24 ชั่วโมง ผมรู้ว่ามีบาง repo ที่ผมคิดว่ามีอะไรที่เรียกว่า caffeinated mode ผมไม่ใช้มันเพราะผมใช้แล็ปท็อปและผมใช้เครื่องตลอดเวลา แต่คุณสามารถรันเอเจนต์ได้ตลอด 24 ชั่วโมง ให้มันตื่นขึ้นมา แล้ววนลูปทำสิ่งต่าง ๆ มันเหมือนผู้ช่วยส่วนตัวที่มีคำสั่ง เช็คอีเมล เช็คทุกอย่าง ให้แน่ใจว่าทุกอย่างเป็นไปตามแผน ให้แน่ใจว่าเราโอเค ซึ่งคุณทำได้ แต่ผมไม่แนะนำ เพราะคุณยังไม่ได้เปลี่ยนมันให้เป็นสกิลด้วยซ้ำ ถ้าคุณทำแบบนี้ทุกวัน ผมจะเริ่มจากการแมปสิ่งที่คุณอยากได้ก่อน แล้วค่อยเปลี่ยนเป็นสกิลแต่ละอัน สกิลหนึ่งสำหรับการส่งข้อความตอนเช้าของผม ผมรู้ว่ามันเฉพาะเจาะจงมากสำหรับผม แต่คุณแค่เอาไปปรับเปลี่ยนได้ มันคือการส่งเอเจนต์ไปดูใบแจ้งหนี้ทั้งหมด แล้วให้แน่ใจว่ามันอัปเดตครบในวันนี้ เช็กงานที่ค้างของผม อะไรก็ตามที่อยากให้ทำ ผมเองจะรันมันทุกเช้าตอนที่เปิดคอมพิวเตอร์ก่อนเป็นอย่างแรก ไม่มีอะไรซับซ้อน ถ้าคอมคุณรันอยู่ คุณสามารถตั้ง scheduled tasks ใน Claude Code ได้ มันจะทำ cron ซึ่งก็คืองานตามตารางเวลา แค่นั้นแหละ

แต่ปัญหาคือมันอยู่ได้แค่ไม่กี่วัน Claude ยังไม่ออกฟีเจอร์ที่รันได้ตลอด 24 ชั่วโมงอย่างสม่ำเสมอ มันอยู่ได้จริง ๆ แค่ประมาณสามวัน แล้วคุณก็ต้องอยู่ในคอนเท็กซ์วินโดว์เดียวกัน ผมเลยแนะนำให้เริ่มจากสร้างสกิลก่อน

แล้วถ้าผมอยากทำอะไรตอนอยู่นอกบ้านล่ะ ถ้าผมอยากแค่พูดว่า พรุ่งนี้ผมมีประชุม มีนัดกับคนนี้ ช่วยจัดตารางให้หน่อย ลงในปฏิทิน ให้แน่ใจว่าอีกฝ่ายยืนยัน อันนั้นทำกับ Claude ไม่ได้เหรอ แล้วถ้าทำได้ มันจะเป็นสกิลไหม

คุณสามารถรันแบบ dispatch mode ได้ เพื่อนของผมที่ชื่อ [ฟังไม่ชัด] ส่งอันนี้มาให้ ผมจะแปะให้พวกคุณดูด้วย ผมยังไม่ได้ตั้งค่ามัน แต่เป็นแอปที่สามารถเชื่อมต่อกับ Claude Code ตอนที่คุณไม่อยู่ เพราะ dispatch ที่ Anthropic สร้างไว้ตอนนี้มันห่วยมาก อันนี้ดีกว่ามาก ตราบใดที่คอมพิวเตอร์คุณเปิดอยู่และคุณอยู่ในคอนเท็กซ์เดียวกัน ใครลองไปดูแล้วบอกผมด้วยนะ คุณสามารถทำงานกับ Claude ต่อไปได้แม้คุณจะไม่อยู่ ผมยังไม่ได้ลองเลย แค่โยนไอเดียออกมา แต่ปกติแล้วผมต้องบังคับตัวเองให้หยุด นั่นคือตอนที่ผมออกจากบ้าน เข้าใจไหม

เอาล่ะ ผมแค่นึกว่ามันเป็นการใช้งานง่าย ๆ แต่เดี๋ยวผมเริ่มจากสกิลก่อนแล้วค่อยดูว่ามันพาไปได้ไกลแค่ไหน เริ่มจากง่าย ๆ แล้วค่อยเติมอะไรเล็ก ๆ น้อย ๆ แล้วค่อยเพิ่มมากขึ้น แล้วค่อยดูว่าตอนท้ายมันควรเป็นเอเจนต์จริง ๆ ไหม ขอบคุณครับ

เรามี Jared อยู่ด้วย มีอะไรจะถามครับ

ว่าไงเพื่อน คำถามสั้น ๆ ผมทำงานอยู่ภายใน Cursor เต็มตัว ตามคำแนะนำของคุณที่ให้ใช้ Claude Code แต่ผมพบว่าตัวเองกลับไปใช้ Claude Desktop เพื่อแชท เมื่อผมแค่อยากคุยโต้ตอบกลับไปมา ผมสังเกตว่าทุกอย่างที่ทำใน Cursor มันไม่ได้เชื่อมโยงกับอะไรใน Claude Desktop ของผมเลย คำถามคือ เวลาคุณอยากใช้แชทโดยเฉพาะ คุณแค่ใช้มันใน Cursor แล้วคุยกับ Claude Code เลยเหรอ หรือคุณหาวิธีเชื่อมต่อ Claude Desktop เข้ากับ Cursor แล้ววิธีของคุณคืออะไร

เอาล่ะ Ramsey ถามคำถามเดียวกันเป๊ะ และตอนนี้ผมเข้าใจจริง ๆ ว่าเขาหมายถึงอะไร คุณใช้ Claude Desktop เพื่อคุยกับ Claude เรื่องไอเดียหรือความคิดบางอย่าง แล้วใช้โค้ดจริงกับเทอร์มินัลเพื่อสร้างของจริงใช่ไหม ใช่ เป๊ะ หรือถ้าผมมีคำถามสองสามข้อหรืออยากคุย ผมอาจจะอยากคุยเรื่องโปรเจกต์ที่ผมจะไปทำใน Cursor แต่มันไม่ได้เชื่อมต่อกับอันนั้นจริง ๆ ถ้าผมเข้าไปใน Claude Desktop

ผมไม่รู้ว่าทำไมคุณถึงอยากทำแบบนั้น เพราะมันเป็นโมเดล Claude ตัวเดียวกันข้างใน แค่หน้าตามันน่าเกลียดกว่ามาก ณ จุดนั้นคุณควรใช้ Claude Code อย่างเดียว ทั้งแชทและทุกอย่าง เพราะมันมีคอนเท็กซ์ทั้งหมดของผมเกี่ยวกับทุกอย่างในธุรกิจของผม นั่นคือคุณค่าของมัน ถ้าผมเข้าไปในเดสก์ท็อป มันทำงานจากความจำที่มันคุยกับผมสะสมมาเรื่อย ๆ ถ้าผมถามว่าตอนนี้ผมทำอะไรอยู่ มันจะบอกว่าผมอยู่ในปวยร์โตริโกมาสี่เดือนแล้ว แต่ถ้าผมถาม Claude Code มันจะบอกว่าคุณอยู่ที่นั่นมาสามสัปดาห์ เพราะมันรู้ว่าผมอยู่ไหนและกำลังทำอะไร มันอัปเดตตลอดเวลา และทุกครั้งที่ผมปล่อยสมอง (brain dump) และกำลังคิดกระบวนการในหัว ผมทำผ่าน Cursor หรือผ่าน Claude Code ใน Cursor เพราะมันมีคอนเท็กซ์ทั้งหมดนั้น และผมจะได้คำตอบที่ดีที่สุด มันเป็นโมเดลเดียวกัน แค่หน้าตาไม่สวยเท่า

เคสการใช้งานเดียวที่ผมใช้ Claude Desktop คือก็อปปี้วางบทเรียนของโรงเรียน เพราะเทอร์มินัลก็อปปี้วางของธรรมดาไม่ค่อยดี ครับ เข้าใจแล้ว ดังนั้นคุณใช้ Claude Code ใน Cursor เป็นตัวหลัก ใช่มันเป็นโมเดลเดียวกับเดสก์ท็อป ไม่มีความแตกต่างจริงจัง ยกเว้นว่าเวอร์ชันเดสก์ท็อปเหมือนเอาผ้าปิดตาตัวเองแล้วใช้มือเดียว เทียบกับใน Cursor ที่มีทุกอย่างที่คุณต้องการ มีคอนเท็กซ์ทั้งหมดบนทุกอย่าง และรู้ทุกอย่างเกี่ยวกับคุณ เพอร์เฟกต์ ขอบคุณ

ตอบคำถามคุณแล้วใช่ไหม ครับ ได้ มันยังทำให้ผมงงอยู่ดี เพราะสำหรับโปรเจกต์ในแอปเดสก์ท็อป ความสามารถในการย้อนกลับไปในแชทบางแชทตลอดเวลามันสำคัญมาก ผมว่า /rename จะเป็นทางเลือกของผม คุณจะใช้มันทุกครั้งที่อยากกลับไปหาความคิดเดิม เพราะผมมีธีมที่เกิดซ้ำ ๆ ที่ผมพยายามแยกลูกค้าออกมา เพื่อไม่ให้ทุกอย่างมารวมอยู่ในที่เดียว แล้วผมก็พยายามถามตัวเองว่า ฉันเคยพูดถึงเรื่องนี้แล้วหรือยัง สิ่งที่ฉันกำลังหาอยู่ที่ไหน เพราะในเดสก์ท็อปผมเห็นแชททั้งหมดของผมในแต่ละลูกค้า ไม่รู้สิ แต่มันสมเหตุสมผลกับที่คุณพูด

พิมพ์ /resume นะทุกคน คุณสามารถกลับไปบทสนทนาไหนก็ได้ที่คุณเคยมี ด้วยคำสั่ง /resume ใช่ เป๊ะ นั่นคือทางออก นั่นคือทางออกแน่นอน

ผมขอเพิ่มอะไรสั้น ๆ เพราะผมใช้ Antigravity เหมือนกัน ผมได้ยินว่าคุณใช้เหมือนกัน คุณสามารถใช้เทอร์มินัลซึ่งผมมักจะวางไว้ข้างล่าง แล้วก็ใช้ส่วนขยาย (extension) ซึ่งมันเหมือนการผสมระหว่างเดสก์ท็อปกับเทอร์มินัล เพราะคุณยังสามารถรันคำสั่งต่าง ๆ ได้ และคุณมีคำสั่ง /resume แล้วคุณจะเห็นเซสชันที่คุณรันอยู่ปรากฏในแอปเดสก์ท็อป มันคือความสมดุลว่า คุณกำลังทำงานในโฟลเดอร์ไหน เพราะผมเจอปัญหานี้บ่อยมาก การแบ่งไฟล์ของคุณเจ๋งมาก แต่พอผมอยู่ในโฟลเดอร์ลูกค้า หรือทำงานอะไรสักอย่าง คุณต้องอยู่ในโฟลเดอร์ที่ถูกต้อง หรืออยู่ในโฟลเดอร์ที่สูงพอที่จะมีคอนเท็กซ์ของทุกอย่างที่อยู่ข้างล่างมัน แต่ถ้าคุณลงลึกเกินไป มันจะเห็นคอนเท็กซ์แค่ตรงนั้น ถ้าเป็นโปรเจกต์ลูกค้าและคุณกำลังทำเว็บไซต์ของพวกเขา มันก็จะมองแค่ตรงนั้นโดยประมาณ แต่แต่ละเซสชันจะโชว์เหมือนที่ Noah โชว์ ว่าคุณอยู่ในโฟลเดอร์ไหน ไม่ว่าจะใช้ /resume หรือดูจากรายการ มันโชว์ตรงนั้น

ผมเพิ่งค้นพบว่าคุณรู้ไหม ผมเคยใช้เทอร์มินัลแบบเดียวกับที่ Noah โชว์ แล้วผมสังเกตว่าพวกเขามีปลั๊กอินสำหรับมัน และมันดูดีกว่ามาก และมันก็คือเทอร์มินัลนั่นแหละ ของเดียวกันเป๊ะ มันยังมีช่องว่างอยู่บ้าง บางครั้งคุณก็ต้องเปิดเทอร์มินัล แต่คุณสามารถวางมันไว้ข้างล่างได้ มันก็ประมาณนั้น แต่ทุกอย่างมันทำงานได้ ผมค่อนข้างแน่ใจว่ามีปลั๊กอินของ Claude Code อยู่ข้างใน Cursor ด้วยนะ ผมสงสัยว่ามันจะเวิร์กไหม มันเหมือนกันหมด ไม่ว่าจะเป็น VS Code หรืออะไรก็ตาม มันเหมือนกันทั้งหมด

และสิ่งสุดท้ายที่ผมอยากเพิ่มคือ คุณพูดถึงเรื่องคอนเท็กซ์ในโฟลเดอร์ย่อย เพราะผมเจอแบบเดียวกัน ผมมีลูกค้ารายหนึ่งที่ผมเกือบจะเรียน Claude Code for Dummies จบแล้ว ดีมาก บอกผมด้วยนะว่ามันเป็นยังไง ผมเจอคนที่หยิบมันขึ้นมาใช้แล้วมันเข้าใจง่าย และพวกเขาก็เริ่มนำไปใช้จริง แต่ก็มีคนที่ยังบอกว่า ผมยังคิดไม่ออกว่าจะทำยังไง ผมพยายามทำให้ทรัพยากรเหล่านี้ดีที่สุดเท่าที่จะทำได้ งั้นบอกผมด้วยนะว่าเป็นยังไงบ้าง ไม่มีปัญหา

เอาล่ะ ต้องไปแล้ว Arson มีคำถามว่า ทำตอนนี้เลยไหม

กลับมาที่เรื่องสกิลที่คุณอาจจะพูดถึงไปแล้ว ผมใส่ไว้ในคอมเมนต์แล้ว ผมควรคิดไหมว่าสกิลไหนที่ต้องอยู่ในโฟลเดอร์ และสกิลไหนที่ใช้ได้ทั่วไป เพื่อให้ง่ายต่อการค้นหาสำหรับผมหรือสำหรับ AI

การทำแบบ global จะเป็นวิธีที่ง่ายที่สุดในการค้นหาพวกมัน ผมแค่ทำสำเนา แต่เวลาผมสร้างสกิล ผมต้องแน่ใจว่ามันไม่สามารถถูกเรียกซ้ำซ้อนได้ ถ้าคุณสร้างสกิลในโฟลเดอร์ มันจะสร้างสำเนาของทุกสกิลจริง ๆ และผมไม่อยากให้สกิลของผมโผล่มาสองตัวเวลาผมเรียกใช้ ผมลืมไปแล้วว่ามันคืออะไร แต่ผมถาม Claude ตรง ๆ ว่า ผมอยากให้มันอยู่ในโฟลเดอร์ ผมไม่อยากให้มันทำงานเวลาผมเรียกใช้แบบ global บนคอมพิวเตอร์ แล้วผมก็หาวิธีได้แล้ว ผมแค่ทำสำเนาไฟล์สกิลทั้งหมดของผม แล้ววางไว้ในโฟลเดอร์นั้น แล้วก็ commit และ push ขึ้น GitHub ของผม
