## บทนำ
วิดีโอนี้สอนวิธีตั้งค่าการเชื่อมต่อกับ Creatomate โดยไปสร้างโปรเจกต์หรือเทมเพลตใหม่ จากนั้นคัดลอก API key มาวางใน n8n แล้วกด save เพื่อเชื่อมต่อ

## คำแปลเต็ม
คุณต้องตั้งค่าการเชื่อมต่อก่อน ถ้าคุณต้องการ API key คุณก็ไปที่ Creatomate แล้วคุณอาจต้องสร้างโปรเจกต์ใหม่หรือเทมเพลตใหม่เพื่อให้มีโปรเจกต์ แล้วจากนั้นคุณก็ไปที่เมนู แล้วกดที่ปุ่ม แล้วก็คัดลอก API นี้มา แล้วเราก็วางมันลงตรงนี้ จากนั้นกด save
