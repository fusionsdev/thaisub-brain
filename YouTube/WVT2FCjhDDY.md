## ประเด็นหลัก

- ช่อง stick man วาดมือง่ายๆ ได้วิว 7.5 ล้าน และยอดรวมหลักล้านภายใน ~2 เดือน ด้วยภาพนิ่งไม่ต้องมี 3D หรือคลิปจริง
- ใช้ prompt เดียวบน Claude AI Free Plan เพื่อได้ viral topic ห้าไอเดีย พร้อม long-form script 5–15 นาที และไฟล์ดาวน์โหลด
- จุดสำคัญของ workflow: ทำ voiceover ก่อน แล้วค่อยสร้างฉาก — ฉากเกิดจาก pause ธรรมชาติของเสียง ไม่ใช่ sync ทีหลัง
- สร้าง voiceover ฟรีด้วย 11labs (Raunak) แล้วใช้ faziscribe.ai โหมด accuracy หา pause + timestamp ทุกจุด
- นำ timestamp script กลับเข้า Claude เพื่อ generate text-to-image prompt ทีละชุด แล้วดาวน์โหลดเป็นไฟล์รวม
- สร้างภาพบน Google Flow ด้วย Nano Banana 2 (16:9) และ bulk ด้วย Zappy Flow Chrome extension ของ zappywala.ai
- ตัดต่อโดยจัดฉากตาม timestamp ในชื่อไฟล์ แล้ว preview จังหวะก่อน export
- ใช้ Claude สร้าง viral title/description/tags และ thumbnail prompts สูง CTR ห้าแบบ แล้วอัปโหลด YouTube

## ความเห็นสรุป

คลิปนี้เป็น tutorial workflow ฟรีครบวงจรสำหรับวิดีโอ stick-man doodle บน YouTube เน้นจังหวะเสียงเป็นศูนย์กลาง และใช้ extension ลดงาน generate ภาพจำนวนมาก เนื้อหาเน้นขั้นตอนปฏิบัติ ไม่ใช่การพิสูจน์ตัวเลข $77,000 ในชื่อเรื่องโดยตรง ผู้ชมได้ระบบทำซ้ำได้ตั้งแต่สคริปต์จน publish โดยไม่ต้องเสีย subscription
