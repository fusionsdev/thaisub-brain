## คำแปลเต็ม

สวัสดีครับ ผม William และในวิดีโอนี้ ผมจะโชว์วิธีตั้งค่าแคมเปญโดยใช้ AirPush มันเป็นแพลตฟอร์มที่ใช้งานง่ายมาก ผมคิดว่าคุณจะไม่มีปัญหาในการใช้มัน แต่ผมจะพาคุณดูทีละขั้นตอน เพื่อให้แน่ใจว่าทุกอย่างชัดเจน

นี่คือแพลตฟอร์ม AirPush และนี่คือบัญชีใหม่ล่าสุด เมื่อคุณสร้างบัญชีแล้ว คุณควรเห็นแดชบอร์ดแบบนี้ ยังไม่มีอะไรเลย ดังนั้นสิ่งแรกที่คุณต้องทำคือตั้งค่าแคมเปญของคุณ และหลังจากนั้นต้องเติมเงินเข้าบัญชี เพื่อให้คุณเริ่มได้รับ traffic ได้

ผมจะไปที่ new campaign และตรงนี้คือข้อมูลของแคมเปญ ผมจะใส่ test ลงไป แล้วเลือกหมวดหมู่ สมมติว่าผมอยากทำหมวดสุขภาพและความงาม แล้วก็มีวันเริ่มต้นและวันสิ้นสุด ซึ่งไม่จำเป็นต้องตั้งจริงๆ คุณสามารถรันแคมเปญต่อเนื่อง แล้วค่อยกดหยุดเมื่อคุณคิดว่ามันไม่ดี หรือเมื่อคุณคิดว่าต้องปรับเปลี่ยนบางอย่าง

ตรงนี้คืองบประมาณรายวัน (daily budget) คุณสามารถเริ่มจากจำนวนเล็กน้อย สมมติว่า 10 ดอลลาร์ หรือจะใส่เพิ่มก็ได้ ถ้าคุณพร้อมลงทุนมากขึ้นเพื่อให้ได้ข้อมูลเร็วขึ้น และเร่งกระบวนการทดสอบแคมเปญ

จากนั้นคุณเลือกได้สองทางเลือก: คุณจะโฆษณาบนแอปพลิเคชัน หรือโฆษณาบนเว็บไซต์มือถือ (mobile websites) ซึ่งไม่ใช่กฎตายตัว แต่ผมคิดว่าถ้าคุณโปรโมตแอป ควรเลือกโฆษณาบนแอปดีกว่า ถ้าคุณโปรโมตข้อเสนอที่เป็นเว็บไซต์ที่คนต้องสมัครเพื่อเข้าถึงบางอย่าง หรือต้องใช้บริการบางอย่าง เว็บไซต์มือถืออาจดีกว่า

ดังนั้นมันขึ้นอยู่กับว่าคุณโปรโมตอะไร แต่ไม่ใช่กฎตายตัว อย่างไรก็ตาม โดยทั่วไปคุณควรโฟกัสแบบนี้: ถ้าคุณโปรโมตแอป ก็โฆษณาบนแอป ถ้าคุณโปรโมตเว็บไซต์ ก็โฆษณาบนเว็บไซต์

ไปต่อกันเลย แล้วเลือก Android คุณสามารถเลือก Android หรือ iOS ได้

ตรงนี้มีรูปแบบโฆษณาหลายแบบ ถ้าคุณไม่แน่ใจว่าโฆษณาแบบนี้คืออะไร หรือเป็นโฆษณาประเภทไหน คุณก็คลิก learn more แล้วคุณจะเห็นว่าโฆษณาหน้าตาเป็นอย่างไร อย่างที่เห็น มันบอกว่า small banner มาลองแบบ landing กัน ซึ่งแสดงเต็มหน้า อย่างที่คุณเห็น หรือแบบนี้คือโฆษณา Overlay

นี่คือสามแบบที่ผมใช้บ่อยที่สุด แต่คุณลองแบบอื่นได้ เช่น rich media ซึ่งก็น่าสนใจมาก และคุณจะเห็นว่ายังมีตัวเลือกอื่นๆ อีกที่น่าสนใจ แต่ส่วนใหญ่ผมจะใช้ landing หรือ overlay

จากนั้นกด save and continue แล้วคุณต้องเลือกหนึ่งในนั้น ลองเลือก landing ดู

และนี่คือขั้นตอนที่สอง คุณสามารถเลือกตำแหน่งที่ตั้งของแคมเปญ กำหนดเป้าหมายทุกภูมิศาสตร์เป็นค่าเริ่มต้น แต่ผมไม่คิดว่าคุณจะใช้ตัวเลือกนี้ คุณควรเลือกประเทศที่นี่ สมมติว่าไปสหรัฐอเมริกา

คุณเลือกได้ ส่วนใหญ่แล้วมันไม่จำเป็นต้องใช้ เรื่องการกำหนดเวลา (schedule) ไม่ใช่สิ่งที่ผมใช้บ่อย ผมเลือกทุกวัน แล้วถ้าผมเริ่มเห็นว่าได้คอนเวอร์ชันมากขึ้นตอนกลางคืนหรือตอนกลางวัน ผมก็เริ่มปรับ แต่วิ่งแคมเปญทุกวันก่อน

ถ้าคุณอยากเลือกอะไรเจาะจงกว่านั้น คุณสามารถเลือกได้ [ฟังไม่ชัด] ขึ้นอยู่กับข้อเสนอของคุณ คุณอาจอยากปรับตัวเลือกนี้

ผมจะปล่อยเป็น target all device ไว้ เพราะมันขึ้นอยู่กับข้อเสนอจริงๆ บางข้อเสนอต้องการให้กำหนดเป้าหมายเฉพาะอุปกรณ์บางประเภท คุณต้องระวังตรงนี้

คุณยังสามารถกีดกันผู้ใช้ที่ติดตั้งแอปของคุณแล้วได้ แต่ผมคิดว่าคุณไม่ต้องยุ่งกับมันบ่อยนักเมื่อโปรโมต affiliate offers และคุณยังสามารถกำหนดเป้าหมายตาม [ฟังไม่ชัด] ได้ แต่ผมคิดว่ามันไม่จำเป็นสำหรับข้อเสนอส่วนใหญ่ บางข้อเสนออาจต้องการสิ่งนี้ คุณใช้ได้ แต่ส่วนใหญ่แล้วมันไม่จำเป็น

จากนั้นคุณก็วางราคาประมูล (bid) ได้ ผมมักเริ่มจากราคาต่ำๆ ส่วนใหญ่ผมเริ่มที่ 25 เซนต์ ผมคิดว่ามันเป็นไอเดียที่ดีมาก แล้วค่อยเพิ่มหรือลดราคาตามสถานการณ์ ดังนั้นมันเป็นแค่ราคาประมูลเริ่มต้น คุณต้องปล่อยให้แคมเปญวิ่งเพื่อดูว่าราคาแบบไหนที่ควรวาง

และนี่คือขั้นตอนที่สาม คุณสามารถสร้างครีเอทีฟของคุณได้ ลองใส่ test ad ตรงนี้ แล้วคุณก็ใส่ URL ของ landing page ได้ ลองใส่ดู นี่คือเว็บไซต์ ดังนั้นคุณใส่ URL ของ landing page ซึ่งควรเป็น landing page ของคุณ หรือถ้าคุณลิงก์ตรงๆ ก็ได้ แล้วคลิก create

และเสร็จแล้ว คุณได้สร้างแคมเปญของคุณแล้ว ถ้าคุณอยากใช้หลาย landing pages คุณก็เพิ่ม URL ใหม่ได้แบบนี้ และถ้าผมมีโฆษณาอื่นๆ ผมก็ตั้งค่าโฆษณาทั้งหมดตรงนี้ มันง่ายมากที่จะตั้งค่าโฆษณา และดูว่าโฆษณาหน้าตาเป็นอย่างไรบนหน้าจริง

ขอบคุณมากครับที่ดูวิดีโอนี้ แล้วเจอกันในวิดีโอหน้าครับ
