## บทนำ
วิดีโอนี้เป็นขั้นตอนแรกของการตั้งค่า automation แปลงวิดีโอ YouTube เป็นโพสต์โซเชียลมีเดีย คุณเพียงวางลิงก์วิดีโอ ระบบจะดึง transcript ภาพขนาดย่อ และข้อมูลของวิดีโอโดยอัตโนมัติ จากนั้นแปลงเป็นโพสต์สามรูปแบบตามเทมเพลต วิดีโอนี้เน้นการตั้งค่า Google Sheet ซึ่งเป็นส่วนแรกของระบบ

## คำแปลเต็ม
ในวิดีโอนี้ ผมจะแชร์ขั้นตอนการตั้งค่าอันแรกของ automation แปลง YouTube เป็นโซเชียลมีเดีย ระบบนี้ทำให้คุณเปลี่ยนวิดีโอ YouTube ใดก็ได้ เพียงวางลิงก์ลงไป แล้วมันจะดึง transcript ให้อัตโนมัติ รวมถึงภาพขนาดย่อ และให้ข้อมูลบางอย่างเกี่ยวกับวิดีโอนั้น จากนั้นคุณคลิกตรงนี้ แล้วมันจะเปลี่ยนวิดีโอเหล่านั้นเป็นโพสต์สามรูปแบบที่แตกต่างกันตามเทมเพลต TOM เหล่านี้

มันจะวิเคราะห์ประเด็นสำคัญของวิดีโอ แล้วเปลี่ยนเป็นประเด็นหลักและบทสรุปของวิดีโอ ดังนั้นคุณจะได้สามโพสต์จากวิดีโอโซเชียลมีเดียหนึ่งวิดีโอ และคุณยังขยายได้อีก เพื่อเปลี่ยน YouTube หนึ่งวิดีโอเป็นโพสต์สี่ ห้า หก เจ็ด หรือมากกว่านั้น และผมมีบทช่วยสอนเฉพาะที่คุณสามารถดูได้ ซึ่งแสดงวิธีขยายระบบนี้

แต่ก่อนอื่น มาตั้งค่าระบบที่เปลี่ยนวิดีโอ YouTube หนึ่งวิดีโอเป็นสามโพสต์นี้ก่อน นี่คือ automation ที่เราต้องการ เพื่อเชื่อมต่อกับ Google นี้ และส่วนที่สองของ automation เรียกว่า publisher ส่วนนี้สร้างโพสต์ และส่วนนี้เผยแพร่โพสต์ และผมจะแสดงการตั้งค่าทีละส่วนในอีกสามวิดีโอถัดไป

อันดับแรก เราจะตั้งค่า Google Sheet จากนั้นตั้งค่า generator แล้วตั้งค่า publisher และด้านล่างแต่ละส่วน คุณจะพบเทเทมเพลตที่ต้องใช้ เริ่มจาก Google Sheet กันก่อน สิ่งแรกที่คุณทำคือคลิก make a copy ด้านล่างคุณจะพบเทมเพลตของ Google Sheet นี้ แล้วการตั้งค่าง่ายมาก คุณแค่ต้องรอสักครู่จนกว่าเมนู custom นี้จะโหลดเสร็จ จากนั้นคลิก install อาจใช้เวลาไม่กี่วินาที คุณเห็นว่ามันเรียกว่า custom actions

ขั้นแรกคุณคลิก จากนั้นต้องคลิกเพื่อทำขั้นตอนการอนุญาต (authorization) คุณต้องเลือกบัญชี Google ของคุณ และให้สิทธิ์กับ automation นี้ว่ามันสามารถดำเนินการบางอย่างในบัญชีของคุณได้ ผมจะไม่แสดงขั้นตอนนี้ให้ดู เพราะมันมีความละเอียดอ่อน ผมจะตัดวิดีโอต่อหลังจากทำขั้นตอนนี้เสร็จ แต่คุณแค่คลิก OK แล้วยืนยันและทำตามขั้นตอนทั้งหมดให้ครบ

เมื่อเสร็จแล้ว ขั้นต่อไปเราต้องคลิก install triggers แล้วฟังก์ชันแรกของ Google Sheet ก็ตั้งค่าเสร็จ ตอนนี้เราต้องเข้าไปใน AppScript เราต้องเพิ่ม API key ไปที่ AppScript แล้วเราต้องแทนที่ API key สองตัว คือ Rapid API key จากบริการ YouTube Summarizer API

การจะได้ API นี้ ผมจะไม่แสดงให้ดู เพราะผมมีบทช่วยสอนที่แสดงวิธีได้มาอย่างชัดเจนอยู่แล้ว คุณไปที่ get API key for YouTube transcript API ดูวิดีโอนั้น แค่ 30 วินาทีก็ได้ API key แล้ววางลงไปแทนที่ วาง API key ตรงนี้ เมื่อเสร็จแล้วคลิก จากนั้นยังมี API key อีกตัวที่ต้องได้ ซึ่งคือ YouTube API key และผมมีบทช่วยสอนให้เช่นกัน คุณไปที่ get YouTube API from Google Cloud Console หาได้ในบทช่วยสอนทางเทคนิคอื่นๆ ดูวิดีโอนั้น ผมจะแสดงให้เห็นชัดเจนว่าเอา API key จาก YouTube ได้ที่ไหน แล้ววางลงไป

จากนั้นต้องทำอีกครั้ง สำหรับจำนวนผู้ติดตามช่อง เราก็ใส่ YouTube API key ตัวเดียวกันที่เพิ่งเพิ่มไป คลิก และเท่านี้สำหรับตอนนี้ ที่เหลือจะตั้งค่าในวิดีโออื่นๆ ยังมีอีกสองสามอย่างที่ต้องทำ แต่จะสมเหตุสมผลก็ต่อเมื่อคุณตั้งค่าเสร็จแล้ว จากนั้นเราจะเชื่อมต่อกับ Google Sheets

ตอนนี้เราทดสอบได้เลย ผมจะไปที่ YouTube เลือกวิดีโอนี้ คัดลอกลิงก์ของวิดีโอนี้ แล้วทดสอบว่าระบบของผมตั้งค่าถูกต้องหรือไม่ เมื่อวางลิงก์ลงไป มันควรดึง title ควรดึงภาพขนาดย่อ ควรดึง transcript และคุณจะเห็นว่ามันทำงานได้แล้ว ผมคลิก allow access มันจะดึง title จาก URL ของ YouTube และขั้นตอนต่อไปคือตั้งค่าส่วนอื่น เพื่อแปลง transcript ของ YouTube เป็นสามโพสต์ของเรา ซึ่งเราจะตั้งค่าในวิดีโอถัดไป
