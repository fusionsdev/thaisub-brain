## ประเด็นหลัก
- Jono แจก local SEO agent ฟรีทั้งชุด สร้างด้วย Claude Code พร้อม blueprints บน GitHub ที่โคลนผ่าน VS Code ได้ทันที เป็นการย่อ local SEO masterclass ยอดวิว 110,000 ของเขาให้เป็นระบบ plug and play
- local SEO เริ่มเห็นผลใน 1-3 เดือน (เทียบ SEO ทั่วไปที่ใช้เกือบปี) ฟรี และแข่งกับธุรกิจท้องถิ่นใกล้ตัวแทนมาร์กเตอร์ระดับโลกอย่าง Homestars หรือ Yellow Pages
- เริ่มด้วยการสร้าง Google Business Profile แล้วใช้คำสั่ง /GBP ใน Claude Code (ต่อ Semrush ผ่าน connectors) ให้สร้าง dashboard ข้อมูล optimize ครบ ชี้ความไม่สอดคล้อง เช่น เบอร์โทรต่างเมือง
- หมวดหมู่ (categories) สูงสุด 10 อัน โดย Claude เลือก primary category ให้จากการวิเคราะห์คู่แข่งสามอันดับแรก ส่วน service areas ใส่ได้ 20 พื้นที่ (ไม่เกินระยะขับ 2 ชั่วโมง) และ services ได้ 50 รายการ โดยเรียงตาม search volume จาก Semrush
- ระบบรีวิวอัตโนมัติ: ส่งฟอร์มถามความเต็มใจแนะนำ 1-5 คะแนน คะแนน 4-5 พาไปทิ้งรีวิว Google อัตโนมัติ คะแนนต่ำถูกกรองไป Slack พร้อม feedback เพื่อตามแก้ปัญหา ใช้ make.com + web hook เชื่อมทุกอย่าง
- ตอบกลับรีวิวอัตโนมัติผ่าน make.com (ข้ามขั้นตอนยืนยัน 14 วันของการเชื่อมตรง) คะแนน 4-5 ดาวตอบอัตโนมัติ 1-3 ดาวแจ้งเตือน Slack ให้ตามจัดการเอง
- โพสต์ GBP เป็นอัตโนมัติ: สั่งครั้งเดียวได้ draft 8 โพสต์ทั้งเดือน (แนะนำ 2-3 โพสต์/สัปดาห์) — โพสต์ไม่ได้เพิ่มการมองเห็น แต่เพิ่มอัตรากลายเป็น lead
- หา keyword ด้วย /keyword-research: กรองด้วย search volume ความยากของการแข่งขัน และ intent แล้วจับกลุ่ม (cluster) เพื่อให้หนึ่งหน้าติดหลาย keyword
- service page = keyword เจตนาจ้างบริการ (เช่น wedding photographer Toronto) สร้างเป็น matrix บริการ x เมือง/ย่าน (Riverdale, the Beaches, Cabbage Town, Leslieville) ส่วน blog post = keyword คำถาม ควรเลือกหัวข้อท้องถิ่นเพื่อจับคนในเมืองจริง
- เผยแพร่เว็บด้วย /publish ขึ้น GitHub + Vercel (ฟรีทั้งคู่) แล้ว syndicate blog post เป็นโพสต์ social media อัตโนมัติผ่าน Blotato ($29/เดือน)
- citations (โปรไฟล์ธุรกิจบน Yelp, Foursquare ฯลฯ) เพิ่ม trust ให้ Google แบ่งเป็น tier 1-4 ทำ manual หรือใช้ Semrush จัดการข้าม 150 directories

## ความเห็นส่รุป
วิดีโอนี้เหมาะกับเจ้าของธุรกิจท้องถิ่นและเอเจนซีที่อยากทำ local SEO แบบเป็นระบบโดยไม่ต้องมีสกิลเทคนิค เพราะ Claude Code ทำหนักให้เกือบหมด เหลือ manual แค่ copy-paste ลง Google Business Profile จุดที่ต้องลงทุนจริงคือ Semrush (ทดลองฟรี 14 วัน), Blotato และเวลาทำ citations ซึ่งผู้สอนย้ำว่าอย่าข้าม ข้อควรระวังคือหลายขั้นตอนผูกกับบริการของผู้สอนเอง (blueprints ผ่านคอมมูนิตี้, CRM ราคาพิเศษ) ควรประเมินความจำเป็นก่อนสมัคร
