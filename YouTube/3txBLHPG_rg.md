## ประเด็นหลัก

- LM Studio ปล่อยแอปใหม่ฟรีชื่อ **Bionic** ที่เข้ามาแทนที่เครื่องมืออย่าง Claude Code และ Claude Co-work สำหรับการใช้งานโมเดล AI ในเครื่อง (local AI)
- Bionic มีสองโหมดหลัก: **work mode** (ทำงานเอกสาร สร้าง/แก้ไขไฟล์ในเครื่อง) และ **code mode** (เขียนโค้ด สร้างแอป ควบคุมคอมพิวเตอร์) พร้อมแผง preview browser ในตัว
- รองรับการเชื่อมต่อ **MCP** ทั้งแบบสำเร็จรูปและแบบกำหนดเอง (เช่น ClickUp) ทำให้โมเดล AI ในเครื่องทำงานร่วมกับเครื่องมือภายนอกได้
- มีฟีเจอร์ **built-in web search** และ **การถอดเสียงพูดแบบเรียลไทม์** ที่ทำงานบนเครื่อง (ดาวน์โหลดโมเดล 2-3 GB)
- ใช้งานได้ทั้งโมเดลท้องถิ่น (GGML/MLX) และโมเดลโอเพนที่โฮสต์บนเซิร์ฟเวอร์ LM Studio ในสหรัฐฯ (GLM 5.2, Kimiko 3, Deep Seek V4) แบบ zero data retention แต่ต้องตั้งค่าการเรียกเก็บเงิน
- เดโมจริง: ให้ Bionic ค้นหาข่าว AI ล่าสุดบนเว็บ → สร้างเอกสารรายงาน → ส่งอัปเดตเข้า ClickUp ผ่าน MCP ได้ครบวงจร
- เดโมโค้ด: ดึงข้อมูลจาก ClickUp มาสร้างหน้า HTML รัน local server และดูตัวอย่างในแอปได้ แม้ใช้โมเดลเล็กอย่าง Gemma 426B
- ฟีเจอร์เด่น: **LM link** แชร์โมเดลข้ามเครื่องได้ และเลือกเครื่องที่จะดาวน์โหลดโมเดลได้ในแท็บ explore
- ทริก: ส่ง username ฟรีของ LM Studio ไปที่อีเมลที่ผู้ก่อตั้งแจ้งบน Hacker News เพื่อรับเครดิต ~5 ดอลลาร์
- คำแนะนำ: อัปเดต Bionic และ LM Studio ให้เป็นเวอร์ชันล่าสุดเสมอ เพราะปัญหาต่างๆ ยังถูกแก้ไขเรื่อยๆ (ปล่อยมา 14 วัน)

## ความเห็นสรุป

Bionic ถือเป็นตัวเลือกที่น่าสนใจมากสำหรับคนที่อยากใช้โมเดล AI ในเครื่องของตัวเองทำงานจริงจัง ทั้งเอกสารและโค้ด แม้เพิ่งปล่อยมาไม่นานและยังมีจุดบกพร่องบ้าง แต่ด้วยความสามารถที่ครบวงจรขนาดนี้โดยใช้โมเดลเล็กๆ ก็คุ้มค่าที่จะติดตามอย่างใกล้ชิด โดยเฉพาะเมื่อผนวกกับ LM Studio เดิมที่แข็งแกร่งอยู่แล้ว
