## บทนำ
วิดีโอนี้เป็นส่วนสุดท้ายของการตั้งค่าระบบอัตโนมัติ คือการเผยแพร่วิดีโอขึ้น TikTok โดยอัตโนมัติ โดยใช้เครื่องมือสองตัวคือ Zapier ซึ่งเป็นเครื่องมือเวิร์กโฟลว์อัตโนมัติ และ Buffer ซึ่งเป็นแพลตฟอร์มจัดตารางเผยแพร่โซเชียลมีเดีย เริ่มจากทริกเกอร์จาก Google Sheets แล้วส่งวิดีโอไปยัง Buffer แล้วต่อออกไปยัง TikTok

## คำแปลเต็ม

ตอนนี้เป็นส่วนสุดท้ายของการตั้งค่า คือการเผยแพร่ขึ้น TikTok โดยอัตโนมัติเช่นกัน ดังนั้นถ้าคุณไม่ได้วางแผนจะทำส่วนนี้ คุณข้ามไปได้เลย แต่ถ้าคุณต้องการทำ คุณต้องดูวิดีโอนี้ให้ครบ และคุณต้องใช้เครื่องมือสองตัวที่เราใช้ นั่นคือ Zapier และ Buffer

Zapier เป็นเพียงเครื่องมือเวิร์กโฟลว์อัตโนมัติอีกตัวหนึ่ง ที่ช่วยให้เราสามารถเผยแพร่โดยตรงได้ ซึ่งเป็นเรื่องที่ทำได้ยากด้วย n8n หรือแม้แต่เครื่องมืออื่น ๆ แต่นี่เป็นวิธีแก้ที่ง่ายกว่า

ขั้นแรกคุณสมัครบัญชีฟรีของ Zapier คลิก create a new Zap และในระหว่างนั้นคุณก็สมัครบัญชีฟรีของ Buffer ได้ด้วย ซึ่ง Buffer เป็นแพลตฟอร์มจัดตารางเวลาโซเชียลมีเดีย โดยพื้นฐานแล้วเราส่งข้อมูลจาก Zapier ไปยัง Buffer แล้วไปยัง TikTok

ตรงนี้ทริกเกอร์ต้องเป็น Google Sheets และเราต้องเลือกบัญชีที่เราอัปเดตก่อน คุณต้องคลิก connect account เลือกบัญชีเดียวกับที่มี Google Sheet อยู่ จากนั้นคลิกเลือกสเปรดชีต (choose spreadsheet) เราจะใช้ชีตนี้ ซึ่งก็คือชื่อของชีต ส่วน worksheet ที่สร้างขึ้นก็คือส่วนนี้ คอลัมน์ทริกเกอร์อยู่ตรงนี้ เรามี TikTok และนี่คือสิ่งที่โมดูลนี้ทำ ซึ่งเป็นหน้าที่เดียวของมัน

อย่างแรกเราต้องเลือกชีตที่ถูกต้องตรงนี้ ซึ่งก็คือ Generated Posts ใช่ ถูกต้องแล้ว และสิ่งเดียวที่มันเขียนลงในคอลัมน์ A นั่นหมายความว่าวิดีโอนี้ควรถูกเผยแพร่ขึ้น TikTok และนี่คือสิ่งที่ทริกเกอร์กระบวนการเผยแพร่นี้ แล้วคลิก test จากนั้น continue with selected record ซึ่งนั่นคือเรคคอร์ดของวิดีโอที่เราสร้างไว้แล้ว

ขั้นตอนถัดไปคือ จะให้เกิดอะไรขึ้น? มันควรจะเผยแพร่ไปยัง Buffer ไปที่คิว เราต้องเชื่อมต่อบัญชี เมื่อคุณสมัคร Buffer แล้ว มันจะถูกเชื่อมให้อัตโนมัติเมื่อคุณคลิกปุ่มนั้น จากนั้นคลิก continue organization และ channel ตรงนี้เราต้องเชื่อมต่อช่องทาง ซึ่งก็คือแพลตฟอร์มโซเชียลมีเดีย คุณไปที่ Showboard connect แล้วก็แค่คลิก finish connection จากนั้นมันก็เชื่อมต่อแล้ว กลับมาคลิก refresh แล้วเลือกอันนี้กับข้อความ นี่ก็คือแค่คำบรรยาย (caption) และวิดีโอนี้ก็คือ URL ของวิดีโอที่เรามีอยู่ตรงนี้

ตอนนี้ type เป็นแบบ direct และ method เป็น add to queue ตอนนี้ Share next หรือ share now ไม่ค่อยสำคัญเท่าไหร่ ผมเลยได้ลูกศร นั่นคือเหตุผลที่ผมเลือก schedule now แต่มันก็ยังจะถูกเผยแพร่อยู่ดี จากนั้นผมคลิก test แล้วก็เห็นว่าวิดีโอจะถูกส่งไปยัง Buffer

ถ้าผมไปที่ Buffer ผมก็เห็นวิดีโอนี้แล้ว ถ้าผมรีเฟรช คุณจะเห็นว่ามันปรากฏอยู่ตรงนี้ และมันจะถูกเผยแพร่ในเวลานี้ ผมเปลี่ยนได้ถ้าต้องการ โดยไปที่ posting schedule แล้วปรับเปลี่ยนได้ว่าวิดีโอของผมควรถูกเผยแพร่เมื่อไหร่ หรือผมจะคลิก publish now ก็ได้ ดังนั้นเราต้องรอสักครู่ วิดีโอยังอยู่ระหว่างการประมวลผล แต่เดี๋ยวมันก็จะถูกเผยแพร่ ตอนนี้กระบวนการถูกตั้งค่าแล้ว และผมสามารถคลิก publish ได้

ทีนี้กลับมาตรงนี้ สิ่งสุดท้ายคือการเปลี่ยนชื่อเป็น TikTok เท่านั้นเอง และนั่นคือทั้งหมดที่เราต้องทำ ระบบนี้เชื่อมต่อแล้ว และมันจะถูกเผยแพร่โดยอัตโนมัติทุกครั้งที่เราสร้างวิดีโอใหม่

สิ่งเดียวที่ต้องจำไว้คือ สำหรับ Buffer ในแผนฟรี คุณสามารถเผยแพร่ล่วงหน้าได้สูงสุดสิบวิดีโอ คือจัดตารางได้สูงสุด 10 วิดีโอ แล้วคุณต้องอัปเกรด หรือคุณสามารถอัปเกรดเพื่อเผยแพร่แบบไม่จำกัดในราคาประมาณ 6 ดอลลาร์ต่อเดือน คุณสามารถดูรายละเอียดค่าใช้จ่ายทั้งหมดได้ใต้วิดีโอนี้ และนี่คือการตั้งค่าระบบอัตโนมัติทั้งหมดที่เสร็จสมบูรณ์
