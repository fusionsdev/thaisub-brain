## บทนำ

วิลเลียม โซซา (William Souza) สอนการตั้งค่าแคมเปญโฆษณาบน Facebook ตั้งแต่ต้นจนจบสำหรับสาย CPA ไม่ว่าจะเป็นการเลือกวัตถุประสงค์ (แนะนำ Traffic สำหรับมือใหม่) การตั้งงบประมาณ การเลือกกลุ่มเป้าหมายแบบละเอียด (Detailed Targeting) การเลือก placement การตั้งค่าโฆษณารูปภาพพร้อมพาดหัว ไปจนถึงการกดเปิดแคมเปญและรอการอนุมัติ

## คำแปลเต็ม

วิลเลียมครับ และในวิดีโอนี้ผมจะแสดงวิธีตั้งค่าแคมเปญบน Facebook คุณจะเห็นทุกขั้นตอนที่ต้องผ่าน เพื่อตั้งค่าและสร้างแคมเปญของคุณ แล้วเริ่มส่ง traffic ไปยัง landing page และ offer ของคุณ

สิ่งแรกที่ต้องทำคือเข้าไปที่ Ads Manager คุณเข้าถึงบัญชีธุรกิจของคุณก่อน แล้วค่อยเข้า Ads Manager ถ้าอยากเข้า Ads Manager ตรง ๆ ก็เปิด business.facebook.com/adsmanager แล้วคุณจะมาถึง Ads Manager ที่นี่คุณมีตัวเลือกในการสร้างโฆษณา คลิกปุ่ม Create เพื่อเริ่มกระบวนการ จากนั้นคุณจะมาที่หน้านี้ สิ่งแรกที่ต้องทำคือเลือกวัตถุประสงค์ (Objective) ของแคมเปญ คุณต้องบอก Facebook ว่าคุณอยากทำอะไรกับแคมเปญนี้

มีวัตถุประสงค์หลายแบบที่ใช้ตั้งค่าแคมเปญเพื่อโปรโมท offer แบบ CPA ได้ สามแบบหลักคือ Traffic, Engagement และ Conversions ตัวหลักและพบบ่อยที่สุด คือง่ายที่สุดในการใช้และเข้าใจ ผมแนะนำให้เริ่มด้วย Traffic ซึ่งสุดท้ายคุณจะได้เรียนรู้เรื่อง Conversions เพิ่มเติม และในอนาคตอาจลองใช้และทดสอบมัน เพราะคุณเพิ่งทำครั้งแรก ผมถือว่าคุณเพิ่งทำครั้งแรก ผมแนะนำให้เลือกเส้นทางที่ง่ายที่สุดคือวัตถุประสงค์ Traffic คลิก Traffic แล้วเลื่อนลงมา Facebook จะให้คุณตั้งชื่อแคมเปญ ใส่อะไรก็ได้ เป็นเพียงการอ้างอิงของคุณเอง ผมจะใส่ "Example Campaign"

จากนั้น Facebook ให้ตัวเลือกสร้าง A/B Test (split test) ซึ่งคุณไม่จำเป็นต้องใช้ตอนนี้ ปล่อยปิดไว้ แล้วก็มีตัวเลือกให้ปรับงบประมาณอัตโนมัติข้าม Ad Sets (Advantage Campaign Budget) เปิดไว้ได้ เพราะคุณคงไม่ได้ทดสอบหลาย ad sets มันเลยไม่สร้างความแตกต่างมากนัก

คุณสามารถตั้งงบประมาณได้ตรงนี้ ผมแนะนำให้ใช้ Daily Budget (งบรายวัน) คุณเลือกแบบอื่นได้ เช่น Lifetime Budget แต่ถ้าใช้ lifetime เช่น ตั้ง 300 ดอลลาร์ แปลว่าแคมเปญจะจบเมื่อถึงยอดนั้น คุณไม่อยากได้แบบนั้น สิ่งที่คุณต้องการคือให้แคมเปญรันต่อไปเรื่อย ๆ คุณ pause แคมเปญได้ถ้าเห็นว่าไม่มีศักยภาพ หรือรันต่อและขยายสเกลได้ถ้ามันดี — Daily Budget ดีที่สุด แน่นอนว่าปรับงบนี้ทีหลังได้ ผมจะคงค่าไว้ตรงนี้ แต่คุณเริ่มน้อยกว่านั้นได้ เช่น 20 ดอลลาร์ต่อวัน ขึ้นอยู่กับประเภทแคมเปญที่รัน

จากนั้นคลิก Continue และคุณสามารถตั้งชื่อ Ad Set ได้ บน Facebook มีลำดับชั้น (hierarchy) ที่ใช้จัดการสิ่งต่าง ๆ คุณสร้างแคมเปญ และแคมเปญก็ง่ายมาก ตรงระดับบนสุดคุณแค่บอกว่าอยากทำอะไร โดยการเลือกวัตถุประสงค์ จากนั้นคุณสร้าง Ad Set ภายในแคมเปญเดียวกันมีได้หลาย Ad Sets เช่น ภายในแคมเปญเดียวมีสี่ ad sets ได้ และที่ระดับ Ad Set นี่เองที่คุณให้ข้อมูล targeting ของโฆษณากับ Facebook คุณกำหนดกลุ่มเป้าหมายที่ระดับ ad set

เป็นไปได้ที่จะสร้างแคมเปญเดียวแบบ Traffic และภายในแคมเปญนั้นมีสอง ad sets ที่ต่างกัน โดยแต่ละอันเจาะกลุ่มคนต่างกัน ทำได้จริง แต่ตอนนี้คุณยังไม่ต้องทำอะไรแบบนั้น เพราะอยากให้ทุกอย่างง่ายที่สุด คุณจะมีแค่หนึ่งโฆษณา หนึ่งกลุ่มเป้าหมาย หนึ่งมุม (angle) เจาะจงมาก ไม่ต้องใช้ tracking tool อะไร ไม่อยากใช้หลายอย่างจนกระบวนการรก

แต่ขอให้รู้ไว้ว่ามันเป็นไปได้ ถ้าคุณมี tracker ตั้งไว้ คุณทดสอบหลายมุมพร้อมกันได้ มีหลาย ad sets เจาะคนต่างกัน โปรโมทต่างกัน ใช้วิธีต่างกัน แล้วใช้ tracking tool ช่วยดูว่า ad set ไหนสร้าง Conversion มากกว่า แต่คุณไม่จำเป็นต้องทำแบบนั้น สำหรับตอนนี้เริ่มด้วยหนึ่งโฆษณา หนึ่งกลุ่มเป้าหมาย ทดสอบดู ถ้าได้ผลก็ใช้ต่อไป ถ้าไม่ได้ผลก็ pause อันนั้นแล้วลองอันอื่น

ภายใน Ad Set ยังมีโฆษณาได้หลายตัว เดี๋ยวผมจะแสดงให้ดู แต่คุณดูตรงคอลัมน์ซ้ายนี้ Facebook แสดงสามระดับ: Campaign หนึ่งแคมเปญมีหลาย Ad Sets ได้ และที่ระดับแคมเปญคุณให้... ที่ระดับ Ad Set คุณให้ targeting ทั้งหมดของแคมเปญ แล้วแต่ละ Ad Set มีโฆษณาได้หลายตัว ซึ่งโฆษณาคือรูปภาพและข้อความที่คนเห็น และมีลิงก์ให้คลิกไปยัง landing page

เรามาดูขั้นตอนการตั้งค่าตรงนี้กัน ผมจะคงชื่อ Ad Set เริ่มต้นไว้ ไม่สำคัญหรอก เป็นแค่การอ้างอิงของคุณเอง ใส่อะไรก็ได้ จากนั้นเลือก Website เพราะ landing page ของคุณเป็นเว็บไซต์ ตัวเลือกขั้นสูงพวกนี้ปล่อยปิดได้ เช่น Dynamic Creative ปล่อยปิดไว้

จากนั้นไปที่กลุ่มเป้าหมาย (Audience) เปลี่ยนตำแหน่งที่ตั้งตรงนี้ ใส่ประเทศที่อยากเจาะ เช่น ผมอยากเจาะสหรัฐอเมริกา ผมจะใส่ United States แล้วเลือกประเทศ United States ตรงนี้ — คนที่อาศัยอยู่ในหรือเพิ่งอยู่ในสหรัฐฯ มีตัวเลือก Custom Audience ตรงนี้ที่ปล่อยว่างไว้ได้ แต่ในวิดีโอหน้า ผมจะแสดงวิธีใช้มันด้วย แต่ตอนนี้ไม่ต้องกังวล แค่ใส่ประเทศแล้วไปต่อ

จากนั้นช่วงอายุ (Age Range) ใส่ช่วงอายุที่อยากเจาะ แคมเปญส่วนใหญ่ไม่เหมาะกับทั้งคนอายุน้อยและผู้สูงอายุพร้อมกัน เลยต้องใส่ช่วงอายุที่เหมาะสมกับคุณ สำหรับอันนี้ผมจะใส่ประมาณ 20 ถึง 45 (เป็นแค่ตัวอย่าง) แล้วก็เลือกเพศ แคมเปญบางอันให้เลือกทั้งสองเพศ บางอันอยากแก้ตรงนี้ สำหรับอันนี้ผมจะเลือกทั้งหมด (All) ถ้าอยากโปรโมทสินค้าบางอย่าง ทดสอบผู้ชายและผู้หญิงแยกกันได้ เจาะแค่ผู้ชายดูก่อน ถ้าไม่ได้ผลก็ลองแค่ผู้หญิง เพราะพวกเขามีความชอบต่างกันในเรื่องนั้น แต่สำหรับอันนี้ผมจะเลือกทั้งหมด

จากนั้น Detailed Targeting ควรเปิดไว้ โดยค่าเริ่มต้นมันอาจปิดอยู่ คลิก Edit แล้วคุณจะได้ฟิลด์สำหรับใส่ความสนใจ (Interests) ซึ่งโดยพื้นฐานคือความสนใจและพฤติกรรม (behaviors) — ข้อมูลเฉพาะเจาะจงที่คุณให้เกี่ยวกับกลุ่มเป้าหมายได้ ตรงนี้คุณบอก Facebook ว่าอยากเจาะใครกันแน่ คุณบอกแล้วว่าอยากเจาะคนในสหรัฐฯ อายุ 20-45 ทั้งชายหญิง แต่ตรงนี้คุณระบุ demographics และความสนใจเฉพาะ ที่จะช่วยให้ Facebook หาคนที่เป็นลูกค้าที่มีศักยภาพจริง ๆ ซึ่งอาจสนใจสิ่งที่คุณโปรโมท

สำหรับอันนี้ผมจะใส่ Streaming Services — Netflix ตัวอย่างที่ผมจะใช้คือแคมเปญโปรโมทบริการสตรีมมิ่ง ผมจะเจาะ Netflix แต่ผมอยากให้มันเฉพาะเจาะจงมาก อย่างที่เห็น Facebook แสดง potential reach ของแคมเปญ คุณอยากเข้าถึงคนจำนวนพอสมควร แต่ตอนนี้ผมได้ 54 ล้านคน ซึ่งเยอะมาก และคุณลดให้ต่ำกว่าหนึ่งล้านได้ในหลายกรณี หรือแม้แต่ล้านกว่า ๆ ก็ยังโอเค แต่ 54 ล้านน่าจะมากเกินไป

ไม่ได้มีกฎตายตัวเรื่องขีดจำกัดของ potential reach ผมว่าขั้นต่ำน่าจะประมาณหนึ่งล้านคน อะไรที่ต่ำกว่านั้นอาจทำให้แคมเปญไม่คุ้มค่า ไม่มีกฎแบบนั้น แต่แคมเปญของผมยังไม่เจาะจงพอ ผมใส่แค่ตัวเลือกเดียว ต้องเพิ่มอะไรอีกเพื่อให้แคมเปญเจาะจงขึ้น ผมจะเลือกตัวเลือก Narrow Audience

ขออธิบายว่ามันทำงานยังไง ผมเพิ่ม interest อื่นได้ เช่น ผมใส่ interest เกี่ยวกับหนังแอ็กชัน แล้วเจาะคนที่ชอบหนังแอ็กชัน แต่เมื่อผมใส่ทั้งสองตัวเลือกในฟิลด์เดียวกัน สิ่งที่ผมบอก Facebook คือผมอยากเจาะคนที่ชอบ Netflix **หรือ** หนังแอ็กชัน โฆษณาผมอาจแพงขึ้น เพราะไปแสดงกับคนที่ชอบหนังแอ็กชันแต่ไม่ชอบ Netflix เยอะ และนี่ทำให้แคมเปญกว้างขึ้น อย่างที่เห็น potential reach เพิ่มจาก 54 เป็น 79 ล้านคน

ดังนั้นแทนที่จะทำแบบนั้น ผมจะใช้ตัวเลือก Narrow Further ตรงนี้ผมจะใส่ interest เกี่ยวกับหนัง — Action Movies แล้วเมื่อผมมีสองฟิลด์แยกกัน ผมกำลังบอก Facebook ว่าผมอยากเจาะคนที่ชอบ Netflix **และ** หนังแอ็กชัน คนที่จะเห็นโฆษณาผมต้องชอบทั้งสองอย่าง ซึ่งแน่นอนว่าทำให้ targeting แคบลง และอย่างที่เห็น จากเดิม 54 ล้าน ตอนนี้เหลือ 39 ล้าน

ผมเพิ่ม interest อีกเพื่อให้แคบลงอีก ผมจะเพิ่ม interest เกี่ยวกับหนังอีก เพราะอยากแน่ใจว่าเจาะคนที่ชอบหนังและดูหนังจริง ๆ ขอดูว่าใช้ interest อะไรได้อีก — อันนั้นใช้ไปแล้ว ลองดูที่เกี่ยวกับ Hollywood — คนที่ชอบ... ตอนนี้เหลือ 18 ล้านคน และผมทำให้แคบลงอีกหน่อยได้ เพราะ 18 ล้านยังมีพื้นที่ให้เจาะจงขึ้นอีก แต่ผมว่าแค่นี้พอแล้วสำหรับตัวอย่างนี้

สรุปผมเจาะคนที่ชอบ Netflix และหนังแอ็กชัน และ Hollywood — ไม่ใช่คนที่ชอบ Netflix หรือหนังแอ็กชันหรือ Hollywood อย่างที่เกิดขึ้นถ้าใส่ทุก interest ในฟิลด์เดียวกัน นั่นคือเหตุผลว่าทำไมตัวเลือก Narrow Further ถึงมีอยู่ ยังมีตัวเลือก Exclude People ซึ่งให้ผมแยกคนที่ชอบสิ่งใดสิ่งหนึ่งออก ผมจะไม่ใช้ฟีเจอร์นี้ตรงนี้ แต่ใช้ได้เหมือนกัน

เมื่อจัดการกลุ่มเป้าหมายเสร็จ เลื่อนลงไปที่ส่วน Placements Placements คือตำแหน่งที่โฆษณาจะแสดง และ potential reach จะลดลงตามจำนวน placements ที่น้อยลง เพราะถ้าปล่อยไว้ Facebook จะวางโฆษณาคุณทุกที่ คุณใช้ placement อัตโนมัติได้ แต่ตอนนี้ยังไม่ควรทำ สิ่งที่ผมแนะนำคือใช้ Manual Placements

สิ่งแรกที่ต้องทำคือเลือกอุปกรณ์ (Devices) ผมแนะนำว่าอย่ารันแคมเปญทั้ง desktop และ mobile พร้อมกัน ตัวอย่างที่ผมจะใช้ตรงนี้คือ offer ที่รองรับ traffic ทั้งสองแบบ แต่ปกติแล้ว offer และแคมเปญโดยทั่วไปมีประสิทธิภาพต่างกันมากระหว่าง desktop กับ mobile คุณอาจได้ Conversion จากมือถือ แต่แคมเปญดูเหมือนไม่ค่อยได้ผล หรือมันทำงานดีบนมือถือ และ traffic จาก desktop แค่เปลืองงบ คุณจะไม่เห็นความแตกต่างเพราะคุณเจาะทั้งสองและได้ traffic ทั้งสองพร้อมกัน

สิ่งที่ผมแนะนำคือแก้ตรงนี้และคงอุปกรณ์แค่ชนิดเดียว มันขึ้นอยู่กับ offer ของคุณ ไม่ว่าจะเป็น desktop หรือ mobile ก็โปรโมททั้งสองแบบบน Facebook ได้ แต่ผมจะคงแค่ mobile เพราะ mobile ให้ volume มากกว่า ปกติแล้วมีคนใช้ Facebook ผ่านมือถือมากกว่า desktop ผมจะปิด placement อื่น: Audience Network และ Messenger ซึ่งค่อนข้าง... แต่เป็นสิ่งที่ต่างออกไปโดยสิ้นเชิง — นี่คือ placements ทั้งหมดที่มีบน Facebook คุณทดสอบ placement อื่นได้ และเพิ่มเพิ่มเติมเพื่อพิจารณา scaling ในอนาคต แต่ตอนนี้ การคงแค่ Facebook News Feed น่าจะเป็นไอเดียที่ดีที่สุดในการทดสอบแคมเปญ

ผมจะเอา option อื่นออก Stories เป็นโฆษณาประเภทที่ต่างออกไปโดยสิ้นเชิง ต้องเอาออก ผมจะปิดหน้านี้เพื่อให้ง่ายขึ้น In-Stream, Search, Apps และ Insights — เอาออกทั้งหมด เหลือแค่ Facebook News Feed ที่เปิดใช้งาน อย่างที่เห็น potential reach ลดเหลือ 11 ล้านคน จากเดิม 18 ล้านตอนเปิด placements ทั้งหมด

ไปต่อ ตรงนี้คือ Optimization และ Spending Controls มีวิธีจัดการหลายแบบ Facebook เป็นแพลตฟอร์มใหญ่ที่มีตัวเลือกเยอะ แต่สิ่งที่ให้ผลดีที่สุดคือการไม่แก้อะไรมากนัก คุณคง Optimization for Ad Delivery และคง Link Clicks ไว้ หมายความว่าคุณจะถูกคิดเงินเมื่อมีคนคลิกลิงก์ในโฆษณา และคง Schedule ให้ ad set รันต่อเนื่องเริ่มตั้งแต่วันนี้ ไม่ต้องตั้งวันสิ้นสุด รันแคมเปญตลอดเวลา ถ้าอยาก pause ก็ pause ถ้าอยากเปิดใหม่ก็ทำได้ สะดวกมาก ไม่ต้องตั้งวันสิ้นสุด และคุณกำหนดงบประมาณไปแล้ว ก็เรียบร้อย

คุณปล่อยให้ Facebook ควบคุม bid ในกรณีนี้ได้ บางกรณีคุณอาจควบคุมเองได้ แต่ตอนนี้ไม่ต้องทำตรงนี้ คุณเพิ่มสิ่งอื่นได้อีกแต่ไม่จำเป็นต้องแก้ออปชันอื่น ๆ ตรงนี้บอกว่าคุณจะถูกคิดเงินแบบไหน แต่โฆษณายังถูก optimize เพื่อ link clicks — Facebook จะพยายามให้คนคลิกลิงก์คุณ และไม่ว่าคุณจะถูกคิดเงินแบบไหน หลังรันไปแล้ว Facebook จะแสดงว่าคุณจ่ายต่อคลิกเท่าไหร่ ให้ cost per click แก่คุณ เพราะถ้าจ่ายต่อการแสดงผล มันก็ยังคำนวณได้ว่าค่าเฉลี่ยต่อคลิกเท่าไหร่โดยดูจากค่าโฆษณารวมในรอบเวลาหนึ่งหารด้วยจำนวนคลิกทั้งหมด Facebook จะคำนวณให้เองและแสดง average cost per click คุณต้องใช้เมตริก CPC ในภายหลัง และคุณจะได้มันมาโดยไม่ต้องแก้อะไรตรงนี้ แค่กด Continue ต่อไป

อย่างที่เห็นก่อนคลิก เราได้ผ่านทุกส่วนที่เกี่ยวกับ Ad Set แล้ว ตอนนี้ไปที่โฆษณา (Ad) สิ่งแรกที่เห็นคือตั้งชื่อโฆษณาได้ ไว้สำหรับตัวคุณเอง ใส่อะไรก็ได้ ผมจะปล่อยค่าเริ่มต้นไว้ ไม่สำคัญจริง ๆ

จากนั้น Identity — เลือก Fan Page ของคุณ ถ้าคุณมีหลาย fan page เชื่อมกับบัญชี ก็เลือกอันที่อยากให้โฆษณาเชื่อมด้วย แล้วก็มีตัวเลือกให้เลือก Instagram Account ด้วยถ้าใช้ Instagram แต่กรณีนี้ไม่ใช้ ก็ข้ามส่วนนี้ไปได้เลย

ในการสร้างโฆษณา คุณมีตัวเลือกสร้างโฆษณาใหม่ ใช้โพสต์ที่มีอยู่บน fan page หรือใช้ mock-up คุณจะสร้างโฆษณาใหม่ เลือกตัวเลือกนี้ ซึ่งปกติถูกเลือกไว้เป็นค่าเริ่มต้น แล้วคลิก Single Image or Video เลือกอันนี้ คุณลองตัวอื่นได้ อย่างที่เห็นมีหลายอย่างให้เล่น แต่สิ่งที่ผมแสดงคือสิ่งที่ใช้งานง่ายและให้ผลดีตามปกติ

เราจะใช้โฆษณารูปภาพ เพราะโฆษณาวิดีโอต่างออกไป — วิดีโอใช้สร้าง engagement สร้าง custom audiences มากกว่า ไม่เหมาะสำหรับโปรโมท offer แบบ CPA และการหาคลิกไป landing page เท่าไหร่ ผมแนะนำให้ใช้รูปภาพ

เลื่อนลงมาแล้วจะมีตัวเลือก Add Media คลิกที่นี่ แล้วคลิก Add Image แล้วกด Continue นี่คือหน้าตาโฆษณาของคุณ แก้ไขรูปภาพได้ ถ้าอยากครอปหรือปรับแต่ง ดู preview ทางขวาได้ นี่คือรูปของผม และนี่คือสิ่งที่คนจะเห็นบนมือถือ

ตอนนี้ต้องใส่ข้อความ Primary Text จะแสดงเหนือรูปภาพ ส่วน Headline จะแสดงใต้รูปภาพ และ Description แสดงใต้ headline แต่บนมือถือปกติไม่ค่อยแสดง มันไม่จำเป็นนัก สำหรับ desktop ใส่ได้ ใส่คำอธิบายไป อย่างที่เห็นมันแสดงใต้โฆษณา และ primary text แสดงด้านบน

จากนั้นใส่ Landing Page URL ซึ่งเอามาจากโฆษณาได้ นี่คือลิงก์ที่คนจะไปเมื่อคลิก "Learn More" หรือคลิกรูปภาพ พวกเขาจะไปที่ลิงก์นี้ Display Link คือลิงก์ที่คนเห็น โดยค่าเริ่มต้นมันจะแสดงแค่โดเมนของคุณ ซึ่งก็โอเค ถ้าอยากใส่อะไรก็ใส่ เช่น "Example" แล้วใส่ luckyday.cc/prime แล้ว Facebook จะแทนที่ตรงนั้น

Display Link ต้องเป็นโดเมนเดียวกับ Destination URL ของคุณ ใช้โดเมนอื่นไม่ได้ แต่หลังจากนั้น หน้า /prime ไม่จำเป็นต้องมีอยู่จริงก็ได้

จากนั้นเลือก Call to Action — "Learn More" ปกติก็โอเค "Shop Now" ก็เป็นอีกอย่างที่ทดสอบได้ ตัวอื่นปกติยากกว่าจะเข้ากันได้ แต่เลือกอะไรก็ได้ที่คิดว่าน่าสนใจสำหรับแคมเปญ แล้วยังมีตัวเลือกอีกสองสามอย่างที่ไม่ต้องกังวล ใส่พารามิเตอร์ตรงนี้ได้ ซึ่งมีประโยชน์ถ้าใช้ tracking tool — กรณีนี้ไม่ใช้

เมื่อทำครบทุกอย่างแล้วคลิกปุ่ม และ Facebook จะให้รอสักครู่จนกว่าจะตรวจสอบ อนุมัติ และเริ่มรัน เมื่อผ่านแล้วมันจะออนไลน์ทันทีและเริ่มได้รับ impression และคลิก จากนั้นเริ่มติดตามแคมเปญและเริ่ม optimize แคมเปญได้เลย

ผมจะแสดงวิธี optimize และจัดการแคมเปญที่กำลังรันอยู่ในวิดีโออื่น ๆ นั่นไม่ใช่หัวข้อของวิดีโอนี้ ที่นี่ผมแค่อยากแสดงวิธีสร้างโฆษณา Facebook หวังว่าวิดีโอนี้จะเป็นประโยชน์กับคุณ ถ้ามีคำถามอะไร จำไว้ว่านี่ไม่ควรเป็นการเดินทางเดี่ยว คุณส่งข้อความขอความช่วยเหลือ (support ticket) ได้เสมอ และรับความช่วยเหลือเรื่องแคมเปญของคุณ แล้วเจอกันในวิดีโอหน้าครับ
