## บทนำ
วิดีโอนี้สอนวิธีตั้งค่า API credentials (ข้อมูลประจำตัวสำหรับเชื่อมต่อ API) ของ JSON2VIDEO ใน n8n โดยเลือกประเภท credential แบบ custom แล้ววาง JSON code พร้อม API key ลงไปเพื่อให้การเชื่อมต่อใช้งานได้

## คำแปลเต็ม
ผมต้องใช้ credential ประเภท generic ตรงนี้ผมเลือกแบบ custom และตรงนี้ต้องกด create new แล้วก็ตรงนี้ต้องเพิ่ม JSON code ลงไป และต้องใส่ API key ของผมเข้าไป แล้วคุณก็ไปเอา API จาก JSON2VIDEO มาคัดลอก วางลงไป แล้วกด save
