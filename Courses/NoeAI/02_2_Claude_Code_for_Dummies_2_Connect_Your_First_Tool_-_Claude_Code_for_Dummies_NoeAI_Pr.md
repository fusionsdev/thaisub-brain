ว่าไงครับทุกคน? ยินดีต้อนรับสู่วิดีโอถัดไปนะครับ ในวิดีโอนี้ ผมจะมาโชว์วิธีเชื่อมต่อเครื่องมือแรกของคุณเข้ากับ Claude Code ครับ เราจะลองเชื่อมต่ออะไรง่าย ๆ อย่าง Canva หรือ Gmail หรืออะไรแบบนั้นครับ มันง่ายมาก และทรงพลังสุด ๆ ครับ ถ้าคุณเชื่อมต่อเครื่องมือของคุณเข้ากับ Claude Code ได้ มันจะเริ่มทำงานภายในเครื่องมือพวกนั้นให้คุณเอง เจ๋งมากครับ ผมเชื่อมต่อเครื่องมือทุกอย่างที่ผมมีไว้หมดแล้ว เดี๋ยวจะโชว์ให้ดูครับ

มีสองวิธีที่เราจะทำกันในวันนี้ เราจะทำแบบแบ่งหน้าจอไปด้วยกันครับ ผมจะทำอันนึงใน Claude Desktop ปกติ และอีกอันใน Claude Terminal ผมแนะนำเสมอให้ใช้ Claude ใน Cursor แต่ถ้าคุณยังไม่ถนัด เราก็ใช้ Claude Desktop ไปก่อนครับ ผมจะเปิดสองหน้าต่างนี้คู่กัน แล้วพาทุกคนดูทั้งสองแบบครับ

วิธีเช็คว่าแอปของคุณเชื่อมต่ออะไรไปแล้วบ้าง มันง่ายมากครับ ใน Claude Code คุณแค่พิมพ์เครื่องหมายสแลช แล้วพิมพ์ MCP ครับ มันจะบอกคุณว่าคุณเชื่อมต่อ MCP ตัวไหนอยู่บ้าง ตอนนี้ผมเชื่อมต่อ Gmail, Google Calendar และ n8n อยู่ครับ ส่วนใน Claude Desktop ผมแค่เปิดแถบข้าง แล้วไปที่ customize ครับ แล้วผมก็มีตัวเลือก customize อยู่ตรงนี้ คุณสามารถ connect, create new, browse ได้ประมาณนั้นครับ ผมไม่ค่อยชอบใช้เวอร์ชันเดสก์ท็อป แต่เดี๋ยวโชว์ให้ดูครับ เพราะผมรู้ว่าพวกคุณอาจจะถนัดแบบง่าย ๆ กว่าผม สิ่งที่คุณทำคือคลิกเข้าไป แล้วก็จะเห็นทุกอย่างที่คุณเชื่อมต่ออยู่ ตรงนี้ผมเชื่อมต่อ Google, Claude และ Chrome ครับ แล้วคุณก็จะมี permissions ทั้งหมดอยู่ตรงนี้ มันจะถามอนุญาตเสมอเวลาจะเข้าถึงบางอย่าง ผมเลยตั้งให้มันทำได้ทุกอย่างตลอด เพราะมันไม่มีเครื่องมือลบข้อมูล ก็ปลอดภัยดีครับ ผมก็เปลี่ยนเป็น always allow หรือ blocked ได้ ถ้าไม่อยากให้มันทำบางอย่างในบางสถานการณ์ ก็บล็อกมันได้เลยครับ

ถ้าผมทำงานใน Claude Code สิ่งที่ต้องทำเพื่อเชื่อมต่อคือ ไปที่ connectors กด connectors แล้วกด browse connectors แล้วผมก็เลือกจากแอปหลายร้อยตัวได้เลยครับ ลองเลือกมาหนึ่งตัวเป็นตัวอย่างนะครับ สมมติว่าผมอยากอ่านและส่ง iMessage ผ่านตรงนี้ มันเจ๋งมากครับ หรือลองเชื่อมต่อกล้องของผมดู เพราะอยากเห็นว่ามันทำได้ไหม มันจะเปิดแท็บขึ้นมาใหม่ แล้วก็เปิดหน้าต่างที่เรียกว่า OAuth sign-in ครับ OAuth sign-in ก็คือแบบที่คุณเคยเจอตอนเข้าสู่ระบบ Google น่ะครับ เหมือนกับให้คุณกดยืนยันสองสามครั้ง ครับ หน้าตามันเป็นภาษาโปรตุเกส เพราะผมอยู่ที่บราซิล ผมอ่านไม่ออกแม้แต่คำเดียว แต่ผมจะกดอนุญาตไปครับ สำหรับคุณมันจะขึ้นเป็น accept หรือ cancel ครับ พอ authorization successful แล้ว มันจะให้ผมเปิดกลับมา และมันก็เชื่อมต่อกับ Canva แล้วครับ เห็นไหมครับ? ตอนนี้ผมเชื่อมต่อกับ Canva แล้ว ผมสามารถค้นหาดีไซน์ สร้างงานออกมาได้ เดี๋ยวลองทดสอบดูว่ามันเป็นยังไงครับ ผมจะถามมันว่า คุณเชื่อมต่อกับ Canva อยู่ไหม?

[ฟังไม่ชัด — ช่วงสาธิตการถาม Claude ในเวอร์ชันเบราว์เซอร์ เสียงต้นฉบับไม่ชัด]

ระหว่างนั้น ผมจะโชว์วิธีทำแบบเดียวกันในเวอร์ชันเทอร์มินัลให้ดูครับ ดูเหมือนมันเสร็จแล้วตรงนี้ นี่คือเวอร์ชันเบราว์เซอร์ ส่วนเวอร์ชันเดสก์ท็อปจริง ๆ ผมมี Canva เชื่อมต่ออยู่ ผมสามารถค้นหา ดูตัวอย่าง สร้างใหม่ แก้ไขงานเดิม หรือส่งออกได้ครับ ผมจะลองยืนยันอีกที ลองดึง thumbnail ดีไซน์ล่าสุดของผมมาโชว์หน่อยสิครับ โอเค ไม่รู้ว่า preview mode คืออะไร แต่เดี๋ยวเราจะรู้เอง มันกำลังจะเรียกใช้งาน มันจะค้นหา thumbnail ดีไซน์ของคุณใน Canva ให้ครับ แล้วมันก็เข้าไปค้น จริง ๆ แล้วมันยืนยันได้เลยว่ามี access ถึง thumbnail ของผม ซึ่งเจ๋งมากครับ ผมเจอ thumbnail หนึ่งอัน มี 10 เพจ มันกำลังทำงานอยู่ ปล่อยให้มันทำงานไปครับ

ทีนี้มาดูเวอร์ชันเทอร์มินัลกันบ้าง ข้างในเทอร์มินัล ให้อัปเดตตัวนี้ให้ทันก่อน โอเค ดูนี่สิครับ กด show image ไม่รู้ว่าทำไมมันไม่โชว์ให้ผมเห็นตรงนี้ แต่มันก็เข้าถึงทุกอย่างของผมได้หมดเลยครับ มันมี access ถึงข้อมูลทั้งหมดของผม ไม่ว่าจะแก้ไขหรือ export อะไรก็ทำได้ตามที่ต้องการ เจ๋งมากครับ นี่คือวิธีเชื่อมต่อแอปเข้ากับ Claude Code ผ่านเดสก์ท็อปครับ

ถ้าผมอยากเชื่อมต่อแอปในแบบที่ผมใช้จริง ๆ ผมก็แค่ทำแบบนี้ครับ พิมพ์สแลช แล้วดึงเมนูขึ้นมา อันนี้มันโชว์เฉพาะสิ่งที่ integratable กับ Claude ได้ครับ ถ้าผมเลื่อนดู ผมก็จะเห็นว่าผมเข้าถึง Google อะไรพวกนั้นได้ แต่สิ่งที่ผมอยากทำคือ ผมจะออกมาก่อน พิมพ์ cd แล้วเข้าไปในโฟลเดอร์ Noah Barner ครับ ผมแค่ลากโฟลเดอร์ลงมา แล้วเปิดมันขึ้นมา ตอนนี้ผมทำงานในโฟลเดอร์นั้นแล้ว เห็นไหมครับ แล้วก็ Claude Code โอเค สิ่งที่เกิดขึ้นคือ เพราะว่า MCP พวกนี้มันไม่ได้เป็นแบบ global อย่างที่ผมเคยอธิบายไว้ เดี๋ยวผมพิมพ์ดู MCP แล้วคุณจะเห็น MCP ทั้งหมดของผมครับ ผมมี Airtable, Google, Meta, Coach, Nano, Supabase มี Loom ที่เชื่อมต่อในเครื่อง แล้วก็ Google, n8n และ Stripe ครับ มีการเชื่อมต่อเยอะมากจนน่าตกใจ

สำหรับโปรเจกต์แบบนี้ คุณต้องสร้าง MCP แยกแต่ละตัว ซึ่งเราจะทำในบทเรียนหน้า เราจะได้สร้าง MCP ของคุณเองจริง ๆ แต่บทเรียนนี้ ขอแค่เชื่อมต่อของที่มีอยู่แล้วใน Claude ให้ดู เพื่อให้เห็นความเป็นไปได้ที่คุณจะเชื่อมต่อกับ Claude ได้ ซึ่งน่าสนใจมากครับ เพราะดูเหมือนว่าในเดสก์ท็อปจะมี connectors เยอะกว่า เหมือนมี MCP แบบ native ใน Claude Desktop มากกว่า เชื่อมต่อง่ายกว่าครับ แต่คุณก็ยังเชื่อมต่อแอปพวกนี้ในเวอร์ชันเทอร์มินัลได้ เพียงแต่คุณอาจต้องสร้างสิ่งที่เรียกว่า MCP ซึ่งเราจะสร้างกันในบทเรียนหน้า ครับ

สำหรับตอนนี้ ลองเลือกตัวที่เรายังไม่ได้เชื่อมต่อดูครับ จริง ๆ ผมยังไม่ได้เชื่อมต่อ Stripe นะ ไม่แน่ใจว่าอยากให้มันแตะเรื่องธนาคารไหม น่าจะไม่ค่อยดีเท่าไหร่ แต่คุณก็แค่คลิกตัวนี้ มันก็เหมือนเดิม แค่ยืนยันตัวตน มันไม่ดึงข้อมูลที่ละเอียดอ่อนออกมาแน่นอนครับ แล้วมันจะให้คุณ authorize แล้วคุณก็เปิดใช้งานสำหรับบัญชีนี้ จากนั้นก็เลือก permissions ที่ต้องการ ครับ ให้สิทธิ์อ่านบัญชี อ่านยอดเงินได้ ผมโอเคกับอันนั้น ส่วน charges และ refunds ผมไม่อยากให้มันทำแทนผมได้ ก็เลือกไม่ครับ ให้มันอ่านได้อย่างเดียว ถ้าผมอยากให้มันเขียนใบแจ้งหนี้และส่งให้ลูกค้าได้ ผมก็ทำได้ในทางเทคนิค ซึ่งผมอาจจะทำ เพราะใบแจ้งหนี้ไม่ใช่การเรียกเก็บเงินอัตโนมัติ การให้สิทธิ์ invoice จะหมายรวมถึงสิทธิ์ credits และ read ด้วย ผมจะให้สิทธิ์อ่านอย่างเดียว ไม่ให้มันทำอะไรงี่เง่า ส่วน payment ผมให้สิทธิ์อ่านยอดชำระ แล้วก็อ่าน promotion steps โอเค แล้วผมก็กด authorize ครับ แล้วก็ authorization successful โอเค แล้วมันก็จะพากลับมาที่ Claude แล้วเราก็จะเข้าถึง Stripe ได้ครับ Stripe จัดไป

พอผมกลับมา มันก็ authenticate ให้อยู่แล้ว กำลังสร้างการเชื่อมต่อ แล้วก็เชื่อมต่อกับ Claude Stripe สำเร็จ ตอนนี้ผมอยากลองใช้ ครับ ลองดึงชื่อลูกค้าคนแรกของการเรียกเก็บเงินล่าสุดในบัญชีให้หน่อยสิครับ ผมจะรันมันดู ว่าเดี๋ยวจะทำอะไร โอเค เสร็จแล้ว ดูนี่สิครับ ผมลองจะดึงข้อมูลจริง ๆ แต่คิดว่ามันคงไม่ดีเท่าไหร่ payment intent ล่าสุดคือ customer ID ว่างเปล่า ตอนนี้เราเชื่อมต่อกับทุกอย่างแล้วครับ ถ้าผมเปิดดู MCP ผมเชื่อมต่อ Stripe, n8n, Google, โฆษณา ทุกอย่างเลยครับ

นี่คือสิ่งที่ Claude Code ของผมทำได้นะครับ มันจะเข้าไปดู CRM ของลูกค้า ไปดูบัญชี Meta Ads ดูว่าโฆษณาไหนดีที่สุด แล้วดูใน CRM ว่าลีดเหล่านี้มาจากไหน แล้วดูใน Stripe ว่าลีดคนไหนจ่ายเงินจริง แล้วก็ย้อนกลับไปเชื่อมโยงกับโฆษณา แบบนี้ครับ บ้า ๆ บอ ๆ ไปเลย ยิ่งผมให้ access มันมากเท่าไหร่ มันก็ทำงานให้ผมได้มากขึ้นเท่านั้นครับ ผมเลยพยายามเชื่อมต่อทุกอย่างเข้ากับเจ้านี่ให้หมดเลย

นี่คือการเชื่อมต่อแบบ native ครับ ทั้งในเทอร์มินัลและใน Claude Desktop บทเรียนหน้า เราจะสร้างสิ่งที่ไม่ได้เป็น native กันครับ แบบ native มันง่ายแบบเสียบปลั๊กแล้วใช้ได้เลย แต่ถ้าเป็นแอปที่ไม่มีอยู่ เช่น Slack ผมไม่เห็น Slack ในรายการตรงนี้ใช่ไหมครับ ถ้าผมอยากเชื่อมต่อ ผมต้องสร้าง MCP ขึ้นมาเอง บทเรียนหน้าผมจะโชว์วิธีเชื่อมต่อ Claude Code กับอะไรก็ได้จริง ๆ โดยเฉพาะสิ่งที่ไม่มีในรายการ ครับ แต่ภารกิจที่ผมให้ทุกคนตอนนี้คือ เชื่อมต่อสิ่งต่าง ๆ เข้ากับ Claude Code ให้ได้มากที่สุด แล้วลองทดสอบดูว่ามันทำอะไรได้บ้าง วิธีที่ดีที่สุดคือลองถามมันว่า คุณทำอะไรได้บ้างในแอปนี้ ในบัญชีนี้ ในซอฟต์แวร์นี้ ครับ นั่นคือทั้งหมดสำหรับวันนี้ เจอกันบทเรียนหน้าครับ
