# สรุป: OpenMausBot DESTROYS Grok Bot?

- **ช่อง:** Julian Goldie SEO · **ความยาว:** ~14 นาที · **ลิงก์:** https://www.youtube.com/watch?v=midY3xIxKAk

## ประเด็นหลัก

- OpenMausBot คือเวอร์ชันโอเพนซอร์สฟรีของ GrokBot ที่เสียบเข้ากับ AI subscription ที่คุณมีอยู่แล้ว (Claude, Codex, Grok) ไม่ต้องสมัครใหม่ ไม่ต้องจ่ายเพิ่ม.
- GrokBot เพิ่งเข้าสู่ early beta และหมด token เร็วมาก โดยผู้พูดลองฟรีไทรอัลแล้วหมด token ภายใน 20 นาที.
- ผู้สร้างคือ Milind Sony (มิลินด์ โซนี่) สร้าง OpenMausBot เป็นโอเพนซอร์สเต็มรูปแบบ แชร์สู่สาธารณะบน GitHub.
- หน้าตาเป็นแบบ chat app คล้าย Telegram หรือ WhatsApp โดย contact แต่ละตัวคือ AI agent ที่มีสมอง ความจำ แอปที่เชื่อมต่อ และคอมพิวเตอร์เป็นของตัวเอง.
- มี model picker ให้เลือก model ได้ทีละบอท (เช่น Fable 5, Opus 5, Sonnet 5, Haiku, Codex หรือ Grok 4.5) ต่างจาก GrokBot ที่เปลี่ยน model ไม่ได้.
- บอททุกตัวมีคอมพิวเตอร์ของตัวเองในรูปแบบ cloud desktop (Linux) พร้อมพรีวิวหน้าจอสด ขณะที่มันทำงาน หรือจะชี้ให้บอททำงานบน Mac ของคุณเองก็ได้.
- ระบบขออนุญาต (permission) จะแสดงการ์ด allow หรือ deny ก่อนบอทลงมือทำอะไรที่เสี่ยง ทุกการกระทำสำคัญต้องผ่านการอนุมัติจากคุณ.
- connected apps บนมาร์เก็ตเพลสที่สร้างบน Composio เชื่อมแอปได้กว่า 500 ตัว เช่น Gmail, Slack, Notion, Linear เชื่อมครั้งเดียวใช้ได้ทุกบอท.
- เป็นสถาปัตยกรรม local-first ข้อมูล คีย์ และ event log อยู่ในเครื่องคุณ แต่ยังต้องส่งข้อมูลไปยังคลาวด์โมเดลของ Claude, Codex หรือ Grok.
- ดาวน์โหลดเป็นแอป Mac จาก GitHub ได้เลย ตอนนี้ยังเป็น Windows ก่อน (Windows, Linux และ Ubuntu กำลังจะตามมา) และต้องมีเครื่องมือ AI อย่างน้อยหนึ่งตัวที่ติดตั้งและล็อกอินแล้ว.
- ข้อจำกัด: รันได้เฉพาะ Claude, Codex และ Grok เพิ่งเปิดตัววันนี้ ระบบอนุมัติอาจน่ารำคาญเมื่อใช้ไปนานๆ และการแท็กให้บอทคุยกันเองยังใช้ไม่ได้.
- GrokBot ยังลื่นกว่า แต่คนส่วนใหญ่เข้าใช้ GrokBot ไม่ได้ เพราะมี waitlist และ token จำกัด ส่วน OpenMausBot เป็นทางเลือกระยะยาวที่เปิดกว้างกว่า.

## ความเห็นสรุป

OpenMausBot เป็นตัวอย่างที่ดีของทิศทาง "ทีม agent" ที่ AI แต่ละตัวมีชื่อ หน้าที่ model แอป และคอมพิวเตอร์เป็นของตัวเอง ซึ่งกำลังกลายเป็นมาตรฐานใหม่ของการใช้ AI. แม้ยังเป็นโอเพนซอร์สที่เพิ่งเปิดตัวและไม่ลื่นเท่า GrokBot แต่ความง่ายในการติดตั้ง การใช้ subscription ที่มีอยู่แล้ว และการควบคุมผ่านระบบขออนุญาต ทำให้เป็นตัวเลือกที่น่าสนใจสำหรับคนทั่วไปที่อยากลองใช้ agent โดยไม่ต้องลงทุนเพิ่ม.
