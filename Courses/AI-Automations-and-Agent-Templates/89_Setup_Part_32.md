## คำแปลเต็ม

ในการส่งโพสต์ตามกำหนดเวลาไปยังระบบเผยแพร่ของเรา เราจะใช้ make.com อีกครั้ง แค่เข้าสู่ระบบ make แล้วด้านล่างวิดีโอนี้คุณจะพบ make blueprint นี้ ดาวน์โหลดมัน คลิกที่ create a new แล้วเราก็จะนำเข้ามัน เราคลิก import คลิก แล้วตอนนี้เราแค่ต้องปรับเปลี่ยนไม่กี่จุดเท่านั้น

สิ่งแรกที่ต้องทำคือ ต้องเพิ่ม webhook ตรงนี้ คลิกที่คัดลอก แล้วจากนั้นเราต้องกลับไปตรงนี้ เพราะตรงนั้นเราก็มีช่องว่างสำหรับ webhook ด้วย เราต้องคลิกเข้าไปตรงนี้ก่อน แล้วค้นหา webhook จากนั้นมันต้องเป็น make webhook โดยปกติคุณควรเห็นช่องว่างให้ใส่ เพราะเมื่อถึงเวลาที่คุณดูวิดีโอนี้ ผมคงเปลี่ยนมันเป็นข้อความช่องว่างแล้ว และเราแค่เพิ่มอันนี้ครั้งเดียว คลิก save ดังนั้นนี่คือ webhook ที่ส่งข้อมูลโพสต์ไปยังโพรเซสเผยแพร่ของเรา

ตอนนี้มาคลิก save ไว้ก่อน และสิ่งเดียวที่เหลือคือ ถ้าคุณเคยใช้เทมเพลตระบบอัตโนมัติของผมมาก่อน หรือคุณเคยมีแพลตฟอร์มเผยแพร่นี้ หรือเคยใช้ make.com สักครั้ง คุณก็จะเชื่อมต่อบัญชีเหล่านี้ไว้แล้ว คุณแค่ต้องเลือก OpenAI จากตรงนี้ และมันเชื่อมต่อแล้ว เช่นเดียวกับแพลตฟอร์มโซเชียลมีเดียที่เชื่อมต่อไว้แล้ว

ถ้าคุณยังไม่ได้ทำ ให้ดูวิดีโอที่ผมโชว์วิธีตั้งค่า และเพราะตรงนี้ผมจะปล่อยให้มันเลือกไว้เหมือนเดิม เพราะมันเลือกบัญชีโซเชียลมีเดียทั้งหมดไว้แล้ว เนื่องจากพวกมันเชื่อมต่อกับบัญชี make ของผมแล้ว แต่ถ้าคุณยังไม่ได้ทำ ตรวจสอบให้แน่ใจว่าได้ดูวิดีโอนี้: publish social media posts via เพราะมันจะโชว์วิธีตั้งค่าอะไรแบบนี้ แล้วคุณสามารถกลับมาเชื่อมต่อโปรไฟล์โซเชียลมีเดียเหล่านี้ได้ แต่มันง่ายมาก คุณแค่เข้าสู่ระบบบัญชีของคุณเท่านั้น ตรงนี้ก่อน Twitter คุณต้องเพิ่มอีกนิดหน่อย แต่ก็ครอบคลุมในส่วนนี้ด้วย: setup developer account for posting module

ตอนนี้ไปต่อกัน สิ่งเดียวที่ผมต้องเพิ่มหรือเปลี่ยนคือใส่ sheet ID ของผมในช่องนี้ และ sheet ID คืออันนี้ นั่นคือ sheet ID ตรวจสอบให้แน่ใจว่าบัญชี Google ตรงนี้คือบัญชี Google ที่คุณมีชีตอยู่ แล้วมันควรโหลดชื่อชีตที่ถูกต้อง ออกมาดี ตรงนี้ผมไม่ต้องทำอะไร ตรงนี้คือเวลากำหนดการ และผมมีเวลากำหนดการ ไม่ใช่เวลากำหนดการ แต่หมายถึงเวลาที่เผยแพร่ เมื่อโพสต์ถูกเผยแพร่ มันจะเขียนวันที่ลงในชีตนั้น

เราก็เชื่อมต่ออันแรกแล้ว และตอนนี้เราจะลบพวกนั้นออก แล้วให้ผมทำสำเนาอันนี้ เพราะมันเหมือนกันสำหรับทั้งหมด สิ่งเดียวที่มันทำคือเขียนวันที่หลังจากที่โพสต์ถูกเผยแพร่กลับไปยัง Google Sheets และสิ่งที่เราอยากได้อีกอย่างคือสถานะควรเปลี่ยนเป็น published ดังนั้นอันนี้จะเปลี่ยนเป็น published มาเพิ่มอันนี้เข้าไป เพื่อให้ AI agent ของผมรู้ว่าโพสต์ไหนถูกเผยแพร่แล้ว สถานะ published สถานะ published โอเค

ตอนนี้เราต้องเชื่อมต่อสองสิ่ง คือ webhook เราต้องเปิดใช้งานอันนี้ แล้วจากนั้นเราต้องเพิ่ม webhook ที่ถูกต้องจาก n8N ของเรา เพราะอันนี้จะส่งข้อความยืนยันกลับมาที่บัญชี Telegram ของผม ซึ่งบอกว่าโพสต์ถูกเผยแพร่ไปยังแพลตฟอร์มนี้ในเวลานี้ เพื่อให้ผมมีข้อความยืนยันและมั่นใจได้ว่าโพรเซสเผยแพร่นี้เสร็จสมบูรณ์จริง ๆ

ในการทดสอบ ผมต้องกำหนดเวลาโพสต์จริง ๆ ผมต้องคลิกที่ start waiting for แล้วจากนั้นผมต้องไปอีกทางหนึ่ง กลับมาตรงนี้ เพราะตรงนี้ผมต้องเปลี่ยน webhook จาก และผมเข้าไปในโมดูล webhook แล้วเลือกอันที่เป็นแบบทดสอบ และผมต้องทำแค่อันเดียวเท่านั้น มาทำกับสาขา Facebook เพราะผมต้องทดสอบมันหนึ่งครั้งแล้วบันทึก

ตอนนี้ผมต้องไปที่โพสต์ของผม เลือกโพสต์หนึ่ง และตรงนี้ผมจะให้มันใช้ Facebook เป็นช่องทาง แล้วผมจะบอกให้มันกำหนดเวลาโพสต์ในอีกประมาณ 5 นาที แล้วมันจะรันสิ่งนี้ ผมจะคลิกที่มัน แล้วสิ่งที่ต้องทำอีกอย่างคือคลิก listen for test event แต่ต้องแน่ใจว่ากำหนดเวลาโพสต์ก่อน เริ่มแบบนี้ กำหนดเวลาโพสต์แรกในรายการให้เผยแพร่ในอีก 3 นาทีจากตอนนี้ ผมต้องกลับไปก่อน ผมต้องไปที่ test workflow แล้วมันควรทำแบบนั้นให้ผม มันอยู่ที่ 10:27 ซึ่งก็คือ 3 นาทีพอดี

และตอนนี้ผมกลับมาตรงนี้ มาตรวจสอบให้แน่ใจก่อนว่าอันนี้ยัง active อยู่ มันกำลังรอข้อมูล ดี ตอนนี้ผมต้องกลับมาตรงนี้แล้วคลิก listen for test event ภายใน 3 นาทีนี้มันอาจเกิดขึ้นแล้วหยุด จากนั้นคุณต้องคลิก start อีกครั้ง และตรวจสอบให้แน่ใจว่ามันกำลังฟังอยู่ในขณะที่โมดูลนี้ได้รับข้อมูล เพราะอันนี้ส่งข้อมูลกลับไปที่นั่น แล้วเราจะรู้ว่า webhook ทำงานได้

ผมจะหยุดวิดีโอนี้ชั่วคราวแล้วเล่นต่อเมื่อมันรันเสร็จ ตอนนี้คุณเห็นว่ามันเพิ่งเสร็จ และตอนนี้คุณก็เห็นว่าอีเวนต์ถูกส่งมาตรงนี้แล้ว ตอนนี้ผมกลับไป และผมต้องดูว่าการแมปถูกต้องไหม อันนี้เป็นสีเขียว มันเป็นสัญญาณที่ดี นี่คือสิ่งที่ถูกต้อง ดังนั้นผมจะได้รับข้อความโพสต์กลับมา นี่คือตอนนี้มันทำงานแล้ว ดี

และตอนนี้ผมต้องเปลี่ยน webhook ดังนั้นตอนนี้ผมต้องสลับจาก test เป็น production และตอนนี้ผมสามารถใส่ค่านั้นได้ ใส่ตรงนี้ได้ และใส่ตรงนี้ด้วย แล้วจากนั้นผมจะได้รับข้อความยืนยันกลับมาทุกครั้งเมื่อโพสต์ถูกเผยแพร่ ผมจะทำการทดสอบรอบสุดท้ายในตอนท้าย แต่นี่คือเราตั้งค่าทุกอย่างแล้ว เพื่อให้มันส่งโพสต์ รูปภาพ แพลตฟอร์มที่ควรเผยแพร่ ในแชท มันส่งข้อความยืนยันกลับมาในข้อความ Telegram เดียวกัน และตอนนี้มันทำงานได้

ดังนั้นสิ่งเดียวที่เหลือคือ กลับไปที่อันนั้นแล้วเปลี่ยนเป็นเปิด ฉันต้องกลับไปก่อน ผมยังใช้ make แบบฟรีอยู่ ดังนั้นผมต้องปิดอันหนึ่งตรงนี้ แล้วจากนั้นผมสามารถกลับไปและเปิดมันได้ นี่คืออันที่ผมเพิ่งตั้งค่า ดี ตอนนี้มันเปิดอยู่แล้ว และในวิดีโอถัดไป ผมจะโชว์วิธีเชื่อมต่อ Google Sheet เวอร์ชันอัปเดตนี้เข้ากับโซเชียลมีเดีย agent ของคุณที่สร้างและเผยแพร่โพสต์โดยตรง
