## บทนำ
คลิปนี้สอนวิธีขอข้อมูล API ของ WhatsApp Business ประกอบด้วย client ID, client secret, access token และ WhatsApp business account ID โดยใช้บัญชี developers.facebook.com ผู้สอนพาทำทีละขั้นตอน ตั้งแต่สร้างแอป เลือก business portfolio จนได้ค่า token สำหรับโหมดทดสอบ พร้อมอธิบายข้อจำกัดว่า token ในโหมดทดสอบหมดอายุใน 1 ชั่วโมง และต้องมี verified business account ถึงจะใช้แบบจริง (live) ได้

## คำแปลเต็ม
เราต้องการ client ID และ client secret ตอนนี้เราต้องใช้บัญชี developers.facebook.com คุณต้องสมัครบัญชีก่อน ผมคิดว่าคุณแค่ล็อกอินด้วย Facebook ของคุณ แล้วคลิก My Apps

จากนั้นคุณสามารถคลิก create app เราจะตั้งชื่อให้มันว่า AI agent setup แล้วตรงนี้ผมเลื่อนลงมา คลิกที่ select business แล้วตรงนี้ผมปล่อยไว้ตามเดิม คลิก create app ผมต้องล็อกอินด้วยบัญชี Facebook ส่วนตัวของผม

เราต้องไปที่ app แล้วไปที่ basic คุณจะเจอ app ID นั่นคือ client ID ที่เราจะวางตรงนี้ ส่วน client secret เราจะได้ตรงนี้ คลิกที่มัน แล้วคุณกรอกมันตรงนี้

ต่อไปเราต้องการ access token และ business account ID ซึ่งเราจะได้จากตรงนี้ เราต้องกลับไปที่ Dashboard แล้วตรงนั้นคุณต้องไปที่ส่วนนี้ คลิก WhatsApp

ตอนนี้คุณต้องเลือก business portfolio ถ้าคุณยังไม่มี อันที่จริงมันมีบัญชี Facebook business ซึ่งคุณสามารถตั้งค่าได้ฟรี และถ้าคุณยังไม่มี คุณก็ไปที่ business.facebook.com แล้วมันจะพาคุณทำตามขั้นตอนเพื่อสร้างบัญชีธุรกิจ

ถ้าคุณต้องการแค่ทดสอบ agent และตั้งค่าอย่างที่ผมโชว์ในวิดีโอนี้ บัญชีธุรกิจก็เพียงพอแล้ว แต่ถ้าคุณอยากใช้งานจริง เช่นใช้เบอร์โทรศัพท์ทางการที่ลูกค้าคุยด้วยได้ และคุณไม่สามารถใส่ไว้บน [เว็บไซต์/แอป] ได้ คุณต้อง verify บัญชีธุรกิจใน Facebook ซึ่งทำได้แต่ต้องใช้ขั้นตอนเพิ่มอีกเล็กน้อย

ผมเตรียมพรอมต์ไว้ให้ คุณแค่คัดลอกมันไปใส่ใน ChatGPT แล้วมันจะพาคุณทำตามขั้นตอนการขอ verified business account แต่สำหรับตอนนี้ คุณไปที่ create a new business แล้วคุณต้องสร้าง Facebook page ด้วย และภายใต้ business นี้ ถ้าต้องการความช่วยเหลือก็ถาม ChatGPT ได้เลย

จากนั้นคุณเลือก business portfolio ของคุณจากเมนู dropdown ตรงนี้ ผมมีสองอัน แล้วคุณก็กด continue ต่อไปได้ ผมคิดว่าขั้นตอนนี้ก็เพื่อป้องกันสแปม ไม่ให้คนมาใช้หรือนำ WhatsApp for business หรือ API ไปในทางที่ผิด

ตรงนี้เราคลิก start using the API และตรงนี้เรามี access token อยู่แล้ว เราคลิกที่มัน แล้วผมต้องล็อกอินหรือยืนยันตัวตนอีกครั้งด้วยบัญชี Facebook ของผม แค่คลิกที่ด้านบน คลิก save

โอเค ตอนนี้ access token นี้มีอายุประมาณ 1 ชั่วโมง พอครบ 1 ชั่วโมงมันจะหมดอายุ และคุณสามารถต่ออายุได้ เพราะนี่เป็นแค่การทดสอบ และเมื่อคุณเปลี่ยนเป็นโหมด [live] คุณจะได้ access token แบบถาวร แต่ตรงนั้นคุณต้องมี verified business account ตามที่ผมบอก มันจะแสดงให้เห็นว่าต้องทำอะไรบ้างเพื่อสลับไปใช้แบบ live

แต่เอาล่ะ เราจะตั้งค่าในโหมดทดสอบก่อน ผมคลิกวาง access token ตรงนี้ แล้วเราจะเห็น WhatsApp business account ID ผมคัดลอกมันมา วางลงไป แล้วคลิก save
