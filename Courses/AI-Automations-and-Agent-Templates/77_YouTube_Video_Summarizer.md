## บทนำ
วิดีโอนี้สาธิตการตั้งค่า YouTube Summarizer ซึ่งเป็นระบบที่สรุปวิดีโอ YouTube อัตโนมัติ โดยใช้ Gemini 2.0 Flash 1.5 ซึ่งเป็น AI ฟรีจาก Google ทำงานร่วมกับ Google Sheets และ Make.com เพื่อดึงข้อมูลวิดีโอ สร้างบทถอดความ (transcript) ผ่าน API จาก RapidAPI จากนั้นให้ Gemini สรุปเนื้อหาแล้วบันทึกกลับลง Google Sheets

## คำแปลเต็ม

ในวิดีโอนี้ ฉันจะโชว์วิธีตั้งค่า YouTube Summarizer เวอร์ชันที่ใช้ Gemini 2.0 Flash 1.5 ซึ่งเป็น AI ฟรีที่เราใช้ได้จาก Google มันเป็น API ฟรี เราจ่ายเงินไม่ต้องจ่ายอะไรเลยเพื่อใช้มัน แค่คลิกลิงก์ใต้วิดีโอนี้ นั่นคือ Google Sheet ที่เราใช้เริ่มต้น

เราตั้งค่า Google Sheet แล้ว จากนั้นมี blueprint (เทมเพลต) หรือระบบอัตโนมัติสองสามอันที่ต้องตั้งค่าใน Make เพื่อเชื่อมต่อฟังก์ชันต่าง ๆ ฟังก์ชันสรุปเนื้อหา และ API ต่าง ๆ ที่เราต้องการ

อย่างแรกต้องรอสองสามวินาทีจนกว่ามันจะแสดงขึ้นมา จากนั้นคลิก authorize app (อนุญาตแอป) แล้วทำตามขั้นตอนการอนุญาต มีบางอย่างที่ต้องยืนยัน: คุณต้องเลือกบัญชี Gmail แล้วคลิก allow และเมื่อเสร็จแล้วเราจะไปต่อ แค่ทำตามขั้นตอนเหมือนที่ฉันทำอยู่ตอนนี้ มีจุดหนึ่งที่ต้องคลิก advanced (ขั้นสูง) บางคนพลาดจุดนี้บ่อย ในระหว่างขั้นตอนการอนุญาตมีจุดที่ต้องคลิก แล้วต้องดำเนินการต่อด้วยตัวเลือก unsafe (ไม่ปลอดภัย) พอทำเสร็จมันจะแสดงว่า authorization เสร็จสิ้น จากนั้นคลิก install triggers (ติดตั้งตัวกระตุ้น) นั่นคือส่วนถัดไปที่ต้องทำ และเมื่อทุกอย่างเรียบร้อย เราต้องใส่ webhooks จากระบบอัตโนมัติสองอันที่เราต้องการ

ไปที่ make.com ของคุณ แล้วคลิก create a new scenario (สร้างสถานการณ์ใหม่) และใต้วิดีโอนี้คุณจะเจอสอง scenario เราจะเริ่มด้วย part one ก่อน คลิกดาวน์โหลด scenario ใต้วิดีโอนี้ แล้วคลิก import นำเข้าอันแรกซึ่งก็คืออันนี้ ลองอีกครั้ง คลิก save มันเวิร์กแล้ว

สิ่งแรกที่ต้องทำคือคลิก add a new webhook (เพิ่มเว็บฮุคใหม่) แล้วคัดลอก address นี้ แล้ววางลงใน webhook one ก่อนหน้านั้นเราต้องแน่ใจว่ามันเชื่อมต่อกับ Google Sheet ได้ สิ่งที่ต้องทำคือตอนนี้เราจะยกเลิกการเชื่อมต่อไว้ก่อน ลองดู คลิกอีกครั้ง มันดูเหมือนยังไม่บันทึก คลิกอีกครั้ง คัดลอกแล้ววางลงตรงนี้ โอเค ตอนนี้มันกำลังฟังอยู่

สิ่งที่เราจะทำคือไปที่ชีตของเราตรงนี้ แล้วใส่ YouTube URL เพื่อทริกเกอร์ webhook วางลิงก์หนึ่งอันเข้าไป แล้วมันก็ควรจะทริกเกอร์และทำงาน เราต้องใส่ YouTube API key ฉันจะไม่โชว์วิธีหามันตรงนี้ เพราะคุณจะเจอมันในบทเรียนเทคนิค ชื่อ Get YouTube API key from Google Cloud Console คุณแค่วาง API key ของคุณลงตรงนั้น เราทำแบบเดียวกันตรงนี้ วาง API key แล้วคลิก OK

และใน Google Sheets คุณต้องเลือกบัญชี Google เดียวกับที่เชื่อมต่อกับ Google Sheet ของคุณ เอาเมาส์ไปวางบนไอคอนของคุณ แล้วมันจะบอกว่าคุณเข้าสู่ระบบด้วยบัญชีใด ถ้าคุณมีหลายบัญชี Google และถ้ายังไม่ได้สร้างการเชื่อมต่อกับ Google ให้คลิก Add แล้วทำการสมัครให้เสร็จ แล้วเลือกบัญชี Google ของคุณจากเมนู drop-down

ตรงนี้เราต้องใส่ sheet ID ซึ่งก็คือส่วนนี้ตรงนี้ คัดลอกมัน วางลงตรงนี้ จากนั้นเราต้องยกเลิกการเชื่อมต่อก่อน แล้วให้มันรันหนึ่งครั้ง เราจะกรอกข้อมูลนี้อีกครั้งเพื่อดูว่ามันดึงข้อมูลได้หรือยัง ตอนนี้เชื่อมต่อได้อีกครั้ง ตรงนี้ลองดู มันดึงข้อมูลทุกอย่างมาได้ดี

ตอนนี้เราสามารถแมปฟิลด์ต่าง ๆ ได้ เราต้องแมปข้อมูลทั้งหมดตรงนี้ YouTube URL ถูกใส่ไว้แล้ว YouTube title มาจากโมดูล make a request อันแรก มันควรจะมาจากตรงนี้ นั่นคือ title ในอันแรก เราทำแบบมาตรฐานได้ ส่วน resolution display เราไม่ต้องการ เพราะมันเกิดขึ้นใน Google Sheet อยู่แล้ว view count (จำนวนวิว) อยู่ในโมดูลถัดไป ควรจะมาอยู่ใต้ view จากนั้นมี subscribers (ผู้ติดตาม) อยู่ในโมดูลถัดไป ควรอยู่ใต้ subscriber ชื่อช่อง (channel name) ฉันว่าอยู่ด้านล่างตรงนี้อีกครั้ง channel วันที่เผยแพร่ก็อยู่ตรงนี้ และนั่นคือทั้งหมดที่เราต้องการตอนนี้

บันทึกมัน แล้วทดสอบอย่างรวดเร็ว ตั้งให้รันหนึ่งครั้ง ลบข้อมูลแล้วกรอกใหม่ ตอนนี้มันควรจะเติมข้อมูลทั้งหมดนี้ให้เรา เราต้องคลิก allow ตรงนี้ แล้วเราก็มีรายละเอียดครบที่ต้องการ

ตอนนี้เราต้องตั้งค่าส่วนนี้ ในการตั้งค่า เราต้องตั้งค่าระบบอัตโนมัติอีกอันที่หาได้ใต้วิดีโอนี้ บันทึกอันนี้ก่อน ฉันจะเปลี่ยนชื่อเป็น demo กลับไปแล้วสลับเป็น on แล้วไปที่ scenarios จากนั้นสร้าง scenario ใหม่และอัปโหลดส่วนที่สองของระบบอัตโนมัติที่ให้ดาวน์โหลด ชื่อ part two บันทึกแล้ว

เราเริ่มต้นด้วย webhook อีกครั้ง เพิ่มใหม่ แล้วคัดลอก address กลับไปที่ webhooks แล้ววาง วางลงตรงนี้ แล้วเราจะทริกเกอร์มัน ก่อนอื่นยกเลิกการเชื่อมต่อตรงนี้ก่อน แล้วรันมัน ยังไม่รันนะ ฉันทำผิด มันต้องดึงข้อมูล response จาก Google Sheet ก่อน คลิกที่มัน แล้วมันควรจะดึงมาได้ เยี่ยม ตอนนี้เชื่อมต่อได้แล้ว

ตรงนี้เราต้องใส่ API key อีกอันจาก RapidAPI สำหรับ API ที่สร้างบทถอดความ (transcript) และคุณจะพบวิธีหา API key นี้ได้ตรงนี้เหมือนกัน ถ้ายังไม่รู้ก็ดูวิดีโอนั้น แล้วกลับมาวาง key ของคุณตรงนั้น เราต้องตั้งค่าตรงนี้ คลิก add จากนั้นเพิ่ม API key จาก Gemini AI ไปที่ส่วน AI แล้วคลิก get API key จากนั้นคลิก create API key แล้วคุณจะได้ key ของคุณ วางลงไปแล้วคลิก แล้วคุณจะได้การเชื่อมต่อนี้

ตรงนั้นคุณไม่ต้องทำอะไร แค่คลิก OK และตรงนี้เราต้องใส่ชีตของเรา ซึ่งก็คืออันนี้ ตรวจสอบให้แน่ใจว่าเป็นบัญชี Google เดียวกับ Google Sheet และสิ่งที่ต้องทำคืออย่างเดียว คือบันทึกบทสรุป (summary) บทสรุปอยู่ตรงนี้ เป็นผลลัพธ์นี้ คลิก save ตอนนี้ กด stop แล้วสลับเป็น on กลับไป ตอนนี้มันถูกเปิดใช้งานแล้ว มันน่าจะทำงาน

ถ้าฉันยกเลิกการเลือกแล้วเลือกใหม่ มันควรจะถูกเปิดใช้งาน อย่างที่เห็นมันกำลังรันอยู่ และตรงนี้ฉันดูว่ามันเวิร์กไหม โอ๊ะ API key ไม่ถูก ฉันเลือกอันนี้ ฉันว่าการทดสอบครั้งก่อนใช้ key ผิด นี่คือเหตุผลที่เราต้องทดสอบสิ่งเหล่านี้ สลับเป็น on แล้วลบทั้งหมด ลบ แล้วลองใหม่ โอเค ตอนนี้มันจะถูกเปิดใช้งานอีกครั้ง ฉันว่าคราวนี้น่าจะเวิร์ก ดูดีแล้ว

ตอนนี้บทถอดความถูกสร้างขึ้น และบทสรุปก็ถูกสร้างขึ้นจากบทถอดความของวิดีโอที่ดึงมา แล้วมันจะถูกบันทึกลง Google Sheets และจะปรากฏตรงส่วนนี้ เห็นไหมว่านี่คือบทสรุป และเมื่อตั้งค่าเสร็จ Google Sheet สำหรับการสรุปก็พร้อมใช้งาน

แน่นอนคุณสามารถปรับแต่ง prompt ได้ ถ้าอยากได้ผลลัพธ์ที่แตกต่างก็ใช้ prompt อื่นได้ และถ้าอยากใช้ AI ตัวอื่นก็แค่สลับโมดูลนี้ตรงนี้ ตอนนี้มาตรวจสอบให้แน่ใจว่ามันถูกเปิดใช้งาน แล้วฉันก็ใช้ Google Sheet นี้ได้
