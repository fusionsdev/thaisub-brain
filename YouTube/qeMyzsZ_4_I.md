## ประเด็นหลัก
- Julian Goldie อธิบายวิธีใช้ Agent OS (ระบบปฏิบัติการสำหรับเอเจนต์ AI) ให้ได้ประโยชน์สูงสุด
  ทั้งการเลือกโมเดล การติดตั้งหลายเครื่อง และการสร้าง workflow แบบกำหนดเอง
- **งานซ้ำๆ ให้เอเจนต์ทำ:** เปลี่ยนงานอย่างการอัปโหลดสินค้าเข้าพอร์ทัลซัพพลายเออร์
  ให้เป็น skill ที่มี UI สวยๆ ใน Agent OS โดยบรรยายสิ่งที่ต้องการให้ Claude แล้วให้ Claude สร้างให้
- **ให้ทีมเข้าถึงได้:** ใช้ Tailscale เพื่อให้พนักงานหรือทีมงานเชื่อมต่อเข้าเครื่อง
  ที่ติดตั้ง Agent OS ไว้จากที่ไหนก็ได้ รวมถึงมือถือ
- **ตั้งเป็น routine อัตโนมัติ:** สร้าง skill → สร้างแท็บ → ตั้งเป็น schedule รายวัน
  เช่น Hermes Muse ที่วิเคราะห์คอนเทนต์และหาคอนเทนต์ใหม่ๆ ทุกวันโดยไม่ต้องกดปุ่ม
- **ติดตั้งหลายเครื่อง:** ใช้ Tailscale เชื่อม Agent OS ระหว่างเดสก์ท็อป VPS หรือแล็ปท็อป
  สมัครบัญชี ติดตั้งบนเครื่องหลักและเครื่องอื่นๆ แล้วเปิด Tailscale เมื่อต้องการใช้
- **โมเดลที่แนะนำ:** Claude Fable 5 ดีที่สุดสำหรับการ orchestrate ทั้งระบบ
  Deepseek V4 Pro เหมาะกับงาน agentic ราคาสมเหตุสมผล GLM 5.3 ดีสำหรับงาน coding
  ส่วนใน Hermes ใช้ Deepseek V4 Flash หรือ V4 Pro ผ่าน API
- **ทดสอบโมเดลใหม่ด้วย profile แยก:** สร้าง profile ใหม่ใน Hermes สำหรับแต่ละโมเดล
  เช่น GPT-5.6 หรือ Qwen 3.8 Max เพื่อสลับใช้งานตามความต้องการ
- **Qwen 3.8 27B:** มีให้ใช้บน Ollama และ LM Studio (มีเวอร์ชัน MOX สำหรับ Mac)
  แต่ยังใหญ่เกินไปสำหรับ Mac Studio ควรใช้กับ DGX Spark หรือเครื่อง RTX
  ส่วน LM Studio จะประเมินให้ว่าฮาร์ดแวร์ของคุณรันได้หรือไม่
- **ข่าว AI:** OpenAI ลดราคาลงมากเพื่อแข่งกับ DeepSeek ส่วนใหญ่แล้ว
  ไอเดียคอนเทนต์ของ Julian มาจากคอมมูนิตี้ที่แชร์ข่าวและสิ่งที่ใช้แล้วได้ผล
- **ประหยัดค่า API:** เสียบ subscription Codex ที่มีอยู่เข้ากับ Hermes
  ใช้ได้โดยไม่ต้องจ่ายค่า API เพิ่ม เหมือนที่ Kazra Dash เพื่อนของเขาทำ
- **ทิปจาก Boris (Anthropic):** การลบ skills และไฟล์ claude.md ทิ้ง
  ทำให้ Claude ทำงานดีขึ้น (ได้ยินจากหลายแหล่ง) แต่ Julian ไม่ทำเพราะ skills
  ของเขาเฉพาะทางสำหรับ SEO มาก หากจะลอง ควรสำรองข้อมูลก่อนเสมอ

## ความเห็นสรุป
วิดีโอนี้ให้แนวทางปฏิบัติที่ชัดเจนสำหรับการใช้งาน Agent OS ในชีวิตจริง
ตั้งแต่การตั้งค่างานอัตโนมัติให้ทีมงาน ไปจนถึงการเลือกโมเดลให้เหมาะกับแต่ละงาน
จุดเด่นคือคำแนะนำแบบ step-by-step และการชี้ช่องทางประหยัดค่าใช้จ่าย
อย่างการนำ subscription เดิมมาใช้กับ Hermes หรือการทดสอบโมเดลผ่าน profile แยก
เหมาะกับคนที่เริ่มจริงจังกับ AI agents และอยากนำไปใช้งานกับธุรกิจของตัวเองครับ
