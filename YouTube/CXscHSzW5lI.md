# สรุป: How to make $15k/month from Claude and Etsy
- **ช่อง:** Ray Fu · **ความยาว:** ~0.9 นาที · **ลิงก์:** https://www.youtube.com/watch?v=CXscHSzW5lI

## ประเด็นหลัก
- สร้างธุรกิจสินค้าดิจิทัลรายได้ $15,000/เดือนบน Etsy ได้โดยไม่ต้องซื้อโฆษณา
- แกนของสูตร: พรอมต์ 3 ตัวใช้กับ Claude เรียงลำดับ
- ขั้น 1: เปิด Etsy + Claude ในเบราว์เซอร์ — ดึง 20 รายการขายดีใน niche พร้อมจุดขายเด่นและรีวิว 1 ดาว
- ขั้น 2: ป้อนข้อมูลวิจัยกลับเข้า Claude — สร้างสินค้าดิจิทัลที่แก้ complaint เหล่านั้นพอดี (Notion template / swipe file / prompt pack)
- ขั้น 3: ไม่ต้องรอทราฟฟิกค้นหาของ Etsy — ใช้ Claude เขียนสคริปต์วิดีโอสั้นจาก pain point
- ใช้ Hix AI สร้างวิดีโอ โพสต์ IG / TikTok Shop ชวนให้คอมเมนต์เพื่อรับของ
- ส่ง DM อัตโนมัติพาไปลิงก์ checkout
- รับคู่มือพร้อมพรอมต์ทั้งสามตัวโดยกดไลก์ + คอมเมนต์ "sell"

## ความเห็นสรุป
สูตรวางขั้นตอนชัดและใช้หลัก "แก้ปัญหาที่คนอื่นพลาด" ซึ่งฟังขึ้นกว่าการเดาสินค้า แต่ตัวเลขรายได้เป็นเพียง claim ของครีเอเตอร์ ควรพิจารณาเป็นแนวทางศึกษาครับ
