# สรุปภาษาไทย — Hermes Agent Threshold Release

- **เฮอร์มีส เอเจนต์ 0.22.0 "Threshold Release"** เป็นการอัปเดตใหญ่ที่รวมฟีเจอร์สำคัญหลายอย่าง: Bot Screen/Bot Mode, Local Models แบบคลิกเดียว, Connectors, Stable Release Channels, Plugins Catalog และระบบ Onboarding ใหม่
- **Bot Screen** ช่วยให้การทำงานกับ Agent เป็นแบบ Collaborative — ผู้ใช้คลิกและจัดการหน้าจอได้โดยตรง Agent เห็นสิ่งที่ผู้ใช้ทำและตอบสนองได้ทันที โดยไม่ต้องอธิบายเป็นตัวอักษร
- **Local Models** ติดตั้งและรันได้ในคลิกเดียวจากใน Desktop App รองรับการค้นหาโมเดลจาก Hugging Face ทั้งหมด เลือก Quantization ได้ และแสดงข้อมูลว่าเหมาะกับเครื่องของคุณหรือไม่
- **ChatGPT Plan Sharing** บน News Portal ให้คุณใช้ Subscription ChatGPT ของตัวเองผ่าน News Portal ได้ โดยไม่ต้องเปลี่ยน Provider และไม่เสีย Credit ของ News Portal
- **Stable Release Channel** — ค่าเริ่มต้นใหม่ อัปเดตแค่ Stable Releases แทนที่จะเป็นทุก Commit ทำให้ผู้ใช้ทั่วไปไม่ต้องกังวลกับ Commits ใหม่เป็นร้อยเป็นพัน
- **ระบบ Onboarding ใหม่** นำผู้ใช้ใหม่ผ่านการตั้งค่าชื่อ, สี, Layout, การเชื่อมต่อ Third-Party Services, การติดตั้ง MCP Connectors และพาชม Desktop App แบบ Guided Tour

** verdict:** วิดีโอนี้เป็นภาพรวมที่ยอดเยี่ยมของฟีเจอร์ใหม่ใน Hermes Agent — โดยเฉพาะ Bot Screen และ Local Models ที่ลดอุปสรรคในการเริ่มต้นใช้งาน Local AI สำหรับผู้ใช้ทั่วไปได้อย่างมาก
