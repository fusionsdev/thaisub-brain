## ประเด็นหลัก

- ปัญหาหลักของการทำ automation บน YouTube Facebook TikTok คือต้องคัดลอก prompt ทีละอันเข้า Google Flow ด้วยมือ
- ติดตั้ง Chrome extension ฟรีชื่อ AI Wali Sarkar Out Flow จากลิงก์ใน description แล้ว Load unpacked ใน developer mode
- ตั้งค่า settings: prompting speed 5, agent output prompt 4, delay 0–5 วินาที, auto-download (เช่น 720p), Auto Rename + prompt tag plus time code
- โหมด controls มี 6 แบบ: text-to-image image-to-image text-to-video frame-to-video ingredient-to-video และ agent mode
- Text-to-image: วางหลาย prompt คั่นด้วยบรรทัดว่าง แล้วกด Start Outflow เพื่อสร้างและเซฟอัตโนมัติ
- เพิ่มตัวละครใน Characters ตั้งชื่อให้ตรง prompt แล้ว Scan Characters from Flow เพื่อ character consistency
- Image-to-image / Ingredient-to-video: อัปโหลด references ตั้งชื่อชัด ใช้ Auto Pick by Name และ Add Ingredient ใน Google Flow
- Text-to-video: ตั้งเสียงตัวละครล่วงหน้า เลือกความยาว 4–10 วินาที โมเดล เช่น Omni แล้ว Start Auto Flow
- ภาพรายวันได้เครดิตไม่จำกัด แต่วิดีโอ 10 วินาทีใช้ 15 เครดิต (ฟรี ~50 เครดิต ≈ 3 คลิป/วัน) — มีทิปแพลน Google AI Pro
- ท้ายคลิปชวน subscribe / WhatsApp และคอมเมนต์ auto editing เพื่อคลิปซิงก์ voiceover + transitions ถัดไป

## ความเห็นสรุป

คลิปนี้เป็น walkthrough ใช้งานจริงของ extension ที่ครอบคลุมทั้งภาพและวิดีโอบน Google Flow โดยเน้นลดงานมือซ้ำๆ สำหรับคนทำคอนเทนต์จำนวนมาก.
จุดแข็งคือ demo ตัวละครคงที่ references อัตโนมัติ และโหมดหลายแบบในที่เดียว แต่ผู้ชมต้องทำตามขั้นตอนติดตั้งและรูปแบบ prompt ให้ครบไม่งานจะไม่รัน.
