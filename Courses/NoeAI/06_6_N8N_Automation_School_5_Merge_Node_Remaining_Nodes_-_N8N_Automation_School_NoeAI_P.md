## บทนำ

วิดีโอนี้สอนการใช้งาน Merge Node ใน n8n ซึ่งใช้รวมข้อมูลจากหลายแหล่งเข้าด้วยกัน ต่างจาก Aggregate และ Split Out ตรงที่ข้อมูลมาจากหลายจุด พร้อมตัวอย่างการใช้งานจริง เช่น การรวมข้อมูลลูกค้าเป้าหมายจาก Airtable กับ Meta Ads และยังอธิบายโหนดจัดการข้อมูลอื่นๆ ที่เหลือ เช่น Summarize, Convert to, Edit Image และ Extract from File

## คำแปลเต็ม

ยินดีต้อนรับสู่อีกวิดีโอหนึ่งครับ ในวิดีโอนี้ เราจะพูดถึง Merge Node ซึ่งเจ๋งมาก มันช่วยให้คุณต่อข้อมูลจากหลายแหล่งเข้ามา แล้วรวมสองอย่างเข้าด้วยกัน มันต่างจาก Aggregate และ Split Out เพราะว่าข้อมูลมาจากหลายแหล่ง

ผมจะโชว์ตัวอย่างให้ดู สมมติว่าผมแยกตรงนี้ออก แล้วใส่ Edit Fields Node แล้วก็ใส่อีกอันหนึ่งเป็น Edit Fields Node เหมือนกัน ผมจะวางไว้ด้านล่างตรงนี้ อันนี้เราจะทำเพื่อให้เห็นภาพ แล้วผมก็ต่ออันนี้เข้าไป อันนี้จะเป็น ID กับ In สองแหล่งข้อมูลถูกแยกเป็นสองทาง

ถ้าอยู่ในโฟลว์แบบเส้นตรง (linear) คุณจะรวมไม่ได้ เพราะสมมติว่าผมต่อมันเข้ากับ Filter ลองดูว่าเกิดอะไรขึ้น มันจะรันแล้วก็จะได้สอง items แล้วมันก็จะส่งสอง items ต่อ ซึ่งเราไม่ต้องการ เราอยากให้มันส่งอันเดียว เพราะถ้ามันส่งสองอัน มันจะรันโฟลว์สองรอบ เราไม่ต้องการแบบนั้น เราอยากให้มันรวมแล้วรันครั้งเดียว

นั่นคือที่มาของ Merge Node เรามี Merge Node ตรงนี้ เรารวม Input 1 และ Input 2 เข้าด้วยกัน แล้วดูตรงนี้ มันจะ append แล้วส่งต่อไป มันดูเหมือนว่ามีหลาย items และบาง field อาจไม่มีในแต่ละ items น่าสนใจครับ เราควรเลือกแบบ Combine แต่โดยสรุป มันก็คือโหนดที่ให้คุณรวมข้อมูลหลายชุดเข้าด้วยกัน

แล้วคุณยังทำได้มากกว่านั้น เช่นรวม field โดยการจับคู่ (by matching) เราจับคู่ด้วย field เช่น ID เอง ลองดูว่ามันเวิร์กไหม เห็นไหม? ดูสิว่ามันผ่าน Airtable มาหนึ่งร้อย items เห็นไหม? หนึ่งร้อย items พอเราทำแบบ append มันก็รวมสองชุดเป็น 200 items แต่ถ้าเราจับคู่ด้วย record ID คุณจะเห็นว่ามันจับคู่แล้วรวม view และ reach เข้าด้วยกัน มันเอา view count ขึ้นมา เอา reach ขึ้นมา แล้วรวมกันโดยอิงตาม ID นั้น

SQL Query คือคุณสามารถ query ไปยังฐานข้อมูลได้ แต่ผมไม่เคยใช้ Merge Node ในกรณีนั้น แล้วก็ Choose Branch ซึ่งผมไม่รู้ด้วยซ้ำว่ามันคืออะไร แต่คุณจะใช้แค่ Combine และ Append แล้วคุณก็เลือกหลายแหล่งข้อมูลได้ ลองดูสิ ผมไม่คิดว่ามันทำได้ แต่บางทีคุณอาจเลือกจำนวนไม่ได้ แต่คุณทำแบบ append ได้ เช่นผมรวมได้ 10 แหล่ง ดูสิ ผมรวม 10 แหล่งข้อมูลที่ต่างกัน แล้วรวมทั้งหมดเข้าด้วยกัน ซึ่งเจ๋งมาก

สรุปคือ มันให้คุณดึงข้อมูลจากหลายแหล่ง แล้วรวมทั้งหมดเป็นหนึ่ง item ที่ส่งต่อ สมมติว่าคุณดึงข้อมูลลูกค้าเป้าหมายทั้งหมดจาก Airtable หรือ GoHighLevel แล้วอยากจับคู่ด้วยชื่อจากฟอร์ม Meta Ads lead ของคุณ สองอย่างนั้นรวมเข้า Merge เดียว แล้วมันจะรวมโดยอิงตามชื่อ แล้วส่งทั้งหมดไปด้วยกัน นี่ก็เป็นอีกวิธีหนึ่งในการจัดการข้อมูล

เอาล่ะ นั่นคือทั้งหมดสำหรับโหนดพวกนี้ เพื่อประหยัดวิดีโออีกอัน ผมจะพูดถึงสองอันสุดท้ายนี้ด้วย เราผ่านมาหมดแล้ว ยังมี Summarize ซึ่งเหมือนการรวมนับ (sum count) ผมไม่เคยใช้มัน คุณไม่จำเป็นต้องใช้เพื่อสรุปข้อมูล ซึ่งน่าสนใจ ผมไม่เคยใช้มันเลย

มีโหนด Convert To ที่ให้คุณแปลงไฟล์ได้ เช่น คุณมีไฟล์ JSON เข้ามา แล้วอยากแปลงเป็น CSV หรือ RTF หรือ text คุณก็ส่งไปที่โหนดนี้ มี Edit Image ซึ่งอันนี้พื้นฐานมาก ผมไม่แนะนำให้ใช้ แต่คุณทำ blur, crop แบบนั้นได้ ถ้าสิ่งที่คุณทำซ้ำๆ บ่อยๆ มันจะเวิร์กสำหรับคุณ

มี Extract From File ถ้าคุณส่งไฟล์มา คุณก็แยกข้อมูลทั้งหมดออกมา แล้วจัดการ แล้วแปลงเป็นอย่างอื่น ถ้าคุณทำงานกับ XML ผมจะไม่พูดถึงมัน เหมือนกัน Rename เราไม่ใช้ และผมพูดถึง Code Nodes ไปแล้ว แต่ก็ไม่ใช้เหมือนกัน

เอาล่ะครับ นั่นคือทั้งหมดสำหรับโหนดจัดการข้อมูล (data transformation) ขั้นตอนต่อไปในคอร์ส n8n นี้ เราจะพูดถึง logic และ flows ลงรายละเอียดมากขึ้นเกี่ยวกับการส่งข้อมูลระหว่างทาง เจอกันในบทเรียนเหล่านั้นครับ
