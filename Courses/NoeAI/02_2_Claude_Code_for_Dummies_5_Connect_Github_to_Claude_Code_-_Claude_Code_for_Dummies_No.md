## บทนำ

บทเรียนนี้สอนวิธีเชื่อมต่อ Claude Code กับ GitHub repo เพื่อให้เราสั่ง commit และ push การเปลี่ยนแปลงไฟล์ได้ด้วยภาษาธรรมชาติ ผู้สอนให้สองวิธี: วิธีเนทีฟผ่านการตั้งค่า และวิธีแบบ janky ด้วยการวาง URL repo พร้อมโชว์ตัวอย่างจริงตั้งแต่ connect repo, commit ครั้งแรก, push จนถึงให้ Claude เขียน README และอธิบายเรื่องการ clone repo

## คำแปลเต็ม

ว่าไงครับทุกคน ในบทนี้ผมจะโชว์วิธีเชื่อมต่อ Claude Code กับ GitHub repo ของคุณ ถ้าคุณยังไม่ได้ดูวิดีโอ GitHub walkthrough plus setup ขอให้ไปดูตอนนี้เลย แต่ผมจะโชว์วิธีเชื่อมต่อ Claude Code เข้ากับ GitHub เพื่อที่เมื่อคุณแก้ไฟล์และสร้างสิ่งต่างๆ คุณก็แค่บอกว่า "อยากให้ commit และ push การเปลี่ยนแปลงเหล่านี้ขึ้น GitHub" จากบทเรียนที่แล้ว commit คือการถ่าย snapshot ส่วน push คือการบันทึก snapshot ขึ้นไปบนคลาวด์

จริงๆ แล้วมันง่ายกว่าที่คุณคิดมาก ผมจะให้สองวิธี วิธีหนึ่งเป็นแบบมั่วๆ หน่อย อีกวิธีเป็นวิธีที่ฉลาดกว่า ทั้งสองวิธีอยู่ใน Claude Desktop ถ้าคุณใช้ Claude Code ก็ทำงานเหมือนกันเป๊ะ ง่ายมาก วิธีที่ฉลาดและง่ายที่สุดคือแบบนี้ Claude Code มีการผสานรวมกับ GitHub แบบเนทีฟอยู่แล้ว คุณแค่เข้าไปในตั้งค่า แล้วจะเห็น GitHub GitHub ของผมเชื่อมต่อแล้ว ผมสามารถถอดการเชื่อมต่อได้ แต่จะไม่ทำ มันง่ายมาก แค่คลิกสิ่งที่เรียกว่าเชื่อมต่อ GitHub โดยเฉพาะ หรือเราจะทำแบบมั่วๆ ซึ่งผมทำแบบนี้อยู่แล้ว คุณไปที่ "connect to this GitHub repo" แล้ววาง URL ของ GitHub ของคุณลงไป ส่งไป นี่เป็นวิธีที่ดูจืดชืดหน่อย และนี่คือวิธีที่ผมใช้เชื่อมต่อทุก repo เลย

ก่อนทำผมอยากเริ่มเซสชันใหม่ เพื่อให้แน่ใจว่าผมอยู่ในโฟลเดอร์ที่ถูกต้อง ที่อยากให้ repo อยู่ มันสำคัญมาก เพราะถ้าคุณอยู่ผิดโฟลเดอร์ คุณจะเชื่อมต่อไม่ได้ และถ้าเผลอ push ก็จะ push ของผิดทั้งหมด ซึ่งคุณไม่อยากให้เกิดแน่นอน ผมอยู่ในโฟลเดอร์ที่ถูกต้องแล้ว ผมจะเลือกโฟลเดอร์ตัวอย่างที่เราอยู่ คลิก open แล้วพิมพ์ "connect to this GitHub" แล้วส่งออกไป

มันจะเข้าไปดู repo ของเรา แล้วก็จะถามให้คุณเชื่อมต่อ เพราะผมเชื่อมต่อแล้ว มันก็เลยบอกว่า "origin ถูกตั้งเป็น GitHub แล้ว พร้อมใช้งาน อยากให้ผม push, pull หรืออย่างอื่นไหม?" อันนี้ผมทำในอีกหน้าต่างหนึ่งเพื่อโชว์ว่าการเชื่อมต่อหน้าตาเป็นยังไง มันจะติดตั้งสิ่งที่เรียกว่า GitHub CLI ซึ่งก็คือเครื่องมือช่วยเอาของขึ้น GitHub แค่นั้น แล้วมันจะทำการยืนยันตัวตน และเมื่อเสร็จแล้วจะแจ้งว่าคุณเชื่อมต่อแล้ว ถ้ามันบอกว่าเชื่อมต่อไม่ได้ ก็แค่ขอให้มันช่วย เช็คง่ายๆ Claude Code มีการผสานรวมเนทีฟกับ GitHub อยู่แล้ว มันรู้ว่าต้องทำอะไรเพื่อเชื่อมต่อ

ผมอยากทดสอบว่า "มีอะไรอยู่ในนี้?" แล้วมันควรตอบกลับมาด้วย README และไฟล์ .gitattributes เรามาดูกันว่ามันให้อะไร มันจะเข้าไปอ่านว่ามีอะไรอยู่ใน repo นี้ และคุณกำลังเห็นขั้นแรกๆ แต่มันอ่านได้ขนาดนี้ ลองนึกภาพมันอ่านบัญชี Stripe ของคุณ อ่าน GoHighLevel ของคุณ แล้วเชื่อมสองอันเข้าด้วยกัน นึกภาพมันอ่าน Meta Ads ของคุณ คุณกำลังเห็นจุดเริ่มต้นของวิธีการทำงานของสิ่งเหล่านี้ ปล่อยให้มันทำงาน มันอ่านทุกอย่างใน repo และอ่านโฟลเดอร์ของผมด้วย มัน cross-reference ระหว่างสิ่งที่อยู่ใน repo กับสิ่งที่อยู่ในโฟลเดอร์ของผม

นี่คือไฟล์ root มี README และ .gitattributes ซึ่งเจ๋งมาก แล้วเรามีสามโฟลเดอร์หลักใน repo ของผม: personal และ school มันคือโครงสร้างโฟลเดอร์พื้นฐานสำหรับจัดระเบียบ ตอนนี้เราจะทำ commit และ push ครั้งแรกกัน ผมแค่บอกว่า "commit and push" แล้วคุณจะเห็นว่าเรายังไม่มีโฟลเดอร์พวกนั้นอยู่ คุณดูได้เลย มันจะอ่านทั้ง repo ถ่าย snapshot แล้วอัปโหลด snapshot นั้นขึ้นไป

มันบอกว่า "มีโฟลเดอร์ personal brand ที่ไม่แสดง? เดี๋ยว ข้าม .DS_Store ของ Mac OS และเพิ่มคอนเทนต์จริง Git ต้องการไฟล์ภายในโฟลเดอร์ ดังนั้นโฟลเดอร์ว่างๆ ต้องมี git placeholder ขอเพิ่ม placeholder แล้ว commit" เจ๋งมาก ผมเห็นว่ามันไม่ push โฟลเดอร์ว่าง มันจะใส่ dummy file เข้าไปเพื่อให้ทำบทเรียนนี้ได้ แล้วผมก็ให้มันทำงาน มัน commit โฟลเดอร์ให้ แล้วกำลัง push การเปลี่ยนแปลง เสร็จแล้ว push ขึ้น main แล้วปรากฏว่ามันอยู่ในโฟลเดอร์ย่อย ซึ่งมี git ของมันเอง ถ้าต้องการให้ถูกต้อง ควรเพิ่มเป็น git submodule มันถามว่าจะให้แก้ไหม หรือใช้การตั้งค่าปัจจุบัน

เรามารีเฟรชกัน แล้วเราก็ได้แล้ว มี personal และทุกอย่าง ถ้าผมไปอีกเครื่องหนึ่งและอยากได้ไฟล์เหล่านี้เป๊ะๆ ผมก็แค่เชื่อมต่อกับ GitHub นี้ แล้ว pull ไฟล์เหล่านี้มา ซึ่งเจ๋งมาก แล้วเราก็อัปเดต README ได้ เช่น ถ้าผมอยากให้มันอธิบายว่ามีอะไรในไฟล์บ้าง ผมก็พิมพ์ว่า "ช่วยเขียน README บนหน้า main ของ GitHub หน่อย ผมเห็นว่ายังไม่มีอะไรอยู่" แล้วผมจะสกรีนช็อตให้มันเห็นว่ามีอะไรอยู่ใน repo นี่สำคัญมากสำหรับคนที่กำลังทำตาม

มันจะวิเคราะห์และรู้ทันทีว่าผมพูดถึงอะไร เพราะผมให้ context ไปแล้ว แล้วมันจะเขียนคำอธิบายให้เรา มันอ่านทุกอย่างในโฟลเดอร์ทั้งหมด แล้วเขียน README ให้ "อยากให้ commit ไหม?" มันสร้าง README แล้ว เรามาดูว่าในไฟล์เรามีแล้วไหม มีแล้ว เห็นไหม ตรงนี้ personal และมี README ที่เพิ่งสร้าง ตอนนี้ผมอยาก commit และ push นี้ ผมจะเข้าไปใน Claude Code พิมพ์ "commit and push" แล้วมันก็ commit และ push ให้ มี error บ้างไม่เป็นไร ปล่อยให้มันทำงาน แล้วมันจะอัปเดต เสร็จแล้ว อันที่สองเสร็จเรียบร้อย

ดูนี่สิ school community repo นี่คือ tree ถ้าจำได้จากบทเรียนก่อน นี่คือโครงสร้างของโฟลเดอร์ personal และโฟลเดอร์ย่อยทั้งหมด วิธีใช้งาน: clone repo นี้เพื่อให้ได้โครงสร้างเต็มในเครื่อง มันบอกวิธีใช้จริงๆ คุณต้อง clone แล้ววางไฟล์ของคุณลงไป และถ้าคุณอยากนำ repo ใดๆ จาก GitHub มาใช้ คุณก็แค่... อันนี้เป็น repo ส่วนตัว ผมตั้งเป็น private เพื่อไม่ให้ใครเอา URL ไป clone ได้ แต่ถ้าอยากได้ repo สาธารณะ อย่าง get shit done repo ที่ผมทำไว้ก่อนหน้า อันนี้เป็นสาธารณะเต็มรูปแบบ เห็นไหม มัน public เราดาวน์โหลดได้ ผมมาเปิด Claude แล้วบอกว่า "clone repo นี้" แล้วให้ URL มันก็จะก็อปปี้ repo ลงในระบบไฟล์ของผม ผมจะหยุดมันไว้ เพราะไม่อยากได้ไฟล์เยอะขนาดนั้น แต่นี่คือวิธีก็อปปี้ repo นั่นคือความหมายของการ clone

แล้วมันก็อธิบายว่าอะไรควรอยู่ตรงไหน วาง invoice, tax docs, bookkeeping ไว้ตรงนี้ ฝ่ายการตลาดไว้ใน content CRM ส่วน credential ก็ใส่ password manager สำหรับข้อมูลอ่อนไหว มันอธิบายให้ฟัง นี่คือทั้งหมดสำหรับการเชื่อมต่อกับ GitHub ขอให้ทุกคนลองเชื่อมต่อ แล้วบอกผมถ้ามีคำถาม แล้วทำ commit และ push ครั้งแรก แล้วบอกผมในคอมมูนิตี้ว่าทำได้ไหม ผมอยากเห็นว่ามันทำงานได้จริง เจอกันบทเรียนหน้าครับ
