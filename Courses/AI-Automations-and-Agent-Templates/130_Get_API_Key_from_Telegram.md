## บทนำ
คลิปนี้อธิบายวิธีสร้างบอท (bot) ใหม่ใน Telegram เพื่อขอ API key หรือ access token มาใช้ในระบบอัตโนมัติ พร้อมข้อควรระวังเรื่องการไม่เปิดเผยคีย์ให้ใครเห็น และวิธีเพิกถอน (revoke) คีย์เมื่อไม่ใช้แล้ว

## คำแปลเต็ม

ตรงนี้คือ access token ของเรา แล้วจะได้มายังไง? โดยพื้นฐานก็คือคุณเข้าไปที่ Telegram พิมพ์ชื่อนี้ลงไป แล้วคลิกที่มัน จากนั้นคลิก start และตรงนี้คือที่ที่คุณจัดการบัญชี Telegram ของคุณ ทุกอย่างที่คุณใช้สร้างระบบนี้ คุณก็ทำผ่านตรงนี้แหละ จากนั้นคุณต้องคลิกที่ create a new bot เพื่อสร้างบอทตัวใหม่ แล้วก็ต้องตั้งชื่อบอทใหม่ ผมจะเรียกมันว่า my 1st AI agent จากนั้นเราต้องเลือก username และมันต้องอยู่ในรูปแบบนี้ ผมจะตั้งเป็น my 1st AI agent จะเว้นวรรคระหว่างคำก็ได้ เห็นไหมว่ามันไม่ได้... มันต้องลงท้ายด้วยคำว่า bot ต้องลงท้ายด้วย bot เสมอ ดี จากนั้นตอนนี้คุณก็จะได้ API key ของผมมา ไม่อยากให้คุณเอานี่ไปโชว์ใครนะ ผมจะลบคีย์นี้ทิ้งและเพิกถอน (revoke) คีย์ทีหลัง โดยวิธีทำก็แค่พิมพ์คำสั่งเข้าไป แล้วคุณก็สามารถปิดการใช้งาน API key ของคุณได้ ผมจะไม่โชว์มันให้ใครเห็น ก่อนที่ผมจะอัปโหลดวิดีโอนี้ ผมจะลบมันทิ้งก่อน แต่ตอนนี้ผมมีคีย์ที่ใช้สำหรับระบบนี้แล้ว มาคลิก save ตรงนี้กัน และเมื่อทำเสร็จ...
