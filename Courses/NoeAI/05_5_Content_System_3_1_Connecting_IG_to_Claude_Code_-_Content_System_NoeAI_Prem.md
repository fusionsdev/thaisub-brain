## บทนำ

วิดีโอนี้สอนวิธีเชื่อมต่อ Instagram เข้ากับ Claude Code ผ่าน Meta Developer App และ Meta Business Suite — เริ่มจากดาวน์โหลดไฟล์เทมเพลตจากคอมมูนิตี้ NoeAI ใส่ลงใน Claude Code แล้วกรอกค่าสามอย่างในไฟล์ .env ได้แก่ Meta App ID, Meta App Secret และ Meta Access Token จากนั้นสร้าง System User ใน Meta Business Suite มอบสิทธิ์แอปและเพจ สร้าง token แล้วทดสอบว่าการเชื่อมต่อสำเร็จ — Claude Code จะดึงโพสต์ Instagram 5 อันล่าสุดกลับมาได้

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่บทเรียนการเชื่อมต่อ Instagram เข้ากับ Claude Code ในบทนี้ผมจะโชว์วิธีเชื่อมต่อ Instagram ของคุณกับ Claude Code เพื่อที่เราจะเริ่มวิเคราะห์คอนเทนต์ของคุณ และทำทุกอย่างที่เราต้องการภายใน Instagram ได้

ถ้าคุณยังไม่ได้ดูบทเรียนก่อนหน้า เราสร้างแอปไปแล้ว — คุณต้องมี Meta Developer App เพื่อทำสิ่งนี้ แต่เมื่อคุณสร้าง Meta Developer App เสร็จแล้ว มันก็ใช้ได้เลย มีอย่างหนึ่งที่ผมลืมบอกไป: คุณต้องแน่ใจว่าได้เลือก Instagram Graph API และ Facebook Login ไว้ แล้วแค่กด Set Up มันก็ตั้งค่าให้ทันที หลังจากนั้นก็พร้อมใช้งาน

ต่อไปสิ่งที่เราต้องทำคือ มาดาวน์โหลดไฟล์ที่ผมให้ไว้ ซึ่งข้างในจะมีโฟลเดอร์บทเรียน Claude และเทมเพลตทรัพยากร (resources template) จากนั้นเราจะไปที่ Claude Code ผมจะเริ่มเซสชันใหม่ แล้วก็ลากโฟลเดอร์นี้ลงไปในนั้น ทิ้งลงไป แล้วเราจะทำงานภายในนั้น คุณจะเข้าถึงทุกอย่างในนั้นได้

สิ่งที่เราอยากทำคือพรอมป์ตมันประมาณว่า "ผมเพิ่งดาวน์โหลดอันนี้จากคอมมูนิตี้ NoeAI เราจะเชื่อมต่อ Instagram ของผมเข้ากับบัญชี Claude Code ของผมยังไง? ช่วยอ่านไฟล์เหล่านี้หน่อย" อะไรประมาณนั้น ง่ายๆ แล้วมันจะทำงาน — ผมให้ไฟล์ Claude lesson แบบย่อๆ ไว้ ซึ่งมันไม่ได้เปิดเป็นไฟล์ข้อความ ซึ่งแย่หน่อย แต่มันก็คือบทสรุปบทเรียนสำหรับ Claude Code เพื่อให้มันรู้ว่าเรากำลังทำอะไรอยู่ ทำให้ชีวิตคุณง่ายขึ้นมาก

เราจะปล่อยให้มันทำงานไปก่อน ระหว่างนี้คุณต้องเปิด Meta Business Suite ไว้ และต้องไปที่หน้า System และเราจะต้องใช้แอปด้วย ดูสิ มันบอกว่า "บทเรียนนี้เชื่อมต่อบัญชี Instagram ของคุณกับ Claude Code ดังนั้นสร้างไฟล์ .env ของคุณ คุณต้องมีค่า 3 ค่าสำหรับ Meta จะเอามาจากไหน?" เจ๋ง เราต้องหาค่าสามค่านี้: Meta App ID, Meta App Secret และ Meta Access Token

ถ้าคุณยังไม่ได้สร้าง System User นี่คือวิธีสั้นๆ เอาล่ะ สิ่งที่ผมอยากทำคือเราต้องการไฟล์ .env ซึ่งผมจะขอให้ Claude เปิด — มันอยู่ในโฟลเดอร์ของคุณแล้ว คุณสามารถคลิกที่ ENV template ได้เลย แต่ผมจะขอให้ Claude "ช่วยเปิดไฟล์ .env ให้หน่อย เพื่อที่ผมจะได้ใส่ข้อมูลลงไป" ผมจะย้ายมันออกจากหน้าจอ เผื่อมีคีย์หลุดออกมา สำคัญมากที่คุณต้องรู้ว่าไฟล์ .env นี้เก็บ API keys ทั้งหมดของคุณ ทุกอย่างของคุณจริงๆ ดังนั้นห้ามเปิดเผยมันเด็ดขาด

ปล่อยให้มันเปิดไฟล์ขึ้นมา แล้วคุณจะเห็นหน้าตาประมาณนี้ มันมี Meta App ID, Meta App Secret และ Meta Access Token เราจะเติมค่าทั้งสามลงไป เห็นมั้ยว่ามันมีตัว placeholder ตัวอย่างไว้ แล้วผมจะพาคุณไปดูวิธีหาข้อมูลเหล่านี้ และคุณไม่ต้องใช้ User Login — Claude Code จะจัดการให้เอง

เราจะไปที่แอปของเรา ภายในแอปไปที่ Settings แล้วไปที่ Basic สิ่งที่คุณต้องใช้คือ App ID ก็อปปี้มันมา กลับมาที่นี่ วางลงไป แล้วกด Command+S เพื่อบันทึก จากนั้นกด Show บน secret แล้วก็อปปี้วางค่าลงไป ผมจะทำนอกจอหน่อยนะ และเมื่อคุณกด copy secret แล้ววางลงไป มันจะได้ค่าแบบนั้น — ไม่ใช่ secret จริง นี่คือตัวอย่าง ผมจะใส่ dummy ไว้ก่อน

ต่อไปเราต้องหา Meta Access Token — หาได้จาก System User ยังไง? ไปที่ Meta Business Suite ถ้าคุณอยู่ที่หน้าแรก ให้ไปที่ Settings แล้วไปที่ System Users — สำคัญมาก — ผมมี system user อยู่ 2 คนแล้ว สร้างใหม่ไม่ได้ ซึ่งแย่หน่อย แต่สำหรับคุณมันง่ายมาก สิ่งที่ต้องทำคือคลิกสร้าง ตั้งชื่อมัน เช่น "Claude" เพื่อให้รู้ว่ามันคืออะไร ให้สิทธิ์ Admin แล้วคลิก Create System User มันไม่ให้ผมสร้าง แต่พอคุณมี system user แล้ว สิ่งที่ต้องทำคือไปที่ Assign Assets เพื่อมอบสิทธิ์ให้กับ system user

ผมคลิกตรงนี้แล้วทุกอย่างถูกมอบไปแล้ว แต่คุณก็แค่เลือก หรือจะจำกัดสิทธิ์เฉพาะบางอย่างก็ได้ ผมจะให้มันเข้าถึงแอปโฆษณา และให้สิทธิ์เต็มกับแอป — แอปที่เราสร้างไว้ (Manage App) และถ้าเรามี เราก็ต้อง Assign Instagram และข้อมูลต่างๆ ด้วย จากนั้นคลิก Assign Assets พอ Assets ถูกมอบให้ system user แล้ว Claude Code ก็จะได้รับสิทธิ์เข้าถึงสิ่งเหล่านี้

แต่สิ่งที่ต้องทำต่อไป — สำคัญมาก — คือการ Generate Token คุณจะเลือกแอปที่คุณสร้างไว้ก่อนหน้านี้ เราสร้างแอปของคอมมูนิตี้คอร์สไว้ ก็เข้ามาคลิก แล้วคุณเลือกระยะเวลาหมดอายุหรือ Never ก็ได้ ผมแนะนำให้ตั้ง 60 วัน แล้วหมุน token เป็นระยะ เผื่อมีอะไรหลุด ซึ่งผมจะต้องลบ token นี้ทันทีหลังวิดีโอ เพื่อไม่ให้หลุด

จากนั้นเลือก permissions — เลือกทั้งหมดที่มีให้คุณ ทุกอย่างที่คุณเข้าถึงได้ ตอนเราสร้างแอป ถ้ายังไม่ได้ดูก็ไปดูได้เลย เราเลือกทุกอย่างไว้แล้ว ซึ่งเยี่ยมมาก — คุณจะจัดการคอนเทนต์ โพสต์ ดึงข้อมูล ฯลฯ ได้ทั้งหมด พอเลือกครบแล้วก็กดสร้าง แล้วคุณจะได้ token ขึ้นมา ซึ่งแน่นอนว่า token จริงยาวกว่านี้มาก ประมาณ 40 ตัวอักษร ผมจะก็อปปี้มัน แล้วกลับมาวางลงในช่อง system user ในไฟล์ .env ผมจะหยุดวิดีโอแป๊บนะ

โอเค ผมวาง App ID และ Access Token ลงใน placeholder ที่โชว์ให้ดูแล้ว แค่กด Command+S เพื่อบันทึก แล้วกลับไปที่ Claude Code ตอนนี้เราอยู่ใน Claude Code แล้ว ผมบันทึก token ทั้งหมดแล้ว "อย่าเปิดเผย token ใดๆ เพราะผมกำลังอัดวิดีโอ แต่ช่วยทดสอบหน่อยว่าเราเชื่อมต่อกับบัญชี Instagram ของผมแล้วหรือยัง" ปล่อยให้เจ้านี่ทำงาน

มันจะอ่านไฟล์ .env แล้วดึงค่าต่างๆ จากนั้นมันจะทำสิ่งที่เรียกว่า HTTP request เห็นมั้ย? ดูสิ มันรันอยู่ — ดูเหมือนมันได้สิทธิ์ทั้งหมดแล้ว "token ใช้ได้ เยี่ยม ทีนี้มาหา user ID ของคุณ" สิ่งที่มันทำคือ HTTP request สำเร็จ ตอนนี้มันกำลังหา Instagram ID ของผม แล้วมันจะเติม user ID นั้นลงในไฟล์ .env ที่เราสร้างไว้ ดูสิ มันเจอแล้ว — เจอบัญชี Instagram ธุรกิจของผม เจ้านี่โคตรเจ๋ง เราจะกด Allow ไปเรื่อยๆ แล้วมันก็ทำงานต่อไปเรื่อยๆ

บูม — "คุณเชื่อมต่อเรียบร้อยแล้ว นี่คือสิ่งที่ได้กลับมาจากโพสต์ Instagram 5 อันล่าสุด" เยี่ยม มันดึงโพสต์ Instagram ล่าสุดของผมมา "Token ถูกตรวจสอบแล้ว เจอเพจ Instagram แล้ว .env ของคุณตั้งค่าสมบูรณ์ พร้อมสำหรับบทเรียนถัดไป"

นั่นคือทั้งหมดสำหรับวิดีโอนี้ ตอนนี้เราเชื่อมต่อกับ Instagram ของผมแล้ว และมันพิสูจน์ได้จริง — มันดึงโพสต์ Instagram 5 อันล่าสุดของผมมา ดังนั้นตอนนี้คุณสามารถทำอะไรก็ได้ภายใน Instagram ซึ่งเจ๋งมาก และต่อไปจากนี้ เพราะเราเชื่อมต่อเสร็จแล้ว เราจะเริ่มสร้างระบบข้อมูลของคุณ เจอกันบทเรียนหน้าครับ
