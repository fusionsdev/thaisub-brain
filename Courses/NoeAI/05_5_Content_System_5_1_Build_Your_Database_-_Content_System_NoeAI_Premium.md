## คำแปลเต็ม

ยินดีต้อนรับสู่บทเรียน Build Your Database นะครับ ในบทเรียนนี้ เราจะได้เริ่มสร้าง content database ของเรากันใน Supabase ครับ ตื่นเต้นมากกับบทเรียนนี้ บทเรียนที่แล้ว เราได้สร้าง Supabase และเชื่อมต่อมันกับ Claude Code เรียบร้อยแล้ว ดังนั้นเราพร้อมลุยได้เลยครับ ถ้าคุณยังไม่ได้ดูบทเรียนการตั้งค่า Supabase ก็ไปดูกันก่อนได้นะครับ

แต่ตอนนี้ ให้คลิกปุ่มดาวน์โหลดและดาวน์โหลดไฟล์มา แล้วสิ่งที่เราจะทำต่อไปคือ พอได้ไฟล์มาแล้ว เราก็แค่เปิดเจ้านี่ขึ้นมา แล้วจากนั้นเราจะดึง Mr. Claude Code มาตรงนี้ แล้วเริ่ม session ใหม่กันครับ โอเค สิ่งที่เราจะทำคือลากไฟล์นี้ แล้วปล่อยลงไป เอานั่นไม่ใช่ที่ที่ต้องการนะ เราจะลากอันนี้ลงไป แล้ววางไฟล์ลงไป ตอนนี้มันยืนยันแล้ว เอาล่ะ เรามาสร้าง database กันเลย รันมันได้เลย ช่วยผมตั้งค่านี้หน่อย ช่วยผมตั้งค่านี้หน่อย เยี่ยม Trust this workspace แล้วก็พร้อมลุยแล้วครับ เรียบร้อย

ตอนนี้เรากำลังเริ่มทำงานกันแล้ว มันจะอ่านไฟล์ Claude MD ต่าง ๆ โดยพื้นฐานแล้ว เราจะสร้างตารางสามตารางด้วยกัน และผมจะอธิบายว่าทำไมเราถึงต้องสร้างแต่ละตาราง แต่นี่คือการเตรียมพร้อมให้เราสามารถดึง metrics ของ Instagram ทั้งหมดที่ถูกต้องออกมาได้

ผมเคยสร้างอะไรแบบนี้ใน Airtable ซึ่งคุณจะเห็นว่าผมมีทุก metrics ทุกชิ้นของคอนเทนต์ที่ผมเคยโพสต์ในชีวิตเลย ซึ่งผมได้ให้ทุกแถวและทุกอย่างกับคุณแล้ว เพื่อที่คุณจะได้ดาวน์โหลดและสร้างมันได้ทันที เราจะปล่อยให้ Claude Code ทำงานไปก่อน เรียบร้อย ผมได้ SQL มาแล้ว แต่ดูเหมือนคุณยังไม่มี MCP server นั่นก็เพราะว่าผมเชื่อมต่อไว้ในบทเรียนที่แล้ว ซึ่งนั่นคือเหตุผลที่เราทำแบบนี้พอดี

ผมจะวางไฟล์นี้ลงไป ผมจะวางคู่มือการตั้งค่า Supabase ของผมไว้ตรงนี้ นี่คือตัวอย่างสิ่งที่คุณจะเห็นบ่อย ๆ แต่มันอาจจะดูยุ่งเหยิงได้มาก โฟลเดอร์ที่ผมให้คุณไว้ก็เพื่อพาคุณดูทีละขั้นตอนนั่นแหละครับ คุณต้องแน่ใจว่าคุณวางทุกอย่างไว้แบบ global บนคอมพิวเตอร์ของคุณ สำหรับผม ผมแค่ทำลงในโฟลเดอร์ในเครื่องเพื่อโชว์ให้ดูในท้องถิ่น ในไฟล์เฉพาะไฟล์หนึ่ง แต่พอคุณตั้งค่ามันบนคอมพิวเตอร์ของคุณแล้ว คุณจะสามารถอ้างอิงมันได้ทุกเมื่อที่ต้องการ โอเค ดังนั้นสิ่งที่ผมจะทำคือ นี่คือไฟล์ ENV จากบทเรียน 1.4 ขอให้อ่านไฟล์นี้แล้วใช้มัน แล้วเรามาสร้าง MCP server กัน และก็แค่นั้นแหละ ไปเลย บูม

เราจะปล่อยให้มันทำงาน ดูเหมือนมันกำลังรันอยู่ตอนนี้ ตามที่ตั้งไว้ มันจะไม่ไปแก้การตั้งค่า global ของผม เพราะผมตั้งค่าแบบนั้นไว้ คุณควรแก้ไฟล์ของคุณให้เป็นแบบ global เพื่อให้มันอยู่บนเครื่องของคุณ และคุณไม่ต้องคอยสั่งให้มันใช้โฟลเดอร์ใดโฟลเดอร์หนึ่งซ้ำแล้วซ้ำเล่า ดูเหมือนมันติดตั้ง extension อะไรบางอย่าง แล้วก็เปิดใช้งานมันเรียบร้อย แล้วสคริปต์ก็รันสำเร็จ และตอนนี้ทุกอย่างก็ทำงานแล้ว นี่คือสิ่งที่คุณมีตอนนี้ในโปรเจกต์ Supabase ของคุณ ดูเหมือนมัน query ฐานข้อมูลแล้ว งั้นเราไปดูกันตรงนี้เลย บูม

ดูนี่สิ ผมไปที่ Table Editor ตรงนี้ใน Supabase และเรามีตารางสี่ตารางด้วยกัน ดูนี่สิ เรามี account stats นี่คือเหมือนกับ snapshot ของผู้ติดตาม นี่คือ flow ที่เราจะสร้างและรันทุกวัน โดยเราจะถ่าย snapshot ของบัญชีเรา เพื่อดูว่าเรามีผู้ติดตามกี่คน โพสต์ไปกี่โพสต์ ค่าเฉลี่ยการดูและเวลาในการรับชมรวมเป็นเท่าไร เป็นต้น

แล้วเราก็มี content table ซึ่งมีข้อมูลทุกอย่างบนโลกที่เราดึงได้จาก Meta Graph API เลยครับ แล้วเราก็มี content snapshots คอนเทนต์พวกนี้จะถูกอัปเดตทุกวัน นี่คือที่ที่คอนเทนต์ทั้งหมดของเราอยู่ แล้วก็ metrics ที่จะอัปเดตทุกวัน

สำหรับ content snapshot เราจะถ่าย snapshot ของคอนเทนต์หนึ่งชิ้นทุกวัน ตัวอย่างเช่น คุณโพสต์วิดีโอแล้วมันมียอดดูหนึ่งพันครั้ง ใช่ไหมครับ เราจะบันทึกไว้ แล้ววันถัดไปวิดีโอเดียวกันนี้อาจจะมียอดดูมากขึ้น มันก็จะถ่าย snapshot ไปเรื่อย ๆ แบบนั้น แล้วเราจะสามารถติดตามยอดได้จริง ๆ ว่าบัญชีของคุณโตเร็วแค่ไหน ยอดดูเป็นเท่าไร แต่ที่สำคัญกว่านั้นคือคอนเทนต์ชิ้นไหนกำลังปังอยู่ ซึ่งคุณจะได้สร้างคอนเทนต์แบบนั้นเพิ่มขึ้นเรื่อย ๆ ซึ่งเจ๋งมากครับ

จริง ๆ แล้วมันก็ง่ายมาก มันสร้างมันให้เราเลย ผมให้คุณไปแล้ว ใช่ไหมครับ ผมหวังว่าจะทำให้มันซับซ้อนกว่านี้ได้หน่อย แต่ถ้าคุณอยากแก้ไข คุณก็แค่สั่งมันได้เลย เช่น สมมติว่าเรื่องคอนเทนต์ ผมอยากเพิ่มอะไรสักอย่าง อย่างเช่น ขอแค่โชว์ให้ดูว่าคุณช่วยแก้ content table และเพิ่มคอลัมน์ใหม่ชื่อว่า test column ได้ไหม ขอหน่อยนะ ผมไม่เอาแบบ test เอาแบบที่ดูเหมือนมนุษย์หน่อย เรียบร้อย ตอนนี้มันจะรัน SQL ดูสิครับ แล้วมันจะส่ง post request เล็ก ๆ ไป แล้วเสร็จแล้ว คอลัมน์ test ถูกเพิ่มเข้าไปใน content ของคุณแล้ว ตรวจสอบได้เลย เยี่ยม เราจะรีเฟรช และเราน่าจะเห็นมันตอนท้าย ดูสิครับ มันเพิ่มให้เรียบร้อยแล้ว ซึ่งเจ๋งมาก

ถ้าผมอยากลบมัน ผมก็แค่บอกว่าลบให้หน่อยได้ไหม มันก็จะทำแบบเดียวกัน รันมัน เรียบร้อย สคีมากลับมาแล้ว พร้อมสำหรับบทเรียนต่อไปเมื่อไหร่ก็ได้ เยี่ยม เราไปดูกัน เรียบร้อย เห็นไหมครับ มันไม่อยู่แล้ว คุณสามารถแก้ไขตารางทั้งหมดของคุณได้โดยตรงใน Claude ซึ่งเจ๋งมาก คุณจะไม่ต้องเข้าไปแก้อะไรด้วยตัวเองอีกเลย โอเค นั่นคือทั้งหมดสำหรับบทเรียนนี้ครับ ตอนนี้คุณมี database ที่สมบูรณ์พร้อมแล้วสำหรับให้เราเริ่มใส่ข้อมูลเข้าไป เจอกันบทเรียนหน้านะครับ
