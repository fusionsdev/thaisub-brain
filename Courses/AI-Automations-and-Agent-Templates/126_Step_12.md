## บทนำ
วิดีโอนี้สอนวิธีตั้งค่าเบอร์โทรศัพท์สำหรับ voice agent ผ่าน Twilio ตั้งแต่การสมัครบัญชีทดลอง ปล่อยหมายเลขทดสอบ ซื้อหมายเลขจริง การยืนยันตัวตนทางธุรกิจ (business verification) การอัปโหลดเอกสาร และนำค่า credentials ไปใส่ในระบบเพื่อเชื่อมต่อ voice agent ให้โทรเข้าจริงได้

## คำแปลเต็ม
ตอนนี้เราจะตั้งค่าเบอร์โทรศัพท์ โดยเลือกจาก Twilio และตรงนี้เราต้องมีบัญชีของแพลตฟอร์มที่ชื่อว่า Twilio คุณสามารถสมัครทดลองใช้บัญชี Twilio ฟรีได้ เมื่อสมัครเสร็จแล้วคุณจะไปที่ dashboard แล้วไปที่ active numbers จะมีหมายเลขทดสอบที่เขาให้ไว้สำหรับการทดสอบ แต่มันทำงานไม่ค่อยดีสำหรับ voice agent ตัวนี้ เพราะฉะนั้นคุณต้องซื้อหมายเลขของตัวเอง

แต่ในโหมดทดลอง คุณมีหมายเลข active ได้เพียงหนึ่งหมายเลขเท่านั้น ดังนั้นให้คลิก release หมายเลขทดสอบ และเมื่อปล่อยแล้ว ไม่มีหมายเลขแสดงอีก คุณก็สามารถคลิก buy a number ได้

ก่อนซื้อหมายเลขมีขั้นตอนที่ต้องทำหลายขั้นตอน ขั้นแรกคือต้องเลือก country code และสถานที่เฉพาะ อย่างน้อยในกรณีของผม ผมซื้อได้เฉพาะหมายเลขเยอรมันตามข้อมูลที่อยู่และรหัสพื้นที่ของผม พิมพ์ชื่อประเทศ ลองอีกครั้ง พิมพ์ชื่อประเทศ จากนั้นต้องพิมพ์รหัสพื้นที่ของเมืองของผม ตัวอย่างเช่น นี่คือเมืองข้างเคียง แล้วผมก็คลิกซื้อได้

คุณต้องตรวจสอบว่านี่คือเมืองของคุณหรือไม่ แล้วคลิก จากนั้นผมเลือก business จากนั้นต้อง assign approved bundle ซึ่งก็คือ Twilio ต้องการให้คุณยืนยันหรือส่งหลักฐานว่าคุณเป็นธุรกิจที่ถูกต้องตามกฎหมาย เพราะพวกเขาอนุญาตให้คุณจัดการสายโทรศัพท์ พวกเขาไม่อยากให้คนที่ไม่ถูกต้องตามกฎหมายมาใช้บริการ เพราะอาจทำสิ่งที่ไม่ดี นั่นคือเหตุผลที่พวกเขาอนุญาตเฉพาะคนที่มีธุรกิจจดทะเบียนที่ถูกต้องบนแพลตฟอร์มเท่านั้น

นั่นคือข้อกำหนดเดียวที่คุณต้องมี คุณต้องพิมพ์ชื่อธุรกิจ ประเทศ ที่อยู่ จากนั้นอัปโหลดเอกสารสองฉบับ ปกติแล้วพวกเขาให้คุณเลือกเฉพาะสารสกัดจากทะเบียนพาณิชย์ (commercial register) แต่ผมไม่มีจริงๆ ผมเลยอัปโหลดบัตรประชาชนหรือพาสปอร์ตของผม ถ่ายรูปด้านหน้าและด้านหลังของพาสปอร์ตหรือบัตรประชาชน แล้วแนบตรงนี้ได้ แค่นั้นก็พอ

ตรงนี้ผมเลือก trade license เพราะผมต้องจดทะเบียนธุรกิจในท้องถิ่น และเขาให้เอกสาร trade license มา ผมแค่ถ่ายรูปแล้วอัปโหลดตรงนี้ แล้วคลิก continue ผมทำขั้นตอนนี้ไปแล้ว และทำซ้ำไม่ได้อีก เมื่อส่งแล้ว มันจะเข้าสู่กระบวนการอนุมัติ มีคนตรวจสอบว่าเอกสารถูกต้องหรือไม่ และเมื่อผ่าน มันใช้เวลาไม่กี่นาทีหรือไม่กี่ชั่วโมงก็จะได้รับการอนุมัติ

จากนั้นคุณสามารถเลือก bundle นี้ในขั้นตอนการซื้อหมายเลขของคุณ และคุณต้องยืนยันโดยกำหนดที่อยู่ตรงนี้ด้วย เมื่อทำครบสองอย่างนี้แล้ว คุณคลิก buy the number แล้วคุณจะซื้อหมายเลขได้ในราคา $1.15 ต่อเดือน เมื่อซื้อเสร็จ หมายเลขนี้จะแสดงขึ้นมาตรงนี้ภายใต้ active numbers ของคุณ จากนั้นคลิก และนั่นคือสิ่งที่เราต้องการตอนนี้

ตอนนี้ผมจะ copy ส่วนนี้ ซึ่งเป็น country code ของเยอรมนี ต้องการแค่นี้ ผมต้องการแค่ส่วนนี้ จากนั้นกลับไปที่ระบบของผม และตรงนี้ต้องวางค่านี้ ผมต้องเลือก จากนั้นตั้งชื่อให้มัน แล้วต้องใส่ account SID โดยไปที่ account management ต้องยืนยันตัวตนอีกครั้ง บางครั้งมันไม่เกิดขึ้นทุกครั้ง และตรงนั้นคุณจะเห็น account SID ของคุณ ผม copy แล้ววางตรงนี้ แล้วมันจะโหลดฟิลด์นี้

จากนั้นต้องใส่ Twilio authentication token ผมหาได้ตรงนี้เมื่อไปที่ API keys and tokens คลิกที่ primary และนี่คือสิ่งที่ต้องใช้ copy วาง แล้วคลิก จากนั้นมันจะนำเข้าหมายเลข และผมสามารถเลือก voice agent ที่ต้องการผูกกับหมายเลขนี้ ตอนนี้มันเชื่อมต่อแล้ว

และตอนนี้ผมโทรได้เลย พิมพ์เบอร์ในโทรศัพท์ แล้วโทรออก "ยินดีต้อนรับสู่ Zen Touch Massage and Spa ผมอยู่ที่นี่เพื่อช่วยคุณจองเซสชันผ่อนคลายที่สมบูรณ์แบบ ขอถามคำถามสั้นๆ สองสามข้อเพื่อหาบริการที่เหมาะกับคุณได้ไหม?" และคุณเห็นไหม มันเชื่อมต่อแล้วและทำงานได้ และด้วยสิ่งนี้ เราก็ทำการตั้งค่าส่วนนี้เสร็จสมบูรณ์
