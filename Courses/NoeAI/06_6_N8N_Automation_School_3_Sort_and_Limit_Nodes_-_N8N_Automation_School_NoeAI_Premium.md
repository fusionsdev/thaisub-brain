## บทนำ

บทเรียนนี้อธิบายการใช้ Limit node และ Sort node ใน n8n เพื่อควบคุมจำนวนข้อมูลและเรียงลำดับข้อมูลก่อนส่งต่อไปยังขั้นตอนถัดไป ตัวอย่างใช้ข้อมูล Instagram reels จำนวน 100 รายการ แล้วเรียงตามยอดเข้าชมเพื่อเลือก 10 hooks ที่มีผลงานดีที่สุดครับ

## คำแปลเต็ม

ยินดีต้อนรับสู่วิดีโออีกบทหนึ่งครับ วิดีโอนี้เราจะพูดถึง Limit node ซึ่งเป็น node ที่ค่อนข้างน่าสนใจ เพราะมันใช้จำกัดปริมาณข้อมูลที่ไหลผ่านเข้ามา

ตัวอย่างคือ เราจะดึงข้อมูลเพิ่มและดึงข้อมูลให้ได้จำนวนมากขึ้น ลองดูว่าเราจะดึง records ทั้งหมดของผมออกมาได้ไหม และเราจะปิด Limit ไว้ก่อนครับ

ดีครับ เราจะดึงข้อมูล 100 รายการจาก Instagram reels แล้วทดสอบดู จะเห็นว่าเราได้มา 100 รายการ ทีนี้เราต้องจัดข้อมูลใน Edit Fields node ก่อน ผมต้องการส่งต่อ ID, view count, reach count, like count และ comments

นอกจากนี้ผมอยากรู้ว่ารายการนี้โพสต์เมื่อไร hook คืออะไร และ created time ด้วย ดังนั้นเราจะส่งข้อมูลทั้งหมดนี้ต่อไปครับ ส่วน Filter node เราจะใส่ในภายหลัง ตอนนี้เรามี 100 items เห็นไหมครับ

ถ้าผมต้องการส่งต่อเพียงจำนวนรายการที่กำหนด ผมก็ใช้ Limit ได้เลย ต่อ node นี้เข้าไป ขั้นตอนง่ายมากครับ ผมตั้งค่า Max ว่าต้องการส่งต่อเพียง 10 รายการ

จากนั้น node จะส่งรายการชุดแรกหรือชุดสุดท้ายตามตัวเลือกที่กำหนด ในตัวอย่างนี้ผมเลือก First แล้วกด Execute เท่านี้ก็ส่งต่อมาเพียง 10 รายการจริงๆ ครับ

สิ่งที่ผมจะเพิ่มให้เห็นในบทเรียนนี้คือ node ถัดไปที่เราสามารถใช้ร่วมกันได้ นั่นคือ Sort node คุณจะเห็นด้านล่างว่า node นี้ใช้จัดเรียงข้อมูลให้เรา ที่สำคัญคือ Limit กับ Sort ทำงานร่วมกันได้ดีครับ

สมมติว่าผมดึง reels 100 รายการจากฐานข้อมูล แต่ต้องการส่งต่อเฉพาะ 10 อันดับแรก เพราะอยากรู้ hooks ที่ดีที่สุด 10 อันดับ ผมก็เข้ามาลบข้อมูลอื่นๆ ออก แล้วส่งต่อแค่ view count กับ spoken hook จากนั้นต่อเข้ากับ Sort node

Sort จะจัดระเบียบข้อมูลตามลำดับจากน้อยไปมาก หรือจากมากไปน้อย คุณยังสามารถใช้การเรียงแบบสุ่มได้ด้วย ซึ่งค่อนข้างดี แต่สำหรับตัวอย่างง่ายๆ นี้ เราจะเลือก ascending หรือ descending ครับ

ผมจะเลือก field name เป็น views แล้วตั้งให้เรียงตาม views แบบ ascending หรือ descending ตอนแรกผมเลือกผิดนิดหน่อย [ฟังไม่ชัด] เดี๋ยวแก้ให้ถูกต้อง เราจะเลือก field นี้ แล้วตั้งเป็น descending

เห็นไหมครับว่าค่านี้ตรงกับ field ในข้อมูล ดังนั้นระบบจึงรู้ว่าจะดึงข้อมูลจาก field นี้ เราจะใช้ descending ซึ่งหมายถึงเรียงจากบนลงล่าง หรือจากตัวเลขที่มากที่สุดไปหาตัวเลขที่น้อยที่สุด

ถ้าเลือก ascending ก็จะเรียงจากตัวเลขที่น้อยที่สุดไปหาตัวเลขที่มากที่สุด แต่ผมต้องการดึง 10 hooks ที่มียอดเข้าชมสูงสุด จึงกดตัวเลือกนี้ครับ

ดูนี่ครับ ข้อมูลถูกเรียงตาม view count แบบ descending แล้ว วิดีโอหนึ่งของผมเกือบถึงหนึ่งล้าน views ซึ่งถือว่าเยอะมากครับ และจะเห็นว่าข้อมูลถูกจัดเรียงลงมาตามลำดับ

ถ้าต้องการสลับลำดับ ผมก็เปลี่ยนค่าได้ ผมจะ pin ไว้ก่อนเพื่อไม่ให้ระบบเรียก API ซ้ำเรื่อยๆ เห็นไหมครับ พอสลับแล้วข้อมูลก็เปลี่ยนลำดับ เป็นขั้นตอนที่ค่อนข้างง่าย

ผมต้องการให้เรียงแบบ descending แล้วส่งต่อไปยัง Limit node ทีนี้เรามี records ทั้ง 100 รายการที่เรียงจากมากไปน้อยแล้ว จากนั้นผมจะบอกว่าให้ส่งรายการแรกๆ และเอาแค่ 10 อันดับแรก

พอกด Execute ระบบก็จะประมวลผล และส่งมาให้เราเฉพาะรายการที่กำหนด เห็นไหมครับ มันตัดข้อมูลไว้ที่ 10 อันดับแรกพอดี สองรายการท้ายอาจไม่มี spoken hook ผมคิดว่ามันอาจเป็นข้อมูลที่ไม่มีค่า hook หรือ [ฟังไม่ชัด] แต่ระบบก็ยังส่ง 10 อันดับแรกมาให้ครับ

ทั้งหมดนี้คือโมดูล Sort และ Limit ครับ จะเห็นว่าเราสามารถใช้มันจัดการข้อมูลได้ เมื่อส่งข้อมูลต่อไป เราสามารถเรียงข้อมูล และจำกัดจำนวนข้อมูลที่ไหลผ่านได้ แล้วพบกันในบทถัดไปครับ
