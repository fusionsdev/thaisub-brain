## บทนำ
วิดีโอนี้สอนตั้งค่า AI agent ที่เปลี่ยนบทความบล็อกเป็นโพสต์โซเชียลมีเดียหลายแพลตฟอร์มโดยอัตโนมัติ เริ่มจากส่งลิงก์บทความผ่าน Telegram จากนั้นระบบจะดึงเนื้อหา สร้างสรุป สร้างภาพโปรโมตด้วยโมเดล Flux.1 ผ่าน PiAPI สร้างโพสต์เฉพาะแต่ละแพลตฟอร์มด้วย Claude 3.7 ของ Anthropic และบันทึกทุกอย่างลง Google Sheets

## คำแปลเต็ม

เรามาดาวน์โหลด workflow กันก่อน แล้วคุณต้องไปที่ n8n ถ้าคุณยังไม่มีบัญชี คุณสามารถสร้างได้ตรงนี้ ซึ่งให้ทดลองใช้ฟรีสองสัปดาห์ แล้วผมไปที่ personal จากนั้นคลิก create the workflow ต่อมาเราจะคลิก import from แล้วนำเข้า blueprint ที่เราดาวน์โหลดมา คลิกที่มัน ตอนนี้เราก็แค่ต้องเชื่อมต่อโมดูลต่าง ๆ ที่คุณเห็น เรามาตั้งชื่อกันก่อน ผมเรียกมันว่า demo ตั้งชื่อว่า blog to social แล้วมันก็จะเริ่มจากจุดเริ่มต้น

ต่อไปคือ Telegram trigger ในการเชื่อมต่อ Telegram คุณต้องใส่ access token และคุณจะเห็นวิดีโอ get the API from Telegram ที่สอนวิธีทำ แค่ดูวิดีโอเทคนิคสั้น ๆ นี้ แล้วกลับมาใส่ access token ตรงนี้ คลิก แล้วก็แค่นั้น ผมทำไว้แล้ว วิธีการทำงานของระบบอัตโนมัตินี้: เรามีสามบล็อกหลัก อันแรกคือการสร้างสรุป โดยพื้นฐานเราเริ่มจากตรงนี้ ถ้าผมเปิด Telegram เราจะเริ่มโดยส่งลิงก์บทความเว็บไซต์เข้าไป แล้วมันจะถูกประมวลผลตลอดทั้ง workflow นี่คือบทความบล็อก เช่นที่ผมส่งไป แล้วมันจะถูกเปลี่ยนเป็นโพสต์โซเชียลมีเดียต่าง ๆ รูปภาพ และเผยแพร่ เรามาดูส่วนนี้กัน

ผมจะอธิบายโมเดลไม่กี่ตัวตรงนี้ โมดูลนี้จะดึงเนื้อหาจากบทความ เช่นข้อความ แล้วทำความสะอาดข้อความเล็กน้อย จากนั้นส่งต่อให้ AI agent ตรงนี้เมื่อเราดับเบิลคลิก คุณไม่ต้องตั้งค่าอะไรตรงนี้ คุณสามารถปรับแก้ได้ นี่คือคำแนะนำการตั้งค่า AI agent นี้จะสร้างสรุปของบทความบล็อก และสร้าง image prompt ที่เป็นข้อความบรรยายภาพสำหรับโซเชียลมีเดียของเรา และนี่คือตัวอย่าง image prompt สองสามแบบ คุณสามารถกำหนดตามกฎตรงนี้ได้ว่าต้องการภาพแบบไหน อันนี้อาจต้องลองปรับแต่งและแก้ไขคำสั่งการสร้างภาพและ image prompt อยู่บ้าง ตัวนี้ไม่ได้สร้างภาพจริง มันแค่สร้างข้อความบรรยายภาพ แล้วภาพจะถูกสร้างในส่วนถัดไป

ต่อไปคือ Anthropic AI นี่คือที่ผมใช้ ผมพบว่าในตอนนี้ Anthropic AI Claude 3.7 เป็นหนึ่งในโมเดลที่น่าเชื่อถือที่สุดในการทำตาม system instructions อย่างถูกต้อง นั่นคือเหตุผลที่ผมใช้โมเดลนี้ตรงนี้ ถ้าคุณยังไม่มีบัญชี Anthropic คุณสามารถคลิกที่ลิงก์นี้และสมัครบัญชีได้ เพราะคุณต้องคลิก create new ใส่ API key แล้วคลิก save ตอนนี้ผมมีวิดีโอสอน get API key from Anthropic ให้คุณดูได้ถ้าต้องการ และเมื่อเชื่อมต่อแล้วเราก็ไปต่อได้ตรงนี้

นี่คือหน่วยความจำ (memory) ของ AI agent ไม่ได้จำเป็นจริง ๆ เพราะจำเป็นก็ต่อเมื่อคุณแชทโต้ตอบกลับไปกลับมา แต่ในกรณีนี้เราแค่ส่งลิงก์ และตรงนี้สิ่งที่เราต้องทำคือเชื่อมต่อ Google Sheet นี่คือที่ที่เราจะพบเทมเพลตนี้ คลิกแล้วคลิก make a copy นี่คือที่ที่เราเก็บข้อมูลทั้งหมดที่ถูกสร้างขึ้นตลอดกระบวนการ เรามารอจนกว่ามันจะเสร็จ แล้วผมจะตั้งชื่อให้มันด้วย เพื่อที่คุณจะได้หามันเจอ ไม่ใช่ตรงนี้ ควรจะไปตรงนี้ แล้วคุณต้องจำไว้ว่า: บัญชี Google นี้เชื่อมต่อกับอะไร? เพราะตอนนี้คุณต้องล็อกอิน ถ้าคุณยังไม่ได้เชื่อมต่อบัญชี Google Sheets ของคุณ คลิก create new คลิก sign in with Google แล้วเลือกบัญชีที่คุณต้องการเข้าสู่ระบบ ซึ่งต้องเป็นบัญชีเดียวกับอันนี้ และเมื่อคุณทำเสร็จแล้ว ผมทำไปแล้ว มันค่อนข้างตรงไปตรงมา ไม่ต้องสาธิตให้ดู และเมื่อคลิกตรงนี้ คุณจะเห็น Google Sheet ใหม่ที่คุณเพิ่งสร้างถูกพบ และตอนนี้มันควรจะแมตช์กับคอลัมน์เฉพาะต่าง ๆ อย่างถูกต้อง ตรงนี้คือที่ที่ข้อมูลทั้งหมดถูกเก็บ: บล็อก บล็อก บล็อก ภาพ และภาพ รวมถึงโพสต์ต่าง ๆ ที่ถูกสร้างสำหรับแพลตฟอร์มโซเชียลมีเดียเหล่านั้น และตรงนี้คือส่วนที่บอก AI agent ว่าต้องบันทึกข้อมูลอะไรบ้าง ตรงนี้ block summary ถูกบันทึกภายใต้ block summary และอื่น ๆ อันนี้ตั้งค่าไว้แล้ว

ต่อไปเรามาถึงตรงนี้แล้ว และเราจะทดสอบรันอย่างรวดเร็วเมื่อถึงจุดนี้ ตรงนี้เราก็ต้องเลือก Google Sheet ที่ถูกต้อง ชีตนี้ และแค่นั้น อันนี้จะโหลด image prompt ที่ถูกสร้างขึ้นมา เพราะมันถูกบันทึกโดย AI agent ลงใน Google Sheet ด้วย จากนั้นมันจะทำความสะอาด ตรวจสอบให้แน่ใจว่าไม่มีอักขระเหล่านี้ใน image prompt บางครั้งมันอาจทำให้เกิดปัญหา syntax กับโมดูลสร้างภาพของเรา และสิ่งที่เราจะทำคือยกเลิกการเชื่อมต่อตรงนี้ คลิก แล้วคลิก execute workflow แล้วคุณก็ไปที่บทความบล็อกใดก็ได้ คัดลอกลิงก์บทความ ตรวจสอบให้แน่ใจว่าระบบถูกเปิดใช้งาน แล้วส่งลิงก์ไปยังบอท Telegram ที่คุณเชื่อมต่อไว้ใน Telegram trigger แล้วคลิกวางลงตรงนี้ แล้วกระบวนการก็เริ่ม มันควรจะจบลงตรงนี้ และสิ่งที่เราจะได้กลับมาคือ image prompt ที่ทำความสะอาดแล้ว มาดูกัน รันเลย ตอนนี้เราเห็นว่ามันรันแล้ว image prompt สะอาดแล้ว เรามาเชื่อมต่อกันต่อ

และคุณสามารถตรวจสอบใน Google Sheets ได้ว่าเราเห็นลิงก์บล็อก สรุปบล็อก และ image prompt อันนั้นดี ทุกอย่างมีเครื่องหมายถูก ไม่มี error และอันนี้เราจะเชื่อมต่อกับบัญชีที่ถูกต้อง อันนี้เผื่อกรณีที่ลิงก์ของคุณใช้ไม่ได้ด้วยเหตุผลบางอย่าง มันจะคืนค่า error และขอให้คุณพิมพ์ลิงก์เว็บไซต์ที่ถูกต้อง ตอนนี้เรามีเครื่องมือ generate image เราจะใช้แพลตฟอร์มที่เราสามารถใช้โมเดลภาพที่ค่อนข้างล้ำสมัย และเข้าถึง AI อื่น ๆ ได้อย่างที่เห็น คุณต้องสมัครบัญชี ในเวอร์ชันฟรีคุณจะได้รับเครดิตไม่กี่เครดิต และเมื่อใช้หมดแล้วต้องไปที่ Settings แล้วเติมเครดิต คุณสามารถซื้อได้ประมาณ $5 ซึ่งเพียงพอ แล้วเราก็สร้างภาพได้ และภาพค่อนข้างถูก แค่ประมาณหนึ่งเซนต์ครึ่งต่อภาพที่สร้าง และเป็นภาพคุณภาพสูง นี่คือเครื่องมือที่ใช้ Flux.1 ซึ่งสร้างภาพที่มีรายละเอียดสูง สิ่งที่ต้องทำคือเลือก Header แล้วคลิก Create API key และตรงนี้สิ่งที่ต้องใส่คือ คลิก run API คุณต้องใส่ X API key ตรงนี้ กลับไป แล้วใส่ API key ตรงนี้ คุณหาคีย์ได้จากตรงนี้ ไปที่ API แล้วพิมพ์สร้างใหม่ หรือคัดลอกและวาง คลิก แล้วก็แค่นั้น และตรงนี้คุณจะเห็นว่านี่คือโมเดลภาพ มันง่ายมาก นี่คือ image prompt ที่ AI ของเราสร้าง ตรงนี้เรามีความกว้างและความสูง คุณสามารถปรับได้ถ้าต้องการ แต่ต้องแน่ใจว่าปรับพารามิเตอร์ให้ถูกต้องว่าขนาดภาพแบบไหนที่รองรับ แต่ผมจะปล่อยให้เป็นสี่เหลี่ยมจัตุรัส ซึ่งดีอยู่แล้ว

ตอนนี้ผมสามารถไปยังขั้นตอนถัดไปได้ เพราะตอนนี้เรามี wait node เราต้องรอสูงสุด 2 นาทีจนกว่าภาพจะถูกประมวลผล แล้วเราจะได้ภาพที่เสร็จสมบูรณ์ และตรงนี้คุณต้องเลือกบัญชีที่คุณเพิ่งเชื่อมต่อกับ PiAPI ด้วย แล้วก็แค่นั้น และตอนนี้ถ้าผมคลิก execute step มันจะรอ 2 นาทีแล้วให้ภาพกับผม ระหว่างที่มันรัน ผมสามารถไปทำอย่างอื่นได้เพราะตรงนี้เราก็ต้องเลือกบัญชีที่ถูกต้องเช่นกัน นี่คือที่ที่จะบันทึกลิงก์ภาพ ตรวจสอบให้แน่ใจว่าเลือก Google Sheet ที่ถูกต้อง ตอนนี้ผมต้องลบทั้งหมดนี้ เพราะผมยังไม่บันทึกโพสต์เหล่านี้ ผมแค่อยากบันทึก URL ของภาพลงในชีต

และตรงนี้เรามีโมดูลที่เปลี่ยนสรุปที่ AI สร้างขึ้นให้เป็นโพสต์ต่าง ๆ ที่มีรูปแบบและโครงสร้างการเขียนเฉพาะตามเกณฑ์ของแต่ละแพลตฟอร์มคอนเทนต์ คุณสามารถปรับแก้ตามสิ่งที่คุณคิดว่าเป็นแนวปฏิบัติที่ดีที่สุดสำหรับแต่ละแพลตฟอร์ม แนวคิดก็คือสร้างโพสต์โซเชียลมีเดียหรือคอนเทนต์จากสรุปบทความบล็อกนี้ที่ปรับแต่งให้เหมาะกับแพลตฟอร์มเฉพาะนั้น ๆ โพสต์สำหรับ LinkedIn จะต่างจากโพสต์สำหรับผู้ชม Instagram เล็กน้อย และนั่นคือแนวคิดเบื้องหลังสิ่งนี้ ตอนนี้ตรวจสอบให้แน่ใจว่าคำสั่งเหล่านี้เป็นสีเขียว อันนี้ดี และนี่คือผลลัพธ์ มันให้โพสต์สี่แบบที่แตกต่างกันกับผม ตอนนี้มันรันเสร็จแล้ว ตรงนี้เราเห็นภาพ มันเสร็จสมบูรณ์แล้ว และเราได้ URL ของภาพแล้ว ลองเปิดดู ดี มันคือภาพ และอย่างที่คุณเห็น คุณสามารถปรับ system instructions ที่สร้าง prompt เริ่มต้นได้ และตรงนี้คุณต้องเลือกบัญชี Anthropic ของคุณด้วย เพราะเราใช้โมเดลเดียวกันที่สร้างคอนเทนต์ต่าง ๆ เหล่านั้น

ผมจะคลิก execute step มันจะบันทึก URL ภาพก่อน แล้วผมตรวจสอบได้ เห็นว่าบันทึกแล้ว จากนั้นมันจะสร้างคอนเทนต์อื่น ๆ แล้วฟังก์ชันนี้จะตรวจสอบ แค่เปลี่ยนคอนเทนต์แต่ละชิ้น เช่น โพสต์ LinkedIn, Facebook, Instagram และ Twitter ให้เป็นค่าที่แยกจากกันสามค่า อย่างที่เห็น มันให้บล็อกข้อความก้อนใหญ่กับผม แต่ผมอยากแยกมัน ผมมีฟังก์ชันนี้ที่ให้ค่าสี่ค่าแยกกันสำหรับแต่ละแพลตฟอร์มคอนเทนต์ จากนั้นผมจะบันทึกโพสต์เหล่านี้ใน Google Sheet ของผม เลือกชีตที่ถูกต้อง ผมอยากเลือก summary sheet โอเค ตรงนี้ผมต้องแมปมันใหม่ให้ถูกต้อง ผมต้องดึงลิงก์จาก Telegram trigger ของผม ตอนนี้อันนี้มีอยู่แล้ว ผมสามารถลบทั้งหมดนี้ได้ยกเว้นโพสต์ต่าง ๆ ผมไม่ต้องการ publish date ตอนนี้ผมต้องไปที่ส่วนนี้ แล้วลากวางคอนเทนต์ชิ้นต่าง ๆ ลงตรงนี้: Instagram content และตรงนี้ Twitter content เมื่อเสร็จแล้วคลิก execute แล้วมันควรจะบันทึกโพสต์เหล่านั้น ใช่ ดีมาก
