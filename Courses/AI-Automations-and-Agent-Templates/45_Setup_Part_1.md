## บทนำ
วิดีโอนี้เป็นตอนที่ 1 ของการตั้งค่าระบบ AI Clone Automation (ระบบ AI ลอกเลียนวิดีโอ) โดยเริ่มจากการดาวน์โหลดเทมเพลตเวิร์กโฟลว์ AI แล้วนำเข้าใน n8n จากนั้นเชื่อมต่อโมดูลต่าง ๆ กับบัญชีของเรา เริ่มจาก Telegram, TikTok downloader, Cloudinary สำหรับอัปโหลดรูปภาพ, OpenAI สำหรับวิเคราะห์รูป แล้วจบด้วย Google Sheet สำหรับเก็บข้อมูลทั้งหมด

## คำแปลเต็ม

ในวิดีโอนี้ เราจะตั้งค่าระบบ AI clone automation ในการทำสิ่งนี้ ก่อนอื่นเราดาวน์โหลดเวิร์กโฟลว์ระบบอัตโนมัติ AI มาก่อน จากนั้นเข้าไปที่ n8n สร้างบัญชีใหม่ถ้าคุณยังไม่มี หรือเข้าสู่ระบบบัญชีปัจจุบันของคุณ จากนั้นคลิกที่ Create the workflow แล้วเราจะนำเข้า blueprint (พิมพ์เขียว/เทมเพลต) ที่เราเพิ่งดาวน์โหลด โดยคลิกที่ลิงก์นี้ ตรงนี้คุณไปที่ import from file แล้วคุณก็แค่ดับเบิลคลิกที่ blueprint นี้ แล้วมันจะถูกนำเข้า และสิ่งเดียวที่เหลือคือการเชื่อมต่อโมดูลต่าง ๆ เหล่านี้ ขึ้นอยู่กับเวอร์ชันของคุณ คุณอาจเห็นสามเหลี่ยมสีแดงเยอะมาก และนั่นหมายความว่าคุณต้องเชื่อมต่อเครื่องมือต่าง ๆ เหล่านี้เข้ากับบัญชีของคุณ นั่นคือสิ่งที่เราจะทำ แต่ส่วนที่ยากได้ทำเสร็จแล้ว เพราะ blueprint ถูกสร้างไว้แล้ว

สิ่งแรกที่คุณต้องมีคือบัญชี Telegram ถ้าคุณเคยใช้ Telegram มาก่อนในขั้นตอนก่อนหน้านี้ คุณสามารถเลือกบัญชี Telegram ที่ใช้งานอยู่บัญชีหนึ่ง หรือคุณจะสร้างบัญชีใหม่โดยคลิกที่ create new และจากนั้นคุณก็ไปที่ technical tutorials ซึ่งผมได้แสดงวิธีรับ API key จาก Telegram ไว้ที่นั่น จากนั้นคุณทำตามนั้น แล้วคุณก็สามารถเชื่อมต่อบัญชี Telegram ใหม่และเชื่อมต่อบอตใหม่ได้ ผมจะปล่อยไว้แบบนั้น เพราะมันทำงานอยู่แล้วสำหรับผม แล้วเราก็ไปต่อขั้นตอนถัดไป

ตอนนี้เรามี TikTok downloader นี่คือเครื่องมือที่ดึงเนื้อหาจากวิดีโอ TikTok ที่กำลังเป็นไวรัล ซึ่งเราต้องการใช้เป็นพื้นฐานสำหรับวิดีโอ AI clone ของเรา ตรงนี้สิ่งที่คุณต้องทำคือไปที่ technical tutorial และตรงนั้นผมมี get API key from download the API ซึ่งผมจะแสดงวิธีสมัครใช้งานฟรี และแสดงวิธีรับคีย์จากเว็บนั้น แล้วคุณนำมาวาง แล้วคลิก save แล้วเราก็ไปต่อขั้นตอนถัดไป เรามีโมดูลนี้ตรงนี้ ซึ่งเราไม่จำเป็นต้องตั้งค่า มันแค่ดึงรูปปก (cover image) มา สิ่งที่เราจะทำจริง ๆ คือเราจะใช้ข้อมูลสำหรับขั้นตอนต่าง ๆ เหล่านี้ทั้งหมด และยังสามารถทดสอบแต่ละโมดูลได้ว่าเชื่อมต่อถูกต้องหรือไม่

ในการทำสิ่งนี้ คุณเข้าไปที่บอท AI clone automation ที่คุณสร้างไว้ เช่นตอนที่คุณสร้าง หรือคุณไปที่บอทที่คุณเชื่อมต่อกับบัญชี Telegram ก่อนหน้าบัญชีหนึ่ง สิ่งสำคัญคือบัญชี Telegram นั้นต้องเชื่อมต่อกับบอตเสมอ ดังนั้นคุณต้องเปิดมัน คุณต้องเข้าไปตรงนี้ แล้วหาว่าอันไหนคืออันที่เชื่อมต่อกับบัญชีของผม และผมมีอันนี้อยู่แล้ว สิ่งที่ต้องทำคือ ระบบนี้ทำงานโดยการส่งลิงก์ TikTok เท่านั้น คุณสามารถทำได้จากโทรศัพท์หรือจากคอมพิวเตอร์ ผมแค่คัดลอกลิงก์นี้ หรือคุณจะคลิกที่ share แล้วแชร์หรือคัดลอกลิงก์ก็ได้ แล้วให้แน่ใจว่าคลิกที่ test the workflow สิ่งที่ผมจะทำคือผมต้องการยกเลิกการเชื่อมต่อตรงนี้ ผมเคยยกเลิกการเชื่อมต่อนี้มาก่อนแล้ว ดี เพราะผมไม่อยากประมวลผลโมดูลอื่น ๆ เพราะพวกมันยังไม่ได้เชื่อมต่อ แล้วผมก็แค่วางลิงก์ลงตรงนี้ แล้วดูว่าเกิดอะไรขึ้น

เราจะเห็นว่าโมดูลนี้ทำงาน มันดึงเนื้อหาทั้งหมดจากวิดีโอ TikTok ของเรา แล้วอันนี้ดึงรูปปกมา แล้วเมื่อผมคลิกที่มัน นั่นคือรูปภาพของวิดีโอ TikTok ที่ผมส่งเข้าไป ดีมาก ตอนนี้เราเชื่อมต่อแล้ว และเราสามารถไปต่อขั้นตอนถัดไปได้ ขั้นตอนถัดไปคือ upload cover (อัปโหลดรูปปก) ตรงนี้เราใช้เครื่องมือที่ชื่อว่า Cloudinary ตรงนั้นคุณต้องใส่ Cloudinary ID ของคุณ และคุณต้องเชื่อมต่อมันด้วย คุณต้องไปคลิกที่ Create New แล้วใส่ user และ password ผมแสดงวิธีทั้งหมดนั้นไว้ใน technical tutorials หัวข้อ get credentials from ซึ่งผมแสดงวิธีรับ ID รวมถึง API keys และ credentials แล้วคุณนำมาใส่ตรงนี้ แล้วคลิก save

จากนั้นตรงนี้คุณต้องใส่ชื่อ preset ตรงนี้คุณแค่ไปที่ settings ด้านล่าง แล้วไปที่ upload แล้วคลิกที่ add upload preset แล้วตั้งชื่อให้มัน ชื่ออะไรก็ได้ ไม่สำคัญ สิ่งที่สำคัญคือคุณต้องคลิก unsigned แล้วคลิก แล้วคัดลอกชื่อของ upload preset นี้ แล้ววางลงตรงนี้ จากนั้นถ้าคุณคลิก test คุณควรเห็นบางอย่างเช่นการได้ URL ของรูปปก ตรงนี้เรามี URL แล้ว และคุณเห็นว่ามันคือรูปเดียวกัน และสิ่งสำคัญคือเราได้อัปโหลดมันไปยังแพลตฟอร์มเก็บไฟล์บนเว็บแล้ว ตอนนี้เราสามารถประมวลผลและวิเคราะห์มันได้

ขั้นตอนถัดไปคือ OpenAI analyze image ถ้าคุณยังไม่ได้เชื่อมต่อบัญชีของคุณ คุณคลิกที่ create new แล้วคุณจะได้รับ API key จาก platform.openai.com และผมแสดงวิธีนั้นไว้ใน technical tutorials ด้วย หัวข้อ Get API key from OpenAI ผมทำไว้แล้วตรงนี้ และตรงนี้คุณไม่ต้องทำอะไร แค่คลิก test step แล้วโมเดล AI นี้จะวิเคราะห์รูปภาพ และมันจะให้ข้อความที่อยู่ในรูปภาพแก่เรา จากนั้นเราก็ไปต่อได้

ตอนนี้เรามีโมเดล AI ตัวถัดไปที่ใช้ในการแยกข้อความจริง ๆ ตรงนี้เป็นเพียง input จากโมดูลก่อนหน้าที่วิเคราะห์ข้อความ มันวิเคราะห์รูปภาพ แล้วตรงนี้เราต้องการแยกข้อความ เราต้องการแค่ข้อความที่เครื่องมือวิเคราะห์นี้เจอในรูปภาพ และตรงนี้คุณสามารถเลือกบัญชี OpenAI เดียวกับที่คุณเชื่อมต่อในขั้นตอนที่แล้ว แล้วมันควรให้ข้อความที่อยู่ในรูปภาพแก่เรา และอย่างที่คุณเห็น นี่คือเนื้อหาที่ทำงานได้ดี

ต่อไปเรามีส่วนของเสียง อันนี้เป็นสิ่งที่คุณไม่ต้องทำอะไร เพราะมันเชื่อมโยงมาจาก TikTok ของเราแล้ว ซึ่งรวมถึงไฟล์เสียงที่ดาวน์โหลดมา ตรงนี้เราแค่รับลิงก์ไปยังไฟล์เสียงนั้น โดยพื้นฐานแล้วมันคือเสียงที่คนพูดในวิดีโอ และเราใช้มันเพื่อรับบทถอดเสียง (transcript) ซึ่งอยู่ในโมดูลตรงนี้ เราก็ไม่ต้องทำอะไรตรงนี้เหมือนกัน เมื่อเราคลิก test step มันควรแยกสคริปต์ของวิดีโอนี้จากไฟล์เสียงที่เราได้ในขั้นตอนก่อนหน้า ตรงนี้คุณเห็นว่านี่คือสคริปต์ เยี่ยมมาก

ตรงนี้คุณไม่ต้องทำอะไร นี่เป็นเพียง template ID ที่จะสร้าง ID เฉพาะสำหรับวิดีโอที่เราดาวน์โหลด เพื่อให้เราสามารถระบุมันได้ในภายหลัง และตรงนี้เรามีโมดูล Google Sheet ซึ่งสำคัญมาก สิ่งที่คุณต้องทำคือคลิก create new แล้วคลิก sign in with Google แต่ก่อนที่คุณจะทำ ต้องแน่ใจว่าคุณดาวน์โหลดเทมเพลตฐานข้อมูล Google Sheet ก่อน นี่คือการคลิกหรือ make a copy ที่เราจะเก็บข้อมูลทั้งหมดที่เราประมวลผล เนื้อหาทั้งหมดจากวิดีโอ TikTok ที่เราจะเก็บไว้ตรงนี้ เนื้อหาทั้งหมดสำหรับวิดีโอของเราเองที่เรากำลังประมวลผล จะถูกเก็บไว้ตรงนี้ และส่งไปยังเครื่องมือต่าง ๆ เหล่านั้น

ตรงนี้เราสร้างมันขึ้นมาแล้ว ผมตั้งชื่อเฉพาะให้มัน สำหรับอันนี้ และเรามีสองส่วน: template และ generate post ซึ่งจะชัดเจนขึ้นในขั้นตอนถัดไป คุณต้องแน่ใจว่า: ในบัญชี Google นี้ คุณต้องเข้าสู่ระบบด้วยตรงนี้ คลิกที่ sign in with Google จากนั้นคุณจะได้รับแจ้งให้เลือกบัญชี Google ของคุณ เลือกบัญชีเดียวกับที่มี Google Sheet นี้อยู่ และเมื่อคุณทำเสร็จ Google ของคุณจะถูกเชื่อมโยง และเมื่อคุณคลิกตรงนี้ มันจะโหลดชีตใหม่ที่คุณสร้างขึ้น และตรงนี้เราต้องเลือก templates

ตอนนี้เราต้องบอกมันว่า: เราต้องการบันทึกเทมเพลตอะไรหรือค่าอะไรบ้าง? เราก็แค่ลากค่าเหล่านี้ลงในฟิลด์ตรงนี้ และสิ่งเหล่านี้ก็คือคอลัมน์ต่าง ๆ ตรงนี้ และตรงนี้เราต้องการระบุว่า: เราต้องการบันทึกข้อมูลอะไรลงในคอลัมน์ไหน? วิดีโอลิงก์ มาจากโมดูลแรกสุด นั่นคือลิงก์ไปยัง TikTok ซึ่งผมมีตรงนี้ ดังนั้นผมจะเลือกอันนี้ จากนั้นเรามี text overlay template นี่คือข้อความที่วางอยู่บนวิดีโอ นั่นคือข้อความตรงนี้ และอันนี้ถูกแยกโดยโมดูล AI ของผม เรามี extract นั่นก็คืออันนี้ จากนั้นเรามีอันที่มาจากส่วน transcribe audio และเรามี captions template คำบรรยายอยู่ในโมดูลที่ดาวน์โหลดวิดีโอ มันอยู่ตอนเริ่มต้นมาก ๆ ตรงที่เราเห็นว่ามันเรียกว่า title นี่คือสิ่งที่ captions เป็น และเมื่อผมคลิก มันควรบันทึกข้อมูลนี้ลงในแถวแรก และคุณเห็นว่ามันถูกดาวน์โหลดและบันทึกอย่างถูกต้อง ตอนนี้เราสามารถไปต่อกับเวิร์กโฟลว์ของเราได้
