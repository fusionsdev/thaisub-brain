# สรุป: Claude + Obsidian 2.0 Just Changed AI Workflows

## ประเด็นหลัก
- Claude Obsidian คือ plugin โอเพนซอร์สฟรี (สัญญาอนุญาต MIT) สำหรับ Claude Code พัฒนาโดยนักพัฒนาชื่อ Daniel Agreesy เวอร์ชันปัจจุบัน 2.1 เปลี่ยน Claude ให้เป็น "บรรณารักษ์" จัดการความรู้ของคุณเอง
- หลักการทำงาน: โยนแหล่งข้อมูลลงในโฟลเดอร์ inbox แล้ว Claude จะอ่าน เชื่อมโยง และจัดเก็บเป็นหน้า markdown ธรรมดาบนเครื่องคุณ ไม่ใช่ cloud database ไม่ผูกติดกับแอปใด และไม่อัปโหลดไปให้โมเดล
- ทุกข้อความสำคัญมีตัวชี้กลับไปยังแหล่งที่มา และเมื่อ vault ไม่รู้เรื่องอะไรก็ตอบตรงๆ ว่าไม่รู้ แทนที่จะมโนขึ้นมา
- วงจร capture → ground → connect → use ทำให้ vault ยิ่งใช้ยิ่งมีประโยชน์ ไม่รกขึ้นเรื่อยๆ
- เสียบเป็นชั้นความจำ (memory layer) ใน Agent OS ทำให้ agent ทุกตัวอ่านความจำชุดเดียวกัน
- แก้ "ปัญหาความจำปลาทอง" ของ AI ที่ตื่นขึ้นมาทุกเช้าโดยไม่รู้จักคุณ ต้องอธิบายตัวเองซ้ำแล้วซ้ำเล่า
- มาพร้อม 15 สกิลที่ใช้กฎชุดเดียวกัน เช่น เช็คสุขภาพ vault แปลง inbox เป็นหน้าที่เชื่อมโยง ตอบคำถามจาก vault เท่านั้น สร้างบอร์ดภาพบน Obsidian canvas สรุปกิจกรรมรายสัปดาห์ ทำความสะอาด dead links/โน้ตกำพร้า ค้นเว็บเมื่อได้รับอนุญาต และทบทวนความเชื่อมโยงของโน้ต
- ตัวอย่างการใช้งานจริง: สร้างคอนเทนต์ซีรีส์ วางแผน onboarding สมาชิกใหม่ และวิเคราะห์คีย์เวิร์ดจากคอนเทนต์คู่แข่ง โดยทุกไอเดียชี้กลับไปยังแหล่งข้อมูลจริงในโน้ต
- การตั้งค่าที่คนส่วนใหญ่ข้าม: โหมดการจัดเก็บ (mode) โดยเฉพาะ PARA (projects, areas, resources, archives) ทำให้โน้ตใหม่จัดระเบียบตามวิธีคิดของคุณ โดยไม่แตะต้องโน้ตเดิม
- เคล็ดลับ: ใช้ inbox จริงๆ อย่าจัดไฟล์ด้วยมือ เชื่อคำตอบแบบซื่อสัตย์ของมัน และใช้ safe adopt ถ้ามี Obsidian vault อยู่แล้ว
- plugin ฟรี Obsidian ฟรี ตั้งค่าได้ทันทีโดยไม่ต้องใช้เครื่องมือพิเศษ ความรู้ของคุณควรทบต้นดีขึ้นทุกวัน ไม่ใช่หายไปทุกเช้า
## ความเห็นสรุป
คลิปนี้นำเสนอแนวคิด "AI ที่มีความจำแบบทบต้น" ได้ชัดเจนและน่าสนใจ ผ่านการสาธิตฟีเจอร์จริงและตัวอย่างการใช้งานที่จับต้องได้ จุดแข็งคือการย้ำหลักการอ้างอิงแหล่งที่มาของทุกคำตอบ ซึ่งช่วยเพิ่มความน่าเชื่อถือให้ AI ได้มาก ส่วนท้ายเป็นโปรโมต AI Profit Boardroom และ AI Success Lab ตามสไตล์การตลาดของช่องนี้
