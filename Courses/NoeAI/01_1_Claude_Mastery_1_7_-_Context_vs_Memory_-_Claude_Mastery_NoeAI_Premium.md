## บทนำ

วิดีโอนี้อธิบายความแตกต่างระหว่าง Context กับ Memory ในโมเดล AI อย่างเข้าใจง่าย — Context Window คือกรอบของบทสนทนาปัจจุบัน ส่วน Memory คือข้อมูลที่โมเดลจำได้ข้ามบทสนทนา ทั้งสองทำงานเสริมกันเพื่อให้คำตอบของ Claude ดีขึ้นเรื่อยๆ

## คำแปลเต็ม

ยินดีต้อนรับสู่บทเรียน Context กับ Memory ครับ ในบทเรียนนี้ผมจะอธิบายหนึ่งในพื้นฐานที่สำคัญที่สุดของการใช้ AI เพื่อให้คุณใช้ Claude และเครื่องมือ AI อะไรก็ได้อย่างคุ้มค่าที่สุด มันเป็นพื้นฐานที่ง่ายมากที่คุณต้องเข้าใจ แต่มันคือสิ่งที่ทำให้ผลลัพธ์ของคุณดีหรือแย่ ตั้งใจฟังกันหน่อยนะครับ

Context กับ Memory — Context คือสิ่งที่คุณให้ข้อมูลในสิ่งที่คุณกำลังคุยกัน และโมเดล AI ทั้งหมดทำงานบนพื้นฐานนี้ โอเคไหมครับ? ถ้าคุณมีหน้าต่างอยู่ตรงนี้ อย่างเช่นในแชทนี้ เราเรียกมันว่า context window (หน้าต่างบริบท) ทุกอย่างที่คุณพิมพ์ภายในนี้เกี่ยวข้องกับการสนทนานี้ ผมจะโชว์ตัวอย่างให้ดู: ถ้าผมเริ่มแชทใหม่แล้วถามว่า "วันนี้เราทำอะไรกันอยู่?" — มันจะทำแบบนี้: มันจะเข้าไปค้นหาใน memory ของมันเพื่อหาคำตอบนี้

Context ก็คือ context window นั่นแหละ มันทำงานเฉพาะภายในหน้าต่างนี้เท่านั้น ตัวอย่างคือ เวลาคุณคุยกับคน: นี่คือคุณ คุณกำลังสนทนาอยู่กับอีกคนหนึ่ง — context มีอยู่เฉพาะภายในบทสนทนานี้เท่านั้น หมายความว่า ตอนที่ผมคุยกับคนนี้ และเขาตอบกลับ นี่คือ context มันเหมือนหน้าต่าง เหมือนกับที่เรากำลังคุยกันในบริบทของบทสนทนานี้โดยเฉพาะ

ถ้าเราคุยกันเรื่องเบสบอล แล้วคุยกันไปมา เราก็อยู่ในหัวข้อนี้ เราไม่ได้ดึงความทรงจำเข้ามา เราไม่ได้คุยกับคนอื่นในบริบทอื่น เราไม่ได้อ้างอิงข่าว เราคุยกันเฉพาะสองคนเท่านั้น ดังนั้นเมื่อคุณทำงานกับ AI ในหน้าต่างใดหน้าต่างหนึ่ง นี่คือ context window เดียวที่คุณทำงานอยู่ มันไม่มีอะไรอื่นให้คุณอีก

และเมื่อคุณคุยลึกขึ้นเรื่อยๆ ทุกครั้งที่คุณถาม AI ว่า "เรากำลังทำอะไรอยู่?" มันจะอ่านทุกอย่างที่อยู่ข้างบน นั่นแหละ มันจะรู้ได้ทันทีว่าคุณอยู่ตรงไหนในงาน มันจะรู้ว่าเราเคยทำอะไรมาบ้าง ตอนนี้มันไม่ได้ไปอ้างอิงแชทอื่น หรือดึงข้อมูลอื่นมา แต่มันอ้างอิงทุกอย่างที่อยู่ข้างบน มันจำ context ทั้งหมดของคุณ จากคำถามและการสนทนาที่คุณเคยมี แล้วใช้มันเพื่อสร้างคำตอบใหม่ให้คุณ

สมมติว่าไม่มี memory เลย และผมเริ่มแชทใหม่ถามว่า "เรากำลังทำอะไรอยู่?" แล้วมันก็ตอบว่า "ไม่รู้สิ เราไม่ได้ทำอะไรเลย" เพราะมันไม่มี context แต่ว่า memory — มันเหมือนกับมนุษย์: สมมติว่าคุณกำลังคุยกับผม แล้วผมถามว่า "คุณกำลังทำอะไรอยู่?" คุณจะเข้าไปในสมองของคุณ — เราจะเรียกมันว่าสมองของคุณ — คุณจะเข้าไปในคลังที่เก็บความทรงจำทั้งหมด ไม่ว่าจะเป็นเรื่องที่คุณทำงาน คนที่คุณรู้จัก ครอบครัวของคุณ อะไรพวกนั้น

ถ้าผมถามคุณว่า "จนถึงตอนนี้คุณทำงานอะไรมาบ้าง?" ถ้าคุณไม่มีความทรงจำ คุณก็คงตอบว่า "ไม่รู้สิ" แต่เพราะคุณมีข้อมูลว่าคุณทำงานอะไร รู้จักใคร อะไรแบบนั้น คุณจะไปดึงข้อมูลนั้นมา นำกลับมา แล้วสร้างคำตอบ แล้วตอบออกมา ง่ายมาก

โมเดล AI ก็เหมือนกัน มันก็เหมือนมนุษย์: มันมี context window อย่างที่ผมโชว์ไป แต่สิ่งที่ Claude และโมเดล AI อื่นๆ มีเพิ่มเติมก็คือ memory พวกมันจำสิ่งสำคัญบางอย่างเกี่ยวกับคุณได้จริงๆ ดังนั้นถ้าผมถามในแชทใหม่ว่า "ผมคือใคร?" — ถ้ามันไม่มีข้อมูลเดิมเลย และถ้าเป็นสิ่งที่ผมไม่ได้ใช้มานานถึงสองปี มันก็คงตอบว่า "ไม่รู้" แต่มันจะออกไปนอก context window นี้ เพราะมันจำบทสนทนาก่อนหน้าของเราได้ จำสิ่งที่ผมชอบ มันรู้ว่าผมชอบเล่นอะไร รู้ว่าผมมี LLC และรัน NoeAI Premium อะไรประมาณนั้น มันมีข้อมูลพวกนั้นครับ

และผมค่อนข้างแน่ใจว่า memory ที่เก็บไว้ใน Claude Desktop — ถ้าคุณเข้าไปที่การตั้งค่า คุณสามารถดึง memory เฉพาะของคุณขึ้นมาดูได้ ผมว่ามันได้นะ — ไปที่ memory preferences โอเค คุณสามารถเข้าไปดูได้จริงๆ ว่า AI เก็บข้อมูลอะไรเกี่ยวกับคุณไว้ ทั้งในแง่ข้อมูลของคุณ และความทรงจำที่มีต่อคุณ เพราะนั่นคือสิ่งที่มันใช้และอ้างอิงทุกครั้ง

ดังนั้นเมื่อไหร่ก็ตามที่ผมเริ่มสนทนากับ Claude — ผมอยู่ตรงนี้ สนทนาอยู่ นี่คือ Claude — มันจะจำบทสนทนาก่อนหน้านี้ทั้งหมดที่ผมเคยมี มันดึงข้อมูลนั้นมา แล้วตอบกลับภายใน context นี้ มันเพิ่ม context ให้กับแชทของเรา เพราะมันมี memory ดังนั้นสองสิ่งนี้ทำงานซ้อนทับกัน

สรุปง่ายๆ ก่อนจากกัน: Context ก็คือหน้าต่างเดียวที่คุณกำลังสนทนาอยู่ และนั่นคือบริบทของการสนทนานั้น ส่วน Memory คือตอนที่คุณออกไปนอก context window เพื่อไปดึงความทรงจำที่คุณมี เอาข้อมูลเฉพาะนั้นกลับมา แล้วเพิ่มเข้าไปใน context window — memory นี้เสริมให้ context ดีขึ้น เพื่อให้คุณได้คำตอบที่ดีขึ้นเรื่อยๆ แค่นั้นเองที่คุณต้องรู้

นี่คือทั้งหมดของบทเรียน Context กับ Memory ครับ ถ้าสงสัยตรงไหนก็ถามในคอมมูนิตี้ได้ แล้วเจอกันในบทเรียนถัดไปครับ
