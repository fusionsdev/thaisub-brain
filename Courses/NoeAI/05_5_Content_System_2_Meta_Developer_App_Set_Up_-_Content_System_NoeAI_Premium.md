## บทนำ

วิดีโอนี้สอนวิธีสมัคร Meta Developer Account และสร้างแอปบน developers.facebook.com เพื่อใช้ดึงข้อมูล Instagram ผ่าน Claude Code — รวมถึงวิธีแก้ปัญหา "เทคโนโลยีนี้ยังไม่พร้อมใช้งาน" ด้วยการล้างคุกกี้ การเลือกสิทธิ์การใช้งานต่างๆ การเชื่อมต่อ business portfolio และขั้นตอนการยืนยันตัวตน

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่อีกหนึ่งบทเรียนครับ ในบทเรียนนี้ผมจะโชว์วิธีตั้งค่า Instagram Developer Account และแอปของคุณ เพื่อให้เราเริ่มดึงข้อมูล Instagram ของคุณผ่าน Claude Code ได้ อันนี้สำคัญมากๆ ถ้าไม่มีขั้นตอนนี้ คุณจะทำคอร์สส่วนที่เหลือไม่ได้เลย ดังนั้นเราต้องตั้งค่าให้ถูกต้อง เริ่มเลยครับ

ขั้นแรก สิ่งที่คุณต้องทำคือ ไปที่ developers.facebook.com แล้วเลือก — ถ้าคุณยังไม่เคยสร้างบัญชีผู้พัฒนา คุณก็แค่ลงทะเบียน แล้วระบบจะพาคุณผ่านขั้นตอนต่างๆ ไปเอง แต่ถ้าคุณเข้าไปที่ Facebook Developers แล้วเจอข้อความว่า "เทคโนโลยีนี้ยังไม่พร้อมใช้งานสำหรับคุณ" — ซึ่งเพิ่งเกิดขึ้นกับผมจริงๆ — สิ่งที่คุณต้องทำคือ ไปล้างคุกกี้ก่อน โอเคไหม?

วิธีก็คือ เข้าไปที่การตั้งค่าของ Chrome แล้วคิดว่าเป็นหัวข้อ privacy and third-party cookies (ความเป็นส่วนตัวและคุกกี้ของบุคคลที่สาม) แล้วค้นหาคำว่า Facebook แล้วลบมันทิ้ง — ผมลบไปแล้ว เลยไม่เห็นอะไรแล้ว ดูสิ มีช่อง see all site and data from แล้วก็ค้นหา แล้วก็ลบได้เลย จากนั้นเปิด Chrome หน้าต่างใหม่ แล้วเริ่มต้นใหม่ ถ้าเจอปัญหานี้บอกผมได้เลยนะ เพราะมันเกิดขึ้นกับผมบ่อยมากด้วยเหตุผลบางอย่าง

พอคุณสร้างและลงทะเบียนเป็น developer เรียบร้อยแล้ว คุณก็จะเห็นสิ่งที่เรียกว่า My Apps อยู่ด้านบน สิ่งที่คุณต้องทำคือ ไปที่ My Apps แล้วคุณจะเห็นแอปทั้งหมดที่คุณเคยสร้าง — ผมทำ tutorial นี้มาหลายรอบมาก แต่เราจะทำอีกรอบให้ทุกคนดู สิ่งที่ผมจะทำคือกด Create App แล้วตั้งชื่อแอปอะไรสักอย่าง ง่ายๆ แล้วใส่ชื่อผู้ติดต่อของคุณตรงนี้ แล้วกด Next

ตรงนี้คุณจะเห็นรายการความสามารถทั้งหมดที่คุณทำได้กับ Meta app ของคุณ เราจะเลือกมากกว่าที่จำเป็นเล็กน้อย เพราะสำหรับ AI ad system (ระบบโฆษณา AI) และอะไรก็ตามที่เราใช้ Meta คุณจะใช้แอปตัวนี้ทั้งหมด เว้นแต่คุณอยากแยกมันออกจากกันด้วยเหตุผลบางอย่าง ซึ่งจริงๆ แล้วไม่จำเป็นต้องทำ มีหลายสิ่งหลายอย่างที่ทำได้ในนี้ เดี๋ยวผมจะอธิบายไปทีละอย่างครับ

คุณสามารถสร้างและจัดการโฆษณาด้วย Marketing API — อันนี้จะให้คุณสร้างและรันโฆษณาได้จริงๆ คุณสามารถวัดผลประสิทธิภาพโฆษณาได้ คุณจะได้ข้อมูลโฆษณาทั้งหมด เราอยากได้อันนี้ Capture and manage ads lead (เก็บและจัดการลีดจากโฆษณา) — ถ้าคุณรันแคมเปญลีด ที่เก็บข้อมูลลีด คุณก็สามารถดึงมันผ่าน Claude Code ได้เหมือนกัน Create and manage app ads with manager — ถ้าคุณมีแอปมือถือหรือซอฟต์แวร์ และต้องการให้คนติดตั้ง คุณก็รันโฆษณาให้มันได้

คุณสามารถเข้าถึง Threads API — อันนี้จะให้คุณทำสิ่งเดียวกันบน Meta แต่ดึงข้อมูลจาก Threads และโพสต์เนื้อหา ซึ่งผมว่ามันเจ๋งมาก Advertise your app on the audio — อันนี้ผมไม่ค่อยต้องการ Manage catalogs with API — ไม่ค่อยจำเป็น Engage with customers on Messenger with Meta — ถ้าคุณทำอะไรบน Facebook คุณก็ใช้ได้ แต่ผมไม่ค่อยได้ใช้เท่าไหร่

จัดการข้อความและเนื้อหาบน Instagram — อันนี้สำคัญมาก คุณสามารถ publish ตอบกลับ ตอบข้อความตรง (direct message) และอื่นๆ อีกมากมายด้วย Instagram API ได้ จากนั้นก็มี Manage messaging ads on your content และ Access the live video API — ใช้ API สำหรับสตรีมวิดีโอสดบน Facebook ซึ่งเราไม่ค่อยจำเป็น Embed Facebook, Instagram และ Threads ลงบนเว็บไซต์อื่น จัดการทุกอย่างบนเพจของคุณ — อันนี้ผมอยากทำบนเพจ Facebook ของผม แล้วก็ Connect with customers through WhatsApp — ผมไม่จำเป็น แต่ถ้าคุณอยู่ในพื้นที่อื่นนอกเหนือจากนี้ คุณอาจต้องใช้มัน

ต่อไปเราก็กด Next แล้วคุณจะเห็นหน้าธุรกิจ — คุณก็แค่เลือก business profile (โปรไฟล์ธุรกิจ) ของคุณ นั่นคือเหตุผลที่ผมบอกว่า ถ้าคุณยังไม่ได้ตั้งค่า business profile ก็ต้องกลับไปดูวิดีโอก่อนหน้านั้นเพื่อตั้งค่ามันก่อน ส่วน Publishing เราไม่ได้ใช้ ทุกอย่างดูเรียบร้อยดี ตรวจสอบ use cases แล้วก็กด Create App

และมันควรจะพาเราไปขั้นตอนถัดไป — ดูเหมือนว่าผมต้องยืนยันตัวตน อืม มันดีที่คุณได้เห็น error ด้วยนะครับ ดูเหมือนระบบแจ้งว่า "เราพบว่าคุณกำลังเข้าถึงธุรกิจนี้จากอุปกรณ์ใหม่" หรืออาจเป็นเพราะผมเปิด VPN อยู่ เพื่อช่วยให้มันผ่าน ผมจะรีเฟรชหน้านี้ ผมน่าจะต้องสร้างแอปใหม่ แล้วลองดูว่าจะเลี่ยงมันได้ไหม

เสร็จแล้ว เราเชื่อมต่อธุรกิจสำเร็จครับ สิ่งที่เกิดขึ้นคือ ผมต้องกลับไปที่ Meta Business ของผม แล้วล็อกอินเข้าบัญชี developer ใหม่ จากนั้นก็กลับมาตรงนี้ แล้วเข้าไปที่ basic app settings (การตั้งค่าพื้นฐานของแอป) แล้วไปที่ business portfolio แล้วเพิ่มมันเข้าไป ตอนนี้มันขอให้ยืนยันตัวตน (verification) ผมว่าเรายังไม่ต้องยืนยันตอนนี้ เดี๋ยวค่อยดูกันทีหลัง แต่ประมาณนี้คือวิธีสร้างแอป และยังมีอีกหลายอย่างที่คุณตั้งค่าได้ในนี้ แต่ฝั่งนี้เราน่าจะพร้อมแล้ว

ต่อไป สิ่งที่เราจะทำคือ ผมจะพาทุกคนดูวิธีนำแอปตัวนี้ไปเชื่อมต่อกับ Claude Code ครับ แล้วเจอกันในบทเรียนถัดไป
