## บทนำ
วิดีโอนี้สอนตั้งค่า workflow อัตโนมัติที่เปลี่ยนรูปภาพใดก็ได้ให้เป็นวิดีโอที่มีข้อความและเพลงประกอบ โดยใช้ n8n ร่วมกับ Telegram, Cloudinary, PiAPI (Kling สำหรับสร้างวิดีโอ และสร้างเพลง), OpenAI และ JSON2Video ก่อนที่จะเผยแพร่ไปยัง YouTube Shorts และ TikTok ในวิดีโอถัดไป

## คำแปลเต็ม

ในวิดีโอนี้เราจะตั้งค่า workflow อัตโนมัติที่เปลี่ยนรูปภาพใดก็ได้ให้เป็นวิดีโอที่มีข้อความและเพลงประกอบ แล้วเราจะเผยแพร่มันในส่วนถัดไปโดยอัตโนมัติไปยัง YouTube Shorts และ TikTok ในการเริ่มต้น สิ่งแรกที่ต้องมีคือบัญชี n8n นั่นคือระบบอัตโนมัติที่เราใช้ คุณสามารถคลิก get started for free แล้วเริ่มทดลองใช้ถ้าคุณยังไม่มีบัญชี จากนั้นเมื่อเข้าไปแล้วคลิก Create Workflow แล้วกลับไปด้านล่าง คุณจะพบปุ่มดาวน์โหลด workflow template แล้วกลับไปที่ import from file แล้วนำเข้าไฟล์ที่เพิ่งดาวน์โหลด

แล้วสิ่งที่เหลือคือการเชื่อมต่อโมดูลไม่กี่ตัวตรงนี้ เราจะเริ่มจาก Telegram ถ้าคุณยังไม่มี Telegram คุณต้องคลิก create a new credential แล้วคุณต้องใช้ access token และคุณจะพบวิดีโอสอนในส่วน technical tutorials: get API key from Telegram แค่ดูแล้วกลับมาวาง access token ตรงนี้ แล้วคลิก save ผมเชื่อมต่อไว้แล้ว แล้วไปที่โมดูล Telegram ถัดไปซึ่งเชื่อมต่อไว้แล้วโดยปกติ ในของคุณถ้าคุณมีหลายบัญชีคุณอาจต้องเลือกบัญชีที่ถูกต้อง

และเรามีโมดูลแยกข้อความ (split) เรายังไม่ต้องเปลี่ยนอะไร แต่ก่อนอื่นเรามาทดสอบอย่างรวดเร็วและอธิบายให้คุณเข้าใจมากขึ้นว่ามันทำงานอย่างไร เราจะดูว่าโมดูล Telegram ทำงานไหม สิ่งที่ผมจะทำคืออัปโหลดรูปภาพ แล้วผมก็แค่บอกว่า ให้คนนี้ดื่มชามัทฉะหนึ่งถ้วย และเพิ่มชั้นหนังสือที่มีต้นไม้เข้าไปในฉาก แล้วนี่คือวิธีที่ผมต้องการให้วิดีโอเป็น จากนั้นผมต้องอธิบาย: อยากให้คำบรรยายเป็นแบบไหน คือข้อความที่เผยแพร่พร้อมวิดีโอของผม และนี่อาจเป็นอะไรก็ได้ เช่น เทคนิคเขียนหนังสือให้เร็วขึ้นด้วย ChatGPT แล้วก็มาถึงเพลง ฉันอยากได้เพลงแนวไหน? ผมพิมพ์อะไรก็ได้ เช่น lo-fi happy แล้วคลิก แล้วมันก็ถูกส่ง และตรงนี้คุณเห็นว่าข้อความถูกแยกออกเป็นวิดีโอ ไอเดียคำบรรยาย และสไตล์เพลง ทั้งหมดนี้มันทำงาน

ตอนนี้เราสามารถเชื่อมต่อกลับไปที่ get image และสิ่งที่โมดูลนี้ทำคือดึงรูปภาพจาก Telegram ของเรา และตรงนี้คุณต้องใส่ bot token อีกครั้ง คุณแค่กลับไปที่บอทของคุณ แล้วคุณจะพบโทเคนตรงนี้ วาง bot token ลงไป แล้วคลิก test เพื่อดูว่ามันทำงานไหม และเมื่อมันแสดงแบบนี้ก็แปลว่ามันทำงาน ตอนนี้กลับไป

จากนั้นเราต้องอัปโหลดรูปภาพเพื่อให้เข้าถึงได้แบบสาธารณะ และตรงนั้นคุณต้องใส่ cloud name ของคุณ และคุณต้องได้สิ่งนี้ก่อน คุณต้องมีบัญชี Cloudinary คลิก get started for free นี่คือเครื่องมือที่คุณใช้ฟรีเพื่อโฮสต์ไฟล์และทำให้เข้าถึงได้แบบสาธารณะด้วยลิงก์ และเมื่อตั้งค่าบัญชีฟรีแล้วคุณต้องไปที่แดชบอร์ด แล้วตรงนี้คือ cloud name ที่คุณต้องวางลงไป แล้วเลือก basic แล้วตรงนี้ภายใต้ credential นี้ คุณต้องเลือกอันนี้ แล้วคลิก create new แล้วใส่ user และ password และคุณจะพบวิดีโอสอนสั้น ๆ ใน technical tutorials: get credentials from Cloudinary แค่ดูแล้วคัดลอกลงตรงนี้

แล้วเรามาต่อตรงนี้ อันนี้ควรถูกโหลดไว้ล่วงหน้าให้คุณแล้ว สิ่งเดียวที่ต้องทำคือสร้าง upload preset คุณจะได้มันภายใต้ Settings > Upload แล้วตรงนั้นคุณต้องเพิ่ม อันนี้ชื่อไม่สำคัญ สิ่งที่สำคัญคือต้องสลับเป็น unsigned แล้วคลิก แล้วคุณจะได้ค่ามาวางตรงนี้ และเมื่อคลิก test มันควรทำงานและให้ URL ของรูปภาพที่อัปโหลดไปยัง Cloudinary อย่างที่เห็น เยี่ยม ไปต่อกัน

ต่อไปเรามาถึงโมดูล generate video แล้ว ดับเบิลคลิกที่มัน ตอนนี้เราต้องใช้เครื่องมือหรือแพลตฟอร์มที่ชื่อ PiAPI นี่คือที่เราใช้ตัวสร้างภาพ และเราจะใช้มันสำหรับเพลงด้วย มันคือแพลตฟอร์มที่คุณสามารถเข้าถึงเครื่องมือ AI ต่าง ๆ จากที่เดียว และตรงนี้เราใช้ Kling นั่นคืออย่างแรกที่เราใช้ นี่คือตัวสร้างวิดีโอ และตรงนั้นคุณต้องเชื่อมต่อบัญชี คลิก create a new แล้วใส่ name และ value ลงตรงนี้ ผมมีวิดีโอสอนสำหรับคุณแล้ว: get API credentials from PiAPI ดูวิดีโอนั้น แล้ววางค่านี้ลงตรงนี้แล้วคลิก save แล้วตรงนี้ควรถูกโหลดไว้ล่วงหน้าให้คุณ ตอนนี้ทุกอย่างควรเป็นสีเขียว แค่นั้น

ตอนนี้คือข้อมูลสำคัญ นี่คือพารามิเตอร์ที่ใช้สร้างวิดีโอ คุณเห็นที่นี่ 9:16 มันเป็นรูปแบบแนวตั้ง (vertical) สิ่งเดียวที่คุณอาจต้องปรับคือความยาววิดีโอ คุณมีความยาววิดีโอได้ 5 วินาทีหรือ 10 วินาที คุณตัดสินใจตรงนี้ นั่นคือสิ่งเดียว ผมปล่อยไว้ที่ 5 วินาทีเพราะมันเพียงพอสำหรับวิดีโอสั้น ถ้าคุณเปลี่ยนเป็น 10 คุณต้องเพิ่มเวลารอเป็น 5 นาที ผมจะพิมพ์ 5 นาที เพราะนี่คือระยะเวลาที่วิดีโออาจใช้ในการสร้างและประมวลผล ก่อนที่เราจะใช้มันต่อในขั้นตอนถัดไป

ขั้นตอนถัดไปคือ get the video URL อันนี้ควรโหลดไว้ล่วงหน้าแล้ว ถ้าเรารันอันก่อนหน้า เราต้องรอประมาณสองนาทีครึ่งจนกว่าวิดีโอจะถูกสร้าง และถ้าผมไปที่ PiAPI แล้วคลิก ผมจะเห็นว่าการสร้างวิดีโอกำลังดำเนินการ และคุณยังเห็นค่าใช้จ่ายการใช้งานตรงนี้ มันราคา 26 เซนต์ต่อวิดีโอ 5 วินาที และ 52 เซนต์สำหรับวิดีโอ 10 วินาที

ระหว่างที่รอ เราจะตั้งค่าโมดูลอื่น ๆ ตรงนี้ เรามี generate music อันนี้ควรโหลดไว้ล่วงหน้าแล้ว ตรงนี้คุณแค่เลือกบัญชีเดียวกับ PiAPI มันจะเป็นบัญชีเดียวกันเสมอ เหมือนกับการสร้างภาพ และตรงนี้เรามี prompt และมันจะเปลี่ยนเป็นสีเขียวเมื่อวิดีโอของเราถูกสร้างแล้ว และนี่คือสไตล์เพลง นี่คือค่าที่มาจากตอนเริ่มต้น ซึ่งถูกแยกออกมาตรงนี้ คุณเห็น lo-fi music, happy music นี่คือเพลงที่จะถูกสร้างให้คุณ เราปล่อยไว้แบบนี้ แล้วเราจะได้ URL อันนี้ก็ไม่ต้องเปลี่ยนอะไร

ตรงนี้เรามีข้อความบนวิดีโอ นี่คือข้อความที่แสดงด้านบนของวิดีโอ แบบสองบล็อก บล็อกหนึ่งและสอง และนี่คือสิ่งที่โมดูลนี้สร้างให้เรา นี่คือโครงสร้างของวิดีโอ และตรงนี้หัวข้อก็คือไอเดียคำบรรยาย ไอเดียคำบรรยายคือส่วนที่เราใส่ตอนเริ่มต้น เช่น เทคนิคเขียนหนังสือให้เร็วขึ้นด้วย ChatGPT นี่คือสิ่งที่ผมใส่ และมันจะถูกคั่นด้วยเครื่องหมายจุลภาคเสมอ เพราะจุลภาคคือตัวคั่น และมันแยกออกมา ดังนั้นตรวจสอบให้แน่ใจว่าคุณมีเพียงสามส่วน: วิดีโอ คำบรรยายที่เป็นข้อความบนวิดีโอ และเพลง แค่นั้น

สิ่งเดียวที่ต้องเพิ่มคือบัญชี OpenAI ถ้าคุณยังไม่ได้เชื่อมต่อ และคุณจะพบวิดีโอสอนสั้น ๆ วิธีรับ OpenAI key วางลงตรงนี้ คลิก แล้วแค่นั้น ผมกลับไปได้ ตอนนี้มันเสร็จแล้ว และเราควรจะดึงวิดีโอได้ เราสามารถรีโหลดเพื่อดูว่ายังประมวลผลอยู่หรือเสร็จแล้ว และคุณเห็นว่ามันใช้เวลาประมาณ 2 นาที 20 วินาที ดังนั้นมันน่าจะพร้อมแล้ว ถ้าคุณคลิก test แล้วเห็นว่ามันเสร็จ แล้วคลิกที่มัน คุณเห็นตรงนี้มีชั้นหนังสือ มันไม่ใช่แค่ชั้นหนังสือ มันมีต้นไม้อยู่บนนั้น และคนกำลังดื่มชา ดี อันนี้ใช้ได้สำหรับผม ตอนนี้เราไปต่อได้

ผมจะไปที่โหนดนี้แล้วคลิก test แล้วมันจะรันโหนดก่อนหน้าเสมอ เรานำวิดีโอไปประมวลผลต่อผ่านกระบวนการทดสอบของเรา เรารอเพลง ใช้เวลาประมาณ 1 นาทีในการสร้างเพลง แล้วตรงนี้เรามีฟังก์ชันแยกอีกครั้ง มันจะชัดเจนขึ้นว่ามันทำอะไร เพราะตรงนี้ในวิดีโอเรามีข้อความสองข้อความ: ข้อความหนึ่งและข้อความสอง จากโมดูลนี้เราได้ตัวแปรข้อความสองตัว: ข้อความหนึ่งไปที่ด้านบน และข้อความสองไปที่ด้านล่าง และฟังก์ชันนี้แยกข้อความนี้ คุณไม่ต้องเปลี่ยนอะไร

และเรามีโมดูลที่รวมวิดีโอ ข้อความ และเพลงเป็นวิดีโอสุดท้าย และสำหรับสิ่งนั้นเราใช้เครื่องมืออีกตัวที่ชื่อ JSON2Video คุณจะพบลิงก์และสมัครบัญชีฟรีได้ และรับเครดิตฟรี และถ้าคลิก get your free API key แล้วเมื่อทำเสร็จคุณสามารถเข้าสู่ระบบได้ แล้วสิ่งแรกที่ต้องทำคือตรงนี้ภายใต้ custom คุณเห็นไหม ผมไม่แน่ใจว่ามันโหลดไว้ล่วงหน้าหรือเปล่า แต่ถ้าไม่ คุณจะพบโค้ดชิ้นนี้ตรงนี้ใช่ไหม คุณคัดลอกวางลงตรงนี้ แล้วนี่คือ JSON2Video API ของคุณ และคุณจะพบวิดีโอสอนวิธีได้มาในส่วน technical tutorials แล้ววางลงตรงนี้แล้วไปต่อ คลิก save ผมจะเลือกบัญชีที่เชื่อมต่อไว้แล้ว

และตรงนี้คุณไม่ต้องตั้งค่าอะไร นี่คือการรวมวิดีโอของเรากับข้อความ นี่คือข้อความบนวิดีโอ นี่คือข้อความที่ด้านล่าง และนี่คือแทร็กเพลง สิ่งที่คุณปรับได้คือสไตล์ฟอนต์ของข้อความ ขนาดฟอนต์ และอื่น ๆ คุณทดลองได้ ผมจะคลิก test step แล้วมันควรให้ผลลัพธ์จากโหนดก่อนหน้า และตรงนี้เมื่อเราเปิดมัน ปกติทุกอย่างควรเป็นสีเขียวเมื่อเราคลิก วิดีโอเป็นสีเขียว ข้อความหนึ่งเป็นสีเขียว ข้อความสองเป็นสีเขียว และไฟล์เพลงเป็นสีเขียว ดี

ตอนนี้เรามี wait node เพื่อรับ URL สุดท้าย เพราะมันจะใช้เวลาสองสามวินาทีจนกว่าวิดีโอจะถูกสร้าง โดยปกติประมาณ 10-15 วินาที แล้วเรามีการเชื่อมต่อบัญชี OpenAI ซึ่งเชื่อมต่อไว้แล้วเพราะเราตั้งค่าไว้แล้ว แค่นั้นพอ และนี่คือส่วนที่สร้างข้อความคำบรรยายโซเชียลมีเดียให้เรา นั่นคือข้อความที่ไปพร้อมกับวิดีโอบนแพลตฟอร์มเผยแพร่ของเรา

แล้วมาถึง Google Sheet คุณจะพบเทมเพลต Google Sheet ด้านล่างวิดีโอนี้ เปิดมัน แล้วคลิก make a copy นี่คือที่ที่เราจะเก็บวิดีโอที่สร้างทั้งหมด และพวกมันจะถูกใช้สำหรับการเผยแพร่: เผยแพร่วิดีโอและข้อความคำบรรยายไปยัง YouTube Shorts และ TikTok เราจะตั้งค่าส่วนนี้ในวิดีโอหน้า ตรงนี้คุณเห็นมันถูกตัดต่อ เรายังมีเพลงในพื้นหลังด้วย เยี่ยม นี่คือวิดีโอสุดท้าย และทุกอย่างเป็นสีเขียว ดังนั้นผมสามารถทดสอบขั้นตอนนี้ได้ และนี่คือข้อความคำบรรยาย คุณสามารถปรับสไตล์ของคำบรรยายนี้ได้โดยการแก้ prompt นี้ ผมปล่อยไว้แบบนั้น

ใน Google Sheets สิ่งที่ต้องทำก่อนอื่นคือไปที่ Google Sheet ของเรา และก่อนใช้งานคุณต้องคลิก authorize เพราะ Google Sheet นี้มีฟีเจอร์พิเศษที่ช่วยให้วิดีโอของคุณถูกเผยแพร่โดยอัตโนมัติตามตารางการเผยแพร่ที่คุณตั้งได้ตรงนี้ คุณสามารถกำหนดได้: ต้องการเผยแพร่วิดีโอกี่รายการต่อวัน? ผมตั้งได้ตรงนี้ ผมตั้งเวลาได้ตามต้องการ เช่น 9 โมงเช้าถึง 19:00 น. และวิดีโอจะถูกเผยแพร่แบบสุ่มกระจาย อันหนึ่งช่วงเช้า อันหนึ่งช่วงบ่าย และวิดีโอทั้งหมดที่สร้างด้วยระบบอัตโนมัติของผมจะถูกบันทึกไว้ที่นี่

และอีกอย่างที่ต้องทำคือคลิก install แล้วแค่นั้น เพราะนี่คือ Google Sheet ที่มีสคริปต์ที่ทำงานนี้ให้เรา มันจัดตารางโพสต์เหล่านี้ให้ตามตารางการเผยแพร่ของเรา ตรงนี้ผมจะตั้งชื่อเฉพาะให้มัน แล้วกลับไปที่ n8n และตรงนี้คุณต้องสร้างบัญชี Google ใหม่ ถ้าคุณยังไม่ได้เชื่อมต่อ คลิก sign in with Google แต่ก่อนที่คุณจะทำ คุณต้องแน่ใจ: บัญชี Google ที่คุณใช้ต้องเป็นบัญชีเดียวกับที่มี Google Sheet นี้ คุณเอาตัวชี้ไปที่รูปโปรไฟล์ด้านบนขวา แล้วคุณจะเห็น และคลิก sign in with Google ผมเลือกแล้วคลิก และนั่นคือทั้งหมดที่ต้องทำ

และเมื่อผมคลิกที่เอกสารนี้ มันควรโหลด Google Sheet นี้ ตรงนี้ผมต้องเลือกชีต videos แล้วแมปคอลัมน์อีกครั้ง ตรงนี้ผมต้องลบสองอันนั้น แล้วเลือก schema ตรงนี้ ข้อความคำบรรยายมาจากตรงนี้ URL วิดีโอสุดท้ายมาจากอันนั้น และ video ID มาจากตอนเริ่มต้น video ID แค่นั้น ตอนนี้ถ้าผมคลิก test ข้อมูลนี้ควรถูกส่งไปยังแถวแรก อย่างที่เห็นมันทำงานแล้ว

และเรายังต้องการข้อความกลับจากวิดีโอไปยัง Telegram ด้วย ถ้าผมคลิก test มันจะส่งข้อความคำบรรยายที่สร้างพร้อมลิงก์วิดีโอ และมันจะส่งวิดีโอให้ผมโดยตรงด้วย ถ้าผมคลิก test มันจะส่งวิดีโอมาตรงนี้ ตรวจสอบให้แน่ใจว่าตรงสองโมดูลสุดท้ายนี้คุณเลือกบัญชี Telegram ที่ถูกต้อง แล้วคลิก save และตอนนี้ด้วยส่วนนี้ เราทำเสร็จแล้วสำหรับวิดีโอนี้ ไปที่วิดีโอถัดไป เราจะตั้งค่ากระบวนการเผยแพร่
