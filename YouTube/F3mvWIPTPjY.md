# Thai Summary - OPNSense Monitoring with Prometheus, Alloy and Grafana

## บทสรุปวิดีโอ

- แนะนำระบบการจับติดตามแบบ centralized สำหรับไฟร์วอลล์ OPNSense โดยใช้ Prometheus, Alloy และ Grafana
- อธิบายความจำเป็นของระบบการจับติดตามแบบ centralized เพื่อการวิเคราะห์ปัญหาระบบและประสิทธิภาพ
- เปรียบเทียบระหว่าง dashboard ที่มีอยู่ใน OPNSense กับระบบการจับติดตามที่กำลังจะสร้าง
- แสดงข้อดีของการเชื่อมโยงสถิติหลายๆ ตัวพร้อมกันเพื่อการวิเคราะห์ปัญหาได้เร็วขึ้น
- อธิบายวิธีการปรับแต่ง dashboard และ queries เพื่อตรวจสอบระบบหลายตัวพร้อมกัน
- แสดงวิธีการหาสาเหตุของปัญหาเช่น spike ในการใช้งาน CPU ที่สัมพันธ์กับการใช้งานเครือข่ายสูง
- ครอบคลุมกรณีการใช้งานที่จำเป็นต้องใช้ระบบการจับติดตามขั้นสูง
- นำเสนอโซลูชันที่ช่วยให้การตรวจสอบและแก้ไขปัญหาระบบมีประสิทธิภาพมากขึ้น
