## บทนำ

ในบทเรียนนี้ โรบี้ แบลนชาร์ด (Robby Blanchard) พาเราเข้าไปดูเทมเพลต landing page template (เทมเพลตหน้าเว็บตัวกลาง) สำเร็จรูปที่ผ่านการพิสูจน์แล้วและออกแบบมาให้สอดคล้องกับข้อกำหนด compliance (ข้อกำหนดของแพลตฟอร์มโฆษณา) ในชุดเครื่องมือ proven toolkit ของคอร์สนี้ เขาสาธิตวิธีสร้างเว็บไซต์ สร้าง landing page แรก และปรับแต่งให้เป็นของเราเองได้ง่ายๆ บทเรียนนี้เหมาะสำหรับคนที่กำลังทำ pay-per-call (จ่ายเงินต่อสายเรียกเข้า) หรือ CPA (จ่ายเงินต่อการกระทำ) แล้วอยากได้หน้าเว็บที่เปิดใช้ได้ทันที

## คำแปลเต็ม

ยินดีต้อนรับสู่บทเรียนอีกบทหนึ่งในโมดูลที่ห้าครับ เราอยู่ในหัวข้อ landing pages (หน้าเว็บตัวกลาง) และ call funnels (ช่องทางกรองสายเรียกเข้า) ครับ.

ในบทเรียนที่แล้ว ผมได้พูดถึง landing page ไปแล้ว รวมถึงสูตร landing page ที่สมบูรณ์แบบ ไม่ว่าจะเป็นหัวข้อ headline (พาดหัว) ไปจนถึงคำกระตุ้นการตัดสินใจ call to action (ปุ่มหรือข้อความชวนโทร) หรือจะใส่แบบทดสอบ quiz สั้นๆ แบบเลือกได้เพื่อกระตุ้นความอยากรู้อยากเห็น รวมถึงตัวแปรต่างๆ ที่ใส่ลงไปใน headline ได้ พร้อมยกตัวอย่างหลายแบบว่าหน้าตาเป็นยังไงครับ.

แต่วันนี้ผมตื่นเต้นมากกับบทเรียนนี้ เพราะเราจะมาดูเทมเพลต landing page template (เทมเพลตหน้าเว็บตัวกลาง) สำเร็จรูปที่ผ่านการพิสูจน์แล้วและเป็นมิตรต่อ compliance (สอดคล้องกับข้อกำหนดของแพลตฟอร์มโฆษณา) ในชุดเครื่องมือ proven toolkit (ชุดเครื่องมือที่พิสูจน์แล้ว) กันครับ.

สิ่งที่ยอดเยี่ยมคือคุณได้สิทธิ์เข้าถึงชุดเครื่องมือนี้พร้อมกับคอร์สนี้ มันรวมทุกเครื่องมือที่ผมพูดถึงไว้ให้เลย ไม่ว่าจะเป็นเครื่องมือสำหรับสร้างเพจแฟนเพจ fan page หรือสร้างคอนเทนต์ content ก็มีให้หมด เยี่ยมมากเลยครับ.

และตอนนี้เราจะเจาะลึกเข้าไปในส่วนของ landing page ซึ่งก็เจ๋งไม่แพ้กันครับ เพราะว่ามันถูกสร้างสำเร็จรูปมาให้คุณแล้ว คุณแค่ปรับแต่งเล็กน้อยเพื่อให้มันดูเป็นเอกลักษณ์ของเราเองก็พอครับ.

งั้นเราไปดำดิ่งสู่ proven toolkit กันเลยครับ.

เราจะเข้าไปที่ dashboard (หน้าควบคุมระบบ) กันก่อนครับ เมื่อคุณล็อกอินเข้า dashboard คุณจะเห็นทุกอย่างถูกตั้งค่าไว้สำหรับยอดขายของคุณ และหวังว่าคุณจะเห็นยอดขายเหล่านั้นเข้ามาเรื่อยๆ นั่นน่าตื่นเต้นมากครับ.

แต่ก่อนอื่นเราจะไปที่ส่วน home ก่อน แล้วเลื่อนลงมาที่หัวข้อ landing ครับ.

สิ่งแรกที่เราจะทำคือคลิกที่ landing page editor (เครื่องมือแก้ไขหน้าเว็บตัวกลาง) ครับ.

เมื่อคุณเข้าไปที่หน้า landing page คุณจะเห็นการแจ้งเตือนสำคัญบอกว่าให้ไปดูหน้าบทแนะนำ tutorial นี้ก่อนที่จะเริ่มใช้เครื่องมือครับ.

ถ้าคุณคลิกเข้าไป มันจะให้บทแนะนำหลายอย่าง ซึ่งผมจะพูดถึงในบทเรียนนี้ด้วย มันจะอธิบายวิธีเชื่อมต่อ URL หรือ domain (ชื่อโดเมน) ของคุณเข้ากับ landing pages ของคุณ และยังมีคำแนะนำเรื่องการติดตั้ง pixel (โค้ดติดตามการแปลง) ซึ่งทั้งหมดนี้มีอยู่ในบทเรียนและในคอร์สนี้ด้วย แต่ถ้าคุณมีคำถาม มันก็มีขั้นตอนทีละสเต็ปให้ดูเพิ่มเติมครับ.

เพราะฉะนั้นอย่าลืมอ่านหน้านั้นก่อนที่จะเริ่มใช้เครื่องมือด้วยนะครับ.

พอเข้ามาที่เครื่องมือสำหรับ landing page คุณจะเห็นหัวข้อที่เขียนว่า my sites (เว็บไซต์ของฉัน) ครับ ตอนนี้คุณยังไม่มีเว็บไซต์อะไรที่นี่ ส่วนผมมีเว็บไซต์ทดสอบอยู่แล้ว แต่เดี๋ยวผมจะโชว์วิธีสร้างเว็บไซต์ให้ดูครับ.

จำได้ไหมครับ ตอนที่เราทำคอนเทนต์สำหรับแฟนเพจหรือ business page (เพจธุรกิจ) เราตั้งชื่อแฟนเพจและใช้เครื่องมือต่างๆ ในนั้น เราอยากสร้างเว็บไซต์ของเราโดยใช้ชื่อที่คล้ายกับชื่อแฟนเพจหรือชื่อกลุ่มธุรกิจ vertical (กลุ่มธุรกิจเฉพาะ) ก็ได้ครับ จะแบบไหนก็ได้ทั้งนั้น.

ปกติแล้วผมจะใช้ชื่อตามแฟนเพจ เช่นอันนี้ชื่อว่า auto insurance one test (ประกันรถยนต์ชุดทดสอบ) แต่ถ้าผมอยากตั้งชื่อเว็บไซต์ตามชื่อแฟนเพจ ก็เป็นอีกวิธีหนึ่งที่ช่วยให้รู้ว่าเว็บไซต์ไหนมี landing page อะไรอยู่ข้างในครับ.

เพราะจริงๆ แล้วคุณมีหนึ่งธุรกิจ หนึ่งแฟนเพจ แล้วคุณก็วิ่งโฆษณาสำหรับกลุ่มธุรกิจ vertical นั้นให้กับแฟนเพจนั้นครับ.

เอาล่ะ ผมจะกด create new site (สร้างเว็บไซต์ใหม่) ครับ.

เมื่อกดสร้างเว็บไซต์ใหม่ คุณจะเห็นว่ามันให้กรอก title (ชื่อเรื่อง) ซึ่งจะใส่อะไรก็ได้ครับ ปกติผมจะตั้งตามชื่อแฟนเพจหรือ business page ของผม แต่คุณจะตั้งตาม vertical ก็ได้ เช่น ถ้าเป็นเรื่องหนี้รถยนต์ก็ใส่ auto debt หรือถ้าเป็นเรื่องเงินออมก็ใส่ savings อะไรแบบนั้นครับ.

ถ้าเว็บไซต์นี้มาจากแฟนเพจ ผมอาจจะมีแฟนเพจหรือ business page ชื่อ savings แล้วก็กรอก site URL (ที่อยู่เว็บไซต์) ครับ.

ตรงนี้ไม่ใช่ domain ที่คุณซื้อมานะครับ เดี๋ยวผมจะสอนในโมดูลนี้ว่าต้องซื้อ domain ยังไงและตั้งค่าอย่างไร แต่อันนี้ไม่ใช่ domain จริงของคุณ ไม่ต้องกังวลไปครับ.

คุณแค่ใส่อะไรก็ได้ลงไปตรงนี้ จะตั้งชื่ออะไรก็ได้ มันเหมือนกับชื่อ lander (หน้าเว็บโฆษณา) ของคุณนั่นแหละครับ.

สำหรับอันนี้ผมจะใส่ savings ก็แล้วกัน ถ้าเป็นประกันรถยนต์ผมอาจจะใส่อย่างอื่น แต่ไม่ต้องกังวลกับชื่อนี้มากนัก มันเป็นแค่ชื่อเรียกภายในเท่านั้นครับ.

จากนั้นมันก็เลือกเทมเพลต auto insurance (ประกันรถยนต์) ไว้ให้แล้ว ถ้าคุณเข้าไปดู คุณอาจจะเห็นเทมเพลตอื่นๆ ด้วย เช่น debt relief (การปลดหนี้) หรือ vertical อื่นๆ ซึ่งจะมีการอัปเดตเพิ่มเติมตามคอร์สในบทต่อๆ ไปครับ.

แต่ตอนนี้คุณใช้เทมเพลตเดียวกันนี้ได้หมดทุกอันครับ.

คุณเลือก auto insurance แล้วมันจะขึ้นว่า selected (เลือกแล้ว) ถ้ายังไม่เลือกก็คลิกเลือก แล้วกด create site (สร้างเว็บไซต์) ครับ.

คุณจะเห็นข้อความขอบคุณ บอกว่าธุรกรรมของคุณเสร็จสมบูรณ์ และใบเสร็จการซื้อถูกส่งไปทางอีเมลแล้ว ไม่ต้องกังวลนะครับ คุณจะไม่ถูกเรียกเก็บเงินอะไรทั้งนั้น.

ตอนนี้คุณจะเห็นว่าผมมีเว็บไซต์ชื่อ Savings Today (เซฟวิ่งส์ทูเดย์) แล้ว ผมจะเข้าไปที่ admin (หน้าการจัดการ) แต่จริงๆ ผมจะกด visit (เยี่ยมชม) ก่อน เพื่อให้คุณเห็นว่าหน้าตาเป็นยังไงครับ.

เมื่อกดเข้าไป คุณจะเห็นว่าเว็บไซต์ตอนนี้เป็นแบบนี้ นี่คือเว็บไซต์ของผม มันจะมีข้อความประมาณว่า คุณกำลังมองหาประกันรถยนต์อยู่ใช่ไหม ซึ่งจริงๆ แล้วนี่เป็นแค่หน้า placeholder (หน้าตัวยึดตำแหน่ง) ใน funnel (ช่องทางการขาย) ของคุณเท่านั้นครับ.

จะมีข้อความว่า นี่คือสิ่งที่ผมเรียนรู้เกี่ยวกับการเลือกกรมธรรม์ที่เหมาะกับความต้องการและงบประมาณของคุณ นี่เป็นแค่ตัวยึดตำแหน่งสำหรับเว็บไซต์แรกของคุณครับ.

ในการเข้าไปปรับแต่งเว็บไซต์และสร้าง landing page เราต้องกลับไปที่หัวข้อ my sites แล้วคลิกที่ Savings Today เพื่อเข้าไปที่ dashboard ครับ.

จริงๆ แล้วถ้าผมกด admin panel (แผงผู้ดูแลระบบ) มันก็จะพามาที่หน้านี้เหมือนกัน แต่ผมอยากให้คุณเห็นว่าถ้ากด view site (ดูเว็บไซต์) หน้าตาเว็บไซต์เดี่ยวๆ จะเป็นแบบไหน ซึ่งนั่นไม่ใช่ landing page ของคุณนะครับ.

เดี๋ยวเราจะเข้าไปที่ landing pages กันในอีกไม่กี่อึดใจ แต่สิ่งหนึ่งที่ต้องจำไว้คือ ในหน้าเว็บไซต์ของคุณจะมี settings (การตั้งค่า) ทั้งหมดอยู่ที่นี่ นี่คือที่ตั้งค่าของ dashboard ครับ.

ถ้าคุณอยากเปลี่ยนชื่อเว็บไซต์ คุณก็กด see more (ดูเพิ่มเติม) ได้ครับ.

สมมติว่าผมอยากเปลี่ยนชื่อเว็บไซต์ ผมก็เข้าไปในนี้ได้ และยังเปลี่ยนเทมเพลตหรือทำอย่างอื่นได้อีกหลายอย่างครับ.

แต่คุณต้องแน่ใจว่า เช่น ถ้าผมอยากแก้ชื่อ Savings Today ผมก็กด edit (แก้ไข) แล้วเปลี่ยนชื่อได้เลยครับ.

ปกติแล้วคุณไม่จำเป็นต้องเปลี่ยนชื่อหลังจากสร้างเสร็จแล้ว แต่ถ้าคุณเผลอตั้งชื่อผิด หรือตัดสินใจอยากเปลี่ยน ก็เปลี่ยนตรงนี้ได้เลย ไม่มีปัญหาครับ แค่เปลี่ยนแล้วกด save changes (บันทึกการเปลี่ยนแปลง) เท่านั้นเอง.

กลับมาที่ dashboard กันครับ ถ้าคุณต้องการแก้ไขอะไรเกี่ยวกับเว็บไซต์ คุณก็ทำได้ตรงนี้.

แต่เดี๋ยวจะมีบทเรียนหนึ่งในโมดูลนี้ที่เราจะมาคัดเลือก domain และเพิ่ม domain เข้าไป ซึ่งสำคัญมาก เพราะเราต้องแน่ใจว่า domain เชื่อมต่อกับเว็บไซต์ของเราแล้ว จะได้เอาไปใช้กับ landing page ได้ครับ.

ผมจะโชว์ตรง settings อีกครั้ง เดี๋ยวเราจะลงรายละเอียดลึกกว่านี้ตอนที่พูดถึงการติดตั้ง tracking (เครื่องมือวัดผล) เพราะมันสำคัญมาก รวมถึงการยืนยัน Facebook verification (การยืนยันความเป็นเจ้าของ) ผ่าน meta tag (แท็กเมตาดาต้า) ซึ่งเราจะพูดถึงอีกครั้งตอนคุยเรื่อง domain ครับ.

ต่อจากนั้นคุณจะเห็น pixel code (โค้ดพิกเซล) อยู่ทางด้านซ้าย นี่คือ pixel code ที่เราคุยกันไปแล้ว อันนี้มันแสดงอยู่ให้เห็น แต่คุณต้องแน่ใจว่าได้ดูโมดูลเรื่องการติดตั้ง pixel เรียบร้อยแล้ว เพราะ pixel จะถูกวางไว้ตรงนี้ครับ.

ส่วนที่เหลือก็เป็นแค่ส่วนช่วยเหลือ ถ้าคุณต้องการติดต่อทีมงานด้วยเหตุผลใดก็ตาม หรือมีคำถาม หรือมีปัญหากับเว็บไซต์ของคุณ ก็ติดต่อศูนย์ช่วยเหลือ support center ได้ตรงนี้ครับ.

เอาล่ะ ต่อไปผมจะไปที่ landing pages เพื่อสร้าง landing page แรกของเรา เราต้องสร้างเทมเพลต landing page ใหม่ก่อน แต่คุณจะเห็นว่าเทมเพลตเหล่านี้ถูกสร้างสำเร็จรูปไว้ให้แล้ว.

ขั้นตอนต่างๆ ใน funnel ของคุณถูกเตรียมไว้ให้ครบแล้ว ไม่ว่าจะเป็นหน้า about (หน้าเกี่ยวกับเรา) หน้า contact (หน้าติดต่อ) และหน้า homepage (หน้าหลัก) ซึ่งถ้าผม preview (ดูตัวอย่าง) ก่อนหน้านี้ นั่นคือหน้าหลักนั่นเองครับ.

ถ้าผมอยากแก้ไขคำถาม เช่น อยากปรับให้เข้ากับ offer หรือเงื่อนไขว่าคุณต้องอาศัยอยู่ในพื้นที่ใดพื้นที่หนึ่ง คำถามอย่างเช่น คุณมีประกันอยู่แล้วหรือยัง ก็แก้ไขคำถามได้ และคุณเห็นปุ่ม yes หรือ no ตรงนี้ไหมครับ.

คุณไม่เพียงแต่แก้ไขคำถามได้ แต่ยังแก้ไขฟอนต์ได้ด้วย เห็นฟอนต์ตรงนี้ไหมครับ ถ้าอยากได้แบบอื่นก็เปลี่ยนได้.

สมมติว่าผมอยากเพิ่มคำถามอีกข้อ เช่น คุณเป็นเจ้าของบ้านหรือเปล่า หรือคำถามว่าคุณอาศัยอยู่ในรัฐใด ซึ่งรัฐใดต่อไปนี้ที่คุณอาศัยอยู่.

คำถามเหล่านี้จะช่วยคัดกรองลูกค้าเบื้องต้น pre-qualify (คัดกรองล่วงหน้า) สิ่งที่ต้องจำไว้ตอนตั้งคำถามใน quiz คือ คุณอยากคัดกรองลูกค้า แต่คุณอยากให้ทุกคำถามคัดกรองได้จริง ไม่อยากได้คำถามที่ไม่ช่วยคัดกรองอะไรเลย ถ้าเข้าใจตรงกันนะครับ.

ผมอยากแน่ใจว่าทุกคำถามมีคำตอบที่นำไปสู่ขั้นตอนถัดไปได้อย่างน้อยหนึ่งคำตอบ จุดนี้สำคัญมากครับ.

quiz พวกนี้จะช่วยกรองคน และทำให้ได้คนโทรเข้ามาที่มีคุณสมบัติตรง ซึ่งนั่นคือสิ่งที่คุณต้องการ เพราะคุณจะได้ค่าตอบแทนจากการโทรแต่ละครั้ง พวกเขาจะอยู่บนสายและคุยกันต่อได้จริงครับ.

ตัวอย่างคำถาม ต่อไปนี้คุณอาศัยอยู่ในรัฐใด จากนั้นผมจะเลื่อนลงมาแล้วกรอกคำตอบ ผมแก้ไขคำตอบแรกได้ เช่น Wisconsin หรือ New York แล้วแต่ offer ของคุณ ถ้า offer นี้รองรับ 15 รัฐ และคุณได้ค่าตอบแทน tier (อัตราที่สูงกว่า) สำหรับบางรัฐ ผมก็ใส่ได้ เช่น Wisconsin กับ Florida ผมแค่ยกตัวอย่างมั่วๆ นะครับ.

ผมยังเปลี่ยนสไตล์ของคำตอบได้ด้วย เช่น สีพื้นหลัง ถ้าอยากเปลี่ยนก็ทำได้ มีอะไรให้ปรับอีกหลายอย่าง แต่ฟอนต์ผมจะคงไว้เหมือนเดิม แล้วก็ save ครับ.

จากนั้นผมจะเพิ่มคำตอบอีกข้อ เพราะอยากได้อีกหนึ่งรัฐให้เลือก และไม่สำคัญว่าพวกเขาจะเลือกคำตอบไหน พวกเขาก็ยังผ่านการคัดกรองอยู่ดี เพราะผมใส่เฉพาะรัฐที่รองรับ offer นี้เท่านั้น.

รัฐถัดไปก็ใส่ Colorado แค่นั้น และมีแค่สองคำตอบนี้ ไม่ว่าพวกเขาจะอาศัยอยู่ในรัฐใดในนี้ พวกเขาจะเลือกคำตอบใดคำตอบหนึ่ง แล้วผมก็ save ครับ.

ถ้าผมอยากไปที่ style เพื่อเปลี่ยนสีตัวอักษร text color ก็ทำได้ บางทีผมอยากให้ตัวอักษรเป็นสีอื่น หรือเปลี่ยนขนาดฟอนต์ font size หรือสีพื้นหลัง background color ก็เปลี่ยนได้ทั้งหมดตรงนี้ครับ.

จากนั้นมันจะแสดงขั้นตอน validating (กำลังตรวจสอบ) analyzing (กำลังวิเคราะห์) confirming (กำลังยืนยัน) ซึ่งเป็นสิ่งที่เราเห็นในทุกเทมเพลต ตรงนี้ดีอยู่แล้ว ผมจะไม่แก้อะไรมากครับ.

หลังจากนั้นก็ถึงขั้น qualify (ผ่านการคัดกรอง) ถ้าเราแก้ตรงนี้ ผมจะเข้าไปที่ dynamic phone numbers (เบอร์โทรแบบไดนามิก) นี่คือจุดที่เราใส่เบอร์โทรของเรา พอลูกค้าตอบคำถามครบและผ่านการคัดกรองแล้ว ระบบก็จะโชว์เบอร์โทรที่คุณต้องการให้พวกเขาโทรเข้า ขึ้นมาทันทีครับ.

ผมจะโชว์ให้ดูคร่าวๆ ว่าหน้าตาเป็นแบบไหน และคุณเปลี่ยนอะไรได้อีกหลายอย่างในนี้ แต่เดี๋ยวผมจะกด save แล้ว preview ให้ดูกันครับ.

อีกเรื่องที่ต้องจำเกี่ยวกับ landing pages เหล่านี้คือ ตอนที่คุณกด publish (เผยแพร่) คุณไม่ควรกด save to draft (บันทึกร่าง) นะครับ การกด publish จริงๆ แล้วคือการบันทึก มันไม่ได้หมายความว่าหน้าเว็บจะออนไลน์ทันที มันหมายถึงการบันทึกงานของคุณไว้ต่างหาก.

คุณควรกดบันทึกเสมอ เพราะระบบไม่ได้บันทึกให้อัตโนมัติ และคุณอาจเสียงานที่ทำไว้ได้ครับ.

ผมจะกด publish แล้วโชว์ให้ดูว่าหน้าตาเป็นยังไงครับ.

นี่คือสิ่งที่ landing page จะเป็นแบบนี้ครับ มีคำถามว่า คุณมีประกันอยู่แล้วหรือยัง ตอบว่าใช่ แล้วคำถาม คุณเป็นเจ้าของบ้านหรือเปล่า.

เห็นไหมครับว่าผมปรับข้อความนิดหน่อย เปลี่ยนความแตกต่างของข้อความตรงนั้น แต่คุณยังเปลี่ยนปุ่ม เปลี่ยนข้อความบนปุ่ม เปลี่ยนฟอนต์ได้อีก มีรูปแบบให้ปรับเยอะมาก และนั่นจะทำให้ landing page ของคุณเป็นเอกลักษณ์ แค่เปลี่ยนสีก็ต่างแล้วครับ.

คำถาม คุณเป็นเจ้าของบ้านหรือเปล่า แล้วก็คำถาม คุณอาศัยอยู่ในรัฐใด เห็นไหมครับว่าปุ่มของผมมีสีต่างกัน ถ้าผมทำแบบสีเขียวก็จะเขียวทั้งชุด แต่ผมแค่อยากโชว์ว่าคุณปรับเปลี่ยนรูปแบบได้หลากหลายแค่ไหนครับ.

จากนั้นระบบก็จะแสดงขั้นตอนถัดไป ขึ้นข้อความ confirming และต่อจากนั้นก็ถึงจุดที่เบอร์โทรจะโผล่ขึ้นมาตรงนี้ เจ๋งไปเลยใช่ไหมครับ ทุกอย่างถูกเตรียมไว้ให้แล้ว.

มันมีตัวจับเวลา timer ที่สร้างความเร่งด่วน urgency (ความเร่งด่วน) ให้ด้วย ทุกอย่างถูกสร้างไว้ในนี้แล้ว สิ่งที่คุณต้องทำคือใส่เบอร์โทร แล้วก็ปรับแต่งนิดหน่อยเท่านั้นเองครับ.

landing pages พวกนี้ยอดเยี่ยมมาก และผมบอกไม่ถูกเลยว่ามันจะช่วยคุณได้มากแค่ไหน เพราะคุณมีเทมเพลตที่พิสูจน์แล้ว.

คุณต้องทำให้ landing page ของคุณเป็นของคุณเองบ้าง เช่น เปลี่ยนฟอนต์สักหน่อย เปลี่ยนคำสองสามคำใน ad copy (ข้อความโฆษณา) หรือหัวข้อย่อย subheadline (หัวข้อย่อย) หรือปรับคำถามใน quiz ของคุณสักเล็กน้อย.

ยิ่ง landing page ของคุณดูเป็นเอกลักษณ์มากเท่าไหร่ ผลลัพธ์ก็จะยิ่งดีเท่านั้นครับ.

ถ้าผมอยากกลับมาแก้ไขอีกครั้ง ผมไม่ต้องย้อนกลับไปที่ my sites แล้วเข้า landing ใหม่ ผมแค่กด visual editor (ตัวแก้ไขแบบเห็นภาพ) ซึ่งจะพากลับมาที่หน้าแก้ไข landing page นี้ได้เลยครับ.

อีกหนึ่งฟีเจอร์ที่ยอดเยี่ยมคือ ตอนนี้มันแสดงมุมมองแบบ desktop (คอมพิวเตอร์ตั้งโต๊ะ) หรือแล็ปท็อปอยู่ ถ้าผมอยากดูว่าหน้าตาเป็นยังไงบนมือถือหรือแล็ปท็อป ผมก็เลื่อนลงมาตรงนี้ แล้วเข้าไปที่ responsive editing (การแก้ไขแบบปรับตามอุปกรณ์) ครับ.

ฟีเจอร์นี้เจ๋งมาก เพราะคุณสามารถแก้ไขตามประเภทอุปกรณ์ได้ เช่น extra large (จอขนาดใหญ่มาก) ก็คือ desktop แล้วถ้าอยากแก้ไขตรงนี้ก็ทำได้ จากนั้น large (ขนาดใหญ่) จะเป็นแล็ปท็อป medium (ขนาดกลาง) จะเป็น iPad หรือแท็บเล็ต ส่วน small (ขนาดเล็ก) จะเป็นมือถือของคุณครับ.

ถ้าผมเข้ามาดูแล้วรูปภาพใหญ่เกินไป หรือหน้าตาแปลกๆ ผมก็แก้ไขตรงนี้ได้ โดยแก้ทั้งหมดในมุมมองมือถือ แล้วมุมมองบนมือถือก็จะดูดีขึ้นอย่างเป็นระบบ ทั้งสวยงามและใช้งานง่ายบนมือถือครับ.

นี่เป็นวิธีที่ยอดเยี่ยมในการเข้าไปจัดการ breakpoints (จุดแบ่งการแสดงผลตามขนาดจอ) และดูว่าหน้าตาเป็นยังไงในแต่ละขนาด ผมชอบทำงานในโหมด larger หรือ extra large เพื่อให้เห็นชัดเจนขณะที่ปรับแต่ง แล้วถ้าอยากแก้ไขอะไรเพิ่มเติมก็ทำได้ครับ.

ผมอยากโชว์ส่วนสุดท้ายให้ดู landing pages พวกนี้เจ๋งมาก ผมจะกด done (เสร็จสิ้น) แล้วกด publish เพื่อให้มันบันทึกงานไว้.

แล้วถ้าอยาก preview landing page ดูล่ะ เดี๋ยวผมโชว์วิธีทำครับ ตอนนี้ผมอยู่ที่ Savings Today ผมจะไปที่ my sites ตอนนี้ domain ยังไม่ได้ใส่ไว้ที่นี่ แต่ถ้าผมอยาก preview ก็แค่กด preview ที่หน้า landing auto insurance landing page ครับ.

ตอนนี้คุณจะเห็นว่า landing page ของผมอยู่ตรงนั้นแล้ว พอใส่ domain เข้าไปแล้ว ซึ่งเดี๋ยวผมจะโชว์ในบทเรียนเรื่อง domain ถ้าผมอยากเห็นว่าหน้าตาเป็นยังไง ก็คัดลอกลิงก์ไปวางในเบราว์เซอร์ได้ แต่ตอนนี้ domain ยังไม่ได้ใส่ไว้ ผมเลยทำไม่ได้ แต่ผม preview ได้ และมันจะแสดงให้เห็นว่า landing page ของผมหน้าตาเป็นยังไง และผมยังตรวจสอบทุกอย่างได้ด้วยครับ.

หวังว่าบทเรียนนี้จะเป็นประโยชน์นะครับ ผมพูดไม่รู้จบว่าชุดเครื่องมือนี้เจ๋งแค่ไหน และผมตื่นเต้นแทนคุณมาก ลงมือเล่นกับมันได้เลยครับ.

คุณจะอยากลองเทมเพลตต่างๆ และเล่นไปเรื่อยๆ เมื่อคุณคุ้นเคยกับ funnel builder (ตัวสร้างช่องทางการขาย) ใน pay-per-call profits มากขึ้น คุณก็จะเก่งขึ้นเรื่อยๆ ครับ.

เข้ามาเล่นได้เลย คุณทำพังไม่ได้หรอกครับ ผมแนะนำให้สร้าง landing page ทดสอบสักหน้า แล้วเข้าไปเล่นกับมัน เปลี่ยนฟอนต์ เพิ่มองค์ประกอบ elements เข้าไปใน landing page เพื่อให้คุณได้ลองเล่นและคุ้นเคยกับมัน.

ยิ่งคุณเข้ามาใช้ funnel builder นี้บ่อยเท่าไหร่ คุณก็จะยิ่งเก่งขึ้นเท่านั้นครับ และคุณสามารถสร้าง landing pages ได้มากเท่าที่ต้องการในเว็บไซต์ของคุณ.

ผมตื่นเต้นมากที่คุณจะได้เข้ามาลองเล่น ทำความคุ้นเคยกับ funnel builder ของคุณ และสนุกกับการสร้าง landing page ของคุณครับ.

ในบทเรียนหน้า เราจะมาพูดถึงอีกหนึ่งตัวเลือก ซึ่งเป็นทางเลือกเสริม secondary option (ทางเลือกเสริม) คร่าวๆ ผมจะให้ข้อมูลพอสังเขปเกี่ยวกับเทมเพลตสำเร็จรูป pre-built templates ที่คุณได้มาพร้อมกับคอร์สนี้ด้วยครับ.

แล้วเจอกันในวิดีโอที่สาม ขอบคุณครับ แล้วเจอกันนะครับ.
