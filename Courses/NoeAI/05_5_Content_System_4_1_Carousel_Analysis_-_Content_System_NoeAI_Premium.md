## คำแปลเต็ม

ยินดีต้อนรับสู่บทเรียน carousel analysis skill นะครับ สกิลนี้เป็นส่วนหนึ่งของ ไม่รู้สิ มันเป็นหนึ่งในสี่สกิลเกี่ยวกับ carousel ที่คุณจะได้ใช้ และแต่ละสกิลก็ทำงานเชื่อมโยงกันไปมา ดังนั้น carousel analysis จะวิเคราะห์รูปแบบจากคู่แข่งของคุณ เช่นเดียวกับที่คุณมี short form content analysis และ long form และเราจะปล่อยสกิลแบบนี้ออกมาเพิ่มเรื่อย ๆ ครับ

มันจะวิเคราะห์คู่แข่งของคุณ และให้การวิเคราะห์เต็มรูปแบบว่าพวกเขากำลังทำอะไรอยู่ และ carousel ของพวกเขา perform เป็นอย่างไร จากนั้นพอคุณได้ผลวิเคราะห์ครบแล้ว มันจะส่งต่อไปให้ carousel ideator ซึ่งจะสร้างไอเดีย carousel สำหรับทั้งสัปดาห์ของคุณ จากนั้นมันจะรับไอเดียเหล่านั้นไป แล้ว carousel creator จะลงมือสร้าง carousel จริง ๆ

ตอนนี้ สิ่งที่สกิลนี้ทำโดยเฉพาะคือ มันดึงข้อมูลจาก superbase data table ที่เราสร้างไว้ ถ้าคุณยังไม่ได้ดู ลองไปดูบทเรียน short form content system ได้ ถ้าคุณกำลังดูอยู่ มันคือ viral content หรือ short form content แต่ข้างในนั้น เราได้สร้าง superbase data table ขึ้นมา ผมจะโชว์วิธีตั้งค่ามันให้คุณดู โดยเราจะทำการ scrape คอนเทนต์ที่ชนะของคู่แข่งคุณทั้งหมด และคอนเทนต์ที่ชนะของคุณเองด้วย รวมถึง carousel ด้วย

และสิ่งที่ผมแนะนำ ถ้าคุณยังไม่ได้ดูคู่แข่งที่ทำ carousel เก่ง ๆ ผมแนะนำให้เริ่มขโมยของพวกเขาเลย คุณจะขโมยของผมก็ได้ บอกตรง ๆ เลย แต่สิ่งที่สกิลนี้จะทำคือ มันจะนำข้อมูลคอนเทนต์ของคุณและข้อมูลคอนเทนต์ของพวกเขามา แล้วก็ scrape มันออกมา มันจะดึงโพสต์ carousel ทั้งหมดของคุณจาก Supabase ดึง carousel คู่แข่ง 20 อันดับแรก โดยจัดอันดับตามจำนวนคอมเมนต์

อันนี้ดีมากสำหรับการสร้าง leads เราอยากดูอันที่ได้รับคอมเมนต์มากที่สุด เพราะนั่นบอกผมว่ามันได้ leads มากที่สุดให้ผม ผมไม่ได้มองหา views หรือค่าผิดปกติอะไรทั้งนั้น ผมมองหาแค่คอมเมนต์โดยเฉพาะ จากนั้นมันจะวิเคราะห์ฟอร์แมต จำนวนสไลด์ ผู้สร้างอันดับต้น ๆ มันจะอ่านทุกสไลด์ และจริง ๆ แล้วมันจะวิเคราะห์ภาพทั้งหมดให้คุณ เพื่อหารูปแบบ แล้วมันจะเปรียบเทียบ carousel ของคุณกับค่าเฉลี่ยของคู่แข่ง และหาช่องว่างที่ใหญ่ที่สุด จากนั้นมันจะสร้างรายงานเต็มรูปแบบพร้อม script brief ให้คุณบันทึกไว้ในโฟลเดอร์ carousel ของคุณ

เดาได้ไหมว่าเกิดอะไรขึ้นต่อ บรีฟนั้นจะถูกอ่านโดย ideator และ scripter และ creator ของคุณ เพื่อสร้าง carousel ที่ดีที่สุดเท่าที่จะเป็นไปได้ ผมไม่ใช่คนชอบสร้างสกิลที่ทั่ว ๆ ไป ผมชอบสร้างสิ่งที่ดีที่สุดในโลก และนี่คือสิ่งนั้น

สิ่งที่เราจะทำคือดาวน์โหลดมัน คุณแค่คลิกที่ analysis แล้วดาวน์โหลด zip ไป คุณก็แค่กด download ตรงนี้ แล้วมันจะโผล่ขึ้นมา แล้วเราจะเปิดมันตรงนี้จริง ๆ ดูนี่สิ เรามีไฟล์ skill MD อยู่ข้างใน สิ่งที่เราจะทำคือไปที่ Claude Code ของเรา ผมเปิด Claude Code ไว้แล้ว ผมจะโชว์วิธีรันมันให้ดู คุณก็แค่ drop สกิลลงไปเพื่อติดตั้ง มันง่ายมาก แล้วเราก็แค่รัน carousel แล้วปล่อยให้มันทำงาน

ดูเหมือนมันกำลังรันการวิเคราะห์บนข้อมูลใน Supabase ทั้งหมด และสิ่งที่มันมองหาคือ carousel album เพราะโพสต์ที่เข้ามาใน Supabase มักจะเข้ามาเป็น reels หรือ carousel album มันก็จะคัดกรองเฉพาะอันที่เป็น carousel แล้วดึงสถิติทั้งหมดมาเพื่อให้เห็นภาพเต็ม ๆ ดูเหมือนมันดึงข้อมูลครบแล้ว และกำลังเขียนรายงานให้เรา และเสร็จเรียบร้อย บันทึกรายงานแล้ว นี่คือไฮไลต์: ช่องว่างมหาศาล 10.5 เท่า carousel ของคุณมีค่าเฉลี่ย 319 และทั้งหมดเป็นแนวไลฟ์สไตล์ ส่วนตัว ส่วนคู่แข่งมี 334 คอมเมนต์ คุณมี carousel แบบความรู้เป็นศูนย์ ฟอร์แมตคิดเป็น 95% ของ engagement ของคู่แข่ง

เรามีคู่แข่งอันดับต้น ๆ คือ Claude Tyler German ผมสร้าง content [system] เต็มรูปแบบพร้อม mini chat automations สามตัว และพวกคุณสามารถขโมยมันได้ด้วยนะ จะเจ๋งมาก แล้วสามรูปแบบที่ใหญ่ที่สุดคือ resource reveal น่าสนใจ เจ๋ง มันเขียนรายงานเต็มรูปแบบเป็นไฟล์ MD ให้เรา และถ้าไม่มีข้อมูลส่วนตัวอะไร ผมจะเอารายงานไปแปะไว้ให้พวกคุณได้ดูด้วย

มันให้ภาพรวมเต็มรูปแบบ: ทรัพยากรสำคัญทั้งหมดที่มันพบ คุณมี carousel 20 อันดับแรก ว่าอะไรเวิร์ก อะไรไม่เวิร์ก ทั้งฟอร์แมต สไลด์ จำนวนสไลด์เท่าไร ซึ่งเจ๋งมาก สังเกตว่าจุดที่ลงตัวคือห้าถึงเจ็ดสไลด์ แล้วคุณก็มีรูปแบบของ cover slide ดูเหมือนว่า resource reveal กำลังเวิร์กอยู่ ตัวเลขแบบ listicle เวิร์กดีมาก open source personal builds ก็เวิร์ก และ bold reframes ก็เยี่ยม แล้วก็หนึ่งคอนเทนต์ต่อหนึ่งโพสต์ ไม่มีข้อยกเว้น ไตเติลตัวหนา 15 ถึง 40 คำ บวกคำอธิบายหนึ่งถึงสองประโยค เจ๋งมาก

มันจะสังเกตเห็นรูปแบบทั้งหมดบนทุกโพสต์ แล้วมันก็สังเกตคำกระตุ้นที่ perform ดีที่สุดด้วย เช่น CTA ท้ายโพสต์ เรามีผู้สร้างอันดับต้น ๆ โดยเปรียบเทียบ carousel ของคุณกับคู่แข่ง ซึ่งของผมแย่มาก และ cover slide และอีกหลายอย่าง มันสร้างรายงานเต็มรูปแบบ มันเจ๋งมาก

แต่สิ่งที่เจ๋งที่สุดคือ ideator และ scripter จะนำรายงานนี้ไปใช้ มันจะนำปัจจัยเหล่านี้ไปพิจารณาว่า อันนี้เวิร์กกับคนอื่น อันนี้ไม่เวิร์ก อันนี้เวิร์กสำหรับเรา แล้วมาลงทุนเพิ่ม มาสร้างไอเดียกัน มาสร้างสคริปต์ให้ดีขึ้น แล้วก็ออกมาแบบนี้ทั้งหมด มันเจ๋งมากครับ หวังว่าทุกคนจะสนุกกับบทเรียนนี้นะครับ ไปดาวน์โหลดมันแล้วลองใช้ดู แล้วบอกผมในคอมมูนิตี้ด้วยว่าสนุกไหม แล้วเจอกันบทเรียนหน้านะครับ
