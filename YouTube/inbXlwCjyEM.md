## ประเด็นหลัก

- Cursor เปิดตัวแผนใหม่ชื่อ **Cursor Start for India** ราคาเพียง 649 รูปีต่อเดือน (ราว 6–7 ดอลลาร์) ซึ่งรวมภาษีแล้ว และถูกกว่าแผนขั้นต่ำ 20 ดอลลาร์ของ OpenAI / Claude Code มาก
- นี่คือการเสนอ purchasing power parity (กำลังซื้อที่เท่าเทียมกัน) ให้ประเทศแรกอย่างอินเดีย ซึ่งเป็นประเทศที่มีนักพัฒนาปริมาณมหาศาล
- Cursor ถูก xAI (SpaceXAI) เข้าซื้อ จึงเป็นบริษัทที่ทั้งสร้างโมเดลของตัวเองและให้บริการผ่านฮาร์เนสของตัวเอง ทำให้ตั้งราคาต่ำได้เพราะมีมาร์จิ้นสูง
- แผน Cursor Start ให้โมเดล 2 ตัว: **Grok 4.5** และ **Composer 2.5** โดย Grok 4.5 เป็นโมเดลระดับ frontier ที่ใช้เป็นตัวขับเคลื่อนหลักประจำวันได้จริง
- วิธีใช้ Cursor มี 3 แบบ: cloud agents (คอมพิวเตอร์บนคลาวด์ที่ AI ใช้เอง), IDE, และ Cursor CLI ที่ UI ดีจนใช้แทน CLI ตัวอื่นได้สบาย
- ทดสอบจริงโดยให้สร้างภาษาโปรแกรมมิ่ง "flux" ใน JavaScript พร้อมเซิร์ฟเวอร์ Express JS สไตล์ — ทำงานสำเร็จในครั้งเดียว และรันได้จริง
- แนะนำแนวปฏิบัติความปลอดภัย: ตั้ง minimum release age 1 สัปดาห์ใน PNPM เพื่อกันมัลแวร์จากแพ็กเกจใหม่ ๆ
- โควตาประมาณ 20–30 ล้านโทเคนต่อเดือน (ส่วนใหญ่เป็น cached input tokens) คุ้มมากเมื่อเทียบกับราคาปกติ ~2 ดอลลาร์/ล้านโทเคนอินพุต และ ~6 ดอลลาร์/ล้านโทเคนเอาต์พุต
- เหมาะสำหรับผู้ใช้ระดับเบาถึงปานกลาง แต่ไม่เหมาะกับผู้ใช้หนักที่เปิดหลายแท็บถล่ม AI พร้อมกัน

## ความเห็นสรุป

ดีลนี้ถือว่าคุ้มค่ามากสำหรับผู้เริ่มต้นหรือผู้ใช้ทั่วไปในอินเดีย เพราะได้โมเดลระดับ frontier ในราคาไม่ถึง 10 ดอลลาร์ต่อเดือน พร้อมฟีเจอร์ครบทั้ง IDE, CLI และ cloud agents การที่บริษัทเริ่มเสนอราคาตามกำลังซื้อของแต่ละประเทศเป็นก้าวที่น่าสนใจ และน่าจะเป็นเทรนด์ที่ตามมาในอนาคต
