## บทนำ
คลิปนี้อธิบายขั้นตอนการขอ API key ของ YouTube Data API v3 จาก Google Cloud Console ตั้งแต่การสมัครบัญชีและเพิ่มข้อมูลการเรียกเก็บเงิน (billing) การสร้างโปรเจกต์ ไปจนถึงการเปิดใช้ API และสร้าง credentials

## คำแปลเต็ม

แต่เพื่อให้ได้สิ่งนี้มา เราต้องไปที่สิ่งที่เรียกว่า Google Cloud Console ไปที่เว็บไซต์ และถ้าคุณยังไม่มีบัญชี คุณก็ต้องสมัครขึ้นมาก่อน Google กำหนดให้คุณต้องตั้งค่าการเรียกเก็บเงิน (billing) แม้ในตอนที่คุณใช้บริการแบบไม่มีค่าใช้จ่ายก็ตาม ใช่ไหม? มันไม่ได้คิดเงินคุณอะไรเลยสำหรับฟังก์ชันที่เราต้องใช้เพื่อค้นหาวิดีโอ แต่มันก็ยังให้คุณเพิ่มข้อมูลการเรียกเก็บเงินอยู่ดี ดังนั้นคุณไปที่ billing แล้วเลือกบัญชีและจัดการการเรียกเก็บเงิน แล้วเพิ่มข้อมูลการเรียกเก็บเงินของคุณ และเมื่อทำเสร็จแล้ว คุณก็กลับมาที่หน้านี้ได้ จากนั้นเราคลิกที่ปุ่มสร้างโปรเจกต์ใหม่ แล้วตั้งชื่อมันว่า YouTube search จากนั้นคลิก create จากนั้นคุณไปที่โปรเจกต์ของคุณ ผมมีโปรเจกต์อยู่แล้ว คุณต้องเลือกโปรเจกต์ที่คุณมี จากนั้นต้องไปที่ APIs and services แล้วคลิกที่ library จากนั้นค้นหา YouTube Data API version three คลิกที่มัน แล้วคลิก Enable ต่อไปคุณต้องคลิกที่ Create Credentials ตรงนั้นเลือก Public data แล้วคลิก Next ตอนนี้เราก็ได้ API key ของเราแล้ว
