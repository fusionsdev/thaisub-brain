## คำแปลเต็ม

ว่าไงครับทุกคน ในวิดีโอนี้ผมจะมาอธิบายวิธีสร้างตาราง เพื่อใช้ลิสต์และรวบรวมคู่แข่งทั้งหมดของคุณครับ และเราจะลงมือค้นหาคู่แข่งจริง ๆ ภายในกลุ่มเฉพาะของคุณ (niche) ด้วยนะครับ ผมจะโชว์กลยุทธ์ของผมเองเลยว่าทำยังไง เพื่อที่เราจะได้เอาเนื้อหาที่ชนะของพวกเขา ไปใช้ในกระบวนการเขียนสคริปต์ของเราต่อไป เพื่อสร้างเนื้อหาที่ได้ผลจริงครับ

อย่างแรกเลย ผมอยากให้คุณไปที่ไฟล์ดาวน์โหลดก่อน สิ่งที่เราจะทำคือ เอาโค้ดจากไฟล์ดาวน์โหลดนั้น ไปวางรัน แล้วก็ตั้งค่ามันครับ แล้วเราก็ปล่อยให้มันทำงานไปครับ

สิ่งที่มันทำคือ มันดึงข้อมูลรับรอง (credentials) ของ Supabase บนเครื่องผมมา และตอนนี้มันกำลังจะสร้างตาราง accounts ในตารางข้อมูลของ Supabase ของผมครับ ถ้าคุณยังไม่ได้ดูวิดีโอการตั้งค่า Supabase ไปดูได้นะครับ เราสร้างตารางเนื้อหาทั้งชุดไว้ในนั้นแล้ว คุณน่าจะเห็นหน้าตาแบบนี้ครับ ถ้าผมเข้าไปในตัวอย่าง school community คุณจะเห็นตารางประมาณนี้ มีตาราง accounts ตาราง content และตารางที่มีคะแนนครับ ถ้าคุณไม่เห็น กรุณาไปดูวิดีโอเหล่านั้นก่อน เพราะผมลงรายละเอียดทุกอย่างไว้หมดแล้วครับ

เราจะปล่อยให้มันทำงานต่ออีกหน่อย ตอนนี้เรามีตาราง accounts แล้วครับ ขอบอกไว้ก่อนว่า ผมเจอปัญหากับ Supabase MCP ของผมเหมือนกัน แต่คุณสร้าง Supabase ไปแล้วในบทเรียนก่อนหน้า เพราะฉะนั้นถ้าคุณเจอปัญหา แค่เรียกใช้แล้วบอก Claude Code ว่า ใช้ Supabase MCP ของผม แล้วบอกมันให้ชัดเจนว่าคุณอยู่ในโปรเจกต์ไหนครับ

ผมใช้โปรเจกต์ school community แล้วใช้ Supabase MCP ของผม สร้างตารางในโปรเจกต์นั้น ซึ่งมันก็ทำได้ตามนั้นครับ มันสร้างตาราง accounts ให้ผมตรงนี้ และถ้าคุณยังเจอปัญหาอยู่ และคุณอยากได้แค่โค้ดสำหรับสร้างตารางนี้ ผมจะแปะให้ด้วย มันอยู่ในไฟล์ดาวน์โหลด คุณเปิดดูได้ทั้งหมด ถ้าเข้าไปในไฟล์ คุณจะเห็นว่าตรงนี้คือตาราง accounts คุณแค่เอาโค้ดไปวางได้เลยครับ

ส่วน CLAUDE.md และ lesson.md ก็เอาไว้ให้ Claude เดินตามขั้นตอนที่เราทำอยู่ แต่คุณจะปรับเปลี่ยนยังไงก็ได้ตามใจครับ

ทีนี้เรามีตารางแล้ว ข้างในมี ID เฉพาะ เราจะได้ account type จำนวนผู้ติดตามเฉลี่ยทั้งหมด หมวดหมู่ที่แอ็กทีฟ และโน้ตอะไรแบบนั้น เราอาจไม่ต้องใช้ทั้งหมดนี้ก็ได้ แต่ผมจะโชว์ให้คุณเห็นว่า เราเริ่มสแครปคู่แข่งได้ยังไง แต่สิ่งแรกที่ต้องทำคือ เราต้องได้ลิสต์รายชื่อคู่แข่งก่อน เราจะทำตรงนั้นตอนนี้ครับ

เวลาผมหาคู่แข่ง คุณรู้ไหม ผมจะทำในวิดีโอหน้าแทน เพื่อจะได้แบ่งเนื้อหากันครับ โอเคครับ เดี๋ยวผมจะพาเดินดูและหาคู่แข่งในวิดีโอหน้านะครับ แล้วเจอกันครับ
