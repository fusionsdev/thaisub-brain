# N8N Automation School 5 — Chat Message Trigger

## บทนำ

บทเรียนว่าด้วย Chat Message Trigger ใน n8n ซึ่งเป็นทริกเกอร์ที่ให้คุณใช้กล่องแชทเป็นหน้าต่าง UI สำหรับคุยและทดสอบ AI agent ของคุณ พร้อมสาธิตการต่อโหนดกับ OpenAI และ Simple Memory รวมถึงการอ่าน log การทำงานทีละขั้น

## คำแปลเต็ม

ทุกคนครับ ยินดีต้อนรับสู่อีกหนึ่งวิดีโอ ในบทนี้เราจะพูดถึง Chat Message Trigger ครับ อันนี้ค่อนข้างเจ๋ง ทริกเกอร์ตัวนี้ใช้สำหรับคุยและทดสอบ AI ของคุณจริง ๆ มันถูกกระตุ้นด้วยกล่องแชทเล็ก ๆ ตรงนี้ ถ้าคุณเห็นแชทนี้ที่ด้านล่าง นี่คือจุดที่คุณสามารถใช้มันเป็น front-end UI เพื่อคุยกับเอเจนต์เพื่อทดสอบมัน เห็นไหมครับ มันสว่างขึ้นตรงนั้น

แล้วกรณีการใช้งานของมันคือ สมมติผมไปที่ AI แล้วต่อโหนด Chat Trigger ดูตรงนี้ ผมให้ system prompt กับมัน อันที่จริงไม่ต้องก็ได้ แล้วเพื่อโชว์ให้ทุกคนดู ผมจะใช้ Chat Model เป็น OpenAI และให้ Simple Memory กับมัน และเดี๋ยวผมจะสอนการสร้าง AI agent อีกเยอะในโมดูลถัดไป แต่ถ้าผมอยากรีสตาร์ทแชท ผมก็แค่ทำแบบนี้ เรารีสตาร์ทมันแล้วตรงนี้ ผมจะจัดกึ่งกลางให้ มันจะเข้าไปที่ AI เข้าไปที่ memory ของมัน แล้วมันก็ตอบกลับมา: คุณชื่ออะไร? แล้วคุณจะเห็นว่าเรามี log ตรงนี้

มันแสดงให้เห็นว่าแชทเป็นยังไง จากนั้นมันแสดงว่ามันไปที่ AI agent และอย่างแรกมันเข้าไปที่ memory เพื่อดึงข้อมูลทั้งหมดก่อน มันดึงข้อความล่าสุดทั้งหมดมาตรงนี้ มันดึงประวัติแชททั้งหมด เห็นไหมครับ ประวัติข้อความแชททั้งหมด สมมติว่าคุณส่ง 'สวัสดี' และ 'วันนี้ช่วยอะไรได้ไหม' นั่นคือสองข้อความที่ผมส่งไป แล้วมันก็แสดง input ว่าค่าต่าง ๆ เป็นยังไง จากนั้นมันก็แสดงว่า AI agent พูดอะไรกับ OpenAI แล้วมันก็แสดง output ของ Simple Memory ว่านี่คือสิ่งที่มันตอบ blah เจ๋งดี และนั่นก็คือ log จริง ๆ แล้ว

ที่ที่คุณจะใช้ Chat Message Trigger จริง ๆ คือตอนที่คุณสร้าง AI agent สำหรับงาน back-end ตัวอย่างเช่น ผมใช้ Telegram เป็น front-end เยอะมาก และนั่นก็คือข้อความที่ผมเสียบเข้าไปใน AI agent เพื่อคุยกับมัน มันเหมือนกัน แค่เป็น chat message trigger อืม แต่ก็ค่อนข้างง่ายและตรงไปตรงมา นี่คือทั้งหมดครับ แล้วเจอกันบทเรียนหน้านะครับ
