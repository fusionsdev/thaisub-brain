## บทนำ
วิดีโอนี้สอนวิธีแก้ปัญหาโมดูล Twitter ใน Make.com ที่ไม่รองรับอีกต่อไป โดยใช้บริการอื่นมาทดแทน เพื่อให้ยังสามารถโพสต์วิดีโอลง Twitter (X) ได้อัตโนมัติ ขั้นตอนครอบคลุมตั้งแต่ดาวน์โหลดโมดูลสำเร็จรูป นำเข้า ตั้งค่า API key และทดสอบการเผยแพร่จริง

## คำแปลเต็ม
ในวิดีโอนี้ ผมจะแสดงวิธีเปลี่ยนโมดูล Twitter ที่ Make.com ไม่รองรับแล้ว ให้ไปใช้โซลูชันที่ใช้งานได้จริงจากบริการอื่น ก่อนอื่น คุณต้องเปิด automation ของคุณที่มีโมดูล Twitter ที่ต้องเปลี่ยน จากนั้นเปิด scenario ใหม่ โดยไปที่ open a new แล้วคลิก create a new scenario เพราะผมได้สร้างโมดูลที่คุณต้องวางหรือแทนที่ใน automation ของคุณเพื่อให้โพสต์ลง Twitter ได้

ตรงนี้ คุณไปที่ด้านล่างก่อน ดาวน์โหลดไฟล์นี้ จากนั้นไปที่ import คลิก select แล้วนำเข้าไฟล์นั้น คลิก save อันนี้จะให้ string มาให้คุณ สิ่งที่คุณต้องการจริงๆ มีแค่โมดูลเดียวเท่านั้น คลิกขวาแล้ว copy แล้วกลับมาตรงนี้ คุณก็แค่ลบโมดูล Twitter เหล่านั้นออก แล้ววางสิ่งที่คุณ copy มาแทน และนั่นคือทั้งหมดที่เราต้องการ

ตอนนี้ผมจะ unlink โมดูลอื่นๆ เพราะผมไม่ต้องการให้โมดูลอื่นถูกทดสอบ นี่เป็นแค่ตัวอย่าง workflow แต่ไม่ว่า workflow จะเป็นแบบไหน สิ่งเดียวที่คุณต้องทำคือสิ่งที่ผมเพิ่งทำไป นั่นคือ copy โมดูลนี้แล้วแทนที่โมดูล Twitter ด้วยโมดูลเดียวนี้ จากนั้นคลิก open

นี่คือบริการที่คุณใช้ มันชื่อว่า upload.post.com ตรงนี้คุณสามารถสมัครบัญชีฟรีได้ ไปที่ลิงก์ที่คุณเห็นด้านล่างวิดีโอนี้ ในแบบฟรี คุณจะได้ 10 uploads ต่อเดือน และถ้าต้องการมากกว่านั้น คุณต้องอัปเกรดแพ็กเกจถัดไป ซึ่งเสียค่าใช้จ่าย $14 ต่อเดือน คุณจะได้ 120 uploads

เมื่อทำขั้นตอนนี้เสร็จ ขั้นแรกคือไปที่ manage users ตรงนี้คุณพิมพ์ username อะไรก็ได้ แล้วคลิก add user จากนั้นคุณสามารถเชื่อมต่อ user เข้ากับบัญชีใดก็ได้ที่ต้องการ ในกรณีนี้คุณต้องการเชื่อมต่อกับ X (Twitter) คุณคลิกเพื่อยืนยันว่าต้องการเชื่อมต่อกับบัญชีนี้ และเมื่อเสร็จแล้วมันจะมีลักษณะแบบนี้

ตอนนี้เรากลับมาตรงนี้ แล้วตั้งค่าโมดูลนี้ทีละขั้นตอน สิ่งเดียวที่เราต้องการคือ API key ไปเอา key มาตรงนี้ คุณสามารถสร้าง key ใหม่ได้ถ้ายังไม่มี ผมจะลบอันนี้แล้วให้ดูว่ามันเป็นอย่างไร จากนั้น generate key ใหม่ แล้ว key ใหม่จะแสดงขึ้นมา copy ไป แล้วกลับมาตรงนี้วางลงไป สำคัญมากที่ค่านี้ต้องอยู่ครบ อันนี้คือส่วนหนึ่ง แล้วอันนี้คือคำว่า API

ลงมาด้านล่างตรงนี้ ค่าของ title ในเคสของผม มันมาจากโมดูลนี้ เพราะสำคัญที่ค่าตรงนี้คือข้อความ caption ซึ่งเป็นข้อความที่เผยแพร่พร้อมกับวิดีโอไปที่ Twitter และสำคัญว่าข้อความนี้ต้องน้อยกว่า 240 ตัวอักษร ไม่อย่างนั้นคุณจะเจอ error แต่ในเคสส่วนใหญ่ของผม ค่านี้ถูกจัดการไว้แล้ว เพราะฉะนั้นผมมักจะเพิ่มโมดูลพิเศษก่อนหน้านั้น ซึ่งเป็นโมเดล AI แบบ open browser ที่จะลดข้อความให้เหลือน้อยกว่า 100 หรือ 200 ตัวอักษรเสมอ

ต่อไปคือ username อันนี้คือ username จาก upload.post.com คุณไปที่ manage แล้ว copy บัญชีที่เชื่อมต่อกับบัญชี Twitter หรือ X ของคุณ จากนั้นวางลงตรงนี้ และสิ่งสุดท้ายที่ต้อง map คือ image URL อันนี้ควรเป็นรูปภาพของผมซึ่งอยู่ตรงนี้ แล้วคลิก save จากนั้นคลิก แล้วผมก็ทดสอบได้เลย คลิก run ผมจะส่ง test run ใน automation นี้เพื่อส่งข้อมูลผ่านไปดูว่ามันเผยแพร่หรือยัง และวิดีโอหรือรูปภาพถูกอัปโหลดและเผยแพร่ไปยังบัญชี Twitter ของผมหรือไม่

และมันดูดีมาก ตอนนี้ผมเข้าไปดูได้ ปกติแล้วผมจะเห็น success ดี จากนั้นผมไปที่ Twitter รีเฟรช แล้วเห็นว่าโพสต์ถูกเผยแพร่แล้ว ดังนั้นการ auto-publish นี้ใช้งานได้แล้ว ผมคลิก save แล้วเชื่อมต่อโมดูลอื่นๆ กลับมาได้ และตอนนี้คุณสามารถโพสต์ลง Twitter ได้อัตโนมัติด้วย integration นี้
