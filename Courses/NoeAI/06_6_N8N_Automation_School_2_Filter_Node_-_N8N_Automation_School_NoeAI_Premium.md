## บทนำ

บทเรียนนี้พูดถึง Filter node ใน n8n ซึ่งเป็น node ในหมวด Data Transformation ที่ใช้กรองข้อมูลที่ไม่ต้องการออก ผู้สอนสาธิตการสร้างเวิร์กโฟลว์กรอง subscriber counts แบบเงื่อนไขเดียว และแบบหลายเงื่อนไขด้วย AND/OR พร้อมตัวอย่างการใช้งานจริง

## คำแปลเต็ม

ว่าไงทุกคน วันนี้เราจะพูดถึง Filter node ในหมวด data transformation เราจะสร้างเวิร์กโฟลว์ไปด้วยกันเลย ผมจะกดปุ่มบวกตรงนี้ แล้วไปที่ data transformation และขอพูดถึงตัวอื่น ๆ คร่าว ๆ ก่อน — AI transformation คือตัวที่แปลงข้อมูลโดยใช้ AI พรอมต์ แต่ตัวนี้ผมไม่เคยใช้ในชีวิตเลย ผมใช้แค่ GPT nodes กับ Code nodes

ผมเขียนโค้ดไม่เป็น เลยไม่เคยใช้ แต่ Claude Code ชอบเลือกใช้ code nodes เพราะโค้ดจะช่วยให้คุณสร้างโซลูชันแบบกำหนดเองได้ คุณจะเห็นว่า Claude Code มักจะเลือกใช้ code nodes บ่อย ๆ ซึ่งส่วนตัวผมไม่ค่อยชอบ ผมพยายามให้ Claude Code ใช้ code nodes ให้น้อยที่สุดเท่าที่จะทำได้ เพื่อให้ผม debug ง่ายขึ้น และคุณก็จะสร้างงานแบบกำหนดเองได้ดีขึ้น แล้วก็มี Date and Time ซึ่งอีกเช่นกัน ผมไม่เคยใช้ในชีวิต แต่ที่เราจะพูดถึงวันนี้คือ Filter

Filter node ทำหน้าที่ตามชื่อของมันเป๊ะ ๆ — มันกรองข้อมูลที่คุณไม่ต้องการออก เรากำลังส่งข้อมูลผ่าน edit fields node อยู่ เรามี channel name กับ subscriber count สมมติว่าเราอยากส่งเฉพาะ subscriber counts ที่ผม hard-code ไว้จากบทเรียนที่แล้ว สมมติว่าเราอยากให้ผ่านเฉพาะช่องที่มีจำนวน subscriber น้อยกว่า หรือมากกว่า ค่าที่กำหนด

ผมก็จะเลือกฟิลด์ subscribers แล้วก็มีตัวเลือกให้ทำได้หลายอย่าง ถ้าเป็นข้อมูลแบบข้อความ คุณสามารถใช้เงื่อนไขแบบ — ถ้ามีค่า (exists) ถ้าเงื่อนไขนี้จริงก็ทำสิ่งนี้ ถ้าไม่จริงก็ไม่ทำ หรือเช็คว่าว่าง (is empty) หรือไม่ว่าง มีหลายอย่างให้เลือก ถ้าเป็นตัวเลข ก็มีเงื่อนไขแบบเดียวกันโดยประมาณ และมีแบบวันที่เวลา เช่น หลังจากเวลาที่กำหนด หรือเช็คว่ามีค่าหรือไม่มี จริง/เท็จ อะไรประมาณนั้น มีหลายแบบให้เล่น

แต่ในเมื่อเราส่งแค่ subscriber counts สมมติว่าผมอยากใช้เงื่อนไขมากกว่า (greater than) ลองดู — เรามีข้อมูล 5 รายการ พอกด Execute มันจะรันผ่านและดูผล — มันผ่านแค่ 4 รายการ จาก 5 คนที่ผมกำลังดูอยู่ มีแค่ 4 คนที่ผ่านเงื่อนไขนี้ แล้วมันก็ทิ้ง Chase ไป — ถ้าคุณยังไม่รู้จักเขา ลองไปดูช่องเขานะครับ เขาเจ๋งมาก

แล้วคุณยังเพิ่มเงื่อนไขได้อีก เช่น มันต้องผ่านทั้งสองเงื่อนไขนี้ — สมมติว่าต้องมี subscriber อย่างน้อยจำนวนหนึ่ง และ channel name ต้องมีคำว่า AI — ดูนะครับ กด Execute แล้วเหลือแค่รายการเดียว — ชื่อช่องต้องมี AI ด้วย แบบนี้มันก็กรองออกไปเรื่อย ๆ หรือคุณจะใช้แบบ OR ก็ได้ เช่น channel name มีคำว่า AI หรือไม่ก็มีคำอื่น — ดูสิครับ มันเก็บไว้ทั้ง 5 รายการ เพราะช่อง Chase AI มีคำว่า AI อยู่ในชื่อ

คุณเพิ่มเงื่อนไขหลาย ๆ แบบได้แบบนั้น ไม่ต้องกังวลกับตัวเลือกอื่น ๆ เช่น convert, regex หรือ ignore มากนัก ผมไม่ค่อยได้ใช้พวกนั้น แต่นั่นคือ Filter node — โดยพื้นฐานมันกรองข้อมูลที่คุณไม่ต้องการออก คุณเห็นจากตัวอย่างของผมแล้ว ตัวอย่างการใช้งานจริงที่ผมใช้คือ ถ้าผม scrape ทวีต 200 อันดับแรกจากหัวข้อที่กำลังมาแรง ผมไม่อยากอ่านทั้ง 200 ทวีต ผมอยากได้แค่ 50 อันดับแรก ผมก็กรองเอาท็อป 50 หรือกรองทิ้ง 150 อันล่าง แล้วเหลือแค่ท็อป 50 — เดี๋ยวผมจะลงรายละเอียดเพิ่มอีกในอีกไม่กี่บทเรียนข้างหน้า นั่นคือทั้งหมดสำหรับ node นี้ เจอกันบทเรียนหน้าครับ
