## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 3 ของการตั้งค่า Air Voice Engine โดยเราจะเพิ่มเครื่องมือ (tool) อีกตัวที่ให้ AI Voice Agent ใช้สำหรับสร้างการจองนัดหมายจริง ๆ หลังจากที่พบช่วงเวลาว่างและผู้ใช้เลือกเวลาแล้ว รวมถึงการเชื่อมต่อ Supabase, การแปลงเวลา และการทดสอบระบบจองผ่านบทสนทนาตัวอย่างกับลูกค้า

## คำแปลเต็ม

ขั้นตอนต่อไป เราจะตั้งค่าเครื่องมืออีกตัวที่ Air Voice Engine ต้องเข้าถึง ซึ่งก็คือการสร้างการจอง (create the booking) หลังจากที่ระบบหาช่วงเวลาว่างได้และผู้ใช้เลือกเวลาที่ต้องการจองแล้ว เราก็จะสร้างการจองจริง ๆ ในระบบของเรา กลับมาที่นี่ แล้วเพิ่มเครื่องมือแบบ custom อีกตัว ชื่อว่า complete booking ตั้งคำอธิบายว่าใช้สำหรับทำการจองให้เสร็จสมบูรณ์

ตรงนี้เรามี post และ URL เราจะใช้ production URL จริง ตรงนี้เราจะตั้งค่า response time ที่ 70 วินาที ตรงนี้เรามี body parameters แต่เราจำเป็นต้องส่งเพียงสองค่าเท่านั้น อันแรกคือเวลาจอง (booking time) ซึ่งก็คือวันและเวลาของนัดหมาย ที่ผู้ใช้บอกให้จองในรูปแบบ Farmo เฉพาะที่เราต้องการ ดังนั้นตรงนี้คุณแค่ต้องกรอก time zone ของคุณ ของผมคือ Berlin ประเทศเยอรมนี จากนั้นเราก็ต้องการส่งหมายเลขโทรศัพท์อีกครั้ง เพื่อระบุการจองที่เจาะจงได้ นี่คือ dynamic variable ที่มาจาก caller ID เพิ่มคำอธิบายว่า "ข้อมูลที่เกี่ยวข้องสำหรับการจองนัดหมาย" แล้วเพิ่มเครื่องมือ

ตอนนี้เราตั้งค่านี้เสร็จแล้ว ต้องกลับไปด้านบนสุด ต้องตั้งค่าตรงนี้ เราเชื่อมต่อ Supabase ไว้แล้ว ก็แค่เลือกบัญชีของเรา และตรงนี้เราต้องการ field ID ดูเหมือนเราต้องโหลดใหม่สักครั้ง ว่ามันควรทำอะไร ตอนนี้มันเจอแล้ว แต่อย่างไรก็ตาม เราอยากเพิ่มเงื่อนไข (condition) ตัวแปรฟิลด์คือ phone ขอโทษที ผมมีตัวแปรนี้จากขั้นตอนก่อนแล้ว ก็แค่ดึงมาตรงนี้ Phone number

มันจะตรวจสอบและค้นหาคนที่เพิ่ง... เหมือนขั้นตอนแรกที่เราหาช่วงเวลาว่าง ตอนนี้ผู้ใช้ที่มีหมายเลขโทรศัพท์เดียวกัน ซึ่งถูกเก็บไว้ในระบบของเราแล้ว จะถูกตรวจสอบว่าคนนี้เคยจองนัดหมายไปแล้วหรือยัง ถ้าอย่างนั้นก็ดำเนินการต่อ เพราะอาจเกิดกรณีที่มีคนใช้หมายเลขโทรศัพท์เดียวกันอยู่ในระบบแล้ว เช่น เขาอาจจองนัดหมายทุกสัปดาห์ เราจึงมีหลายรายการของหมายเลขเดียวกัน แต่เราต้องการค้นหารายการที่การจองยังไม่ได้ดำเนินการ (processed) เท่านั้น เพราะเขาต้องการจองใหม่ เราจึงเจอแค่รายการนั้น และเราไม่ต้องการบันทึกลงในส่วนอื่น แต่บันทึกลงรายการเดิมที่เรามีอยู่แล้ว และคุณจะเห็นการทำงานจริงในขั้นตอนถัดไป

ตรงนี้เราต้องสร้างการจอง เราจะใช้ booking tool ด้วย เราต้องใส่ API key เรายังมีอันนี้อยู่ตรงนี้ ดึงมาจากตรงนี้ API key มาจากตรงนี้ เปิดมัน แล้วใส่ API key ต่อไปคือ convert time ซึ่งทำหน้าที่แปลงเวลาจาก UTC เป็นเวลาท้องถิ่น เพื่อแสดงให้ผู้ใช้เห็น ตรงนี้คุณต้องเปลี่ยนเป็น time zone ของคุณ ผมใช้เวลา Berlin แต่ก่อนอื่นคุณต้องเชื่อมต่อบัญชี OpenAI คลิก Create New แล้ว Get API key ซึ่งผมจะแสดงให้ดูในส่วน technical tutorials: "get the API key from OpenAI" ดูวิดีโอนั้น แล้ววาง API key คลิก และปล่อยโมเดลไว้ตามเดิม เท่านั้นเอง ไม่ต้องทำอย่างอื่น

ตรงนี้ สิ่งเดียวที่เราอยากทำคือรักษาความปลอดภัยของบัญชี Supabase ของเรา ตรงนี้มันควรค้นหา... ผมจะลบทั้งหมดนี้อีกครั้ง ปล่อยไว้ตามเดิมได้ booked ถูกตั้งเป็น yes ตอนนี้มันบันทึกข้อมูล และ booked ถูกตั้งเป็น yes และมันต้อง... ตรงนี้เรามีเงื่อนไข: field value ID condition และเราได้ ID จาก node ก่อนหน้า ซึ่งเราสามารถจับคู่มันได้ตรงนี้ เพื่อให้รันได้ ขอพิมพ์เป็น ID ตรงนี้ไปก่อน แล้วมันจะระบุแถวที่เจาะจงของชีต และเราบันทึกฟิลด์ส่งค่า yes ควรถูกตั้งแบบนั้น และเราก็ต้องการบันทึกวันที่นัดหมาย (appointment date) ด้วย จากนั้นก็เป็น appointment date ซึ่งมาจาก node ก่อนหน้าเช่นกัน แต่ปล่อยไว้อย่างนี้ก่อน เราจะจับคู่ให้ถูกต้องหลังทดสอบ

เท่านี้แหละ ทีนี้เราจะทดสอบอย่างรวดเร็วว่าใช้งานได้หรือไม่ จากนั้นเราจะเชื่อมต่อให้ถูกต้องและจับคู่ค่าต่าง ๆ ให้ตรง ตรวจสอบให้แน่ใจว่าคลิก execute call: "Massage and Spa ยินดีให้บริการ ช่วยจัดสรรเวลาพักผ่อนที่สมบูรณ์แบบให้คุณได้ไหม ขอถามคำถามสั้น ๆ สองสามข้อเพื่อหาบริการที่เหมาะกับคุณ" โอเค เยี่ยม วันนี้สนใจบริการอะไรคะ? นวด (Massage) "เห็นว่าคุณสนใจ quick massage คุณมีเวลาที่ต้องการหรืออยากได้ช่วงเวลาว่างถัดไป?" ช่วงเวลาว่างถัดไป (Next available) "รับทราบ และนี่เป็นการมาครั้งแรกที่ Zen Touch ไหม?" ใช่ "เยี่ยมมาก คุณจะได้รับส่วนลด 15% กรุณามาถึงก่อนเวลานัด 15 นาทีเพื่อรับคำปรึกษาสั้น ๆ" "เพื่อยืนยันการจอง quick massage ฉันขอชื่อคุณหน่อย" Andreas สะกด A-N-D-R-E-A-S ถูกต้องไหม? ใช่ "ขอบคุณ ต้องการจอง quick massage ตอนนี้เลยไหม?" ใช่ "รอสักครู่ กำลังตรวจสอบช่วงเวลาว่าง ช่วงเวลาว่างถัดไปสำหรับ quick massage คือ 16 มิถุนายน เวลา 13:15, 13:30, 13:45, 14:00 และ 14:15 กรุณาบอกเวลาที่สะดวกที่สุด" ผมเลือกอันแรก "คุณเลือกวันที่ 16 มิถุนายน เวลา 13:15 ใช่ไหม กรุณาตอบ yes ถ้าถูกต้อง" ช่วงเวลานี้เหมาะมาก "รอสักครู่ กำลังจองนัดหมายให้คุณ" ข่าวดี!

ตรงนี้ เข้าไปดูว่าเรามีอะไรบ้าง สิ่งแรกที่เราต้องปรับคืออีเมล โดยปกติแล้วนี่คืออีเมลของลูกค้าที่ควรได้รับอีเมลยืนยัน แต่เราไม่เก็บอีเมลผ่านโทรศัพท์ เพราะสำหรับผมมันเป็นวิธีที่ขัดจังหวะและไม่สะดวก คุณต้องสะกดอีเมลให้ voice agent ฟัง ซึ่งมันมักฟังผิด บางครั้งต้องพูดไปมาหลายรอบกว่าอีเมลจะถูกต้อง นั่นคือเหตุผลที่ผมไม่เก็บอีเมล แต่ถ้าคุณอยากลองทำ คุณต้องปรับตรงนี้ แทนที่จะถามแค่อย่างอื่น ก็ถามอีเมลเพิ่ม แล้วไปที่ get availability แล้วเพิ่ม parameter property ชื่อ email บอกว่ามันคืออีเมลของผู้ใช้ แล้วเพิ่มเข้าไปได้ แต่ผมไม่ทำแบบนั้น ดังนั้นผมจึงใส่อีเมลจำลอง (dummy email) ซึ่งควรมีอยู่จริง คุณอาจตั้งบัญชีอีเมลที่ไม่ค่อยได้ใช้ ไว้รับอีเมลยืนยันจากผู้ใช้ทั้งหมด

ตรงนี้เราต้องการ time zone ซึ่งควรเป็น time zone ที่คุณเห็นในแพลตฟอร์มเครื่องมือจองของคุณ สำหรับผมคือ Europe/Berlin เลือกมัน คลิก แล้วคัดลอก ตรวจสอบว่าไม่มีช่องว่างเปล่า ไม่งั้นจะได้ error แต่ค่านี้ต้องอยู่ตรงนี้ ทุกอย่างดูดีแล้ว

ตอนนี้คลิก execute step แล้วเห็นว่าสำเร็จ และเมื่อไปที่ events ควรเห็นรายการนี้แล้ว เวลาก็ถูกต้องด้วย ดี ตอนนี้เราทำการตั้งค่าต่อได้ ไปที่ตรงนี้ ตรวจสอบว่าอันนี้เป็นสีเขียวด้วย ถ้าคลิกอันนี้มันควรพาไปยังจุดที่ถูกต้อง จากนั้นเราต้องบันทึกข้อมูลนี้ ตรงนี้เรายังต้องเพิ่ม ID ซึ่งเป็น ID ที่เราได้จาก Get contact ดังนั้นแค่ลากฟิลด์นี้มาตรงนี้ จากนั้น booked เป็น yes และตรงนี้เราต้องการ appointment date ซึ่งมาจากส่วนนี้ และเมื่อคลิก มันจะถูกบันทึก คุณสามารถตรวจสอบฐานข้อมูลได้ว่ารายการถูกบันทึกหรือไม่ แต่ตอนนี้เราเห็น booked และ appointment date แล้ว

เท่านี้แหละ ทุกอย่างที่เราจำเป็นต้องใช้จริง ๆ คือ webhook response ซึ่งก็คือการตอบกลับกลับมา ไม่ต้องใช้อะไรเพิ่ม ตอนนี้คลิก save ได้ และขั้นตอนสุดท้ายคือต้องสลับไปใช้ production นี่คือส่วน booking ผมต้องกลับไปที่ complete booking แล้วแทนที่ webhook นี้ด้วย production webhook คลิก save แล้วทำแบบเดียวกันกับอีกส่วน คลิกตรงนี้ คลิกอันนั้น แล้ววางลงตรงนี้ คลิก save คลิก save แล้วก็เสร็จสิ้น

จากนั้นกลับไปสลับเป็น live (เปิดใช้งาน) ตอนนี้มันทำงานแล้ว สิ่งสุดท้ายที่เหลือคือนำหมายเลขนี้ไปวางบนเว็บไซต์ของคุณ หรือที่ใดก็ตามที่คุณต้องการให้คนโทรหาธุรกิจของคุณ และถ้าคุณสังเกต ตอนเราทำการทดสอบเหล่านี้ จะมีข้อความตัวอักษรอยู่ตอนต้นเสมอ ซึ่งให้พิมพ์ตัวอักษรเพื่อยืนยัน และการจะเอาอันนั้นออก คุณต้องอัปเกรดบัญชี Twilio ของคุณเป็นแบบเสียเงิน
