## บทนำ
วิดีโอนี้เป็นขั้นตอนถัดไปของระบบอัตโนมัติสำหรับ Instagram Reels คือการสร้างข้อความ โดยใช้ Perplexity ค้นคว้าข้อมูลออนไลน์เพื่อหามุมมองใหม่ที่ไม่ซ้ำกับวิดีโอต้นฉบับ จากนั้นใช้ OpenAI เขียนสคริปต์ ไทเทิล และคำบรรยายใหม่ แล้วแยกตัวแปรและบันทึกทุกอย่างลง Google Sheets เพื่อเตรียมสร้างวิดีโอจริงในขั้นตอนถัดไป

## คำแปลเต็ม

ขั้นตอนถัดไปของระบบอัตโนมัตินี้คือการสร้างข้อความ ดังนั้นต่อไปเรามาคลิก research กัน เพราะผมไม่ต้องการให้ได้วิดีโอที่เหมือนต้นฉบับเป๊ะ ๆ แต่ผมต้องการทำการค้นคว้าออนไลน์ เพื่อหามุมมองใหม่ที่ไม่ซ้ำใครสำหรับหัวข้อนี้ ซึ่งจะทำให้มีโอกาสสูงขึ้นที่ Reels บน Instagram ของเราจะทำผลงานได้ดี

และเราใช้เครื่องมือที่ชื่อ Perplexity ซึ่งเป็นเสิร์ชเอนจินที่ขับเคลื่อนด้วย AI ที่เราสามารถใช้ได้ ดังนั้นสิ่งเดียวที่คุณต้องใส่ตรงนี้คือ API key จาก Perplexity ตรงนี้คุณสมัครบัญชี Perplexity ฟรี จากนั้นไปที่บัญชีของคุณ คลิกตรงนี้ แล้วคลิก API key ผมยังมีบทเรียนที่สอนวิธีขอ API key จาก Perplexity คุณสามารถดูได้ตรงนี้ และคุณอาจต้องเติมเครดิตเล็กน้อยภายใต้ billing ประมาณ 5 ดอลลาร์หรืออะไรประมาณนั้น แต่การใช้ Perplexity ในระบบอัตโนมัตินี้ถูกมาก

จากนั้นวาง API key ลงในช่องนี้ และตรงนี้เรามี prompt ซึ่งเป็นคำแนะนำที่แท้จริงสำหรับ Perplexity มันจะใช้สคริปต์ของวิดีโอ และควรจะทำตาม prompt นี้ คุณสามารถปรับปรุง prompt ได้ถ้าต้องการ หรือปรับตามผลลัพธ์ที่คุณได้ แต่สำหรับผมอันนี้ดีแล้ว ผมก็เลยคลิก test step ซึ่งอาจใช้เวลาสักสองสามวินาทีกว่าจะค้นคว้าเสร็จ

ทีนี้เรามาดูขั้นตอนถัดไปกัน ขั้นตอนถัดไปคือการทำความสะอาดผลลัพธ์จาก Perplexity เพราะคุณเห็นตรงนี้ นี่คือเนื้อหาจริง มันรวมถึงกระบวนการคิดว่ามันค้นคว้าอย่างไร แต่ผมไม่ต้องการส่วนนี้ ผมต้องการแค่ผลลัพธ์ดิบ และนี่คือสิ่งที่ฟังก์ชันนี้ให้ผม แค่คลิก test step

จากนั้นเรามีโมดูลใหม่ของ OpenAI ซึ่งสร้างข้อความทุกอย่างที่ผมต้องการ คุณก็ใช้บัญชี OpenAI ที่เชื่อมต่อไว้แล้วในขั้นตอนก่อนหน้าได้ จากนั้นก็คือ prompt ตรงนี้ สิ่งที่มันทำคือ มันใช้ผลลัพธ์จาก Perplexity ใช้สคริปต์ต้นฉบับของวิดีโอที่เรามี และใช้ข้อความไทเทิลตรงนี้ด้านบน แล้วมันก็เขียนทั้งหมดใหม่ โดยรักษาโครงสร้างที่พิสูจน์แล้วจากวิดีโอนี้ แต่เขียนใหม่สำหรับหัวข้อค้นคว้าใหม่

จากนั้นมันจะให้องค์ประกอบสามอย่างของ Reels ของฉัน นั่นคือสคริปต์ ไทเทิล และคำบรรยาย ตอนนี้มันเป็นบล็อกเดียวอย่างที่คุณเห็น เราจึงต้องแยกมันออกจากกัน นั่นคือเหตุผลที่ผมสร้างฟังก์ชันแยก (split function) ให้คุณแล้ว คุณแค่คลิก test step แล้วมันจะให้สามส่วนที่แตกต่างกัน ซึ่งเป็นทุกสิ่งที่เราต้องการสำหรับวิดีโอของเรา

และตอนนี้เรามี video ID ซึ่งคล้ายกับเทมเพลตอีกครั้ง แค่เป็นสตริงที่ไม่ซ้ำกัน เพื่อให้เราสามารถระบุวิดีโอที่เราต้องการสร้างได้ และตรงนี้ใน Google Sheets ผมแค่ต้องเลือก Google Sheets ของผม และนี่คือจุดที่ผมบันทึกไปที่ generated posts

ตอนนี้ผมต้องบันทึกคอนเทนต์ที่สร้างทั้งหมดลงในชีตของผม ผมจะบันทึก template ID ด้วย เพราะผมต้องการรู้ว่าวิดีโอของผมอิงจากวิดีโอไหน ทีนี้ขึ้นไปที่ video ID นี่คือสิ่งที่ผมมีอยู่ตรงนี้ ส่วน topic ก็คือผลลัพธ์ที่ทำความสะอาดแล้วจาก Perplexity ส่วน text overlay คือไทเทิลที่สร้างขึ้นของผม ดังนั้นผมต้องไปที่ split นั่นคืออันนี้ ส่วน script ก็คือสคริปต์ที่สร้างขึ้นของผม และตรงนี้ caption text ยังไม่ต้องใช้ตอนนี้ รวมถึง video URL และวันที่เผยแพร่ด้วย อันนี้มาทีหลัง แต่ตอนนี้ยังไม่จำเป็น

กลับไปที่เดิม แล้วคลิก test step จากนั้นมันควรจะถูกบันทึกเป็นผลลัพธ์ที่สร้างขึ้นของผม อย่างที่คุณเห็นตรงนี้ เยี่ยมมาก ในขั้นตอนถัดไป ผมต้องสร้างวิดีโอจริง ซึ่งเราจะตั้งค่าในวิดีโอถัดไป
