## ประเด็นหลัก

- OpenWork เป็นทางเลือกโอเพนซอร์สแทน Claude Code (เครื่องมือเขียนโค้ดด้วย AI แบบเสียเงินบนคลาวด์) มีดาว 21K+ บน GitHub
- OpenWork มีทั้งเว็บแอปพลิเคชันและเดสก์ท็อปแอป รองรับการทำงานร่วมกันแบบกระจาย (distributed collaboration)
- สถาปัตยกรรมประกอบด้วย 3 ส่วน: OpenWork frontend, OpenWork worker nodes (backend), และ Open Code (coding agent)
- worker node แต่ละตัวเชื่อมต่อกับ workspace (โฟลเดอร์บนเครื่อง remote) และใช้ Open Code เป็นเอเจนต์เขียนโค้ด
- รองรับหลายโมเดล AI ผ่าน Puter เช่น Claude Opus, Kimi, Qwen เป็นต้น
- สาธิตการทำงาน: สร้างไฟล์ แก้ไขไฟล์ผ่าน frontend แล้วเห็นผลลัพธ์บนเซิร์ฟเวอร์ remote แบบ real-time
- สอนวิธีการติดตั้งแบบ non-Docker ทีละขั้นตอน: clone repo, ติดตั้ง dependencies (PNPM, Rust), ตั้งค่า environment variables, CORS, tokens
- ใช้ PM2 รัน frontend เชื่อมต่อไปยัง backend worker ด้วย URL และ token

## ความเห็นสรุป

OpenWork เป็นเครื่องมือที่น่าสนใจสำหรับทีมที่ต้องการ self-host ระบบ coding agent โดยไม่ต้องพึ่ง Claude Code แบบเสียเงิน คอนเซปต์การทำงานร่วมกันแบบหลาย client ต่อหนึ่ง worker (หรือกลับกัน) และการใช้ Open Code เป็นเอเจนต์หลักทำให้มันยืดหยุ่นและปรับแต่งได้มาก เหมาะสำหรับทีมที่ต้องการควบคุมโครงสร้างพื้นฐานของตัวเองทั้งหมด
