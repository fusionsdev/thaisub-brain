## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 2 ของการตั้งค่า AI Agent สำหรับ WhatsApp โดยใช้แพลตฟอร์ม ManyChat เราจะสร้างบัญชี เชื่อมต่อหมายเลข WhatsApp (แบบฟรีหรือซื้อหมายเลขใหม่), เชื่อมโยงกับ Facebook Business Portfolio, นำเข้า workflow อัตโนมัติที่เตรียมไว้ ตั้งค่า trigger และ field ต่าง ๆ เพื่อให้ผู้ใช้ส่งข้อความหรือคลิกลิงก์แล้วคุยกับ AI agent ได้

## คำแปลเต็ม

คลิกที่ ManyChat ตามลิงก์ด้านล่างนี้ ถ้าคุณยังไม่มีบัญชี คุณสามารถใช้สิทธิ์ทดลองฟรี 100% ก่อน ซึ่งเป็นทดลองใช้ฟรี 30 วัน จากนั้นคลิก continue with... แค่ลงชื่อเข้าใช้แบบฟรี แล้วผมจะถูกนำไปที่หน้านี้ แต่ผมไม่ต้องการอันนี้จริง ๆ ผมจะลบส่วนนี้ออก

สิ่งที่คุณต้องไปจริง ๆ คือ settings ผมคิดว่าระบบจะพาคุณผ่านขั้นตอนนี้ทันทีหลังสมัคร น่าจะเห็นแบบนี้ ตอนนี้คุณมีตัวเลือกต่าง ๆ ในการเชื่อมต่อบัญชี WhatsApp คุณสามารถย้ายหมายเลข WhatsApp ของคุณเองมาใช้ได้ ถ้าคุณมีหมายเลขโทรศัพท์ที่อยากใช้อยู่แล้ว นี่คือสิ่งที่คุณจะทำ หรือคุณสามารถสร้างหมายเลข WhatsApp ใหม่ ซึ่งผมเคยใช้วิธีนี้มาก่อน โดยคุณสามารถซื้อหมายเลขได้ในราคา 66 เซนต์ต่อเดือน ถ้าผมเลือกประเทศใดประเทศหนึ่ง ราคา $66 ต่อเดือนสำหรับสหรัฐอเมริกา ซึ่งเป็นกระบวนการที่ง่าย และจัดการให้ทั้งหมดโดย ManyChat

หรือคุณสามารถเริ่มด้วยเวอร์ชันแรก ซึ่งง่ายที่สุด คลิก "receive with own number" หรือ "connect a new number" ถ้าคุณมีหมายเลขของตัวเองก็ใช้ได้ แต่ผมอยากใช้วิธีที่เราเลือก เพราะตรงนั้นคุณสามารถให้ WhatsApp ให้หมายเลขฟรีแก่คุณได้ ดังนั้นตรงนี้ผมกด continue เพื่อเริ่มต้น ตอนนี้ผมต้องเลือก business portfolio ซึ่งคุณต้องมีบัญชี Facebook Business และถ้าคุณยังไม่มี ก็ทำได้ง่ายมาก แค่ไปที่ลิงก์นี้ แล้วมันจะพาคุณผ่านขั้นตอนการสร้างบัญชีธุรกิจ ถ้าเปิดในโหมดไม่ระบุตัวตน คุณจะเห็นว่าต้องเข้าสู่ระบบบัญชี Facebook ก่อน แล้วมันจะพาคุณตั้งค่าบัญชี และเมื่อทำเสร็จแล้ว คุณก็คลิกตรงนี้เพื่อดำเนินการต่อด้วยหมายเลขของคุณ หรือจริง ๆ ผมทำไว้แล้ว และคุณก็เลือก business portfolio แล้วดำเนินการต่อผ่านกระบวนการนี้

เลือกบัญชี WhatsApp สร้าง WhatsApp ใหม่ถ้าคุณยังไม่มี ต้องการโปรไฟล์ WhatsApp ใหม่ แล้วต้องตั้งชื่อ (display name) เลือกหมวดหมู่ จากนั้นตรงนี้คุณสามารถเลือกเพิ่มหมายเลขโทรศัพท์ของคุณเองแล้วยืนยัน หรือรับหมายเลขโทรศัพท์ฟรี นี่คือวิธีที่ง่ายที่สุด และวิธีนี้ยังช่วยให้คุณทำทุกอย่างที่เราทำกับ WhatsApp agent ได้อีกด้วย สิ่งเดียวที่... ผมจะเลือกอันนี้ แต่ผมมีบัญชีอยู่แล้ว เพราะผมสร้างไว้แล้วและใช้หมายเลขนี้แล้ว ดังนั้นผมต้องกลับมาตรงนี้ แล้วเลือก WhatsApp account ซึ่งเชื่อมกับหมายเลขหนึ่งอยู่แล้ว แต่คุณสามารถทำตามขั้นตอนเลือกหมายเลขฟรีนี้ได้เลย กด continue แล้วเราก็จะมาอยู่ตรงนี้เหมือนกัน คุณจะไม่เห็น error ที่ผมเจอ ผมเจอมันเพราะผมใช้หมายเลขฟรีนี้ไปแล้ว

จากนั้นคลิก continue แล้วมันก็เชื่อมต่อแล้ว แต่คุณจะถูกนำไปที่หน้านี้ ซึ่งน่าจะแสดงสถานะ connected ถ้าคุณคลิกและรอสักครู่ มันจะคงสถานะเชื่อมต่อไว้ มีหมายเลข WhatsApp ที่เชื่อมต่อแล้ว และนั่นคือทั้งหมดที่ต้องทำ

คุณข้ามส่วนนี้ได้ เพราะขีดจำกัดนี้ไม่ค่อยมีผล เนื่องจากมันใช้กับการสนทนาที่เริ่มโดยธุรกิจเท่านั้น ถ้าคุณส่งข้อความหาผู้ใช้ก่อน ขีดจำกัดนี้จะใช้ แต่ในกรณีของเรา ผู้ใช้เป็นฝ่ายส่งข้อความหาเรา พวกเขาคลิกลิงก์ WhatsApp แล้วเริ่มพิมพ์หาเรา ดังนั้นขีดจำกัดนี้จึงไม่ค่อยเกี่ยวข้อง คุณสามารถยืนยันบัญชีได้ถ้าต้องการ แต่คุณต้องส่งเอกสารบางอย่างให้ WhatsApp จนกว่าพวกเขาจะยืนยันบัญชีของคุณ

แต่สำหรับเรา เราเข้าไปในส่วน fields ต่อ เราต้องเพิ่มสองฟิลด์ตรงนี้ ฟิลด์แรกชื่อ user input และกำหนดหมายเลขให้มัน เพราะผมมีฟิลด์พวกนี้หลายอันอยู่แล้ว จากนั้นมี assistant reply ซึ่งก็เป็นหมายเลขเช่นกัน คุณไม่จำเป็นต้องเพิ่มหมายเลข อย่าเพิ่งบันทึก และนั่นคือทั้งหมดที่ต้องทำตรงนี้

กลับไปที่ปุ่มนี้ด้านล่าง แล้วคลิกที่มัน จากนั้นคุณจะถูกนำไปที่หน้านี้ และตรงนั้นคลิก save to ManyChat แล้วมันจะนำเข้า workflow อัตโนมัติโดยตรง คลิก save ลงบัญชีของคุณ คลิก view flow แล้วคุณก็จะได้มันมา

ตอนนี้เราต้องเพิ่ม trigger trigger แรกคือ "user sends a message" เราสามารถกำหนดคำเฉพาะได้ เช่น "hello" หมายความว่า AI agent จะตอบสนองเฉพาะเมื่อมีคนส่งข้อความที่มีคำเหล่านี้เท่านั้น นั่นคือเหตุผลที่ผมมีคำเหล่านี้ แต่ใช้กับข้อความแรกเท่านั้น เมื่อการสนทนาดำเนินไปแล้ว ไม่จำเป็นต้องมีคำ trigger ทุกครั้ง ดังนั้นเฉพาะเมื่อพวกเขาไม่เคยส่งข้อความถึงเรามาก่อน ข้อความแรกที่ส่งมาจะต้องมีคำใดคำหนึ่งเหล่านี้ นั่นคือเงื่อนไขแรกที่เรามี คลิก create

จากนั้นเราต้องมี trigger อีกตัว: "user clicks a link" ตรงนี้เราสามารถตั้งข้อความแรกที่โหลดไว้ล่วงหน้าเมื่อผู้ใช้คลิกลิงก์ ถ้าผมไม่มีมัน มันก็จะไม่ทำอะไร แค่ให้แบบนี้ และผมสามารถวางลิงก์นี้บนเว็บไซต์ เช่น แล้วมันจะ trigger บัญชี WhatsApp ของผมหรือของระบบ และโหลดข้อความที่ผู้ใช้สามารถส่งได้ทันที นี่อาจเป็นอะไรก็ได้ แต่ไม่จำเป็นจริง ๆ จากนั้นคุณก็พิมพ์ "I want to book an appointment" แต่สิ่งนี้จะให้ error เพราะมันถูกสร้างสำหรับ workflow อื่นแล้ว ผมมีสิ่งนี้ในชุดอื่นอยู่แล้ว ผมก็แค่... อันนี้ควรเป็นแบบนี้ ผมต้องการ "I want an appointment" ใช่ไหม แล้วนี่จะเป็นลิงก์ของผมซึ่งจะ trigger workflow

ต่อไปไปที่ส่วน actions สิ่งแรกที่ต้องทำคือไปที่ตรงนี้ นี่คือ user input ที่ผมเพิ่งสร้าง แล้วต้องตั้งค่าเป็น last text input แบบนี้ นี่คือจุดที่ข้อความที่ผู้ใช้ส่งมาจะถูกเก็บไว้ในค่านี้ จากนั้นจะถูกส่งไปยัง AI agent ของเรา ดังนั้น AI agent ของเราจะเห็นสิ่งที่ผู้ใช้ส่งใน WhatsApp และนั่นคือจุดประสงค์ของสิ่งนี้

และตรงนี้คือจุดที่เราเชื่อมต่อกับ workflow ของเรา คุณต้องดึง webhook นี้ ขอดึง test webhook ก่อน ต่อไปค่อยสลับเป็น production จากนั้นวาง test webhook ลงตรงนี้ คลิก แต่เรายังอยากทดสอบก่อน ตรงนี้เราต้องเปลี่ยนสิ่งนี้ด้วย เพิ่มฟิลด์ และนี่คือ user input ซึ่งเป็นจุดที่เราส่งข้อมูลไปยัง AI agent ของเรา custom user เราต้องการส่งข้อความที่ผู้ใช้ส่งมา เรายังส่ง WhatsApp ID ในรูปแบบ connected ID ด้วย

ก่อนที่เราจะทดสอบได้ คุณต้องเพิ่มผู้ใช้ก่อน โดยไปที่ WhatsApp ถ้าคุณยังไม่มี WhatsApp ก็ไปที่เว็บไซต์นี้แล้วดาวน์โหลด ติดตั้งลงคอมพิวเตอร์ได้ เพื่อให้มีหน้าต่างนี้เปิดอยู่และทดสอบได้ดีขึ้น จากนั้นสิ่งที่คุณทำคือ... กลับมาตรงนี้เพื่อแสดงขั้นตอนทั้งหมด ต้องเปิดใช้งานอันนี้ นี่คือ trigger คลิกที่มัน แล้วมันจะเปิด WhatsApp โดยอัตโนมัติพร้อมข้อความที่โหลดไว้ล่วงหน้าที่เรากำหนดไว้ และเมื่อคุณส่งข้อความ ผู้ติดต่อจะถูกสร้างขึ้นตรงนี้

คลิก update ตอนนี้เราควรเห็นผู้ติดต่อ ตอนนี้ต้องค้นหาของฉัน และเมื่อเข้าไป เราจะเห็น user input แต่ user ยังไม่... บางทีอาจต้องทดสอบอีกครั้ง ผมเห็นว่ามัน... เราต้องคลิก update ลองอีกครั้ง ไปที่ contacts คุณเห็นผู้ติดต่อของผมอยู่ ลบมันอีกครั้ง คลิก delete กลับไปที่ automations ตอนนี้ automations ของผมถูกนำเข้าแล้ว นี่คือสิ่งที่ผมนำเข้า ดี ลองอีกครั้ง ไปที่ลิงก์อีกครั้ง ควรเปิดเหมือนเดิม ใช่ ตอนนี้ส่งข้อความนี้แล้ว ควรเห็นค่าที่ถูกต้อง คลิก edit automation ไปที่ response และตอนนี้คุณเห็นว่ามันทำงานแล้ว user input ที่ถูกต้องอยู่ตรงนี้

ต่อไปไปที่ response mapping ผมต้องแมปสิ่งนี้ตรงนี้ด้วย ไปที่ assistant reply ซึ่งเป็นจุดที่ส่งการตอบกลับที่มาจาก webhook นี้และเก็บไว้ในค่านี้ สิ่งที่ต้องทำคือเข้าไปข้างใน คลิก listen for test event คลิก send test และเมื่อได้สถานะ 200 และเห็นว่ามันทำงานแล้ว user input คือหมายเลขโทรศัพท์ contact ID เรียบร้อย ตอนนี้เราได้แล้วและใกล้เสร็จแล้ว

สิ่งที่เราจะทำคือ ขอคัดลอกอันนี้ก่อน เพราะในขั้นตอนถัดไปเราจะทดสอบ ดังนั้นจะใส่ production URL นี้ไว้ตรงนี้ คลิก save ตอนนี้ไปที่ส่วนสุดท้าย นี่คือ response spec ซึ่งเป็นจุดที่รับการตอบกลับจาก AI agent ส่งกลับมาตรงนี้ แล้วส่งข้อความกลับถึงเรา เราต้องแมปกับ assistant reply นี่คือจุดที่มีค่า และตรงนี้ user input ต้องเป็น user input ที่เราสร้างไว้ ของผมคือ user input 8 ใช่ไหม คลิก update และเมื่อตั้งค่านี้เสร็จแล้ว ผมจะเปลี่ยนชื่อทั้งหมด และตอนนี้เราสามารถทดสอบได้ ซึ่งเราจะทำในขั้นตอนถัดไป
