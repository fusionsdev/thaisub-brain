# Content System — Connect Canva (Canva MCP Setup)

## บทนำ

บทเรียนนี้เป็นคู่มือการเชื่อมต่อ Canva เข้ากับ Claude ผ่าน MCP ผู้สอนสาธิตสองวิธี — วิธีเชื่อมต่อแบบ native ผ่าน Claude Desktop และวิธีติดตั้งไฟล์ MCP server ใน Claude Code เพื่อให้ Claude สร้างและแก้ไขคารูเซล รูปภาพ รวมถึงโพสต์คอนเทนต์ได้โดยตรง

## คำแปลเต็ม

ว่าไงทุกคน ยินดีต้อนรับสู่คู่มือการตั้งค่า Canva MCP ครับ ในวิดีโอนี้ผมจะโชว์วิธีเชื่อมต่อ Canva จาก Claude ซึ่งเจ๋งมาก ๆ คุณจะสามารถสร้างคารูเซล รูปภาพ และเห็นของเจ๋ง ๆ พวกนี้ทั้งหมดได้ และสิ่งที่คุณจะเอามันไปใช้คือสกิล carousel ที่ผมกำลังจะปล่อยเร็ว ๆ นี้ แต่ก่อนอื่นผมจะพาคุณดูวิธีเชื่อมต่อก่อน แล้วคุณจะแก้ไข อัปโหลด เอ็กซ์พอร์ต โพสต์อัตโนมัติ หรือค้นหาได้ด้วย

ขั้นแรก สิ่งที่คุณต้องทำคือคัดลอกข้อความนี้ แล้วเลื่อนลงไปดาวน์โหลดไฟล์ MCP — เราจะดาวน์โหลดมัน แล้วไปที่ Claude Code ครับ ผมรู้ว่านี่คือ Claude Desktop ผมแค่อยากโชว์ให้คุณดูคร่าว ๆ ก่อนที่เราจะทำแบบเทอร์มินัล ถ้าคุณใช้ Claude Code อยู่ มันมีการเชื่อมต่อแบบ native ให้อยู่แล้ว เหมือนกับที่มีใน Claude Desktop ซึ่งเจ๋งมาก สิ่งที่คุณต้องทำคือเข้าไปที่ Customize แล้วไปที่ Connectors คุณจะเห็นว่าผมตั้งค่า Canva connector ไว้ตรงนี้ นี่คือวิธีเชื่อมต่อที่ง่ายที่สุด — คุณแค่เข้ามา คลิก Browse แล้วเลือก Canva แล้วกด Connect มันจะทำการยืนยันตัวตน (authentication) ขึ้นป๊อปอัปมา แล้วคุณก็คลิกยืนยัน แค่นี้ Claude ก็เชื่อมต่อแล้ว และคุณน่าจะใช้งานมันได้ภายในเทอร์มินัล

แต่ผมให้ไฟล์ไว้สำหรับใส่ใน Claude Code เผื่อไว้ด้วยนะครับ ลองวิธีแรกก่อน แล้วค่อยดูว่าคุณทำอะไรได้บ้าง สิ่งที่ผมจะทำตรงนี้คือ MCP จริง ๆ — โอ้ นั่นไม่ใช่ แล้วก็ อย่างที่บอก ผมให้ไฟล์ไปแล้วเหมือนตอนดาวน์โหลด Canva — ในนั้นมี lesson.md กับ config.json นี่คือ MCP server โดยพื้นฐาน แล้วคุณก็แค่ลากไฟล์เข้าไปในโฟลเดอร์ของเรา แล้วเราก็คัดลอกข้อความที่อยากส่ง — ข้อความคือ add a new MCP server called Claude Canva blah blah blah — คุณวางข้อความนั้นเข้าไป แล้วเรียกใช้ MCP builder ของคุณ หรือจะวางข้อความที่คัดลอกมาก็ได้ เหมือนกับ MCP ตัวอื่น ๆ ที่เราตั้งค่าไปแล้ว แค่บอกว่าผมอยากเชื่อมต่อ MCP ตัวไหน แล้วมันก็จะพาเดินทีละขั้น

ถ้าคุณมีปัญหาในการเชื่อมต่อ ให้พรอมต์มันอธิบายเหมือนคุณเป็นเด็ก ป.3 แล้วมันจะพาคุณทำทุกอย่าง พอเสร็จแล้วและเชื่อมต่อแล้ว สิ่งที่อยากให้ลองคือ — คุณเชื่อมต่อกับ Canva MCP server ของฉันแล้วหรือยัง ช่วยทดสอบให้หน่อย — แล้วมันก็จะลองเชื่อมต่อให้ดู และคุณยังเช็คได้แบบเรียลไทม์ว่ามันเชื่อมต่ออยู่หรือเปล่า โดยเข้าไปที่เมนู แล้วถ้าผมพิมพ์ /mcp connect คุณจะเห็น Nano Banana, Slack, Supabase — แล้ว Canva อยู่ไหนล่ะ? โอเค ผมไม่เห็นตรงนั้นนะ แต่จริง ๆ แล้วคุณก็แค่เลือก Canva เองได้ และนั่นแหละ — Claude Desktop เป็นวิธีที่ง่ายมาก มันเป็นฟีเจอร์ native ในตัว ไม่ต้องติดตั้งอะไรเพิ่ม แต่ผมให้คู่มือนี้ไว้ เพราะมีบางคนบ่นว่าไม่มีไฟล์ให้ นั่นคือสิ่งที่ผมให้คุณครับ

เอาล่ะ นั่นคือทั้งหมด คุณน่าจะเชื่อมต่อกับ Canva ได้แล้ว ถ้ามีคำถามอะไร ทิ้งไว้ในคอมเมนต์ได้เลย แล้วเจอกันบทเรียนหน้าครับ
