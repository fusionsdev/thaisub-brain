## คำแปลเต็ม

ในคลิปนี้ผมจะแสดงวิธีแทนที่ Twitter modules ซึ่งไม่ได้รับการสนับสนุนโดย make.com อีกต่อไปด้วยโซลูชันที่ใช้งานได้จากบริการอื่น ดังนั้นขั้นแรกคุณต้องเปิด automation ที่มี Twitter modules ที่เราต้องแทนที่ แล้วคุณเปิด scenario อื่น ดังนั้นคุณไปที่ open a new แล้วคลิก create a new scenario เพราะผมได้สร้าง module ที่คุณต้องการ paste หรือแทนที่ใน automation ของคุณ เพื่อให้คุณสามารถ publish ไปยัง Twitter ได้ ตอนนี้ที่นี่คุณไปที่ด้านล่างนี้ download นี้ก่อนแล้วไปที่ import คลิก select แล้ว import นั่น คลิก save นี่เพียงให้คุณได้ string เดียว สิ่งที่คุณต้องการจริงๆ คือ module เดียวนี้ module เดียวนี้เท่านั้นดังนั้นคุณคลิกขวา copy แล้วที่นี่คุณลบ Twitter modules เหล่านั้นแล้วคุณ paste ที่คุณเพิ่ง copy มา และนั่นคือสิ่งเดียวที่เราต้องการตอนนี้ผมจะ unlink modules เหล่านี้เพราะผมไม่ต้องการทดสอบ modules อื่นๆ นี่คือ workflow ตัวอย่างเท่านั้น แต่ไม่ว่า workflow จะเป็นอย่างไรก็ตาม สิ่งที่คุณต้องการแทนที่คือสิ่งที่ผมเพิ่งทำ คัดลอกนี้และแทนที่ Twitter modules ด้วย module เดียวนี้จากนั้นเราคลิกที่ open นี่คือบริการที่คุณใช้ มันเรียกว่า upload.post.com ที่นี่คุณสามารถลงทะเบียนสำหรับบัญชีฟรีได้ ไปที่ลิงก์นี้ที่คุณจะพบด้านล่างคลิปนี้ด้วย แล้วในบัญชีฟรีคุณจะได้ 10 uploads ต่อเดือน และถ้าคุณต้องการมากขึ้นต่อเดือนคุณจะต้องอัพเกรดไปยังระดับต่อไปซึ่งให้ $14 ต่อเดือนและคุณจะได้ 120 uploads เมื่อคุณทำเสร็จแล้วขั้นแรกคือคุณไปที่ manage users และที่นี่คุณป้อน username สุ่มใดๆ แล้วคลิก add user และตอนนี้คุณสามารถ connect user กับบัญชีใดๆ ที่คุณต้องการ ในนี้คุณต้องการ connect มันกับ X (Twitter) ดังนั้นคุณคลิกยืนยันว่าคุณต้องการ connect มันกับนี้ และเมื่อมันเสร็จมันจะดูเป็นแบบนี้ และตอนนี้เราสามารถกลับมาที่นี่และเราไปที่ module นี้และ set it up ทีละขั้นตอน ดังนั้นสิ่งเดียวที่เราต้องการที่นี่คือ API key ดังนั้นเรามาหา key นี้ คุณสามารถสร้าง key ใหม่ถ้าไม่มี key ใหม่ได้ ดังนั้นผมจะลบนี้...

ที่นี่คุณต้องเลือก service ที่เราใช้ นั่นคือ X (Twitter) และคุณต้องใส่ username ที่คุณเพิ่งสร้างขึ้น และคุณต้องใส่ API key ที่คุณเพิ่งสร้างขึ้น และเมื่อคุณ save มันเสร็จมันจะ connect ไปยัง Twitter ของคุณอย่างอัตโนมัติ ตอนนี้ทุกอย่างพร้อมแล้วคุณสามารถทำงานกับ Twitter ใน automation ของคุณได้เหมือนเดิม แต่ใช้บริการ upload.post.com แทนที่ Twitter modules ที่เก่า

นี่คือวิธีแก้ปัญหาการ auto publish ไปยัง Twitter ใน make.com เมื่อ Twitter modules ไม่ได้รับการสนับสนุนอีกต่อไป คุณสามารถใช้ upload.post.com เป็นตัวแทนที่ทำงานได้จริง คุณต้องลงทะเบียนบัญชีฟรี สร้าง API key และเชื่อมต่อกับ Twitter ของคุณ หลังจากนี้ automation ของคุณจะทำงานได้เหมือนเดิม
