## คำแปลเต็ม

ผมกำลังจะสอนคุณเกี่ยวกับเทคโนโลยีที่ทรงพลังที่สุดบนอินเทอร์เน็ต และในโลกตอนนี้ นั่นคือ Claude skill ครับ และในวิดีโอนี้ ผมจะอธิบายว่ามันคืออะไร ทำงานยังไง ผมจะสาธิตแบบสด ๆ ด้วย ดังนั้นอย่าไปไหนนะครับ

ถ้าคุณยังไม่รู้ว่า Claude skill คืออะไร มันถูกปล่อยออกมาประมาณหกเดือนที่แล้วจาก Anthropic และมันเปลี่ยนเกมสุด ๆ ครับ ทำไมน่ะเหรอ เพราะมันให้คุณกดปุ่มเดียว แล้วมันทำเวิร์กโฟลว์ทั้งหมดให้คุณเลย ตอนนี้ฟังดูเกินจริง แต่จริงมากครับ

Claude skill คืออะไร ลองนึกดูว่า ตอนคุณพิมพ์ prompt ลงใน ChatGPT แทนที่จะเขียน prompt เดิมซ้ำทุกครั้ง คุณก็แค่ก็อปปี้แล้ววางมัน เซฟไว้ แล้วกดปุ่มหนึ่งครั้ง มันก็ดึง prompt นั้นกลับขึ้นมา มันก็คือเวิร์กโฟลว์นั่นแหละครับ และที่ดีที่สุดคือ ให้ผมโชว์ตัวอย่าง จะได้เห็นว่ามันทำงานสด ๆ จริงยังไง

มันคือเวิร์กโฟลว์ที่คุณทำกับ Claude เช่น ทุกเช้าผมรัน Claude skill นี้ ถ้าคุณเห็นคำสั่งแบบ slash command แบบนี้ นี่คือ skill ที่ผมใช้อยู่ หรือคนอื่น ๆ ใช้อยู่ครับ

มันถูกทริกเกอร์ด้วยปุ่มเดียว แล้วมันจะทำอย่างนี้ อย่างแรก มันวิเคราะห์เนื้อหาที่ชนะของผม ซึ่งคืออะไรก็ตามที่กำลังได้ผลกับผมในตอนนี้ มันวิเคราะห์ข้อมูลทั้งหมดของผม จากนั้นมันสแครป Reddit เพื่อหาหัวข้อที่ชนะ โดยอิงจากเนื้อหาที่ชนะของผม เช่นเดียวกันกับ X ทั้งหมดอิงจากเนื้อหาที่ชนะของผม แล้วมันก็เสนอสรุปไอเดีย 10 อันดับแรก ที่ผมควรจะอัดวิดีโอในวันนั้น โดยอิงจากข้อมูลที่ชนะของผม

ดังนั้นตอนที่ผมจะสร้างเนื้อหา ผมมีลิสต์ไอเดียเต็มรูปแบบ ให้รีบทำออกมาได้ทันที และมันคือไอเดียที่พิสูจน์แล้วว่าชนะ เพราะมันใช้ข้อมูลของผม และสิ่งที่ผมต้องทำคือ กดปุ่มง่าย ๆ ปุ่มเดียวเท่านั้น

ผมจะโชว์ให้ดูว่ามันทำงานยังไงตอนนี้เลย ผมจะเปิด Claude แล้วเข้าไปที่ new chat แล้วผมก็แค่กดปุ่ม มันก็ดึงลิสต์ skill ที่ผมมีใน Desktop ขึ้นมา ผมใช้ Claude Code อยู่ แต่ตัวอย่างนี้ผมใช้ Claude Desktop แล้วเราจะดึงมันขึ้นมา ดูสิ คุณมี skill หลายตัว แล้วก็มีคำอธิบาย มันคือ Agentic Morning Researcher ที่ทำ GitHub อะไรแบบนั้น มันดูข้อมูลเฉพาะของผม แล้วดึงข้อมูลของผมมา โอเคไหม

ผมจะรันมัน สิ่งที่ต้องทำคือกดปุ่มเดียว แล้วมันจะทำทุกอย่างให้ผม เราจะปล่อยให้มันทำงาน แล้วผมจะโชว์ผลลัพธ์ให้ดู

เสร็จแล้ว มันให้ 10 อันดับแรกของวันนี้ มันสแครป X และ Reddit แล้วตอนนี้มันให้ผลลัพธ์ยอดนิยมทั้งหมด โดยอิงจากข้อมูลเฉพาะของผม มันให้มุมมอง (angles) ว่าทำไมผมควรทำหัวข้อไหน แล้วมันก็เขียน brief ทั้งหมดให้ผมจากการที่ผมกดปุ่มเพียงปุ่มเดียว

นี่คือภาพรวมระดับสูงว่า skill คืออะไรครับ หวังว่ามันจะทำให้คุณตื่นเต้นนะครับ คุณจะเห็นว่า คุณเริ่มอัตโนมัติสิ่งต่าง ๆ มากมายได้ยังไง แค่กดปุ่มเดียว เจอกันครับ
