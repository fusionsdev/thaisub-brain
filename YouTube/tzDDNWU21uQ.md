## ประเด็นหลัก

- **Orca คือ ADE (Agent Development Environment)** — ไม่ใช่แค่ terminal emulator แต่เป็น workspace เต็มรูปแบบสำหรับ AI coding agents ที่ทำงานบนเทอร์มินัล รองรับ CLI agent ได้ทุกตัว (Pi Agent, Claude Code, Codex, Grok ฯลฯ) และใช้ AI subscription ที่มีอยู่แล้ว
- **Git Worktrees แบบแยกส่วน (Isolated)** — แต่ละ feature/งาน รันใน Git worktree แยกกัน ไม่ชนกัน เอเจนต์หลายตัวทำงานพร้อมกันได้โดยไม่แย่งไฟล์กัน
- **Browser Mode ในตัว** — สามารถจับ (grab) องค์ประกอบ UI ใด ๆ บนหน้าเว็บ แล้วส่ง context + annotation ตรงไปที่ prompt ของเอเจนต์ เพื่อให้เอเจนต์แก้ไขหรืออธิบายได้ทันที
- **Mobile Companion** — ควบคุมและติดตามเอเจนต์จากมือถือผ่าน iPhone/Android แม้บางครั้งจะยังมีบั๊กเล็กน้อย
- **Multi-Agent Orchestration** — สั่งให้เอเจนต์หนึ่งเป็นตัวควบคุม (coordinator) แล้ว spawn sub-agents หลายตัวทำงานคู่ขนานกัน เช่น front-end แยก back-end แยก หรือ documentation แยก
- **YOLO Mode** — ตั้งค่า agent permissions ให้ launch โดยไม่ต้อง manual checks ทุกครั้ง (มีประโยชน์สำหรับ Claude/Codex ที่ถาม permission บ่อย)
- **Live Demo: Home Lab Management App** — Christian สร้างแอป SvelteKit + Docker จริง ๆ แบบสด ๆ ใน ~5 นาที แสดงให้เห็นว่า Orca + Pi Agent ช่วยคนที่เขียนโค้ดไม่เก่งให้สร้างโปรเจกต์ได้จริง
- **สปอนเซอร์: Morph (ModelCode.ai)** — เครื่องมือแปลง legacy codebase ทั้งโปรเจกต์ให้เป็นแอปสมัยใหม่ โดยสร้าง project spec และ modernization plan ก่อน ใช้โค้ด Christian ได้ 60,000 credits ฟรีต่อเดือนสำหรับปีแรก

## ความเห็นสรุป

Orca เป็นเครื่องมือที่น่าประทับใจมากสำหรับการทำงานกับ AI agents บนเทอร์มินัล โดยเฉพาะฟีเจอร์ Git worktrees แบบ isolate และ browser annotation ที่ไม่เหมือนใคร แม้ code editor ในตัวจะยังสู้ VS Code ไม่ได้ แต่จุดแข็งของ Orca อยู่ที่การ orchestrate เอเจนต์หลายตัวให้ทำงานร่วมกันมากกว่าการเป็น IDE — เหมาะสำหรับทั้งนักพัฒนาและสาย IT/Operations ที่อยากให้ AI ช่วยทำงาน automation ต่าง ๆ
