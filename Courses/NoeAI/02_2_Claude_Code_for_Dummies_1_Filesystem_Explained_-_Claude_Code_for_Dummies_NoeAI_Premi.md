## บทนำ

บทเรียนนี้อธิบายระบบไฟล์ (file system) ซึ่งเป็นหัวใจของการทำงานของ Claude Code — Claude Code ทำงานกับไฟล์บนคอมพิวเตอร์ของคุณ ดังนั้นการจัดระเบียบไฟล์และโฟลเดอร์ให้ดีจึงสำคัญมาก ผู้สอนสาธิตจริงด้วยการสร้างโฟลเดอร์รก ๆ แล้วให้ Claude Code จัดระเบียบให้อัตโนมัติ

## คำแปลเต็ม

ยินดีต้อนรับเข้าสู่บทเรียน Filesystem Explained ในบทนี้ผมจะโชว์สิ่งที่อาจเป็นบทเรียนที่สำคัญที่สุดที่ผมจะสอนคุณเกี่ยวกับ Claude Code และวิธีการทำงานของมัน ถ้าคุณยังไม่ได้ดูบทเรียนการติดตั้ง (setup) ขอให้ไปดูบทนั้นก่อน ไปติดตั้ง Claude Code ให้เรียบร้อย แล้วเราค่อยเข้าเรื่องกัน

สิ่งที่เราจะทำคือ ผมจะอธิบายระบบไฟล์ให้คุณฟัง แล้วเราจะทำตัวอย่างจริงด้วยกัน ดังนั้นเตรียม Claude Code ให้พร้อม เราจะได้ทำบทเรียนไปด้วยกัน

Claude Code ทำงานกับไฟล์บนคอมพิวเตอร์ของคุณ ถ้าคุณมีคอมพิวเตอร์ คุณก็มีไฟล์บนคอมพิวเตอร์ เห็นไหมครับ? เห็นภาพพวกนี้ไหม นี่คือไฟล์ โอเค ทุกอย่างคือไฟล์บนคอมพิวเตอร์ของคุณ ทั้งคอมพิวเตอร์ของคุณทำงานด้วยไฟล์ทั้งนั้น ถ้าผมเปิดโฟลเดอร์ home ของผม คุณจะเห็นทุกอย่าง มีโฟลเดอร์ส่วนตัว มีโฟลเดอร์งาน มีโฟลเดอร์ downloads ผมสร้างโฟลเดอร์ dummy สำหรับ Claude Code ไว้ให้คุณดูด้วย มีโฟลเดอร์ applications ที่รวมแอปทั้งหมด ทุกอย่างบนคอมพิวเตอร์ของคุณอยู่ในโฟลเดอร์ มันเรียกว่า file และเรียกรวมกันว่าระบบ (system)

เมื่อคุณทำงานใน Claude Code สิ่งที่ Claude ทำคือ มันทำงานภายในไฟล์ที่เฉพาะเจาะจง ตัวอย่างเช่น สมมติว่าคุณมีโฟลเดอร์งานแบบเดียวกับผม ผมไม่อยากให้แอปบนเดสก์ท็อปกับโฟลเดอร์งานมารวมกัน ผมอยากให้มันเป็นระเบียบ ผมเลยมีโฟลเดอร์ work โฟลเดอร์นี้ชื่อว่า work ทุกอย่างข้างในเกี่ยวข้องกับงาน พอเข้าใจใช่ไหมครับ?

สมมติว่าคุณมีธุรกิจหลายอย่าง ผมมีโฟลเดอร์นี้สำหรับแบรนด์ส่วนตัวของผม แล้วก็มีโฟลเดอร์นี้สำหรับเอเจนซี่ของผม สองอย่างที่แตกต่างกันโดยสิ้นเชิง แต่อยู่ใต้โฟลเดอร์ work ทั้งคู่ ผมมี work แล้วข้างในมีสองโฟลเดอร์ หนึ่งสำหรับอย่างหนึ่ง อีกหนึ่งสำหรับอีกอย่าง แล้วคุณก็มีโฟลเดอร์ย่อยลงไปได้อีก ซึ่งผมจะพูดถึงในบทหลัง แค่อยากให้เห็นว่า Claude ทำงานภายในโฟลเดอร์ทั้งหมดของคุณ

ถ้าคุณให้สิทธิ์มันแค่โฟลเดอร์แบรนด์ส่วนตัว มันก็จะทำงานเฉพาะในโฟลเดอร์นี้กับอะไรก็ตามที่อยู่ข้างใต้มัน โอเค? ถ้าผมเปิดดู มันจะมี NoeAI work ของผม มีเอเจนซี่ของผม ถ้าผมให้ Claude Code เข้าถึงแค่แบรนด์ส่วนตัว มันก็จะทำงานในแบรนด์ส่วนตัวเท่านั้น นี่คือวิธีที่ผมจัดระเบียบสิ่งต่าง ๆ

วิธีที่ผมมองระบบไฟล์คือ มันเหมือนสมองของคุณ คุณมีระบบไฟล์ ซ้อนระบบไฟล์ ซ้อนระบบไฟล์ สำหรับแต่ละอย่าง ข้างในแต่ละโฟลเดอร์ก็มีอะไรต่าง ๆ อยู่ข้างใต้ สำหรับธุรกิจของผม ผมมีหลายโฟลเดอร์ในนั้น มันคือสมองของคุณ คุณต้องมองว่าระบบไฟล์คือสมองของคุณ ที่คุณจัดระเบียบสิ่งต่าง ๆ

สิ่งที่สำคัญมากคือสมองของคุณต้องเป็นระเบียบ ถ้าสมองคุณไม่เป็นระเบียบ ไฟล์ของคุณกระจายเต็มไปหมด คุณจะสับสนตลอดเวลา ความคิดจะขุ่นมัว คิดอะไรก็ยากไปหมด มันเหมือนกับ Claude Code ถ้าทุกอย่างของคุณรกมาก ผลลัพธ์ก็จะแย่ และมันจะทำงานให้คุณไม่ได้ดีเท่าที่ควร

ผมจะโชว์ตัวอย่างจริงให้ดู สิ่งที่ผมอยากให้คุณทำตอนนี้คือ ไปที่โฟลเดอร์ของคุณ แล้วสร้างโฟลเดอร์ dummy ขึ้นมา ถ้าซูมเข้าไป ผมสร้างโฟลเดอร์ dummy สำหรับ Claude Code ไว้แล้ว ขอเด็ดทิ้งเพื่อความสมบูรณ์ของตัวอย่าง แล้วสร้างใหม่ โอเค เราจะเรียกมันว่า "school community" ทุกอย่างที่ผมทำข้างในจะอยู่ใต้โฟลเดอร์นี้ สิ่งที่อยากให้คุณทำคือ คลิกเข้าไปแล้วเปิดมัน กดหยุดวิดีโอไว้ก่อนจนกว่าคุณจะทำเสร็จ

เราจะสร้างข้าวของมั่ว ๆ ขึ้นมาสักหน่อย ใส่ไฟล์อะไรก็ได้แบบสุ่ม ลองเปิดหน้าต่างใหม่ดู ขอเปิด finder window ใหม่นะ สมมติว่าเราจะใส่เอกสารรายสัปดาห์ของห้องเรียนเข้าไปสักหน่อย แล้วก็ใส่โฟลเดอร์มั่ว ๆ อีกสองสามโฟลเดอร์ เขย่า ๆ ใส่รูปภาพเข้าไปบ้าง วิดีโอบ้าง อะไรก็ได้ โยนของมั่ว ๆ เข้าไปในนั้น พอได้โฟลเดอร์ที่รกเต็มไปหมดแล้ว ขั้นตอนต่อไปคือ ไปที่ Claude Code กัน

ผมจะเปิด Claude ขึ้นมา ลองดูว่าผมเปิดได้ไหม เปิดไม่ได้ เราจะเปิด Claude กัน แล้วไปที่ New Chat เพื่อไม่ให้คุณเห็นงานที่ผมทำอยู่ แล้วบูม โอเค ตอนนี้ผมอยู่ใน Claude แล้ว จากนั้นผมจะไปที่ Claude Code แล้วเริ่ม session ใหม่ กด new session ตรงนี้ แล้วสิ่งที่เราจะทำคือ เปิดโฟลเดอร์ที่เพิ่งสร้างขึ้นมาใน Claude Code เพื่อให้ Claude Code ทำงานภายในนั้นและจัดระเบียบโฟลเดอร์ให้เรา

เจ๋งมาก ดูตรงนี้ ด้านล่างคุณจะเห็นไฟล์ สิ่งที่คุณต้องทำคือ คลิกตรงนี้ แล้วคุณสามารถเลือกโฟลเดอร์อื่นได้ เลือกโฟลเดอร์ที่ต้องการ แล้วกด open หรือวิธีโปรดของผมคือ คุณเข้ามาตรงนี้ แล้วเลือกโฟลเดอร์เลย โอเค เรามาเลือกโฟลเดอร์กัน

(ตัดบางส่วนที่วิดีโอไม่มี ตรงนี้ผมเอาออกไปแล้ว) สมมติว่าผมอยากลบอันนี้ทิ้ง ลบ ๆ ๆ กลับไปที่จุดเริ่มต้น แล้วสิ่งที่ผมอยากให้คุณทำคือ จัดระเบียบมันตามวิธีที่ดีที่สุดสำหรับคุณ โอเค แล้วผมจะรันมัน ดูว่ามันจะทำอะไร

ผมสนใจว่าจะได้โครงสร้างการจัดระเบียบแบบไหน มันกำลังอ่านไฟล์ทั้งหมด แล้วคิดหาวิธีที่ดีที่สุดในการจัดระเบียบไฟล์ของคุณ อันนี้เด็ดมาก เจ๋งมากที่คุณได้เห็นสิ่งนี้ เพราะเจ้านี่สามารถจัดระเบียบคอมพิวเตอร์ทั้งเครื่องของคุณได้ ถ้าคุณให้สิทธิ์เข้าถึง มันจะจัดระเบียบทุกอย่างให้คุณอย่างดีที่สุด เห็นไหมครับ? ดูสิ มันน่าสนใจว่ามันทำอะไร

ดูเหมือนมันแบ่งเป็น assets กับ planning โอเค เจ๋ง ดูสิ มันสร้างโฟลเดอร์หลักสามโฟลเดอร์ แล้วใต้แต่ละโฟลเดอร์มันก็สร้างโฟลเดอร์ย่อย นี่เรียกว่า parent folder (โฟลเดอร์แม่) ซึ่งก็คือโฟลเดอร์หลัก แล้วโฟลเดอร์ที่อยู่ข้างใต้เรียกว่า child folder (โฟลเดอร์ลูก) แล้วมันก็วางไฟล์เข้าไปข้างใน เห็นไหมครับ? เจ๋งมาก

มันจัดวิดีโอและ thumbnails ไว้ใต้ assets แล้วสำหรับบทเรียนมันก็วางไว้ใต้โฟลเดอร์บทเรียน แล้วสำหรับแผนทั้งหมดมันก็วางไว้ใต้ planning เจ๋งจริง ๆ มันเข้าไปอ่าน สังเกตว่าไฟล์คืออะไร แล้วจัดระเบียบตามนั้น และคุณเห็นไหมว่ามันแสดง tree ให้เราดูด้วย ถ้าคุณไม่รู้ว่า tree คืออะไร นี่คือ tree นี่คือระบบไฟล์ที่แสดงเป็นเส้น ๆ ให้เห็นโฟลเดอร์หลัก parent, parent, child, child

เมื่อผมขอให้ Claude Code จัดระเบียบไฟล์ทั้งหมดของผม ผมก็อยากเห็นว่าไฟล์หน้าตาเป็นยังไง ผมจะโชว์ให้ดู ผมทำแบบนี้ตรงนี้ ผมถามว่า "ช่วยแสดงเป็น tree ว่าหน้าตาไฟล์ทั้งหมดของผมเป็นยังไง" มันก็โชว์ให้เห็นอย่างชัดเจนว่ามีอะไรอยู่ใต้แต่ละโฟลเดอร์ ซึ่งเรากำลังเรียนบทนี้อยู่ตอนนี้ มันก็แค่จัดระเบียบไฟล์ของเรา

นี่คือทุกอย่างสำหรับบทเรียนนี้ ถึงตรงนี้คุณเข้าใจพื้นฐานที่สุดแล้วว่า Claude Code ทำงานอย่างไรผ่านระบบไฟล์ของคุณ มันสำคัญมากที่คุณต้องทำงานภายในโฟลเดอร์ที่คุณต้องการ และต้องมั่นใจว่าทุกอย่างเป็นระเบียบ

ความท้าทายของผมคือ ถ้าคุณมีโฟลเดอร์ที่รก ๆ ไปที่ Claude Code ให้สิทธิ์เข้าถึงโฟลเดอร์นั้น โยนมันเข้าไป แล้วให้มันจัดระเบียบให้คุณเอง แต่มันเจ๋งมากจริง ๆ แล้วเจอกันในบทเรียนหน้าครับ
