## บทนำ

วิดีโอนี้สอนการตั้งค่าส่วนการเผยแพร่อัตโนมัติ (publishing automation) ต่อจากภาคแรก โดยเริ่มจากการนำเข้า blueprint ของ Make.com (เดิมชื่อ Integromat) ตั้งค่า webhook เชื่อมต่อกับ Google Apps Script เชื่อมต่อบัญชี Twitter ผ่าน Twitter Developer รวมถึงการตั้งค่า Google Sheet เพื่อบันทึกวันเวลาเผยแพร่ และทดสอบการโพสต์ไปยัง Facebook, Instagram และ LinkedIn

## คำแปลเต็ม

ตอนนี้เราจะมาตั้งค่าส่วนการเผยแพร่อัตโนมัติกัน ขอเปลี่ยนชื่ออันนี้เป็น demo ก่อน กลับมาตรงนี้ ตอนนี้เราอยากมาอยู่ตรงนี้ เพื่อนำเข้าอันที่สองซึ่งก็คืออันนี้ ไปที่ save แล้วสร้าง scenario (สถานการณ์จำลอง) ใหม่ ก่อนอื่นเราต้องดาวน์โหลด publishing automation (ระบบเผยแพร่อัตโนมัติ) ก่อน แล้วไปที่ import blueprint (นำเข้าแปลน) นำเข้าไฟล์นั้นแล้วบันทึก

อันนี้จะตั้งค่าได้เร็วกว่ามาก สิ่งเดียวที่เราต้องทำเพิ่มคือตั้งค่า webhook ขอสร้าง webhook ใหม่สักอัน ชื่ออะไรก็ได้ไม่สำคัญ จากนั้นผมต้องกลับไปที่โค้ด Apps Script ของผมตรงนี้ เลื่อนลงไปด้านล่าง ถ้าเราแก้ไข webhook นี้ ตอนนี้คุณต้องใส่ webhook นี้ลงไป มันจะต่างจากของคุณเพราะคุณต้องสร้างอันนี้ขึ้นมา แล้วคลิก OK ตรงนี้ คลิก และนั่นคือข้อมูลทั้งหมดที่คุณต้องเพิ่มตรงนี้

ผมไม่ต้องทำอะไรเพิ่ม สิ่งที่คุณต้องทำคือตั้งค่าแพลตฟอร์มที่คุณต้องการเผยแพร่ใช่ไหม และผมจะไม่ลงรายละเอียดมากเพราะตอนนี้มันมีแค่ Twitter ในการเชื่อมต่อกับ Twitter คุณต้องตั้งค่าบัญชีของคุณก่อน ก็แค่คลิก add แล้วคลิก show advanced settings (แสดงการตั้งค่าขั้นสูง) จากนั้นคุณต้องใช้ API key และ API secret

ผมมีวิดีโอสอนเทคนิคเฉพาะที่แสดงให้เห็นว่าคุณจะหาข้อมูลเหล่านี้ได้จากที่ไหน เพราะคุณต้องตั้งค่า Twitter Developer และตรงนั้นคุณจะได้ข้อมูลเหล่านี้มา ซึ่งคุณต้องใช้เพราะมีโมดูลที่สองด้วย คุณต้องใช้ client ID และคุณก็ได้ข้อมูลนี้จากวิดีโอสอนนั้น แล้วคุณก็ตั้งค่าบัญชี Twitter ของคุณเรียบร้อย

แน่นอนว่าตรงนี้ผมต้องตั้งค่า sheet ID ของผมใหม่ ขอใส่ลงไปตรงนี้ เพราะสิ่งที่ถูกเพิ่มลงในชีตของผมคือวันที่เผยแพร่ มันจะแสดงเวลาเผยแพร่ ขอผมกลับไปตรงนี้ก่อน ผมต้องดูสูตรที่แน่นอนที่ผมใช้ใน automation อีกตัว เพราะมันถูกลบไป somehow แต่ผมพอจำได้แล้ว นี่คือ publishing time (เวลาเผยแพร่) ผมใส่อะไรลงไปตรงนี้ ขอเช็คหน่อย มันคือ post remix automation publisher ใช่ไหม และอย่างที่เห็นผมมีรูปแบบนี้

ผมจะบันทึกมันให้คุณด้วย ตรงนี้ คุณมีมันไว้ตรงนี้แล้ว โดยพื้นฐานแล้วมันคือโค้ดที่คุณต้องพิมพ์เพื่อบันทึกเวลาเผยแพร่ลงในชีต และมันจะมีลักษณะแบบนี้: format date now แล้วก็อันนี้ และอันนั้น แล้วมันจะบันทึกวันที่นั้น ขอคัดลอกอันนั้น ดี

และโดยพื้นฐานแล้วผมสามารถทำอีกวิธีหนึ่งได้ เพราะโมดูลพวกนี้ทั้งหมดทำงานเหมือนกัน มันเป็นโมดูลเดียวกันทุกอัน ไม่ว่าคุณจะใช้แพลตฟอร์มอะไร แค่วันที่เผยแพร่จะถูกบันทึกในคอลัมน์เดียวกัน มันใช้งานได้ ใช่ไหม ตอนนี้เราต้องการ ID นี้ ตรงนี้ ID นี้ไม่ถูกต้องใช่ไหม แต่มันถูกต้องไหม ผมยังไม่ได้บันทึกมัน ขอลองอีกครั้ง ไม่ มันเป็นอันที่ผิด อันที่ผิดจริง ๆ

อันนี้ต่างหากที่เป็น automation ที่ถูกต้องที่ผมต้องการ Publishing time นั่นคือสิ่งที่ผมหมายถึง อันนั้นแหละถูกต้อง ใช่ บันทึกอันนั้น แล้วตอนนี้เราจะลบพวกนี้ ไม่ใช่อันนั้น ไม่อยากลบอันนี้ ขอลองอีกครั้ง Google Sheet ตรงนี้ ลองดูว่าผมจะคัดลอกอันนี้ตรง ๆ ได้ไหม จะเกิดอะไรขึ้นถ้าผมคัดลอกอันนี้แล้วบันทึกอันนี้ อันนี้ก็ใช้ได้เหมือนกัน คุณสามารถคัดลอกและวางได้โดยตรง ดีที่รู้ Clone แล้ว clone โอเค

ตอนนี้ลองรันมัน สิ่งที่ผมจะทำตามปกติ ถ้าผมตัดสินใจว่าจะทำทันที นี่คือจุดที่มันควรจะรันจริง เพราะผมมีอันนี้อยู่ตรงนี้ ตรงนี้ผมสามารถระบุแพลตฟอร์มได้: Facebook และผมยังพิมพ์ Twitter และ LinkedIn ได้ เหล่านี้คือแพลตฟอร์มที่ผมมี และอีกอันหนึ่ง

เมื่อผมคลิกตอนนี้ คุณควรเห็นว่า webhook ถูกเปิดใช้งาน มันส่งไปที่ Facebook และ Instagram เท่านั้น จากนั้นผมก็ไปที่บัญชี Facebook และ Instagram ของผม ซึ่งคุณก็ต้องมีเหมือนกัน โดยวิธีก็คือคลิก add connection ถ้าคุณยังไม่มีการเชื่อมต่อ ทำตามขั้นตอนสำหรับ LinkedIn ด้วย

มันล้มเหลว ทำไม อ๋อ ผมต้องให้สิทธิ์ (reauthorize) ใหม่อีกครั้ง ขอเช็คที่หน้า demo ของผมก่อน มันควรจะเผยแพร่อันนี้ นี่คืออันนี้ มันทำงานบน Instagram แล้ว มันยังไม่ได้เผยแพร่เพราะผมเห็น error (ข้อผิดพลาด) บางครั้ง error แบบนี้ก็เกิดขึ้น ลองดูว่าผมจะแก้ error ตรงนี้ได้ไหม ขอไปที่อันนี้แล้วทำขั้นตอนการให้สิทธิ์ใหม่อีกครั้ง ลองดูว่าจะแก้ปัญหาได้ไหม

มันน่าจะเป็นแบบนี้ นี่มันแสดงหน้าเว็บได้อย่างถูกต้อง ดี ดังนั้นก่อนที่คุณจะโพสต์ไปที่ Instagram ได้ คุณต้องเชื่อมต่อมันก่อน คุณต้องเชื่อมต่อหน้า Facebook กับหน้า Instagram ของคุณ ผมคิดว่าผมมีคู่มือนี้ไหมตรงนี้ ผมไม่มีเป็นคู่มือ แต่มันค่อนข้างง่าย คุณไปที่หน้า Facebook ของคุณ แล้วเปลี่ยนเป็นหน้าของคุณ คุณต้องมีหน้า Facebook เพื่อทำสิ่งนี้ ถ้าคุณยังไม่มี คุณต้องสร้างก่อน จากนั้นไปที่ settings แล้วเลื่อนลงไปที่ด้านล่าง ตรงส่วนที่เชื่อมต่อ (linked) อยู่ และตรงนั้นคุณสามารถเชื่อมต่อบัญชี Instagram ของคุณได้ ขอทำตามขั้นตอนตรงนี้

ทีนี้ลองรันมันอีกครั้ง คุณเห็นไหมว่าบันทึกวันที่โพสต์แล้ว อันนี้ใช้ได้ ถ้าผมทำแบบนี้ ลองดูว่าตอนนี้มันจะทำงานกับ Instagram ไหม ตอนนี้ Facebook ดูเหมือนว่าจะทำงาน ขอหวังว่ามันจะทำงานด้วยคราวนี้ ตอนนี้มันทำงานแล้ว บางครั้งคุณต้องให้สิทธิ์ใหม่ ขอรีโหลดมัน แล้วคุณจะเห็นว่าโพสต์ของผมอยู่ตรงนั้น ดี ดังนั้นตัวเผยแพร่ก็ทำงานเช่นกัน

ตอนนี้ผมจะไปรัน scenario ทันทีตามข้อมูลใช่ไหม และผมจะบันทึกมัน จากนั้นผมจะสลับอันนี้ไปเป็นแบบนั้น และผมก็สามารถสร้างโพสต์ด้วย automation อีกตัวของผม แล้วเผยแพร่ไปยังแพลตฟอร์มที่ผมต้องการ นี่คือวิธีที่คุณเห็นการตั้งค่านี้ และตอนนี้กระบวนการตั้งค่าก็เสร็จสมบูรณ์

อย่าลืมตรวจสอบด้วยว่าถ้าคุณต้องการรันอีกอันหนึ่ง คุณต้องเปิดสวิตช์อันนั้นไว้ด้วย และตรงนี้ นั่นคือทั้งหมดจริง ๆ และผมคิดว่าเราครอบคลุมทุกอย่างแล้ว ครับ โอเค
