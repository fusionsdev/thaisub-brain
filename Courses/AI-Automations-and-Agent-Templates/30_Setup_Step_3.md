## บทนำ
วิดีโอนี้สอนวิธีแก้ไขข้อผิดพลาดที่อาจเจอใน Make.com workflow หรือ AI agent workflow เมื่อรูปภาพที่ระบบสร้างออกมาเป็นลิงก์ Google Drive แล้วไม่สามารถโพสต์ลง Instagram ได้ เพราะ Instagram คืน error ว่า "only photo or video can be accepted" วิธีแก้คือใช้ Cloudinary แปลงลิงก์ Google Drive ให้เป็นลิงก์รูปภาพที่ใช้ได้จริง แล้ว map กลับเข้า workflow อัตโนมัติ

## คำแปลเต็ม

ในวิดีโอนี้ผมจะแสดงวิธีแก้ error ที่คุณอาจเจอใน Make.com workflow หรือ AI agent workflow ที่มีขั้นตอนการเผยแพร่ผ่าน Make.com อยู่นั่นคือกรณีที่รูปภาพที่ระบบสร้างออกมาเป็นลิงก์ Google Drive และนี่คือกรณีเดียวเท่านั้นที่คุณจะเจอ error นี้

ถ้าผมคลิกที่ webhook นี้จะเห็นว่า URL เป็นลิงก์ Google Drive ซึ่งลิงก์แบบนี้ใช้ได้กับ Facebook โมดูลอื่น ๆ และ LinkedIn แต่สำหรับอันนี้มันคืน error กลับมาบอกว่า "only photo or video can be accepted" หรือรับได้เฉพาะรูปภาพหรือวิดีโอ เมื่อก่อนใช้กับ Google Drive ได้ แต่ตอนนี้ใช้ไม่ได้แล้วไม่ว่าด้วยเหตุผลใดก็ตาม

เพราะฉะนั้นผมจึงเตรียมวิธีแก้ไขไว้ให้คุณแล้ว โดยคุณสามารถอัปเดต workflow อัตโนมัติใน Make.com ที่ใช้ URL ของ Google Drive เป็นรูปภาพ และต้องการให้โพสต์ลง Instagram ได้ เฉพาะในกรณีนี้เท่านั้นที่คุณอาจต้องอัปเดต ถ้าคุณเห็น error "only photo and video can be accepted" คุณน่าจะต้องใช้วิธีแก้ที่ผมจะแสดงให้ดูตอนนี้ ซึ่งทำได้เร็วมาก

ไปที่ส่วนที่เขียนว่า Updates and Bug fixes แล้วเลือก Fix Google Drive image upload จากนั้นดาวน์โหลด AI automation fix module พอดาวน์โหลดเสร็จ ให้คลิก Create a new แล้วเลือก Import a blueprint โดยเลือก blueprint ที่เพิ่งดาวน์โหลดไป นี่คือ blueprint ที่ชื่อ AeroFix (ในคำบรรยาย STT อ่านว่า arrow fixed) ซึ่งดาวน์โหลดได้จากวิดีโอนี้

blueprint นี้ไม่ได้ให้ตัว fix สำเร็จรูปมาให้ แต่จะให้โมดูลที่คุณต้องนำไปรวมกับระบบของคุณ กด Select all แล้วคลิก Copy modules จากนั้นกลับไปที่ automation ที่ต้องการแก้ไข เราจะลบการเชื่อมต่อเดิมออก แล้ววางโมดูลเหล่านี้ลงไปตรงนี้ จากนั้นลากวางไว้ตรงนี้ และตอนนี้เราต้อง map ค่าให้ถูกต้อง แต่ยังไม่ต้อง connect

สิ่งแรกคือต้อง map ค่าให้ถูกต้อง อย่างแรกคือ image URL ที่ชี้ไปยัง Google Drive URL เพราะเราต้องแปลงลิงก์ Google Drive ให้เป็นลิงก์รูปภาพรูปแบบอื่น ที่ไม่ใช่ลิงก์ Google Drive และนั่นคือสิ่งที่เราใช้โมดูลเหล่านี้ทำ

ส่วนนี้วางไว้ข้าง ๆ ได้เลย สิ่งเดียวที่คุณต้องปรับจริง ๆ คืออันนี้ เพราะตรงนี้คุณต้องคลิก Add แล้วสิ่งที่ต้องทำคือคลิกที่ลิงก์นี้ เพื่อไปสมัครใช้งานแบบฟรี และใช้ได้ฟรีจริง ๆ มันคือแพลตฟอร์มเก็บไฟล์ออนไลน์ที่คุณสามารถอัปโหลดไฟล์ได้อัตโนมัติ

พอสมัครฟรีเสร็จ ไปที่ Dashboard แล้วคลิก Cloud Copy จากนั้นกลับมาที่ automation ของเรา มาป้อนชื่อ cloud ตรงนี้ คุณต้องใช้ username ซึ่งจะหาได้ตรง Settings ไปที่ API Keys โดย username ก็คือ API key นั่นเอง และอันนี้คือ API key secret

ถ้าคลิกที่ตรงนั้น ระบบจะส่งอีเมลมาให้ แล้วคุณต้องใส่รหัสยืนยันจากอีเมล จากนั้นคุณจะเห็น API key secret คัดลอกมาวางตรงนี้ แล้วคลิก Create ต่อไปได้เลย

ที่เหลือแทบไม่ต้องทำอะไรนอกจากสิ่งนี้ คุณต้องกลับไปที่ Cloudinary ไปที่ Upload แล้วคลิก Add upload preset ตั้งชื่ออะไรก็ได้ ไม่สำคัญ แล้วสิ่งสำคัญคือต้องเลือก Unsigned จากนั้นคลิก Save แล้วคัดลอกชื่อนี้มาวางตรงนี้ แค่นี้ก็เสร็จแล้ว

จากนั้นคลิก Run (ผมจะคลิก Run ให้ดู) แล้วคุณต้องเลือก workflow ซึ่งจะแตกต่างกันไปตามระบบอัตโนมัติหรือระบบ AI agent ที่คุณใช้ ผมใช้ระบบนี้ที่ส่งโพสต์เข้าสู่ workflow ตามเวลาที่กำหนด ผมแค่ต้องตั้งเวลาโพสต์อีก 5 นาทีจากนี้ พอประมวลผลเสร็จก็จะถูกส่งไปที่ webhook นี้ แต่จริง ๆ แล้วมันขึ้นอยู่กับ trigger ของแต่ละระบบ ซึ่งผมเตรียมไว้ให้แล้ว รันได้ทันที

ดูตรงนี้ รูปถูกส่งออกไปแล้ว ยังเป็น image URL อยู่ แต่นี่เป็นสิ่งที่ดี เพราะมันถูกแปลงเป็นไฟล์รูปภาพของ Cloudinary แล้ว จะเห็นว่าลิงก์ใหม่นี้ใช้กับ Instagram ได้ ตรวจดูว่าไฟล์อยู่ตรงนั้นจริง

และตอนนี้เหลืออีกอย่างเดียวคือ connect กลับเข้าไปใหม่ แล้ว map ไปที่ image URL แต่ตอนนี้ image URL นี้ต้องมาจาก Parse JSON ตรงนี้ แล้วคลิก Save

ผมจะเปลี่ยน image URL อันอื่นให้ใช้ลิงก์นี้เหมือนกันเพื่อความสอดคล้อง ต่อไปเราใช้ URL นี้ลิงก์เดียว ไม่มีปัญหาอะไร โมดูลอื่น ๆ ก็ทำงานกับลิงก์นี้ได้เหมือนกัน ตรงนี้... ตรงนี้ก็มีแล้ว คลิก Save คลิก Save

ตรงนี้ผมขอทดสอบอีกครั้งเพื่อดูว่าตอนนี้ใช้ได้หรือยัง และจะไม่เจอ error อีกต่อไป ตอนนี้มันทำงานแล้ว รูปภาพจะถูกเผยแพร่ผ่าน cloud ของเรา ดูดีมาก มันสำเร็จแล้ว

นี่คือ fix ที่คุณต้องนำไปใช้ จากนั้นเชื่อมต่อโมดูลอื่น ๆ กลับทั้งหมดอีกครั้ง ทดสอบอีกสักครั้งกับทุกแพลตฟอร์มที่คุณเชื่อมต่อหรือต้องการเผยแพร่ และเมื่อทุกอย่างใช้ Cloudinary แล้วค่อยเปิดสวิตช์นี้อีกครั้ง นี่คือเวอร์ชันที่แก้ไขและอัปเดตแล้ว ซึ่งควรจะโพสต์รูปภาพของคุณไปยังบัญชีโซเชียลมีเดียต่าง ๆ ได้โดยไม่มี error อีกต่อไป
