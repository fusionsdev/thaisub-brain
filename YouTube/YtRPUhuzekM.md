# สรุป: I Made 3D Motion Graphics With FREE AI Tools

## ประเด็นหลัก
- ทำโมชันกราฟิก 3D สไตล์ที่เห็นบน Instagram TikTok และ Pinterest โดยไม่เปิด After Effects
- ใช้ master prompt ใน ChatGPT เลือก niche ไอเดีย บทพากย์ visual theme แล้วแตกฉากพร้อม image/video prompt
- สร้างภาพและวิดีโอใน Google Flow ด้วยเครดิตวิดีโอฟรีวันละ 50 เครดิต (ภาพไม่กินเครดิต)
- ใช้ Chrome extension จาก Telegram ช่วย paste/load prompts และ generate อัตโนมัติ
- ตั้ง video model เป็น VO3.1 light อัตราส่วน 9:16 ความยาว 8 วินาที โหมด S+E
- ผูก start frame / end frame แบบต่อเนื่อง (01→02 02→03 … 07→01) เพื่อให้คลิปไหลลื่น
- สร้าง voice-over จาก narration ใน ElevenLabs แล้วตัดต่อใน CapCut
- ตัดช่วงเงียบ ซิงก์คลิปกับพากย์ เร่ง speed ถ้าคลิปยาว ลดเสียงคลิป -8 ถึง -10 dB เพลงพื้นหลังประมาณ -20 dB
- ส่งออกเมื่อตรวจภาพและเสียงครบ แล้วตามทรัพยากรบน Telegram จากลิงก์ใน bio
- มีคลิปถัดไปสอนทำวิดีโอประวัติศาสตร์ไวรัลด้วย AI

## ความเห็นสรุป
คลิปนี้เป็น tutorial เชิงปฏิบัติที่รวม ChatGPT Google Flow extension ElevenLabs และ CapCut เป็น pipeline เดียวครับ.
จุดเด่นคือ master prompt ที่ลดงานคิดฉากและ prompt เอง พร้อมเทคนิค start/end frame ให้คลิปต่อกันนุ่มครับ.
เหมาะกับคนที่อยากทำคลิปแนว editorial 3D แนวตั้งบนโซเชียลโดยใช้เครื่องมือฟรีเป็นหลักครับ.
