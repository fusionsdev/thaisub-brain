## บทนำ

วอล์กทรูอินเทอร์เฟซแอป Claude Desktop ตั้งแต่การแชท, ปุ่มเพิ่มไฟล์และรูปภาพ, การเพิ่มโปรเจกต์, สกิล, คอนเนกเตอร์, ฟีเจอร์ research และการเปลี่ยนสไตล์การตอบ พร้อมแนะนำโมเดลหลักทั้ง Opus, Sonnet และ Haiku ว่าเหมาะกับงานแบบไหน รวมถึงการดูประวัติแชทและฟีเจอร์ incognito

## คำแปลเต็ม

ยินดีต้อนรับสู่ Claude Desktop App UI walkthrough ครับ ในวิดีโอนี้ผมจะพาคุณเดินชมแอป Claude Desktop ทั้งแอป เพื่อให้คุณเข้าใจอย่างแท้จริงว่าคุณกำลังใช้ตัวอะไรอยู่ และมันสำคัญมากที่คุณต้องดูและตั้งใจฟัง พอจบวิดีโอนี้ คุณจะรู้ทุกอย่างที่อยู่ใน Claude และเริ่มใช้มันได้เลย เริ่มทดลอง เล่นไปเรื่อยๆ ได้เลย

สิ่งที่เราจะทำคือ เปิด Claude ขึ้นมา แล้วมันจะพาคุณเข้าสู่ Claude Desktop ขอผมขยายหน้าต่างให้หน่อยนะ คุณจะเห็นอะไรสองสามอย่างเมื่อเข้ามาถึง อย่างแรก ตอนที่คุณสมัคร คุณตั้งชื่อให้มัน คุณมีชื่อของคุณตรงนี้ มันเขียนว่า "good Noah AI" คุณมีช่องแชทของคุณ นี่คือที่ที่คุณพิมพ์อะไรก็ได้ แล้วกดส่ง เหมือนกับ ChatGPT หรือ AI ตัวอื่นๆ มันก็คือแชทนี่แหละ อันนี้เรียกว่า context window ผมจะลงรายละเอียดเพิ่มเติมทีหลัง แต่นี่คือจุดที่คุณสื่อสารกัน

คุณจะเห็นที่มุมซ้ายล่างมีเครื่องหมายบวก ถ้าคุณกดมัน ขอให้กดเครื่องหมายบวก แล้วคุณจะเห็นหลายอย่าง คุณจะเห็น add files or photos นี่คือที่ที่คุณคลิก แล้วมันจะเปิดไฟล์ของคุณขึ้นมา คุณสามารถลากไฟล์ลงไป แล้ว Claude จะอ่านให้คุณ ถ้าคุณให้เอกสารมัน เช่น คุณให้มันอ่านแล้วบอกว่ามีอะไรอยู่ข้างใน สรุปให้หน่อย หรือคุณให้รูปภาพของคุณกับเพื่อนคุณ มันก็สรุปและบอกได้ว่ามีอะไรอยู่ในนั้น

แล้วก็มี add to project — โปรเจกต์ ผมจะพูดถึงในบทอื่นๆ ทีหลัง แต่โดยพื้นฐานมันให้คุณสร้าง AI employee ของคุณเองได้ แล้วก็ add to GitHub ยังไม่ต้องกังวลกับอันนั้น แต่ก็ประมาณพวกงานโค้ด คุณมี skills ตรงนี้ ผมจะพูดถึงทีหลัง เช่นเดียวกันกับ connectors อันนี้จะให้เราเชื่อมต่อกับทุกแอปใน Claude ได้ แล้วก็มี research ซึ่งทำการค้นคว้าเชิงลึกให้คุณบนอินเทอร์เน็ต Web search ให้คุณค้นหาบางอย่างบนเว็บได้ แล้วก็ use style คุณสามารถเปลี่ยนสไตล์การตอบสนองของมันต่อคุณได้ เช่น โหมด learning ซึ่งจะสอนคุณ — ผมแนะนำเสมอว่า ถ้าคุณเพิ่งเริ่มกับ AI ให้ลองให้มันอธิบายกับคุณในระดับความเข้าใจของเด็กประถมว่าทำไมมันถึงให้คำตอบนั้นมา มันจะให้คำตอบสั้นลง อธิบายละเอียดขึ้น หรือแบบเป็นทางการขึ้น ซึ่งเป็นสไตล์ที่จริงจังกว่า และคุณสร้างสไตล์ของคุณเองได้ในนี้ด้วย

แล้วสิ่งที่คุณจะเห็นคือ Opus 4.7 ตรงนี้ ณ วันที่ 16 เมษายน อันนี้เพิ่งปล่อยวันนี้เอง แต่ถ้าคุณคลิกที่มัน คุณจะเห็นหลายโมเดล คุณมี Opus, Sonnet และ Haiku 4.5 สิ่งที่คุณต้องรู้คือ Opus ซึ่งอยู่บนสุดคือโมเดลที่ดีที่สุด มันแพงที่สุด คุณจ่ายตามการใช้งาน คุณไม่จำเป็นต้องกังวลเรื่องนั้น แต่สิ่งที่คุณต้องรู้คือ โมเดลบนสุดคือตัวท็อป ใช้สำหรับงานที่ต้องคิดหนัก ตอนที่คุณทำโปรเจกต์ใหญ่ๆ และต้องวางแผน มันเป็นงานระดับสูงกว่า

ส่วน Sonnet มีประสิทธิภาพมากสำหรับงานประจำวัน เช่น การอ่าน การร่าง การตั้งค่า การดึงข้อมูล อะไรพวกนั้น เป็นงานพื้นฐานง่ายๆ และ Haiku เหมาะที่สุดกับคำตอบเร็วๆ สิ่งที่คุณต้องรู้คือ แค่ใช้ Opus 4.7 ไปก่อน ถ้าคุณอยากประหยัดเงิน ประหยัดการใช้งาน ก็ใช้ Sonnet 4.6 หรือ Haiku ผมไม่เคยเปลี่ยนโมเดลเลย พูดตามตรง

แล้วก็มี adaptive ยังไม่ต้องกังวลกับมัน แล้วก็ more models ซึ่งเป็นโมเดลรุ่นเก่า เราไม่อยากใช้ของเก่า นั่นคือทั้งหมดสำหรับส่วนนี้

คุณยังมีปุ่มที่กดเพื่ออัดเสียงได้ คุณสามารถพูดได้เลย กดปุ่มนี้แล้วเริ่มพูด นั่นคือสิ่งที่พิมพ์ข้อความแทนคุณ เห็นไหม? คุณสามารถพูดกับ Claude แล้วมันจะเขียนให้คุณ ผมใช้ Whisper ซึ่งเป็นแอป AI ที่เอาเสียงพูดทั้งหมดของผมมาแปลงเป็นข้อความ ตั้งแต่วันที่ผมโหลดมา มันให้ผมพิมพ์โดยใช้เสียง แล้วมันเขียนทุกอย่างที่ผมต้องการออกมา เห็นไหม? ปัง! เจ๋ง นี่คืออินเทอร์เฟซเล็กๆ น้อยๆ

แล้วคุณจะเห็นโค้ดตรงนี้ อันนี้ให้คุณสลับไปเป็น Claude Code อันนี้คือ strategize ไม่ค่อยต้องใช้เท่าไหร่ แล้วคุณจะเห็น Drive, Gmail อันเหล่านี้เรียกว่า connectors มันให้คุณเชื่อมต่อกับ Google ของคุณ มันอ่าน Google Drive ของคุณและจัดระเบียบให้คุณ ปฏิทินของคุณ มันเข้าไปจองนัดหมายให้คุณ หรือบอกคุณว่ามีอะไรจะมาถึง มันร่างอีเมลให้คุณ สตาร์อีเมลให้คุณ อะไรดีๆ แบบนั้น แต่ผมไม่อยากให้คุณตื่นเต้นเกินไป ผมจะลงรายละเอียดเรื่องนั้นทีหลังในคอร์ส

นั่นคือทั้งหมดสำหรับ UI ด้านหน้า คุณจะเห็นที่มุมขวาบน มี incognito ผมไม่ค่อยได้ใช้มันเท่าไหร่ แต่โดยพื้นฐานมันไม่บันทึกประวัติแชทของคุณ ถ้าคุณกำลังบอกอะไรที่ลับสุดๆ คุณก็ใช้มันได้

แล้วคุณจะเห็นแถบที่มุมซ้ายบน ตรงนี้คุณแค่คลิกมัน สิ่งที่จะเกิดขึ้นคือ มันจะเปิดประวัติแชทของผม ซึ่งผมกำลังเปิดเผยแชทของผมเอง นั่นไม่เป็นไร เพราะพวกคุณรู้ว่าผมบ้าแค่ไหน แต่คุณจะเห็นหลายอย่าง ด้านบนมี collapse มันแค่เปิดปิด แล้วก็ search ให้คุณค้นหาแชทต่างๆ ที่คุณมี แล้วก็ new chat ให้คุณเริ่มแชทใหม่ สมมติว่าผมพูดว่าเริ่มแชท มันก็จะไปโผล่ในรายการ recent ตรงนั้น ใต้ greeting อันเหล่านี้คือแชทเก่าทั้งหมดของคุณ เท่าที่เคยมีมา และคุณคลิก view all เพื่อดูทั้งหมด แล้วคุณลากมันแบบนี้ได้ คุณลากมาปักหมุดได้ ถ้าคุณอยากปักหมุดบางแชทที่คุณทำงานใน context เดิมตลอด คุณก็ลากมันไปตรงนั้น นั่นคือแชทของคุณโดยสรุป

ถ้าคุณอยากเริ่มแชทใหม่ ก็คลิก new chat แล้วเริ่มใหม่ คุณมีอีกสองสามอย่างตรงนี้ คุณมี projects — ผมจะลงรายละเอียดทีหลังว่ามันคืออะไร แต่โดยพื้นฐานมันเหมือนแชตบอตที่เทรนด้วยคำสั่งเฉพาะ ที่จดจำทุกอย่างให้คุณ แต่ยังไม่ต้องกังวลตอนนี้ เราจะลงรายละเอียดทีหลัง นี่คือที่ที่คุณเชื่อมต่อแอปทั้งหมดของคุณ และคุณสร้างสกิลใหม่ได้ แต่ผมจะลงรายละเอียดเพิ่มเติมทีหลัง

แล้วก็มี artifacts ผมไม่ค่อยได้ใช้ ไม่ซื่อสัตย์เลยที่จะบอกว่าผมไม่เข้าใจมันจริงๆ แต่โดยพื้นฐานมันให้คุณเริ่มสร้างแอปและเครื่องมือเพิ่มประสิทธิภาพ มันให้จุดเริ่มต้นในการสร้างสิ่งเหล่านั้น นั่นคือ UI
