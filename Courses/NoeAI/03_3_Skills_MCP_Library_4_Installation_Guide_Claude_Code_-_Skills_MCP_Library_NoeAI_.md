## บทนำ

วิดีโอนี้สาธิตการติดตั้ง skills และ MCP servers เข้าไปใน Claude Code ตั้งแต่ดาวน์โหลดไฟล์จาก Google Sheet อัปโหลดผ่านเมนู Customize ไปจนถึงการตรวจสอบด้วย slash command และใน terminal เนื้อหายังอธิบายแนวทางติดตั้งแบบ global กับแบบเฉพาะโปรเจกต์ด้วยครับ

## คำแปลเต็ม

ยินดีต้อนรับสู่คู่มือการติดตั้ง Claude Code สำหรับ skills และ MCP servers ครับ วิดีโอนี้ผมจะแสดงให้ดูว่าติดตั้ง skill เข้าไปใน Claude Code ได้อย่างไร งั้นเราเริ่มกันเลยครับ

ก่อนอื่น skills ทั้งหมดที่เรามีจะอยู่ใน Google Sheet ครับ แนะนำให้ไปดูวิดีโอเฉพาะเรื่องนี้ด้วย ตอนนี้ผมยังไม่ได้อัปโหลดวิดีโอนั้น แต่ขอให้ไปดูนะครับ ผมจะแจกแจงให้เข้าใจว่ามันทำงานอย่างไร หน้าตามันจะเป็นไฟล์ขนาดใหญ่ที่รวมทุกอย่างที่คุณอาจต้องการดาวน์โหลดเอาไว้ในที่เดียว

เราจะเลือก skill สักตัวเป็นตัวอย่าง ผมจะเปิดโฟลเดอร์ Drive ตรงนี้ แล้วข้างในเป็นไฟล์ zip เราก็กด Download จากนั้นไปที่ Claude ครับ

ตอนนี้เราอยู่ใน Claude แล้ว ผมจะเปิดฟีเจอร์ Code ตรงนี้ ตอนนี้เราอยู่ใน Claude Code โดยเฉพาะ และถ้าคุณใช้งานผ่าน terminal ผมจะแสดงวิธีตั้งค่าให้ดูด้วย แต่ขั้นตอนแรกคือเข้ามาที่ Customize ก่อน ผมจะย้ายหน้าต่างนี้ออกไป แล้วไปที่ Create new skills

จากนั้นคุณจะเห็นรายการ skills และกด Create skill ต่อด้วย Upload แล้วเปิดไฟล์ที่เราเพิ่งดาวน์โหลดมา เห็นไหมครับว่าเรามี ad brief อยู่ตรงนี้ สิ่งที่ต้องทำก็แค่ลากไฟล์มาวางเท่านั้น

ผมมี ad brief อยู่ในระบบแล้ว แต่จะสาธิตด้วยการกด Upload and replace ส่วนคุณจะเห็นปุ่ม Create จากนั้นระบบก็จะอัปโหลดไฟล์และสร้าง skill ให้ครับ พออัปโหลดเสร็จ ระบบจะ generate skill ขึ้นมาตรงนี้ และตอนนี้ผมก็มี skill แบบเต็มอยู่ในระบบแล้ว พร้อมใช้งานครับ

เพื่อทดสอบ ผมจะกลับไปแล้วพิมพ์ slash command จากนั้นพิมพ์ add brief เห็นไหมครับ มันทำงานและ active แล้ว เท่านี้ก็พร้อมใช้ครับ นี่คือวิธีติดตั้ง skills ทั้งหมดของคุณ สำหรับ MCP ก็ใช้แนวทางเดียวกัน เพราะทั้งหมดเป็นไฟล์ คุณแค่ลากไฟล์เข้ามาแล้วติดตั้งครับ

ถ้าคุณใช้งานใน Cursor หรือโปรแกรมอื่น ก็เป็นรูปแบบการติดตั้งเดียวกัน คุณเปิดไฟล์ที่กำลังทำงานอยู่ แล้วลากไฟล์เข้ามาได้เลย จากนั้นคุณสามารถดาวน์โหลด skill แบบ global ลงในคอมพิวเตอร์ของผม หรือถ้าต้องการใช้เฉพาะโปรเจกต์ ก็ให้ดาวน์โหลดไว้ในโปรเจกต์นั้นแทนครับ

ถ้าคุณไม่รู้ว่าหมายถึงอะไร แสดงว่ายังไม่ได้เรียนคอร์ส Cloud Code Mastery [ฟังไม่ชัด] ถ้าอย่างนั้นกลับไปดูคอร์สนั้นก่อนนะครับ จากนั้นคุณก็ส่งคำสั่งให้ระบบ และมันจะดาวน์โหลด skill ลงในเครื่องให้ ในที่สุดคุณก็จะเห็นว่ามันติดตั้งเสร็จแล้ว ระบบอาจมี skill อยู่ก่อนแล้ว แต่คุณเพียง prompt ให้มันดาวน์โหลดและตั้งค่า skill ให้คุณได้ครับ

ถ้าอยากตรวจสอบว่าดาวน์โหลดสำเร็จหรือยัง ผมคิดว่าผมให้คำแนะนำไว้แล้ว แต่คุณสามารถใช้คำสั่ง `ls` และดูโฟลเดอร์ `claude skills` ได้ หรือวิธีที่ผมชอบคือเปิด Finder แล้วกด Command + Shift + จุด เพื่อแสดงไฟล์ที่ซ่อนอยู่

โฟลเดอร์ skills ถูกซ่อนไว้ คุณมองไม่เห็นเพราะมันอยู่ในอุปกรณ์ของคุณ แต่ถ้าเข้าไปที่โฟลเดอร์ skills แล้วค้นหา คุณจะพบว่ามันอยู่ในโฟลเดอร์ Claude จากนั้นเข้าไปที่ skills แล้วก็จะเห็นรายการทั้งหมดครับ เห็นไหมครับ นี่คือ skill ที่เราเพิ่งติดตั้ง และ skills เหล่านี้เป็นแบบ global บนเครื่องของผม ผมจึงรู้ได้ว่ามันทำงานจริงและมองเห็นไฟล์อยู่ในนั้น

ผมจะทดสอบอีกครั้งใน terminal เพื่อดูว่ามันทำงานหรือไม่ เราพิมพ์ add แล้วคำสั่งก็แสดงขึ้นมา นี่คือวิธีติดตั้ง skills และ MCP servers บน Claude Code ทั้งในแอปเดสก์ท็อปและใน terminal ครับ ถ้ามีคำถามก็แจ้งมาใน community ได้เลย
