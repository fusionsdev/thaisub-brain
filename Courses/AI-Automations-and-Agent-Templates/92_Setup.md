## บทนำ
วิดีโอนี้สอนสร้าง AI agent บน WhatsApp ด้วย n8n ที่สามารถคุยกับลูกค้า ให้ข้อมูลสินค้า ส่งลิงก์ซื้อสินค้า ตอบคำถาม และเคลียร์ข้อกังขาของลูกค้าเพื่อปิดการขาย ระบบประกอบด้วย agent สองตัว: ตัวหนึ่งไว้ฝึกให้เรียนรู้ข้อมูลสินค้าจากลิงก์หน้าเว็บ และอีกตัวหนึ่งไว้บริการลูกค้า โดยมี Google Sheets เป็นฐานข้อมูลกลาง

## คำแปลเต็ม

ในวิดีโอนี้เราจะสร้าง WhatsApp AI agent ที่สามารถคุยกับลูกค้า ให้ข้อมูลเกี่ยวกับสินค้าของคุณ ส่งลิงก์สำหรับซื้อสินค้า ตอบคำถาม และเคลียร์ข้อกังขา เพื่อให้ลูกค้าตัดสินใจซื้อสินค้า เราจะทำทั้งหมดนี้ใน n8n คุณจะได้เทมเพลตเวิร์กโฟลว์ด้านล่างวิดีโอนี้ พร้อมลิงก์ที่ต้องใช้ในการตั้งค่า มาเริ่มกันเลย

อย่างแรก ถ้ายังไม่มีบัญชี n8n ต้องสมัครก่อน คลิก Get Started for Free แล้วเริ่มทดลองใช้ฟรีได้ พอลงชื่อเข้าใช้แล้ว คลิก Create a new workflow จากนั้นไปที่ตรงนี้ คลิก Download แล้วคลิก Import from file นำเข้าเวิร์กโฟลว์ที่เพิ่งดาวน์โหลดมา พอโหลดเสร็จ หน้าตาจะเป็นแบบนี้ ผมจะอธิบายโหนดหรือโมดูลต่าง ๆ ไปเรื่อย ๆ ตามที่เราทำ

สิ่งแรกที่ต้องตั้งค่าคือ WhatsApp trigger เพื่อให้ได้มา คลิก Create new credential ตรงนี้ต้องใช้ client ID และ client secret ตอนนี้ต้องใช้บัญชี Facebook developers คุณต้องสมัครบัญชีก่อน ผมคิดว่าแค่ล็อกอิน Facebook แล้วคลิก My Apps จากนั้นคลิก Create App ตั้งชื่อแอปตรงนี้ว่า AI agent setup template จากนั้นเลื่อนลงมา คลิก Select business ผมปล่อยไว้ตามเดิม คลิก Create App แล้วต้องล็อกอินบัญชี Facebook ส่วนตัว จากนั้นไปที่แอป ไปที่ Basic settings หา app ID นั่นคือ client ID ที่เราวางตรงนี้ ส่วน client secret ได้จากตรงนี้ คลิก แล้วกรอกข้อมูลนี้ เราจะตั้งชื่อมันว่า Test setup เท่านี้บัญชี WhatsApp ก็เรียบร้อย

ตอนนี้เรามีโมดูล WhatsApp อีกสองโมดูล ในการตั้งค่าก็คลิก Create new credential เหมือนเดิม ตรงนี้ต้องใช้ access token และ business ID ซึ่งได้จากตรงนี้ ต้องกลับไปที่แดชบอร์ด แล้วไปที่ Setup WhatsApp ตรงนี้ต้องเลือก business portfolio ถ้ายังไม่มี โดยพื้นฐานคือบัญชี Facebook business ซึ่งสมัครได้ฟรี ถ้ายังไม่มีก็ไปที่ business.facebook.com แล้วมันจะพาคุณทำตามขั้นตอนสร้างบัญชีธุรกิจ

ถ้าต้องการมากกว่านั้น บัญชีธุรกิจก็เพียงพอสำหรับการทดสอบ AI agent และตั้งค่าตามที่ผมสอนในวิดีโอนี้ แต่ถ้าอยากใช้งานจริงกับเบอร์โทรศัพท์จริงที่ลูกค้าคุยด้วยได้ และนำไปใส่บนเว็บไซต์ได้ ต้องทำการยืนยันบัญชีธุรกิจ (verify) บน Facebook ซึ่งต้องทำอีกสองสามขั้นตอน ผมเตรียม prompt ไว้ให้ คัดลอกไปวางใน ChatGPT หรือคลิก แล้วมันจะพาคุณทำตามขั้นตอนการยืนยันบัญชีธุรกิจ แต่สำหรับตอนนี้แค่นี้ก็พอ ไปที่ Create new business แล้วต้องสร้าง Facebook page ด้วย ถ้าต้องการความช่วยเหลือก็ถาม ChatGPT เกี่ยวกับเรื่องนี้ได้

จากนั้นเลือก business portfolio จากเมนูแบบเลื่อนลงตรงนี้ ผมมีอยู่แล้ว แล้วทำต่อได้ ผมคิดว่านี่คือวิธีที่ Facebook กันสแปม หรือป้องกันการใช้ WhatsApp เพื่อธุรกิจหรือ API ในทางที่ผิด ตรงนี้เราคลิก Start using the API และตรงนี้เรามี access token อยู่แล้ว ตอนนี้ access token เราคลิก แล้วต้องล็อกอินหรือยืนยันอีกครั้งด้วยบัญชี Facebook ตรงนี้แค่คลิกอันบนสุด คลิก Save

access token นี้มีอายุประมาณ 1 ชั่วโมง พอหมดอายุก็ต่ออายุใหม่ได้ เพราะนี่ใช้สำหรับการทดสอบเท่านั้น พอสลับเป็นโหมดจริงแล้วจะได้ access token แบบถาวร ซึ่งต้องใช้บัญชีธุรกิจที่ยืนยันแล้ว แต่ระบบจะสอนว่าต้องทำอะไรเพื่อสลับเป็นโหมด live เอาล่ะ ก่อนอื่นเราตั้งค่าในโหมดทดสอบก่อน ผมวาง access token ตรงนี้ แล้วเห็น WhatsApp business account ID คัดลอกแล้ววางตรงนี้ คลิก Save

สิ่งสุดท้ายที่ต้องทำตรงนี้คือเลือกเบอร์โทรศัพท์ที่จะส่งข้อความไปหา นี่คือเบอร์ที่ agent ใช้ส่งข้อความ และนี่ใช้ส่งถึงตัวผมเอง ผมใส่เบอร์ของผมตรงนี้แล้วคลิก Send message พอเปิดดู จะเห็นว่าผมได้รับข้อความแล้ว "Congratulations! This message demonstrates your ability to send a WhatsApp message notification from the cloud API hosted by Meta to our workflow." จากนั้นเราตั้งชื่อใหม่เพื่อให้หาเจอในภายหลัง คลิก Save

กลับไปที่เวิร์กโฟลว์ เลือกบัญชีนั้นในอีกโมดูลด้วย นั่นคืออันที่สี่ จากนั้นยังมีอีกอย่างที่ต้องทำ คือ HTTP request ตรงนี้ต้องเลือก WhatsApp account ที่เพิ่งสร้าง แล้วก็มี access token อีกครั้ง ไปที่ตรงนี้ ผมไม่อยากคัดลอกผิด วางตรงนี้แล้วคลิก Save

เพื่ออธิบายสิ่งที่เราตั้งค่า: สาขานี้แยกไปด้านบนและด้านล่าง เราสามารถคุยกับ AI agent ได้ด้วยการส่งข้อความเสียง หรือพิมพ์ข้อความธรรมดา พอส่งเสียง มันจะถอดเสียงก่อน แล้วส่งบทถอดเสียงเข้าสู่ agent เพื่อใช้เป็นคำสั่ง

ตรงนี้ต้องเชื่อมต่อบัญชี OpenAI ด้วย ถ้ายังไม่ได้ตั้งค่า คลิก Create New Credential ใส่ API key ซึ่งหาได้ในบทเรียนเทคนิคหัวข้อ Get API key from OpenAI จากนั้นใส่ได้เลย แล้วต้องเลือก chat model ด้วย จะใช้โมเดล chat ใดก็ได้ แต่ตรงนี้ต้องมีบัญชี Anthropic ผมพบว่ามันทำงานได้ดีที่สุดสำหรับผมในฐานะ chat model ของ AI agent และคุณก็เรียนรู้วิธีขอ API key จาก Anthropic ได้ในบทเรียนเทคนิคเช่นกัน

ให้ผมตรวจดูว่ามีอะไรต้องตั้งค่าอีกไหม ต่อไปคือ Google Sheet Google Sheet คือฐานข้อมูลที่ AI agent ของเราจะเก็บข้อมูลเกี่ยวกับสินค้า ตรงนี้เรามี Google Sheet คลิก Make a copy แล้วผมจะอธิบายว่ามันทำงานยังไง

ตรงนี้มี AI agent ชื่อ support นี่คือ agent ที่จะคุยกับลูกค้าเกี่ยวกับสินค้าและตอบคำถามเกี่ยวกับสินค้า มันเข้าถึง Google Sheet ได้ อ่านข้อมูลเกี่ยวกับสินค้าของเราได้ และนี่คือ training AI agent ตรงนี้เราสามารถฝึก AI agent เกี่ยวกับสินค้าได้ ผมจะส่งลิงก์หน้าเว็บสินค้าให้มัน แล้วมันจะเรียนรู้จากลิงก์นั้นและบันทึกข้อมูลอย่างเป็นระบบลงใน Google Sheet เพื่อให้ agent ฝ่ายบริการลูกค้าได้รับข้อมูลใหม่เกี่ยวกับสินค้าเหล่านี้ และตอบคำถามลูกค้าได้ นี่คือเหตุผลที่มี AI agent สองตัว ตัวหนึ่งไว้ฝึกและเรียนรู้เกี่ยวกับสินค้า อีกตัวไว้คุยกับลูกค้า และทั้งหมดเชื่อมกับฐานข้อมูลเดียวกัน

ผมจะใช้เทมเพลต Google Sheet นี้ สำคัญมากที่ต้องเชื่อมต่อบัญชี Google ของคุณ ไปที่ Google Sheets ตรงนี้ นี่คือสิ่งแรกที่ต้องทำ สร้างการเชื่อมต่อ คลิก แล้วสมัครด้วยบัญชี Google เดียวกับที่ถือสเปรดชีตนี้ แล้วคลิก Save ปิดหน้านี้ได้ ผมว่าของผมน่าจะเป็นอันนี้ ไม่แน่ใจเหมือนกัน แต่ต้องดูจริง ๆ setup demo นั่นแหละ เรียบร้อย ที่เหลือปล่อยไว้เหมือนเดิม โหลดใหม่ แค่นี้พอ

โดยพื้นฐานแล้ว พอเราส่งลิงก์เข้าเว็บไซต์ มันจะดึงข้อความออกมาจากหน้าสินค้า แล้วเก็บข้อความหรือคำอธิบายสินค้าไว้ใน Google Sheet แล้ว AI agent ก็ใช้ข้อมูลนั้นได้ ตรงนี้ต้องเชื่อมต่อ Google ที่ถูกต้องด้วย เอาล่ะ นี่คือสิ่งเดียวที่ต้องทำตรงนี้ และตรงนี้ก็ต้องตั้งค่า Google Sheet ด้วย หลังจากนั้นคิดว่าทดสอบได้แล้ว เลือก Setup แค่นี้พอ ตรงนี้เพิ่มตัวเลือกให้หยุดอ่านเมื่อถึงแถวว่างแรก ผมคิดว่าเราตั้งค่าทุกอย่างครบแล้ว ไม่ต้องเปลี่ยนอะไร

ตอนนี้คลิก Test workflow มันมีข้อมูลบางอย่างอยู่แล้ว ดูว่ามันทำอะไร แต่ไม่มีข้อความอยู่ในนั้น มันแค่รอคำตอบ เพราะมันเข้าใจเสียงผิดไปหน่อย ไม่เป็นไร กลับมาตรงนี้ เพราะตอนนี้เรายังไม่มีสินค้า ขั้นแรกที่อยากทำคือสลับ test workflow กับสิ่งที่ผมทำไว้ และไม่รู้ว่าทำไมมันยังรันอยู่ บางทีต้องลบมัน มันยังทำงานอยู่ มาตรวจสอบว่ามันใช้ input อะไร ตรวจสอบว่าข้อความที่ใช้คืออะไร มันใช้ไฟล์เสียงบางอย่าง ดูสิ อาจเป็นเพราะมันประมวลผลเสียงทั้งหมดที่มีอยู่ สิ่งที่ต้องทำคือลบข้อความทั้งหมดก่อน แล้วดูว่ามันทำอะไร ยังไม่รู้ว่าทำไมมันมีข้อความอยู่แล้ว เห็นข้อความ แล้วมันทำอะไร? ยังมีเสียงอยู่ แต่เสียงพูดว่าอะไร? ดูได้จากบทถอดเสียง นั่นเป็นข้อความเก่า มันตอบกลับมาจากอันนี้

ลองสลับเป็น Active เลิกใช้โหมดทดสอบ บางทีอาจง่ายกว่า เพราะตอนนี้ฝึกมันได้แล้ว วิธีฝึกคือพิมพ์ train ตัวพิมพ์ใหญ่ แล้วตามด้วยชื่อเว็บไซต์ ไปที่เว็บไซต์ของผมตรงนี้ นี่คือเว็บไซต์สินค้าเทมเพลตระบบอัตโนมัติของผม แล้วพิมพ์ train ตามด้วยเว็บไซต์ ตอนนี้มันควรจะเก็บข้อมูลนี้ลงในสเปรดชีตของเรา เห็นไหมว่า product description อยู่ในนั้นแล้ว ลิงก์ก็อยู่ และตอนนี้ AI agent จะหาสินค้า เติมข้อมูลสินค้าตามที่เห็น ครบถ้วนแล้ว

ตอนนี้สิ่งที่ทำได้คือผมทำเป็นลูกค้า ผมทำเป็นลูกค้า หรือลูกค้าจะใช้เบอร์เดียวกัน นี่คือเบอร์ทดสอบ คุณตั้งเบอร์จริงได้ แต่สำหรับการทดสอบ ผมให้เบอร์โทรศัพท์กับลูกค้าของผมได้ หลังจากฝึกโมเดลกับสินค้าหลายตัวแล้ว ลูกค้าของผมก็คุยกับมันได้ว่ามีสินค้าอะไรบ้าง

ผมจะเพิ่มสินค้าอีกหนึ่งตัวเพื่อให้มีข้อมูลหลากหลายขึ้น ฝึกมันอีกครั้งกับสินค้าอีกตัว ไปที่เว็บไซต์ของผม แล้วไปที่สินค้านี้ พิมพ์ train อีกครั้ง แล้วจะเห็นว่าสินค้าตัวที่สองปรากฏในฐานข้อมูลของเรา เห็นไหม ลิงก์ และนี่คือข้อความบนเว็บไซต์ของสินค้านั้น จากนั้น AI จะดึงราคาสินค้า และเขียนคำอธิบายสั้น ๆ ของสินค้า

ตอนนี้ลองถามด้วยเสียง: "What products do you have that I can purchase?" การดำเนินการนี้ใช้เวลาสองสามวินาที เพราะต้องถอดเสียงข้อความเสียงก่อน แล้วค้นหาในฐานข้อมูล แล้วสร้างคำตอบ แล้วมันจะบอกสินค้าที่มี แล้วผมถามต่อว่า "I want to automate social media content, which product is the best for me? And also send me the link to buy the product." ตอนนี้ได้รับคำตอบแล้ว มันให้ข้อมูลตรงตามที่ต้องการ: สินค้าคืออะไร ทำอะไรได้ และลิงก์สำหรับซื้อ AI agent ของเราทำงานแล้ว เรา switched เป็น live แล้ว เยี่ยม
