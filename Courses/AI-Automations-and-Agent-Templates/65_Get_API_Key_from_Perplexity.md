## บทนำ
วิดีโอนี้อธิบายวิธีขอ API Key จาก Perplexity เพื่อนำไปใช้ในการตั้งค่าระบบอัตโนมัติ ซึ่งขั้นตอนง่ายมาก แค่สมัครบัญชี เติมเครดิตเล็กน้อย แล้วคัดลอก API Key ไปใช้งาน

## คำแปลเต็ม

ในการตั้งค่า คุณก็ต้องใช้ API key เหมือนกัน ซึ่งหามันได้ง่ายมาก เพียงไปที่ perplexity.ai ถ้ายังไม่มีบัญชีก็สามารถสมัครแบบฟรีได้ จากนั้นไปที่... [ฟังไม่ชัด] ตรงนั้นคุณจะต้องเติมเครดิตก่อน ประมาณ 5 ดอลลาร์ แล้วก็ไปคลิกที่... [ฟังไม่ชัด] ตรงนั้นคุณสามารถคัดลอก API key แล้วนำไปใส่และบันทึกได้
