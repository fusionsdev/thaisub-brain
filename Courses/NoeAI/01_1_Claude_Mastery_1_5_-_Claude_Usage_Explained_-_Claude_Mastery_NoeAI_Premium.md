## คำแปลเต็ม

ผมจะมาอธิบายเรื่องข้อจำกัดการใช้งานของ Claude (usage limits) ครับ ซึ่งเป็นหนึ่งในคำถามที่ถูกถามบ่อยที่สุดเท่าที่ผมเคยเห็นบนอินเทอร์เน็ต และอาจเป็นฟีเจอร์ที่คนบ่นมากที่สุดของ Claude ด้วย เพราะไม่มีใครเข้าใจมันจริง ๆ และ Anthropic ก็จำกัดปริมาณการใช้งานที่ให้คุณค่อนข้างจำกัด ผมจะอธิบายในวิดีโอนี้ว่าการใช้งานทำงานยังไง คุณจะเลี่ยงการเผาผลาญโควต้าทั้งหมดยังไง และวิธีที่ดีที่สุดในการปรับใช้ต่อไปข้างหน้า เรื่องนี้สำคัญมาก คุณต้องดูให้จบ ไปดูกันเลยครับ

จริง ๆ แล้วคุณสามารถดูข้อจำกัดการใช้งานของคุณได้นะครับ ข้อจำกัดการใช้งานคืออะไร ก็เหมือนบทสนทนา เหมือนรูปภาพนั่นแหละครับ คือคุณมีจำนวนจำกัด สมมติผมให้เงินคุณ 20 ดอลลาร์ แล้วคุณไปที่ร้านค้าใช้หมดทั้ง 20 ดอลลาร์ นั่นคือการใช้งานของคุณทั้งหมด ถูกไหมครับ? มันเหมือนกับการใช้งาน Claude เลย มีสิ่งที่เรียกว่า tokens ถ้าคุณไม่รู้ว่า tokens คืออะไร มันก็ประมาณว่า คุณถูกเรียกเก็บเงินเพื่อใช้ AI ใด ๆ บนโลกใบนี้ พวกมันทำงานบนสิ่งที่เรียกว่า tokens และ tokens ก็คือคำพูดนั่นแหละ มีแค่นั้นเลย คุณถูกเรียกเก็บเงินต่อคำ

ถ้าผมหาคำนิยามของ token usage มันก็คือจำนวนรวมของกลุ่มตัวอักษร หรือพูดง่าย ๆ คือ token ไม่ใช่ตัวอักษรเดียวโดยตรง เห็นไหมครับว่ามันมีสีม่วง นั่นคือหนึ่ง token มันคือการรวมกันของคำและตัวอักษร และการใช้นั้นมีค่าใช้จ่าย แค่นี้ก็พอที่คุณต้องรู้แล้วครับ

เห็นไหมครับว่ามันเป็นตัวเลข 382 แต่มันคือ 94 tokens รวมทั้งหมด ข้อความทั้งหมดนี้มีค่าใช้จ่าย 94 tokens คุณจะได้รับการจัดสรร tokens จำนวนหนึ่งต่อสัปดาห์และต่อเดือนกับ Claude และถ้าคุณอยากรู้ว่าราคาเป็นยังไง คุณก็แค่ค้นหาด้วย Google ว่า Claude token cost

วิธีที่มันทำงานกับราคา subscription ก็คือ แต่ละโมเดลใช้ tokens มากขึ้นเรื่อย ๆ สมมติว่าคุณใช้โมเดลที่แรงที่สุด ซึ่งผมได้อธิบายไปแล้ว ถ้าเราเข้าไปที่ chat models คุณเปลี่ยนโมเดลได้ตามที่ผมสอนไป Opus คือโมเดลที่แรงที่สุด เทียบกับ Sonnet 4.6 และ Haiku 4.5 มันคือโมเดลที่แรงที่สุดและดีที่สุด และยังเป็น AI ที่แพงที่สุดในการใช้ด้วย เพราะมันใช้ tokens มากกว่าและพลังงานมากกว่า มันทำให้บริษัทเสียค่าใช้จ่ายมากขึ้นเพื่อใช้โมเดลนั้นให้ผลลัพธ์เดียวกันกับคุณ

ดังนั้น Claude Opus มีค่าใช้จ่าย $5 ต่อหนึ่งล้าน tokens หมายความว่า การใส่หนึ่งล้าน tokens เข้าไปจะมีค่าใช้จ่ายประมาณ $5 ถ้าผมคุยกับมันและให้ข้อมูลเยอะ ๆ มันก็ใช้เวลานานกว่าจะได้ แต่ถ้าผมคุยสักพักแล้วส่งข้อมูลเยอะ ๆ อย่างที่เห็นจากตัวอย่าง 382 ตัวอักษรคิดเป็น 94 tokens ดังนั้นถ้าผมส่งหนึ่งล้าน tokens จะเสีย $5 ง่ายมาก

นอกจากนี้ยังมีค่าใช้จ่ายสำหรับ Claude อีกด้วย มันเสียเงินให้ผมคุยกับ Claude คือผมต้องเสียเงินเพื่อส่งข้อความถึง Claude ครับ การส่งข้อความเข้าไปเสีย $5 แต่การที่ Claude ตอบกลับมานั้นแพงยิ่งกว่า จริง ๆ แล้วเสีย $25 เพื่อให้มันตอบกลับมา อันแรกคือ input ที่เราส่งเข้าไป ส่วน output คือสิ่งที่มันส่งกลับมาให้เรา ดังนั้น $25 ต่อหนึ่งล้าน tokens ของ output

แต่ละโมเดลมีค่าใช้จ่ายต่างกัน Claude Sonnet 4.6 มีค่าใช้จ่ายแค่ $3 คือเสียแค่ $3 เพื่อคุยกับ Claude ต่อหนึ่งล้าน tokens และการตอบกลับเสียแค่ $15 เห็นไหมครับว่าคุณประหยัดเงินได้ด้วยการเปลี่ยนโมเดล

แล้วก็มี Haiku ซึ่งเร็วที่สุด และ input แค่ $1 ไม่ถึง $3 ด้วยซ้ำ เอาไว้ใส่หนึ่งล้าน tokens เข้าไปใน Claude และการตอบกลับก็ถูกมาก Opus 4.7 คือโมเดลที่มีความฉลาดสูงที่สุด เป็นโมเดลที่ดีที่สุด ใช้ tokens มากที่สุด เทียบกับ Claude Sonnet ที่ไม่ฉลาดเท่าแต่ก็ไม่ได้โง่เท่า Haiku 4.5 นั่นคือสาเหตุที่ผมบอกว่ามันดีที่สุด ส่วน Sonnet เป็นค่าใช้จ่ายระดับกลาง ส่วน Haiku คือตัวที่ถูกที่สุดและให้ผลลัพธ์แย่ที่สุด พูดตรง ๆ เลยครับ

ในวิดีโอหน้า ผมจะอธิบายกรณีการใช้งานเฉพาะว่าคุณควรใช้โมเดลไหนในงานแบบไหน แต่นี่คือภาพรวมของวิธีการทำงานของ usage และถ้าคุณเข้าไปที่การตั้งค่าของคุณ คุณก็จะเห็นได้ด้วยตัวเอง
