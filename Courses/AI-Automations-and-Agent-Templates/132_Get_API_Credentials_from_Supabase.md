## บทนำ
วิดีโอนี้สาธิตการสมัครใช้งาน Supabase ตั้งแต่การสร้างโปรเจกต์ สร้างองค์กร ตั้งรหัสผ่านฐานข้อมูล ไปจนถึงการดึงข้อมูลรับรอง (credentials) จากหน้า project settings ในส่วน Data API เพื่อนำ project URL และ service role ไปใช้กับระบบอัตโนมัติ

## คำแปลเต็ม

ตรงนี้เราแค่คลิกที่ Start your project จากนั้นก็คลิก Sign up แล้วกรอกชื่อและอีเมล คลิก sign ต่อมาเราก็ต้องยืนยัน [อีเมล] ของเรา แล้วก็ต้องสร้างองค์กร (organization) แค่ตั้งชื่อและเลือกประเภทขององค์กร แล้วคลิก create ต่อไปผมต้องตั้งรหัสผ่านของฐานข้อมูล (database password) ผมจะใช้รหัสเดียวกับที่ใช้ตอนสร้างบัญชี และผมอยากเปลี่ยน [ชื่อ] ของโปรเจกต์ด้วย แล้วคลิก create เราต้องกรอกข้อมูลบางอย่างตรงนี้ ซึ่งเราได้มาจาก project settings ในส่วน Data API และตรงนั้นเราจะเห็น project URL ที่ต้องคัดลอก จากนั้นก็มี service role และมีอันนี้ด้วย เราก็คลิกแล้วคัดลอกไปวาง แค่กรอกเข้าไป แล้วคลิก save
