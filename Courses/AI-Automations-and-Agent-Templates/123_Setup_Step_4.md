## บทนำ
วิดีโอนี้เป็นส่วนสุดท้ายของ workflow การจองนัดหมาย โดยสอนวิธีตั้งค่าระบบ SMS reminder เพื่อเตือนลูกค้าก่อนเวลานัดหมาย เนื้อหาครอบคลุมการเชื่อมต่อ Google Sheet เดียวกัน การสร้างรายการทดสอบ การกรองนัดที่ใกล้ถึงเวลา และการเชื่อมต่อบริการส่ง SMS พร้อมตรวจสอบค่าใช้จ่ายต่อข้อความ

## คำแปลเต็ม
ส่วนสุดท้ายของ workflow นี้คือการตั้งค่า SMS reminders เพื่อให้ผู้คนมาร่วมการจองนัดหมายจริงๆ นั่นคือเหตุผลที่เรามี workflow นี้อยู่ด้านล่าง เรามี schedule ซึ่งโดยพื้นฐานแล้วจะตรวจทุกๆ ว่ามีการนัดหมายใหม่หรือไม่ และมีนัดหมายใดที่ถึงกำหนดภายใน 2 ชั่วโมงข้างหน้าไหม นี่คือสิ่งที่เรามีในตัวกรองเวลา (filter) ซึ่งผมจะโชว์ให้ดูเช่นกัน

แต่ก่อนอื่น เราต้องเชื่อมต่อ Google Sheet เดียวกันตรงนี้ก่อน เลือกชีตนี้ สิ่งเดียวที่มันทำคือดึงข้อมูลการจองทั้งหมดจากชีต ผมจะสร้างรายการที่สองขึ้นมาเพื่อโชว์ขั้นตอนการกรอง เรียกชื่อนี้ว่า Tim ให้ชื่อที่แตกต่างออกไปตรงนี้ เพื่อให้ทั้งสองรายการจองอีเวนต์เดียวกัน แต่ตอนนี้ผมบอกว่า ต้องมีรายการหนึ่งที่นัดถึงกำหนดภายใน 2 ชั่วโมงข้างหน้า ตัวอย่างเช่น อาจเป็นเวลา 11 นาฬิกาตามเวลาของผม ก็คือวันที่ 6 เวลา 11 นาฬิกา และสิ่งสำคัญคือ SMS reminder ยังไม่ถูกส่งไป เพราะผมไม่ต้องการส่งข้อความซ้ำสองครั้ง

ตอนนี้กลับไปที่ขั้นตอน execute เราจะได้ข้อมูลสองแถว ลองสลับไปดูในรูปแบบตาราง คุณจะเห็นว่าผมมีสองรายการ ตอนนี้ถึงขั้นตอนการกรอง ซึ่งจะให้เฉพาะการนัดหมาย หรือผู้ติดต่อที่จองนัดหมายและถึงกำหนดภายใน 2 ชั่วโมงข้างหน้าเท่านั้น จากนั้นมันจะส่ง SMS reminder และคุณจะเห็นว่ามันให้ผมแค่รายการเดียว คือรายการที่นัดถึงกำหนดภายใน 2 ชั่วโมงข้างหน้า ระบบนี้ทำงานได้

ต่อไปเป็นเครื่องมือที่ผมใช้ ชื่อว่า... คุณเห็นได้ตรงนี้ คุณจะพบลิงก์ด้านล่างวิดีโอนี้ แค่คลิกลิงก์นั้น คุณก็สมัครบัญชีฟรีได้ และคุณยังได้รับเครดิตบางส่วนติดมาด้วย ผมคิดว่าน่าจะประมาณ 50 เซนต์หรืออะไรประมาณนั้น จากนั้นสลับมาตรงนี้ สิ่งที่เราต้องการคือเชื่อมต่อบัญชีนี้ คลิก create a new แล้วรับ API key ของคุณ คุณแค่ไปคลิกที่เครื่องหมายบวก ตั้งชื่อให้มัน ชื่ออะไรก็ได้ ไม่สำคัญ คลิก save แล้วคลิกตรงนี้ วาง key ลงไป เท่านั้นเอง

ตอนนี้ระบบจะส่ง SMS ไปยังหมายเลขโทรศัพท์ของลูกค้าของเรา ดังนั้นต้องแน่ใจว่ามี [ฟังไม่ชัด] ฟิลด์ From ไม่สำคัญตรงนี้ ไม่ต้องใส่อะไร มันจะถูกเติมให้อัตโนมัติเพราะมาจาก 7.io จากนั้นนี่คือข้อความที่จะส่ง ซึ่งจะระบุว่า อีเวนต์การนัดหมายของคุณสำหรับการนวดผ่อนคลาย (express relief massage) จะเกิดขึ้นภายใน 2 ชั่วโมงข้างหน้า ภายในสองสามชั่วโมงข้างหน้า ในวันที่ 11 มิถุนายน เวลา 11 นาฬิกา เท่านั้นเอง

เมื่อผมคลิก execute ระบบจะส่งข้อความมาให้ผม และผมจะให้คุณตรวจสอบโทรศัพท์ของคุณ คุณได้รับข้อความไหม? และยังต้องสลับไปที่ Google Sheet ของคุณตรงนี้ด้วย เพราะสิ่งที่ต้องทำคือเขียนคอลัมน์สำหรับใช้จับคู่ คุณเลือก Contact ID ตรงนี้ Contact ID อยู่ตรงนี้ ไม่ว่าเราจะมีอะไรตรงนี้ เพิ่มตัวกรองเวลา Contact ID เราต้องการแค่ฟิลด์ SMS reminder ด้านล่าง ให้ผมพิมพ์ว่า yes ลงไป เพื่อบอกว่าส่ง reminder แล้ว

ตอนนี้ผมแค่ต้องเปลี่ยน Contact ID นี้ เพราะผู้ติดต่อแต่ละคนมีค่าแตกต่างกัน เพราะ reminder ถูกส่งไปแล้วของผม ไปที่ด้านล่างตรงนี้ ถ้าผมคลิกอีกครั้ง มันจะถูกเขียนไว้ตรงนี้ แล้วก็ระบุว่าส่ง SMS reminder แล้ว และแม้เมื่อระบบตรวจสอบอีกครั้งในครั้งหน้า มันก็จะไม่ส่งซ้ำ และคุณยังสามารถเห็นใน dashboard ของคุณได้ว่า SMS ถึงหรือไม่ ในกรณีของผม มันไม่ถึงเพราะโทรศัพท์ผมปิดอยู่ และเมื่อส่งถึง มันจะแสดงเป็นสีเขียว

จากนั้นไปที่สถิติ (statistics) แล้วคุณจะเห็นค่าใช้จ่ายของข้อความ หนึ่งข้อความมีค่าใช้จ่าย 7.5 เซนต์ และคุณอาจต้องเติมเครดิตเพิ่ม แต่คุณจะพบรายละเอียดค่าใช้จ่ายที่แน่นอนด้านล่างวิดีโอนี้ คุณสามารถเปลี่ยนไปใช้เครื่องมือ SMS อื่นได้ถ้าคุณพบว่าถูกกว่าในประเทศของคุณ แต่มันขึ้นอยู่กับประเทศของคุณจริงๆ แต่สำหรับคอร์สนี้ ระบบนี้ก็ใช้งานได้ดี

ดังนั้นผมคลิก และการตั้งค่าออโตเมชันทั้งหมดก็เสร็จสมบูรณ์
