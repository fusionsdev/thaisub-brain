แต่เดี๋ยวก่อน พวกคุณยังไม่ต้องใช้อะไรพวกนั้น ผมเตรียมกิจกรรมเล็กๆ แบบอินเทอร์แอกทีฟให้พวกคุณทำ คือให้คุณรวบรวมไฟล์ประเภทต่างๆ เข้ามา แล้วเราจะลองโยนมันลงไปใน Claude Code ผมทำไปแล้วในบทที่แล้ว ซึ่งผมจะโชว์ให้ดู ถ้าพวกคุณยังไม่ได้ดูบทที่แล้ว เราจัดระบบไฟล์ระบบหนึ่งของคุณไปแล้วนะ

สิ่งที่เราจะทำคือ เปิด Claude Code ขึ้นมา ผมอยากให้มันอ่านไฟล์ประเภทต่างๆ ได้ ผมแค่อยากโชว์ให้เห็นว่ามันเป็นไปได้แค่ไหน บทนี้จะเป็นบทเรียนเบสิกมากๆ ผมแค่พยายามให้พวกคุณเห็นศักยภาพของ Claude Code

Claude อ่านเอกสารได้หลายแบบ ไฟล์ MD ไฟล์ MD เรียกว่า markdown มันเป็นภาษาแบบนี้ หน้าตาแบบนี้ตรงนี้ มันเขียนด้วยเส้นเล็กๆ แบบนี้ เห็นไหมว่ามีหัวข้อแบบนี้ แล้วก็มีเครื่องหมายดอกจันตรงนี้ นี่คือวิธีที่ LLM อ่านไฟล์ มันเป็นวิธีที่มีประสิทธิภาพที่สุดสำหรับ Claude Code ในการอ่านไฟล์อะไรก็ตาม เวลาผมจะส่งไฟล์ให้มัน ผมจะแปลงเป็น markdown ก่อนแล้วค่อยส่ง มันเป็นวิธีที่อ่านง่ายที่สุด และผ่านมันไปได้ไวที่สุด ไม่ได้หมายความว่าคุณต้องทำแบบนั้นทุกครั้งนะ แต่ทำได้ แค่นั้นเอง นั่นคือไฟล์ MD

คุณให้ HTML กับมันได้ด้วย HTML ก็ประมาณนี้ นี่คือภาพหน้าจอของโค้ด จริงๆ มันไม่เชิงว่าอ่านได้ เหมือนโค้ดอีกประเภทหนึ่ง อีกอย่างที่เจ๋งมาก ขอผมเปิดหน้าต่าง Finder ใหม่หน่อยนะ มันอ่านภาพได้ชัดเจน ถ้าผมให้ภาพกับมัน เช่น สมมติว่าผมอยากแคปหน้าจอปัญหาสักอัน สมมติว่าเรามีไฟล์ระบบเปิดอยู่ แล้วผมอยากแคปหน้าจอ เป๊ะ! ผมแคปหน้าจอได้ ผมลากมันลงไปใน Claude Code แล้วถามมันว่าเห็นอะไร เจ๋งไหมล่ะ? แล้วมันจะวิเคราะห์ให้ มันดูไฟล์ PNG หรือภาพแบบนั้นของคุณได้

สิ่งที่มันทำไม่ได้คือ มันดูวิดีโอให้คุณไม่ได้ ในสถานะปัจจุบัน แต่สิ่งที่ทำได้คือ เราสามารถเชื่อมมันเข้ากับอะไรบางอย่างที่เรียกว่า Gemini ซึ่งถ้าคุณไม่รู้ว่า Gemini คืออะไร มันก็คือ LLM อีกตัวหนึ่ง แต่คุณโยนวิดีโอเต็มๆ ลงไปได้ แล้วมันจะดูวิดีโอให้จริงๆ เจ๋งมาก แต่ที่เจ๋งกว่านั้นคือ เราสามารถเชื่อมมันเข้ากับ Claude ได้ ซึ่งผมจะโชว์ให้ดูในบทหลังๆ โดยเฉพาะตอนที่เราวิเคราะห์โฆษณาและคอนเทนต์ คุณเชื่อมมันได้ แล้วคุณก็จะให้ดวงตามันได้จริงๆ ตัว Claude เองทำไม่ได้ แต่พอเชื่อมกับ Gemini แล้ว คุณให้ดวงตามันได้ แล้วคุณโยนวิดีโอทั้งเรื่องลงไปได้ มันจะดูให้คุณเอง

มีอะไรที่เรียกว่าไฟล์ข้อความ ถ้าพวกคุณไม่รู้ว่าไฟล์ข้อความคืออะไร สมมติว่าผมดึงเอกสาร prompt ของลูกค้าคนหนึ่งมา เห็นไหมว่ามันเป็นไฟล์เอกสาร มันเป็น documentation จริงๆ มันเปิดออกมาเป็นเอกสาร เห็นไหม? มันอยู่ในรูปแบบเอกสาร เหมือนกับ Google Drive doc อะไรแบบนั้น สมมติว่าผมอยากเปลี่ยนไฟล์นี้เป็นไฟล์ข้อความ สิ่งที่ผมทำได้คือ คลิกที่มัน แล้วคลิก rename จะเห็นว่ามันเขียนว่า Alex แล้วก็ .docx ถ้าผมอยากเปลี่ยนประเภทของเอกสาร ผมก็แค่ลบมันทิ้ง แล้วพิมพ์เป็นข้อความ กด Enter แล้วมันจะถามว่า "คุณแน่ใจหรือว่าต้องการเปลี่ยนนามสกุลจาก docx เป็น text file?" กดยืนยัน แล้วดูนะ มันจะเปิดขึ้นมา แล้วปัง! ไฟล์เปลี่ยนไปทั้งไฟล์ หน้าตามันเหมือนเอเลี่ยนมาเกิดเลย น่าจะเป็นเพราะดีไซน์ของมัน ใช่แล้ว เพราะไฟล์แบบนั้นไม่เหมาะที่จะเป็นไฟล์ข้อความ แต่คุณเข้าใจแล้ว นี่คือวิธีเปลี่ยนไฟล์โดยพื้นฐาน

ตอนนี้ผมแค่คลิกแล้วมันก็กลับไปเป็น Word doc ผมไม่รู้ว่าทำไมมันช้าจัง เอาเป็นว่า ผมขอไปดูหน่อยว่ามันทำอะไร แล้วกลับมาตรงนี้ นี่คือการให้มันดูภาพไฟล์เรา โดยสรุปคือ คุณให้มันวิเคราะห์ภาพได้ คุณลาก PDF เข้ามาได้ ลากสเปรดชีตเข้ามาได้ ถ้าคุณมีสเปรดชีต คุณก็ลากมันเข้าไปได้ เห็นไหม ผมเห็นภาพหน้าจอของ Freeform แอปไวต์บอร์ดของ Apple แต่จริงๆ มันคือ Figma แต่คุณบอกมันได้ถูกไหม? มันเห็นไฟล์ระบบที่มีโฟลเดอร์ย่อยส่วนตัว มันเห็นได้ นี่คือปัญหาเป๊ะ เวลาผมใช้มันแล้วเจอปัญหา ผมแคปหน้าจอปัญหา แล้วใส่ลงไปใน Claude Code แล้วบอกว่า "นี่คือสิ่งที่ผมเห็นฝั่งผม ช่วยแก้ให้หน่อยได้ไหม? ลองใหม่ได้ไหม?" ยิ่งคุณให้ภาพหน้าจอเยอะเท่าไหร่ และให้ข้อมูลเกี่ยวกับปัญหาที่เจอเยอะเท่าไหร่ มันก็ยิ่งตอบได้ถูกต้องง่ายขึ้นเท่านั้น ถ้าคุณส่งไปส่งมาแบบมั่วๆ คุณจะไม่ได้คำตอบที่ดี มันจะแย่สุดๆ แต่คุณทำง่ายๆ แค่ส่งภาพ 3 ภาพให้มัน แล้วให้มันวิเคราะห์ นี่คือข้อความ error นี่คือปัญหาที่ผมเจอ ช่วยแก้ให้หน่อย และทั้งหมดนี้เกิดขึ้นได้เพราะมันมองเห็น แค่นั้นเอง
