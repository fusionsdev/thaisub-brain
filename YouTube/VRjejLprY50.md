## วิดีโอนี้เกี่ยวกับอะไร

ตอนที่สามของซีรีส์สร้างธุรกิจด้วยเอเจนต์ตั้งแต่ศูนย์ ธุรกิจ **Keepsake Threads** ร้านพิมพ์ลายตามสั่งบน **Shopify** ที่ดึงลวดลายจากชุดเด็กเก่าสุดที่รักแล้วพิมพ์ลงเสื้อผ้าใหม่ ตอนนี้ลงมือทำ **ดีไซน์หน้าบ้าน** ด้วย **Claude Design** และสร้าง **วิดีโอสั้นแบบเลื่อนแล้วเล่น** ด้วยโมเดล **MiniMax H3** บนเครื่องตัวเองผ่าน **ComfyUI** ถ่ายทอดสดทุกขั้นตอนตั้งแต่สเกตช์จนรันบน local dev server ได้จริง

## ประเด็นหลัก

1. **ไอเดียธุรกิจ Keepsake Threads:** ลูกค้าอัปโหลดภาพชุดเบบี๋เก่า ระบบดึงลวดลายแล้วพิมพ์ลงเสื้อผ้าวัยปัจจุบัน เป็นสินค้าฝั่งผู้บริโภคเว็บเลยต้องสวยมาก
2. **ผังหน้า landing ที่สเกตช์:** navbar กับโลโก้มุมบน โซน hero เหนือรอยพับจอ แถบวิดีโอเลื่อนแล้วเล่นคั่นกลาง โซน how it works วิดีโอตัวที่สอง และท้ายเพจ
3. **คอนเซปต์หนังสั้นสองตัว:** เบบี๋ชุดวันซีลายดอกไม้ เส้นด้ายสีทองลอยขึ้นฟ้าเชื่อมไปหาเด็กหญิงคนเดียวกันวัย 5 ขวบและวัยรุ่นที่ใส่เสื้อลายเดียวกัน
4. **เวิร์กโฟลว์วิดีโอ local ฟรี:** เขียนบรีฟเป็น markdown ส่งให้เอเจนต์บน **DGX Spark** เริ่มจากคีย์เฟรมเปิดปิด อนุมัติภาพนิ่งก่อนแล้วค่อยรันดราฟต์ motion ความละเอียดต่ำก่อนเรนเดอร์จริง
5. **ความจริงของการเจนวิดีโอ:** **MiniMax H3** ต้องแก้หลายรอบเรื่องความต่อเนื่องกับรายละเอียด ส่วน **Grok Imagine** ภาพเพี้ยนจนใช้ไม่ได้ สุดท้ายใช้เวอร์ชันที่ดีสุดเป็น placeholder ไปก่อน
6. **โลโก้ด้วย ChatGPT images:** ลองหลายแบบจนได้เส้นด้ายสีชมพูอ่อนรูปหัวใจกับข้อความสี blush แล้วให้ **Hermes Agent** ขัดเกลาเป็นระบบโลโก้พร้อมใช้
7. **ดีไซน์เว็บด้วย Claude Design:** เสนอมาสามสไตล์ เลือก **warm cream scrapbook (1A)** พื้นสว่าง แล้วต่อยอดเป็นหกเพจครบทั้ง landing กับ design library กับ getting started กับ sign in กับ policies
8. **สโลแกนกับ em dash:** ปรับข้อความ hero หลายรอบจนได้ประโยคที่ชอบ พร้อมบ่นว่า **Claude** ใส่ em dash ทุกประโยคจนต้องลบออกเอง
9. **ผลลัพธ์สุดท้าย:** เอฟเฟกต์สกรอลล์เล่นวิดีโอเวิร์กบน local dev server เหลือแก้ความละเอียดต่ำกับไทมิงที่ด้ายออกช้าไปด้วยการอัปสเกล
10. **ตอนหน้า:** เชื่อมร้าน **Shopify** กับ **Printful** เลือกสินค้า เชื่อม **AI** ดึงลาย แล้วเทสต์สั่งจริงด้วยชุดเบบี๋ของลูกชาย ก่อนไปทำโฆษณา **Meta ads** แล้วเปิดตัว
