# สรุป: Stop Copying YouTube Channels. Use This AI Automation Instead!

- **ช่อง:** AIpreneur · **ความยาว:** ~14 นาที · **ลิงก์:** https://www.youtube.com/watch?v=i3EUBPnCmZA

## ประเด็นหลัก

- ถอดสูตรช่อง YouTube ที่ monetize แล้วด้วย Notebook LM ฟรี แล้วสร้างคอนเทนต์ต้นฉบับทับสูตร ไม่ใช่ก็อปทั้งช่อง
- ตัวอย่างช่อง History and Mythology (82000+ subs วิวล้านใน 30 วัน) และ Koo Psychology (109000 subs รายได้ประมาณ $3700/เดือน ใน ~9 เดือน)
- โหลด 10–15 คลิปท็อปเป็น sources ใน Notebook LM แล้วใช้ prompt ถอด audience หัวข้อ โทน hook และโครงสคริปต์
- ต่อด้วย prompt ตั้งชื่อช่อง 10 ชื่อ brainstorm ไอเดีย 10 คลิป และเขียน narration เต็มตามสูตร
- ใช้ visual planner ใน notebook เดิมให้ได้ character reference image prompt และ video prompt สอดคล้องสไตล์
- เส้นทางเร็ว: Notebook LM Studio สร้างวิดีโอ Explainer (เช่น Whiteboard) อัตโนมัติครบ voiceover และภาพ
- เส้นทาง batch: Google Flow + Nano Banana 2 + Agent สร้างภาพ/วิดีโอเป็นชุด แล้วใส่เสียงด้วย 11 Labs V3
- ประกอบใน CapCut: compound clip จาก voiceover จัดคลิปตามซีน transitions captions เพลงราว -20 dB แล้ว export
- เน้นว่าสูตรอย่างเดียวไม่พอ ต้องเลือก niche ให้ถูก และชวนดูคลิป niche/decode ถัดไป พร้อม CTA ให้พิมพ์ clone ในคอมเมนต์

## ความเห็นสรุป

คลิปนี้ขาย workflow ถอดสูตรช่องด้วย Notebook LM แล้วผลิตทั้งแบบคลิกเดียวและแบบ batch ควบคุมภาพเองครับ. จุดแข็งคือขั้นตอนชัดและแยก “ยืมสูตร” กับ “ก็อปอัตลักษณ์” ชัดเจน แต่ตัวเลขรายได้/วิวเป็นประมาณการจากผู้พูดและควรตรวจกับแหล่งจริงก่อนตัดสินใจลงทุนเวลาครับ.
