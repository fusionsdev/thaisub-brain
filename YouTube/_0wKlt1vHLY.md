## ประเด็นหลัก
- SEO agent ฟรีทั้งชุดจาก Jono แก้ 6 ปัญหาใหญ่ของการทำอันดับ: หา keyword สร้างเว็บ เขียนคอนเทนต์ optimize ทุกหน้า เผยแพร่เว็บ และ audit — ทั้งหมดด้วยคำสั่งสั้น ๆ ใน Claude Code
- อย่าถาม AI กว้าง ๆ ว่า "ช่วยหา keyword เจ๋ง ๆ" เพราะเป็นกลยุทธ์แพ้ — ต้องหา high-converting keywords อย่างเป็นระบบ 4 ขั้น: กางแหหา keyword เยอะ ๆ → กรองเหลือตัวชนะ → จับกลุ่มเป็น cluster → เรียงลำดับว่าสร้างหน้าไหนก่อน
- กรอง keyword ด้วย 4 เกณฑ์ใน Keyword Magic tool ของ Semrush (พิมพ์ SEO เฉย ๆ ได้ถึง 103,000 keyword): volume อย่างน้อย 50-100/เดือน, keyword difficulty ≤ 30, intent (informational → blog post, transactional → service/money page), และ cost per click สำหรับ keyword เชิงธุรกรรม
- ต่อ Semrush เข้า Claude Code ผ่าน connectors แล้วใช้ /keyword-research ได้ลิสต์ keyword เรียงตามลำดับความสำคัญการสร้างหน้า พร้อม cluster ต่อหน้า
- สร้างเว็บด้วย /build-website (มี template ฟรีให้) หรือต่อเข้า WordPress ผ่าน plugin Nova Mira — Shopify, Webflow, Duda น่าจะเชื่อมได้แต่ automate ได้จำกัด
- อุปมาน้ำขึ้น-เรือ: blog post คือกระแสน้ำ money page คือเรือ ยิ่ง blog post คุณภาพดีมาก เว็บยิ่งมี authority และ money page ยิ่งลอยขึ้นในอันดับ
- /blog-post ทำงาน 5 ขั้น: เลือก keyword ถัดไปจากลิสต์ → วิจัย 30 แหล่งทั้งบทความ ข่าว พอดแคสต์ → สแกน 3 อันดับแรกของ Google เพื่อสกัดสูตรชนะ → เขียนบทความ → เติมเสียงเฉพาะตัว
- Content is king: SEO เป็นกล่องดำที่มีตัวชี้วัด 200+ ตัว แต่ถ้าคอนเทนต์แย่ก็ไม่มีทางเห็นผล — Google อยากให้คนอยู่หน้าเว็บนาน ๆ เพื่อแสดงโฆษณา วิธีที่ง่ายที่สุดคือเขียนให้ตลกและน่าติดตาม
- /service-page สร้างหน้าบริการพร้อมจุดโน้มน้าวให้คนจองหรือโทร และต้องทำ city service matrix ครบทุกบริการ x ทุกเมือง (plumber Toronto/Mississauga/Brampton/Hamilton แล้วต่อด้วยบริการถัดไป)
- SEO optimization ครอบคลุม 4 ด้าน: on-page, technical (ความเร็ว/การเข้าถึง), AI overviews และ large language models (ChatGPT, Claude, Perplexity) — มักต้องรันหลายครั้งคะแนนถึงจะขึ้นใกล้ 100
- /publish เอาเว็บขึ้น GitHub + Vercel ฟรี (หรือ WordPress ผ่าน Nova Mira) แล้วขั้นสุดท้ายเด็ดขาด: สร้างบัญชี Google Cloud Console และส่ง site map ไม่งั้น Google มองไม่เห็นเว็บและจะไม่มี lead เลย
- คำสั่ง audit ตรวจทุกหน้าแบบ before/after score เช็คถึง doorway pages (หน้าซ้ำ) ที่ Google ไม่ชอบ และให้คำแนะนำ Google Business Profile ท้องถิ่น
