## บทนำ
วิดีโอนี้สอนตั้งค่าระบบอัตโนมัติตัวแรก ที่แปลงวิดีโอ YouTube เป็นโพสต์โซเชียลมีเดียหลากหลายรูปแบบ โดยเริ่มจากนำเข้า blueprint ใน n8n (create scenario → import blueprint) แล้วต่อ webhook เข้ากับ Apps Script ของ Google Sheets จากนั้นตั้งค่าโมดูล Google Sheets และเชื่อมต่อ OpenAI เพื่อให้ AI วิเคราะห์ทรานสคริปต์ของวิดีโอ ดึงข้อเท็จจริงหลัก แล้วสร้างโพสต์และรูปภาพบันทึกลง Google Sheets

## คำแปลเต็ม

ตอนนี้เราจะตั้งค่าระบบอัตโนมัติตัวแรก เพื่อแปลงวิดีโอ YouTube ของเราเป็นโพสต์โซเชียลมีเดียรูปแบบต่าง ๆ และคุณจะพบลิงก์ไปยังระบบอัตโนมัตินี้อยู่ใต้วิดีโอนี้ เริ่มจากสร้าง scenario (สถานการณ์) แล้วไปที่ import blueprint (นำเข้าแปลน) เลือกไฟล์ที่ดาวน์โหลดมา แล้วคลิก save

ขั้นตอนการตั้งค่าง่ายมาก สิ่งแรกที่ต้องทำคือเพิ่ม webhook ใหม่ คลิก แล้วก็คัดลอกที่อยู่ของ webhook นี้ จากนั้นกลับไปที่โค้ด Apps Script ของเราอีกครั้ง ถ้าหาไม่เจอ ไปที่ Apps Script แล้วไปที่ "insert webhook" ตรงนั้นเราวาง webhook นี้ลงไป แล้วคลิก save

ตอนนี้ชีตเชื่อมต่อกับระบบนี้แล้ว และเราสามารถรันมันได้แล้ว อย่างน้อยก็เพื่อให้มันเปิดใช้งาน webhook โดยการคลิก generate แล้วคุณจะเห็นว่ามันจะเจอโครงสร้างข้อมูลและแสดงผลว่า "successfully termed" (สำเร็จ) ตอนนี้มันตั้งค่าเสร็จแล้ว

สิ่งต่อไปที่ต้องทำคือตั้งค่าโมดูล Google Sheets ตรงนี้ ในการตั้งค่าพวกนี้ เราต้องการแค่ Google Sheets ซึ่งก็คือส่วนนี้จาก Google copy จากนั้นเราก็แค่แทนที่ sheet ID ด้วยชีตที่เราเพิ่งคัดลอก

ส่วนแรกของระบบอัตโนมัติจะดึงเทมเพลตสำหรับรูปแบบโพสต์ต่าง ๆ ซึ่งมีสามรูปแบบที่แตกต่างกันอย่างที่เห็นตรงนี้ หนึ่งรูปแบบสำหรับแต่ละสาขา (branch) และมันจะได้เทมเพลตมา แล้วใช้เทมเพลตนั้นวิเคราะห์ทรานสคริปต์และพยายามดึงข้อเท็จจริงสำคัญจากวิดีโอ

คุณไม่ต้องปรับแต่งอะไรเลย ยกเว้นต้องเพิ่มการเชื่อมต่อ OpenAI ถ้ายังไม่มี คุณต้องคลิก add แล้วเพิ่ม API key จาก OpenAI และคุณจะพบคำแนะนำตรงนี้ด้วย: "get API key from OpenAI" แค่ทำตามนั้น

และเมื่อมันได้สรุปหรือคีย์แล้ว ขั้นแรกมันจะบันทึกลงใน Google Sheets ของเรา ตรงนี้จะถูกบันทึกภายใต้ "post topic" จากนั้นมันจะสร้างโพสต์ แล้วบันทึกลง Google Sheets อีกครั้ง จากนั้นสร้างรูปภาพและบันทึกลง Google Sheets ด้วย นี่คือวิธีการทำงาน

สิ่งที่ต้องเปลี่ยนตรงนี้คือแทนที่ Google Sheet ID ด้วยชีตของเรา ถ้ายังไม่มีบัญชี Google คุณต้องเพิ่มบัญชีตรงนี้ คลิกแล้วทำตามขั้นตอน แค่ให้แน่ใจว่าเป็นบัญชี Google เดียวกันกับที่ใช้กับ Google Sheets นี้ แล้วลงชื่อเข้าใช้ จากนั้นคุณก็แค่เลือก ส่วนที่เหลือทั้งหมดเชื่อมต่อกันอยู่แล้ว สิ่งเดียวที่ต้องทำคือแทนที่ด้วยชีตของคุณ แล้วปล่อยให้มันโหลด

ตรงนี้เราต้องใส่ข้อมูล สิ่งที่เราต้องการบันทึกคือ อย่างแรก video ของ YouTube เลือกอันนี้ ส่วน post style (รูปแบบโพสต์) ซึ่งโดยพื้นฐานในอันนี้คือ key facts คุณต้องพิมพ์มันตรงนี้ และตอนนี้ "post topic" คือผลลัพธ์จากอันนี้ เอาล่ะ

ทีนี้ทำแบบเดียวกันกับชีตนี้ ตรงนี้ source video คือวิดีโอ ส่วน post style คือ key ส่วน topic คือผลลัพธ์จากอันนี้ และอีกครั้งสำหรับอันนี้ ให้วาง Google Sheet ID ลงไป source video, post style: summary

ดังนั้นมันจะถูกบันทึกลงใน Google Sheets ของเรา เพื่อให้เรารู้ว่าโพสต์นี้สร้างจากรูปแบบใด โดย post topic เป็นผลลัพธ์จากตัวสร้างข้อความโพสต์ของเรา เราไม่ต้องเปลี่ยนอะไร

ต่อไปไปที่อันนี้ แทนที่ด้วย Google Sheets ของเรา สิ่งเดียวที่ต้องบันทึกคือโพสต์ที่สร้างขึ้น ซึ่งเป็นผลลัพธ์จากอันนี้ ทำแบบเดียวกันในโมดูลนี้ ก็คือ generated post text เดียวกัน และตรงนี้ก็ generated post text เช่นกัน

ต่อไปสำหรับโมดูลที่บันทึกรูปภาพ ซึ่งก็คือการบันทึก image URL รูปภาพนี้อยู่ภายใต้ data ลองทำแบบเดียวกันสำหรับอันนี้ และตรงนี้ก็ image link, data URL ด้วย เอาล่ะ และอันสุดท้าย จากนั้นเราก็ทดสอบระบบอัตโนมัติเป็นครั้งแรกได้แล้ว

ตรงนี้ image link URL บันทึกแล้ว ตอนนี้ฉันอยากเปลี่ยนตรงนี้เป็น "run immediately" (รันทันที) เปิดใช้งาน scenario มันควรจะรันทันทีและเมื่อมีข้อมูลเข้ามา ตอนนี้ฉันคิดว่าตั้งค่าเสร็จแล้ว กลับไปได้ มันกำลังสลับเป็น on และตอนนี้ฉันก็กระตุ้นมันได้แล้ว

ตอนนี้กลับไปที่วิดีโอ ยกเลิกการเลือกอันนี้ และตอนนี้เมื่อฉันคลิก มันก็จะกระตุ้นกระบวนการ และเราจะรันมันหนึ่งครั้งเพื่อดูว่ามันรันโดยไม่มี error และตั้งค่าถูกต้องหรือไม่ จากนั้นฉันจะกรอวิดีโอนี้ไปข้างหน้า

มันทำงานแล้ว และคุณเห็นตรงนี้ว่ามีโพสต์สามโพสต์จากวิดีโอนี้ด้วยรูปแบบโพสต์ที่แตกต่างกัน และขั้นตอนต่อไปคือการตั้งค่าระบบอัตโนมัติที่ให้ฉันเผยแพร่โพสต์เหล่านี้ไปยังแพลตฟอร์มเฉพาะจาก Google Sheets นี้ ฉันแค่คลิกตรงนี้ แล้วมันก็ควรจะถูกเผยแพร่ไปยังแพลตฟอร์มนั้น ในการทำแบบนี้เราต้องตั้งค่าอีกตัวหนึ่ง ซึ่งเราจะทำในวิดีโอถัดไป
