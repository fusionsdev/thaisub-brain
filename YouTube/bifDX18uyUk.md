# Thai Summary — Hermes Desktop Kanban, Custom Widgets, SSH Backend, Custom Layouts

## จุดสำคัญ

- **Hermes desktop app ได้รับการปรับปรุงอย่างมาก** จากทีม Nous Research ตั้งแต่ช่วงเปิดตัวซึ่งเคยมีปัญหาเรื่องความล่าช้าและประสิทธิภาพ ปัจจุบันการใช้งานลื่นไหลขึ้นมาก

- **เชื่อมต่อผ่าน SSH ภายใน desktop app ได้แล้ว** ฟีเจอร์ใหม่ในหัวข้อ Gateway ช่วยให้ผู้ใช้เชื่อมต่อกับเครื่องปลายทาง (เช่น DGX Spark) ผ่าน SSH ได้โดยตรง ไม่ต้องพึ่งพาส่วนขยาย VS Code อีกต่อไป ระบบจัดการ tunneling และทุกอย่างให้อัตโนมัติ

- **Multi-session และ multi-tab** ช่วยให้ผู้ใช้ปรับแต่ง workspace ได้อย่างยืดหยุ่น สามารถลากและวาง session ต่าง ๆ เป็น pane หรือ tab แยกกันได้ และยังดึง session เก่ามาเป็น context ใน session ใหม่ได้ด้วยการลากวาง

- **Hermes desktop plug-in SDK** เปิดโอกาสให้ผู้ใช้สร้าง custom widget ภายใน desktop app เอง เช่น วิดเจตแสดง process ที่ใช้ memory สูงสุด หรือวิดเจตแสดงคะแนนเบสบอล MLB แบบเรียลไทม์

- **วิดเจตปรับเลย์เอาต์ได้** หลังสร้างแล้วผู้ใช้สามารถสั่ง Hermes ให้ปรับให้ย้ายได้ แล้วจัดเลย์เอาต์ได้ตามต้องการ

- **Kanban board เป็น plug-in ตัวแรกอย่างเป็นทางการ** ตอบสนองความต้องการของผู้ใช้ที่อยากให้มี Kanban ที่เคยอยู่เฉพาะใน web dashboard มาไว้ใน desktop app ด้วย

- **Kanban ดึงข้อมูลจาก dashboard เดิม** ทำให้บอร์ดเก่าและงานเดิมยังอยู่ครบ ใช้งานร่วมกันได้ทันที

- **Auto Decomposer** ใน Kanban จะแตกงานใหญ่เป็นงานย่อยและมอบหมายให้ profile ที่เหมาะสมโดยอัตโนมัติ เช่น Wiki Researcher, Wiki Writer, Wiki Verifier

- **Estimate Effort** เป็นปุ่มใหม่ที่เรียก LLM เพื่อประมาณการจำนวน token ที่งานแต่ละ task จะใช้

- **Orchestration Settings** แสดงความถนัดของแต่ละ profile ซึ่งเป็นข้อมูลที่ระบบใช้ในการตัดสินใจมอบหมายงาน

- **ผลลัพธ์ตัวอย่าง** การสั่งวิจัยและสร้าง wiki เกี่ยวกับ Matt PCO skills ให้ผลลัพธ์เป็น markdown wiki 9 หน้า ผ่าน workflow อัตโนมัติตั้งแต่ค้นคว้า ร่าง จนถึงตรวจทาน

## คำตัดสิน

คลิปนี้โชว์ให้เห็นว่า Hermes desktop app พัฒนาไปไกลมากจากช่วงเปิดตัว ฟีเจอร์ SSH backend, multi-session/tab UI, plug-in SDK สำหรับ custom widget และ Kanban board ล้วนตอบโจทย์ผู้ใช้ที่ต้องการปรับแต่งและใช้งาน Hermes agent ในเครื่องเดียวโดยไม่ต้องพึ่งเครื่องมืออื่น เหมาะอย่างยิ่งสำหรับผู้ที่ใช้งาน Hermes agent อย่างจริงจัง
