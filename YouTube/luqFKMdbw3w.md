## ประเด็นหลัก

- XAI เปิด Grokbot OpenAI เปิด ChatGPT dots และ Meta เปิด Muse — ทั้งสามเป็น AI agent แบบ always-on บนคลาวด์และมีค่าใช้จ่าย
- OpenBot เป็นแอปเดสก์ท็อปฟรีที่รันบนเครื่องคุณเอง เชื่อมแพลนที่มีอยู่แล้ว เช่น ChatGPT ผ่าน Codex Claude ผ่าน Claude Code Gemini หรือ Grok
- ยังเป็น development preview: agent มีสิทธิ์เต็ม approval policy = never จึงควรให้เฉพาะงานที่ไว้ใจและเก็บ backup
- สร้าง agent ง่าย เลือก avatar ชื่อ คำอธิบายงาน และโมเดล — ค่าเริ่มต้น OpenCode กับ Flint 40B free รวมโมเดลฟรีอื่น ๆ โดยไม่ต้องมีบัญชี
- แต่ละ agent มี session โฟลเดอร์ แชท และ workspace ของตัวเอง ย้าย provider ได้โดยคงแชทเดิม มี backup model เมื่อแพลนเต็มหรือ provider ล่ม
- รองรับ OpenAI-compatible endpoint Ollama LM Studio และ custom agent ผ่าน ACP (เช่น Goose QuenCode GitHub Copilot)
- มี context monitoring / compact คิวงาน channels ระหว่าง agent เบราว์เซอร์ในตัว และ computer use บน Mac Windows Linux
- Local-first หมายถึง workspace แชท ไฟล์ อยู่บนเครื่อง แต่พรอมต์ยังไป provider — มี hosted Linux server ในยุโรปถ้าไม่อยากเปิดเครื่องค้าง
- ติดตั้งได้บน macOS 13+ Windows 10 x64 Linux AppImage มี Docker Nix flake และโหมด headless บน Ubuntu server
- Electron + SolidJS + typed bridge เบราว์เซอร์ใน sandbox บัญชีบน Cloudflare Workers ส่วนแชท/ไฟล์/คำสั่งไม่อยู่บน Cloudflare
- ใบอนุญาต PolyForm non-commercial (ไม่ใช่ open source ทางการ) เวอร์ชันเก่าถึง 0.1.11 ยังเป็น Apache 2 — ใช้เชิงพาณิชย์ต้องซื้อ license

## ความเห็นสรุป

OpenBot เหมาะกับคนที่จ่ายแพลน AI หลายตัวอยู่แล้ว และอยากให้ agent ทำงานร่วมกันบนไฟล์ในเครื่องตัวเอง ครับ.
ถ้าไม่อยากเปิดคอมพิวเตอร์ค้างและโอเคกับโมเดลคลาวด์ของบริษัทเดียว Grokbot dots หรือ Muse ใช้ง่ายกว่า ครับ.
สำคัญคือยังเป็น preview และ agent มีสิทธิ์เต็ม ต้องเก็บ backup และอย่าชี้ไป production ครับ.
