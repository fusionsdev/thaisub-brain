## บทนำ

บทเรียนนี้พูดถึง Sound Hooks ใน Claude Code ซึ่งเป็นฟีเจอร์ที่เล่นเสียงแจ้งเตือนเมื่อ Claude ทำงานเสร็จ หรือต้องการขอสิทธิ์อนุญาตจากผู้ใช้ ช่วยให้ไม่พลาดงานที่ค้างรออยู่ในเทอร์มินัลอื่น ผู้สอนสาธิตวิธีให้ Claude ตั้งค่า hook ง่าย ๆ และเลือกเสียงแจ้งเตือนได้ตามใจชอบ

## คำแปลเต็ม

ว่าไงทุกคน ยินดีต้อนรับสู่อีกบทเรียนหนึ่งครับ วันนี้ผมจะพูดถึง Sound Hooks — sound hooks ก็คือเสียงแจ้งเตือนที่จะดังขึ้นเมื่อ Claude ทำงานเสร็จ ซึ่งเจ๋งมากเลย มันช่วยประหยัดเวลาผมไปได้เยอะ เพราะเวลาที่ Claude ต้องการสิทธิ์เพื่อทำงานต่อ มันจะแจ้งเตือนผมผ่านเสียง ถ้าผมกำลังโฟกัสกับโปรเจกต์หนัก ๆ และเปิดเทอร์มินัลหลายตัวพร้อมกัน จนไม่สังเกตว่ามันกำลังรอสิทธิ์ในอีกเทอร์มินัลหนึ่ง บางที 20 นาทีผ่านไปก่อนที่ผมจะอนุญาต ซึ่งถือว่าไม่มีประสิทธิภาพเลย เพราะฉะนั้นฟีเจอร์นี้จะส่งเสียงให้คุณรู้ แล้วคุณค่อยไปกดอนุญาตต่อ

ผมให้ไฟล์เทอร์มินัลแบบซับซ้อนจริง ๆ ไปแล้ว แต่ผมจะโชว์วิธีพื้นฐานที่สุดให้ดู คุณแค่พิมพ์บอกมันว่า — ผมอยากสร้าง hook สำหรับตอนที่ Claude Code เทอร์มินัลของผมต้องการสิทธิ์ หรือทำงานเสร็จ แล้วให้มันส่งเสียง เช่น เสียงกระจก หรือเสียงแจ้งเตือนอะไรสักอย่าง ช่วยตั้งค่าให้หน่อยได้ไหม — แค่ง่าย ๆ แบบนี้แหละครับ และ sound hook จะแจ้งเตือนคุณเมื่อทำงานเสร็จ คุณจะเริ่มได้ยินเสียงของผมเอง เพราะมันจะดังขึ้นมาเรื่อย ๆ

จริง ๆ แล้วคุณตั้งค่านี้กับอะไรก็ได้นะครับ ผมโพสต์วิดีโอเมื่อวันก่อนเกี่ยวกับมีมโง่ ๆ ตอนที่ทำงานในเทอร์มินัลเสร็จ และมันก็คือสิ่งนี้แหละ ถ้าคุณยังไม่ได้ดูบทเรียนเรื่อง hooks คุณจะเข้าใจสิ่งที่ผมพูดถึงทันที — มันก็คือ hook ซึ่ง hook ก็เหมือนตัวกระตุ้น (trigger) คือมันบอกว่าเมื่อไหร่ที่เหตุการณ์หนึ่งเกิดขึ้น เช่น เมื่อคุณทำงานในเทอร์มินัลเสร็จ หรือต้องการเสียงแจ้งเตือน มันก็จะตอบสนองให้คุณทันที

จริง ๆ แล้วผมตั้งค่าไว้แล้ว มันอาจจะช่วยหรือไม่ช่วยก็ได้ แต่เราจะปล่อยให้มันทำงานสักครู่ครับ โอเค มันบอกว่าเราตั้งค่าไว้แล้ว มันมี notification hook อยู่แล้ว จะให้หยุดไหม blah blah — และเพื่อให้คุณเห็นว่ามันทำงานยังไง ผมใช้เสียง chime อยู่ ช่วยเล่นเสียงกระจกหน่อยสิครับ ผมจะโชว์ให้คุณดูว่ามันทำงานยังไง คุณอาจจะได้ยินหรือไม่ได้ยินก็ได้ แต่ลองดูกัน เสียงเล็ก ๆ แบบนี้แหละ คุณอาจจะไม่ได้ยินเพราะตอนนี้กำลังอัดอยู่ แล้วเสียงมันเล่นออกลำโพงจริง ๆ แต่โดยรวมคือมันส่งเสียงออกมา

โดยสรุปคือ พอถึงตอนจบของงาน มันจะส่งเสียงให้คุณ อย่างที่บอก แค่คุณพรอมต์ให้มันตั้งค่านี้ แล้วคุณก็เลือกเสียงที่อยากได้ได้เลย ผมใช้เสียงกระจก เพราะฟังง่ายที่สุด แต่คุณจะใส่เสียงอะไรก็ได้ตามใจ คุณจะใส่เสียง Firework ของ Katy Perry ก็ได้ แล้วมันจะเล่นทุกครั้งที่งานในเทอร์มินัลเสร็จ — ผมแนะนำให้ทำแบบนั้นไหม? ไม่ แต่คุณทำได้ไหม? ได้ แล้วก็แค่เลือกเสียงหนึ่งมา มันก็จะตั้งค่า hook ทั้งหมดให้คุณเอง ทุกครั้งที่เทอร์มินัลต้องการสิทธิ์ หรือทำงานเสร็จ มันก็จะส่งเสียงแจ้งเตือนคุณ ซึ่งเจ๋งมาก และเป็นหนึ่งในฟีเจอร์โปรดของผมที่เพิ่งปล่อยออกมาในสัปดาห์หรือสองสัปดาห์ที่ผ่านมานี้เองครับ นั่นแหละทุกคน
