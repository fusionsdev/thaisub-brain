## ประเด็นหลัก

- YC Demo Day: ทีมส่วนใหญ่สร้าง domain-specific harness — คลิปสอนสร้าง harness จริงด้วย Pi + Prime
- กรอบ ABC (Actions / models-Brain / Context) อธิบาย agent + harness ที่เดิน interaction ภายใต้ขอบเขตมนุษย์
- 3 ลูป: model–tool loop · application loop · improvement loop
- สร้าง academy tutor harness สองรูปแบบ: extension ใน Pi agent และ standalone ผ่าน SDK
- จำความก้าวหน้าผู้เรียน รัน scheduled reviews เก็บ cards/attempts
- self-improvement ด้วย feedback ปรับ instruction แล้วทดสอบว่าการเปลี่ยนช่วยจริง (Prime refinement)
- เดินทั้งเส้นจาก design → โค้ดที่รันได้ เพื่อนำไปใช้กับ agent โดเมนอื่น

## ความเห็นสรุป

เหมาะกับคนที่อยากสร้าง tutor/agent ที่มี memory + schedule + ปรับตัวเองได้ ไม่ใช่แค่ chat wrapper
