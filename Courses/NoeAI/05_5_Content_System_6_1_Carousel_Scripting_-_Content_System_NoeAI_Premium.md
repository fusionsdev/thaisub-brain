## บทนำ

วิดีโอนี้สอนการใช้ Carousel Scripter Skill ซึ่งเป็นขั้นตอนในสายงาน (pipeline) การทำคาราเซลของคอร์สนี้ — เริ่มจากวิเคราะห์คาราเซลคู่แข่ง หัวข้อที่ควรทำ แล้วมาถึงขั้นตอนเขียนสไลด์ทุกสไลด์จริงๆ ทั้งเนื้อหา ภาพ และ CTA โดยตัว Skill จะดึงข้อมูลจาก Airtable และ Supabase มาช่วยตัดสินใจ เรียกดูหัวข้อที่รอเขียน แล้วก็เขียนคอปปี้งานให้เสร็จทั้งชุด

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่ Carousel Scripter Skill ในวิดีโอนี้ ผมจะโชว์ Skill ที่เอาไว้เขียนสคริปต์คาราเซลให้คุณ ซึ่งมันต่อเข้ากับสายงานของ Skill ตัวก่อนหน้าโดยตรง — เริ่มจาก Carousel Analysis ที่จะวิเคราะห์ Skill ทั้งหมดของคุณ จากนั้น Carousel Ideator ก็จะคิดหัวข้อคาราเซลให้ 7 ถึง 10 หัวข้อ แล้วส่งต่อไปในสายงาน และตอนนี้เรามาถึงขั้น Carousel ที่จะเขียนคอปปี้งานจริงๆ ทีละสไลด์ ดังนั้นมันสำคัญมากที่คุณควรไปดูวิดีโอของ Skill ตัวอื่นๆ ก่อน เพราะทุกตัวทำงานต่อเนื่องกัน

สิ่งที่ Skill นี้จะทำก็คือ มันจะเขียนคอปปี้แบบทีละสไลด์ให้คุณทั้งชุด ตั้งแต่เนื้อหาหลัก ภาพ Visual, CTA ทริกเกอร์ พูดง่ายๆ คือทุกอย่างเลย และวิธีทำงานของมันคือ มันจะดึงข้อมูลที่อยู่ใน pipeline ของคุณ ผมเองมีอันหนึ่งที่มาร์กว่า Scripted ไว้แล้ว คือตัวที่เราแกะกันมาเมื่อกี้ ตรงนี้แหละ เราจะดึงมันขึ้นมาดูกัน ผมก็อัปเดตสคริปต์ของ Ideator ให้คุณแล้วเหมือนกัน ทุกอย่างอัปเดตล่าสุดหมดแล้ว

เราจะเห็นว่าใน pipeline ของเราตรงนี้ เรายังขาดวันที่อยู่ และมันขึ้นว่า Short ด้วยเหตุผลอะไรสักอย่าง แปลกดี แต่เรามีคาราเซลแล้ว มีหัวข้อและมุมเนื้อหาแล้ว มีตัวบทแล้ว แต่ถึงเวลาต้องเขียนสคริปต์จริงๆ เสียที สิ่งที่เราจะทำคือเข้าไปดึงตัวนี้ขึ้นมา แล้วไปที่ Carousel Scripter

สิ่งแรกที่มันจะทำคือ มันจะไปที่ตาราง Airtable ของผม แล้วดูว่าเรากำลังทำงานกับตัวไหนอยู่ ไม่ว่าคุณจะส่งเนื้อหาผ่านอะไร ก็แค่เชื่อมมันเข้ามา แล้วมันจะดึงตัวที่พร้อมจะเขียนสคริปต์ จากนั้นมันจะโหลด Carousel Analysis ล่าสุดที่เราทำไว้ในบท Carousel ก่อนหน้า แล้วมันจะ query ไปที่ Supabase เพื่อหาข้อมูล — อย่างน้อยก็ตามวิธีที่ผมตั้งค่าไว้ เพราะผมมีคาราเซลไม่เยอะ ผมเลยให้ query เอาคู่แข่ง 5 อันดับแรกพร้อมข้อมูลสไลด์เต็มๆ เพื่อที่เราจะได้เข้าใจทุกอย่างเกี่ยวกับพวกเขา จากนั้นมันจะอ่าน caption และ brand voice ของผม แล้วก็เสนอหัวข้อพาดหัว 3 แบบให้ผมเลือก แล้วมันจะเขียนสคริปต์แบบเต็มทุกสไลด์ พร้อมคำอธิบายภาพ Visual ไปในตัว คุณจะได้เห็นว่ามันทำงานยังไง

พูดง่ายๆ คือ มันดึงข้อมูลอ้างอิงทั้งหมดมา โหลดเรคคอร์ดเสร็จ ให้ผมเลือกพาดหัว — หนึ่ง Skill หกสไลด์: หน้าปก บวกเนื้อหา 4 สไลด์ บวก CTA นี่แหละเงินเลย ตรงตามที่เราจ่ายไปพอดี เหมือนที่ทำกันในวิดีโอก่อนๆ นี่คือพาดหัว 3 แบบ "Four Claude Skills ที่สร้างคาราเซลให้คุณ" "ผมทำให้กระบวนการคาราเซลทั้งหมดเป็นอัตโนมัติใน Claude Code" อันนี้น่าสนใจ อันนี้ก็ดี แต่เราจะโชว์แบบ 4 Skill ผมว่าแบบนั้นน่าจะเวิร์กที่สุด เอาอันนี้แหละ

เราก็แค่เลือกอันหนึ่ง แล้วปล่อยให้มันทำงาน ต่อไปมันจะเขียนคอปปี้สไลด์ทั้งหมดให้เรา "Four Claude Skills that build carousels for you" คาราเซลนี้สร้างด้วย... พร้อมภาพสกรีนช็อตเทอร์มินัลที่กำลังรัน Carousel Creator แล้วมันก็ให้คำอธิบายภาพว่า Visual ควรเป็นอะไรบนสไลด์ Canva จริงๆ หรือบนคาราเซล รวมถึงแนวดีไซน์ที่เราอยากได้ พอเรามาถึงตรงนี้มันบอกว่า "ตัวละคร pixel art ที่มุมล่างซ้าย" จริงๆ ผมมี pixel art เยอะมาก จะโชว์ให้ดูในวิดีโอหน้า

อันนี้ดูดีสำหรับสไลด์คาราเซล "คาราเซลนี้สร้างด้วย Claude" น่าสนใจดี เหมือนมี social proof ตั้งแต่แรกเลย "วิเคราะห์ทุกสไลด์ว่าอันไหนเวิร์กอันไหนไม่เวิร์ก" คอปปี้น่าสนใจ โอเค สำหรับสไลด์ที่สอง ผมสังเกตว่ามันมีแต่... ไม่มีพาดหัวและพาดหัวย่อย ทุกสไลด์ควรมีโครงสร้างเดียวกัน คือมีพาดหัวย่อยพร้อม Visual ดูซิว่ามันจะแก้ให้เรามั้ย เพราะถ้ามันแก้นี่จะเยี่ยมเลย แล้วผมจะอัปเดต Skill ด้วย ดูผลก่อนดีกว่า แต่ผมอยากย้ำนะ เพราะพอคุณปรับ Skill ให้เข้ากับคุณได้แล้ว ซึ่งผมทำไว้ประมาณ 90% แล้ว คุณสามารถสปอนต์เอเจนต์ 5 ตัว 10 ตัวแบบขนานเพื่อสร้างคาราเซล 10 อันพร้อมกันได้เลย

มาดูกัน พาดหัวตอนนี้ "คาราเซลนี้วิเคราะห์สไลด์คู่แข่งทุกสไลด์ทีละสไลด์" ก็ไม่เลว "เลือกหัวข้อท็อป 10 จากข้อมูลคู่แข่ง บวกกับตัวที่ชนะของคุณ" "เขียนทุกสไลด์ ทั้งพาดหัว คอปปี้ Visual เปิด แก้ไข ส่งออกเป็น PNG" น่าสนใจ นี่คือโครงสร้างที่เราต้องการ งั้นอัปเดต Skill เลย

ในแง่ของคอปปี้ ผมอยากได้อะไรที่ชูประโยชน์ (benefit-driven) มากกว่า เช่น แทนที่จะบอกว่า "เปิด Canva แก้ไขเทมเพลต ส่งออกสไลด์เป็น PNG" ก็บอกว่า "มันเอาสคริปต์ที่ชนะมาสร้างคาราเซลทั้งอันและออกแบบให้คุณเสร็จ" ใช่อันนั้นแหละที่ผมอยากได้ หรืออีกตัวอย่าง "Carousel Ideator ดูคาราเซลของคุณ แล้วขโมยคาราเซลที่ชนะของคู่แข่งมาเขียนคาราเซลไวรัลให้คุณ" ไม่เชิงแบบนั้น แต่คุณคงเห็นภาพว่าผมหมายถึงอะไร — ชูประโยชน์ โอเค คุณจะไปทางปัญหา ทาง social proof ก็ได้ มีอะไรให้ทดลองเยอะมาก และผมขอเชิญชวนให้ทุกคนลองกลยุทธ์ต่างๆ กับคาราเซลของคุณดู

หน้าที่ของผมตรงนี้คือโชว์ให้เห็นว่าคุณเร่งกระบวนการนี้ยังไงได้บ้าง เรากำลังใช้เวลากับตรงนี้อยู่ แต่พอคุณมี Skill แล้ว คุณทำอะไรได้อีกเยอะแยะ และในคอร์สคาราเซลที่ผมกำลังจะทำ ผมจะลงวิดีโอที่ผมทำคาราเซล 7 อันในคราวเดียว ซึ่งจะเจ๋งมาก รอให้มันทำงานไปก่อนสักครู่

เยี่ยม มันอัปเดต Skill ให้เราแล้ว มาดูคอปปี้ใหม่กัน "Carousel Analysis: ขโมยแพตเทิร์นคาราเซลที่ชนะของคู่แข่ง เพื่อที่คุณจะได้ไม่ต้องเดา" "เลือกหัวข้อคาราเซลไวรัลตัวต่อไปของคุณจากข้อมูลจริง" "เขียนทุกสไลด์ ทั้งพาดหัว CTA แล้วเอาสคริปต์ไปออกแบบคาราเซลทั้งอันให้คุณ" ไม่เลวเลย ผมว่าได้ประมาณ 90% แล้ว เราสามารถมาแก้บนคาราเซลจริงได้ตลอด ไม่ต้องเสียเวลากับตรงนี้มาก แต่คุณเห็นแล้วว่าแก้แบบสดๆ ได้ยังไง ดูดี เอาเลย

โอเค ตอนนี้เราจะส่งมันออกไป และดูเหมือนมันจะไปอัปเดตเรคคอร์ดใน Airtable มันน่าจะโผล่ไปที่สถานะ Filming/Create มาดูกัน บูม เสร็จแล้ว นั่นไง มันอยู่ตรงนั้น — "Four Claude Skills ที่สร้างคาราเซลในขณะที่คุณหลับ" และมันยังโชว์มุมเนื้อหา งานวิจัยทั้งหมดที่มาพร้อมการตัดสินใจจากข้อมูลจริง มีฮุค แล้วที่สำคัญที่สุดคือ มันมีสคริปต์ทั้งอันอยู่ข้างใน — "Carousel trigger: 6 สไลด์" นี่คือทั้งหมดที่เราเห็นพอดี นี่แหละเงิน

ต่อไปเราจะไปที่ตัวโปรดของผม นั่นคือ Carousel Creator เจอกันวิดีโอหน้า และให้ผมดาวน์โหลดอันนี้ก่อน ถ้ามีคำถามอะไรบอกได้เลยนะครับ ผมกำลังจะอัปโหลดเวอร์ชันที่ทำเสร็จแล้วตอนนี้
