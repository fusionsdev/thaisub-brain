## คำแปลเต็ม

ยินดีต้อนรับสู่วิดีโอ Anatomy of a Skill ในวิดีโอนี้ผมจะเจาะลึกการวิเคราะห์ว่าแท้จริงแล้ว Skill คืออะไร และโครงสร้างภายในที่ทำให้มันเป็น Skill มันสำคัญมากที่คุณต้องเข้าใจและเรียนรู้สิ่งนี้ เพราะตอนที่คุณสร้าง Skill คุณต้องสามารถแก้ปัญหาได้ — แต่คุณก็ต้องแก้บั๊กมันได้ด้วย เผื่อเจอปัญหาอะไรเข้า คุณไม่ควรสร้างสิ่งที่คุณไม่เข้าใจ

เราจะไล่ดูคร่าวๆ เร็วๆ เพื่อโชว์ให้เห็น โดยพื้นฐาน Skill ก็คือไฟล์บนคอมพิวเตอร์ของคุณ ถ้าผมเปิด — สมมติว่าไปที่แชทใหม่ แล้วคุณจะหา Skill ทั้งหมดของคุณได้ที่เมนู Customize และภายใต้ Skills คุณจะเห็นรายการ Skill ทั้งหมดของคุณ ผมมี Ad Brief Skill ที่อ่าน Meta Ads ทั้งหมดของผม วิเคราะห์ทุกอย่าง แล้วเขียนสรุปให้ผมทุกเช้าว่าโฆษณาทำผลงานยังไง และเรามี Daily Content Researcher Skill ที่ผมโชว์ในวิดีโอที่แล้ว ที่ค้นหาหัวข้อเทรนด์ทั้งหมดให้ผมสร้างคอนเทนต์ทุกวัน

แต่สิ่งที่อยู่ข้างใน Skill ก็คือไฟล์ มันเป็นแค่ไฟล์จริงๆ พูดให้ชัดคือ ถ้าผมเปิดดูว่า Skill หน้าตาเป็นยังไงบนเครื่อง มันจะเรียกว่าไฟล์ Skill และถ้าผมเปิดมัน ผมจะเห็นข้อความที่มนุษย์อ่านได้ใน text editor แต่โดยรวมมันก็คือไฟล์ที่แจกแจงคำสั่งทั้งหมดและทุกรายละเอียดเล็กๆ น้อยๆ ที่ต้องใช้ในการสร้าง workflow แค่นั้นเอง

ทุกครั้งที่ผมเรียกใช้ Skill นั้น — ถ้าคุณเห็นในวิดีโอที่แล้ว มันคือการพิมพ์สแลช มันจะอ่านไฟล์ทั้งอันนี้ เมื่อผมไปที่แชทแล้วพิมพ์ / มันจะทริกเกอร์ Skill ผมเลือก Skill ได้ หรือผมจะพิมพ์เองก็ได้ พิมพ์ "daily content researcher" แล้วกด Tab มันก็จะไฮไลต์ขึ้นมา

ใน Skill แต่ละอันจะมีชื่อ — เห็นไหมว่ามี title: Daily Content Researcher — แล้วก็มีสิ่งที่เรียกว่า front matter คุณไม่จำเป็นต้องเข้าใจลึกซึ้ง แต่โดยรวมมันคือชื่อกับคำอธิบายที่อยู่ด้านหน้า นี่คือสิ่งที่ Claude อ่านเมื่อมันไล่ดูสิ่งต่างๆ มันมี title และ description โดย description จะอธิบายว่ามันคืออะไร ด้วยคีย์เวิร์ดของ Skill นั้น เช่น "การวิจัยเชิงเอเจนต์ในตอนเช้าสำหรับ NoeAI ที่ scrape X, Reddit, GitHub และ Twitter รวมถึงข่าวสาร ผ่าน Apify แล้วสรุปผลเป็นไกด์"

เพื่อที่จะเรียกใช้มัน ผมพิมพ์ "daily" แล้วกด Enter ก็ได้ หรือถ้าผมอยากเรียกโดยไม่พิมพ์ชื่อ — ซึ่งผมไม่เห็นเหตุผลว่าทำไมต้องทำแบบนั้น แต่จะเกิดอะไรขึ้นถ้าผมพูดว่า "ช่วยทำ daily ให้หน่อยได้ไหม?" สิ่งที่ Claude จะทำคือ มันจะเอาคีย์เวิร์ดเหล่านี้ไปค้นหาใน Skills ทันที ว่าตรงกับ title หรือ description อันไหนมั้ย มันจะคิดประมาณว่า "เขาพูดว่า daily เขาอยากได้ daily content โอเค เดี๋ยวไปค้นหาคีย์เวิร์ดใน Skill ทั้งหมดของเขาก่อน เจอแล้ว Daily Content Researcher Skill เขาใช้ตัวนี้บ่อย นี่น่าจะเป็นสิ่งที่เขาหมายถึง" แล้วมันก็รันให้ ง่ายมาก

ข้างใน Skill — ถ้าผมดึงกลับมา นั่นคือสิ่งที่เรียกว่า front matter ที่เพิ่งโชว์ให้ดู — แล้วข้างในเอกสารนั้น มันคือไฟล์บนคอมพิวเตอร์ของคุณที่อยู่ในรูปแบบที่เรียกว่า markdown คุณเห็นไฟล์ที่ผมเปิดตอนแรกมั้ย ว่ามันลงท้ายด้วย .md นั่นหมายถึง markdown แค่นั้น มันเป็นวิธีที่ AI ใช้อ่านไฟล์ เพราะ AI ไม่เหมือนมนุษย์ มันไม่ได้อ่านแบบเดียวกัน แต่มันอ่านได้เป็นระเบียบและมีประสิทธิภาพกว่า เพื่อให้ได้ผลลัพธ์ที่มันต้องการ ดีกว่าการอ่านเอกสารที่รกๆ ที่เราตีๆ กันขึ้นมา

คุณจะเห็นที่ด้านบนมีชื่อ มี front matter — จำได้มั้ยว่ามันเรียกว่าอะไร — แล้วก็มีคำอธิบายว่า Skill ทำอะไรกันแน่ จากนั้นคุณจะเห็นเครื่องหมายแฮช (#) พวกนี้ มันคือการสร้างหัวข้อให้คนอ่าน เห็นไหมว่ามันเป็นหัวข้อใหญ่ เพราะในไฟล์มีเครื่องหมายแฮช ถ้าผมอยากได้หัวข้อย่อยลงไปอีก อันนี้มันก็จะไม่ตัวหนาแล้ว แต่นั่นคือการจัดรูปแบบ และยังมีหัวข้อย่อยอีกหลายระดับ เหมือนกับบริบทของ Skill แล้วมันก็เริ่มไล่ทำทีละขั้น: ขั้นตอนที่หนึ่ง ทำสิ่งนี้, มีไมโครสเต็ป — หลายขั้นตอนย่อยในหนึ่งขั้นตอน — แล้วก็ขั้นตอนที่สาม ขั้นตอนที่สี่ ซึ่งขยายออกไปเรื่อยๆ นี่คือ workflow ทั้งหมด ขั้นตอนแล้วขั้นตอนเล่า ง่ายมาก แต่มันเหมือนเอเจนต์ AI ที่ทำงานรอบๆ ผลิตภัณฑ์ มันแก้ปัญหาให้คุณได้แบบเรียลไทม์ ซึ่งเจ๋งจริงๆ

นั่นคือ Skill พื้นฐาน — ที่มีไฟล์เดียว แล้ว Claude ทำงานยังไง — อย่างที่ผมพูดถึง สมมติว่านี่คือผมคุยกับ Claude โอเค แล้วนี่คือ Claude ทีนี้สิ่งที่มันทำทันทีคือ — จำได้มั้ยตอนที่ผมพูดว่า "ทำ daily content research" มันจะขึ้นไปหาใน Skills แล้วมองหา Skill ที่ตรงกัน มันเจอ Daily Content Skill จาก front matter — จำได้มั้ย ชื่อกับคำอธิบาย — แล้วสิ่งที่มันทำต่อคือ เมื่อเจอ Skill แล้ว มันจะอ่านไฟล์ skill.md นี่คือไฟล์ที่ผมโชว์ให้ดู นี่คือ skill.md ตรงนี้ มันอ่านทั้งไฟล์ ไล่ดูขั้นตอนทั้งหมด เข้าใจว่ามันคืออะไร

จากนั้นถ้า Skill ของคุณมี reference files — reference files ก็เช่น brand voice ของคุณ หรือเอกสารธุรกิจของคุณ — ถ้ามันอยู่ใน Skill เช่น ถ้าผมเป็น Skill นี้ และในขั้นตอนหนึ่งบอกว่า "ไปอ่าน brand voice ของฉัน เพื่อที่คุณจะได้เขียนคอนเทนต์ที่ดีกว่าให้ฉัน" สิ่งที่มันจะทำคือ เพราะมันอยู่ในคำสั่ง มันก็จะไปที่โฟลเดอร์นี้ จากไฟล์ .md นี้ มันจะลงไปอ่านไฟล์ brand voice.md ของผม

บางทีมันซับซ้อนกว่านั้นอีก บางทีคุณมี workflow ที่ซับซ้อนมาก เช่น ไฟล์ Viral Hooks Pattern — viral hooks.md ซึ่งเป็นอีกไฟล์หนึ่ง แต่โดยพื้นฐาน Skill คือตัวหลัก แล้วไฟล์สองไฟล์นี้ให้บริบทเพิ่มเติม ให้ข้อมูลที่ดีกว่า ให้คอนเทกซ์มากกว่า แล้วมันก็เอาทั้งสามอย่างนี้มาอ่านทั้งหมด แล้วส่งกลับไปให้ Claude Claude ทำงานทั้งหมด แล้วส่งคำตอบกลับมาให้ผม

ตรงไปตรงมา ไม่ได้ซับซ้อนมาก แต่มันทำงานแบบนี้แหละ คุณไม่ต้องเป็นผู้เชี่ยวชาญ คุณแค่ต้องเข้าใจว่า Claude ทำงานยังไง ตัวอย่างคือไฟล์ Skill Creator ของผม — ซึ่งคุณควรจะมีด้วย — ทุกครั้งที่ผมอยากสร้าง Skill ใหม่ ซึ่งเราจะทำในวิดีโอหน้า Claude จะเข้ามาอ่านไฟล์ .md นี่คือคู่มือทั้งหมดเกี่ยวกับวิธีสร้าง Claude Skills และเมื่อผมอยากสร้าง Skill เฉพาะสักตัว มันก็จะไปอ่านไฟล์อื่นๆ เหล่านี้ด้วย มันอ่านแล้วเช็คว่ามันดีมั้ย เรื่อง Python อะไรพวกนั้น มันอ่านทั้งหมดก่อนที่จะตอบฉัน มันมีข้อมูลครบทุกอย่าง

ผมไม่อยากให้ข้อมูลคุณมากเกินไป แต่โดยรวมนี่คือกายวิภาคและการแยกย่อยของ Skill คุณไม่จำเป็นต้องเป็นผู้เชี่ยวชาญ ไม่ต้องเครียดไป โอเค? คุณแค่ต้องเข้าใจว่ามันทำงานยังไง — มันหา Skill อ่าน Skill อ่านไฟล์ที่เกี่ยวข้อง แล้วก็ลงมือทำ workflow นั้นให้เรา ง่ายมาก ดังนั้นในวิดีโอหน้า เราจะสร้าง Skill ตัวแรกของคุณจริงๆ เจอกันนะครับ
