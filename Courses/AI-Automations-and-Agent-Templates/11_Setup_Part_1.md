## บทนำ
วิดีโอนี้เป็นส่วนแรกของการตั้งค่าระบบอัตโนมัติ PostRemix AI ซึ่งประกอบด้วยสอง automation ระบบจะนำเข้าโพสต์จาก Instagram ผ่าน RapidAPI แล้วเขียนโพสต์ใหม่ให้เข้ากับหัวข้อที่กำหนด พร้อมสร้างรูปภาพใหม่จากรูปต้นฉบับ และในส่วนที่สองจะทำหน้าที่เผยแพร่ไปยังแพลตฟอร์มที่เลือก วิดีโอนี้ครอบคลุมการตั้งค่า Google Sheets, Apps Script, blueprint แรกใน Make.com, การเชื่อมต่อ OpenAI และการนำเข้าโพสต์ชุดแรก

## คำแปลเต็ม

ระบบอัตโนมัติที่เราจะตั้งค่าวันนี้ชื่อว่า PostRemix AI automation มันประกอบด้วยสอง automation อันหนึ่งนำเข้าหรือสร้างโพสต์ ซึ่งหมายถึงมันนำโพสต์ที่เกิดขึ้นใน Google Apps Script ซึ่งเราจะตั้งค่าด้วย แต่คุณไม่ต้องเขียนโค้ดใด ๆ และมันจะเขียนโพสต์ใหม่

นี่คือสิ่งที่ automation ทำ มันเลือกโพสต์ที่นำเข้าแล้วเขียนใหม่ให้เข้ากับหัวข้อ และมันสร้างรูปภาพโดยการวิเคราะห์รูปภาพที่มีอยู่ แล้วพยายามสร้างรูปภาพใหม่สำหรับหัวข้อของฉัน หรือสร้างจากจุดเริ่มต้นของรูปภาพ

จากนั้นผมมี automation ที่สอง ซึ่งเป็นหน้าที่ของ automation ที่สอง เรียกว่าตัวเผยแพร่ ซึ่งส่งโพสต์ มันส่งโพสต์พร้อมลิงก์รูปภาพ และตรงนี้ผมสามารถระบุแพลตฟอร์มที่ต้องการให้เผยแพร่ได้ และถ้าผมคลิก publish มันจะเผยแพร่โพสต์ของผมเฉพาะไปที่ Twitter หรือผมสามารถบอกให้เผยแพร่ไปที่ Instagram ด้วยก็ได้ จากนั้นมันจะเผยแพร่โพสต์เมื่อผมคลิกที่นี่ไปที่ Instagram ด้วย เราสามารถเพิ่มแพลตฟอร์มทั้งหมดที่ต้องการได้

และนี่คือระบบอัตโนมัติที่เราจะตั้งค่า มันประกอบด้วยสองซีเควนซ์ automation แบบนี้ ไปที่ Make กัน แล้วตั้งค่าจากศูนย์ ด้านล่างวิดีโอนี้คุณจะพบ blueprint สองอันที่ต้องใช้ และ Google Sheet template ที่ต้องใช้

มาเริ่มตั้งค่า Google Sheet ก่อน เพราะนี่คือสิ่งที่เราต้องใช้สำหรับ automation ของเรา คลิกลิงก์ด้านล่าง แล้วคลิก make a copy ตรงนี้สำคัญคือต้องเข้าสู่ระบบด้วยบัญชี Google เดียวกับที่คุณจะใช้สำหรับเชื่อมต่อโมดูล

ก่อนอื่นเราต้องทำสองสามขั้นตอนภายใน Google นี้ เพราะเราต้องติดตั้งและอนุญาตโค้ดที่กำหนดเองที่ผมใส่ไว้ในนั้น และยังต้องแก้ไขหรือใส่ข้อมูลบางอย่าง เช่น API keys และอื่น ๆ

ตอนนี้เราต้องไปที่ตรงนี้ก่อน มันเขียนว่า automation tools อาจใช้เวลาสองสามวินาทีในการโหลด และอันดับแรกคลิกที่ authorize จากนั้นทำตามขั้นตอนการอนุญาต ทำจนครบ คลิกที่มัน แล้วคลิก install อาจใช้เวลาสองสามวินาที เสร็จแล้ว ตอนนี้พร้อมแล้ว เราเริ่มได้เลย

เราจะดาวน์โหลด blueprint automation อันแรกและนำเข้าโดยคลิก create a new scenario จากนั้นตรงนี้เรามีและปุ่ม import blueprint เราจะนำเข้า blueprint มันคืออันนี้ เราต้องการเทมเพลต generator ดี ตอนนี้นำเข้าแล้ว

สิ่งแรกที่ต้องทำคือสร้าง webhook ใหม่ จะตั้งชื่อสุ่มให้มัน เอาล่ะ ตอนนี้ผมคัดลอก webhook นี้ไปยังคลิปบอร์ดแล้วคลิก OK เพราะตอนนี้ผมต้องไปที่ Apps Script ของผม ใส่ webhook นี้ตรงนั้น ไปที่ Apps Scripts แล้วมี placeholder มันเขียนไว้ตรงนี้ว่า Insert make webhook generator automation เราวางมันตรงนั้น คลิก save

มี webhook อีกอันที่ต้องเอา แต่นั่นมาจาก publishing automation เรายังไม่ต้องการมันตอนนี้ และตอนนี้มาเริ่มกัน สิ่งแรกที่ต้องทำคือเพิ่มการเชื่อมต่อ Google ของคุณ ถ้ายังไม่ได้ทำ คลิกที่ add แล้วเลือกการเชื่อมต่อเดียวกับที่คุณมีใน Google Sheet นี้ นี่สำคัญมากเพื่อให้สิ่งนี้ทำงาน

และเมื่อทำเสร็จ คุณดึง ID จาก Google Sheet ของคุณ ซึ่งคือส่วนนี้ แล้วใส่ลงไป จากนั้นมันควรจะโหลดชีต และสิ่งที่คุณต้องทำคือคลิก และตอนนี้คุณทำแบบนี้กับโมดูล Google ทั้งหมด ดูว่ามันโหลดถูกต้องไหม Import ใช่ list เหมือนกัน

ตอนนี้ตรงนี้เราต้องระบุตัวแปรซึ่งก็คือ topic generator ซึ่งควรถูกบันทึกในชีตกลุ่มนี้ และให้ผมตรวจสอบตรงนี้ ตรงนี้เราไม่ต้องทำอะไร มันโอเคแล้ว และไปตรงนี้ นี่คือที่ที่เราบันทึกข้อความโพสต์ที่สร้างแล้ว เราบันทึกโพสต์ต้นฉบับซึ่งมาจาก webhook จริง ๆ และหัวข้อ หัวข้อเป็นเพียงผลลัพธ์ของโมดูล topic generator แบบนี้ โพสต์ที่สร้างแล้วมาจากตรงนี้ แค่ผลลัพธ์ รูปภาพ ภาษา แพลตฟอร์มการแสดงผล นี่ไม่ใช่สิ่งที่เราต้องตั้งค่าตอนนี้ ไปต่อ

เพราะตรงนี้มาถึงส่วนที่เราตั้งค่าไว้ ดี นี่คือสิ่งที่เราตั้งค่า ตอนนี้มาถึงโมดูลรูปภาพ ตรงนี้เราก็มีชีต เราต้องบันทึกข้อมูลเกี่ยวกับรูปภาพ ซึ่งก็แค่ลิงก์รูปภาพ และลิงก์รูปภาพตรงนี้เราเรียกว่า web content link นั่นคือสิ่งที่เราบันทึกตรงนี้ แค่นั้นที่ต้องทำ

และตอนนี้เราต้องตั้งค่าโมดูล OpenAI ถ้าคุณยังไม่ได้เพิ่มการเชื่อมต่อ ต้องเพิ่มมัน และผมมีบทช่วยสอนเฉพาะในหัวข้อ technical tutorials: get OpenAI API key จาก OpenAI คุณแค่ทำตามขั้นตอน แล้วคลิก add แล้วกรอกข้อมูลของคุณ แล้วมันก็เชื่อมต่อ และตอนนี้ค่าต่าง ๆ ควรถูกจับคู่อัตโนมัติ

ตอนนี้เรามีตัวแปรนี้ซึ่งก็คือ และตรงนี้ niche ซึ่งเป็นค่าที่มาจากอันนั้น จากนี้ไปได้ชีต นี่ดี ตรงนี้คือโมดูลสร้างโพสต์ นี่ดี ตอนนี้มันแสดงว่ายังไม่พร้อมเพราะเราต้องส่ง automation นี้ไปที่ webhook ก่อน

มา ยกเลิกการเชื่อมโยงมันตรงนี้ ผมคิดว่านั่นคือโมเดล generator ใช่ แล้วบันทึกมัน คลิก run once และตอนนี้เราต้องเลือก send post data to Make นั่นคือสิ่งที่เราต้องการ ไม่ ยังรันไม่ได้เพราะเรายังไม่มีโพสต์ที่นำเข้า นั่นคือสิ่งที่เราต้องทำเช่นกัน

และเพื่อให้ได้... ผมคิดว่านี่คือสิ่งที่เราควรทำก่อน เราต้องไปที่หน้านี้ ตรงนี้บน Instagram คุณจะต้องเอา API key ของคุณ การทำแบบนี้คลิกที่หนึ่งในสิ่งเหล่านี้ ผมจะคลิกที่ post และ reads แล้วทางด้านขวาคุณจะเห็นว่า API key ของคุณปรากฏที่ไหน และเมื่อทำเสร็จแล้ว ผมจะเพิ่มบทช่วยสอนในส่วนนี้ ผมคิดว่ามันเหมือนกับอันนี้

เอา API key จาก RapidAPI จาก YouTube คุณทำตามบทช่วยสอนนี้ได้เพราะมันแสดงหลักการเดียวกัน วิธีหา API key จาก RapidAPI ซึ่งเป็นบริการหรือแพลตฟอร์ม API ที่ผู้คนสามารถขาย API และคุณสามารถใช้ API ของพวกเขาได้ เลือก basic แล้วคลิก จากนั้นทำตามขั้นตอนในวิดีโอนี้เพื่อเอา key ของคุณ และคุณต้องสมัครบัญชี RapidAPI ฟรี แต่ผมคิดว่าระบบจะให้คุณสมัครเอง

และเมื่อคุณมี API แล้ว คุณจะเพิ่มมันใน placeholder นี้ ซึ่งผมจะทำตอนนี้ แต่ผมจะไม่แสดงให้ดูเพราะเป็นข้อมูลที่ละเอียดอ่อน

เราสามารถนำเข้าโพสต์ชุดแรกได้ และเราไปตรงนี้ นี่คือชีตของผม ตอนนี้ผมต้องพิมพ์หัวข้อ ผมมีตัวอย่างหัวข้ออยู่ในนี้แล้ว แต่ตอนนี้ไม่สำคัญ สิ่งที่เราต้องการคือ Instagram handle ของโซเชียลมีเดีย จะเลือก Instagram อันนี้แล้วใส่ลงไป ผมสามารถระบุได้ว่าต้องการนำเข้ากี่โพสต์ สมมติว่า 30 โพสต์แรก แล้วคลิก import โพสต์ และถ้าคุณตั้งค่าไว้แล้ว มันควรใช้เวลาสักครู่ แล้วมันจะนำเข้าโพสต์ประมาณ 30 โพสต์จากคนนี้ อย่างที่เห็น คลิก allow access แล้วมันจะนำเข้ารูปภาพด้วย มันประมาณ 30 โพสต์ ใช้งานได้

ถ้าคุณไปที่การนำเข้า คุณสามารถกรองโพสต์ได้ แล้วมันจะถูกกรอง จะมีค่าเฉลี่ยจำนวนไลก์ ซึ่งเป็นค่าเฉลี่ยจำนวนไลก์ของโพสต์ที่นำเข้าทั้งหมด แล้วมันจะดูว่าโพสต์นี้มีไลก์สูงกว่าค่าเฉลี่ยไหม แล้วมันจะทำเครื่องหมายว่าเป็นโพสต์ประสิทธิภาพสูงหรือประสิทธิภาพต่ำ

และผมยังตั้งค่า filter ที่สามารถให้มันใช้เฉพาะโพสต์ประสิทธิภาพสูงสำหรับสร้างข้อความโพสต์ของฉัน ดังนั้นข้อความโพสต์แต่ละอันที่สร้างขึ้นจะอยู่บนหัวข้อโพสต์ประสิทธิภาพสูงเสมอ

ตอนนี้กลับมาตรงนี้ และตอนนี้มารันและเปิดใช้งานมัน แค่คลิกที่มัน แล้วผมไปที่ send post data to Make ตอนนี้เราควรเห็นข้อมูลที่มันจะได้รับ มันจะส่งโพสต์ที่สร้างแรกมาที่นี่

โพสต์ต้นฉบับ นี่คือสิ่งที่เราต้องระบุก่อนแน่นอน เพราะมันมาจาก webhook ตรงนี้ไหม? ตรงนี้คือ subtopics มันควรจะอยู่ตรงนี้ ใช่ไหม? โพสต์ต้นฉบับซึ่งก็คืออันนี้ คำบรรยายในกรณีนี้ ดี คุณไปตรงนี้ได้ เรา ต้องเชื่อมต่อมัน มาดูว่ามันทำงานถูกต้องไหม ตอนนี้มันเต็มแล้ว ดี ตรวจสอบว่าถูกต้องไหม ดี และมีอะไรที่เราต้องการอีกไหม? แค่นั้น

ตอนนี้เราควรจะเห็น... อันนี้ผิดอัน ในส่วนที่สร้างแล้ว เราควรเห็นรูปภาพและการแสดงผลรูปภาพด้วย และนั่นคือสิ่งที่เราต้องการ เปิดใช้งานมันอีกครั้ง รันมันอีกครั้ง รันเลย ผมสามารถตั้งเป็นอันนี้ได้ จากนั้นคลิก run send post data to แล้วมันจะส่งโพสต์ถัดไป มันจะส่งโพสต์ที่นำเข้าอันที่สองไปที่ Make แต่ก็จะกรองด้วย ถ้าผมมีโพสต์ประสิทธิภาพสูง/ต่ำ ถ้ามันเป็นโพสต์ประสิทธิภาพสูง มันจะส่งโพสต์นั้น เพราะถ้ามี... ตอนนี้ผมยังไม่ได้ใช้ filter ดังนั้นมันขึ้นอยู่กับคุณว่าจะใช้กระบวนการกรองหรือไม่

ถ้าคุณใช้ มันจะกรองโพสต์ประสิทธิภาพต่ำออก มันจะไม่ส่งโพสต์ประสิทธิภาพต่ำไปที่ Make มันจะข้ามโพสต์เหล่านี้และส่งเฉพาะโพสต์ที่ดี นี่คือวิธีการทำงาน

และถ้าคุณไปที่โพสต์ คุณควรเห็น ตรงนี้ควรเป็นโพสต์ รูปภาพแสดงอยู่ตรงนี้ และนี่คือข้อความที่สร้าง นี่คือหัวข้อที่สร้างจากโมดูลสร้างหัวข้อ เพราะเราใส่หัวข้อไว้ตรงนี้

ตอนนี้ส่วนแรกของ automation ทำงานแล้ว ตอนนี้คุณสามารถตัดสินใจได้ว่าจะรันมันอย่างไร คุณสามารถตั้งค่า automation นี้ให้รันตามเวลาที่กำหนด รันเป็นประจำ คุณสามารถสร้าง 100 โพสต์แล้วปล่อยให้มันรัน หรือคุณสามารถตั้งให้รันทุกนาที มันจะสร้างโพสต์ใหม่ทุกนาที แล้วปล่อยให้มันรัน 100 นาที แล้วคุณจะมีโพสต์ 100 อันบันทึกไว้ที่นี่ เมื่อไหร่ก็ตามที่คุณต้องการโพสต์ใหม่

และแน่นอน คุณสามารถเพิ่ม Instagram handle ต่าง ๆ ได้ตรงนี้ แล้วนำเข้ามา แล้วมันจะถูกเพิ่มด้านล่างเหล่านี้ แล้วคุณสามารถใช้มันสร้างหัวข้อโพสต์ของคุณได้
