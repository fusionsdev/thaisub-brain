## ประเด็นสำคัญ

- คลิปเปิดด้วยคำเตือนจัดเต็ม 3 ข้อ ก่อนใช้ AI ไร้การเซ็นเซอร์ ได้แก่ คุณไม่ได้เป็นเจ้าของโมเดลเหล่านี้จริงๆ (ยกตัวอย่างที่รัฐบาลสหรัฐถอนสิทธิ์เข้าถึงโมเดลที่ทรงพลังที่สุดอย่าง Fable) โมเดลพวกนี้ไม่มีข้อจำกัดแท้ๆ ใช้ทำดีหรือร้ายก็ได้ และเคยมีเหตุการณ์ Hugging Face ถูกโจมตีช่วงต้นปี
- อธิบายหลักการว่าโมเดล obliterated คือการไปหา weights หลายพันล้านตัวในโมเดล แล้วตัดเฉพาะส่วนที่ใช้ปฏิเสธคำขอออกไป ประสิทธิภาพจึงแทบไม่ต่างจากโมเดลปกติ
- ระดับที่ 1 คือใช้ผ่าน API อย่าง obliteration.ai สมัครบัญชีเติมเงิน $5 แล้วถามอะไรก็ได้โดยไม่มีการปฏิเสธ ต่างจาก Claude ที่มักปฏิเสธงานที่ขัดแนวปฏิบัติ
- โชว์การ reverse engineer แอป Granola และ Screen Record Studio ด้วย repo Reverse Engineer Anything แล้วเปิดผลงานใน localhost ได้จริง พร้อมโลโก้และพาเลตต์สีครบ
- จุดขายใหญ่คือราคา สร้าง Linear ด้วย $63 เทียบ Opus 5.5 ที่ $281 สร้าง Granola $32 เทียบ $152 และ Screen Record Studio $55 เทียบ $200 ขึ้นไป โดยรวมคือราว 20% ของราคาโมเดลพรีเมียม
- วิธีเริ่มต้นคือสร้าง API key ใน Obliteration AI โดยเติมขั้นต่ำ $5 และย้ำว่าอย่าเปิด auto billing พร้อมมี starter pack ผ่านลิงก์คอมมูนิตี้ฟรีในคำอธิบาย
- ใช้บนเครื่องตัวเองได้สองทาง คือ agentic operating system ที่สั่งงานด้วยเสียง หรือ DeepSeek harness ที่ทำนองเดียวกับ Claude Code แบบโอเพนซอร์ส
- ระดับที่ 2 คือรันแบบ local ผ่าน Ollama ได้ความเป็นส่วนตัว 100% ไฟล์อยู่กับบ้าน ไม่มีค่า tokens เหลือแต่ค่าไฟ เหมาะกับบันทึกสุขภาพ กรมธรรม์ บันทึกความปลอดภัย และสัญญาลูกค้า
- โมเดล local ปัจจุบันไม่ได้ตามหลังกันหลายปี ตาม benchmark แล้ว DeepSeek V4.1 Flash แข็งแกร่งเท่าโมเดลเก่งที่สุดของเดือน มีนาคม 2026 ส่วน GLM 5.3 เทียบเท่าธันวาคม และ Quen เทียบเท่าพฤศจิกายน 2025
- ให้กฎง่ายๆ ว่าโมเดลโอเพนซอร์สที่ดีที่สุดจะตามหลัง Frontier ราว 4 เดือน และตัวที่ลง Mac ได้จะเก่ากว่าราว 9 เดือน พร้อมสเปรดชีตช่วยเลือกโมเดลตาม GPU RAM และพื้นที่ดิสก์
- ยกระดับการสั่งงานด้วยเสียงผ่าน Fish Audio ที่ถูกกว่าคู่แข่ง ทำ clone เสียงตัวเองในไม่ถึงนาที เลือกเสียงสำเร็จรูปแนว Morgan Freeman หรือ Terminator ได้จาก voice library
- ระดับที่ 3 คือเช่า VPS ของ Hostinger (KVM2) ให้รันตลอด 24/7 ตอนนี้มีดีลลด 64% บวกโค้ด Jack Roberts ลดเพิ่ม 10% เหลือราวต่ำกว่า $200 ประหยัด $470 เลือก Ubuntu 26.04 และเซิร์ฟเวอร์ที่ latency ต่ำสุด จากนั้นเชื่อม Tailscale ระหว่างอุปกรณ์กับ VPS แล้วให้ Claude ติดตั้งทุกอย่างผ่าน web console
