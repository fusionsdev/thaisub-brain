## บทนำ
วิดีโออัปเดตสั้น ๆ สำหรับระบบอัตโนมัติที่ใช้ Creatomate ในการสร้างวิดีโอ เนื่องจากอินเทอร์เฟซของ Creatomate เปลี่ยนไปเล็กน้อย ไม่มีองค์ประกอบวิดีโอให้ลากเข้าไปในเทมเพลตอีกต่อไป วิธีแก้คืออัปโหลดวิดีโอแนวตั้งขึ้นไปก่อน แล้วตั้งค่าเป็น dynamic พร้อมทั้งตั้งค่าข้อความให้เป็น dynamic ด้วย

## คำแปลเต็ม

ในวิดีโอนี้ ฉันจะแสดงอัปเดตสั้น ๆ เกี่ยวกับระบบอัตโนมัติใดก็ตามที่ใช้ Creatomate ในการสร้างวิดีโอ อย่างที่คุณเห็นในบทช่วยสอนการตั้งค่า ระบบนี้ทำงานโดยใช้เทมเพลตและตัวยึดตำแหน่ง (placeholder) สำหรับข้อความและวิดีโอ

ถ้าตอนนี้คุณล็อกอินเข้า Creatomate อินเทอร์เฟซเปลี่ยนไปเล็กน้อย ให้คลิกที่ Create a New Template แล้วคลิก Start from Scratch เลือกรูปแบบแนวตั้ง (vertical) แล้วคลิก Create ตอนนี้คุณจะเห็นว่าไม่มีองค์ประกอบวิดีโอให้ลากเข้าไปอีกแล้ว ด้วยเหตุนี้ คุณต้องคลิกที่ upload คลิก browse แล้วอัปโหลดวิดีโอใดก็ได้ในรูปแบบแนวตั้งนี้ ไม่สำคัญว่าวิดีโอจะเป็นอะไร ขอแค่เป็นรูปแบบเดียวกัน

สิ่งที่เราจะทำตรงนี้คือเปลี่ยน provider เป็น none และตรงนี้เราตั้งค่าเป็น dynamic จากนั้นเราจะมีองค์ประกอบวิดีโอชื่อ video nk6 เราสามารถเปลี่ยนชื่อได้ถ้าต้องการ ฉันจะเรียกมันว่า background แล้วคุณก็ลากและเลือกองค์ประกอบข้อความ คลิกเพื่อเพิ่มองค์ประกอบข้อความ อย่างที่เห็น จากนั้นเราก็เปลี่ยนชื่ออันนี้ได้เหมือนกัน อันนี้จะเป็น text one

องค์ประกอบข้อความยังทำงานเหมือนกับที่ฉันแสดงในบทช่วยสอนแล้ว การอัปเดตมีเพียงวิดีโอพื้นหลังเท่านั้น ดังนั้นคุณเพิ่ม text one แล้วก็ข้อความอื่น ๆ ทั้งหมด ตามที่ฉันแสดงไว้ในบทช่วยสอน

จากนั้นคุณต้อง ฉันจะตั้งชื่อเฉพาะให้เทมเพลตนี้ เช่น 275 เพื่อให้ฉันหาเจอในระบบอัตโนมัติของฉัน จากนั้นเมื่อฉันเข้ามาตรงนี้ ฉันได้สร้างการเชื่อมต่อไว้แล้ว และฉันคลิกที่ refresh ฉันจะเห็นและเลือกเทมเพลตที่ฉันสร้างไว้ มาคลิก use this template กัน อันนี้ดี เทมเพลตถูกบันทึกแล้ว มันน่าจะแสดงตรงนี้ มาคลิก refresh กัน โอเค มันยังไม่ถูกบันทึก บางทีอาจต้องใช้เวลาสักครู่ กลับเข้าไปอีกครั้ง คลิก exit จริง ๆ แล้วอาจต้องใช้เวลาไม่กี่วินาทีกว่ามันจะดึงเทมเพลตมา ตอนนี้มันอยู่ตรงนั้นแล้ว นี่คือสิ่งที่ฉันเพิ่งสร้าง และคุณเห็นวิดีโอพื้นหลัง

ตอนนี้ข้อความไม่แสดงขึ้นมาเพราะฉันลืม ข้อความก็ต้องตั้งค่าเป็น dynamic ด้วย ดังนั้นต้องตั้งค่าข้อความเป็น dynamic จากนั้นเมื่อเราคลิก มันควรโหลดเทมเพลตใหม่ ตอนนี้คุณเห็นข้อความแล้ว และตรงนี้คุณมีเพียงตัวยึดตำแหน่งวิดีโอที่คุณใช้ได้เหมือนกับที่ฉันบอกในบทช่วยสอนการตั้งค่า นี่เป็นเพียงอัปเดตสั้น ๆ
