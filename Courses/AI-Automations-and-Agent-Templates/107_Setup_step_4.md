## บทนำ
วิดีโอนี้เป็นขั้นตอนสุดท้ายเล็ก ๆ ของการตั้งค่าระบบ นั่นคือการเชื่อมต่อ TikTok เข้ากับระบบอัตโนมัติ เพื่อให้วิดีโอทั้งหมดที่เราสร้างถูกเผยแพร่ไปยัง TikTok ได้โดยอัตโนมัติ ใช้เครื่องมือสองตัวคือ Sapier (แพลตฟอร์มเวิร์กโฟลว์อัตโนมัติ) และ Buffer (เครื่องมือจัดตารางเผยแพร่โซเชียลมีเดีย) พร้อมกับอธิบายการตั้งค่าเครดิตของ JSON2Video และการเปิดใช้งานระบบอีกครั้ง

## คำแปลเต็ม

ต่อไปเป็นขั้นตอนเล็ก ๆ สุดท้าย ขอตั้งค่า TikTok ด้วย เพื่อให้เราสามารถเผยแพร่ไปยัง TikTok ได้เช่นกัน สำหรับวิดีโอทั้งหมดที่เราสร้างขึ้น

ตอนนี้เราต้องใช้เครื่องมือสองตัว ตัวแรกคือ Sapier นี่คือ Sapier แค่คลิกที่ "set up a free account" (สมัครบัญชีฟรี) พอทำเสร็จเราก็เข้ามาตรงนี้ คลิกที่ Create แล้วก็ "New SEP" ซึ่งเหมือนกับเป็นเวิร์กโฟลว์อัตโนมัติที่เราสร้างขึ้นมา

ส่วน trigger (ตัวกระตุ้น) คือ Google Sheets ตรงนี้คุณเลือกเป็น "new sheet or update row" เป็น trigger จากนั้นก็เชื่อมต่อบัญชี Google ตรงนี้ คุณไปที่ส่วนนี้แล้วก็เพิ่มบัญชี Google ของคุณได้เลย โดยลงชื่อเข้าด้วยบัญชีเดียวกันกับที่ใช้เชื่อมต่อชีตนี้ แล้วคลิก continue จากนั้นก็เลือกชีต ซึ่งในกรณีของฉันคืออันนี้ worksheet ที่ใช้คือ "generally pause" ส่วนคอลัมน์ trigger คือ TikTok และนั่นคือสาเหตุที่เรามีชีตนี้ไว้สำหรับเขียนค่า "yes"

ดังนั้นเมื่อมันเขียนค่า yes ลงในคอลัมน์ TikTok ของชีตเรา มันก็จะกระตุ้นกระบวนการนี้ให้เผยแพร่ไปยัง TikTok

ขอวกกลับไปก่อน เพราะตอนทดสอบฉันต้องสลับมันกลับไปเป็น inactive ก่อน ฉันต้องคลิกตรงนั้นก่อน และตอนนี้ฉันจะไปที่ระบบอัตโนมัติที่ตั้งไว้ตรงนี้ แล้วเปิดใช้งานมัน เพราะฉันต้องการทดสอบแค่การเผยแพร่ไปยัง TikTok เท่านั้น ฉันไม่อยากให้มันเผยแพร่ไปยังแพลตฟอร์มอื่นด้วย เพราะฉันทดสอบส่วนนั้นไปแล้ว นั่นจึงเป็นเหตุผลที่ฉันปิดมันไว้ชั่วคราว แล้วจะเปิดใช้งานอีกครั้งทีหลังเมื่อตั้งค่า TikTok เสร็จ

เพราะตอนนี้ฉันต้องส่งข้อความอีกครั้งเป็น "publish" แล้วมันก็ควรจะไปที่ระบบนั้น และคุณก็แค่ต้องเช็คว่าทุกอย่างถูกต้อง หรือฉันต้องจับคู่ video ID ให้ตรงกัน แล้วพอฉันคลิก test มันก็จะเขียนค่า yes ลงตรงนี้ เยี่ยมมาก เพราะนี่คือสิ่งที่จำเป็นสำหรับการกระตุ้นเวิร์กโฟลว์การเผยแพร่ TikTok นี้

และตอนนี้ดูตรงนี้ มันเจอ record ใหม่ แล้วฉันต้องคลิกที่ Buffer ตรงนี้คือจุดที่คุณต้องใช้บัญชี Buffer ของคุณ จากนั้นคลิก publish แล้วตรงนี้คลิก connect TikTok เลือกบัญชี TikTok ที่คุณต้องการใช้ แล้วคุณจะเห็นว่ามันเชื่อมต่อแล้ว

ตอนนี้กลับมาที่นี่ได้ แล้วตรงนี้เลือก event เป็น "add your queue account" คุณแค่คลิก create new account แล้วมันก็จะเชื่อมต่อกับบัญชี Buffer ที่คุณลงชื่อเข้าไว้แล้ว คลิก TikTok ข้อความตรงนี้คือ caption text และวิดีโอคือ video URL ตั้งค่าแบบนี้ได้เลย จากนั้น Add to queue ซึ่งมันก็จะเพิ่มเข้าไปในแผนการเผยแพร่ของฉันตรงนี้

คุณสามารถปรับแผนการเผยแพร่ได้โดยเข้าไปตรงนี้แล้วจัดการเวลาการโพสต์ (manage posting times) แต่ด้วยเหตุผลบางอย่างคุณใช้ "share now" ไม่ได้ เพราะมันจะขึ้น error แต่ตัว Add to Queue ใช้งานได้

ดังนั้นตอนนี้ฉันคลิก test step แล้ววิดีโอที่เราสร้างไว้ก็จะถูกส่งไปที่ Buffer แล้วเผยแพร่ไปยัง TikTok ของฉัน ลองเข้าไปดูว่ามันอยู่ใน Buffer หรือยัง คุณเห็นว่ามันอยู่ตรงนี้แล้ว และมันจะถูกโพสต์ตามเวลานี้ เพราะมันถูกโหลดเข้าแผนการโพสต์ของฉันโดยอัตโนมัติ คุณเปลี่ยนเวลาเหล่านี้ได้ใช่ไหม และฉันก็คลิก publish ได้ แล้วมันก็จะถูกเผยแพร่ไปยังบัญชี TikTok ของฉัน

และนี่คือสิ่งที่ใช้ได้ผล คลิก publish ได้เลย ขอเปลี่ยนชื่อเป็น "TikTok" ก่อน แล้วก็จบเท่านี้ ด้วยขั้นตอนนี้การเผยแพร่ TikTok ของฉันก็ใช้งานได้

สิ่งที่ต้องทำอีกอย่างหนึ่งคือ ก่อนหน้านี้ตอนเราสร้างวิดีโอ คุณอาจเห็น error บางอย่าง เพราะใน JSON2Video คุณต้องอัปเกรดแพ็กเกจ ดังนั้นต้องไปที่ส่วน credits แล้วเติมเงิน จากนั้นก็ต้องซื้อแพ็กเกจแบบเสียเงิน ตอนนี้ฉันซื้อแพ็กเกจที่ให้เครดิต 7200 เครดิต ซึ่งคุณสามารถสร้างวิดีโอได้มากกว่า 700 วิดีโอด้วยแพ็กเกจนี้ จ่ายครั้งเดียวประมาณ 50 ดอลลาร์ ซึ่งใช้ได้หลายเดือน ขึ้นอยู่กับวิดีโอของคุณ แต่คุณจะพบรายละเอียดค่าใช้จ่ายแบบเจาะลึกด้านล่างวิดีโอนี้ด้วย

สิ่งสุดท้ายที่ต้องทำคือเปิดใช้งานระบบอีกครั้ง คลิก "delete all data" จากนั้นมันก็เปิดใช้งาน และตอนนี้มันเปิดใช้งานแล้ว สิ่งเดียวที่เหลือก็คือแค่คลิก ฉันสามารถเปิดทิ้งไว้บนเครื่องหรือทำบนคอมพิวเตอร์ของฉันเพื่อสร้างวิดีโอ

และตอนนี้ระบบก็จะวนกลับไปสร้างวิดีโอถัดไปต่อ และนี่คือวิธีที่คุณสามารถสร้างวิดีโอจำนวนมากได้ในเวลาอันสั้น แล้วให้มันเผยแพร่ไปยังบัญชีของคุณทั้งหมด และนี่คือการตั้งค่าที่เสร็จสมบูรณ์
