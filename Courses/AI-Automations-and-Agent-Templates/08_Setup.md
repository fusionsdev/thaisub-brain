## บทนำ
วิดีโอนี้สอนตั้งค่าระบบอัตโนมัติบน Make.com ที่สร้างหัวข้อค้นหาบน YouTube จากหัวข้อหลักของคุณ ค้นหาวิดีโอที่กำลังมาแรง สรุปเนื้อหา สร้างคำบรรยาย พากย์เสียงด้วย ElevenLabs ใช้ Pexels หาภาพพื้นหลัง สร้างวิดีโอด้วย Creatomate แล้วเผยแพร่ไปยัง LinkedIn, Instagram, Twitter, Facebook และ TikTok ผ่านอีเมล โดยบันทึกข้อมูลทั้งหมดลง Google Sheets

## คำแปลเต็ม

ขั้นตอนแรกที่ต้องทำคือตั้งค่าบัญชี Make ถ้ายังไม่มี ให้ไปที่ปุ่มด้านล่างวิดีโอนี้ คลิก Download Automation Blueprint จากนั้นคลิก Create a New Scenario คลิกที่ Import แล้วเลือก blueprint ที่ดาวน์โหลดมา มันจะถูกนำเข้าให้อัตโนมัติ

ตอนนี้ยังมีบางอย่างที่ต้องตั้งค่าเพิ่ม ไปทีละขั้นตอนกัน สิ่งแรกที่ต้องทำก่อนจะเริ่มทำงานกับระบบอัตโนมัตินี้ คือดาวน์โหลดเทมเพลต Google Sheet ที่อยู่ตรงนี้ คลิก Make a copy เพราะนี่คือที่ที่เราจะจัดการข้อมูลสำคัญทั้งหมด และมีบันทึกของโพสต์วิดีโอโซเชียลมีเดียทั้งหมด รวมถึงระบุหัวข้อคอนเทนต์ของคุณได้ และอื่น ๆ

ไปที่จุดแรกกัน ตรงนี้คือ trigger ถ้ายังไม่มีการเชื่อมต่อ ต้องตั้งค่าการเชื่อมต่อก่อน คลิก Add ต้องแน่ใจว่าบัญชี Google ที่เชื่อมต่อเป็นบัญชีเดียวกับที่ถือ Google Sheet อันนี้ ให้ไปที่รูปโปรไฟล์ คลิกที่ไอคอน แล้วจะเห็นบัญชี Google ที่ล็อกอินอยู่ ต้องแน่ใจว่าเป็นบัญชีเดียวกับที่เลือกตรงนี้ หรือถ้าจะเพิ่มบัญชีใหม่ ให้ทำการสมัครให้เสร็จ เลือกบัญชี Google ที่ต้องการสมัคร ต้องแน่ใจว่าเป็นบัญชีเดียวกับสเปรดชีตนี้

จากนั้นต้องใส่ Google Sheet เราได้มาจาก URL ส่วนนี้ ตรงนี้ เลือกอีกครั้งจนถึงจุดนี้ OK ลองอีกครั้ง จากนั้นคัดลอก แล้ววาง มันจะโหลดสเปรดชีตขึ้นมา และตอนนี้ก็ใช้งานได้แล้ว อันนี้เรียกว่า theme เรียบร้อย

ต่อไป ถ้ามีบัญชีอยู่แล้วก็แค่เลือกตรงนี้ สำหรับ Google Sheet ต้องใส่ให้ครบทุกโมดูล Google Sheets อันนี้เรียกว่า search เรียบร้อย ไม่ต้องทำอะไรเพิ่ม

ต่อไปเป็น OpenAI connection ถ้ามีการเชื่อมต่อ API อยู่แล้ว ถ้าเคยใช้โมดูล OpenAI ในระบบอื่นก็มีอยู่แล้ว ถ้ายังไม่มีคลิก Add แล้วใส่ API key ของคุณ ซึ่งผมสอนวิธีได้มาใน technical tutorials ที่แสดงวิธีขอ OpenAI API key จากนั้นกลับมาใส่ตรงนี้ คลิก Save แล้วมันจะโหลด และหน้าตาจะเป็นแบบนี้ ตรงนี้ไม่ต้องทำอะไร แค่คลิก OK

ตรงนี้ผมเลือกบัญชี Google อีกครั้ง Google Sheet ID ถูกใส่เข้าไปแล้ว คลิก OK จากนั้นต้องระบุคำค้นหา (search term) ต้องไปที่ content ระบบจะสร้างคำค้นหาและบันทึกลงใน Google Sheet ของผม คลิก OK

ต่อไปตรงนี้ไม่ต้องทำอะไร แต่ตรงนี้ต้องทำ ต้องใส่ API key จาก YouTube Google Cloud Console ผมไม่ได้สอนวิธีตั้งค่าตรงนี้ แต่จะมีบทเรียนเทคนิคที่แสดงวิธีตั้งค่า Google Cloud Console เพื่อขอ YouTube API key ซึ่งนำมาวางตรงนี้ พอได้ API แล้วคลิก OK ได้เลย

ตรงนี้ไม่ต้องทำอะไร ตัว iterator ก็ไม่ต้องทำอะไรเหมือนกัน ต้องใส่ API เดียวกันจาก YouTube แล้วคลิก OK อีกครั้ง ตรงนี้คลิก OK

ตอนนี้มาถึงโมดูลนี้ ต้องใช้ API key อีกอันจาก RapidAPI ตรงนี้มีลิงก์สำหรับขอ API key คลิกเข้าไปแล้วจะเจอ API key ถ้าต้องการความช่วยเหลือดูในบทเรียนเทคนิคที่สอนวิธีขอ API นี้ พอได้มาแล้ววางตรงนี้ คลิก OK

OpenAI อีกอัน แค่เลือกการเชื่อมต่อ OpenAI ที่มีอยู่ OK Google เลือกบัญชี ภายใน Google Sheet ของเราอีกครั้ง ตรงส่วนนี้

ตอนนี้ต้องเลือกค่าบางค่า อันแรกคือ YouTube และเพื่อให้ง่ายขึ้นลองรันมันก่อน แล้วค่อยเชื่อมโยงค่าต่าง ๆ คลิก Run บนโมดูล Google นี้ คลิก OK ลองอีกครั้ง ก่อนอื่นต้องหยุดมันก่อน เราต้องใส่หัวข้อหลักของเรา สมมติว่า digital products creation นี่ควรเป็นหัวข้อหลักของผม ตอนนี้เริ่มใหม่ได้เลย และมันควรจะรันจนถึงจุดนี้ แล้วสรุปบทถอดเสียง (transcript) เราทำแค่นี้ก็พอ แล้วหยุดมัน

ตอนนี้เห็นคำค้นหาแล้ว ระบบสร้างคำค้นหาสำหรับ YouTube แล้ว แต่ยังไม่ได้บันทึกชื่อวิดีโอ เพราะเราจะระบุกันตอนนี้ กลับไปที่ส่วนนี้ ตรงนี้ เราต้องเลือกชื่อวิดีโอ ไปที่โมดูล YouTube ที่ทำการค้นหาครั้งแรก ตรงนี้เห็น title ต้องเลือกอันนี้ เรามี description ตรงนี้ วิดีโอมาจากตัวสรุป (summarizer) นั้น จำนวนวิว (view count) มาจากตรงนี้ OK นี่คือ view count จำนวนผู้ติดตาม (subscriber count) น่าจะอยู่ด้านล่างตรงนี้ somewhere มาตรวจสอบ Channel อาจจะอยู่ตรงนี้ นั่นคือ subscriber count ส่วน publish มาจากวิดีโอ อาจจะอยู่ตรงนี้ ด้านล่าง Publish time ดี คลิก OK ตอนนี้เชื่อมต่อได้แล้ว

ตรงนี้อีกครั้งเลือกบัญชี OpenAI คลิก OK อันนี้ก็เหมือนกัน OK ตรงนี้ไม่ต้องทำอะไร Google ต้องใช้ Google Sheet ID ของเราอีกครั้ง ใส่ลงไป แล้วตรงนี้ต้องเลือก captions: choices message content สำหรับคำบรรยายเราใช้อันนี้ choices message content OK

ต่อไปเป็นโมดูล ElevenLabs ถ้าไม่เคยใช้มาก่อน ต้องสร้างใหม่ ขอ API key ดูในบทเรียนเทคนิควิธีขอ API จาก ElevenLabs พอได้แล้ววางตรงนี้ แล้วหน้าตาจะเป็นแบบนี้ ตรงนี้เลือกเสียงได้ หาเสียงได้ในบัญชี ElevenLabs ใต้หัวข้อ Voices ผมเลือกเสียงไว้แล้ว อันนี้คือเสียงที่เลือก ฟังดูได้เลยเพื่อหาเสียงที่ชอบ หรือจะเพิ่มเสียงใหม่ก็ได้ อัดเสียงตัวเองได้ พอเลือกเสียงแล้วไม่ต้องทำอะไรตรงนี้ คลิก OK

ต่อไปเป็น Google Drive ถ้ายังไม่ได้เลือกหรือเชื่อมต่อ ไปที่ Add แล้วสมัครด้วยบัญชี Google ของคุณ ต้องแน่ใจว่าเป็นบัญชีเดียวกับที่ใช้กับ Google Sheets ด้วย พอเสร็จแล้วคลิกแบบเดียวกันตรงนี้ คลิก OK

ต่อไปต้องใช้ Pexels API key เพื่อให้ได้มา ผมมีบทเรียนเทคนิคที่สอนวิธีขอ Pexels API key วางลงตรงนี้ได้เลย คลิก OK อันนี้ใช้ได้ ไม่ต้องทำอะไรตรงนี้

ต่อไปเป็น Creatomate ถ้าไม่เคยใช้มาก่อน ต้องเพิ่มการเชื่อมต่อ Creatomate ใหม่ แล้วต้องขอ API key ดูในส่วนบทเรียนเทคนิคที่สอนวิธีขอ Creatomate API key พอได้แล้วคลิก OK แล้วมันจะแสดงเทมเพลตให้เลือก นั่นคือเทมเพลตที่ตั้งค่าไว้ตรงนี้ ผมเลือกไว้แล้วสองสามอัน นี่คือเทมเพลตวิดีโอว่าวิดีโอควรมีหน้าตาแบบไหน โครงสร้างทั่วไปของวิดีโอ ผมเลือกเทมเพลตนี้ แล้วคลิก Create แล้วปรับแต่งนิดหน่อย เพื่อปรับสไตล์และการตกแต่ง ผมจะไม่ลงรายละเอียด แต่มีบทเรียนเทคนิคที่สอนวิธีสร้างเทมเพลตแบบนี้เพื่อใช้ในระบบอัตโนมัติของคุณ พอเสร็จแล้วเลือกเทมเพลตจากรายการ มันจะปรากฏขึ้น แล้วคลิก OK

ต่อไป Google Sheet อีกอัน แค่เลือกการเชื่อมต่อและใส่ Google Sheet ID จากนั้นวางลงไป เพราะตอนนี้เราจะบันทึก URL ที่ได้จาก Creatomate คลิก OK

ต่อไปเป็นแพลตฟอร์มโซเชียลมีเดีย อันแรกเลือกว่าอยากให้โพสต์ไปที่แพลตฟอร์มไหน แล้วตั้งค่าแพลตฟอร์มที่ต้องการ ถ้าต้องการก็ทำตามขั้นตอนที่ผมจะแชร์ให้ ง่ายมาก คลิก Create a connection จากนั้นระบบจะให้ลงชื่อเข้าใช้บัญชีโซเชียลมีเดีย เช่น LinkedIn แล้วทำตามขั้นตอน การเชื่อมต่อก็จะสำเร็จ

สำหรับ Twitter ต้องตั้งค่าบัญชี developer ผมจะสอนในบทเรียนเทคนิควิธีตั้งค่า พอเสร็จแล้วจะได้ API key และ secret ซึ่งต้องใช้ในโมดูลแรก ตรงนี้เห็นไหม คลิก Show แล้วกรอกข้อมูลนี้ พอตั้งค่าเสร็จไปต่อโมดูลถัดไป Twitter อีกโมดูลต้องใช้ client ID และ client secret ซึ่งก็ได้จากบัญชี developer เช่นกัน พอตั้งค่าเสร็จ นี่สำหรับ Twitter

สำหรับ Facebook ต้องไปที่ Facebook แล้วสลับบัญชี Facebook เป็นเพจของคุณ เปิดตรงนี้ คลิกที่ Facebook นั้น แล้วคลิก Settings เลื่อนลงไปที่ปุ่มที่เขียนว่า Connected accounts คลิก แล้วเชื่อมต่อบัญชี Instagram ที่ต้องการโพสต์ด้วยระบบอัตโนมัติได้ พอเสร็จแล้วคลิก Create คลิก แล้วระบบจะให้สมัครบัญชี Facebook และ Instagram จากนั้นก็เป็นกระบวนการเดียวกันกับที่ผมเชื่อมต่อไว้แล้ว ผมโชว์ให้ดูว่าหน้าตาเป็นแบบไหน แล้วเรียบร้อย ถ้ายังไม่มีก็คลิกและทำตาม แล้วคลิก OK เสร็จสิ้นการตั้งค่า

ทำแบบเดียวกันกับบัญชีอื่น คลิก Create แล้วมันจะให้สมัครบัญชี Facebook

ส่วน TikTok ตรงนี้พิเศษหน่อย เพราะถ้าต้องการเผยแพร่วิดีโอ ผมยังหาวิธีง่าย ๆ ใน Make automation ไม่เจอ มีวิธีแก้ (workaround) คือผมตั้ง Gmail และเชื่อมต่อกับบัญชีอีเมล คลิกตรงนี้ Sign up with your Gmail แล้วพิมพ์อีเมลที่ต้องการรับวิดีโอสำหรับ TikTok ของคุณ ระบบจะส่งไฟล์วิดีโอไปยังอีเมลนี้ จะใช้อีเมลอะไรก็ได้ที่ต้องการรับอีเมลนี้ แล้วอีเมลนั้นจะเป็นวิดีโอ TikTok พร้อมอัปโหลด นี่คือวิดีโอของคุณ และไฟล์จะถูกแนบมากับอีเมลนี้ จากนั้นคลิก แล้วคุณจะได้รับไฟล์วิดีโอแนบมาเป็นไฟล์

ทีนี้ลองทดสอบรันดูก่อน เพราะสิ่งสุดท้ายที่ต้องทำคือตั้งค่า trigger ว่าจะให้ระบบอัตโนมัติรันเมื่อไหร่ รันทุกวันเวลาที่กำหนด? รันเฉพาะบางวันของสัปดาห์? หรือรันเฉพาะบางวันของเดือน? ระบุได้ตรงนี้ตามเวลาที่ต้องการ แต่ก่อนตั้งค่า ถ้าตั้งให้รันวันอังคารและพฤหัสบดี แล้วสลับเป็น On จะเห็นว่ามันจะรันวันพฤหัสบดีและวันอังคาร ตามเวลาที่กำหนด และพอตั้งค่าเสร็จมันจะรันอัตโนมัติตามเวลานั้น

แต่ก่อนหน้านั้นผมแนะนำให้ทดสอบสองสามครั้งก่อน เพื่อดูว่ามีอะไรต้องปรับหรือไม่ แค่คลิก แล้วมันจะทำงาน มันจะสร้างคำค้นหาใหม่ ตรงนี้เปลี่ยนคำค้นหาได้ แล้วมันจะเปลี่ยนหัวข้อหลัก จากนั้นสร้างคำค้นหาที่แตกต่างให้คุณ แล้วมันจะค้นหาวิดีโอ YouTube ที่กำลังมาแรง บันทึกสรุปวิดีโอลงบัญชีของคุณ จากนั้นพยายามสร้างบทถอดเสียงและคำบรรยาย แล้วจะเห็นว่าอยู่ในขั้นตอนการสร้าง ดูเหมือนต้องรันอีกรอบ ลองทดสอบอีกครั้ง มันสร้างสรุปขึ้นมา ในการค้นหาครั้งถัดไปเจอวิดีโอเพิ่มอีกสองสามอัน อันนี้ถูกบันทึกไว้ วิดีโอถูกสร้างแล้ว อย่างที่เห็น ผมสร้างไปแล้ว 1100 แล้วจากนั้นก็เผยแพร่อัตโนมัติ แต่ผมจะทำแบบนี้สองสามครั้งก่อน แล้วค่อยปรับเอาต์พุต

ตรงนี้ปรับเอาต์พุตได้ เช่น ปรับบทถอดเสียงและคำบรรยาย ในการทำแบบนี้เข้าไปที่โมดูล ผมจะหยุดมันก่อน ตรงนี้คือจุดที่ transcript ถูกสร้าง ในนั้นเห็นตัวอย่างโครงสร้างของ transcript ต้องแน่ใจว่ามีห้าบรรทัดพอดี เพราะนี่คือสิ่งที่ตั้งค่าไว้ในเทมเพลต อย่างที่เห็นคือห้า ห้าบล็อกข้อความที่ปรากฏบนวิดีโอ จะขยายก็ได้ ไปที่ตรงนี้ แล้วเพิ่มข้อความอีกอัน เลือก ไปที่ Creatomate แล้วเมื่อเพิ่มบล็อกข้อความในเทมเพลต มันจะปรากฏขึ้น แล้วคุณก็จะมีข้อความ คัดลอกแล้วเปลี่ยนตัวเลขเพื่อปรับแต่งเทมเพลตแบบนั้น เช่น มีหกประโยค แต่ต้องแน่ใจว่าครอบคลุม ถ้าแก้ไขแล้วอยากให้คงไว้แบบเดิมที่มีห้าบรรทัด ก็รักษาห้าบรรทัดไว้ แต่ปรับแต่งได้ ถ้าเจอรูปแบบที่ดีกว่า ปรับตามต้องการได้ นี่คือพื้นฐานที่ใช้สร้าง transcript

และปรับแต่งคำบรรยาย (captions) ในแบบเดียวกันได้ ตรงนี้คำบรรยายค่อนข้างสั้น เปลี่ยนได้ แล้วเอาต์พุตจะเปลี่ยนตาม ต้องลองเล่นดูเล็กน้อย นี่คือสิ่งที่ปรับแต่งเอาต์พุตได้ และไม่ต้องทำอย่างอื่นเพิ่ม แล้วตั้งค่า trigger ว่าจะรันเมื่อไหร่ ตั้งให้รันทุกวันเวลาที่กำหนด หรือหลายวันต่อสัปดาห์ พอตั้งค่าเสร็จสลับเป็น On แล้วมันจะรันอัตโนมัติ สร้างโพสต์ วิดีโอ และเผยแพร่ไปยังแพลตฟอร์มที่เลือก โดยอัตโนมัติ

สิ่งเดียวที่ต้องจำไว้คือบนแผนฟรีของ Creatomate จะได้วิดีโอแค่ไม่กี่วินาที ถ้าอยากใช้วิดีโอเหล่านี้อย่างเต็มที่และได้คุณภาพสูง ควรอัปเกรดเป็นแผนถัดไปที่ 49 เหรียญ แต่ทดสอบด้วยแผนฟรีก่อนได้จนกว่าเครดิตจะหมด แล้วค่อยตัดสินใจว่าจะใช้ต่อหรือไม่
