## บทนำ

บทเรียนนี้สาธิตการใช้งานสกิล Carousel Creator ซึ่งรวมเอาความสามารถของ Nano Banana Carousel และ Scriptor เข้าด้วยกัน เพื่อสร้างคาราเซล Instagram ผ่าน Claude Code โดยเชื่อมต่อกับ Canva MCP, Nano Banana MCP และ Dropbox MCP พร้อมการสาธิตสดการสร้างคาราเซลจริงตั้งแต่เทมเพลต แก้ไขข้อความ เปลี่ยนรูปภาพ ไปจนถึงการเทรนสกิลให้เรียนรู้จากข้อผิดพลาด

## คำแปลเต็ม

ยินดีต้อนรับสู่สกิล Carousel Creator ครับ ตัวนี้โคตรเจ๋งเลย มันเป็นการรวมทุกอย่างที่เราทำกับ Nano Banana Carousel และ Scriptor เข้าด้วยกัน และสกิลนี้จะให้คุณสร้างคาราเซลด้วย Claude Code ซึ่งบ้าไปแล้ว เพราะคุณสามารถสร้างคาราเซลได้ 21 อันพร้อมกันด้วยสกิลเฉพาะตัวนี้

ผมจะพูดตรง ๆ เลยว่าคุณต้องเตรียมของสองสามอย่างสำหรับบทเรียนนี้ คุณต้องมี Canva MCP คุณต้องมีบัญชี Canva และต้องเชื่อมต่อมันผ่าน MCP ผมใส่ไว้ใน MCP library ให้คุณตั้งค่าแล้ว เช่นเดียวกับ Nano Banana MCP มันอยู่ในนั้นด้วย แล้วก็ Dropbox MCP ถ้าคุณอยากเก็บไฟล์ของคุณ ถ้าคุณใช้ Google Drive หรือที่ไหนก็ตามที่คุณเก็บไฟล์ นั่นคือที่ที่คุณจะต้องใช้มัน แล้วก็ที่ที่คุณทำงานอยู่ คุณจะต้องมี Airtable สองอันนี้จำเป็นสำหรับบทเรียนนี้ 100 เปอร์เซ็นต์

สิ่งที่สกิลนี้จะทำคือ มันจะนำคาราเซลที่มีสคริปต์แล้วที่เราสร้างไว้ มาแปลงเป็นคาราเซลจริง ซึ่งน่าตื่นเต้นมาก วิธีการทำงานคือ มันจะดึงข้อมูลจาก Scriptor แล้วสร้างสไลด์ขึ้นมา ผมจะโชว์ให้คุณดูว่ามันทำงานยังไง มันจะเอาสไลด์ทั้งหมดมาสร้างเทมเพลตให้เรา แล้วที่เหลือเราก็แค่เข้าไปแก้ไข

ผมจะบอกตรง ๆ ว่าผมไม่รู้ว่ามีใครโม้คุณหรือเปล่า แต่คุณไม่สามารถสร้างคาราเซลได้สมบูรณ์ 100% ผมไม่เคยสร้างคาราเซล 100% แล้วโพสต์เลยโดยไม่ดูมัน คุณยังต้องแก้ไขอยู่ แต่ผมจะโชว์วิธีทำคาราเซลที่ใช้งานได้จริง

ผมมีคาราเซลที่โพสต์เมื่อวานด้วยกลยุทธ์เดียวกันกับที่ผมจะโชว์ และตอนนี้มันมีคอมเมนต์เกินพันคอมเมนต์แล้ว นั่นคือลีดพันรายที่ผมสร้างในเวลาไม่ถึง 24 ชั่วโมง และน่าจะทำเงินได้แล้ววันนี้ จากการสมัครสมาชิกโดยเฉพาะจากสิ่งที่ผมจะโชว์คุณ มันโคตรเหลือเชื่อ เริ่มกันเลย

อย่างแรก เราจะเปิดไฟล์ที่เราทำงานอยู่ แล้วเราจะรัน Carousel Creator ระหว่างที่มันทำงาน ผมจะเข้าไปใน Canva ขอโชว์อะไรบางอย่าง เมื่อคุณเชื่อมต่อ Canva MCP เข้ากับ Carousel มีข้อจำกัดบางอย่างที่คุณต้องรู้ Claude Code ไม่สามารถผ่าน MCP เข้าไปสร้างคาราเซลใหม่ใน Canva ได้โดยตรง ใช่ไหมครับ? ซึ่งนั่นคือปัญหา เพราะผลลัพธ์มันออกมาแบบนี้

สิ่งที่มันทำคือ มันเอาคาราเซลเทมเพลตที่ Canva มี มาสร้างใหม่ ซึ่งมันค่อนข้างห่วย สิ่งที่เราต้องทำคือ ถ้าคุณมีเทมเพลตคาราเซลที่คุณชอบมาก ผมแนะนำให้ทำแบบนั้น ผมแนะนำให้คุณสร้างคาราเซลที่คุณชอบ แล้วทำเป็นเทมเพลต ตัวอย่างเช่น นี่คือเทมเพลตคาราเซลที่ผมออกแบบไว้ อันนี้ที่ผมชอบ อันนี้ยังไม่มีรูปภาพทั้งหมดที่ผมต้องการ ผมจะใช้อันนี้ เราไปเทมเพลตหนึ่ง เทมเพลตสอง เราจะทำแบบนี้

คุณต้องหาเทมเพลตที่คุณชอบ นี่คือเทมเพลตที่ผมชอบ อันนี้เหมาะกับสิ่งที่เรากำลังทำ สี่สกิล Claude Code วันนี้ อันนี้ตรงกับโครงสร้างที่ผมต้องการเป๊ะ ผมจะตั้งชื่อมันว่า Claude Skill Drop Template โอเค และสิ่งที่เกิดขึ้นคือ Claude จะใช้เทมเพลตนี้ เปลี่ยนรูปภาพและทุกอย่าง มันจะสลับสิ่งต่าง ๆ ออก

คุณต้องสร้างเวอร์ชันแบบเทมเพลตของสิ่งที่คุณต้องการ พื้นหลังของผมเหมือนเดิม เรามีรูปภาพตรงนี้ ไปเรื่อย ๆ แล้วก็รูปภาพ และทั้งหมดนี้คือสิ่งที่ MCP จะทำ คือแค่สลับสิ่งต่าง ๆ ออกไป แค่นั้นเอง ซึ่งเจ๋งมากและ scalable มาก เพราะสิ่งที่เกิดขึ้นได้คือ เดี๋ยวผมจะโชว์ในคอร์ส Carousel ที่จะปล่อยที่นี่ ผมจะสร้างคาราเซลเจ็ดหรือสิบอัน ใช่ไหมครับ? ที่ผมต้องทำคือกด duplicate แล้วส่งลิงก์ทั้งหมดให้ Claude แล้วบอกว่า "ผมมีเจ็ดอัน ผมอยากให้คุณเขียนคาราเซลทั้งหมดนี้และสร้างรูปภาพทั้งหมดให้มัน แล้ววางไว้ทั้งหมด" จากนั้นผมก็แค่เข้าไปแก้แต่ละอัน แล้วเสร็จภายในวันเดียว ซึ่งบ้าไปแล้ว

เราจะสร้างสิ่งนั้นกัน และผมยังมีไลบรารีคอนเทนต์ทั้งหมดตั้งไว้แล้ว ผมมีครีเอทีฟแอสเซ็ตมากมายที่สร้างด้วย Nano Banana เพื่อสลับเข้าและออก ซึ่งตอนนี้ผมยังไม่ต้องการมัน เดี๋ยวผมลบออกก่อน ดูสิ บูม บูม การเก็บของให้เป็นระเบียบสำคัญมาก เดี๋ยวค่อยทำทีหลัง แต่ผมมีรูปภาพมากมายที่ใช้ส่วนตัว

ที่จริงผมจะปล่อยทั้งหมดนี้ให้คุณด้วยเมื่อผมสร้างคอร์สนั้นสัปดาห์หน้า ดังนั้นคอยดูไว้ด้วย แต่ผมมีไอคอนครีเอทีฟทั้งหมดที่ต้องใช้สลับเข้าและออก แต่สิ่งที่ผมออกแบบไว้ในสกิลคือ ถ้าคุณไม่มีแอสเซ็ตบางอย่างที่ผมต้องการเฉพาะสำหรับสกิลนี้ มันจะสร้างขึ้นมาเองด้วย Nano Banana แล้วแทรกภาพให้ผม คุณจะเห็นว่ามันทำงานยังไง

ดูสิ เรารันสกิลแล้ว ผมมี record ตรงนี้ "สกิล Claude สี่ตัวที่สร้างคาราเซลให้คุณ" นี่คือรูปภาพทั้งหมด บูม เจ๋ง แค่นั้น เราทำไปแล้วเมื่อบทเรียนที่แล้ว ทุกอย่างโอเคสำหรับเรา ผมจะโชว์วิธีตั้งค่าพวกมัน

สำหรับ CTA ผมอยากให้เป็น "comment paid" เพราะนี่สำหรับสมาชิกพรีเมียมของผม นี่สำหรับคอมมูนิตี้ ผมอยากให้คนรู้ว่านี่ไม่ฟรี ดังนั้นมันอาจเป็น "comment paid แล้วผมจะส่งสิทธิ์เข้าคอมมูนิตี้ให้" แล้วใส่ในวงเล็บว่า "อันนี้ไม่ฟรี" เพื่อไม่ให้มีคนขอฟรี ดูว่ามันแก้ไขให้ไหม แล้วผมไม่ต้องทำเองด้วยซ้ำ ผมทำบนมือถือได้ พูดตรง ๆ

มันบอกว่า "ต้องการสี่อย่างนี้ใช่ไหม? comment แล้วผมจะส่งสิทธิ์เข้าคอมมูนิตี้ให้ ไม่ฟรี" ดูดีมาก มาสร้างกัน ตรงนี้ โอเค ตอนนี้สิ่งที่ผมจะทำคือวางเทมเพลต Canva นี้ และผมตั้งโปรแกรมไว้ให้บันทึกทุกอย่าง ถ้าผมเข้าไปดู ผมควรมีโฟลเดอร์คาราเซล ทุกครั้งที่ผมสร้างคาราเซล ที่จริงผมสร้างเครื่องมือ Twitter ด้วย ซึ่งจะโชว์ในคอร์สเต็ม แต่มันจะเก็บคาราเซลทุกอันที่ผมสร้าง ซึ่งเจ๋งมาก คุณเห็น "ห้าสกิล Claude Code" ไว้ ทุกครั้งที่คุณเขียนทับมันก็ไม่เป็นไร เพราะมันบันทึกไว้ก่อนแล้ว

ดูสิ เริ่ม editing transaction "แก้ไขคาราเซล สลับข้อความทั้งหมดบนเจ็ดสไลด์" มันกำลังแก้ไข มีเครื่องมือหลายอย่างที่มันให้ ผมค่อนข้างแน่ใจว่าผมอธิบายไว้ในคอร์สแล้ว มันจะสลับข้อความ สร้างสิ่งต่าง ๆ และลบสิ่งที่ไม่ต้องการ ซึ่งง่ายมาก ฉันเพิ่งได้ยินเสียง โอเค มันกำลังมา เราจะดูมัน ดูว่ามีอะไรเปลี่ยนยัง ไม่ ยังไม่ได้ deploy การเปลี่ยนแปลง มันยังเรียกอยู่ เราจะปล่อยให้มันทำงาน เจ๋ง

มันบอกว่าเสร็จแล้ว มาดูว่ามันทำอะไร "สี่สกิล Claude ประโยคข้อดี" ดูเหมือนมันยังไม่ได้ push ไปที่ Canva ใช่ ใช่ "push ไปที่ Canva" โอเค และมันบอกว่าเราต้องลบหน้า 6 ผมจะปล่อยให้มันทำ เห็นไหม? มันสลับออกแล้ว เยี่ยม มันสลับแล้ว สลับทุกอย่างออก "Carousel Ideator" มันเข้าไปสลับทั้งหมดนี้ให้เรา "comment แล้วผมจะส่งสิทธิ์เข้าคอมมูนิตี้ให้ อันนี้ไม่ฟรี" โคตรเจ๋ง และผมลบอันนี้ได้เพราะมันบอกให้ลบ

ตอนนี้เปิดมันตรงนี้ "ลบเทอม แล้วสร้างการ์ดเทอร์มินัลใหม่สำหรับสไลด์สองถึงห้า แล้วสร้างรูปภาพและ push ไปที่ Canva" เราสลับข้อความทั้งหมดแล้ว สิ่งที่มันจะทำคือ ผมสร้างไว้แล้ว เพราะมันเป็นคาราเซลสำเร็จรูป ผมเคยสร้างสไลด์หน้าตาแบบเทอร์มินัลไว้แล้ว เห็นไหมว่ามันเหมือนกันทุกอัน? ผมมีหน้าตาที่ต้องการแล้ว ผมสร้างมันใน Nano Banana ด้วย Claude Code และทุกครั้งที่มันสร้างรูปภาพใหม่ มันจะอ้างอิงภาพนั้นแล้วแก้ไขใน Nano Banana

Nano Banana มีฟีเจอร์ที่คุณสามารถอัปโหลดรูปภาพ แล้วแก้ไขมันแทนการสร้างใหม่ทั้งหมด ซึ่งทำให้เกิดความไม่สม่ำเสมอ เมื่อคุณพบรูปภาพที่ชอบ คุณก็ใช้มันต่อได้ เราจะใช้แบบนั้นวันนี้ ปล่อยให้มันทำงาน มันจะเข้าไปหาไฟล์ของเรา แล้วสร้างการ์ดเทอร์มินัลและป้าย paid แล้วคุณจะเห็นมันสลับคีย์เวิร์ดจริง ซึ่งเจ๋งมาก

เราจะปล่อยให้มันทำงาน และระหว่างนั้นมีสิ่งสำคัญที่คุณต้องเห็น มันเข้ามาแล้วไม่สมบูรณ์แบบ มีระดับที่คุณต้องแก้ไขเสมอ ใช่ไหมครับ? ตอนนี้มันสร้างทุกอย่างให้ผมแล้ว สิ่งที่ผมต้องทำคือเข้ามาปรับว่าผมอยากให้มันเป็นแบบไหน เราจะทำแบบนี้: "สี่สกิล Claude ที่สร้างคาราเซลเพื่อการวิเคราะห์คาราเซล" ผมจะจัดกึ่งกลาง "ขโมยแพตเทิร์นคาราเซลที่ชนะของคู่แข่ง พวกเขาไม่เดา" มันควรจะถูกสลับออก "Carousel Ideator เลือกหัวข้อคาราเซลไวรัลอันถัดไปของคุณ ด้วยข้อมูลจริง" เลือกของคุณ ดูว่ามันทำงานยังไง มันยังทำงานอยู่

"เลือกหัวข้อคาราเซลไวรัลถัดไปของคุณด้วยข้อมูลจริง" ผมอยากได้แบบนี้ "ขโมย" ใช่ไหม? "แพตเทิร์นคาราเซลที่ชนะของคู่แข่งเพื่อลอกเลียน" ผมอยากทำให้คนโมโห ผู้คนโมโหเวลาคุณลอกเลียนพวกเขา "เราไม่ได้ลอก เราทำให้ดีกว่า" "Carousel Ideator เลือกหัวข้อคาราเซลไวรัลถัดไปของคุณ ด้วยข้อมูลจริง" ผมชอบ "ใช้ข้อมูลคู่แข่งบวกข้อมูลของคุณสร้างคาราเซลไวรัล"

สะกดคาราเซลยังไงนะ C-A-R-O-U-S-E-L ผมแค่อยากดึงมันขึ้นมาหน่อย ดูว่ามันทำอะไรอยู่ มันยังสร้างรูปภาพอยู่ ซึ่งเจ๋ง แล้วผมก็เข้าไป ผมไม่ชอบหน้าตามัน ผมจะ backspace "ให้คาราเซล" ดูเหมือนต้องปรับนิดหน่อย เอาล่ะ "Carousel ทุกสไลด์สำหรับพาดหัว แล้ว Carousel Creator เอาสคริปต์มาออกแบบคาราเซลทั้งหมดให้คุณใน Canva" "คาราเซลนี้สร้างด้วย" เราไม่ต้องไปไกลขนาดนั้น พูดตรง ๆ เจ๋ง
