## บทนำ

วิดีโอนี้เป็นวอล์กทรูวิธีเข้าถึง Skills และ MCP Library ทั้งหมดที่ผู้สอนแจกให้ในคอร์ส — ตัวคลังเป็น Google Sheet พร้อม Google Drive ที่เก็บไฟล์สกิลเป็น zip แยกตามหมวด ผู้สอนแนะนำวิธีค้นหาสกิลด้วย Ctrl+F และย้ำว่าต้องเรียนคอร์สพื้นฐานก่อนใช้

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่ Skills และ MCP Library ครับ ในวิดีโอสั้นๆ นี้ ผมจะพาวอล์กทรูวิธีเข้าถึงสกิลทั้งหมดที่ผมให้คุณ และ MCP servers ทั้งหมดที่ผมให้คุณด้วย

และถ้าคุณไม่รู้ว่ามันคืออะไร หรือไม่เข้าใจที่ผมพูดไปเมื่อกี้ แสดงว่าคุณมาไกลเกินไปแล้ว ขอให้กลับเข้าไปในคอมมูนิตี้ แล้วไปดูคอร์ส Claude Mastery และคอร์ส Claude Code for Dummies ก่อน มันสำคัญมากที่คุณต้องไปดูสองคอร์สนี้ เพื่อให้คล่องกับ Claude skills และ MCP และเข้าใจว่ามันทำงานยังไง และเอาไปใช้อะไร

แล้วค่อยมาดาวน์โหลด ผมรู้ว่ามันน่าดึงดูดมากที่อยากได้ของพวกนี้ทันทีและอยากเริ่มใช้ แต่ไม่มีประโยชน์อะไรที่ผมจะให้เครื่องมือสุดทรงพลังกับคุณ ถ้าคุณยังเป็นเด็กหัดเดินและไม่รู้วิธีใช้มัน เพราะฉะนั้นไปดูสองคอร์สนั้นก่อน แล้วคุณจะเข้าใจวิธีใช้มันอย่างลึกซึ้งขึ้น

วิธีใช้คือ คุณมีคู่มือติดตั้งสำหรับ Claude Desktop และ Claude Code ขอให้ไปดูวิดีโอคู่มือตามที่คุณใช้ ถ้าคุณใช้ Claude Desktop แบบแชทโดยเฉพาะ ไปดูอันนี้ ถ้าคุณใช้ Claude Code ในเทอร์มินัลหรืออะไรก็ตาม ไปดูอันนี้ แล้วผมจะโชว์วิธีโหลดสกิลและ MCP ลงอุปกรณ์ของคุณ

แต่ตัวคลังทำงานยังไง? ง่ายมาก แค่เข้าไป มันคือ Google Sheet และผมยังให้ Google Drive ไว้ให้คุณเข้าไปดูได้ด้วย มันจัดหมวดหมู่ไว้แล้ว และในแต่ละหมวดมี zip ข้างในแต่ละ zip ก็จะมีไฟล์ Skill MD เฉพาะตัว กับไฟล์อ้างอิงต่างๆ ที่จำเป็นสำหรับสกิลนั้นๆ

แต่ผมให้ตัวคลังจริงๆ ไว้ที่นี่ให้คุณคลิกเข้าไปดูได้ และสิ่งที่เจ๋งมากคือ ผมใส่ลิงก์ดาวน์โหลดไว้ในคำอธิบายและในชื่อด้วย สิ่งที่คุณทำได้คือ เข้ามา กด Ctrl+F แล้วค้นหาได้เลย ถ้าผมหาเกี่ยวกับโฆษณา (ad) ผมก็แค่พิมพ์คำว่า ad แล้วก็เห็นสกิลสายเอเจนซี่ทั้งหมดของผม สมมติว่าผมหาสกิลช่วงเช้า (morning skill) ที่ผมพูดถึงบ่อยๆ มันก็มีอยู่สามอัน แล้วคุณเข้ามา พิมพ์ morning แล้วมันก็มีคำอธิบายและทุกอย่างให้ดู

เพราะฉะนั้นคุณค้นหาสิ่งที่ต้องการได้เลย ลองไล่ดูได้ มันอ่านง่ายมาก ไม่ได้ยุ่งยากอะไร และทุกอย่างอยู่ในนี้เรื่อยๆ ไป และเมื่อไหร่ที่ผมอัปเดตอะไร ผมจะประกาศให้พวกคุณรู้ในคอมมูนิตี้เสมอ เราจะเพิ่ม ลบ และอัปเดตสกิลและ MCP libraries ในนี้ตลอดเวลา

จบเท่านี้สำหรับวิดีโอนี้ครับทุกคน บอกผมในคอมมูนิตี้ได้เลยถ้ามีคำถามอะไร แล้วผมจะตอบให้เร็วที่สุด
