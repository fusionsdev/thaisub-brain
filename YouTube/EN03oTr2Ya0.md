## ประเด็นหลัก
- Sakana AI ปล่อยอัปเดตครั้งใหญ่ให้ Sakana Chat แชท AI ฟรีที่ไม่ต้องใช้ API key
- มีการเปลี่ยนแปลง 4 อย่างในครั้งเดียว คือ เพิ่มโมเดลใหม่ รุ่นอัปเกรดโมเดลเดิม เพิ่มความสามารถรันโค้ดได้เอง และรองรับการอัปโหลดรูปภาพ/เอกสาร
- ผู้พูดทดสอบจริงโดยไม่ล็อกอิน ใช้โมเดล Namazu ขอให้สร้างเกมเรียนภาษาญี่ปุ่น 3 ระดับความยาก ได้เกมที่เล่นได้จริงครบทั้ง landing page แบบทดสอบ การนับคะแนนและสตรีค
- Sakana Namazu อัปเกรดเป็นเจนเนอเรชันใหม่ เก่งขึ้นด้านคุณภาพการตอบภาษาญี่ปุ่น และความสามารถทำงานเป็น agent ลงมือปฏิบัติจริงได้
- Sakana Fugu คือโมเดลใหม่อีกตัว เป็น orchestrator model ที่ทำผลงานเทียบเท่าโมเดลระดับแนวหน้า เหมาะกับงานซับซ้อนหลายขั้นตอน
- หัวใจของอัปเดตคือการรันโค้ดใน sandbox ภายในแชท โมเดลรัน Python คำนวณ ประมวลผล และสร้างไฟล์จริง เช่น HTML Word หรือสไลด์ โดยแสดงผลในพาเนลด้านขวาให้เห็นทันที
- วงจรทำงานเปลี่ยนจาก "ได้โค้ดไปรันเอง แก้ error เอง" เป็น "ถาม สร้าง ดู ปรับ" ในเธรดเดียวจบโดยไม่ต้องออกจากแชท
- ตัวอย่างเพิ่มเติม เช่น แนบไฟล์ Excel ให้รวมข้อมูลรายไตรมาสแล้วสร้างแผนภูมิ หรือเอา PDF เอกสารประชุมมาสร้างสไลด์ โดยไม่ต้องสลับเครื่องมือ
- รองรับการแนบรูปภาพและเอกสารในทุกโมเดล เช่น ถามเรื่อง screenshot ข้อความ error หรือ PDF
- อัปเดตนี้ไม่ใช่การเพิ่ม context window หรือหน่วยความจำ แต่คือการเปลี่ยนความสามารถของเครื่องมือจาก "โมเดลที่พูดได้" เป็น "โมเดลที่ทำงานได้"
- การเลือกโมเดลให้ตรงงานสำคัญพอๆ กับตัวโค้ด คือ Fugu สำหรับงานซับซ้อน Namazu สำหรับงานซ้ำๆ โดยเฉพาะงานที่ใช้ภาษาญี่ปุ่น
- ท้ายวิดีโอโปรโมต AI Success Lab และ AI Profit Boardroom พร้อมชวนลองใช้ Sakana Chat ฟรีด้วยตัวเอง
