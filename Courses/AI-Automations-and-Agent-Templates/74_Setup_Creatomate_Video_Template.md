## บทนำ
วิดีโอสอนวิธีสร้างเทมเพลตวิดีโอ (template) ใน Creatomate ตั้งแต่เริ่มต้นสำหรับใช้กับระบบโซเชียลมีเดียอัตโนมัติ ประกอบด้วยการเพิ่มองค์ประกอบวิดีโอ เสียงพากย์ ตัวยึดตำแหน่งข้อความ (text placeholder) ห้าตำแหน่ง จัดเรียงตำแหน่งและเวลาการแสดงผล และตั้งค่าให้เป็นแบบ dynamic เพื่อรับค่าจาก AI automation

## คำแปลเต็ม

เราต้องการ template ID ตรงนี้มันจะแสดงเทมเพลตทั้งหมดที่เราสร้างไว้แล้ว เทมเพลตเหล่านี้คือสิ่งที่เราต้องใช้สำหรับวิดีโอของเรา จำเป็นต้องปรับให้เข้ากับระบบโซเชียลมีเดียอัตโนมัติของเรา ฉันจะสร้างเทมเพลตใหม่จากศูนย์ ฉันต้องการใช้ Video Template แบบเว็บ

ในเทมเพลตของเรา เราต้องการองค์ประกอบสองสามอย่าง อันแรกคือวิดีโอ เราก็แค่คลิกที่วิดีโอแล้วลากให้เต็มหน้าจอ และทำแบบเดียวกันตรงนี้ ลากให้เต็มพื้นที่ จากนั้นเราต้องการเครื่องมือเสียง (audio) อันนี้จะเป็นเสียงพากย์ (voiceover) ของเรา ต่อไปเราต้องการตัวยึดตำแหน่งข้อความห้าตำแหน่ง อันนี้จะเป็น text 1 ของเรา จากนั้นก็ทำแบบเดียวกัน มาคัดลอกแล้ววาง วาง วางอีกสี่ครั้ง จากนั้นเปลี่ยนชื่อเป็น two, three เพราะบทพูด (transcript) ของเรามีความยาวห้าประโยคเสมอ อีกครั้ง ลากมันลงมาตรงนี้ นี่คือข้อความทั้งหมดที่เรามี

ตอนนี้เราต้องแน่ใจว่าพวกมันถูกจัดวางอย่างเหมาะสม อันนี้จะเป็น text number 2 ควรจะปรากฏตรงตำแหน่งนี้ text number 3 ควรปรากฏตรงนี้ และฉันยังจัดเรียงได้อีก คุณสามารถกำหนดได้ว่าข้อความจะปรากฏเมื่อไหร่ โดยปกติฉันจะให้ห่างกันประมาณ 3-4 วินาที ซึ่งฉันตั้งค่าได้ตรงนี้ ตรงนี้คือ 3 วินาที และเมื่อครบเวลา ข้อความแรกทั้งหมดก็จะหายไป จากนั้นฉันจะใช้ text ถัดไป ซึ่งจะปรากฏขึ้นหลังจากนั้น และกลับขึ้นไปอยู่ด้านบนอีกครั้ง จากนั้นเราก็มี text ถัดไป มาทำให้มันปรากฏตรงบริเวณนี้ก่อน

ตอนนี้เราได้มาไกลขนาดนี้แล้ว เราต้องแน่ใจว่าวิดีโอและเสียงมีความยาวเต็มคลิป อันที่ต้องลบออก เราต้องเลือกทุก ๆ อัน แล้วตั้งค่าให้เป็น dynamic เพราะข้อความจริง ๆ มาจากระบบ AI automation ของเรา เราทำแบบนี้กับทุกอัน ลบข้อความ placeholder ออก แล้วตั้งเป็น dynamic ลบ placeholder ตั้งเป็น dynamic ตอนนี้มันเรียกว่า blank โอเค นี่คือวิธีตั้งค่า

เมื่อคุณสร้างวิดีโอสองสามอันด้วยระบบของเราแล้ว คุณก็สามารถปรับแต่งเพิ่มเติมได้ แม้กระทั่งสไตล์ฟอนต์และอื่น ๆ ตอนนี้ฉันทำไปแล้ว ขอกลับไปที่เทมเพลตของฉัน ฉันจะให้ดูว่าฉันทำอะไรไว้ นี่คือเทมเพลตของฉัน ฉันตั้งค่าแบบนี้ และเมื่อเทมเพลตของฉันพร้อม ฉันก็สามารถเลือกเทมเพลตที่ต้องการใช้ได้ ในกรณีของฉันคือเทมเพลต storytelling ซึ่งฉันตั้งค่าในแบบเดียวกันกับที่เพิ่งโชว์ให้ดู เพียงแค่ปรับแต่งเล็กน้อย
