## ประเด็นหลัก
- แนะนำโมเดล AI ตัวใหม่ที่ใช้ฟรีได้ในตอนนี้ ชื่อในคำบรรยายอัตโนมัติปรากฏหลายแบบ เช่น Longat 2.0 / Long Cat 2.0 / Lancat 2.0 (ชื่อจริงอาจเป็นโมเดลขนาดใหญ่ตัวใหม่ที่เพิ่งเปิดตัว) สร้างโดยทีม Mawan Longat
- โมเดลนี้เป็นแบบ mixture of experts มีพารามิเตอร์ถึง 1.6 ล้านล้านตัว แต่เปิดใช้งานครั้งละประมาณ 4.8 หมื่นล้านตัวเท่านั้น จึงใหญ่แต่ยังเร็ว
- มีหน่วยความจำสูงสุด 1 ล้าน token หมายถึงอ่านโปรเจกต์ทั้งโปรเจกต์ ทุกไฟล์ ทุกโฟลเดอร์พร้อมกัน โดยไม่ลืมงานก่อนหน้า
- โมเดลเสียบเข้ากับ Hermes ได้โดยตรง ซึ่งเป็นเครื่องยนต์ที่ขับเคลื่อนระบบ Agent OS ทั้งหมดของช่อง
- สาธิตสด: พูดว่า Apollo เพื่อปลุกผู้ช่วยเสียง Hermes Apollo พูดสั่ง "สร้างเกมงู" แล้วมันเขียนโค้ดให้จริง ๆ และบันทึกผลงานทั้งหมดไว้
- ทำคะแนน 70.8 ในการทดสอบเขียนโค้ด Terminal Bench ซึ่งสูงกว่าโมเดลใหม่ล่าสุดตัวหนึ่งของ Google และเป็นโมเดลโอเพนที่สร้างมาเพื่องาน agent โดยเฉพาะ
