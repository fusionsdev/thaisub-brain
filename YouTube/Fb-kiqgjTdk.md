# สรุป: Hermes Desktop HUD Mode: An Agent Buddy For Any App

- **ช่อง:** Tonbi's AI Garage · **ความยาว:** ~17 นาที · **ลิงก์:** https://www.youtube.com/watch?v=Fb-kiqgjTdk

## ประเด็นหลัก

- โหมด HUD ของ Hermes บนเดสก์ท็อปคือวิดเจ็ตโปร่งแสงเล็กๆ ที่ลอยอยู่เหนือหน้าจอ ช่วยให้ถามคำถาม AI โดยอิงบริบทของแอป/หน้าต่างที่เปิดอยู่ข้างใต้ได้โดยไม่ต้องสลับหน้าต่าง
- เปิดใช้งานได้ผ่าน settings → keyboard shortcuts → toggle HUD mode (สำหรับผู้พูดคือ Ctrl+Shift+H แล้วแต่ระบบปฏิบัติการ) การสลับเข้า-ออกใช้เวลาเพียงเสี้ยววินาที
- composer ในโหมด HUD เหมือนกับเวอร์ชันเดสก์ท็อปทุกอย่าง — เปลี่ยนโมเดลได้ ใช้ voice dictation, wake word, บทสนทนาด้วยเสียง และแนบไฟล์ได้ แต่หน้าจอคำตอบเล็ก จึงไม่เหมาะกับคำตอบยาวๆ
- ทดสอบกับโพสต์บน X (อ่านเนื้อหาโพสต์ของ Brooklyn และสรุปให้ได้) และอ่านคลิปวิดีโอที่ฝังอยู่ได้ด้วย (เห็น Hermie ลอยเหนือ Figma)
- อ่านกราฟหุ้น Nvidia ใน TradingView ได้และวิเคราะห์ fair value gaps (FVG) จากแท่งเทียนได้ โดยตอบว่า "Clearly active bullish at FVGs"
- ควบคุม Clipchamp ให้สร้างวิดีโอใหม่และนำเข้าไฟล์ล่าสุดจากโฟลเดอร์ raw ได้ผ่าน computer use โดยไม่ต้องมี MCP หรือการเชื่อมต่อพิเศษใดๆ
- ควบคุม Spotify ได้ (เปลี่ยนจาก "Clint Eastwood" เป็น "Feel Good Inc." ของ Gorillaz) และตอบคำถามทั่วไปเกี่ยวกับศิลปินได้
- บน Steam มันหลุดจากคำถามหลอก (ถามเกมที่เล่นปีนี้ แต่รู้ว่าปีนี้ยังไม่ได้เล่น และปีปัจจุบันคือ 2026) พร้อมอ่านข้อมูลเกมปีที่แล้ว เช่น XCOM 2
- ใช้เป็น "agent สำรอง" ได้ — ขณะ SSH อยู่ใน DGX Spark ที่รัน DeepSeek (โมเดลที่ไม่มีฟีเจอร์ภาพ) ก็ถามให้สรุปงานบนหน้าจอหรือตรวจทานงานได้ในเซสชันแยกและโมเดลคนละตัว
- ข้อจำกัดสำคัญ: ต้องบอกให้มันรู้เมื่อเปลี่ยนแอป (เช่น "ตอนนี้ผมอยู่บนอะไร?") เพราะมันจะไม่ตรวจจับการเปลี่ยนแปลงเองโดยอัตโนมัติ แต่การสลับระหว่างแอปใช้เวลาตอบเพียง ~20 วินาที ไม่ต้องรีสตาร์ทหรือตั้งค่าอะไร

## ความเห็นสรุป

โหมด HUD เป็นฟีเจอร์ที่มีประโยชน์จริงสำหรับการใช้งานแบบ "มีตัวช่วย AI คอยอยู่ข้างๆ" ใช้ถามคำถามเกี่ยวกับสิ่งที่เห็นบนหน้าจอ หรือใช้เป็น agent ตัวที่สองช่วยตรวจทานงานได้ โดยไม่ต้องพึ่งการผสานรวมกับแอปเฉพาะใดๆ เพราะอาศัยการอ่านหน้าจอและ computer use เป็นหลัก ข้อควรจำคือต้องคอยบอกมันเมื่อเปลี่ยนบริบทการใช้งาน เพื่อให้ได้คำตอบที่แม่นยำ
