## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่บทเรียนสกิล n8n ครับ ในบทนี้ผมจะโชว์วิธีเชื่อมต่อ Claude Code เข้ากับ n8n เพื่อให้มันสร้างเวิร์กโฟลว์ทั้งหมดให้คุณเอง

มันสำคัญที่พวกคุณต้องเข้าใจ และสำคัญที่คุณต้องเรียนทั้งคอร์สนี้ว่าแต่ละ node ทำงานยังไง เพราะ Claude Code จะเก่งกว่าคุณในการสร้างเวิร์กโฟลว์ n8n แบบ end-to-end แต่ถ้าคุณไม่เข้าใจว่ามันกำลังสร้างอะไร และไม่เข้าใจว่ามันทำอะไร เพราะบางครั้งมันสร้างเกินจำเป็น ถ้าคุณไม่เข้าใจ n8n ดีพอ มันจะดูเหมือนว่ามันทำงานเยอะมาก ทั้งที่จริงมันทำน้อยมาก และมันอาจสร้างภาระปวดหัวให้คุณในระยะยาว เพราะมันสร้างเกินจำเป็น

วันนี้เราจะติดตั้งสกิลกัน ผมจะโชว์ให้เห็นว่ามันทำงานยังไงแบบเรียลไทม์ แล้วต่อไป ผมต้องการให้พวกคุณเรียนทั้งคอร์สนี้ และอย่าพึ่งแค่ Claude Code สร้างเวิร์กโฟลว์ให้คุณ เพราะถ้ามันสร้างให้ แล้วคุณไม่รู้วิธีดีบั๊กมันเลย คุณไม่รู้วิธีประกอบมันกลับเข้าไปใหม่ คุณไม่รู้ว่ามันทำอะไรไปบ้าง

เริ่มกันเลย อย่างแรก ผมให้แพ็กเกจสกิล n8n ไว้แล้ว แค่คลิกแล้วดาวน์โหลด zip พอได้แล้วก็ลากมันลงไปใน Claude Code และเช่นเดียวกันกับ n8n MCP server คุณดาวน์โหลด MCP server ได้ด้วย MCP server ก็คือไฟล์ที่เป็น MCP นั่นแหละ

ขอผมโชว์โครงสร้างของมันให้ดูหน่อย เปิดด้วย Cursor แล้วพวกคุณมีไฟล์เหล่านี้อยู่แล้ว ถ้าคุณเข้าไปดาวน์โหลดในคอมมูนิตี้ และเข้าไปที่ start here ผมให้ทรัพยากรทั้งหมดไว้แล้ว คุณมี end-to-end และ MCP เตรียมไว้ให้แล้ว ถ้าคุณยังไม่ได้ดาวน์โหลด กรุณาไปดาวน์โหลด มันมีค่ามาก

ดาวน์โหลดสองอย่างนี้ แล้วคุณก็จะมี MCP server MCP server นี้ก็คือวิธีที่คุณเชื่อมต่อกับ Claude Code ทุกครั้งที่ Claude Code อยากคุยกับ n8n มันจะผ่านไฟล์ .env ของคุณ แล้วหาค่า API key ของคุณ แล้วมันจะเรียกไปที่ n8n — มันเหมือนกุญแจไข n8n แล้วเมื่อ n8n ปลดล็อกแล้ว คุณก็จะได้สิทธิ์เข้าถึง

การสร้าง API key ก็ง่ายมาก สิ่งที่คุณต้องทำคือไปที่ workflows แล้วเปิดตรงนี้ แล้วเข้าไปที่ n8n API แล้วสร้าง tokens ผมมีหลาย tokens ตรงนี้ คุณแค่คลิก create API key ตั้งชื่อมันว่า Claude Code หรืออะไรก็ได้ ตั้งวันหมดอายุได้ แล้วมันก็จะหมดอายุเอง ผมไม่ค่อยตั้งนะ เว้นแต่กลัวคนแฮก แต่ก็พยายามรักษาความปลอดภัยไว้ แล้วมันจะเลือกทั้งหมดให้อัตโนมัติ เว้นแต่คุณมีแพ็กเกจสูงกว่า แล้วคุณก็แค่ save คัดลอก แล้วก็เข้ามาตรงนี้ วางลงไป ปัง!

แล้วคุณต้องใส่ instance ของคุณ instance ของคุณก็คือตรงนี้ เห็นไหม? มันกำลังหาค่า instance app.n8n.cloud ของคุณ คุณแค่เปลี่ยนเป็นของผมที่ชื่อว่า Noah automates แล้วคุณก็เข้ามาแทนที่ตรงนั้น แล้วกด save แล้วตั้งแต่นี้ไป ทุกครั้งที่ Claude Code ต้องการเข้าถึงอันนี้ มันก็จะรันได้ แต่ผมจะลบคีย์นั้นทิ้ง เพราะไม่อยากให้พวกคุณแฮกผมตลอดไป

นั่นคือวิธีเชื่อมต่อโดยประมาณ พอคุณมีสกิลจริงๆ แล้ว คุณก็แค่พิมพ์คำสั่ง /n8n build configure แล้วโชว์ให้ผมเห็นภายในสกิล พร้อม reference ทั้งหมด

วิธีที่ผมสร้างมันคือ ผมให้เครื่องมือทั้งหมดที่มันต้องใช้ในการสร้าง n8n และยังต้องมี reference ด้วย มี reference หลายตัวที่มันต้องใช้ และ reference ก็คือไฟล์ที่มีสิ่งที่มันต้องดูเพื่อเข้าใจว่ามันกำลังทำอะไร ถ้าคุณไม่ให้ reference มัน คุณจะได้ผลงานห่วยๆ พูดตรงๆ

ลองดูว่ามันดึงขึ้นมาไหม โอ้ เราชน context limit แล้ว ว้าว เร็วมาก ขอผมดาวน์โหลดสกิลลงมาก่อน แล้วผมจะโชว์ให้ดู เพราะจริงๆ มีหลายตัว เห็นไหม มีหลายตัว ลองแกะ zip ดู แล้วคุณจะเห็นว่าข้างในมี reference หลายตัว มี node code เยอะแยะ โค้ด node ไปจนถึง MCP ทุกอย่างที่มันต้องใช้อ้างอิง เพื่อสร้างโฟลว์ที่สมบูรณ์แบบทุกครั้ง นั่นคือเหตุผลว่าทำไมการดาวน์โหลดอันนี้จึงสำคัญมาก

พอคุณมีสองอย่างนี้ และตั้งค่า MCP เสร็จแล้ว คุณก็สร้างโฟลว์ใหม่ได้เลย สมมติว่าผมเริ่มอันใหม่ตรงนี้ แล้วผมจะโชว์ให้เห็นว่ามันทำงานยังไงแบบสดๆ "ช่วยสร้างเวิร์กโฟลว์ n8n แบบง่ายๆ ด้วย manual trigger ที่ดึงข้อมูลทั้งหมดของผม จัดระเบียบ แล้วส่งใหม่ สร้างในนี้เลย"

แล้วเจ้าเครื่องนี้ก็จะไปอ่าน reference ทั้งหมดของมัน เมื่อผมพิมพ์ คุณสังเกตไหมว่าผมไม่ต้องพิมพ์ n8n ในคำอธิบาย มันสำคัญมาก พอผมพิมพ์ มันเห็นว่าผมกำลังสร้างเวิร์กโฟลว์ n8n ผมจะเรียกมันว่า ending เพราะมันอ่านได้ แล้วมันก็ query หาข้อมูลนั้นได้ ดูเหมือนมันกำลังดึงข้อมูล node มาให้เรา มันกำลังดึง properties ทั้งหมดที่มันต้องใช้ base node, Gmail, base base เจ๋ง แล้วมันก็ไล่ดู กำลังหาเวิร์กโฟลว์ ตอนนี้มันเริ่มทำเกินจำเป็น โอ้ มันกำลังอัปเดตโฟลว์อยู่ เจ๋ง ดูเหมือนมันได้ credential ให้ผมแล้ว คุณมี Gmail credential ที่ตั้งไว้แล้ว ถ้าพวกคุณไม่รู้วิธีตั้งค่า ผมจะลงรายละเอียดง่ายๆ ในบทหน้า มันง่ายมาก

ตอนนี้มันกำลังดึง credential แล้วมันจะสร้างเวิร์กโฟลว์เต็มรูปแบบ คิดว่ามันกำลังอัปเดตเวิร์กโฟลว์ปัจจุบันนี้อยู่ตอนนี้ แล้วคุณเห็นไหมว่ามันเขียนว่า ID ตรงนี้ เห็น ID ไหม? ID คือเลขประจำตัวของเวิร์กโฟลว์ คุณจะเห็นมันในนี้ ซึ่งเป็น ID ของเวิร์กโฟลว์เฉพาะอันนี้ ซึ่งมันไม่ฟังที่ผมเพิ่งพูดเลย แต่นี่คืออันที่จัดระเบียบและส่งใหม่ใน n8n แล้วมันให้ลิงก์มา และผมเปิดมันได้ ดูสิว่ามันสร้างไว้ที่ไหน เจ๋ง แล้วมันให้ sticky note และคำอธิบายของทุก node ซึ่งเจ๋งมาก และอีเมลสรุป

เยี่ยม "คุณสร้างเวิร์กโฟลว์ใหม่หรืออัปเดตเวิร์กโฟลว์เก่า?" เพราะเวิร์กโฟลว์เก่านั้นผมทำไว้ คุณต้องแน่ใจด้วยว่าเจ้านี่ทำตามที่มันบอกว่ามันอยากทำ ดูเหมือนมันยังดึงมันเข้ามาและทดสอบให้เราด้วยซ้ำ เพื่อตรวจสอบว่ามันสำเร็จ โอ้ มันอัปเดตโฟลว์เดิม เจ๋ง ไม่รู้ว่าทำไมผมถึงดึงมันเข้ามา

เอาล่ะ นั่นคือวิธีการทำงานของสกิล n8n ครับ มันจะสร้างเวิร์กโฟลว์ที่ทำงานได้เต็มรูปแบบให้คุณ และเราจะลงรายละเอียดมากขึ้นเรื่อยๆ และเจ๋งขึ้นเรื่อยๆ เมื่อคอร์สดำเนินไป แล้วเจอกันบทหน้าครับ
