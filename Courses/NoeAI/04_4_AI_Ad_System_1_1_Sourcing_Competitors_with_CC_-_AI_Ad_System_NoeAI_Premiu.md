## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่บทเรียน Sourcing Competitors with Claude Code นะครับ ในบทเรียนนี้ ผมจะมาโชว์วิธีใช้ Claude Code สร้างฐานข้อมูลคู่แข่ง สำหรับโฆษณาของคุณครับ และตลอดทั้งโมดูลการวิจัยคู่แข่งนี้ ผมจะโชว์วิธีสร้างคลังโฆษณา Meta ขนาดยักษ์ ที่เต็มไปด้วยโฆษณาที่ชนะ แบบที่ผมมีอยู่ตรงนี้ครับ ผมมีโฆษณาที่ชนะ หลายร้อยรายการ พร้อมข้อมูลทั้งหมดของมันอยู่ในนั้นครับ ผมมีชื่อคู่แข่งเฉพาะราย ผมมี URL ของพวกเขา ผมมีคอปปี้โฆษณาทั้งหมดของพวกเขา ซึ่งโคตรจะเจ๋งเลยครับ รวมถึงลิงก์วิดีโอโฆษณาจริง ๆ ด้วย คุณสามารถดาวน์โหลดวิดีโอ แล้วส่งให้ Claude Code วิเคราะห์ต่อได้ครับ ผมยังดึงทรานสคริปต์ของวิดีโอออกมาได้อีกด้วย แทบจะทุกข้อมูลที่ผมอยากได้ จากโฆษณาหลายร้อยรายการ มันบ้ามากจริง ๆ ครับ

แต่ในบทเรียนนี้ ผมจะโชว์วิธีสร้างรายชื่อคู่แข่งครับ รายชื่อคู่แข่งทั้งหมดของคุณ ที่คุณจะไปขโมยโฆษณามาใช้ได้ครับ สำหรับบทเรียนนี้ ผมได้เตรียมไฟล์ให้คุณแล้ว ที่ด้านล่างคือ Competitor Research Skill ครับ ไปดาวน์โหลดสกิลนี้มาได้เลยครับ และผมยังเตรียมไฟล์ Airtable CSV สำหรับรายชื่อคู่แข่งให้ด้วยครับ เดี๋ยวบทเรียนหน้า ผมจะโชว์วิธีสร้างงานวิจัยโฆษณา และคลังข้อมูลทั้งหมด แต่ตัวนี้จะช่วยตั้งค่าระบบพื้นฐานให้คุณครับ และผมยังเตรียมแผนการสอน ที่จะให้ Claude Code ใช้เป็นแนวทางด้วยครับ นี่คือแผนการสอนทั้งหมดที่ผมสร้างไว้ครับ

สิ่งที่สกิลนี้ทำคือ มันจะวิจัยคู่แข่ง 10 ราย ผ่านเว็บครับ แต่ผมไม่แนะนำให้ปล่อยให้ Claude Code ทำทุกอย่างเองนะครับ คุณควรติดตามคู่แข่งด้วยตัวเอง เพราะมันสำคัญมากครับ เวลาคุณลงโฆษณาในอุตสาหกรรมไหนก็ตาม ไม่ว่าธุรกิจอะไรก็ตาม สิ่งแรกที่ผมทำเสมอ เมื่อเริ่มสร้างระบบเหล่านี้ คือเริ่มวิจัยคู่แข่งครับ เพราะเวลาคุณลงโฆษณา และอยากประสบความสำเร็จ คุณจะไปตามความคิดตัวเองคนเดียวไม่ได้ครับ

ลองคิดดูนะครับ สมมติว่าคุณเริ่มจากบัญชีเล็ก ๆ หรือคุณลงโฆษณาเดือนละห้าพันดอลลาร์ คุณจะมีข้อมูลน้อยมาก คุณไม่มีเงินมากพอจะทดสอบอะไรเยอะ ๆ ครับ แต่พวกบริษัทใหญ่ ที่ทุ่มเงินล้านดอลลาร์ต่อเดือนในการลงโฆษณา พวกเขามีข้อมูลมหาศาล พวกเขาปรับแต่งกลยุทธ์โฆษณาจนเป๊ะ แล้วรู้ว่าอะไรเวิร์กในตลาด สำหรับกลุ่มเป้าหมายเฉพาะของพวกเขา เราจึงต้องลอกเลียนสิ่งที่พวกเขาทำครับ ถ้าคุณเป็นธุรกิจเล็ก คุณจะไม่มีเงินไปทดสอบสิ่งต่าง ๆ และถ้าคุณไม่มีเงินทดสอบ แล้วคุณออกไปทดสอบแบบมั่ว ๆ โดยไม่รู้ว่ากำลังทำอะไร คุณจะเผาเงินไปเยอะมากเร็วมากครับ ซึ่งเราไม่ต้องการแบบนั้น

สิ่งที่ผมแนะนำคือ หาคนสามประเภทครับ เราต้องการหาแบบ micro ต้องการหาสามกลุ่ม แล้วก็พวก ad leaders อีกสองสามคน สิ่งที่หมายถึงคือ สำหรับแบบ micro เราต้องการหาคนห้าคน ที่อยู่ในอุตสาหกรรมเดียวกันกับเรา และให้บริการกลุ่มเป้าหมายเดียวกันเป๊ะ ครับ ตัวอย่างเช่น ธุรกิจที่ผมช่วยดูแลโฆษณาอยู่นี้ พวกเขาทำซอฟต์แวร์สำหรับกีฬา ครับ สำหรับคนที่ออกไปฝึกซ้อม นักกีฬาเยาวชน สิ่งที่ผมทำคือ ผมจะเข้าไปดู Instagram แล้วเริ่มติดตามบัญชีแบบนี้ครับ เวลาผมเลื่อนฟีด ผมจะไปที่แท็บค้นหาก่อนครับ สมมติว่า ผมเปิด Instagram ขึ้นมา ผมจะไปที่แท็บค้นหา แล้วมองหาคู่แข่งในกลุ่มเฉพาะของผมครับ ถ้ากลุ่มผมคือกีฬา ผมก็จะค้นหาคำว่ากีฬา ครับ Coach IQ ก็เป็นธุรกิจหนึ่งที่ผมรู้จัก แล้วผมก็เจอคนอื่น ๆ อีก พวกนี้เป็นเทรนเนอร์กีฬา เป็นโค้ชกีฬาครับ

ผมจะค้นหา แล้วไล่ดูคอนเทนต์ต่าง ๆ เพื่อหาคนที่ทำอะไรเฉพาะทางครับ อย่างนี้คือแบบหลากหลายทิศทาง อันนี้ค่อนข้างใกล้กลุ่มเรา คือเทรนเนอร์สำหรับนักกีฬา ซึ่งในกลุ่มนี้ค่อนข้างเฉพาะเจาะจง คนจะไม่เยอะมากครับ แต่ถ้าผมค้นหาคำว่า facility หรือสถานที่ฝึกซ้อม ผมจะเจอคนที่มีสนามกีฬาเป็นของตัวเอง แล้วผมก็จะไล่ดูคนพวกนั้นครับ อันนี้คือหนึ่งในคนที่เราติดตามอยู่จริง ๆ แต่ประเด็นคือ คุณแค่เปิด Instagram แล้วหาคู่แข่งของคุณได้เลยครับ ถ้าคุณอยู่ในกลุ่มนี้ คุณจะติดตามคนพวกนั้นอยู่แล้วโดยธรรมชาติ สิ่งที่ผมทำคือ เจอคนพวกนั้น แล้วให้คุณทำรายชื่อขึ้นมาครับ ผมเตรียม Airtable setup ให้แล้ว ใส่ชื่อพวกเขาทั้งหมดลงไป หรือจะเก็บไว้ในแถบโน้ตของคุณก็ได้ครับ แล้ว Claude Code จะช่วยคุณตั้งค่าระบบทั้งหมดนี้เองครับ

เพื่อให้เข้าใจง่ายขึ้น เราต้องการ micro 5 ราย niche 3 ราย และ ad leaders 2 รายครับ micro niche คือกลุ่มเฉพาะ ที่ให้บริการกลุ่มเป้าหมายแบบเดียวกันเป๊ะ ตัวอย่างเช่น ถ้าคุณอยู่ในวงการฟิตเนส นั่นคือ macro niche ครับ ฟิตเนสครอบคลุมหลากหลาย แต่ก็ถือเป็น niche หนึ่ง แล้ว micro niche ก็คือ โค้ชลดน้ำหนัก ครับ ผมจะมองหาโค้ชลดน้ำหนักตัวใหญ่ ๆ ห้าคน เพราะผมไม่อยากไปวิจัยโฆษณาคู่แข่ง ที่ใช้เงินน้อยมาก ๆ ผมอยากได้คนที่คิดหาวิธีสำเร็จแล้ว ครับ ถ้าผมอยู่ในวงการฟิตเนส ผมจะมองหาโค้ชลดน้ำหนักห้าคน ที่มีผู้ติดตามเยอะ และลงโฆษณาเยอะชัดเจน

ถ้าพวกคุณไม่รู้วิธีวิจัยโฆษณา คุณไปที่ Meta Ad Library ได้ครับ ใน Meta Ad Library คุณจะเจอโฆษณาหลายร้อยรายการ ครับ ลองไปที่ประเทศสหรัฐอเมริกา แล้วเลือกดูโฆษณาทั้งหมด ลองค้นหา fitness coaches นี่คืออีกวิธีที่ดีมากในการหาโฆษณา คุณสามารถค้นหาด้วยคีย์เวิร์ด แล้วดึงโฆษณาหลายร้อยรายการ ของคนที่ targeting โค้ชฟิตเนสโดยเฉพาะครับ แบรนด์อย่าง Everfit ผมค่อนข้างมั่นใจว่าพวกเขาทำซอฟต์แวร์ ครับ อันนี้ไม่ค่อยตรง แต่ก็เป็น macro niche ถ้าผมทำฟิตเนสครับ Beyond Volleyball อันนี้น่าจะใช้ได้ดีกับเราเลยครับ คุณเห็นภาพแล้วใช่ไหมครับ?

คุณยังสามารถค้นหาบัญชีเฉพาะได้อีกด้วย ตัวอย่างเช่น Alex Hormozi ผมสามารถดูโฆษณาทุกตัวที่ Alex Hormozi ลงได้ครับ เขาลงโฆษณาอยู่ 260 ตัว และนี่แค่โฆษณาที่ active อยู่เท่านั้นนะครับ แล้วคุณยังจัดเรียงตามระยะเวลาที่โฆษณาลงมาได้อีกด้วย โดยปกติผมจะไม่เก็บโฆษณาที่ลงมาน้อยกว่า 14 ถึง 28 วันครับ เพราะถ้าใครลงโฆษณาตัวหนึ่งนานถึง 28 วัน ผมรู้ได้เลยว่ามันคือโฆษณาที่ชนะ พวกเขากำลังชนะจริง ๆ ครับ

ในสเปรดชีตของผม ผมจัดระเบียบข้อมูลทั้งหมดนี้ โดยมีจุดข้อมูลหลายตัวครับ ผมมีโฆษณาทั้งหมด และทุกอย่างที่เกี่ยวข้อง แล้วผมก็คำนวณออกมา เดี๋ยวผมจะลงรายละเอียดในโมดูลหน้า แต่ผมรู้ว่าโฆษณาลงมานานแค่ไหน รู้ว่ากี่วันที่ active ผมจัดระดับมันได้จากข้อมูลพวกนี้ครับ ถ้าต่ำกว่า 30 วัน พวกเขากำลังทดสอบอยู่ ถ้าลงมานานกว่า 30 วัน นั่นคือโฆษณาที่ชนะครับ

สิ่งที่อยากให้ทุกคนทำคือ ไปที่บทเรียน แล้วดาวน์โหลดสกิลมา แล้วจากนั้นก็เปิด Claude Code ขึ้นมา วางสกิลลงไป แล้วเรียกใช้ skill builder หรือ skill creator ที่ผมให้ไว้นะครับ แล้วก็กด Enter ครับ สิ่งที่ผมทำคือ ผมจะพรอมต์ให้มันถามคำถามคุณหลายข้อ เกี่ยวกับว่าคู่แข่งของคุณเป็นใครบ้าง ถ้าคุณสร้างรายชื่อไว้แล้ว ก็เยี่ยมเลยครับ

กลับมาที่รายชื่อคู่แข่งอีกครั้ง สุดท้ายเราต้องการ ad leaders ครับ ผมไม่เพียงแต่อยากได้คนในกลุ่มเฉพาะของผม ที่ใช้เงินโฆษณาเยอะ ๆ เท่านั้น ผมอยากได้คนใน macro niche ของผมด้วย ครับ ถ้าเป็นฟิตเนสและลดน้ำหนัก คุณก็จะหาคนที่ทำเรื่องลดน้ำหนัก แล้วก็หาคนที่อยู่ในกลุ่มนั้นโดยตรง แล้วเราก็อยากได้ ad leaders ครับ ผมใช้ Alex Hormozi เป็นตัวอย่าง แบบนั้นครับ พวกนี้เป็นผู้เล่นตัวใหญ่ ลงโฆษณาหลายร้อยตัวต่อเดือน และผมรู้ได้เลยว่าพวกเขาอยู่แนวหน้าเรื่องโฆษณา พวกเขารู้ว่าอะไรเวิร์กในตลาด การสร้างรายชื่อแบบนี้จึงสำคัญมากครับ

เมื่อคุณได้รายชื่อครบแล้ว ก็แค่ดาวน์โหลดสกิล อัปโหลดเข้าระบบ แล้วมันจะพรอมต์ให้คุณตั้งค่าระบบเอง และพาคุณทำทีละขั้นตอนครับ คุณจะต้องใช้เครื่องมือสามอย่าง นั่นคือบัญชี Apify ครับ แล้วก็ Airtable หรือจะใช้ Google Sheets ก็ได้ครับ

ขอลงรายละเอียดเพิ่มอีกนิด เพื่อให้ทุกคนเห็นสิ่งที่ผมทำไว้ภายในครับ ผมมีข้อมูล description ของคู่แข่งแต่ละราย และสกิลจะสร้างทั้งหมดนี้ให้คุณเองครับ แล้วผมก็มี Facebook Page ID ของพวกเขา มี URL ของ Ad Library ด้วย ผมคลิกเข้าไปได้เลย แล้วตรงเข้าไปดูบัญชีโฆษณาของพวกเขา ผมรู้เป๊ะว่าพวกเขาลงโฆษณาอะไรอยู่บ้าง ผมมี Instagram มี LinkedIn ด้วยครับ ผมอยากรู้ทุกอย่างเกี่ยวกับคนพวกนี้ครับ แล้วผมยังมีมุมมองแบบ gallery ซึ่งผมสร้างขึ้นเองด้วย นี่คือเหตุผลที่ผมชอบ Airtable ครับ คุณสามารถสร้าง CRM ที่ custom ได้สุด ๆ บนโลกนี้เลย แล้วผมก็มีเวอร์ชันที่สวยงามของข้อมูลทั้งหมด ตั้งค่าไว้เกือบครบแล้วครับ ถ้าคุณไม่รู้วิธีทำ คุณแค่กด create new แล้วสร้างอะไรก็ได้ตามที่คุณต้องการ คุณเลือกมุมมอง gallery ได้ แล้วมันจะสร้าง gallery ให้อัตโนมัติ ซึ่งเจ๋งมากครับ
