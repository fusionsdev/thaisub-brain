## บทนำ

บทเรียนนี้เป็นการเปลี่ยนจาก Claude Desktop ไปใช้ Claude Code ใน Terminal ซึ่งให้ความสามารถมากกว่ามากสำหรับการสร้างทีม AI agent ผู้สอนพาทำความรู้จัก Terminal ทีละขั้น: การเปิดโฟลเดอร์, คำสั่ง cd, การแยกหน้าต่าง, การจัดการไฟล์ และการเรียกใช้ skills และ MCP servers

## คำแปลเต็ม

ยินดีต้อนรับเข้าสู่บทเรียน Switch to Terminal ในบทนี้ผมจะพาคุณเดินผ่านการเปลี่ยนผ่านครั้งสำคัญ จนถึงตอนนี้เราทุกคนใช้ Claude Desktop กันมาโดยตลอด เราเพิ่งทำงานภายใน Claude Code Desktop มาตลอด ปัญหาของ Claude Desktop คือมันจำกัดความสามารถที่มันทำได้ มันรันงานระดับสูง (high-level tasks) ไม่ได้

และต่อจากนี้ผมจะสอนวิธีสร้างทีม AI agents ที่จะทำงานให้คุณ ซึ่ง Claude Desktop ทำแบบนั้นไม่ได้ จนถึงตอนนี้คุณได้เรียนพื้นฐานทั้งหมดแล้ว เรียนการติดตั้ง เรียนระบบไฟล์ที่คุณต้องใช้ ฝึก Claude Code ด้วยข้อมูลธุรกิจของคุณ ใส่และใช้ skills สร้าง skill แรกของคุณ เข้าใจว่ามันทำงานยังไง และยังเชื่อมเครื่องมือแรกของคุณเข้ากับ Claude Desktop อีกด้วย

ตอนนี้ถึงเวลาเลื่อนชั้นไปยังจุดที่คุณจะเริ่มเห็นผลลัพธ์ที่บ้ามากจาก Claude Code มันเหมือนเอา Claude Desktop มาคูณสิบ และนั่นคือผลลัพธ์ที่คุณจะได้จาก Claude Code

ผมรู้ว่าหลายคนกลัวการใช้ Terminal เพราะมันดูน่ากลัวนิดหน่อย แต่ผมสัญญาได้เลย ผมไม่ใช่คนที่ฉลาดที่สุดในโลก แต่ผมก็เรียนรู้ได้ ผมรับประกันว่าคุณก็ทำได้ ถ้าคุณยังไม่ได้ดูบทเรียนการติดตั้งและบท Claude Code + Cursor ขอให้ไปดูวิดีโอนั้นก่อน ดูแล้วตั้งค่า แล้วบอกผมว่ามีปัญหาอะไร หรือถ้าตั้งค่าได้สำเร็จ นี่คือการตั้งค่าหลักสำหรับ Claude Code ใน Terminal

เข้าเรื่องกันเลย เราจะเปิด Claude Code ขึ้นมา แล้วผมจะพาคุณทำความรู้จักมันนิดหน่อย เพื่อให้คุณคุ้นเคย แล้วจากนั้นเราจะเรียนบทต่อไปและสร้าง MCP connection ของคุณเอง โอเค เข้าเรื่องกันเลย

ผมจะเปิดหน้าต่างใหม่ตรงนี้ โอเค อย่างที่ผมบอกไว้ในบทก่อน ผมแจกแจงสิ่งที่คุณต้องมีไว้แล้ว นี่คือสิ่งที่คุณต้องทำ — แค่คลิก open แล้วเข้าไปในโฟลเดอร์ที่คุณทำงานอยู่ ผมจะคลิกโฟลเดอร์ school community เป็นตัวอย่าง เพราะผมทำงานในนั้นมาตลอด แล้วคลิก open บูม

ตอนนี้เรามีสามพาเนลที่คุณเห็น แชทตรงนี้ก็คือ... Cursor มี LLM ท้องถิ่นของตัวเอง มี Claude อะไรประมาณนั้น มี AI agent ของตัวเองอยู่ข้างใน ซึ่งเจ๋งมาก ผมเข้าไปได้ มีแชท แล้วก็มี... จริง ๆ คุณสามารถให้ Claude Code กับ AI agent อีกตัวทำงานในโปรเจกต์เดียวกันได้ ซึ่งเจ๋ง แต่มันไกลเกินไปหน่อย เรายังไม่ต้องไปไกลขนาดนั้น แค่คลิก X ปิดตรงนี้ แล้วคุณจะเห็น sidebar เล็ก ๆ ปิดมันลงไปได้

สิ่งที่เราต้องการคือ คลิก Show Terminal ถ้าผมเปิดตรงนี้ มันจะเป็น PowerShell ไปที่... ผมเดาว่ามันจะขึ้นว่า Open PowerShell คุณก็แค่กด Show Terminal แล้วเราก็อยู่ใน Terminal แล้วคุณจะเห็นว่ามันเขียนว่า school community folder example แปลว่าเราอยู่ในโฟลเดอร์นั้นแล้ว ซึ่งเจ๋งมาก

ถ้าผมอยากทำงานในโฟลเดอร์อื่น ผมแค่พิมพ์ cd เห็นไหมครับ กด space แล้วดูตรงนี้ ผมเปิด Finder ขึ้นมา สมมติว่าผมทำงานอยู่ในโฟลเดอร์พวกนี้ ผมจะเลือกโฟลเดอร์ที่อยากสลับไป สมมติว่าผมอยากสลับไปโฟลเดอร์ Noah Varner AI ของผม สังเกตชื่อตรงนี้: school community folder ผมจะลากโฟลเดอร์นั้นวาง แล้วก็กด enter เห็นไหมว่าชื่อเปลี่ยนไป ตอนนี้ผมทำงานเฉพาะในโฟลเดอร์นั้นแล้ว

ถ้าผมอยากเปลี่ยนอีก ลองทำตามกันนะครับ เปลี่ยนโฟลเดอร์ด้วยการพิมพ์ cd แล้วเว้นวรรค สมมติว่าผมอยากเปลี่ยนไปโฟลเดอร์หลัก ซึ่งก็คือ NoeAI Work ตอนนี้ผมอยู่ในโฟลเดอร์ NoeAI Work แล้ว เห็นไหมว่ามันเขียนว่า NoeAI Work ตรงนั้น มันเปลี่ยนไปแล้ว "Noah Varner ที่ MacBook Pro" เห็น "Noah Varner" ตรงนี้ไหม นั่นคือคอมพิวเตอร์ของผมบน MacBook และผมอยู่ในโฟลเดอร์นี้ ง่ายมาก

ผมจะเปลี่ยนกลับไปโฟลเดอร์ school ตัวอย่าง ลากมันวาง แล้วที่เหลือผมแค่พิมพ์ claude แล้วกด enter เท่านั้นเอง นี่คือวิธีเริ่มต้นใช้งาน มันง่ายขนาดนั้น ความกลัวและความตื่นเต้นทั้งหมดนั้นไม่จำเป็นเลย มันง่ายมาก ๆ

ตอนนี้เราอยู่ใน Claude Code แล้ว คุณได้เข้าถึงเครื่องมือที่ทรงพลังที่สุดบนโลกที่อยู่ใน Terminal ของคุณ ผมจะพาคุณดูสิ่งที่ผมชอบทำ ผมชอบที่ Terminal แยกหน้าต่างได้ ถ้ากดปุ่มเล็ก ๆ ตรงนี้ ผมสามารถแยกมันออกเป็นหลายส่วนได้ ผมยังอยู่ในโฟลเดอร์ เห็นไหม school community Claude แล้วผมก็รัน Claude สองตัวพร้อมกันได้ เห็นไหมครับ? ผมรันทั้งสองตัวได้ ทำหลายโปรเจกต์พร้อมกัน และถ้าผมอยาก... สมมติว่าผมอยู่ในโปรเจกต์ของอีกที่หนึ่ง ผมแค่ cd แล้วเปิด NoeAI Work ตรงนี้ ตอนนี้ผมทำงานในโฟลเดอร์นี้ เห็นไหมว่ามันเขียน NoeAI Work ตรงนั้น มันบอกผมว่าผมอยู่ในโฟลเดอร์นี้ ส่วนอีกหน้าต่าง Claude Code ก็อยู่ที่ CC school community folder example ผมอยู่ในโฟลเดอร์นี้สำหรับเวอร์ชันนี้

แล้วก็ดูไฟล์ที่ผมกำลังทำงานได้ ถ้าผมไปที่... ดูตรงนี้ เห็นโฟลเดอร์ finance ในแบรนด์ส่วนตัวของผมไหม "ช่วยลบโฟลเดอร์ finance ในแบรนด์ส่วนตัวหน่อยได้ไหมครับ" โอเค ดูนะ ผมควบคุมไฟล์เหล่านี้ได้โดยตรงจากตรงนี้ ง่ายมาก ดูนะ ขอเช็คก่อนว่ามีอะไรในโฟลเดอร์ โฟลเดอร์ว่าง ใช่ ลบเลย โอเค ดำเนินการ แล้วมันก็ถูกลบ เห็นไหม? หายไปแล้ว ง่ายมาก

ทุกอย่างที่เราเรียนมาถึงตอนนี้ ผมสอนคุณเรื่อง skills เราเรียนเรื่องไฟล์ วิธีจัดระเบียบ วิธีสอน ทุกอย่าง ไฟล์ทั้งหมดของคุณยังอยู่ ไม่มีอะไรเปลี่ยนไปจากการย้ายจาก Claude Desktop มาที่ Terminal คุณแค่มีความสามารถมากขึ้น มีความสามารถเพิ่มขึ้นเยอะ และคุณได้เรียนวิธีรัน skills แล้ว

มีสองสิ่งที่เราต้องพูดถึง หนึ่งคือ skills ถ้าคุณพิมพ์ / คุณจะเห็น skills ทั้งหมดที่คุณมี ผมค่อนข้างแน่ใจว่าเราสร้าง content machine ไว้ตอนที่เราสร้าง skills ในตัวอย่างก่อนหน้า มันอยู่ตรงนั้น เป็น skill ระดับ global บนเครื่องของผม และผมรันมันเมื่อไหร่ก็ได้ แค่กด enter หรือจะพูดสั่งก็ได้ มันจะรันแบบ global ง่ายมาก ประมาณนี้แหละ ไม่มีอะไรแตกต่างอีกแล้วในนี้

และถ้าคุณอยากใช้ MCP และอยากเห็นว่าคุณเชื่อมต่อกับอะไรอยู่ Claude ของคุณเชื่อมกับแอปอะไรบ้าง ไปที่เครื่องหมาย slash แล้วพิมพ์ /mcp จัดการ MCP servers ดูตรงนี้ นี่คือทุกอย่างที่ผมเชื่อมต่ออยู่ Airtable, Canva, Figma, Gmail, Google และก็ Stripe — อัน Stripe ที่เราทำในเซสชันก่อน ทุกอย่างที่คุณเชื่อมต่อกับ Claude Desktop คุณจะเห็นตรงนี้ทั้งหมด เพราะมันอยู่ภายใต้ claude.ai

ไม่ว่าคุณจะเข้าไปในแอปไหนแล้วกด connectors ตามที่ผมบอกให้ทำในบทก่อน แล้วไล่กดดูว่าคุณเชื่อมกับอะไรอยู่ คุณควรเห็นทั้งหมดตรงนี้ โอเค

ในบทต่อไป เราจะสร้าง MCP servers ที่ไม่ได้อยู่ใน Claude AI เพราะ Claude AI ไม่อนุญาต และนี่คือเหตุผลที่เราย้ายจาก Claude Desktop มาที่ Terminal — เพราะคุณสร้าง MCP servers และเชื่อมต่อกับแอปที่ไม่อยู่ในระบบของ Claude ได้

นี่คือทุกอย่างสำหรับบทนี้ อย่าเพิ่งตกใจ ไปลองเล่นดู ดูว่าคุณทำอะไรได้บ้าง ทำความรู้จักมันสักหน่อย ขอให้ Claude Code สอนวิธีทำอะไรบางอย่าง ถ่าย screenshot กลับไปที่ Claude อะไรประมาณนั้น แล้วเจอกันบทเรียนหน้าครับ
