## บทนำ
บทเรียนนี้สอนวิธีอัปโหลด Conversion Adjustments (การปรับคอนเวอร์ชัน) ไปยัง Google Ads ด้วยการใช้ Google Sheets เป็นไฟล์นำเข้า โดยอธิบายคอลัมน์ทั้ง 6 คอลัมน์ที่ต้องกรอก วิธีเลือกประเภทการปรับระหว่าง Retract และ Restate รวมถึงขั้นตอนการอัปโหลดแบบแมนนวลและแบบกำหนดเวลา พร้อมอธิบายว่าฟีเจอร์นี้ช่วยให้ Smart Bidding ทำงานได้อย่างมีประสิทธิภาพมากขึ้น

## คำแปลเต็ม
มาดูกันให้ละเอียดว่า คุณจะอัปโหลด Conversion Adjustments (การปรับคอนเวอร์ชัน) ไปที่ Google ได้อย่างไรจริงๆ

วิธีที่ง่ายที่สุด คือการใช้ Google Sheets (สเปรดชีตของ Google)

และใน Google Sheets นี้ โดยพื้นฐานแล้ว คุณจะมีคอลัมน์ที่แตกต่างกัน 6 คอลัมน์ ได้แก่ Order ID (รหัสออเดอร์) คอนเวอร์ชัน (Conversion)

เวลาที่ปรับ (Adjustment Time) ประเภทการปรับ (Adjustment Type) มูลค่าที่ปรับ (Adjustment Value) และสกุลเงินที่ปรับแล้ว (Adjusted Currency)

และคุณยังมีการตั้งค่าเล็กน้อยอีกอย่างหนึ่ง นั่นคือ โซนเวลา (Time Zone) ของคุณ

ดังนั้น อย่าลืมกรอกโซนเวลา

ที่สอดคล้องกับคุณในจุดนี้

ผมจะใส่ลิงก์สำหรับแปลงเวลาไว้ให้ด้วย แต่คุณสามารถหาได้ในเอกสารตัวนี้เองเช่นกัน

นั่นคือลิงก์เฉพาะนี้

ดังนั้น ทำแบบนั้นก่อน จากนั้น อย่าลืมใช้คอลัมน์ Order ID หรือ Google

Click ID (รหัสคลิกของ Google)

ถ้าคุณใช้ Transaction ID ส่งไปพร้อมกับอีเวนต์ conversion/purchase (คอนเวอร์ชัน/การซื้อ) คุณต้องตั้งค่านี้เป็นคอลัมน์ Order ID โดยคุณจะบันทึก Transaction ID ทั้งหมดไว้ตรงนี้

โดยพื้นฐานแล้ว สิ่งเหล่านี้คือ Transaction ID ที่คุณต้องการปรับ

อย่าลืมใช้ ID เดียวกันกับที่คุณส่งไปจริงในอีเวนต์ conversion/purchase

ไม่อย่างนั้น Google Ads จะไม่สามารถหา Transaction ID นั้นเจอได้

จำจุดนี้ไว้ให้ดี

ถ้าคุณไม่ได้ส่ง Transaction ID ไปกับอีเวนต์ conversion/purchase คุณสามารถใช้ Google Click ID ได้ เพราะ Google สามารถปรับคอนเวอร์ชันตามคลิกที่คุณบันทึกไว้ร่วมกับลีด (lead) หรือออเดอร์นั้นได้เช่นกัน

โดยส่วนใหญ่แล้ว วิธีนี้มักใช้กับนักโฆษณาสาย lead gen/SaaS (การสร้างลีด/ซอฟต์แวร์แบบสมัครสมาชิก) เท่านั้น

ในกรณีที่พวกเขาไม่ได้ส่ง Transaction ID

แต่แน่นอนว่า เพื่อให้วิธีนี้ทำงานได้ คุณต้องส่ง Google Click ID ไปพร้อมกับฟอร์มของคุณ จากนั้นภายหลัง คุณก็สามารถเชื่อม Conversion Adjustments เข้ากับ Google Click ID ได้

แต่ตามหลักการแล้ว คุณยังสามารถใช้ประโยชน์จาก Transaction ID ในแท็กคอนเวอร์ชัน (conversion snippets) หรือแท็ก Google Ads Conversion ใน GTM (Google Tag Manager) ของคุณได้ เพราะสิ่งนี้ช่วยให้คุณตัดคอนเวอร์ชันที่ซ้ำกัน (deduplicate) ได้

ถ้าคุณใช้ Transaction ID ในคอนเวอร์ชันของคุณ คุณต้องใช้คอลัมน์ Order ID/Transaction ID นี้ แทนที่จะใช้ Google Click ID ถ้ายังพอเข้าใจกันได้นะ

นั่นคือขั้นตอนแรก

อย่าลืมส่งออก (export) ข้อมูลทั้งหมด ที่ถูกปรับ ยกเลิก คืนบางส่วน หรือคืนทั้งหมด แล้วบันทึกลงในไฟล์เฉพาะนี้

แต่ละแถว โดยพื้นฐานแล้วคือ

Conversion Adjustment หนึ่งรายการ เว้นแต่ว่าคุณมีชื่อคอนเวอร์ชันหรือ Conversion Actions (การดำเนินการคอนเวอร์ชัน) หลายรายการ ที่ใช้ในบัญชีของคุณ

เพื่อให้ชัดเจนยิ่งขึ้น ผมใช้ Conversion Booster ของ ProfitMetrics (เครื่องมือติดตามกำไร) อยู่

ซึ่งช่วยให้ผมติดตามทั้งรายได้ (revenue) และกำไรขั้นต้น (gross profit) ในบัญชีของผม

ดังนั้น โดยพื้นฐานแล้ว ผมมี Conversion Actions ที่แตกต่างกันสองรายการ

แต่ผมใช้ Conversion Booster ด้วยเช่นกัน

รวมแล้วก็เป็นสี่

Conversion Actions ที่แตกต่างกันในบัญชีของผม

เพราะถ้าแท็กฝั่งเบราว์เซอร์ (browser tag) ไม่สามารถยิง (fire) ได้ตอนที่ลูกค้าทำ checkout (ชำระเงิน) สำเร็จ ProfitMetrics จะอัปโหลดคอนเวอร์ชันที่พลาดไปนั้นให้โดยอัตโนมัติ ผ่านการนำเข้าคอนเวอร์ชัน (Conversion Import)

เนื่องจากผมไม่รู้ว่า Transaction ID นี้ ถูกเชื่อมโยงกับ Conversion Action ตัวไหน ผมจึงต้องอ้างอิงถึง

Conversion Actions ทั้งหมด ที่ผมใช้อยู่ในบัญชี Google Ads ของผม

ดังนั้น อย่าลืมตรวจสอบจุดนี้ให้ดี

ถ้าคุณมี Google Ads Conversion ประเภท purchase (การซื้อ) เพียงตัวเดียว คุณก็ใช้แค่หนึ่งแถว

แต่บางครั้งมันก็ซับซ้อนขึ้นอีกหน่อย เพราะคุณสามารถใช้ Conversion Action ได้มากกว่าหนึ่งรายการในบัญชี

จากนั้นก็ถึงคอลัมน์ Adjustment Time

อย่าลืมจัดรูปแบบเป็น วันที่ (วัน/เดือน/ปี) แล้วตามด้วย ชั่วโมง นาที และวินาที

นี่คือเวลาที่ทำการปรับ (adjustment) เกิดขึ้น

สมมติว่า Transaction ซึ่งเป็นธุรกรรมเดียวที่ไม่ซ้ำกันนี้ ถูกคืนบางส่วน ให้ใช้วันที่คืนบางส่วนนั้น เป็นเวลาในการปรับ (adjustment time)

ไม่ใช่วันที่คุณอัปโหลดไฟล์นี้

แต่ให้ใช้วันที่ที่ออเดอร์นี้ถูกคืนหรือยกเลิก หรือวันที่เกิดเหตุการณ์นั้นๆ ตามเหตุผลที่คุณมี

จากนั้นก็มีคอลัมน์ Adjustment Type (ประเภทการปรับ)

ตรงนี้ คุณสามารถเลือกได้ระหว่าง Retract (เพิกถอน) และ Restate (ปรับค่าใหม่)

Retract ใช้เมื่อคุณต้องการลบคอนเวอร์ชันออกทั้งหมด

เช่น เมื่อคุณต้องการลบออเดอร์เฉพาะนี้ออกจากบัญชี เพราะมันอาจถูกคืนทั้งหมด เป็นต้น

ซึ่งจะเป็นการลบทั้งค่าคอนเวอร์ชัน (conversion value) และคอนเวอร์ชันออกไป

แต่คุณยังสามารถใช้ Restate ได้เช่นกัน

และ Restate หมายความว่า คุณสามารถใช้มูลค่าที่ปรับ (adjustment value) ของคุณได้

โดยระบุมูลค่าที่ปรับแล้ว และสกุลเงินที่ปรับแล้ว

ตรงนี้ คุณต้องกรอกมูลค่าที่ปรับแล้ว (adjusted value) หลังจากที่ทำการปรับเรียบร้อยแล้ว

สมมติว่ารายได้เดิมคือ 1,500 ยูโร

จากนั้น มูลค่าที่ปรับแล้ว หลังจากการคืนบางส่วน อาจเป็น 377.7 ยูโร

จากนั้น อย่าลืมใช้สกุลเงิน หรือรูปแบบสกุลเงินที่คุณใช้ในบัญชี ซึ่งควรเป็นรหัสสกุลเงินตามมาตรฐาน ISO เช่น USD หรือ EUR

คุณสามารถค้นหาข้อมูลนี้ได้

ถ้าคุณไม่รู้ว่ารหัสสกุลเงินของคุณคืออะไร

สิ่งที่สำคัญมาก คือ คุณต้องปล่อยเซลล์เหล่านั้นไว้ให้ว่างเปล่า ถ้าคุณใช้ Retract หรือลบคอนเวอร์ชันออกทั้งหมด

เพราะถ้าคุณใส่ค่าเป็นศูนย์ แล้วส่งข้อมูลเข้าไป Google จะขึ้นข้อผิดพลาด (error) ให้คุณ เพราะมันเห็นว่าคุณกำลังส่งค่าที่ปรับแล้ว แต่กลับไม่มีอะไรให้ปรับ

คุณต้องการลบคอนเวอร์ชัน ดังนั้น ปล่อยเซลล์นี้ว่างไว้ ถ้าคุณใช้ฟังก์ชัน Retract อย่าลืมกรอกข้อมูลนี้โดยเร็วที่สุด พยายามทำให้เอกสารนี้เป็นแบบอัตโนมัติ โดยให้ระบบของคุณ ดึงออเดอร์ที่ถูกคืนบางส่วนและคืนทั้งหมด เข้ามาใส่ในเทมเพลตเฉพาะนี้โดยอัตโนมัติ เพื่อที่คุณจะได้ตั้งเวลา (schedule) ให้เทมเพลตนี้ทำงานทุกๆ 24 ชั่วโมง

การปรับทุกครั้ง จะถูกทำโดยเร็วที่สุด

โดยเร็วที่สุดเท่าที่จะทำได้ ซึ่งการสร้างเอกสารนี้ขึ้นมา แล้วอัปโหลดคอนเวอร์ชันที่ปรับไปแล้วครั้งก่อนซ้ำอีกครั้ง ก็ไม่เป็นไร เพราะมันจะขึ้น error เฉพาะแถวเหล่านั้น แล้วก็จะถูกข้ามไป (ignore)

บางครั้ง คุณก็สามารถล้างข้อมูลในชีตได้ หรือคุณอาจล้างข้อมูลหลังการอัปโหลดทุกครั้งก็ได้

คุณสามารถทำให้มันเป็นแบบอัตโนมัติได้เช่นกัน

ถ้าคุณมีการปรับที่ไม่บ่อยนัก คุณก็ยังสามารถใช้การอัปโหลดแบบแมนนวล (manual upload) ได้

การอัปโหลดแบบนั้นก็ได้ แต่สุดท้ายแล้วมันก็ขึ้นอยู่กับคุณ

ถ้าคุณจะทำ ลองทำอย่างน้อยทุกๆ 24 ชั่วโมง ในบัญชีของคุณ

โดยรวมแล้ว ก็ประมาณนี้

เมื่อคุณกรอกข้อมูลเรียบร้อยแล้ว คุณก็ไปที่ Conversion Actions (การดำเนินการคอนเวอร์ชัน) ของคุณได้

ตรงนี้ ผมมีบัญชีทดลอง (dummy account) ของผม และผมจะให้ดูว่าคุณสามารถอัปโหลดข้อมูลนี้ได้ที่ไหน

เพราะมันเป็นบัญชีทดลอง ผมจึงไม่มี Transaction ID จริง และชื่อคอนเวอร์ชันเหล่านี้ ก็เป็นแค่ชื่อสุ่มขึ้นมา

เพื่อให้คุณเห็นภาพว่ามันทำงานอย่างไร อย่างที่คุณเห็น ผมไม่มีคอนเวอร์ชันเหล่านี้อยู่ในบัญชีทดลองของผม

แต่ถ้าคุณต้องการอัปโหลดคอนเวอร์ชันของคุณ คุณต้องไปที่เมนู Uploads (การอัปโหลด) จากนั้นก็ต้อง

สร้างอัปโหลดใหม่ (New Upload) ถ้าคุณต้องการทำแบบแมนนวลตรงนี้

ถ้าคุณต้องการตั้งเวลา คุณต้องเพิ่มการอัปโหลดแบบกำหนดเวลา (scheduled upload) ตรงนี้

สมมติว่าคุณต้องทำการอัปโหลดแบบแมนนวล

ตรงนั้น คุณก็เลือก Google Sheets ของคุณได้ ง่ายๆ แค่นั้น

จากนั้นก็เชื่อมโยง (link) ชีตของคุณ

อย่าลืมเพิ่มผู้ใช้ Google (Google user) ที่ Google ให้คุณไว้ เพื่อแชร์สิทธิ์เข้าถึงชีต

จากนั้นลองพรีวิว (preview) ดูว่ามี error อะไรเกิดขึ้นหรือไม่ และถ้ามีปัญหาอะไร ถ้าทุกอย่างดูเรียบร้อยดี ก็กดนำไปใช้ (apply)

ทำแบบนี้ทุกครั้ง เมื่อคุณต้องปรับคอนเวอร์ชันในอนาคตของคุณอีกครั้ง

คุณยังสามารถสร้างตารางเวลา (schedule) ตรงนี้ได้ โดยเลือก Google Sheets แล้วบอก Google ว่าให้ทำงานทุกๆ 24 ชั่วโมง ช่วงเวลาที่กำหนด จากนั้นเชื่อมโยงชีตของคุณ บันทึก และปล่อยให้มันทำงานทุกครั้ง

แต่คุณต้องแน่ใจว่า เอกสารนี้ถูกเติมข้อมูลโดยอัตโนมัติ ก่อนที่คุณจะตั้งเวลาอัปโหลด

วิธีทำงานก็เป็นแบบนี้

การจัดรูปแบบ (formatting) ให้ถูกต้องนั้น ค่อนข้างจะยุ่งยากนิดหน่อย

ดังนั้น อย่าลืมใช้เทมเพลตที่ถูกต้อง โดยผมจะใส่ลิงก์เทมเพลตทางการ (official templates) ไว้ใต้วิดีโอนี้ ที่คุณสามารถใช้ได้ ไม่ว่าคุณจะใช้ Transaction ID สำหรับคอนเวอร์ชันออนไลน์ (online conversions) หรือใช้ Google Click ID

สำหรับคอนเวอร์ชันออฟไลน์ (offline conversions)

ทั้งสองเป็นเทมเพลตที่แตกต่างกัน เพราะชื่อคอลัมน์จะต่างกันเล็กน้อย แต่ส่วนที่เหลือ ทำงานเหมือนกันทุกอย่าง

ผมคิดว่าการใช้ฟีเจอร์นี้สำคัญมาก
