## ประเด็นหลัก
- อดีตนักวิจัย OpenAI เปิดตัว "Jevity" (Jev) — AI ที่อ้างว่าถูกกว่า Claude/GPT 400 เท่า
- ความต่างหลัก: GPT/Claude สร้างข้อความทีละคำ แต่ Jev ทำแค่ "ตัดสินใจ" — ใช่/ไม่ใช่, เลือก A/B/C
- ราคา: 4 เซนต์ ต่อ 10 ล้าน token เทียบ Claude ที่ $10
- งานจริงส่วนใหญ่ไม่ใช่การเขียนย่อหน้า แต่เป็นคำถามใช่/ไม่ใช่ (สแปม? ปลอดภัย? คุณภาพดี?)
- ใช้ Jev กับงานที่คำตอบเป็นตัวเลือก: content moderation, lead scoring, sentiment analysis, ตรวจคุณภาพระหว่างขั้น agent
- งานประเภทนี้กินบิล API ~90%
- 3 วิธีใช้: Vercel AI gateway (รวมในตัว), Type Safe ผ่าน API key, และ Claude Code (ผ่าน skill ที่ติดตั้งเพิ่ม)
- รับคู่มือติดตั้งโดยกดไลก์ + คอมเมนต์ "Jev"
