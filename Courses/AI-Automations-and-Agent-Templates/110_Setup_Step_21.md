## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 21 ของการตั้งค่าระบบอัตโนมัติ โดยเราจะเปิดแพลตฟอร์ม ManyChat ซึ่งเป็นแพลตฟอร์มระบบอัตโนมัติสำหรับโซเชียลมีเดียอย่าง Instagram เพื่อใช้จัดการข้อความอัตโนมัติ จากนั้นเชื่อมต่อบัญชี Instagram เข้ากับแพลตฟอร์ม เพิ่ม custom fields (ฟิลด์ข้อมูลที่กำหนดเอง) สำหรับรับส่งค่าข้อมูลกับ AI agent และนำเข้าเทมเพลตเวิร์กโฟลว์สำหรับ trigger ทั้งจากข้อความส่วนตัวและจากคอมเมนต์ใต้โพสต์

## คำแปลเต็ม

ในขั้นตอนที่ 2 นี้ เราจะเปิดอีกแพลตฟอร์มหนึ่งที่ชื่อว่า ManyChat นี่คือแพลตฟอร์มระบบอัตโนมัติที่ออกแบบมาโดยเฉพาะสำหรับโซเชียลมีเดียอย่าง Instagram เพื่อใช้จัดการข้อความอัตโนมัติบนแพลตฟอร์ม คุณสามารถคลิกตรงนี้ แล้วคุณจะได้รับเดือนแรกของแพ็กเกจ Pro ฟรี ซึ่งแพ็กเกจ Pro จำเป็นต้องใช้เพื่อให้มีฟังก์ชันทั้งหมดที่เราต้องการ จากนั้นคุณคลิกที่ get your 100% discount (รับส่วนลด 100 เปอร์เซ็นต์) จากนั้นคุณก็เลือกและเข้าสู่ระบบ แล้วรับ 30 วันแรกฟรี

อย่างแรก คุณไปที่ settings แล้วก็ไปที่ channels คุณเลือก แล้วคลิกที่ Connect ตอนนี้ก่อนที่คุณจะคลิก Go ให้แน่ใจว่าคุณเข้าสู่ระบบในหน้า Facebook ของคุณในฐานะผู้ใช้ คุณจึงคลิกที่ Change Account จากนั้นผมจะเปลี่ยนไปยังบัญชี Instagram ที่ผมต้องการติดตั้ง AI agent นี้ขึ้นมา นั่นคือที่ที่ข้อความจะถูกจัดการอัตโนมัติ สำหรับผมคือบัญชีนี้ พอผมเข้าสู่ระบบในบัญชีนี้แล้ว ผมจะเห็นไอคอนรูปโปรไฟล์ตรงนี้ จากนั้นผมคลิกที่ go to Instagram แล้วคลิก allow แล้วมันจะเชื่อมต่อบัญชีนี้ อย่างที่คุณเห็นตรงนี้ เข้ากับแพลตฟอร์มระบบอัตโนมัติของผม แล้วผมก็สามารถสลับกลับได้

ตอนนี้ผมจะเข้าไปที่โปรไฟล์ของผม หรือไปที่ more แล้วสลับกลับไปยังบัญชีอื่น ซึ่งเป็นบัญชีส่วนตัวหรือ Instagram อีกเพจหนึ่งของผม เพื่อที่ผมจะได้ทำหน้าที่เป็นผู้ใช้และทดสอบกระบวนการอย่างถูกต้อง เพื่อให้ผมสามารถส่งข้อความไปกลับระหว่างเพจของผมได้ ตอนนี้เรากลับมาที่แพลตฟอร์มของผม เพราะขั้นตอนถัดไป เราเชื่อมต่อช่องทางแล้ว ขั้นตอนถัดไปที่เราต้องทำคือเพิ่ม custom fields สองสามฟิลด์ ไปที่ settings ไปที่ fields นี่คือ custom fields ที่เราต้องเพิ่ม เพื่อให้เราสามารถประมวลผลและแลกเปลี่ยนค่าและข้อมูลระหว่างเวิร์กโฟลว์ของ AI agent กับระบบอัตโนมัติของ ManyChat ที่เชื่อมต่อกับบัญชี Instagram ของเรา

อย่างแรกที่เราต้องทำคือเพิ่มฟิลด์ user input (ข้อมูลที่ผู้ใช้ป้อน) เพื่อเพิ่มฟิลด์ใหม่ คลิกที่ new แล้วพิมพ์ user input ผมเรียกมันว่า five ก็ได้ คุณสามารถเรียกมันว่า user input ก็ได้ เพราะผมสร้างฟิลด์ชื่อ user ไว้แล้ว จากนั้นเราต้องการ assistant reply (คำตอบของแอสซิสแทนต์) ผมเรียกมันว่า five แต่คุณไม่จำเป็นต้องเพิ่มตัวเลข แล้วเรามีอะไรอีก? เรามี call booked (การจองคอล) ผมเรียกมันว่า five จากนั้นเรามี follow-up send (การส่งข้อความติดตามผล) five แล้วก็ยังมี real name (ชื่อจริง) ที่เราสามารถใช้ได้ และนั่นคือทั้งหมด จากนั้นเราก็ไปต่อที่การตั้งค่าเวิร์กโฟลว์อัตโนมัติตัวแรกของเรา

ตรงนี้คุณคลิกที่ download manager automation part แล้วมันจะเปิดหน้านี้ มันก็เหมือนเทมเพลตระบบอัตโนมัติที่คุณสามารถคลิก save เพื่อนำเข้าอีกที แล้วมันจะนำเข้าตรงเข้าไปในบัญชีของคุณ คุณแค่คลิก save flow ผมปิดหน้านี้ได้ แล้วคุณคลิกที่ view flow จากนั้นตรงนี้ผมเปลี่ยนชื่อเป็นวันที่ปัจจุบัน เพื่อที่ผมจะได้ระบุได้ในภายหลัง ตอนนี้เราต้องเปิด trigger นี้ สิ่งที่เกิดขึ้นคือ เมื่อมีคนส่งข้อความหาคุณที่มีคำเหล่านี้ คำเหล่านี้จะ trigger เวิร์กโฟลว์นี้ที่เชื่อมต่อกับ AI agent ของเรา และมันจะเริ่มกระบวนการคัดกรอง (qualification) โดยพื้นฐานคือ เมื่อมีคนคลิก send message แล้วพิมพ์ว่า can I work with you หรือ can I get a template แล้วนี่จะ trigger ตรงนี้

แต่ยังมีอีกสองสามอย่างที่เราต้องแก้ตรงนี้ อย่างแรก คลิกที่อันที่เป็น actions คุณคลิกเข้าไป แล้วเราต้องเลือกฟิลด์ที่ถูกต้อง นี่คือ user input ในกรณีของผมคือ user input five และค่าเป็น last text input (ข้อความล่าสุดที่ป้อน) มันจะตั้งค่า user input ดังนั้นไม่ว่าผู้ใช้จะพิมพ์อะไร มันจะบันทึกค่าลงในฟิลด์นี้ ฟิลด์นี้จะถูกส่งไปยัง AI agent เพื่อให้มันรู้ว่าข้อความล่าสุดที่ผู้ใช้พิมพ์คืออะไร จากนั้นต้องไปที่ webhook ตรงนี้เราก็แค่ต้องคัดลอก webhook นี้มา เราใช้ test URL สำหรับการทดสอบ คลิก แล้วภายหลังเราจะเปลี่ยนเป็น production URL แต่ตอนนี้คุณต้องใช้ test

จากนั้นเราไปที่ตรงนี้ เราต้องเปลี่ยนตรงนี้ ลบสิ่งที่อยู่ตรงนี้ออก แล้วเพิ่มฟิลด์ custom user ตรงนี้คุณเพิ่ม user input ที่คุณได้สร้างไว้ และนั่นคือทั้งหมด ผมต้องสร้างคอนแทกต์สำหรับทดสอบ ผมจะคลิก save แล้วคลิก และให้แน่ใจว่าอันนี้ถูกสลับเป็น live จากนั้นผมก็สร้างข้อความทดสอบ แต่ข้อความนั้นต้องมีหนึ่งในคีย์เวิร์ดที่เรากำหนดไว้ ผมก็พิมพ์ว่า can I get the template? ตอนนี้ผมจะไม่ได้รับคำตอบ แต่สิ่งที่ผมจะได้คือคอนแทกต์ใหม่จะถูกสร้างขึ้น เมื่อผมเข้าไปตรงนี้และค้นหาคอนแทกต์ของผม นี่ควรจะเป็นบัญชีของผมที่ส่งข้อความมา จากนั้นผมไปที่ body แล้วเราจะเห็นคำตอบ นี่คือสิ่งที่ถูกต้องใช่ไหม? และเมื่อข้อความนี้ถูกต้อง ผมก็สามารถกด Listen for test event ได้ นี่เป็นเพียงการทดสอบสั้น ๆ เพื่อดูว่า webhook ได้รับคำตอบหรือไม่ จากนั้นคุณจะเห็นว่ามันส่งข้อความนี้ ถ้าผมคลิกดู นี่คือสิ่งที่ถูกส่งจริง ๆ มันส่ง contact ID และส่ง user พร้อมข้อความ can I get the template? และนี่หมายความว่าการตั้งค่านี้ทำงานแล้ว

จากนั้นผมกลับมาตรงนี้ ยังมีอีกหนึ่งอย่างที่ผมต้องเปลี่ยน ผมคลิกที่อันที่เป็น assistant reply ตรงนี้ผมต้องตั้งค่านี้ไปที่ฟิลด์ คลิกที่มัน Custom user field ผมต้องตั้งค่าเป็น assistant reply และตรงนี้ที่ส่วนท้าย คุณต้องคลิก แล้วตรงนี้ผมต้องลบอันนี้ออก แล้วเราต้องสลับอันนี้เป็น assistant reply จริง ๆ แล้วเป็น user input ซึ่งก็คือฟิลด์ผู้ใช้ที่คุณมี แล้วอัปเดตมัน และนั่นคือทั้งหมด

สิ่งที่ผมทำได้คือสลับไปที่ production webhook ผมเลือกอันนี้ แล้วเพิ่มตรงนี้ แทนที่อันนี้ด้วย production webhook ลบอันนี้ออก แล้วไปที่ response ตรงนี้ custom field ต้องตั้งค่าเป็น assistant reply ที่คุณมี โดยไม่มีตัวเลขต่อท้าย ในกรณีของผมเพราะผมมีหลายฟิลด์ จากนั้นคลิก save แล้วคลิก update และเพื่อทดสอบจริง ๆ ผมต้องสลับไปที่ active แล้วผมก็สามารถทดสอบเวิร์กโฟลว์ทั้งหมดได้ แต่ก่อนที่เราจะทำ มีอีกหนึ่งอย่างใน ManyChat ที่เราต้องตั้งค่า เราจะทดสอบเวิร์กโฟลว์ในขั้นตอนถัดไป ก่อนที่เราจะไปต่อ แต่ตอนนี้เราต้องนำเข้าเทมเพลตระบบอัตโนมัติอีกหนึ่งอันใน ManyChat เพราะสิ่งที่เราต้องการคือ ระบบอัตโนมัติของเราไม่ควร trigger เฉพาะเมื่อมีคนส่งข้อความหาเรา แต่ควร trigger เมื่อมีคนคอมเมนต์ใต้โพสต์ของเราด้วย

และนั่นคือเหตุผลที่ผมสร้างเวิร์กโฟลว์ ManyChat อีกอันหนึ่งไว้ให้คุณ ผมคลิกที่ส่วนนี้ มันเปิดหน้านี้ คลิกที่ Save to ManyChat คลิกที่ Save แล้วตรงนั้น เราต้องเพิ่ม trigger ตรงนี้ เราสามารถเพิ่ม new user comments on your post (ผู้ใช้ใหม่คอมเมนต์บนโพสต์ของคุณ) จากนั้นคุณสามารถเลือกโพสต์เฉพาะ แต่ผมจะเลือก all posts แล้วตอนนี้คุณต้องเลือกคีย์เวิร์ด ว่าคีย์เวิร์ดไหนควร trigger ตรงนี้ ในกรณีของผมอาจเป็น template หรือ free และเรายังต้องการให้มันเป็นแบบ call หรือ how can I book, Can I get the template? Can I get this free? Free ใช่ไหม? และนี่คือสิ่งที่ผมต้องการให้มีตรงนี้ คลิกที่ save

นี่คือสิ่งที่ผมตั้งค่าไว้ เปิดเผย นี่คือสิ่งที่เกิดขึ้น เมื่อมีคนคอมเมนต์ ข้อความนี้จะถูกส่งเป็นคำตอบถึงบุคคลนั้นโดยอัตโนมัติ และข้อความนั้นจะเป็นแบบนี้: ผมเห็นคอมเมนต์ของคุณ และหนึ่งในนั้น พิมพ์ yes ถ้านี่คือคุณ และถ้าพวกเขาพิมพ์ อย่างแรก เรามาเปลี่ยนชื่ออันนี้เป็น twenty-seven dot five เพื่อให้ผมระบุได้ จากนั้นสลับไป ตอนนี้ผมกลับไปที่ของผม พวกมันถูกเปิดทั้งหมด และคุณเห็นตรงนี้ ถ้ามีคน ผมตั้งอันนี้ไว้ มันจะเริ่มทำงาน และคุณจะเห็นสิ่งนี้เกิดขึ้นแบบเรียลไทม์ เราจะเริ่มกระบวนการทดสอบนี้จริง ๆ ในวิดีโอถัดไป
