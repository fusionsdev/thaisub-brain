## ประเด็นหลัก
- แนะนำ Claude Code เป็นเอเจนต์ช่วยทำ Google Ads แบบ end-to-end
- เซ็ตอัป VS Code + Claude และเชื่อม Google Cloud / OAuth
- รัน audit บัญชี แล้วหา keywords / negative keywords
- สร้างแคมเปญแรก จัด ad groups และกำหนด location/exclusions
- เขียนโฆษณา (headlines/assets) และเช็ก landing page
- ตั้ง conversion tracking ด้วย Tag Assistant
- เผยแพร่ผ่าน GitHub + Vercel ตามเวิร์กโฟลว์ในคลิป
- เน้น automation ที่ตรวจสอบได้ ไม่ปล่อยเอเจนต์รันมั่ว
- ปิดด้วย outro ชวนกลับมาดูคลิปถัดไป
