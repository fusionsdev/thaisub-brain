## ประเด็นหลัก
- OpenAI เปิดตัว ChatGPT desktop app บน Linux เป็นครั้งแรก โดยยังอยู่ในช่วง preview (เวอร์ชันทดลอง) แต่ใช้งานได้จริงตั้งแต่วันนี้
- แอปนี้รวมเครื่องมือสามอย่างไว้ในที่เดียว ได้แก่ Chat, Work และ Codex
- Chat คือการถามตอบแบบเดิม เร็วและง่าย
- Work ใช้ทำงานหลายขั้นตอน เช่น วิจัยข้อมูล สร้างเอกสาร สเปรดชีต สไลด์ และรายงาน
- Codex ใช้เขียน แก้ และเทสต์โค้ด รวมถึงสแกนทั้งโฟลเดอร์เพื่อหาข้อผิดพลาด
- ฟีเจอร์ Projects ช่วยจัดเก็บไฟล์ แชต และคำสั่งไว้ในที่เดียว เหมือนโฟลเดอร์
- ตัวอย่างการใช้งานจริง เช่น วางแผนคอนเทนต์ทั้งเดือน หรือให้ Codex เร่งความเร็วเว็บไซต์
- ChatGPT เริ่มทำงานร่วมกับสิ่งที่ทำในเบราว์เซอร์ได้ (browser workflows) และกำลังกลายเป็นพื้นที่ทำงานเต็มรูปแบบ
- ข้อจำกัด: รองรับเฉพาะ Ubuntu 24.04, Ubuntu 26.04, Debian 13, Fedora 43 และ Fedora 44 (ทั้ง x64 และ arm64)
- ฟีเจอร์บางอย่าง เช่น voice ใน Work หรือ Codex ยังมีเฉพาะบน Mac และ Windows
- การเปิดตัวบน Linux เป็นส่วนหนึ่งของแผนใหญ่ที่ OpenAI วางไว้ คือรวม Chat, Work และ Codex เข้าด้วยกันบนทุกระบบ
- ช่วงท้ายโปรโมต AI Profit Boardroom และ AI Success Lab สำหรับเจ้าของธุรกิจที่อยากใช้ AI อัตโนมัติ
