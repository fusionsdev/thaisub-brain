## บทนำ

บทเรียนว่าด้วยฟังก์ชัน Compact และ Clear ใน Claude Code ซึ่งใช้จัดการ context window ฟังก์ชัน Compact จะย่อและสรุปบทสนทนาเพื่อเปิดพื้นที่ใหม่ ในขณะที่ Clear จะล้างบทสนทนาทั้งหมดเพื่อเริ่มต้นใหม่ โดยผู้สอนอธิบายความแตกต่างของทั้งสองฟังก์ชันพร้อมสาธิตการใช้งานจริง

## คำแปลเต็ม

ทุกคนครับ วันนี้เราจะพูดถึงฟังก์ชัน compact และ clear ครับ ฟังก์ชันเหล่านี้ทำอะไรบ้าง มันช่วยให้คุณ compact การสนทนาของคุณได้ คุณจะเห็นว่าผมใช้ไปแค่ 4% เอง ผมยังไม่ได้ใช้ context window มากนัก แต่ในแต่ละ context ของ Claude Code คุณมี context ให้ใช้จำกัด เมื่อคุณเริ่มใช้มันเยอะขึ้น จนถึงประมาณ 80% คุณต้องทำสิ่งที่เรียกว่าการ compact การสนทนา

การ compact การสนทนาคืออะไร มันก็คือการบีบอัดและสรุปทุกอย่างที่คุณคุยมา แล้วส่งต่อไปยังการสนทนาถัดไปใน Claude Code มันยังเข้าถึงข้อมูลเก่าได้ แต่มันไม่ใช่ context เต็ม ๆ และมันจะเปิดหน้าต่างใหม่ให้คุณ ดังนั้นถ้าคุณกลับมา กด compact แล้วกด enter มันก็จะทำการบีบอัดการสนทนา มันจะเอาบทสนทนาที่เรามีอยู่ แล้วย่อให้เล็กลงมาก นี่คือคำสั่ง compact และผมจะโชว์ว่ามันทำงานยังไง มันใช้เวลาสองสามนาทีในการประมวลผล ขอแบ่งหน้าจอก่อนนะครับ ผมจะทำ resume ตรงนี้ แล้วเลือกอันนี้ นี่คือสิ่งที่เราคุยกันเรื่อง TM หรืออะไรสักอย่าง ผมว่ามันน่าจะเป็นบทเรียนก่อนหน้านี้

แล้วก็มีสิ่งที่เรียกว่า clear ครับ clear ทำอะไร มันก็แค่ล้างการสนทนาทั้งหมด นั่นคือทั้งหมดที่มันทำ ล้างทุกอย่าง แล้วคุณก็เริ่มต้นใหม่จากศูนย์ ผมแค่กด แล้วเราก็เริ่มจากจุดเริ่มต้น นี่ต่างจาก compact เพราะ compact อย่างน้อยก็สร้างสรุปว่าคุณกำลังทำงานอะไรอยู่ แล้วส่งต่อไปยังการสนทนาถัดไป พอทำเสร็จ คุณจะเห็นว่ามันถูก compact แล้ว ถ้าผมกด Ctrl+O มันจะเปิดสรุปทั้งหมดที่มันทำขึ้นมา compact summary มันสร้างสรุปของบทสนทนาครั้งล่าสุด และมันอ่านสกิลด้วย แล้วตอนนี้เราก็คุยกันต่อได้ โดยมันยังอ้างอิงสิ่งที่เราคุยไว้ครั้งก่อน ในขณะที่ clear ไม่มี context เกี่ยวกับอะไรที่เราทำมาจนถึงตอนนี้เลย นั่นคือสองฟังก์ชันนั้นครับ
