## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 1 ของการตั้งค่า AI Agent สำหรับสร้างวิดีโอโซเชียลมีเดีย โดยเริ่มจากการเชื่อมต่อ Telegram trigger, ตั้งค่า Google Sheets สำหรับเทมเพลตและข้อมูลที่สร้าง, กำหนด system instructions ให้ AI agent และเชื่อมต่อบัญชี Anthropic (Claude) ซึ่งเป็นโมเดลหลัก แล้วทดสอบการทำงานตั้งแต่การสร้างหัวข้อ คำบรรยาย จนถึงการบันทึกข้อมูลลงชีต

## คำแปลเต็ม

จากนั้นตรงนี้ คุณไปที่ Download AI Agent Workflow แล้วคลิก Import from File แล้วนำเข้า AI Agent ที่เพิ่งดาวน์โหลดมา ตรงนี้ไง สิ่งเดียวที่เหลือคือเชื่อมต่อโมดูลต่าง ๆ ตรงนี้คุณจะเห็นสามส่วนของมัน ส่วนแรกคือสร้างชื่อเรื่องและคำบรรยายสำหรับวิดีโอ ซึ่งก็คือข้อความที่ใส่ลงในวิดีโอและเผยแพร่ไปพร้อมกับมัน จากนั้นเราต้องสร้างวิดีโอจริงจากข้อความ และส่วนสุดท้ายคือกระบวนการเผยแพร่

เราจะเริ่มจาก trigger ตรงนี้ก่อน นั่นคือ Telegram trigger ดับเบิลคลิก แล้วคุณต้องเชื่อมต่อบัญชี Telegram แต่ก่อนหน้านั้นขั้นตอนแรกคือดาวน์โหลดแอป Telegram ลงโทรศัพท์และคอมพิวเตอร์ของคุณ เพราะมันสะดวกกว่าที่จะสลับไปมาระหว่างอุปกรณ์เพื่อทำการตั้งค่าให้ครบ และสิ่งที่ต้องทำคือ คลิก create a new ถ้าคุณยังไม่ได้เชื่อมต่อ คุณต้องใส่ access token ผมจะไม่ลงรายละเอียดเรื่องการเชื่อมต่อเหล่านี้ เพราะคุณดูวิดีโอ "get API key from Telegram" ได้เลย ผมอธิบายไว้แล้ว ใช้เวลาไม่กี่วินาที แล้วคุณก็นำ access token มาวางแล้วคลิก save ผมทำไว้แล้วตรงนี้

ส่วนถัดไปคือสวิตช์ ซึ่งเราไม่จำเป็นต้องใช้ เพราะวิธีการทำงานของ AI agent ตัวนี้คือ ขั้นแรก เมื่อผมไปที่ด้านบน จะเห็นว่ามันเริ่มต้นเมื่อผมพูดว่า "start" เมื่อพูดคำนี้ มันจะ trigger การทำงานของ workflow ที่จุดเริ่มต้น ขั้นแรกคือสร้างข้อความที่ใส่ลงวิดีโอและข้อความ caption และขั้นแรกที่เกิดขึ้นจริงคือสร้างวิดีโอ ดังนั้นสิ่งเดียวที่คุณต้องเพิ่มหรือเปลี่ยนคือ Google Sheet

ผมเตรียม Google Sheet template ไว้ให้คุณแล้ว ซึ่งก็คืออันนี้ คลิกที่มัน แล้วคลิก make a copy จากนั้นคลิก Create Credential แล้วเข้าสู่ระบบหรือลงชื่อเข้าใช้ด้วยบัญชี Google เดียวกับที่ Google Sheet นี้เชื่อมต่ออยู่ แล้วตรงนี้ผมจะเปลี่ยนชื่อเป็น "my demonstration" เท่านั้นเอง

เมื่อเข้าไปข้างในและคลิกที่มัน ผมควรพบมันแล้ว ตรงนี้เราต้องเลือก generated posts ก่อน อย่างที่เห็น Google Sheet แบ่งเป็นสองส่วน เรามี templates ซึ่งเป็นข้อความที่ AI agent ใช้เป็นฐานในการสร้างเนื้อหา และผมจะลงรายละเอียดเพิ่มเติมในอีกไม่กี่ขั้นตอนถัดไป และตรงนี้คือข้อมูลทั้งหมดที่เราต้องบันทึกลง Google Sheet เพื่อประมวลผลวิดีโออย่างถูกต้องและสร้างมันขึ้นมา ตรงนี้คุณจะเห็นว่า video ID ถูกสร้างขึ้น เมื่อทำเสร็จแล้ว ตรงนี้เราก็ต้องไปที่ส่วนนี้ด้วย ซึ่งก็แค่บัญชี Chrome ฝั่งขวา ถ้าคุณมีหลายบัญชี เท่านั้นเอง นี่คือทั้งหมดที่ต้องทำ

ตอนนี้คลิก test workflow แล้วทดสอบสาขาแรกตรงด้านบน นี่คือลักษณะ AI agent ของผมเมื่อคลิกที่มัน จากนั้นพิมพ์ "start" แล้วเห็นว่ามันทำงานแล้ว ตอนนี้มันไปที่ขั้นตอนแรก นั่นคือสร้าง video ID แล้วส่งข้อความยืนยันกลับมา: "วิดีโอของคุณถูกสร้างแล้ว นี่คือตัวระบุเฉพาะที่เราต้องใช้ในการประมวลผลวิดีโอชิ้นนี้ผ่าน workflow ต่าง ๆ เหล่านี้" และเรายังเห็นว่า video ID ถูกบันทึกลงใน Google Sheet ด้วย ซึ่งสำคัญมาก และมันทำงานได้

ต่อไปคือโมดูล AI agent ตรงนี้ สิ่งเดียวที่ต้องตั้งค่าคือ Telegram ให้แน่ใจว่าเชื่อมต่อบัญชีที่ถูกต้องแล้ว ไม่ต้องทำอย่างอื่น เพราะมันมี system message อยู่แล้ว แน่นอนว่าคุณสามารถปรับเปลี่ยนทุกส่วนของ AI agent ที่เราตั้งค่านี้ให้เข้ากับความต้องการหรือผลลัพธ์ที่คุณต้องการได้ แต่ทุกอย่างที่อยู่ในนั้นทำงานได้อยู่แล้ว

ผมจะอธิบายสั้น ๆ ว่ามันทำงานอย่างไร system instructions ของ AI agent ก็คือคุณบอกมันว่าควรทำอะไร และมีเครื่องมืออะไรที่ใช้ได้บ้างเพื่อทำงานให้สำเร็จ นั่นคือเหตุผลที่ผมระบุในส่วนต่าง ๆ เหล่านี้: รูปแบบทั่วไปควรเป็นอย่างไร? ขั้นตอนที่ควรพาผู้ใช้เดินผ่านคืออะไร? สิ่งที่สร้างในแต่ละขั้นตอนคืออะไร? และควรทำอะไรในแต่ละขั้นตอน? ทั้งหมดนี้ถูกกำหนดไว้ตรงนี้

ต่อไป เรามี Google Sheet template ตรงนี้ต้องเปิดมันแล้วจับคู่กับบัญชี Google Sheets หลัก นี่คือจุดที่มันอ่าน templates เราต้องใช้ templates คุณเพิ่มเทมเพลตของคุณเองได้ตรงนี้ ผมสร้างไว้ให้แล้ว เพื่อให้คุณเห็นว่ามันทำงานอย่างไร คุณสามารถไปที่โซเชียลมีเดียใดก็ได้ ถ้าเจอวิดีโอที่ชอบ ซึ่งมี caption และข้อความ หรือข้อความชื่อเรื่อง โดยปกติจะมีข้อความด้านบนและด้านล่าง คุณก็บันทึกมันไว้ตรงนี้ แล้วคัดลอกวางข้อความเหล่านั้นลงตรงนี้ จากนั้นมันก็เป็นเทมเพลต ซึ่งเป็นโครงสร้างที่พิสูจน์แล้วว่ามีประสิทธิภาพสำหรับคนอื่น และคุณใช้เป็นแบบจำลองเพื่อสร้างข้อความที่วางบนและล่างของวิดีโอ และคุณสามารถใส่เทมเพลตได้ไม่จำกัดจำนวนตามที่เก็บสะสมไว้ แล้ว AI agent ก็เข้าถึงมันได้ นั่นคือจุดประสงค์ของส่วนนี้ เราอ่าน templates ได้ เท่านั้นที่ต้องใช้

ต่อไปไปที่ชีตหลัก ซึ่งเชื่อมกับบัญชีที่ถูกต้องแล้ว คลิกที่มัน ตรงนี้ generate posts ถูกเลือกไว้แล้ว ตรงนี้เราอาจรีเฟรชได้ แต่ผมคิดว่าไม่มีอะไรเกิดขึ้นเพราะมันเป็นสิ่งเดียวกัน เราไม่ต้องใช้มัน มันถูกโหลดไว้แล้ว นี่คือจุดที่ AI agent จะบันทึกข้อความที่สร้างขึ้น (generated posts) ให้เรา และเรายังต้องให้ความสามารถในการอ่านข้อความที่มันบันทึกไว้ด้วย นี่คือส่วนนี้ และเราต้องเลือก generate posts ด้วย เท่านั้นที่ต้องใช้ คลิก save

และเหลืออีกอย่างเดียวคือบัญชี Anthropic ซึ่งก็คือโมเดล AI ซึ่งเป็นสมองของ AI agent คุณสามารถใช้ OpenAI ได้เช่นกัน แค่ลบอันนี้แล้วลาก OpenAI เข้ามา แต่ผมมีประสบการณ์ที่ดีกับ Anthropic ตรงนี้ ถ้าคุณไม่เคยเชื่อมต่อ คุณต้องไปตรงนี้ คลิก แล้วใส่ API key ของคุณ ซึ่งคุณจะพบได้ในส่วน "Get API key from Anthropic" แล้ววางลงตรงนี้ ผมทำไว้แล้ว ดังนั้นกลับไปได้เลย

เราตั้งค่าเสร็จแล้ว ตรงนี้เรายังมีการทดสอบสั้น ๆ อีกครั้งได้ และคุณจะเห็นว่าระบบถามผมว่า "พิมพ์ yes เพื่อดำเนินการต่อ" จากนั้นมันจะพาผมเดินผ่านกระบวนการ มาดูกันว่าจะเกิดอะไรขึ้น มันกำลังคิดและอ่าน templates ของผม รวมถึงเข้าถึง system instructions ของมัน และตอนนี้มันรู้ว่าควรให้อะไรกับผมถัดไป มันให้รายการ templates ที่มีอยู่ใน Google Sheets แก่ผม แล้วให้เลือกเทมเพลตและระบุหัวข้อ

ผมพิมพ์ว่า "ฉันต้องการ template 3 และหัวข้อของฉันคือ plant-based nutrition" แล้วใส่ลงไป คลิก test workflow ตรงนี้มันสร้างชื่อเรื่องขึ้นมา โดยใช้ข้อความชื่อเรื่องจาก template หมายเลข 3: "นี่คือระบบโภชนาการจากพืชของคุณ เรียนรู้ได้ใน 45 นาที และเพิ่มความอึดของคุณอย่างเป็นธรรมชาติ" ตรงนี้ผมบอกว่า "อยากได้ 50 นาที" หรือเปลี่ยนเวลาจาก 45 นาทีเป็น 15 นาที แล้วมันจะปรับข้อความให้จนกว่าผมพอใจ ผมปรับแบบนี้เรื่อย ๆ ได้ และเมื่อพอใจแล้วก็พูดว่า "Save it" มันจะเก็บข้อความนี้ลงใน Google Sheets ของผม เห็นกระบวนการทำงานอยู่แล้ว และเมื่อไปที่ Google Sheets ของผม มันบันทึกในแถวที่ถูกต้อง ซึ่งก็คือแถววิดีโอ และตรงนี้คือ text one และ text two

ต่อไปคือ caption ซึ่งจะถูกสร้างในขั้นตอนถัดไป คุณจะเห็นว่าผมมี caption templates สามแบบ ซึ่งเป็นเทมเพลตคำบรรยายที่ผมเลือกใช้ได้ ผมจะใช้ template 3 เช่นกัน กลับไปทดสอบ แล้วมันจะสร้าง caption ให้ผม และเมื่อเสร็จแล้วก็ไปต่อขั้นตอนถัดไป ตรงนี้ caption ถูกสร้างแล้ว ผมสามารถบอกให้มันยึดตามเทมเพลตตัวอย่างที่มันแสดงให้ดูเป๊ะ ๆ แล้วปรับโครงสร้างเล็กน้อยให้ใกล้เคียงเทมเพลตมากขึ้น เพราะเห็นว่าอันนี้ยาวกว่าตัวอย่าง และอันนี้ของผมเน้นแค่การกระตุ้นให้คนมีส่วนร่วม แล้วเมื่อพอใจก็คลิก save มันควรบันทึกลงใน generated post text ของผม ในส่วน caption text และมันก็ปรากฏตามนั้น

ตอนนี้เรามีทุกอย่างที่ต้องใช้เพื่อไปต่อและสร้างวิดีโอได้แล้ว
