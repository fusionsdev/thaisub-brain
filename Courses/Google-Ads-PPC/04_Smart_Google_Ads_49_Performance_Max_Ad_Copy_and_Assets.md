## บทนำ

คลิปนี้พูดถึงกลยุทธ์การเขียนข้อความโฆษณา (ad copy) และการเลือก assets สำหรับแคมเปญ Performance Max ซึ่งต่างจากแคมเปญประเภทอื่น เพราะโฆษณาสามารถแสดงบนหลายช่องทาง ต่อผู้ชมหลายกลุ่ม ในหลายช่วงของเส้นทางลูกค้า พร้อมหลักการเขียน headline และ description ให้แตกต่างและมีเอกลักษณ์ ไม่ซ้ำซาก ปรับข้อความให้เข้าถึงผู้ชมหลากหลาย รักษาความสอดคล้องระหว่างข้อความกับรูปภาพและวิดีโอ และคำแนะนำเรื่องวิดีโอสำหรับแคมเปญ

## คำแปลเต็ม

Brett พูดเรื่อง ad copy และ assets ไปบ้างแล้ว แต่วิธีที่เราจัดการกลยุทธ์ข้อความสำหรับ Performance Max แตกต่างจากแคมเปญอื่นเล็กน้อย ผมเลยอยากพูดแยกให้ชัดเจน

สำหรับ Performance Max จำไว้ว่า เรากำลังเขียนข้อความสำหรับโฆษณาที่สามารถแสดงบนหลายช่องทาง ต่อผู้ชมหลายกลุ่ม ในหลายช่วงของเส้นทางลูกค้า (customer journey) ดังนั้นการปรับแต่งโฆษณาให้เฉพาะกลุ่มจึงยากกว่าโฆษณาที่อื่น เราจะมาพูดถึงวิธีสร้างโฆษณา Performance Max ที่ปรับใช้ได้กับทุกช่องทาง และพูดกับผู้ชมหลายกลุ่มพร้อมกัน

สิ่งแรกคือเรื่องตำแหน่งโฆษณา (ad placements) เราต้องคิดว่า headline ของเราจะอ่านยังไงเมื่อแสดงรวมกัน สำหรับโฆษณา search ที่คุณเห็น headline สองถึงสามบรรทัดพร้อมกัน หรือแสดงเดี่ยวๆ บน display และ discovery

เพราะฉะนั้นมันสำคัญมากที่แต่ละ headline และ description ต้องมีเอกลักษณ์เฉพาะตัว คุณต้องโปรโมตประโยชน์หรือฟีเจอร์ที่แตกต่างกันในทุก headline และทุก description คุณไม่ต้องการ headline หลายอันที่พูดเรื่องเดียวกัน เพราะมันซ้ำซาก ให้ประสบการณ์ผู้ใช้แย่ และยังทำให้คุณใช้พื้นที่โฆษณาที่มีอยู่จำกัดได้ไม่เต็มที่

แต่ต้องแน่ใจว่าแต่ละ headline พูดถึงคนละเรื่อง สิ่งที่คุณไม่ควรทำเด็ดขาดคือการใช้ headline เดียวกันแบบเปลี่ยนคำนิดหน่อย นี่คือสิ่งที่ผมหมายถึง: ดูสองอันนี้ "best skincare for women" กับ "top women's skincare" นี่อาจเป็นคู่ที่เราทดสอบในโฆษณา search เพื่อดูว่า best หรือ top ได้ผลดีกว่า แต่มันไม่ใช่คู่ที่เหมาะสำหรับ Performance Max เพราะเมื่ออ่านรวมกันมันก็ไม่ค่อยสมเหตุสมผล คุณกำลังพูดถึงแค่สกินแคร์ โดยไม่ได้โปรโมตฟีเจอร์และประโยชน์ทั้งหมดของคุณ

ดังนั้นมันควรเป็นแบบ "best skincare for all natural ingredients" เป็นต้น

แล้วก็เรื่องผู้ชม (audiences) คุณต้องแน่ใจว่าข้อความของคุณโดนใจผู้ชมหลากหลายกลุ่ม เพราะไม่ว่าคุณจะใส่กลุ่มผู้ชมอะไรลงใน Performance Max มันจะไปไกลกว่ากลุ่มนั้น พวกมันคือสัญญาณ (signals) ไม่ใช่คำสั่งตายตัว

การปรับข้อความของคุณให้ตรงกับความสนใจของกลุ่มเดียวมากเกินไป อาจทำให้คุณเสียผู้ใช้กลุ่มใหญ่ไป ยกตัวอย่าง ผมมีลูกค้าที่ขายแหวน และสินค้าส่วนหนึ่งเป็นแหวนแต่งงาน ในโฆษณา display เราสามารถใช้ top-of-funnel targeting เพื่อกำหนดเป้าหมายคนที่กำลังวางแผนแต่งงาน และในโฆษณาเราจะพูดเจาะจงว่าแหวนเหล่านี้สำหรับงานแต่งงาน

แต่ถ้าแคมเปญ Performance Max ถูกปรับให้เหมาะสมกับกลุ่มผู้ชมที่ชอบรองเท้า คนที่มองหารองเท้าอาจเป็นผู้ซื้อที่สมบูรณ์แบบสำหรับแหวนของเรา แต่พวกเขาจะเลื่อนผ่านโฆษณาเราไป ถ้าโฆษณาพูดถึงแต่แหวนแต่งงาน

คุณต้องรักษาข้อความให้โฟกัสที่คุณค่าของแบรนด์คุณ แทนที่จะพูดตรงๆ กับกลุ่มใดกลุ่มหนึ่งโดยเฉพาะ ดังนั้นให้โฟกัสที่แบรนด์และสินค้าของคุณ มากกว่าตัวผู้ใช้

ข้อความของคุณควรพูดกับทั้งลูกค้าใหม่และลูกค้าที่กลับมา แม้ว่าสัญญาณของคุณจะหนักไปทาง bottom of funnel โฆษณาของคุณก็ยังแสดงต่อผู้ชมใหม่ (cold traffic) อยู่ดี คุณจึงควรผสม headline สักสองสามอันที่พูดกับผู้ชม top of funnel และอีกสองสามอันที่เหมาะกับการ remarketing (การตลาดกับคนที่เคยมีปฏิสัมพันธ์แล้ว)

และสุดท้าย ตรวจสอบให้แน่ใจว่าข้อความ รูปภาพ และวิดีโอของคุณสอดคล้องกัน ถ้าข้อความของคุณเจาะจงสินค้า คุณก็ควรใส่เฉพาะรูปภาพของสินค้านั้น และเช่นเดียวกันกับหมวดหมู่ ถ้า asset group ของคุณเกี่ยวกับหมวดหมู่หนึ่ง ก็ใส่เฉพาะรูปภาพของหมวดหมู่นั้น

คุณไม่ต้องการทำให้ผู้ใช้สับสน นี่เหมือนกับการโชว์ไดร์เป่าผม ในขณะที่โฆษณาพูดถึงยาย้อมสีผม คุณแค่ไม่ควรทำแบบนั้น มันไม่สมเหตุสมผล เป็นประสบการณ์ผู้ใช้ที่แย่ และผลลัพธ์ก็จะไม่ดี

สำหรับวิดีโอ ถ้าคุณไม่อัปโหลดวิดีโอของคุณเอง Performance Max จะสร้างวิดีโอให้คุณ มันจะใช้รูปภาพที่คุณให้พร้อมกับข้อความ เพื่อสร้างวิดีโอสั้นๆ พร้อมดนตรี วิดีโอเหล่านี้ดูเหมือนสไลด์ PowerPoint ที่มีแอนิเมชัน มันไม่ค่อยดีเท่าไหร่

ดังนั้นถ้าคุณมีวิดีโอสินค้าของคุณเอง ควรใช้มันเด็ดขาด ถ้าคุณไม่มีวิดีโอเลย Google มีเครื่องมือ video builder ให้ ซึ่งจะให้คุณควบคุมข้อความและรูปภาพได้ คุณยังสร้างสคริปต์เพื่อเพิ่มเสียงพากย์ ทำให้วิดีโอมีคุณภาพสูงขึ้นได้

วิดีโอเหล่านี้ไม่ได้ดีที่สุด แต่ก็ดีกว่าวิดีโอที่สร้างอัตโนมัติภายใน Performance Max เพราะคุณควบคุมข้อความและเพิ่มเสียงพากย์ได้ ถ้าคุณไม่มีวิดีโอเป็นของตัวเอง ควรใช้เครื่องมือ video builder แทน แต่ตัวเลือกที่ดีที่สุดคือใช้วิดีโอของคุณเอง

Performance Max เราต้องทำหน้าที่ของเราด้วย และถ้าไม่มีข้อมูลที่ถูกต้อง เราก็ไม่สามารถใช้ศักยภาพเต็มที่ของมันได้ ผมอยากให้คุณใช้เวลาวางแผน ad copy ข้อความ และ assets ของคุณ โดยเฉพาะสำหรับ Performance Max ครับ
