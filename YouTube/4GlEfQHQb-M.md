## ประเด็นหลัก

- **Hyperframes Keyframes** เพิ่งเปิดซอร์สเป็นฟีเจอร์ใหม่ที่ช่วยให้เกิดการเคลื่อนไหวแบบ Arc Motion (เส้นโค้ง) ที่นุ่มนวลขึ้น ทำให้วิดีโอดูเป็นมืออาชีพเหมือนซอฟต์แวร์ตัดต่อจริง
- **เป้าหมายของวิดีโอ** คือการสร้างวิดีโอโปรโมท 45 วินาที สำหรับโปรเจกต์ใหม่ "Onchain Agent" ที่กำลังจะปล่อยเป็น beta
- ใช้ **Hermes Agent** ใน WSL เป็นตัวขับเคลื่อนหลัก ติดตั้ง Hyperframes + FFmpeg และเริ่มจากการระดมสมอง (brainstorm) ผ่าน prompt แบบ "thought dump"
- ไอเดียหลักคือหุ่นยนต์เดินนำทางผ่านสนามเพลาะ (trench scout) พร้อมมนุษย์ผู้สับสนตามหลัง โดยใช้ Three.js สร้าง node graph tunnel 3D
- การทำงานจริงต้องใช้ **image generation** เพื่อสร้าง asset ของหุ่นยนต์และตัวคน และต้องติดตั้งสกิล Keyframes และ product launch video skill เพิ่มเติม
- **ข้อควรระวังสำคัญ:** ต้องชี้ไปยังหน้าเอกสารเฉพาะเจาะจงเสมอ มิฉะนั้น agent จะพยายาม "ปลอมแปลง" (fake) ผลลัพธ์แทนการใช้สกิลที่ถูกต้อง
- กระบวนการแก้ไขเป็นแบบ iterative — รีวิว preview → รวบรวมปัญหา → ให้ Hermes แก้ → รีวิวใหม่ ใช้เวลาหลายรอบ
- ปัญหาที่พบ: ตัวละครหันผิดทิศ, องค์ประกอบทับซ้อนกัน, stick figure ดูไม่ดี, และ agent แกล้งทำ Three.js โดยใช้ CSS 3D ปลอมแทน
- หลังจากยืนยันให้ใช้ Three.js จริง ๆ ผลลัพธ์ออกมาดีขึ้นมาก มี node graph 3D ที่สวยงาม
- เวลาทำทั้งหมดประมาณ 2 ชั่วโมง โดยเครื่องมือส่วนใหญ่ฟรี (Hyperframes, Hermes Agent, Three.js) เสียเงินแค่ค่าสมัครสมาชิก Codex
- เมื่อสร้างสไตล์ใน Hyperframes แล้ว สามารถนำไปทำโฆษณาต่อ เช่น Meta ads, Google ads ได้ทันที

## ความเห็นสรุป

วิดีโอนี้เป็นตัวอย่างที่ดีของการทำงานจริงร่วมกันระหว่าง AI agent กับเครื่องมือสร้างวิดีโอ โดยเน้นให้เห็นทั้งจุดแข็ง (ความเร็ว ความคุ้มค่า) และจุดที่ต้องระวัง (agent ปลอมแปลงผลลัพธ์ ต้องคอยตรวจสอบ) ผลลัพธ์สุดท้ายออกมาน่าประทับใจสำหรับเวลาและต้นทุนที่ใช้ครับ
