## บทนำ
บทเรียนนี้มาจากคอร์ส Master Google Ads Conversion Tracking ของ Bob Miles สอนวิธีติดตามการส่งฟอร์ม (form submission) ด้วย Google Tag Manager (GTM) โดยใช้เทคนิค thank you page URL เฉพาะของแต่ละฟอร์ม พร้อมขั้นตอนสร้าง conversion action ใน Google Ads, ตั้งค่าแท็กคอนเวอร์ชันใน GTM และทดสอบการทำงานจริงในโหมด preview

## คำแปลเต็ม

คุณสามารถติดตามการส่งฟอร์มได้หลายวิธี และผมชอบติดตามด้วยการอ้างอิงจาก URL ของหน้า thank you page ที่เชื่อมกับฟอร์มเฉพาะที่ต้องการติดตาม ตรงนี้คุณจะเห็นเว็บไซต์ส่วนตัวของผม พร้อมหน้าเนื้อหาของผม และตรงนี้คุณจะเห็นฟอร์มติดต่อฟอร์มหนึ่งที่ผมติดตั้งไว้บนเว็บไซต์

สิ่งที่ผมทำคือสร้างหน้า thank you page ที่ไม่ซ้ำใคร เรียบง่ายมาก พร้อม URL เฉพาะ จากนั้นลิงก์มันเข้ากับฟอร์มนี้โดยเฉพาะ และเมื่อมีคนส่งฟอร์มติดต่อ สำเร็จแล้ว บุคคลนั้นจะถูกเปลี่ยนเส้นทางไปยัง URL ของหน้า thank you page ที่ลิงก์ไว้นั้น

ผมจะไม่ทำให้คุณเบื่อกับค่าตั้งค่าที่ผมใช้ เพราะแพลตฟอร์ม CMS ของผมอาจต่างจากของคุณ และปลั๊กอินฟอร์มติดต่อของผมก็อาจต่างกันด้วย ควรศึกษาข้อมูลด้วยตัวเอง ถึงวิธีตั้งค่า redirect หลังจากที่ฟอร์มถูกส่งและกรอกเรียบร้อยแล้ว และถ้าคุณทำเองไม่ได้ คุณอาจต้องขอความช่วยเหลือจากนักพัฒนาเว็บ

มาเริ่มด้วยการตรวจสอบก่อนว่าทุกอย่างทำงานถูกต้อง นี่จะเป็นการส่งแบบทดสอบ และอย่างที่คุณเห็น ผมถูกเปลี่ยนเส้นทางไปยังหน้าที่ไม่ซ้ำใคร คุณมองไม่เห็น URL แต่ URL อยู่ด้านบน มันคือ /en/contact-thank-u/ นี่คือหน้า thank you page เฉพาะที่เราจะใช้ในแท็กของเรา

เริ่มจากขั้นตอนแรกกัน นั่นคือการสร้างคอนเวอร์ชันใน Google Ads ภายใน Google Ads เราจะไปที่ Tools and Settings จากนั้นไปสร้าง conversion action ใหม่ นี่จะเป็น website pixel โดเมนของเว็บไซต์ผมคือ bobmayer.nl เราจะเพิ่ม conversion action แบบ manual และเราจะเลือก goal ซึ่ง goal ในที่นี้คือ contact goal ผมต้องการให้คอนแทกต์นี้เป็น account default goal ผมอยากใช้มันเพื่อการประมูล ดังนั้นจะตั้งเป็น primary จากนั้นสร้าง contact form ยังไม่กำหนดค่า value ใด ๆ ในตอนนี้ ผมต้องการนับคอนเวอร์ชันเฉพาะหนึ่งครั้งต่อหนึ่งคลิก/อินเทอร์แอ็กชัน ผมจะใช้การนับแบบ 90-day click-through conversion และตอนนี้เรายังไม่เปิดใช้ Enhanced Conversions ส่วน attribution model แบบ data-driven เป็นค่าเริ่มต้น เรามากดบันทึกและไปต่อกัน

จากนั้นเราจะใช้ Tag Manager เพื่อตั้งค่าแท็กเฉพาะนี้ ตรงนี้คุณจะเห็นว่าเรามี conversion ID และ conversion label ซึ่งก็คือตัวนี้ และเราจะต้องใช้ทั้งสองค่านั้นใน Google Tag Manager ไปที่ Google Tag Manager กันเถอะ และตอนนี้เรายังคงเปิดแท็บหน้าต่างนี้ไว้

ภายใน GTM ของผม นี่เป็นแค่อะเคานต์ทดลอง ที่ยังไม่มีแท็กอะไรเลย เราจะสร้างแท็กคอนเวอร์ชันใหม่ เราจะตั้งชื่อว่า "Google Ads Conversion Tracking – Contact form" เพื่อให้สังเกตเห็นได้ง่ายในคอนเทนเนอร์ของเรา สำหรับตัวแท็ก เราจะใช้ Google Ads Conversion tag จากนั้นเราจะสร้างคอนเวอร์ชันนี้ เนื่องจากเรายังไม่เคยสร้างมาก่อน แต่ตอนนี้เรามีแล้ว และตรงนี้เราต้องกรอก conversion ID และ conversion label เพื่อส่งข้อมูลเหล่านี้ไปยัง Google

กลับไปที่ Google Ads อีกครั้ง ตรงนี้เราสามารถคัดลอก conversion ID วางข้ามมาที่นี่ และคัดลอก label ด้วย แล้ววางไว้ตรงนี้ เท่านั้นเอง นี่คือข้อมูลทั้งหมดที่ Google Tag Manager ต้องการ เพื่อส่ง conversion tracking ID และ label ของ Google Ads ไปยังบัญชี Google Ads ของคุณ แล้วเชื่อมคอนเวอร์ชันของคุณ เมื่อมีคนเยี่ยมชมหน้า thank you page ของคุณ จากการคลิกโฆษณา Google Ads แน่นอน

ส่วนนี้เป็นขั้นสูงทั้งหมด เราจะข้ามไปก่อน เราจะพูดถึงมันในบทเรียนต่อ ๆ ไป

จากนั้นเราจะตั้งค่า triggering เนื่องจากเราตั้งค่าแท็กของเราเรียบร้อยแล้ว ตอนนี้เราต้อง trigger แท็ก นี่คือ page view trigger ที่เราจะใช้ เพราะเราต้องการ trigger แท็กเมื่อหน้าเพจเฉพาะหนึ่งถูกเปิดดู และหน้านั้นคือหน้า contact thank you URL ที่ผมเพิ่งกล่าวถึง เรายังไม่ได้สร้าง trigger สำหรับอีเวนต์หรือหน้า thank you นี้ ดังนั้นมาสร้าง trigger กันก่อน มันคือ page view trigger และชื่อว่า "Contact form EN Thank you page"

ตรงนี้ผมจะตั้งค่า trigger ของผม มันคือ page view trigger เราต้องการติดตามการเปิดดูบางหน้า และเราต้องการติดตาม page path เฉพาะ ที่มีสตริงนี้อยู่ โดยคัดลอกและวาง path ที่มีสตริงดังกล่าว คุณยังสามารถใช้การวาง URL และวาง URL เต็มได้ด้วย แต่ผมชอบใช้ page path เพื่อไม่ต้องรวมโดเมนของผมเข้าไป เท่านั้นเอง ผมจะบันทึกมัน และตอนนี้มันจะเชื่อมกับชุดแท็กของผมโดยอัตโนมัติ

ตอนนี้ผมมีแท็กที่ตั้งค่าเรียบร้อย และมี triggering ที่ตั้งค่าเรียบร้อย ดังนั้นทันทีที่ผู้คนเยี่ยมชมหน้า contact thank you ภาษาอังกฤษ conversion tracking pixel จะถูกยิง และส่งข้อมูลไปยัง Google Ads เราจะบันทึกอันนี้ จากนั้นเราจะ submit และ publish แท็ก เท่านั้นเองครับ

ยังมีอีกหนึ่งสิ่งที่คุณควรทำ นั่นคือการดีบักชุดติดตามของคุณ เราจะใช้โหมด preview ของ GTM จากนั้นนำเว็บไซต์ของเรามาใส่ นี่คือหน้าติดต่อปกติ และอย่างที่คุณเห็น tag assistant เชื่อมต่อสำเร็จแล้ว ตรงนี้ด้วย ตรงนี้คุณจะเห็นว่าแท็กใหม่ของเรายังไม่ถูกยิง และนี่เป็นสิ่งที่ดี เพราะเราไม่อยากให้มันยิงตอนเปิดดูหน้าติดต่อปกติ เราอยากให้มันยิงเมื่อฟอร์มถูกส่งแล้ว

มาดูกันว่ามันทำงานได้ไหม ส่งคำขอติดต่อของฉัน ไปแล้วครับ เราถูกส่งไปยังหน้า contact thank you ของเรา และอย่างที่คุณเห็น เราจะเห็น contact thank you และแท็กของเราเพิ่งถูกยิง แท็กถูกยิงแล้ว คุณเห็นมันตรงนี้ มันทำงานได้อย่างถูกต้องและเหมาะสม ควรจะทำงานได้ดี เท่านั้นเองครับ

ผมหวังว่าวิดีโอนี้จะช่วยคุณในการตั้งค่า conversion action สำหรับการส่งฟอร์ม ถ้าคุณต้องการความช่วยเหลือหรือความช่วยเหลือเพิ่มเติม บอกผมได้เลย เพื่อผมจะได้ช่วยคุณออก
