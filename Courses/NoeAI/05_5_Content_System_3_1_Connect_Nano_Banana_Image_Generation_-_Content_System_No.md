## คำแปลเต็ม

ว่าไงครับทุกคน? ในวิดีโอนี้ ผมจะโชว์วิธีเชื่อมต่อกับ Nano Banana MCP ครับ เพื่อให้คุณใช้สกิล Nano Banana ที่ผมให้คุณไปได้ สกิลนี้จะทำให้คุณเชื่อมต่อกับบริการสร้างภาพทั้งหมดของ Google Gemini ซึ่งเจ๋งมาก ๆ คุณจะได้สร้าง แก้ไขภาพอะไรก็ได้ที่คุณต้องการภายใน Claude ได้เลย ซึ่งสุดยอดมากครับ

สิ่งที่คุณต้องทำคือ ไปที่เว็บ Gemini เพื่อเอา API key ของคุณ สิ่งที่ต้องทำก็แค่คลิกที่ AI Studio ครับ ซึ่งเป็นที่ที่คุณสร้างภาพสำหรับ Nano Banana โดยตรง ลองเปิดดูนะครับ คุณจะเข้ามาที่หน้า API ซึ่งคุณควรจะไปถึงจุดที่ต้องการ แต่ถ้าเผลอไปที่อื่น ก็แค่เข้ามาที่ตรงนี้ แล้วไปที่ get API key คุณจะเห็น API key และโปรเจกต์ ถ้าคุณเพิ่งเริ่ม คุณอาจต้องสร้างโปรเจกต์ก่อน มันจะให้คุณตั้งชื่อโปรเจกต์ ผมตั้งชื่อของผมว่า super ฮ่า ๆ แต่ก็แค่ตั้งชื่ออะไรก็ได้ แล้วก็กดสร้าง

จากนั้นก็มาสร้าง API key แล้วตั้งชื่ออะไรก็ได้ เช่น Claude ครับ แล้วเลือกอันนั้น กด create มันจะสร้าง API key ให้คุณ แล้วมันจะเด้งอะไรบางอย่างออกมา เห็นไหมครับ มันเด้งขึ้นมาตรงนี้ คุณจะต้องตั้งค่าบัญชีการเรียกเก็บเงิน (billing account) กับ Google และมันจะให้คุณทำ ถ้าคุณไม่เคยทำมาก่อน มันจะบอกว่า free account ก็แค่เดินตามขั้นตอนการตั้งค่า billing account ถ้าคุณทำไม่เป็น ก็แค่แคปหน้าจอ แล้วเอาไปถาม Claude ครับ มันจะพาคุณตั้งค่า billing สำหรับ Google Gemini หรือจะไปถาม Gemini ตรง ๆ ก็ได้

คุณต้องตั้งค่า billing account ก่อน ถึงจะเริ่มใช้สิ่งนี้ได้ ปัญหาที่ผมเจอบ่อยจากคนอื่นคือ พวกเขาตั้งค่าเสร็จ แต่ 24 ชั่วโมงแรกยังใช้ไม่ได้ เพราะ billing กำลังถูกตั้งค่า ซึ่งเป็นเรื่องจริงที่เกิดขึ้นได้ ดังนั้นถ้าใช้งานไม่ได้ ให้รอ 24 ชั่วโมงแล้วกลับมาดูใหม่ครับ

จากนั้นคุณจะคัดลอก API key และดูได้ว่าคุณใช้เงินไปเท่าไรแล้ว ผมเองก็ใช้ API นี้เยอะมาก คุณจะเห็นได้ว่าผมใช้เงินไปเท่าไรในช่วง 28 วันที่ผ่านมา ซึ่งผมใช้เงินไปค่อนข้างเยอะกับการสร้างภาพ แต่ก็คุ้มค่ามากครับ คุณจะมี keys ของคุณ แค่คัดลอก API key ไปใช้

จากนั้นก็ไปที่ Claude แล้วดาวน์โหลด MCP ที่ผมให้คุณไป ดาวน์โหลดมาแล้วก็เข้าไปใน Claude แล้วแกะ zip ออกมา จะเห็นไฟล์ lesson.md ซึ่งเป็นบทเรียนที่ผมสอนคุณจริง ๆ และไฟล์ config.json ซึ่งเป็น MCP server สำเร็จรูป จากนั้นเปิด Claude Code แล้วเรียกใช้ MCP builder พิมพ์ว่า สร้าง MCP server สำหรับ Google AI Studio ให้ฉัน เพื่อสร้างภาพใน Nano Banana โดยใช้ config.json ที่อยู่ในโฟลเดอร์นี้ ซึ่งเป็น MCP server ที่สร้างไว้แล้ว

ตั้งค่าตามนั้นได้เลยครับ คุณไม่ต้องละเอียดขนาดนั้นก็ได้ พิมพ์ง่าย ๆ ว่า build me the NanoBanana MCP แล้วกด enter ยิ่งละเอียดยิ่งดีครับ มันจะติดตั้ง MCP ให้คุณบนคอมพิวเตอร์ แล้วพอเปิดขึ้นมา คุณจะเห็น API key และสิ่งที่มันติดตั้งให้ แล้วก็แค่ใส่ API key ลงไป แล้วทดสอบ พิมพ์ว่า ทดสอบ MCP หน่อย ว่ามันทำงานหรือยัง แล้วก็เสร็จเรียบร้อย คุณจะเชื่อมต่อกับ Nano Banana แล้วครับ

ถ้าพวกคุณเจอปัญหา ก็แค่แคปหน้าจอไปให้ Claude ดู แล้วคุยกับ Claude ให้มันพาคุณทำทีละขั้นตอนเหมือนสอนเด็กประถม จนกว่า MCP จะเชื่อมต่อได้ ทุกอย่างนี้ควรช่วยคุณได้เกือบทั้งหมดครับ ผมอยากโชว์ทุกขั้นตอนให้คุณดูจริง ๆ แต่เราต้องฝึกคิดแก้ปัญหาด้วยตัวเองบ้าง เพราะผมคิดว่าผมจะเป็นครูที่แย่ถ้าไม่ให้คุณลองแก้ปัญหาที่ยากขึ้น แล้วคุณจะเก่งขึ้นเอง นี่คือทั้งหมดของคู่มือตั้งค่า Nano Banana MCP server ครับ ถ้ามีปัญหาอะไร ก็ทักหาผมได้ในคอมมูนิตี้ แล้วเจอกันวิดีโอหน้าครับ
