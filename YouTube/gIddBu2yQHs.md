## ประเด็นหลัก

- T3 Code คือแอปโอเพนซอร์สฟรี ทำหน้าที่เป็น "agent harness control surface" (ตัวควบคุมการทำงานของเอเจนต์ AI) สร้างโดย Theo และทีมงาน มีทั้งเวอร์ชันเดสก์ท็อปและแอปมือถือ
- รองรับเอเจนต์หลายตัวในตัว เช่น Codex, Claude, Cursor, Grok Build และ OpenCode โดยใช้ CLI ของผู้ให้บริการแต่ละรายที่มีอยู่แล้ว
- จุดเด่นคือการทำงานกับ Git: ดู diff ตาม work tree และตามรอบการทำงาน (turn) ของเอเจนต์แต่ละตัว, commit, push และ publish repo ได้จากในแอป
- รองรับ threads หลายตัวพร้อมกันในโปรเจกต์เดียว และ sub agent (เอเจนต์ย่อย) สำหรับโปรเจกต์ใหญ่ที่ต้องทำงานหลายอย่างขนานกัน
- มี actions (คำสั่งลัดระดับโปรเจกต์) เรียกใช้ได้จากแถบด้านบนหรือคีย์ลัด เช่น คำสั่งรันเซิร์ฟเวอร์
- แอปมือถือเชื่อมต่อผ่าน T3 Connect และ relay client ทำให้ทำงานต่อจากเดสก์ท็อปบนโทรศัพท์ได้จริง ทั้งถามเอเจนต์ รันคำสั่ง commit/push
- ผู้รีวิวประทับใจ UI ทั้งบนเดสก์ท็อปและมือถือ ว่าสะอาด ลื่นไหล แม้ยังเป็นช่วงต้นและเจอบั๊กประปราย
- ยังไม่แน่ใจว่าจะแทนที่ herdr ได้หรือไม่ เพราะ herdr ให้การควบคุมมากกว่าและผสานกับ Hermes ได้ แต่จะติดตามการพัฒนาของ T3 Code ต่อไป

## ความเห็นสรุป

วิดีโอนี้เป็นการรีวิวแบบลองใช้จริง (hands-on) ที่ครอบคลุมตั้งแต่ติดตั้งจนถึงใช้งานบนมือถือ เหมาะสำหรับคนที่ใช้เอเจนต์เขียนโค้ดหลายตัวและอยากได้หน้าจอเดียวคุมทั้งหมด โดยเฉพาะฟีเจอร์ work tree, threads แบบขนาน และแอปมือถือคือจุดขายที่โดดเด่น ผู้พูดให้ความเห็นอย่างตรงไปตรงมา ทั้งข้อดีและข้อจำกัดของเครื่องมือ
