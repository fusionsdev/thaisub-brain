# สรุป: SureThing.io: The World's First Always-On Growth Marketing AI Agent

ช่อง: DevsKingdom · ความยาว: 13:48 · ลิงก์: https://www.youtube.com/watch?v=KS45D5CvaRk

- SureThing.io คือแพลตฟอร์ม AI agent (ตัวแทนอัจฉริยะ) ด้าน growth marketing ที่ทำงานตลอดเวลา (always-on) ช่วยให้งานประจำวันเป็นอัตโนมัติ
- เริ่มต้นง่ายๆ แค่สร้างโปรเจกต์ ระบบจะสร้าง agent เริ่มต้นชื่อ project agent ให้อัตโนมัติ
- โครงสร้างของโปรเจกต์ประกอบด้วย conversation (คุยกับ agent), pages (รายงาน), chart and metrics, ส่วน agents และ routines
- มี agent สำเร็จรูปให้เลือกมากมายในส่วน browser agent เช่น social media automation ที่ใช้สาธิตในคลิปนี้
- เดโมสร้างงาน social media automation ให้บริษัทกาแฟอินดี้ เลือกรูปแบบโพสต์ text only และเชื่อมต่อบัญชี Reddit ใหม่
- agent สร้างโพสต์ให้อัตโนมัติ รอการอนุมัติ และตั้งค่าร่างโพสต์รายสัปดาห์ทุกวันจันทร์ 9:00 น.
- โพสต์ลง subreddit ได้ตามต้องการ (เช่น roasting และกลุ่ม RTTM) พร้อมฟีเจอร์ลบหรือเปลี่ยน subreddit ได้
- เชื่อมต่อกับ Notion และโพสต์โน้ตตัวอย่างให้อัตโนมัติผ่านส่วน connection
- ฟีเจอร์ pages สร้างหน้า task tracking พร้อมภาพรวมสดของงาน รีเฟรชอัตโนมัติทุกชั่วโมง แสดงเมตริก เช่น pending 6 รายการ completed 3 รายการ recurring 4 รายการ
- routines ถูกสร้างอัตโนมัติ เช่น weekly social post draft และ routine รีเฟรชหน้า task tracking ตั้งเวลารายชั่วโมงหรือรายวันได้
- รองรับแพลตฟอร์มอื่นๆ เพิ่มเติม เช่น LinkedIn, Twitter และ Linear สำหรับสายโปรเจกต์แมเนเจอร์

ความเห็น: วิดีโอสาธิตการใช้งาน SureThing.io ที่ชัดเจนและเข้าใจง่าย แสดงให้เห็น workflow จริงตั้งแต่สร้างโปรเจกต์จนโพสต์อัตโนมัติ เหมาะสำหรับผู้ที่สนใจใช้ AI agent ทำการตลาดแบบอัตโนมัติ
