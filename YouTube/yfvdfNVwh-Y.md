## ประเด็นหลัก
- OpenMAIC (Open Multi-Agent Interactive Classroom) สร้างห้องเรียน AI จากพรอมต์เดียว
- โปรเจกต์โอเพนซอร์สมีประมาณ 23K stars บน GitHub
- สร้างคอร์ส สไลด์ เอกสาร ควิซ และเอเจนต์ช่วยสอนอัตโนมัติ
- รองรับหลายผู้ให้บริการโมเดล เช่น OpenAI และ Anthropic รวมถึงเสียงและวิดีโอ
- เดโมแรก: สอน Python จากศูนย์ใน 30 นาที พร้อมสไลด์ ครู AI และ interactive whiteboard
- แชทกับสไลด์ ทำควิซ ดูคะแนน และเลื่อนหัวข้อย่อยทีละสไลด์ได้
- เพิ่มตัวละครในห้องได้ เช่น assistant, class clown, curious mind, note taker
- เดโมสอง: เรียนวิธีเล่นบอร์ดเกม Avalon แบบหลายคนคุยและถกเถียงพร้อมกัน
- อัปโหลดเอกสาร เลือกโมเดล ดู token consumption ได้จากหน้า UI
- เซ็ตอัพ: clone → pnpm install → ตั้ง environment (API key, base URL, models) → pnpm dev หรือ build/start
- การสนทนาไม่ใช่ช็อตเดียวจบ แต่เหมือนห้องเรียนจริงที่คุยต่อเนื่อง และหยุดได้เมื่อต้องการ

## ความเห็นสรุป
OpenMAIC เหมาะกับคนที่อยากได้ห้องเรียน AI ครบชุดจากหัวข้อเดียวโดยไม่ต้องออกแบบคอร์สเอง
จุดเด่นคือ multi-agent ในห้องเดียวกัน ทั้งครู นักเรียน และตัวละครบทบาทต่างกัน
ถ้ามี API key และรัน pnpm ได้ ทดลองเซ็ตอัพเองไม่ยากครับ
