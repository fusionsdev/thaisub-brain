## บทนำ

บทเรียนนี้อธิบายการแปลงข้อมูลใน n8n โดยเน้นการใช้ Split Out และ Aggregate nodes เพื่อแยกข้อมูลหนึ่งรายการออกเป็นหลายรายการ หรือรวมหลายรายการกลับเป็นรายการเดียว นอกจากนี้ยังสาธิต Remove Duplicates แบบสั้น ๆ และยกตัวอย่างกับข้อมูลยอดวิวและ spoken hooks

## คำแปลเต็ม

สวัสดีครับ ทุกคน ยินดีต้อนรับเข้าสู่วิดีโอเรื่องการแปลงข้อมูลอีกตอนหนึ่ง วันนี้เราจะพูดถึง Remove Duplicates กันนิดหน่อย แม้จริง ๆ แล้วไม่จำเป็นต้องลงรายละเอียดมาก แต่ผมจะสาธิตให้ดู จากนั้นเราจะไปดู Split Out และ Aggregate แบบเร็ว ๆ เพื่อให้เห็นภาพ

Remove Duplicates ใช้สำหรับลบรายการที่ซ้ำกันอยู่ภายในรายการข้อมูล ถ้ามี item เดิมส่งเข้ามาซ้ำกัน เช่น มี item เดียวกันผ่านเข้ามาสามครั้ง และคุณไม่ต้องการให้ประมวลผลต่อทั้งสามครั้ง ก็สามารถลบรายการซ้ำให้เหลือเพียงหนึ่งรายการได้ มันค่อนข้างง่ายครับ ผมแทบไม่เคยใช้ node นี้ และคุณเองก็คงไม่จำเป็นต้องใช้บ่อยเหมือนกัน แต่วันนี้เราจะเน้น Split Out กับ Aggregate

Split Out ทำอะไร? มันจะแยก item เดียวที่มีข้อมูลจำนวนมากออกเป็นหลาย items ส่วน Aggregate ทำตรงกันข้าม คือรับข้อมูลหลายรายการแล้วรวมกลับเป็นรายการเดียว ลองดูครับ

เราจะเริ่มจากกรณีที่ผมต้องการนำข้อมูลมารวมกัน สมมติว่าเรามีข้อมูลอยู่ 10 รายการ และผมต้องการรวม view counts กับ spoken hooks ของทั้งหมดเข้าด้วยกัน ผมกด Step แล้วดูผลลัพธ์ตรงนี้ จะเห็นว่ามันสร้าง item เดียวที่ชื่อ views ขึ้นมา

สิ่งนี้เรียกว่า array หรืออาร์เรย์ ซึ่งก็คือรายการข้อมูลที่รวมอยู่ด้วยกัน มันนำข้อมูลทั้งหมดมาใส่ไว้ใน array ให้เรา นี่คือ item เดียวที่มีข้อมูลทั้งหมดแสดงเรียงอยู่ รวมถึง spoken hooks ทั้งเจ็ดรายการด้วย นี่แหละครับคือ Aggregate มันนำข้อมูลทั้งหมดมารวมเป็นรายการเดียว แทนที่จะปล่อยให้เป็นหลายรายการ

ส่วน Split Out เราจะย้อนกลับไปดูอีกด้านหนึ่ง จะเห็นข้อมูลทั้งหมดอยู่รวมกันเป็นรายการเดียว ลองสังเกตนะครับ แบบหนึ่งคือหลายบรรทัดถูกรวมเป็นหนึ่งรายการ แต่อีกแบบคือหนึ่งรายการถูกแยกออกเป็นหลายรายการ

ใน Split Out เราจะเลือก view count หรือเลือก views แล้วเพิ่มตัวเลือกใหม่ได้ เราอาจเลือก all other fields ด้วยก็ได้ ลองดูว่ามันทำอะไร ผมเองก็ยังไม่เคยใช้ตัวเลือกนั้นมาก่อน น่าสนใจครับ แต่เพื่อให้เข้าใจง่าย เราจะเลือกแค่ views และไม่เอาฟิลด์อื่น

ดูผลลัพธ์ตรงนี้ครับ ข้อมูลที่อยู่ในรายการเดียวกำลังถูกแยกออกเป็น items แต่ละรายการ เห็นไหมครับ? ตอนนี้แต่ละค่ากลายเป็น item แยกกันแล้ว และเราสามารถดึงแต่ละ item ไปใช้งานต่อได้ ดูตรง JSON นะครับ ถ้ามีวงเล็บครอบข้อมูลหนึ่งชุด นั่นคือหนึ่ง item

ถ้าเราเข้าไปที่ Aggregate เราจะเห็นข้อมูลหลายรายการถูกรวมอยู่ภายในรายการเดียว นี่คือวิธีที่คุณใช้จัดการโครงสร้างข้อมูล

แล้วเราจะใช้สิ่งนี้เมื่อไหร่? ตัวอย่างเช่น เมื่อมีข้อมูลจำนวนมากมาจาก HTTP requests หรือมาจากระบบอื่น ๆ ระบบต้นทางอาจรวมข้อมูลทั้งหมดไว้เป็น array ซึ่งค่อนข้างน่ารำคาญเวลาจะนำไปใช้ต่อ ดังนั้นเราจึงใช้ Split Out node เพื่อแยกข้อมูลทั้งหมดออกจากกัน

ในทางกลับกัน ถ้ามีข้อมูลจำนวนมากที่เป็นรายการแยกกัน แต่คุณต้องการรวมกลับเป็นรายการเดียว ก็ใช้ Aggregate ได้ สมมติว่าเป็นข้อมูลของ Instagram reel หนึ่งรายการ ผมจะสาธิตให้ดู

ดูข้อมูลที่ไหลเข้ามานะครับ มันเข้ามาเป็น item เดียว ข้อมูลส่วนหนึ่งตรงนี้ก็คือหนึ่ง item และ item นี้มีขนาดใหญ่มาก เห็นไหมครับ? ทั้งหมดนี้อยู่ใน item เดียว และด้านในก็มี array อยู่ ถ้าผมต้องการแยกข้อมูลเหล่านี้ออก ก็ใช้ Split Out

แต่ถ้าผมต้องการรวมทุกอย่างไว้ใต้ item เดียว ก็ทำได้ด้วย Aggregate ลองดูครับ ผมจะเลือก all item อาจจะไม่ได้ตั้งชื่อว่า data แต่ลองดูว่าทำงานหรือไม่ ปรากฏว่าได้ครับ ตอนนี้มันอยู่รวมกันเป็นบรรทัดเดียวแล้ว

เห็นไหมครับ? ข้อมูลหลายรายการถูกรวมเข้าด้วยกัน แต่เดิมแต่ละชิ้นเป็น individual items ตอนนี้ Aggregate รวมทุกชิ้นเข้าด้วยกันให้เป็นข้อมูลชุดเดียว ซึ่งสะดวกมาก

จากนั้นถ้าผมต้องการแยก data ชุดนี้ออกอีกครั้ง ก็กลับมาใช้ Split Out ได้ มันจะแยก records ทั้งหมดออกจากกัน

ทั้งหมดนี้คือเรื่องของ Aggregate และ Split Out nodes ครับ แล้วพบกันในบทเรียนถัดไป
