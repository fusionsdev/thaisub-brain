## บทนำ

วิดีโอโบนัสนี้สอนวิธีบีบอัดขนาดไฟล์วิดีโอก่อนส่งไปยังแพลตฟอร์มเผยแพร่ make.com เพราะบัญชีฟรีของ make.com จำกัดขนาดไฟล์สูงสุด 5MB วิดีโอจะพาสร้างโฟลว์บีบอัดวิดีโอโดยใช้ Cloud Convert และ Cloudinary ผ่าน HTTP request node ใน Make โดยที่คุณภาพของวิดีโอแทบไม่เปลี่ยนแปลง

## คำแปลเต็ม

ในวิดีโอนี้ ผมจะแสดงวิธีบีบอัดขนาดไฟล์ก่อนส่งไปยังแพลตฟอร์มเผยแพร่ make.com เพราะอย่างที่ผมบอกใน setup step 5 แพลตฟอร์มนี้มีข้อจำกัดขนาดไฟล์สูงสุดบนบัญชีฟรีที่ 5MB ดังนั้นถ้าคุณไม่อยากจ่ายเงินให้ make.com ในการใช้ระบบเผยแพร่ คุณต้องบีบอัดไฟล์วิดีโอก่อนส่งไปที่ make.com เพื่อให้มันเล็กกว่า 5MB

นั่นเป็นเหตุผลที่ผมเพิ่มส่วนนี้ ซึ่งเป็นกระบวนการเล็ก ๆ ที่แปลงไฟล์วิดีโอให้มีขนาดเล็กลงโดยไม่เปลี่ยนอะไรเกี่ยวกับมันเลย และคุณภาพก็ยังดูเหมือนเดิม ในการเชื่อมต่อสิ่งนี้เข้ากับระบบของคุณ สิ่งที่คุณต้องทำคือ อันดับแรกขยับอันนี้หน่อย แล้วเราต้องปลดลิงก์ส่วนนี้ตรงนี้ ขอซูมเข้าไปก่อน Google Sheet นี้ คุณต้องปลดลิงก์อันนี้ แล้วเราต้องลากอันนี้ลงมาตรงนี้ เพราะนี่คือจุดที่เราจะตั้งค่าเวิร์กโฟลว์นี้

สิ่งแรกที่คุณต้องทำ และผมจะสร้างมันให้ดู คุณต้องเพิ่ม HTTP request node (โหนดคำขอ HTTP) และก่อนที่คุณจะไปต่อ คุณต้องสมัครบัญชีฟรีที่ Cloud Convert ก่อน และเมื่อคุณทำเสร็จแล้ว คุณก็ไปที่ dashboard (แดชบอร์ด) ของคุณ แล้วเราจะไปต่อ

ด้านล่างวิดีโอนี้ ผมคิดว่าผมใส่ไว้แล้ว เรามีลิงก์อยู่ตรงนี้ และสิ่งแรกที่เราต้องการคือ URL นี้ เพราะมันจะถูกใส่เข้าไปในส่วนนั้น เราต้องตั้งเป็น POST อันนี้ใส่เข้าไป แล้วเราก็มี parameters (พารามิเตอร์) ที่เราต้องการสำหรับ header (ส่วนหัว) ของเรา ก็แค่เปิดใช้งาน send headers (ส่งส่วนหัว) แล้วเราก็ใส่ข้อมูลนี้ คัดลอกและวางลงไป

ตรงนี้จะเป็น API key ของคุณ ซึ่งผมจะแสดงวิธีได้มาให้ดู แล้วเราก็มี content type (ประเภทเนื้อหา) เราก็เพิ่ม content type อีกอัน และมันคือ application/JSON ตอนนี้คุณไปที่ dashboard ของคุณ ไปที่ authorization API แล้วคลิก create a new key (สร้างคีย์ใหม่) พอคุณทำแบบนี้ คุณก็คัดลอกคีย์นั้นแล้ววางลงในของคุณ ตรงนี้

ทีนี้ขอเปลี่ยนชื่ออันนี้เป็น "compress video" (บีบอัดวิดีโอ) แล้วกลับไป และสิ่งที่เราอยากทำจริง ๆ คือเข้าไปตรงนั้นและกระตุ้นเวิร์กโฟลว์หนึ่งครั้ง เพื่อให้เรามีไฟล์วิดีโอจริงสำหรับทดสอบเวิร์กโฟลว์บีบอัดของเรา

ดับเบิลคลิกที่ test แล้วเราต้องไปที่บอท Telegram ของเรา เราต้องส่งลิงก์วิดีโอ TikTok เพื่อให้กระบวนการเริ่มต้นจริง ๆ แล้วเราก็แค่ต้องรอ ระหว่างนั้นเราสามารถเพิ่มอีกสองสามโมดูลได้ เราต้องการ wait node (โหนดรอ) เพราะการบีบอัดวิดีโออาจใช้เวลาถึง 20 วินาที ขอเพิ่ม 20 วินาทีตรงนี้

จากนั้นเราก็ตั้งค่าโมดูลอื่นที่เราต้องการสำหรับ Cloud Convert เพื่อให้ได้ URL ของไฟล์วิดีโอที่บีบอัดแล้ว ขอเปิดอันนั้น ตรงนี้เราต้องสลับเป็น GET แล้วไปที่ตรงนี้ และตรงนี้ผมต้องวาง URL นี้แทน สลับเป็น expressions (นิพจน์) ตอนนี้เราต้องรอจนกว่าเราจะจับคู่มันได้อย่างถูกต้อง มันจะเปลี่ยนเป็นสีเขียว

ทุกอย่างด้านล่างจะเหมือนเดิม เช่นคุณมี API key อยู่แล้วในนั้น ดี ขอเปลี่ยนชื่ออันนี้เป็น แล้วเราก็อยากเพิ่ม Cloudinary อีกอันหนึ่งด้วย เราต้องอัปโหลดไฟล์ เพราะ URL ของ Cloud Convert สำหรับวิดีโอนั้นอาจหมดอายุได้ภายในไม่กี่ชั่วโมง มันไม่ใช่ URL ถาวร นั่นเป็นเหตุผลที่เราต้องเพิ่มอันนี้

แต่ตรงนี้มันง่ายมาก สิ่งเดียวที่เราต้องเปลี่ยนคือเปลี่ยนจาก image (รูปภาพ) เป็น video upload (อัปโหลดวิดีโอ) แล้วสิ่งที่เราต้องเปลี่ยนคืออันนี้เป็น form (ฟอร์ม) แล้วตรงนี้เราต้องแมป URL ที่เราได้จาก Cloud Convert เราจะทำแบบนี้เมื่อการสร้างวิดีโอเสร็จสิ้น อันนี้คือ "upload video" (อัปโหลดวิดีโอ) ขอคลิก save แล้วรอจนกว่ามันจะเสร็จ

ระหว่างที่รอ ผมเพิ่งสังเกตว่าเราต้องเพิ่มอย่างอื่น นี่คือด้านล่างวิดีโอนี้ ซึ่งเป็นโค้ด JSON นี้ และเราต้องเพิ่มอันนี้ใน compress ขอเลื่อนไปที่ activate send headers แล้วตรงนี้ คุณวางอันนี้ลงไป แล้วรอจนกว่ามันจะเสร็จ คลิก save

เข้าไปที่โหนด compressed video ของเรา แล้วเลื่อนลงไปด้านล่าง ตอนนี้เราเจอ error ว่ามันไม่ใช่ JSON ที่ถูกต้อง พอผมคลิก test step อีกครั้ง ตอนนี้มันทำงานแล้ว ดังนั้นโค้ดถูกต้อง มันต้องรอประมาณ 20 วินาที ลองไปตรงนี้ คลิก test step รอ 20 วินาที แล้วมาตรวจดู

ตอนนี้เราต้องไปที่อันนั้นและอัปโหลดวิดีโอ ตรงนี้เราต้องตั้งค่า URL จาก getURL อันนี้แหละ แล้วคลิก test step ตอนนี้มันเสร็จแล้ว มาดูกัน นี่คือ URL ตอนนี้ผมอยากรู้ว่าขนาดไฟล์เท่าไหร่ ขอบันทึกมัน แล้วผมเห็นว่ามันคือ 4MB ซึ่งต่ำกว่า 5 ดังนั้นกระบวนการนี้ทำงานได้แล้ว

ตอนนี้เราจะเชื่อมต่อโหนดเหล่านี้กลับเข้าด้วยกัน ตรวจสอบให้แน่ใจว่าฟิลด์ต่าง ๆ ถูกแมปไปยัง URL ที่ถูกต้องของวิดีโอ ตรงนี้คุณเห็นว่ายังไม่มีอันนั้น และตอนนี้เราต้องเลือกจาก upload video เพราะนั่นไม่ใช่ลิงก์ Cloudinary คลิก test step แล้วอันนี้ก็ทำงาน ตอนนี้ Telegram ถูกต้องแล้ว และผมเดาว่าอันนี้ก็เหมือนกัน ขอคลิก test แล้วผมก็ได้วิดีโอที่ถูกต้อง และน่าจะเป็นอันนั้น

สิ่งสุดท้ายคือตรวจสอบอันนี้ แล้วเช็คว่ามันเป็นลิงก์วิดีโอที่ถูกต้องไหม ใช่ ดี จากตรงนี้ทุกอย่างเหมือนเดิม กระบวนการเผยแพร่ยังคงเหมือนเดิม เพราะสิ่งเดียวที่เปลี่ยนคือลิงก์ และคุณไม่ต้องเปลี่ยนอะไรเลย แค่คลิก แล้วตอนนี้คุณก็มีซีเควนซ์การบีบอัดของคุณแล้ว ซึ่งทำให้แน่ใจว่าวิดีโอต่ำกว่า 5MB

ถ้าคุณมีวิดีโอที่ยาวกว่า คุณอาจต้องปรับการตั้งค่าการบีบอัดตรงนี้ bit rate (อัตราบิต) ควรจะต่ำลง แล้วขนาดไฟล์ก็จะเล็กลงด้วย ดังนั้นถ้าคุณต้องการลดขนาดไฟล์ให้มากกว่านี้อีก ผมแนะนำให้คัดลอกโค้ดนี้ ใส่ลงใน ChatGPT แล้วขอให้มันช่วยคุณ หรือใส่ลงใน Claude เพื่อปรับโค้ดให้
