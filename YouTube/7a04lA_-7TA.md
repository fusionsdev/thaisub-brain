## ประเด็นหลัก
- DeepSeek Harness คือแฮร์เนส (โครงสร้างที่ห่อหุ้มโมเดล AI ให้ทำงานจริงได้) แบบ open source ใบอนุญาต MIT เปิดตัว 13 สิงหาคม เป็น developer preview เวอร์ชัน 0.1 ทะลุ 115,000 ดาวบน GitHub และมีปลั๊กอินจากชุมชนกว่า 300 ตัว
- แนวคิดหลัก: โมเดล AI คือสมอง แฮร์เนสคือร่างกาย (มือ ความจำ พื้นที่ทำงาน กฎกติกา) การทำงานจริงทั้งหมดเกิดขึ้นที่แฮร์เนส
- ระดับที่ 1: ติดตั้ง Node.js รันคำสั่งติดตั้ง ใช้เว็บ UI ที่ localhost:3080 เชื่อม DeepSeek API key เพิ่ม provider อย่าง OpenRouter, OpenCode (DeepSeek V4 Flash ฟรี), Llama/LM Studio สำหรับโมเดลท้องถิ่น สร้าง workspace เป็นโฟลเดอร์ทำงานของ agent และเขียนงานแบบ look at / produce / rules
- ระดับที่ 2: ทุกอย่างคือปลั๊กอิน (Everything is a plugin) รวมถึงอินเทอร์เฟซและ agent loop ระบบออกแบบบน Cordis 4 โหมด ได้แก่ standard, code, minimal, creator mode (สร้างปลั๊กอินด้วยการพิมพ์พรอมป์ประโยคเดียว) ไฟล์ซ่อน cordis.patch.yml ใช้ปิดชิ้นส่วนได้ และรองรับ MCP, agent client protocol, ไฟล์ AGENTS.md และ CLAUDE.md
- trajectory view แสดงทุกสเต็ปของ agent แบบคลิกดูได้ พร้อม system prompt, ความคิด, การให้เหตุผล, คำสั่ง, payload และผลลัพธ์ รวมถึงส่งออก session log เป็นไฟล์ zip
- ระดับที่ 3: agent operating system ใช้ Obsidian vault เป็นหน่วยความจำร่วม (โฟลเดอร์ข้อความธรรมดาที่ agent ทุกตัวอ่าน-เขียนได้) จัดเป็น daily, projects, research, output และมีไฟล์ AGENTS.md คอยสั่งงานอัตโนมัติ สร้าง mission control dashboard ได้ด้วยพรอมป์เดียว รันหลายเซสชันพร้อมกัน และสอนสกิลใหม่ให้ agent ได้
- ใช้โมเดลฟรีได้โดยการเพิ่ม provider เช่น OpenCode กับ DeepSeek V4 Flash, OpenRouter (พิมพ์ค้นหา free) หรือโมเดลท้องถิ่นผ่าน Llama
- โฆษณาชุมชน AI Profit Boardroom (aiprofitboom.com) มีคอลให้คำปรึกษารายสัปดาห์ ห้องเรียน และระบบ Agentic Operating System ให้ดาวน์โหลด

## ความเห็นสรุป
วิดีโอนี้เป็นคอร์สแนะนำ DeepSeek Harness ที่ครบถ้วนและเป็นมิตรกับผู้ใช้ทั่วไป เน้นการสาธิตจริงทีละขั้นตอน ตั้งแต่การติดตั้งจนถึงการตั้งระบบ agent เต็มรูปแบบ จุดแข็งคือการอธิบายแนวคิดแฮร์เนส vs โมเดล และระบบปลั๊กอินที่สลับได้ทั้งหมดได้อย่างเข้าใจง่าย อย่างไรก็ตาม ผู้พูดมักแทรกโปรโมชันชุมชนของตัวเองบ่อยครั้ง และคำบรรยายอัตโนมัติทำให้ชื่อผลิตภัณฑ์บางชื่อเพี้ยนไป ซึ่งผู้แปลได้เก็บความหมายตามบริบทและระบุความไม่ชัดเจนไว้ในรายงานการแปล
