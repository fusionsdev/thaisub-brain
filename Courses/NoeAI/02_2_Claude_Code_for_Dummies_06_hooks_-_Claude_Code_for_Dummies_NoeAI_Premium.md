## บทนำ

บทเรียนนี้พูดถึงฟีเจอร์ Hooks ใน Claude Code ซึ่งเป็นฟีเจอร์ใหม่ที่ทำหน้าที่เป็นตัวกระตุ้นให้เกิดการทำงานบางอย่างโดยอัตโนมัติ ผู้สอนสาธิตการตั้งค่า hook ให้เล่นเสียงแจ้งเตือนทุกครั้งที่ Claude Code ทำงานเสร็จ หรือขอสิทธิ์อนุญาตจากผู้ใช้

## คำแปลเต็ม

ยินดีต้อนรับกลับมาอีกวิดีโอหนึ่งครับ วันนี้ผมจะพูดถึงเรื่อง hooks ถ้าคุณยังไม่รู้ว่า hooks คืออะไร มันเป็นฟีเจอร์ที่ค่อนข้างใหม่ โดยสรุปแล้ว มันก็คือตัวกระตุ้นให้เกิดการทำงานอย่างหนึ่ง เหมือนกับตัวอย่างที่ผมกำลังจะโชว์ให้ดู เช่น ถ้า Claude Code ทำงานโปรเจกต์เสร็จ หรือมันต้องการขอสิทธิ์จากคุณ มันก็จะไปกระตุ้นบางอย่างต่อ เช่น กระตุ้นให้มีการแจ้งเตือนขึ้นมา

ผมสร้างการแจ้งเตือนอันนี้ไว้ตรงนี้ เล่นเสียงให้ฟังหน่อยสิครับ นี่คือสิ่งที่มันจะเล่นทุกครั้งเลย ดูเป็นมืออาชีพมาก ณ จุดนี้ (หัวเราะ) สิ่งที่ผมทำทั้งหมดก็คือ ขอให้มันตั้งค่า hook ขึ้นมา โดยที่เมื่อ Claude Code จบ session ที่ต้องขอสิทธิ์ มันก็จะเล่นเสียงนี้บนคอมพิวเตอร์ของผม

ผมจะไม่เก็บเสียงนี้ไว้นาน แต่เราลองตั้ง hook ให้มันเล่นเสียงกระจกสั้น ๆ ทุกครั้งที่ Claude Code ทำงานเสร็จ หรือต้องการขอสิทธิ์ดูไหมครับ แค่ง่าย ๆ แบบนี้แหละ แล้วก็ขอให้มันตั้ง hook ให้

จากนั้นเมื่อคุณใช้คำสั่ง slash command นี่คือจุดที่คุณจะเห็น hooks ทั้งหมดของคุณได้ชัดเจน มันกำลังอัปเดตทั้งสองฝั่งอยู่ตอนนี้ มันจะเล่นเสียงนั้นเมื่อทำงานเสร็จให้ผม

เราลองทดสอบกันดูตรงนี้ได้ครับ ... เสร็จแล้ว แล้วช่วยรัน bash command เพื่อทดสอบการแจ้งเตือนหน่อยได้ไหมครับ มาดูกันว่ามันจะทำงานหรือเปล่า มันไม่ทำงาน เศร้าใจเลย ต้องไปแก้ไขหน่อย

แต่จริง ๆ แล้วทุกครั้งที่มีอะไรกระตุ้น มันก็จะทำงานนะครับ โอ้ มันทำงานแล้ว นั่นไงครับ ทันทีที่ถึงจุดแจ้งเตือนนั้น เรียบร้อย มันอาจจะทำให้รำคาญได้บ้าง แต่มันก็คือประมาณนี้แหละครับ
