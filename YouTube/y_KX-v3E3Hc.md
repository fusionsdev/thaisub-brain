## ประเด็นหลัก
- Cursor คือ agent harness ที่ไม่ยึดติดกับค่ายโมเดลใดค่ายหนึ่ง เลือกใช้โมเดลไหนก็ได้ (Composer 2.5, Kimi K2.7, Haiku, Claude Code, Codex ฯลฯ) และทุกอย่างรวมอยู่ในหน้าต่างเดียว ทั้ง browser, terminal และ GUI
- แนวคิด "skills" คือแพ็กเกจพกพาที่ควบคุมเวอร์ชันได้ ใช้สอน agent ให้ทำงานเฉพาะด้าน เปรียบเหมือนการปฐมนิเทศพนักงานใหม่ที่ต้องให้ทั้งบริบท (context) และความสามารถ (capability)
- Skills มีสองระดับ: dot folders (.agents, .cursor) สำหรับกฎ/ทักษะแบบ global หรือ project และ slash command สำหรับคำสั่งซ้ำๆ เช่น /automate
- ไฟล์ skills เป็น markdown อ่านง่ายทั้งมนุษย์และ LLM และโฟลเดอร์แบบ dot จะถูก git ignore อัตโนมัติ ไม่ถูก push ขึ้น GitHub เว้นแต่สั่งให้ทำ
- สาธิตการ scaffold โปรเจกต์ "Cursor for GTM demo" จริงๆ โดยสร้าง readme, GTM outreach overview และทักษะย่อย 3 ตัว: GTM outreach, cold email deliverability, cold email copywriting
- เรื่องสำคัญสำหรับงานอีเมล: ต้องรู้จัก naming convention ของ merge tags ให้ตรงกับ sequencer ที่ใช้ เช่น first_name แบบ snake case เป็นมาตรฐาน (Instantly ใช้ camel case) ไม่อย่างนั้น merge tags จะไม่แสดงผล
- การเพิ่ม capabilities ทำได้ผ่าน CLI tools หรือ MCP servers (Model Context Protocol) เช่น ติดตั้ง Instantly CLI ผ่าน NPM ที่ระดับโปรเจกต์ แล้วเชื่อมต่อด้วย API key จากหน้า Integrations
- หลังติดตั้งควรตรวจสอบการเชื่อมต่อด้วยการถามคำถามจริง เช่น "แคมเปญตอนนี้มีอะไรบ้าง" และหมุนเวียน API keys เป็นประจำ อย่าเก็บ key ไว้ในโค้ดตรงๆ
- Cursor รองรับ multi-agent orchestration — สร้าง agent หลายตัวแล้วจัดการเหมือนจัดการพนักงาน เพื่อใช้ leverage และไม่ถูกตีกรอบให้อยู่กับโมเดลเดียว

## ความเห็นสรุป
วิดีโอนี้เหมาะมากสำหรับคนทำงานสายขาย/การตลาดที่อยากเริ่มใช้ Cursor โดยไม่ต้องเขียนโค้ดเป็น เพราะสาธิตจริงตั้งแต่แนวคิดจนถึงการติดตั้งเครื่องมือเชื่อมต่อระบบส่งอีเมล เนื้อหาครบถ้วนและปฏิบัติตามได้ทันที ข้อสังเกตคือผู้พูดพูดเร็วและเป็นกันเอง คำบรรยายอัตโนมัติมีคำที่ฟังคลาดเคลื่อนบ้างเล็กน้อย (เช่นชื่อโมเดล) แต่ไม่กระทบความเข้าใจหลัก
