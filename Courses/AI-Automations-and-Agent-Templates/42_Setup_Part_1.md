## บทนำ
วิดีโอนี้สอนตั้งค่าเวิร์กโฟลว์อัตโนมัติใน n8n ที่เปลี่ยนภาพนิ่งใดก็ได้ให้เป็นวิดีโอคนพูดได้ (talking person video) ระบบรับคำสั่งผ่าน Telegram แยกเป็น prompt วิดีโอและ prompt บทพูด สร้างวิดีโอด้วย Kling ผ่าน PIAPI สร้างเสียงพากย์ด้วย OpenAI และ ElevenLabs ซิงค์ริมฝีปากกับเสียงด้วยฟีเจอร์ lip sync แล้วประกอบวิดีโอสุดท้ายพร้อมหัวข้อและคำบรรยายด้วย JSON2Video บันทึกทุกอย่างลง Google Sheets

## คำแปลเต็ม

ในวิดีโอนี้ผมจะสาธิตการตั้งค่าเวิร์กโฟลว์อัตโนมัติที่เปลี่ยนภาพใดก็ได้ให้เป็นวิดีโอคนพูดได้ สิ่งแรกที่ต้องทำคือเข้าไปที่บัญชี n8n แล้วคลิก Create a Workflow จากนั้นด้านล่างวิดีโอนี้จะมีเทมเพลตเวิร์กโฟลว์ คลิกดาวน์โหลด แล้วกลับมาที่ n8n คลิก Import from file แล้วดับเบิลคลิกเพื่อนำเข้า ตอนนี้มันถูกนำเข้าแล้ว โมดูลทั้งหมดอยู่ที่นี่

สิ่งที่ต้องทำคือเชื่อมต่อเครื่องมือต่าง ๆ เหล่านี้กับบัญชีของคุณ สิ่งแรกที่ต้องทำ ถ้ายังไม่มีบัญชี Telegram คลิก Create a credential แล้วใส่ access token ของคุณ มีบทเรียนเทคนิคที่พาคุณทำทีละขั้นตอนในไม่กี่นาที: Get API Key from Telegram ดูบทเรียน ใส่ token แล้วคลิก Save แค่นี้ก็เรียบร้อย

จากนั้นต้องเลือกบัญชี Telegram ที่ถูกต้องในทุกโหนดที่เพิ่งเชื่อมต่อ ตรงนี้ปล่อยได้เลย ถ้ามีบัญชี Telegram เดียว มันควรถูกเลือกไว้แล้ว แต่ให้แน่ใจว่าตั้งค่าถูกต้อง แล้วไปขั้นตอนถัดไป

ฟังก์ชัน split ต่อไปนี้ ผมจะอธิบายสั้น ๆ ว่าแต่ละโมดูลทำอะไร เพื่อให้คุณเข้าใจพื้นฐานและปรับแต่งเองได้ โมดูล split ง่ายมาก มันแยกคำสั่งของเราออกเป็นสองส่วน: ส่วนแรกคือ video prompt ว่าจะให้เกิดอะไรขึ้นกับภาพ เปลี่ยนเป็นวิดีโอแบบไหน และส่วนที่สองคือ script prompt ว่าข้อความที่ซ้อนทับ (text overlay) ควรเป็นอะไร จากนั้นมันจะถูกแยกเพื่อประมวลผลแยกกัน video prompt ไปตรงนี้เพื่อสร้างวิดีโอ และ script prompt ไปตรงนี้เพื่อสร้างบทพูด และตรงนี้คือ ID เฉพาะซึ่งจะถูกบันทึกลงในฐานข้อมูล Google Sheet ในภายหลัง

โมดูลถัดไปที่ต้องเชื่อมต่อคือ Telegram ตรงนี้ต้องใส่ bot token ซึ่งเป็น token ที่ได้จาก BotFather ที่คุณสร้างระหว่างขั้นตอนตั้งค่า คัดลอกและวางตรงนี้ แล้วทำต่อ

อันนี้ดาวน์โหลดภาพที่เราอัปโหลดใน Telegram จากนั้นอัปโหลดภาพ เราต้องอัปโหลดเพื่อให้มีลิงก์ที่เข้าถึงได้สาธารณะ และเราใช้ Cloudinary ซึ่งเป็นบริการพื้นที่เก็บข้อมูลออนไลน์ที่ใช้ฟรีได้ ตรงนี้ต้องสร้างบัญชี แล้วต้องใส่ cloudinary ID ของคุณ นี่คือส่วนนี้ ใส่ตรงนี้

สิ่งที่ต้องทำต่อคือเลือก generic credential type เป็น authentication และเลือก basic auth จากนั้นคลิก Create new credential ใส่ user และ password ซึ่งหาได้ในบทเรียนเทคนิค: Get API credentials from Cloudinary ดูบทเรียน ใส่ค่า แล้วคลิก Save ผมทำไว้แล้ว

สิ่งถัดไปคือสร้าง upload preset หาได้ใน Settings ใต้ Upload คลิก Add Upload Preset ตั้งชื่ออะไรก็ได้ เช่น Image to voice แล้วเลือก... คลิก Save แล้ววางค่านี้ตรงนี้ แค่นี้ก็พอ คลิก Save

เรามีโมดูล Cloudinary อีกอันที่ตั้งค่าได้แล้ว ตรงนี้ เราใช้ cloudinary ID เดิมที่ได้มาก่อน อันแรกจะใส่ค่า video สำหรับ... ซึ่งอาจเป็นอะไรก็ได้ แล้วก็มี cloudinary ID อีกครั้ง หาได้ใต้ My dashboard ไปคัดลอก วางตรงนี้ และตรงนี้ต้องแน่ใจว่าใช้ credential ที่ถูกต้องซึ่งเชื่อมต่อไว้ในขั้นตอนก่อนหน้า แค่นั้น

โหนดถัดไปคือ Generate video ตรงนี้เราใช้เครื่องมือชื่อ Kling ซึ่งเป็นเครื่องมือสร้างวิดีโอ AI สิ่งเดียวที่ต้องทำคือเลือก Header Auth จากนั้นเลือก Header account แล้วตรงนี้ต้องสร้าง credential ด้วย name และ value ผมสอนไว้แล้วในบทเรียน Get API credential from PIAPI ดูบทเรียน ใส่ค่า แล้วคลิก Save แค่นั้น

วิธีทำงานคือ คุณมี video generator ใน PIAPI ถ้าตั้งค่าและเชื่อมต่อแล้ว สมัครบัญชีไว้ ในการใช้งานต้องเติมเครดิตก่อน ไปที่ Settings แล้ว Billing เพื่อใช้ฟีเจอร์ lip sync แบบนี้ คือเสียงจะซิงค์กับการขยับริมฝีปาก ต้องอัปเกรดเป็นแผนแบบเสียเงิน ไปที่ Subscriptions แล้วสมัครแผน 15 เหรียญต่อเดือน

นี่คือโมเดลวิดีโอที่เราใช้ ชื่อ Kling มีการตั้งค่าบางอย่างที่ควบคุมได้ ผมจะไม่ลงรายละเอียด แค่บอกว่า มีตัวเลือก 5 หรือ 10 วินาที นั่นคือขีดจำกัด ตรงนี้คือ prompt ที่เรากรอกไว้ตอนต้น โดยพื้นฐานคือ "Wind is blowing in the image" แล้วภาพนี้จะถูกแปลงเป็นวิดีโอ เริ่มจาก 5 วินาที เปลี่ยนเป็น 10 วินาทีได้ถ้าต้องการยาวขึ้น และยังมีตัวเลือกเพิ่มเติม ถ้าไปที่ run API แล้วค้นหา extend จะเห็นว่าสามารถต่อวิดีโอได้ มีฟังก์ชันนี้อยู่ตรงนี้ ถาม ChatGPT หรือ Claude ให้ช่วย implement แล้วต่อวิดีโอเพิ่มครั้งละ 5 วินาทีเพื่อให้วิดีโอยาวขึ้นได้ถ้าต้องการ

ตรงนี้คือเวอร์ชัน มีเวอร์ชัน 1.0 และ 2.0 ทดลองกับเวอร์ชันต่าง ๆ เพื่อดูว่าแบบไหนให้ผลลัพธ์ดีที่สุด ตรงนี้โหมดเป็น standard เลือก Pro ได้ ซึ่งแพงกว่าเล็กน้อยแต่อาจได้วิดีโอที่ดีกว่า สำหรับเคสการใช้งานโซเชียลมีเดียแบบนี้ standard ก็ดีพอแล้ว ผมจะปล่อยไว้ตามเดิม

กลับมาตรงนี้ wait node นี้คือต้องรอนานแค่ไหนกว่าวิดีโอจะถูกสร้าง สำหรับวิดีโอ 5 วินาทีประมาณสองนาทีครึ่ง เห็นตรงนี้: video generation ประมาณหนึ่งนาทีครึ่ง แต่ผมตั้งไว้สองนาทีครึ่ง ถ้าเป็นวิดีโอ 10 วินาที อาจต้องเพิ่มเป็นสองเท่า ตั้ง 5 นาทีก่อนประมวลผลต่อ

Get video URL ตรงนี้ควรใช้ header auth แบบเดียวกับที่เชื่อมต่อกับ video generator มันควรโหลดให้อัตโนมัติ

ต่อไปเสียง เราใช้ OpenAI ในการสร้างเสียง จะเปลี่ยนเป็น Claude หรือโมเดล AI อื่นก็ได้ แต่ถ้าใช้ OpenAI ต้องเชื่อมต่อบัญชี คลิก Create New แล้วดูวิดีโอนี้ Get API key from OpenAI ที่สอนวิธีขอ API เป๊ะ ๆ ใส่ตรงนี้แล้วคลิก Save กลับมา

โดยพื้นฐานแล้ว อันนี้สร้างเสียงและบทพูด (script) ก่อนอื่นลองกระตุ้นเวิร์กโฟลว์นี้ก่อน อันนี้สร้างข้อความหรือบทพูดที่คนในวิดีโอจะพูด และปรากฏในคำบรรยายด้วย และสร้าง hook (พาดหัว) ที่อยู่ด้านบนเป็นหัวข้อวิดีโอ และส่งออกเป็นตัวแปรสองตัว ซึ่งเราใช้ฟังก์ชันโค้ดแยกค่าออกมา ตัวหนึ่งเป็นข้อความสำหรับบทพูดพากย์เสียง และอีกตัวเป็น hook เพื่อประมวลผลแยกกัน

เพราะเสียงจะไปที่ ElevenLabs ตรงนี้ต้องใส่ voice ID ไปที่ ElevenLabs จะเห็นลิงก์ ElevenLabs ด้านล่างวิดีโอนี้ สมัครบัญชีฟรีได้ และใช้เสียงตัวอย่างหรือเสียงของคุณเอง ไปที่ Add voice แล้วเลือก Instant Voice Clone อัดวิดีโอประมาณสองนาที แล้วมันจะโคลนเสียงคุณ อย่างที่ผมทำไว้ตรงนี้ แล้วคลิก View voice แล้วจะได้ voice ID วาง voice ID ลงไป แล้วมันจะสร้างเสียงหรือไฟล์เสียงสำหรับวิดีโอด้วยเสียงของคุณ

ถ้าอยากใช้เสียงมาตรฐานอื่น เช่น เสียงผู้หญิง ไปที่เสียงนั้น คลิก View แล้ว Copy ID แล้ววางตรงนี้ แค่นั้น ตรงนี้ต้องขอ API key หาได้ใต้หัวข้อ API keys แล้ววางตรงนี้ แค่นี้ที่ต้องเปลี่ยน การตั้งค่าเหล่านี้คือค่าของเสียงที่สร้าง ปรับเล่นได้ แต่ผมปล่อยไว้ตามเดิมเพราะไม่ต้องเปลี่ยนอะไร

แล้วก็มี wait node อีกอัน และ Cloudinary อีกอันเพื่ออัปโหลดเสียง เชื่อมต่อไว้แล้ว

Lip sync เป็นอีกโมดูลสำคัญ อันนี้ใช้ร่วมกับ Kling AI เพราะมันซิงค์การขยับริมฝีปากกับเสียงจากไฟล์ MP3 ที่เราสร้างด้วย ElevenLabs มันรวมวิดีโอและไฟล์เสียงเป็นวิดีโอเดียว ต้องแน่ใจว่าบัญชีที่เชื่อมต่อจาก PIAPI ถูกต้อง เป็นบัญชีเดียวกับที่ใช้ตรงนี้และตรงนั้นตลอด

แล้วก็มี get video URL อีกอัน เลือกบัญชีที่ตรงกัน มันให้ URL ของวิดีโอมา มี wait node อีกอัน สำคัญ ถ้าวิดีโอเป็นแบบนี้คือ 5 วินาที ถ้าเป็น 10 วินาทีอาจต้องใส่ 19 ตรงนี้ อาจใช้เวลาสองเท่า สำหรับวิดีโอ 10 วินาที ต้องตั้งเวลารอให้ถูกต้องเสมอ และดูได้ว่าใช้เวลานานแค่ไหนใน PIAPI ใต้ Task History เพื่อให้แน่ใจว่าวิดีโอเสร็จก่อนประมวลผลต่อ ไม่งั้นจะเจอปัญหาในภายหลัง

อีกโมดูลสำคัญคือโมดูลที่รวมเสียงของวิดีโอกับเสียงของคนในวิดีโอ และเพิ่มหัวข้อด้านบนกับคำบรรยายด้านล่าง เราใช้เครื่องมือชื่อ JSON2Video เปิดตรงนี้ได้ สมัครบัญชีฟรีได้ แล้วตรงนี้เลือก Generic credential custom แล้วคลิก Create credential แล้วใส่โค้ดส่วนนี้ แล้วขอ API key วางตรงนี้ ผมสอนวิธีทำในบทเรียนเทคนิค Get API from JSON2Video วางแล้วคลิก Save ก็เชื่อมต่อเรียบร้อย

ตรงนี้มีพารามิเตอร์สองสามตัวที่ปรับแต่งวิดีโอได้ เช่น format เป็น Instagram ซึ่งเป็นรูปแบบแนวตั้ง (vertical) เหมาะกับทุกแพลตฟอร์มโซเชียลมีเดีย ตรงนี้มี top text และการจัดรูปแบบ เปลี่ยนฟอนต์ พื้นหลัง และอื่น ๆ ได้ ปรับพารามิเตอร์เหล่านี้ นี่คือข้อความด้านบน และตรงนี้คือสไตล์คำบรรยาย ปรับแบบเดียวกันได้ ทั้งฟอนต์ ฟอนต์ ฟอนต์ และอื่น ๆ แค่นี้ตรงนี้

ตอนนี้คลิก Start testing เราเริ่มทดสอบได้แล้ว ผมจะใช้รูปเดิม คุณทำบนโทรศัพท์หรืออุปกรณ์อื่นก็ได้เพื่อสร้างวิดีโอ ใช้รูปเดิม คลิก แล้วมันจะสร้างวิดีโอเวอร์ชันแรกก่อน แล้วส่วนถัดไปจนได้วิดีโอที่เสร็จสมบูรณ์ เพราะใช้เวลาสักครู่ ผมตั้งค่าส่วนที่เหลือไว้ระหว่างรอ และ video URL ก็ใช้การเชื่อมต่อ JSON2Video เหมือนกัน และตรงนี้เลือก authentication เดียวกับที่ใช้ตรงนั้น

ต่อไปเป็น Google Sheet สำคัญมาก หาเทมเพลต Google Sheet ได้ด้านล่างวิดีโอนี้ คลิกที่สเปรดชีต คลิก Make a copy ถ้ายังไม่ได้เชื่อมต่อ Google Sheet คลิก Create new credential ต้อง Sign in with Google แต่ก่อนทำ ต้องแน่ใจว่าเป็นบัญชีเดียวกับที่ถือ Google Sheet นี้ เอาเมาส์ไปวางที่ไอคอนด้านบน แล้วจะเห็นว่าบัญชีไหนเชื่อมต่ออยู่ ถ้ามีหลายบัญชี แล้วลงชื่อเข้าใช้ด้วยบัญชีเดียวกัน ผมปิดหน้านี้เพราะทำไว้แล้ว และตรงนี้ผมจะตั้งชื่อเฉพาะ: Setup demo

Google Sheet นี้ทำสองอย่าง เราตั้งตารางได้ว่าควรเผยแพร่กี่วิดีโอ ในช่วงเวลาไหน เช่น กี่วิดีโอต่อวัน ตั้งเป็นสองได้ ไม่ใช่ค่านี้ นี่คือค่าที่ต้องปรับ ผมบอกได้ว่าเป็นช่วงเวลาที่วิดีโอควรถูกเผยแพร่ไปยังบัญชีโซเชียลมีเดีย และตรงนี้วิดีโอจะถูกบันทึก

ในการตั้งค่า ต้องคลิก Select document from drive แล้วเลือก Google Sheet ที่เพิ่งสร้าง จากนั้นไปที่ Select videos ตอนนี้มันแสดงโหนดที่ถูกต้องอยู่แล้ว เชื่อมต่อไว้แล้ว ไม่ต้องใช้ตรงนี้ แล้วมันควรจะทำงานและบันทึกวิดีโอทั้งหมด ข้อความคำบรรยาย และ video URL

อันนี้ผมยังไม่ได้พูดถึง นี่คือข้อความคำบรรยาย (caption text) ที่จะถูกเผยแพร่พร้อมกับวิดีโอบนโซเชียลมีเดีย สร้างโดยโมเดล OpenAI ตรงนี้ ปรับแต่งเพื่อให้ได้โครงสร้างและคำบรรยายที่ต้องการได้

ตรงนี้เห็น error ซึ่งเกิดขึ้นได้เมื่อไฟล์เสียงยาวกว่าวิดีโอ เพราะจะซิงค์ริมฝีปากยาก พอเปิดดูไฟล์เสียงของผม มันควรสั้นกว่านี้ แต่เห็นว่าเสียงช้ามาก อาจต้องเปลี่ยนเสียงหรือความเร็วเสียง ทำได้ด้วยพารามิเตอร์ของ ElevenLabs ตรงนี้ แต่ในกรณีนี้ผมจะเลือกเสียงอื่นที่เร็วกว่านี้เล็กน้อย นี่คือวิธีหนึ่งในการแก้

ตรงนี้ผมจะใส่ voice ID อีกอัน แล้วทดสอบขั้นตอน ทดสอบแล้วเห็นว่า ตอนนี้เสียงยาว 4 วินาที จากเดิม 8 วินาที สั้นกว่าวิดีโอ ดี จะได้ไม่มี error และตรงนี้ผมตั้งไว้ว่าเสียงพากย์ควรยาวแค่ไหน ประมาณ 13 คำ เพราะ 13 คำพูดได้ประมาณ 4 วินาที

ตอนนี้ต้องคลิกเข้าไปแล้วคลิก Test แล้วรออีกครั้ง จากนั้นมันจะลอง... เห็นไหม ตอนนี้เป็นสีเขียวแล้ว ทำต่อได้ ไปที่ Google Sheets อีกครั้ง คลิก Test แล้วมันจะรัน เราต้องรอจนกว่าวิดีโอ lip sync จะเสร็จ ซึ่งประมาณเก้านาทีครึ่ง แล้วค่อยทำต่อ

ตอนนี้ต้องรอประมาณ 9 นาทีจนกว่าวิดีโอ lip sync จะเสร็จ แล้วมันจะถูกประมวลผลและส่งถึงผมทาง Telegram เพราะทุกอย่างตั้งค่าไว้แล้ว ตอนนี้เสร็จแล้ว ไปที่โหนด Telegram ก่อน คลิก Test step แล้วตอนนี้เราควรได้รับข้อความคำบรรยายและวิดีโอ และเห็นว่ามันทำงาน และเมื่อเปิด Google Sheets จะเห็นว่าวิดีโอถูกบันทึกไว้ตรงนี้ด้วย

ขั้นตอนถัดไปคือทำให้วิดีโอนี้ถูกเผยแพร่ไปยังแพลตฟอร์มโซเชียลมีเดียต่าง ๆ เช่น YouTube Shorts และนั่นคือสิ่งที่เราจะตั้งค่าในวิดีโอส่วนถัดไป
