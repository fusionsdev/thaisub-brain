## บทนำ
วิดีโอนี้เป็นตอนที่ 1 ของการตั้งค่าระบบอัตโนมัติที่ดึงคอนเทนต์จาก Instagram Reels แล้วนำมาทำเป็นวิดีโอของเราเอง เริ่มจากนำเข้าเทมเพลตเวิร์กโฟลว์ใน n8n จากนั้นเชื่อมต่อโมดูลต่าง ๆ ไล่จาก Telegram, Instagram scraper ผ่าน Rapid API, Cloudinary สำหรับอัปโหลดรูป, OpenAI สำหรับวิเคราะห์รูปและถอดเสียง และสุดท้ายบันทึกข้อมูลทั้งหมดลง Google Sheet

## คำแปลเต็ม

ตอนนี้เราจะตั้งค่าตอนที่ 1 ของระบบอัตโนมัติของเรา ซึ่งทำหน้าที่ดึงคอนเทนต์จาก Instagram Reels แล้วรีเมคเป็นวิดีโอของเราเอง ขั้นตอนแรกคือไปที่ n8n ถ้าคุณยังไม่มีบัญชี สมัครใช้งานฟรีได้ มีช่วงทดลองใช้ฟรี และเมื่อคุณเข้าสู่ระบบแล้ว คลิกที่ create new workflow จากนั้นด้านล่างตรงนี้คุณจะพบเทมเพลตระบบอัตโนมัติ แล้วคุณไปที่ import from file ตรงนี้ แล้วนำเข้าไฟล์ที่คุณเพิ่งดาวน์โหลด ตอนนี้เรามาเปลี่ยนชื่อมันเป็น Instaclum clone automation กัน

ขั้นตอนถัดไปคือการเชื่อมต่อโมดูลต่าง ๆ เหล่านี้ทั้งหมดตรงนี้ เราเริ่มด้วย Telegram คลิกที่ Telegram ถ้าคุณยังไม่ได้เชื่อมต่อ Telegram คุณต้องคลิกที่ Create New Credential และตรงนี้คุณต้องใส่ access token ขั้นตอนแรกก่อนที่คุณจะทำได้คือ คุณต้องดาวน์โหลดแอปไปยังโทรศัพท์ของคุณและคอมพิวเตอร์ของคุณด้วย เพราะมันจะง่ายกว่าในการใช้ทดสอบ และผมได้สร้างบทช่วยสอนไว้ให้คุณแล้วตรงนี้: technical tutorials หัวข้อ get API key from Telegram นี่คือที่ผมแสดงวิธีรับการเข้าถึงของคุณ ดูวิดีโอนั้นให้แน่ใจ แล้วกลับมาวางไว้ตรงนี้ แล้วคลิก save ผมทำไปแล้ว ดังนั้นผมจึงเชื่อมต่ออันนี้ไว้แล้ว แล้วเราไปต่อกัน

เราจะตั้งค่าเฉพาะส่วนบนก่อน แล้วเราจะไปยังส่วนอื่น ๆ ในวิดีโอถัดไป ตรงนี้ get post คุณปล่อยไว้ได้ จากนั้นไปที่ post content แล้ว get post content และคุณต้องมี Instagram scraper คุณคลิกด้านล่างตรงนี้ คุณจะพบอันนี้ คลิกที่มัน แล้วคุณจะถูกนำไปยังแพลตฟอร์มที่ชื่อว่า Rapid API คุณสามารถสมัครบัญชีฟรีได้ จากนั้นตรงนี้คุณคลิกที่ Basic แล้วคลิกที่ Sign Up for this Plan จากนั้นคุณต้องรับ API key ของคุณ ซึ่งทำได้ง่ายมาก และผมได้บันทึกวิดีโอไว้ให้คุณแล้ว ภายใต้ technical คุณจะเห็น get API key from Instagram Reel Downloader ดังนั้นดูวิดีโอนั้น แล้ววาง API key ของคุณตรงนี้ แล้วคลิก save แล้วเราก็ไปต่อ

ตอนนี้เรามาทดสอบรันแบบสั้น ๆ กัน ขยายไปที่ get post content แล้วคลิกที่ delete ตรงนี้ โหนดนี้ควรถูกตัดการเชื่อมต่อ เพราะเราต้องการทดสอบเฉพาะโมดูลที่เราตั้งค่าไว้แล้ว จากนั้นคลิกที่ test workflow แล้วเปิดบอทของคุณ แล้วคลิก start ก่อนอื่นเราจะได้ error เพราะโมดูลนี้คาดหวังโพสต์ ซึ่งหมายถึงลิงก์โพสต์จาก Instagram ผมไปที่ get any URL ไปที่วิดีโอใดก็ได้ แล้วกลับมา คลิก test workflow แล้ววางลิงก์นั้นลงใน Telegram ของผม แล้วเราจะเห็นว่ามันกำลังทำงาน และสิ่งที่มันควรให้เราคือคอนเทนต์ของ Instagram Reel ที่เราโพสต์ ดังนั้นอันนี้ทำงานแล้ว ตอนนี้เราสามารถไปต่อได้

ตอนนี้เราจะเชื่อมต่อมันกลับเข้าไปใหม่ และภายใต้ get cover คุณแค่คลิก test ซึ่งน่าจะตั้งค่าไว้แล้ว และอันนี้จะให้รูปปกของ Instagram Reel นี้แก่เรา เยี่ยมมาก จากนั้นเป็นเครื่องมืออัปโหลดที่ชื่อว่า Cloudinary มันเป็นแพลตฟอร์มเก็บไฟล์ออนไลน์ที่เราใช้ฟรีได้ ตรงนี้ไปสมัครบัญชีฟรี จากนั้นคุณต้องไปที่ home แล้วคัดลอก cloud name กลับมา แล้ววาง cloud name ลงในช่องว่างตรงนี้ ขั้นตอนถัดไปที่คุณต้องทำคือเลือก basic และตรงนี้คุณต้องคลิก create new credential ตรงนี้คุณต้องใส่ user และ password ซึ่งก็คือ API key และ API secret และผมได้บันทึกบทช่วยสอนไว้ให้คุณแล้ว ตรงนี้ใน technical หัวข้อ get API key from Cloudinary คุณควรจะเห็นมัน ดูวิดีโอนั้นเพื่อรับ API ของคุณ วางลงไป คลิก แล้วคุณก็ไปต่อได้

สิ่งถัดไปที่คุณต้องทำคือสร้าง upload preset ไปที่ settings แล้วคลิกที่ Add Preset อันนี้ชื่ออะไรก็ได้ ชื่อไม่สำคัญ แต่ต้องเป็น unsigned คลิกที่ Save คัดลอกแล้ววางลงตรงนี้ คลิก test step แล้วมันควรทำงาน ตอนนี้กลับไป สิ่งถัดไปที่คุณต้องทำคือ OpenAI อันนี้จะวิเคราะห์รูปภาพให้เรา ตรงนี้คุณแค่ไปที่ create new ใส่ API key และคุณยังมีบทช่วยสอนทางเทคนิคที่แสดงวิธีรับ API key จาก OpenAI ด้วย ดูวิดีโอนั้น วาง API ของคุณ คลิก Save และนั่นคือทั้งหมดที่เราต้องทำ คลิก test แล้วมันจะวิเคราะห์รูปภาพ และเป้าหมายคือเพื่อให้ข้อความที่อยู่บนรูปภาพแก่เรา เพราะนั่นคือสิ่งที่เราต้องการใช้ เราจะใช้มันในวิดีโอของเราเอง

แล้วเรามาcontinue ตรงนี้ นี่คือขั้นตอนที่ 2 อันนี้จะดึงข้อความให้เราจริง ๆ แค่ให้แน่ใจว่าทุกอย่างเป็นสีเขียวตรงนี้เสมอ ดูดีแล้ว นี่คือโมเดล AI ตอนนี้มันเชื่อมต่อกับบัญชี OpenAI ของผมแล้ว และทั้งหมดที่มันควรทำคือให้ข้อความดิบแก่เรา คุณเห็นไหม นี่คือข้อความที่อยู่บนรูปปกวิดีโอนี้พอดี เยี่ยมมาก ตอนนี้ไปต่อกัน ขั้นตอนถัดไปคือ filter audio อันนี้แค่ดึงไฟล์เสียงจากวิดีโอ หรือเสียงของทรานสคริปต์ ไฟล์เสียงพากย์ที่ผมหมายถึง ตรงนี้เรามี download audio คุณไม่ต้องตั้งค่าอะไร แค่คลิก test step แล้วนี่คือเสียงของเสียงพากย์หรือสคริปต์วิดีโอ

ตอนนี้เราต้องถอดเสียง เราจะใช้บัญชี OpenAI เดียวกัน และคุณไม่ต้องตั้งค่าอะไรตรงนี้ แค่คลิก test step แล้วมันจะถอดเสียงให้เรา จากนั้นก็ไม่มีอะไรต้องตั้งค่า อันนี้แค่คลิก create a template ID เพื่อให้เรามี ID เฉพาะสำหรับทุกวิดีโอ แล้วเราบันทึกคอนเทนต์ลงใน Google Sheet ของเรา สำหรับ Google Sheet เราต้องเชื่อมต่อมันกับบัญชี Google ของเราก่อน แต่ก่อนที่เราจะทำ คลิกด้านล่างวิดีโอ ตรงนี้คุณจะพบเทมเพลต Google คลิกที่ make a copy ตั้งชื่อเฉพาะให้มัน เช่น Timo 19 May แล้วผมกลับมา คลิกที่ Create a new credential และเพราะผมใช้เวอร์ชันคลาวด์ ผมจึงสามารถเข้าสู่ระบบด้วย Google ได้โดยตรง ถ้าคุณใช้แบบ self-hosted มันอาจไม่แสดงตัวเลือกนี้ และคุณต้องใช้วิธีอื่นซึ่งก็ทำง่ายเหมือนกัน แค่ถาม ChatGPT ให้ช่วยคุณเชื่อมต่อ Google กับบัญชี n8n แบบ self-hosted ของคุณ แต่ผมคลิก sign in with Google ได้ ผมเลือกบัญชีที่ผมมีตรงนี้ คลิก continue มันเป็นบัญชีเดียวกับที่เชื่อมต่อ Google Sheet ของผม

เมื่อมันเสร็จแล้ว ผมก็ไปต่อได้ ผมต้องคลิกตรงนี้ แล้วคลิกเลือก Google Sheet ที่ผมเพิ่งสร้าง ตอนนี้ผมไปที่ และตรงนี้ผมต้องเลือกตัวแปรทั้งหมด ผมต้องลากเข้าไปใน template: video link ซึ่งมาจาก trigger ของ Telegram ตรงนี้ นั่นคือวิดีโอ จากนั้นเรามี text overlay template นั่นคือข้อความ นั่นคืออันนี้ จากนั้น video script มาจากส่วน Transcribe นั่นก็คืออันนั้น ส่วน captions template เราต้องไปที่จุดเริ่มต้นตรงที่เรามี get post content และตรงนั้นเราต้องมีข้อมูลทั้งหมดที่ดึงมาจาก Instagram นี้ และตรงนั้นมี caption อยู่ somewhere ดูแบบนี้ นี่คือ caption และผมว่ามันควรเป็นบรรทัดแรก มาตรวจสอบว่านี่คือ caption หรือไม่ มันใช่ และยังมีอีกสองสามอย่างที่ผมสามารถบันทึกได้ถ้าคุณต้องการ นั่นคือ follower count และ play count

play count อาจต้องใช้เวลาหาเล็กน้อย ตัวเล่นวิดีโออยู่ที่ไหน มาดูกัน ตรงนั้นเรามีคอมเมนต์อื่น ๆ ทั้งหมด ลองสลับตารางดู จริง ๆ แล้วผมจะไปที่ post content อาจจะหาได้ง่ายกว่า เลื่อนลงมา นี่คือรูปแบบต่าง ๆ ตรงนี้เรามี video play count อยู่ในนี้โดยตรง ลองอีกครั้ง แล้วเรามี followers ตอนนี้ follower count ก็อยู่ตรงนี้ด้วย อยู่ในนี้โดยตรง ตอนนี้เมื่อผมคลิก test คอนเทนต์นี้ควรถูกบันทึกลงในชีตของผม และใน templates นั่นคือทั้งหมด กลับไป คลิก save ตอนนี้ผมได้ดึงคอนเทนต์มาแล้ว ในวิดีโอถัดไปผมจะสร้างคอนเทนต์สำหรับวิดีโอของผมเองโดยอิงจากคอนเทนต์ที่ดึงมา และนั่นคือสิ่งที่เราจะตั้งค่าในวิดีโอถัดไป
