## บทนำ

บทเรียนนี้ต่อยอดจากบท What Are Agents โดยแนะนำ agent pattern ห้าแบบที่เจ้าของธุรกิจใช้ได้จริง และพาคุณสร้างทีมวิจัย (research team) ด้วยตัวเองผ่าน prompt เดียว ผู้สอนสาธิตการ spawn agent หลายตัวให้ค้นคว้าข้อมูลจากหลายแหล่งพร้อมกัน แล้วรวมเป็นสรุปจัดอันดับ

## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับกลับมาอีกบทเรียนหนึ่ง วันนี้เราจะมาพูดถึง agent patterns และการสร้างทีมวิจัยของคุณเอง ถ้าคุณยังไม่ได้ดูบท What Are Agents ขอให้ไปดูบทนั้นก่อน ในบทนั้นผมอธิบายว่า AI agents คืออะไรใน Claude Code โดยเฉพาะวิธีการ spawn พนักงานหลายคนพร้อมกัน เพื่อให้มันไปทำงานให้คุณ ขณะที่คุณทำงานหลักตรงกลางอยู่ มันเจ๋งมาก และวันนี้เราจะต่อยอดจากบทนั้น

สิ่งที่คุณจะได้จากบทนี้คือ agent pattern ที่มีประโยชน์ห้าแบบสำหรับธุรกิจใดก็ได้ และเมื่อจบบทนี้ คุณจะมีทีมวิจัยที่ใช้งานได้จริง เราเข้าเรื่องกันเลย

ถ้าคุณดูบทที่แล้ว ผม spawn agent สี่ตัว หรือสามตัวพร้อมกัน เพื่อให้ค้นคว้าข้อมูลให้ผม บนเว็บและบน Twitter มัน spawn ออกมาพร้อมกันทั้งหมด และนี่คือสิ่งที่เราจะสร้างกัน โดยสรุป agent ก็คือ มันจะทำงานหลายอย่างให้คุณ ขณะที่คุณกำลังทำงานหลักอยู่

มี pattern ไม่กี่แบบที่คุณในฐานะเจ้าของธุรกิจใช้กับสิ่งเหล่านี้ได้ และผมชอบใช้มาก แบบแรกคือ ทีมวิจัย (research team) แบบที่ผมโชว์ไป — spawn agent หลายตัวค้นหาจากหลายแหล่งพร้อมกัน แล้วได้ผลลัพธ์ทั้งหมดกลับมาเป็นสรุปเดียวที่สะอาด ตัวอย่างเช่น คุณรัน research agent สี่ตัว ตัวหนึ่งไปหาโพสต์ AI ที่กำลังมาแรงบน Twitter ตัวหนึ่งไป Reddit หาข่าวตามเวลา ตัวหนึ่งไปหาข่าว AI ล่าสุดจาก Fox News หรืออะไรประมาณนั้น ทำทั้งหมดพร้อมกัน แล้วกลับมาพร้อมสรุป และนั่นคือทั้งหมดที่ผมต้องสั่ง มันจะออกไปทำทั้งสี่อย่าง รวมผล ให้ผม แล้วยังจัดอันดับให้ด้วย นี่คือตัวอย่างหนึ่งของทีมวิจัย

ต่อมา คุณสร้างทีมคอนเทนต์ (content team) ได้ โดยสร้าง agent หลายตัวที่เขียนคอนเทนต์คนละประเภทพร้อมกัน ตัวหนึ่งเขียนอันหนึ่ง ตัวหนึ่งเขียนอีกอันหนึ่ง ทำแบบขนานทั้งหมด ตัวอย่างที่ดีมากที่เพิ่งนึกออกคือ สมมติว่าคุณมีวิดีโอ YouTube สิ่งที่คุณทำได้คือ สั่งว่า "ไปดาวน์โหลดวิดีโอ YouTube นี้มา" เพราะคุณเชื่อมช่อง YouTube ของคุณเข้ากับ Claude Code ได้ ถ้าไม่รู้วิธี ก็แค่ถาม Claude Code มันเหลือเชื่อจริง ๆ "ดาวน์โหลดวิดีโอ YouTube แล้วเอาทรานสคริปต์มา แล้ว spawn agent สามตัวแบบขนาน ตัวหนึ่งเขียนสคริปต์ห้าอันจากวิดีโอนั้น พร้อมคำพูดเด่นและคุณค่า ตัวหนึ่งเขียนโพสต์ LinkedIn ห้าอันพร้อมคำพูดเด่นและคุณค่า ตัวหนึ่งเขียนทวีต Twitter ห้าอัน" แล้วก็ spawn อีกตัวให้เขียนอีเมลหลายฉบับเกี่ยวกับเนื้อหาที่ผมพูด และตัวที่ห้าให้เขียนประกาศแจ้ง community ของผมว่ามีวิดีโอใหม่ลง

ผมสามารถรันทั้งห้าตัวพร้อมกัน และมันจะทำทุกอย่างให้ผม และถ้ามันถูกฝึกด้วยข้อมูลธุรกิจของคุณและข้อมูลของคุณจริง ๆ คุณจะได้ผลลัพธ์ที่เกือบสมบูรณ์แบบ คุณ spawn ทีมทั้งหมดนี้ หรือทีมคอนเทนต์ของคุณ แล้วคุณก็ยังทำงานต่อได้ พวกมันทั้งหมดทำงานให้คุณเบื้องหลัง ขณะที่คุณโฟกัสกับงานหลัก ซึ่งถูกต้องแล้ว

Pattern ที่สามคือ ทีมคู่แข่ง (competitor team) คุณสร้าง agent หลายตัวให้ค้นคว้าคู่แข่งคนละราย ตัวอย่างเช่น สมมติว่าคุณเป็นเจ้าของฟิตเนส แล้วอยากได้ข้อมูลโซเชียลและรีวิวของยิมต่าง ๆ คุณ spawn สิบ agent ได้เลย "spawn ให้ผม 10 agents ไปค้นคว้ายิมคู่แข่งทั้งหมดในพื้นที่ ไปเก็บข้อมูลและ handles โซเชียลมีเดียของพวกมัน" มันจะส่ง 10 ตัวออกไป แต่ละตัวไปหาข้อมูลคนละที่ แล้วเอาผลกลับมารวมใส่ใน Google Spreadsheet ถ้ามันเชื่อมกับ Google ของคุณ มันก็จะสร้างสเปรดชีตให้ หรือสร้างไฟล์ให้ local แทน ประมาณนั้น นี่คือทีมคู่แข่ง

แล้วก็มีทีมรีแพ็กเกจ (repurpose team) — เอาชิ้นคอนเทนต์หนึ่งชิ้นมาแปลงเป็นหลายรูปแบบพร้อมกัน ผมเพิ่งพูดไปข้างหน้าหน่อยเพราะตื่นเต้น มันจะเอาวิดีโอ 10 นาทีของคุณ ไปตัดคลิป 60 วินาที ตัวหนึ่งเขียนบล็อก ตัวหนึ่งเขียนสรุปอีเมล ทำแบบขนานให้คุณทั้งหมด และถ้าคุณทำได้ดีมาก ผลลัพธ์ออกมาดี คุณแค่กด approve แล้วมันจะส่งอีเมลให้คุณ เขียนบล็อกและโพสต์ให้คุณ ทวีตให้คุณ มันจะทำอีกหลายอย่างให้คุณ

แล้วก็ pattern สุดท้ายคือ ทีมตรวจสอบ (audit team) — agent หลายตัวตรวจสอบคนละส่วนของธุรกิจคุณพร้อมกัน แล้วคุณได้รายงานเต็มรูปแบบโดยไม่ต้องเสียเวลาทั้งวัน ใครก็ตามที่ต้องการเช็คเป็นระยะ เช่น ตรวจสอบฝ่ายบริการลูกค้า อันนี้ดีมากสำหรับเจ้าของธุรกิจจริง ๆ ที่มีหลายแผนก อยากรู้ว่าทุกคนทำงานกันยังไง ก็แค่สั่ง "spawn agent สำหรับทุกแผนก ตรวจสอบกระบวนการทั้งหมด แล้วเอาสรุปกลับมาว่าแต่ละแผนกกำลังทำอะไรอยู่" ซึ่งน่าสนใจมาก

นี่เป็นแค่ตัวอย่าง pattern สองสามแบบ สิ่งที่เราจะทำคือ เราจะสร้างทีมวิจัยแบบที่ผมโชว์ให้ดูตอนแรก สิ่งที่เราจะทำคือ...

ผมใช้ GitHub และนั่นสำหรับผมเป็นการส่วนตัวในสาย AI คุณสามารถประยุกต์ใช้กับกลุ่มเฉพาะใดก็ได้ นี่คือสิ่งที่เราจะทำ "ผมต้องการให้คุณค้นคว้าข่าว AI ที่กำลังมาแรงที่สุดเกี่ยวกับ ChatGPT และ Claude และผมอยากให้คุณ spawn agent สี่ตัวแบบขนาน ตัวหนึ่งค้นคว้าบน GitHub ตัวหนึ่งบน Reddit ตัวหนึ่งบน X/Twitter และตัวหนึ่งบนข่าว (news) แล้วรวมผลวิจัยทั้งหมด แล้วให้สรุปพร้อมหัวข้อ trending 10 อันดับล่างสุด อิงตามคะแนนที่กำหนด"

แล้วเราก็ยิงคำสั่งออกไป ปล่อยให้มันทำงาน สิ่งที่ผมทำคือ แค่บอกให้มันทำงานแบบขนาน บอกแหล่งที่มาเฉพาะ ว่าจะทำอะไร แล้วมันก็รันให้เรา ถ้าคุณอยากรู้ว่าผมใช้เครื่องมืออะไรอยู่ ผมใช้ WhisperFlow เพื่อให้ผมดับเบิลคลิกตรงนี้ได้

เดี๋ยวเราจะเรียนกันในบทหลังเรื่องการสร้าง custom agents ที่จะทำสิ่งนี้ให้อัตโนมัติ มี prompt และทุกอย่างพร้อม รู้ชัดเจนว่าต้องทำอะไร ตอนนี้ research agent ทั้งสี่ตัวกำลังรันแบบขนาน: GitHub agent, Reddit, X/Twitter และ news โอเค แล้วมันจะรวมเป็น top 10 ที่ให้คะแนนแล้ว เมื่อมันรายงานกลับมาหมด

มันกำลังรันทั้งสี่ agent พร้อมกันแบบขนาน ซึ่งเจ๋งมาก เราจะปล่อยให้มันทำงาน แล้วดูว่ามันให้อะไรกลับมา ดูเหมือนมันเสร็จแล้ว กำลังส่งผลกลับมา ดูสิครับ มันสร้างรายงานข่าว AI ให้เรา มันได้ GitHub trends มาหมด ดูเหมือน OpenClaw เป็นราชาแห่ง GitHub ตอนนี้ อะไรอื่นก็ร้อนแรงตามกัน แล้วมันก็ดึงข่าวใหญ่ทั้งหมด และจัดอันดับ top 10 ให้ทั้งหมด ซึ่งเจ๋งมาก

จากนั้นผมก็เอาข้อมูลพวกนั้นไปต่อได้ "ตอนนี้ spawn agent สามตัวให้เขียนสคริปต์คอนเทนต์ตามแต่ละแหล่ง" อะไรประมาณนี้ เป็นของเจ๋ง ๆ ที่คุณทำได้ที่นี่

นี่คือทุกอย่างสำหรับบทนี้ เราพูดถึง agent patterns ไปบางส่วน เพื่อเปิดมุมมองให้คุณเห็นว่าคุณทำอะไรได้บ้าง แล้วเราก็สร้างทีมวิจัยด้วย prompt ง่าย ๆ ด้วยกัน และผมให้ตัวอย่าง prompt ไว้ให้คุณด้วย นี่คือทุกอย่างสำหรับบทนี้ครับ ถ้าชอบก็บอกกันใน community ได้ ถ้ามีคำถามก็ถามใน community ได้ แล้วเจอกันบทเรียนหน้าครับ
