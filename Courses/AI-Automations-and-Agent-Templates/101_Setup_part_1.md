## บทนำ
วิดีโอนี้สอนตั้งค่าเวิร์กโฟลว์ AI automation ใน n8n ที่สร้างวิดีโอพร้อมข้อความและเสียงพากย์จาก prompt ที่คุณพิมพ์ เพียงพิมพ์คำสั่งใน Telegram ว่ wants วิดีโอแบบไหน ระบบจะแยกคำสั่งออกเป็นส่วน prompt วิดีโอและส่วนข้อความ สร้างวิดีโอผ่านเครื่องมือ AI สร้างเสียงพากย์ด้วย OpenAI อัปโหลดเสียงขึ้น Cloudinary แล้วรวมทุกอย่างเป็นวิดีโอสำเร็จรูปด้วย JSON2Video พร้อมบันทึกลง Google Sheets ในส่วนที่ 2 จะต่อกับการเผยแพร่อัตโนมัติไปยัง TikTok และ YouTube Shorts

## คำแปลเต็ม

ในวิดีโอนี้เราจะตั้งค่าเวิร์กโฟลว์ AI automation ใน n8n ที่สร้างวิดีโอแบบนี้ได้ พร้อมข้อความและเสียงพากย์ ตาม prompt ใดก็ได้ที่คุณให้ ขั้นตอนแรกคือด้านล่างวิดีโอนี้จะมีลิงก์ให้คลิก Download AI agent จากนั้นเข้าไปที่บัญชี n8n ถ้ายังไม่ได้สร้างบัญชี ก็สมัครฟรีได้ มีทดลองใช้ฟรี 14 วัน จากนั้นคลิก Create แล้วเราจะนำเข้าเวิร์กโฟลว์ที่เพิ่งดาวน์โหลด ไปที่ Import from file แล้วนำเข้า ใช้เวลาไม่กี่วินาที

นี่คือส่วนแรกของเวิร์กโฟลว์ของเราในการสร้างวิดีโอ ในส่วนถัดไปมีวิดีโอแยกที่สอนวิธีให้วิดีโอเหล่านี้ถูกเผยแพร่ไปยัง TikTok, YouTube Shorts อัตโนมัติ หรือที่ใดก็ตามที่ต้องการ

ตอนนี้เราต้องเชื่อมต่อโหนดต่าง ๆ และเครื่องมือต่าง ๆ เริ่มจากอันแรก: Telegram trigger อย่างที่เห็น AI agent ของเราทำงานใน Telegram ถ้ายังไม่ได้เชื่อมต่อบัญชี คลิก Create new credentials แล้วใส่ access token ของคุณ ผมจะไม่ลงรายละเอียดเพราะสอนไว้แล้วในบทเรียนเทคนิคหัวข้อ Get API Key from Telegram วิธีขอ access token ทำตามนั้น แล้วกลับมาใส่ access token คลิก Save

พอทำเสร็จ เราจะทดสอบสั้น ๆ ก่อนว่าใช้งานได้หรือไม่ ดับเบิลคลิก คลิก Test ไปที่บอทของคุณ แล้วพิมพ์ข้อความทดสอบเพื่อดูว่ามันถูกส่งมายังเวิร์กโฟลว์ของผมหรือไม่ มันทำงานได้ เพราะนั่นคือจุดเริ่มต้นของระบบ

วิธีทำงานคือ เราจะให้ prompt กับ AI agent หรือเวิร์กโฟลว์ของเรา ระบุประเภทวิดีโอที่ต้องการ ตัวอย่างเช่น ง่ายแค่นี้ ลองเลือกอันนี้: พิมพ์ generate video จากนั้นพิมพ์ this is the video I want นี่คือส่วนที่สอง และอย่าใช้เครื่องหมายจุลภาค (comma) แค่บรรยาย ใช้มหัพภาค (full stop) ได้ แล้วต่อข้อความ แต่ห้ามใช้ comma เพราะ comma ถูกใช้เป็นตัวคั่น เนื่องจากอีกสิ่งที่อยากให้มีในวิดีโอคือข้อความบนวิดีโอ ซึ่งจะถูกสร้างโดยโมเดล AI เช่นกัน

เพื่อให้คำสั่งสร้างวิดีโอแยกส่วนแรกคือวิดีโอ: มีอะไรอยู่ในวิดีโอและแสดงอย่างไร กับส่วนที่สองคือข้อความบนวิดีโอ เราต้องแยกสองส่วนนี้ออกจากข้อความ และนี่คือสิ่งที่เกิดขึ้น ฟังก์ชันแรกนี้คือตัวแยก (splitter) ที่แยกข้อความนี้ออก

เราไม่ต้องตั้งค่าอะไรตรงนี้ แต่ใน AI agent ต้องใส่คำสั่งว่าอะไรจะเกิดขึ้น นี่คือส่วนที่สร้าง video prompt เพราะตรงนี้เราใช้เครื่องมือ AI วิดีโอเจเนอเรเตอร์ที่ใช้ prompt จากตรงนั้น สิ่งเดียวที่ต้องเพิ่มคือบัญชี OpenAI คลิก Create แล้วใส่ API key ซึ่งหาได้ในบทเรียนเทคนิค จากนั้นกลับมาตรงนี้ แล้วทำต่อ

โค้ดส่วนนี้ใช้สร้าง video ID ถ้าผมรัน จะเห็นว่ามันทำงานและสร้าง video ID ที่ไม่ซ้ำกัน ซึ่งเราจะใช้เป็นข้อมูลอ้างอิงในภายหลัง เพราะเราบันทึกวิดีโอทั้งหมดที่สร้างลงใน Google Sheet นั่นคือเหตุผลที่ต้องมี video ID

เห็นแล้วว่ากำลังเกิดอะไรขึ้น ข้อความ prompt ยังไม่ได้ถูกส่ง ลองคลิก Test workflow ก่อน เพราะอยากโชว์ว่า prompt นี้ทำงานยังไงเพื่อให้เข้าใจเวิร์กโฟลว์ส่วนที่เหลือ ข้อความถูกแยกที่ split ตรงนี้ video prompt ถูกแยกออกจากแนวคิดคำบรรยาย (caption idea) โดยอิงจาก comma ที่เราใส่ ส่วนแรกคือวิดีโอที่ต้องการ ส่วนที่สองคือข้อความบนวิดีโอและเสียงพากย์ จากนั้นสิ่งนี้จะถูกประมวลผลต่อใน AI ซึ่งจะสร้าง video prompt ให้

และจากนั้นวิดีโอก็จะถูกสร้างขึ้นตาม prompt จาก AI agent แล้ว ตรงนี้เข้าไปดู สิ่งที่ต้องทำคือคลิก Create ตรงนี้มี header auth type ปล่อยไว้ตามเดิม แต่ตรงนี้ต้องคลิก Create new credential หรือ header account header auth และต้องพิมพ์ credentials ของ PIAPI ที่มีอยู่ในบทเรียนวิดีโอด้านล่าง ไปดู ใส่ credentials แล้วกลับมา ผมปล่อยไว้ตามเดิม ปล่อยไว้ได้เลย

อันนี้จะสร้างวิดีโอแรกตาม prompt ความยาววิดีโอ 10 วินาที ซึ่งยาวที่สุดที่ทำได้ เปลี่ยน Pan เป็นศูนย์ จริง ๆ แล้วมันเป็นศูนย์อยู่แล้วเมื่อดูวิดีโอ นี่เป็นเพียงค่าเล็กน้อย panning คือการเคลื่อนไหวของกล้อง แต่ผมไม่ต้องการให้มีการเคลื่อนไหวเป็นค่าเริ่มต้น

ไปต่อกัน ตรงนี้มี wait node เพราะวิดีโอใช้เวลาประมวลผลนานถึง 6 นาที จากนั้นในวิดีโอมีฟังก์ชันดึงวิดีโอกลับมา เราสามารถกระตุ้นกระบวนการสร้างวิดีโอได้แล้วตรงนี้ ตอนนี้จะเห็นว่า... จริง ๆ แล้ววิดีโอยังอยู่ในสถานะ pending กำลังประมวลผล และผมจะไปที่โหนดถัดไป เพราะมันจะกระตุ้นโหนดก่อนหน้า ตอนนี้มันรอ 6 นาที แล้วตรวจสอบว่าวิดีโอเสร็จหรือยัง

คุณสามารถไปที่บัญชี PIAPI ได้ เพราะเราใช้เครื่องมือสร้างวิดีโอชื่อนี้ และตรงนั้นจะเห็นวิดีโอที่กำลังประมวลผล รวมถึงวิดีโอที่สร้างแล้วทั้งหมดและราคา มาต่อการตั้งค่าตรงนี้ ใน OpenAI เราไม่ต้องตั้งค่าอะไรตรงนี้ แค่บัญชีที่เชื่อมไว้แล้ว และอันนี้สร้างเสียงพากย์ (voiceover) ให้เรา

ตรงนี้ผมบอกว่าข้อความต้องพอดีกับวิดีโอ 10 วินาที ไม่ได้ผลเสมอไป ต้องปรับเล่นเล็กน้อยเพื่อให้ข้อความบนวิดีโอยาวพอ ๆ กับ 10 วินาที เห็นว่าข้อความยาวไปนิดหน่อย อาจต้องตั้งเป็นไม่กี่วินาที หรือใช้คำพูดเช่น 20 คำ หรืออะไรก็ได้ ประมาณ 10 เพื่อให้เสียงพากย์สั้นกว่าวิดีโอ แต่นี่ไม่ทำให้ error แค่อาจไม่สวยงาม ไม่สำคัญเท่าไรถ้าวิดีโอจบแล้วเสียงพากย์ยังไม่จบ แต่ปรับให้เหมาะสมได้ถ้าต้องการ

ขั้นตอนถัดไปคือสร้างเสียง (audio) อันนี้สร้างข้อความสำหรับเสียงพากย์ และอันนี้สร้างไฟล์เสียงของเสียงพากย์ ตรงนี้เลือกเสียงต่าง ๆ ได้ เป็นเสียงมาตรฐานของ OpenAI ถ้าต้องการเสียงที่ปรับแต่งได้มากขึ้นหรือใช้เสียงตัวเอง สลับไปใช้โมดูล ElevenLabs แล้วถาม ChatGPT หรือ Claude วิธีทำได้ ง่ายมาก

ต่อไปเป็น upload audio node ตรงนี้ต้องอัปโหลดเสียงพากย์ที่เพิ่งสร้าง เพื่อนำไปประมวลผลต่อและเพิ่มลงในวิดีโอ เราจะใช้เครื่องมือชื่อ Cloudinary ซึ่งเป็นบริการพื้นที่เก็บข้อมูลออนไลน์ และตรงนี้ต้องคลิก Create new credentials ต้องใส่ user และ password ซึ่งมีบทเรียนเทคนิคด้านล่าง หัวข้อ Get API from Cloudinary ที่บอกวิธีหามาจากตรงไหนเป๊ะ ๆ จากนั้นคลิก แล้วสิ่งที่เหลือคือใส่ username ของผม หาได้ตรงนี้ นี่คือ username ของผม วางลงไป ปล่อยทุกอย่างไว้ตามเดิม

ตรงนี้ต้องใส่ preset name ไปที่ Settings จากนั้นไปที่ Upload settings ไปที่ Upload แล้วสร้าง preset ใหม่ คลิกตรงนี้ ตั้งชื่ออะไรก็ได้ ไม่สำคัญ แล้วเลือก... สำคัญมาก จากนั้นคลิก Save แล้วใส่ตรงนี้ แค่นี้ก็พอ คลิก Save

ต่อไปเป็นเครื่องมือสร้างวิดีโอสำคัญอีกตัวชื่อ JSON2Video เปิดในหน้าต่างใหม่ ตรงนี้ต้องสร้าง credential ใหม่ด้วย และสิ่งที่ต้องใช้คือโค้ดส่วนนี้ซึ่งมีอยู่แล้ว ต้องใส่ API key ซึ่งหาได้จากบทเรียนเทคนิค Get API credential from JSON2Video ดูแล้วใส่ API key ผมทำไว้แล้ว กลับมาตรงนี้

โดยพื้นฐานแล้ว สิ่งที่เกิดขึ้นคือวิดีโอที่เราสร้างในขั้นตอนแรกกับเสียงพากย์จะถูกรวมเข้าด้วยกัน และใช้เวลาพอสมควร ประมาณ 30 วินาที แล้วจึงดึง URL วิดีโอออกมา ตรงนี้แค่เลือกบัญชีที่เชื่อมต่อกับ JSON2Video แล้วก็มี wait node อีกอัน แล้วก็ JSON2Video อีกอัน เลือก custom auth ที่เชื่อมไว้

เพราะสิ่งที่เกิดขึ้นตรงนี้คือวิดีโอและเสียงพากย์ที่เราสร้างจะได้คำบรรยาย (subtitles) คําบรรยายถูกสร้างขึ้น โดยคำบรรยายหมายถึงข้อความที่เห็นปรากฏบนวิดีโอ ตรงส่วนบนของวิดีโอ นั่นคือ subtitle

ตรงนี้มีการตั้งค่าสไตล์เล็กน้อย center to center หมายถึงจัดแนวแนวตั้ง อยู่กึ่งกลางวิดีโอ แน่นอนว่าเลื่อนได้ และตรงนี้คือฟอนต์ คำ เงา เส้น และอื่น ๆ สีทั้งหมดนี้ปรับแต่งได้ถ้าต้องการ แค่นี้ก็พอแล้วถ้าอยากปรับแต่งอะไร ก็เข้าไปที่แดชบอร์ดของ JSON2Video แล้วถามได้เลย เช่น "What font families can I use as subtitle?" แล้วมันจะให้คำตอบ แล้วแทนที่ได้ถ้าอยากเปลี่ยนสไตล์ ผมปล่อยไว้ตามเดิม

อันนี้เสร็จแล้วและได้ URL วิดีโอมา ไปที่ตรงนี้ควรเห็น URL วิดีโอ อย่างที่เห็น นี่เป็นเพียงไฟล์ raw ยังไม่มีการตัดต่อ จริง ๆ แล้วผมชอบอันนี้ ค่อนข้างน่าสนใจ

ขั้นตอนถัดไปคือเสียงพากย์ที่สร้างสำหรับวิดีโอนั้น โดยใช้เสียงที่เลือกไว้ก่อนหน้านี้ จากนั้นก็วิดีโอ เราจะรันเวิร์กโฟลว์ ตอนนี้รอ 30 วินาที ระหว่างรอไปที่โหนดนี้ อันนี้ก็แค่ดึง URL วิดีโอ เชื่อมต่อกับบัญชีที่ถูกต้องหรือเลือกบัญชี JSON2Video และมีโมดูลอีกอันที่สร้างข้อความคำบรรยายโซเชียลมีเดีย (social media caption) ตอนนี้ OpenAI เชื่อมต่อแล้ว

ต่อไปเป็นส่วนสำคัญกับ Google Sheet ที่เราต้องการ มาทำเวิร์กโฟลว์ต่อ ไปที่ตรงนั้น ทดสอบขั้นตอน แล้วมันควรจะรันทุกอย่าง เราจะได้ข้อมูลพร้อมสำหรับ Google Sheet ของเรา

สำหรับ Google Sheet เราจะมี Google Sheet แบบกำหนดเอง ถ้ากลับไปที่ setup part 1 ตรงนี้เห็น Google Sheet database template คลิกแล้วเลือก Make a copy แล้วจะเห็น Google Sheet นี่คือฐานข้อมูลที่วิดีโอของเราจะถูกจัดระเบียบ วิดีโอทั้งหมดที่สร้างจะถูกบันทึกและเก็บไว้ นี่คือสิ่งที่เราจะตั้งค่าต่อไป

และตรงนี้ตั้งตารางการโพสต์ (posting schedule) ได้ เพราะเราจะรวมหรือเชื่อมต่อกับแพลตฟอร์มโซเชียลมีเดียใน setup part 2 แล้ววิดีโอจะถูกเผยแพร่ตามตารางการโพสต์ของคุณ: กี่วิดีโอต่อช่วงเวลาใด ควรเผยแพร่เมื่อไหร่

ก่อนจะใช้ Google Sheets ต้องเปิดใช้งานมันก่อน ตั้งชื่อก่อน ผมจะตั้งชื่อที่ไม่ซ้ำกันเพื่อให้หาเจอในเวิร์กโฟลว์ทีหลัง จากนั้นตรงนี้ต้องคลิก Authorize คลิก OK เลือก Google คลิกที่ลิงก์ด้านล่าง เลื่อนไปที่... สวัสดี และแค่นั้น ตอนนี้ต้องคลิก Install Trigger คลิก Install Trigger อีกครั้ง ตอนนี้มันทำงานแล้ว กลับไปที่เวิร์กโฟลว์

ตรงนี้ต้องเชื่อมต่อบัญชี Google คลิก Create new credential แล้ว Sign in with Google ด้วยบัญชี Google เดียวกับที่ถือ Google Sheet นี้ พอทำเสร็จ ซึ่งผมทำแล้ว จากนั้นคลิกที่เอกสารนั้น มันควรจะแสดงสเปรดชีต ตรงนี้ผมเลือกอันนี้ สำคัญมาก

ตอนนี้ต้องจับคู่คอลัมน์ (map the columns) ตรงนี้คือการกำหนดว่าค่าใดควรถูกบันทึก ผมต้องการวิดีโอซึ่งอยู่ที่จุดเริ่มต้นตรงนี้ คืออันนี้ ตอนนี้ข้อความคำบรรยายถูกสร้างที่ส่วนท้าย นั่นคืออันนี้ video URL คืออันนี้ และเมื่อคลิก มันควรถูกบันทึกตรงนี้ลงในสเปรดชีต และตรงนี้เห็นวิดีโอที่เสร็จแล้ว มันมีข้อความและเสียงพากย์อยู่แล้ว เยี่ยม

เหลืออีกขั้นตอนเดียวในการตั้งค่าตรงนี้ คือบัญชี Telegram ตรงนี้แค่เชื่อมต่อกับบัญชีเดียวกัน ตอนนี้เชื่อมต่อไว้แล้ว เราจะทดสอบ เพราะตรงนี้จะเห็นข้อความคำบรรยายและวิดีโอ แต่ผมก็อยากได้รับวิดีโอด้วย นั่นคือจุดประสงค์ของโมดูลที่สองนี้ พอคลิก Test มันควรส่งวิดีโอมาให้ อย่างที่เห็นวิดีโออยู่ตรงนั้น และข้อความคำบรรยายกับทุกอย่างถูกบันทึกลงในสเปรดชีตของผมแล้ว เยี่ยม ขั้นตอนถัดไปคือเชื่อมต่อกับการเผยแพร่อัตโนมัติ
