## บทนำ

บทเรียนนี้พูดถึงเครื่องมือและเทคนิคเด็ด ๆ ใน Google Ads ที่ช่วยให้ทำงานง่ายขึ้นและประหยัดค่าใช้จ่าย เริ่มจาก Google Ads Editor สำหรับอัปโหลดแคมเปญและโฆษณาจำนวนมากในคราวเดียว จากนั้นพูดถึงการใช้ Google Ads rules (กฎอัตโนมัติ) เพื่อเปิดปิดโฆษณาตามเวลา และเทคนิคการตั้ง bid limit (เพดานการประมูล) สำหรับแคมเปญแบบ Target CPA และ Target ROAS

## คำแปลเต็ม

ต่อไปนี้ เป็นเคล็ดลับและเทคนิคสุดโปรดของผมบางส่วน เกี่ยวกับ Google Ads ซึ่งจะทำให้ชีวิตคุณง่ายขึ้นมาก และประหยัดเงินได้นิดหน่อย เราจะมาพูดถึง Google Ads Editor มันเป็นเครื่องมือที่ยอดเยี่ยมสำหรับการอัปโหลดจำนวนมาก ผมจะโชว์วิธีดาวน์โหลด มันง่ายมาก แค่ไปที่ Google แล้วค้นหาว่า Google Ads Editor แล้วก็จบแค่นั้น มันเหมาะมากสำหรับการอัปโหลดโฆษณาหรือคีย์เวิร์ดจำนวนมากพร้อมกัน งั้นเราเข้าเรื่องกันเลย

อย่างแรกเลย กับ Google Ads Editor คุณต้องดาวน์โหลดการเปลี่ยนแปลงล่าสุดของบัญชีก่อน เราจะไปที่แคมเปญ ผมดาวน์โหลดไว้แล้ว คุณสามารถดาวน์โหลดแคมเปญทั้งหมด หรือเลือกเฉพาะแคมเปญที่อยากจะแก้ก็ได้ พอได้แคมเปญทั้งหมดแล้ว การเปลี่ยนแปลงทั้งหมดจะถูกนำเข้าไปใน Google Ads Editor มันจะไฮไลต์การเปลี่ยนแปลงใด ๆ ตั้งแต่ครั้งล่าสุดที่คุณเข้ามา คุณแค่กดปุ่ม Done ตรงด้านบน

อย่างแรกที่เราอยากทำ คืออัปโหลดโฆษณาใหม่ เราจะเลื่อนลงมาที่ส่วนโฆษณาตรงนี้ แล้วคลิก Responsive Search Ads ภายในนี้เราสามารถอัปโหลดทั้งชีตนี้เข้าไปใน Google Ads ได้เลย แค่นี้ก็เสร็จเรียบร้อย โดยเรากรอกแคมเปญของเราไว้แล้ว ชื่อแคมเปญ ชื่อแอดกรุ๊ป ประเภทโฆษณาของเราคือ Responsive Search Ad และ Responsive Search Ads มีจำนวน headline ขั้นต่ำสามอัน ผมแนะนำให้ใช้ asset ทั้งหมดที่มี แต่ตรงนี้เราใส่แค่สามอัน

คุณจะเห็น headline ตรงนี้ และตรงนี้คือจำนวนตัวอักษร โดยเรามีสูงสุด 30 ตัว และมันจะเปลี่ยนเป็นสีแดงตรงนี้ ถ้าคุณใส่ตัวอักษรมากเกินไป ทำให้สังเกตได้ง่ายมาก เรามี headline ด้วย ถ้าคุณต้องการใช้ headline ไหน คุณสามารถเลือกได้ตรงนี้ อันที่หนึ่ง สอง หรือสาม นี่คือ headline ทั้งหมดของเรา มากสุดถึง 15 อัน แล้วเราก็เลื่อนไปที่ส่วนคำอธิบาย (description) เราสามารถมี description ได้ ขั้นต่ำคือสองอัน และเช่นเดียวกัน เราจะเห็นจำนวนตัวอักษร ถ้าคุณอยากจะปักหมุด description ไว้กับตำแหน่งใดตำแหน่งหนึ่ง คุณก็ทำได้ตรงนั้น

เรายังมี final URL ซึ่งก็คือหน้าแสดงรายละเอียดสินค้า แล้วก็ path one และ path two ซึ่งคือ display path ที่แสดงในโฆษณา เราจะใช้เครื่องหมายถูกตรงนี้ ถ้าเกิดว่าคุณต้องการให้มันทำงานอัตโนมัติกับสิ่งที่คุณใส่เข้ามา

จากนั้น เราจะไปยังการสร้างแคมเปญใหม่ เราจะไปที่แคมเปญ แล้วคลิกปุ่มเพิ่มแคมเปญใหม่ เราเลือกประเภทได้ เราจะเลือก Search Campaign แล้วกรอกชื่อแคมเปญของเรา ตรงนี้เราจะเลือกงบประมาณ ถ้าคุณไม่ใส่ ค่าเริ่มต้นของมันอาจจะไม่ถูกต้อง ดังนั้นถ้าคุณสร้างแคมเปญแบบนี้ คุณต้องแน่ใจว่าตรวจสอบการตั้งค่าทั้งหมดของแคมเปญก่อนอัปโหลด เราจะพิมพ์งบประมาณลงไป

เราจะเห็นประเภทแคมเปญตรงนี้ เป็น Search โดยรวมอยู่ในเครือข่ายการค้นหา (search network) เราไม่ต้องการเปิดใช้งาน Display Network ดังนั้นเราจะแน่ใจว่ามันถูกปิดใช้งาน และตรงนี้เรามีการตั้งค่าทั้งหมดของเรา ไล่ลงไปจนถึงตำแหน่งที่ตั้ง (location) และวิธีกำหนดเป้าหมาย เราต้องการแบบ presence (อยู่ในพื้นที่นั้น) ไม่ใช่ presence or interest และนั่นคือทั้งหมดที่เราต้องทำ

พอทุกอย่างดูดีและคุณพร้อมจะอัปโหลดเข้าไปในบัญชีแล้ว คุณจะเก็บการเปลี่ยนแปลงทั้งหมดของคุณไว้ และส่วนสำคัญที่สุดคือปุ่ม Post จากนั้นคุณสามารถเลือกได้ว่าจะโพสต์เฉพาะการเปลี่ยนแปลงที่ทำกับแคมเปญนั้นโดยเฉพาะ หรือการเปลี่ยนแปลงที่ทำกับทั้งบัญชี เนื่องจากอันนี้เป็นแคมเปญทดลอง ผมแค่อยากแน่ใจว่ามันถูก pause ก่อนที่เราจะอัปโหลดเข้าบัญชี แค่นั้นเอง จากนั้นเราจะเห็นแคมเปญนี้ในบัญชี Google Ads ของเรา

เข้ามาในบัญชีอีกที หนึ่งในเทคนิคสุดโปรดของผม คือการใช้ Google Ads rules กฎเหล่านี้ดีมาก ถ้าคุณมีโฆษณาโปรโมชันที่อยากจะรัน แล้วต้องการเปิดปิดโฆษณาในช่วงเวลาที่กำหนด เช่น สมมติว่าช่วงลดราคาของคุณสิ้นสุดตอนเที่ยงคืน แทนที่คุณจะต้องคอยนั่งเฝ้าเพื่อปิดเอง คุณสามารถตั้งกฎได้ แล้วมันจะ pause โฆษณาให้อัตโนมัติ

กฎมีหลายประเภท กฎระดับแคมเปญ กฎระดับแอดกรุ๊ป กฎระดับโฆษณา มีหลายระดับที่เราสามารถใช้ได้ สมมติว่าเราอยากสร้างกฎเพื่อปิดโฆษณาลดราคา เราจะเลือก pause โฆษณาลดราคาพวกนี้ แล้วตรงนี้คุณสามารถเลือกโฆษณาในแคมเปญใดแคมเปญหนึ่ง หรือทั้งบัญชีก็ได้ หรือคุณสามารถกรองโฆษณาที่มีเงื่อนไขบางอย่างได้ด้วย ผมจะเลือกแบบ pause แล้วก็เลือกว่าจะส่งอีเมลแจ้งเตือนหรือไม่ แล้วก็ความถี่ คุณสามารถตั้งเป็นรายเดือนได้ แต่ถ้าเป็นแค่การปิดโฆษณาลดราคา เราจะเลือกเป็นรายครั้ง แล้วระบุเวลาที่ต้องการ

คุณสามารถลงมาด้านล่างตรงนี้ เพื่อตั้งเวลาจริงได้ด้วยตัวเอง มันไม่ใช่ช่วงเวลา เราอยากให้โฆษณาลดราคาของเราถูก pause เวลา 23:59 น. ของวันนั้น มันจะส่งอีเมลถึงคุณทุกครั้งที่มีการเปลี่ยนแปลงเหล่านี้ ถ้าคุณต้องการ หรือไม่ส่งอีเมลเลย ถ้าคุณมั่นใจว่ามันจะไม่พลาด จากนั้นคุณสามารถ preview เพื่อดูว่ากฎจะทำการเปลี่ยนแปลงอะไรบ้าง หรือจะบันทึกเลย ถ้าคุณแน่ใจ

ต่อไป เป็นเครื่องมืออีกอันหนึ่งที่อาจจะช่วยประหยัดเงินให้คุณได้นิดหน่อย สำหรับ Target ROAS และ Target CPA คุณอาจคิดว่าคุณควบคุมไม่ได้ คุณไม่สามารถตั้งค่าได้ในระดับแคมเปญ สิ่งที่เราทำได้คือเข้าไปที่เครื่องมือและการตั้งค่าของบัญชี แล้วทำจากตรงนั้น เพื่อตั้งค่า bid limit (เพดานการประมูล) เมื่อคุณใช้ Target CPA หรือ Target ROAS เราจะลงมาที่ส่วนกลยุทธ์การเสนอราคา (bid strategies) แล้วสร้างกลยุทธ์การเสนอราคาใหม่

เราจะเลือก Target CPA จากนั้นคุณสามารถตั้งชื่อให้มันได้ตามที่ต้องการ จะเป็นชื่อแคมเปญก็ได้ เราจะบอกว่าอันนี้สำหรับแคมเปญสีผมฟ้าของเรา จากนั้นตรงนี้เราจะเลือกแคมเปญที่ต้องการนำไปใช้ เรามีแคมเปญสีผมฟ้านี้ เราจะตั้ง Target CPA ที่เราต้องการสำหรับแคมเปญนี้ อาจจะเป็นค่าอะไรก็ได้แบบสุ่ม คุณยังสามารถสร้าง shared budget ได้ แต่สำหรับตรงนี้ เราแค่อยากใช้สิ่งนี้เพื่อตั้ง bid limit เลือกอันนั้น และตรงนี้คือจุดที่เราตั้ง bid limit ในตัวเลือกขั้นสูง

สิ่งนี้มีประโยชน์มาก ถ้าคุณมี CPA สูงมาก เพราะมันอาจทำให้ CPC สูงตามไปด้วย ถ้าคุณเห็น CPC ไต่ขึ้นสูงกว่าที่คุณต้องการมาก นี่คือจุดที่คุณจะตั้ง bid limit สำหรับกลยุทธ์การเสนอราคาอัจฉริยะ (smart bidding) ของคุณ สมมติว่าเพดานการประมูลสูงสุดของเรา เรากำลังเห็น search terms เข้ามา แล้วเราอยากจ่ายแค่ $10 คุณก็แค่ตั้ง maximum bid ตรงนี้ แล้วกดบันทึก คุณสามารถทำแบบนี้ได้กับแคมเปญแบบ Target CPA หรือ Target ROAS

ผมไม่ได้ใช้มันบ่อยนัก แต่พอได้ใช้เมื่อไหร่ มันเป็นสิ่งที่ดีมากที่ควรรู้ เผื่อจำเป็น และช่วยประหยัดเงินให้คุณได้นิดหน่อย รวมถึงช่วยลด CPC ลงได้ เหล่านี้คือเครื่องมือสุดโปรดของผมใน Google Ads ผมใช้ rules ตลอดเวลา เทคนิค bid strategies ก็เยี่ยม ถ้าคุณเห็น CPC สูง แต่ Google Ads Editor จะเป็นเพื่อนซี้ของคุณ ถ้าคุณต้องอัปโหลดจำนวนมาก ดังนั้นควรทำความรู้จักกับ Google Ads Editor ให้ดี
