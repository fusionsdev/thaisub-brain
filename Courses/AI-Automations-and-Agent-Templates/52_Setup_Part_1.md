## บทนำ

## คำแปลเต็ม

ในวิดีโอนี้เราจะมาตั้งค่าระบบอัตโนมัติที่เปลี่ยนจดหมายข่าวให้เป็นวิดีโอแบบที่เห็นอยู่นี้ พร้อมภาพเคลื่อนไหวและเพลงประกอบ และเราจะเริ่มต้นที่ N8N ครับ ถ้าคุณยังไม่มีบัญชี N8N ก็ไปสมัครก่อน และเมื่อทำเสร็จแล้วให้คลิก create a workflow จากนั้นไปที่ส่วนนี้ ในส่วนแรกคือ download automation workflow มันจะดาวน์โหลด blueprint ของระบบอัตโนมัติให้คุณนำเข้าไปใน N8N ได้ คลิกที่ import from file แล้วนำเข้าไฟล์นั้น จากนั้นเราก็แค่เชื่อมต่อโมดูลต่าง ๆ การตั้งค่าส่วนใหญ่ถูกเตรียมไว้ให้แล้ว สิ่งเดียวที่ต้องทำคือเชื่อมต่อโมดูลเหล่านี้ ไม่ต้องเชื่อมทั้งหมด แค่บางส่วน เพื่อให้ระบบเข้าถึงเครื่องมือและบัญชีของคุณเอง

เริ่มต้นด้วยการคลิก save ก่อน คุณจะตั้งชื่อให้มันก็ได้ ผมจะตั้งว่า demo newsletter จากนั้นที่จุดเริ่มต้น นี่คือ trigger ครับ ระบบอัตโนมัติแบบนี้ทำงานโดยผมส่งต่อจดหมายข่าวหรืออีเมลใด ๆ ไปยังอีกอีเมลหนึ่งที่เชื่อมต่อกับระบบ แล้วอีเมลนั้นจะถูกเปลี่ยนเป็นวิดีโอสามคลิป และสิ่งที่เราต้องทำคือเชื่อมต่อมันกับกล่องจดหมาย (inbox) ของเรา คืออีเมลที่เราใช้ส่งต่อจดหมายข่าว โดยผมจะใช้ Gmail และแนะนำให้คุณใช้ Gmail เหมือนกันเพราะเชื่อมต่อง่ายกว่า เพราะถ้าใช้เวอร์ชันเว็บ (web) ผมคลิก sign in with Google ได้เลย แต่ถ้าคุณใช้แบบ self-hosted อาจต้องทำขั้นตอนที่เทคนิคกว่าเล็กน้อย แต่ก็ทำง่ายเหมือนกัน แค่ให้ ChatGPT ช่วยคุณก็ได้

ตรงนี้ผมจะคลิก sign in with Google แล้วเลือกบัญชี Gmail ที่ต้องการเชื่อมต่อ ซึ่งเป็นบัญชีที่ผมใช้รับจดหมายข่าว และผมจะให้ลิงก์กับคุณด้วย ถ้ายังไม่มีบัญชี Gmail มีลิงก์ใต้วิดีโอนี้สำหรับสร้างบัญชี Gmail แค่สร้าง Gmail หรืออีเมลใหม่ หรือกล่องจดหมายใหม่ และให้แน่ใจว่าคุณได้ sign out จาก Google ก่อน แล้วคลิกลิงก์เพื่อสร้างบัญชีใหม่ คุณสร้าง Gmail ได้หลายบัญชี แล้วคุณก็จะมีกล่องจดหมายที่ใช้เชื่อมต่อกับ Google Sheet ต่อจากนั้นก็ทำตามขั้นตอนการเชื่อมต่อที่ผมเพิ่งทำไป พอเชื่อมต่อเสร็จแล้ว มาที่ trigger แล้วคลิก fetch test event ตรงนี้เราจะเปลี่ยนเป็น expression ตรงนี้ควรเป็น unread เรามาลองดูว่ายังทำงานได้ไหม มันควรดึงเฉพาะอีเมลที่ยังไม่ได้อ่าน และผมเห็นมันตรงนี้ ผมได้อีเมลล่าสุดมา สิ่งที่คุณควรทำคือเริ่มจาก... ผมจะลบพวกนี้ออกแล้วเลือกมาหนึ่งฉบับ แล้วส่งต่อ (forward) ผมจะเข้าไป คลิก forward แล้วพิมพ์อีเมล inbox ที่เพิ่งเชื่อมต่อ แล้วคลิกส่ง มันจะไปอยู่ตรงนั้น จากนั้นผมคลิก fetch test แล้วมันควรโหลดอีเมลนั้นขึ้นมา

ต่อไปเราจะไปอัปเดตสเปรดชีต คุณต้องเชื่อมต่อ Google Sheet ของคุณเอง และผมเตรียม template ไว้ให้แล้ว ไปที่ลิงก์ คลิก make a copy ผมจะตั้งชื่อให้ว่า demo และในชีตนี้มีฟีเจอร์หลายอย่าง คุณสามารถตั้งตารางการโพสต์ (posting schedule) ได้ ซึ่งเราจะพูดถึงรายละเอียดในตอนตั้งค่าถัดไปที่จะตั้งค่าระบบเผยแพร่จริง และระบบจะสร้างโพสต์จากข้อมูลที่บันทึกไว้ และตรงนี้ก็จะมีอีเมลไว้รับข้อความแจ้งกลับเมื่อวิดีโอถูกเผยแพร่แล้ว กลับมาที่นี่ จำบัญชี Google นี้ไว้ เพราะนี่คือบัญชีที่เราต้องเชื่อมต่อ ไปที่ create new แล้ว sign in with Google เลือกบัญชี Google เดียวกันกับที่สร้างชีตนี้ไว้ คลิก continue เสร็จแล้วกลับมา ไปที่เมนู drop-down หา Google Sheet นี้ และตรงนี้ต้องคลิกที่ email response เพราะสิ่งที่ผมต้องการบันทึกคืออีเมลที่ผมใช้ส่งต่อจดหมายข่าวมา ตรงนี้เรียกว่า update row และเป็นแถวที่สอง ถ้าคุณเข้าไป email response จะอยู่แถวที่สอง เป็นที่อยู่อีเมล และคุณต้องเลื่อนลงไปหาว่าอีเมลที่ผมส่งต่อมาอยู่ตรงไหน มันน่าจะอยู่ตรงนี้ ลองลากมันเข้ามา แล้วคลิก test ระบบจะดึงอีเมลขึ้นมา เยี่ยม มาทำต่อกัน

ตรงนี้เรามีฟังก์ชัน clean up ที่ทำความสะอาดข้อความอีเมล อย่างที่เห็น ข้อความที่ trigger module ได้มามันรกไปด้วยพารามิเตอร์ต่าง ๆ ผมไม่ต้องการแบบนั้น ผมต้องการข้อความที่สะอาดเพื่อให้โมดูลถัดไปประมวลผลได้ดีขึ้น ต่อไปคือ music เป็นเพลงประกอบที่ถูกเพิ่มให้วิดีโอของเรา ซึ่งสร้างโดย AI เราจะคลิกเข้าไปแล้วใช้เครื่องมือที่สร้างเพลงได้ ซึ่งเครื่องมือนี้อยู่ภายใต้ PIAPI (แพลตฟอร์มรวมบริการ AI ผ่าน API) คลิก open แล้ว sign up สำหรับบัญชีฟรี ผมสมัครไว้แล้ว สิ่งที่ต้องทำคือ คุณจะได้รับเครดิตฟรีจำนวนหนึ่ง พอใช้หมดต้องไปที่ settings แล้วไป billing เติมเงินสัก $5 หรือประมาณนั้น และตรงนี้เรามี audio model ภายใน PIAPI คุณสามารถเข้าถึงบริการ AI ต่าง ๆ จากแพลตฟอร์มเดียวผ่าน API ที่ใช้ในระบบอัตโนมัติได้ ในส่วนนี้ผมใช้ Div Rhythm API ซึ่งให้ผมสร้างแทร็กเพลงจาก prompt เพียงอย่างเดียว

ในการเชื่อมต่อ ไปที่ credential แล้วกรอก name และ value จาก PIAPI ผมเคยบันทึกบทเรียนสั้น ๆ ไว้ให้คุณแล้ว ใต้ technical tutorials เรื่อง get API key from PIAPI ดูได้เลย ใช้เวลาไม่กี่วินาที ใส่ค่าต่าง ๆ แล้วคลิก save แล้วก็ทำต่อได้ แล้วเราจะเลื่อนลงมาที่ body สิ่งสำคัญตรงนี้คือคุณใส่ music prompt ของคุณ นี่คือสิ่งที่กำหนดว่าแทร็กเพลงของวิดีโอแรกควรเป็นแบบไหน เราสร้างวิดีโอสามคลิป ดังนั้นเพลงแต่ละคลิปคุณเลือกได้เอง ผมอาจตั้งว่า soft piano เท่านั้นแหละ พอคลิก test step เพื่อดูว่ามันทำงานไหม จะเห็น status และเมื่อผมเข้าไปที่ PIAPI แล้วรีโหลด มันควรจะขึ้นการสร้างเพลงใหม่และกำลังประมวลผล และจากขั้นตอนก่อนหน้าของผม การสร้างเพลงอาจใช้เวลาถึง 4 นาที นั่นคือเหตุผลที่เรามีโหนด wait ตรงนี้ แต่ขอไปทำโมดูลอื่นก่อน สิ่งเดียวที่ต้องทำกับโมดูลอื่นคือเลือก credential ที่ถูกต้องแล้วใส่ prompt เพลงถัดไป ถ้าอยากได้สไตล์ต่างกันก็ใส่ เช่น rock music ผมจะลองเป็นสไตล์ที่สองสำหรับวิดีโอที่สองของผม และในช่อง music prompt ถัดไปก็ใส่ low-fi electronic music และควรตรวจสอบก่อนเสมอว่าโมดูลทั้งหมดกำลังประมวลผลและไม่มี error เพราะบางครั้งถ้าใส่ prompt สไตล์แปลก ๆ สองแบบอาจมีปัญหา แต่ตอนนี้ทุกอย่างเรียบร้อยดี

ต่อไปคือโหนด wait รอประมาณ 5 นาที ควรเป็น 5 นาที แล้วคลิก test step แล้วรอ 5 นาทีจนกว่าเพลงจะสร้างเสร็จ ตอนนี้ผมเห็นแล้วว่ามันดี ตรงนี้คือจุดที่เราได้ music URL เราจะสร้างมันขึ้นมาและต้องรับมันกลับมาด้วย และนั่นคือเหตุผลที่เราใช้บัญชี PIAPI เดียวกัน ตรงนี้ควรเป็นสีเขียวแล้ว และเราก็แค่รอจนกว่าการสร้างเพลงจะเสร็จ ตรวจสอบให้แน่ใจว่าเลือกบัญชี PIAPI ที่เชื่อมต่อไว้ถูกต้อง แล้วก็ไปต่อได้ ผมจะปล่อยให้มันรัน 5 นาทีระหว่างนี้

สำหรับการสร้างวิดีโอ สิ่งที่ต้องเชื่อมต่อคือ OpenAI แน่นอนคุณเปลี่ยนเป็นโมเดล AI อื่นที่อยากใช้ก็ได้ แค่ให้คง prompt ไว้ ผมจะปล่อยไว้แบบนี้ ในการเชื่อมต่อ OpenAI คลิก create new credential แล้วใส่ API key ของคุณ ผมมีบทเรียนสั้น ๆ ให้คุณแล้ว มันง่ายมาก ไปดู get API key from OpenAI ใส่ API key แล้วเสร็จ ตรงนี้เป็นแค่ prompt มันทำหน้าที่สร้างสคริปต์วิดีโอสำหรับวิดีโอทั้งสามคลิป อย่างที่เห็นในวิดีโอของเรา ตรงนี้มีองค์ประกอบข้อความหลายส่วน เรามี title อยู่ด้านบน จากนั้นก็มีสคริปต์ และมีฉาก (scenes) ต่าง ๆ ผมแบ่งเป็นสี่ฉาก พร้อมภาพเคลื่อนไหวต่าง ๆ ที่จะถูกสร้างในขั้นตอนถัดไป สิ่งที่เราต้องการคือวิดีโอสคริปต์สี่ชุด สำหรับสี่ฉาก และเรายังต้องให้ AI สร้าง prompt สำหรับภาพด้วย นี่คือสิ่งที่ระบุไว้ใน prompt ตรงนี้ เหมือนเป็นคำสั่งให้โมเดล AI ของเราสร้างผลลัพธ์ที่ต้องการ และเราขอให้มันสร้าง prompt สำหรับภาพ เพื่อใช้ในขั้นตอนถัดไป แต่ละฉากมันควรสร้าง prompt สำหรับภาพที่ตรงกับหัวข้อของวิดีโอ นั่นคือสิ่งที่เรากำลังทำอยู่ตรงนี้ ตรงนี้ยังเป็นสีเทาเพราะต้องรอให้ขั้นตอนก่อนหน้าทำเสร็จก่อน แล้วมันควรเปลี่ยนเป็นสีเขียว

โมดูลถัดไปคุณไม่ต้องแก้ไขอะไร เราจะรอจนกว่าจะไปต่อได้ โมดูลนี้แค่ลบเครื่องหมายคำพูด (quotation marks) ออกจาก prompt สร้างภาพที่ได้จากตัวสร้างสคริปต์ เพื่อไม่ให้เกิด error ในขั้นตอนถัดไป ต่อไปคือ get voice โมดูลนี้ทำอะไร? ผมเลือกบัญชีที่เชื่อมต่อไว้แล้ว get voice ให้ผมระบุเสียงที่ต้องการใช้ใน voiceover ได้ และผมจะแสดงให้ดูว่าจะหารายการเสียงได้จากที่ไหน แต่ก่อนอื่นต้องเชื่อมต่อมันกับโมดูลที่ถูกต้องก่อน มันอยู่ในตำแหน่งที่ถูกต้องแล้วใช่ไหม? เท่านี้พอ มันดึงค่าทั้งหมดจากขั้นตอนนี้มา แล้วผมค่อยเลือกทีหลัง: ผมแค่ต้องการค่า voice เท่านั้น ด้านล่างคุณจะเห็นรายการเสียงที่ใช้ได้ ซึ่งจัดเรียงตาม... และนั่นเป็นส่วนของเครื่องมืออีกตัวที่เราจะเชื่อมต่อในขั้นตอนถัดไป แต่เราจะตั้งค่า voiceover ก่อน คุณอยากใช้เสียงแบบไหน? เลือกตาม... แล้วทดสอบได้ เช่น ไปที่ All voices คุณจะเห็นโมเดลเสียงต่าง ๆ ผมจะไปที่ voices by แล้วค้นหาในบัญชีของผม แล้วเลือกเสียงที่ชอบ ผมจะใช้ United States และตรงนี้ผมเลือกเสียงนี้ หรือเลือก Andrew ก็ได้ คุณฟังตัวอย่างเสียงได้ถ้าต้องการ ผมจะคลิกอันนี้ แล้ววางค่าเสียงลงตรงนี้ แล้วเสียงนี้จะถูกใช้ในวิดีโอของเรา

กลับมาที่ scenario ของผม มันรันเสร็จแล้ว ตอนนี้ไปที่ Get music คลิก test step มันควรให้ URL ของแทร็กเพลงมา เมื่อไม่มี error แปลว่าทำงานได้ คลิก test นี่คือแทร็กถัดไป เยี่ยม และคลิก test step อีกครั้ง มันก็ทำงาน ผมลองเปิดตรวจสอบหนึ่งแทร็กได้ เปิดมา มันใช้ได้ คลิก save แล้วผมจะไล่ดูโมดูลที่เพิ่งแสดงให้ดู เพื่อตรวจว่าตัวแปรตรงนี้เป็นสีเขียวหมด ตรงนี้เห็นว่ามันคือข้อความอีเมลที่ใช้สร้างสคริปต์ เป็นสีเขียว ดี จากนั้นเราอยากใช้ clean quotes เพื่อดูว่ามันรันได้ไหม ก่อนอื่นมันต้อง trigger การสร้างสคริปต์วิดีโอก่อน แล้วมันจะเอาสคริปต์วิดีโอที่สร้างขึ้นมาทำความสะอาด ลบเครื่องหมายคำพูดออกทั้งหมดเพื่อไม่ให้ error ตรงนี้ทำงานได้แล้ว นี่คือเนื้อหาที่สะอาด ต่อไปไปที่ get voice คลิกมัน มันควรให้ตารางออกมา แล้วเราจะใช้ค่าเดียวจากตารางนี้ในขั้นตอนถัดไป ก่อนอื่นเราต้องแยกค่าต่าง ๆ ออก นี่คือสิ่งที่ฟังก์ชัน split ทำ จะเห็นภาพชัดขึ้นตรงนี้ นี่คือ output ที่เราได้จาก AI ซึ่งเป็นข้อความก้อนเดียว และตอนนี้เราแยกมันออกเป็นส่วนต่าง ๆ เพื่อใช้แต่ละส่วนในโมดูลที่เราจะสร้างต่อไป

นี่คือส่วนการสร้างวิดีโอ เราไปที่โมดูลของวิดีโอหนึ่ง ตรงนี้เราใช้บริการอีกแบบหนึ่งที่เรียกว่า JSON2Video (บริการสร้างวิดีโอจากโค้ด JSON) ผมเปิดมันไว้แล้วตรงนี้ นี่คือ JSON2Video นั่นคือชื่อ คุณจะพบลิงก์ด้านล่าง คุณสมัครบัญชีฟรีเพื่อทดลองใช้ได้ แล้วเราต้องใช้อะไรตรงนี้? กลับไปดู ตรงนี้ตั้งค่าไว้แล้ว นี่คือ URL ตรงนี้คุณต้องใช้ custom auth ไปที่ create credential สิ่งที่ต้องทำคือเลื่อนลงมาด้านล่าง แล้ววาง... คัดลอกอันนี้มาวางตรงนี้ และตรงนี้ใส่ API key ของ JSON2Video ไปที่ API keys หาคีย์ของคุณ คัดลอกแล้ววางตรงนี้ อยู่ในเครื่องหมายคำพูด แล้วคลิก save มันก็เชื่อมต่อเสร็จ แล้วเลื่อนลงมา มีบางอย่างที่ต้องตรวจสอบ ต้องเช็คว่าทุกอย่างเป็นสีเขียว มันควรเป็นแบบนั้น ผมจะอธิบายสั้น ๆ ว่า JSON2Video สร้างวิดีโอให้คุณได้อย่างไร อย่างที่เห็น นี่คือ output ของ JSON2Video มันเพิ่ม title ด้านบน สร้างภาพสี่ภาพสำหรับแต่ละฉาก เพิ่มคำบรรยาย และสร้าง voiceover มันทำทั้งหมดนี้ให้เรา ภายในบล็อกโค้ดนี้ และมีการปรับแต่งบางอย่างที่เปลี่ยนสไตล์วิดีโอที่คุณจะได้ นี่คืออย่างแรก Instagram story เป็นรูปแบบแนวตั้ง นี่คือโมเดลสร้างภาพ ตรงนี้คือ prompt ที่มาจาก AI ของเรา มาจากตรงนี้ คุณปรับแต่ง prompt ได้เพื่อให้ได้สไตล์การสร้างภาพที่ต่างออกไป ถ้าต้องการทำแบบนั้นก็สุดแล้วแต่คุณ ผมแค่อยากแสดงให้เห็นว่าค่าเหล่านี้มาจากไหน วิดีโอ prompt นี้สร้างภาพให้เรา นี่คือโมเดลที่สร้างภาพ มีอีกโมเดลหนึ่งชื่อ Flux Pro คุณลองใช้ได้ มันเสียเงินนิดหน่อย และคุณจะเห็นรายละเอียดค่าใช้จ่ายด้านล่างวิดีโอนี้ แต่ผมจะใช้ Flux Shell เพราะผมมีประสบการณ์ที่ดีกับมัน ส่วน duration หมายความว่าภาพจะยาวเท่ากับ voiceover script และ resize หมายถึงภาพจะเต็มทั้งเฟรมของวิดีโอ และตรงนี้มี zoom และ pan หมายความว่าวิดีโอจะซูมเข้า ภาพเคลื่อนไปทางซ้ายหรือขวา นี่คือวิธีควบคุมการเคลื่อนไหว

ต่อไปคือการสร้างสคริปต์ ตรงนี้คือวิดีโอสคริปต์ที่มาจากโมเดล OpenAI ของเรา และตรงนี้คือเสียง เราใส่เสียงนี้ลงในสเปรดชีตไว้ก่อนแล้ว และตรงนี้คือสคริปต์ และมันซ้ำกันสี่ฉาก มีสี่ฉาก: สร้างภาพสี่ครั้ง voice และคำบรรยาย คุณปรับข้อความที่อยู่ด้านบนได้ นี่คือสไตล์: พื้นหลังขาวดำ ตามที่ผมกำหนดไว้ และฟอนต์ คุณปรับเปลี่ยนได้ตามต้องการ ทดลองดูได้ นี่คือสไตล์คำบรรยาย นี่คือแทร็กเพลง นี่คือระดับเสียงเพลง ตรงนี้ปรับได้ เช่น ยิ่งค่ายิ่งเบา พอปรับเสร็จก็ไปต่อกัน

ก่อนไปต่อ เรามา trigger จริง ๆ เพื่อดูว่ามี error ไหม นี่คือสิ่งที่เราควรทำก่อนไปต่อเสมอ trigger แล้วมันทำงาน มันทำงานในแบบเดียวกัน เราประมวลผล ซึ่งใช้เวลาประมาณ 2 นาทีต่อคลิป แล้วเราก็จะได้ URL มา ขอรีบดูว่าทุกอย่างเป็นปกติ มันควรเป็นแบบนั้น เราจะ trigger อันนั้น และอันนี้ด้วย นี่คือคลิปที่สาม คลิก test step แล้วเรามีโหนด wait ที่รอ 2 นาที ซึ่งเป็นเวลาปกติที่ใช้สร้างวิดีโอ และคุณเห็นได้จาก render logs ว่าควรมีวิดีโอสามรายการกำลังประมวลผล เห็นว่าวิดีโอสามตัวกำลังรัน ดี แล้วเราก็รอ

ระหว่างนี้เราไปโมดูลถัดไปได้ คล้ายกัน เราได้ค่ามา ซึ่งเชื่อมต่อไว้แล้ว เป็นสีเขียวอยู่แล้ว แค่ตรวจให้แน่ใจว่ามันเชื่อมต่อกับบัญชี JSON2Video ที่คุณสมัครไว้ก่อนหน้า สำหรับวิดีโอทั้งหมดนี้ แล้วมาต่อกัน นี่คือส่วนการสร้างวิดีโอ และเท่านี้ก็ครบแล้ว ตอนนี้ผมจะพาคุณดูโมดูลอื่น ๆ อย่างคร่าว ๆ ซึ่งตรงไปตรงมา นี่คือตัวสร้าง video ID สิ่งเดียวที่มันทำคือสร้างสตริงอักขระผสมตัวอักษรและตัวเลขเพื่อสร้าง ID วิดีโอที่ไม่ซ้ำกัน ซึ่งจะถูกบันทึกไว้ในโฟลเดอร์ generated ของผม วิดีโอแต่ละคลิปมี ID เดียว เพื่อให้ระบุได้ทีหลัง และมันทำแบบนี้กับวิดีโอทุกคลิป

จากนั้นเรามาที่นี่ มีโมดูล OpenAI อีกตัวที่จะสร้างแคปชัน (captions) ซึ่งก็คือข้อความที่จะโพสต์พร้อมวิดีโอบนแพลตฟอร์มโซเชียลมีเดีย คุณปรับแต่งได้แน่นอน อย่างที่เห็น เรามี prompt ที่รวมสไตล์ต่าง ๆ และตัวอย่างแคปชันไว้ คุณปรับตามแคปชันที่ต้องการได้ แล้วก็มี split captions แยกแคปชันออกเป็นสามส่วน เพื่อเก็บใส่แต่ละวิดีโอ แล้วก็ clean subject ดึงหัวข้อ (subject line) ของจดหมายข่าวต้นฉบับ มันดึงข้อความดิบของหัวข้อออกมาโดยไม่มีอักขระแปลก ๆ แล้วบันทึกทุกอย่างลง Google Sheet

ตรงนี้ไปที่ Google Sheet ดับเบิลคลิก จะเห็นว่าวิดีโอถูกบันทึกแล้ว เพราะตอน trigger มันจะเรียกใช้โมดูลทั้งหมดก่อนหน้านั้นด้วย ผมเปิดเข้าไปได้เลย แต่ก่อนอื่นต้องเชื่อมต่อบัญชี Google ที่ถูกต้องก่อน ถ้าคุณมีหลายบัญชี ของผมคือบัญชีนี้ที่เก็บ Google Sheet ไว้ จากนั้นเลือก Google Sheet ของผม แล้วตอนนี้ผมจะบันทึกข้อมูลทุกอย่างเกี่ยวกับวิดีโอที่ต้องใช้ ตรงนี้เรามี video ID ที่สร้างไว้ วิดีโอ ID หมายเลขหนึ่ง ตรงนี้คือ video ID ตรงนี้มีสีแดง บางครั้งก็เป็นแบบนี้ คุณแค่พิมพ์ 1st ลงในวงเล็บเหล่านี้ แล้วมันควรจะทำงานได้ ต่อไปคือหัวข้อจดหมายข่าว (newsletter subject line) เราได้มาจากไหน? จาก clean subject นั่นแหละ ต่อไปคือ text overlay ของวิดีโอหนึ่ง มาจาก... ไปดูในตารางจะง่ายกว่า จาก generate video scripts มันมาจากฟังก์ชัน split ดังนั้น caption ของวิดีโอหนึ่งคือ text overlay นั่นคือ title ตรงนี้ผมต้องเลือก พิมพ์ 1st แล้วมันควรจะได้ค่า แล้วก็สคริปต์ สคริปต์ก็คือ voiceover ทั้งหมดตรงนี้ สคริปต์วิดีโอหนึ่ง เสียงที่สอง... วิดีโอเสียงสคริปต์ที่สามและเสียง... ทั้งหมดนี้มาจากวิดีโอใช่ไหม? เราจะทำวิดีโออื่นต่อ

ตอนนี้ผมเห็นว่ายังมีค่าเหล่านี้อยู่ ผมจะจับมันมา คัดลอกแล้วแทนที่ตรงนี้ แล้วก็มีค่าที่มาจาก split ซึ่งคือแคปชันหมายเลขหนึ่ง ผมลากมันมาตรงนี้ แล้วต้องแทนที่ด้วย 1st อีกครั้ง จากนั้นเป็น video URL ผมกลับไปที่ get video นี่คือ URL แล้วตรงนี้ก็ใส่ 1st อีกครั้ง ผมไม่ต้องการค่านี้แล้ว เลยลบทิ้ง แล้วคลิก test step ถ้าไปดูในสเปรดชีต มันควรบันทึกวิดีโอแรกพร้อมข้อมูลทั้งหมดที่จำเป็นสำหรับแพลตฟอร์มเผยแพร่
