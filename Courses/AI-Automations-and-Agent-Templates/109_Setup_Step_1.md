## บทนำ
วิดีโอนี้เป็นขั้นตอนแรกของการตั้งค่า AI agent ที่ทำงานในข้อความตรง (direct messages) ของ Instagram เมื่อมีคนคอมเมนต์ใต้โพสต์ ระบบจะส่งข้อความตรงไปหาเพื่อคัดกรอง (qualify) และส่งลิงก์จองคอลหรือลิงก์ซื้อสินค้าระดับเริ่มต้นให้ ครอบคลุมการนำเข้า workflow ใน n8n การเชื่อมต่อ Google Sheets, การตั้งค่าระบบจองนัดหมายด้วย Cal.com และการปรับแต่งบทสนทนาของ AI agent

## คำแปลเต็ม

ในวิดีโอนี้เราจะตั้งค่าขั้นตอนแรกของ AI agent ที่ทำงานในข้อความตรงของ Instagram เมื่อใดก็ตามที่มีคนคอมเมนต์ใต้โพสต์ของเรา มันจะส่งข้อความตรงไปหาพวกเขา คัดกรองพวกเขา ส่งลิงก์จองคอลหรือลิงก์ซื้อสินค้าระดับเริ่มต้นของเรา

และขั้นตอนแรกคือดาวน์โหลด AI agent workflow นี้ด้านล่างวิดีโอ แล้วไปที่ n8n คุณสามารถสมัครบัญชีฟรีได้ ถ้าคุณยังไม่มี คุณจะได้ทดลองใช้ฟรี 14 วัน และเมื่อเข้าสู่ระบบแล้ว ไปที่ dashboard ของคุณ คลิก create workflow แล้ว import from file แล้วเลือกไฟล์ที่เพิ่งดาวน์โหลด จากนั้น workflow ทั้งหมดจะถูกนำเข้า

สิ่งที่เหลือคือการเชื่อมต่อโหนดต่าง ๆ กับบัญชีของคุณ webhook ไม่ต้องใช้ข้อมูลประจำตัวใด ๆ มาเริ่มจากส่วนบน แล้วไล่ลงมาด้านล่าง อันดับแรกเราจะตั้งค่าสองอันนี้ และ SMS reminder จะมาในขั้นตอนสุดท้ายคือขั้นตอนที่สี่

ไปกันต่อ สิ่งที่เราต้องเชื่อมต่อคือ Google Sheet ของเรา ด้านล่างวิดีโอนี้คุณจะพบ Google Sheet database template นี่คือที่เก็บข้อมูลทั้งหมดที่ AI agent ของเรารวบรวมผ่านกระบวนการ: ชื่อติดต่อ เบอร์โทร และอื่น ๆ คลิก make a copy แล้วไปที่บัญชีนี้ หรือเรามาตั้งชื่อก่อน ให้ชื่อที่ไม่ซ้ำกัน ผมจะเรียกมันว่า Setup Demo และวันที่วันนี้ 27

แล้วผมเข้ามาตรงนี้ ผมต้องไปที่ create new credential ถ้าคุณยังไม่ได้เชื่อมต่อบัญชี Google Sheets คุณต้องทำแบบนี้ แล้วคลิก sign in with Google ตรงนี้ผมเลือกบัญชีที่เชื่อมกับ Google Sheet นี้ คุณหาบัญชีได้โดยวางเคอร์เซอร์ที่มุมขวาบนเหนือไอคอนนี้ ซึ่งเป็นโปรไฟล์ของคุณ แล้วผมเลือกอันนี้ คลิก continue มันสำเร็จแล้ว แล้วผมคลิกตรงนี้เพื่อหา Google Sheet นี้ และตรงนี้เราต้องเลือก leads ตอนนี้เพิ่ม filter อีกครั้ง แล้วมันควรจะโหลดข้อมูล สิ่งที่เราจะโหลดคือ contact ID

ตอนนี้เราจะต้องจับคู่ข้อมูล แต่เราจะทำแบบนี้ ขอพิมพ์ test ไว้ก่อน แล้วไปต่อ ตรงนี้เรามี create booking นี่คือเครื่องมือจองที่เราใช้สร้างและยืนยันกระบวนการจอง เพื่อสร้างการจองนัดหมายในเครื่องมือจองของเรา เราใช้บริการอีกตัวที่ชื่อว่า Cal.com คลิกเปิดมัน คุณสามารถสมัครบัญชีฟรีได้ และฟรีตลอดไป ไม่มีข้อจำกัดในแพ็กเกจนั้น

เมื่อเข้าสู่ระบบแล้ว ไปที่บัญชีของคุณ แล้วภายใต้ event types คลิก create a new event จะลบอันนี้ทิ้งก่อน แล้วสร้าง test event ใหม่ การสร้างนัดหมายนี้ คุณสามารถเรียกมันว่า consulting call หรือ coaching call หรือ strategy ก็ได้ ตรงนี้คุณตั้งกรอบเวลา ผมจะตั้งเป็น 45 นาทีก่อน แล้วคุณสามารถตั้งเวลาว่าง ว่าคุณต้องการให้คนจองคอลได้เมื่อไหร่ และอื่น ๆ อีกเล็กน้อย เช่น จองล่วงหน้าได้กี่ครั้ง และอื่น ๆ ซึ่งจะกำหนดเวลาว่างที่จองได้

แล้วคลิก save แล้วคุณสามารถ preview ได้ แล้วคุณจะเห็นว่านี่คือหน้าจองที่คนปกติจะเห็นถ้าคุณส่งลิงก์ให้พวกเขา AI agent ของเราสามารถเข้าถึงเวลาว่างเหล่านั้นได้ และการทำแบบนี้เราต้องเอา API key จาก Cal.com ก่อน กลับไปที่บัญชีของคุณ คลิกที่ API keys คลิก Add a New Key ผมจะตั้งชื่อมัน ชื่อไม่สำคัญมากนัก มันเป็นแค่สำหรับคุณเพื่อให้ระบุคีย์ที่คุณสร้างได้ คลิก never expires แล้ววางคีย์นี้ตรงนี้

และอีกสิ่งหนึ่งที่ต้องเพิ่มคือ event ID เราได้ event ID โดยกลับไปที่ event types แล้วคลิกที่ event ที่คุณสร้าง แล้วคัดลอกตัวเลขนี้ แล้ววางในฟิลด์นั้น และนั่นคือทั้งหมดที่เราต้องทำเพื่อตั้งค่าระบบนี้สำหรับการสร้างการจอง

และกระบวนการถัดไปก็เป็นแค่ฟังก์ชันที่แปลงวันที่จองให้อยู่ในรูปแบบที่เหมาะสมสำหรับผู้ใช้ และถ้าพวกเขามีการจองอยู่แล้ว เราจะบอกว่า ดูเหมือนว่าการจองนี้ไม่ว่างแล้ว กรุณาเลือกเวลาอื่น นี่คือการจอง และคุณจะเห็น workflow ทำงานจริงในวิดีโอต่อ ๆ ไป ในอีกไม่กี่นาที

ตรงนี้ผมต้องเลือก update sheets ผมต้องเลือกบัญชี Google ที่เชื่อมไว้ และผมสามารถหาชีตนี้ที่เราสร้างไว้สำหรับสิ่งนั้นได้ และอันนี้ควรถูกกรอกไว้แล้ว เอาล่ะ ตรงนี้ผมมี contact ด้วย ดังนั้นผมสามารถดึงมันมา และผมต้องการมันจริง ๆ ตรงนี้ ผมสามารถวางค่าได้แล้ว ดังนั้นผมต้องสลับเป็น expression ดี

แล้วสิ่งที่อันนี้ทำคือ หลังจากที่การจองได้รับการยืนยัน มันจะเขียนลงในชีตของเรา คุณเห็นไหมว่าตรงนี้มีข้อมูลทั้งหมด มันเขียนตรงนี้ว่าการจองสำเร็จ เพื่อให้เรารู้ว่าคนนี้ยืนยันการจองนัดหมายแล้ว

และตอนนี้มาถึงกระบวนการคัดกรอง (qualification process) เราจะตั้งค่ามัน ตอนนี้มันก็ง่ายมากเช่นกัน เราแค่เชื่อมต่อบัญชีของคุณ ไปที่ Create New Credential ถ้าคุณยังไม่ได้เชื่อมต่อ แล้วคุณสามารถไปที่บทช่วยสอนทางเทคนิค คลิก get API key from และมันจะแสดงให้เห็นว่าคุณจะเอา API key ได้จากที่ไหน แล้ววางมันลงไปแล้วคลิก Save ผมทำไว้แล้ว นี่คือโมเดลที่ผมใช้ ซึ่งเชื่อถือได้สำหรับการใช้งานประเภทนี้

ตรงนี้เรามีเครื่องมือง่าย ๆ เราไม่ต้องเชื่อมต่ออะไรตรงนี้ แต่ที่นี่สำคัญคือต้องเลือก Google Sheet ที่ถูกต้องอีกครั้ง นี่คือ Google Sheet ที่ผมเชื่อมต่อ อันนี้ และทุกอย่างอื่นจะถูกกรอกให้ตลอดการสนทนา AI agent จะเข้าถึงเครื่องมือนี้และบันทึกเบอร์โทร สรุป และ contact ID ซึ่งสำคัญสำหรับการระบุผู้ติดต่อ

ตรงนี้โดยพื้นฐานมันกำหนดค่า และตรงนี้ผมมีคำอธิบาย ผมบอกได้ว่าควรบันทึกอะไรลงตรงนี้ และเรามีอีกชีตหนึ่งที่แชร์กันเรียกว่า update leads นี่คือตอนที่มันสามารถบันทึกข้อมูลเพิ่มเติมระหว่างการสนทนาที่มันยังไม่ได้บันทึกในรอบแรก

แล้วเรามีเครื่องมือนี้ ตรงนี้เราก็ต้องเลือกให้แน่ใจว่าถูกต้อง แล้วมันสามารถบันทึก: คนนี้ติดต่อเมื่อไหร่? เลือกนัดหมายอะไร? โซนเวลาของเขาคืออะไร? เพื่อให้การแปลงโซนเวลาทำงานถูกต้อง

และตรงนี้เรามีเครื่องมือปฏิทินด้วย ดังนั้นในการสร้างการจองตรงนี้ AI agent จะดูเวลาว่าง มันจะเข้าถึง event ของคุณและดูว่าเวลาไหนว่างบ้าง และมันทำได้ด้วยเครื่องมือนั้น เราคลิกที่มัน เราต้องเพิ่มข้อมูลประจำตัวของคุณตรงนี้ด้วย เราต้องการ event ID เหมือนกัน เรายังมี event อยู่ตรงนี้ นี่คือตัวเลขเมื่อคุณคลิกที่ event ของคุณ และเราต้องการ API key ด้วย มันอยู่ตรงนี้ เราใช้มันไปแล้ว มันเป็นตัวเดียวกับที่เราใส่ไว้ก่อนหน้านี้ มา copy ค่าทั้งหมดแล้วไปตรงนี้ แล้ววางมันลงไป แล้วเราก็กรอกครบทุกอย่างแล้ว ไม่ต้องคิดอะไรเพิ่ม

นี่คือสิ่งที่ AI agent จะทำ มันจะตรวจสอบเวลาว่างของฉันใน event การจองคอลของฉัน และส่งกลับมาให้ฉัน

อีกหนึ่งสิ่งที่คุณอาจต้องปรับคือการตั้งค่าโซนเวลาของคุณ เพราะ AI agent จะบันทึกเวลานี้ในโซนเวลาของคุณ และสิ่งนี้ถูกกำหนดใน system instruction ของคุณ นี่คือสิ่งที่สองที่คุณต้องแก้ไข

นี่คือ use case สำหรับประเภทธุรกิจของผม ตรงนี้คือ identity: คุณคือ Fabian Marcus เป็นคนที่เป็นมิตรบน Instagram ตรงนี้คุณต้องกรอกชื่อของคุณเอง และตรงนี้อีกครั้งแทนที่ด้วยชื่อของคุณ

นี่คือ context นี่คือสิ่งที่ AI agent ควรรู้ หรือมันมีหน้าที่อะไร? มันใช้อะไรเป็นข้อมูลบริบท? ผู้เชี่ยวชาญระบบอัตโนมัติของฉันช่วยเหลือลูกค้าประเภทนี้ เขาเสนอสิ่งนี้ สิ่งนี้ และนี่คือสิ่งที่คุณต้องแก้ไขตามประเภทธุรกิจเฉพาะของคุณ

และตรงนี้คือ role คุณก็แค่เปลี่ยนชื่อ และจากนั้นเรามี qualification requirements ควรเกิดอะไรขึ้น? ถ้าคนนี้เหมาะสม มันจะส่งลิงก์ให้จองคอล ถ้าไม่เหมาะสม มันจะส่งลิงก์ไปยังข้อเสนอระดับเริ่มต้น ในกรณีของฉันคือ subscription template และถ้าไม่ใช่ ถ้าพวกเขาไม่ต้องการซื้อ ก็ส่งลิงก์ไปยังช่อง YouTube ของฉัน

และนี่คือ flow ของการสนทนา ควรเริ่มต้นอย่างไร? เช่นเมื่อมีคนคอมเมนต์หรือส่ง DM มาหาคุณ มันจะเรียกข้อความนี้ มันจะเริ่มการสนทนาและกระบวนการคัดกรอง จากนั้นมันจะถามคำถามเหล่านี้ และหลังจากแต่ละคำถาม มันจะประเมิน: จากคำตอบที่คนนี้ให้มา เขาผ่านการคัดกรองหรือไม่? จากนั้นมันจะทำการคัดกรองขั้นสุดท้ายแล้วตัดสินใจ: ควรเกิดอะไรขึ้นต่อจากนี้?

ถ้าผ่าน มันจะถามผู้ใช้ชื่อและอีเมล แล้วบันทึกข้อมูลนั้นลงใน Google ชีตหรือฐานข้อมูลของฉัน จากนั้นมันจะถาม: ดูเหมือนคุณเหมาะสมดี คุณต้องการจองคอล 45 นาทีไหม? ตรงนี้คุณต้องกำหนดความยาวของการโทรของคุณ ควรยาวเท่าไหร่? ในกรณีของฉันคือ 45 นาที ถ้าของคุณ 30 หรือ 15 นาที คุณต้องเปลี่ยนสิ่งนี้ และคุณต้องเปลี่ยนลิงก์ด้วย ตรงนี้คือชื่อและการโทรของคุณคืออะไร และลิงก์ตรงนี้

และถ้าพวกเขาไม่ผ่านการคัดกรอง คุณต้องบอกมันว่าควรทำอย่างไร ในกรณีนี้ฉันส่งลิงก์ไปยังข้อเสนอระดับเริ่มต้นหรือทรัพยากรฟรี และถ้าพวกเขาไม่ผ่านและไม่ต้องการซื้อ ฉันก็ส่งลิงก์ไปยังช่อง YouTube

และตอนนี้ appointment booking flow คุณสามารถปล่อยไว้แบบนี้ได้โดยพื้นฐาน สิ่งเดียวที่คุณอาจต้องเปลี่ยนคือตรงด้านล่าง ตรงนี้เรามีโซนเวลา ไม่มีการปรับแต่งอื่นที่จำเป็น ดังนั้นตรงนี้บันทึกเวลาจองที่แปลงเป็นโซนเวลาเฉพาะของฉันลงในชีต update leads คุณต้องแทนที่ด้วยตำแหน่งที่ตั้งและโซนเวลาของคุณ มันสามารถเป็นเมืองใหญ่ถัดไปที่อยู่ในโซนของคุณได้ AI agent จะรู้ว่าโซนเวลาของตำแหน่งนี้คืออะไร นี่คือโซนเวลาของคุณ

และผมคิดว่านั่นคือทั้งหมดที่ต้องเปลี่ยน เมื่อคุณตั้งค่าระบบนี้เสร็จแล้ว คุณสามารถกลับไปคลิก และขั้นตอนแรกนี้ก็ตั้งค่าเสร็จเรียบร้อย
