## บทนำ
วิดีโอนี้สอนสร้าง AI agent ที่จองนัดหมายกับลูกค้าหรือผู้สนใจผ่าน WhatsApp ให้ตรงกับปฏิทินของคุณ โดยใช้ n8n ร่วมกับ OpenAI, Google Calendar, Google Sheets และ Gmail เพื่อรับข้อมูลผู้จอง ค้นหาช่วงเวลาว่าง แปลงเขตเวลา บันทึกข้อมูล และส่งอีเมลยืนยัน รวมถึงระบบเตือนความจำผ่าน WhatsApp ก่อนถึงเวลานัด

## คำแปลเต็ม

ในวิดีโอนี้เราจะสร้าง AI agent ที่สามารถจองนัดหมายกับผู้สนใจหรือลูกค้าให้ตรงกับปฏิทินของคุณ ด้านล่างนี้คุณจะพบเทมเพลต AI agent แค่คลิกดาวน์โหลดแล้วไปที่ n8n ถ้าคุณยังไม่ได้สร้างบัญชี n8n คุณสามารถไปที่ n8n และสมัครใช้งานฟรีสำหรับทดลองใช้ และเมื่อทำเสร็จแล้วคุณสามารถคลิก create a workflow แล้วนำเข้า workflow ที่คุณเพิ่งดาวน์โหลด ผมไปที่ import from คลิกที่มัน แล้วมันก็จะถูกนำเข้า และสิ่งที่เหลือก็แค่เชื่อมต่อโมดูลต่าง ๆ ตรงนี้ เรามาดูกัน

เริ่มจากอันแรกคือ WhatsApp trigger ถ้าคุณดับเบิลคลิกที่มันและยังไม่ได้เชื่อมต่อ WhatsApp คุณต้องสร้าง credential ใหม่ ถ้าคุณเชื่อมต่อไว้แล้วเพราะคุณเคยสร้าง AI agent ตัวอื่นไว้แล้ว สิ่งที่ต้องทำคือต่ออายุ และคุณไม่ต้องทำอะไรกับ client ID หรือ client secret แต่คุณจะต้องหาโหนดอื่นหรือโมดูลอื่นตรงที่มันระบุว่า access token แล้วแทนที่ด้วย access token ใหม่ของคุณ ถ้าคุณไม่มีโทเคนถาวร และผมจะเริ่มจากจุดเริ่มต้น สิ่งแรกที่คุณต้องทำคือ กลับไปก่อน ผมถือว่าคุณยังไม่ได้เชื่อมต่อ ถ้าคุณเชื่อมต่อแล้วคุณก็มี client ID และ client secret ผมจะไม่ลงรายละเอียดในวิดีโอนี้ คุณจะพบสิ่งนี้ในวิดีโอสอนเทคนิค get API credentials from WhatsApp และเมื่อคุณทำเสร็จแล้วมันควรจะมีลักษณะแบบนี้ แล้วเรากลับไปได้

ตอนนี้เราจะไปที่อันถัดไป ตรงนี้ในโมดูลนี้เราไม่ต้องทำอะไร ไปที่ WhatsApp Download Audio ตรงนี้เรามีอีกอัน ตรงนี้ถ้าคุณคลิก create a new คุณจะเห็นว่าต้องใช้การเข้าถึงรูปแบบอื่นและบัญชีธุรกิจ Account ID และคุณจะพบสิ่งนี้ในวิดีโอ get API credential from WhatsApp เช่นกัน คุณแค่กรอกตรงนี้แล้วคลิก save ตอนนี้ผมจะกลับไปตรงนั้น เพราะผมเชื่อมต่อไว้แล้ว และตรงนี้ผมจะวาง access token ใหม่ของผมอีกครั้ง ตอนนี้กลับไปได้แล้ว

ต่อไปคือ HTTP request นี่คือสิ่งที่ดาวน์โหลดข้อความเสียง เมื่อผมส่งเสียง และตรงนี้สิ่งเดียวที่ต้องเปลี่ยนคือคุณต้องใส่ access token ซึ่งคุณได้จาก developer.facebook.com ดูวิดีโอนี้แล้วจะเข้าใจชัดขึ้นว่าหาคีย์ได้ที่ไหน แล้วกลับไป นี่คือสิ่งเดียวที่ต้องเพิ่ม ไม่ต้องเปลี่ยนอะไรตรงนี้ ในโมดูล AI ผมไม่ต้องตั้งค่าอะไรตรงนี้ มันมี system prompt ที่ถูกต้องอยู่แล้ว ไม่ต้องเปลี่ยนอะไร

กับ Open AI chat ตรงนี้คุณต้องเชื่อมต่อบัญชี OpenAI ของคุณ และการทำเช่นนี้คุณแค่ต้องมี API key จาก OpenAI และตรงนี้มีวิดีโอสอนเทคนิคที่แสดงวิธีทำ ผมจะเลือกบัญชีที่เชื่อมต่อไว้แล้ว กลับไป ตรงนี้ Window buffer memory เราไม่ต้องทำอะไร กับปฏิทิน คุณต้องเข้าไปในปฏิทินของคุณ ตรงนี้คลิก create a new แล้วคลิก sign in with Google คุณต้องลงชื่อเข้าด้วยบัญชี Google ที่มีปฏิทินที่คุณต้องการใช้สำหรับการจองนัดหมาย ผมมีอยู่แล้ว นี่คือบัญชี Google ที่ผมต้องการใช้ และเมื่อทำเสร็จแล้วปฏิทินของบัญชี Google นี้จะปรากฏในรายการ และนั่นคือทั้งหมดที่ต้องทำ แค่เชื่อมต่อตรงนี้ แล้วเข้าไปในปฏิทินอีกอันหนึ่ง ตรวจสอบให้แน่ใจว่าเลือกอันที่ถูกต้อง แล้วกลับไป และอีกอันหนึ่ง โอเค แล้วกลับไป แค่นั้นสำหรับส่วนปฏิทิน

ต่อไปเรามาดูอันนี้ก่อน นี่คือบัญชี OpenAI อีกครั้ง คุณเชื่อมต่อไว้แล้ว คุณก็แค่เลือกบัญชีที่ถูกต้อง แล้วลูกศรก็หายไป แล้วเราไปที่ WhatsApp response เราจะทำแบบเดียวกัน คุณแค่เลือกบัญชีที่เพิ่งเชื่อมต่อ แล้วมันก็จะทำงาน

ต่อไปคือ Google Sheets สำหรับ Google Sheets นี่คือที่ที่จัดการบทสนทนาหรือนัดหมาย คุณจะมีรายการข้อมูลติดต่อ มันเหมือนฐานข้อมูลที่เกิดการจอง และก่อนอื่นแค่ตั้งชื่อตรงนี้ ผมอยากใส่ชื่อไว้ด้านบน ตั้งว่า setup demo และก่อนใช้งานคุณต้องคลิก authorize ตรงนี้ แล้วคลิก OK แล้วทำตามขั้นตอนเพื่อให้สิทธิ์ตามที่ต้องการ ตรงนี้คลิก advanced ตรงนี้ต้องเลือกลิงก์ด้านล่าง และตรงนี้ต้องเลื่อนลงไปด้านล่างอีกครั้งแล้วคลิก allow เพราะ Google Sheet นี้มีสคริปต์ ซึ่งผมจะแสดงให้ดูในภายหลัง ที่ทำงานบางอย่างให้คุณซึ่งสำคัญสำหรับ AI agent ของเราในการจองนัดหมาย จากนั้นคลิก install และเมื่อเสร็จแล้ว Google Sheet นี้ก็พร้อมใช้ใน workflow ของ AI agent

ตรงนี้ผมไปที่โมดูล Google Sheets มันสำคัญ ผมคลิก create a new credential ถ้าคุณยังไม่ได้เชื่อมต่อ Google Sheets กับ n8n แล้วลงชื่อเข้าด้วยบัญชีเดียวกับที่มี Google Sheet นี้ คือบัญชี Google เดียวกัน และเมื่อทำเสร็จแล้ว Google Sheet ควรจะปรากฏตรงนี้ อย่างที่เห็น setup demo ปรากฏตรงนี้ แล้วเราก็มี appointments และตรงนี้เราต้องเพิ่ม data location บนชีต มันควรอ่านจนถึงแถวว่างแรก จากนั้นเราเชื่อมต่อโมดูลถัดไป ซึ่งมีหน้าที่เพิ่มแถว ตรงนี้แค่เลือกอันนี้ให้แน่ใจว่าถูกชีต แต่มีเพียงชีตเดียว เราไม่ต้องเปลี่ยนอะไร อันนี้คงไว้อย่างเดิม Google Sheets update เลือกชีตที่ถูกต้อง ตรงนี้อาจเกิดกรณีที่มันแสดง และผมแค่คลิก reload แล้วอย่างอื่นตรงนี้ก็ดีอยู่แล้ว ผมไม่ต้องการอันนี้ เพอร์เฟกต์

และชิ้นส่วนสุดท้ายของ workflow นี้คือบัญชี Gmail นี่คือที่ส่งอีเมลเตือนความจำ ตรงนี้คุณแค่คลิกที่มัน คลิก create new credentials ลงชื่อเข้าด้วยบัญชี Gmail ใดก็ได้ที่คุณมีและต้องการให้ส่งการแจ้งเตือนจากบัญชีนั้นไปยังทุกคนที่จองนัดหมายกับคุณ และผมจะเลือกอันนี้ที่มีอยู่แล้ว สิ่งเดียวที่ต้องเปลี่ยนคือคุณใส่ที่อยู่อีเมลที่คุณต้องการรับการยืนยัน ผมจะพิมพ์อีเมลหนึ่งที่อยู่ที่จะรับการยืนยันการจองทั้งหมดที่คนอื่นทำ ดังนั้นเมื่อมีคนจองนัดหมายกับคุณ พวกเขาจะได้รับอีเมลพร้อมรายละเอียดการจอง และคุณจะได้รับสำเนาอีเมลนั้น นั่นคือวิธีการทำงาน

workflow แรกนี้ควรจะทำงานได้แล้วเมื่อตั้งค่าเสร็จ แต่เรามาตรวจสอบให้แน่ใจก่อนโดยการทดสอบ คลิก save แล้วเราจะตั้งค่าส่วนบนในขั้นตอนถัดไป นี่คือ workflow เตือนความจำ ที่ส่งการเตือนให้ทุกคนที่จองนัดหมายมาร่วมนัด และส่งการแจ้งเตือนผ่าน WhatsApp แต่ก่อนอื่นเราจะทดสอบ workflow การจองนัดหมายเพื่อดูว่ามันทำงานไหม ในการทำเช่นนี้คุณต้องเข้าไปที่บัญชี developer.facebook ก่อน ซึ่งเราตั้งค่าไว้แล้วเมื่อคุณดูวิดีโอ get API credential from WhatsApp API และเมื่อทำเสร็จแล้วคุณไปที่ API setup แล้วเลือก recipient phone number จากนั้นคลิก send message แล้วคุณควรได้รับข้อความตรงนี้ ขอลองอีกครั้งเพราะผมอยากได้แชทว่าง ๆ ตอนนี้ลองอีกครั้ง เมื่อคุณได้รับข้อความนี้แปลว่า API เชื่อมต่อแล้ว และตอนนี้ผมสามารถเริ่มทดสอบ AI agent ของผมได้

ผมเห็นว่าคุณต้องเชื่อมต่อ WhatsApp reminder นี้ตรงนี้กับ WhatsApp ที่ถูกต้องก่อน คุณอาจเจอ error แล้วจึงรันการทดสอบได้ ในการทดสอบ ตอนนี้ผมแค่พิมพ์ แล้วมันควรจะพาผมผ่านกระบวนการ และตรงนี้ผมเห็นทุกอย่างที่มันทำ คุณต้องการจองนัดหมายไหม และก่อนที่ผมจะพิมพ์ข้อความใหม่ ผมต้องคลิก test workflow อีกครั้ง ผมบอกว่าผมต้องการจองนัดหมาย กรุณาให้ที่อยู่อีเมลของผมด้วย ตรงนี้ผมก็ใส่อีเมล ตรงนี้ผมจะคลิก test ตลอดเพราะอยากเห็นว่ามันเดินผ่านขั้นตอนอย่างไรและลูกศรอยู่ตรงไหน กรุณาให้ชื่อเต็มของคุณ Trias Miller แล้วมันจะบันทึกข้อมูลทั้งหมดลงใน Google ของผมอย่างที่เห็น กรุณาให้เบอร์โทรศัพท์ พิมพ์อะไรก็ได้ มันหยุดไปนะ เทสต์อีกครั้ง มันรับเบอร์โทรศัพท์ได้ กรุณาให้สถานที่และเขตเวลาของคุณ ผมพิมพ์อะไรก็ได้ ในกรณีนี้ผมจะพิมพ์ New York City พิมพ์อีกครั้ง คุณอยากคุยเรื่องอะไร? วิธีเริ่มช่อง YouTube

ตอนนี้มันตรวจสอบปฏิทินของผมแล้วหาช่วงเวลาว่างให้ ในกรณีนี้มันค้นหาวันพุธ ล่วงหน้าสองวัน คุณสามารถเปลี่ยนได้ใน system instructions: ว่าอยากให้คนจองล่วงหน้าได้กี่วัน แล้วมันจะหาช่วงเวลาว่างที่แปลงเป็นเขตเวลาของคุณ ผมอยู่ในเขตเวลาเยอรมัน ปฏิทินผมเป็นเขตเวลาเยอรมัน แต่คนที่จองมาจากนิวยอร์ก เขาจะเห็นช่วงเวลาว่างทั้งหมดในเขตเวลาของเขา แล้วก็จองได้ ถ้าผมต้องการเวลานี้ ผมจะเปลี่ยนให้คุณดู ผมจะบอกในอีกสักครู่ว่าคุณปรับเขตเวลาได้อย่างไร มาดูกันว่าเกิดอะไรขึ้นเมื่อมันจอง มันเป็นวันพุธ 13:00 และตรงนี้คุณเห็นว่า 13:00 นั่นคือ 6 ชั่วโมงก่อนหน้านั้น มันคือ 19:00 ตามเวลาของผม ดังนั้น 13:00 ตามเวลานิวยอร์ก เมื่อแปลงเป็นเวลาเยอรมันก็เป็น 19:00 คุณเห็นว่ามันถูกต้อง ผมบอกว่าผมต้องการจองเวลา 13:00 ตามเวลานิวยอร์ก และมันจองได้ถูกต้องที่ 19:00 ตามเวลาเยอรมัน และโดยปกติมันจะส่งการยืนยันด้วย เมื่อผมเข้าไปในปฏิทิน ผมเห็นว่ามีการจองใหม่วันพุธ 13:00 มันแสดงในเขตเวลาของคนนั้น คือเขตเวลานิวยอร์ก เพราะนั่นคืออีเมลของคนที่จองนัดหมาย มันสมเหตุสมผลที่จะแสดงในเขตเวลาของพวกเขาเพื่อไม่ให้สับสน คุณ Dear Andreas การจองของคุณได้รับการยืนยันสำหรับวันพุธเวลา 13:00 เราจะพูดคุยเกี่ยวกับวิธีเริ่มช่อง YouTube และอื่น ๆ มันทำงานได้ นี่คืออีเมลที่ส่ง และมันถูกส่งไปยังคนที่จองนัดหมายด้วย

และเมื่อผมเข้าไปใน Google Sheets ตอนนี้มันกรอกอีเมลซ้ำ แต่ไม่เป็นไร ผมแค่ลบมันได้ หรือมันจะจัดการเองในครั้งหน้า ตรงนี้ผมมีวันที่และข้อมูลติดต่อทั้งหมดที่ต้องการ ใช่ไหม และบางอย่างก็ถูกกำหนดเวลาไว้แล้ว แต่นี่คือสิ่งที่เราจะทำต่อไป เราต้องตั้งค่าอะไรใหม่ แต่ก่อนอื่นผมอยากบอกคุณก่อน: คุณเปลี่ยนการตั้งค่าเขตเวลาได้ที่ไหน? มันง่ายมาก คุณต้องเข้าไปใน system instructions ก่อน ผมระบุเขตเวลาของผมไว้ตรงนี้ ลองไปที่ German และมันจะใช้เขตเวลาท้องถิ่นของผู้ช่วย เขตเวลาเยอรมัน และตรงนี้คุณแค่ใส่เขตเวลาของคุณ ไม่ว่าคุณอยู่ที่ไหน ใส่ตรงนี้ และแทนที่ทุกที่ที่ผมเขียนว่า German ด้วยเขตเวลาของคุณเอง และเมื่อทำเสร็จแล้วคุณกลับไป และยังมีอีกจุดหนึ่งที่ต้องเปลี่ยนคือใน add row ไม่ใช่ add row มันคือ updates ตรงนี้เราก็มี คุณเห็น German วันที่นัดหมายควรถูกแปลงเป็นเขตเวลาเยอรมัน เพื่อให้บันทึกแบบนั้น ตรงนี้สำหรับผมมันอ่านง่ายกว่า ผมเห็นนัดหมาย มันถูกจองเวลา 19:00 ตามเวลาของผม ดี และตรงนั้นเรามีเบอร์โทรศัพท์ โอเค แค่นั้นที่เราต้องการ ตอนนี้มาตรวจสอบที่อยู่อีเมลเมื่อส่งอีเมล ตอนนี้มันทำงานแล้ว ดี นั่นคือจุดที่คุณปรับเปลี่ยน ตรงนี้คุณก็ใส่เขตเวลาของคุณแทนที่จะบอกว่าเขตเวลาเยอรมัน ใส่เขตเวลาตามที่คุณอยู่ และเมื่อทำเสร็จเราคลิก save แล้วเราก็รู้ว่าส่วนที่จองนัดหมายทำงานแล้ว ตอนนี้เราจะจัดการส่วนที่ตั้งการเตือนความจำ
