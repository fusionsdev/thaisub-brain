## บทนำ

วิดีโอนี้พาชมโหนด LLM ทั้งหมดใน n8n — ตั้งแต่โหนด AI ตัวแทนของผู้ให้บริการต่างๆ (Anthropic, Google Gemini, OpenAI) ไปจนถึงโหนดเสริมอย่าง LLM Chain, Information Extractor, Summarizer, Sentiment Analysis, Text Classifier, Text Splitter และ Embeddings พร้อมคำแนะนำว่าควรใช้ตัวไหนกับงานแบบไหน

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่อีกหนึ่งวิดีโอครับ ในบทเรียนนี้ผมจะอธิบายโหนด LLM ที่เหลือทั้งหมด ในบทเรียนก่อนหน้านี้เราได้สร้าง AI แบบพื้นฐานมากๆ ขึ้นมาหนึ่งตัว และผมได้โชว์ให้เห็นว่า AI agent ทำงานยังไงใน n8n แต่ตอนนี้ผมจะโชว์โหนดอื่นๆ ที่เหลือทั้งหมดให้ดู และทั้งหมดนี้ก็คือโมเดลของ OpenAI เป็นหลัก ครับ — พวกมันคือ AI agent ที่คุณให้ข้อมูลได้ คุยกับมันได้ อะไรแบบนั้น

แต่โหนด LLM จะต่างกันเล็กน้อย คุณจะเห็นว่าตรงนี้มีแค่ trigger เข้ามา เพื่อให้ฉันเรียกใช้แอปอื่นๆ ได้ แต่ภายในโหนด AI คุณมี AI อยู่ตรงกลาง แล้วข้างใต้ก็จะมี LLM หลากหลายตัวให้เลือก ตัวอย่างเช่น Anthropic — นี่คือทุกอย่างที่คุณทำได้กับมัน: คุณทำ message generate (สร้างข้อความ) ได้ วิเคราะห์รูปภาพได้ มีการวิเคราะห์ไฟล์และเอกสารต่างๆ แต่มันก็คือ AI agent นั่นแหละ พวกมันเป็น AI agent แต่ถูกสร้างสำเร็จรูปมาแล้ว พร้อมความสามารถติดตั้งมาให้ นั่นคือทั้งหมด

เช่นเดียวกันกับ Google Gemini — ตรงนี้คุณวิเคราะห์เสียงได้ ถอดความเอกสาร รูปภาพได้ โดยสรุป คุณสามารถเข้าถึงโมเดล AI ทุกตัว แล้วเชื่อมต่อพวกมันทั้งหมดเข้าด้วยกัน ยกตัวอย่างเช่น สมมติว่าคุณมีข้อมูลที่กำลังประมวลผลอยู่ แล้วอยากให้ AI node หลายๆ ตัวช่วยกันวิเคราะห์ — คุณเข้ามาตรงนี้ แล้วใส่ข้อมูลให้ OpenAI หนึ่งตัว และสมมติว่าผมอยากให้ Claude ด้วย ผมก็แค่เข้ามาตรงนี้ แล้วสร้างข้อความแบบนั้น คุณทำได้หลายอย่าง ง่ายๆ ครับ

และภายในแต่ละโหนดมันก็เหมือนกัน คุณก็แค่เลือกโมเดล อย่างที่ผมพูดถึงในบทเรียน AI agent คุณแค่เลือกโมเดล ดูราคาของการใช้งาน token — เดี๋ยวคุณจะใช้จนหมดไวมาก มีทรัพยากรต่างๆ ที่คุณส่งให้มันได้ เช่น วิดีโอ ส่งไฟล์ไบนารี วิดีโอ รูปภาพ ค้นหาไฟล์ มันขึ้นอยู่กับว่าเครื่องมือที่คุณใช้รองรับอะไร

สำหรับผม ผมชอบใช้ Gemini — คุณใช้ Gemini ทำ Google Deep Research ได้ แต่ผมหันไปใช้ Perplexity สำหรับงานนั้นแทน คุณใช้ Gemini วิเคราะห์รูปภาพและวิดีโอได้เยอะมาก มันมีตัววิเคราะห์รูปภาพและวิดีโอที่ดีที่สุดเท่าที่ผมเคยเห็นมา ส่วน OpenAI ใช้กับงานพื้นฐานทั่วไป ที่ไม่ต้องคิดเยอะ ส่วน Claude ผมใช้กับงานที่ต้องคิดลึกๆ อะไรแบบนั้น แต่โดยพื้นฐานคุณเพิ่มโมเดลอะไรก็ได้

และโมเดลที่คุณไม่เห็นในลิสต์ — คุณเห็น Gemini แล้ว แต่ไม่เห็นตัวอื่นอีก — จริงๆ แล้วคุณสามารถไปที่ Ollama ได้ และมันเข้าถึงได้ — ผมยังไม่ได้ตั้งค่า credentials ผมไม่เคยใช้ฟังก์ชันนี้ ผมใช้ Claude Code แล้วเชื่อมต่อกับทุกอย่างแทน แต่คุณสามารถใช้ Ollama ได้ และมันเข้าถึงโมเดล AI ทุกตัวบนโลกใบนี้ แล้วคุณก็จัดการทุกอย่างให้เป็นระบบเดียวกันได้ นั่นคือเรื่องของโหนดพวกนั้น

แล้วก็ยังมีอีกหลายโหนดที่คุณทำอย่างเช่น basic LLM chains (ห่วงโซ่ LLM พื้นฐาน) — นี่ก็คือ chain ง่ายๆ สำหรับส่ง prompt ไปยัง large language model มันง่ายมากๆ ผมก็ไม่รู้ว่ามันต่างจากตัวอื่นตรงไหนจริงๆ พูดตรงๆ เลย มันมี chat trigger node ที่ให้คุณคุยกับมันได้ และเพิ่ม system prompts (คำสั่งระบบ) ได้ อะไรแบบนั้น พวกนี้คล้ายๆ กัน แต่โดยรวมมันคือ basic LLM chain

Information extractor (ตัวดึงข้อมูล) — อันนี้เอาไว้ดึงข้อมูลภายในข้อความที่กำหนด ถ้าคุณป้อนบทความข่าวเข้าไป แล้ว prompt ว่า "ช่วยดึงประเด็นสำคัญออกมา" มันก็จะดึงข้อมูลออกมาให้ เช่นเดียวกับ Summarizer — น่าจะมี Summarizer chain อยู่ตรงนี้ อันนี้จะแปลงข้อความเป็นสรุปที่กระชับ มันจะสรุปบทความข่าวให้คุณ

Sentiment analysis (การวิเคราะห์ความรู้สึก) เจ๋งดี — มันจะวิเคราะห์ข้อความ แล้วตัดสินว่าข้อความนั้นมีนัยเชิงบวกหรือเชิงลบ เช่น ถ้า trigger เป็นรีวิวใหม่ที่คุณได้รับบน Google site ของคุณ หรือ Google My Business มันจะบอกว่าเป็นกลางหรือเชิงลบ แล้วถ้าเป็นเชิงลบ มันก็จะตอบกลับอัตโนมัติแบบ "เสียใจที่ได้ยินแบบนั้น" หรือถ้าเป็นบวกก็ส่ง "ขอบคุณ" อะไรประมาณนั้น

แล้วมีอะไรอีก? Text classifier (ตัวจำแนกข้อความ) — มันจะจำแนกข้อความของคุณเป็นหมวดหมู่ต่างๆ มันจะอ่านข้อความ แล้วคุณก็สามารถจัดมันลงในหลายหมวดหมู่ได้ ง่ายมาก ผมไม่ค่อยได้ใช้โหนดพวกนี้เท่าไหร่ จริงๆ ผมแทบไม่ได้ใช้โหนดพวกนี้เลยด้วยซ้ำ Evaluation — รันการประเมินผลกับอะไรก็ตาม... ผมเองก็ไม่รู้ว่ามันคืออะไร ไม่เคยใช้มันมาก่อน เนื้อหาพวกนี้เยอะแยะไปหมด แต่สรุปคือคุณคงไม่ได้ใช้มันจริงๆ

แล้วก็ยังมีโหนด AI อื่นๆ อีก เช่น memory node ที่เราพูดถึงในบทเรียนที่แล้ว — มันคือการเพิ่มความจำให้กับ AI agent ใดๆ คุณมี language node ซึ่งก็คือ structured output (ผลลัพธ์แบบมีโครงสร้าง) Text splitter — เอาข้อความก้อนใหญ่ๆ มาหั่นเป็นชิ้นเล็กๆ หลายชิ้น เช่นเดียวกับ token splitter แล้วคุณก็กำหนดด้วยจำนวน token ได้ ทำเป็นจำนวนอักขระก็ได้ อะไรแบบนั้น

Embeddings — ผมจะลงรายละเอียดเพิ่มเติมในบทเรียนเรื่อง vector storage แต่โดยสรุปมันคือการแปลงข้อความเป็นเวกเตอร์ (embed) และผมจะพูดถึงเรื่อง vector ในบทเรียนถัดไป ซึ่งสำคัญมากจริงๆ ครับ

เอาล่ะ นั่นคือทั้งหมดของโหนด AI ครับ ด้วยการมาถึงของ Claude คุณไม่ค่อยต้องใช้โหนดพวกนี้เท่าไหร่ แทบจะไม่ได้ใช้เลยด้วยซ้ำ แต่มันเป็นความรู้ที่ดีที่ควรรู้ไว้ นี่คือทั้งหมดของวิดีโอนี้ แล้วเจอกันในบทเรียนถัดไปครับ
