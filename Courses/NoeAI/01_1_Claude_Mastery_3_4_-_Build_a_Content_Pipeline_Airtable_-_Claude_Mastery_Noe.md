## บทนำ

บทเรียนนี้โชว์วิธีใช้ Claude สร้าง content pipeline (ระบบจัดการคอนเทนต์) บน Airtable แบบเรียลไทม์ — ตั้งแต่เชื่อมต่อ Airtable ผ่าน connector, ให้ Claude ออกแบบตารางให้อัตโนมัติ จนถึงการตั้ง Kanban board และสั่งให้ Claude ย้ายงานข้ามสถานะได้ด้วยภาษาเดียวกับที่คุยกับคน ผู้สอนเน้นย้ำว่าการให้ Claude ถามคำถามก่อนลงมือสร้างจะได้ผลลัพธ์ที่ตรงความต้องการมากที่สุด

## คำแปลเต็ม

ว่าไงครับทุกคน วันนี้เราจะมาสร้าง content pipeline กัน โดยใช้ Claude นะครับ pipeline นี้จะจัดการคอนเทนต์แบบสั้น แบบยาว หรืออะไรก็แล้วแต่ที่คุณมี เช่นของผมเองก็มี carousel มีคอนเทนต์ทั้งหมด อยู่ในที่เดียว ที่สามารถลากวางและจัดการได้ เฉพาะธุรกิจของผม ซึ่งวิธีนี้ใช้ได้กับทุกอย่างครับ และผมใช้มันผ่านซอฟต์แวร์ชื่อ Airtable คุณแค่เสิร์ชหา Airtable ในอินเทอร์เน็ตได้เลย ผมชอบ Airtable เพราะมันปรับแต่งได้เยอะมาก และเชื่อมต่อเข้ากับ Claude ได้โดยตรง และใช้งานง่ายมาก

ดังนั้นผมจะโชว์ให้ดูว่า ผมจะสร้าง content pipeline แบบสดๆ ตอนนี้เลย ด้วย Airtable ไปลุยกันเลยครับ อย่างแรกก่อนที่เราจะเข้าไป คุณก็ต้องสมัคร Airtable ก่อน สิ่งที่จะเกิดขึ้นคือ คุณจะเข้ามาอยู่ในหน้านี้ และถ้าคุณเป็นบัญชีใหม่ก็ยังไม่มีอะไรตั้งค่าไว้ สิ่งที่ผมอยากให้ทำคือ สร้าง base ขึ้นมา แค่คลิก แล้วก็คลิก build your own แล้วมันจะพาคุณเข้าไป จุดสำคัญคือ เรามีสิ่งที่เรียกว่า base อยู่ แล้วถ้าอยากได้ เราก็เลือก start from scratch ได้เลย ตั้งชื่อว่าอะไรก็ได้ ผมจะลบอันนี้ทิ้ง เพื่อความเป็นระเบียบ เพราะผมชอบความเรียบร้อย แล้วเราจะก็อปปี้ base นี้ไว้ เพื่อให้มีไว้ใช้ แล้วเราจะเข้าไปที่ Claude

รอบนี้เราจะไม่ทำเป็นโปรเจกต์นะครับ ถ้าคุณอยากสร้างในโปรเจกต์ก็ได้ ถ้าคุณมีโปรเจกต์ที่เทรนด้วยข้อมูลธุรกิจของคุณแล้ว และอยากทำในนั้น ก็ทำได้เลย ไม่มีปัญหา แต่เพื่อบทเรียนนี้ เราจะทำในโหมดแชท เพราะผมอยากโชว์ให้เห็นว่าเราใช้ Claude ในรูปแบบต่างๆ ได้ยังไง ซึ่งการทำในโปรเจกต์ที่เทรนด้วยธุรกิจคุณจะให้ผลลัพธ์ดีกว่าแน่นอน แต่ไม่เป็นไร เราจะสร้างของบางอย่างในวันนี้เท่านั้น

สิ่งที่อยากให้คุณทำต่อคือ เข้าไปที่ customize แล้วไปที่ connect your apps ตรงนี้หรือตรงนี้ก็ได้ แล้วผมจะเลือก Airtable ผมเสิร์ชหา Airtable แล้วก็กด connect เหมือนกับแอปอื่นๆ มันจะทำ OAuth ให้คุณเชื่อมต่อ เมื่อเชื่อมต่อแล้ว คุณจะเห็นปุ่ม disconnect ได้ สิ่งที่เจ๋งมากเกี่ยวกับ Airtable คือ คุณสร้าง base ได้หลายอัน แล้ว Claude ก็ทำงานภายใน CRM ที่ปรับแต่งได้เองทั้งหมด มันดึง lead ให้คุณได้ สร้าง content pipeline ให้คุณได้ และทำอะไรได้อีกเยอะ ซึ่งเดี๋ยวเราจะได้เห็นกัน

พอเชื่อมต่อ Airtable แล้ว เราก็แค่พรอมป์ต์ให้ Claude สร้าง content pipeline ที่ใช้ติดตามคอนเทนต์แบบสั้นทั้งหมดบน Instagram ของผม ข้อมูลที่เราจะมีก็คือสคริปต์ แค่นั้น เราจะเรียกมันแบบนั้น แล้วบอกให้มันสร้างในตารางนี้ แล้วก็ถามอะไรก็ได้ที่อยากรู้ ผมมักจะบอกให้มันถามเสมอ เพราะผมไม่อยากให้มันไปสร้างอะไรตามใจ ตัวอย่างเช่น ถ้าผมให้คำสั่งเฉพาะเจาะจงแบบนี้ มันจะลงมือทำเลยโดยไม่ถามอะไร แต่ถ้าผมบอกให้มันถามคำถามที่อยากรู้ก่อน มันจะได้ความชัดเจนในทุกอย่างที่มันอยากรู้ก่อนลงมือ ซึ่งสำคัญมาก

เราปล่อยให้มันทำงานสักครู่ แล้วมันจะตอบว่า "ฉันจะช่วยคุณสร้าง content pipeline ก่อนสร้าง ขอถามสองสามคำถาม" เรื่องฟอร์แมตก็เป็น single select เราก็ตอบว่าใช่ แล้วส่วนตัวเลข ให้เป็น free form ส่วนวันที่ก็เลือกแบบทั่วไป แล้วก็มีอะไรเพิ่มเติมไหม ก็เพิ่ม status ใส่สถานะลงใน pipeline stage ตั้งแต่ idea แล้วก็ Posted โอเค เราก็ตอบคำถามของมันไปเรื่อยๆ นี่คือเหตุผลที่เราบอกให้มันถามไงครับ

พอเราวางแผนก่อนลงมือสร้าง และให้มันเข้าโหมดวางแผนเชิงลึกก่อนสร้าง ขอให้แน่ใจว่า Claude วางแผนทุกอย่างละเอียดครบถ้วน นี่คือสาเหตุที่ผมให้มันถามคำถามเสมอ เพราะมันสร้างของให้สมบูรณ์แบบในครั้งเดียวได้ ถ้าคุณให้คำสั่งเยอะพอ แล้วดูนี่สิ ตอนนี้มันกำลังสร้างใน Airtable ให้เรา มันเพิ่มคอลัมน์อยู่เรื่อยๆ คอลัมน์เหล่านี้ไม่ได้มีอยู่ก่อนหน้านี้นะครับ แล้วคุณจะเห็น มันถามว่าเราอยากใช้ตารางแบบนี้ไหม ซึ่งก็โอเค เมื่อมันถามเรา มันแค่ขออนุญาตทำงาน มันไม่ลงมือทำโดยไม่ได้รับอนุญาตจากเรา ซึ่งเป็นเรื่องดี ระบบไม่ได้พัง แสดงว่ามันทำงานถูกต้อง

มันกำลังอัปเดตฟิลด์อยู่ เห็นไหมว่ามันเพิ่ม status เข้ามาแล้ว เพิ่ม Posted เข้ามาแล้ว ขณะที่มันทำงาน ผมจะลองลบดู คุณจะลบตารางหรือแถวไม่ได้ ซึ่งเป็นสิ่งที่ดี เพราะมันเข้ามาลบอะไรตามอำเภอใจไม่ได้ แต่เราจะปล่อยให้มันทำงานแล้วดูว่ามีอะไรเพิ่มเติมไหม แล้วมันก็เสร็จ ผมจะลบแถวพิเศษที่มาจากค่าเริ่มต้นออก แล้วเสร็จแล้ว ระบบ content pipeline ของคุณสร้างเสร็จเรียบร้อย มันบอกว่า "มีหมายเหตุ: status เริ่มต้นมีค่า default ผมลบผ่าน API ได้" แล้วถามว่าอยากได้ตัวอย่าง record ไหม ใช่เลย

ดูนี่สิ มันทำเสร็จแล้ว มันเขียนฟอร์แมตวันที่ให้แล้ว มีฟอร์แมตของตัวสคริปต์ และสถานะ ผมจะลากมันมาตรงนี้ แล้วสถานะเราก็มี Posted ซึ่งเจ๋งมาก และมันกำลังสร้าง record ในตารางให้เรา เห็นไหมว่ามันแทรก record เข้ามาให้แล้ว มันสร้างวิดีโอที่ชื่อว่า "How I Use Claude Code to Build a Client Automation in 20 Minutes" แล้วเราก็ได้สถานะ ว่ามันเป็นฟอร์แมตแบบไหน และสคริปต์ของวิดีโอจริงๆ นี่คือวิธีที่ Claude สร้าง content pipeline ให้คุณ

อยากไปอีกขั้น เพื่อโชว์ว่า Airtable ทำงานยังไง และผมตั้ง Kanban board ยังไง เพื่อให้ได้ผลลัพธ์แบบที่เห็น ผมจะสร้าง dummy rows เพิ่มอีกสามแถว เพื่อให้มีข้อมูลมากขึ้น แค่คลิก create new ใต้ตาราง content pipeline แล้วเลือก Kanban view ตั้งชื่อว่า content ก็ได้ Kanban ก็คือบอร์ดแบบที่ลากวางได้ ซึ่งเจ๋งมาก และ Airtable มีมุมมองให้เลือกเยอะแยะ ผมอยากจัดเรียงตาม status เพราะเราอยากติดตามตามสถานะ ดูนี่สิ มันเพิ่มมา 4 แถว โดยแต่ละแถวอยู่ในสถานะที่ต่างกัน ผมเข้ามาเปลี่ยนและย้ายมันได้ ตอนนี้คุณมี pipeline ที่ทำงานได้เต็มรูปแบบแล้ว

แล้วสิ่งที่เจ๋งอีกอย่างคือ สมมติเราอยากย้ายงานใน pipeline ด้วย Claude เราแค่บอกว่า "ย้ายทุกอย่างไปเป็นสถานะ posted" แล้วเราจะดูมันทำแบบสดๆ แบบเรียลไทม์ ผมว่ามันโคตรเจ๋ง มันเหมือนผู้ช่วยส่วนตัวที่ทำงานแทนเรา แล้วมันก็ทำได้จริง มันย้ายงานข้ามตารางให้เรา นี่คือวิธีใช้ Claude สร้าง content pipeline ของคุณเอง

หวังว่าทุกคนสนุกกับวิดีโอนี้ ถ้าคุณสร้างตามแล้ว ชอบ ก็เข้าไปในคอมมูนิตี้แล้วแชร์ชัยชนะของคุณ เข้าไปประกาศว่า "เพิ่งสร้าง content pipeline ด้วย Claude" มันเจ๋งมาก ผมอยากเห็นสิ่งที่คุณสร้าง ขอให้เอาไปลองทำ แล้วบอกผมด้วยว่าผลเป็นยังไง เท่านี้แหละครับ เจอกันวิดีโอหน้า
