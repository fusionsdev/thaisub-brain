## บทนำ
วิดีโอสอนวิธีเชื่อมต่อ OpenAI API กับระบบ เริ่มจากการเพิ่มการเชื่อมต่อ สร้างบัญชี เติมเครดิตขั้นต่ำ 5 ดอลลาร์ สร้าง Secret Key และคัดลอก Organization ID เพื่อให้การเชื่อมต่อสำเร็จ

## คำแปลเต็ม

ถ้าคุณยังไม่มีการเชื่อมต่อ ให้คลิก add (เพิ่ม) แล้วไปที่บัญชีของคุณ หรือคุณจะสร้างบัญชีใหม่ สมัครบัญชีฟรีก็ได้ จากนั้นไปที่ billing (การเรียกเก็บเงิน) คุณต้องเติมเครดิตอย่างน้อย 5 ดอลลาร์ แต่อย่างที่ผมบอกในวิดีโอ การใช้งาน OpenAI ต้นทุนแค่ประมาณ 3 เซนต์เท่านั้น มันถูกมาก ต่อไปให้คลิกสร้าง Secret Key ใหม่ จะตั้งชื่ออะไรก็ได้ จากนั้นสร้าง แล้วคัดลอกและวางลงไป จากนั้นคุณต้องเอา Organization ID ของคุณ หาได้ที่ settings (การตั้งค่า) ไปที่เมนูนั้น มันอยู่ตรงนั้นแล้ว Organization ID คัดลอกวางลงไป แล้วคลิก save (บันทึก) เสร็จแล้วการเชื่อมต่อก็จะถูกสร้างขึ้น
