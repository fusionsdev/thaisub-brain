## บทนำ
วิดีโอนี้สอนวิธีเปลี่ยนโมดูล Twitter ในระบบอัตโนมัติที่เลิกสนับสนุนแล้ว ด้วยโซลูชันที่ใช้บริการ UploadPost.com โดยนำเข้าเวิร์กโฟลว์ตัวอย่าง คัดลอกโมดูลเดียวที่จำเป็นไปแทนที่โมดูล Twitter เดิม ตั้งค่าบัญชี UploadPost.com เชื่อมต่อกับบัญชี X ใส่ API key และแมปฟิลด์ต่าง ๆ เพื่อให้เผยแพร่ขึ้น Twitter ได้อัตโนมัติอีกครั้ง

## คำแปลเต็ม

ในวิดีโอนี้ผมจะแสดงวิธีเปลี่ยนโมดูล Twitter ที่ไม่ได้รับการสนับสนุนจาก n8n อีกต่อไป ด้วยโซลูชันที่ใช้งานได้จริงโดยใช้บริการอีกตัวหนึ่ง คุณต้องเปิดระบบอัตโนมัติของคุณที่มีโมดูล Twitter ที่ต้องเปลี่ยน จากนั้นเปิด scenario ใหม่ ไปที่ open new แล้วคลิก create a new scenario เพราะผมได้สร้างโมดูลที่คุณต้องวางหรือใช้แทนในระบบอัตโนมัติของคุณ เพื่อให้คุณสามารถเผยแพร่ขึ้น Twitter ได้

ตอนนี้ตรงนี้ คุณสามารถดาวน์โหลดไฟล์นี้ได้ก่อนจากลิงก์ใต้วิดีโอ จากนั้นไปที่ import คลิก select แล้วเลือกไฟล์นั้นเพื่อนำเข้า คลิก save สิ่งนี้จะให้สตริงนี้มา สิ่งเดียวที่คุณต้องการจริง ๆ คือโมดูลเดียวนี้เท่านั้น ดังนั้นคลิกขวาแล้ว copy จากนั้นตรงนี้คุณก็ลบโมดูล Twitter เหล่านั้นทิ้ง แล้ววางสิ่งที่คุณคัดลอกไว้ ซึ่งเป็นสิ่งเดียวที่เราต้องการ

ตอนนี้เราจะปลดลิงก์สาขาเหล่านี้ เพราะผมไม่ต้องการให้โมเดลอื่น ๆ ถูกทดสอบ นี่เป็นเพียงเวิร์กโฟลว์ตัวอย่าง แต่ไม่ว่าเวิร์กโฟลว์จะเป็นแบบไหน สิ่งเดียวที่คุณต้องเปลี่ยนก็คือสิ่งที่ผมเพิ่งทำไป คัดลอกอันนี้แล้วแทนที่โมดูล Twitter ด้วยโมดูลเดียวนี้

จากนั้นคลิก open ตรงนี้คือบริการที่คุณใช้ มันเรียกว่า UploadPost.com คุณสามารถสมัครบัญชีฟรีได้ที่นี่ ไปที่ลิงก์นี้ซึ่งคุณจะพบได้ใต้วิดีโอนี้เช่นกัน และในแผนฟรีคุณจะได้อัปโหลด 10 ครั้งต่อเดือน และถ้าคุณต้องการมากกว่านั้น คุณต้องอัปเกรดเป็นแผนถัดไปซึ่งมีค่าใช้จ่าย 14 ดอลลาร์ต่อเดือน คุณจะได้ 120 อัปโหลด

เมื่อทำเสร็จแล้ว ขั้นแรกคือไปที่ Manage Users แล้วใส่ชื่อผู้ใช้แบบสุ่มอะไรก็ได้ แล้วคลิก Add User และตอนนี้คุณสามารถเชื่อมต่อผู้ใช้กับบัญชีใดก็ได้ที่คุณต้องการ ในกรณีนี้คุณต้องการเชื่อมต่อกับ X ดังนั้นคุณคลิกเพื่อยืนยันว่าต้องการเชื่อมต่อกับอันนี้ และเมื่อมันเสร็จสิ้นมันจะหน้าตาแบบนี้

ตอนนี้เรากลับมาที่นี่ และเราจะตั้งค่าโมดูลนี้ทีละขั้นตอน สิ่งเดียวที่เราต้องการคือ API key ดังนั้นเรามารับคีย์ตรงนี้กัน คุณสามารถสร้างคีย์ใหม่ได้ ถ้ายังไม่มีคีย์ใหม่ถูกสร้างขึ้น ผมจะลบอันนี้แล้วคุณจะเห็นว่ามันหน้าตาเป็นอย่างไร สร้างคีย์ใหม่ แล้วคีย์ใหม่จะแสดงขึ้นมา คัดลอกมัน กลับมาที่นี่ แล้ววางลงตรงนี้ สิ่งสำคัญคือต้องรักษาส่วนนี้ไว้ นี่คืออันหนึ่ง แล้วนี่คือคำว่า API

ลงมาด้านล่างตรงนี้ นี่คือ title และ value ของไทเทิลนั้น ในระบบของผม มันมาจากโมดูลนี้ตรงนี้ เพราะมันสำคัญที่ไทเทิลจะต้องเป็นข้อความคำบรรยาย (caption text) โดยพื้นฐาน นั่นคือข้อความที่ถูกเผยแพร่ไปพร้อมกับวิดีโอบน Twitter และมันสำคัญที่ข้อความนี้ต้องน้อยกว่า 240 ตัวอักษร ไม่งั้นคุณจะได้รับ error แต่ในระบบส่วนใหญ่ของผม สิ่งนี้ถูกจัดการไว้แล้ว นั่นคือเหตุผลที่ผมมักจะเพิ่มโมดูลพิเศษไว้ก่อนหน้านี้ ซึ่งเป็นโมดูล AI ของ OpenRouter ที่มักจะลดข้อความให้เหลือน้อยกว่า 100 หรือ 200 ตัวอักษร

ต่อไปคือ username ซึ่งเป็นชื่อผู้ใช้จาก UploadPost.com ดังนั้นคุณไปที่ Manage Users แล้วคัดลอกชื่อผู้ใช้ที่เชื่อมต่อกับบัญชี Twitter หรือ X ของคุณ แล้ววางลงตรงนี้ จากนั้นสิ่งที่เหลือให้แมปคือ image URL ซึ่งควรจะเป็นรูปภาพของผมที่อยู่ตรงนี้ แล้วคลิก save

ตอนนี้คลิกที่ปุ่มรัน แล้วผมก็ทดสอบได้เลย คลิก run มันจะส่งการทดสอบรันในระบบอัตโนมัตินี้ และส่งข้อมูลผ่านไปเพื่อดูว่ามันถูกเผยแพร่หรือไม่ และวิดีโอหรือรูปภาพถูกอัปโหลดและเผยแพร่ไปยังบัญชี Twitter ของผมหรือไม่ และมันดูดี

ตอนนี้ผมสามารถเข้าไปดูได้ ผมเห็นว่ามันเรียบร้อยดี จากนั้นผมไปที่ Twitter ของผม รีเฟรช แล้วเห็นว่าพีดถูกเผยแพร่แล้ว ดังนั้นระบบเผยแพร่อัตโนมัตินี้ทำงานแล้ว ผมคลิก save แล้วเชื่อมต่อโมดูลอื่น ๆ กลับมาใหม่ และตอนนี้ผมก็สามารถเผยแพร่ขึ้น Twitter โดยอัตโนมัติด้วยการผสานรวมนี้ได้แล้ว
