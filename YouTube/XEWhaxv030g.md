## ประเด็นหลัก

- Agent Operating System (ระบบปฏิบัติการสำหรับ AI agent) รวม AI agent และระบบที่ดีที่สุดไว้ในที่เดียว เสียบโมเดลใหม่ได้ทันทีที่ปล่อยออกมา และดีขึ้นทุกวันที่ใช้
- ท้ายวิดีโอแจก skill สำหรับสร้าง SEO content แบบอัตโนมัติเต็มรูปแบบที่ติดอันดับจริง
- ตอบคำถาม Barb เรื่อง projects ใน ChatGPT/Claude: โมเดลไม่เคยทำถูกตั้งแต่ครั้งแรก แต่ปกติได้ภายใน 1-2 คำตอบ ควรให้ตอบหลายตัวเลือก แล้วเลือก + ให้ feedback
- เขียน instructions ในโปรเจกต์ให้ละเอียดมาก มีตัวอย่าง มีกฎ (อาจถึง 50 ข้อ) และปรับวนไปเรื่อย ๆ จนได้ผลที่ต้องการ (โปรเจกต์ Claude ของเขาปรับมาประมาณ 30 รอบ)
- งาน scheduled tasks (ตามกำหนดเวลา) ใน agent: แนะนำ Hermes เพราะรันเบื้องหลังได้แม้ปิดคอมพิวเตอร์ ต่างจาก Claude/Codex
- แนะนำให้อดทน เพราะผู้ใช้ยังนำหน้าเจ้าของธุรกิจ 99% แล้ว การเทรนพนักงานใช้เวลา 6 เดือนและน่าหงุดหงิดกว่า AI agent มาก
- ตอบ Waleed: skills เป็นไฟล์ markdown มาตรฐาน ใช้ร่วมกันได้ทุก agent (Claude, Hermes, ChatGPT, Codex) ถ่ายโอนได้หมด
- ตอบ Tim: ใช้ agent operating system ตัวเดียวเท่านั้น (หลายระบบ = จุดเสี่ยงเยอะ); เข้าถึง Windows จาก Mac ได้ด้วย Tailscale, ทางเลือกคือ VPS หรือ Cloudflare tunnels
- คอมเก่าไม่ควรคิดรัน local models แต่ใช้ API/cloud-based ได้ทุกเครื่อง; มีสมาชิกตั้ง VPS กับ Agent OS เพื่อใช้ RAM บนคลาวด์
- โมเดลราคาถูกแนะนำ: Qwen 3.8 บน coding plan หรือ Kimi K3 (open-source ใช้กับ subscription ได้); ทดสอบ GLM 5.2 แล้วไม่แย่ ดูผลได้ที่ GoldyBench
- ตอบ Fabio: ใช้ Antigravity CLI เป็น coding agent สำหรับ Gemini เพราะ Gemini/Claude ยุติการให้ subscription ใช้กับ agent อื่นแล้ว
- ตอบ Vinnie: รักษาคุณภาพ SEO content ด้วยกฎละเอียดหลายชั้นใน skill — ตั้งแต่ keyword, การฟอร์แมต, ชื่อเรื่อง ไปจนถึง meta description

## ความเห็นสรุป

วิดีโอให้คำแนะนำเชิงปฏิบัติที่ใช้ได้จริงสำหรับคนที่เริ่มใช้ AI agents ในการทำงาน โดยเน้นเรื่องการปรับแต่ง project/skill ให้ละเอียดและวนปรับซ้ำ ซึ่งเป็นหัวใจของการได้ผลลัพธ์ดีจาก AI พร้อมทั้งแนะนำเครื่องมือและโมเดลทางเลือกแบบเฉพาะเจาะจง เนื้อหาเป็นสไตล์ Q&A ที่เป็นกันเองและตรงประเด็น เหมาะกับผู้ที่ใช้ Agent OS หรือกำลังจะเริ่มต้น
