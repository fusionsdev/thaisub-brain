## บทนำ

บทเรียนนี้สาธิตการใช้ competitor analysis skill เพื่อวิเคราะห์เนื้อหาของคู่แข่งและเปรียบเทียบกับเนื้อหาของเรา ระบบจะจัดอันดับคู่แข่ง วิเคราะห์ hooks และ top performers รวมถึงสร้างข้อสังเกตเกี่ยวกับรูปแบบและคำแนะนำสำหรับการทำคอนเทนต์ต่อไป

## คำแปลเต็ม

สวัสดีครับทุกคน ยินดีต้อนรับเข้าสู่บทเรียนเรื่อง competitor analysis ในบทเรียนนี้คุณจะเห็นไฟล์หนึ่งไฟล์ ผมจะมอบ competitor analysis skill ให้คุณ เพื่อใช้รวบรวมข้อมูลทั้งหมดที่คุณสร้างไว้ก่อนหน้านี้ ตอนนี้คุณมีฐานข้อมูลขนาดใหญ่มากของคู่แข่งทั้งหมด รวมถึงข้อมูลต่าง ๆ ของพวกเขาแทบทุกอย่างแล้ว

ถึงเวลานำข้อมูลทั้งหมดมารวมกัน เพื่อทำ research หรือทำ competitor analysis จริง ๆ ระบบจะสร้าง brief ที่เปรียบเทียบคอนเทนต์ของคุณกับคอนเทนต์ของคู่แข่งให้ครับ

ขั้นตอนค่อนข้างง่าย แค่ดาวน์โหลดไฟล์แล้วนำไปวาง จากนั้น prompt ให้ระบบตั้งค่าให้ เมื่อพร้อมแล้ว เราก็สั่งให้มันทำงานได้เลย

ผมอยากเปิดดูข้างในสักครู่นะครับ อยากให้เห็นว่า skill นี้มีหน้าตาอย่างไร และคำสั่งจริง ๆ ข้างในเป็นแบบไหน โดยหลักแล้ว skill จะดูคอนเทนต์ของคู่แข่ง วิเคราะห์ข้อมูล และดึง metrics มาคำนวณ outlier scores

จากนั้นมันจะพิจารณาว่า hooks แบบไหนดีที่สุด เปรียบเทียบกับ hooks ของคุณ และจัดทำ brief แบบเต็มให้ครับ

ผลลัพธ์มีส่วน competitor overview ซึ่งจัดอันดับคู่แข่งทั้งหมดตามค่าเฉลี่ยของยอดวิวหรืออัตรา outlier เพื่อให้เทียบกันแบบ side by side

นอกจากนี้ยังมี per competitor top performer โดยแสดง top three hooks และโครงสร้างที่ดีที่สุดของคู่แข่งแต่ละราย

ส่วน competitor versus creator comparison จะค้นหาวิดีโอที่พูดถึงหัวข้อเดียวกันหรือใกล้เคียงกัน แล้วดูว่าทำไมวิดีโอของคุณหรือของคู่แข่งจึงทำผลงานได้ดีกว่า

สุดท้ายคือ patterns and recommendations ซึ่งสรุปรูปแบบที่พบและคำแนะนำสำหรับการทำงานต่อไปครับ

จริง ๆ แล้ววิธีรันมีแค่เลือก competitor analysis แล้วกด Run จากนั้นก็ปล่อยให้ระบบประมวลผลได้เลย เราจะรอให้มันทำงานเสร็จครับ

เสร็จแล้ว ลองดูผลลัพธ์ตรงนี้ ระบบสร้าง full analysis ของคู่แข่งให้เรา ผมใช้ข้อมูลจาก table เก่าของระบบเดิมเพื่อไม่ต้องรอการวิเคราะห์ชุดเต็ม แต่ผลลัพธ์ก็แสดง top 10 competitors พร้อม average views, outlier และข้อมูลอื่น ๆ ของพวกเขา

ระบบยังแสดงช่องว่างที่พบ และดึง top three hooks ของแต่ละคู่แข่งมาให้ดูด้วย อันนี้ดีมากครับ มีข้อมูลของ Brody และ Sabrina รวมถึงข้อมูลของทุกคนในรายการ

Section three คือ competitive versus me เป็นส่วนเปรียบเทียบคู่แข่งกับเรา ตัวอย่างหนึ่งคือหัวข้อเกี่ยวกับ Claude Code setup ระบบจะดูว่าคู่แข่งชนะตรงไหน เช่น ทุกคนกำลังใช้ Claude Code และใช้ split screen

จากนั้นจะนำมาเทียบกับเวอร์ชันของคุณ ซึ่งในตัวอย่างนี้มีข้อความประมาณว่า ผมเพิ่งแทนที่ marketing vertical ทั้งหมด ผลลัพธ์จึงเป็นการเปรียบเทียบหัวข้อที่คู่แข่งพูดถึงกับสิ่งที่คุณพูด และชี้ให้เห็นความแตกต่าง

ในกรณีนี้ ผมคิดว่า Claude มองว่าผมทำได้ดีกว่าคู่แข่ง เพราะผมเพิ่งสร้างหรือแทนที่ marketing บางส่วนทั้งหมด ข้อมูลที่ระบบให้มามีทั้งเหตุผลที่ชนะ ชื่อที่นำไปแชร์ได้ ตำแหน่งสำคัญทางการตลาดที่จำง่าย และ data points อื่น ๆ อีกหลายแบบ

ระบบกำลังทำ comparison ระหว่างแต่ละรายการ และดู hope templates รวมถึงข้อมูลสำคัญอื่น ๆ ทั้งหมด

พูดตามตรง ผมไม่ได้ใช้ skill นี้บ่อยมากแล้ว เพราะตอนนี้ผมเติบโตบน social media ค่อนข้างมาก และรู้สึกว่าการแข่งขันของผมเป็นการแข่งขันกับตัวเองมากกว่า

แต่ถ้าคุณกำลังพยายามเติบโตบน social media ผมแนะนำให้ใช้ skill ที่มอบให้ไป แล้วปรับแต่งให้คุณได้ข้อมูลทุกชิ้น และนำไป cross-stream กับคอนเทนต์ของคุณเอง เพราะมันจะช่วยได้มาก

frameworks ที่ผมให้ไว้ใน skill นี้มีความสำคัญมาก และสิ่งที่ดีของ skills เหล่านี้คือมันปรับแต่งได้ คุณสามารถนำ skill ไปใช้กับตัวเอง ทำให้ดีขึ้น ปรับให้เข้ากับ niche ของคุณ และต่อยอดได้เรื่อย ๆ

การปรับแต่งก็เป็นเพียงการแก้ไขเล็ก ๆ น้อย ๆ เท่านั้น และถ้าคุณเรียนกระบวนการ editing ของผมมาครบแล้ว คุณจะเห็นว่าเวลาผมรันงานจริง ผมมักแก้ไขหน้างานไปด้วย ผมพูดเรื่องนี้อย่างตรงไปตรงมา เพราะอยากให้คุณทำแบบเดียวกัน

ทั้งหมดนี้คือเรื่อง competitor analysis ครับ ผมคิดว่ามันมีประโยชน์มาก ไปสร้างระบบนี้และลองทำด้วยตัวเองได้เลย แล้วพบกันในวิดีโอถัดไป
