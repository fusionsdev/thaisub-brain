## บทนำ

วิดีโอนี้สอนสร้าง Skill ตัวแรกของคุณใน Claude — ผู้ช่วยอีเมล (Email Assistant) ที่ใช้ Gmail โดยใช้ Skill Creator Skill ซึ่งเป็น Skill สำเร็จรูปที่ทุกคนมีอยู่แล้วใน Claude ตัวนี้จะถามคำถามเราเป็นขั้นตอน แล้วสร้าง Skill ให้อัตโนมัติ จากนั้นเราจะได้ทดสอบจริง: อ่านอีเมลที่ยังไม่ได้อ่าน 24 ชั่วโมงล่าสุด สรุป จัดลำดับความสำคัญ และร่างคำตอบให้

## คำแปลเต็ม

ยินดีต้อนรับสู่การสร้าง Skill ตัวแรกของคุณ ในวิดีโอนี้ผมจะโชว์วิธีสร้าง Skill ตัวแรกของคุณ เพื่อที่คุณจะได้เริ่มทำระบบอัตโนมัติในชีวิตประจำวัน นี่คือเทคโนโลยีที่ทรงพลังที่สุดบนโลกใบนี้ และคุณต้องใช้มันทุกวัน ผมจะโชว์วิธีตั้งค่าตั้งแต่เริ่มต้น จนจบวิดีโอ เราจะมีผู้ช่วยอีเมลให้คุณใช้งาน และเราจะใช้ Gmail สำหรับบทนี้

ถ้าคุณยังไม่ได้ใช้ Gmail ก็ไม่เป็นไร ผมยังอยากให้คุณดูวิดีโอนี้อยู่ดี เพื่อจะได้เห็นวิธีสร้าง Skill แบบสดๆ เรียลไทม์ และถ้าคุณยังไม่ได้ดูวิดีโอ Anatomy of a Skill กับ What is a Skill ก่อน และไม่รู้ว่าผมพูดถึงอะไรอยู่ ขอให้ย้อนกลับไปดูวิดีโอเหล่านั้นก่อนนะครับ

สิ่งที่เราจะทำคือ เปิด Claude ขึ้นมา แล้วผมจะกลับไปที่หน้าจอแชทก่อน เพื่อเริ่มจากศูนย์จริงๆ เราจะไปที่แถบด้านบนซ้าย ไปที่ Skill แล้วคุณจะเห็นตัวเลือกสร้าง Skill ใหม่ ผมอยากให้คุณรู้จักกับสิ่งที่เรียกว่า Skill Creator Skill ซึ่งทุกคนมีอยู่แล้ว ทันทีที่คุณดาวน์โหลด Claude คุณจะมีมัน โอเค? มันถูกสร้างไว้ให้เรียบร้อยแล้ว และถ้าคุณไม่เห็นมัน บอกผมในคอมมูนิตี้หรือในช่อง Slack ของผมได้ ผมช่วยคุณได้

Skill นี้ถูกสร้างขึ้นมาเพื่อสร้าง Skill ตัวอื่นๆ Anthropic สร้างมันและเพิ่มเข้ามา เพื่อให้คุณสร้าง Skill ได้ง่ายและมีประสิทธิภาพ เอาล่ะ เราต้องเช็คว่าคุณมีมันแล้ว กลับไปที่แชทกัน ตอนนี้ — อย่างที่ผมบอกในวิดีโอ Anatomy of a Skill — มีสองวิธีในการเรียกใช้ Skill คุณสามารถใช้คำสั่งสแลช (slash command) เลือกอันที่ต้องการแล้วรัน หรือมันมีสิ่งที่เรียกว่า front matter ซึ่งเป็นคำอธิบายที่มีคีย์เวิร์ดเยอะแยะ ที่ทำให้ Skill ถูกเรียกใช้ได้โดยอัตโนมัติ เช่น คุณพูดว่า "รันงานประจำวันของฉัน" ก็ได้ เหมือนกันกับ Skill

เราสามารถพูดว่า "ช่วยสร้าง Skill ที่..." หรือถ้าอยากสร้าง Skill ตรงๆ เลย เราก็พิมพ์ /skill creator ผมอยากให้คุณพิมพ์ /skill creator แค่นั้น ง่ายมาก แล้วกด Enter สิ่งที่ Skill Creator จะทำคือ มันจะถามคำถามเราสองสามข้อเกี่ยวกับสิ่งที่เราอยากสร้าง คุณจะพูดว่า "ฉันอยากให้คุณสร้าง Skill ที่..." แล้วอธิบาย workflow ทั้งหมดก็ได้ แล้วมันจะสร้างให้ แต่เพื่อประโยชน์ของบทนี้ ผมอยากโชว์ให้เห็นว่า Skill Creator Skill ทำงานยังไงแบบสดๆ และคุณจะใช้มันสร้าง Skill ตัวอื่นๆ ได้ยังไง

พอคุณเก่งและชำนาญขึ้น คุณจะรู้ว่าคุณไม่จำเป็นต้องใช้ Skill Creator Skill อีกต่อไป ผมเองแทบไม่ใช้มันเลย แต่มาดูกัน มันตอบว่า "พร้อมแล้วที่จะช่วยคุณสร้าง Skill — เนื่องจากเราไม่ได้ใช้ Claude Code เราจะใช้ workflow ที่เรียบง่ายในการทำซ้ำแพ็กเกจ ฯลฯ สร้าง Skill ใหม่ หรือปรับปรุง Skill ที่มีอยู่" เจ๋ง มันกำลังถามเราว่า: เราจะสร้าง Skill ใหม่หรือปรับปรุง Skill เดิม? เราจะสร้าง Skill ใหม่จากศูนย์ ผมเตรียมพรอมป์ตที่แน่นอนไว้ให้คุณแล้ว เพื่อประหยัดเวลา

ถ้าคุณยังไม่ได้ดูวิดีโอก่อนหน้า ผมได้โชว์วิธีเชื่อมต่อ Gmail และ Google Calendar ของคุณ เราสร้างโปรเจกต์ผู้ช่วยส่วนตัวไปแล้ว ซึ่งสิ่งที่เราทำตอนนี้ทรงพลังกว่านั้นมาก น่าทึ่งจริงๆ แต่ขอให้คุณไปก็อปปี้พรอมป์ตนี้มา และถ้าอยากตรวจสอบว่า Connector ของคุณเชื่อมต่ออยู่ ให้ไปที่หน้า Connectors แล้วเช็คว่า Gmail และ Google Calendar ของคุณเชื่อมต่อแล้ว และพอเชื่อมต่อเสร็จ เราก็พร้อมลุย

ผมจะไปหาหน้าต่างแชทนั้น แล้ววางพรอมป์ตนี้ลงไป โดยพื้นฐานเรากำลังบอกว่า: "สร้าง Skill ชื่อ Email Assistant ที่อ่านอีเมลที่ยังไม่ได้อ่านจาก 24 ชั่วโมงล่าสุด สรุปสิ่งที่เกิดขึ้น ระบุว่าอีเมลไหนต้องตอบ และร่างคำตอบสำหรับ 3 อันดับแรกตามความเร่งด่วน เขียนด้วยน้ำเสียงของฉัน ใช้ประโยคสั้นๆ อย่าเพิ่งส่งจริง แค่ร่างคำตอบให้ฉัน" เจ๋งมาก ดังนั้นทุกเช้าที่คุณอยากเช็คอีเมล คุณแค่พิมพ์คำสั่งสแลช แล้วเจ้านี่จะทำงานให้

ผมจะให้พรอมป์ตมัน แล้วปล่อยให้มันสร้างให้เรา สิ่งแรกที่มันทำคือถามคำถามเราสองสามข้อ อันแรกมันกังวลเล็กน้อย — มันบอกว่า Skill นี้เรียกใช้ Gmail Connector ดังนั้นคุณต้องแน่ใจว่าเชื่อมต่อ Gmail แล้วก่อนที่จะสร้าง มันถามว่า "Skill ควรจัดการกับน้ำเสียงการเขียนของคุณยังไง?" ก็แค่ "เป็นธรรมชาติและเป็นมืออาชีพ" คุณสามารถให้รายละเอียดเจาะจงได้ แต่สำหรับบทนี้ ขอให้ผ่านไปก่อน "การจัดลำดับความสำคัญ ใช้ความเร่งด่วนแล้วข้ามไป" "สร้างเลย เดี๋ยวฉันตรวจเองแล้วปล่อยใช้" ง่ายมาก

คุณสามารถเจาะจงได้มากกว่านี้ ผมแค่ทำเพื่อเป็นตัวอย่าง แต่ถ้าคุณอยากให้อีเมลฟังดูเหมือนเสียงของคุณจริงๆ สิ่งที่ต้องทำคือขอให้ Claude สร้างไกด์เกี่ยวกับอีเมลของคุณ แล้วยกตัวอย่างการเขียนอีเมลของคุณสองสามตัวอย่าง แล้วมันจะเขียนได้สมบูรณ์แบบให้คุณต่อจากนั้น เช่น ถ้าคุณทำ email marketing และส่งอีเมลบางประเภท หรืออยากเขียน cold email ที่ชนะ ให้ตัวอย่าง cold email หลายๆ อัน ให้ตัวอย่างที่ชนะจากคลังของคุณ แล้วมันจะเขียนให้คุณ

ปล่อยให้มันทำงานไปก่อน ดูเหมือนมันสร้างเสร็จแล้ว ตอนนี้กำลังแพ็กเกจ จะได้ลุยกันในอีกแป๊บ ดูสิ มันประกอบร่างทุกอย่างให้แล้ว ให้คำอธิบาย ตั้งชื่อว่า Email Assistant อธิบายว่าเข้าใจเนื้อหาอะไร ความเร่งด่วน รูปแบบผลลัพธ์ ฯลฯ คุณสามารถเข้าไปปรับแต่งได้เสมอ สิ่งที่ผมชอบทำคือรันมันก่อน แล้วบอกมันว่าชอบอะไร ไม่ชอบอะไร

จากนั้นคุณเลื่อนลงมาแล้วกด Save Skill เราจะบันทึกเป็น Email Assistant Skill แล้วมันจะบันทึกให้ เราสามารถคลิก Manage เพื่อดูได้ ดูสิ มันบันทึกเข้าไปใน Skills ของเราโดยตรง ซึ่งเยี่ยมมาก ทีนี้เรามาทดสอบกัน ลองเลย

เรากลับไปที่แชทใหม่ โอเค? แล้วพิมพ์สแลช คุณควรจะเห็น Email Assistant ขึ้นมา เห็นมั้ย? ถ้าไม่เห็น ให้กลับไปที่แชทของคุณแล้ว... ส่วนใหญ่คุณแค่ไม่ได้บันทึก คุณต้องบันทึกและแน่ใจว่ามันอยู่บนเครื่องแล้ว แต่เราจะไปที่แชทใหม่ เรียกใช้มัน ไปที่ Email Assistant แล้วรัน ปล่อยให้มันทำงานดูว่ามันเวิร์กมั้ย

เสร็จแล้ว มันสะดุดนิดหน่อย รันช้าลงเล็กน้อย แต่ก็ทำสรุปกล่องจดหมายทั้งหมด ทำเครื่องหมายว่าต้องตอบอะไรบ้าง และสร้างร่างคำตอบให้คนสองสามคน เอาล่ะ นี่ไง ทั้งหมดจากทริกเกอร์เดียว

นี่แหละครับ นี่คือวิธีสร้าง Skill ตัวแรกของคุณ ตอนนี้คุณปลดล็อกสิ่งที่ทรงพลังที่สุดบนโลกใบนี้แล้ว ผมแนะนำให้ลองสร้าง Skill เพิ่มเติมอีก ในวิดีโอหน้า ผมจะโชว์วิธีแก้ไข Skill ตัวนี้ที่เราสร้าง เพื่ออัปเกรดมันขึ้นไปอีก และคุณจะได้เห็นวิธีแก้ไข Skill อื่นๆ ต่อไป เจอกันวิดีโอหน้า
