## บทนำ

บทเรียนนี้แนะนำคำสั่ง Loop ใน Claude Code ซึ่งคล้ายกับ cron แต่ทำงานภายใน Claude Code ผู้สอนสาธิตวิธีใช้คำสั่งนี้เพื่อให้ Claude Code ตรวจสอบงานซ้ำ ๆ ในช่วงเวลาที่กำหนด เช่น ตรวจสอบว่าโพสต์ Instagram ถูกเผยแพร่แล้วหรือยัง พร้อมทั้งอธิบายข้อจำกัดของฟีเจอร์นี้

## คำแปลเต็ม

เอาล่ะครับ เรามาพูดถึงคำสั่ง loop กัน ผมจะโชว์ตัวอย่างการใช้งานจริงที่ผมใช้อยู่ตอนนี้ให้ดู

โดยสรุปแล้ว คำสั่ง loop ก็คล้ายกับ cron ครับ มันคือการบอกให้บางอย่างทำงานซ้ำ ๆ ทุก ๆ 5 นาที หรือตามช่วงเวลาที่คุณต้องการ ถ้าผมพิมพ์คำสั่งนี้ ผมสามารถสั่งให้รัน prompt หรือ slash command ในช่วงเวลาที่ซ้ำ ๆ กันได้ เช่น ทุก ๆ 1 ชั่วโมง ผมสามารถให้มันกลับมาตรวจสอบ code base นี้ได้ หรือตรวจสอบโปรเจกต์นี้ในอีกหนึ่งชั่วโมง

หรือทุก ๆ 5 นาที ผมอยากให้มันไปดึงข้อมูล Instagram ของผมเพื่อดูว่ามีอัปเดตใหม่ไหม หรือทุก ๆ 20 นาที ให้มันวนตรวจสอบอีเมลของผมว่ามีใครส่งอะไรมาบ้าง ประมาณนั้นครับ

ตัวอย่างการใช้งานคือ ผมกำลังโพสต์บน Instagram แล้วทุกอย่างกำลังประมวลผล สิ่งที่ผมทำได้คือตั้ง loop ทุก ๆ 5 นาที เพื่อตรวจสอบว่าทุกอย่างถูกโพสต์เรียบร้อยหรือยัง

ตรงนี้ bash command อาจต้องหยุดก่อน แต่สิ่งที่มันจะทำคือ มันจะวนกลับมาอัตโนมัติในอีก 5 นาที ตราบใดที่ context window ยังเปิดอยู่ และคุณไม่ได้ปิดมันไป มันก็จะวนกลับมาตรวจสอบว่างานเสร็จหรือยัง ซึ่งเจ๋งมากครับ

มันเป็นฟีเจอร์ใหม่เอี่ยม ผมค่อนข้างแน่ใจว่า Claude เพิ่งปล่อยฟีเจอร์นี้เมื่อเดือนมีนาคม 2025 เอง มีกรณีการใช้งานมากมายสำหรับคุณโดยเฉพาะ

ข้อเดียวคือมันเหมือน cron แต่ทำงานได้นานสุดแค่สามวันเท่านั้น เช่น ผมสามารถตั้งให้มันตรวจสอบราคาหุ้นทุก ๆ 5 นาที แล้วรายงานว่าราคาอยู่ที่เท่าไหร่ แล้วแจ้งเตือนผม แต่เงื่อนไขคือคอมพิวเตอร์ของผมต้องเปิดอยู่ และ context window ต้องเปิดตลอดเวลา และมันทำงานได้แค่สามวันเท่านั้น คุณจึงต้องเริ่มมันใหม่ทุกสามวัน

แต่จริง ๆ แล้วนั่นเป็นไอเดียที่ดีมากเลยนะครับ ผมอาจจะทำแบบนั้นเองบ้าง เอาล่ะ นี่คือพื้นฐานของคำสั่ง loop ครับ
