## บทนำ
วิดีโอนี้แสดงขั้นตอนการสมัครบัญชีฟรีบน Pexels และวิธีการเข้าไปยังส่วน Image and Video API เพื่อค้นหาและคัดลอก API Key ไปใช้ในระบบอัตโนมัติของคุณ

## คำแปลเต็ม

ในหน้านี้คุณสามารถสมัครบัญชีฟรีได้ เมื่อสมัครเสร็จแล้วก็เข้าไปที่ Image and Video API ไม่รู้ว่าทำไมมันขึ้น error ก็เลยโหลดหน้าใหม่ จากนั้นคลิกที่ API key ของคุณ พอคลิกเข้าไปก็จะเห็น API key และตรงนี้ในช่อง value จะเป็น API key ของคุณ ผมจะใช้ API ของผมเอง ดังนั้นก็ก็อปปี้แล้ววางลงไปตรงนี้
