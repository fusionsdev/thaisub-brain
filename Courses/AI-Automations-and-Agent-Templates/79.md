## คำแปลเต็ม

ในนี้ผมจะแสดงวิธีแก้ error ที่คุณอาจเจอใน make.com workflows หรือ AI agent workflows ที่มี make.com publishing workflow และ automation และเมื่อรูปภาพที่สร้างขึ้นมาใช้ Google Drive link นี่คือกรณีเดียวที่คุณจะเจอ error นี้ ถ้าผมคลิกที่ webhook นี้คุณจะเห็นว่า URL เป็น Google Drive ซึ่งนี่จะทำงานได้สำหรับ Facebook และ modules อื่นๆ และ LinkedIn แต่สำหรับตัวนี้จะให้ผม error ว่า "Only photo or video can be accepted" มันเคยทำงานกับ Google Drive ได้แต่ไม่ได้อีกแล้วเพราะเหตุใดก็ตามนั้น นั่นเป็นเหตุผลที่ผมได้เตรียมโซลูชันให้คุณแล้วซึ่งคุณสามารถอัปเดต automated workflows ใน make.com ที่มี Google Drive URL เป็นรูปภาพและต้องการ publish ไปยัง Instagram ดังนั้นในกรณีนี้คุณอาจต้องการอัปเดตนี้ ถ้าคุณเห็น error "only photo and video can be accepted" คุณอาจต้องโซลูชันนี้ซึ่งผมจะแสดงให้คุณว่าคุณสามารถนำไปใช้ได้เร็วมาก

คุณไปที่ส่วนที่บอกว่า updates และ Bug fixes แล้วคุณคลิกที่ fix make.co Google Drive image upload ที่นี่คุณ download AI automation fix module และเมื่อคุณทำเสร็จแล้วคุณไปคลิก create ใหม่แล้วเราจะไปที่ import blueprint นั่นคือ blueprint ที่คุณเพิ่ง download มา นั่นคือ AeroFix blueprint ตัวนี้ที่คุณสามารถ download จากคลิปนี้ได้ และตอนนี้มันจะไม่ให้คุณ automation ที่ถูกแก้ไข มันจะให้คุณ modules ที่คุณต้องการ integrate ดังนั้นคุณสามารถกด select all แล้ว click copy modules แล้วเราไปที่ automation ที่เราต้องการแก้ เราจะ unlink แล้วเราจะ paste modules เหล่านี้เข้ามาในนี้ และเราจะ drag มันเข้ามาที่นี่ และตอนนี้เราต้อง map แต่เราจะไม่ connect มันก่อน

ดังนั้นสิ่งแรกที่เราต้องทำคือ map มันให้ถูกต้อง ดังนั้นอันแรกคือ image URL ที่ต้องไปที่ Google Drive URL เพราะเราต้องแปลง Google Drive link เป็น Image link อื่นที่ไม่ใช่ Google Drive และนั่นคือเราใช้ modules เหล่านี้เพื่อแปลง Google Drive URL ให้เป็น Direct URL ซึ่งทำให้ Instagram ยอมรับ

คุณต้องป้อน API key สำหรับ Google Drive และคุณต้องกรอก Google Drive file ID ซึ่งคุณสามารถ copy ได้จาก Google Drive link ของคุุณ คุณต้องคลิกที่แต่ละ module และ paste ค่าที่เรากล่าวมา จากนั้นคุณต้อง map แต่ละ connections ตามที่เราบอก จากนั้นเราก็ connect modules ทั้งหมดเข้าด้วยกัน และตอนนี้ automation ของคุณก็พร้อมแล้ว

ตอนนี้ทุกอย่างมีอยู่ที่นี่ แต่นี่คือวิธีที่คุณต้องทำให้มันทำงาน คุณต้องสร้าง Google Drive file ID โดยคลิกที่ Google Drive URL ที่มันส่งออกมาแล้ว copy ชิ้นที่อยู่ระหว่าง /d/ กับ /view ซึ่งเป็น file ID และคุณต้องใช้มันใน module แรก คุณต้องใส่มันในที่ที่บอกว่า "Google Drive file ID"

จากนั้นคุณต้อง copy และ paste ไปที่ module ที่สองและใส่มันในที่ที่เราบอกว่า "Google Drive file ID" หลังจากนั้นคุณก็ save และ run มัน

ทุกอย่างมันก็ต้องทำงานแล้ว แต่ถ้ามันไม่ได้ทำงานคุณสามารถลองตรวจสอบว่า connections ถูกต้องไหม อาจจะเป็นว่าคุณใส่ API key หรือ connections ผิดพลาด

นี่คือวิธีแก้ปัญหา Google Drive upload error ใน make.com สำหรับ Instagram automation คุณสามารถใช้โซลูชันนี้สำหรับทุก automation ที่มีปัญหาเดียวกันและทำให้มันทำงานได้ถูกต้อง
