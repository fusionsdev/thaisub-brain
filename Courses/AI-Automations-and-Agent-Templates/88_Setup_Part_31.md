## บทนำ
วิดีโอนี้เป็นส่วนที่ 3 ของกระบวนการพัฒนา AI Agent โดยเราจะตั้งค่าให้ AI Agent จัดตารางโพสต์โซเชียลมีเดียให้อัตโนมัติ โดยสร้างบอท Telegram แยกต่างหากที่เข้าถึง Google Sheets ชุดเดียวกับที่ใช้ในส่วนก่อนหน้า เพื่อกำหนดเวลาลงโพสต์ และให้ Google Sheets ส่งข้อมูลไปยังระบบอัตโนมัติอีกชั้นหนึ่งเพื่อเผยแพร่ในเวลาที่กำหนด

## คำแปลเต็ม

ในวิดีโอนี้ เราจะตั้งค่า AI Agent ให้จัดตารางโพสต์โซเชียลมีเดียให้เรา โดยคุณจะพบลิงก์ที่ต้องใช้อยู่ด้านล่างวิดีโอนี้ นี่คือส่วนที่สามของกระบวนการพัฒนา AI Agent ที่ผมลิสต์ไว้ด้านบนนี้ และเราจะอัปเดต AI Agent ตัวแรกของคุณให้สร้างโพสต์ให้คุณ และเผยแพร่สิ่งที่คุณตั้งค่าไว้ในส่วนที่สองด้วย โดย AI Agent จัดตารางโซเชียลมีเดียจะเป็นบอทแยกต่างหากใน Telegram ซึ่งจะเข้าถึง Google Sheets ชุดเดียวกันเพื่อจัดตารางโพสต์ที่คุณสร้างด้วย AI Agent ตัวอื่น และทุกอย่างจะชัดเจนขึ้นเมื่อเราตั้งค่าผ่านไปเรื่อย ๆ

เราจะตั้งค่าฟังก์ชันการจัดตาราง (scheduling) เราต้องดาวน์โหลด N8N workflow สำหรับการจัดตารางของ AI ก่อน คุณไปที่บัญชี N8N ของคุณ ซึ่งคุณอาจตั้งค่า workflow อื่นไว้แล้ว โดยเฉพาะตัวเผยแพร่โพสต์โซเชียลมีเดีย (publish to social media posts AI) จากนั้นก็คลิกสร้าง workflow ใหม่ (create a new workflow) แล้วเราจะนำเข้าไฟล์ที่เพิ่งดาวน์โหลดมา ตรงนี้ ถ้าคุณเคยทำงานกับ AI ตัวอื่นใน N8N มาก่อน คุณก็มีการเชื่อมต่อ (connections) อยู่แล้ว ดังนั้นไม่ต้องตั้งค่า Telegram connections ใหม่ แต่ผมจะพาคุณดูบางส่วน

สิ่งแรกที่เราต้องมีคือ BotFather ไปที่ BotFather กัน เราต้องการบอทใหม่ เพราะเราอยากให้แยกจาก AI agent ตัวอื่น ๆ คลิกที่สร้าง credential ใหม่ (create a new credential) แล้วเราจะไปที่ BotFather คลิกสร้างบอทใหม่ แล้วมันจะให้ตัวเลือกในการจัดการบัญชีของเรา คลิก create a new ตั้งชื่อบอท มันใช้ชื่อซ้ำแล้ว เราต้องเปลี่ยนชื่อ ตั้งเป็นชื่อใหม่ แล้วลองใหม่ คราวนี้น่าจะใช้ได้ ดี ทีนี้คัดลอก access token ไปวางตรงนี้ นี่คือบัญชี Telegram เราจะตั้งชื่อให้มันว่า AI agent schedule setup เพราะเดี๋ยวผมต้องเลือกจาก dropdown

ต่อไป ผมต้องไปที่ Telegram models ต่าง ๆ แล้วเลือกบัญชีที่เราเพิ่งเชื่อมต่อ ไม่ต้องเปลี่ยนการตั้งค่าใด ๆ เลือกอันนั้น แล้วก็ตรงนี้ด้วย ตรงนี้ไม่ต้องตั้งค่าอะไร แค่ใส่ OpenAI connection ตรงนี้ และถ้าคุณยังไม่ได้ตั้งค่าหรือต้องการความช่วยเหลือเรื่องการขอ API คุณก็ดูวิดีโอสอนในส่วน technical tutorials ได้ คุณจะพบคำแนะนำและขั้นตอนทั้งหมดในการเชื่อมต่อ OpenAI หรือบัญชีอื่น ๆ ที่คุณต้องใช้ ตรงส่วน chat ผมเลือก GPT-4 ซึ่งทำงานร่วมกับ AI agent ได้ดีมาก ในส่วน AI เราไม่ต้องเปลี่ยนหรือตั้งค่าอะไร ปล่อยไว้ตามเดิม

สิ่งสุดท้ายที่เหลือคือ Google Sheet เราต้องเพิ่ม Google Sheet ก่อน แต่ก่อนอื่นให้ดาวน์โหลดเทมเพลต Google Sheet ก่อน เพราะผมได้อัปเดตฐานข้อมูล Google Sheet ที่ใช้เก็บข้อความโพสต์และช่วยให้เราสร้างโพสต์ได้ เราจะเข้าไปใน AI agent workflow ที่เราตั้งค่าไว้ในขั้นตอนที่หนึ่ง แล้วสลับ Google Sheet ไปใช้ตัวใหม่ เพราะผมได้ปรับปรุงและแก้ไขบางอย่าง แต่ก่อนอื่น คลิก make a copy ก่อน

เมื่อเราเชื่อมต่อเสร็จ ตอนนี้ใน workflow นี้ นี่คือตัวจัดตาราง ให้ตั้งชื่อว่า AI agent scheduler demo setup ก่อนที่จะใช้งานได้ เราต้องรอสักครู่ เพราะจะมีเมนูแบบกำหนดเอง (custom menu) ปรากฏขึ้น เห็นไหมว่า "automation" แล้วคลิก authorize script จากนั้นระบบจะให้ลงชื่อเข้าใช้กับบัญชีที่ถูกต้องเพื่อยืนยันบัญชี คลิกที่มัน จากนั้นคลิก advanced แล้วคลิกที่ลิงก์สุดท้ายตรงนี้ เลื่อนลงมาแล้วคลิก allow แล้วก็สำเร็จ จากนั้นคลิก install automation หรือ install

ตอนนี้ Google Sheet เกือบจะพร้อมแล้ว เราต้องปรับเปลี่ยนเล็กน้อย ไปที่ extensions แล้วเข้า Apps Script นี่คือโค้ด AppScript ซึ่งเป็นโปรแกรมปรับแต่งที่ผมสร้างขึ้นเพื่อทำให้ Google Sheet ทำสิ่งที่เราต้องการ และมันจะชัดเจนขึ้นเมื่อเราตั้งค่าไปเรื่อย ๆ ก่อนอื่นต้องคัดลอก ID นี้ แล้ววางแทนที่ในไฟล์โค้ด แล้วเรายังมี sheet ID ตรงส่วนล่างตรงนี้ด้วย และผมคิดว่าเรามีตรงนี้ด้วยเหมือนกัน รวมทั้งหมดสามจุด จากนั้นคลิก save เท่านั้นแหละ

ต่อไป เราต้องให้ชื่อที่เหมาะสม ผมเรียกมันว่า setup เพราะตอนนี้ต้องนำไปเชื่อมกับ AI agent workflow ของผม ตรงนี้ผมต้องเข้าไปในส่วน Google Sheet ใน AI agent ตัวนี้ ถ้าคุณยังไม่ได้เชื่อมต่อกับ Google คุณก็เข้าไปดูได้ว่า Google Sheet ที่เพิ่งสร้างปรากฏขึ้นหรือยัง เหมือนที่เห็นของผม มันควรชื่อว่า setup demo ดังนั้นมันอยู่ตรงนี้แล้ว ตรงนี้เราต้องใช้แท็บ generated posts และต้องเพิ่ม option โดยควรเป็นแถวว่างแถวแรก ดี

ตรงนี้เราก็ต้องเลือก Google Sheet ที่ถูกต้อง ถ้าคุณไม่เห็น Google Sheet ของคุณปรากฏ แสดงว่าคุณต้องสลับไปใช้บัญชี Google อื่น หรือลงชื่อเข้าใช้ด้วยบัญชีที่คุณเชื่อมต่อ Google Sheet นี้ไว้ ผมแนะนำแบบนั้น ตรวจสอบให้แน่ใจว่าบัญชี Google ถูกต้อง แล้วคลิก create credential แล้วลงชื่อเข้าใช้ด้วยบัญชีนั้น ผมเห็นอยู่แล้ว ดังนั้นสิ่งที่ต้องทำคือคลิก refresh แล้วลบอันที่ไม่ใช้ออกได้

นี่คือสิ่งเดียวที่ AI agent ตัวนี้ต้องทำ เพราะสิ่งเดียวที่มันทำคือค้นหาโพสต์ ID แล้วเขียนเวลาที่กำหนดลงในชีตถัดจากโพสต์ เมื่อไปที่ generated posts คุณจะเห็นคอลัมน์ scheduled time นี่คือจุดที่เราบอกให้ AI จัดตารางโพสต์ตามเวลานี้ แล้วมันจะตั้งสถานะเป็น scheduled จากนั้น Google Sheet จะทำงานต่อ โดยจะส่งข้อความโพสต์ รูปภาพ และแพลตฟอร์มที่ควรเผยแพร่ไปยังระบบอัตโนมัติอีกตัวหนึ่ง ซึ่งจะเผยแพร่โพสต์ในเวลานั้นไปยังแพลตฟอร์มที่เราจะตั้งค่าในขั้นตอนสุดท้าย

กลับมาตรงนี้ ระบบนี้ทำงานได้ และเราไม่ต้องทำอะไรตรงนี้ ส่วนนี้เราข้ามได้ ตรงนี้ก็เชื่อมต่อชีตด้วย นี่คือชีต settings เราต้องตรวจสอบว่าเป็น settings แล้วไม่ต้องเปลี่ยนอะไร คลิก แล้วก็เสร็จ

เราสามารถทดสอบรันครั้งแรกได้ แต่ขอบอกไว้ก่อนว่า การจะรันได้ต้องมีโพสต์ในชีตก่อน ซึ่งเราจะเชื่อมกับชีตสร้างโพสต์ของเราในขั้นตอนสุดท้าย แต่เดี๋ยวผมจะดึงโพสต์สองสามอันที่ผมมีอยู่ในชีตนี้อยู่แล้ว ซึ่งสร้างด้วย post generator AI agent ของผม คัดลอกแล้ววางลงตรงนี้ คลิก allow มันจะโหลดรูปภาพด้วย ซึ่งเป็นการปรับปรุงอีกอย่างของ Google Sheet นี้ มันจะแสดงรูปภาพตรงนี้

ตอนนี้ผมถาม AI agent ได้แล้ว ไปที่ AI agent คลิก start ก่อนอื่นต้องทดสอบ workflow ก่อน มันอาจจะส่งข้อความต้อนรับกลับมา จากนั้นผมพิมพ์ถามได้ว่า "ตอนนี้มีโพสต์ไหนบ้างที่ยังไม่ได้จัดตาราง" แล้วคลิก test อีกครั้ง ระบบจะอ่านโพสต์และให้ข้อมูลกลับมา มีเจ็ดโพสต์ที่จัดตารางได้ ผมสามารถสั่งได้ว่า "จัดสามอันแรกภายใน 5 นาทีข้างหน้า" หรือ "จัดตารางให้ห่างกัน 5 นาทีจากตอนนี้" จากนั้นคลิก test workflow อีกครั้ง และภายในไม่กี่วินาทีมันควรเขียนเวลาจัดตารางของสามโพสต์แรก มาดูกันว่ามันทำได้ไหม

เมื่อจัดตารางแล้ว สิ่งที่เกิดขึ้นคือ App Script ของผมจะคอยตรวจสอบ และตั้งค่า trigger เฉพาะเพื่อส่งโพสต์ตามเวลาที่กำหนดไปยัง workflow อัตโนมัติใหม่ ซึ่งเราจะตั้งค่าในส่วนถัดไปของกระบวนการนี้
