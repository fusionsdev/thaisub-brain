## บทนำ

บทเรียนสั้น ๆ ว่าด้วยคำสั่ง /rename ใน Claude Code ที่ใช้สำหรับเปลี่ยนชื่อ terminal เพื่อจัดระเบียบการทำงานหลายโปรเจกต์พร้อมกันในหน้าต่างเดียวกัน ทำให้รู้ทันทีว่ากำลังทำงานอะไรอยู่ที่ไหน

## คำแปลเต็ม

ทุกคนครับ ยินดีต้อนรับสู่บทเรียน rename ครับ ในบทนี้ผมจะโชว์วิธีเปลี่ยนชื่อ terminal ของคุณ มันเจ๋งมากสำหรับการจัดระเบียบ terminal ใน Claude Code และผมชอบฟีเจอร์นี้มาก มันเป็นอะไรที่ผมใช้บ่อย และผมว่าทุกคนก็ควรใช้ด้วยเหมือนกัน

เดี๋ยวผมเปิด terminal ใหม่ให้ดูนะครับ สมมติว่าผมล็อกอินแล้ว และกำลังทำงานอยู่ ผมจะเปิดโฟลเดอร์ personal brand ตรงนี้ เราอยู่ใน Cursor กับ terminal แล้ว มันดึงอย่างอื่นขึ้นมาแทน ไม่เป็นไร ผมเปิดอะไรสุ่ม ๆ ตรงนี้ละกัน

โอเค ตอนนี้ผมอยู่ใน terminal และเปิดมันขึ้นมาแล้ว เมื่อผมใช้ฟีเจอร์นี้ มันคือการจัดระเบียบหลาย ๆ อันพร้อมกัน สมมติว่าผมแบ่งหน้าจอ แล้วทำงานห้าหกโปรเจกต์ หรือสองสามโปรเจกต์พร้อมกัน สิ่งที่ผมจะทำคือ ถ้าผมอยากเปลี่ยนชื่อ อย่างเช่นตรงนี้ ผมกำลังทำงาน Claude Code for Dummies และตรงนี้ผมกำลังทำงานฟีเจอร์การตลาดบางอย่าง อาจจะเป็นการทำ cold email สิ่งที่ผมทำได้คือ พิมพ์คำสั่งสแลช แล้วพิมพ์ rename จากนั้นกด enter แล้วคุณจะเห็นว่ามันขึ้นชื่อมาตรงนั้น นี่คือคำสั่งดั้งเดิมของ Claude Code ผมจะตั้งชื่อว่า cold email marketing แล้วมันจะทำยังไง เห็นแถบสีฟ้านั่นไหมครับ มันจะเปลี่ยนชื่อ terminal ให้เรา

แล้วสมมติผมมาอีกฝั่งหนึ่ง ผมกำลังทำงานบทเรียน rename และกำลังทำคอร์สเรียนอยู่ มันก็จะเปลี่ยนชื่อ terminal ให้ผม เห็นไหมครับว่ามันเป็นสีฟ้า นี่ช่วยให้ผมจัดระเบียบงานข้ามโปรเจกต์ได้ ถ้าผมทำงานห้าโปรเจกต์พร้อมกัน ผมก็รู้ว่ากำลังทำอะไรอยู่ แล้วพอผมกลับมา แล้วกด cold email มันก็เด้งกลับขึ้นมาเลย มันเป็นวิธีจัดระเบียบที่ง่ายมาก ผมรู้ว่ามันง่ายแบบสุด ๆ แต่ก็เจ๋งและมีประโยชน์มากสำหรับหลายกรณีการใช้งาน ผมใช้มันบ่อยมาก นี่คือทั้งหมดของบทเรียนนี้ครับ สิ่งที่คุณต้องทำก็แค่พิมพ์คำสั่งสแลช แล้วคุณก็จัดระเบียบ terminal ทั้งหมดของคุณได้แล้ว
