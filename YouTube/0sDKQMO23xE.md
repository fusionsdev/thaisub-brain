## ประเด็นหลัก

- Hermes Agent ปล่อยอัปเดตใหม่ (เมื่อวาน) ที่ให้เอเจนต์ AI เรียนรู้จากหนังสือ PDF หรือเอกสารใดก็ได้ด้วยคำสั่ง /learn เพียงคำเดียว แล้วแปลงเป็นทักษะถาวร (skill)
- ฟีเจอร์นี้ประกาศโดย Technium ผู้ร่วมก่อตั้งและวิศวกรหลักของ Hermes Agent และ Nous Research ผ่านโพสต์บน X
- ปัญหาเดิม: การเท PDF ลงแชททำให้ AI สำลักเมื่อหนังสือใหญ่เกิน context window หรือลืมทันทีที่แชทจบ ต้องป้อนเอกสารซ้ำทุกครั้ง
- ทางออกคือ Book Brain Engine: อ่านหนังสือครั้งเดียว ดึง framework กฎการตัดสินใจ จุดพลาดที่ควรหลีกเลี่ยง แล้วสร้างไฟล์ดัชนี/glossary/patterns/cheat sheet ให้เอเจนต์พกติดตัวตลอด
- สร้างบนโปรเจกต์โอเพนซอร์ส Book to Skill (ดาว GitHub เกิน 18,000 ดาว) ซึ่งวัดผลแล้วใช้ tokens น้อยลง 24-51 เท่าเมื่อเทียบกับการเทหนังสือทั้งเล่มเข้าบริบท
- ขีดจำกัด: ไฟล์ skill หลักสูงสุด 100,000 ตัวอักษร (~33,000 tokens) แต่ระบบออกแบบให้แตกเป็นไฟล์อ้างอิงย่อย และรองรับไฟล์ ePub ด้วย
- ต้นทุนแฝงที่เรียกว่า discovery loop tax: เอเจนต์ที่อ่าน PDF แบบเดิมต้องวนเปิดสารบัญ ย้อนกลับ อ่านซ้ำทุกบทสนทนา Book Brain Engine แก้ครั้งเดียวจบ เปลี่ยนจากการเช่าความรู้มาเป็นเจ้าของความรู้
- เดิมทักษะ Hermes จำกัดแค่ ~200 บรรทัดและห้ามไฟล์อ้างอิง ตอนนี้รองรับเนื้อหาใหญ่แบบหนังสือเต็มเล่ม เปลี่ยนจากการเรียนทริกมาเป็นการเรียนวิชา
- การใช้งานจริง: เอกสารออนบอร์ดดิ้งลูกค้า คู่มือเสียงแบรนด์ สื่อการสอนของโค้ช เอกสารภายใน งานวิจัย สเปกและมาตรฐาน
- จุดขายของ Hermes Agent: รันได้บนโทรศัพท์ Discord CLI มี scheduled tasks ความจำถาวร และ sub-agents ทำงานแบบขนาน ฟอร์แมต skill รองรับมาตรฐาน open agent skills ใช้ข้าม Claude Code, GitHub Copilot CLI และ Amp ได้
- ขั้นตอนเริ่มต้น: ติดตั้ง Hermes Agent (ฟรี โอเพนซอร์ส) → เลือกเอกสารหนึ่งไฟล์ → รัน /learn → ทดสอบ → ค่อยๆ เพิ่มทักษะสัปดาห์ละหนึ่งตัว
- โปรโมต AI Profit Boarding: personas กว่า 3,800 ตัว บทเรียนรายวัน คอลโค้ช 4 ครั้ง/สัปดาห์ แผนงาน 30 วัน Agent Operating System และ Mission Control Dashboard

## ความเห็นสรุป

วิดีโอนี้เป็นการตลาดเชิงการศึกษา (edu-marketing) ที่อธิบายฟีเจอร์ /learn ใหม่ของ Hermes Agent ได้ชัดเจนและเป็นขั้นเป็นตอน ตั้งแต่หลักการทำงาน ตัวเลขประสิทธิภาพ จนถึงกรณีใช้จริงในธุรกิจ แม้จะมีส่วนโปรโมตสมาชิก AI Profit Boarding ค่อนข้างชัดเจน แต่เนื้อหาหลักให้ข้อมูลที่เป็นประโยชน์สำหรับคนที่อยากให้เอเจนต์ AI เรียนรู้จากเอกสารของตัวเองแบบถาวรครับ
