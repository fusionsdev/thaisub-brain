## ประเด็นหลัก
- การ deploy แอพจาก localhost สู่ production environment
- การ push โค้ดขึ้น GitHub
- การ deploy บน Vercel
- การเปลี่ยน database และ storage จากเครื่องเป็น production-grade
- การตั้งค่า OAuth สำหรับ live URL
- การติดตั้ง custom domain
- การสร้าง workflow ที่ทำให้การเปลี่ยนแปลง local flow ไปยัง production อัตโนมัติ
- ความสำคัญของการ deploy แอพเพื่อสร้างประสบการณ์จริง
