## บทนำ
คลิปนี้สอนวิธีเปลี่ยน API ที่ใช้ค้นหาวิดีโอพื้นหลังจาก Pexels ไปเป็น Pixabay ในระบบสร้างวิดีโอโซเชียลมีเดียอัตโนมัติ เพราะช่วงนี้ Pexels สมัครบัญชีใหม่ไม่ได้ ทาง Pixabay ยังเปิดให้สร้างบัญชีและใช้ API ได้ฟรี ผู้สอนสาธิตการแก้ไขทีละขั้นตอนตั้งแต่สมัครบัญชี ใส่ API key จนถึงทดสอบระบบให้ทำงานได้จริง

## คำแปลเต็ม
ในวิดีโอนี้ ผมจะมาแชร์วิธีเปลี่ยน Pexels ซึ่งเราใช้สร้างวิดีโอพื้นหลังให้เข้ากับเนื้อหาในระบบสร้างวิดีโอโซเชียลมีเดียของเรา โดยคุณสามารถเปลี่ยนไปใช้บริการอื่นได้ เพราะตอนนี้คุณไม่สามารถสร้างบัญชีใหม่บน Pexels ได้แล้ว ถ้าคุณเจอปัญหานี้ ผมอยากโชว์ทางเลือกอื่นที่คุณยังสมัครบัญชีใหม่ได้ และยังใช้ API ได้ฟรี

คุณก็ไปสมัครบัญชีกับ Pixabay ก่อน แล้วผมจะโชว์วิธีเปลี่ยนให้ดู วิธีนี้ใช้ได้กับระบบสร้างวิดีโอโซเชียลมีเดียเท่านั้น สำหรับวิดีโออื่นๆ คุณก็ทำการเปลี่ยนแบบเดียวกันได้เป๊ะๆ ตามที่ผมโชว์ให้ดูครั้งเดียวตรงนี้

ตอนนี้ผมมีค่า Pexels อยู่ และผมอยากเปลี่ยนเป็น Pixabay สิ่งที่ต้องทำคือ ลบ query นี้ทิ้ง ลบ header ทิ้ง และลบส่วนนี้ทิ้งด้วย จากนั้นต้องใส่ API URL ซึ่งหน้าตาประมาณนี้ ผมจะให้คุณหานิพจน์ (expression) ที่ตรงเป๊ะด้านล่างนี้ แล้วผมต้องแทนที่มันในสองตำแหน่งด้วยข้อมูลสองอย่าง

อย่างแรกต้องเอา API key มาจากไหน ผมไปที่ explore แล้วคลิก API คลิก Get แล้วเลื่อนลงมา ตรงนี้คุณจะเห็น API key ของผม ผมคัดลอกแล้ววางลงไป อีกอย่างคือต้องใส่ค่า value ซึ่งก็คือ ประเภทของวิดีโอ หรือควรเป็นวิดีโอหัวข้ออะไร แล้วคลิก OK

ก่อนจะตั้งค่าได้ ผมต้องรันมันสักครั้งก่อน ผมปลดลิงก์มันไว้ตรงนี้ แล้วคลิก run และในการรันนี้ผมต้อง trigger จาก Google Sheet ของผม ผมไปที่ Google Sheet ฟังก์ชันที่ต้อง trigger คือ rotate and send ซึ่งจะส่งข้อมูลตรงนี้ไปที่ระบบ แล้วมันควรจะทำงานผ่านไปได้

ที่ผมอยากได้คือทดสอบก่อนว่า Pixabay ทำงานได้หรือไม่ ตอนแรกมันไม่มีอะไร แล้วตอนนี้ผมสามารถปรับแต่งเพิ่มเติมได้ตรงนี้ ผมต้องเปลี่ยนตรงนี้ ฟังก์ชัน shuffle ต้องเป็นแบบนี้ คลิก OK ตอนนี้ผมเชื่อมมันกลับได้แล้ว และต้องรันมันอีกครั้ง งั้นปลดลิงก์จากตรงนี้ แล้ว trigger อีกครั้ง บันทึกไว้ รันหนึ่งครั้ง

ตอนนี้ trigger อีกครั้ง จากนั้นมันก็ทำงานได้แล้ว มีวิดีโอสุ่มถูกเลือกมา เยี่ยม ตอนนี้ผมสามารถเชื่อมมันได้แล้ว และตรงนี้ผมสามารถตั้งค่าตัวแปรอื่นๆ ของ Pixabay ได้ กลับไปข้างล่างสุดของ random video แล้วตอนนี้ผมต้องเลือก Go to Videos ตรงนั้นผมเลือกขนาดวิดีโอพื้นฐานที่ต้องการได้ ผมเลือกขนาดกลาง (medium) แล้วใช้ URL ตรงนี้ คลิก OK ขอเช็คหน่อยว่าได้อันที่ถูกต้องไหม แล้วตอนนี้มันก็ทำงานได้แล้ว
