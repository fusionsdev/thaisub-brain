# Jack Dorsey's Buzz DESTROYS Hermes Agent?

> [!info] แหล่งที่มา
> Julian Goldie SEO · https://www.youtube.com/watch?v=AotXHyMYlNA

## 📝 สรุป

Julian Goldie SEO รีวิว Buzz — โปรเจกต์โอเพนซอร์สใหม่จาก Jack Dorsey ที่สร้างบน Nostr ซึ่งเป็นแพลตฟอร์มสำหรับทีมเวิร์กกับ AI agents ที่มีลักษณะคล้าย Slack

## จุดเด่น
- ลักษณะการใช้งานคล้าย Slack — แชนเนล, ห้อง, คอมเมนต์ในไฟล์, แท็ก AI agents ได้
- ติดตั้งง่ายผ่าน Desktop App (การตั้งค่าด้วยตัวเองใช้เวลานาน)
- รองรับ Claude Code และ Codex — ไม่ต้องใช้ API key แยก
- แชร์ AI ให้ทีมเข้าถึงได้ ซึ่งทำได้ยากใน Hermes หรือ OpenClaw
- มี memory และ branch rooms — จดจำประวัติและแยกห้องทำงานย่อยได้
- ตั้งความเชี่ยวชาญของเอเยนต์ได้ — Honey (เขียน), Bumble (ค้นคว้า), Fizz (สร้าง)
- เลือกโมเดลได้เอง — Codex, Buzz Agent, Claude, Opus หรือ custom model
- มี allow list ควบคุมว่าใครเข้าถึงเอเยนต์ได้บ้าง
- ใช้ Computer Use เปิด browser ตรวจสอบงานที่สร้างขึ้นได้
- แอปฟรี — ต่างจาก Slack ที่แพงสำหรับทีมใหญ่

## ข้อเสีย / ข้อสังเกต
- ต้องแท็กเอเยนต์ทุกครั้ง — การตอบกลับโดยไม่ @mention จะไม่ถูกประมวลผล
- มีประโยชน์เฉพาะผู้ใช้ Claude/Codex — ถ้าไม่ได้ใช้ทั้งคู่อาจไม่คุ้มค่า
- AI อาจ Hallucinate — เช่น สร้างลิงก์ที่ใช้ไม่ได้ในตอนแรก
- การตั้งค่าผ่าน Claude Desktop ใช้เวลานานมาก (22 นาทียังไม่เสร็จ)

## ผลการทดสอบจริง
- ✓ เขียนบทความ OpenClaw beginner's guide ได้สำเร็จ
- ✓ จัดรูปแบบสวยงาม ใช้ custom workflow ของ Claude ที่มีอยู่แล้ว
- ✓ เข้าถึง WordPress โดยใช้ credentials จากการตั้งค่า Claude
- ✓ ตรวจสอบงานผ่าน Computer Use โดยเปิด Firefox
- ✕ เกิด hallucination ตอนแรกว่าลิงก์ใช้ไม่ได้ — แท้จริงเป็น cache ของผู้รีวิวเอง

## ความเห็นสรุป
Buzz เป็นเครื่องมือที่คุ้มค่าลองถ้าคุณใช้ Claude และ Codex อยู่แล้ว ตั้งค่าง่าย ใช้งานง่าย มีฟีเจอร์ครบ โดยเฉพาะการให้ทีมเข้าถึง AI agents ได้พร้อมกัน ทั้งยังมีแอปมือถือเร็ว ๆ นี้
