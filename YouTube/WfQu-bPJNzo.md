## ประเด็นหลัก

- ตั้งให้ Hermes agent ทำงานแทน social media manager เต็มเวลา ค้นคว้า เขียน โพสต์ และตอบคอมเมนต์ได้เองตลอดวัน
- ระบบมีสองส่วนคือ Hermes ที่รันบนเครื่องของเรา และ Mallory.AI เป็นตัวเชื่อมไปยังบัญชีโซเชียลจริง
- ความรู้ส่วนตัวในโฟลเดอร์ knowledge base คือสิ่งที่ทำให้คอนเทนต์ฟังดูเป็นตัวเรา ไม่ใช่ AI สำเร็จรูป
- skill คือสูตรที่ใช้ซ้ำได้ สร้างจากพรอมต์เดียว ขยายไปทำเธรด แคปชัน สคริปต์วิดีโอ และ newsletter ได้
- skill คารูซัลค้นคว้าหัวข้อให้ถูกต้องและทันสมัยก่อน แล้วจึงเขียนตามความรู้ของเจ้าของบัญชี
- ผลลัพธ์คือคารูซัล 7-10 สไลด์ พร้อมภาพและแคปชันครบในคำสั่งเดียว ใช้เวลาราว 12 นาที
- database ของโพสต์กันการซ้ำซ้อน และเป็นจุดที่ agent ใช้ตามหาคอมเมนต์ที่ยังไม่ได้ตอบ
- เชื่อม Mallory ได้สองทางคือ MCP ที่ง่ายแต่กินโทเคน หรือ API ที่ควบคุมได้กว่าสำหรับผู้ใช้ขั้นสูง
- เก็บ API key อย่างปลอดภัยในไฟล์ .env.local แทนการทิ้งคีย์ลงในแชท
- skill ตอบคอมเมนต์ตรวจก่อนว่าไม่เคยตอบ ร่างคำตอบจากคลังเนื้อหา มี cron job รันอัตโนมัติ และขออนุมัติก่อนโพสต์ทุกครั้ง

## ความเห็นสรุป

คลิปนี้เป็นบทเรียนลงมือทำจริงที่ครบวงจร ตั้งแต่วางรากฐานความรู้ส่วนตัวจนถึงระบบตอบคอมเมนต์อัตโนมัติที่ขออนุมัติก่อนโพสต์เสมอ จุดขายจริงของเวิร์กโฟลว์นี้คือความรู้ของเจ้าของบัญชีที่ทำให้ทุกโพสต์และทุกคำตอบดูเป็นคนจริง ส่วนการโพสต์และตอบคอมเมนต์ข้ามแพลตฟอร์มใช้ Mallory.AI เป็นตัวเชื่อม โดยผู้พูดเปิดเผยว่าได้รับอนุญาตให้ทดลองใช้ฟรีก่อน และฟีเจอร์ครบต้องใช้แพ็กเกจเสียเงิน
