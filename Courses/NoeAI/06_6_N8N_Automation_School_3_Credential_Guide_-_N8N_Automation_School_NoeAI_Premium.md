## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับสู่อีกหนึ่งวิดีโอครับ วันนี้เราจะพูดถึง credentials ใน n8n ซึ่งเป็นส่วนที่น่าเบื่อที่สุด แต่จำเป็นที่สุดของ n8n ครับ วิดีโอนี้จะสั้น ๆ ผมจะโชว์ให้ดูว่า credentials ทำงานยังไงใน n8n เพื่อที่คุณจะได้เชื่อมต่อแอปนับพัน ๆ ตัวเข้ากับ n8n ได้อย่างรวดเร็วครับ

ตรงนี้คือ credentials ที่คุณมีอยู่ และ credential คืออะไร มันก็คือสิ่งที่ให้คุณเชื่อมต่อกับแอปต่าง ๆ ครับ ผมมี Google Drive, มี ChatGPT ของผม ผมเอา API tokens มาจากที่ต่าง ๆ แล้วให้ Claude Code แล้วมันก็สร้างอะไรแบบนี้ เหมือนกับที่คุณรู้จัก ในการสร้าง MCP servers เพื่อเรียกใช้งานสิ่งต่าง ๆ แล้วมันก็ทำงานในเครื่องของเรา ทำให้ทุกอย่างง่ายมาก คุณแค่ต้องใส่ API key เท่านั้น

บางอย่างก็ปวดหัวหน่อย เช่น Google นี่ปวดหัวสุด แต่โดยพื้นฐานแล้ว มันให้คุณเชื่อมต่อกับสิ่งต่าง ๆ ได้ คุณคลิกเพื่อสร้าง credential ตรงนี้ แล้วเชื่อมต่ออะไรก็ได้ที่ต้องการครับ แต่ผมไม่เคยทำแบบนั้นนะ สิ่งที่ผมชอบทำคือ ตอนที่กำลังสร้างเวิร์กโฟลว์ และยังไม่มี credential ผมก็แค่เชื่อมต่อเข้าไปข้างในเลย ซึ่งวิธีทำง่ายมากครับ เพราะแต่ละแอป หรืออย่างน้อยก็หนึ่งในแอปเหล่านี้ มันมีขั้นตอนตั้งค่าให้

คุณเข้ามาตรงนี้ จะเห็นว่า Novara credentials เชื่อมต่อกับอีเมลของผมพอดี ถ้าผมอยากสร้างใหม่ ผมแค่คลิก create new ซึ่งถ้าคุณยังไม่เคยเชื่อมต่อ Gmail คุณจะเห็นขั้นตอนนั้น แต่คุณจะไม่เห็นขั้นตอนนี้นะ เพราะ Google เป็นแอปที่ยุ่งยากที่สุด แต่ผมแนะนำให้ทำเพราะมันทรงพลังมากครับ

สำหรับทุกแอป มันจะบอกคุณว่าต้องทำอะไร คุณเปิดเข้าไป แล้วมันจะสร้างคู่มือแนะนำทีละขั้นตอนให้คุณเลย ซึ่งทำให้การเชื่อมต่อง่ายมาก เจ๋งจริง ๆ ครับ และถ้าคุณมีปัญหา แค่ถาม Claude Code โดยก็อปปี้ข้อความนี้ไปวาง แล้วบอกว่า ช่วยให้ฉันดูขั้นตอนการตั้งค่าเพื่อเชื่อมต่อ Google OAuth กับ n8n ทีละขั้นตอนหน่อย ได้โปรดอ่านคู่มือนี้นะครับ แล้วผมก็วางมันลงไป มันก็จะสาดคำแนะนำทั้งหมดออกมาให้ผม แล้วเราก็ปล่อยให้มันทำงานต่อ

คุณจะเห็นว่า ทุกแอปมีวิธีที่ต่างกันไป เช่น ถ้าผมเปิด Airtable ขึ้นมา มันง่ายมากเลย ผมเปิด Airtable แล้วไปที่ create แล้วก็จะมี access token ซึ่ง access token ก็คือ API key นั่นแหละ เอาไปวาง เท่านี้เอง ง่ายมากครับ

ดูเหมือนคู่มือ end-to-end จะปวดหัวอยู่เหมือนกัน ผมจะไม่รอแล้ว แต่โดยรวม นี่คือวิธีตั้งค่า credentials ครับ จริง ๆ แล้ว ทุกแอปที่คุณอยากเชื่อมต่อ จะมีคู่มือของมันเอง มันจะพาคุณทำทีละขั้นตอน แค่ทำตามคู่มือ ให้ Claude ช่วยจัดการ แค่นั้นเองครับ นี่คือทั้งหมดของ credential guide ครับ
