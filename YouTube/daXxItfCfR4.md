## ประเด็นหลัก

- Claude Code ต่างจาก ChatGPT ตรงที่ลงมือทำงานแทนเราจริง ๆ เช่น สร้างเว็บไซต์ บล็อก หรือแดชบอร์ดทั้งอัน ไม่ใช่แค่ตอบคำถาม
- IDE อย่าง VS Code / Anti-Gravity (ฟรี) และ Cursor (เสียเงิน) คือพื้นที่ทำงานที่ Claude Code อยู่ในรูปแบบ extension
- Prompt ที่ดีต้องเจาะจงและให้ role กับ Claude เช่น "คุณคือนักออกแบบเว็บ" และยิ่งให้ context (ไฟล์น้ำเสียง/อารมณ์ขัน/ตัวอย่างงานเขียน) มากเท่าไหร่ ผลลัพธ์ยิ่งดีขึ้น
- Permissions มีหลายระดับ ตั้งแต่ ask for edits (ถามทุกครั้ง) ไปจนถึง bypass permissions และ plan mode ที่ให้ Claude คิดวางแผนก่อนลงมือ เหมาะกับโปรเจกต์ใหญ่
- Context window คือความจำระยะสั้นของ Claude มีขีดจำกัด พอใกล้เต็มคุณภาพตกและเปลือง tokens แก้ด้วย /clear หรือ /compact
- Tokens คือสกุลเงินของ Claude Code (1 token ≈ 3/4 คำ) และ input tokens คือบทสนทนาทั้งก้อนทุกข้อความ ทำให้ค่าใช้จ่ายโตแบบยกกำลังในบทสนทนายาว ๆ
- Memory ทำให้ข้อมูลคงอยู่ข้ามบทสนทนา ต่างจากบทสนทนาปกติที่แยกขาดกัน
- Skills คือ workflow สำเร็จรูปที่เรียกใช้ผ่าน slash command สำหรับงานที่ทำซ้ำ เช่น เขียนโพสต์ LinkedIn ทุกวัน
- Hooks คือการกระทำอัตโนมัติที่ trigger ตามขั้นตอนของบทสนทนา เช่น บล็อกคำขอที่มีรหัสผ่าน หรือเปิดเสียงเตือนเมื่อ Claude ตอบกลับ
- MCP servers เชื่อม Claude เข้ากับแอปต่าง ๆ (Gmail / Slack / Notion) และถ้ายังไม่มี MCP ให้ใช้ API key เก็บในไฟล์ .env เพื่อความปลอดภัย
- Sub-agents เหมือนสั่งอาหารให้ครัวปรุงเบื้องหลัง (ประหยัด context) ส่วน skills เหมือนเชฟปรุงตรงหน้า (เห็นทุกขั้นตอน) และ agent teams แบ่งงานให้หลายเอเจนต์ทำขนานกันได้เร็วขึ้น
- แนวคิดเสริม: extended thinking (คิดก่อนตอบ) checkpoints (ย้อนโค้ดแบบ undo) GitHub (สำรองและ deploy โค้ด) scheduled tasks (งานตามตารางเวลา) และ terminal (ใช้ Claude จากกล่องดำ)

## ความเห็นสรุป

วิดีโอนี้เหมาะมากสำหรับมือใหม่ที่งงกับศัพท์และแนวคิดรอบตัว Claude Code เพราะอธิบายด้วยการเปรียบเทียบในชีวิตจริง (file system = Google Drive context window = ความจำมนุษย์ sub-agent = สั่งอาหาร) จนเข้าใจได้โดยไม่ต้องมีพื้นเทคนิคเลยครับ. ครอบคลุมแนวคิดได้ค่อนข้างครบตั้งแต่พื้นฐานจนถึงระดับกลาง แม้แต่ละหัวข้อจะลึกแค่ภาพรวม แต่ก็เพียงพอให้ผู้ชมรู้ว่าอะไรคืออะไรและไปต่อที่ไหนได้ครับ.
