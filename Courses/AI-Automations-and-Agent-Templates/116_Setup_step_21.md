## บทนำ
วิดีโอนี้เป็นขั้นตอนการเผยแพร่คอนเทนต์ที่สร้างเสร็จแล้ว โดยเริ่มจากเผยแพร่ตรงไปยัง LinkedIn ผ่าน n8n เนื่องจากมีการเชื่อมต่อโดยตรง จากนั้นตั้งค่า webhook เพื่อส่งข้อมูลไปยัง make.com เพื่อเผยแพร่ไปยัง Facebook และ Instagram พร้อมทั้งเชื่อมต่อบัญชี Google Sheets และ Telegram เพื่อบันทึกผลการเผยแพร่

## คำแปลเต็ม

ขั้นตอนถัดไปของเราคือการเผยแพร่คอนเทนต์ที่เราเพิ่งสร้างเสร็จ และมีสองขั้นตอนที่ต้องทำ เราจะเผยแพร่ตรงไปยัง LinkedIn ผ่าน n8n เพราะมันมีการเชื่อมต่อโดยตรง ทำให้ง่ายขึ้น แต่ในการเผยแพร่ไปยังแพลตฟอร์มอื่น ๆ เราจะสลับไปใช้แพลตฟอร์มอื่นที่ชื่อว่า make.com แต่เราจะตั้งค่าอันนี้ให้เสร็จก่อน แล้วค่อยสลับไปแพลตฟอร์มอื่น

ขั้นตอนถัดไปคือตรงนี้: เราต้องดาวน์โหลดรูปภาพ เพื่อให้สามารถเผยแพร่ไปยัง LinkedIn ได้ ซึ่งจำเป็นต้องใช้ตรงนี้ ตอนนี้สิ่งที่คุณต้องทำคือ เชื่อมต่อบัญชีของคุณ คลิกที่ Create Credential ผมข้ามส่วนนี้ไป เพราะผมไม่อยากเชื่อมต่อบัญชีองค์กร แต่จะใช้บัญชี LinkedIn ส่วนตัวของผม ตรงนี้คุณแค่ต้องเข้าสู่ระบบด้วย LinkedIn ปกติของคุณ แล้วเมื่อทำเสร็จ บัญชีนี้จะแสดงอยู่ในรายการตรงนี้ แล้วคุณจะเห็นชื่อของคุณปรากฏตรงนี้ ซึ่งเป็นชื่อบุคคล ดังนั้นคุณอาจต้องรีเฟรชถ้ามันไม่ขึ้นในตอนแรก คุณรีเฟรดแล้วมันควรแสดงชื่อที่เชื่อมโยงกับบัญชี LinkedIn ที่คุณเชื่อมต่อไว้

ตรงนี้คือคอนเทนต์ของ LinkedIn เราต้องแมปมันให้ถูกต้องตรงนี้ ลากตัวแปร LinkedIn เข้ามา แล้วจากนั้นนี่คือสิ่งที่ต้องทำ แค่นั้นเอง ดังนั้นถ้าผมคลิก execute มันควรส่งโพสต์ไปยัง LinkedIn ทันที มันดูดี และตรงนี้บน LinkedIn ผมเห็นว่าโพสต์ถูกเผยแพร่แล้ว ดังนั้นมันทำงานได้

และตอนนี้มาถึงส่วนถัดไป ตรงนี้เรามี webhook webhook คือ: เราใช้ webhook เมื่อใดก็ตามที่เราต้องการส่งข้อมูลบางอย่างไปยังเครื่องมืออื่นหรือระบบอื่น ซึ่งเป็นสิ่งที่เรากำลังจะทำ นั่นคือเหตุผลที่คุณไปตรงนี้ แล้วตรงนี้คุณคลิกที่ make.com ก่อน อันนี้จะเปิดหน้าต่างนี้ขึ้นมา คุณสามารถสมัครบัญชีฟรีได้ถ้ายังไม่มีบัญชี แล้วจากนั้นคุณไปที่ scenarios คลิกที่ create a new scenario แล้วจากนั้นเราไปที่การดาวน์โหลด make blueprint ซึ่งคุณจะพบได้ด้านล่างวิดีโอนี้ แล้วเราดาวน์โหลดมัน แล้วตรงนี้เราคลิกที่ import select file แล้วเราก็เลือกไฟล์ที่เพิ่งดาวน์โหลดมา แล้วอัปโหลดระบบอัตโนมัตินี้ ซึ่งเราสามารถเผยแพร่ไปยังแพลตฟอร์มต่าง ๆ ได้ เพราะมันมีการเชื่อมต่อโดยตรง และรวมถึง Twitter ด้วย แต่ Twitter ต้องใช้เครื่องมืออื่นเพิ่มเติม และนี่คือเหตุผลที่เรามีขั้นตอนติดตั้งที่สาม ซึ่งผมจะโชว์วิธีใช้ Twitter อย่างละเอียดถ้าคุณต้องการใช้ ในวิดีโอนี้เราจะโฟกัสที่การตั้งค่า Facebook Pages และ Instagram

ขั้นตอนแรกที่คุณต้องทำคือคลิกที่ add webhook แค่คลิก save แล้วจากนั้นสิ่งที่ต้องทำคือ เข้าไปตรงนี้ แล้วเราต้องแทรกข้อมูลก่อน คัดลอกที่อยู่แล้ววางลงตรงนี้ อันนี้จะส่งคอนเทนต์ Facebook ไปยังคอนเทนต์และ Instagram รวมถึง URL รูปภาพไปยังระบบอัตโนมัตินี้ และนี่คือข้อมูลที่เราต้องการเพื่อให้มันถูกเผยแพร่ คลิก แค่นั้นเอง

ตอนนี้เราต้องไปที่ Facebook และตรงนี้คุณต้องคลิกที่ add a page ที่คุณเป็นผู้ดูแล (administrator) แล้วคุณจะถูกขอให้เข้าสู่ระบบด้วยบัญชี Facebook ของคุณ และเมื่อทำครบแล้ว คุณก็ไปต่อตรงนี้ได้ และตรงนี้เราก็มี Google Sheets ด้วย คุณต้องสร้างการเชื่อมต่อ Google Sheet คลิกที่ Sign in with Google โดยใช้บัญชีเดียวกับที่เก็บ Google Sheet นี้ แล้วมันจะโหลดชีตนี้ขึ้นมา ในกรณีของผม ผมมี demo 6 ผมก็พิมพ์ demo 2.6 ตรงนี้แล้วมันก็แสดงขึ้นมา เยี่ยม

และทั้งหมดนี้จริง ๆ แล้วมันแค่เขียนวันที่เผยแพร่ลงในคอลัมน์ที่ผมเตรียมไว้ แล้วจากนั้นเราก็มี Telegram bot อีกครั้ง ตรงนี้คุณทำเหมือนเดิม ไปที่ add แล้วเพิ่ม access token ของคุณ คุณอาจต้องกลับไปที่ไฟล์ที่คุณสร้าง access token ไว้แล้วคัดลอกมัน มันเป็นโทเคนเดียวกันกับที่คุณใช้ตอนเชื่อมต่อโมดูลครั้งแรก เราอยากใส่มันไว้ตรงนี้ด้วย เพราะเราต้องการบันทึกการยืนยันกลับมาว่าโพสต์ถูกเผยแพร่แล้วลงในชีตนี้ และนั่นคือเหตุผลที่เราใช้มัน

และผมอยากทำให้ชีวิตของผมง่ายขึ้นอีกหน่อย เพราะโมดูลเหล่านี้มักจะเหมือนกันเกือบตลอด ผมสามารถคัดลอกและวางมันลงตรงนี้ได้ สิ่งเดียวที่ต้องเปลี่ยนคือตรงนี้ publish successfully to Instagram และ publish successfully to Twitter มาคลิก save กัน ตอนนี้มาเชื่อมต่อ Instagram กัน

ในการเชื่อมต่อ Instagram คุณต้องไปที่ Facebook ก่อน จากนั้นไปที่เพจที่คุณเป็นผู้ดูแล แล้วคลิกที่ switch page สลับเพจ แล้วจากนั้นคุณต้องไปที่การตั้งค่าของเพจนี้ และตรงหัวข้อ linked accounts คุณต้องเชื่อมต่อบัญชี Instagram ถ้ายังไม่มีบัญชี Instagram คุณต้องทำตอนนี้ คลิกที่มัน แล้วคุณสามารถเข้าสู่ระบบด้วยบัญชีที่คุณต้องการเผยแพร่ไป เมื่อทำเสร็จแล้วคุณสามารถคลิก แล้วคุณจะถูกขอให้เข้าสู่ระบบ Facebook และเมื่อทำครบแล้ว มันจะโหลดอันนี้ แล้วคุณสามารถเลือกเพจได้ ซึ่งในกรณีนี้คือบัญชี Instagram ที่คุณต้องการเผยแพร่ไป ซึ่งเชื่อมต่อกับ Facebook Page ที่คุณเพิ่มไว้ตรงนี้

เพิ่ม URL และข้อความคำบรรยาย (caption) ตรงนี้ยังว่างอยู่เพราะเรายังไม่ได้ทดสอบ แต่ผมอยากทดสอบตอนนี้ ยกเลิกการเชื่อมโยงโพสต์ Twitter เพราะมันยังไม่ได้ตั้งค่า เราจะตั้งค่าในวิดีโอถัดไป คลิก save ตอนนี้คลิก run once กลับไปที่ webhook ของเราตรงนี้ เราจะคลิก execute step แล้วตอนนี้คุณจะเห็นว่ามันส่งข้อมูลนี้ไปแล้ว มันส่ง URL รูปภาพและ chat ID ซึ่งสำคัญมากเพื่อรับข้อความยืนยันกลับมาใน Telegram รับข้อความยืนยันกลับมาใน Telegram คุณเห็นว่ามันถูกเผยแพร่ไปยัง Facebook สำเร็จ และถูกเผยแพร่ไปยัง Instagram แล้ว มาดูกัน

ตรงนี้ผมเห็นว่ามันถูกเผยแพร่แล้ว แต่ไม่มีคำบรรยาย ถ้าคุณเข้าไปดู ข้อความคำบรรยายไม่ได้ถูกแมป เราต้องจับคู่มันกับค่าเฉพาะเหล่านี้ นี่คือ Facebook ผมต้องคลิกอันนี้ แล้วตรงนี้เราต้องแมปมันกับ Instagram เมื่อถึงเวลาที่คุณดูวิดีโอนี้ ผมคงแก้ไขให้แล้ว คุณจะไม่ต้องจับคู่ด้วยมืออีกต่อไป แต่อย่างไรก็ตาม มันทำงานได้ และการตั้งค่าแพลตฟอร์มทั้งสองนี้ก็เสร็จสมบูรณ์
