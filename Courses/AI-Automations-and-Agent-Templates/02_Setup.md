## บทนำ
วิดีโอนี้เป็นขั้นตอนแรกของการตั้งค่าระบบโซเชียลมีเดียอัตโนมัติ เริ่มจากการดาวน์โหลด blueprint และนำเข้าใน Make.com จากนั้นตั้งค่าโมดูลต่าง ๆ ทีละตัว ได้แก่ Google Sheets, OpenAI, Perplexity, โมดูลสร้างรูปภาพ และโมดูลโซเชียลมีเดีย (Twitter, Facebook, Instagram, LinkedIn) รวมถึงการกำหนดเวลารันระบบอัตโนมัติ

## คำแปลเต็ม

ขั้นตอนแรกในการตั้งค่าระบบโซเชียลมีเดียอัตโนมัติของคุณคือการดาวน์โหลด automation blueprint คุณจะพบปุ่มนี้ด้านล่างวิดีโอ แล้วเข้าไปที่บัญชี Make ของคุณ ถ้าคุณยังไม่มีบัญชี Make คุณต้องสมัครบัญชีฟรี แล้วคลิก create จากนั้นไปที่จุดสามจุดเหล่านี้ แล้วคลิก import blueprint แล้วเลือกไฟล์ที่คุณเพิ่งดาวน์โหลด แล้วคลิก save

แต่งานยังไม่เสร็จสิ้น เพราะตอนนี้เราต้องตั้งค่าโมดูลทั้งหมดเหล่านี้ด้วยการเชื่อมต่อเฉพาะของคุณ และเราจะเริ่มจากจุดเริ่มต้นตรงนี้

ตรงนี้เรามีโมดูล Google Sheets ดังนั้นคุณต้องเลือกบัญชี Google Sheets และตั้งค่าการเชื่อมต่อกับ Google Sheets แต่ก่อนอื่น คุณต้องคลิกที่ Google Sheet นี้ เพราะนี่คือ Google Sheet ที่เราจะใช้ในระบบอัตโนมัตินี้ คลิกที่ create แล้ว make a copy จากนั้นสำเนาของ Google Sheet นี้จะถูกสร้างในบัญชี Google ที่คุณเข้าสู่ระบบอยู่

จากนั้นคุณสามารถตั้งชื่อได้ คุณสามารถบุ๊กมาร์กไว้เพื่อให้มีไว้ หรือบันทึกลิงก์ไว้ก็ได้ เพราะนี่คือที่ที่เราจัดการกระบวนการอัตโนมัติทั้งหมด นี่เหมือนกับหน้าด้านหน้าของระบบอัตโนมัติ

ตอนนี้เราต้องตั้งค่าชีตนี้ และถ้าเรากลับไปที่ระบบอัตโนมัติ คุณต้องเพิ่มบัญชี Google ของคุณ คลิกที่ Add แล้วคลิก Sign in with Google แล้วทำขั้นตอนการเข้าสู่ระบบให้เสร็จ และเมื่อระบบให้เลือกบัญชี Google ถ้าคุณมีหลายบัญชี ให้แน่ใจว่าเป็นบัญชีเดียวกับที่เก็บ Google Sheet นี้อยู่ คุณไปที่รูปโปรไฟล์หรือไอคอนตรงมุมบน แล้วคลิก แล้วคุณจะเห็นว่าคุณเข้าสู่ระบบด้วยบัญชี Google ไหน แล้วคุณต้องเลือกบัญชีเดียวกันในขั้นตอนนี้

ผมจะทำขั้นตอนนี้ให้เสร็จ แต่จะไม่แสดงให้ดู เพราะผมมีหลายบัญชี Google และมันเป็นข้อมูลที่ละเอียดอ่อน ดังนั้นทำการตั้งค่าให้เสร็จ แล้วเราไปต่อ

ตอนนี้ผมเห็นว่ามันบอกว่า Google Sheet connection ถ้าคุณเห็นข้อความนี้ แสดงว่าทุกอย่างทำงานแล้ว เราต้องใส่ Google Sheet ID ของคุณ คุณจะพบมันตรงนี้ใน URL ของ Google Sheet ของคุณ ในส่วนนี้ อย่าลืมคัดลอกและวางมันตรงนี้ และถ้าทำถูกต้องแล้ว ให้คลิกเพื่อรีโหลดชีตนี้ และถ้าทำถูกต้อง มันจะโหลดชีตทั้งหมดขึ้นมา

จากนั้นเราเลื่อนไปที่ส่วนนี้ และตรง filter เราต้องเลือก topic ก่อน เพราะมันเรียกว่าแบบนั้น จากนั้น subtopic จะถูกเลือก และเราไม่ต้องทำอะไรเพิ่ม ตอนนี้โมดูลนี้ถูกตั้งค่าแล้ว

ก่อนที่เราจะเลือกตัวแปรที่ถูกต้อง เราต้องรันอันนี้ก่อน และการทำแบบนี้เราจะยกเลิกการเชื่อมโยงมัน แล้วคลิก แล้วคลิก run once และตอนนี้คุณจะเห็นว่าไม่มี error และตอนนี้ผมมีตัวเลือกเหล่านี้ และผมสามารถเชื่อมต่อมันได้ แล้วคุณจะเห็นว่า subtopic หรือตัวแปรถูกเลือกอย่างถูกต้อง

ไปที่สิ่งถัดไป คุณไม่ต้องเพิ่มบัญชี Google ใหม่เพราะคุณทำแค่ครั้งเดียว ตรงนี้คุณไปที่ dropdown แล้วเลือกบัญชี Google ที่คุณใช้สมัครไว้เพื่อเชื่อมต่อโมดูลนี้ และตอนนี้คุณสามารถเลือกการเชื่อมต่อทั้งหมดนี้ได้อีกครั้งใน dropdown และเมื่อทำเสร็จแล้ว ให้วาง Google Sheet ID ของคุณอีกครั้ง คุณต้องทำกระบวนการเดียวกันนี้กับโมดูล Google ทั้งหมด

จากนั้นผมต้องไปที่ dropdown และเลือก input เสร็จแล้ว มาทำกัน ไปที่โมดูลถัดไปคือโมดูล OpenAI ตรงนี้คุณต้องสร้างการเชื่อมต่อด้วย คลิก create connection จากนั้นไปเอา API key และ organization ID ของคุณ ถ้าคุณยังไม่มีบัญชี OpenAI ให้ไปที่ส่วนบทช่วยสอนทางเทคนิค แล้วคุณจะพบหัวข้อ get your OpenAI API key ทำตามขั้นตอนนั้น แล้วกลับมาตรงนี้ แล้วใส่คีย์ของคุณ เมื่อเสร็จแล้วคุณจะเห็นการเชื่อมต่อ OpenAI ของผม จากนั้นไปต่อได้ ไม่ต้องทำอะไรเพิ่ม อันนี้ตั้งค่าไว้แล้ว แค่คลิก OK

อีกหนึ่ง Google Sheet ตรงนี้คุณต้องเลือกบัญชีของคุณอีกครั้ง จากนั้นผมต้องใช้ Google Sheet ID ผมมีอันนี้ตรงนี้ นี่คือ Google Sheet ID วางมันตรงนี้ ในชีตผมต้องเลือก topic อันนี้ แล้วส่วนที่เหลือจะถูกโหลดโดยอัตโนมัติ ตรงนี้ผมต้องใส่ค่านั้น ซึ่งในกรณีนี้มาจาก topic content คลิก OK

ต่อไปเป็นโมดูล Perplexity ตรงนี้คุณต้องเอา API key มาเช่นกัน และคุณจะพบมันในหัวข้อ technical: get your perplexity API key เอา key มาแล้วกลับมาใส่ตรงนี้ เมื่อเสร็จแล้วคลิก OK ไปที่สิ่งถัดไป

ตรงนี้เรามีการเชื่อมต่อ OpenAI คุณแค่เลือก connected account อันนี้ตั้งค่าไว้แล้ว ไม่ต้องทำอะไรตรงนี้ เราทำแบบนี้กับโมดูลทั้งหมดเหล่านี้ เอาล่ะ เหมือนกันกับอันนี้ เอาล่ะ เอาล่ะ คลิก OK

ตอนนี้มาถึงโมดูล Google Sheets อีกตัวที่ต้องตั้งค่า เลือกบัญชีของคุณ วาง Google Sheet ID ตรงนี้ ชื่อชีตควรถูกเลือกไว้แล้ว Twitter ใช่ ตรงนี้ผมต้องใส่ output จากโมดูลก่อนหน้าหรือโมดูลสร้างโพสต์ ซึ่งก็คือ content และผมต้องทำขั้นตอนเดียวกันนี้กับโมดูล Google Sheets ทั้งหมดตอนนี้

ผมจะแสดงให้ดูอีกครั้งหนึ่ง เลือกบัญชี Google วาง Google Sheet ID และตรงนี้ในช่องข้อความใส่อันนี้ save ตอนนี้ทำกับโมดูลอื่น ๆ ด้วย มาทำกัน ID, Message, Choices เหมือนกัน ตอนนี้อันนี้ content คลิก save เรายังบันทึกไม่ได้ตอนนี้ เพราะเราต้องตั้งค่าทั้งหมดก่อน

ตอนนี้มาถึงโมดูล OpenAI สำหรับสร้างรูปภาพอีกครั้ง เอาล่ะ เลือกการเชื่อมต่อ เอาล่ะ เอาล่ะ และเครื่องมือนี้ มาดูกันว่าเราบันทึกได้หรือยัง เราต้องเชื่อมต่อโมดูล Google Sheets ทั้งหมดก่อนจึงจะบันทึกได้ มาทำ Google Sheets อีกครั้ง วาง Google Sheet ID หมายเลขแถวตรงนี้มา แล้วจากโมดูลสร้างรูปภาพเราจะได้รูปภาพซึ่งเป็น URL เอาล่ะ

เหมือนกันกับอันนี้ วาง Google Sheet ID ตรงนี้มาเป็นลิงก์รูปภาพอีกครั้ง เอาล่ะ เหมือนกันตรงนี้ Google Sheet ID รูปภาพ URL และโมดูล Google Sheets อันสุดท้ายของเรา Google Sheet ID และ URL

ตอนนี้โมดูล HTTP ถูกตั้งค่าไว้แล้ว ตอนนี้คุณต้องตั้งค่าโมดูล Twitter ผมจะไม่แสดงวิธีสร้างการเชื่อมต่อแบบละเอียด ให้ไปที่บทช่วยสอนทางเทคนิคแล้วดูว่าคุณหาข้อมูลได้จากที่ไหน สิ่งที่ผมจะแสดงคือจะหาข้อมูลเหล่านี้ได้จากที่ไหน

คุณต้องมี Twitter developer account และอย่างที่ผมพูดในหัวข้อเทคนิค ผมจะแสดงบทช่วยสอนสั้น ๆ วิธีตั้งค่า developer account และคุณต้องสร้างโปรเจกต์ใหม่ในนั้นด้วย และในโปรเจกต์นั้น คุณไปที่หน้านี้ภายใต้ keys and tokens ตรงนั้นคุณจะได้ API key และ API secret และนี่คือสิ่งที่คุณต้องใช้ในการตั้งค่า

ในการตั้งค่า คุณต้องไปที่ advanced แล้วใส่ API key และ API secret และเพื่อให้ได้คีย์เหล่านี้ ผมเข้าไปตรงนี้แล้วคลิก regenerate แล้วผมจะได้คีย์เหล่านี้ และคุณต้องทำแบบนี้สำหรับโมดูลนี้ และทำแบบนี้กับโมดูลนี้ด้วย แต่ตรงนี้คุณต้องใช้ client ID และ client secret คุณจะพบสิ่งนี้ในบัญชีของคุณตรงนี้ด้านล่าง Client ID แล้วตรงนี้คุณต้องคลิก regenerate แล้วคุณจะสร้าง client secret ของคุณ แล้วคลิก save จากนั้นโมดูล Twitter ก็ถูกตั้งค่าแล้ว

สำหรับ Facebook page มันง่ายมากเช่นกัน ง่ายมาก คุณทำตามขั้นตอนนี้ คุณไม่ต้อง... คลิก save แล้วระบบจะให้เข้าสู่ระบบบัญชี Facebook ของคุณ และคุณต้องเป็นแอดมินในบัญชี Facebook นั้น จากนั้นเลือกมันแล้วตั้งค่าได้

สำหรับ Instagram มันเป็นกระบวนการคล้าย ๆ กัน ตรงนี้คุณต้องไปที่... คุณต้องทำขั้นตอนนี้ให้เสร็จ แต่ก่อนอื่นคุณต้องไปที่ Facebook แล้วไปที่เพจที่คุณต้องการใช้ เข้าสู่ระบบ แล้วคุณต้องแน่ใจว่าคุณเชื่อมต่อเพจ Facebook กับบัญชี Instagram แล้ว คุณถึงจะใช้โมดูลนี้ได้

การทำแบบนี้คุณต้องไปที่ settings แล้วเลื่อนลงไปที่ connected accounts ในภาษาอังกฤษเรียกว่า connected accounts และตรงนี้คุณจะเห็นว่ามันเชื่อมกับบัญชี Instagram แล้ว ถ้ายังไม่เชื่อม คุณจะเห็นปุ่ม connect to Instagram แล้วทำตามขั้นตอน แล้วเมื่อเสร็จแล้วมันจะมีลักษณะแบบนี้ และเมื่อคุณทำขั้นตอนนี้เสร็จแล้ว กลับมาตรงนี้แล้วทำขั้นตอนนี้ให้เสร็จ มันก็จะทำงาน

และสำหรับ LinkedIn นี่ตรงไปตรงมามาก แค่ทำตามขั้นตอนที่ให้เข้าสู่ระบบบัญชี LinkedIn ของคุณ แล้วเข้าสู่ระบบให้เสร็จ แล้วโมดูลเหล่านี้ก็ถูกตั้งค่าทั้งหมด แล้วคลิก save แล้วคุณก็รันได้ เพราะผมยังไม่ได้ตั้งค่าไว้ แต่ผมแสดงวิธีทำแล้ว

และเมื่อคุณตั้งค่าทั้งหมดนี้แล้ว หรือคุณสามารถตั้งค่าเฉพาะบัญชีโซเชียลมีเดียที่คุณต้องการก็ได้ ถ้าคุณต้องการโพสต์บน Twitter และอื่น ๆ คุณก็แค่กด Shift แล้วลบโมดูลเหล่านั้น แล้วคุณจะเหลือแค่โมดูลที่ต้องการ นี่คือวิธีเลือกแพลตฟอร์มที่คุณต้องการโพสต์

และขั้นตอนสุดท้ายคือคุณสามารถเลือกได้ว่าระบบอัตโนมัตินี้ควรทำงานเมื่อไหร่ ควรทำงานทุกวันไหม? ควรทำงานเวลาไหน? วันไหนของสัปดาห์? จากนั้นมันจะทำงานและสร้างโพสต์และรูปภาพต่าง ๆ

แต่ก่อนที่คุณจะตั้งค่านี้ ผมแนะนำให้คุณรันมันสักสองสามครั้งก่อน แล้วดูว่าคุณได้โพสต์แบบไหน รูปภาพแบบไหนที่ถูกสร้าง จากนั้นคุณอาจปรับแต่งเล็กน้อย อาจแก้ไข prompt ตรงนี้ และปรับให้เข้ากับกลุ่มเฉพาะของคุณ นี่คือวิธีตั้งค่าระบบนี้
