## บทนำ
วิดีโอนี้สอนวิธีปรับแต่งระบบให้บล็อกโพสต์หนึ่งบทความถูกแยกออกเป็นพีดโซเชียลมีเดียมากกว่าสามพีดตามค่าเริ่มต้น โดยเพิ่มประเภทพีดใหม่ (เช่นแบบผลลัพธ์/result) คัดลอกโมดูลที่มีอยู่ ปรับแต่ง prompt และเชื่อมต่อสาขาใหม่ เพื่อให้บล็อกโพสต์แตกเป็นพีดได้สี่ หก หรือเจ็ดแบบตามที่ต้องการ

## คำแปลเต็ม

ในวิดีโอนี้ผมจะแสดงวิธีทำให้บล็อกโพสต์ของคุณถูกแยกออกเป็นหลายพีด ตอนนี้ตามค่าเริ่มต้น ถ้าคุณใช้ระบบนี้ มันจะถูกแยกออกเป็นสามพีดสำหรับโซเชียลมีเดีย เพราะเรามีสามสาขาที่แตกต่างกันตรงนี้ แล้วถ้าผมอยากเพิ่มอีกหนึ่งสาขาล่ะ?

สิ่งแรกที่ผมทำคือ ผมต้องกำหนดว่าประเภทพีด (post type) จะเป็นอะไร สมมติว่ามันเรียกว่า result จากนั้นผมต้องหาเทมเพลตที่สอดคล้องกัน ผมดูพีด Instagram ของผมเกี่ยวกับเรื่องส่วนตัว ซึ่งน่าจะเป็นต้นแบบที่ดีได้ ขึ้นอยู่กับว่าบล็อกโพสต์นั้นอิงจากผลลัพธ์หรือไม่ แต่อย่างน้อยผมจะแสดงให้ดูว่ามันทำงานอย่างไรพื้นฐาน คุณสามารถคิดเองได้ว่าพีดโซเชียลมีเดียแบบไหนที่เหมาะสมที่สุดสำหรับคุณ

ตอนนี้ผมได้เพิ่มประเภทพีดที่สี่แล้ว ซึ่งบล็อกของผมสามารถแยกออกได้เป็นแบบนี้ และสิ่งที่ผมทำคือ ผมกดปุ่ม shift บนคีย์บอร์ดของผม จากนั้นคลิก copy modules แล้วก็แค่คลิกตรงนี้ แล้วคลิก paste จากนั้นผมก็มีสาขาใหม่ ซึ่งผมสามารถเชื่อมต่อได้ แล้วตรงนี้มันจะรับข้อมูลมา

ผมต้องกำหนดว่ามันอยู่ตรงไหน มันอยู่ในคอลัมน์ B แถวที่ห้าของชีต post templates ซึ่ง post templates เชื่อมต่อไว้แล้ว มันอยู่ในคอลัมน์ B แถวที่ห้า และผมต้องการเปลี่ยนชื่อมัน ตอนนี้มันเรียกว่า result ลองอีกครั้ง แล้วเปลี่ยนชื่อเป็น result

ทีนี้ส่วนนี้คือ prompt ซึ่งจะเปลี่ยนบล็อกโพสต์ให้เป็นพีดแบบอิงผลลัพธ์ (result-based post) โดยพื้นฐาน คุณต้องปรับแต่งเล็กน้อย ตรงนี้มันรับบทความบล็อกมา ผมบอกว่าคุณต้องดูบทความ จากนั้นคุณต้องสร้าง แล้วคุณต้องระบุผลลัพธ์ที่น่าสนใจที่สุดที่กล่าวถึงในบล็อกโพสต์ เพื่อให้ได้พีดที่เน้นผลลัพธ์ แล้วก็จะได้หนึ่งในสามแบบนั้น แน่นอนว่าคุณสามารถปรับให้ดีขึ้นได้อีก

ลองดูโมดูลอื่น ๆ ตรงนี้ ผมต้องไปที่ post style มันคือ result และอันนี้ถูกเลือกไว้แล้ว มันเป็นอันที่ถูกต้องแล้ว ใช่ นี่คือผลลัพธ์จากอันนี้ ดี จากนั้นโมดูลนี้จะสร้างพีดโซเชียลมีเดียจากบล็อก และตรงนั้นผมไม่ต้องเปลี่ยนอะไรเลย เพราะเทมเพลตและหัวข้อถูกกำหนดไว้แล้วเท่านั้น มันเป็นแบบนี้ ดี ผมแค่เปลี่ยนชื่อเป็น result และผมคิดว่าชีตถูกต้องแล้ว ดี

ตอนนี้คลิก save แล้วคุณจะเห็นว่าผมสามารถจัดวางมันได้ตรงนี้ ตอนนี้บล็อกโพสต์ของผมถูกแยกออกเป็นสี่พีดโซเชียลมีเดียที่แตกต่างกัน และตอนนี้ผมสามารถรันมันได้ สิ่งที่ผมจะทำเพื่อทดสอบก็คือ ผมจะปลดลิงก์สาขาเหล่านั้นออก เพราะผมไม่ต้องการทดสอบสาขาเหล่านั้น ผมทดสอบไปแล้ว

และสิ่งที่ผมทำคือ ผมกลับไปที่บล็อกโพสต์ของผม ทำให้แน่ใจว่ามันเปิดใช้งานอยู่ ดี บันทึกการเปลี่ยนแปลงตอนนี้ แล้วคลิก run เพื่อให้ง่ายขึ้น คลิก generate และตอนนี้มันควรจะแยกหรือระบุ ตรงนี้มันพยายามหาผลลัพธ์ของบล็อกโพสต์ มันขึ้นอยู่กับว่าบล็อกนั้นมีผลลัพธ์หรือไม่ แต่แล้วมันก็จะพยายามหามันให้เจอ

ตรงนี้มันบอกว่า คุณเห็นไหม แล้วมันก็ดูเหมือนว่า หนึ่งในผลิตภัณฑ์ของผมใช้เวลาสร้างน้อยลงห้าเท่า และนี่คือวิธีการที่มันทำงานเป็นพีดแบบอิงผลลัพธ์ มันยังสร้างรูปภาพให้ด้วย และนั่นคือทั้งหมด

และนี่คือวิธีที่ผมขยายมันได้ ดังนั้นถ้าผมต้องการ ผมสามารถเพิ่มพีดที่หกหรือเจ็ดได้ ผมสามารถทำให้บล็อกโพสต์ของผมถูกแยกออกเป็นพีดโซเชียลมีเดียหกหรือเจ็ดแบบที่แตกต่างกัน และคุณก็ทำได้โดยใช้กระบวนการเดียวกันกับที่ผมเพิ่งแบ่งปันให้คุณดู
