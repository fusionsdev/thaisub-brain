# สรุป: NEW BTL-4 35B and Macaw 2.7B AI AGENT are HERE! 🤯
- **ช่อง:** Julian Goldie SEO · **ความยาว:** ~8 นาที · **ลิงก์:** https://www.youtube.com/watch?v=Lyi0NNo95bo

## ประเด็นหลัก
- Bad Theory Labs ปล่อยโมเดล AI สองตัว: BTL-4 35B (โมเดลคิด/วางแผน) และ Macaw 2.7B (โมเดลลงมือทำ) ทำงานแบบ local ทั้งคู่ ไม่ส่งข้อมูลขึ้นคลาวด์
- BTL-4 35B เป็นโมเดล open weights แบบ reasoning เน้นการใช้งานเครื่องมือ วางแผนบริบทยาว และงานหลายขั้นตอน
- คะแนน benchmark: SWE-Bench verified 78.4% และ BFCL V4 (วัดการเรียกใช้เครื่องมือ/action chaining) 73.5%
- BTL-4 มี context window ขนาด 262,000 token เก็บ project brief, คอนเทนต์ backlog, บันทึกชุมชน และเอกสารกลยุทธ์ได้พร้อมกัน
- การเพิ่ม output budget จาก 16K เป็น 32K token ทำให้ผลลัพธ์ในงานยากดีขึ้นอย่างเห็นได้ชัด
- Macaw 2.7B ตัวเล็ก (~1.5 GB บนดิสก์, ใช้แรม ~2 GB) บน Apple M2 ตอบกลับใน ~2 วินาทีต่อคำขอ ควบคุม Mac ได้จริง
- Macaw เปิดแอป อ่านเอกสารบนหน้าจอ จัดระเบียบโฟลเดอร์ และต่อเครื่องมือ macOS ที่ผ่านการตรวจสอบแล้ว 97 ตัวจากพรอมป์เดียว ไม่ต้องใช้ API key
- การจับคู่: BTL-4 คือสมอง (วางแผน/คิด) + Macaw คือมือ (ลงมือทำ) = AI local ที่ทำงานซับซ้อนจบในเครื่องของตัวเอง
- ตัวอย่างจริง: สร้างสคริปต์ YouTube, โพสต์ LinkedIn, ประกาศชุมชน จากกระทู้ประจำสัปดาห์ แล้วให้ Macaw จัดการไฟล์/เปิดแอปโดยไม่ต้องแตะ Finder
- ตัวอย่างโค้ชชิ่งคอล: จัดกลุ่มคำถามสมาชิก 18 ข้อเป็นธีม + เขียน brief ใช้ได้ทันที จากเดิม 2 ชั่วโมงเหลือ ~10 นาที
- ข้อจำกัด: การตั้งค่ายังต้องคุ้นเคยกับเครื่องมือเทคนิคมากกว่าการสมัครคลาวด์ แต่ทิศทางชัดเจนว่า local AI กำลังใช้งานได้จริง
- ปลายทาง: ชวนเข้าร่วม AI Profit Boardroom (aiprofitboardroom.com) และ AI Success Lab สำหรับโน้ตเต็ม + 100+ กรณีใช้งาน AI automation

## ความเห็นสรุป
วิดีโอนี้ให้ภาพรวมที่ชัดเจนและใช้งานได้จริงของชุด AI แบบ local รุ่นใหม่ ที่แยกบทบาท "คิด" และ "ลงมือทำ" ออกจากกันอย่างชาญฉลาด จุดแข็งคือการยกตัวอย่าง workflow จริง (คอนเทนต์ + โค้ชชิ่งคอล) พร้อมพรอมป์ตัวอย่าง ทำให้ผู้ชมเห็นคุณค่าทางธุรกิจทันที แม้เนื้อหาช่วงท้ายจะเป็นการโปรโมตชุมชน AI Profit Boardroom และ AI Success Lab เป็นหลัก แต่ข้อมูลเทคนิคของโมเดลก็มีประโยชน์ต่อคนที่สนใจสร้าง AI agent ในเครื่องของตัวเอง
