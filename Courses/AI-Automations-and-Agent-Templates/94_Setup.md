## บทนำ
วิดีโอนี้สอนวิธีตั้งค่า AI agent สำหรับเว็บไซต์ ที่สามารถติดตั้งบนเว็บไซต์ใดก็ได้ เพื่อให้ตอบคำถามเกี่ยวกับสินค้าและข้อเสนอของคุณ และส่งลิงก์ไปยังหน้าสินค้าให้กับคนที่สนใจ ครอบคลุมตั้งแต่การนำเข้าเทมเพลตใน n8n การเชื่อมต่อ OpenAI และ Google Sheets การตั้งค่าฐานข้อมูล Supabase สำหรับเก็บความทรงจำของการสนทนา ไปจนถึงการฝังแชต widget ผ่าน CodePen และนำไปวางบนเว็บไซต์จริง

## คำแปลเต็ม

ในวิดีโอนี้ผมจะแสดงวิธีตั้งค่า AI agent สำหรับเว็บไซต์ ที่คุณสามารถติดตั้งบนเว็บไซต์ใดก็ได้ ให้มันตอบคำถามเกี่ยวกับสินค้าและข้อเสนอของคุณ และส่งลิงก์ให้คนที่สนใจ เพื่อไปซื้อสินค้าจากหน้าสินค้านั้น ๆ

คุณจะพบลิงก์เทมเพลตของ workflow นี้ด้านล่างวิดีโอ คลิกที่ create จากนั้นคลิกดาวน์โหลด แล้วเราเข้ามาตรงนี้ Import from file ถ้าคุณยังไม่มีบัญชี n8n คุณสามารถสมัครทดลองใช้ฟรีได้ และเมื่อนำเข้าเสร็จแล้ว เราจะทำการเชื่อมต่อโมดูลต่าง ๆ ตรงนี้

โมดูลแรกคือ AI model ตรงนี้คุณต้องเลือกบัญชี OpenAI แล้วคลิก create a new credential แล้วใส่ API key คุณจะพบบทช่วยสอนได้ในหัวข้อ technical: get API key from OpenAI เมื่อทำเสร็จแล้ว ไปที่โมดูลถัดไป

โมดูลถัดไปคืออันนี้ Info sheet คุณจะพบเทมเพลตด้านล่างวิดีโอนี้เช่นกัน ผมจะเปิดมันตรงนี้ แล้วคุณคลิก make a copy จากนั้นเข้ามาตรงนี้ ถ้าคุณยังไม่ได้เชื่อมต่อบัญชี Google Sheets ของคุณ ให้คลิก create credential แล้วเข้าสู่ระบบด้วย Google และถ้าคุณมีหลายบัญชี Google ให้แน่ใจว่าเข้าสู่ระบบด้วยบัญชีเดียวกันกับที่เก็บ Google Sheet นี้ไว้ คุณจะรู้ได้โดยวางเคอร์เซอร์เหนือไอคอนนี้ตรงนี้ ซึ่งเป็นโปรไฟล์ มันจะแสดงให้เห็นว่าเป็นบัญชี Google ไหน

ตรงนี้ผมจะตั้งชื่ออย่างรวดเร็ว แล้วเข้ามาตรงนี้ เมื่อเข้าสู่ระบบแล้วคลิก OK ผมจะปล่อยไว้เพราะผมเข้าสู่ระบบไว้แล้ว จากนั้นคลิกอันนั้น แล้วเลือก Google Sheet ที่คุณเพิ่งสร้าง ตรงนี้เราไปที่ products จากนั้นเราต้องเพิ่มตำแหน่งข้อมูลในชีต: first empty row แค่นั้นเองที่ต้องทำตรงนี้

ตอนนี้กลับไปที่ชีต เพื่อให้ชีตนี้ทำงานได้ คุณต้องมีข้อมูลบางอย่างตรงนั้น: product, product, product หรือ product topic คุณสามารถกรอกเองได้ หรือจะใช้ WhatsApp AI agent sales assistant ก็ได้ เพราะมันมีความสามารถที่คุณแค่ส่งลิงก์ให้ AI agent นี้ แล้วมันจะกรอกข้อมูลอื่น ๆ ให้ทั้งหมด และดึงราคาสินค้ามาให้ คำอธิบาย หัวข้อ จากแค่การส่งลิงก์ จากนั้นมันจะกรอกลงใน Google sheet เดียวกัน ผมทำไว้แล้ว ผมจะดึงข้อมูลเหล่านี้จาก Google sheet อื่น ๆ เกี่ยวกับสินค้าของผม แล้วคัดลอกวางลงมาตรงนี้

เราต้องไปที่โมดูลสองอันนี้ store memory นี่คือที่เก็บข้อมูลเกี่ยวกับการแชตของเรา ดังนั้นเมื่อใดก็ตามที่มีคนโต้ตอบกับแชตหรือ AI ของเรา มันจะเก็บบทสนทนาหรือข้อมูลเชิงลึกที่ได้เรียนรู้ลงในความทรงจำ ทุกการโต้ตอบ และการทำแบบนี้เราใช้ Supabase ซึ่งเป็นเครื่องมือฐานข้อมูลที่คุณใช้ได้ คุณแค่คลิก create a new credential และผมมีบทช่วยสอนให้คุณในหัวข้อ Get Create API credentials from Supabase คุณทำตามนั้น แล้วใส่ข้อมูลลงไป

ผมจะไปที่ Supabase แล้วเข้าสู่ระบบด้วยบัญชีที่สร้างไว้แล้ว และเมื่อกรอกเสร็จแล้วกลับมาเลือกบัญชี ตอนนี้เราต้องสร้าง table ตรงนี้ผมจะไปที่ Dashboard แล้วเข้าโปรเจกต์ เมื่อคุณตั้งค่าบัญชีแล้วคุณต้องสร้างโปรเจกต์หนึ่ง เราจะเข้าไปที่โปรเจกต์ แล้วไปที่ table แล้วคลิก create a new แล้วตั้งชื่อ ชื่อไม่สำคัญเท่าไร จากนั้นเราสามารถเพิ่มคอลัมน์ได้เลย

คอลัมน์แรกที่เราต้องการคือเก็บชื่อของคนที่กรอกในช่องแชตของเรา เมื่อผมรีเฟรชคุณจะเห็นว่าสิ่งแรกที่คนต้องกรอกคือชื่อและอีเมล และเมื่อกรอกแล้ว ผมต้องการบันทึกไว้ เผื่อผมจะติดต่อกลับได้ในภายหลัง มันเป็น text เช่นกัน

ต่อไปคือ memory นี่คือที่ AI agent ของเราจะเก็บสิ่งที่เรียนรู้จากการโต้ตอบ จากนั้นเรามี session ID ซึ่งก็คือ ID ของการแชตเรา มันเป็น text เช่นกัน ตรงนี้ก็ text คลิก save ตอนนี้ table นี้จะถูกสร้าง และเราจะเลือกมันได้จาก dropdown

ตอนนี้มันถูกสร้างแล้ว ผมเข้าไปที่ table ของผม และอันดับแรกต้องสลับไปที่โหมดที่ถูกต้อง แล้วเราจะเลือก table ใหม่นี้ได้ อันนี้ โดยปกติฟิลด์ต่าง ๆ จะถูกแมปมาให้แล้ว ถ้ามันไม่ขึ้น คุณก็ไปดูด้านล่างวิดีโอ ให้ผมรีเฟรชเพราะตรงนั้นคุณแค่กรอกข้อมูลพวกนี้ ถ้าฟิลด์พวกนี้ไม่ปรากฏ ให้เลื่อนลงไปด้านล่างสุด คุณจะเห็นหัวข้อ Supabase store memory setup และสิ่งที่คุณต้องทำ ถ้าฟิลด์นี้ไม่ขึ้น ให้คลิก add a field แล้วเลือกคอลัมน์ มันก็แค่ชื่อตรงนี้ อันนี้คือ memory

จากนั้นสิ่งที่เราทำกับฟิลด์นี้ คือตรงนี้ที่ AI model หรือ AI agent ของเราจะเขียนข้อมูล เราต้องใช้โค้ดชิ้นนี้ วางมันลงไป สลับไปที่โหมดที่ถูกต้อง แล้วคุณจะเห็นว่านี่คือตัวแปรหรือคำสั่งที่บอก AI agent ว่าควรบันทึกข้อมูลอะไร มันบอกว่า store new memory based on user input and be as specific as you can (เก็บความทรงจำใหม่จากอินพุตของผู้ใช้ และระบุให้เฉพาะเจาะจงที่สุด) และมันทำแบบนี้กับฟิลด์อื่น ๆ ด้วย คุณก็แมปแบบเดียวกันตรงนี้ ตรงนี้คือ session ที่เราต้องแมปโดยตรงจาก workflow ของเรา คุณต้องมี customer และคุณต้องมี customer พร้อมโค้ดสั้น ๆ เหล่านี้ ซึ่งคุณจะพบได้ด้านล่างวิดีโอ ถ้ามันไม่ปรากฏมาให้

จากนั้นเราเปิดโมดูลนี้แล้วทดสอบอย่างรวดเร็ว เพราะผมจะเข้าไปตรงนั้นได้ ตอนนี้ผมกลับไปที่โมดูล และคุณเห็นว่าเราต้องอัปเดตสิ่งเหล่านี้ นี่คือ email และตรงนี้เราต้องใส่ session ID ตรงนี้ เอาล่ะ ตอนนี้เราต้องสลับให้เป็นเมื่อได้รับข้อความแชต (when chat message was received) และตรงนี้เรามี session ID ของเรา แค่ลากมันเข้ามาตรงนี้ เสร็จแล้วตั้งค่าถูกต้องแล้ว

ต่อไปคลิก และอีกสิ่งหนึ่งที่เราต้องการคือ get memory ตรงนี้คุณแค่เลือก table ที่เพิ่งสร้าง เลือกมัน แค่นั้น ไม่ต้องทำอะไรเพิ่ม และ workflow นี้ก็ตั้งค่าเสร็จแล้ว

ขั้นตอนสุดท้ายคือไปที่ CodePen ซึ่งเป็นที่ที่เราจำลองการแชตของเรา เพื่อให้เราปรับแต่งเล็กน้อยก่อนนำไปวางบนเว็บไซต์ คลิกที่ pen และด้านล่างวิดีโอนี้คุณจะพบ chat widget embed code นี่คือวิธีทำให้หน้าต่างแชตปรากฏบนเว็บไซต์ของคุณ เราวางมันลงในช่อง HTML ตรงนี้

และตรงนั้นเราต้องใส่ webhook ตรงนี้ มี placeholder ว่าง ๆ ที่เราต้องใส่ข้อมูล webhook ที่เราได้จากการดับเบิลคลิกที่โมดูลนั้น และตรงนี้คือ chat URL นี่คือ webhook ของเรา วางลงตรงนี้ จากนั้นเรามีความสามารถในการใส่โลโก้ ถ้าผมไปที่ของผม ผมสามารถเลือกรูปภาพใดก็ได้ที่ต้องการ ควรเป็นรูปสี่เหลี่ยมจัตุรัส คัดลอกลิงก์ URL ของรูป แล้วกลับมาตรงนี้ วางลงไป แล้วคุณจะเห็น ลองอีกครั้ง โลโก้นี้ปรากฏขึ้น

และขั้นตอนสุดท้ายคือชื่อบริษัท หรือชื่ออะไรก็ได้ที่คุณต้องการเลือก ผมจะใช้ชื่อเว็บไซต์ของผม save ตอนนี้ผมใช้มันได้แล้ว และถ้าคุณต้องการปรับแต่งเพิ่ม คุณสามารถไปที่ hex color codes และเปลี่ยนสีอะไรก็ได้ตามต้องการ

ผมอยากได้สีนี้แทนสีเขียว มีช่องสีสองช่อง นี่คือ gradient ตรงนี้เราตั้งค่าสีหลัก คุณเห็นว่าตอนนี้มันเป็นสีส้มและสีเขียว แล้วผมจะทำให้มันเข้มขึ้นอีกหน่อย เพื่อให้เห็น gradient ชัดเจน บางทีผมจะเลือกอันนี้ และนี่คือวิธีที่คุณปรับแต่งให้เข้ากับแบรนด์ของคุณ คุณเห็นไหมว่าตอนนี้มันเป็น gradient แบบนี้

ก่อนที่เราจะไปต่อกับการนำไปใช้จริง เรามาทดสอบครั้งสุดท้ายกัน สลับอันนี้เป็น active แล้วเรามาทดสอบ คลิก ใส่ชื่อ ใส่อีเมล แล้วคลิก continue chat แล้วคุณจะเห็นว่ามันใช้ชื่อของผม และเมื่อผมเข้าไปในฐานข้อมูลของผม เมื่อรีเฟรชมันควรจะมีอีเมลและชื่อที่ผมเพิ่งกรอก และยังเก็บบางอย่างในความทรงจำแล้วด้วย

ตอนนี้ผมถามได้ว่า "ฉันต้องการทำระบบโซเชียลมีเดียอัตโนมัติ คุณมีสินค้าอะไรบ้าง?" และตอนนี้ AI agent จะดูในชีตสินค้าของผมและดูคำถามของผม แล้วพิจารณาว่าสินค้าไหนน่าสนใจสำหรับคนนี้ จากนั้นมันจะดึงคำอธิบายและส่งลิงก์ที่เกี่ยวข้องมาให้ รวมถึงลิงก์ที่สามารถซื้อสินค้าเหล่านี้ได้ ดังนั้นถ้าผมคลิก มันควรจะพาไปที่หน้าขายของข้อเสนอของผม

และเมื่อเรากลับมา รีเฟรชฐานข้อมูลของเรา มันควรจะมีความทรงจำใหม่ "Fabian กำลังมองหาระบบโซเชียลมีเดียอัตโนมัติ และกำลังสำรวจสินค้าอัตโนมัติของคุณ" ดังนั้นกระบวนการทำงานได้ผล

ตอนนี้ขั้นตอนสุดท้ายคือการนำมันขึ้นเว็บไซต์ของเรา สำหรับผม ผมใช้ WordPress เป็นระบบจัดการเว็บไซต์ แต่คุณสามารถใช้อะไรก็ได้ที่ต้องการ สิ่งเดียวที่ต้องทำคือเลือกโค้ดทั้งหมดแล้วคัดลอก แล้ววางลงบนเว็บไซต์ของคุณ ในกรณีของผม ผมมีปลั๊กอินชื่อ WP Headers and Footers ควรวางไว้ในส่วน footer ของเว็บไซต์ของคุณ ซึ่งสามารถทำได้บนแพลตฟอร์มจัดการเว็บไซต์ใดก็ได้ คุณแค่วางมันลงไปแล้วคลิก save

และเมื่อผมไปที่เว็บไซต์ของผม คุณจะเห็นว่าช่องแชตปรากฏขึ้นที่ด้านล่าง และคุณเห็นว่าผมใช้มันได้เลย ตอนนี้การตั้งค่าของเราเสร็จสมบูรณ์แล้ว
