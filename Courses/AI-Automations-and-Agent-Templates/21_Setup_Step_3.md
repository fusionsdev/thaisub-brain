## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 3 ของการตั้งค่าระบบอัตโนมัติ โดยสอนวิธีสร้างซีนาริโอสำหรับเผยแพร่โพสต์ (publishing scenario) ใน Make.com เริ่มจากการนำเข้า blueprint ชื่อ publisher ต่อด้วยการตั้งค่า webhook ร่วมกับ Google Apps Script และเชื่อมต่อบัญชีโซเชียลมีเดียต่าง ๆ อย่าง LinkedIn, Instagram, Facebook และ Twitter รวมถึงการตั้งค่า Google Sheets เพื่อบันทึกเวลาเผยแพร่ และการทดลองรันระบบจริง

## คำแปลเต็ม

ผมจะเปิดอันนี้ทิ้งไว้ก่อน ขั้นตอนต่อไปเราจะมาทำซีนาริโอสำหรับเผยแพร่โพสต์กัน คลิกที่ create a new scenario คุณจะพบลิงก์ด้านล่างวิดีโอนี้สำหรับดาวน์โหลด blueprint ของระบบอัตโนมัติที่คุณต้องใช้ตอนนี้ คลิกที่ import blueprint ผมเลือกไฟล์ มันชื่อว่า publisher คลิก save แล้วก็เสร็จเรียบร้อย

ตอนนี้เราจะทำตามขั้นตอนคล้าย ๆ เดิม เราต้องเพิ่ม webhook ก่อน จากนั้นต้องคัดลอกที่อยู่ webhook กลับไปที่ Google ของเรา กลับไปที่ Apps Script ตอนนี้เราต้องวาง webhook ไว้ตรงนั้นด้วย เพราะว่า webhook จะรับข้อมูลจากโพสต์โซเชียลมีเดียของเรา ซึ่งก็คือรูปภาพ แล้วส่งต่อไปยังแพลตฟอร์มโซเชียลมีเดียต่าง ๆ

เลื่อนดู เรามี webhook นี้อยู่แล้ว และมีอีกอันหนึ่งตรงนี้ มาหามันกัน webhook อันถัดไป อยู่ตรงนี้ Insert make webhook publisher วางมันไว้ตรงนี้ คลิก save และนี่คือทั้งหมดที่คุณต้องทำใน Google Sheet

กลับไปที่ระบบอัตโนมัติ เราสามารถรันมันได้หนึ่งครั้ง เพื่อให้ระบบอัตโนมัติของเรามีข้อมูลบ้าง แต่พอทำจริงผมก็แค่ไปคลิก แล้วคลิกที่ run once แล้วสิ่งที่ผมทำต่อคือไปตรงนี้ ผมไม่ต้องเลือกแพลตฟอร์มด้วยซ้ำ แค่คลิกอะไรก็ได้ แล้วมันควรจะหาข้อมูลให้เจอ อย่างที่เห็นมันดึงโพสต์มาให้ และปกติมันก็ส่งแพลตฟอร์มที่ผมเลือกมาด้วย แต่เนื่องจากผมกรอกไว้ มันเลยไม่มี แต่ไม่เป็นไร มันมีตัวแปรครบ และนั่นคือสิ่งที่สำคัญ

ตอนนี้ผมสามารถเชื่อมต่อมันได้อีกครั้ง และสิ่งที่ต้องตั้งค่าตรงนี้คือ Google Sheet แต่โดยพื้นฐานสิ่งเดียวที่โมดูลนี้ทำคือบันทึกเวลาเผยแพร่ และสิ่งที่คุณต้องทำ ถ้ายังไม่ได้ทำ คือเชื่อมต่อบัญชีโซเชียลมีเดียของคุณ ผมจะไล่ทำไปเรื่อย ๆ แต่แน่นอนว่าคุณเชื่อมต่อเฉพาะบัญชีที่คุณใช้จริงเท่านั้น ถ้าผมอยากเผยแพร่ไปทุกแพลตฟอร์ม ผมก็แค่ตั้งค่าทั้งหมด

สำหรับ LinkedIn ถ้าคุณยังไม่ได้เชื่อมต่อ ให้คลิกที่ add แล้วไปคลิกที่ต่อ จากนั้นระบบจะให้คุณเข้าสู่ระบบบัญชี LinkedIn ของคุณ แล้วเมื่อเสร็จแล้ว โดยปกติคุณไม่ต้องทำอะไรเพิ่ม เพราะ placeholder ต่าง ๆ ถูกตั้งไว้แล้ว แต่ผมแค่อยากอธิบายว่ามันทำงานอย่างไร มันจะดึงไฟล์ นี่คือการดึงรูปภาพ เข้าใจไหม ตรงนี้มันส่ง URL รูปภาพจาก Google Drive แล้วแปลงเป็นรูปแบบที่ใช้ได้ จากนั้นมันก็ดึงไฟล์ได้โดยตรงและใช้ในโพสต์ได้ และตรงนี้คือข้อความโพสต์ซึ่งได้มาจาก webhook และตรงนี้คุณสามารถตั้งค่าการมองเห็นเป็น public เพื่อให้ทุกคนเห็นได้

สำหรับแพลตฟอร์มอื่นก็คล้ายกัน และนี่คือ Instagram โดยพื้นฐาน ถ้าคุณยังไม่มีบัญชี คุณต้องคลิกที่ add แล้วคลิก create a new แล้วระบบจะให้คุณสมัคร และสิ่งที่สำคัญสำหรับบัญชีนี้คือ คุณต้องมีเพจ Facebook เป็นเพจ Facebook ไม่ใช่ Instagram คุณต้องเป็นผู้ดูแลเพจ Facebook และเพจนั้นต้องเชื่อมต่อกับบัญชี Instagram ของคุณ

ถ้าคุณไม่เคยทำมาก่อน ผมจะแสดงให้ดูในอีกไม่กี่วินาที มันง่ายมาก ไปที่ Facebook ของคุณ แล้วไปที่ settings ตำแหน่งอาจต่างกันเล็กน้อยแต่หาเจอแน่นอน จากนั้นไปที่ connected accounts และตรงนั้นคุณจะเห็นว่าผมเชื่อมต่อบัญชี Instagram ไว้แล้ว ถ้าคุณยังไม่ได้ทำ คุณต้องเชื่อมต่อบัญชี Instagram ตรงนี้ และเมื่อทำเสร็จแล้ว คุณก็เลือกมันได้จากเมนู dropdown ตรงนี้ จากนั้นก็เพิ่มและมันก็ควรจะทำงานได้

มันทำแบบเดียวกัน คือดึง URL รูปภาพ แต่ตรงนี้มันดึงได้ และตรงนี้คือคำบรรยาย (captions) โมดูลอื่น ๆ ก็ทำงานแบบเดียวกัน ตรงนี้คือ Facebook เพิ่มบัญชี Facebook ของคุณ แล้วเลือกเพจที่คุณต้องการให้โพสต์ไป รูปภาพและข้อความโพสต์ควรถูกกรอกมาให้แล้ว

ส่วน Twitter ต่างออกไปเล็กน้อย เพราะอันดับแรกเรามีโมดูลจาก OpenAI เพราะ Twitter มีข้อจำกัดเรื่องจำนวนตัวอักษร และอย่างที่เห็นโพสต์พวกนี้ค่อนข้างยาวเป็นโพสต์โซเชียลมีเดียทั่วไป ตรงนี้ผมต้องการให้แน่ใจว่าโพสต์ถูกตัดให้สั้นลง เพื่อให้อยู่ในจำนวนตัวอักษรที่จำกัด ซึ่งอยู่ที่ประมาณ 200 ตัวอักษร และนี่คือสิ่งที่โมดูลนี้ทำ

จากนั้นเรามีโมดูล Twitter สองอัน อย่างที่เห็น อันหนึ่งใช้สำหรับอัปโหลดรูปภาพไปที่ Twitter และอีกอันใช้สำหรับสร้างโพสต์ และในการตั้งค่าโมดูลเหล่านี้ คุณต้องคลิก add account ด้วย โอ๊ะ ตรงนี้ต้องรอแป๊บหนึ่ง มันเร็วเกินไป และถ้าคุณยังไม่มีบัญชี Twitter คุณต้องไปที่ show advanced settings แล้วคุณจะได้ API secret และสำหรับเรื่องนี้ผมได้บันทึกบทช่วยสอนไว้ให้คุณแล้ว สอนวิธีตั้งค่า Twitter developer account เพราะคุณจะหาข้อมูลพวกนี้ได้จากตรงนั้น และยังแสดงให้ดูว่าจะหา API key ใน Twitter developer account ของคุณได้ที่ไหน

เมื่อทำเสร็จแล้ว คุณก็ทำคล้าย ๆ กันคือ Client ID และ client secret ซึ่งครอบคลุมอยู่ในวิดีโอเดียวกันนั้น และเมื่อคุณเพิ่มบัญชีแล้ว อันนี้ทำเสร็จแล้ว สิ่งสุดท้ายที่ต้องทำคือตั้งค่าโมดูล Google Sheets และการทำแบบนี้ผมต้องใช้ sheet ID อีกครั้ง เพราะโดยพื้นฐานมันคือสิ่งนี้ มันแค่บันทึกเวลาเผยแพร่ลงใน Google sheet ของผม ตอนนี้มันยังไม่มีโค้ดเวลาเผยแพร่ตรงนี้ ผมเลยต้องกลับไปที่ระบบอัตโนมัติของผม ผมบอกไปแล้วว่าผมลิงก์โค้ดนี้ไว้ด้านล่างวิดีโอ ซึ่งเป็นโค้ดที่เราต้องใช้ นี่คือสิ่งที่คุณต้องใช้ และคุณจะพบมันด้านล่างแล้ว ผมเพิ่มไว้แล้ว จากนั้นคุณก็เพิ่มมันตรงนี้แล้วคลิก save

ผมไม่ต้องทำแบบนี้กับโมดูลอื่น เพราะนี่คือสิ่งที่สำคัญ คุณใช้ Google Sheets แค่หนึ่งอัน และมันควรอยู่ในตำแหน่งที่เหมาะสม เพราะมันทำงานแบบนี้ โพสต์ LinkedIn ถูกเผยแพร่ จากนั้น Google Sheets จะบันทึกวันที่และเวลาเผยแพร่ มันจะบันทึกให้ดู เราาจะทดสอบในอีกไม่กี่วินาที แล้วคุณก็รู้ว่าโพสต์ถูกเผยแพร่แล้ว จากนั้นมันก็รันผ่านแพลตฟอร์มอื่น ๆ แต่มันเผยแพร่พร้อมกันเกือบจะเวลาเดียวกัน คุณเลยไม่ต้องใช้โมดูล Google Sheets เพิ่มอีก แค่เพิ่มในหนึ่งโมดูลเท่านั้นเอง และนั่นคือทั้งหมด

ตอนนี้มันถูกตั้งค่าเรียบร้อยแล้ว เราคลิก run เริ่มทำงาน และอย่างที่เห็นมีการตั้งค่า filter ไว้แล้ว ซึ่งทำให้แน่ใจว่าคุณเผยแพร่เฉพาะแพลตฟอร์มที่คุณเลือกเท่านั้น

ตอนนี้ผมจะไปที่ชีตของผม และตอนนี้ผมจะยกเลิกการเลือกอันนี้ก่อน ผมได้สร้างโพสต์ไว้ประมาณสามโพสต์แล้ว ตอนนี้ผมสามารถปรับแต่งเล็กน้อย แล้วก็เผยแพร่ไปยังแพลตฟอร์มที่ต้องการหรือที่ตั้งค่าไว้ ผมตั้งค่าไว้แล้ว และผมสามารถเผยแพร่ไปทั้งหมดนี้ได้ ถ้าผมพิมพ์ให้ถูกต้อง แล้วคลิก publish มันก็จะเผยแพร่ไปทั้งหมด หรือผมจะให้มันเผยแพร่เฉพาะ Instagram ก็ได้ ลองเป็น Facebook เฉพาะ Facebook แล้วก็ Twitter ลองเป็น Instagram ดีกว่า เพราะผมคิดว่าคนส่วนใหญ่เผยแพร่ไปที่ Instagram ลองเป็นแบบนี้ แล้วคลิก publish

ตอนนี้ระบบอัตโนมัติควรจะรันแล้ว มันถูกเปิดใช้งานอยู่ มันถูกเปิดใช้งานซีนาริโอแล้ว และผมคิดว่ามันน่าจะรันในอีกไม่กี่วินาที สิ่งที่ผมจะทำคือเปิดบัญชีต่าง ๆ ของผม แล้วเราจะตรวจสอบว่าโพสต์ถูกเผยแพร่หรือยัง เห็นไหม มันเผยแพร่ไปแล้ว และตอนนี้กำลังทำ Twitter และตอนนี้เรามี error บางครั้งมันเกิดขึ้นกับโมดูล Twitter ได้ ลองดูว่า error คืออะไร บางครั้งเป็นเพราะโพสต์ยาวเกินไป และผมคิดว่าครั้งนี้ก็เป็นเพราะโพสต์ยาวเกินไป เพราะ Twitter อนุญาตแค่ประมาณ 200 ตัวอักษร และคุณเห็นว่ามี 393 ตัวอักษร

โมดูลนี้ไม่ทำงาน นี่คือสิ่งที่ผมต้องบอกคุณ แม้ว่าผมจะบอกมันแล้วว่าโพสต์แค่ 200 ตัวอักษร ไม่ใช่จำนวนคำ บางครั้งมันก็พลาดได้ แล้วคุณก็แค่ต้องลองใหม่ มันถูกเผยแพร่ไปแล้ว ไปที่ Facebook และ Twitter ผมจะตรวจ Instagram ก่อน มันถูกเผยแพร่ไปที่ Instagram ไหม? มันน่าจะถูกเผยแพร่แล้ว มาดูกัน อย่างที่เห็นโพสต์นี้ถูกเผยแพร่แล้ว และบนบัญชี Twitter ทดลองของผม มันไม่ใช่อย่างที่ผมต้องการ มันไม่ถูกเผยแพร่เพราะผมมีปัญหา แต่บนเพจ Facebook ของผม มันถูกเผยแพร่แล้ว

ตอนนี้ผมกลับไปเลือกเฉพาะ Twitter ได้ ผมลองอีกครั้ง และบางครั้งมันก็ลองแล้วได้จำนวนตัวอักษรที่ถูกต้อง แต่ก่อนอื่นผมต้องหยุดมันก่อน เพราะเมื่อมี error มันจะปิดระบบอัตโนมัติของคุณเสมอ จากนั้นคุณต้องเข้าไปและตอนนี้มันน่าจะ... ผมลองอีกครั้ง ลองดูว่าครั้งนี้มันจะทำงานได้ถูกต้องไหม เห็นไหม ตอนนี้มันทำงานแล้ว ผมสามารถรีเฟรชตรงนี้ได้ และมันควรจะแสดงทวีตของผม เห็นไหม ตอนนี้มันสั้นลงมาก ดังนั้นคุณแค่ต้องลองใหม่

แต่ตอนนี้ระบบอัตโนมัตินี้ใช้งานได้แล้ว และคุณสามารถทำแบบนี้กับบัญชีทั้งหมดเหล่านี้ได้ และคุณเห็นตรงนี้ด้วยว่าเวลาเผยแพร่ยังไม่ถูกบันทึก เพราะเวลาเผยแพร่ถูกบันทึกที่ LinkedIn ดังนั้นถ้าผมเผยแพร่แค่ Facebook และ Twitter ผมก็จะย้ายโมดูลนี้มาตรงนี้ แล้วเวลาเผยแพร่ก็จะถูกบันทึกลงใน Google sheet ของผม

ในวิดีโอถัดไป ผมได้สร้างวิดีโออีกอันที่จะแสดงวิธีขยายระบบอัตโนมัติของคุณ เพื่อให้คุณสามารถแบ่งบทความบล็อกของคุณ ไม่ใช่แค่ออกเป็นสามโพสต์โซเชียลมีเดีย แต่เป็นจำนวนเท่าไรก็ได้ที่คุณต้องการ โดยปรับแต่งเพียงเล็กน้อย
