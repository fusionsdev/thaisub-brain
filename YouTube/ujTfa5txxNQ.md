## ประเด็นหลัก

- SemiAnalysis บริษัทวิจัยที่นักลงทุนรายใหญ่จ้างให้ติดตามวงการ AI เปิดเผยว่า OpenAI แก้ปัญหา pre-training ได้แล้ว และกำลังสร้างโมเดลขนาดใหญ่ที่ใช้ชื่อรหัสว่า Doug
- คนปล่อยข่าว Chris GPT อ้างว่า Doug จะเป็นการเทรน pre-training ที่ใหญ่ที่สุดของ OpenAI และจะทำให้ Fable 5 ของ Anthropic ดูโบราณ แต่ข้อมูลส่วนนี้มาจากบัญชีนิรนาม จึงควรถือเป็นคำกล่าวอ้าง ไม่ใช่ข้อเท็จจริง
- OpenAI ติดปัญหาการเทรน pre-training มาเกือบสองปี ทำได้เพียงขัดเกลารากฐานเดิมตั้งแต่ยุค GPT-4 จนกระทั่ง Google ปล่อย Gemini 3 แล้ว Sam Altman ประกาศสถานการณ์ code red ภายในบริษัท
- หลังวิกฤต มีรายงานว่า Mark Chen หัวหน้าฝ่ายวิจัยบอกทีมว่าแก้บั๊กที่ทำให้การเทรนพังได้แล้ว โดยโมเดลทดสอบรหัสชื่อ Garlic พิสูจน์ว่าการแก้ได้ผล และ Doug ถูกสร้างต่อจากข้อมูลนั้น
- โมเดลที่ใกล้กว่าชื่อ Astra ซึ่ง Sam Altman ยืนยันเองว่าเทรนเสร็จแล้ว แต่ระงับการปล่อยเพื่อตรวจสอบความปลอดภัยทางไซเบอร์ หลายคนเชื่อว่า Astra คือ GPT-6 โดยข่าวลือระบุว่ามีพารามิเตอร์ประมาณ 10 ล้านล้านตัว
- Doug คาดว่าจะเปิดตัวไม่เกินเดือนพฤศจิกายน น่าจะเทรนบนชิป Vera Rubin รุ่นถัดไปของ Nvidia และอาจมี context window สูงถึง 1.5 ล้าน tokens
- ด้านความน่าสงสัย: ยังไม่มีอะไรเกี่ยวกับ Doug ที่ OpenAI ยืนยันอย่างเป็นทางการ ไม่มีใครภายนอกเคยรัน prompt ผ่านมัน และการเทรนใหญ่ๆ เคยทำให้ผิดหวังมาแล้ว เช่น GPT-4.5
- สัญญาณเพิ่มเติม: Jeff Dean ลาออกจาก Google ไปเปิดแล็บ Discovery Loop และ Demis Hassabis ก้าวลงจากตำแหน่ง CEO ของ DeepMind ทำให้สนามแข่งเหลือผู้เล่นระดับแนวหน้าตัวจริงเพียงสองราย
- เคล็ดลับจากผู้บรรยาย: สร้าง workflow บนโมเดลปัจจุบันทันที ตรวจสอบแหล่งข่าวก่อนแชร์ข่าวลือ และออกแบบระบบให้สลับโมเดลได้ง่ายโดยไม่ต้องสร้างใหม่ทั้งหมด

## ความเห็นสรุป

วิดีโอนี้สรุปข่าวลือวงในเกี่ยวกับ Doug และ Astra ได้อย่างรอบด้าน พร้อมแยกแยะชัดเจนว่าข้อมูลใดมาจากแหล่งที่เปิดเผยชื่อและข้อมูลใดเป็นเพียงคำกล่าวอ้างของบัญชีนิรนาม สิ่งที่ควรจดจำคือทิศทางมากกว่ารายละเอียด: กำแพงของ pre-training ดูเหมือนจะพังลงแล้ว และโมเดลรุ่นใหญ่กำลังจะมาเร็วกว่าที่หลายคนคาดคิดครับ
