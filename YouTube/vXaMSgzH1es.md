## ประเด็นหลัก

- เมื่อวันที่ 8 สิงหาคม Anthropic ปล่อยอัปเดต Claude Code ที่ทำให้เซสชันของ Claude ส่งข้อความหากันได้ โดยไม่ต้องคัดลอกวางหรืออธิบายบริบทซ้ำระหว่างเซสชัน
- เซสชันหนึ่งส่งสรุปงานให้อีกเซสชันหนึ่งได้ และอีกฝ่ายรับช่วงทำงานต่อกลางคันได้ทันที รวมถึงถาม-ตอบข้ามเซสชันได้โดยไม่ต้องสลับหน้าต่าง
- จุดเด่นที่ซ่อนอยู่คือการส่งข้อความอัตโนมัติ เมื่อการเปลี่ยนแปลงของเซสชันหนึ่งกระทบงานของอีกเซสชัน ระบบจะแจ้งให้อีกฝ่ายรู้เองโดยไม่ต้องรอคำสั่ง
- เปรียบเทียบกับรังผึ้ง: ไม่มีผึ้งตัวไหนฉลาดเดี่ยวๆ แต่รังทั้งรังฉลาด Claude Code กำลังเปลี่ยนผู้ช่วย AI เดี่ยวๆ ให้เป็น "ทีม" ที่ทำงานร่วมกัน
- เดิมทีคนต้องทำตัวเป็นนกพิราบส่งสารระหว่างเซสชันของตัวเอง มีผู้ใช้รายหนึ่งทำแบบนี้ด้วยมือมานาน 2 ปี โดยให้ Claude เขียนเอกสารส่งต่องาน (handoff document) เมื่อ context window เต็ม 80%
- สิ่งที่ส่งระหว่างเซสชันเป็นเพียงสรุป (summary) ไม่ใช่ประวัติแชทหรือไฟล์ทั้งหมด เพื่อความเป็นส่วนตัวและไม่ให้หน่วยความจำของเซสชันเต็ม
- จุดอ่อน: สรุปก็คือสรุป รายละเอียดอาจหายไปตอนบีบอัด เซสชันที่สองอาจต้องเดาว่าข้อความหมายถึงอะไร ถ้าไม่มีไฟล์ต้นทางประกอบ
- เทรนด์ของวงการ: ผู้ช่วย AI ตัวเดียวคือเรื่องของปี 2024 ส่วนทีม AI agents คือเรื่องของปี 2026 โดย Codex ของ OpenAI ก็มีฟีเจอร์คล้ายกันอยู่แล้ว และคาดว่าเครื่องมือทั้งหมดจะมาบรรจบกัน
- ขั้นต่อไปที่คาดว่าจะเกิดคือเครื่องมือต่างตัวกันคุยหากัน ซึ่งทำได้แล้วผ่านโปรเจกต์โอเพนซอร์สอย่าง Herder
- ผู้พูดโปรโมตระบบ agent operating system (แดชบอร์ดรวม AI agent ที่แชร์หน่วยความจำผ่าน Obsidian) และคอร์ส AI Profit Bootcamp ที่มีสมาชิกกว่า 3,800 คน

## ความเห็นสรุป

วิดีโอนี้เป็นการรีวิวเชิงการตลาดที่อธิบายฟีเจอร์ใหม่ของ Claude Code ได้เข้าใจง่าย ด้วยการเปรียบเทียบรังผึ้งและตัวอย่างธุรกิจจริง ทั้งฟรีแลนซ์และร้านค้าออนไลน์ จุดแข็งคือการชี้จุดอ่อนเรื่องความคลุมเครือของ summary อย่างตรงไปตรงมา แต่เนื้อหาช่วงท้ายเป็นโฆษณาหลักสูตรเสียเป็นส่วนใหญ่ เนื้อหาสาระจริงๆ อยู่ประมาณสองในสามของวิดีโอแรก
