## บทนำ
วิดีโอนี้สอนวิธีแทนที่โมดูล Twitter ของ make.com ที่ไม่รองรับอีกต่อไป ด้วยโซลูชันที่ใช้งานได้จริงผ่านบริการ uploadpost.com โดยเริ่มจากการนำเข้าเทมเพลตโมดูลเดียว ตั้งค่าบัญชี เชื่อมต่อ API key แล้วจับคู่ฟิลด์ต่างๆ เพื่อให้โพสต์วิดีโอหรือรูปภาพไปยัง Twitter/X ได้อัตโนมัติ

## คำแปลเต็ม
ในวิดีโอนี้ ผมจะโชว์วิธีแทนที่โมดูล Twitter เหล่านั้น ซึ่งไม่ได้รับการสนับสนุนอีกต่อไป ด้วยโซลูชันที่ใช้งานได้จริงโดยใช้บริการอื่น ก่อนอื่นคุณต้องเปิดออโตเมชันของคุณที่มีโมดูล Twitter ที่ต้องแทนที่ จากนั้นเปิด scenario ใหม่ ไปที่ open a new แล้วคลิก create a new scenario เพราะผมได้สร้างโมดูลที่คุณต้องวางหรือแทนที่ในออโตเมชันของคุณ เพื่อให้คุณสามารถ publish ไปยัง Twitter ได้

ตรงนี้ คุณสามารถไปที่ลิงก์ด้านล่าง ดาวน์โหลดไฟล์นี้ แล้วไปที่ import คลิกที่ select แล้ว import ไฟล์นั้นเข้ามา จากนั้นคลิก save ซึ่งจะได้ string ออกมา สิ่งเดียวที่คุณต้องการจริงๆ ก็คือโมดูลตัวเดียวนี้ คลิกขวาแล้ว copy แล้วตรงนี้คุณก็แค่ลบโมดูล Twitter เหล่านั้นออก แล้ววางสิ่งที่คุณ copy ไว้ นั่นคือทั้งหมดที่เราต้องการ

ต่อไป เราจะ unlink โมดูลอื่นๆ เพราะผมไม่ต้องการให้โมดูลอื่นถูกทดสอบ นี่เป็นแค่ตัวอย่าง workflow แต่ไม่ว่า workflow จะเป็นแบบไหน สิ่งเดียวที่คุณต้องทำก็คือแทนที่ตามที่ผมเพิ่งทำไป — copy โมดูลนี้แล้วแทนที่โมดูล Twitter ด้วยโมดูลเดียวนี้ จากนั้นคลิก open นี่คือบริการที่คุณจะใช้ มันชื่อว่า uploadpost.com ตรงนี้คุณสามารถสมัครบัญชีฟรีได้ ไปที่ลิงก์ที่คุณเห็นด้านล่างวิดีโอนี้ด้วย และในแผนฟรี คุณจะได้ 10 uploads ต่อเดือน ถ้าต้องการมากกว่านั้น คุณต้องอัปเกรดเป็นแพ็กเกจถัดไป ซึ่งมีค่าใช้จ่าย $14 ต่อเดือน และคุณจะได้ 120 uploads

เมื่อคุณทำขั้นตอนนี้เสร็จ ขั้นแรกคือไปที่ Manage Users ตรงนี้คุณใส่ชื่อผู้ใช้แบบสุ่มก็ได้ แล้วคลิก Add User จากนั้นคุณก็สามารถเชื่อมต่อผู้ใช้กับบัญชีใดก็ได้ที่คุณต้องการ ในกรณีนี้คุณต้องการเชื่อมต่อกับ X คุณคลิกเพื่อยืนยันว่าต้องการเชื่อมต่อกับบัญชีนี้ และเมื่อเชื่อมต่อเสร็จมันจะมีลักษณะแบบนี้ จากนั้นเรากลับมาที่นี่ และตั้งค่าโมดูลนี้ทีละขั้นตอน

สิ่งเดียวที่เราต้องการคือ API key มาดึง key ตรงนี้กัน คุณสามารถสร้าง key ใหม่ได้ถ้ายังไม่มี key ใหม่ถูกสร้าง ผมจะลบอันนี้ออกแล้วให้คุณดูว่ามันเป็นอย่างไร Generate key ใหม่ แล้ว key ใหม่ก็จะแสดงขึ้นมา copy มันแล้วกลับมาที่นี่ วางลงตรงนี้ สิ่งสำคัญคือต้องคงส่วนนี้ไว้ อันนี้คือส่วนแรก แล้วนี่คือคำว่า API

ลงมาด้านล่าง ตรงนี้คือ title และ value ของ title นั้น ในกรณีของผม มันมาจากโมดูลนี้ตรงนี้ เพราะสิ่งสำคัญคือมันคือข้อความ caption ซึ่งเป็นข้อความที่เผยแพร่พร้อมกับวิดีโอไปยัง Twitter และสิ่งสำคัญคือข้อความนี้ต้องน้อยกว่า 240 ตัวอักษร ไม่อย่างนั้นคุณจะได้รับ error แต่ในออโตเมชันส่วนใหญ่ของผม สิ่งนี้ถูกจัดการไว้แล้ว นั่นคือเหตุผลที่ผมมักเพิ่มโมดูลพิเศษไว้ข้างหน้า ซึ่งก็คือโมดูล open router AI model ที่จะย่อข้อความให้เหลือน้อยกว่า 100 หรือ 200 ตัวอักษรเสมอ

ถัดมาคือ username นี่คือ username จาก uploadpost.com คุณไปที่ manage แล้ว copy ชื่อผู้ใช้ที่เชื่อมต่อกับบัญชี Twitter หรือ X ของคุณ จากนั้นวางลงตรงนี้ และสิ่งสุดท้ายที่ต้อง map คือ image URL ซึ่งควรจะเป็นรูปภาพของผมที่อยู่ตรงนี้ จากนั้นคลิก save

ตอนนี้คลิกที่ปุ่ม run แล้วผมก็ทดสอบได้เลย คลิก run ผมจะส่งการทดสอบ เรียกใช้ในออโตเมชันนี้และส่งข้อมูลผ่านไป เพื่อดูว่ามันถูกเผยแพร่และวิดีโอหรือรูปภาพถูกอัปโหลดและโพสต์ไปยังบัญชี Twitter ของผมหรือไม่ และมันก็ดูเรียบร้อยดี จากนั้นผมไปที่ Twitter รีเฟรชหน้า แล้วเห็นว่าโพสต์ถูกเผยแพร่แล้ว ดังนั้นระบบ auto-publishing นี้ทำงานได้แล้ว ผมสามารถคลิก save แล้วเชื่อมต่อโมดูลอื่นๆ กลับมาได้ และตอนนี้ผมก็สามารถโพสต์ไปยัง Twitter ได้อัตโนมัติด้วยอินทิเกรชันนี้
