## ประเด็นหลัก
- โมดูลแรกของซีรีส์ Hermes Agent Masterclass จำนวน 10 ตอน อัปเดตใหม่ถึงเดือนกรกฎาคม 2026 ครอบคลุมการติดตั้ง การตั้งค่า และคำสั่งเบื้องต้น
- Hermes Agent เป็น AI agent แบบ open-source สร้างโดย Nous Research (แล็บที่สร้างตระกูลโมเดล Hermes) — แตกต่างจาก agent ทั่วไปเพราะถูกพัฒนาโดยคนที่เทรนโมเดลเอง
- จุดเด่นทางสถาปัตยกรรมคือ compounding value — ทุกเซสชันจะหล่อเลี้ยงเซสชันถัดไปผ่าน trajectory และการสร้าง skill ที่นำกลับมาใช้ใหม่ได้ ทำให้ Hermes ที่ใช้มานานย่อมฉลาดกว่าของใหม่
- รองรับทุกโมเดล: Claude, GPT, Grok, Kimi, Gemini, และโมเดล local มี star กว่า 200, 000 ดวงและ contributor เกือบ 2,000 คน ปัจจุบันอยู่ที่เวอร์ชัน 18
- รันใน terminal (TUI), มี web dashboard และ desktop app ใหม่ และสามารถตอบกลับผ่าน Telegram, Discord, Slack
- เดินผ่าน setup wizard ตั้งแต่เลือก provider (Nous Portal, OpenRouter ฯลฯ), เลือกโมเดล (GLM 5.2), ตั้งค่า tool gateway, browser automation, และ text-to-speech
- เน้นคำสั่ง CLI ที่ใช้บ่อย เช่น `hermes`, `hermes gateway`, `hermes doctor`, `hermes model`, `hermes status`, `hermes insights`, `hermes sessions browse`, `hermes skills browse`/`search`, `hermes config show`, `hermes update`
- คำสั่ง slash ในแชต เช่น `/new`, `/model` (สลับโมเดลกลางเซสชันได้), `/fast`, `/background`, `/btw`, `/q`, `/compress`, `/skills`, `/yolo`, `/help`
- ไฟล์และ config ทั้งหมดเก็บใน `~/.hermes` — แก้ `config.yaml`, `.env`, memories ได้ด้วยตัวเอง แต่ sessions/cron ให้สั่ง agent ทำแทน
- demo ภารกิจจริง: ใช้ web search (ผ่าน Tavily) วิจัยตลาดหนังสือเด็ก AI ที่กำหนดเอง ได้รายงานคู่แข่งสามชั้นและระบุช่องว่างทางการตลาด เช่น การเลือกสไตล์ศิลปะกำหนดเอง, กลุ่มอายุที่สูงขึ้น, สองภาษา, audio-first
- เป็นการเริ่มต้นจากศูนย์จริง ๆ บนเครื่องใหม่ที่ไม่เคยมี Hermes Agent — ผู้ชมจะได้เห็นว่ามันพัฒนาและเรียนรู้ skill ไปตามเวลา

## ความเห็นสรุป
วิดีโอนี้เป็นจุดเริ่มต้นที่ครอบคลุมและปฏิบัติได้จริงสำหรับผู้ที่อยากใช้ Hermes Agent อย่างจริงจัง โทนของ Tonbi เป็นกันเองและเน้นการลงมือทำจริงตั้งแต่ติดตั้งจนถึงภารกิจแรก จุดที่น่าสนใจคือการพาผู้ชมเห็นว่าค่าแบบ compounding value ทำงานอย่างไร และทำไมการเลือก agent ที่เรียนรู้จากการใช้งานจึงสำคัญ เหมาะสำหรับผู้ใช้ที่ต้องการอิสระในการเลือกโมเดลและต้องการความเป็นส่วนตัวสูง เนื้อหาเหมาะกับผู้ที่ใช้ agent บ่อยพอจะรู้สึกถึงประโยชน์แบบสะสม
