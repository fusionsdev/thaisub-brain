## สรุปสั้นๆ

วิดีโอนี้เป็นการทดสอบและสาธิตการใช้งาน **Herder App** (Herder Core) ซึ่งเป็นแอปพลิเคชันใหม่ของ Herder ที่เพิ่มขึ้นมา มาจากการประกาศข่าวสดของทีม Herder ที่ทำให้เกิดการเปลี่ยนแปลงสำคัญในวิธีการทำงานของ AI coding agent

## จุดของสนใจหลัก

1. **การติดตั้ง** - แสดงขั้นตอนการติดตั้ง Herder App บน Windows โดยใช้ PowerShell command
2. **ความสามารถในการสร้างตัวเอง (Build Itself)** - สามารถขอให้ agents เพิ่ม components (เรียกว่า mods) ลงในแอปได้
3. **Community Mods & Layouts** - มี community ส่งมาผู้ใช้ layouts (ธีม) และ plugins (mods) มาก่อนให้ใช้งาน เช่น automations mod ทำหน้าที่เป็น scheduler รูปแบบ cron
4. **การปรับแต่ง UI** - สามารถให้ agent แก้ไขฟอนต์ หรือ layout ของแอปได้โดยตรง
5. **ความเป็นเบราว์เจอร์** - แอปเป็นแบบ open source ทั้งหมด ใช้ Apache 2.0 license

## ข้อจำกัด

- **ไม่ทำงานบน Windows** - automations mod ที่เป็น scheduler ไม่สามารถทำงานบน Windows ได้
- **Agent compatibility** - บาง agent เช่น Hermes, Codex, Grok ไม่แสดงใน panel เพราะไม่มี OCS 7501 status message
