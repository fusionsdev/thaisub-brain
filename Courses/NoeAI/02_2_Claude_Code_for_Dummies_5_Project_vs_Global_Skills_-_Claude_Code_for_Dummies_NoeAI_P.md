## บทนำ

บทเรียนสั้นๆ ว่าด้วยความแตกต่างระหว่าง project skills กับ global skills ใน Claude Code — สกิลแบบโปรเจกต์จะอยู่เฉพาะในโฟลเดอร์ที่คุณทำงาน ส่วนสกิลแบบ global จะใช้ได้ทุกที่ ทุกโปรเจกต์บนเครื่อง ผู้สอนสาธิตวิธีดูไฟล์ซ่อน (Cmd+Shift+.) และวิธีให้ Claude ย้ายสกิลจากแบบ global ไปเป็นแบบโปรเจกต์

## คำแปลเต็ม

ยินดีต้อนรับสู่บทเรียน project กับ global skills ครับ บทนี้จะสั้นมาก ผมแค่อยากเพิ่มบทนี้เข้าไปในคอร์ส เพราะผมเองก็เพิ่งรู้เรื่อง project กับ global skills และมันเปลี่ยนเกมสำหรับผมจริงๆ ในเรื่องการจัดระเบียบ และการจัดระเบียบไฟล์ทั้งหมดของผมด้วย ขออธิบายสั้นๆ นะ

project กับ global skills — คำว่า project หมายถึงโฟลเดอร์ที่คุณทำงานอยู่นั่นเอง ถ้าผมเปิดโฟลเดอร์ที่ผมโชว์ให้พวกคุณดูตลอดทั้งคอร์สนี้มา ขอซูมเข้ามาตรงนี้นะ นี่คือโปรเจกต์ ใช่ไหม? โปรเจกต์คือโฟลเดอร์ที่คุณอยู่ แค่นั้นเอง ดังนั้น สกิลที่ชื่อ content machine ที่เราสร้างไว้ มันอยู่ในโปรเจกต์นี้เท่านั้น อยู่ในโปรเจกต์นี้แค่นั้น ผมจะไม่สามารถเข้าถึงมันได้จากที่อื่น

สมมติว่า ผมมีคอมมูนิตี้โรงเรียนของผม ถ้าผมเข้าไปทำงานในโฟลเดอร์โปรเจกต์นี้โดยเฉพาะ มันจะเข้าถึงสกิลนั้นได้ เพราะ Claude ทำงานภายในไฟล์ระบบของคุณ โฟลเดอร์ไหนที่คุณอยู่ มันเข้าถึงทุกอย่างในนั้นได้ มันเข้าถึงอันนี้ได้ แต่สมมติว่าผมไปที่โฟลเดอร์ Noah Varner AI แบรนด์ส่วนตัวของผม ซึ่งอยู่คนละที่ ห่างไกลจากที่ Claude Code เข้าถึงได้ มันจะใช้โฟลเดอร์ content machine ไม่ได้ เพราะสกิล content machine อยู่ในโปรเจกต์ของผม

นี่เป็นวิธีที่ดีในการจัดระเบียบสกิล ถ้าคุณอยู่ในโปรเจกต์อื่น และสกิลนั้นเกี่ยวข้องกับโปรเจกต์นั้นโดยตรง มันเหมือน hard-coded เข้าไป hard-coded ก็คือ มันถูกสร้างขึ้นมาเฉพาะ และเขียนขึ้นมาเพื่อโปรเจกต์นั้นโดยเฉพาะ สมมติว่าผมไปที่ Novarner AI แล้วเริ่มใช้ content machine แต่สกิลมันเขียนเนื้อหาสำหรับโปรเจกต์นี้โดยเฉพาะ มันก็ไม่สมเหตุสมผลใช่ไหม? มันไม่ให้ผลลัพธ์ที่ผมต้องการ ดังนั้น ในกรณีนั้น ผมจะวางสกิลไว้ฝั่งโปรเจกต์

ทีนี้ฝั่ง global — global skills คือสกิลที่คุณเข้าถึงได้ทุกที่ ในทุกโปรเจกต์ ถ้าผมจะเขียนมันออกมาให้ดู จะเห็นว่ามีโฟลเดอร์หนึ่งสำหรับ personal อีกโฟลเดอร์หนึ่งสำหรับแบบนั้น ถ้าผมมีสกิลหนึ่งตัว สมมติว่าเราใส่ไว้ในโฟลเดอร์ agency ผมจะใช้สกิลนั้นได้ก็ต่อเมื่อผมอยู่ในโฟลเดอร์ agency เท่านั้น แต่ถ้าผมอยากใช้มันตอนที่อยู่ในโฟลเดอร์แบรนด์ส่วนตัวล่ะ? Claude Code ไม่สามารถออกไปข้างนอกได้ มันทำได้ในทางเทคนิค ถ้าคุณสั่งมัน แต่ มันจะไม่เดินออกไปอ่านแล้วเอามาใช้ ไม่ทำแบบนั้น

แต่ global ทำอะไร? มันไม่ได้ทำงานในโฟลเดอร์เฉพาะของคุณ มันทำงานในขอบเขตทั้งหมดของคอมพิวเตอร์ของคุณ หรือไฟล์ทั้งหมดของคุณ มันไม่ใช่สิ่งที่คุณมองเห็นได้จริงๆ คุณมีไฟล์ทั้งหมดบนเครื่องคุณ แต่มีไฟล์บางอย่างที่ผมอยากให้คุณเห็น แม้มันจะมองไม่เห็น ดูนะ พวก global ของผม คุณมองไม่เห็น พวกมันไม่ใช่สิ่งที่มองเห็นได้

สิ่งที่คุณทำได้คือ กด command shift period ดูนะ command shift period โอ๊ย นี่มันน่าอาย ทำไมมันไม่โผล่มาวะ command shift period เอาล่ะ เจ๋ง เห็นไหม ไฟล์เหล่านี้ทั้งหมดถูกซ่อนไว้ ผู้ใช้ทั่วไปมองไม่เห็น คุณมี MCP servers อยู่ คุณมีไฟล์ ENV ที่เก็บ secret keys ทั้งหมดของคุณ แล้วคุณจะเห็นไฟล์ CLAUDE.md ตรงนี้ ถ้าผมเปิดมันขึ้นมา คุณมี agents ทั้งหมดของคุณ มี backup ทั้งหมดของคุณ ซึ่งก็คือสกิลนั่นเอง แล้วดูตรงนี้ ถ้าผมเลื่อนลงไปที่ skills อยู่ไหนนะ? ปัง! นี่คือ global skills ทั้งหมดที่ผมมี

ทุกครั้งที่ผมเปิดโปรเจกต์ขึ้นมา สมมติว่านี่คือ daily content research ของผม ตรงนี้ ผมสามารถเรียกมันขึ้นมาได้ในโฟลเดอร์ Noavarner AI ใช่ไหม? หรือสมมติว่าผมไปที่คอมมูนิตี้โรงเรียนของผม ที่เราสร้างไว้เป็นตัวอย่าง ผมอยู่ในโปรเจกต์ใหม่ มันเข้าถึง daily content research ไม่ได้สินะ? เห็นไหม? ผมเข้าถึงสกิลพวกนี้ได้ทั่วทุกไฟล์ของผม ต่างจากในโปรเจกต์ที่ผมเข้าถึงได้เฉพาะบางสกิลในบางโปรเจกต์เท่านั้น

แล้วคุณจะแก้ไขมันยังไง? สมมติว่าผมอยู่ในโฟลเดอร์โรงเรียน และด้วยเหตุผลบางอย่าง ผมไม่เห็น content machine เพราะมันไม่โผล่มา แต่ผมรู้ว่ามันอยู่ในนี้ ถ้าผมไปที่ content machine แล้วผมไม่แน่ใจว่าเราใส่ไว้ตรงไหน เราทำให้มันเป็น global จริงๆ นะ แล้วทำไม Claude Desktop ไม่ดึงมันขึ้นมาล่ะ? บางทีมันอาจจะยาวเกินไป แต่สมมติว่าผมอยากให้สกิลนี้เป็น project side เท่านั้น และไม่อยากให้มันเป็น global คุณช่วยเอาสกิลนี้ไปใส่ไว้ในโฟลเดอร์ที่เรากำลังทำงานอยู่ตอนนี้ได้ไหม? ผมอยากให้สกิลนี้ใช้ได้เฉพาะในโปรเจกต์นี้เท่านั้น ไม่อยากให้มันเป็น global

แล้วผมก็จะพรอมป์มันไปแบบนั้น และมันก็ทำได้ทั้งสองทาง ถ้าคุณอยากให้มันใช้ได้ทั่วทุกไฟล์หรือทุกโปรเจกต์ของคุณ มันก็จะทำ แต่ดูนี่สิ มันกำลังค้นหา content มันมองหาทุกอย่าง รวบรวมทุกอย่าง สกิลนี้มีอยู่แบบ global ขอให้ค้นหาและคัดลอกมันไปยังโฟลเดอร์คำสั่งเฉพาะโปรเจกต์ แล้วเราจะให้มันไปตรงนั้น เราจะอนุญาต เพราะมันอ่านไฟล์อื่นๆ ทั้งหมดของเรา

พอผมรู้เรื่องนี้ มันยากมากที่จะหาคำตอบ เพราะผมสังเกตตลอดว่าทำไมสกิลของผมหายไปตลอด มองไม่เห็นซักที แต่ที่จริงหลายตัวมันแค่นั่งอยู่ในโฟลเดอร์บางโฟลเดอร์เท่านั้น เอาล่ะ ดูเหมือนมันเจอแล้ว หรือมันเจอมันแบบ global มันสร้างมันในโฟลเดอร์คำสั่งเฉพาะโปรเจกต์ มันก็แค่ย้ายมันมาอยู่ฝั่งโปรเจกต์แทนที่จะเป็น global ทั้งคอมพิวเตอร์ของผม แทนที่จะอยู่ในโฟลเดอร์ธรรมดาๆ แล้วผมจะลบมันก็ได้ถ้าอยาก ผมจะไม่ลบนะ ไม่มีเหตุผลต้องทำ

มันประมาณนี้แหละ จุดประสงค์ของบทเรียนนี้ คือการโชว์ให้เห็นว่า บางครั้งเวลาคุณสร้างสกิลในโปรเจกต์ คุณอาจจะต้องติดตั้งมันแบบ global เพื่อให้เข้าถึงได้จากบางที่ "ขอติดตั้งสกิลนี้แบบ global เพื่อให้ผมเข้าถึงมันได้ทุกที่" แค่นั้นแหละ แล้วมันจะอัปโหลดมันลงในไฟล์ลับบนคอมพิวเตอร์ของคุณ ที่คุณจะเข้าถึงมันได้ทุกที่ที่คุณไปโดยใช้ Claude

นั่นคือทั้งหมดสำหรับบทเรียน project กับ global skills ครับ เป็นอะไรที่แปลกๆ นิดหน่อยแต่เข้าใจง่าย และสำคัญที่ต้องเข้าใจ ผมเองก็พลาดเรื่องนี้ตอนที่สร้างสกิล เพราะฉะนั้นเรื่องนี้น่าจะช่วยคุณได้มาก แล้วเจอกันในโมดูลหน้า ซึ่งเราจะเริ่มเชื่อมต่อ Claude Code เข้ากับเครื่องมือทั้งหมดของคุณ
