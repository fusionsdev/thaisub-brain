## บทนำ
วิดีโอนี้สอนตั้งค่า AI agent ที่สร้างและเตรียมโพสต์รูปภาพสำหรับโซเชียลมีเดียผ่าน Telegram โดยใช้ n8n ร่วมกับ OpenAI, Anthropic, Google Sheets (ระบบเทมเพลตโพสต์), Google Drive และโมเดลสร้างภาพ รวมถึงการอัปโหลดรูปภาพของตัวเองเพื่อใช้ในโพสต์

## คำแปลเต็ม

ในวิดีโอนี้ผมจะแสดงวิธีประกอบ AI agent ที่สร้างและเผยแพร่โพสต์รูปภาพโซเชียลมีเดียโดยใช้แอป Telegram มาเริ่มกันเลย สิ่งที่คุณต้องมีคือบัญชี n8n ถ้าคุณยังไม่มีคุณสามารถสมัครทดลองใช้ฟรีได้ ผมคิดว่าประมาณสองสัปดาห์ แล้วหลังจากนั้นจ่ายประมาณ $24 ต่อเดือน คุณมีเวลาสองสัปดาห์เพื่อทดสอบว่าคุ้มไหม และสิ่งแรกที่คุณทำคือคลิก get started for free จากนั้นเมื่อสมัครเสร็จแล้วคลิก create a workflow แล้วไปที่ส่วน resources ใน AI agent templates เพื่อตั้งค่าส่วนที่ 1 คุณดาวน์โหลด AI agent แล้วคลิก import from file แล้วอัปโหลดไฟล์ที่เพิ่งดาวน์โหลด ตอนนี้ workflow ทั้งหมดจะถูกนำเข้า แล้วเราแค่ต้องเชื่อมต่อเครื่องมือไม่กี่ตัว

เริ่มจากเครื่องมือแรกที่เห็นตรงนี้ ผมจะอธิบายเล็กน้อยว่ามันทำงานอย่างไรระหว่างที่เราตั้งค่าเครื่องมือเหล่านี้ แต่ฟีเจอร์หลักคือมันทำงานกับ Telegram ดังนั้นคุณต้องมีแอป Telegram ถ้าคุณยังไม่มีก็ดาวน์โหลดลงคอมพิวเตอร์และโทรศัพท์ แล้วทำตามขั้นตอนที่ผมทำตรงนี้และเชื่อมต่อกับ workflow ที่เราเพิ่งนำเข้า มาตั้งชื่อกันก่อน workflow นี้คือ demo เหมือนการสาธิต ไปที่ Telegram trigger ถ้าคุณไม่เคยใช้มัน คุณต้องคลิก create new credential ใส่ access token ผมจะแชร์รายละเอียดว่าหาได้จากที่ไหนในวิดีโอสอนเทคนิค get API from Telegram ดูวิดีโอนี้ก่อนแล้วกลับมา แล้วคุณก็ไปเอา access token ซึ่งคืออันนี้ ในบัญชีของผมมันมีลักษณะแบบนี้ ผมจะคัดลอกมัน แล้ววางลงตรงนี้ แล้วมันจะเปลี่ยนเป็นสีเขียว เมื่อมันเป็นสีเขียวแสดงว่าเชื่อมต่อแล้ว ตอนนี้มันคือบัญชี Telegram หมายเลข 9

สิ่งนี้สำคัญที่ต้องรู้ เพราะผมต้องแน่ใจว่าหมายเลข 9 ถูกเลือกจากดรอปดาวน์ ผมต้องเข้าไปในทุกโมดูล ถ้าคุณมีบัญชีเดียว มันอาจเลือกให้อัตโนมัติ แต่ผมจะเปลี่ยนในทุกโมดูล Telegram เหล่านี้ บัญชี Telegram หมายเลข 9 เรามีอีกอันตรงนี้ หมายเลข 9 ไปทางขวา นี่คือเครื่องมือ Telegram อีกอัน สลับเป็นหมายเลข 9 อีกอันตรงนี้ แล้วไปที่ส่วนนี้ นี่คือจุดสิ้นสุด และเรามีโมดูล Telegram สี่โมดูลที่ต้องเลือกบัญชี Telegram ที่ถูกต้อง ถ้าคุณมีบัญชีเดียวและเชื่อมต่ออันแรกแล้ว คุณจะเห็นเพียงบัญชีเดียว คุณจะไม่เห็นเก้าบัญชี ถ้าง่ายแบบนั้นคุณก็เลือกอันแรกถ้ายังไม่ได้เลือก แล้วคลิก save

ต่อไปเราจะซูมเข้า สิ่งที่ต้องตั้งค่าต่อไปคืออะไร? เราต้องตั้งค่าแค่สวิตช์เหล่านี้ ไม่มีอะไรต้องเปลี่ยน ตรงนี้ OpenAI คุณต้องเชื่อมต่อบัญชีของคุณ ถ้าคุณยังไม่ได้ทำ ใส่ API key คุณจะพบวิดีโอสอน API keys ทั้งหมดในส่วน technical tutorials แล้วมันก็เชื่อมต่อ แล้วคุณต้องไปตรงนี้ นี่คือโมเดล OpenAI อีกอัน ตรงนี้คุณแค่เลือกบัญชีที่เพิ่งเชื่อมต่อ แล้วไปขั้นตอนถัดไป

ขั้นตอนถัดไปคือโมเดล Anthropic chat ตรงนี้คุณต้องสร้าง credential ใหม่ด้วย ใส่ API key จาก Anthropic และคุณจะพบมันในส่วน technical tutorial เมื่อทำเสร็จแล้ว สิ่งถัดไปที่เราต้องการคือ Google Sheet ตรงนี้คุณต้องนำเทมเพลตจากด้านล่างวิดีโอนี้ คลิกแล้วมันจะเปิด มันจะเปิดชีตนี้ แล้วคลิก make a copy และตั้งชื่อเฉพาะให้มัน เรียกมันว่า Setup demo แล้วเราจะเข้าไปข้างใน ขยายอีกหน่อย และโมดูล Google ทั้งหมดเหล่านี้เราต้องเลือก Google Sheet ที่ถูกต้องที่เพิ่งสร้าง

เข้าไปตรงนั้น คุณต้องลงชื่อเข้าด้วย Google ตรวจสอบให้แน่ใจว่าเป็นบัญชีเดียวกับที่มี Google Sheet นี้ คลิกตรงนี้ มันจะให้ลงชื่อเข้า แล้วเลือกจากรายการ แล้วเลือกเอกสาร แล้ว Google Sheet ที่คุณเพิ่งเปลี่ยนชื่อจะปรากฏตรงนี้ เห็นไหม มันชื่อ setup demo นั่นคือชื่อของมัน มันใช้ได้สำหรับผม และตรงนี้ผมต้องเลือกชีตที่ถูกต้องอีกครั้ง ตรงนี้คือ templates ผมจะบอกในอีกสักครู่ว่าชีตทำงานอย่างไรเพื่อให้คุณเข้าใจสิ่งที่เราทำอยู่

จาก templates ตรงนี้เรามีสองส่วน เรามี templates ซึ่งเป็นเหมือนแม่แบบโพสต์ เมื่อคุณบอก AI agent ของคุณให้สร้างโพสต์ให้ มันจะถามว่าคุณต้องการโครงสร้างแบบไหน แล้วมันจะสร้างไอเดียสำหรับโพสต์ตามตัวอย่างที่พิสูจน์แล้ว และคุณสามารถขยายคลังแม่แบบโพสต์นี้ได้โดยการคุยกับ AI agent ซึ่งผมจะแสดงในอีกสักครู่ และโมดูลเหล่านี้ทำให้ AI agent ทำสิ่งเหล่านี้ได้: อ่านแม่แบบ เพิ่มใหม่ ลบของเดิม ตอนนี้ตรงนี้ไปยังส่วนถัดไป ที่นี่โพสต์ที่สร้างทั้งหมดจะถูกบันทึก นี่สำคัญสำหรับกระบวนการเผยแพร่ ตรงนี้คุณต้องเลือกชีตที่ถูกต้อง และอันนี้ก็เป็นชีตที่ถูกต้องแล้ว ดี คุณไม่ต้องทำอะไรตรงนี้ และอันถัดไป ชีต stat ในดรอปดาวน์ถูกเลือกแล้ว ตรงนี้ generate posts ด้วย และตอนนี้ผมคิดว่ายังมีอีกสองอัน ตรงนี้ในส่วนนี้เราต้องเลือกอันแรกให้ถูกต้อง เราอยู่ในกระบวนการเผยแพร่ ตรงนี้เราบอก AI agent ให้เผยแพร่โพสต์นี้ แล้วมันจะดึงจากชีตที่มี URL ที่เรามี แล้วส่งต่อไปยังระบบเผยแพร่อัตโนมัติของเรา ตรงนี้เราก็ต้องเลือกอันนี้ด้วย ดี คลิก save

และตอนนี้มีอีกสองสิ่งที่ต้องเชื่อมต่อในตอนนี้ คือ Google Drive เพื่อเชื่อมต่อ Google Drive คุณต้องไปตรงนี้แล้วคลิก create a new แล้วเชื่อมต่อ Client ID และ client secret คุณจะได้สิ่งนี้โดยดูวิดีโอนี้ก่อน: connect Google Drive to n8n นี่คือวิธีที่คุณได้ข้อมูลนี้ ใส่ลงตรงนี้แล้วคลิก save แล้วมันจะเชื่อมต่อ แล้วคุณก็สร้างบัญชี Google Drive ได้ แล้วคุณจะสามารถเลือกมันจากตรงนี้ และตรงนี้ด้วย บัญชี Google Drive ทั้งหมดจะเชื่อมต่อ

แล้วสาขานี้ตรงนี้ Google Drive ทำไมเราถึงมี Google Drive? นี่คือเมื่อคุณอัปโหลดรูปภาพของคุณเอง เมื่อคุณอัปโหลดรูปภาพของคุณเอง ไปที่ social media agent ของผม นี่คืออันที่ผมเชื่อมต่อ เมื่อผมอัปโหลดรูปภาพ มันจะถูกใช้ เพื่อให้มันอยู่ในโพสต์โซเชียลมีเดียของผม และเมื่อผมได้ยินเสียง ตรงนี้คือสาขาที่จะสร้างภาพให้ AI และภาพนี้จะถูกอัปโหลดไปยังไดรฟ์ของเรา

สิ่งสุดท้ายที่ต้องทำก่อนทดสอบคือ HTTP request ตรงนี้เราต้องใส่ bot API ด้วย คุณต้องกลับไปที่ bot father แล้วดึงโทเคน คัดลอกข้อความที่เลือก แล้ววางลงในช่องว่างตรงนี้ แล้วกลับไป นี่สำคัญสำหรับการรับรูปภาพจาก Telegram และดาวน์โหลดมาให้เรา เพื่อใช้ในกระบวนการเผยแพร่และอัปโหลดไปยัง Drive แค่นั้นสำหรับตอนนี้ เราสามารถสร้างโพสต์ได้แล้ว เราสามารถทดสอบรอบแรกได้ และเมื่อเราสร้างโพสต์แล้ว เราก็ไปต่อที่การตั้งค่ากระบวนการเผยแพร่

แต่มาคลิก test workflow ก่อน แล้วผมกลับไปที่ Telegram social media ของผมซึ่งอยู่ตรงนี้แล้ว ผมสามารถทดสอบฟีเจอร์ทั้งหมดที่เราตั้งค่าไว้ได้ สิ่งแรกที่ผมทำได้คือถามว่า ฉันมีแม่แบบโพสต์อะไรในชีตของฉันบ้าง แล้วมันจะตรวจสอบชีตตรงนี้ มันควรตรวจสอบชีตใดชีตหนึ่ง แล้วให้รายการแม่แบบที่ผมมีสำหรับโพสต์ของผม เพราะผมจะได้ตัดสินใจ ตอนนี้ผมมีสามแม่แบบ นี่คือแม่แบบมาตรฐานที่ผมใส่ไว้

อีกอย่างที่เจ๋งและมีค่ามากสำหรับแม่แบบคือ เมื่อผมอยู่บนโซเชียลแล้วเจอโพสต์ที่ทำผลงานได้ดีของคนอื่น ผมสามารถหยิบโพสต์นั้นแล้วเพิ่มเป็นแม่แบบได้ ผมสามารถเพิ่มโพสต์นี้เป็นสไตล์โพสต์ใหม่ และตอนนี้ผมต้องคลิก test อีกครั้ง เรายังอยู่ในโหมดทดสอบ เพราะผมจะได้เห็นโดยตรงว่ามี error ไหม และตอนนี้มันควรเพิ่มแม่แบบโพสต์ และเราสามารถตรวจสอบได้โดยเข้าไปตรงนี้ มันเพิ่มแล้ว และมันให้ ID เฉพาะที่ผมระบุได้

ขั้นตอนต่อไปคือสร้างข้อความโพสต์ เข้าไปตรงนี้ มันบอกว่าทำแล้ว แล้วถามว่า คุณต้องการสร้างโพสต์โดยใช้แม่แบบไหม? ฉันต้องการ สร้างโพสต์โดยใช้แม่แบบ product หัวข้อคือการลดน้ำหนักด้วยอาหารจากพืช แล้วตอนนี้มันควรสร้างโพสต์ให้เรา และให้ข้อความตามแม่แบบที่พิสูจน์แล้ว คุณเห็นไหม มันยังให้สิ่งที่สำคัญคือ โพสต์ที่สร้างแต่ละอันมี post ID เฉพาะ เพราะมันสำคัญสำหรับกระบวนการเผยแพร่ในภายหลัง

และตอนนี้สิ่งแรกที่ผมทำได้คือขอให้มันเปลี่ยนบางอย่าง ผมเพิ่มอีกหนึ่งประเด็นได้ อย่างที่เห็น มันยังดูเกี่ยวกับการตลาดมากไป ขอให้โพสต์นี้เกี่ยวข้องกับการกระทำมากขึ้น สำหรับผู้ชมที่กำลังมองหาการลดน้ำหนัก โพสต์ของคุณยังพูดถึงเรื่องการตลาดมากเกินไป มาดูว่ามันปรับได้ไหม แล้วเราก็บอกให้เผยแพร่โพสต์ได้ ตรงนี้คุณเห็นว่าตอนนี้มันเกี่ยวกับการลดน้ำหนักมากขึ้น และมันให้ ID ใหม่ ตอนนี้ผมปรับเพิ่มเติมและปรับแต่งได้ แล้วบอกได้ว่า: ควรเผยแพร่บนแพลตฟอร์มไหน? ตอนนี้เราเลือกทั้งหมดใช่ไหม ผมอยากเผยแพร่บน Instagram และ Facebook กรุณาบันทึกสิ่งเหล่านี้ด้วย รวมถึงข้อความโพสต์ มาดูว่ามันทำได้ไหม ปกติมันทำได้ ตอนนี้ผมต้องทดสอบ workflow อีกครั้ง แล้วมันควรบันทึกโพสต์และแพลตฟอร์มที่ผมต้องการเผยแพร่ มาดูว่ามันทำทั้งหมดพร้อมกันได้ไหม

มีปัญหาตรงนี้เรื่องการแมตช์ชื่อคอลัมน์ บางครั้งสิ่งนี้เกิดขึ้นได้ นี่คือเหตุผลที่เราตรวจสอบ ถูกต้องไหม มันบอกว่าผมต้องรีเฟรชสิ่งเหล่านั้น ดี มาทดสอบ workflow อีกครั้ง แล้วบอกมันอีกครั้ง ข้อความเดิม สำหรับโพสต์นี้ ตรวจสอบให้แน่ใจว่าบันทึกข้อความแล้วเพราะมันไม่ได้บันทึก รวมถึงแพลตฟอร์มด้วย ตอนนี้มาดู นี่คือสิ่งที่เรากำลังดู มันรันได้โดยไม่มี error แล้ว ดูดี และถ้าคุณดูชีต คุณจะเห็นว่ามันถูกบันทึกพร้อมกับแพลตฟอร์ม ดี

และสิ่งสุดท้ายคือการสร้างภาพ ใช่ไหม? เราสามารถพูดว่า generate แล้วรันมัน ตอนนี้มันควรไปที่สาขาบนสุดนี้ เพราะมันจะระบุคีย์เวิร์ด generate แล้วควรไปที่ด้านบนอย่างที่เห็น แล้วมันจะรันโมเดลสร้างภาพ สร้างภาพ อัปโหลดไปยัง Google Drive ให้ลิงก์ Google กับผม แล้วผมขอให้มันบันทึก คุณเห็นไหม มันให้ข้อความโพสต์กลับมาอีกครั้ง ผมคลิกได้ แล้วมันก็ดาวน์โหลด ดี นั่นเป็นสัญญาณว่ามันทำงาน มันให้ลิงก์ที่ถูกต้อง

วิธีที่ภาพนี้ถูกสร้างคือ ตัวสร้างภาพนี้ เมื่อคุณเปิดมัน มันใช้ข้อความโพสต์เป็นตัวตั้งต้น และมีพารามิเตอร์สองสามตัวที่ควรรวม คน และอื่น ๆ ตอนนี้คุณสามารถเปลี่ยน image prompt ของคุณจนกว่าจะได้ภาพที่คุณชอบ นั่นคือวิธีที่ผมทำ สิ่งที่คุณทำได้อีกคืออัปโหลดรูปภาพของคุณเอง คลิก แล้วผมก็อัปโหลดรูปภาพของตัวเองได้ เช่นรูปของฉันหรืออะไรก็ได้ ตรวจสอบให้แน่ใจว่าถูกต้อง แล้วอัปโหลด แล้วตรงนี้คุณจะเห็นว่ามันจะ trigger อันนี้ แล้วมันจะอัปโหลดภาพและให้ลิงก์ Google Drive แก่ผม ตอนนี้มันอยู่บนไดรฟ์แล้ว

สิ่งสำคัญเพียงอย่างเดียวที่ต้องบอกคือ: ควรบันทึก URL ไหนลงในโพสต์? ผมต้องได้ URL ที่แน่นอนแล้วบอกมันว่า บันทึก URL นี้ลงในโพสต์ แล้วคลิก test อีกครั้ง แล้วตอนนี้มันควรบันทึกที่นี่ในช่องนี้ และเมื่อเราทำเสร็จแล้ว ส่วนแรกของ AI agent ของเราก็ทำงาน เราสร้างได้แล้ว ตอนนี้มัน C ผมคิดว่าปัญหาคือเราต้องรีเฟรชคอลัมน์ที่นี่ด้วย มาทำกัน คลิก save เห็นไหม มันยังไม่ได้บันทึก URL เราก็แค่ลองใหม่ ให้มันอีกครั้ง ทดสอบ workflow ตอนนี้มันควรไปตรงนี้และทำงาน มันยังไม่ทำงาน โอเค อาจเป็นเพราะมันบันทึกไปแล้วแต่สับสน เพราะมีหลายโพสต์ที่มีค่าเหมือนกัน ผมเลยระบุอันไหนไม่ชัดเจน มาลองอีกครั้ง ทำอีกครั้ง ดูว่าครั้งนี้มันระบุได้ไหม มันสำคัญมากที่จะทดสอบอย่างถูกต้อง มาดูว่าครั้งนี้ทำงานไหม ผมหวังว่ามันจะ ดูดี และมันคือภาพที่ถูกต้อง ดี!
