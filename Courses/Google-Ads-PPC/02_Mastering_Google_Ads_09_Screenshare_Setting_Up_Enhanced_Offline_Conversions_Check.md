## บทนำ

วิดีโอแบบ Screen Share จากคอร์ส Mastering Google Ads — พาเดินดูการตั้งค่า Enhanced Conversions แบบ Offline จริงในบัญชี Google Ads: เริ่มจากสร้าง Conversion Action ใหม่ใน Google Ads (แบบ Tag เอง ไม่ใช่นำเข้าจาก GA4), สร้าง Tag ใน Google Tag Manager (Google Ads Conversion Tracking, Conversion Linker, Enhanced Conversion Data Report), ทดสอบด้วย Tag Assistant, แล้วปิดท้ายด้วยการเชื่อม Google Sheet สำหรับอัปโหลดข้อมูลลีดและยอดขายกลับเข้า Google Ads เพื่อให้ระบบจับคู่กับอีเมลแบบ hashed และเห็นมูลค่าคอนเวอร์ชันจริง

## คำแปลเต็ม

เอาล่ะ ผมอยากพาคุณดู Walkthrough ของ Conversion Tracking ที่ผมตั้งไว้ใน Google Ads ของผม — ระบบที่รับคอนเวอร์ชันจากฟอร์มอีเมล แล้วโหลดกลับขึ้นไปใน Google Ads เพื่อให้ผมเห็นมูลค่าคอนเวอร์ชัน (conversion values) และผมอยากโชว์ให้ดูเร็วๆ ว่านี่คือสิ่งที่ท้ายที่สุดเราอยากเห็นผ่านตรงนี้ — ผมจะเปลี่ยนมันเป็น Primary แต่ว่าผมตั้งไว้เป็น Secondary ไว้ก่อน จนกว่าจะตั้งค่าเสร็จ — คือคุณจะเห็นได้เลยว่าเรามี Conversion Value ที่มาจากการส่งฟอร์มของเรา หรือถ้าผมจะเรียกมันว่าอะไรก็ตาม

เป้าหมายสูงสุดคือ เราอยากให้ Conversion Action ไปไกลกว่าแค่ตอนที่มีคนกรอกฟอร์มแบบนี้ — ซึ่งหลายคนอาจเคยเห็นมาก่อน — สิ่งที่เราทำคือเราอัปโหลดข้อมูลนี้ แล้วอย่างที่เห็น เราเพิ่มคอนเวอร์ชันเข้าไป แล้วมันก็โหลดข้อมูลจากยอดขายที่รวมกันเหล่านี้กลับเข้า Google Ads

สิ่งที่เรากำลังทำคือ เรานำข้อมูลคอนเวอร์ชันให้ไปไกลกว่าแค่ตอนที่คนกรอกฟอร์ม แล้วพามันไปถึงจุดที่คนแปลงเป็นยอดจริงๆ แต่พลังของมันคือ ยิ่งเราป้อนข้อมูลคอนเวอร์ชันกลับเข้าไปใน Google มากเท่าไหร่ มันก็ยิ่งบ่งชี้ได้ชัดเจนขึ้นว่า ใครบ้างที่กรอกฟอร์ม — โดยเฉพาะอย่างยิ่งเมื่อเราใช้แคมเปญแบบ Performance Max หรือกลยุทธ์การเสนอราคาแบบ Maximize Conversion Value — Google จะสามารถกำหนดเป้าหมายผู้ใช้ที่มีแนวโน้มจะไม่เพียงแค่กรอกฟอร์ม แต่ท้ายที่สุดแล้วแปลงเป็นยอดขายจริงได้ดีขึ้น

ผมอยากเตือนอย่างแรงเลยว่า ขั้นตอนที่ผมกำลังจะพาคุณทำ อาจไม่ทำงานกับเว็บไซต์ของคุณ และมันแทบเป็นไปไม่ได้ที่ผมจะให้วิธีที่ใช้ได้กับทุกเว็บไซต์ เหตุผลก็เพราะมีองค์ประกอบมากมายที่ต้องพิจารณา โดยเฉพาะวิธีที่เว็บไซต์ของคุณส่งข้อมูล และ Triggers ที่ใช้ มันค่อนข้างเป็นไปได้ที่คุณอาจต้องคุยกับนักพัฒนาเว็บของคุณ — เหมือนที่ผมทำ — เพื่อให้เขาช่วยทำขั้นตอนเหล่านี้ให้เสร็จ

อีกประเด็นที่อยากพูดคือ ถ้าคุณใช้ระบบขายของบุคคลที่สามอย่าง Salesforce หรือถ้าคุณใช้ตัวอื่น — มันมีอยู่มากมายนับไม่ถ้วน — ถ้าคุณค้นหา "import enhanced conversion values into Google Ads" แล้วใช้ระบบของคุณ คุณจะเห็นว่าหลายๆ ตัวมีเอกสารซัพพอร์ตบางอย่างอยู่แล้ว และอีกอย่างที่ผมอยากแนะนำคือ ติดต่อ CRM ของคุณ เพราะจะมีโซลูชันใหม่ๆ ออกมาเรื่อยๆ

ณ เวลาที่อัดคลิปนี้ นี่เป็นกระบวนการที่ค่อนข้างใหม่ มันใช้เวลาผมและทีมหลายเดือนกว่าจะได้มาถึงระดับนี้ เราจะอัปเดตมันเรื่อยๆ เมื่อมีข้อมูลเข้ามามากขึ้น แต่นี่คือกระบวนการปัจจุบันที่เรามี และอย่างที่ผมบอก มันต่างกันไป — เราทำสิ่งนี้ข้ามบัญชีห้าบัญชี มีบางอย่างที่เราต้องปรับต่างกัน นี่คือเวอร์ชันที่สะอาดที่สุดที่เราทำได้ แต่ผมขอบอกเลยว่า มีโอกาสสูงมากที่คุณจะต้องให้ทีมพัฒนาของคุณช่วย เพื่อให้มันทำงานได้จริง

เอาล่ะ มีองค์ประกอบหลักสามอย่าง: คุณต้องตั้งค่าบางอย่างใน Google Ads, ตั้งค่าบางอย่างใน Google Tag Manager แล้วก็กลับมาตั้งค่าเพิ่มเติมใน Google Ads อีกครั้ง

สิ่งที่เราอยากทำในส่วนแรกคือ ตั้งค่า Google Ads Conversion และขอย้ำว่า นี่ไม่ใช่การนำเข้าจาก Google Analytics 4 หรือ Google Analytics เพราะสิ่งที่เราต้องการคือ Conversion ID และ Conversion Label — ผมอยากโชว์ขั้นตอนการตั้งค่าขั้นแรกของสิ่งนี้ ซึ่งก็คือ Google Ads Conversion และจำไว้ว่า สิ่งที่เราอยากให้มันเป็น — นั่นคือตัวจริงที่ผมมีอยู่ — ผมอยากโชว์ให้เห็นว่า เราอยากให้มันไม่ได้มาจาก Google Analytics หรือ Universal Analytics แต่ถูกเก็บไว้ใน Google Ads เอง เพราะสิ่งที่เราต้องทำคือต้องได้ User ID ซึ่งก็คือ Conversion ID และ Conversion Label ซึ่งอยู่ตรงนี้

วิธีที่เราจะทำคือ ไปที่ New Conversion → เลือก Website → ใส่รายละเอียด → แล้วคลิก Scan ตอนนี้คุณจะเห็นว่าผมมี Conversion Action ตั้งไว้บนหน้านี้แล้ว ผมเห็นมันอยู่ แต่อย่างที่เราอยากทำคือ เพิ่มอันใหม่แบบ Manual เราอยากให้มันเป็น Contact หรือ Form Lead Submit — อันไหนก็ไม่สำคัญเท่าไหร่ ตอนนี้ผมจะพิมพ์ว่า Form Submit และจะสร้าง Tag ใหม่ตรงนี้ เพราะเรามี tag เก่าอยู่แล้ว และเราอยากใช้ค่าที่ต่างกันสำหรับแต่ละคอนเวอร์ชัน เพราะเราจะตั้งค่ามันในภายหลัง

จากนั้นเราก็แค่เลื่อนลงมา และทำให้แน่ใจว่า Enhanced Conversions ถูกเปิดอยู่ แล้วคลิก Done และสิ่งที่เราอยากได้จากตรงนี้คือ ไปที่ Settings แล้วคลิก Save and Continue จากนั้นเราจะเข้าไปใช้ Google Tag Manager และเมื่ออยู่ใน Google Tag Manager คุณต้องคัดลอก User ID นี้ และโค้ดนี้จากตรงนี้

เราได้ตั้งค่านี้ไว้แล้วตอนนี้ และผมจะตั้งมันเป็น Secondary — ส่วนของคุณให้เป็น Primary ไว้ เหตุผลที่ผมตั้งเป็น Secondary ตรงนี้ เพราะผมสร้างอันนี้เป็นตัวซ้ำ (duplicate) เพื่อยกตัวอย่างให้คุณดู ผมจะลบมันหลังเทรนนิ่งนี้จบ เพราะจริงๆ ผมตั้งค่ามันไว้แล้ว — และนี่คือ Conversion ID และ Conversion Label ที่เราต้องคัดลอก ตอนนี้ให้เปิดหน้าต่างนั้นค้างไว้

เราได้ตั้งค่าส่วน Google Ads เสร็จเป็นอันแรก — ผมจะโชว์กระบวนการตั้งค่า Google Tag Manager ของคุณต่อ วิธีที่เราทำคือ ก่อนอื่นเราต้องเพิ่ม Tag ใหม่ใน Google Tag Manager ที่ชื่อว่า Google Ads Tags และนี่คือจุดที่เราต้องใช้ Conversion ID และ Conversion Label ที่ได้จาก Google Ads — อันนี้และอันนี้ สิ่งที่เรากำลังตั้งค่าคือ Tag ที่ชื่อ Google Ads Tags — คุณเห็นว่าผมตั้งมันเป็น Google Ads Conversion Tracking พร้อม Conversion ID และ Conversion Label แล้วเราก็มี User-Provided Data

ผมจะโชว์วิธีทำ — สิ่งที่ต้องทำคือ ไปที่ New — ผมจะเรียกมันว่า Google Ads แต่จะเติมคำว่า new ต่อท้ายไว้ คุณไม่จำเป็นต้องทำแบบนี้ แต่ผมทำเพื่อให้รู้ว่าต่างกัน — ไปที่ Google Ads แล้วเลือก Google Ads Conversion Tracking และจากตรงนั้นเราเข้าไปที่บัญชี Google ของเรา นี่คือจุดที่เราจะได้ Conversion ID แล้วก็ต้องมี Conversion Label ด้วย จากนั้นผมจะโชว์การตั้งค่าเหล่านี้ — คุณเก็บส่วนที่เหลือไว้ได้ แต่สิ่งที่เราต้องทำคือ เราต้องเลือก Include User-Provided Data from Your Website

เหตุผลที่มันสำคัญ เพราะมันจะอนุญาต — เมื่อมีคนกรอกฟอร์ม มันจะส่งอีเมลของเขาเข้าไปในข้อมูลของ Google เพื่อที่เราจะได้จับคู่กับข้อมูลที่เราอัปโหลดในภายหลัง สิ่งที่เราต้องทำตรงนี้คือ เลือก Include User-Provided Data — ผมมี User-Provided Data เป็นตัวแปรอยู่แล้ว — คุณจะต้องสร้าง Data Variable ใหม่ที่ชื่อว่า User-Provided Data แล้วเลือก Manual Configuration และใช้ Email (fields.email.value)

ให้ผมโชว์ส่วนนั้น — ตรงนี้ผมมีมันอยู่แล้ว แค่เลือก User-Provided Data แต่ถ้าคุณไปที่ New คุณจะเห็นว่ามันเป็นแบบ User-Provided และสิ่งที่คุณต้องทำคือ เลือกใช้ Email แล้วคลิก Save — ผมจะไม่คลิก Save เพราะเรามี User-Provided Data อยู่แล้ว นั่นคือวิธีสร้างตัวแปรใหม่ และเลือก Manual Configuration เพื่อใช้ Email

จากนั้นคุณตั้ง Trigger โดยใช้ Form Submission — หมายความว่าเมื่อเราอยู่ตรงนี้ เราไปที่ Form Submission แล้วคลิก Save จากนั้นเราต้องรัน Preview Test ใน Google Tag Manager วิธีทำคือ เข้าไปที่ Preview — ผมจะใช้ Google Ads Tags นี้เป็นตัวทดสอบ — เราเข้าไป แล้วเมื่ออยู่ในหน้าทดสอบ คุณต้องได้ URL ที่มีฟอร์มนั้นอยู่ เราจะใช้อันนี้ — ถ้าคุณไม่เคยอยู่ในหน้าต่างทดสอบของ Google มาก่อน ผมจะย่อมันลงหน่อยเพื่อให้เห็นชัดขึ้น คุณต้องแน่ใจว่าเห็น Tag Assistant ถูกตั้งขึ้นมาแล้ว จากนั้นคลิก Continue ที่หน้าต่างด้านหลัง — นี่ช่วยให้เรารู้ว่า Tag เหล่านี้ fire หรือไม่

Tag ที่เราอยากให้แน่ใจว่า fire แล้วคือ Google Ads Tags — เราอยากให้แน่ใจว่า Google Ads Tags ทำงานอยู่ สิ่งที่เราต้องทำต่อจากนี้คือรัน Preview Test ใน Google Tag Manager แล้วเมื่อคุณคลิกฟอร์มบนเว็บไซต์ของคุณ ให้ตรวจ Tag ที่ fire ว่าแสดงข้อความว่า "Enhanced Conversion Value ถูกส่งแล้ว" (has provided enhanced conversion value) ให้ผมโชว์ว่ามันหน้าตาเป็นอย่างไร

สิ่งที่ต้องทำคือ ไปกรอกอีเมลจริงบนฟอร์มนี้ — ผมจะไปที่ฟอร์ม — สิ่งที่ผมทำไว้คือเข้าไปกรอกฟอร์มให้ครบ แล้วคลิก Submit จากนั้นเรามาดูตรงนี้ แล้วเราจะเห็นว่า Google Ads Tag นี้ fire แล้ว สิ่งถัดไปที่ต้องทำคือตรวจ Tag ที่ fire เพื่อให้แน่ใจว่า Tag แสดงข้อความว่า Enhanced Conversion Value ถูกส่งแล้ว

ถ้าเราคลิกที่ Google Ads → เข้าไปที่ Form Submit ตรงนี้ คุณจะเห็นว่ามันแสดง Enhanced Conversion Value และกำลังแสดงอีเมลอยู่ และมันจะป้อนข้อมูลนั้นด้วยตนเอง — เราจึงต้องแน่ใจว่าเห็นอีเมลตรงนั้น เมื่อเข้าไปดูข้อความ Enhanced Conversion Value ที่ถูกส่ง คุณต้องแน่ใจว่ามันคืออีเมล และเหตุผลก็คือ เมื่อเราอัปโหลดข้อมูลกลับเข้าไปใน Google มูลค่าคอนเวอร์ชันจะถูกจับคู่กับอีเมลนั้น ดังนั้นมันสำคัญมากที่คุณต้องเห็นมันตรงนั้น

เมื่อทำเสร็จ นั่นคือ Tag แรกที่ต้องตั้งใน Google Tag Manager — จากนั้นเราต้องตั้งอีกสองตัว: Conversion Linker และเราต้องเพิ่ม Tag ใหม่ใน Google Tag Manager ที่ชื่อ Enhanced Conversion Data Report — ตัวพวกนี้ซับซ้อนขึ้นอีกนิด อย่างที่คุณคงเห็น — คุณคงเข้าใจแล้วว่านี่เป็นกระบวนการทางเทคนิคพอสมควร

สำหรับการตั้งค่า Conversion Linker — เราแค่ต้องตั้งมันเป็น Conversion Linker และมันจะเชื่อมทุกอย่างใน Google Ads อันนี้ค่อนข้างง่าย — ไปที่ New — ผมจะเรียกมันว่า New Conversions Linker — เลือก Conversion Linker แล้วสิ่งที่ต้องทำคือเปิดให้มันลิงก์บนทุกหน้าเว็บ (enable linking on all page URLs) และให้ Trigger บนทุกหน้า (All Pages) — สิ่งที่มันทำคือมันเป็นสิ่งที่ Google ใช้เชื่อมข้อมูลทั้งหมดเข้าด้วยกัน — แค่นั้นก็เสร็จขั้นตอน Conversion Linker

แล้วเราต้องเพิ่ม Tag ที่สามใน Google Tag Manager ชื่อ Enhanced Conversion Data Report — อันนี้ตรงนี้: Enhanced Conversion Data Report — เราต้องใช้ Conversion ID อีกครั้ง วิธีทำคือสร้างอันใหม่ — ผมจะเรียกมันว่า New — และ Tag Configuration ต้องเป็น Google Ads และต้องใช้ตัวนี้: Google User Provided Data Event — เรายังต้องใช้ Conversion ID จาก Google ซึ่งก็คืออันนี้ — จากนั้นเลือก User-Provided Data — ถ้าคุณยังไม่มี ให้ไปที่ New Variable แล้วสร้าง User-Provided Data อย่างที่ผมโชว์ก่อนหน้านี้ — และ Tag นี้ต้อง Trigger บนฟอร์ม ซึ่งอยู่ตรงนี้ — เมื่อตั้งเสร็จก็คลิก Save

เมื่อคุณตั้งครบทั้งสาม Tag แล้ว — Google Ads Conversion Tracking, Conversion Linker และ Enhanced Conversion Data Report — คุณต้องไปที่ Submit และถ้าคุณไม่กดเผยแพร่ Tag เหล่านี้จะไม่ทำงานบนเว็บไซต์ของคุณ ดังนั้นต้องแน่ใจว่าคุณได้เผยแพร่การเปลี่ยนแปลงเหล่านี้แล้ว

เมื่อเสร็จแล้ว ก็มาถึงขั้นตอนสุดท้าย — คุณต้องนำเข้าคอนเวอร์ชันใน Google Ads — ครั้งนี้เรากลับมาที่ Google Ads แต่คราวนี้คุณต้องตั้งค่าคอนเวอร์ชันใน Google Ads โดยใช้ตัวเลือก Import และเลือก Manual Import Using API หรือ CSV และเลือก Track Conversions from Clicks

เมื่ออยู่ใน Google Ads เราจะเข้าไปที่ — นี่คืออันที่ผมตั้งไว้: Converted Sales — แต่ผมจะโชว์วิธีที่เราตั้งค่า — ไปที่ New Conversion และใช้ตัวเลือก Import ในครั้งนี้ — เราจะใช้ Manual Import Using API หรือ CSV และต้องการ Track Conversions from Clicks — และมันจะถูกตั้งเป็นคอนเวอร์ชันแบบลีด (converted lead) — ในบัญชีของผมเราเรียกมันว่า Converted Sales

สำหรับอันนี้ คุณต้องใช้ค่าที่ต่างกันสำหรับแต่ละคอนเวอร์ชัน จากนั้นเราก็ไปตั้งค่า — เรายอมให้เป็น 90 วัน และใช้รูปแบบ Data-Driven — แล้วคลิก Create and Continue

ตอนนี้ยังมีการกระทำอีกอย่างที่ต้องทำ — เราต้องใช้ Google Sheet นี้ และถ้าผมโชว์จากตรงนี้ คุณต้องใช้สคริปต์/ชีตจากตรงนี้ — สิ่งที่เกิดขึ้นคือ เมื่อเรากรอกข้อมูลลงไป สิ่งที่คุณต้องทำคือคัดลอกชีตไปไว้ในบัญชีของคุณ — คุณต้องสร้างสำเนา (copy) ก่อน — แต่เมื่อตั้งค่าเสร็จ สิ่งที่จะเกิดขึ้นคือ — เมื่อผมพิมพ์อีเมลของผม ให้คุณดูแถวนี้ — คุณจะเห็นว่ามันเปลี่ยนเป็นอีเมลแบบ Hashed — เราเรียกมันว่าอีเมลแบบ hashed — เพื่อที่เมื่อเรามีคอนเวอร์ชันที่ตรงกัน นั่นคือสิ่งที่ Google รับไป

จำตอนที่เราทำ Preview Test ก่อนหน้านี้ได้ไหมครับ — เราเห็นอีเมลที่อยู่ใน Tag นั้น — นั่นคืออีเมลที่จะแสดงให้ Google เห็นว่าเป็นข้อมูลร่วมกัน (common theme) และถ้าเรามีมูลค่าคอนเวอร์ชัน มันก็จะใส่มูลค่านั้นเข้าไปใน Google Ads

สิ่งที่ต้องทำสุดท้ายเมื่ออยู่ใน Google Ads คือ เข้าไปที่ส่วนอัปโหลด — นี่คือสิ่งที่เรากำลังทำตรงนี้ — เรากำลังสร้าง Upload และเลือกแหล่งข้อมูลที่จะเป็น Google Sheet และเราต้องเชื่อมมันกับ Google Sheet ที่มีอยู่ — และสิ่งที่ต้องแน่ใจคือใน Google Drive ของคุณ คุณต้องแชร์ชีตนี้ผ่านตรงนี้ — วิธีทำคือ ใน Google Drive ของผม เมื่อคุณไปที่มัน คุณจะเห็นสิทธิ์การแชร์ตรงนี้ — ก่อนอื่นคุณต้องคัดลอกอีเมลและเพิ่มมันลงในการแชร์กับอีเมลนั้น

เมื่อทำเสร็จ คุณต้อง Link an Existing Google Sheet — สำคัญมากที่คุณต้องอยู่ในบัญชีเดียวกันอยู่แล้ว — มันต้องอยู่ในบัญชี Google เดียวกัน — เรามีอันนี้อยู่ตรงนี้ เราคลิก และสิ่งที่ต้องทำต่อคือคลิก Apply — จากนั้นมันจะทำงานและรันมัน — ผมเห็น error บางอย่าง แต่ผมรู้ว่ามันทำงานอยู่

และสิ่งที่ต้องทำต่อจากนั้นคือไปที่ Schedules — คุณสามารถเปลี่ยนได้ — ผมตั้งให้รันทุกวัน และอย่างที่ผมพูด เมื่อตั้งค่านี้แล้ว คุณจะเห็นค่าต่างๆ ไหลเข้ามาตรงนี้

อีกประเด็นที่อยากบอกคือ ในบางกรณีมันใช้เวลาถึงสอง สาม หรือแม้กระทั่งสี่สัปดาห์ กว่าเราจะเห็นข้อมูล และเหตุผลก็คือ เมื่อตั้งค่านี้แล้ว คุณต้องรอประมาณสามสี่สัปดาห์ก่อน แล้วค่อยดาวน์โหลดข้อมูลยอดขายของคุณและนำเข้าไปใน Google Ads เพราะมันจะไม่เก็บข้อมูลก่อนหน้านี้ ก่อนที่ Google Ads Tags และคอนเวอร์ชันเหล่านี้จะถูกตั้งขึ้น — ถ้ามีคนกรอกฟอร์มวันนี้ แต่ยังไม่แปลงเป็นยอดอีกสี่หกสัปดาห์ คุณก็จะยังไม่ได้รับข้อมูลคอนเวอร์ชันนั้น จนกว่าพวกเขาจะแปลงเป็นยอดจริง

ผมรู้ว่ามันเป็น Screen Share ที่เทคนิคัลมาก และผมยอมรับตรงๆ ว่าผมต้องการความช่วยเหลือเพิ่มเติมจากนักพัฒนาเว็บของผมเพื่อทำให้มันเสร็จ ถ้าคุณกำลังมีปัญหา สิ่งที่ผมจะทำคือขอความช่วยเหลือจากทีมพัฒนาเว็บของคุณ เพราะอย่างที่เราพูดในบทเรียน นี่เป็นกระบวนการที่เทคนิคัลมาก แต่มันมีคุณค่าสูงมาก นั่นคือเหตุผลที่ผมแนะนำให้คุณใช้เวลาให้ถูกต้องในบัญชี Google Ads ของคุณ — นี่คือวิธีที่เราเดินดูการตั้งค่า Enhanced Conversions ใน Google Ads
