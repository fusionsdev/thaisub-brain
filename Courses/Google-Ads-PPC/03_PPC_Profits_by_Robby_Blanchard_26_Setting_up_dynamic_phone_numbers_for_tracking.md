## บทนำ

วิดีโอนี้เป็นบทเรียนในคอร์ส Pay-Per-Call Profit System ของ Robby Blanchard ครับ เนื้อหาอธิบายวิธีตั้งค่า dynamic phone numbers (เบอร์โทรติดตามแบบไดนามิก) ซึ่งเป็นหัวใจของการติดตามผลแบบ pay-per-call เพราะเบอร์โทรคือจุดเกิด conversion และเป็นสิ่งที่ทำให้เราได้รับค่าคอมมิชชัน Robby สาธิตการขอเบอร์โทรจากเครือข่าย affiliate การนำเบอร์ไปแปะบน landing page หรือในปุ่ม call to action ของ quiz และข้อควรระวังสำคัญที่ห้ามใส่เบอร์โทรลงในโฆษณา Facebook ครับ

## คำแปลเต็ม

ยินดีต้อนรับกลับสู่บทเรียนถัดไปใน Pay-Per-Call Profit System ครับ ดีใจมากที่ได้มาอยู่ตรงนี้ เรายังอยู่ในโมดูลนี้ และในบทเรียนนี้ผมจะสอนเรื่องการตั้งค่า dynamic phone numbers เพื่อใช้ติดตามผล ถ้ายังไม่ได้ดูบทเรียนก่อนหน้า อย่าลืมกลับไปดูก่อนนะครับ เพราะเนื้อหาต่อเนื่องกัน

ในบทเรียนที่แล้วผมพูดถึงโครงสร้าง landing page ว่า landing page คืออะไร รู้จักกันอีกชื่อว่า bridge page และทำไมเราถึงต้องใช้มันในโฆษณาแบบ pay-per-call รวมถึงเทมเพลต landing page สำเร็จรูปที่ผ่านการพิสูจน์แล้วและเป็นมิตรกับข้อกำหนด (compliance) ใน Proven Toolkit ที่คุณเข้าถึงได้ในชุดคอร์สเรียน ผมยังพูดถึงการตั้งค่า ClickFunnels แบบคร่าวๆ เผื่อใครมี ClickFunnels อยู่แล้ว วิธีอัปโหลดเทมเพลตเพิ่มเติมที่มาพร้อมชุดคอร์ส รวมถึงข้อดีข้อเสียของการใช้ ClickFunnels วันนี้เราจะมาพูดถึงการตั้งค่าเบอร์โทรติดตามแบบไดนามิกกัน ไปดูกันเลยครับ

ประเด็นแรกคือ เบอร์โทรคือจุดเกิด conversion และมันคือสิ่งที่ทำให้เราได้รับเงิน เพราะฉะนั้นจำไว้ให้ขึ้นใจว่าเบอร์โทรคือกุญแจสำคัญของการติดตามผล มันคือเบอร์ติดตามเฉพาะ (unique tracking number) ที่เครือข่าย affiliate เป็นผู้ให้เสมอ ไม่ว่าเราจะโปรโมตกับเครือข่าย affiliate ไหน เบอร์โทรนั้นคือ tracking link ของเรา

จากตรงนั้น เราจะแนะนำให้เริ่มต้นกับ Market Call ครับ เพราะเรามีความสัมพันธ์ที่ดีกับเขา และวันนี้ผมจะสาธิตวิธีขอเบอร์โทรจากทางนั้นให้ดู

ถ้าคุณลงโฆษณา Facebook และโปรโมตแคมเปญ pay-per-call วิธีทำงานคือ เมื่อรันโฆษณา Facebook ผู้ชมจะคลิกโฆษณา แล้วจาก Facebook ก็จะพาไปที่ landing page ซึ่งบน landing page นี่แหละครับที่จะมีเบอร์โทรอยู่ พวกเขาจะเห็นเบอร์โทรและปุ่มคลิกเพื่อโทร ด้วยเบอร์ติดตามที่เรากำหนดไว้ จากนั้นสายจะถูกต่อเข้าไปยังทีมขายหรือ call center ของข้อเสนอ pay-per-call

ลองดูภาพรวมครับ เรามีโฆษณา Facebook ผู้ชมคลิกโฆษณาแล้วไปที่ landing page จาก landing page ไม่ว่าจะเป็นหน้าเดียวหรือมี quiz (เดี๋ยวผมจะสาธิตวิธีตั้งค่าให้ดูวันนี้) ตรงปุ่ม call to action ไม่ว่าจะอยู่ตรงไหน นั่นคือตำแหน่งที่เบอร์ติดตามจะไปอยู่ ลูกค้าจะโทรหาเบอร์นั้น ได้พูดคุยกับทีมขาย แล้วเราก็จะได้รับเงินจากเครือข่าย เมื่อพวกเขาโทรเข้าไป สายจะต่อถึงทีมขายหรือ call center ของข้อเสนอ pay-per-call

อีกหนึ่งสิ่งที่สำคัญมากที่ต้องจำไว้คือ Facebook ไม่ชอบให้มีเบอร์โทรอยู่ใน ad copy ของโฆษณา ถ้าเราเขียน ad copy ลงในโฆษณา Facebook (เดี๋ยวผมจะสอนตอนเรารันโฆษณาจริง) หรือแม้แต่ในข้อความ บนรูปภาพ หรือที่ไหนก็ตาม เราไม่ต้องการให้มีเบอร์โทรอยู่ในนั้น เพราะมันไม่ผ่านข้อกำหนด และอาจทำให้บัญชีถูกจำกัดหรือถูกแบนได้ เราจะใส่เบอร์โทรติดตามลงบน landing page เท่านั้น แค่นั้นจริงๆ ส่วน ad copy บอกได้แค่ learn more, get a quote, see if you qualify หรือ click now ห้ามมีเบอร์โทรและคำว่า call now อยู่บนโฆษณาโดยเด็ดขาด

มาตั้งค่า dynamic phone number กันเถอะครับ ผมจะโชว์วิธีขอเบอร์โทรจาก Market Call แล้วก็วิธีนำไปใส่ใน landing page ข้อควรจำข้อหนึ่งคือ เราต้องสร้างแคมเปญก่อนถึงจะได้เบอร์โทร หรืออย่างน้อยต้องมีข้อเสนอ (offer) ให้ผูกกับเบอร์โทร เพราะฉะนั้นจำไว้ว่าตอนที่เข้าไปในส่วนของ offer ถ้าเราไปที่ส่วน pay-per-call offers แล้วปล่อยให้ข้อมูลโหลด สมมติว่าผมอยากเลือก ผมจะเลือกอันนี้ ข้อเสนอ pest control (กำจัดแมลง) พอคลิกเข้าไปในส่วน pest control มันจะขึ้นว่า create a campaign ผมต้องสร้างแคมเปญจริงๆ ก่อนถึงจะได้เบอร์โทร

ผมจะกด create campaign ตรงนี้ ในบทเรียนก่อนหน้าผมพูดไว้ว่า ตอนที่เลือกข้อเสนอและต้องการขออนุมัติ เราต้องส่งข้อมูลด้วย คือต้องส่ง ad และเว็บไซต์หรือ landing page ของเราเข้าไปให้ตรวจ ดังนั้นเตรียมทุกอย่างให้พร้อมก่อนที่จะขออนุมัติข้อเสนอ

สำหรับตรงนี้ผมจะตั้งชื่อแคมเปญว่า pest control จากนั้นตรงที่เขียนว่า call ผมจะเช็คให้แน่ใจว่ามันเป็น calls โดยกด drop-down แล้วเลือก calls จากนั้นก็ต้องเลือก social media ด้วย แล้วกด get a phone ก็จะให้เลือกเบอร์ได้ เช่น 800, 866, 855 เลือกได้ตามต้องการ อย่าลืมกด get a phone number ตรงนี้ พอเสร็จมันจะขึ้นว่าประสบความสำเร็จในการเช่าเบอร์ (successfully rented a number) และให้เบอร์โทรกับเรามา จากนั้นเราต้องเข้าไปเพิ่ม advertising materials แล้วกดยอมรับว่าเราได้อ่านและเข้าใจกฎเกณฑ์แล้ว

ลองดูครับ ถ้าเรากด create and submit โดยที่ยังไม่ได้เพิ่มสื่อโฆษณา มันจะแจ้งเตือนว่าเราต้องเพิ่ม advertising materials ก่อน นั่นหมายความว่าเรายังไม่สามารถขออนุมัติข้อเสนอหรือขออนุมัติเบอร์โทรได้ จนกว่าเราจะเพิ่มสื่อเข้าไป นี่เป็นจุดสำคัญที่ต้องรู้ไว้ เพราะเวลาคิดว่าจะเลือกข้อเสนอไหนดี เราสามารถเข้าไปอ่านรายละเอียดข้อเสนอต่างๆ เลือกข้อเสนอที่สนใจ จากนั้นก็ไปทำ landing page และ ad copy ให้เสร็จทั้งหมด แล้วค่อยกลับมากดขออนุมัติ เพื่อจะได้เบอร์โทรและเพิ่ม advertising materials

ถ้ายังไม่ได้ดูบทเรียนก่อนหน้าในโมดูลนี้ อย่าลืมกลับไปดูนะครับ เพราะเนื้อหาต่อเนื่องกัน ผมพูดเรื่อง creatives วิธีสร้าง landing page และวิธีจัดเตรียมสื่อโฆษณา (advertising materials) ไว้ก่อนหน้านี้แล้ว

เราจะได้เบอร์โทรตรงขั้นตอนนี้แหละครับ เพราะผมจะเพิ่ม advertising materials แล้วกด create and submit เพื่อส่งตรวจสอบ แต่ตอนนี้ผมจะกลับไปที่ส่วนแคมเปญของผมก่อน เพราะผมมีแคมเปญหนึ่งอยู่แล้วและใส่ creatives ไว้แล้ว

เมื่อมีแคมเปญที่สร้างไว้แล้วและใส่ creatives เรียบร้อย ตรงนี้จะเห็นรายการแคมเปญของผม แสดง campaign ID และเบอร์โทรที่ผูกกับแคมเปญนั้น เราสามารถกด copy เบอร์นี้ได้ และนี่คือเบอร์ที่ผมจะนำไปใส่ใน landing page เราสามารถขอเบอร์เพิ่มได้อีกด้วย โดยขอได้ 10 เบอร์ต่อหนึ่งบัญชีหรือแคมเปญ แต่จริงๆ แล้วเราแค่ต้องการเบอร์เดียวก็พอ ข้อสำคัญคือเตรียมสื่อทั้งหมดให้พร้อมก่อนส่งขออนุมัติ เพื่อจะได้เบอร์โทรออกมา

ได้เบอร์โทรแล้วครับ ผม copy เบอร์นั้นมาแล้ว ตอนนี้ไปที่ส่วน landing pages ของ Pay-Per-Call Profit System กัน ถ้ายังไม่ได้ดูบทเรียนเรื่องการสร้างและแก้ไข landing page อย่าลืมกลับไปดูนะครับ ผมจะเข้าไปที่ landing pages แล้วกด editor เพื่อเข้าถึงเครื่องมือ ผมสร้างเว็บไซต์ของผมไว้แล้ว สำหรับการสาธิตนี้ผมจะเข้าไปที่หน้า auto insurance test จากนั้นเข้าไปแก้ไข landing page ที่สร้างไว้ในบทเรียนก่อนหน้า

จำไว้ว่าถ้าเป็น landing page หน้าเดียวและปุ่ม call to action อยู่หน้าแรก เบอร์โทรจะไปอยู่ตรงนั้น แต่ถ้าเป็น quiz เบอร์จะอยู่ที่ปุ่ม call to action ใน quiz หรือ survey ของเรา ผมจะเข้าไปที่ quiz settings แล้วเลื่อนลงมาที่สไลด์สุดท้าย สไลด์ที่ 4 ที่เขียนว่า you qualify แล้วกดแก้ไข ตรงนี้แหละที่ผมจะวางเบอร์โทร ผมจะวางเบอร์โทรลงไป แล้วกดบันทึก เช็คดูว่าบันทึกแล้วหรือยัง ยังไม่ทัน ผมจะทำใหม่ ผมไม่ต้องการ URL ตรงนั้น ต้องการแค่เบอร์โทร ผมจะพิมพ์ว่า call now แล้วใส่เบอร์โทรของผมตรงนี้ กดแก้ไขและวางเบอร์ลงไปให้แสดงข้างคำว่า call now เสร็จแล้วกดอัปเดตและบันทึก เช็คดูว่าบันทึกเรียบร้อย ใช่แล้ว ตอนนี้เห็นข้อความ call now แล้ว

จริงๆ เราสามารถใช้ปุ่มก็ได้ ไม่จำเป็นต้องเป็นข้อความธรรมดา แต่ผมจะบันทึกแบบนี้แล้วโชว์ให้ดูว่าหน้าตาเป็นยังไง กดบันทึก และจำไว้ว่าเวลาแก้ไข landing page เราต้องกด done แล้วกด publish เพื่อให้การเปลี่ยนแปลงถูกบันทึกจริงๆ พอปล่อยให้โหลดสักครู่ แล้วเราจะออกไปดูหน้า landing page จริง ไปที่ dashboard เลือก landing pages แล้วกด preview หน้า landing page ผมจะคลิกผ่านเพื่อทดสอบคำตอบ แบบจริงๆ ผมคงมีคำถาม 4-5 ข้อ แต่สำหรับการสาธิตแค่นี้ก็พอ ตอนนี้เห็นปุ่ม call now แล้ว จริงๆ ผมคงใส่เครื่องหมายขีดให้ดูเป็นเบอร์ เช่น 1-855-648-4690 เพื่อให้คนกดโทรได้ ปุ่มนี้เปลี่ยนสไตล์ได้ ทำได้หลายแบบ แต่เห็นไหมครับ นี่คือปุ่ม call to action ของเรา และมันสำคัญมากเพราะมันคือสิ่งที่ใช้ติดตามผล เมื่อคนโทรหาเบอร์นี้ เราจะได้ลูกค้าที่มีคุณสมบัติ (qualified lead) และได้เงินจากเบอร์โทรนี้

ต่อไป ผมอยากโชว์ให้ดูใน ClickFunnels ด้วย ผมล็อกอินไว้แล้ว ในบทเรียนก่อนหน้าผมพูดถึงการตั้งค่า ClickFunnels และวิธีใช้เทมเพลต ผมจะเข้าไปที่หน้าหลักซึ่งก็คือ landing page ของผม แล้วกดแก้ไข นี่คือหน้าของผม และเราสามารถมีอีกหน้าหนึ่งที่โผล่ขึ้นมา ซึ่งเป็นหน้าที่มี call to action และเบอร์โทรของผม สำหรับอันนี้ผมจะใช้ pop-up ผมเคยสอนวิธีทำ pop-up ไปแล้ว ถ้ากด show pop up เราจะเห็นช่องให้ใส่เบอร์โทร ผมจะใส่เบอร์เฉพาะนั้นลงไป เช่น 648-1000 แล้วตั้งค่าให้เปิดในหน้าต่างเดียวกัน (same window) กด back ตอนนี้บันทึกเรียบร้อย ตรงนี้จะไม่มีปุ่ม action เพราะไม่มีลิงก์ นั่นคือสาเหตุที่มันขึ้นคำเตือน warning button not set ถ้ามีลิงก์เราควรตรวจสอบให้แน่ใจว่ามันใช้งานได้จริง แต่ตรงนี้ไม่มีลิงก์ มีแค่เบอร์โทร ก็บันทึกได้ จากนั้นกลับไปที่ preview แล้วคลิกผ่าน quiz ไป ตอนนี้เห็นเบอร์โทรที่เราใส่แล้ว เมื่อคนโทรหาเบอร์นี้ก็จะต่อสายไป และเราสามารถปรับปุ่มหรือตกแต่งอื่นๆ เพื่อทำให้ landing page เป็นเอกลักษณ์ของเราเอง
