## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 3 ของการตั้งค่า ซึ่งเน้นที่ "publishing automation" หรือระบบเผยแพร่คอนเทนต์อัตโนมัติ โดยนำเทมเพลต Publisher มาอิมพอร์ตใน Make.com เชื่อมต่อ webhook กับโค้ด Waymaker แล้วตั้งค่าโมดูลโซเชียลมีเดียต่าง ๆ ทั้ง LinkedIn, Instagram, Facebook และ Twitter ให้โพสต์วิดีโอ YouTube หนึ่งรายการกลายเป็นโพสต์โซเชียลได้หลายแพลตฟอร์ม พร้อมบันทึกเวลาเผยแพร่ลง Google Sheets

## คำแปลเต็ม

ระบบอัตโนมัติตัวต่อไปคือ publishing automation หรือระบบเผยแพร่โพสต์อัตโนมัติของเรา เริ่มจากคลิกที่ create a new scenario (สร้างสถานการณ์ใหม่) จากนั้นไปที่ Import Blueprint (นำเข้าเทมเพลต) แล้วเลือกไฟล์ที่คุณดาวน์โหลดได้จากใต้วิดีโอนี้ ชื่อว่า Publisher template

ตอนนี้เราต้องเพิ่ม webhook อีกตัวหนึ่งก่อน คลิกที่ copy address (คัดลอกที่อยู่) เพื่อคัดลอก แล้วกลับไปที่โค้ดของเราตรงส่วนล่างสุดตรงนี้ หาที่ที่เราจะต้องเพิ่มมันเข้าไป มันควรจะอยู่แถว ๆ ด้านล่างตรงนี้ เจอแล้ว อยู่ใน Waymaker Code Publisher คลิก save (บันทึก) เท่านี้ก็เรียบร้อยสำหรับส่วนนี้

ตอนนี้ตรงนี้คุณไม่ต้องตั้งค่าอะไรเพิ่ม ยกเว้นเราต้องให้มันรันหนึ่งครั้งเพื่อให้ระบบค้นหาโครงสร้างข้อมูลได้ ไปที่โพสต์แล้วคลิก publish (เผยแพร่) จากนั้นมันควรจะทริกเกอร์ระบบนี้ ลองดูกัน ตรวจสอบว่ามันถูกเพิ่มเข้ามาอย่างถูกต้องหรือไม่ อันนี้ถูกเพิ่มแล้ว แต่ฉันลืมเปิดใช้งานมัน ฉันลืมทำขั้นตอนนี้ ตอนนี้ลองใหม่อีกครั้ง คราวนี้น่าจะทำงานได้แล้ว คลิกอีกครั้ง ตอนนี้มันเจอแล้ว เรียบร้อย

ตอนนี้สิ่งเดียวที่คุณต้องตัดสินใจคือ คุณต้องการตั้งค่าโซเชียลมีเดียทั้งหมดและ Twitter ครบทุกแพลตฟอร์ม หรือจะเลือกแค่บางอัน? คุณตั้งค่าได้ทั้งหมด เพราะจากตรงนี้คุณสามารถพิมพ์ชื่อแพลตฟอร์มที่ต้องการให้โพสต์ถูกเผยแพร่ลงได้ เช่น ถ้าคุณพิมพ์ Instagram และ Twitter โพสต์นี้ก็จะถูกเผยแพร่ไปยังบัญชี Instagram และ Twitter ของคุณ ฉันจะสาธิตวิธีตั้งค่าทั้งหมดให้ดู แต่มันง่ายมาก

สิ่งแรกที่ต้องทำคือคลิกที่โมดูลเหล่านี้เพื่อเพิ่มการเชื่อมต่อ (connections) ของคุณ ตรงนี้คุณต้องสมัครเข้าระบบด้วยบัญชี LinkedIn ของคุณ จากนั้นก็... ฉันว่าเราไม่ต้องเลือกใหม่ แต่ต้องแน่ใจว่าข้อความโพสต์ (post text) ตรงนี้อยู่ในช่อง content และอันนี้คือ media แล้วก็เรียบร้อย

สำหรับ Instagram สิ่งที่คุณต้องมีคือต้องไปที่ Facebook เพราะคุณต้องมีเพจที่เชื่อมต่อกับบัญชี Facebook คุณไปที่เพจ Facebook ของคุณแล้วคลิกเข้าไป คุณจำเป็นต้องมี Facebook เพื่อให้ส่วนนี้ทำงาน ถ้าไม่มีก็ต้องไปตั้งค่าก่อน จากนั้นไปที่ settings (การตั้งค่า) ใน Facebook แล้วไปที่ connected (การเชื่อมต่อ) ตรงนั้นคุณสามารถเชื่อมต่อบัญชี Instagram ของคุณกับเพจ Facebook ได้ เมื่อทำเสร็จแล้วคลิก add (เพิ่ม) โดยสมัครเข้าระบบด้วยโปรไฟล์ Facebook ของคุณ จากนั้นเลือกภายใต้ตัวเลือก page คุณจะเห็นอันที่ฉันเชื่อมต่อกับเพจนี้อยู่แล้ว

ต่อไปคือ image URL ที่ควรจะถูกใส่ไว้ให้แล้ว และ caption (คำบรรยาย) ที่ใช้เป็นข้อความโพสต์ เท่านี้ก็ครบ

สำหรับ Facebook คุณแค่เพิ่มและเลือกเพจจากเมนู drop-down ตรวจสอบให้แน่ใจว่าเลือกอันนี้ไว้ ดาวน์โหลดรูปภาพจาก URL รูปภาพจะอยู่ตรงนี้ และข้อความอยู่ใต้ส่วน message (ข้อความ) ซึ่ง post text จะถูกใส่ไว้ใต้ message

โมดูลนี้ต้องมีขั้นตอนเพิ่มอีกเล็กน้อย ขั้นแรกเมื่อคุณคลิกตรงนี้ คุณต้องคลิก show (แสดง) แล้วกรอก API key และ API secret ฉันมีวิดีโอสอนที่บอกตำแหน่งที่คุณจะหาข้อมูลเหล่านี้ได้อย่างชัดเจน คุณแค่ดูแล้วจะรู้ว่าจะเอา API key และ API secret มาจากไหน จากนั้นคลิก save และ okay

เมื่อทำเสร็จแล้ว อันนี้ใช้สำหรับรูปภาพเป็นหลัก ตรวจสอบให้แน่ใจว่าเลือกเป็นรูปภาพหรือ GIF จากนั้นก็ถึงโมดูลที่ใช้เผยแพร่โพสต์ ตรงนี้คุณต้องสร้างการเชื่อมต่อด้วย client ID และ client secret ซึ่งคุณก็จะหาได้จากวิดีโอสอนนั้นเช่นกัน ฉันแสดงไว้ชัดเจนว่าจะหาข้อมูลเหล่านี้ได้จากที่ไหน

เมื่อทำเสร็จแล้ว มาที่ส่วนข้อความ ตรงนี้มีขั้นตอนพิเศษเพิ่ม เพราะอย่างที่เห็น post text ค่อนข้างยาว และ Twitter มีข้อจำกัดเรื่องจำนวนตัวอักษรในโมดูลเหล่านี้ ดังนั้นโมดูล AI นี้จะตัดโพสต์ให้สั้นลงเหลือประมาณ 140 ตัวอักษร ไม่เช่นนั้นระบบอัตโนมัติจะเจอ error ส่วน media ตัวแปรนี้มาจากอันนี้ และ text content นี้ก็คือผลลัพธ์จากโมดูล Twitter post minimizer

และเรายังมี Google Sheets คอยอยู่เบื้องหลังแต่ละแพลตฟอร์ม ซึ่งทำหน้าที่บันทึกวันที่และเวลาที่โพสต์ถูกเผยแพร่บนแพลตฟอร์มนั้น ตรงนี้ฉันเอา Google Sheet ID ของฉันมาใส่ แล้วเลือกจากเมนู drop-down ตรงนี้ฉันต้องกรอกตัวแปรที่คุณหาได้จากใต้วิดีโอนี้ ฉันต้องใช้โค้ดนี้ แค่วางลงไปแล้วคลิก OK

ตอนนี้ฉันต้องทำแบบเดียวกันกับทุกแพลตฟอร์ม แต่ให้ฉันเพิ่ม Google Sheet IDs ทั้งหมดก่อน จริง ๆ แล้วไม่จำเป็นต้องทำขนาดนั้น ตอนนี้ฉันจะทำการ duplicate (ทำสำเนา) มันแทน เพราะโมดูลเหมือนกันทุกอัน โดยปกติคุณแค่ต้องใส่ค่าแล้วก็เผยแพร่คอนเทนต์เป็นประจำ เพราะสิ่งเดียวที่โมดูลนี้ทำคือบันทึกเวลาที่โพสต์ถูกเผยแพร่

จากนั้นฉันเปิดสวิตช์ให้ทำงาน คลิกที่ immediately as data arrives (ทันทีที่มีข้อมูลเข้ามา) แล้วเราก็ทดสอบได้เลย ขอปิดการเลือกไว้ก่อน สมมติว่าฉันอยากโพสต์เฉพาะ Twitter กับโพสต์นี้ ฉันแค่คลิก publish แล้วถ้ากลับไปดู มันน่าจะรันและทริกเกอร์ระบบอัตโนมัติ มันเปิดอยู่แล้ว Twitter Instagram เห็นไหมว่ามันถูกเผยแพร่ตรงนี้และตรงนี้ เฉพาะ Twitter และ Instagram ตามที่เรากำหนด และเวลาที่เผยแพร่ก็ถูกบันทึกไว้ด้วย

ถ้าฉันรีเฟรชและไปที่บัญชีของฉัน ฉันจะเห็นโพสต์ใหม่พร้อมรูปภาพ มันเพิ่งถูกโพสต์ และตรงนี้ฉันเห็นว่ามันถูกเผยแพร่ไปยัง Instagram ของฉันแล้ว มันใช้งานได้

ทีนี้ลองทดสอบโมดูลอื่น ๆ กัน สมมติว่าอันต่อไปฉันอยากให้ลง Facebook และ LinkedIn ตรวจสอบให้แน่ใจว่าสะกดถูกต้อง ไปที่ปุ่ม publish แล้วฉันก็ไปที่โปรไฟล์ LinkedIn และบัญชี Facebook ที่เปิดไว้อยู่แล้ว มันกำลังรันอยู่ มันเผยแพร่ไปยัง LinkedIn แล้ว ตอนนี้กำลังทำกับ Facebook และเสร็จแล้ว ตอนนี้โพสต์นี้น่าจะถูกโพสต์แล้ว อย่างที่เห็นตรงนี้ และไปที่บัญชี LinkedIn ของฉันด้วย ไปที่โพสต์ LinkedIn แล้วเห็นว่ามันถูกเผยแพร่แล้ว ใช้งานได้ เยี่ยม

ตอนนี้ระบบอัตโนมัตินี้ทำงานแล้ว มันรับวิดีโอ YouTube หนึ่งรายการแล้วแปลงเป็นโพสต์โซเชียลมีเดียสามโพสต์ และให้เราสามารถเผยแพร่ได้จากตรงนี้

อีกอย่างที่คุณทำได้คือเพิ่มจำนวนโพสต์ที่วิดีโอ YouTube ถูกแปลงเป็น ฉันไม่ได้อัดวิดีโอเพิ่มให้คุณดู เพราะมันเป็นขั้นตอนเดียวกันกับที่ใช้แปลงบทความบล็อกเป็นโซเชียลมีเดีย แค่ดูวิดีโอนั้นแล้วฉันจะแสดงให้เห็น ตรงนี้คุณเห็นว่าฉันขยายจากสามเป็นสี่โพสต์ ตอนนี้มันแปลงบทความบล็อกเป็นโพสต์โซเชียลสี่โพสต์ คุณสามารถทำตามขั้นตอนเดียวกันเพื่อให้วิดีโอ YouTube ถูกแปลงเป็นสี่หรือห้าโพสต์ได้ คุณแค่ทำการ duplicate สาขา (branches) เหล่านี้ซ้ำไปเรื่อย ๆ สิ่งเดียวที่ต้องเปลี่ยนคือเทมเพลตโพสต์ คุณแค่เพิ่มสไตล์ใหม่ตรงนี้ ใส่ชื่อสไตล์เทมเพลตโพสต์ให้มัน
