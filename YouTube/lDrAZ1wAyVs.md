## ประเด็นหลัก
- Anthropic เปิดตัว Claude Mods ให้ Claude Code สร้างและติดตั้งส่วนเสริมเองได้จากคำอธิบาย
- mods ต่างจาก skills และ MCP connectors เพราะรันใน Claude Code และเปลี่ยน UI/พฤติกรรมจริง
- Savvy Progress โชว์ progress bar และ live panel ของ sub-agents พร้อมปรับ mascot ได้
- Claude Skins reskin หน้าตา tool calls/edits มีธีมเช่น Noir และ Tokyo Night
- You Should Know (ของ Anthropic) รัน agent ที่สอง flag ประเด็นสำคัญจาก wall of text
- File Tree โชว์ไฟล์ที่ Claude แตะ/เซฟแบบ visual โดยไม่กิน tokens
- Cache Tax เตือนก่อน cache เย็นและมี /keep warm ช่วยคุม usage ในเซสชันยาว
- Blast Radius หยุดคำสั่งเสี่ยงก่อนลบไฟล์ ต้องมีคนกด proceed
- Reflect เก็บ feedback เป็นกฎใน Claude.md/skill; Terminal Browser และ Replay Theater ช่วยพรีวิวและไล่ดู edit ย้อนหลัง
- ต้อง Claude Code ≥ 2.1.287 ใช้ skill plugin authoring + hot reloading แล้วเซฟเป็น plugin ถ้าชอบ
