## ประเด็นหลัก
- Cursor คือ IDE (fork จาก Visual Studio Code) ที่เต็มไปด้วยฟีเจอร์ AI — ดูและแก้ไขโค้ดได้พร้อมใช้ AI ช่วย ต่างจากเครื่องมือ CLI อย่าง Claude Code หรือ Codex ที่คุณควบคุมได้น้อยกว่า
- เริ่มต้นฟรี: ดาวน์โหลดแอปเดสก์ท็อป (Windows/Mac/Linux) สมัครบัญชี แล้วใช้แผนฟรีก่อน ค่อยอัปเกรดเป็น Pro, Pro Plus, Ultra, Teams หรือ Enterprise ตามการใช้งาน
- โมเดลหลักของ Cursor คือ Composer 2.5 (งานง่าย) และ Grok 4.5 (งานท้าทายขึ้น) ส่วนโมเดลภายนอกอย่าง Claude หรือ GPT 5.6 จะกินเครดิตเร็วกว่า ใช้เมื่อต้องการมุมมองใหม่หรือของพัง
- อินเทอร์เฟซมี 2 มุมมอง: agent view (เหมาะกับคนไม่สายเทคนิค รัน agents หลายตัวพร้อมกัน) และ IDE view (ดูโค้ดและแก้ไขแบบดั้งเดิม) สลับกันได้ตลอด
- เวิร์กโฟลว์แนะนำสำหรับมือใหม่: สร้างโฟลเดอร์ใหม่ → เลือกโมเดล → เปิด plan mode → ให้ prompt ละเอียด (แนะนำ Wispr Flow สำหรับพิมพ์ด้วยเสียง) → ให้ AI ถามคำถาม clarifying → รีวิวแผน → build in parallel
- โหมดการทำงาน: plan, debug (หา/แก้บั๊ก), multitask, ask (ถามเกี่ยวกับโค้ดโดยไม่แก้), design mode (ชี้จุดบนหน้าจอสั่งแก้ UI ได้)
- เปิดใช้งาน git เสมอเพื่อติดตามการเปลี่ยนแปลง ดู diff view รีวิวทีละเล็กน้อย ทดสอบแอป แล้ว commit เป็น checkpoint ก่อนไปต่อ
- ฟีเจอร์ขั้นสูง: multi-model review (agents หลายตัวรีวิวโค้ดกันเองใน work tree), cloud agents (ส่งงานรันบน Cursor Cloud ผ่าน GitHub), sub agents, side chats (ถามคำถามข้างๆ โดยไม่ขัดจังหวะ agent หลัก)
- project rules เก็บในโฟลเดอร์ .cursor ถูก inject อัตโนมัติทุกครั้งที่เขียนโค้ด ส่วน skills คือ workflow ที่นำกลับมาใช้ใหม่ได้ (สร้างเองได้ผ่านคำสั่ง /)
- plugins และ MCP servers (เช่น GitHub MCP) เพิ่มความสามารถจาก marketplace เช่น Slack, Figma, Zapier
- automations ให้ agents รันตามตารางเวลาหรือ trigger จากเหตุการณ์ (Slack, GitHub, Sentry) — มีประโยชน์กับโปรเจกต์จริงจัง

## ความเห็นสรุป
วิดีโอนี้เป็นคอร์สเริ่มต้นที่ครบถ้วนและปฏิบัติตามได้จริง ตั้งแต่การติดตั้ง ไปจนถึงฟีเจอร์ขั้นสูงอย่าง cloud agents และ automations โดยใช้เกมเดโมเป็นตัวอย่างที่เห็นภาพชัด เนื้อหาเหมาะกับทั้งผู้ที่ไม่เคยใช้ Cursor มาก่อนและผู้ใช้เดิมที่อยากรู้ฟีเจอร์ใหม่ในเวอร์ชัน 3.0
