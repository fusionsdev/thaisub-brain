## บทนำ

บทเรียนนี้เป็นการเริ่มต้นโหมดการสร้าง "พนักงาน AI" (AI employees) ด้วย Claude Code ผู้สอนอธิบายว่า agent คืออะไร เปรียบเทียบเหมือนการจ้างฟรีแลนซ์ที่ทำงานเบื้องหลังพร้อมกันหลายคน พร้อมสาธิตการรัน agent หลายตัวแบบขนานเพื่อค้นคว้าข้อมูลจากหลายแหล่งพร้อมกัน

## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับเข้าสู่บทเรียน What Are Agents ในซีรีส์นี้ ถ้าคุณมาถึงจุดนี้ได้ แปลว่าคุณมาถึงจุดที่เราจะเริ่มสร้างพนักงาน AI (AI employees) ให้กับคุณแล้ว พวกนี้คือพนักงานจริง ๆ เลยนะครับ ที่จะออกไปค้นคว้าข้อมูลให้คุณ เขียนคอนเทนต์ให้คุณ ค้นคว้าโฆษณาให้คุณ ปรับแต่งทุกอย่างให้คุณ แค่คุณพูดสั่งไม่กี่คำ มันก็ออกไปทำได้เลย มันโคตรจะเหลือเชื่อเลยว่า agent ทำอะไรได้บ้างภายใน Claude Code

จนถึงตอนนี้ คุณได้เรียนรู้วิธีติดตั้ง Claude Code ไปแล้ว เรียนรู้วิธีจัดระเบียบไฟล์ของคุณ ฝึก Claude Code ด้วยข้อมูลทั้งหมดของคุณ เริ่มทำให้ทุกอย่างเป็นอัตโนมัติด้วย automation และเชื่อมต่อ Claude เข้ากับเครื่องมือทั้งหมดของคุณแล้ว ทีนี้เราจะมาเริ่มสร้างพนักงาน AI กันจริง ๆ แล้วครับ นี่มันจะเจ๋งมาก ๆ และผมตื่นเต้นกับส่วนนี้มาก

แล้ว agent จริง ๆ แล้วคืออะไรล่ะ? โดยพื้นฐานแล้ว มันก็เหมือนมี Claude อีกตัวหนึ่งรันอยู่เบื้องหลัง ผมจะอธิบายแบบโลกจริงให้ฟัง มันก็คล้าย ๆ กับว่าคุณกำลังจ้างคนสักคน เหมือนจ้างฟรีแลนซ์คนหนึ่ง ที่คุณคุยงานด้วย ลองนึกภาพตามนะครับ สมมติว่านี่คือผม และผมกำลังคุยกับ Mr. Claude Code แล้วผมกับ Claude ก็ทำงานในงานหนึ่งด้วยกัน คุยกันไปคุยกันมา แทนที่ผมจะต้องหยุดงานที่ทำอยู่ แล้วไปบอกว่า "Claude ไปค้นคว้าข้อมูลเรื่องนี้ให้หน่อย" แล้วมันก็ไปค้นคว้า แล้วก็กลับมา วิธีนั้นมันยังกินเวลาของเราไปเหมือนเดิม มันดึงเวลาจากตัวเรานี่แหละ

แต่สิ่งที่เราทำได้คือ ให้ Claude Code รัน agent ทำงานเบื้องหลัง ขณะที่เรายังทำงานกับมันอยู่ แทนที่ผมจะต้องหยุดแล้วไปค้นคว้าจากแหล่งข้อมูลทีละแหล่ง ผมก็บอก Claude ได้ว่า "ไปค้นคว้าข้อมูลนอกจอตรงนี้ไปก่อน ขณะที่ผมยังทำงานอยู่ตรงนี้" มันก็จะทำงานไปพร้อมกับผม นี่คือการรัน agent ที่ออกไปทำงาน เช่น สมมติว่าให้มันไปค้นคว้าข้อมูล ผมไม่อยากหยุดรอ Claude Code ทำวิจัย ขณะที่ผมมีอย่างอื่นต้องทำ ผมก็แค่สั่งให้มัน spawn agent ไปค้นคว้า spawn agent ไปเขียนงาน spawn agent ไปตรวจสอบอะไรต่อมิอะไร พร้อมกันทั้งหมด โดยที่ไม่ทำให้ Claude Code ช้าลง และผมยังทำงานที่กำลังทำอยู่ต่อไปได้ งานพวกนี้เกิดขึ้นเบื้องหลังหมดเลย

ผมรู้ว่ามันอาจจะฟังดูงงหน่อย แต่มันทรงพลังมาก ๆ มันเกือบจะเหมือนกับการจ้างพนักงานหลายคน พูดง่าย ๆ เหมือนคุณมีพนักงานอยู่คนหนึ่งกำลังคุยงานกับคุณอยู่ แล้วคุณก็มีพนักงานอีกคนหนึ่งที่อยากให้ไปค้นคว้าข้อมูล คุณก็บอกให้มันไปค้นคว้า มันก็ไปทำ แล้วคุณก็ทำงานอย่างอื่นไปเรื่อย ๆ พอมันกลับมา มันก็ส่งผลงานให้คุณ ขณะที่คุณทำงานอย่างอื่นตลอดเวลา นี่คือสิ่งเดียวกันกับ Claude ครับ เพียงแต่มันเร็วเป็นหลายเท่า และคุณสามารถ spawn พนักงานได้สิบคนพร้อมกัน แทนที่จะเป็นแค่คนเดียว มันเหลือเชื่อมากว่าคุณทำอะไรได้บ้างตรงนี้

ทีนี้ เมื่อไหร่ที่มันคุ้มค่า? agent จะคุ้มค่าตอนที่คุณมีงานหลายอย่างที่ไม่พึ่งพากัน ตัวอย่างเช่น ผมจะโชว์ตัวอย่างการค้นคว้าของผมให้ดู สมมติว่าคุณทำงานกับ Claude อยู่ แล้วคุณต้องค้นคว้าข้อมูล แต่ต้องไปหาจากสี่แหล่งที่ต่างกัน เช่น ต้องดู Twitter ดูข่าว ดู GitHub ประมาณนี้ ถ้าเป็นวิธีปกติ คุณก็ต้องทำทีละอย่าง ไปทีละแหล่ง ไปทีละแหล่ง แล้วก็ไปทีละแหล่ง มันกินเวลามาก

แต่สิ่งที่เราทำได้คือ ถ้าเรามี agent พวกนี้ ผมก็บอกได้ว่า "เฮ้ ไป spawn agent สี่ตัวเพื่อค้นคว้าข้อมูล" มันจะส่ง agent ไปหาแต่ละแหล่งพร้อมกัน ค้นคว้าพร้อมกัน แล้วเอาผลกลับมาส่งให้ผม ซึ่งผมก็ยังนั่งอยู่ตรงนี้ งานแบบนี้แหละที่ควรใช้ agent — ตอนที่คุณมีงานหลายอย่างที่ไม่เป็นเส้นตรง (linear)

งานแบบเส้นตรง เช่น สมมติว่าผมกำลังทำคอนเทนต์ ผมต้องทำอย่างแรกก่อน แล้วค่อยทำอย่างที่สอง ต้องทำอย่างนั้น แล้วก็ต้องอัดวิดีโอ นี่คืองานแบบเส้นตรง คุณจะไม่ส่ง Claude Code ไปทำทั้งสี่อย่างพร้อมกัน เพราะมันไม่ได้มีข้อมูลครบ มันต้องไปทีละขั้น ทีละขั้น ทีละขั้น นี่คือตอนที่คุณไม่ควรใช้ agent ครับ ใช้ agent เฉพาะงานที่ไม่พึ่งพากัน ไม่ใช่แบบต้องทำหนึ่งก่อน สองก่อน สามก่อน สี่ก่อน แล้วก็อีกอย่าง อย่าใช้ agent ตอนที่งานมันง่ายเกินไปด้วย มันจะ overkill

แต่ลองมาทำจริงสักตัวอย่างดีกว่า ผมจะโชว์ตัวอย่างที่ดีมากให้ดู อันนี้เจ๋งจริง ๆ โอ้ ผมชอบ agent พวกนี้มาก ตัวอย่างนี้จะโผล่มาอีกเรื่อย ๆ ระหว่างเรียน เพื่อให้คุณเข้าใจลึกขึ้น โอ้ ผมเปิด Cursor อีกหน้าอยู่ ขอปิดอันนี้ก่อน แล้วเปิดอันใหม่ เราจะเปิด Cursor ขึ้นมา เห็นแผนการสอนทั้งหมดที่ผมกำลังสอนคุณอยู่ไหมครับ ตอนนี้เราอยู่ในโฟลเดอร์ของผมแล้ว ทีนี้ผมจะเปิด Claude ขึ้นมา ดูตรงนี้ เพื่อโชว์ให้เห็นว่า agent ทำงานยังไง

ผมจะสั่งว่า "สปอนส์ agent สี่ตัวให้ค้นคว้าข้อมูลให้ผม ตัวหนึ่งค้นคว้าเรื่องหนึ่ง ตัวหนึ่งค้นคว้าเรื่องหนึ่ง ตัวหนึ่งค้นคว้าออนไลน์โดยใช้ WebFetch" แล้วก็มีแหล่งอื่นอีกไหม? เอาสามตัวนี่ก่อน แล้วให้ค้นคว้าหัวข้อที่กำลังมาแรงในวงการ AI เกี่ยวกับ Claude Code เราจะส่งงานพวกนี้ออกไป ผมแค่สั่งมันตรงนี้ ขอให้มันเปิด agent สามตัวพร้อมกัน

สิ่งสำคัญคือคุณต้องเข้าใจว่าเมื่อไหร่ที่คุณควรเปิดใช้ agent ซึ่งเป็นเหตุผลที่ผมพูดถึงเรื่องนี้ไป เพราะคุณสามารถสั่งมันได้ มันกำลังเปิดทั้งสามตัวแบบขนานอยู่ตอนนี้ มันเพิ่งเปิด content researcher ตัวหนึ่ง ค้นคว้าหัวข้อที่กำลังมาแรง กำลังค้นคว้าเรื่อง AI พร้อมกัน ทั้งสามตัวกำลังออกไปหาแหล่งข้อมูลพร้อมกัน ทั้งสาม agent กำลังรันอยู่เบื้องหลัง: X agent, GitHub, web research ทุกตัวรันอยู่ แล้วมันจะแชร์ผลลัพธ์กลับมาเป็นบทสรุป แล้วผมก็ยังทำงานกับมันต่อได้ "ช่วยดึง top 3 ของผมขึ้นมาให้หน่อย" ขณะที่พวกมันออกไปทำงานอยู่ ผมก็ยังคุยกับ Claude Code ได้โดยตรง นี่คือการทำงานไปพร้อมกัน ยังอยู่ใน context window เดียวกัน มันเจ๋งจริง ๆ

ตอนที่มันออกไปทำงาน และ agent ทั้งหมดรันอยู่เบื้องหลัง มันจะอธิบายให้คุณฟังว่ามันกำลังทำอะไรอยู่ และคุณสามารถพิมพ์เครื่องหมาย slash ได้ตลอด เช่น พิมพ์ว่า "อัปเดตความคืบหน้าของ agent ให้หน่อย" สิ่งนี้ทำให้ Claude ตอบกลับข้อความคุณได้ทันที เพื่ออัปเดตสถานะให้คุณ ผมก็เลยพิมพ์ว่า "อัปเดตเรื่อง agents ให้หน่อย" ดูเหมือนมันกำลังจะตอบ แล้วมันก็ดึงข้อมูล Supabase ทั้งหมดของผมออกมา ขณะที่ยังรัน agent อยู่ด้วย มันบ้ามาก มี research agent สามตัวยังรันอยู่เบื้องหลัง แล้วก็ยังมี agent ที่ไปค้นคว้าคอนเทนต์ทั้งหมดของผมอีก ทำงานพร้อมกันหมดเลย บ้าไปแล้ว

โอเค เราจะปล่อยให้มันทำงานไปเรื่อย ๆ ดูเหมือนมันเพิ่งดึง hooks ทั้งหมดของผมออกมา ประมาณ 1.2, 1.4, 700 ตัว ตอนนี้ 763 ตัวแล้ว โอ้โห แล้วมันก็ยังรอผลจาก research agent อยู่ มี agent ท้องถิ่นสามตัวยังทำงานอยู่ มันยังออกไปทำงานพวกนั้นให้ผม ขณะที่ผมคุยกับ Claude Code โดยตรง มันเหลือเชื่อมากว่าคุณทำอะไรได้บ้างกับ Claude Code ผ่าน agent พวกนี้

ผมจะปล่อยให้มันทำงานต่อไป แล้วจะโชว์ผลลัพธ์ให้ดู ดูสิครับ ดูเหมือน research agent ตัวหนึ่งกลับมาจาก GitHub แล้ว มันเจอหัวข้อ Claude Code ที่กำลังมาแรง 10 อันดับบน GitHub ตอนนี้ เช่น "Claude Code กับ Discord กำลังจะออกฟีเจอร์" อันนี้น่าสนใจจริง ๆ "Open Claude เทียบกับ Claude Code" กำลังเป็นที่นิยมมาก "Hindsight MCP memory" ให้ AI มีความจำถาวร ผล benchmark ความยืนยาว 91% "MCP GitHub server" น่าสนใจ โอเค เจ๋ง แล้วก็ "Claude Code เป็น curated skill" อีก ดูสิ มันเพิ่งคืนผลจาก web search agent กลับมา มันค้นหาบนอินเทอร์เน็ตให้เราและทำการค้นคว้าเชิงลึก และผมเชื่อว่ามันเลือกจากหัวข้อที่กำลังมาแรง ที่มันคิดว่าจะเป็นไวรัลที่สุดให้ผม และมันยังรัน Twitter กับ X อยู่ตอนนี้ ผลน่าจะโผล่มาอีกสักสองสามวินาที

แต่ลองคิดดู ถ้าคุณต้องทำเอง คุณก็คงต้องสั่งว่า "ไปที่ GitHub แล้วหาหัวข้อที่กำลังมาแรงทั้งหมด แล้วเอาผลกลับมาให้ฉัน" พอได้ข้อมูลจาก GitHub แล้ว คุณก็ต้องไปค้นคว้าต่อ แล้ว research agent ก็เอาผลกลับมา แล้วคุณก็ไปทำ Twitter กับ X แล้วเอาผลกลับมา แล้วก็ดึง top 3 hooks จากฐานข้อมูลของคุณ งานนี้ใช้เวลา 30 นาที แต่ตอนนี้มันทำเสร็จในสองถึงสามนาที ด้วยการทำงานขนานกันทั้งหมด

และถ้าคุณอยากเพิ่มงานเข้าไปอีก ก็แค่สั่งให้มันรัน agent แบบขนาน "ทำสามอย่างนี้เพิ่มเติมด้วย" มันก็จะรวมเข้ามา ผมเคยรัน agent สิบตัวพร้อมกันมาแล้ว โอเค มันซิงก์กันหมด และดึงข้อมูล Twitter ทั้งหมดมา เห็นไหมครับ ช่อง Claude Code อะไรประมาณนั้น มันดึงทุกช่องที่เราสั่งไว้มาหมด

นี่คือบทนำเรื่อง agents ครับ เริ่มต้นด้วยบทเรียนที่เด็ดมาก แต่คุณเริ่มเห็นพลังของสิ่งที่คุณทำได้แล้ว — การสร้างพนักงาน AI ด้วย agent ที่จะออกไปทำงานให้คุณ ขณะที่คุณยังทำงานกับ Claude Code ต่อไป ต่อไปเราจะลงลึกกว่านี้ ผมจะให้ไอเดียเพิ่มเติมเกี่ยวกับ agent pattern แบบเฉพาะเจาะจง และเราจะสร้างทีมวิจัย (research team) ของคุณเอง เจอกันในบทเรียนถัดไปครับ
