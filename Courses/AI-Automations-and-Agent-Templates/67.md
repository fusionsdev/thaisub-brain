# Get API Key from Telegram

**วิดีโอต้นฉบับ:** AI Automations Course
**ช่อง:** AI Automations and Agent Templates
**ความยาว:** ~1.5 นาที
**ภาษาต้นฉบับ:** อังกฤษ (STT โดย NVIDIA Parakeet)

---

## บทนำ

วิดีโอนี้สอนวิธีการดึง API key จาก Telegram สำหรับใช้ในการสร้าง AI agent ที่จะใช้ในระบบอัตโนมัติของคุณ

## คำแปลเต็ม

นี่คือ access token ของคุณ แต่วิธีการได้มันมาอย่างไร ก่อนอื่นคุณต้องเข้าไปที่นี่ แล้วพิมพ์ แล้วกดที่นี่ คลิกที่ start แล้วนี่ก็คือส่วนที่คุณจะจัดการบัญชีของคุณใน Telegram อะไรที่คุณใช้ในการสร้างมันนี่ก็คือที่ทำอยู่ แล้วคุณต้องคลิกที่ create a new bot ใหม่ แล้วต้องตั้งชื่อใหม่ เราจะเรียกว่า my 1st AI agent แล้วเราต้องเลือก username และมันต้องอยู่ในรูปแบบนี้ จะเรียกว่า my 1st AI agent คุณสามารถเว้นวรรคได้ มันจะดูเหมือนว่า แต่ต้องลงท้ายด้วย bot ต้องลงท้ายด้วย bot ดี แล้วตอนนี้คุณมัน... API key ของคุณคุณไม่ควรจะให้ใครเห็นนะ เดี๋ยวเดี๋ยวภายหลังเราจะลบ key นี้ออก และ revoke ด้วย เพื่อทำเช่นนี้คุณต้องพิมพ์ แล้วคุณสามารถ deactivate API key ได้ ฉันจะไม่ให้ใครเห็น ก่อนที่ฉันจะ upload ฉันจะลบมันไป แต่ตอนนี้ฉันมี key ที่ใช้ได้แล้ว แล้วเรามากด save ที่นี่ แล้วเมื่อนี้...
