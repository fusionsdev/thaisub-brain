## บทนำ
ขั้นตอนนี้เป็นการตั้งค่าลำดับการติดตามผล (follow-up sequence) ใน ManyChat ที่คอยตรวจว่าลูกค้าจองคอลแล้วหรือยัง ถ้ายังไม่จองก็จะส่งข้อความติดตามไป โดยเชื่อมต่อกับ Google Sheets เพื่อบันทึกสถานะการจองคอลและการส่งข้อความติดตาม พร้อมวิธีทดสอบระบบจริง

## คำแปลเต็ม

ขั้นตอนต่อไปของเราคือลำดับการติดตามผล (follow-up sequence) ซึ่งเป็นลำดับการติดตามผลใน ManyChat อีกชุดหนึ่ง ที่จะคอยตรวจว่าคนๆ นั้นจองคอลแล้วหรือยัง ถ้ายังไม่จองเราก็จะส่งข้อความติดตามไป

ตรงนี้คุณแค่คลิก save to ManyChat นี่คือเวอร์ชันสำเร็จรูปที่สร้าง workflow มาให้แล้ว คลิก save flow แล้วคลิก view flow จากนั้นผมจะเปลี่ยนชื่อเป็นวันที่ปัจจุบันคือ 7.5

ต่อไปเราต้องตั้ง trigger ตรงนี้ trigger ก็คือ contact events เมื่อมีคอนแทกต์ใหม่ถูกสร้างขึ้น แล้วเราก็ตั้งชื่อว่า user โดยให้มีค่าอะไรก็ได้ จากนั้นก็เป็นส่วนของเวลารอ โดยปกติผมอาจตั้งไว้ที่ 2 นาที แล้วค่อยเปลี่ยนกลับเป็นกรอบเวลา follow-up ที่ต้องการทีหลัง แต่สูงสุดได้ 23 ชั่วโมง

จากนั้นผมต้องเชื่อมต่อ Google Sheets ไปที่ settings ก่อน แล้วคลิก connect to your Google Sheet ตรวจสอบให้แน่ใจว่าเป็น Google account เดียวกับที่ชีตนี้อยู่ พอเสร็จแล้วกลับมาตรงนี้ แล้วไปที่ actions → Row by value แล้วเลือกสเปรดชีต ซึ่งก็คือชื่อนี้ใช่ไหมครับ ปิดหน้านั้นแล้วเลือก worksheet ชื่อ leads

ตอนนี้ lookup column คือ contact ID มันจะตรวจ contact ID ของคนๆ นั้น ซึ่งเป็นเหตุผลที่เราบันทึกมันไว้ตรงนี้ มันจะหาค่า contact ID เจอ และถ้ามีหลายรายการก็จะตรวจเฉพาะรายการของคนๆ นี้เท่านั้น

ตรงนี้ผมตั้งค่าได้ ผมบอกได้ว่า call booked จะถูกเก็บไว้ตรงนี้ เพราะถ้าจองคอลแล้วก็ไม่ต้องส่ง follow-up ใช่ไหม เพราะเขาจองคอลไปแล้ว และเรายังต้องมีค่า follow-up sent ด้วย นี่คือเหตุผลที่ผมสร้างค่านี้ไว้ก่อน ถ้ายังไม่ได้ส่ง follow-up ก็ไม่ควรส่งซ้ำ มันจะส่ง follow-up เฉพาะเมื่อ call booked ไม่มีค่า และยังไม่เคยส่ง follow-up มาก่อน นั่นคือถ้ายังไม่ได้จองคอลและยังไม่ได้รับข้อความติดตาม ตรงนี้คือสิ่งที่เราจะตรวจ

เราจะตรวจว่า contact user field ชื่อ call booked ขอดูอีกที ขอเปิดอันนี้ใหม่ ตรงนี้เราต้องมี contact user call booked ถ้าค่า contains เป็น yes คนๆ นั้นจะได้รับข้อความนี้ "ฉันเห็นว่าคุณจองคอลแล้ว แจ้งให้ฉันทราบหากมีอะไร..." หรือคุณจะลบส่วนนี้ออกก็ได้ถ้าไม่อยากส่งข้อความถึงคนที่จองคอลแล้ว ลบทิ้งได้เลย แต่ผมขอเก็บไว้อย่างเดิม

อีกอย่างที่ผมจะเปลี่ยนคือเพิ่มฟิลด์อีกอัน เพราะอยากได้ชื่อจริงของคนๆ นั้น บางครั้งใน ManyChat ชื่อที่เก็บไว้ก็เป็นแบบนี้ แต่ผมอยากได้ชื่อจริงที่ลูกค้าให้ไว้ตอนกรอก จะได้ดูเป็นส่วนตัวมากขึ้น นี่คือชื่อ Thomas ที่ควรถูกเก็บและใช้เรียกคนๆ นั้น เพราะงั้นผมจึงใช้ real name แล้วเปลี่ยนมาตรงนี้เป็นฟิลด์นี้: custom user field → real name

จากนั้นเราต้องตั้งเงื่อนไขที่สอง ตรงนี้คือถ้า contact user field call booked ไม่มีค่า และ follow-up ยังเป็น unknown ผมกลับไปที่ custom user field follow-up sent เป็น unknown แล้วคลิก update

ผมต้องเพิ่มอันนี้ด้วย คลิก update row เลือก Google Sheets account ก่อน เพราะตอนนี้ผมแค่อยากเขียนค่าที่ contact ID นี้เป็น lookup contact และเขียนว่า follow-up sent = yes เพื่อบันทึกค่า follow-up sent จริงๆ และต้องตั้งฟิลด์นี้ด้วย เพราะอันดับแรกต้องตั้งก่อนว่า follow-up ถูกส่งแล้ว แล้วเก็บค่านั้นลงในชีต จากนั้นคลิกบันทึก ตอนนี้มันทำงานได้แล้ว กระบวนการนี้ควรจะทำงานได้แล้ว

และนี่คือข้อความ follow-up "ฉันเห็นว่าคุณยังไม่ได้จองคอลฟรีของคุณ พิมพ์ call ถ้ายังต้องการ" และถ้าคนๆ นั้นพิมพ์ มันก็จะดำเนินการต่อ เช่น พิมพ์ว่า "เพื่อจองคอล กรุณาใส่เบอร์โทรศัพท์พร้อมรหัสประเทศ" แล้วก็เข้าสู่ขั้นตอนการจอง

เพื่อทดสอบจริง ผมต้องกลับไป ลบคอนแทกต์ที่อยู่ตรงนี้ออก แล้วกลับไปที่ automation ของผม อยู่ไหนนะ คิดว่าน่าจะเป็น follow-up อันนี้ ตรวจสอบให้แน่ใจว่าเปิดใช้งานอยู่ ซึ่งมันก็เปิดอยู่แล้ว จากนั้นกลับเข้าไป สิ่งที่ต้องทำคือพิมพ์ reset หรือจะคอมเมนต์ทิ้งไว้ก็ได้ เพื่อให้กระบวนการเริ่มใหม่ จากนั้นผมจะมีเวลาประมาณ 2 นาทีจนกว่าจะได้รับ follow-up เพราะผมตั้งเวลาไว้ 2 นาที

สองนาทีคือระยะเวลารอตอบ เราเริ่มกระบวนการใหม่ แล้วตอนนี้ก็ถึงจุดที่อาจเกิดขึ้นได้ว่าคนๆ นั้นไม่ตอบด้วยเหตุผลใดก็ตาม จากนั้นผมก็จะได้รับข้อความ follow-up ที่ตั้งค่าไว้จาก automation นี้ และผมตรวจได้ด้วยว่าถ้ารีโหลดหน้านี้ ควรมีคอนแทกต์หนึ่งอัน ตรงนี้เห็น send 1 และ waiting 1 อัน ก็ถือว่าดี

และตอนนี้คุณจะเห็นว่าผมได้รับข้อความ follow-up แล้ว "Nina ฉันเห็นว่าคุณยังไม่ได้จองคอลฟรีของคุณ พิมพ์ call ถ้ายังต้องการ" และถ้าคนๆ นั้นพิมพ์ มันก็จะดำเนินการต่อ เช่น พิมพ์ว่า "เพื่อจองคอล กรุณาใส่เบอร์โทรศัพท์พร้อมรหัสประเทศ" แล้วก็เข้าสู่ขั้นตอนการจอง

ลำดับการติดตามผลทำงานได้แล้ว และขั้นตอนนี้ก็เสร็จสมบูรณ์ ในขั้นตอนถัดไปเราจะตั้งค่าระบบข้อความ SMS เพื่อเตือนคนๆ นั้น 1 ชั่วโมงก่อนถึงเวลานัดหมาย จะได้มาเข้าคอลจริงๆ
