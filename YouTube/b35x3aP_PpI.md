# สรุป: แนะนำ Hermes Agent AI คู่หูที่คุณเลี้ยงดูได้

- **ช่อง:** Tonbi's AI Garage · **ความยาว:** ~18 นาที · **ลิงก์:** https://www.youtube.com/watch?v=b35x3aP_PpI

## ประเด็นหลัก

- Hermes Agent คือเอเจนต์ AI แบบ open source ที่พัฒนาโดย Nous Research ต่างจากแชต AI ทั่วไปตรงที่รันบนเครื่องของเรา ลงมือทำงานจริง และจดจำเรื่องราวต่าง ๆ ได้
- สาธิตการใช้งานจริง: ให้ Hermes อ่านโปรเจกต์เกม "Token Burn" ในเครื่อง แล้วตอบได้ทันทีว่าโปรเจกต์คืออะไร แม้ไฟล์ทั้งหมดยังไม่ได้อัปโหลดขึ้นอินเทอร์เน็ต
- จุดเด่นด้านความจำ: Hermes จำได้ข้ามการสนทนา จำงานและโปรเจกต์ที่ทำเมื่อวานได้ทั้งหมด ทำให้ไม่ต้องอธิบายเรื่องเดิมซ้ำ ๆ
- การติดตั้งง่ายมาก แค่รันคำสั่ง 1 บรรทัดใน terminal (แยกตาม Mac / Linux / Windows) จากนั้นตั้งค่าผ่าน Quick Setup ได้ในประมาณ 30 วินาที
- เลือก AI model ได้หลากหลายผ่าน Provider และ Nous Portal (สมัครฟรี เลือก model ได้เป็นร้อยตัว) รวมถึง local model ที่รันบนเครื่องตัวเองโดยไม่เสียค่าใช้จ่าย
- ฟีเจอร์ Skill: Hermes จดจำขั้นตอนที่ทำสำเร็จเป็นสกิล และสร้างสกิลใหม่ให้เองอัตโนมัติโดยไม่ต้องสั่ง
- Tools + MCP: เชื่อมต่อกับ GitHub, เบราว์เซอร์, ข้อมูลราคาหุ้น และบริการภายนอกอื่น ๆ ได้ และคุยผ่าน LINE / Discord ได้ตลอด 24 ชั่วโมง
- Cron Automation: ตั้งตารางให้ทำงานเอง เช่น สรุปข่าวส่งให้ทุกวัน พร้อมโหมดไม่ทำงานเมื่อว่างเพื่อให้ค่าใช้จ่ายแทบเป็นศูนย์
- Sub-agents + Kanban: สร้างทีมเอเจนต์หลายตัวแบ่งงานกันทำพร้อมกัน แบ่งบทบาทเหมือนทีมงานจริง
- Security: มีระบบขออนุมัติก่อนรันคำสั่งอันตราย ช่วยลดความกังวลเรื่องคอมพิวเตอร์เสียหาย
- ผู้พูดเป็นชาวต่างชาติที่เคยเรียนภาษาญี่ปุ่นที่เกียวโต วิดีโอนี้เป็นการลองนำเสนอ Hermes เป็นภาษาญี่ปุ่น และจะลงรายละเอียดแต่ละฟีเจอร์ในวิดีโอถัด ๆ ไป

## ความเห็นสรุป

วิดีโอนี้ให้ภาพรวมของ Hermes Agent ครบทั้งแนวคิด วิธีติดตั้ง และฟีเจอร์หลัก (ความจำ, สกิล, การเลือกโมเดล, MCP, การตั้งเวลาอัตโนมัติ, ทีมเอเจนต์ และความปลอดภัย) เหมาะสำหรับผู้เริ่มต้นที่อยากรู้ว่าเอเจนต์ AI แบบรันบนเครื่องตัวเองต่างจากแชตบอตทั่วไปอย่างไร น้ำเสียงเป็นกันเองเหมือนเพื่อนแนะนำของดี และเนื้อหามีการสาธิตจริงประกอบตลอดทั้งคลิป
