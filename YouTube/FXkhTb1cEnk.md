## วิดีโอนี้เกี่ยวกับอะไร
Tonbi ทดสอบ **GPT-6 Astra** (โมเดลใหม่ของ OpenAI ที่เปิดให้สมาชิกแผน Codex) ด้วย prompt ชุดเดียวกับที่เคยให้ **Claude Fable 5.1** ทำ เพื่อเทียบกันแบบหมัดต่อหมัด

## ประเด็นหลัก

1. **Benchmark:** reasoning/coding 99.9% บน ARK AI 3, ชนะ Fable บน terminal bench 4.0 และ deep WSE แต่แพ้บน humanities last exam แบบมี tools · computer use 72.6% บน OS world 2.0 (จาก 65.7 ของ GPT soul) · latency ต่อทาสก์ลด 47% · retrieval 96.3% (จาก 73.8) · ราคาเท่า Fable (input $10 / output $50) แต่ไม่มี prompt caching แบบ Fable
2. **ฟีเจอร์ใหม่:** async tools, steer กลางเทิร์นผ่าน web socket, ปรับ reasoning effort กลางบทสนทนาโดยเก็บ cache prefix, cross-window notes · written reasoning ตรวจยากขึ้น (recurrent depth) แต่มี safeguard
3. **งานที่ 1 — เกม Sonic:** สร้างเกมสไตล์ Sonic ได้ฟิสิกส์ดี มีห่วงให้เก็บ
4. **งานที่ 2 — โลก Hobbit (three.js cinematic):** Astra ได้งานกลมมนรายละเอียดดี รันลื่นกว่า Fable มาก (Fable ต้องเร่ง 10x) แต่สีจืดกว่า (ออกเขียว) — ผลเสมอกัน ขึ้นกับรสนิยม
5. **งานที่ 3 — Blender (สไลเดอร์ + เรือโจรสลัด One Piece):** สไลเดอร์ one-shot ดีกว่า Soul ชัดเจน · เรือ Merry เต็มฉากทะเล+เกาะ+ลูกปืนใหญ่ใน 17 นาที — ประทับใจสุดในวิดีโอ เหมาะกับทำเกมและ asset 3 มิติ
6. **งานที่ 4 — แลนดิ้งเพจ Sunny Dinosaur:** Astra ทำ scrolling video พัง + ไม่มี interactive element ครบตามโจทย์ — **Claude ชนะขาด** งานฟรอนต์เอนด์ยังต้อง Claude
7. **สรุปการใช้:** Astra = ฟิสิกส์เกม + 3D/Blender · เสมอกัน = three.js · Claude = ฟรอนต์เอนด์ + art direction · งานนี้กินโควต้ารายสัปดาห์ไป 25% (แผน $100) — เหมาะกับงานโค้ดหนักเท่านั้น
8. **ความเห็น:** โมเดลดีมากแต่ไม่ถึงกับ “ล้ม Fable” อย่างที่อวยกันบน X
