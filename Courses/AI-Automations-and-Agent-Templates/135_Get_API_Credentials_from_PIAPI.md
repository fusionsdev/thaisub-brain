## บทนำ
วิดีโอนี้สาธิตขั้นตอนการขอ API Key จาก PIAPI โดยเข้าไปที่หน้า API สร้างคีย์ใหม่ ตั้งชื่อ แล้วนำไปคัดลอกและวางเพื่อใช้งาน

## คำแปลเต็ม

จากนั้นคุณก็ไปที่ API และนี่คือสิ่งที่เราต้องการตรงนี้ คุณก็แค่คลิกที่ create a new key คุณสามารถตั้งชื่อให้มันได้ แล้วคีย์ก็จะถูกเพิ่มตรงนี้ คัดลอกและวางมัน จากนั้นคลิก save
