## บทนำ
วิดีโอนี้แสดงวิธีตั้งค่าระบบส่งการแจ้งเตือน WhatsApp ให้กับผู้ติดต่อที่จองคิวแล้ว โดยใช้ Google Apps Script ใน Google Sheets เพื่อเรียก webhook ตามเวลาที่กำหนด แล้วให้ n8n ส่งข้อความแจ้งเตือนไปยัง WhatsApp ผ่าน OpenAI พร้อมทั้งสาธิตการทดสอบทั้ง webhook แบบ test และ production รวมถึงข้อควรระวังในการใช้ WhatsApp เป็นโซลูชันทางธุรกิจจริง

## คำแปลเต็ม

ในการส่งการแจ้งเตือน WhatsApp ไปยังผู้ติดต่อของเราที่จองคิวแล้ว เราต้องไปที่ Google Sheet ของเรา แล้วตรงนี้เราต้องไปที่ extensions แล้วไปที่ Apps Script เพราะวิธีที่มันทำงาน อย่างที่คุณเห็นแล้ว Google Sheet นี้ได้ทำบางอย่างแล้ว มันบอกว่ามันได้กำหนดเวลาการแจ้งเตือน WhatsApp นี้ และนี่คือสิ่งที่โปรแกรมเล็ก ๆ นี้ทำ แต่ก่อนที่มันจะทำงานจริง เราต้องเชื่อมต่อมัน ซึ่งง่ายมาก เราก็แค่ต้องวาง webhook ลงตรงนี้

จะมี webhook สองแบบ: webhook แบบ test และแบบ production เราจะใส่แบบ test ก่อน เพราะเราสามารถคลิก test แล้วดูว่ามันทำงานได้ไหม งั้นเลือก webhook แบบ test ก่อน แล้วจากนั้นก็ยังมีอีกอย่างที่ต้องปรับ นั่นคือเวลาการแจ้งเตือน นี่คือวิธีการตั้งค่า 1 ชั่วโมงก่อนเวลานัด ตัวอย่างเช่น ในกรณีของผม ถ้าคนนัดตอน 6 โมง คนคนนั้นจะได้รับการแจ้งเตือน WhatsApp 1 ชั่วโมงก่อนนัด

ตอนนี้คุณสามารถใส่ตัวเลขเท่าไหร่ก็ได้ เช่น 10 ชั่วโมงก่อนนัด คุณแค่พิมพ์เลข 10 แต่ตอนนี้ผมจะตั้งเป็น 2 แล้วผมจะพิมพ์เลข 2 และเราจะย้ายสติกเกอร์หนึ่งอันตรงนี้ ผมจะเปลี่ยนมันกลับในภายหลัง แต่ตอนนี้ผมอยากทดสอบ ดังนั้น 2 นาทีก่อนเวลานัด ผมถึงจะได้รับการแจ้งเตือน ผมไม่ต้องรอนานขนาดนั้นในช่วงทดสอบ

และผมจะเปลี่ยนอันนี้ด้วย วันนี้วันที่เท่าไหร่? มันคือเดือนมีนาคม ตรงนี้ก็คือเลข 3 วันที่ 31 ตอนนี้ผมต้องใส่เวลาของผมตรงนี้ ตอนนี้เป็น 10:30 งั้นเปลี่ยนเป็น 10:35 แล้วตอนนี้เราลบเครื่องหมาย reminder sent ออก แล้วมันจะประมวลผลสิ่งนั้น แล้วมันควรส่งการแจ้งเตือน WhatsApp มาให้ผม

แต่ก่อนที่มันจะทำ ผมต้องคลิกที่ test workflow แล้วอันนี้ควรเข้าสู่โหมดฟัง (listening mode) webhook นี้กำลังเฝ้าดูข้อมูลจาก Google Sheet นี้ และ Google Sheet นี้จะส่งการแจ้งเตือนนี้ หรือจะเปิดใช้งานอันนี้ในเวลาที่กำหนด ซึ่งก็คือ 2 นาทีก่อนถึงกำหนด ดังนั้นมันควรอยู่ที่ 10:33 คุณเห็นไหมว่าการแจ้งเตือนถูกกำหนดเวลาไว้ และมันจะถูกส่งตอนนี้ 2 นาทีก่อนกำหนด มันควรเป็นเวลา 10:33 ดังนั้นภายใน 1 นาทีผมควรได้รับการแจ้งเตือนตรงนี้ ถ้าทุกอย่างเป็นไปด้วยดี

และตรวจสอบให้แน่ใจว่าอันนี้อยู่ในโหมดฟัง มันอยู่ในโหมดฟังสักสองสามนาทีแล้วมันจะหยุด แล้วคุณต้องคลิก start listening อีกครั้ง งั้นรอกันก่อน แล้วตอนนี้คุณเห็นว่าการแจ้งเตือนถูกส่งแล้ว ข้อความถูกส่งแล้ว และถ้าผมไปดู ผมเห็นว่าข้อความถูกส่งแล้ว

ตอนนี้กลับมาตรงนี้ มาดูกัน ตรงนี้เรามีข้อผิดพลาด ใช่ไหม? ตรงนี้เราอาจต้องเปลี่ยน เพราะ API key ไม่ถูกต้อง มันหมดอายุแล้ว ดังนั้นตรงนี้คุณก็มี OpenAI ด้วย ตรงนี้คุณต้องเลือกบัญชี OpenAI ที่คุณเพิ่งเชื่อมต่อ นั่นคือสาเหตุที่เราเจอข้อผิดพลาด แต่ไม่เป็นไร อย่างน้อยเราก็รู้ว่าการแจ้งเตือนและ webhook ทำงาน

เราจะลองอีกครั้ง ในการทำแบบนี้ ผมลบมันออก แล้วตอนนี้ก่อนอื่นผมจะเปลี่ยนเวลาอีกครั้ง ประมาณ 5 นาทีจากนี้ นั่นคือ 10:38 แล้วลบมันออกอีกครั้ง แล้ววาง webhook ลงในโหมดฟัง มีปัญหาตรงนี้ ทำไมถึงเป็นปัญหา? กลับไปก่อน ลบอันนั้นออก ตอนนี้มันทำงานแล้ว ผมต้องลบการทดสอบนี้ออก ตอนนี้เข้าสู่โหมดทดสอบ แล้วตอนนี้มันควรทำงาน ใช่ ตอนนี้เราได้รับข้อมูลอีกครั้งแล้ว ตอนนี้มันทำงานแล้วอย่างที่เห็น

แล้วตอนนี้กลับไปอีกครั้ง และสิ่งที่เราจะทำคือ เปลี่ยนอันนี้เป็น active แล้วเราอยากทดสอบว่าการแจ้งเตือน WhatsApp จริง ๆ มาถึงไหม แล้วเราจะเปลี่ยนอันนี้เป็น production คัดลอกอันนั้นมาวางที่นี่ แล้วแทนที่ webhook ตรงนี้ด้วยอันนั้น คลิก save แล้วเราทำการทดสอบอีกครั้ง

เราจะเปลี่ยนเวลาเป็นประมาณ 10:40 หรือ 10:41 และตอนนี้มันใกล้แล้ว ผมไม่ต้องทดสอบอีก แล้วผมก็แค่ต้องดูว่าภายใน 1 นาทีการแจ้งเตือนจะส่งผ่านไหม ตรงนี้ผมเห็นว่าการแจ้งเตือนถูกส่งแล้ว แต่ผมไม่เห็นมันปรากฏใน WhatsApp งั้นกลับมาตรงนี้ แล้วผมสามารถไปที่ execution เพื่อดูว่ามี error ไหม และคุณเห็นว่าเรามี error ตรงนี้

มาหาสาเหตุของปัญหากัน ตรงนี้มีข้อความว่า Recipient phone number not in allowed list ผมเข้าใจแล้ว เพราะหมายเลขโทรศัพท์ต้องเป็นหมายเลขจริง ดังนั้นผมต้องใส่หมายเลขโทรศัพท์ของตัวเองที่ใช้สำหรับทดสอบตรงนี้ และนั่นคือหมายเลขที่ผมมีในการตั้งค่า API ดังนั้นเมื่อคุณคลิกที่ select recipient phone number นั่นคือหมายเลขที่ผมใช้ทดสอบ ดังนั้นผมต้องใส่หมายเลขจริงของผมพร้อมรหัสประเทศ ซึ่งก็คือ 49 สำหรับเยอรมนี

มาลองอีกครั้ง กลับไปที่ editor ตรงนี้ มันยังเหมือนเดิม ผมแค่ต้องเปลี่ยนเวลานี้อีกครั้งเป็นเวลาว่างถัดไป ให้เป็น 10:45 ผมจะลบอันนี้ แล้วตอนนี้คุณเห็นว่าการแจ้งเตือนมาถึงแล้ว ดังนั้นเวิร์กโฟลว์ของเราถูกตั้งค่าเรียบร้อย

ตอนนี้เราจะกลับไปและเปลี่ยนเป็นเวลาการแจ้งเตือนจริงที่ผมต้องการ ผมจะเพิ่มเลข 6 กลับเข้าไป และนี่จะเป็นการแจ้งเตือน 2 ชั่วโมงก่อนเวลานัด คุณต้องพิมพ์สิ่งที่คุณต้องการ ผมอาจใช้ 4 ชั่วโมงก่อนนัด คนควรได้รับการแจ้งเตือน และนั่นคือทั้งหมดที่จำเป็น

แน่นอนว่าขั้นตอนสุดท้ายคือเปลี่ยนอันนี้ให้เป็นโซลูชันจริง ให้ออกจากช่วงทดสอบ เพราะ access token นี้หมดอายุหลังจากช่วงเวลาหนึ่ง คุณจะต้องเปลี่ยนเป็นโหมด live คุณต้องให้ privacy URL ในการตั้งค่าพื้นฐาน แล้วทำตามขั้นตอนเหล่านี้ ต้องเพิ่มหมายเลขโทรศัพท์ตรงนี้ คุณอาจต้องซื้อซิมการ์ดเพิ่ม และผมมีโทรศัพท์ธุรกิจ แล้วใส่ข้อมูลนี้ แล้วเชื่อมต่อ แล้วคุณสามารถเพิ่มวิธีการชำระเงิน ข้อความหนึ่งพันข้อความแรกต่อเดือนฟรี และคุณมีรายละเอียดต้นทุนที่แน่นอนด้านล่างวิดีโอนี้

หรือถ้าคุณต้องการโซลูชันที่ปรับขนาดได้มากกว่า ผมแนะนำให้ดู Twilio และคุณต้องสมัครบัญชีที่นั่น แต่สิ่งที่สำคัญคือ การใช้ WhatsApp อย่างมีประสิทธิภาพในฐานะ agent หรือโซลูชันธุรกิจ คุณต้องมีบัญชีธุรกิจ Facebook ที่ได้รับการยืนยัน (verified Facebook business account) ถ้าคุณยังไม่มี นี่คือพรอมต์ที่คุณสามารถใช้ได้ ซึ่ง ChatGPT หรือ Claude จะพาคุณไปทีละขั้นตอนเพื่อให้ได้บัญชีธุรกิจ Facebook ที่ได้รับการยืนยัน

และเมื่อคุณทำเสร็จแล้ว คุณสามารถใช้ WhatsApp AI agent นี้อย่างถูกต้องเป็นโซลูชันด้วยหมายเลขโทรศัพท์ธุรกิจของคุณ หรือกับโซลูชันอย่างเช่น ที่คุณสามารถจัดการการสื่อสาร WhatsApp ทั้งหมดที่คุณได้รับผ่าน agent นี้บนแพลตฟอร์มเดียว ใช่แล้ว
