## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 2 ของการตั้งค่าระบบ โดยเราจะสร้างเวิร์กโฟลว์ที่ใช้ตรวจสอบเวลาว่างของปฏิทิน แล้วนำเวิร์กโฟลว์นี้ไปผูกเป็น tool (เครื่องมือ) ให้กับ voice agent (ตัวแทนเสียง) เพื่อให้มันสามารถตรวจสอบเวลาว่างและตอบกลับผู้ใช้ได้ โดยตั้งค่าทั้งเขตเวลา, ฐานข้อมูล Supabase, การเชื่อมต่อปฏิทิน และการเพิ่ม custom tool พร้อม body parameters ต่าง ๆ

## คำแปลเต็ม

ขั้นตอนการตั้งค่าถัดไป ในระบบอัตโนมัตินี้เราจะตั้งค่าเวิร์กโฟลว์ที่ตรวจสอบเวลาว่างของเรา แล้วเราจะผูกเวิร์กโฟลว์นี้เป็น tool ให้กับ voice agent ของเรา เพื่อที่มันจะสามารถเข้าถึงกระบวนการตรวจสอบเวลาว่างนี้ ดึงเวลาว่างกลับมา และตอบกลับผู้ใช้ได้ ดังนั้นเราใช้สิ่งนี้ และถ้าคุณยังไม่มีบัญชี คุณสามารถเริ่มต้นได้ฟรี สมัครทดลองใช้ 14 วัน และเมื่อคุณเข้าสู่ระบบแล้ว คลิกที่ create the workflow และตรงนี้ด้านล่างคุณจะพบ download n8n แล้วคลิกที่ import from file แล้วคุณก็แค่นำเข้าไฟล์ที่คุณเพิ่งดาวน์โหลด และนั่นคือเวิร์กโฟลว์ นั่นคือทั้งหมดที่เราต้องการตรงนี้

ก่อนอื่นเราจะโฟกัสที่ส่วนนี้ ในวิดีโอนี้ และในวิดีโอถัดไปเราจะตั้งค่าส่วนอื่น นี่เป็นเพียงการรับเวลาว่างจากปฏิทินของเราแล้วตอบกลับไปยังผู้ใช้ ตอนนี้มีสองสามอย่างที่เราต้องตั้งค่า เราจะเชื่อมต่อเครื่องมือต่าง ๆ ตรงนี้ นี่คือโมดูล AI agent และตรงนี้เราก็มี system message ด้วย สิ่งเดียวที่เราต้องเปลี่ยนตรงนี้ โดยพื้นฐานแล้ว AI agent ตัวนี้จะตรวจสอบเวลาว่างโดยอิงจากข้อมูลของบุคคลนั้น ข้อมูลนี้จะมาจากเวิร์กโฟลว์ของเราตรงนี้ เราจะส่งไปยังส่วนนั้น และเราจะตั้งค่านี้ด้วย ตรงนี้คุณแค่ต้องใส่เขตเวลาของคุณ ในกรณีของผม เขตเวลาของผมคือเยอรมนี และตรงนี้ผมต้องระบุด้วยว่า conversion คืออะไร? และคุณเห็นตรงนี้ มันแสดงเวลาท้องถิ่นของคุณ และโดยปกติแล้วนี่ควรเป็นเวลาที่ถูกต้อง สำหรับอันนี้มันเป็นแบบนี้ สิ่งที่เรียกว่าเวลา UTC และตรงนี้คือค่าชดเชยเขตเวลาโดยพื้นฐาน ดังนั้นตรงนี้มันเป็นบวกสอง นี่หมายความว่า ตัวอย่างเช่น ถ้าเป็นแบบนี้ คุณจะเห็นว่าตรงนี้เราต้องมีบวกสอง ดังนั้นเราจึงมีโดยพื้นฐาน ผมต้องแน่ใจว่านี่คือการเพิ่ม 2 ชั่วโมงให้กับเวลา UTC ใด ๆ เพราะมันแสดงบวกสอง และตรงนี้ผมยังให้มันด้วย ดังนั้นอันนี้ต้องเป็น 13 หรือ 13:00 น. ตามเวลาเบอร์ลินเยอรมนี และตรงนี้ด้านล่างเรามีเขตเวลาอีกครั้ง นี่สำคัญมากว่ามันต้องถูกต้อง

เครื่องมือถัดไปที่เราตั้งค่าคือ tool นี้ นี่คือเครื่องมือของเราที่จะบันทึกข้อมูลทั้งหมดเกี่ยวกับการจองและลูกค้าที่จองนัดหมายลงในฐานข้อมูลของเรา และตรงนี้เราจะใช้เครื่องมือที่ชื่อว่า Supabase คุณสามารถสมัครบัญชีฟรีได้ตรงนี้ แล้วไปที่ dashboard ตรงนี้ภายใต้ ฉันต้องไปที่ project settings แล้วไปที่ data API จากนั้นฉันไปคัดลอกอันนั้น แล้วกลับไปที่ API service role คัดลอก วางลงตรงนี้ คลิก save แล้วมันก็ทำงานได้ดี

และตอนนี้ฉันต้องกลับไปที่ table และสร้างตารางใหม่ ฉันจะตั้งชื่อให้มัน ชื่ออะไรก็ไม่สำคัญ Voice agent คลิกที่ save และเพราะตรงนี้ฉันต้องเลือก แต่ฉันต้องสร้างมันก่อน ดังนั้นตรงนี้ฉันมี ฉันคลิกที่ new column อันแรกจะเป็นคอลัมน์ ประเภทเป็น text save อันถัดไปคือ phone number และเราใช้ตรงนี้ด้วยว่าเป็น text เรามี summary ซึ่งเป็นแค่บทสรุปของการสนทนา คุณต้องการบันทึกสิ่งนั้นด้วย แล้วเรามีอีกสองสามอย่าง เรามี event name โดยพื้นฐานแล้วนั่นคือชื่อบริการ ในกรณีของเรา เช่น คนจองบริการนวดประเภทไหน? แล้วเรายังต้องมี event ID ที่ตรงกันสำหรับอันนี้ด้วย ดังนั้นเราก็แค่ event ID คุณใช้ text ตรงนี้ด้วย มี just booked เราต้องการให้แน่ใจว่าเราสามารถทำเครื่องหมายบุคคลนี้ได้หลังจากที่พวกเขาจองนัดหมาย และเราสามารถทำเครื่องหมายเป็น yes ได้ ดังนั้นบุคคลนั้นได้จองแล้ว และเรายังมี appointment date โดยพื้นฐาน นี่คือที่ที่จะเก็บวันที่และเวลาที่เฉพาะเจาะจงของการนัดหมาย

ตอนนี้มันถูกตั้งค่าแล้ว เลือกมันได้ ต้องสร้างอันนี้ก่อน ตอนนี้มันปรากฏขึ้น และต่อไปเราต้องกำหนดว่า ชื่อควรถูกบันทึกอย่างไร โดยพื้นฐานแล้วเราแค่แมปมันตรงนี้ อันแรกจะเป็น name เราสามารถกำหนดได้เลย ชื่อของผู้ใช้ ชื่อของผู้ใช้ อันถัดไปจะเป็นหมายเลขโทรศัพท์ เพิ่มคำอธิบายตรงนี้ ดังนั้นเมื่อใดก็ตามที่ฉันคลิก Magic นี้ AI จะกำหนดเองว่าจะเขียนค่าอะไรลงไป และฉันแค่แนะนำมันด้วยคำอธิบาย และฉันจะแสดงให้คุณเห็นว่ามันรับค่าเหล่านั้นมาจากไหน คลิกที่อันนั้น Summary ของการสนทนา จริง ๆ แล้วฉันไม่ต้องกำหนดอันนี้ แล้วเรามีอะไรอีก? ID event name ฉันคิดว่าฉันไม่ต้องใส่คำอธิบายด้วยซ้ำ เพราะอันนี้ถูกกำหนดไว้แล้วใน system instructions แล้ว ดังนั้นเรามี event name, event phone และนั่นก็เพราะว่าตรงนี้คุณเห็นว่าฉันได้กำหนดไว้แล้วใน system instructions AI agent รู้ว่าค่าเหล่านี้คืออะไรและควรบันทึกอย่างไร และตอนนี้ฉันแค่บอกให้บันทึกลงใน Supabase ของฉัน

และฉันยังต้องการให้มีการเชื่อมต่อนี้ ฉันต้องเลือกบัญชีที่ฉันเพิ่งใช้ Supabase เลือก และสิ่งเดียวที่มันทำคือมันสามารถอ่านรายการทั้งหมดได้ สำหรับการบันทึกข้อมูลใหม่และการอ่าน คุณต้องมี tool พิเศษในกรณีนี้ ตอนนี้ฐานข้อมูลถูกตั้งค่าแล้ว และเรายังต้องการเชื่อมต่อปฏิทินของเราด้วย ใช่ไหม? เราต้องการอนุญาตให้ AI agent ตรวจสอบเวลาว่างของเราสำหรับอีเวนต์ต่าง ๆ เหล่านั้น และนั่นคือเหตุผลที่เราใช้ getAvailability อันนี้ถูกตั้งค่าไว้ล่วงหน้าแล้ว คุณต้องระบุเขตเวลาของคุณด้วย ของฉันคือเยอรมนี และอันนี้ถูกกำหนดไว้แล้ว โดยพื้นฐานแล้วมันค้นหา event ID นี้ เช่น บริการเฉพาะที่บุคคลนั้นต้องการในอันนี้ ใช่ไหม? ฉันมีเวลาว่างอะไรบ้างสำหรับบริการนวดเหล่านี้? และนี่คือช่วงเวลาที่มันค้นหา มันระบุช่วงเวลา เช่น มันจะค้นหาใน 30 วันถัดไป และหาเวลาว่างห้าช่วงเวลาถัดไป และอันนี้ถูกกำหนดไว้ตรงนี้ คุณสามารถแก้ไขได้ตามที่คุณเห็น เวลาสิ้นสุดคือ 30 วันนับจากนี้ แล้วคืนเฉพาะห้าช่วงว่างแรก คุณสามารถกำหนดมันได้ตามที่คุณต้องการเลย

และตรงนี้สิ่งเดียวที่เราต้องแทนที่คือ API key จากเครื่องมือปฏิทินนี้ และคุณจะพบมันภายใต้ settings ตรงนี้ภายใต้ API key แล้วคลิกที่ add key ตั้งชื่อว่า demo setup แล้ว never expires คลิกคัดลอกแล้ววางลงตรงนี้ โอเค ตั้งค่าเสร็จ ตอนนี้เรายังไม่เสร็จ ยังมีอีกหนึ่งอย่างที่เราต้องทำ เราต้องกลับไปที่ voice agent ของเรา ตรงนี้เราต้องคลิกที่ Add Custom Tool และตรงนั้นเราต้องตั้งชื่อให้มัน ตอนนี้ชื่อ tool ผมไม่แน่ใจว่าผมได้กำหนดไว้ตรงนี้หรือไม่ บางทีมันถูกกำหนดแล้ว? มันอยู่ในอันนี้ เลื่อนไปด้านล่าง มันคือ get availability tool นั่นควรเป็นชื่อ นั่นควรเป็นชื่อตรงนี้ ดี จากนั้นฉันมีนี่คือคำอธิบายของ tool นี่คือเหมือนกับ tools ที่เราได้เพิ่มไว้ตรงนี้ เราบอก AI ว่ามันมีเครื่องมืออะไรให้ใช้

สิ่งที่เราจะทำคือ ตรงนี้เราจะให้ test URL ของ webhook แก่มัน นี่คือสิ่งที่เราวางลงไป และอันนี้ต้องเป็น POST และ response เราตั้งค่านี้เป็น 70 เพื่อให้แน่ใจว่ามันรอนานพอที่จะได้รับคำตอบกลับมาจากเวิร์กโฟลว์ของเรา และตรงนี้เราต้องมี body parameters ตรงนั้นเรามี description เราไม่ได้มีจริง ๆ ดังนั้นนี่เป็นเพียงข้อมูลที่รวบรวมจากผู้ใช้ และเราเพิ่ม property ในอันแรก Property แรกที่เรามีคือ phone number และเราได้รับหมายเลขโทรศัพท์โดยตรง ดังนั้นมันเป็นตัวแปรไดนามิก นี่คือการโทร ดังนั้นมันถูกระบุโดยตรงจากการโทร เมื่อมีคนโทรหาคุณ คุณจะเห็นหมายเลขเหมือนกับตัวบุคคล นั่นคือเหตุผลที่ฉันตั้งค่าแบบนั้น ฉันอาจถามบุคคลนั้นสำหรับโทรศัพท์ระหว่างการสนทนาได้ แต่ฉันต้องการหลีกเลี่ยงสิ่งนั้น ฉันต้องการรับมันโดยตรงจากการโทร เพราะโดยปกติแล้วมันถูกส่งมาพร้อมกับการโทรทุกครั้ง ดังนั้นฉันจะปล่อยมันไว้แบบนั้น

แล้วเรามี event name ชื่อของอีเวนต์หรือบริการ ซึ่งก็คือชื่อของผู้ใช้ อันนี้ถูกรวบรวมตลอดการสนทนา Voice agent จะถามชื่อโดยเฉพาะ แล้วเรามี event ID ถัดไป อันนั้นสำคัญสำหรับการจองหรือตรวจสอบเวลาว่างของบริการเฉพาะที่ผู้ใช้ต้องการ บริการนวดเฉพาะ แล้วเรามีอะไรอีก? เรามี summary นี่เป็นเพียงบทสรุปสั้น ๆ มันต้องอยู่ตรงนี้ บทสรุปของการสนทนา เพื่อให้ฉันสามารถบันทึกมันลงในฐานข้อมูลได้ด้วย และนั่นคือทั้งหมด จากนั้นฉันคลิกที่ Add Tool และตรงนี้คลิก Save เราได้เพิ่ม tool แล้ว ดังนั้นตอนนี้ voice agent สามารถเข้าถึงเวิร์กโฟลว์นี้และตรวจสอบเวลาว่างได้
