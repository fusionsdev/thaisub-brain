## บทนำ

บทเรียนนี้สอนวิธีสร้างฐานข้อมูลโฆษณาของคู่แข่งจำนวนมหาศาล เพื่อนำมาวิเคราะห์และ "ขโมย" ไอเดียโฆษณาที่เวิร์กจริง ผ่านสกิล Scrape Ad ที่ผู้สอนเตรียมให้ ซึ่งดึงโฆษณาทั้งหมดจาก Meta Ad Library มาถอดทรานสคริปต์ แยกข้อมูลฮุก แองเกิล รูปแบบโฆษณา แล้วเก็บลง Airtable พร้อมอธิบายทุกคอลัมน์ในตารางวิจัยว่ามีความหมายและใช้ประโยชน์ยังไง

## คำแปลเต็ม

ว่าไงครับทุกคน? ยินดีต้อนรับสู่บทเรียน Steal Competitors Ads ครับ ในบทเรียนนี้ ผมจะโชว์วิธีสร้างฐานข้อมูลโฆษณาของคู่แข่งจำนวนมหาศาล ที่คุณสามารถเอาไปใช้ ขโมย และใช้ประโยชน์จากมันได้ทุกอย่างจริง ๆ และผมให้สกิลสำหรับทำสิ่งนี้กับคุณด้วย ข้างล่างนี่ ไปดาวน์โหลดสกิล Scrape Ad แล้วก็เข้าไปที่หน้า setup ของคุณ แล้วเราจะตั้งค่ามัน

วิธีติดตั้งคือคุณแค่ลากสกิลลงไป แล้วให้ Claude Code ตั้งค่าสกิลให้คุณ ผมให้ไฟล์ติดตั้งมาแล้ว มันจะพาคุณผ่านขั้นตอนการตั้งค่าเกือบทั้งหมด สิ่งเดียวที่คุณต้องมีสำหรับบทเรียนนี้คือ Airtable หรือจะใช้ Google Sheets ก็ได้ และผมให้ตารางวิจัยที่ผมใช้จริงพร้อมข้อมูลทุกจุดมาให้คุณด้วย

หรือจะใช้ Airtable ก็ได้ ผมชอบ Airtable มาก มันสร้างคัสตอมวิวที่ดีที่สุด และมันเจ๋งมาก คุณมี token หรือ scopes มากมายกับ Airtable เหมือน Claude Code สร้างอะไรก็ได้ที่คุณฝันไว้ข้างใน Airtable ได้ แล้วสิ่งที่สกิลนี้จะทำคืออะไร

ผมจะพาคุณเดินผ่านบทเรียนนี้ ผมให้แผนบทเรียน (lesson plan) มาด้วย คุณสามารถป้อนให้ Claude Code แล้วมันจะแจกแจงให้ สกิลนี้จะ scrape โฆษษณาของคู่แข่งจากฐานข้อมูลคู่แข่งของคุณ มาจากบทเรียน Sourcing Competitors ถ้าคุณยังไม่ได้ดูบทเรียน Sourcing Competitors ไปดูได้เลย

บทเรียนนั้นจะโชว์วิธีสร้างฐานข้อมูลเล็ก ๆ ของคู่แข่งทั้งหมดของคุณ โดยมี niche และข้อมูลทุกอย่างที่เราอยากรู้เกี่ยวกับคู่แข่ง ถ้ายังไม่ดู กรุณาไปดูก่อน เพราะคุณต้องตั้งค่านั้นก่อน ถึงจะสร้างฐานข้อมูลโฆษณาที่ชนะนี้ได้

สิ่งที่สกิลทำคือ มันจะ scrape โฆษณาทุกตัวใน Ad Library ผมแยกมันเป็นช่วงเวลา แต่ Meta Ad Library คือฐานข้อมูลยักษ์ใหญ่ของโฆษณาทุกตัวที่รันอยู่บนโลกใบนี้ ทุกที่จริง ๆ ตอนนี้ผมอยู่ในบราซิล ผมเข้าไปที่ All Ads แล้วพิมพ์ fitness ใช่ไหมครับ? มันจะให้โฆษณาหลายร้อยรายการจากโค้ชฟิตเนสทุกคนบนโลก ซึ่งเจ๋งมาก

และมันจะบอกหลายอย่าง มันจะบอกว่าวิ่งมานานแค่ไหน อยู่บนแพลตฟอร์มอะไร ยังแอ็กทีฟอยู่ไหม คอนเทนต์โฆษณา (copy) เฉพาะคืออะไร รูปภาพคืออะไร วิดีโอคืออะไร CTA คืออะไร อะไรแบบนั้น แต่ผมจะโชว์วิธีได้ข้อมูลทั้งหมดนี้จริง ๆ เพราะสิ่งนี้มันสำคัญ

คุณไม่อยากแค่เข้าไปค้นหา fitness coaches แล้วเริ่ม scrape โค้ชฟิตเนสทั้งหมด ใช่ไหมครับ? มันมีผลลัพธ์เกือบไม่จำกัด และทำไมนั่นถึงเป็นปัญหา? เพราะคุณไม่สามารถ scrape ข้อมูลเยอะขนาดนั้นแล้วให้ Claude Code หรือ AI ใด ๆ ตีความข้อมูลได้ เพราะมันจะโอเวอร์โหลด context และมันจะระเบิด มันจะไม่ทำงาน

และมีคนจำนวนมากที่โฆษณาแย่ เราอยากได้โฆษษณาของคนที่ทำได้ดีมาก ไม่ใช่คนสุ่ม ใช่ไหมครับ? และผมแจกแจงเรื่องนั้นทั้งหมดในบทเรียนที่แล้ว สิ่งที่มันจะทำคือ scrape โฆษษณาทุกตัวใน Ad Library จากลิสต์คู่แข่งของคุณ มันจะดาวน์โหลดวิดีโอโฆษษณา แล้วดึง metadata อย่าง aspect ratio อะไรพวกนั้น มันจะถอดทรานสคริปต์วิดีโอให้คุณด้วย Whisper

ถ้าคุณยังไม่มี Whisper Claude Code จะถามให้ดาวน์โหลด มันฉลาดพอที่จะจัดการและดาวน์โหลดให้คุณเอง แต่ผมใส่ไว้ในแผนบทเรียนและวิดีโอ Sourcing Competitors แล้ว มันก็จะให้คุณเหมือนกัน จากนั้นมันจะดึงฮุก และอะไรพวกนั้น แล้วผมจะแจกแจงฐานข้อมูลทั้งหมดให้ดู

แล้วมันจะจัดหมวดหมู่แองเกิลโฆษษณาแต่ละตัว ซึ่งเจ๋งมาก จากนั้นมันจะ push ทุกอย่างเข้า Airtable และใช้เวลาประมาณ 10 ถึง 15 นาที ค่าใช้จ่ายประมาณ 20 เซนต์ใน Apify ซึ่งบ้าไปแล้ว ผมว่ามันประมาณหนึ่งดอลลาร์ต่อพันโฆษษณาที่คุณ scrape ซึ่งโคตร crazy

เราไม่จำเป็นต้องใช้เยอะขนาดนั้น เพราะมีสิ่งที่เรียกว่า information overload เราอยากได้ข้อมูลเชิงลึกพอประมาณ ไม่ลึกเกินไป แต่แนวคิดหลักของอันนี้คือ "longevity เท่ากับความสำเร็จ" ใช่ไหมครับ? ถ้าโฆษษณาวิ่งมานาน เรากำลังดูโฆษษณาที่คู่แข่งเรารันอยู่ แต่เราอยากได้ตัวที่รันมานานกว่า 30 วัน

เพราะเรารู้ว่าถ้าใครรันโฆษษณานานกว่า 30 วัน แปลว่ามันทำกำไร มันเวิร์กจริงสำหรับพวกเขา เราจะขโมยสิ่งที่พวกเขาทำเป๊ะ นั่นคือประเด็น และเดี๋ยวผมจะโชว์วิธีนำโฆษษณานั้นไปใช้ด้วย ไม่ว่าจะเป็นวิดีโอหรือรูปภาพ อะไรก็ตาม

ในการติดตั้งสกิล ผมให้คู่มือการตั้งค่าทั้งหมดมาแล้ว ผมวางแผนบทเรียนไว้ให้คุณป้อน Claude Code ได้ แต่สกิลที่ให้จะถามให้คุณตั้งค่าต่าง ๆ เอง เราจะได้ข้อมูลหลายจุด ผมจะพาคุณเดินผ่านฐานข้อมูลทั้งหมดตอนนี้ เราจะดูรูปแบบโฆษษณา อะไรพวกนั้น

สิ่งที่เจ๋งมากคือ มันจะหาว่าผู้คนใช้แองเกิลอะไรบ้าง แองเกิลของโฆษษณาเป็นแบบไหน และสกิลนี้ควรรันเดือนละครั้ง รันแบบนี้ก็พอ คุณไม่จำเป็นต้องรันบ่อยกว่านั้น เว้นแต่คุณเป็นธุรกิจใหญ่ที่ทำงบประมาณหลักแสน คุณอาจต้องวิจัยทุกสัปดาห์หรือทุกสองสัปดาห์

แต่ถ้าคุณเป็นบัญชีเล็ก ๆ ใช้เงินไม่มาก คุณไม่ต้องทำบ่อยขนาดนั้น คุณแค่ต้อง scrape ดูว่าคนอื่นทำอะไร แล้วรันโฆษษณาของคุณ มีเรื่องของเวลาเข้ามาเกี่ยวข้องด้วย เพราะเรื่อง Claude Code พวกนี้มันเท่ดี แต่อย่าลืมว่า สิ่งที่สำคัญที่สุดคือการที่คุณสร้างโฆษษณาและลงโฆษษณาจริง ๆ นั่นคือสิ่งที่สำคัญที่สุด ผมแนะนำให้รันสกิลนี้เดือนละครั้ง นั่นคือที่ผมทำ ผมรันเดือนละครั้ง อย่างน้อยบริษัทที่ผมทำงานด้วยบางแห่งไม่ได้ใช้เงินเยอะ พวกเขาไม่ต้องวิจัยเยอะ แต่ก็ยังสำคัญที่จะทำ

และผมมีคู่มือแก้ปัญหา (troubleshooting guide) ให้ด้วย เช่น โฆษษณาที่ scrape อาจใช้เวลานาน คุณต้องเช็คว่าเวลาคุณ scrape คู่แข่งคนหนึ่ง พวกเขาไม่ได้มีโฆษษณาเยอะเกินไป ตัวอย่างเช่นผม scrape Alex Hormozi เขารันโฆษษณาประมาณ 200 กว่ารายการต่อเดือน 260 แอ็กทีฟ ซึ่งโคตร crazy

หลังจากการอัปเดต Andromeda เมื่อไม่กี่เดือนก่อน Meta ตอนนี้ให้รางวัลกับคนที่รัน ad creative หลายตัว ดังนั้นบัญชีที่ฉลาดจะรันโฆษษณาจำนวนมาก มันจะใช้เวลาพอสมควรสำหรับสกิลที่ทำงานเบื้องหลัง คุณสามารถตั้งค่า n8n automation เพื่อรันมันโดยไม่ต้องพิมพ์คำสั่งเอง ผมตั้งใจจะทำแบบนั้น แต่คุณไม่จำเป็นต้องทำเว้นแต่คุณเป็นคนที่ใช้เงินเยอะ ผมสร้างมันไว้แล้ว เดี๋ยวจะปล่อยในคอมมูนิตี้ ถ้าอยากได้ก็บอกผม แต่คุณไม่จำเป็นจริง ๆ เพราะ Claude Code skill จะจัดการให้

มันจะใช้เวลาประมาณ 10 ถึง 20 นาที สำหรับการ scrape ประมาณ 10 ตัว ไม่ใช่ token เยอะ โดยเฉพาะถ้าคุณมี Claude Code Max แค่เข้าใจว่ามันจะรันอยู่เบื้องหลัง และสิ่งสำคัญคือคุณสามารถทำงานอื่นไปพร้อมกันได้

แล้วคุณอาจเจอ error ชื่อ unknown field name นั่นคือชื่อฟิลด์ต้องตรงกัน แต่ Claude Code จะช่วยคุณแก้ผ่านไปได้ ส่วนปัญหา video transcription ไม่ทำงาน คือถ้าวิดีโอใหญ่เกินไป อาจเป็นแบบนั้น ซึ่งน่าเสียดาย แต่ถ้าคุณเข้าไปดูโฆษษณาของบางคนและได้ลิงก์ของพวกเขาอย่างน้อย คุณจะเห็นว่ามันมีค่ายิ่งกว่าอะไรทั้งหมด

แล้วคู่แข่งบางรายโชว์โฆษษณาเป็นศูนย์ คู่แข่งบางคนที่คุณลิสต์ไว้อาจเป็นแบบนั้น ปัญหาคือ Meta เปลี่ยน API ตลอดเวลา เพราะเขาไม่ชอบคนใช้ Claude หรือ n8n เพื่อทำให้หลายอย่างเป็นอัตโนมัติ คุณสามารถสร้างแอปใน Meta เพื่อทำสิ่งนี้ได้ แต่คุณต้องสมัครขออนุมัติเป็นหลัก มันเหมือนทางเลี่ยงสำหรับคนไม่อยากผ่านขั้นตอนนั้น แต่ทำไมต้องทำแบบนั้นด้วย ในเมื่อผมใช้ Apify ได้ และมันถูกจะตายไปสำหรับการ scrape โฆษษณาพวกนี้?

แค่นั้นแหละ ไปดาวน์โหลดสกิลแล้วอัปโหลด แล้วผมจะแจกแจงให้คุณดูตรงนี้ ผมสร้างวิวแบบ grid ขึ้นมา ผมสร้างแกลเลอรีสวย ๆ ของโฆษษณารูปภาพและวิดีโอทั้งหมด แต่มีข้อมูลหลายจุดที่ผมจะพาคุณดูทีละจุด

เรามี ad archive ID ซึ่งเป็น ID ที่โฆษษณาแต่ละตัวมี คุณจะเห็นว่าผมมี ad library ID นั่นคือวิธีที่คุณค้นหาโฆษษณาเฉพาะเจาะจง แล้วเรามี page และ page ID ซึ่งก็คือเจ้าของเพจ แล้วคุณมีคอลัมน์คู่แข่ง ผมลิงก์คู่แข่งเข้ากับตาราง ad research ของผม เมื่อ Claude Code รัน มันจะหา record ID ของคู่แข่งรายนี้ แล้วลิงก์มันเข้าด้วยกัน

มีอะไรเจ๋ง ๆ ที่ผมยังไม่ได้เพิ่ม คือเราทำ roll-up ได้ เช่น จำนวนโฆษษณาแอ็กทีฟทั้งหมด อันนี้อาจเพี้ยนไปหน่อย แต่ผมโชว์ให้ดูเฉย ๆ ผมสามารถลิงก์มันกับตารางโฆษษณา แล้วทำผลรวม ฟิลด์แบบ roll-up น่าจะเวิร์ก แล้วบูม ผมจะเห็นว่าบัญชีนี้รันโฆษษณาแอ็กทีฟกี่ตัว ซึ่งเจ๋งมาก แน่นอนคุณอยากเห็นว่าใครทำอะไรอยู่ บางคนรัน 200 โฆษษณา เยอะมาก เทียบกับ micro และ macro ของเราที่ไม่ได้รันเยอะขนาดนั้น แต่ในยุค Andromeda คุณต้องรันให้มากที่สุดเท่าที่จะทำได้

แล้วคุณมี ad library URL ผมมีลิงก์โฆษษณาเฉพาะของแต่ละโฆษษณาที่รันอยู่ มันจะเด้งขึ้นมา ดูสิ มันเด้งโฆษษณาเฉพาะตัวนี้ขึ้นมา ผมมีโฆษษณาทั้งหมดที่กดดูได้ ถ้าผมชอบตัวไหน ผมก็เข้าไปดูได้

แล้วผมมี start date เพื่อรู้ว่าโฆษษณาเริ่มรันเมื่อไหร่ และคุณสามารถใส่ end date ได้ ที่จริงไม่ค่อยมีประโยชน์เท่าไหร่ เพราะถ้าโฆษษณาหยุด แปลว่ามันไม่เวิร์กและพวกเขาตัดมันทิ้ง นั่นสำคัญ แล้วก็มีอันนี้ซึ่งสำคัญมาก: days active นี่คือฟิลด์สูตร (formula field) ถ้าเริ่มจาก start date ถ้าอยากได้ก็บอกผมได้ แต่คุณแค่ให้ Claude Code คำนวณว่าวิ่งมานานแค่ไหนจาก start date แล้วมันจะคำนวณให้ และมันอัปเดตทุกวัน ผมเลยรู้ว่าโฆษษณาพวกนี้ยังรันอยู่ทุกวัน

แล้วผมมี performance tier หรือ longevity tier สิ่งนี้จะบอกผมว่า โฆษษณานี้รันมานานกว่า 30 วันไหม? มันมีแค่สองค่า ใช่ไหมครับ? อะไรก็ตามที่ต่ำกว่า 30 วันบอกผมว่ามันคือการทดสอบ อะไรที่มากกว่า 30 วันบอกว่ามันคือตัวทำเงิน พวกเขายังรันอยู่ ยังใช้เงินอยู่ มันเวิร์กชัดเจน เว้นแต่เจ้าของบัญชีโฆษษณาจะโง่ แล้วรันโฆษษณาที่ไม่ทำกำไร ถ้าเป็นแบบนั้นก็แปลว่าคุณเลือกคู่แข่งผิดเอง

แต่ตัวนี้จะบอกว่าถ้ารันนานกว่า 30 วัน มันคือตัวทำเงินแน่นอน แล้วผมไปที่ Claude Code ได้ และบอกว่า "ดูตัวทำเงิน X ตัวหน่อย บอกความต่างระหว่างพวกมันทั้งหมด แล้วสร้างโฆษษณาหนึ่งหรือสามหรือห้าหรือสิบตัวจากข้อมูลนี้" ใช่ไหมครับ?

แล้วเราก็รู้ว่าเขารันบนแพลตฟอร์มไหนบ้าง เช่นผ่าน Audience Network ผมเห็นหลายตัวที่รันอยู่ ผมสังเกตได้ทันทีจากข้อมูลเฉย ๆ ว่าคู่แข่งรายนี้รันบน Facebook และ Instagram เท่านั้น เทียบกับ Jim Launch ข้างบนที่รันบนอีกแพลตฟอร์ม ซึ่งเจ๋งมาก

แล้วคุณมี display format อันนี้สำคัญมากครับ คุณจะเห็นโฆษษณาสามประเภท: วิดีโอ รูปภาพ carousel และ DCO ซึ่งก็คือวิดีโอแบบไดนามิก และพวกนั้นทำผลงานดีที่สุด สิ่งที่ผมเห็นจากบัญชีโฆษษณาใหญ่ ๆ คือบางคนรันโฆษษณารูปภาพหลายตัว อย่างน้อยที่ผมชอบทำคือรันโฆษษณารูปภาพหลายตัว แล้วก็โฆษษณารูปภาพพวกนั้นไม่เคยเวิร์กเท่าวิดีโอ

แล้วแต่อุตสาหกรรม และถ้ามันเวิร์กสำหรับคุณ มันก็เวิร์กสำหรับคุณ แต่ผมรันรูปภาพเพื่อดูว่าข้อความแบบไหนเวิร์กกับผู้คน ก่อนที่ผมจะใช้เงินกับ UGC หรือโฆษษณา AI หรือสร้างโฆษษณาของตัวเองและใช้เวลาอัดวิดีโอ ผมจะไปดูว่าแองเกิลไหนเวิร์กที่สุด แล้วโฆษษณารูปภาพที่ชนะบอกว่ามันเวิร์ก ผมถึงจะใช้เงินและทรัพยากรทำโฆษษณาวิดีโอ ใช่ไหมครับ?

ถ้าพวกเขารันโฆษษณาวิดีโอ พวกเขากำลังชนะ ข้อความภายในนั้นกำลังชนะ อีกอย่างที่ควรรู้คือ คุณมีวิดีโอ รูปภาพ และโฆษษณา DCO ทั้งหมด ด้วย DCO นี่คือข้อจำกัดของการ scrape เพราะ DCO คือสิ่งที่ Meta สร้าง creative หลายรูปแบบ ถ้าคุณให้มัน advance มันจะเอาโฆษษณารูปภาพมาทำหลายวาไรเอชันให้คุณ หรือคุณสามารถใส่โฆษษณาหลายตัวในโฆษษณาเดียว เพื่อทดสอบแข่งกัน ซึ่งเรียกว่า DCO ad

ปัญหาของ DCO คือมัน unscrapable เพราะ Meta บล็อกไว้ และพวกมันทำผลงานดีมาก คุณจะเห็นว่าข้อมูลหลายตัวเป็นแค่ product brand และมันไม่มีวิดีโอโฆษษณาทั้งหมด ฮุกและทรานสคริปต์จะไม่โผล่ เพราะคุณไม่สามารถ scrape มันได้ แต่ก็ยังดี เพราะคุณยังเข้ามาดูได้ว่า DCO โฆษษณาแบบไหนที่พวกเขารัน และบางครั้งคุณได้ thumbnail ด้วย ผมเห็นบางตัวทะลุเข้ามา ตัวนี้เด้งขึ้นมาสำหรับอันนี้ เห็นไหม? ผมเห็นว่าเขารันโฆษษณาอะไร เขากำลัง DCO สองโฆษษณานี้ตรงนี้ แต่คุณยังเข้าไปดูโฆษษณาเฉพาะได้

แล้วในนี้คุณมี body text ซึ่งก็คือ copy บนโฆษษณาเฉพาะ ซึ่งเจ๋งมาก ถ้าอยากเรียนรู้ ให้ไปดูโฆษษณาของ Alex Hormozi แล้วแยก body copy ของเขา คุณจะเห็น offer อะไรพวกนั้น คุณมี title ของโฆษษณา ซึ่งอยู่ล่างสุด ถ้าผมดึงอันนี้ขึ้นมา ดูว่าเขายังรันโฆษษณานี้อยู่ไหม มันเป็น DCO มันอาจไม่เด้งขึ้นมา อย่างที่คาดไว้ DCO พวกนี้อาจปวดหัวหน่อย ดูว่าดึงตัวที่เป็นรูปภาพหรือวิดีโอได้ไหม โอ้ บางทีเพราะผมอยู่ในโหมดอื่น เดี๋ยวดู อา สหรัฐอเมริกา ดึงขึ้นมาแล้ว บางที URL ของผมมันเพี้ยน

อันนี้ดีสำหรับคุณด้วย เพราะเวลา Claude Code สร้าง มันอาจสร้าง URL ผิด ผมมี URL ผิดอยู่ในนี้ นั่นสำคัญที่ต้องรู้ เมื่อคุณไปสร้างของคุณเอง คุณจะรู้ว่าปัญหาคืออะไร แต่คุณสามารถได้ ad library URL เฉพาะได้ บางตัวได้ บางตัวไม่ได้ แล้วคุณมี start ว่าวิ่งมาแล้วกี่วัน

แล้วเรามี CTA ว่าปุ่มข้างล่างโฆษษณาคืออะไร พวกเขาทำ Learn More? Apply Now? Download? ดูเหมือนหลายตัวแค่ทำ Learn More ซึ่งบอกอะไรหลายอย่าง แล้ว CTA type ก็เหมือนกัน แล้วคุณมี link URL ว่าเขาส่งคนไปที่ไหน อันนี้เจ๋งมาก ผมรู้ funnel ของพวกเขาจริง ๆ ผมมีลิงก์ funnel ของพวกเขา เขาส่ง traffic ไปที่ไหน? เขาทำ link URL หรือทำ Messenger? ถ้าเป็น Messenger แปลว่าเขาทำหน้า lead form ของ Facebook เขาส่งคนไปที่ native Facebook lead form page และคุณมีลิงก์ funnel ทั้งหมดของพวกเขา คุณสามารถไป funnel hack ได้ ซึ่งเจ๋งมาก

แล้วคุณมี link description บางคนใส่คำอธิบายลิงก์ว่าข้างในคืออะไร ซึ่งอันนี้ดูไม่ใช่อย่างนั้น ดูเหมือน Hormozi กำลังทำ แล้วคุณมี captions และ video URL เฉพาะ อันนี้จะให้ เรามีวิดีโอทั้งเรื่อง คุณเป็นเจ้าของ URL นี้ คุณเป็นเจ้าของ URL ของรูปภาพและวิดีโอ ซึ่งเจ๋งมาก เพราะคุณสามารถคลิกขวาแล้วบันทึก ดาวน์โหลดมันได้ ซึ่งสุดยอด และคุณเป็นเจ้าของมัน

แล้วมี image URL ซึ่งอันนี้ใช้ไม่ได้ แต่สำหรับรูปภาพมันใช้ได้ แล้วคุณมี video URLs แล้วมีรูปภาพเฉพาะ นั่นคือ Gym Launch แล้วมีวิดีโอ ซึ่งเจ๋งมาก คุณเห็นได้ว่าโฆษษณาวิ่งมานานแค่ไหน ทำไมข้อมูลนี้ถึงดี? เพราะถ้าผมเห็นเทรนด์ว่าโฆษษณายาว ๆ กำลังชนะ แสดงว่าโฆษษณายาวชนะ ถ้าผมเห็นเทรนด์โฆษษณา 15 วินาที ซึ่งไม่ใช่ เพราะส่วนใหญ่เป็น long-form ads แล้วนั่นบอกผม จากการวิเคราะห์ข้อมูลนี้ ผมรู้ว่าโฆษษณายาวทำงานได้ดีกว่า

แล้วคุณมี aspect ratio อันนี้เจ๋ง คุณเห็นได้ว่าพวกเขาทำ 4:5 หรือ 9:16 หรือ 16:9 ซึ่งเจ๋งมาก แล้วคุณมีทรานสคริปต์ของวิดีโอนั้น สำหรับโฆษษณาวิดีโอที่ไม่ใช่ DCO เฉพาะวิดีโอ คุณสามารถได้ทุกอย่างที่พวกเขาพูดข้างใน ซึ่งเจ๋งมาก เพราะบางอย่างที่คุณจะเห็นในวิดีโอหน้า ผมจะแจกแจง brief ที่ผมทำให้บริษัทหนึ่งในวิดีโอหน้า

แต่สิ่งที่ผมเรียนรู้ทันทีจากการได้ข้อมูลทั้งหมดนี้และสร้าง brief คือ Alex Hormozi และทีมของเขา พวกเขาปรับ body copy ให้เป๊ะ แล้วเอา hook หนึ่งตัว มาทำ 15 hooks ต่อ body copy หนึ่งตัว พวกเขาโฟกัสที่การทำ body copy ให้แม่นก่อน แล้วค่อยทดสอบหลาย ๆ hooks ซึ่งเจ๋งมาก

แล้วคุณก็ได้ hooks ด้วย ผมให้ hooks เฉพาะมาให้ดูด้วย คุณมี word count ว่าพูดกี่คำ แล้วมี social proof แล้วมี angle category อันนี้เจ๋งมาก มีหลายแองเกิลในโฆษษณาหนึ่งตัว เช่น social proof ซึ่งก็คือ testimonial แบบนั้น, pain to transformation คือพูดถึงจุดเจ็บแล้วโชว์การเปลี่ยนแปลง, พูดว่า "ผมเปลี่ยนจากสิ่งนี้เป็นสิ่งนี้ในเวลาเท่านี้" นั่นคือแบบนั้น, แล้วมี tips and profit growth, scarcity และ urgency อะไรพวกนั้น

แล้วคุณมี ad format type เช่น UGC, UGC interview, case motion, static UI อะไรพวกนี้ ข้อมูลนี้สำคัญเพราะคุณเห็นได้ว่าอะไรเวิร์ก แล้วลอกเลียนสิ่งที่พวกเขาทำเป๊ะ และแน่นอนคุณมี scrape date และหลายตัวคุณได้ preview หรือ thumbnail ของโฆษษณานั้น

หลายตัวเป็นวิดีโอ ดูเหมือนไม่ค่อยได้ แต่คุณสร้างแกลเลอรีได้ สิ่งที่ผมทำคือคุณแค่สร้างวิวใหม่ เลือก gallery แล้วคุณจะได้แกลเลอรีของโฆษษณาหลายร้อยตัว คุณคลิกเข้าไปแล้วเห็นข้อมูลทั้งหมดที่คุณต้องการ แต่สิ่งที่สำคัญที่สุดคือ LLM สามารถอ่านข้อมูลทั้งหมดนี้ได้ LLM เข้าไปวิเคราะห์ให้คุณ อ่านและสร้างสิ่งใหม่ให้คุณ

นั่นคือทุกอย่างสำหรับการตั้งค่าทั้งหมด ผมว่าไม่มีรายละเอียดอื่นนอกจาก Days active และสูตร longevity ผมสร้างสูตรขึ้นมา ถ้าอยากได้บอกผมได้ เพราะเวลาอัปโหลดตาราง สูตรจะไม่ถูกส่งไปด้วย ผมส่งให้คุณได้ แค่ shout out ใน School แล้วผมจะส่งให้

นั่นคือทุกอย่างสำหรับการสร้างคลังโฆษษณาของคู่แข่งทั้งหมดของคุณ อันนี้มีค่ามาก ไม่ใช่แค่ถ้าคุณรันโฆษษณา แต่ถ้าคุณกำลังสร้างอะไรให้ธุรกิจ คุณสามารถขายสิ่งนี้ได้ในราคาสูงมาก และผมกำลังให้คุณในคอมมูนิตี้นี้ ซึ่งบ้าไปแล้ว

นั่นคือทุกอย่างสำหรับวิดีโอนี้ บอกผมได้ถ้ามีคำถาม แชร์ใน School ถ้าคุณต้องการความช่วยเหลือในการสร้างสิ่งนี้ ถ้าอยากให้ผมสร้างให้ บอกผมได้ เราสามารถโทรคุยและผมตั้งค่าระบบทั้งหมดให้คุณ แต่จบแค่นี้สำหรับวิดีโอนี้ เจอกันในวิดีโอหน้า ซึ่งคือการสร้าง ad briefs จากข้อมูลทั้งหมดนี้ ขอบคุณครับ
