## บทนำ
วิดีโอนี้สอนตั้งค่า AI agent บน WhatsApp ที่พูดได้และมองเห็นได้: ส่งรูปภาพไป มันเข้าใจและตอบกลับได้ ส่งข้อความเสียงไป มันตอบกลับเป็นเสียงได้ และมันยังมีข้อมูลครบถ้วนเกี่ยวกับสินค้าทุกตัว ทั้งหัวข้อ ชื่อสินค้า และลิงก์ซื้อ ระบบใช้ Google Sheets เก็บข้อมูลสินค้า และใช้ Supabase เป็นหน่วยความจำระยะยาวเพื่อจดจำบทสนทนากับลูกค้าแต่ละคน

## คำแปลเต็ม

ในวิดีโอนี้ผมจะสาธิตการตั้งค่า AI agent ที่มีเสียงและมีภาพ (vision) เมื่อคุณส่งรูปภาพให้มัน มันจะเข้าใจและตอบกลับอย่างเหมาะสม เมื่อส่งข้อความเสียง มันก็ตอบกลับเป็นเสียงได้ และมันยังมีข้อมูลทั้งหมดเกี่ยวกับสินค้าทุกตัว เช่น หัวข้อของสินค้า ชื่อสินค้า และลิงก์สำหรับซื้อ นี่คือสิ่งที่เราจะตั้งค่า

ไปที่ n8n ของเรากัน ผมจะเข้าไปที่เวิร์กโฟลว์ n8n ของผม ถ้ายังไม่ได้ตั้งค่า n8n ให้คลิกที่ลิงก์ด้านล่างวิดีโอนี้เพื่อตั้งค่าบัญชี n8n เริ่มทดลองใช้ฟรีได้ จากนั้นคลิก Create new workflow แล้วคลิกที่ด้านล่างวิดีโอนี้ Download AI agent จากนั้นไปที่ Import from file แล้วนำเข้าเวิร์กโฟลว์ที่เพิ่งดาวน์โหลด จากนั้นเราจะเชื่อมต่อโมดูลต่าง ๆ ตรงนี้

เริ่มจาก WhatsApp ตรงนี้ต้องคลิก Create new credential ต้องใช้ client ID และ client secret ผมจะไปที่บัญชี Facebook developers ของผม ผมจะไม่ลงรายละเอียดวิธีตั้งค่าและวิธีขอ App ID และ App Secret เพราะจะมีบทเรียนเทคนิคแยกต่างหาก ผมจะใส่บทเรียนวิธีขอ credentials และวิธีสร้างบัญชี developer บน Facebook สำหรับใช้กับ WhatsApp ทั้ง secret และ client ID รวมถึงวิธีขอค่าเหล่านี้ ดูบทเรียนนั้นได้ มันจะปรากฏตรงนี้

ผมเตรียมไว้แล้ว เข้าไปที่บัญชี Facebook ของผมตรงนี้ client ID คือ app ID และ app secret คืออันนี้ คลิก Show จากนั้นต้องล็อกอิน แล้วก็คัดลอก client ID วาง แล้วคลิก Save

พอทุกอย่างเชื่อมต่อเรียบร้อย ต้องจำไว้ว่านี่คือหมายเลขบัญชี WhatsApp เพราะตอนนี้ต้องเข้าไปในโมดูล WhatsApp ต่าง ๆ แล้วเชื่อมต่อกับบัญชีนี้ ตรงนี้ต้องใช้ credential คนละแบบ ต้องใช้ access token และ business ID ซึ่งก็ต้องหาเหมือนกัน ผมหาได้จากการตั้งค่า WhatsApp API: Generate access token คัดลอก วางตรงนี้ และ business ID ก็คือ WhatsApp business account ID คลิก Save

ตอนนี้เรามีบัญชีหมายเลขแปดแล้ว ดี กลับไปที่เวิร์กโฟลว์ เราต้องเลือกบัญชีที่เพิ่งเชื่อมต่อ ถ้ายังไม่ได้เชื่อมต่อบัญชี WhatsApp อื่น คุณจะมีแค่บัญชีเดียวให้เลือก กลับไปก่อน เราจะจัดการ WhatsApp ในโหนดต่าง ๆ ก่อน จากนั้นต้องเลือกบัญชีและใส่ access token ด้วย กลับไปด้านบน คัดลอก access token วางตรงนี้ แล้วยังมีอีกอันหนึ่ง คิดว่าเราทำอันนี้ไปแล้ว ยังมีอีกอันที่ต้องทำ เลือกบัญชี WhatsApp ที่เพิ่งสร้างและเชื่อมต่อ แล้วใส่ access token ตรงนี้ด้วย

ไปทางด้านขวา ตรงนี้มีโมดูล WhatsApp อีกสองสามโมดูล ตรงนี้เชื่อมต่อไว้แล้ว หมายเลขแปด ตรงนี้ก็เชื่อมต่อหมายเลขแปดแล้ว ดี ตรงนี้ก็เหมือนกัน ดูเรียบร้อยดี

ต่อไปเป็นสิ่งที่ต้องเชื่อมต่อ: บัญชี OpenAI คลิก Create new กรอก API key ของ OpenAI ซึ่งหาได้จากบทเรียน Get API key from OpenAI ทำตามบทเรียนสั้น ๆ นี้แล้ววาง API key ตรงนี้ ผมทำไว้แล้วกับบัญชี OpenAI หมายเลขเจ็ด เชื่อมต่อเรียบร้อย แล้วต้องเลือกบัญชี OpenAI ที่เพิ่งเชื่อมต่อ เรามีโมเดล OpenAI ทั้งหมดสี่โมเดล ตรงนี้ก็มีอีกอันหนึ่งที่โมเดล AI เห็นไหม OpenAI หมายเลข 7 ดี

เหลืออีกสองอย่าง คือการตั้งค่า product info sheet ซึ่งเป็นฐานข้อมูล Google ของเรา คลิกตรงนี้ แล้วคลิก Make a copy ดับเบิลคลิกมัน ก่อนอื่นตั้งชื่อก่อน ผมมักตั้งเป็น setup demo example

Google Sheet นี้มีสองแท็บ อันแรกคือ products ที่ใส่ข้อมูลสินค้า: ชื่อสินค้า หัวข้อสินค้า และอื่น ๆ ถ้าไม่อยากกรอกด้วยมือ ใช้ WhatsApp agent ตัวนี้ (ตัวขาย) ได้ เพราะมันฝึกให้กรอกข้อมูลให้ได้ แค่ส่งลิงก์สินค้าเข้าผ่าน WhatsApp แล้วมันจะกรอกข้อมูลให้เอง โดยไม่ต้องพิมพ์เอง ผมทำไว้แล้วตรงนี้ ข้อมูลตัวอย่างอยู่ในนั้นแล้ว

อีกแท็บคือ customer issues ซึ่งเป็นอีกอย่างที่เราจะตั้งค่า โดยพื้นฐานคือบันทึกปัญหาของลูกค้า: เช่น ปัญหา การตอบสนองของเรา และหมวดหมู่ของการสนับสนุนแบบนี้ เราจะใช้ตัวอย่างตรงนี้ วางลงไป ดี

กลับไปที่เวิร์กโฟลว์ ตอนนี้เรามี Google Sheet นี้ เริ่มจากอันแรก ถ้ายังไม่ได้เชื่อมต่อ คลิก Create new แล้วคลิก Sign in with Google จากนั้นระบบจะให้เลือกบัญชี Google สำคัญมากว่าถ้ามีหลายบัญชี ต้องล็อกอินด้วยบัญชีเดียวกับที่ถือ Google Sheet นี้อยู่ เอาเคอร์เซอร์ไปที่ไอคอนมุมขวาบนใต้โปรไฟล์ แล้วมันจะแสดงว่าสเปรดชีตนี้เชื่อมกับบัญชี Google อะไร แล้วลงชื่อเข้าใช้ด้วยบัญชีเดียวกัน ผมทำไว้แล้ว ใกล้เสร็จแล้ว

พอคลิกตรงนี้ จะเห็นว่ามันโหลดสเปรดชีต setup demo ซึ่งก็คืออันนี้ เพราะเป็นบัญชี Google เดียวกัน จากนั้นเลือก products ตรงนี้ต้องเลือก data location: on sheet และเลือก first empty row จากนั้นไปที่ support แล้วทำเหมือนกัน เลือก setup demo แต่ตรงนี้ต้องเลือกแท็บอื่น: customer โดยใช้ data location เดียวกันคือ on sheet และ first empty row เพื่อให้ AI agent หยุดเมื่อเจอแถวว่างแรก และไม่ทำงานต่อไปเรื่อย ๆ เท่านี้ก็จบสองสเปรดชีตนี้

อีกอย่างที่ต้องมีคือฐานข้อมูลหน่วยความจำระยะยาว (long-term memory database) ที่เก็บการโต้ตอบทั้งหมดกับ AI agent ของเรา ไม่ว่าลูกค้าหรือใครก็ตามที่ใช้ จะถูกบันทึกและเก็บไว้ เพื่อให้ agent เรียนรู้เกี่ยวกับลูกค้าแต่ละคน และใช้สิ่งที่เรียนรู้เขียนคำตอบถัดไป มันจึงรู้ทุกอย่างเกี่ยวกับการโต้ตอบที่เคยเกิดขึ้น จดจำแบบระยะยาวและเข้าถึงได้ เราสามารถ monitor ได้ และ agent ก็พัฒนาตัวเองได้

เราใช้เครื่องมือฐานข้อมูลชื่อ Supabase การตั้งค่า Supabase ผมมีบทเรียนอยู่แล้ว หัวข้อ Get API credential from Supabase เพราะนั่นคือสิ่งที่ต้องใช้ คลิก Create new credential แล้วสมัครบัญชีฟรี พอเสร็จแล้วขอ credential ตามที่สอนในบทเรียน ตรงนี้อันนี้ จากนั้นไปที่ organization แล้วคลิกที่ all ไปที่ Table editor แล้วคลิก Create new table ตั้งชื่อมัน ในกรณีของผมคือ WhatsApp Voice and Vision Demo

ตารางนี้จะเก็บอะไร? เราอยากเก็บ memory ซึ่งเป็นที่เก็บการเรียนรู้และข้อมูลเชิงลึกทั้งหมดจากการโต้ตอบ และ session ID ซึ่งเก็บรหัสของ WhatsApp ของเราเพื่อติดตาม และแค่นี้ก็พอ กลับไป คลิก Save แล้วตารางนี้จะถูกสร้าง เมื่อเชื่อมต่อ Supabase แล้ว ไปที่ Supabase ของผมจะเห็นตารางนี้ปรากฏ นี่คือสิ่งเดียวที่ต้องทำ

ข้อมูลนี้ถูกกรอกไว้แล้ว agent จะเขียนและเก็บทุกข้อความที่ส่ง พร้อมข้อมูลเชิงลึกที่กำหนดในช่อง system instructions และตรงนี้เก็บ session ID เราทำแบบเดียวกันสำหรับ get memory ซึ่งเป็นจุดดึงความจำกลับมา ไปที่บัญชี Supabase เลือกบัญชีที่ถูกต้อง แล้วไม่ต้องทำอะไรตรงนี้ คลิก Save

เท่าที่ดูเราตั้งค่าทุกอย่างแล้ว มันน่าจะทำงานได้ ลองทดสอบดู ในการทดสอบต้องไปที่ Telegram ของผม และเลือกเบอร์โทรศัพท์ของผมตรงนี้ คลิก แล้วมันจะแสดงเบอร์โทรศัพท์ของคุณ ผมจะไม่ทำตรงนี้เพราะไม่อยากโชว์เบอร์โทรศัพท์ แล้วคลิก Send message ก่อนอื่นเลือกเบอร์โทรศัพท์ แล้วปุ่มจะเปลี่ยนเป็นสีน้ำเงิน คลิก Send message แล้วคุณจะได้รับข้อความ WhatsApp

เปิด WhatsApp บนคอมพิวเตอร์ได้ ถ้ายังไม่ได้ดาวน์โหลด WhatsApp สร้างบัญชี คลิกที่ลิงก์ด้านล่างวิดีโอนี้เพื่อดาวน์โหลด WhatsApp บนคอมพิวเตอร์ แล้วใช้ทดสอบ AI agent ได้ ผมจะทำแบบนี้ แล้วกลับมาวิดีโอต่อเมื่อได้รับข้อความ WhatsApp หลังคลิก Send

พอเข้าไปดู จะเห็นว่าได้รับข้อความแล้ว นี่คือสัญญาณว่า AI agent ทำงาน จากนั้นสลับเป็น Live เพื่อเริ่ม แล้วคลิก Test เพื่อทดสอบฟีเจอร์ทั้งหมด

ฟีเจอร์แรก: ส่งข้อความและถามเกี่ยวกับสินค้า ผมจะถามว่า "What products do you have?" แล้วดูว่ามันรันผ่านโดยไม่มี error หรือไม่ ตรงนี้เห็น error: "incorrect API provided" ต้องเลือกบัญชีที่ถูกต้อง ทดสอบอีกครั้ง เลือกข้อความเดิม ตอนนี้น่าจะทำงานได้ มันรันผ่าน สืบค้นสินค้า เก็บความจำ ไปที่ Supabase จะเห็นว่ามันจดจำบทสนทนาแล้ว: "user inquiring about products available" มันเรียนรู้ว่าลูกค้าหรือผู้เยี่ยมชมที่ใช้ WhatsApp ของเราสนใจอะไร แล้วได้รับคำตอบ เห็นไหม มันตอบกลับด้วยสินค้าทั้งหมดที่มี ใช้งานได้

ต่อไปทดสอบเสียงว่ามันตอบกลับเป็นเสียงหรือไม่: "Hello? Can you tell me when I want to automate social media, which product would you recommend?" ผมน่าจะสร้าง test workflow ไว้ก่อน ลองอีกครั้ง: "What products do you recommend when I want to automate social media?" ตอนนี้มันควรจะรันไปที่ด้านบน ตรงนี้ต้องเลือกบัญชี OpenAI อันแรกทำตรงนี้ได้เลยเพราะเชื่อมต่ออยู่แล้ว นี่คือเหตุผลที่ต้องทดสอบสิ่งต่าง ๆ คิดว่าน่าจะทำงานได้ "What product do you recommend when I want to automate posting to Instagram?" ดูกัน ตอนนี้มันจะถอดเสียง ส่งไปยัง AI อ่านข้อมูลสินค้าที่เก็บในหน่วยความจำ แล้วสร้างคำตอบเสียงและส่งกลับมาให้เรา เห็นว่าเพิ่มอีกหนึ่งรายการ: "User interested in automating posts to Instagram" และมันรันผ่าน ดูผลลัพธ์: AI automation engagement templates ถ้าได้ยินเสียงตอบกลับ แสดงว่าเสียงทำงาน

สุดท้ายที่อยากทดสอบคือรูปภาพ อัปโหลดรูปภาพ ผมมีอยู่แล้วหนึ่งรูป อัปโหลดอันนี้ แล้วถามว่า "Can I use your AI agent workflow with this AI model?" ดูกัน ตอนนี้มันควรจะประมวลผลที่ด้านล่าง วิเคราะห์รูปภาพ แล้วส่งคำตอบกลับมา มันเข้าถึง support แล้วส่งคำตอบกลับมา: "I found information regarding the use of DeepSig and AI agent. It seems that while DeepSig may be useful for analysis text, it's not considered reliable for an AI agent module." และนั่นคือสิ่งที่อยู่ในหัวข้อ custom issues ของเรา

ตอนนี้ AI agent ของเราผ่านการทดสอบแล้ว เราสามารถสลับเป็น Live ได้ เพราะตอนนี้ยังอยู่ในโหมดทดสอบ ยังใช้เบอร์โทรศัพท์ทดสอบอยู่ การจะนำไปใช้งานจริงกับบัญชีของคุณ หรือมีบอทบนเว็บไซต์ ให้ลูกค้าโต้ตอบได้ ต้องทำตามขั้นตอนเหล่านี้: เพิ่มเบอร์โทรศัพท์จริง เพิ่มการชำระเงิน ทำการยืนยัน Facebook business ซึ่งมีคู่มือให้ตรงนี้ พอทำเสร็จ ถ้ามีโทรศัพท์บริษัท ก็ใส่เบอร์โทรศัพท์บริษัทลงไป แล้ว AI agent นี้จะทำงานบนโทรศัพท์ของคุณ คือคุณจะได้รับข้อความบนโทรศัพท์เมื่อมีคนโต้ตอบ และ monitor ได้จากโทรศัพท์

ถ้าต้องการระบบที่ขยายได้มากกว่านี้ ต้องดูบริการอย่าง Twilio ที่ให้จัดการข้อความ WhatsApp ในระดับใหญ่ ล็อกอินบัญชี Twilio แล้วเห็นการโต้ตอบกับลูกค้าทั้งหมดและจัดการจากตรงนั้น ผมจะไม่ลงรายละเอียดวิธีตั้งค่า บางทีอาจทำวิดีโอแยก แต่สำหรับคุณ แค่คลิก Start แล้วจะได้เบอร์โทรศัพท์เสมือน แล้วทำตามขั้นตอนสองสามขั้นตอนเพื่อเชื่อมต่อ ผมรู้ว่ามี Twilio node ที่เชื่อมต่อกับ credentials ของคุณได้โดยตรง และเลือก custom call หรืออะไรก็ตามที่ต้องการ ผมไม่แน่ใจว่านี่คือสิ่งที่ต้องตั้งค่าสำหรับ WhatsApp หรือไม่ แนะนำให้ทำตามเอกสารของพวกเขา ถ้าต้องการ deploy ด้วยโซลูชันที่ขยายได้เช่น Twilio หรือบริการ WhatsApp API อื่น ๆ

นั่นคือขั้นตอนเพิ่มเติมเพื่อให้ AI agent นี้ทำงานได้อย่างมีประสิทธิภาพจริง ๆ ในฐานะ agent ที่ใครก็ตามโต้ตอบด้วย ไม่ว่าลูกค้า บนเว็บไซต์ หรือใครก็ตามที่ agent ของคุณช่วยตัดสินใจซื้อหรือตอบคำถามได้
