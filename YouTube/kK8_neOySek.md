## ประเด็นหลัก
- Hermes Agent คือ AI agent แบบโอเพนซอร์สจาก Nous Research ไม่ใช่แชตบอท เพราะมันลงมือทำจริง อ่าน/เขียนไฟล์ รันคำสั่ง ค้นหาเว็บ และจำสิ่งที่เรียนรู้ได้
- อัปเดตเดสก์ท็อปครั้งใหญ่ (เวอร์ชัน 0.20 ชื่อรหัส Herald release ออก 3 ส.ค.) เพิ่มแถบแสดงตัวอย่างด้านขวา ให้เอเจนต์เปิดหน้าเว็บจริง ควบคุมภายในหน้า และแสดงผลข้างช่องแชตได้ ไม่ต้องคัดลอกวางลิงก์อีกต่อไป
- ตัวเลขการพัฒนาในรอบเดียว: ~3,650 commits, ~1,400 pull requests, ~1,200 issues ปิด, ผู้ร่วมพัฒนา 650+ คน
- ฟีเจอร์ใหม่อื่น ๆ: เสียงสนทนาที่พูดพร้อมคิดและขัดจังหวะได้, คำปลุกแบบกำหนดเองที่ประมวลผลบนเครื่อง, grounded citations พร้อมโหมดตรวจสอบข้อเท็จจริง, แพลตฟอร์มปลั๊กอินกับ sandboxed live preview, รองรับ A2A protocol (agent-to-agent), และคำสั่งทรงพลังใหม่ใน command line
- การติดตั้ง: ดาวน์โหลดที่ hermes-agent.newsresearch.com หรือรัน `hermes desktop` ต่อจาก config เดิม; ตัวติดตั้ง Windows ไม่ได้เซ็นโค้ด จึงต้องกด More info → Run anyway ที่ SmartScreen
- ทิป 3 ข้อ: (1) ใช้แถบแสดงตัวอย่างอย่างตั้งใจ อย่าให้เอเจนต์แค่อธิบาย (2) สังเกต context meter เมื่อใกล้เต็มให้เริ่มแชตใหม่ (3) อย่าปิด approvals ระหว่างที่ยังเรียนอยู่
- ทิปโบนัส: พิมพ์ /journey เพื่อดูแผนที่สกิลและความทรงจำทั้งหมดของ Hermes บนไทม์ไลน์ ตรวจทุกสัปดาห์

## ความเห็นสรุป
วิดีโอนี้เหมาะกับคนที่เพิ่งเริ่มใช้ AI agents เพราะอธิบายตั้งแต่พื้นฐานว่าเอเจนต์ต่างจากแชตบอทอย่างไร ไปจนถึงฟีเจอร์ใหม่ที่ทำให้เอเจนต์ "เปิดเว็บเองได้" จริง ๆ เนื้อหาชัดเจน เน้นการใช้งานจริงพร้อมทิปที่ป้องกันความผิดพลาดของมือใหม่ได้ดี โดยเฉพาะคำเตือนเรื่อง approvals ที่หลายคนมองข้าม
