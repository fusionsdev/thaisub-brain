# Skills MCP Library 3 — Installation Guide (Claude Desktop)

> **ที่มา:** บทเรียนจากคอร์ส NoeAI Automator  
> **ภาษา:** คำแปลภาษาไทยจากต้นฉบับภาษาอังกฤษ (STT via faster-whisper)

## บทนำ

คู่มือการติดตั้ง Skills และ MCP จาก Skills MCP Library ลงบน Claude Desktop เริ่มตั้งแต่การดาวน์โหลดไฟล์ zip การอัปโหลดสกิลผ่านเมนู Customize จนถึงการทดสอบการทำงานของสกิล รวมถึงอธิบายความแตกต่างของโครงสร้างสกิลแบบมีโฟลเดอร์ย่อยกับแบบไฟล์เดียว

## คำแปลเต็ม

ยินดีต้อนรับสู่คู่มือการติดตั้ง Claude skills และ MCP สำหรับ Claude Desktop ครับ ถ้าคุณใช้ Claude Desktop ผมจะโชว์วิธีติดตั้งสกิลที่เราให้ไว้ ลงบนคอมพิวเตอร์ของคุณ มันง่ายมากเลย คุณจะได้เข้าถึง Skills และ MCP Library ทุกอย่างอยู่ในไฟล์ zip มันง่ายมาก คุณแค่เข้ามา แล้วหาสกิลเฉพาะที่อยากดาวน์โหลด สมมติว่าผมอยากได้สกิล content analysis ผมก็แค่คลิกเข้ามา แล้วเปิดสกิลตรงนี้ มันเป็นไฟล์ zip สิ่งที่เราจะทำก็คือ คลิกดาวน์โหลด ง่ายมาก แล้วเราก็จะได้มันลงบนเครื่องของเรา พอได้แล้ว เราก็จะเห็นมันในระบบไฟล์ของเรา

จากนั้นเราก็ไปที่ Claude ครับ ไปที่มุมซ้ายบนตรงนี้ คลิก customize แล้วคลิก create new skills แล้วคุณจะเห็นรายการสกิลที่คุณมี ถ้าคุณยังไม่มีก็ไม่เป็นไร ถ้าคุณยังไม่ได้เรียนบทเรียน skills ในคอร์ส Claude Mastery ขอให้ไปดูบทนั้นก่อน เพื่อให้เข้าใจบทนี้มากขึ้น แต่จากนั้นคุณก็แค่ไปที่เครื่องหมายบวก แล้วเลือก create skill แล้วคลิก upload skill โอเค จากนั้นเราก็เปิดไฟล์ของเราตรงนี้ สิ่งที่เราจะทำคือ ลากแล้ววาง แล้วปัง! เห็นไหมครับ เราได้ไฟล์ zip ของเราแล้ว แล้วแปะ! สกิลก็ใช้งานได้แล้ว นั่นคือทั้งหมดที่อยู่ในนั้น

คุณจะเห็นว่าบางสกิลมีโฟลเดอร์อยู่ข้างใต้ อย่างสกิล skill creator อันนี้มีไฟล์ SKILL.md และมีหลายโฟลเดอร์อยู่ข้างใต้ ในขณะที่อันนี้เป็นแค่ไฟล์ SKILL.md ไฟล์เดียว ถ้าคุณไม่รู้ว่าผมพูดถึงอะไร ขอให้ไปดูบทนั้นก่อน มันสำคัญมาก แต่วิธีนี้ใช้ได้กับทุกอย่าง แค่ลากวางลงไป แล้วถ้าคุณอยากทดสอบ เราจะทดสอบ content analysis ดูว่ามันทำงานไหม เราก็แค่เรียกใช้ content analysis แล้วปัง! สกิลก็ทำงานแล้ว คุณพร้อมใช้งานแล้ว มันเป็นวิธีง่าย ๆ แบบนี้ ถ้ามีคำถามอะไรก็บอกผมได้ แล้วเจอกันบทเรียนหน้านะครับ
