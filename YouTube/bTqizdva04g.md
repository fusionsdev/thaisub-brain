# สรุปภาษาไทย — 9 Insane Claude Mods I Already Can't live Without

> ช่อง: Ben AI · เผยแพร่: 2026-10-21 · ระยะเวลา: 848 วินาที
> URL: https://www.youtube.com/watch?v=bTqizdva04g

Anthropic เปิดตัว **mods** สำหรับ Claude Code — plugin ที่ทำให้ Claude สร้างฟีเจอร์ให้ตัวเองได้
แค่บรรยายสิ่งที่ต้องการ Claude ก็สร้างให้ผ่าน skill ชื่อ plugin authoring
Ben คัดมาแล้ว 9 ตัวที่ดีที่สุดจากกว่า 100 ตัวที่ทดลองใช้ พร้อมแจกฟรี

## 9 Mods ที่แนะนำ

1. **Brain Dump** — ดักจับข้อความระบายความคิดยาว ๆ เละ ๆ ถามคำถามเพิ่มเติม
   แล้วเขียนใหม่เป็น prompt ชัดเจนตาม framework ของ Anthropic (task / why / guardrails / done)
2. **Helper Desk** — แสดงสิ่งที่ sub-agent ทำอยู่แบบเรียลไทม์ ทั้ง taskbar สีม่วงบอกความคืบหน้า
   และ side panel ที่แต่ละตัวมีปู Claude crab สีของตัวเอง progress bar และต้นทุน (ไม่เสียค่าใช้จ่าย)
3. **Cash Clock** — นับถอยหลังก่อน cache กลายเป็น cold พร้อมคำสั่ง /keep warm
   ที่ส่งข้อความซ่อนเพื่อยืดอายุ cache ประหยัดค่าใช้จ่ายได้สูงสุด 40 เท่า
4. **Handoff** — ย้ายงานไปแชตใหม่ในจังหวะเหมาะ (แตะ 250,000 tokens / cache cold / พิมพ์ /handoff)
   โดยเขียน handoff prompt ละเอียดพร้อมปุ่มเปิดแชตใหม่ ไม่เสีย context
5. **Reflect** — จับได้เมื่อคุณให้กฎเหล็กกับ Claude แล้วเด้ง pop-up ถามว่าจะเซฟลง memory,
   Claude.md หรือ second brain
6. **Chat Inventory** — side panel แบบ co-work ชื่อ in this chat รวม to-do, connector พร้อมโลโก้,
   skills และไฟล์ที่อ่านหรือสร้าง (ไม่เสียค่าใช้จ่าย)
7. **Screen Share Mode** — เปิดด้วย /screen share ซ่อนชื่อ อีเมล เบอร์โทร และยอดเงินเป็นแถบสีเทา
   เวลาแชร์จอหรืออัดวิดีโอ
8. **Replay Theater** (ของ Anthropic โดยตรง) — พิมพ์ /replay เพื่อเล่นซ้ำทุก edit ที่ Claude แก้ในไฟล์
   ทีละขั้น ย้อนกลับไปเวอร์ชันที่ชอบได้
9. **Switchboard** — พิมพ์ /mods เปิดแผงรวมทุก mod ที่รันอยู่ เปิดปิดหรือซ่อน panel ได้ในที่เดียว

mods มี 2 แบบ คือแบบที่ใช้ AI (กิน usage ตามแพ็กเกจ) กับแบบที่แค่แสดงผลบนจอ (ฟรี)
โหลดทั้งหมดได้ฟรีที่ลิงก์แรกใต้คลิป แล้วโยนเข้าแชต Claude สั่งว่าให้ติดตั้งให้ได้เลย
