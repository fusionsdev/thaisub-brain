## บทนำ
วิดีโอนี้ทดสอบกระบวนการคัดกรองลูกค้าและการจองนัดหมายของระบบ AI agent ตั้งแต่ผู้ใช้ส่งข้อความทักทาย ระบบถามคำถามคัดกรอง แนะนำเวลาว่าง จองนัดหมายผ่าน cal.com และบันทึกลง Google Sheet พร้อมระบบแจ้งเตือนทางอีเมลอัตโนมัติ

## คำแปลเต็ม
ตอนนี้เราจะทดสอบกระบวนการคัดกรองและการจองของเรา โดยเริ่มจากวิธีที่ผู้ใช้ของเราจะเริ่มใช้งาน คุณสามารถคลิกที่ลิงก์ หรือจะส่งข้อความอะไรก็ได้ไปที่ AI ตัวนี้ที่เปิดไว้ให้เราแล้ว ข้อความใดก็ตามที่มีคำสำคัญที่เราตั้งไว้ใน trigger นี้ เช่น hello ถ้าผมพิมพ์คำนั้น มันควรจะเริ่มทำงาน แต่ก่อนอื่นเราต้องสลับไปที่ active ก่อน จากนั้นสลับไปที่ executions ตรงนั้นเราจะดูได้ว่า process ไหนถูกดำเนินการ และมี error ไหนเกิดขึ้นบ้าง

ลองพิมพ์ hello ดู มันรันอยู่แล้วตรงนี้ โอเค ตอนนี้มันเริ่มกระบวนการที่กำหนดไว้ใน agent แล้ว "ขอถามคำถามสองสามข้อได้ไหม?" "คุณต้องการบริการไหน?" ผมต้องการอันนี้ นวดคลายความเครียด (press relief massage) "มีนักนวดบำบัดที่ต้องการเป็นพิเศษไหม?" ไม่เป็นไรในกรณีนี้ มันเป็นแค่ตัวอย่างสิ่งที่คุณทำได้กับระบบนี้ "เป็นการมาเยี่ยมครั้งแรกไหม?" คำถามทั้งหมดนี้ถูกกำหนดไว้ในกระบวนการของ AI agent ถ้าต้องการคำถามอื่น คุณไปที่ system instructions ของ agent ไปที่ system แล้วแก้ไขได้

แต่ผมต้องการทำกระบวนการให้เสร็จ อันนี้ก็ถูกกำหนดไว้เช่นกัน: ลูกค้าครั้งแรกได้ส่วนลด 50% กรุณามาถึงก่อนเวลานัด 50 นาที "กรุณาให้ชื่อและอีเมลของคุณ" ดูสิ่งที่เกิดขึ้นใน workflow ของผมสิ "คุณต้องการจองตอนนี้ไหม?" ใช่ และผมจะตรวจสอบด้วย ดูที่เครื่องมือจับข้อมูล (data capture tool) คุณเปิดดูได้ ผมมีมันอยู่แล้ว แต่ดูนี่สิ คุณเห็นว่ามันบันทึกไว้แล้ว มันบันทึกหมายเลขโทรศัพท์และ contact ID แล้ว

กลับมาตรงนี้ มันเสนอเวลามาให้ผม นี่คือเวลาที่ว่าง และตอนนี้เราจะตรวจสอบว่าเวลาพวกนี้แม่นยำไหม ผมต้องไปที่ปฏิทินของผม ไปที่ event types แล้วตรวจสอบ ผมมีข้อเสนอนี้ที่ต้องการ คลิกเข้าไป แล้วต้องตรวจสอบว่าเมื่อกี้มันบอกเวลาไหนไว้ วันนี้ 18:30 แล้ววันที่ 9 มิถุนายน คุณเห็นว่าเวลาถูกต้อง โซนเวลาตรงกัน ดังนั้นต้องแน่ใจว่าคุณสลับไปใช้โซนเวลาที่ถูกต้อง ซึ่งคุณกำหนดไว้สำหรับ agent ของคุณด้วย ระบบนี้ถึงจะทำงานได้

ตอนนี้ก็แค่ให้ผมเลือกเวลา ผมเลือกวันที่ 9 มิถุนายน เวลา 9 โมงเช้า แล้วสลับกลับมาตรงนี้ที่ executions ตอนนี้มันให้ผมพิมพ์ yes เมื่อผมพิมพ์ มันจะบันทึกเวลาลงใน Google Sheet เราควรเห็นตรงนี้ คุณเห็นว่า update sheets ถูกใช้ ตอนนี้ผมเข้าไปดู มันมีชื่อ event เวลา ซึ่งเป็นโซนเวลาของผม วันที่ 9 มิถุนายน เวลา 9 โมงเช้าตามเวลาของผม

กลับไป เพราะตอนนี้มาถึงส่วนที่มันเปิดใช้งาน workflow หลัก เพราะมันให้ผมพิมพ์คำว่า confirm จากนั้นมันจะรัน workflow หลักและสร้างการจอง และมันดูดีมาก Succeeded และมันยังส่งข้อความว่า "การจองของคุณได้รับแล้ว จะมีการยืนยันทางอีเมลในเร็วๆ นี้" และมันตรวจสอบด้วยว่าถ้ามีปัญหา มันจะเรียกใช้ workflow นี้ ผู้ตอบกลับ (responder) นี้จะบอกว่า "ดูเหมือนเวลาที่คุณเลือกไม่ว่างแล้ว กรุณาเลือกเวลาอื่น" แล้วมันก็หาช่วงเวลาที่ใช้ได้

และการจองถูกตั้งเป็น yes ตรงนี้เราเห็น booked จริงๆ แล้วมันไม่ได้ตั้งเป็น yes เพราะเราลืมบางอย่าง ผมยังไม่ได้เลือกอันที่ถูกต้อง นี่คืออันเก่า อันนี้คืออันที่ถูกต้อง แต่มันเป็นการปรับเล็กน้อย ตอนนี้ผมตรวจสอบแล้ว ตรงนี้ถูกต้องในชีต จากนั้นมันจะเขียน yes และการนัดหมายก็ถูกจอง ตอนนี้ผมไปที่ bookings แล้วการจองแสดงขึ้นมาไหม? แสดง มันแสดง express relief massage

และผมยังไปที่อีเมลของผมเพื่อดูว่าได้รับการยืนยันหรือไม่ คุณเห็นว่า cal.com ยังส่งอีเมลแจ้งเตือนด้วย คุณสามารถตั้งการแจ้งเตือนทางอีเมลทั่วไปได้ตรงนี้ภายใต้หัวข้อนี้ แล้วตั้ง trigger ก่อน event เช่น 24 ชั่วโมงหรือตามที่คุณต้องการ ส่งอีเมลนี้ อันนี้ถูกโหลดไว้แล้ว คลิกแล้วมันจะส่งการแจ้งเตือนนี้ให้กับการจองทั้งหมดโดยอัตโนมัติ คุณ甚至可以เลือกเวอร์ชันที่จะใช้กับทั้งหมด แล้วคลิก save

เอาล่ะ การทดสอบของเราเสร็จสิ้น และตอนนี้เราจะตั้งค่าขั้นตอนถัดไป ซึ่งก็คือการแจ้งเตือนทาง SMS
