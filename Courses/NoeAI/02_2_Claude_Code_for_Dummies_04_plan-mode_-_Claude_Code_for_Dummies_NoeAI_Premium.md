## บทนำ

วิดีโอนี้สอนวิธีใช้ Plan Mode ใน Claude Code ซึ่งผู้สอนถือว่าเป็นฟีเจอร์ที่สำคัญที่สุด ใช้สำหรับวางแผนโปรเจกต์อย่างละเอียดก่อนลงมือสร้าง — โหมดนี้จะถามคำถามเพื่อทำความเข้าใจความต้องการ เขียนแผนทีละขั้น แล้วค่อยลงมือ build ผู้สอนแนะนำให้ใช้เวลาวางแผนถึง 90% ของเวลา เพราะจะช่วยให้ Claude Code ทำสำเร็จในรอบเดียว แทนที่จะต้องแก้กันหลายรอบ

## คำแปลเต็ม

ว่าไงครับทุกคน? ในวิดีโอนี้ ผมจะพูดถึง Plan Mode ครับ ถ้าคุณไม่รู้ว่า Plan Mode คืออะไร — Plan Mode ก็คือ... มันคือฟีเจอร์ที่ผมคิดว่าสำคัญที่สุดที่ Claude ให้คุณมา มันช่วยให้คุณวางแผนโปรเจกต์ของคุณอย่างละเอียดลึกซึ้ง

เวลาที่คุณจะวางแผนโปรเจกต์ และวางแผนการสร้าง โดยเฉพาะงานที่ซับซ้อน มีหลายขั้นตอน คุณควรใช้ Plan Mode เพราะสิ่งที่ Plan Mode จะทำคือ มันจะถามคำถามคุณเป็นชุดๆ อย่างเช่น ถ้าผมกด Plan แล้วมันก็จะขึ้นว่า "Enable a plan or view a current session plan" ประมาณนั้น ถ้าผมคลิกเข้าไป มันก็จะเปิดโหมด Plan Mode แล้วมันจะสร้างพื้นที่วางแผนขึ้นมา เห็นไหมว่าตรงนี้ขึ้นว่า "Plan" แล้วคุณกด Shift+Tab เพื่อสลับปิดได้

ที่เจ๋งคือคุณเรียกใช้จากที่อื่นได้ด้วย คุณเรียกใช้ด้วยการกด Shift+Tab เหมือนกัน เจ๋งไหมล่ะ?

ให้ผมโชว์ให้ดูว่าใน Plan Mode หน้าตาเป็นยังไง ทุกครั้งที่ผมจะวางแผนสร้างอะไร ผมก็จะกด Plan แล้วก็เทสติงรายละเอียดทุกอย่างที่ผมต้องการลงไป ผม brain dump ทุกอย่างลงใน Plan ครับ อะไรก็ตามที่ผมนึกออกว่าอยากให้มีในโปรเจกต์นั้น ผมใส่ทุกอย่างลงไปให้หมด และตอนท้ายของแต่ละครั้ง ผมยังจะถามมันด้วยว่า "Can you ask me any questions?" ขอคำถามเพื่อทำความกระจ่างว่าผมต้องการอะไรจริงๆ

แล้วมันจะสร้างแผนทั้งหมดออกมาทีละขั้นตอน มันเยอะมาก แล้วพอคุณเห็นว่า "อันนี้แหละ ดูดี ใช้แผนนี้" คุณก็กด execute แล้วมันก็จะไปสร้างให้คุณทั้งหมด ซึ่งเจ๋งมาก ผมแนะนำให้ลองใช้ดูกับงาน build ครั้งหน้าของคุณ

การวางแผนสำหรับงาน build ใดๆ ใน Claude ควรใช้เวลาถึง 90 เปอร์เซ็นต์ของเวลาทั้งหมด เพราะถ้าคุณใช้เวลากับ Plan มากขึ้น ค่อยๆ วางแผนอย่างละเอียดว่าคุณต้องการอะไรจริงๆ โอกาสที่ Claude Code จะทำสำเร็จในรอบเดียว (one-shot) หรือสองสามรอบ (three-shot) ก็จะสูงขึ้นมาก ในทางกลับกัน ถ้าคุณไม่เข้า Plan ไม่ได้ให้ข้อมูลเยอะ ไม่ได้แน่ใจว่ามันตั้งค่าถูกต้อง มันก็จะต้องใช้พรอมพ์ถึง 18 รอบ วิ่งไปวิ่งมาระหว่างเราสองคนเพื่อหาคำตอบให้ได้

นี่คือเหตุผลที่ Plan Mode สำคัญขนาดนั้น มันจะอ่านและสำรวจโค้ดของคุณ มันจะเขียนไฟล์แผนพิเศษให้คุณ และถามคำถามเพื่อทำความเข้าใจว่าคุณต้องการอะไร มันจะทำงานเป็น 5 เฟส คือ ทำความเข้าใจสิ่งที่คุณต้องการ ออกแบบ คุณ review มันจะเขียนแผนทั้งหมด แล้วก็ออกจาก Plan Mode แล้วไปลงมือทำตามแผนและสร้างทั้งหมดให้คุณ

แต่ผมแนะนำให้คุณลองไปใช้ดูนะครับ ตอนนี้ผมไม่ได้กำลัง build อะไร ก็เลยไม่มีตัวอย่างจริงให้ดู ตอนนี้ แต่ลองไปใช้กับงาน build ครั้งหน้าของคุณ แล้วเริ่มวางแผนสิ่งต่างๆ ดูสิ มันคือฟีเจอร์ที่ผมใช้บ่อยที่สุดที่ Claude Code ให้เราจริงๆ ไปลองดูได้เลยครับ
