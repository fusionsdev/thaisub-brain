## บทนำ
วิดีโอนี้เป็นขั้นตอนที่ 1 ของการตั้งค่าระบบ AI agent สำหรับการจองนัดหมายผ่าน WhatsApp โดยเริ่มจากตั้งค่าแพลตฟอร์ม n8n นำเข้าเทมเพลตเวิร์กโฟลว์ AI Agent จากนั้นปรับแต่ง system message ให้เข้ากับธุรกิจของคุณ เชื่อมต่อ OpenAI chatbot, หน่วยความจำ, ฐานข้อมูล Google Sheet, และบริการจัดการนัดหมาย Cal.com พร้อมทั้งกำหนด event IDs สำหรับบริการแต่ละอย่าง

## คำแปลเต็ม

ขั้นตอนแรกของเราคือการตั้งค่าแพลตฟอร์ม n8n ไปที่ n8n ถ้าคุณยังไม่มีบัญชี คุณสามารถตั้งค่าได้ฟรี คุณได้รับทดลองใช้ฟรี 14 วัน และเมื่อคุณทำเสร็จและเข้าสู่ระบบแล้ว คุณจะเห็นเวิร์กโฟลว์นี้ และตรงนี้คุณคลิกที่ create a workflow จากนั้นด้านล่างนี้คุณคลิกที่ Download AI Agent Workflow แล้วตรงนี้คุณคลิกที่ Import from แล้วเราก็จะนำเข้าไฟล์ที่เราเพิ่งดาวน์โหลด ตอนนี้ก็แค่การเชื่อมต่อโมดูลต่าง ๆ เหล่านั้นกับ credentials ของคุณ

เราจะเริ่มด้วย AI agent สำหรับการเลือกการนัดหมาย (appointment selection) เพราะนี่คือสิ่งที่ขับเคลื่อนการสนทนาทาง WhatsApp ของเรา และตรงนี้คือ system message (ข้อความระบบ) ที่คุณต้องปรับแต่งให้เข้ากับกรณีธุรกิจเฉพาะของคุณ นี่คือตัวอย่างตรงนี้ เรามีร้านนวด คุณแค่ต้องเปลี่ยนชื่อธุรกิจ เวลาเปิด-ปิด หรืออะไรก็ตาม ทั้งหมดนี้ เราจะไปถึงตรงนั้นในขั้นตอนถัดไป ซึ่งเป็นส่วนถัดไปของการตั้งค่าตรงนี้อีกไม่กี่นาที คุณต้องมีรายการบริการที่คุณให้บริการซึ่งต้องจองล่วงหน้า และเราจะเปลี่ยน event IDs ในภายหลัง แต่ตอนนี้คุณมีอันนี้แล้ว ส่วนที่เหลือคงเดิมได้ น้องแผนกต้อนรับ (receptionist) จากนั้นก็มาถึง conversation flow (ขั้นตอนการสนทนา) ว่า AI agent ควรถามอะไรก่อน ควรผ่านกระบวนการแบบไหน? มันเริ่มด้วยการถามว่าคุณต้องการบริการไหน? จากนั้นมันให้รายการบริการ พวกเขาต้องการเจาะจงคนไหม? ถ้าผมมีหลายคนที่ให้บริการนี้ ผมสามารถใส่ลงไปได้

และสิ่งที่สำคัญตรงนี้: หลังจากที่คุณปรับแต่งสิ่งนี้ให้เข้ากับธุรกิจของคุณแล้ว คุณต้องปรับเขตเวลาของคุณด้วย และผมคิดว่ามีสองจุดตรงนี้ คุณต้องแปลงค่านั้น สองจุด และตรงนี้คุณต้องใส่ค่าชดเชยเวลา (time shift) ของคุณ และคุณจะพบสิ่งนี้เมื่อคุณเลื่อนลงมา มีป้ายสีเขียว และของผมเป็นบวก ใช่ไหม? นั่นคือเหตุผลที่ผมเขียนบวกสองไว้ตรงนี้ แล้วเรายังมีอะไรอีกไหมตรงนี้? เรามีเขตเวลา และนั่นคือทั้งหมด ตรงนี้ยังมีข้อมูลเพิ่มเติมอีกเล็กน้อย คุณต้องอ่านทุกย่อหน้าตรงนี้จริง ๆ และดูว่าคุณต้องปรับมันอย่างไรให้เข้ากับกรณีธุรกิจเฉพาะของคุณ และเมื่อคุณทำเสร็จแล้ว คุณก็ไปต่อได้ หรือคุณจะไปต่อกับการตั้งค่าและเปลี่ยนทีหลังเมื่อคุณเห็นโฟลว์และกระบวนการก็ได้

ตอนนี้เราจะเชื่อมต่อโมดูลต่าง ๆ ตรงนี้ ตรงนี้เรามี OpenAI chatbot นั่นคือสมองของโมดูล AI agent มันจัดการการสนทนาและงานทั้งหมดที่มันทำ ตรงนี้คุณแค่คลิก create new ใส่ OpenAI API ซึ่งคุณสามารถรับได้จากตรงนี้ และเมื่อคุณทำเสร็จแล้วคลิก save กลับไป ตรงนี้เรามีหน่วยความจำ (memory) นี่คือสิ่งที่ทำให้ AI agent จำการสนทนาได้ ผมตั้งไว้ที่ 50 โดยปกติผมรู้ว่าการจองนัดหมายให้ใครสักคนต้องใช้การโต้ตอบประมาณ 10 ถึง 20 ครั้ง ดังนั้น 50 จึงเกินพอสำหรับ agent ที่จะจำได้ว่าคนนั้นพูดอะไรมาบ้าง

แล้วเรามีฐานข้อมูล (database) นี่คือที่ที่ผมเก็บข้อมูลทั้งหมดของคอนแทกต์ สิ่งที่คุณต้องทำคือเชื่อมต่อบัญชี Google Sheet ของคุณ ก่อนที่เราจะทำ มาดูตรงนี้ก่อน เพราะตรงนี้เรามีฐานข้อมูล Google Sheet คลิกที่มัน นี่เป็นแค่ Google Sheet ที่ผมเตรียมไว้ให้คุณ คุณสามารถใช้มันเพื่อเก็บรายละเอียดลูกค้าทั้งหมดที่จำเป็นต่อการประมวลผล เช่น คอนแทกต์ อีเวนต์ที่พวกเขาจอง เวลาที่พวกเขามี ตรงนี้ผมจะเปลี่ยนชื่อเป็น demo ตามวันที่วันนี้ แล้วผมกลับมาตรงนี้ ตอนนี้ผมคลิก Create New แล้วเข้าสู่ระบบด้วยบัญชี Google เดียวกับที่ผมมี Google Sheet นี้อยู่ คลิกที่มัน เลือกบัญชี Google คลิก continue ดูดี ตอนนี้ผมสามารถไปต่อตรงนี้ได้ และตอนนี้ผมสามารถเลือกบัญชีนี้ได้ Leads ถูกเลือกไว้แล้ว ตรงนี้ถูกกำหนดไว้ล่วงหน้าแล้ว โดยพื้นฐานแล้วนี่คือสิ่งที่ n8n จะบันทึก: อีเมล ในบางจุดมันจะถามว่าอีเมลและชื่อคืออะไร แล้วมันจะเก็บข้อมูลนั้นลงใน Google Sheet พร้อมกับหมายเลขโทรศัพท์ ซึ่งมันสามารถรับโทรศัพท์ได้โดยตรงจาก WhatsApp เพราะ WhatsApp ส่งข้อมูลนี้ให้ ซึ่งเราจะเชื่อมต่อในวิดีโอถัดไป การตั้งค่าและบทสรุปของมัน และเรามี contact ID ซึ่งมีอยู่แล้ว

ตอนนี้เรายังต้องอัปเดต leads ด้วย นี่คือที่ที่มันเก็บข้อมูลเพิ่มเติมเกี่ยวกับการจอง ประเภทที่บุคคลนั้นต้องการจอง เช่น ตรงนี้เรามี event type ซึ่งเราจะพูดถึงในอีกไม่กี่นาที และวันที่นัดหมาย และนี่คือสิ่งที่ AI agent จะกรอกให้ และตอนนี้มาถึงโมดูลที่ตรวจสอบเวลาว่าง ในการทำสิ่งนี้เราใช้แพลตฟอร์มอื่นที่ชื่อว่า Cal.com นี่คือที่ที่ผมสามารถผสานรวมได้ง่ายและจัดการการจอง คุณสามารถใช้ได้ฟรี สมัครบัญชีฟรี แล้วผมคลิก Go App และสิ่งที่เราต้องการตรงนี้คือ อย่างแรก คุณมีเขตเวลาของคุณตรงนี้อีกครั้ง ตรงนี้คุณจะแทนที่ด้วยเขตเวลาของคุณและสถานที่ แล้วเรายังต้องมี API key ด้วย เราไปที่ settings แล้วตอนนี้เราจะไปที่ API คลิก add ตั้งชื่อให้มัน ชื่ออะไรก็ไม่สำคัญจริง ๆ แล้วคัดลอกแล้ววางลงตรงนี้ นั่นคือทั้งหมดที่เราต้องทำตรงนี้

และในขณะที่เราอยู่ตรงนี้ เราก็ไปที่อันนี้ด้วย เพราะผมได้บันทึก API ไว้แล้ว นั่นคือโมดูลสำหรับการจองนัดหมาย ก่อนที่ผมจะต้องทำอะไร ผมต้องตั้งค่าการนัดหมายจริง ๆ อย่างที่คุณเห็นตรงนี้ใน AI agent ของผม ผมมีสี่บริการ ดังนั้นสี่การนัดหมาย นั่นคือเหตุผลที่ผมต้องตั้งค่าสี่รายการ ซึ่งผมทำไว้แล้ว แต่ผมจะลบอันนี้เพื่อแสดงวิธีตั้งค่าใหม่ ตรงนี้ผมได้เพิ่มบริการนวดสามแบบไว้แล้ว บริการนวดถัดไปที่ผมต้องเพิ่มคือ quick massage ผมแค่คลิกที่ go to event types แล้วพิมพ์ชื่ออีเวนต์ นี่คือระยะเวลา และถ้าคุณเปลี่ยนระยะเวลาของอันนี้ คุณต้องเปลี่ยนระยะเวลาตรงนี้ด้วย เพื่อให้ AI agent รู้ชัดเจนว่าควรยาวแค่ไหน และนั่นคือทั้งหมดสำหรับอันนี้ จากนั้นคุณมี availability (ช่วงเวลาว่าง) นี่คือที่ที่คุณสามารถตั้งเวลาทำการของคุณ ที่ทำงานของคุณ คุณไปที่ availability และนี่คือที่ที่คุณสามารถเพิ่มตารางเวลาต่าง ๆ สำหรับตารางหนึ่ง ตารางสำหรับอีกอันหนึ่ง และอื่น ๆ จากนั้นคุณสามารถเลือกอันนี้ได้ ภายใต้ event types ตอนนี้ตรงนี้คุณสามารถเลือก availability และเลือกตารางเวลาได้

และตอนนี้เมื่อคุณคลิก preview คุณจะเห็นว่านี่คือปฏิทิน นี่คือเวลาว่างทั้งหมด นี่คือสิ่งที่ AI agent ของเราจะดึงมาและให้กับผู้ใช้ของเรา แต่ก่อนหน้านั้นผมต้องไปที่ event types ตอนนี้ผมต้องไล่ดูทุกอีเวนต์และรับ event ID นี่คือตัวเลขตรงนี้ด้านบน นี่คือ event ID สำหรับ quick massage ตอนนี้ผมต้องแทนที่มันตรงนี้ นี่คือ event ID ของ quick massage เรายังมีมันตรงนี้ด้วย ผมมีมันหลายจุดเพราะมันสำคัญมากที่ AI agent จะได้อันนี้ถูกต้อง มันสำคัญยิ่งต่อกระบวนการจอง

จากนั้นอีเวนต์ถัดไป เราเลือกอันถัดไปตรงนี้ อันนี้เลือก ID สำหรับบริการนวดถัดไป แล้วเรามีมันตรงนี้ไหม ตรงนี้ สามจุด และผมมีอันถัดไปอันนี้ และตรงนี้ด้านล่าง ตอนนี้ผมจะสมมติว่าผมมีสามบริการ ดังนั้นถ้าคุณมีบริการน้อยกว่านั้น คุณก็แค่เอาออกหนึ่งอัน ถ้าคุณมีมากกว่านั้น คุณก็เพิ่มหนึ่งอัน ตรงนี้ผมจะบอกว่าสาม ผมจะลบอันที่สามนี้ ลบอันนี้ แล้วก็เสร็จ เมื่อคุณปรับรายละเอียดอื่น ๆ เกี่ยวกับอันนี้แล้ว คุณสามารถคลิก save ได้ ตอนนี้ก็แค่นั้นสำหรับตอนนี้ในส่วนนี้

ต่อไปเราจะเชื่อมต่ออันนี้ตรงนี้ อันนี้ก็เหมือนเวิร์กโฟลว์การจอง บัญชี Google Sheet กับบัญชี Google เชื่อมต่ออยู่แล้ว ตรงนี้เลือก Google Sheet เดียวกัน แล้วอันนี้แค่รับรายละเอียด โดยพื้นฐานแล้วมันทำงานแบบนี้: เมื่อมีคนพิมพ์คำว่า confirm ใน WhatsApp และ AI agent จะขอให้พวกเขายืนยันการจองเมื่อมันสรุปวันได้แล้ว มันจะไปที่เวิร์กโฟลว์นี้ แล้วมันจะประมวลผลการจองและจองนัดหมายจริง ไม่มีอะไรให้ตั้งค่ามากตรงนี้สำหรับตอนนี้ เพราะเราจะทดสอบสิ่งนี้ในวิดีโอถัดไปว่ามันทำงานหรือไม่ จากนั้นมันจะส่งข้อความถึงผู้ใช้ว่า เฮ้ การจองสำเร็จแล้ว และบันทึกลงใน Google Sheet ว่าคนนี้จองแล้ว และนั่นคือทั้งหมดสำหรับตอนนี้ มาคลิก save กัน
