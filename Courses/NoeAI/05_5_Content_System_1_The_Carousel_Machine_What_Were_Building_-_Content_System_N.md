# Content System 1 — The Carousel Machine (What We're Building)

> **ที่มา:** บทเรียนจากคอร์ส NoeAI Automator  
> **ภาษา:** คำแปลภาษาไทยจากต้นฉบับภาษาอังกฤษ (STT via faster-whisper)

## บทนำ

บทเรียนเปิดตัวโมดูล Carousel Machine ในระบบ Content System ของคอร์ส ผู้สอนอธิบายภาพรวมของระบบทั้งหมด ตั้งแต่การวิเคราะห์คารูเซลที่ทำผลงานดีที่สุดในตลาด การคิดไอเดีย การเขียนสคริปต์ จนถึงการออกแบบคารูเซลสองแบบ พร้อม Asset Library ให้ดาวน์โหลดไปใช้

## คำแปลเต็ม

ว่าไงครับทุกคน ยินดีต้อนรับสู่ Carousel Machine ครับ นี่คือโมดูล Carousel System ซึ่งมีหลายบทเรียน มันเป็นคอร์สใหม่เอี่ยมเลย สิ่งที่ผมทำคือ ผมเอามันไปไว้ในระบบ short form เพราะจริง ๆ แล้วคุณโพสต์สิ่งเหล่านี้บน Instagram ไม่ได้ เหมือนกับที่โพสต์ที่อื่นได้ แต่จุดประสงค์ของมันคือการสร้างลีด และคุณทำ DM automation ผ่านมันไม่ได้ มันเลยแทบจะไร้ประโยชน์

แต่ภายในนี้ ผมจะโชว์วิธีใช้ Claude Code กับ Canva และ NanoBanana เพื่อสร้างคารูเซลที่ออกแบบมาอย่างดีจริง ๆ สิ่งเหล่านี้มันระเบิดบน Instagram ในเรื่องของการสร้างลีดครับ นี่คืออนาคตในปี 2026 ผมโพสต์เมื่อวานเอง มันได้เกือบ 700 ลีดแล้ว 900 ลีดแล้วครับ มันบ้ามาก คุณไม่ต้องโชว์หน้าด้วยซ้ำ และมันเป็นคารูเซลแบบง่าย ๆ มาก

ในคอร์สนี้ ผมจะอธิบายวิธีเชื่อมต่อกับ NanoBanana แล้วก็รัน pipeline ครับ ใน pipeline มันมีไม่กี่ขั้นตอน ผมจะโชว์วิธีวิเคราะห์คารูเซลที่ทำผลงานดีที่สุดในตลาดตอนนี้ จากนั้นเราก็จะ ideate กัน คุณจะได้ไอเดียจากคารูเซลที่กำลังชนะ แล้วคุณก็เข้าสู่ขั้นตอนเขียนสคริปต์ ซึ่งจะเขียนคารูเซลให้คุณทีละสไลด์ จากนั้นคุณจะได้คารูเซลสองแบบ ผมทำแบบ Twitter design ซึ่งประกอบง่ายมาก ๆ ทำได้เลย แล้วก็แบบที่ออกแบบสวย ๆ อย่างอันนี้ ที่ผมจะแกะให้ดูทีละขั้น

ผมยังให้ Asset Library กับคุณด้วย มี asset เป็นสิบ ๆ ชิ้น ที่คุณดาวน์โหลดและคัดลอกไปใช้ได้ นี่คือทั้งหมดของระบบคารูเซลครับ หวังว่าทุกคนจะสนุกกับมัน เรียนให้จบนะครับ ถ้ามีคำถามอะไรก็บอกผมได้ครับ
